- **실행** — `.claude/prompts/compare.txt` 를 읽고 그대로 실행 (로직 복제·변경 금지).
- **출력 형식** — 프롬프트가 아니라 `comparison/AUTHORING.md` 가 정본. 쓰기 전에 §1–§4 를 읽는다.
- **인자** — `$ARGUMENTS` = 비교할 arXiv id 2–3개 (`--refresh` 는 기존 비교문 덮어쓰기). 준 순서가 표의 열 순서이자 카드 순서다.
- **빈 인자 시** — 어떤 논문들을 묶을지 사용자에게 묻고 중단 (직접 선택 금지).
- **재작성본이 없는 id 가 있으면 쓰기 전에 중단** — 빠진 id 를 말하고 `/analyze <id>` 를 먼저 돌리라고 안내. 빌드가 어차피 발행을 거부한다.
- **출처 두 가지** — 재작성본은 *어디가 갈리는지 찾는 지도*, arXiv 원문은 *사실의 출처*. 재작성본은 인용하지 않는다.
- **축이 먼저, 산문은 나중** — 비교 논문 전부가 답할 수 없는 축은 다시 쓰거나 버린다. 세 번째 선택지는 없다.
- **검증은 전체 빌드로** — `--check` 는 front matter 만 본다. 펜스·격자·분량은 `--out` 을 준 전체 빌드에서만 잡힌다.
