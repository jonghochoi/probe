## 1. Identity [STABLE] [AGENT-INPUT]

> Data is upstream of method. The VLA-level pivot rests on the pretraining corpus (P4 D22), with **egocentric human video as the primary data axis**. P0 is the dedicated **data/benchmark scouting front-end**: it systematically surfaces VLA datasets (robot action / human-egocentric video / mixed) and the **tactile / force / torque–bearing** corpora that are scarce but load-bearing for hand-centric contact, plus the benchmarks and eval harnesses that measure progress. Its output feeds the P4 pretraining-data decisions. Task specification stays goal-centric (arm-hand integrated).

**Decomposition (P0-relevant)**
- *Antagonist*: method/architecture papers shipping no released dataset or benchmark; toy single-task demo sets too small for pretraining; vision-only corpora presented as sufficient for contact-rich dexterity
- *Protagonist (P0 owns)*: egocentric-centric data scouting (human ego video + 3D hand tracking) + tactile/FT/torque corpora + dexterous / contact-rich benchmarks + VLA eval harnesses, each tagged by modality coverage, license, scale, and lineage
- *Downstream context*: feeds P4 D22 (pretraining corpus); the egocentric emphasis sets the priority data axis (D24); tactile/torque coverage feeds P2 (observation fusion) and P3 (contact)

> **Note**: P0 owns the data/benchmark half. Architecture (P1), observation

## 2. Pillar P0 — VLA Datasets & Benchmarks [STABLE structure, LIVING content] [AGENT-INPUT]

**Scope**: scout and triage (a) **robot-action** datasets (teleop / sim-augmented, single- to multi-embodiment), (b) **human-egocentric** video corpora with hand/finger tracking, (c) **mixed** human→robot retargeted corpora, (d) **tactile / force / torque** datasets (the scarce contact modality), and (e) **benchmarks / eval harnesses** (dexterous + contact-rich manipulation, sim and real). Each entry is recorded with modality coverage, scale, embodiment/DOF, license, and lineage (what stacks on what). Curation lands in the §5 pin tables and the scouting reports.

**Identity tie**: "data is upstream of method" — a dedicated front-end so the pretraining corpus (P4) and the egocentric data priority are evidence-driven, not incidental.

**Tracked items**: priority data axis (D24), tactile/torque data scouting (D25), benchmark/eval scouting scope (D26), license/usability bar (D27).

**Anti-topics**: method-only papers with no released data/benchmark; sub-pretraining-scale single-task sets; vision-only corpora pitched as sufficient for dexterity; non-manipulation corpora (driving/navigation) unless egocentric-hand-relevant.

**Literature anchor**: EgoDex (egocentric dexterous, flagship), Ego-Exo4D (paired ego-exo), UniHand-2.0 (mixed retarget), AgiBot World (large robot action), DROID (in-the-wild), RH20T (wrist F/T — tactile/torque), ManiSkill 3 (sim benchmark), vla-eval (eval harness). See §5.

## 3. Decision Log — P0 (D24–D27) [LIVING] [AGENT-INPUT]

v1 choice per decision (first-attempt default; rationale and deferred candidates
held outside the context file). P0 covers **D24–D27**; P1 (D1–D7), P2 (D8–D12),
P3/System0 (D13–D18), P4 (D19–D23), P5/World Model (D28–D32) are out of scope
here — see `context/MASTER.md`.

#### [D24] Priority data axis (P0)
- **v1**: **egocentric human video–centric** (the priority data axis), with robot-action and mixed human→robot corpora as supplements. Pure third-person robot-only corpora are tracked but down-weighted vs egocentric + hand-tracking sources
#### [D25] Tactile / force / torque data scouting (P0)
- **v1**: actively scout tactile / 6-axis F/T / joint-torque–bearing datasets (RH20T-class); treat their scarcity as a **first-class gap** (most large corpora are vision-only). Flag any new contact-modality release with high priority
#### [D26] Benchmark / eval scouting scope (P0)
- **v1**: dexterous + contact-rich manipulation benchmarks and VLA **eval harnesses**; track both sim (ManiSkill / Isaac Lab / Robocasa) and real (RoboArena-class) suites. In-hand-rotation / articulated-tool evals (CATFA precedent) prioritized for identity-relevant phasing
#### [D27] License / usability bar (P0)
- **v1**: prefer permissive (Apache-2.0 / CC-BY / MIT); gated corpora (Ego4D / Ego-Exo4D) tracked but flagged ⚠️; record per-dataset license + lineage with every tracked entry. NC-only licenses tracked but flagged for downstream-use risk

## 4. P0 Anti-topics (Noise Filter) [AGENT-INPUT]

Excluded from the digest unless an unusually strong tie to P0 or a P0 Decision (D24–D27):

- Method / architecture papers that release no dataset or benchmark
- Single-task demonstration sets below pretraining scale (unless a benchmark)
- Vision-only corpora pitched as sufficient for contact-rich dexterity
- Non-manipulation corpora (autonomous driving, navigation) unless egocentric-hand-relevant
- Pure data-engineering tooling without a released corpus
- Survey / position papers (read manually, not via agent)
