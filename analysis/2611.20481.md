# 손목 궤적 하나를 얻으려고 3D 모델이 지어 낸 장면을, 버리지 않고 인코더에 가르친다

## 1 무엇이 문제인가

### 사람 영상에는 행동이 없다 | Human-video Pretraining · Frozen Encoder · Behavior Cloning

로봇 조작 데이터는 한 건 한 건 비싸서 대규모로 모으기 어렵습니다. 그래서 이 계열의 연구는 정책 전체가
아니라 **정책의 눈**, 곧 시각 인코더를 먼저 사람 영상으로 사전학습해 둡니다. 사람 영상은 부엌에서
컵을 들고 서랍을 여는 장면을 엄청난 규모로 담고 있으니까요. 문제는 원문의 표현대로 그런 영상에는
**행동과 관련된 표현이 본래 없다**는 것입니다. 손이 어디로 갈지, 무엇을 잡을지가 라벨로 붙어 있지
않습니다.

이 논문의 평가 틀은 이 계열의 관례를 그대로 따릅니다. 사전학습이 끝난 인코더는
[동결](term:frozen-enc)되어 지각 앞단이 되고, 그 위에 가벼운 정책 헤드만
[행동 복제](term:bc)로 학습합니다. 인코더가 무엇을 배웠는지가 정책 성능으로 곧장 드러나는 구조죠.

### 2D 단서는 시간이 없고, 3D 궤적은 너무 성기다 | 2D Visual Primitives · 3D Hand Trajectory · 3D Foundation Models

사람 영상에서 행동 관련 표현을 꺼내는 방법을 원문은 두 갈래로 나눕니다.

첫째는 **2D 시각 단서**입니다. 접촉점, 접촉 히트맵, 물체 바운딩 박스처럼 '어디서 접촉이 일어나고
어느 영역이 조작에 끼는가'를 이미지 평면에 표시합니다. HRP(접촉 히트맵)나 MPI(물체 바운딩 박스)가 이쪽입니다. 원문의 판정은
짧습니다 — 이 단서들에는 **3D 조작 과정의 시간적 표현이 없다.**

둘째는 영상에서 **3D 손 궤적**을 추정하는 쪽입니다. 손이 3D 공간에서 얼마나 움직였는지와 그 변위가
시간에 따라 어떻게 변하는지를 함께 담으니, 로봇이 예측해야 할 행동 공간에 더 가깝습니다. 최근
[3D 파운데이션 모델](term:3dfm)이 발전하면서 이 궤적 추정의 정확도가 크게 올라왔습니다. VITRA 나
Being-H0(둘 다 사람 영상으로 VLA, 곧 시각-언어-행동 모델을 사전학습)가 이 흐름입니다.

교사 토큰과의 유사도로 가중치를 정합니다(부록 A.3). 3층 [CLS] 는 암묵적 기하를, 6층 [CLS] 는 깊이
재구성으로 다듬어진 명시적 기하를 담는다는 것이 원문의 근거입니다.

```probe-term
{"id": "cls", "title": "[CLS] token",
 "body": "ViT 가 패치 토큰 앞에 붙이는 학습용 전역 토큰. 층마다 이미지 전체를 요약한 표현이 됩니다. 이 논문은 [CLS] 를 두 번 씁니다 — 교사 가중치를 정하는 질의로, 그리고 [CLS] 에서 패치로 가는 어텐션 지도를 '모델이 어디를 보나'의 읽기값으로."}
```

```pseudo 알고리즘 1 — 두 교사의 몫을 인코더 자신의 [CLS] 두 개로 정한다
Input: c_l, c_m from the l-th and m-th layers; geometric tokens E'_c, E'_d
Output: global modulation weights w_c, w_d
1: Q <- Unsqueeze(MeanPool(Concat(c_l, c_m)), 1)        # 질의 — 정렬 층과 깊이 재구성 층의 [CLS] 를 이어 붙여 512 채널 묶음으로 평균
2: for all j in {c, d} do
3:     E_pool_j <- MeanPool(E'_j)                        # 교사 토큰도 같은 512 채널 묶음으로 평균 — 두 교사를 같은 폭에서 비교
4:     S_j <- Squeeze((Q E_pool_j^T) / sqrt(D), 1)       # 패치 토큰마다 스케일드 내적, D = 512
5:     s_j <- (1 / N_a) * sum_i S_j[:, i]                # 토큰 평균 — 샘플 하나에 점수 하나
6: end for
7: G <- Softmax([s_c, s_d])                              # 샘플마다 두 교사 사이의 게이트
8: w_c <- avg(G[:, 0]); w_d <- avg(G[:, 1])              # 배치 평균 — 스텝마다 가중치 한 쌍을 식 (2) 에 넣음
9: return w_c, w_d
```

1행의 질의가 이 장치의 핵심입니다. 가중치를 정하는 것이 별도의 학습 모듈이 아니라 **인코더가 지금
만들어 낸 전역 표현**이라서, 인코더가 이미지를 어떻게 보느냐에 따라 샘플마다 게이트가 달라집니다. 원문은
이 설계를 시각 인코더 혼합의 지식 증류(Move-KD)에서 빌려 왔다고 밝힙니다.

다만 8행에서 그 게이트를 배치 평균하므로, 손실에 실제로 걸리는 것은 **학습 스텝마다** 한 쌍의 가중치입니다.
원문의 동기는 '장면마다 최적 기여가 다르다'인데, 가중치가 바뀌는 단위는 장면이 아니라 배치입니다 — 이
간격을 원문은 따로 설명하지 않습니다.

### 6층에서 깊이 지도를 다시 그린다 — See ① | Structural Guidance · Depth Reconstruction · Patchwise Decoder

Lift 가 만든 3D 표현은 원문 표현으로 **암묵적**입니다. 정책 토큰이 교사 특징과 방향이 비슷해졌을 뿐,
장면의 구조를 명시적으로 안다는 보장은 없습니다. See 단계의 첫 번째 안내는 그래서 노골적입니다 —
6층($`m=6`$) 패치 토큰으로 데이터 엔진이 만든 미터 깊이 지도를 다시 그리게 합니다.

고정 2D 사인-코사인 위치 임베딩을 더한 뒤, 8 헤드 셀프어텐션 블록 **8개**를 통과시킵니다. 선형 헤드가
토큰 하나를 $`16\times16`$ 패치의 깊이값 256 개로 펴고, 겹치지 않게 접어서 $`224\times224`$ 깊이 지도를
만듭니다. 예측은 패치 단위, 감독은 픽셀 단위입니다.

### 손 위치로 가장 닮은 머리를 고르고, 층 평균의 선생으로 삼는다 — See ② | Attentive Guidance · Self-distillation · Hand Prior

두 번째 안내는 '어디를 보나'입니다. 원문은 사람 영상에서 어포던스 — 물체의 어디를 어떻게 다룰 수 있는지 — 를 배우는 것이 사전학습에 도움이
된다는 선행 연구에 기대어, 인코더가 **손 중심의 상호작용 영역**에 집중하게 만들려 합니다. 여기서
흥미로운 것은 목표를 정하는 방식입니다. 손 히트맵을 그대로 목표로 쓰지 않고, **모델 안에서 이미
손을 보고 있는 어텐션 머리를 찾아 그것을 목표로** 씁니다.

순서는 이렇습니다. 먼저 움직임 예측 목표 하나로만 인코더를 **10 에폭** 예열해, 과제 관련 어텐션
패턴이 생겨나게 둡니다. 그 다음 손 관절 검출기 MediaPipe 로 손 관절 21 개를 검출해 가우시안 히트맵을 만들고, 패치
격자로 줄여 공간 사전분포 $`\mathbf{h}`$ 를 얻습니다(부록 A.7). 처음 $`R=6`$ 개 층의 모든 머리에서
[CLS]→패치 어텐션 지도 $`\mathbf{A}_{n,k}`$ 를 꺼내, 손 사전분포와의 정렬 점수를 잽니다.

**기준선** — 2D 기준선은 모두 같은 시연, 같은 동결, 같은 헤드(은닉 256 의 3 층 MLP). VIP 는 원 프로토콜대로

### 손가락을 감독하면 나빠졌다 — 손목 세 점이 행동 표현 | D1WE · D3RP · Wrist Proxy

하나는 2D 입니다. Act 만 2D 궤적으로 바꾸면 56.3% 로 무너졌습니다. 다른 하나는 손가락입니다. MANO 손 메시 감독을 더하면 예비 실험에서 나빠졌다고
