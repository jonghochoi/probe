# 행동 손실은 정책이 어디를 보고 맞혔는지 묻지 않는다 — 학습 때만 어텐션에 정답 지도를 걸면, 구조도 입력도 그대로인 정책이 방해물 앞에서 덜 무너진다

## 1 무엇이 문제인가

### 행동 손실은 '무엇을 보고' 맞혔는지 묻지 않는다 | Fine-tuning · Shortcut Learning · Visual Evidence

배포하려면 대개 과제별 [파인튜닝](term:finetune)이 필요합니다. 원문은 여기서 로봇 모델을 LLM 과 대비합니다. LLM 은 추가 학습 없이도 곧잘 쓰이는 데 비해

저자들이 짚는 원인 중 하나는 **감독의 빈칸**입니다. 파인튜닝은 행동만 지도할 뿐, 어떤 시각 증거를 근거로 삼아야 하는지는 제약하지
않습니다. 그래서 좁은 학습 분포 안에서만 행동을 잘 예측해 주는 단서가 있으면 정책은 그것에 기댈 수 있습니다. 이것이
[지름길 학습](term:shortcut)입니다. 머그를 집는 정책이라면 머그, 로봇, 그 둘의 공간 관계를 근거로 행동해야 하지만,
손실만 보면 우연히 시연과 함께 나타난 배경 무늬, 조명, 함께 놓인 물체, 카메라 특유의 흔적에 기대도 값이 낮아집니다.

## 2 무엇을 바꿨나

### 정책 옆의 작은 예측기 — 입력은 같고, 나오는 것은 관련도 지도 | AFP Architecture · MobileNetV3 · Deformable DETR

AFP 의 입력은 정책이 받는 것과 같은 RGB 와 지시문이고, 출력은 프레임마다 $`[0,1]^{H\times W}`$ 의 연속 관련도 지도입니다.
조작 대상과 로봇 말단 등 행동에 중요한 자리는 1 에 가깝고 나머지는 0 에 가깝습니다. 이름은 사람의 중심와(fovea)에서
왔습니다. 필요한 자리만 자세히 보고 주변은 억제한다는 비유입니다(원문 §3.1). 정책과 분리된 별도 모델이라 **같은 마스크를 여러
정책 파이프라인에 공통으로** 쓸 수 있습니다.

구조는 두 경로입니다. 특징 경로는 공간 디테일을 보존하고, 쿼리 경로는 어느 영역이 과제와 관련되는지 추론합니다.

### 어텐션과 마스크를 같은 격자의 분포로 맞춘다 | Grounding Loss · Attention Target · Inference Unchanged

이제 이 논문의 중심입니다. 마스크를 정책의 **입력에 넣지 않습니다.** 파인튜닝 동안 정책의 이미지 토큰 어텐션을 뽑아 층, 헤드, 쿼리
위치에 걸쳐 평균한 $`\bar{\mathbf{a}}`$ 를 만들고, AFP 마스크를 같은 토큰 격자로 평균 풀링한 $`\mathbf{w}`$ 와 비교합니다.

```probe-eq
{"read": "합이 1 이 되게 정규화한 어텐션과 마스크의 제곱 거리를 배치에 걸쳐 평균한다",
 "tex": "\\mathcal{L}_{\\text{AFP}}=\\frac{1}{B}\\sum_{b=1}^{B}\\left\\|\\frac{\\bar{\\mathbf{a}}_{b}}{\\sum_{i}\\bar{a}^{(i)}_{b}}-\\frac{\\mathbf{w}_{b}}{\\sum_{i}w^{(i)}_{b}}\\right\\|_{2}^{2}",
 "symbols": [{"sym": "\\bar{\\mathbf{a}}_{b}", "name": "평균 어텐션", "note": "학습되는 층·헤드·쿼리 위치에 걸친 평균"},
             {"sym": "\\mathbf{w}_{b}", "name": "풀링된 AFP 마스크", "note": "이미지 토큰 격자에 맞춘 값, 범위 [0, 1]"},
             {"sym": "B", "name": "배치 크기", "note": "—"}]}
```

정규화 때문에 이 손실은 절대적인 어텐션 양이 아니라 **이미지 토큰 사이의 배분**만 비교합니다. 전체 손실은
$`\mathcal{L}=\mathcal{L}_{\text{act}}+\lambda\mathcal{L}_{\text{AFP}}`$ 입니다. 원문은 $`\lambda`$ 의 값을 적지 않습니다.

> [!NOTE] 배포 때 AFP 는 없다
> 마스크는 정책 어텐션의 지도 대상으로만 쓰입니다. 그래서 AFP 는 파인튜닝 데이터에서만 돌고, 학습이 끝나면 정책은 원래 관측 스트림을 받으며 제어 루프에 AFP 호출이 없습니다. 덕분에 추론 지연도 구조 변경도 더해지지 않습니다.

원문의 '어텐션'은 정확히 어느 어텐션일까요? 어텐션 가중치는 어떤 토큰(쿼리)이 어떤 토큰(키)을 얼마나 보는지를 나타냅니다. 이 쿼리는 앞서 나온 AFP 의 영역 쿼리와 다른 말로, 정책 안에서 시선을 보내는 쪽 토큰입니다. 본문은 '학습되는 층, 헤드, 쿼리 위치의 평균'에서 멈추지만, 공개 코드는 더 구체적입니다.

```python 어텐션 보조 손실의 핵심 — 공개 코드에서 줄인 발췌
# afp_integrations/attention_aux_loss.py :: attention_afp_loss
# 행동·상태 쿼리는 제외하고 prefix(이미지 + 언어) 쿼리만 쓴다
q_end = prefix_len if prefix_len is not None else attn_weights.shape[2]
img_attn = attn_weights[:, :, :q_end, :n_img_tokens]   # 기본 16 x 16 = 256 토큰
avg_attn = img_attn.mean(dim=(1, 2)).float()           # 헤드와 쿼리 위치 평균

# 분모는 detach: 어텐션을 줄이는 쪽으로 흐르는 되먹임을 끊는다
avg_attn_norm = avg_attn / avg_attn.sum(dim=-1, keepdim=True).detach().clamp(min=1e-8)
target = afp_masks.float()
target = target / target.sum(dim=-1, keepdim=True).clamp(min=1e-8)

per_sample = ((avg_attn_norm - target) ** 2).mean(dim=-1)  # 합이 아니라 토큰 평균
```

### 2 만 스텝에 11,152 번 — 충돌은 예외가 아니었다 | Projection Ablation · Cosine Similarity · Onset Spike

사영을 빼면 어떻게 될까요? 부록 A 의 절제입니다.

사영이 없으면 총 손실이 처음에는 줄다가 그림에 onset 으로 표시된 지점(그림으로 읽으면 약 11k 스텝) 뒤 급등합니다. 사영이 있으면 원문의 표현대로 매끄럽게 단조 감소합니다. [코사인 유사도](https://arxiv.org/html/2607.10655v3/afp_pcgrad_cos_sim.svg)는 학습 초반에 크게 흔들리며 자주 음수가 되고, 학습이 진행되면 0 근처로 모입니다. 저자들은 이를 접지 목표가 행동 학습과 점점 양립해 간다는 신호로 봅니다. 20k 스텝 동안 사영이 11,152 번 일어났으니, 충돌은 드문 사건이 아닙니다. 저자들은 불안정의 원인이 AFP 신호 자체가 아니라 **풀리지 않은 기울기 충돌**이라고 읽습니다. 이 곡선이 보여 주는 것은 손실의 안정성이고, 사영 유무에 따른 성공률 비교는 원문에 없습니다. 어느 모델과 과제의 곡선인지도 적혀 있지 않습니다.

이 읽기에는 원문이 건너뛴 곳이 둘 있습니다. 코사인 패널을 눈으로 읽으면 값이 전 구간에서 대략 ±0.13 안쪽이고, 원문의 두 수로 계산하면 사영은 전체 스텝의 약 56 % 에서 일어납니다. 두 기울기가 거의 직교한 채 부호만 오가는 셈이라, 한 번의 사영이 깎는 몫(보조 기울기 크기 × |cos|)은 작습니다. 또 원문은 충돌이 초반에 특히 문제라고 쓰는데, 급등은 코사인이 잦아든 뒤인 약 11k 스텝에서 시작합니다. 코사인 패널이 어느 쪽 학습의 것인지 적혀 있지 않아 이 대조는 조심해서 읽어야 합니다.

작은 사영이 어떻게 급등을 막는지 원문은 설명하지 않습니다. 공개 코드(`afp_integrations/attention_aux_loss.py`)의 주석은 다른 단서를 줍니다. `pcgrad` 모드 설명은 사영이 방향을, `aux_weight` 가 크기를 맡는다고 나누고, 가중치가 없으면 보조 기울기가 방향을 지배하고 클리핑이 행동 신호를 약화해 학습률이 커질 때 손실이 튄다고 적습니다. 그림의 No PCGrad 가 어떤 설정인지는 코드로도 확인되지 않습니다.

> [!CAUTION] D3WV — 지표는 정렬됐는데 낙차는 남는다

감독만으로는 이득이 작다는 다른 논문들과 AFP 의 어긋남이, 이 논문을 읽고 남는 가장 큰 질문입니다. [FoveaVLA](https://arxiv.org/abs/2610.20064) 에서 상자 감독은 +6.3 점, [V-Link](https://arxiv.org/abs/2608.25308) 에서 주입 없는 감독은 +1.8 점이었습니다(과제와 지표는 각기 다릅니다). 왜 AFP 만 감독으로 큰 이득을 냈을까요? 후보를 들자면, AFP 의 OOD 가 **눈에 보이는 방해물이라는 한 종류로 좁혀져** 어텐션 지도와 맞물리기 쉬운 평가라는 점이 있고, 감독 대상이 추가 예측 헤드가 아니라 **VLM 의 어텐션 자체**라는 점도 있습니다. 원문으로는 가를 수 없습니다.

[VT-WAM](https://arxiv.org/abs/2607.02503) 은 또 다른 대조입니다. 같은 '학습 때만 지도'지만, 벌점을 **행동 쿼리의 어텐션**에 물립니다. 동결 구성으로 옮길 때 참고할 만한 위치입니다.

저자들의 한계인 '마스크 데이터 분포 밖'은 다지 손에서 곧바로 문제가 될 것 같습니다. 원문에는 다지 손 실험이 없고, 손은 물체를 감싸며 가리므로 '말단과 물체를 1 로' 칠하면 지도가 무엇을 뜻하는지가 달라집니다. 접촉 관련 특징을 보존하자는 결정과 닿는 자리입니다(D3AG).

#### 먼저 확인할 것

- **가장 싼 점검 — 동결 아래 보조 기울기 범위.** 공개 `AuxGradientCombiner` 는 첫 스텝에서 보조 기울기를 받는 파라미터 수를 로그에 남기고, 보조 손실에 기울기가 아예 없으면 `RuntimeError` 로 멈춥니다. 우리 동결 설정으로 한 스텝만 돌려 어느 쪽인지 봅니다. 그 오류 문구는 훅 설정 실수를 먼저 가리키므로 훅이 층을 잡았는지도 함께 봅니다. 학습 없이 호환 여부가 나옵니다(D3RP).
- **지도 대상을 행동 쿼리로 옮기기.** 같은 손실을 행동 전문가의 이미지 어텐션에 걸어 OOD 가 움직이는지 재 봅니다. 공개 함수는 쿼리를 앞쪽 `q_end` 까지만 자르므로 행동 쿼리만 고르려면 슬라이스를 고쳐야 합니다. 동결을 유지한 채 쓸 수 있는 경로로 보입니다.
- **마스크 품질 절제를 직접.** 원문에 빠진 실험입니다. 마스크를 뭉개거나 일부러 빗나가게 해 OOD 이득이 따라 변하는지 보면 초록의 인과 주장을 시험할 수 있습니다.

- **손에서 마스크의 정의.** '손 전체 + 물체'와 '접촉 손끝 + 물체' 두 라벨을 소량 만들어 공개 데이터로 학습한 AFP 의 예측이 어디서 무너지는지 봅니다. 공개 README 는 체크포인트를 직접 준비하게 하므로 학습이 전제입니다.
- **보존 비용.** VLM 을 연 조건이라면 사전학습 과제의 성능도 함께 재, OOD 이득이 무엇과 맞바뀌는지 봅니다(D5ZL).
