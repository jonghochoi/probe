## 🧭 한 줄 요약 (TL;DR)

UAM 은 VLA 가 action-only fine-tuning 으로 VLM 다중모달 능력을 잃는
"embodiment tax" 의 구조적 원인을 단일 인코더 병목으로 진단하고,
생성형 사전학습 가중치(Bagel)로 초기화된 별도의 Dorsal Expert 를 MoT
로 병렬 결합한 뒤 visual-dynamics 보조 손실로 학습함으로써 freezing /
gradient stop / VL co-training 없이도 VLM 능력의 95 % 이상을 유지하고
OOD 매니퓰레이션에서 최고 성공률을 달성합니다.

---

## ❓ 문제 정의 / 동기

표준 VLA 레시피는 사전학습 VLM 위에 action loss 만으로 fine-tune 하는데,
저자들은 이 과정이 VLM 의 멀티모달 역량(open-vocab 인식, 속성·공간
추론, OCR, 다국어 grounding 등)을 측정 가능한 수준으로 침식한다는
점을 여러 backbone(Qwen2.5-7B, PaliGemma) × 여러 coupling(Freeze /
+MoT / +MLP) 에서 확인합니다. 기존 처방인 VLM freeze 는 정적 feature
에 control 을 가두고, VL co-training 은 보조 데이터의 규모·다양성
의존성과 objective 간섭을 남기는 등 *증상* 만 다룰 뿐이라는 진단입니다.
저자들은 이 망각을 "단일 인코더로 인식(ventral)과 시각운동
제어(dorsal)를 동시에 통과시키는" 구조적 병목 문제로 재정의하고,
neural 의 dual-stream 조직에서 영감을 받은 architectural separation
으로 풀고자 합니다.

## 🧩 핵심 기여

- **Embodiment tax 의 측정·정량화** — 상대 점수 강하
  $\Delta(f_{\text{VLA}}) = 1 - S(f_{\text{VLA}}) / S(f_{\text{VLM}})$
  를 정의하여 두 backbone × 세 coupling 에서 forgetting 을 통일된
  지표로 비교(Tab. 3).
- **Bottleneck 가설** — MoT 로 parameter 를 분리해도 $E_{\text{act}}$
  가 소비할 시각 feature 는 결국 $\theta_{\text{sem}}$ 의 업데이트로
  공급되므로 "단일 인코더 병목" 이 망각의 구조적 원인이라는 주장.
- **Dorsal Expert 의 도입** — semantic / dorsal / action 의 3-expert
  MoT 구조로 시각 경로를 두 갈래로 분리.
- **설계공간 통제 실험** — initialization(random / VLM / generative
  UMM) × input modality(visual tokens / learnable queries) × auxiliary
  loss(없음 / visual-dynamics) 의 6 variant 스윕(Tab. 1, Fig. 4).
- **UAM(Variant 3b)** — 생성형 UMM(Bagel) 초기화 + visual-dynamics
  보조 손실의 조합만이 frozen-$E_{\text{sem}}$ 프로브 하에서도 action
  성능을 유지하며 Dorsal pathway 가 실제로 control 시각 feature 를
  운반한다는 증거 제시.
- **End-to-end 학습으로 95 % 이상 VLM 능력 보존** — freezing /
  gradient stopping / VL replay 없이 action-only 데이터로 학습했음에도
  multimodal 벤치마크 평균 5 % 미만 강하(Tab. 2).
- **Emergent attention decoupling** — 명시적 grounding 감독 없이도
  $E_{\text{sem}}$ 은 target object / goal region 에, $E_{\text{dor}}$
  는 로봇 팔 · 상호작용 영역 · 전역 컨텍스트에 집중하는 분기가 자연
  발생(Fig. 6, §11.2).

## 🔬 방법론

**문제 정식화.** VLA $\pi_\theta$ 는 관측 $I_{i,t}$ 과 명령 $L_i$ 를
end-effector pose + gripper state $a_{i,t} = \pi_\theta(I_{i,t}, L_i)$
로 매핑합니다. 표준 VLA 는

$$a_t = E_{\text{act}}(E_{\text{sem}}(I_t, L; \theta_{\text{sem}}); \theta_{\text{act}})$$

형태로 $E_{\text{sem}}$ 이 의미와 제어를 동시에 책임지는 병목 구조입니다.

**Dorsal Expert.** UAM 은 시각 입력을 받는 별도 경로 $E_{\text{dor}}$
를 도입하여 세 expert 가 parallel MoT 로 결합됩니다.

$$Z_{\text{sem}} = E_{\text{sem}}(I_t, L; \theta_{\text{sem}}), \quad
Z_{\text{dor}} = E_{\text{dor}}(X_{\text{dor}}; \theta_{\text{dor}}), \quad
a_t = E_{\text{act}}(Z_{\text{sem}}, Z_{\text{dor}}; \theta_{\text{act}})$$

여기서 $X_{\text{dor}} \in \{I_t, q\}$ — raw 관측 또는 learnable
query 토큰. UAM 최종형은 raw 관측 입력 + 생성형 UMM 초기화 + 보조
손실을 사용합니다.

**손실.** Variant 3a 는 $\mathcal{L}_{\text{total}} =
\mathcal{L}_{\text{act}}$, UAM(Variant 3b) 은

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{act}} + \lambda \mathcal{L}_{\text{wm}}(\hat{I}_{t+1}, I_{t+1})$$

로 goal-observation prediction 을 보조 supervision 으로 부과합니다.

**구현 세부.** $E_{\text{sem}}$ 과 $E_{\text{dor}}$ 모두 Bagel
체크포인트로 초기화하고, ViT 토큰은 $E_{\text{sem}}$ 으로, VAE 토큰은
$E_{\text{dor}}$ 으로 라우팅합니다(§9.3). BagelVLA 의 single-step
denoising 을 채택하여 world-model expert 가 이미지를 전부 재구성하지
않고 중간 표현만으로 action 을 생성합니다(§13). MoT 의 attention
마스크가 expert 별 토큰 라우팅을 강제합니다(Fig. 7).

**학습 셋업.** ALOHA 양손 시스템에서 수집한 3 k trajectory 로 8 × A800
에서 30 k step, learning rate $1 \times 10^{-5}$(Qwen) / $5 \times
10^{-5}$(PaliGemma), action chunk size 24, 3-view 입력(primary / left
wrist / right wrist). FSDP + packed dataset(§12).

## 📊 실험 설정과 결과

**3.1 Forgetting 측정(Tab. 3, Fig. 2).** Calvin ABC 10 k step
full-FT 시 — 수치 verbatim:

- Qwen2.5-Freeze + MLP(7B + 10M): Action 30.12 / VQA-AVG 74.32
  (MME 2354, MMMU 53.7, MMBench 85.2)
- Qwen2.5 + MoT(7B + 1B): Action 65.98 / VQA-AVG 37.94 (MME 1675,
  MMMU 30.46, MMBench 23.54)
- Qwen2.5 + MLP(7B + 10M): Action 71.14 / VQA-AVG 0 (전 항목 0)
- PaliGemma-Freeze + MLP: Action 22.18 / VQA-AVG 53.18
- PaliGemma + MoT: Action 70.18 / VQA-AVG 10.83
- PaliGemma + MLP: Action 70.12 / VQA-AVG 0

→ 결론: MLP head 는 VLM 능력을 *완전히* 파괴(VQA-AVG = 0), MoT 는
완화하지만 여전히 큰 강하; freeze 는 보존하지만 action 성능 손실.

action query → visual key 가중치 시각화: $E_{\text{sem}}$ 은 target
object / goal receptacle 에, $E_{\text{dor}}$ 는 gripper /
interaction boundary / 전역 컨텍스트에 집중.

(7B + 7B + 2B MoT) 1500 ms. Single-step denoising 으로 추가 7B expert
의 한계 비용이 minimal 함을 강조.

## ⚖️ 한계

- 저자가 명시한 한계 — world-model 기반 bridge 가 학습·추론
  복잡도를 증가시킴(Sec. 5).
- 추론 지연은 7B + 7B + 2B = 1500 ms 로 $\pi_{0.5}$ 의 6 배. real-time
  closed-loop 제어, 특히 contact-rich 작업에는 부담.
- 평가가 ALOHA bimanual + Calvin / RoboTwin 으로, fine-finger /
  in-hand reorientation / tool articulation 같은 *dexterous* 영역은
  미검증. Pick & place · stack · sweep · drawer 류가 주력(§10).
- "5 % 이내 강하" 가 OOD action generalization 으로 *자동* 이어진다는
  주장은 동일 backbone(Bagel) 의 사전학습 능력에 강하게 의존함 —
  Qwen2.5-VL 등 다른 backbone 으로의 일반성은 §9.3 에서 추가 alignment
  비용이 필요하다고 명시.
- Visual-dynamics objective $\mathcal{L}_{\text{wm}}$ 의 $\lambda$
  민감도 / world-model 수렴이 action 학습과 어떻게 상호작용하는지의
  ablation 부재.
- 비교군의 OpenVLA 가 multimodal 벤치마크에서 일률 0 으로 보고된
  것은 동일 후처리 프로토콜의 부산물일 가능성도 있음 — 절대치
  해석에 주의.

## 🎯 관련 Pillar / Decision (P# / D#)

- **P4 (VLM Pretraining Preservation) — 정통타격.** 논문 전체가
  catastrophic forgetting 측정 → 구조적 처방의 형태로, P4 의 핵심
  문제의식과 정확히 겹칩니다. 특히:
  - **D19 (VLM FT 범위)**: 우리 v1 은 (a) full freeze + action experts
    only. UAM 은 "no freezing, no gradient stop, no VL co-training" 로
    *full unfrozen* end-to-end 학습이 freeze 대안 없이도 95 % 이상
    보존 가능하다고 주장 — D19 의 deferred (c)/(d) 트리거가 아니라
    (e) full-FT 의 새로운 가능 경로를 제시합니다.
  - **D20 (prior-preservation strategy)**: 우리 v1 은 "action-side
    adapter(=split heads)" 로 backbone 무수정. UAM 은 *architectural
    separation* 자체를 preservation 메커니즘으로 위치시켜, 이 D20 의
    옵션 공간에 "structural separation via parallel expert" 라는
    *새 옵션* 을 추가합니다.
  - **D21 (staged recipe)**: UAM 은 Stage 2 단계에서 직접 full-FT
    가능한 단일 phase 만 사용 → 우리의 Stage 3/4 deferred 진입을
    아예 우회하는 대안 제시.
- **P1 (Heterogeneous Body/Hand Action Expert) — 간접타격.**
  - **D7 (π backbone 통합/분할)**: UAM 의 3-expert MoT 는 §14.C
    의 "Reading A — Repurpose: 별도 Body 추가" 와 구조적으로 동형
    이지만, 추가되는 expert 가 *anatomical* 가 아닌 *시각경로* 분기
    라는 점에서 우리의 anatomical 분기 주장과는 *직교*. 그러나 같은
    MoT 슬롯 자원을 두고 "anatomical split + dorsal split" 의
    경합/공존 문제를 새로 부상시킵니다.
  - **D4 (Body↔Hand 정보공유)**: parallel MoT 라우팅 + attention
    mask 로 토큰별 라우팅을 강제하는 §9.3 의 구현은 D4 deferred
    "cross-attention / multi-layer" 의 구체적 prior art.
- **P2 (Structured Input-Modality Binding) — 약간 긴장.** UAM 의
  Dorsal 입력은 raw vision tokens 만 사용하며 tactile / proprio 가
  없습니다. P2 의 "구조화된 finger/palm 토큰" 과는 다른 축. 단, ViT vs
  VAE 라우팅을 통한 "encoder 종류로 expert 결정" 의 패턴은 D8/D9 의
  토큰 attribution 전략에 참고 가능.
- **P3 (System0)**: 직접 무관 — UAM 은 imitation-only.
- **P5 (Evaluation)**: D26 의 generalization/OOD 지표가 "VQA-AVG 와
  action OOD success" 두 축이라는 점에서 D25 falsifier 중 "VLM
  preservation validated by generalization/OOD metric not regressing"
  의 측정 protocol 후보가 됩니다.
- **§10 경쟁자 함의.** ChatVLA(co-training), $\pi_{0.5}$ + KI
  (knowledge insulation), TwinBrainVLA(AsyMoT frozen+trainable) 와
  같은 §10.3 architectural siblings 의 *새로운 형제* — 특히 *동일
  semantic 비교군(Bagel)을 frozen / VL-init / Gen-init 으로 변량* 한
  점에서 TwinBrainVLA 의 AsyMoT 와 직접 경합. Identity 의 "VLA-level
  pivot" 에는 *지지* (VLA-level 에서 forgetting 을 잡을 수 있다는
  증거); "post-hoc correction 은 dead end" 명제와도 정합.

## ✨ 핀 논문 대비 델타

`context/MASTER.md` §8.4 P4 핀 8 편 대비:

- **π0 / π0.5 ([arXiv:2410.24164](https://arxiv.org/abs/2410.24164), [arXiv:2504.16054](https://arxiv.org/abs/2504.16054))**:
  π0 의 frozen-backbone + action-expert 패턴 자체가 UAM 의 baseline.
  π0.5 + KI 는 본 논문 Tab. 2 에서 직접 비교되며 *VQA co-training 에도
  불구* MMMU 18.7 / MMBench 7.3 로 UAM(53.7 / 83.7) 대비 명백히 저조 —
  *co-training 의 한계를 같은 벤치마크에서 본 논문이 정량화* 한 점이
  새로움.
- **VLM2VLA ([arXiv:2509.22195](https://arxiv.org/abs/2509.22195))**:
  LoRA + NL-style action 으로 PEFT-측 forgetting 완화. UAM 은 *full
  parameter 학습* 으로 같은 목표를 달성한다는 점이 정반대 축의 새로움.
- **PriorVLA ([arXiv:2605.10925](https://arxiv.org/abs/2605.10925))**:
  frozen Prior Expert + Adaptation Expert 의 *2-expert* 패턴. UAM 은
  *3-expert*(semantic + dorsal + action) 로 확장하면서, "adaptation
  expert" 가 단순 추가가 아니라 *visual-dynamics 라는 다른 objective*
  를 가질 때만 효과가 있음을 Variant 3a vs 3b 대비로 분리 검증 — 이
  *objective 매칭* 가 PriorVLA 대비 차별점.
- **VLA-Adapter ([arXiv:2509.09372](https://arxiv.org/abs/2509.09372))**:
  Bridge Attention 은 action-side adapter. UAM 의 Dorsal Expert 는
  *시각측 adapter* + 별도 objective 라는 점이 새로움(adapter 의 위치
  반전).
- **MolmoAct2 ([arXiv:2605.02881](https://arxiv.org/abs/2605.02881))**:
  per-layer KV-cache 로 VLM 보존. UAM 은 layer 내부 conditioning 이
  아니라 *parallel expert routing* 으로 보존. 동일 목적의 두 다른
  메커니즘.
- **TwinBrainVLA ([arXiv:2601.14133](https://arxiv.org/abs/2601.14133))**:
  AsyMoT frozen generalist + trainable specialist. UAM 은 *둘 다
  trainable* 인 상태에서 separation 만으로 보존 — *freeze 의존도가 0
  으로 줄어든다는 점이 진정한 새로움*. 같은 MoT slot 위에서 P4 핀
  계열의 정반대 endpoint.
- **RT-2 ([arXiv:2307.15818](https://arxiv.org/abs/2307.15818))**:
  web/robot co-FT — 데이터 측 처방. UAM 은 *구조 측 처방* 으로 co-FT
  데이터 의존성 자체를 제거하려 함.
- **Multi-Embodiment Pretraining Data ([arXiv:2506.19121](https://arxiv.org/abs/2506.19121))**:
  데이터 측 — 직교, 비교군 아님.

**가장 큰 진짜 새로움**: "preservation = architecture, not weights /
data" 라는 명제를, 같은 VLM(Bagel) 을 동일 hyperparameter 로 freeze /
VL-init / Gen-init + Lwm 의 세 조건으로 실험적으로 분리해서 보인 점.
P4 핀 그룹은 *freezing(π0) → PEFT(VLM2VLA) → co-FT(RT-2) → 데이터(다중
embodiment) → 추가 expert(PriorVLA / TwinBrainVLA) → in-layer KV
(MolmoAct2)* 까지 갔지만, *generative initialization × visual-dynamics
matched objective* 라는 조합으로 *둘 다 unfreeze + co-FT 없음* 을
가능케 한 사례는 처음.

## ⚙️ 의사결정 함의

이 논문이 옳다면 우리 파이프라인에서 다음이 바뀝니다.

1. **D19 옵션 (e) full-FT 의 회생.** 우리 v1 (a) "full freeze + action
   experts only" 는 *backbone representation 부족* 이 trigger 였습니다.
   UAM 은 그 trigger 가 발화하기 *전* 에 — full unfrozen 으로 가도
   *architectural separation* 으로 보존이 가능함을 시사. CP1 평가에서
   D19 ablation 에 (e') "full-FT + parallel dorsal expert(생성형
   초기화)" 조건을 추가할 가치가 생깁니다.
2. **D20 옵션 추가.** "action-side adapter(v1)" 에 더해 "structural
   separation via parallel visual expert with matched objective" 를
   *공식 option list 에 등재* — UAM/PriorVLA/TwinBrainVLA 의 공통
   pattern.
3. **구체 config 키 / 하이퍼파라미터** —
   - `model.experts`: `[semantic, dorsal, action]` (현재 2-expert
     baseline 에 dorsal slot 추가, MoT routing).
   - `model.dorsal.init`: `bagel` | `pretrained_vlm` | `random`.
     UAM 결과는 `bagel` 만 의미 있음.
   - `model.dorsal.input`: `raw_vision_tokens`(ViT 토큰은 semantic 으로,
     VAE 토큰은 dorsal 로).
   - `loss.lambda_wm`: visual-dynamics 보조 손실 가중치(논문은 값을
     명시하지 않음; ablation 시 grid 탐색 필요).
   - `loss.terms`: `action + lambda_wm * goal_obs_pred`.
   - `train.freeze_vlm`: `False` (UAM 가설을 우리 스택에서 검증할 때).
4. **D25 falsifier 측정 항목**: 4-contribution ablation 의
   *"VLM-preservation validated by generalization/OOD metric not
   regressing"* 절에 사용할 *구체 벤치마크 집합* 으로 UAM 의 6 종
   MMMU / MME / MMBench / MathVista / MMStar / TextVQA 를 채택 후보로
   고정 — VQA-AVG = 0 시 즉시 reject 의 정량 임계가 보입니다.
5. **D7 (π backbone 분할) 영향**: 우리의 anatomical Body/Hand 분할과
   UAM 의 ventral/dorsal 분할을 *직교 슬롯* 으로 결합할 가능성 →
   `experts = [semantic, dorsal, body, hand]` 의 4-expert 변형이 향후
   설계 옵션이 됩니다(파라미터 / 지연 비용은 별도). CP1 의 *직접*
   변경 사항은 아니나, §14.C D7 sub-reading 의 trade-off 표에 한 행을
   추가할 필요.
6. **추론 지연 예산 재검토**: 7B + 7B + 2B = 1500 ms 는 우리의
   System1 행동기 control rate 와 충돌. dorsal expert size 를 줄이거나,
   D6 v2 "iterative/bidirectional" 트리거의 latency 분석에 단일-스텝
   denoising 기법(BagelVLA single-step) 을 참고 포함.

## ⚠️ 먼저 검증할 실패 모드

우리 스택으로 전이되지 않을 수 있는 이유와 가장 싼 sanity check 순:

1. **Backbone 의존성** — UAM 의 95 % 보존은 *Bagel* 의 사전학습
   능력에 강하게 의존(Tab. 2 의 Bagel 상한 자체가 매우 높음). π0 /
   π0.5 의 PaliGemma backbone 으로의 전이성은 §9.3 에서 *추가
   alignment 필요* 라고 저자도 명시. **Sanity check (cheapest)**:
   π0 의 PaliGemma 위에 dorsal expert 슬롯만 추가하고(random init,
   no Lwm) Calvin ABC 10 k step 학습 → VQA-AVG 가 Tab. 3 의
   PaliGemma + MoT(10.83) 보다 *유의미하게* 개선되지 않으면 backbone
   민감 가설이 우리 스택에서 더 강하게 작동한다는 신호.
2. **Dexterous / contact-rich 검증 부재.** UAM 의 OOD 성공은 pick &
   place · stack · sweep · drawer 류. *In-hand rotation / tool
   articulation* 처럼 finger-level 정밀도와 tactile feedback 이 결정적
   인 작업에서는 *시각 dorsal 경로만으로* 우리의 P2 structured input
   요구를 대체할 수 없음. **Check**: D24 의 in-hand cube rotation
   평가에서 UAM-style dorsal 추가가 *contact-precision* 지표를 개선
   하지 못하면, 우리 identity 의 P2 (tactile binding) 와는 직교한
   문제만 풀고 있다는 결론.
3. **Lwm objective 의 mode collapse.** visual-dynamics loss 가
   기여한다는 결정적 비교는 Variant 3a vs 3b 의 단일 ablation. λ
   민감도 / world-model 학습 안정성 / action 손실과의 gradient
   conflict 가 보고되지 않음. **Check**: 우리 코드에서 λ 를 {0, 0.1,
   1.0} 으로 격자 탐색해 action 곡선이 monotonic 한지 확인.
4. **추론 지연 폭주.** 1500 ms 는 System0 (sub-policy-loop) 와 충돌.
   **Check**: dorsal expert 를 2B 미만으로 축소했을 때도 보존이
   유지되는지 — 본 논문엔 dorsal size 의 ablation 이 없음. 이게 크기
   민감하다면 우리 latency 예산에선 즉시 채택 불가.
5. **OpenVLA baseline 의 VQA = 0 보고.** 같은 후처리로 다른 baseline
   도 0 으로 떨어지는지 검증 안 됨 → UAM 의 절대 우위 폭이 *측정
   protocol artefact* 일 가능성. **Check**: 우리가 baseline 재현 시
   동일 multimodal eval pipeline 으로 측정해 OpenVLA / ChatVLA 의
   값이 재현되는지 우선 확인.

## 💡 컨텍스트 제안

- **P4 §8.4 핀 8 편의 "TwinBrainVLA" vs "PriorVLA" 슬롯 재검토 후보.**
  UAM 은 P4 의 핵심 명제 *"preservation can be architectural"* 의
  가장 강한 증거로, 향후 quarterly rebalance(`Hard cap 8`) 시 P4 핀
  *교체* 후보 1순위. 다만 동일 명제의 다른 형제 두 편(PriorVLA /
  TwinBrainVLA / MolmoAct2) 가운데 가장 *극단적인 endpoint* (freeze
  의존도 0 + co-FT 의존도 0) 인 점에서, 셋 중 하나를 UAM 으로 교체
  하는 안을 인간이 결정. *agent 는 수정하지 않음.*
- **§10.3 architectural siblings 에 UAM 추가 검토.** TwinBrainVLA /
  HEX / DexReMoE / LaMP 와 함께 *3-expert dorsal-routing* 패턴의 대표
  사례로 monitoring 가치 — 단, *anatomical split 이 아닌 시각경로
  split* 임을 명시.
- **D25 falsifier 의 "VLM-preservation 측정 protocol" 정의 보강.**
  현재 "generalization/OOD metric not regressing vs full-FT" 만 기재.
  UAM Tab. 2 의 6 종 multimodal 벤치마크(MMMU, MME-P/S, MMBench,
  MathVista, MMStar, TextVQA) 를 *구체 protocol* 로 못박는 안. 인간
  결정 사항으로 제안만.
- **§14.B 에 dorsal expert latency 검증 항목 추가 후보.** 현재
  "compute budget" 행 하나 — UAM 의 1500 ms 결과는 P3 System0 의
  sub-loop 와 충돌하므로 *latency 예산* 자체를 별도 행으로 추적할
  가치.
