## 🧮 데이터 계약

본 논문은 두 정책 ($`\pi_{\text{hand}}`$ hand-only, $`\pi_{\text{uni}}`$ arm-hand 통합) 의 데이터 계약을 분리해 둡니다. 통합 계약은 hand-only 위에 arm 모달리티를 더한 형태입니다.

- **입력** — $`o_t^{\text{hand}}`$ (식 4) — $`[I_t^{\text{hand}}, l_t, q_t^{\text{hand}}, z_t^{\text{tac-f}}, z_t^{\text{tac-s}}]`$
  - $`I_t^{\text{hand}}`$: eye-in-hand RGB 이미지 (RealSense D405). shape 본문 미명시. 정규화는 $`\pi_0`$ 백본 PaliGemma 규약을 따릅니다.
  - $`l_t`$: 토큰화된 한 문장 instruction ("pick up the object on the table and place it elsewhere"). 토크나이저는 PaliGemma 의 것.
  - $`q_t^{\text{hand}}`$: shape `(12,)`, float, 12-DoF 손 관절 위치. 정규화 통계는 본문에 명시되지 않음 — `(원문에 명시 없음 — 가정으로 메움)` 데이터셋 평균/표준편차.
  - $`z_t^{\text{tac-f}}`$: shape `(5, d_{\text{mlp}})`, fingertip 별 합력 벡터 임베딩. 원천은 $`f_t^{\text{tac-f}} \in \mathbb{R}^{5\times 3}`$ (fingertip 별 3D 합력).
  - $`z_t^{\text{tac-s}}`$: shape `(5, d_{\text{mlp}})`, fingertip 별 spatial CAE latent 임베딩. 원천은 $`f_t^{\text{tac-s}} \in \mathbb{R}^{5\times 128}`$ (CAE 출력 latent, 16×16×3 입력에서 압축).
- **입력** — $`o_t^{\text{uni}}`$ (식 8) — $`[I_t, l_t, q_t^{\text{arm}}, q_t^{\text{hand}}]`$
  - $`I_t`$: 다중-뷰 RGB 묶음 (RealSense D435i 전역 2대 + eye-in-hand D405 1대). 정확한 shape·정규화는 본문 미명시.
  - $`q_t^{\text{arm}}`$: shape `(6,)`, float, UR3e 6-DoF 관절 위치.
  - $`q_t^{\text{hand}}`$: shape `(12,)`, float, 위와 동일.
  - 통합 계약에서는 촉각 임베딩이 빠집니다 — §8.2.1 음(陰)의 결과 때문에 baseline 통합 정책은 촉각을 미주입합니다.
- **출력** — $`A_t^{\text{hand}}`$ — shape `(H, 12)`, hand 액션 시퀀스 (chunk size $`H`$ 본문 미명시; $`\pi_0`$ 관례상 보통 50).
- **출력** — $`\hat{\mathcal{A}}_t^{\text{uni}} = [\hat{\mathcal{A}}_t^{\text{arm}}, \hat{\mathcal{A}}_t^{\text{hand}}]`$ — shape `(H, 6)` + `(H, 12)`, arm 6-DoF + hand 12-DoF 통합 액션 시퀀스.
- **raw 촉각 텐서** — $`F_{\text{raw}} \in \mathbb{R}^{10 \times 12 \times 3}`$ per fingertip, fingertip 표면 격자 (10×12) × 3축 (x, y, z). 정규화 후 16×16×3 으로 zero-padding 됩니다.
- **제어 주파수** — 텔레오퍼레이션 90 Hz, 정책 추론 30 Hz, 동기화 저장 30 Hz (§3.3.2).

## 🧰 모듈 인터페이스

본 논문의 핵심 모듈은 (1) 촉각 인코더, (2) $`\pi_0`$ 기반 hand-only VLA, (3) Arm-Hand Feature Enhancement, (4) corrective fine-tuning 루프입니다.

```python
def tactile_encoder(F_raw: Tensor) -> tuple[Tensor, Tensor]:
    """fingertip raw 촉각 (10x12x3) → (resultant force vector, spatial CAE latent).
    출력: f_tac_f (5x3), f_tac_s (5x128)."""

def mlp_tactile_proj(f_tac_f: Tensor, f_tac_s: Tensor) -> tuple[Tensor, Tensor]:
    """촉각 raw 특징 → VLA action expert 가 받는 토큰 임베딩 z_tac_f, z_tac_s."""

def pi_hand(o_hand: dict) -> Tensor:
    """π0 백본 + 촉각 토큰 주입 → hand action sequence A_hand.
    full-parameter SFT (vision encoder 만 동결, §7.1)."""

def arm_hand_feature_enhancement(z_share: Tensor) -> tuple[Tensor, Tensor]:
    """공유 latent z_share (R^{d_s}) → 사지별 z_arm, z_hand (각 R^{d_s/2}).
    구현: 2-layer MLP × 2, Mish activation."""

def aux_heads(z_arm: Tensor, z_hand: Tensor) -> tuple[Tensor, Tensor]:
    """사지별 latent → 사지별 sub-action 예측. 보조 손실용.
    구현: single linear layer × 2, selective supervision (해당 limb 의 DoF
    인덱스에만 적용)."""

def pi_uni_main_head(z_share: Tensor, z_arm: Tensor, z_hand: Tensor) -> Tensor:
    """fused = concat([z_share, z_arm, z_hand]) → 통합 액션 시퀀스 (arm+hand).
    π0 conditional flow matching head 를 그대로 사용."""

def corrective_sft(pi0: Module, D_uni: Dataset, D_k: Dataset) -> Module:
    """원 π0 에서 D_uni ∪ D_k 로 다시 미세조정 (식 14). 누적이 아니라
    항상 baseline 에서 출발하는 비축적 SFT."""
```

## ⛓️ 불변식·가정

- **Hand auxiliary 모듈은 backbone 의 prior 를 보존한다** — vision encoder 만 동결한 full-parameter SFT 라 backbone 가중치는 변경되지만, 보조 헤드와 사지별 latent 가 별도로 학습돼 backbone 의 표현 공간 자체는 작업 특화로 좁아진 채 유지된다는 가정. fine-tuning 데이터 규모 100 trajectories 에서 88.7% 가 가능한 이유의 핵심.
- **공유 latent + 사지별 latent 분리는 monolithic decoder 보다 occlusion 강건** — 동일 입력·동일 데이터에서 fused-concat 디코딩이 단일 디코더 대비 시각 차폐 시 절대 39 %p 격차를 만든다는 가정 (19% → 58%, Table 3).
- **촉각 통합은 phase-dependent** — hand-only 정책은 촉각 추가 시 단조 개선 (21% → 70% → 90%), 그러나 통합 정책에 같은 촉각을 그대로 주입하면 도리어 13 %p 하락 (95% → 82%, §8.2.1). 도달 단계의 비의도 접촉이 noise 로 작용한다는 가설.
- **비축적 corrective 재학습이 누적 catastrophic forgetting 을 피한다** — 매 corrective 라운드에서 원 $`\pi_0`$ 으로 돌아간 뒤 $`\mathcal{D}_{\text{uni}} \cup \mathcal{D}^{(k)}`$ 으로 다시 SFT 한다는 식 (14) 의 비축적 패턴이 라운드 간 drift 를 막는다는 가정.
- **LSTM admittance 가 자율 데이터 부트스트랩에 충분** — 시각 없이 proprio + tactile 만 보는 LSTM 정책으로 $`\pi_{\text{hand}}`$ 학습용 자율 시연을 모을 수 있을 만큼의 그립 안정성이 확보된다는 가정. force-control 68 + teleop 150 = 218 trajectories.

## 📊 하이퍼파라미터·손실

- **LSTM 사전 학습 손실** (식 2):

$$\mathcal{L} = \frac{1}{N} \sum_{i=1}^{N} \left\| a_{t}^{(i)} - \hat{a}_{t}^{(i)} \right\|_{2}^{2} + \lambda \|\Theta\|_{2}^{2}$$

- **CAE 재구성 손실** (식 3):

$$\mathcal{L}_{\text{recon}} = \frac{1}{3HW} \sum_{c \in \{x,y,z\}} \sum_{i=1}^{H} \sum_{j=1}^{W} \left( F_{c,ij} - \hat{F}_{c,ij} \right)^{2}$$

여기서 $`H = W = 16`$.

- **VLA 메인 손실** (식 9, conditional flow matching):

$$\mathcal{L}_{\text{main}}^{\tau}(\theta) = \mathbb{E}\left[ \left\| \mathcal{H}_{\text{main}}(z_t^{\text{fused}}) - u(\mathcal{A}_t^{\tau,\text{uni}} \mid \mathcal{A}_t^{\text{uni}}) \right\|^{2} \right]$$

노이즈 보간 액션은 $`\mathcal{A}_t^{\tau} = \tau \mathcal{A}_t + (1-\tau) \epsilon`$, 타깃 벡터 필드는 $`u(\mathcal{A}_t^{\tau} \mid \mathcal{A}_t) = \epsilon - \mathcal{A}_t`$.

- **사지별 보조 손실** (식 10, 11) — $`\mathcal{H}_{\text{arm}}(z_t^{\text{arm}})`$ · $`\mathcal{H}_{\text{hand}}(z_t^{\text{hand}})`$ 가 각자 sub-action 을 예측하는 MSE 항.
- **총 손실** (식 12):

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{main}} + \lambda \left( \mathcal{L}_{\text{hand}} + \mathcal{L}_{\text{arm}} \right)$$

- **Corrective 비축적 재학습** (식 14): $`\pi_{\text{uni}}^{(k+1)} = \text{SFT}(\pi_0; \mathcal{D}_{\text{uni}} \cup \mathcal{D}^{(k)})`$.

## 🎯 평가 메트릭

- **지표** — pick-and-place 성공률 (object 가 잡혀서 정확히 placement 위치에 놓이고 slipping/dropping 없으면 성공) · **임계값** — 본 논문 PoC 88.7%, 산업 SOP 채택 $`>`$ 95% · **비교 baseline** — $`\pi_{\text{uni-origin}}`$ ($`\pi_0`$ baseline, no enhancement) (§4.2.2, Table 1).
- **지표** — hand-only 그래스핑 성공률 (handheld 셋업, 5 scene × 50+ 물체 크러터) · **임계값** — 본 논문 95.5% · **비교 baseline** — 동일 셋업의 LSTM blind 정책 (정량 비교 본문 미명시) (§4.2.1).
- **지표** — 시각 차폐 robustness (10 초 차폐 후 그립 유지 성공률, 10 물체 × 10 trial) · **임계값** — $`\pi_{\text{hand-origin}}`$ 21%, $`\pi_{\text{hand-tacf}}`$ 70%, $`\pi_{\text{hand-tacf-tacs}}`$ 90% · **비교 baseline** — $`\pi_0`$ baseline (촉각 미주입) (§4.3.1, Table 2).
- **지표** — Enhancement ablation 성공률 (10 물체) · **임계값** — XHand 88 → 95 (+7 %p), RY-H2 71 → 81 (+10 %p), XHand-Occlude 19 → 58 (+39 %p) · **비교 baseline** — $`\pi_{\text{uni-origin}}`$ (§4.3.2, Table 3).
- **지표** — 데이터 수집 효율 (trajectories per hour per person) · **임계값** — Shared Autonomy 110 (main) / 100 (corrective), Full Teleoperation 90 / 80 · **비교 baseline** — Full Teleoperation 자체 (§8.1, Table 4).
- **지표** — Corrective 단계별 성공률 (5 객체 × 3×3 grid × 방위) · **임계값** — $`\pi_{\text{uni-enhance}}`$ → $`\pi_{\text{uni-orient}}`$ → $`\pi_{\text{uni-final}}`$ 단계마다 20–50 %p 절대 격차 (§4.3.3, Fig. 16).

## ✨ 변경 의도 (intent)

본 논문의 차별점은 두 축의 결합입니다. (1) **데이터 수집 단계에서의 해부학적 분업** — 사람은 VR 로 팔의 매크로 모션만 조종하고, 손의 마이크로 그래스핑은 자율 VLA copilot 이 떠맡아 인지 부하를 낮추면서 (110 vs 90 trajectories/h, +25%) 사람 시연 특유의 요령을 데이터에 보존합니다. (2) **모델 단계에서의 해부학적 분리** — $`\pi_0`$ 의 공유 latent 위에 사지별 MLP 와 보조 헤드를 얹어 단일 monolithic decoder 의 표현 한계를 풉니다. 시각 차폐 19 → 58% 격차가 이 분리의 정량 근거입니다. Hierarchical body→hand 가 아닌 공유 latent 동시 디코딩 구조 (단일 main 헤드, fused-concat) 가 LaMP 의 gated cross-attention 이나 TwinBrainVLA 의 frozen-generalist 와 갈리는 지점입니다.

## 🔌 Foundry 힌트 (선택)

- **`lerobot`** — $`\pi_0`$ 백본을 그대로 사용하므로 `pi0` family 와 직접 매핑됩니다. Arm-Hand Feature Enhancement 모듈은 `pi0` action expert 출력 직후의 토큰 흐름에 2-layer MLP 두 개 + single-linear 보조 헤드 두 개를 추가하는 형태로 들어갑니다. 촉각 인코더는 별도 모듈이며 vendor 의 기본 `pi0` 에는 없습니다 — `/foundry` 가 새 `tactile_encoder.py` 또는 동등 모듈을 신설해야 합니다. 데이터셋 측 변경은 `LeRobotDataset` 의 episode metadata 에 fingertip tactile 채널을 추가하는 형태로 매핑됩니다.

## 🚧 미해결 / 잠정

- 총 손실 보조 가중치 $`\lambda`$ 의 절대값과 민감도 분석이 본문에 없습니다 — `/foundry` 단계에서 기본값을 가정해야 합니다 (예: $`\lambda = 1.0`$).
- 공유 latent 차원 $`d_s`$ 의 구체 수치, encoder/head 의 정확한 hidden width 가 §7.3 에 명시되지 않습니다. $`\pi_0`$ 백본의 표준 표현 차원을 따른다고 가정해야 합니다.
- action chunk size $`H`$ 가 본문에 명시되지 않습니다. $`\pi_0`$ 기본값 (보통 50) 을 가정합니다.
- proprioceptive 정규화 통계 ($`q_t^{\text{arm/hand}}`$ 의 평균/표준편차) 의 출처가 본문에 없습니다. 데이터셋 전체 통계를 사용한다고 가정합니다.
- 음(陰)의 촉각 결과 ($`\pi_{\text{uni-enhance-tac}}`$ 95 → 82%) 의 phase-별 정량 분해 (도달 vs 접촉 단계 기여) 가 빠져 있어, selective gating 의 결정 신호 (`net_normal_force > τ_contact`) 의 임계값 $`τ_{\text{contact}}`$ 는 가정값으로 시작해야 합니다.
- Corrective 데이터셋 ($`\mathcal{D}_{\text{orient}}`$, $`\mathcal{D}_{\text{corner}}`$) 의 정확한 선택 기준 (어떤 실패 패턴을 corrective 로 분류했는지) 이 본문에 정성적으로만 기술됩니다 — 재현 시 분류 규칙을 직접 정해야 합니다.
