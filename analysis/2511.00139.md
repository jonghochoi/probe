## 🧭 한 줄 요약 (TL;DR)

VR 텔레오퍼레이션으로 사람이 팔의 매크로 모션을 직접 조종하는 사이 촉각 기반 DexGrasp-VLA가 다지 손의 마이크로 그래스핑을 자율 수행하는 Shared Autonomy 데이터 수집 패러다임과, π0 위에 Arm-Hand Feature Enhancement 모듈을 얹어 팔/손 잠재 표현을 명시적으로 분리한 엔드-투-엔드 VLA로 50종 이상의 물체에서 약 90% 그래스핑 성공률을 낸 연구입니다.

---

## ❓ 문제 정의 / 동기

저자들은 다지 손 조작 데이터 수집의 두 가지 오래 묵은 병목을 지적합니다. 풀-DoF 텔레오퍼레이션은 작업자의 인지 부하가 과도해 한 사람당 평균 30분이면 피로가 누적됩니다. 자동 모션 플래닝은 양은 늘리지만 분포가 솔버·제약·랜덤화로 편향되어 사람 시연 특유의 요령을 포착하지 못합니다. 그 결과 imitation 기반 VLA 학습에 필요한 고품질 데이터가 만성적으로 부족합니다. 또 기존 VLA는 팔과 손을 한 덩어리 monolithic action decoder로 다루기 때문에 매크로 모션과 마이크로 접촉 조작의 기구학·동역학적 이질성을 충분히 반영하지 못한다고 봅니다.

## 🧩 핵심 기여

- **DexGrasp-VLA (Hand Copilot)**: 5지 12-DoF Xhand 용 촉각 결합 VLA로, 시각·언어·고유수용감각·촉각(resultant force vector + spatial tactile embedding)을 묶어 자율 그래스핑을 수행하는 hand-only policy `π_hand` 를 설계합니다.
- **Shared Autonomy 데이터 수집 프레임워크**: 사람이 VR로 6-DoF 엔드-이펙터 매크로 모션을 조종하고 `π_hand` 코파일럿이 12-DoF 손 마이크로 모션을 자율 수행해 동기화된 팔-손 시연을 모읍니다.
- Arm-Hand Feature Enhancement 모듈: π0 백본의 공유 표현 `z_t^share` 를 별도 MLP `E_arm`, `E_hand` 로 사상해 사지별 잠재 `z_t^arm`, `z_t^hand` 를 만들고 보조 손실로 분리 학습합니다. 메인 헤드는 `[z_t^share, z_t^arm, z_t^hand]` 융합 표현에서 통합 액션을 예측합니다.
- Corrective Human-in-the-Loop Teleoperation: 배포 중 실패가 발생하면 동일 shared-autonomy 인터페이스로 사람이 즉시 개입해 복구 궤적을 모으고, 성공·복구 데이터를 묶어 `π_0` 로부터 재SFT 하는 self-improving 데이터 플라이휠을 구성합니다.
- 실증 결과: hand-only `π_hand` 가 50+ 물체 크러터에서 95.5% 성공률, 엔드-투-엔드 `π_uni-final` 이 시드 91.7% / 미관측 85.6% / 평균 88.7% 성공률을 기록합니다. 시각 차폐 조건에서도 enhancement 모듈 덕에 기준 (19%) 대비 58% 를 유지합니다.
- 부가 관찰: hand-only 정책에서는 촉각이 핵심(21% → 70% → 90%)이지만 동일한 촉각 통합을 통합 arm-hand 정책에 그대로 주입하면 95% → 82% 로 도리어 떨어진다는 음(陰)의 결과도 함께 기록합니다.

## 🔬 방법론

전체 파이프라인은 네 단계로 구성됩니다. (1) 사전: LSTM 기반 blind force-adaptive 정책을 force-control 68 demos + Leap Motion 텔레오퍼레이션 150 demos, 50 Hz 로 학습합니다. 위치 명령은

```
q_c(i) = q_m(i) + q(0) · e^{-k · f_z(i)}
```

식 (1) 의 어드미턴스형 규칙을 따릅니다. 접촉 전에는 빠르게 닫고, 접촉 후 fingertip 정상력 `f_z(i)` 에 따라 단계마다 그립을 강화합니다. LSTM 입력은 `x_t = [s_t^hand, f_t^hand] ∈ ℝ^39`, 손실은 식 (2) 의 MSE + ℒ_2 정규화입니다.

(2) DexGrasp-VLA `π_hand`: fingertip 별 raw 촉각 텐서 `F_raw ∈ ℝ^{10×12×3}` 에서 두 종류의 촉각 특징을 뽑습니다. 합력 벡터 `f_t^tac-f ∈ ℝ^{5×3}` 와, 16×16×3 으로 정규화·제로패딩한 tactile image 를 3-layer CNN encoder (32/64/128 filter, stride 2, ReLU + BN) 로 인코딩한 spatial latent `f_t^tac-s ∈ ℝ^{5×128}` 입니다. CAE 는 식 (3) 의 픽셀-단위 재구성 손실로 학습합니다. 두 임베딩을 MLP 로 `z_t^tac-f`, `z_t^tac-s` 로 변환하여 관측

```
o_t^hand = [I_t^hand, l_t, q_t^hand, z_t^tac-f, z_t^tac-s]    (4)
```

으로부터 `π_hand(A_t^hand | o_t^hand)` 식 (5) 를 학습합니다. 백본은 π0 [arXiv:2410.24164](https://arxiv.org/abs/2410.24164) 이며 LeRobot 프레임워크에서 vision encoder 만 동결한 full-parameter SFT 로 미세조정합니다 (Appendix 7.1).

(3) Shared Autonomy 데이터 수집: VR 측 컨트롤러의 변환을 식 (6) `T_robot,t = T_robot,0 · (T_VR,0^{-1} · T_VR,t)` 로 로봇 EE 목표에 매핑하고 식 (7) 의 속도-수준 QP IK (PlaCo + Pinocchio) 로 관절 명령을 계산합니다 (90 fps, <100 ms 지연, OpenXR · XRoboToolkit). 멀티스레드 제어 구조는 90 Hz 텔레오퍼레이션, 30 Hz `π_hand` 추론, 30 Hz 동기화 저장을 병행해 식 (8) 의 결합 데이터셋

```
𝒟_uni = {(o_t^uni, a_t^arm, a_t^hand)}_{t=1}^T,   a_t^arm ~ p_teleop,  a_t^hand ~ π_hand(·|o_t^hand)
```

을 생성합니다 (`o_t^uni = [I_t, l_t, q_t^arm, q_t^hand]`).

(4) 엔드-투-엔드 `π_uni` + Arm-Hand Feature Enhancement: π0 의 PaliGemma + Gemma Expert 가 만든 공유 표현 `z_t^share ∈ ℝ^{d_s}` 를 두 개의 2-layer MLP (`E_arm`, `E_hand`, Mish activation) 로 사상하여 `z_t^arm, z_t^hand ∈ ℝ^{d_s/2}` 를 만듭니다. 보조 헤드 `H_arm`, `H_hand` 는 각자 사지별 sub-action 을 예측해 보조 손실을 부과하고, 메인 헤드 `H_main` 은 `z_t^fused = [z_t^share, z_t^arm, z_t^hand]` 로부터 통합 액션 `Â_t^uni = [Â_t^arm, Â_t^hand]` 를 출력합니다. 학습 목표는 π0 의 conditional flow matching 을 통합 액션 시퀀스에 적용한 메인 손실 식 (9) 와 사지별 보조 손실 식 (10)·(11) 을 합친

```
ℒ_total = ℒ_main + λ (ℒ_hand + ℒ_arm)    (12)
```

입니다. 평가에 쓴 모든 체크포인트는 80,000 학습 스텝에서 저장되며 제어 주파수는 30 Hz 로 통일됩니다.

(5) Corrective Teleoperation: 자율 실행 중 성공/실패 궤적을 각각 `𝒟_success^(k)`, `𝒟_corrective^(k)` 로 누적하고 (식 13), `π_uni^(k+1) = SFT(π_0; 𝒟_uni ∪ 𝒟^(k))` 식 (14) 로 항상 원 π0 에서 다시 미세조정합니다.

## 📊 실험 설정과 결과

**플랫폼**: UR3e (6-DoF) + Xhand (12-DoF, fingertip 당 120채널 3D 촉각, 83 Hz EtherCAT, fingertip grip 15 N / max 80 N), 보조 검증용 RY-H2 (11 joints, 6 active + 5 underactuated, 0.4 s 오픈-클로즈, max 140 N). 인지: RealSense D435i 2대 (전역) + D405 1대 (eye-in-hand).

**데이터셋**: LSTM 사전학습 (force 68 + teleop 150), `𝒟_hand` 60 종 물체 180 trajectories, `𝒟_uni` 단일물체 시나리오 20 종 100 trajectories, `𝒟_orient` 50 + `𝒟_corner` 50 의 corrective intervention.

핵심 결과:

- `π_hand` (handheld 평가, 5 scene × 50+ 물체): 95.5% 성공률.
- `π_uni-final` (Table 1, 50 물체, 40×40 cm 워크스페이스, 객체당 3 trial): 시드 91.7% / 미관측 85.6% / 평균 88.7%.
- 촉각 ablation (Table 2, 10 물체 × 10 trial, 시각 차폐 10 s 유지): `π_hand-origin` (π0) 21% → `π_hand-tacf` (합력만) 70% → `π_hand-tacf-tacs` (합력 + spatial) 90%. Bottle 2/Orange/Mug/Ball 은 dual-tactile 에서 10/10.
- Arm-Hand Feature Enhancement ablation (Table 3, 10 물체): XHand 에서 기준 88 → enhance 95, RY-H2 71 → 81, XHand-Occlude (우측 카메라 차폐) 에서는 19 → 58 로 격차가 가장 큽니다.
- Corrective teleoperation (Fig. 16): `π_uni-enhance` → `π_uni-orient` (`𝒟_orient` 50 추가) → `π_uni-final` (`𝒟_corner` 50 추가) 단계마다 방위·코너 케이스 실패가 단계별로 해소되며 20~50% 의 절대 성능 차를 기록합니다.
- 데이터 수집 효율 (Table 4): Shared Autonomy 110 trajectories/h/person, corrective 100/h/person 으로 풀 텔레오퍼레이션 (90 / 80) 대비 약 25% 빠릅니다. 4-GPU 4시간 미세조정과 20 trial 10~15분 배포 사이클을 함께 보고합니다.
- 음(陰)의 결과 (§8.2.1): 동일 촉각 통합을 `π_uni-enhance-tac` 로 통합 정책에 그대로 주입하면 95% → 82% 로 떨어집니다. 저자들은 도달 단계의 비의도 접촉이 노이즈로 작용한다고 가설을 세우고, 그래스핑 단계에서만 촉각 처리를 활성화하는 selective gating / attention-based 가중치를 향후 과제로 남깁니다.

저자들은 본 결과가 별다른 엔지니어링 최적화 없는 PoC 수준이며 95% 이상 도달 시 산업 SOP 채택이 가능하다는 전망을 덧붙입니다.

## ⚖️ 한계

- 저자 명시: long-horizon 조작 (도구 사용, in-hand reorientation) 미검증. 전구간 촉각 통합이 도달 단계 비의도 접촉에 취약해 통합 정책에서 정합 misalignment 가 발생합니다. corrective 메커니즘이 여전히 사람 개입에 의존해 스케일링에 한계가 있습니다.
- 명백한 갭: `π_uni` 평가가 50 물체 × 3 trial 의 단일물체 pick-and-place 위주이고 크러터 정량 평가가 부족합니다. `π_hand` 의 95.5% 는 handheld 셋업 결과이므로 통합 시스템에서 같은 분포가 그대로 이전된다고 단정할 수 없습니다. `π_uni` 데이터셋 100 trajectories 라는 규모는 작고, 핵심 결론(특히 enhancement 모듈의 절대 격차)이 데이터 양에 얼마나 민감한지는 별도 검증이 필요합니다. 보조 손실 가중 `λ` 의 절대값과 민감도, `d_s` 의 구체 수치, encoder/head 의 정확한 hidden width 가 본문에 없어 재현이 어렵습니다. 음(陰)의 촉각 결과에 대한 정량 분해(도달/접촉 phase 별 기여)가 빠져 있고, Corrective 단계 비교는 5 객체 소규모 벤치마크라 표본이 좁습니다.

## 🎯 관련 Pillar / Decision (P# / D#)

이 논문은 PROBE 의 P1 (Heterogeneous Body/Hand Action Expert) 과 직접 충돌·중첩하며, `context/MASTER.md` §8.1 의 핀 논문 리스트와 §10.3 경쟁자 모니터링 양쪽에 이미 등록돼 있습니다.

- P1 / D1 (split form): 본 논문의 Arm-Hand Feature Enhancement 는 공유 백본 + 사지별 latent + 사지별 보조 헤드 + 통합 메인 헤드 구조로, PROBE 의 D1 v1 "(iii) 하이브리드 (공유 트렁크 + split head)" 와 동일 계열에 가깝습니다. 다만 PROBE 가 Body/Hand 각각에 별도 action head 를 두는 그림이라면, 본 논문은 보조 헤드만 분리하고 메인 액션은 fused 표현 단일 헤드에서 통합 출력합니다.
- P1 / D4 (Body↔Hand 정보 공유): PROBE 의 D4 v1 "FiLM(a_b) → hand head" 와 본 논문의 "concat([z_share, z_arm, z_hand]) → 단일 메인 헤드" 는 서로 다른 정보 공유 메커니즘입니다. 본 논문은 hierarchical body→hand 가 아니라 공통 latent 위에서 사지를 동시 디코딩하는 흐름입니다.
- P1 / D6 (coordination direction & flow): PROBE v1 의 "body→hand · hierarchical flow" 와 달리, 본 논문은 단일 flow matching 헤드가 통합 액션을 동시 예측하는 (c) coupled single network 에 가깝습니다.
- P1 / D7 (π backbone 분할): π0 액션 전문가를 그대로 두고 그 위에 보조 MLP/헤드만 얹는 방식이라 PROBE 의 D7 (i) "slice partition + FT" 가 아니라 "원 expert 유지 + 보조 어댑터" 에 가깝습니다. §14.C 의 Subdivide(B) 가 아닌 Repurpose-적층(A 변형) 사례로 분류됩니다.
- P4 / D19 (VLM FT 범위): 본 논문은 vision encoder 만 동결한 채 π0 의 나머지 (PaliGemma 포함) 를 full-parameter 미세조정합니다. PROBE D19 v1 "(a) 전 VLM 동결 + action expert 만 학습" 과 정반대이며, D19 의 deferred 후보인 "(c) selective unfreeze / (e) full-FT" 쪽 데이터 포인트로 해석됩니다.
- P2 / D11 (visuotactile encoder): 합력 + spatial CAE 듀얼 촉각 표현은 PROBE D11 "Tactile feature options: tactile image / resultant force vector / pressure distribution / contact map — 비교" 에 해당하는 옵션 두 가지를 실제 동시 채택한 사례로, 합력 단독 70% vs 합력 + spatial 90% 라는 정량 격차를 제공합니다. 단, hardware-specific CNN 을 finger 단위 구조 토큰에 묶는 PROBE 식 binding (D8) 은 본 논문에서 명시적으로 다뤄지지 않습니다.
- P3 (Hand-level System0): LSTM 어드미턴스 정책이 RL 이 아닌 IL 기반이라 PROBE 의 System0 (PPO 기반 슬립 억제 RL) 과 학습 방식이 다르지만, 고수준 VLA 아래에 사지·접촉 저지연 안정화 레이어를 둔다는 분업 사상은 D14 의 bypass-on 인터페이스와 같은 가족입니다. 본 논문에서는 시각 차폐 ablation 으로 촉각-기반 저수준 그립 유지의 가치를 정량화했습니다 (21% → 90%).
- P5 (Falsifiable evaluation): 데이터 수집 효율, 시각 차폐 robustness, corrective 데이터 단계별 기여를 ablation 으로 분해한 방식은 PROBE D25 의 4-기여 ablation 사고와 결이 비슷합니다. 다만 본 논문에는 PROBE 식 사전 정의된 falsifier 임계치는 없습니다.
- §10 경쟁자 함의: §10.3 의 Architectural siblings (P1 split) 항목에 본 논문이 이미 등재돼 있고, 트리거로 "in-hand reorientation 또는 articulated-tool 로 확장 시 CP2/CP3 와 직접 교차" 가 명시돼 있습니다. 본 논문의 future work 가 정확히 그 두 방향 (in-hand reorientation, tool articulation) 을 적극 거론하므로, 다음 follow-up 발표를 CP2~CP3 진입 직전에 한 번 더 확인할 가치가 있습니다.

## ✨ 핀 논문 대비 델타

핀 비교 대상은 같은 §8.1 P1 의 TwinBrainVLA ([arXiv:2601.14133](https://arxiv.org/abs/2601.14133)) 와 LaMP ([arXiv:2603.25399](https://arxiv.org/abs/2603.25399)), 그리고 §10.3 의 본 논문 자체 ([arXiv:2511.00139](https://arxiv.org/abs/2511.00139)) 입니다. 본 논문은 이미 핀 목록 안에 있으므로 델타라기보다는, PROBE 가 핀으로 받아 적은 시점 (v2 발표) 의 본문에서 어떤 디테일이 새로 드러났는지를 정리합니다.

- TwinBrainVLA 대비: 분할 축이 frozen-generalist / trainable-specialist 가 아니라 **anatomical arm vs hand** 입니다. 또 본 논문은 vision encoder 만 동결한 full-FT 라서 TwinBrainVLA 의 frozen 백본 + 학습 specialist 패턴과 정면으로 대비됩니다.
- LaMP 대비: LaMP 의 분할 축은 scene-flow 기반 dual-expert + gated cross-attention 인데 반해, 본 논문은 공유 latent 에서 사지별 MLP 로 가지치기한 뒤 다시 concat·통합 헤드로 합치는 단순한 구조입니다. 정보 공유 메커니즘이 cross-attn 이 아니라 fused-concat 인 셈입니다.
- §8.1 핀 항목 자체 대비 새로 드러난 점:
  - 데이터 측 분업: 핀 메타에는 "VR-teleop arm + autonomous hand VLA" 로 요약돼 있는데, 실측 효율 수치 (110 vs 90 trajectories/h, 25% 가속) 와 데이터 규모 (단지 100 trajectories 로 통합 정책 학습) 가 본문에서 확인됩니다.
  - 시각 차폐 강건성: Arm-Hand Feature Enhancement 가 시각 차폐에서 19% → 58% 로 가장 큰 격차를 만든다는 점은 Architectural sibling 이라는 핀의 추상 정의가 놓치고 있던 구체 falsifier 근거입니다. PROBE 의 P2 multi-camera pre-fusion (D12) 의 occlusion 강건성 평가에도 그대로 차용되는 프로토콜입니다.
  - 촉각 통합의 비대칭: hand-only 에서는 촉각이 핵심이지만 통합 정책에서는 같은 통합이 도리어 -13% 라는 결과는, PROBE 가 finger-bound structured token (D8) 으로 풀려는 문제의 실증 motivation 으로 직접적입니다. 본 논문이 직접 selective gating / attention-based 가중치를 future work 로 지목한 부분과 같은 맥락입니다.
  - Corrective 루프: 항상 원 π0 에서 다시 SFT 한다는 식 (14) 의 비축적(non-cumulative) 재학습 패턴은 핀 메타에 명시되지 않은 디테일입니다.

## ⚙️ 의사결정 함의

이 논문이 옳다고 가정할 때 PROBE 의 학습·평가 파이프라인에서 구체적으로 바뀔 후보는 다음과 같습니다.

- D1 / D4 하이브리드 split 의 보조 손실 항 도입 검토: 본 논문 식 (12) 의 `ℒ_total = ℒ_main + λ (ℒ_hand + ℒ_arm)` 는 사지별 latent 를 강제 분리시키는 비용 낮은 보조 손실입니다. PROBE 의 D1 v1 하이브리드에 동일한 보조 손실 두 항 (`ℒ_body_aux`, `ℒ_hand_aux`) 을 추가하고 가중치 `λ` 를 CP1 ablation 의 추가 축으로 둘 만합니다. 단, PROBE 의 split 은 별도 액션 헤드를 가정하므로 본 논문의 "보조 헤드만 분리, 메인은 단일" 변형까지 ablation 한 그룹으로 비교하면 D1 (i)/(ii)/(iii) 결정에 강한 근거가 됩니다.
- D6 (coordination flow) 의 비교군 추가: 본 논문은 hierarchical body→hand 가 아닌 공유 latent 동시 디코딩으로 통합 액션을 뽑습니다. PROBE 의 CP1 4-contribution ablation 에 본 논문 식 (12) 의 동시 디코딩 그룹을 (b) coupled denoising 또는 (c) coupled single network 의 한 사례로 추가하면 됩니다.
- D11 촉각 인코더 v1 의 듀얼 표현 채택 검토: 합력 + spatial latent 듀얼 표현이 21% → 70% → 90% 라는 단조 개선을 보여주므로, PROBE 의 Deform Map 인코더 v1 도 resultant force vector 추출 보조 head + spatial CNN latent 두 출력을 동시에 finger 토큰에 주입하는 형태로 기본값을 갱신할 수 있습니다. 구체 config 키 후보: `tactile_encoder.dual_head: [resultant_force_vec, spatial_cae_latent]`, `cae_latent_dim: 128`, `cae_input_shape: [16,16,3]`.
- D8 / D11 음(陰)의 결과를 selective gating 트리거로 활용: 본 논문이 통합 정책에서 촉각 추가 시 성능 하락 (95% → 82%) 을 기록했으므로, PROBE 의 finger-bound structured token 에서 도달 단계 동안 촉각 토큰을 마스킹하는 phase-aware gating 을 D8 의 deferred 트리거 (per-finger token 충분도 검증) 와 함께 CP1 사전 검증 항목으로 추가하는 편이 안전합니다. 구체 후보 키: `tactile_token_mask.phase: {reach: 0, grasp: 1}`, `phase_detector.signal: net_normal_force > τ_contact`.
- D12 multi-camera occlusion robustness 의 falsifier 임계치 추가: 본 논문의 19% → 58% 격차는 occlusion 조건에서 모듈 기여를 정량화할 수 있는 재현 가능한 프로토콜입니다. PROBE 의 D26 metric 에 "단일 카메라 차폐 시 성공률 drop ≤ X%" 항목을 명시적으로 추가하고, 임계치 X 를 본 논문의 기준 drop (88 → 19) 대비 PROBE 구조가 그 절반 이하로 줄여야 한다는 식으로 정량화하면 P1 + P2 차별화가 한 줄로 falsifiable 해집니다.
- D24/D26 corrective 데이터 단계 평가 protocol 차용: 본 논문의 (`π_uni-enhance` → `π_uni-orient` → `π_uni-final`) 단계별 벤치 구조 (Fig. 16, 5 객체 3×3 그리드 + 방위 변화) 는 PROBE 의 CP2 real-world 평가에서 데이터 augmentation 효과의 단조성을 보여주는 단순·재현 가능한 프로토콜로 차용할 만합니다.
- D19 (VLM FT 범위) 반례 데이터 포인트로 기록: 본 논문은 vision encoder 동결 + 나머지 full-FT 로도 50+ 물체 88.7% 를 달성했으므로, D19 v1 "(a) 전 VLM 동결" 결정의 deferred 트리거 (frozen 백본의 새 모달리티 조합 표현이 부족 시 LoRA 로 이동) 의 정량 비교 기준으로 활용 가능합니다.

명시적으로 바뀌지 않는 것: P3 의 RL-기반 System0 결정 (D13~D18) 은 본 논문의 LSTM admittance 사례로 직접 대체되지 않습니다. 본 논문은 IL + 어드미턴스 휴리스틱 조합이며, PROBE 가 정조준하는 슬립/그립 유지 reward 의 RL 학습 자체에 대한 반례는 아닙니다. 마찬가지로 본 논문은 in-hand reorientation 을 명시적 future work 로 남겼으므로, CP2 의 first demo (in-hand cube rotation) 결정 D24 v1 은 그대로 유지하는 편이 합리적입니다.

## ⚠️ 먼저 검증할 실패 모드

본 논문의 결과가 PROBE 스택으로 그대로 이전되지 않을 가능성을 가장 싼 점검 순으로 정리합니다.

1. 하드웨어 비대칭: Xhand 의 fingertip 당 120채널 3축 force 와 EtherCAT 83 Hz 인터페이스는 Sharpa Deform Map (320×240 vision-based, 30 Hz) 과 모달리티가 다릅니다. 합력 벡터 추출이 Deform Map 위에서 동일한 SNR/지연을 보장하지 못할 가능성이 크므로, 가장 먼저 Sharpa Deform Map 에서 resultant force vector 를 안정적으로 회귀할 수 있는지를 정적 보정 데이터 수십 분 정도로 확인해야 합니다.
2. 데이터 규모 의존성: 본 논문의 통합 정책은 100 trajectories 라는 작은 규모로 88.7% 를 달성했지만, 이는 단일물체 pick-and-place 워크스페이스 (40×40 cm) 에 맞춰진 결과입니다. PROBE 의 in-hand rotation 처럼 contact-rich · long-horizon 과제로 옮기면 같은 규모로는 수렴이 안 될 가능성이 큽니다. CP1 sim ablation 에서 (100, 300, 1000) trajectories 스윕으로 학습 곡선의 plateau 위치를 먼저 측정해야 합니다.
3. 풀-FT 의 사전학습 prior 소실: 본 논문은 vision encoder 만 동결한 full-FT 인데, PROBE D19 v1 의 핵심 가설은 전 VLM 동결이 prior 보존에 핵심이라는 점입니다. 가장 싼 검증은 본 논문 기준 (`π_uni-enhance`, full-FT) 과 (모든 백본 동결 + 보조 헤드만 학습) 의 OOD 일반화 (예: 새 카테고리 5종) 차이를 sim 에서 빠르게 비교하는 것입니다.
4. 음(陰)의 촉각 통합 결과의 일반화: §8.2.1 의 -13% 결과는 같은 워크스페이스·단일물체 가정에서 나왔습니다. PROBE 의 in-hand rotation 처럼 도달 단계가 짧고 접촉이 처음부터 핵심인 과제에서는 부호가 뒤집힐 가능성이 큽니다. 가장 싼 점검은 단일 객체 in-hand rotation sim 에서 (전구간 촉각 / phase-gated 촉각) 두 그룹의 학습 곡선만 측정하는 것입니다.
5. Corrective 데이터의 분포 편향: 식 (14) 가 항상 원 π0 에서 다시 SFT 한다는 점은 catastrophic 누적을 피하지만, `𝒟_uni ∪ 𝒟^(k)` 의 양이 적은 초기 라운드에서는 corrective 가 도리어 기준 분포를 흐릴 수 있습니다. PROBE 가 동일 패턴을 채택하기 전에 같은 데이터 규모에서 누적 vs 항상 원본 두 그룹의 성공률 분산을 한 번 측정해 두는 편이 안전합니다.
6. VR 텔레오퍼레이션 90 Hz · 추론 30 Hz 의 비동기 데이터의 PROBE 적용성: 본 논문의 multi-thread 90/30/30 Hz 구조는 풀-DoF 텔레오퍼레이션의 인지 부하 감소가 분명한 5지 12-DoF 손 상황에서 정당화됩니다. PROBE 의 22-DoF Sharpa 에서는 손 자율성 비중이 더 커질 가능성이 있어, 어느 phase 에서 자율, 어느 phase 에서 사람인지의 경계를 다시 정의해야 합니다.
