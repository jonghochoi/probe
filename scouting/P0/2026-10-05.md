## 🥇 논문 1

**The Imitator Game: Benchmarking Robot Imitative Ability Beyond Action Prediction**
[arXiv:2608.22301](https://arxiv.org/abs/2608.22301) · Xunzhe Zhou, Yiyang Cai, Fengyi Wang 외 9인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M3 · Real1 · Repro1 — abstract "The project website and access to Imitator Arena are available at https://imitator-game.github.io"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여

- 환경 정렬 인간-로봇 쌍 데이터와 4단계 모방 벤치마크 동시 공개
- 벤치마크 L0–L3은 시연과 로봇 장면의 격차를 단계적으로 확대, 궤적 재생이 통하지 않는 지점 분리
- 쌍 데이터셋 IG-10K는 20,000편 이상 쌍 에피소드·50개 이상 과제·6개 도메인, 4단계 전부를 실환경·시뮬레이션 양쪽에 구성한 유일한 사례로 제시
- 공개 플랫폼 Imitator Arena로 블라인드 A/B 인간 평가 지원
- 9개 최신 모델 평가에서 L0–L2는 안정적이나 L3에서 급락, 같은 의도를 다른 물체 어포던스로 달성하는 기능 대체가 결정적 장벽
- 인간 시연 조건 모델이 캡션 조건 모델보다 우수, 미확인 과제 제로샷 성공률은 전 모델 13% 미만
- IG-10K 사전학습 모델은 쌍 시연 10건 미세조정만으로 큰 향상, 사전학습 규모에 따라 이득 증가

### (c) 시사점

- 인간→로봇 쌍 데이터 규모 기준점 확보
- 궤적 수준이 아닌 의도 수준 모방을 재는 평가축 신규 제공
- 에고센트릭 인간 비디오의 전이 가치를 쌍 데이터 규모별로 측정 가능
- 다지 손 전용 과제는 아님, 일반 조작 범위

### (d) 먼저 확인할 점

- **실환경 비중** — 4단계를 실환경·시뮬레이션에 모두 구성했다는 서술만 확인, 실로봇 정량 결과 분량은 본문 확인 필요
- **공개 범위** — 프로젝트 사이트와 Arena 접근만 명시, 데이터 라이선스와 다운로드 조건 미기재
- **손 모달리티** — 손·손가락 추적과 접촉 모달리티 포함 여부 불명
- **장벽 일반성** — 기능 대체 실패가 모델 계열 전반인지 평가 설계의 산물인지 분리 필요

## 🥈 논문 2

**MANIGUARD: A Benchmark and Data Suite for Specification-Grounded Safety Evaluation and Improvement of Robotic Manipulation**
[arXiv:2608.17386](https://arxiv.org/abs/2608.17386) · Yiyan Peng, Philip Wang, Simon Sinong Zhan 외 11인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R2 · N2 · M3 · Real2 · Repro1 — abstract "we release 8,000 safety-annotated demonstrations, 40 per base task"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여

- 과제 성공과 독립된 사양 기반 안전 평가 하니스 신규 제시
- 접촉 집약 가정 과제 6개 계열·기본 과제 200개, 분포 내 1축과 분포 외 4축 변형으로 1,000개 시나리오 구성
- 매 롤아웃을 LTL$`_f`$ 기반 오토마타 모니터가 물리 술어 위에서 검사, 학습 분류기·LLM 판정 미사용
- 시뮬레이션과 실제 Franka 플랫폼 양쪽에서 검사
- 모션 플래닝 생성기와 인간 텔레옵을 같은 모니터로 주석, 안전 주석 시연 8,000건(기본 과제당 40건) 공개
- 23,000회 이상 롤아웃에서 성공 롤아웃의 6–21%가 사양 위반
- 해당 스위트 미세조정으로 안전 완수율 거의 0에서 7.5–29.8%로 상승
- 시연 증량으로 닫히지 않는 격차 잔존, 참여 롤아웃의 21–42% 여전히 위반, 6개 계열 중 2개는 전 정책 안전 성공률 2% 미만, 실패는 분포 이동과 하드웨어에서도 지속

### (c) 시사점

- 성공률과 분리된 안전 지표 기준점 확보
- 안전 주석 시연 8,000건으로 안전 인지 미세조정 데이터 즉시 활용 가능
- 접촉 집약 가정 과제라 다지 조작 평가 확장 후보
- 다지 손 전용 설정은 아님

### (d) 먼저 확인할 점

- **실로봇 범위** — Franka 플랫폼 검증 비중과 정량 규모 본문 확인 필요
- **공개 범위** — 안전 주석 시연 공개 서술만 확인, 벤치마크 코드 저장소와 라이선스 미기재
- **사양 의존성** — LTL$`_f`$ 술어 설계가 과제 계열별 수작업인지 확장 가능한지 불명
- **다지 전이** — 병렬 그리퍼 중심 과제에서 다지 손으로 옮길 때 술어 재정의 비용 확인 필요

## 🥉 논문 3

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu, Zhao Wu, Jin Chen 외 9인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 9/15** · R2 · N2 · M2 · Real2 · Repro1 — abstract "We will release our code, models, and data to support further research"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여

- 몸·손 모션을 에고센트릭 비디오와 동기한 500시간 전신 코퍼스
- 경량 웨어러블 시스템으로 개방 환경 인간 로코-매니퓰레이션 수집, 코퍼스명 HumanVerse-500
- 3단계 학습 구성, 다양한 에고센트릭 데이터로 상호작용 학습 후 HumanVerse-500으로 몸·손 협응 학습, 하류 과제와 로봇 형상으로 적응
- 인간·로봇 상태와 행동 차이는 도메인별 인터페이스가 흡수, 공유 표현 공간으로 인간 경험 전이
- SIMPLE과 실제 로코-매니퓰레이션 4개 과제에서 최고 성능 보고
- 스케일링 거동, 일반화, 단계별 기여 분석 포함
- 코드·모델·데이터 공개 약속

### (c) 시사점

- 몸·손 모션이 동기된 에고센트릭 코퍼스 후보, 공개 시 우선 데이터 축 보강
- 3단계 학습 레시피가 에고센트릭 코퍼스 활용 방식의 참고 사례
- 휴머노이드 전신 중심이라 다지 손 직접성은 낮음

### (d) 먼저 확인할 점

- **공개 시점** — 공개는 약속 상태, 데이터 범위와 라이선스 미정
- **손 해상도** — 손 모션 동기 방식과 손가락 단위 정밀도 확인 필요
- **실로봇 규모** — 실제 4개 과제의 시행 수와 베이스라인 수 본문 확인 필요
- **전이 범위** — 휴머노이드 로코-매니퓰레이션에서 다지 손 조작으로의 직접 전이 근거 없음
