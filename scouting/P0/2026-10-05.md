## 🥇 논문 1

**The Imitator Game: Benchmarking Robot Imitative Ability Beyond Action Prediction**
[arXiv:2608.22301](https://arxiv.org/abs/2608.22301) · Xunzhe Zhou, Yiyang Cai, Fengyi Wang 외 9인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R3 · N3 · M3 · Real1 · Repro1 — 초록 "The project website and access to Imitator Arena are available at https://imitator-game.github.io"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 인간 시연의 의도 모방을 4단계로 재는 벤치마크
- **문제** — 로봇이 인간 영상에서 동작 궤적이 아니라 시연의 의도를 읽어 낯선 장면에서 재현하는 능력의 부재
  - 인간 영상 학습이 궤적 수준에 머물러, 온라인 인간 영상이 실용적 감독원이 되는지 가르는 능력
- **기존 한계** — 궤적 리매핑 방식과 기존 평가가 의도 수준 모방을 재지 못함
  - 손 키포인트·옵티컬 플로우 추출, 로봇 동작으로 리타겟팅, 유사 장면 재생 방식은 물체 배치·형상·도구가 조금만 바뀌어도 시연 동작이 무효화
  - 기존 일반화 벤치마크는 학습 중 접한 장면의 교란 강건성 평가 중심
  - 영상 조건 정책은 대체로 분포 내 시험, 시연과 실행 환경의 불일치가 제한적
- **핵심 방법** — 시연 장면과 로봇 장면의 불일치를 4단계로 키우는 벤치마크, 쌍 데이터셋, 블라인드 인간 평가 플랫폼의 결합
  - L0 장면 동일 실행, L1 공간 적응, L2 시각·물리 일반화, L3 의도 수준 전이(예 주전자에서 수도꼭지로 대체)
  - IG-10K 쌍 데이터셋과 Imitator Arena 위에서 9개 최신 모델(15개 학습 변형) 평가
- **차별점** — 교란 강건성이 아니라 시연-실행 불일치를 단계적으로 넓혀 궤적 재생이 통하지 않는 지점을 격리
  - 같은 의도를 다른 물체의 어포던스로 달성하는 기능적 대체까지 평가 범위에 포함
- **핵심 기여** — 벤치마크, 데이터셋, 평가 플랫폼, 대규모 모델 비교
  - IG-10K — 환경 정렬 인간-로봇 쌍 데이터 중 최대 규모라고 주장, 20,000쌍 이상 에피소드, 50개 이상 과제, 6개 도메인, 4단계 전부를 실물·시뮬레이션 양쪽에 구성
  - Imitator Arena — 구조화된 블라인드 A/B 인간 평가를 여는 공개 플랫폼
  - 9개 모델 비교 — L0에서 L2까지 성능 안정, L3에서 붕괴하며 기능적 대체가 결정적 장벽
  - 인간 영상 조건 모델이 캡션 조건 모델보다 우수, 모든 모델이 미확인 과제 제로샷 성공률 13% 미만
  - IG-10K 사전학습 모델은 쌍 시연 10개 미세조정만으로 큰 이득, 이득이 사전학습 규모에 따라 증가
- **가치** — 인간 영상을 로봇 감독원으로 쓰려는 연구가 궤적 재생과 의도 이해를 분리해 측정할 척도 확보

### (c) 시사점

- 환경 정렬 인간-로봇 쌍 데이터와 의도 단계 척도 확보
- 인간 영상 중심 데이터 축에서 어떤 단계까지 통하는지 가르는 공개 기준점
- 의도 수준 전이 병목이 기능적 대체로 특정돼 평가 설계 참조 가능
- 프로젝트 페이지와 Arena 공개로 외부 모델 평가 접근 비용 낮음

### (d) 먼저 확인할 점

- 실물 에피소드 포함이나 초록에 실로봇 정량 성공률 수치 없음, 실물과 시뮬레이션 비중 확인 필요
- 저장소·데이터 URL 없이 프로젝트 페이지만 제시, 데이터 다운로드 가능 여부 확인 필요
- 라이선스 조항 초록에 미명시, 재사용 조건 확인 필요
- 과제 도메인이 가정·일상 중심인지, 다지 손 접촉 조작 포함 여부 확인 필요

## 🥈 논문 2

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu, Zhao Wu, Jin Chen 외 9인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M2 · Real2 · Repro1 — 초록 "We will release our code, models, and data"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 500시간 전신 인간 데이터와 3단계 휴머노이드 VLA
- **문제** — 휴머노이드 이동 조작 정책이 요구하는 몸 움직임과 손-물체 상호작용의 시간적 협응 감독 부족
  - 접근, 자세 조정, 파지 유지 후 운반이라는 연속 동작을 학습할 감독 필요
- **기존 한계** — 텔레옵 수집과 손 궤적 중심 영상 감독 모두 전신 협응을 채우지 못함
  - 전신 텔레옵은 로봇 시간과 인력이 많이 들어 과제·환경 확장이 어려움
  - 에고센트릭 영상에서 복원한 손목·손 궤적만으로는 전신 협응 포착 불가
- **핵심 방법** — 전신 모션을 영상과 동기화한 코퍼스와 3단계 학습 정책
  - 가벼운 웨어러블로 에고센트릭 영상과 신체 모션을 수집, 영상에서 손 모션을 복원해 동기화된 전신 감독 구성
  - 1단계 — 다양한 에고센트릭 데이터셋으로 상호작용 학습
  - 2단계 — HumanVerse-500으로 신체와 손 모션 협응 학습
  - 3단계 — 하류 과제와 로봇 형상에 적응
  - 공유 표현 공간으로 단계 간 전이, 도메인별 인터페이스로 인간과 로봇의 상태·행동 차이 처리
- **차별점** — 손 궤적에 그치지 않고 신체 모션을 영상과 같은 시계열로 묶어 감독에 편입
  - 인간 데이터 단계마다 역할을 나눠 어느 단계가 실물 성공에 기여하는지 ablation으로 분리
- **핵심 기여** — 데이터셋, 정책, 스케일링 결과
  - HumanVerse-500 — 개방 환경 인간 이동 조작 500시간, 에고센트릭 영상과 신체·손 모션 동기
  - λ0 — 공유 인간-로봇 표현 위의 3단계 전신 VLA 정책
  - SIMPLE에서 가장 강한 평가 기준선 대비 3.9%p, 실물 이동 조작 4과제에서 22.5%p 향상
  - 전신 인간 데이터가 늘수록 검증 손실 감소와 실물 과제 진행도 향상
  - 두 인간 데이터 단계 중 전신 미드트레이닝이 실물 성공에 더 큰 기여, 인간 시연이 로봇 미확인 물체의 진행도 향상
- **가치** — 휴머노이드 전신 학습에서 텔레옵 의존을 줄일 인간 경험 활용 경로 제시

### (c) 시사점

- 손·전신 모션이 영상과 동기화된 대규모 에고센트릭 코퍼스 확보 가능성
- 인간 영상 중심 데이터 축의 휴머노이드 확장 사례, 전신 미드트레이닝 효과가 수치로 제시됨
- 코드·모델·데이터 공개 예정, 공개 시 도입 비용 낮음

### (d) 먼저 확인할 점

- 공개는 예정 단계, 데이터 공개 범위와 시점 확인 필요
- 실물 평가가 4과제에 그쳐 과제 폭 한계, 다지 손 정밀 조작 비중 확인 필요
- 시뮬레이션 향상폭 3.9%p는 작아 기준선 구성과 시드 수 본문 확인 필요
- 라이선스 조항 초록에 미명시, 재사용 조건 확인 필요

## 🥉 논문 3

**Ego4WAM: What Matters When Scaling Egocentric Human Data for Robot Learning?**
[arXiv:2609.40341](https://arxiv.org/abs/2609.40341) · Zhihao Sun, Liu Liu, Xinjiang Wang 외 6인 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 에고센트릭 인간 데이터의 어떤 속성이 이득인지 분리
- **문제** — 에고센트릭 인간 데이터를 늘릴 때 어떤 속성이 하류 로봇 성능을 끌어올리는지, 학습 파이프라인 어디에 쓸지 불명확
  - 데이터를 시간 길이로만 요약하면 정렬, 행동 범위, 학습 목적, 규모의 효과가 얽힘
- **기존 한계** — 기존 연구는 인간 데이터 증가의 스케일링 이득만 보고하고 원인 속성을 가르지 않음
  - 인간 행동 예측 오차 같은 간접 지표에 의존, 폐루프 정책 성능 직접 측정 부족
  - 정렬이 높은 시연은 다양성이 제한되고, 정렬을 풀면 행동 궤적 신뢰도가 떨어지는 상충
- **핵심 방법** — 월드-액션 모델(WAM) 프레임워크의 백본을 고정하고 데이터 속성과 사용 전략만 바꾸는 통제 연구
  - 인간-로봇 정렬이 분포 밖 일반화와 로봇 데이터 요구량에 주는 영향
  - 데이터 길이와 과제 다양성의 분리
  - 행동 라벨이 불확실한 대규모 영상의 월드 모델링 활용, 이후 영상-행동 학습과의 상호작용
- **차별점** — 총 시간 하나로 보던 스케일링 축을 정렬, 과제 다양성, 감독 종류, 사용 전략으로 쪼갬
- **핵심 기여** — 데이터 속성별 효과의 분리와 실행 지침
  - 로봇 학습에 없던 물체·장면을 다루는 정렬 인간 시연이 분포 밖 일반화를 크게 높이고 목표 과제 로봇 데이터 요구량을 줄임
  - 데이터 길이와 과제 다양성이 하류 능력에 서로 다른 방향으로 작용
  - 행동 라벨 없는 영상만으로도 이후 영상-행동 학습의 기반으로 유효
  - 실물 로봇과 RoboDojo 폐루프 정책 평가로 검증
- **가치** — 에고센트릭 데이터를 어떤 분포로 모으고 어떤 감독을 얻어 어떻게 쓸지에 대한 실용 지침 제공

### (c) 시사점

- 수집 설계 근거 — 길이보다 정렬과 다양성이 관건
- 신규 코퍼스는 없으나 정렬·감독 수준별 효과 분리가 코퍼스 평가 기준으로 활용 가능
- 라벨 없는 영상도 쓸모가 있어 행동 복원 비용을 줄이는 수집 전략 참조 가능

### (d) 먼저 확인할 점

- 코드와 프로젝트 페이지 신호가 없어 재현 경로 확인 필요
- 초록에 정량 수치 없음, 실물 평가의 과제 수와 시행 횟수 본문 확인 필요
- 단일 WAM 백본에서의 결과라 다른 정책 구조로의 일반화는 별도 확인 필요
