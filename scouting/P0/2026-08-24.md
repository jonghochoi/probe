- XPolicyLab과 결합해 30개 정책을 통합·평가, 공개 리더보드와 체계적 성능 분석 결과까지 공개

- 표준화 하드웨어 + 원격 클라우드 실환경 평가 시스템은 자체 실로봇 평가 인프라 구축 시 참조 설계로 즉시 활용 가능
- 30개 정책 통합·공개 리더보드가 이미 확보돼 도입 시 벤치마킹 비용이 낮음

## 🥈 논문 2 — 우선순위 ★★

**SoftVTBench: A Deformation-Aware Visuo-Tactile Dataset and Benchmark for Deformable-Object Manipulation**
[arXiv:2608.18701](https://arxiv.org/abs/2608.18701) · Bowen Jing, Mingxin Wang, Ruiyang Hao 외 15인 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 기존 변형체(deformable-object) 조작 벤치마크 대다수가 태스크 성공 여부만 평가, 슬립·과압축 등 물리적 상호작용 품질을 놓친다는 공백 지적
- 정책이 보는 접촉 관측과 독립적 물리 정답값을 전체 태스크에 걸쳐 짝짓는 시각-촉각 데이터셋 SoftVTBench 신규 공개 — 시연 4,000건 + 자산 50종 이상(변형체 + 시각적으로 매칭된 강체 쌍)
- 20Hz로 멀티뷰 RGB·양지(dual-finger) 촉각 RGB+마커 모션·고유수용감각·언어·그리퍼 액션을 동기화 기록, 평가 전용 유한요소(FEM) 상태까지 동반
- 태스크 성공 + 변형 허용오차 준수를 함께 요구하는 Deformation-aware Success Rate(DSR) 지표로 폐루프 벤치마크 구성
- Diffusion Policy·π0.5·FastWAM 3개 정책을 분포 내 12개 구성 + 분포 외 이동 조건에서 비교, 성공 롤아웃의 0.7–24%가 변형 허용오차 위반임을 정량 확인

### (c) 시사점
- RH20T 이후 희소한 촉각/힘 축에 변형체 조작이라는 신규 하위 도메인 추가 — 접촉 품질을 성공률과 분리 측정하는 평가 설계 참조 가능
- 시각-촉각 융합이 자동으로 접촉 품질을 개선하지 않음을 정량 실증 — 촉각 모달리티 도입 효과를 검증하는 자체 실험 설계 시 참조 가치
- 물리적으로 매칭된 강체-변형체 자산 쌍 구성은 조작 난이도 통제 실험 설계에 재사용 가능한 자원

### (d) 먼저 확인할 점
- 공개 저장소·다운로드 경로가 초록·arXiv comment 모두에 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 4,000건 시연·자산 50종 이상의 규모가 변형체 특화 니치 안에서는 크나 일반 조작 데이터셋 대비로는 소규모 — 사전학습 자원보다 평가 전용 활용에 적합
- 18인 규모 협업 산출물로 FEM 평가 파이프라인의 하드웨어·시뮬레이터 의존성 별도 확인 필요

### (b) 핵심 기여
- 기존 촉각 데이터셋이 하드웨어·수집 체계 제약으로 소규모·좁은 접촉 커버리지에 머물러 있다는 공백 지적, 촉각 탑재 VLA 모델도 동역학-비가지 사후학습에 갇혀 성능 상한이 제한된다고 규정
- 160시간 규모 에고센트릭 인간 비디오 + 300개 이상 태스크 + 13만 5천 에피소드로 구성된 대규모 촉각-액션 데이터셋 H-Tac 신규 공개

- 촉각 전문가(tactile expert) 모듈로 미래 촉각을 예측해 접촉 동역학·정밀 물리 상호작용을 명시적으로 모델링
- 시뮬레이션·실로봇 양쪽 실험에서 우수 성능과 강건한 일반화·정밀 조작 능력 확인

### (c) 시사점
- 에고센트릭(D4ML)과 촉각(D1AL) 두 축을 동시에 대규모로 결합한 사례 — 두 축이 별개로 다뤄지던 최근 트렌드(에고센트릭: HandEdit·VLAff 등, 촉각: PRISM 등)의 교차점
- 160h·13만 5천 에피소드 규모는 촉각 특화 코퍼스로는 이례적 스케일 — 인간→로봇 촉각 전이 사전학습 자원으로 검토 가능
- 통일된 촉각·액션 공간을 사전학습부터 사후학습까지 일관 적용하는 설계는 자체 리타겟팅 파이프라인의 인간-로봇 전이 단 참조 가능

### (d) 먼저 확인할 점
- 공개 저장소·다운로드 경로가 초록·arXiv comment 모두에 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 다지 손(multi-finger) 조작 대비 병렬 그리퍼·단일 접촉점 위주 수집인지 초록상 불명확 — 다지 조작으로의 직접 적용성 별도 확인 필요

- 양팔+다지 손 전용 고난도 태스크 구성은 병렬 그리퍼 데이터셋과 차별화되는 다지 조작 난이도 벤치마크로 활용 가능

- Novelty 3 — 42개 sim 태스크(5차원)+18개 실환경 태스크 통합 + 원격 클라우드 실환경 평가 시스템(RoboDojo-RealEval) 결합은 기존 벤치마크와 차별화
- Reproducibility 2 — arXiv comment "Code: https://github.com/RoboDojo-Benchmark/RoboDojo"
- Methodology 3 — 5차원 sim 평가 + 18개 실환경 태스크 + 30개 정책 통합·리더보드 공개로 체계적 검증
- Sim2Real 3 — 시뮬레이션+실환경 양쪽 표준화 프로토콜로 동일 정책 평가

**SoftVTBench (12/15)**
- Relevance 3 — 시각-촉각 데이터셋+벤치마크로 D1AL 촉각 축 및 D6SE 벤치마크 축 동시 해당
- Novelty 3 — 성공률과 분리된 Deformation-aware Success Rate 지표 + 평가 전용 FEM 정답값 결합은 기존 변형체 벤치마크와 차별화
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — 3개 정책×12개 분포 내 구성+분포 외 이동 조건 비교, 위반율(0.7–24%) 정량 제시하며 촉각 융합의 한계까지 논의
- Sim2Real 3 — 실제 양지 촉각 센서·로봇 시연 기반 수집(비-시뮬레이션 데이터)

**LabDex (11/15)**
- Relevance 3 — 다지 조작 특화 벤치마크로 D6SE 정면 해당
- Novelty 3 — 화학 실험실이라는 신규 고정밀 도메인 + 3단 계층(Atomic/Compositional/Long-Horizon) 태스크 분류 + 실환경-시뮬레이션 최초 통합 프레임워크
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 2 — 실환경+시뮬레이션 양쪽 크로스레벨 평가 수행되나 베이스라인 목록·정량 수치가 초록 수준에서 구체적이지 않음
- Sim2Real 3 — 실환경·시뮬레이션 플랫폼을 표준화 프로토콜로 통합 검증

**H-Tac (11/15)**
- Relevance 3 — 에고센트릭 인간 비디오(D4ML) + 촉각(D1AL) 이중 축 동시 해당
- Novelty 3 — 160시간·13만 5천 에피소드 규모 촉각-액션 데이터셋 + 통일 촉각·액션 공간 인간→로봇 전이 프레임워크는 기존 소규모 촉각 데이터셋과 차별화
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 2 — 시뮬레이션+실로봇 실험 수행되나 베이스라인·정량 수치가 초록 수준에서 구체적이지 않음
- Sim2Real 3 — 시뮬레이션과 실로봇 양쪽에서 검증

**RoboTacDex (11/15)**
- Relevance 3 — 다지 손+촉각 로봇-액션 데이터로 D1AL 정면 해당, D4ML 로봇-액션 보완 축
- Novelty 2 — 다지 손+촉각+휴머노이드 전신 결합은 차별화되나 6천 궤적 규모는 이 니치 안에서 최상위 스케일은 아님
- Reproducibility 1 — 초록 "Our dataset will be open-sourced soon"
- Methodology 2 — 모방학습 모델 3종 평가, 태스크 계열별 강점·한계 분석하나 베이스라인 수·규모는 중간 수준
- Sim2Real 3 — 전량 실제 휴머노이드 로봇(Unitree G1) 데이터(비-시뮬레이션)
