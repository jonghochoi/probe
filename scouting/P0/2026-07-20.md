## 🥇 논문 1 — 우선순위 ★★★

**HABIT: Human-Aware Behavior and Interaction Training Dataset for Robot Manipulation**
[arXiv:2606.31682](https://arxiv.org/abs/2606.31682) · Jaehwi Song, Suchae Jeong, Byeongguk Jeon et al. · source: citation-graph (07-02 리포트 재검토)

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D27](https://img.shields.io/badge/D27-d97706.svg)](#ref-D27)

### (b) 핵심 기여
- 기존 대규모 로봇 시연 데이터셋 대부분이 인간-부재 환경에서 수집되어, 정책이 고립 태스크는 잘 수행하나 인간-인지 행동은 결핍된다는 공백 지적
- 인간-로봇 상호작용을 3개 역할로 구조화한 대규모 데이터셋 제시 — Collaborator(공동 수행), Coworker(공유 공간 내 개별 과제 병행), Supervisor(인간이 로봇 지시)
- 양팔(bimanual) Franka 플랫폼 기준 60개 태스크·10,563 에피소드·164시간 규모로 수집
- 오퍼레이터 복장·수집 조건을 체계적으로 변주해 OOD 분석까지 포함한 데이터 다양성 확보

### (c) 시사점
- 사람이 실제로 함께 있는 조작 환경을 다루는 최초급 대규모 공개 코퍼스 — 협업형 배치 시나리오 학습 데이터 공백 해소
- Robot-only 베이스라인 대비 역할별 인간-인지 행동(동기화, 양보, 제스처 그라운딩) 유의미 향상 확인 — 데이터 축 추가만으로 행동 변화 유도 가능성 시사
- CC BY 4.0 명시적 퍼미시브 라이선스로 HuggingFace Datasets 통해 즉시 활용 가능
- 신규 human-robot interaction 태스크에 대한 빠른 적응력도 확인 — 소량 파인튜닝만으로 전이 가능성

### (d) 먼저 확인할 점
- 단일 환경·10명 오퍼레이터·1:1 human-robot 구성에 한정 — 신체 외형·동작 스타일·다중 에이전트 다이나믹스 다양성은 논문 자체가 제한적이라 명시
- Bimanual Franka 특정 임베디먼트 위주로 zero-shot cross-embodiment 베이스라인 미포함 — 타 임베디먼트 전이성 별도 검증 필요
- 5개 RGB 스트림 등 센서 스위트 규모가 커 저장·처리 파이프라인 비용 사전 점검 필요

## 🥈 논문 2 — 우선순위 ★★

**UMI-Bench 1.0: An Open and Reproducible Real-World Benchmark for Tabletop Robotic Manipulation with UMI Data**
[arXiv:2606.10382](https://arxiv.org/abs/2606.10382) · Shi Jin, Yuntian Wang, Yuhui Duan et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여
- UMI(Universal Manipulation Interface)-style wrist-view 조작 정책을 위한 로컬-퍼스트 실로봇 벤치마크 제시
- 시연 수집·에피소드 명세·씬 리셋·정책 실행·로깅·스코어링·태스크-팩터 분석까지 데이터-투-배포 파이프라인 전체를 표준화 — 산발적 tabletop 태스크 모음이 아닌 재현 가능한 평가 프로토콜 자체가 기여
- 성공률뿐 아니라 부분 진행도·서브골 달성을 seen/unseen 조건 모두에서 측정, unseen 조건은 태스크별 정의된 변주 축으로 조직해 일반화 실패를 해석 가능하게 설계
- 베이스라인 정책·훈련 레포지토리를 프로젝트 페이지와 함께 공개해 재현 경로 제공

### (c) 시사점
- UMI 계열 정책 평가가 지금까지 랩마다 제각각이던 문제에 표준 프로토콜 제시 — 채택 시 비교 가능한 성능 보고 가능
- 성공/진행도/서브골 3단 메트릭이 실패 모드를 세분화해 어떤 능력이 부족한지 구분 가능
- 프로젝트 페이지·베이스라인 코드 공개로 도입 장벽 낮음

### (d) 먼저 확인할 점
- 1.0 릴리스는 tabletop 조작에 한정 — 모바일 조작 커버리지는 논문 자체가 향후 과제로 명시
- UMI 데이터 수집 방식에 의존적 설계 — UMI 외 텔레옵 파이프라인과의 호환성 별도 확인 필요
- 로컬-퍼스트 벤치마크 특성상 하드웨어 셋업(로봇팔·카메라 리그) 재현 난이도 사전 점검 필요

## 🥉 논문 3 — 우선순위 ★

**Open-AoE: An Open Egocentric Manipulation Dataset and Toolchain for Embodied Learning**
[arXiv:2607.14183](https://arxiv.org/abs/2607.14183) · Zishuo Li, Bowen Yang, Changtao Miao et al. · source: citation-graph + keyword-sweep 중복 확인

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여
- 스마트폰 촬영부터 모델 학습까지 전체 파이프라인을 아우르는 커뮤니티 기반 에고센트릭 조작 데이터셋 + 툴체인
- 1차 릴리스 기준 500명 이상 기여자·400대 이상 스마트폰으로 자연 환경에서 수집한 약 2,000시간 조작 영상
- 텍스트 주석, MANO 기반 손 포즈, 카메라 궤적, 시간적으로 국소화된 원자 행동(atomic action) 주석 동시 제공
- 시간적 행동 분할·의미 주석·손 재구성·카메라 궤적 재구성으로 원시 녹화를 구조화된 샘플로 변환하는 처리 파이프라인 포함
- 별도 다운스트림 툴체인이 시각화·크로스-임베디먼트 리타겟팅·모델별 데이터 변환·VLA/WAM/World Model 학습 레시피까지 지원
- OpenEgo·EgoDex·EgoXtreme 대비 주석 커버리지·손 신호 유효성 지표로 정량 비교, VLM 평가자 기반 품질 검증 수행

### (c) 시사점
- 단일 고가 디바이스 의존 없이 범용 스마트폰으로 스케일 확보 — 데이터 수집 비용 구조를 근본적으로 낮추는 접근
- 크로스-임베디먼트 리타겟팅 툴체인이 기본 제공되어 인간 영상 → 로봇 액션 변환 실험 착수 비용 낮음
- 주석 커버리지·손 신호 유효성이 기존 공개 세트 대비 우위 — 사전학습 데이터 품질 개선 여지
- GitHub(ant-research/Open-AoE) + HuggingFace(inclusionAI/OpenAoE-2000h) 로 코드·데이터 모두 공개 확인

### (d) 먼저 확인할 점
- 데이터셋 자체는 로봇 실행·정책 학습 실험을 포함하지 않음 — 리타겟팅 품질과 실로봇 전이 성능은 별도 검증 필요
- 커뮤니티 스마트폰 촬영 특성상 카메라 내참수·조명·해상도 편차가 클 수 있어 전처리 파이프라인 의존도 확인 필요
- 원자 행동 주석의 자동화 정도(수동 vs 모델 기반) 및 라벨 품질 샘플링 검증 권장
