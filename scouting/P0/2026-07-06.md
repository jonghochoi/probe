## 🥇 논문 1 — 우선순위 ★★★

**Human-Centric Transferable Tactile Pre-Training for Dexterous Robotic Manipulation**
[arXiv:2607.01067](https://arxiv.org/abs/2607.01067) · Chi Zhang, Penglin Cai, Ziheng Xi, Haoqi Yuan, Hao Luo, Wanpeng Zhang, Sipeng Zheng, Chaoyi Xu, Zongqing Lu · source: citation-graph + keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여
- **H-Tac 데이터셋 신규 구축** — 160시간 egocentric 인간 영상, 300개 이상 태스크, 135k 에피소드 규모 촉각-액션 코퍼스
- **Transferable Tactile Pre-Training(TTP) 프레임워크 제안** — 인간 데이터로 촉각 기반 사전학습 후 로봇으로 전이하는 시스템
- **통합 촉각·액션 공간 설계** — 인간→로봇 전이 전 구간에 동일 표현 공간 사용, 사전학습 지식 보존 목적
- **촉각 전문가(tactile expert) 기반 미래 촉각 예측** — 접촉 동역학·정밀 물리적 상호작용 명시적 모델링
- **시뮬레이션+실로봇 정량 검증** — 세분화된 조작 능력과 일반화 성능 확인

### (c) 시사점
- **촉각 데이터 규모의 새 기준점 후보** — 기존 촉각 코퍼스 대비 압도적 스케일(135k 에피소드), 인간 영상 기반이라 수집 비용 구조가 로봇 원격조작과 다름
- **인간→로봇 전이 레시피가 이식 가능한 패턴** — 통합 표현 공간 설계가 촉각 외 다른 모달리티 전이에도 참고 가능
- **데이터+방법 결합형 논문** — 데이터셋 단독이 아니라 활용 방법론까지 함께 제시되어 즉시 재현 가능성 판단에 유리

### (d) 먼저 확인할 점
- **공개 여부 직접 확인 실패** — 프로젝트 페이지(beingbeyond.github.io/TTP) 존재 확인했으나 HTTP 403으로 실제 데이터·코드 다운로드 가능 여부 미검증, 수동 확인 필요
- **촉각 센서 하드웨어 사양 abstract 상 불명** — 보유 촉각 하드웨어와의 정합성 별도 확인 필요
- **인간-로봇 접촉 물리 차이** — 인간 손 접촉과 로봇 그리퍼 접촉 간 물리적 차이로 인한 전이 오차 가능성, 실측 정량화 필요

## 🥇 논문 2 — 우선순위 ★★★

**ForceBand: Learning Forceful Manipulation with sEMG**
[arXiv:2606.26093](https://arxiv.org/abs/2606.26093) · Botao He, Zhi Wang, Linna Kuang, Ishaan Ghosh, Jitendra Malik, Cornelia Fermuller, Tingfan Wu, Jiayuan Mao, Ruoshi Liu, Haozhi Qi, Yiannis Aloimonos · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여
- **손목 착용형 sEMG 시스템 ForceBand 신규 개발** — 저비용 손목 근전도 센서로 인간 근육 활동을 손가락별 힘으로 변환
- **10시간 규모 멀티모달 데이터셋 수집** — egocentric 영상 + sEMG + IMU + 손가락 접촉힘을 다양한 행동·물체에 걸쳐 동시 기록
- **EMG2Force 모델 사전학습** — sEMG·IMU 신호로부터 손가락별 힘을 예측, 사용자별 짧은 캘리브레이션만으로 신규 태스크 시연에 힘 라벨 자동 부여
- **비전 기반 힘 추정 대비 정량 우위 확인** — 힘 예측 오차 50% 이상 개선, 물체별 힘 제어가 필요한 pick·squeeze·place 태스크에서 87% 성공률

### (c) 시사점
- **접촉힘 라벨링의 새 축** — 기존 손목 6축 F/T 센서 방식과 달리 인체 근전도 기반이라 별도 로봇 하드웨어 장착 없이 대규모 인간 시연에 힘 정보 부여 가능
- **저비용 대량 수집 경로 후보** — 모션캡처·인터넷 영상이 놓치는 접촉힘 정보를 웨어러블 하나로 보완, 수집 비용 구조가 기존 촉각 센서 대비 유리
- **완전 무개입 수집은 아님** — 사용자별 초기 캘리브레이션 단계 존재

### (d) 먼저 확인할 점
- **공개 여부 직접 확인 실패** — 프로젝트 페이지(forceband-emg.github.io) 확인했으나 HTTP 403으로 데이터셋 다운로드 가능 여부 미검증
- **태스크 다양성 제한적** — pick·squeeze·place 3종 태스크 중심 검증, 도구 사용 등 복잡 접촉 시나리오 일반화 별도 확인 필요
- **sEMG 신호 개인차** — 사용자별 근육 신호 편차로 인한 캘리브레이션 주기·안정성 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**CHORD: Contact Wrench Guidance from Human Demonstration in Robotic Dexterous Manipulation**
[arXiv:2607.00033](https://arxiv.org/abs/2607.00033) · Xinghao Zhu, Zixi Liu, Shalin Jain, Chenran Li, Milad Noori, Huihua Zhao, John Welsh, Michael Andres Lin, Wei Liu, Tingwu Wang, Xingye Da, Zhengyi Luo, Vishal Kulkarni, Naema Bhatti, Yuke Zhu, Linxi Fan, Bowen Wen, Danfei Xu, Soha Pouya, Yan Chang · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여
- **접촉 렌치(contact wrench) 공간 기반 유도 강화학습 프레임워크** — 인간·로봇 동작을 물체에 가하는 힘·토크로 표현해 동작 유사도 측정
- **대규모 시뮬레이션 벤치마크 신설** — 모션캡처 데이터셋 + 자체 촬영 영상으로부터 재구성한 4,739개 양손 다지 조작 태스크
- **강체·관절형 물체 장기 조작 지원** — 1,831개 벤치마크 태스크 평가에서 평균 성공률 82.12%
- **시연 형태 일반화 확인** — 손 단독·3인칭 시연에서도 90.77% 성공률, 전신 조작으로 확장, 실로봇 open-loop/closed-loop 전이 검증

### (c) 시사점
- **대규모 조작 태스크 벤치마크 확보 후보** — 양손 다지·장기 호라이즌 태스크에 특화된 대규모(4,739개) 벤치마크
- **접촉힘 기반 유사도 측정이 이식 가능한 아이디어** — 힘·토크 공간 정합이 다른 인간→로봇 전이 파이프라인의 보상 설계에도 참고 가능
- **NVIDIA Isaac 계열 프로젝트** — 유사 계열 도구 공개 이력 감안 시 벤치마크 공개 가능성 상대적으로 높음

### (d) 먼저 확인할 점
- **공개 여부 직접 확인 실패** — 프로젝트 페이지(nvidia-isaac.github.io/video_to_data/chord) 확인했으나 HTTP 403으로 벤치마크·코드 다운로드 가능 여부 미검증
- **벤치마크가 방법론 논문의 부산물** — 데이터셋/벤치마크 자체보다 RL 프레임워크가 논문의 주 기여, 벤치마크 단독 활용성 별도 확인 필요
- **모션캡처 기반 재구성 데이터 라이선스** — 원본 모션캡처 데이터셋 출처·라이선스 abstract 상 불명, 재배포 조건 확인 필요
