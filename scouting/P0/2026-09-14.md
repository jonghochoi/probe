## 🥇 논문 1 — 우선순위 ★★★

**HuRo: Robotizing Human Videos for Scalable VLA Pretraining**
[arXiv:2609.10706](https://arxiv.org/abs/2609.10706) · 저자 정보 미확인(신규 프리프린트, 메타데이터 미등재) · arXiv preprint · source: citation-graph · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 인간 비디오 데이터셋이 고비용 실로봇 데이터의 대안으로 부상했으나, 기존 인간→로봇 임베디먼트 격차 해소 접근은 태스크-정합 세팅에 한정되거나 관측·액션 정합을 분리 처리한다는 공백 지적
- 이종 인간 비디오를 로봇-정합 관측+액션 궤적으로 변환하며 주석 레벨 간 누락된 중간 신호까지 추론하는 로보타이제이션 파이프라인 신규 구축
- 5개 인간 비디오 소스 기반 약 63만 건 로보타이즈 에피소드·1.42억 프레임 규모 HuRo 데이터셋 신규 공개
- 4개 실환경 조작 태스크에서 로보타이즈 사전학습 스케일 증가에 따른 성능 개선 정량 실증 — 전체 완료율 51.5%→80.3%, 공간·시각 변화 조건 OOD 완료율 34.9%→72.2%
- 어블레이션으로 시각적 로보타이제이션이 OOD 강건성에 기여하며, 리타겟팅 액션까지 포함한 end-to-end 사전학습이 시각 전이 단독보다 우수함을 확인

### (c) 시사점
- 에고센트릭/인간 비디오를 로봇 학습 자원으로 전환하는 데이터 엔진 축에 이례적 스케일(63만 에피소드)의 신규 자원 추가 — 로보타이제이션 기반 사전학습 데이터로 즉시 검토 가능
- 사전학습 스케일 대 실환경 성능 개선의 정량 곡선이 이미 확보돼 자체 데이터 확장 투자 판단 근거로 활용 가능
- 액션 리타겟팅을 포함한 end-to-end 학습이 시각 전이 단독보다 우수함이 실증돼 리타겟팅 파이프라인 설계 우선순위 판단에 참조 가능

### (d) 먼저 확인할 점
- 저자·소속 정보가 Semantic Scholar 기준 아직 등재되지 않았고 arXiv 직접 조회는 API 반복 실패(HTTP 429)로 확인 불가 — 신규 프리프린트 메타데이터 미등재로 추정, 차기 회차 재확인 필요
- 게재 여부(venue)도 동일한 조회 실패로 미확인 — arXiv preprint로 기본 처리
- 5개 소스 인간 비디오 혼합 시 라이선스 조건, 다지 손(multi-finger) 임베디먼트 포함 여부가 초록상 불명확

## 🥈 논문 2 — 우선순위 ★★

**RoboCousin: Build Your Own Simulation Playground for Robust Bimanual Robotic Manipulation**
[arXiv:2609.08339](https://arxiv.org/abs/2609.08339) · Jingbo Zhu, Jing-Yi Li, Liang-Liang Chen 외 3인 · arXiv preprint · source: citation-graph · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 양팔 조작 정책 학습에 필요한 대규모·다양 데이터셋 확보가 실로봇 시연 수집 고비용으로 어렵고, 기존 시뮬레이션 파이프라인은 닫힌 자산 라이브러리·사전 정의 씬에 갇혀 신규 객체·환경 추가에 상당한 수작업이 필요하다는 공백 지적
- 사용자 제공 관측을 재사용 가능한 자산·씬·전문가 궤적으로 변환하는 확장형 시뮬레이션 기반 데이터 생성 플랫폼 RoboCousin 신규 제시 — RoboTwin 2.0 기반 구축
- 객체 이미지를 시각·충돌 지오메트리, 시맨틱·물리 메타데이터, 자동 생성 그래스핑-접촉 후보를 갖춘 시뮬레이션 준비 완료 자산으로 변환
- 호환 객체·배경·배치·언어 지시를 변주하며 태스크 관련 어포던스·공간 관계는 보존하는 digital cousin 구성 방식 도입, 테이블탑+룸 레벨 씬 구축과 충돌 인지 베이스 제어까지 지원
- 3,000개 이상 주석 객체 인스턴스·50개 배경 환경으로 구성된 RoboCousin-OBD 공개, 50개 태스크에 걸친 100만 건 이상 전문가 궤적 생성 — 시뮬레이션+실로봇 실험으로 자동 생성 주석이 큐레이션 주석과 동등하고 sim-to-real 전이에 효과적임을 실증

### (c) 시사점
- 로봇-액션 데이터 축(시뮬레이션 증강)에 닫힌 자산 라이브러리 한계를 넘어서는 확장형 데이터 생성 플랫폼 추가 — 자체 시뮬레이션 자산 파이프라인 구축 시 참조 가능
- 자동 생성 주석이 큐레이션 주석과 동등함이 정량 확인돼 대규모 자산 확장 시 수작업 주석 비용 절감 근거로 활용 가능
- digital cousin 변주 방식은 조작 정책의 분포 외 일반화 평가·훈련 데이터 다양성 확보 설계에 재사용 가능한 프레임워크

### (d) 먼저 확인할 점
- RoboCousin-OBD 공개 저장소 URL이 초록 수준에서 명시되지 않음 — arXiv comment 필드 조회가 API 반복 실패(HTTP 429)로 이루어지지 못해 실제 다운로드 경로 확인 필요
- RoboTwin 2.0 기반 구축으로 해당 시뮬레이터 생태계 종속성 존재 — 독립 활용 시 이식 비용 별도 확인 필요
- 6인 소규모 팀 산출물로 100만 건 이상 궤적 생성 파이프라인의 장기 유지보수 확인 필요
