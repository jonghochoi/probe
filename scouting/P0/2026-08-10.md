## 🥇 논문 1 — 우선순위 ★★★

**VLAff: Vision-Language-Affordance Model for Unified Actionable Affordances**
[arXiv:2608.05215](https://arxiv.org/abs/2608.05215) · Jihoon Oh, Kento Kawaharazuka, Kei Okada · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 인간 비디오로부터 조작 스킬을 학습할 때 인간-로봇 임베디먼트 불일치가 근본 장벽이라는 문제 지적, 임베디먼트-불가지 객체 중심 어포던스 학습을 해법으로 제시
- 에고센트릭 인간 비디오에 3D Structure-from-Motion + 손 메쉬 재구성을 적용해 시각 어포던스(어디를 상호작용할지)·파지 어포던스(어떻게 쥘지)·궤적 어포던스(어떻게 움직일지) 세 축을 동시 추출
- 신규 대규모 데이터셋 EgoAffordance 구축 — 20만 4천 에피소드, 시각 어포던스 560만 건 + 파지·궤적 어포던스 1,160만 건 규모
- 세 어포던스 축의 크로스모달 상관관계를 학습하는 통합 VLM 기반 파운데이션 모델 VLAff 제시 — 시각 관측+지시문 입력으로 어포던스 히트맵·파지 자세·궤적을 동시 생성, 3D 씬 정보로 즉시 실행 가능한 액션으로 변환
- 어포던스 예측 벤치마크에서 SOTA 성능 확인, 제로샷 조작·어포던스 유도 로봇 학습 등 실로봇 응용까지 검증

### (c) 시사점
- 에고센트릭 축(D4ML) 데이터를 원시 비디오가 아닌 구조화된 어포던스 어노테이션으로 변환하는 대규모 사례 — 임베디먼트 전이 격차를 데이터 표현 단계에서 좁히는 접근
- 20만+ 에피소드·1,700만+ 어노테이션 규모는 어포던스 특화 코퍼스로는 이례적 스케일 — 파지·궤적 예측 사전학습 자원으로 즉시 검토 가능
- 실로봇 제로샷 조작 검증까지 포함돼 어포던스 표현이 단순 인식을 넘어 실행 가능한 액션으로 이어지는 경로 실증

### (d) 먼저 확인할 점
- 공개 저장소·라이선스·다운로드 경로가 초록상 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 저자 3인 규모의 소규모 팀 산출물로 20만+ 에피소드 데이터 수집·주석 파이프라인의 검증 재현성 별도 확인 필요
- 다지 손 조작(multi-finger dexterity) 비중이 초록상 불명확 — 파지 어포던스가 병렬 그리퍼 위주인지 다지 핸드까지 포괄하는지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**HABIT: Human-Aware Behavior and Interaction Training Dataset for Robot Manipulation**
[arXiv:2606.31682](https://arxiv.org/abs/2606.31682) · J. Song, Suchae Jeong, Byeongguk Jeon 외 4인 · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 대규모 로봇 시연 데이터셋 대부분이 인간이 부재한 환경에서 수집돼 학습된 정책이 태스크는 수행하나 인간-인지 행동을 보이지 못한다는 공백 지적
- 인간-현존 환경 전용 대규모 로봇 시연 데이터셋 HABIT 신규 도입 — Collaborator(공동 수행)·Coworker(공유 공간 내 별개 작업)·Supervisor(인간이 로봇을 지시) 3개 상호작용 역할로 태스크를 조직화
- 1만 건 이상 에피소드·160시간 이상·60개 태스크 규모로 구성
- 인간-현존 데이터로 학습 시 역할별로 구분되는 인간-인지 행동 유발 확인 — Collaborator에서 시공간 동기화, Coworker에서 양보 행동, Supervisor에서 제스처 그라운딩
- HABIT 학습이 신규 인간-로봇 상호작용 태스크로의 신속한 적응을 가능케 함을 실증

### (c) 시사점
- 로봇-액션 데이터 축(D4ML 보완)에 "인간 현존"이라는 신규 다양성 축을 도입한 최초 사례 — 기존 8편 핀 논문 어디에도 없는 신규 데이터 차원
- 역할별(Collaborator/Coworker/Supervisor) 정량 행동 지표가 향후 자체 인간-로봇 협업 평가 설계 시 참조 가능한 분류 체계 제공
- 신규 HRI 태스크로의 빠른 적응 실증은 사전학습 자산으로서의 전이 가치를 뒷받침

### (d) 먼저 확인할 점
- 공개 저장소·라이선스·다운로드 경로가 초록상 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 60개 태스크의 다지 손·접촉 집약도 비중이 초록상 불명확 — 병렬 그리퍼 위주 여부 확인 필요
- 인간-현존 시나리오 특성상 안전·충돌 회피 관련 라벨링·평가 프로토콜이 별도로 존재하는지 본문 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Open-AoE: An Open Egocentric Manipulation Dataset and Toolchain for Embodied Learning**
[arXiv:2607.14183](https://arxiv.org/abs/2607.14183) · Zishuo Li, Bowen Yang, Changtao Miao 외 30인 · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 기존 에고센트릭 조작 비디오 자원이 저비용 연속 캡처·조작 수준 구조화 주석·재사용 가능한 로봇 학습 툴을 동시에 갖추지 못했다는 공백 지적
- 스마트폰 촬영부터 모델 학습까지 전 파이프라인을 포괄하는 오픈 커뮤니티형 에고센트릭 조작 데이터셋+툴체인 Open-AoE 제시
- 첫 릴리스 기준 500명 이상 기여자가 400대 이상 스마트폰으로 자연 환경에서 촬영한 약 2,000시간 규모 조작 비디오 공개
- 텍스트 주석·MANO 기반 손 자세·카메라 궤적·시간적으로 국소화된 원자적 행동을 데이터셋에 포함
- 시간적 행동 분할·의미 주석·손 재구성·카메라 궤적 재구성을 거쳐 원시 촬영분을 구조화 샘플로 변환하는 처리 파이프라인 동반, VLA·WAM·World Model 학습 레시피를 포함한 다운스트림 툴체인 별도 제공

### (c) 시사점
- 중앙집중형 캡처 대신 커뮤니티 크라우드소싱 방식으로 에고센트릭 데이터(D4ML)를 확장하는 신규 인프라 모델 — AXIS(07-27)의 로봇-액션 크라우드소싱과 대응되는 인간-비디오 축 사례
- 2,000시간 규모 첫 릴리스 자체가 즉시 활용 가능한 오픈 자원 — 손 재구성·카메라 궤적까지 구조화돼 리타겟팅 파이프라인 투입 장벽이 낮음
- 다운스트림 툴체인이 VLA·WAM·World Model 학습 레시피까지 포함해 도입 검토 비용이 상대적으로 낮음

### (d) 먼저 확인할 점
- 데이터 처리 파이프라인 설명은 상세하나 베이스라인 대비 정량 성능 개선폭은 초록 수준에서 확인되지 않음 — 본문 확인 필요
- 실제 로봇 실행·정책 전이 실험이 초록상 포함되지 않음 — 리타겟팅 경로의 실로봇 검증은 별도 필요
- 500명+ 기여자·400대+ 스마트폰 기반 크라우드소싱 특성상 촬영 품질·기기 편차에 따른 데이터 일관성 검증 필요

- **근거** — EgoAffordance(에고 비디오→어포던스 데이터 구조화)·HABIT(인간-현존 상호작용 축 신규 개척)·Open-AoE(커뮤니티 캡처 인프라) 3편이 서로 다른 각도에서 동시 표면화 — ABC-130K·Ego2Robot(08-06)에 이은 대규모 데이터 엔진 트렌드 연속 관찰, 다음 리밸런싱 시 참고 제안
