## 🥇 논문 1

**H2RBench: A Real-to-Sim Benchmark for Evaluating Human-to-Robot Transfer**
[arXiv:2609.24778](https://arxiv.org/abs/2609.24778) · Chuyang Xiao, Haotian Zhan, Sriram Krishna 외 4명 · CoRL 2026 · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 인간 영상 전이 방법을 같은 조건에서 재는 실물-시뮬레이션 벤치마크
- **문제** — 인간 영상 시연에서 로봇 정책으로 넘기는 전이(H2R transfer) 방법을 공정하게 비교할 평가대 부재
  - 방법마다 과제, 물체, 장면 배치, 로봇 시연 사용량이 달라 결과를 나란히 놓을 수 없음
  - 실물 평가는 비싸고 재현이 어려움
- **기존 한계** — 기존 전이 연구는 서로 다른 과제 집합에서 평가되어 방법 차이와 데이터 효율 차이가 섞임
  - 시뮬레이션에서 사람 손을 재현하려면 손 모델 피팅의 복원·접촉 오차나 원격조작의 리타게팅 아티팩트가 끼어듦
  - SIMPLER, PolaRiS, RobotArena ∞는 로봇 데이터 정책에서만 시뮬레이션-실물 순위 일치를 보였고 인간 영상 전이 방법에서는 미검증
- **핵심 방법** — 실제 인간 영상을 모든 평가 방법의 입력으로 쓰고 로봇 쪽 환경은 실물 장면을 재구성한 시뮬레이션으로 평가
  - 과제 4개, 정밀도 요구와 접촉 양상과 시간 지평이 서로 다름
  - 각 과제 환경은 실제 물체와 장면에서 real-to-sim 파이프라인으로 재구성하고 과제별 인간·로봇 시연을 함께 수집
  - 대표 전이 방법 4종 Point Policy, GHOST, Phantom, AMPLIFY를 원 논문 권장 하이퍼파라미터로 평가
  - 방법당 무작위 롤아웃 90회, 시드 3개 기준으로 과제 진행도와 최종 성공률 측정
  - 인간 데이터 효과는 로봇 전용 학습 대비 로짓 변화 $`\Delta_{\text{logit}}`$로 측정해 포화 근처 이득을 보정
- **차별점** — 인간 시연 수를 바꿔 방법별 스케일링을 재고, 같은 방법·과제 조합을 실물에서도 돌려 시뮬레이션 순위의 예측력을 검증
  - 로봇 전용 정책에서만 확인되던 시뮬레이션 순위 예측력을 인간 영상 전이 방법에 확장
- **핵심 기여** — 벤치마크, 스케일링 분석, 시뮬레이션-실물 대응 검증
  - 실제 장면에서 재구성한 조작 과제 집합과 과제별 인간·로봇 시연
  - 인간 시연은 상호작용 같은 상위 수준 행동을 가장 일관되게 개선하고 정밀한 후반 접촉 제어는 여전히 어려움
  - GHOST가 가장 강하고 일관된 성능, 계층 분해나 명시적 서브골 표현을 쓰는 방법이 더 강건한 경향
  - 단순 과제는 인간 시연을 늘릴수록 완만히 개선, 삽입은 이득이 제한적이거나 불안정, 순차 조작은 수익 체감
  - 시뮬레이션 성능이 실물 성능을 대체로 예측, 4과제 × 4방법 16쌍에서 Pearson r 0.89, Spearman ρ 0.85, MMRV 0.06
  - 방법 설계에 참고할 실패 모드 분류 제시
- **가치** — 실물 로봇 없이 인간 영상 전이 방법의 우열과 데이터 스케일링을 가늠하는 공통 잣대

### (c) 시사점

- 인간 데이터 효과를 재는 비교 기준 후보
  - 방법별 인간 데이터 스케일링 곡선이 인간 영상 비중 판단의 근거
  - 시뮬레이션만으로 실물 순위를 가늠하는 평가 경로의 검증 사례
  - 인간 영상이 정밀 접촉 후반 단계에서는 이득이 작다는 점이 촉각 보강의 필요성과 맞닿음
  - 저장소 공개 신호가 없어 직접 도입은 후속 공개에 달림

### (d) 먼저 확인할 점

- **공개 상태** — 코드·벤치마크 저장소와 공개 약속 없음
- **저자 명시 한계** — 탁상 조작과 강체 중심, 변형체·관절 물체·양팔 조작 미포함
  - 인간 시연은 통제된 3인칭 카메라 설정이며 에고센트릭이나 야외 영상 확장은 향후 과제
  - real-to-sim 재구성의 물리 충실도 한계를 그대로 물려받음
- **이식 주의** — 에고센트릭 우선 축과 달리 3인칭 인간 영상 기준 평가
- **표본** — 대응 검증은 16개 방법-과제 쌍 기준

## 🥈 논문 2

**EgoExplorer: A Vision-Motion-Touch Observatory for Human Loco-Manipulation In Situ**
[arXiv:2610.18872](https://arxiv.org/abs/2610.18872) · Yunsong Zhou, Xuekun Jiang, Haiqi Shen 외 11명 · arXiv preprint · source: citation-graph

**점수 8/15** · R2 · N3 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, arXiv comment는 프로젝트 페이지만

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 영상·전신 동작·손가락·촉각을 맞춘 100시간 인간 조작 기록
- **문제** — 휴머노이드 이동 조작(loco-manipulation) 학습에는 시각 맥락, 전신·손 동작, 접촉이 연속 과제에서 함께 기록된 데이터가 필요
  - 로봇 원격조작은 전용 하드웨어와 현장 배치와 조작자 노력 때문에 확장이 어려움
- **기존 한계** — 기존 데이터는 이 협응의 일부만 담음
  - 고정 카메라 배열 기반 모션캡처는 기록 공간마다 장비 설치와 보정 필요
  - 에고센트릭 영상은 시각 맥락은 풍부하지만 몸 대부분이 관측되지 않음
  - 착용형 몸 추적은 손가락 관절과 접촉 측정이 빠지는 경우가 많음
  - 손 중심 데이터는 손 동작과 일부 촉각을 담지만 전신 움직임이 빠짐
- **핵심 방법** — 가벼운 착용 장비로 기록하고 희소한 센서에서 전신 동작을 복원하는 Calibrate-Complete-Constrain 파이프라인
  - 장비 — VIVE Ultimate Trackers 5개(머리·양손·양발목), GoPro HERO13 머리 장착 카메라, 손가락 관절용 MANUS Metagloves 또는 촉각까지 기록하는 Wuji 장갑
  - Calibrate — 지정 동작을 기준 모션 라이브러리와 맞춰 체형·스케일과 몸-센서 변환을 추정, 센서 위치가 같으면 과제 간 재사용
  - Complete — 시간적 사전 모델이 관측되지 않은 관절 동작을 보정된 앵커에서 채워 초기 전신 궤적 생성
  - Constrain — 계층 제약으로 측정 일치, 시간 연속성을 높이고 자기 관통과 지면 관통을 억제
- **차별점** — 몸-센서 기하를 동작 추론에서 분리해 장착 오프셋과 관절 배치의 모호성을 제거
  - 센서 한 번의 포즈가 부착 변환과 기구학 사슬에 함께 의존해 직접 피팅은 여러 해가 가능하다는 저자 지적
- **핵심 기여** — 데이터셋, 복원 파이프라인, 검증 실험
  - 5개 환경과 10개 과제 템플릿에서 에고센트릭 기록 2,715건, 총 100시간, 단계별 서술 주석 포함
  - 추적기 피팅 기준 대비 가장 강한 기준선보다 몸 지점 오차 71.9% 감소
  - 손 안정성, 목표 운동학 복원, 영역별 접촉 추정에서도 평가한 대안보다 우수
  - Cosmos3-Edge 기반 예비 학습 연구에서 영상·행동·촉각 공동 생성이 개별 생성보다 영상 PSNR 15.94에서 16.62dB, 접촉 F1 0.610에서 0.694
  - 기록 영상 조건을 주면 행동 MSE 0.0478에서 0.0277, 촉각까지 더하면 0.0264
  - 기록 2건을 Unitree G1에 리타게팅해 전신 제어기로 추적하는 시뮬레이션 시연
- **가치** — 이동과 조작이 엮인 전신 인간 시연을 가벼운 장비로 수집하는 경로 제시

### (c) 시사점

- 에고센트릭 영상에 전신과 촉각을 맞춘 데이터 후보
  - 에고센트릭 우선 축에 손가락 관절과 접촉 모달리티를 한 기록에서 보태는 사례
  - 촉각은 Wuji 장갑 구성에서만 기록되므로 촉각 포함 분량은 별도 확인 필요
  - 로봇 학습 이득은 시뮬레이션 시연 수준이라 데이터 가치 판단은 보류

### (d) 먼저 확인할 점

- **공개 상태** — 프로젝트 페이지만 있고 코드·데이터 저장소와 공개 약속 없음
- **저자 명시 한계** — 모든 관절의 정확한 복원은 보장되지 않고 촉각 신뢰도가 가변
  - 예비 연구가 실제 휴머노이드 학습 이득을 검증하지 못한다고 §6에 서술
- **평가 범위** — 몸 오차 71.9% 감소는 추적기 피팅 기준 대비 수치이며 별도 광학 모션캡처 정답 대비가 아님
- **이식 주의** — 로봇 실물 결과 없음, 휴머노이드 리타게팅은 시뮬레이션 2건

## 🌱 논문 3 — 인접 분야 픽

**What Matters for World Modeling in Vision-Language-Action Models?**
[arXiv:2610.19825](https://arxiv.org/abs/2610.19825) · Qisen Ma, Yixiang Chen, Yuan Xu 외 10명 · adjacent field: VLA 월드모델 통합 방식 (Slot B)

**점수 10/15** · R2 · N2 · M3 · Real3 · Repro0 — P3 2026-10-19 판정 유지

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- VLA에 월드모델을 붙이는 네 방식을 통제 비교한 연구
- **문제** — 월드모델을 VLA에 넣는 설계 중 무엇이 성능을 좌우하는지 불명
  - 표준 VLA는 현재 관측에서 행동만 예측해 장기 과제와 분포 변화, 동적 환경에 약함
- **기존 한계** — 기존 연구가 월드 표현, 통합 방식, 정책 백본을 동시에 달리해 이득의 원천이 가려짐
  - 픽셀 세부부터 의미 잠재 표현까지 표현이 제각각
  - 암묵적 정렬과 명시적 조건화 같은 설계가 서로 다른 VLA 백본 위에서 비교됨
- **핵심 방법** — 기존 구조를 네 통합 방식으로 정리해 하나의 통일 프레임워크 안에서 각각 구현
  - Implicit Future Alignment, Explicit Future Query, MoT Future Expert, External World Predictor 네 방식
  - 월드 표현 — 픽셀(ImageVAE, WanVAE), 2D 의미(DINOv3, SigLIP), 3D 기하(VGGT), 시공간 영상 동역학(V-JEPA 2.1)
  - 백본 — Qwen3-VL-2B와 사전학습 로봇 VLA인 π0.5
  - 평가 — LIBERO, LIBERO-Plus, RoboTwin 2.0, DOMINO와 실물 4과제
- **차별점** — 한 비교 안에서는 백본과 학습 프로토콜을 공유시켜 표현·방식·백본 요인을 분리
  - 신규 방법 제안 없이 결합과 분리 설계의 득실을 측정하는 연구
- **핵심 기여** — 네 가지 질문에 대한 네 가지 결론
  - 표현 효과는 통합 방식에 좌우되고 2D 의미 표현(DINOv3, SigLIP)이 방식 전반에서 일관된 이득
  - 모든 설정에서 우세한 방식은 없고 분리형 MoT Future Expert가 특히 분포 밖 강건성에서 경쟁력, 저데이터 분포 내 성능은 External World Predictor가 최고
  - 표준 VLM 백본 정책은 월드모델의 이득이 크고 사전학습 VLA에는 분리형 설계가 호환성이 더 좋음
  - 실물 4과제에서 행동 전용 기준선 평균 성공률 45.0%를 월드모델 네 방식이 56.3–73.8%로 상승, MoT Future Expert가 73.8%로 최고
- **가치** — VLA에 월드모델을 붙일 때 참고할 설계 원칙을 통제 실험으로 제공

### (c) 시사점

- 월드모델 통합 설계를 분리해 재는 VLA 평가 프로토콜 사례
  - 표현·통합 방식·백본을 따로 변화시키는 요인 분해 설계는 평가 하네스 구성에 이식 가능
  - 비교 대상이 월드모델 통합이라 데이터 축과는 거리가 있고 벤치마크 설계 참고에 한정

### (d) 먼저 확인할 점

- **공개 상태** — 초록에 프로젝트 페이지와 영상만 있고 코드 저장소와 공개 약속 없음
