**$N_0$-Foundation: Towards the Age of Tactile Intelligence**
[arXiv:2608.29601](https://arxiv.org/abs/2608.29601) · NeoteAI Team, Fudan TEAI Team · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N3 · M2 · Real3 · Repro1 — 초록 "We release the dataset, the representation, and the benchmark" — 저장소 URL 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 3만 시간 시각·촉각 코퍼스와 실물·시뮬 벤치마크 일괄 공개
- **문제** — 접촉 집약적(contact-rich) 조작에 필요한 촉각 신호가 대규모 학습 데이터에서 빠져 있음
  - 성공이 국소 힘·마찰·초기 미끄러짐·접촉 전이에 달린 과제에서 외부·손목 카메라만으로는 관측 부족
  - 해당 과제군 — 변형체 조작, 정밀 삽입·조립, 섬세한 힘 제어, 지속 표면 접촉, 양팔 협조
- **기존 한계** — 대규모 데이터셋은 시각 위주이고 촉각 쪽은 하드웨어별로 파편화
  - 단일 로봇 텔레오퍼레이션 코퍼스, 다기관 교차 구현체 코퍼스, UMI 계열 휴대 수집 장치, 에고센트릭 영상 모두 시각 관측 중심
  - 카메라형 비주오택타일(visuotactile) 센서, 정전용량 어레이, 광섬유 센서가 각자 다른 신호 형식을 내므로 한 장치의 촉각 시연을 다른 장치에 재사용 불가
  - 결과적으로 촉각 데이터·모델이 규모의 이득을 못 봄
- **핵심 방법** — 수집 인프라·데이터·표현·평가 4축을 하나로 묶은 촉각 중심 체계
  - 인프라 — 내구성 있는 비전 기반 촉각 센서, 센서 일체형 UMI 장치 $`\mathcal{N}_{0}`$-TacUMI, 다중 로봇과 UMI 시연을 함께 받는 시각·촉각 동기 수집 시스템
  - NeoData — 실물 텔레오퍼레이션과 UMI 시연을 합친 30,000시간 이상, 6개 구현체, 450개 이상 과제, 수십억 쌍의 RGB·촉각 프레임
  - NeoForce — 조밀한 3축 힘장(force field)을 센서 공통 지도 공간으로 삼아 하드웨어 무관 촉각 표현을 학습하는 시각·촉각 표현 모델
  - 평가 — 실물 NeoReal 10개 과제와 시뮬레이션 NeoSim 12개 과제의 표준 프로토콜
- **차별점** — 센서 외형이 아닌 3축 힘장을 공통 표현으로 써서 이종 촉각 센서 데이터를 한데 학습
  - 장치별 형식 차이가 촉각 데이터 규모화를 막는다는 문제를 표현 수준에서 해소하려는 선택
- **핵심 기여** — 촉각 인프라, 교차 구현체 시각·촉각 코퍼스, 통합 촉각 표현, 표준 평가 프로토콜
  - OpenNeoData — 5,000시간 오픈소스 부분집합, 6개 구현체, 250개 이상 과제, 200개 이상 스킬
  - NeoReal 실물 평가(과제당 무작위 20회) — $`\pi_{0.5}`$가 평균 성공률 26.5%로 최고, 진행 점수 평균 38.1%
  - $`\pi_{0.5}`$ 고정 백본 비교 — 촉각 없음 대비 모든 촉각 변형이 우세, 진행 점수 38.1%에서 NeoForce 조건화 47.5%로 상승
  - NeoSim(과제당 무작위 100회) — $`\pi_{0.5}`$ 평균 45.8%, LingBot-VA 32.1%, 나머지 기준선 다수 11% 미만
- **가치** — 촉각을 대규모 체화 학습에 넣는 데이터·표현·평가 경로를 한 묶음으로 제시
  - 정책이 촉각 신호의 장치 외형이 아니라 물리적 접촉 상태에서 이득을 본다는 주장이 성립하면 센서 무관 촉각 인터페이스의 근거

### (c) 시사점

- 촉각 데이터 공백에 대한 최대 규모 공개 기준점
- 5,000시간 공개분만으로도 기존 추적 촉각·힘 코퍼스보다 한 자릿수 큰 규모
- 실물·시뮬 짝 벤치마크로 촉각 정책 평가를 같은 과제 정의 아래 수행 가능
- 3축 힘장 표현이 센서 간 데이터 통합 비용을 낮출 후보

### (d) 먼저 확인할 점

- 공개 범위는 30,000시간 중 5,000시간 부분집합 — 저장소 URL과 라이선스 표기는 본문에서 미발견
- 실물 최고 성공률 26.5%로 과제 난도가 높아 기준선 간 변별력 확인 필요
- NeoReal 상위 3위인 Fast-WAM이 NeoSim 12개 과제 전부 실패 — 시뮬·실물 순위 일치도 미검증
- 수집 장치가 자체 비전 기반 촉각 센서 — 다른 센서·다지 손으로의 NeoForce 전이 근거 확인 필요

## 🥈 논문 2

**The Imitator Game: Benchmarking Robot Imitative Ability Beyond Action Prediction**
[arXiv:2608.22301](https://arxiv.org/abs/2608.22301) · Xunzhe Zhou 외 11명 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N3 · M2 · Real3 · Repro1 — §5 "IG-10K, Imitator Arena, and the L0–L3 protocol are released" — 코드 저장소 URL 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 인간 시연의 의도 모방을 4단계로 재는 벤치마크와 페어 데이터
- **문제** — 로봇이 인간 시연 영상을 보고 동작이 아닌 의도를 바뀐 장면에서 재현하는지 측정할 수단 부재
  - 이 능력이 온라인의 대량 인간 영상을 로봇 조작 지도 신호로 쓸 수 있는지를 좌우
- **기존 한계** — 인간 영상 학습이 궤적 재매핑 수준에 머물고 기존 평가는 이 간극을 재지 않음
  - 손 키포인트·광학 흐름 추출 후 로봇 동작으로 리타깃해 거의 같은 장면에서 재생하는 방식 — 물체 배치·형상·도구가 조금만 바뀌어도 시연 동작이 무효
  - 기존 일반화 벤치마크는 학습 때 본 장면의 교란 강건성만 평가
  - 영상 조건부 정책은 시연·실행 환경 차이가 작은 분포 내에서만 시험
- **핵심 방법** — 시연과 로봇 장면의 불일치를 단계적으로 키운 L0–L3 계층과 데이터·평가 플랫폼
  - L0 장면 동일 실행, L1 공간 배치 변경, L2 외형·형상이 다른 같은 범주 물체, L3 의미·기능이 다른 물체로 대체한 의도 수준 전이
  - IG-10K — 실물과 시뮬레이션 모두에서 네 단계를 갖춘 환경 정렬 인간·로봇 페어 데이터, 3D MANO 손 자세·분할 마스크·다층 언어 주석
  - Imitator Arena — 블라인드 A/B 인간 평가 공개 플랫폼
  - 언어 조건 VLA, 교차 구현체 스킬 방법, 영상 조건 시각운동 정책 9개 모델(학습 변형 15개)을 공통 어댑터로 평가
- **차별점** — 궤적 재현이 아니라 바뀐 장면에서 무엇을 보존해야 하는지를 단계별로 분리해 측정
  - 시연 장면과 실행 장면의 불일치를 통제 변수로 둔 점이 강건성 벤치마크와 갈리는 지점
- **핵심 기여** — 4단계 벤치마크, IG-10K, Imitator Arena, 9개 모델 체계 평가
  - IG-10K — 20,000개 이상 페어 에피소드, 200개 이상 과제 변형, 6개 도메인
  - 성능은 L0–L2에서 안정적이다가 L3에서 붕괴 — 기능적 대체가 의도 수준 모방의 결정적 장벽
  - 미지 과제 제로샷 성공률은 모든 모델이 13% 미만
  - 실물 Arena(과제·단계 쌍당 5회) — XSkill이 Seen SR 0.63, 제로샷 SR 0.29로 최고, 영상 조건 모델이 제로샷에서 언어 조건 모델을 일관되게 앞섬
  - 페어 데이터 10개 시연 미세조정 — 사전학습 과제 15개에서 45개로 늘릴 때 시뮬레이션 15개 변형 중 14개가 향상
- **가치** — 인간 영상을 로봇 지도 신호로 쓰는 연구에 의도 수준 진척을 재는 공통 척도 제공
  - 의도 수준 모방이 코퍼스나 액션 헤드 확장의 부산물로 오지 않는다는 진단

### (c) 시사점

- 인간 영상 활용도를 의도 수준까지 재는 평가 축 확보
- 에고센트릭 카메라 시점을 포함한 인간·로봇 페어 데이터가 인간 영상 사전학습 효과의 검증 자료
- 페어 사전학습 규모에 따른 소수 시연 적응 향상이 인간 데이터 확보의 근거 수치

### (d) 먼저 확인할 점

- 로봇 쪽은 양팔 그리퍼(16차원 관절·그리퍼 액션) — 다지 손 조작으로의 전이는 별도 검증 필요
- 과제·단계 쌍마다 대체 패턴이 하나뿐이라 대체 간 분산 미측정 — 저자 명시 한계
- 실물 평가는 대표 4개 모델, 쌍당 5회로 표본 작음
- 데이터 공개 방식은 프로젝트 사이트 경유 — 코드 저장소와 라이선스 확인 필요

## 🥉 논문 3

**H2RBench: A Real-to-Sim Benchmark for Evaluating Human-to-Robot Transfer**
[arXiv:2609.24778](https://arxiv.org/abs/2609.24778) · Chuyang Xiao 외 6명 · CoRL 2026 (Tier 1) · source: citation-graph

**점수 11/15** · R3 · N3 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE) [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 인간→로봇 전이 기법을 같은 조건에서 비교하는 Real2Sim 벤치마크
- **문제** — 인간 영상 시연으로 로봇 정책을 학습하는 인간→로봇(H2R) 전이 기법을 체계적으로 비교할 방법 부재
- **기존 한계** — 평가 조건이 제각각이고 시뮬레이션의 인간 쪽 재현이 어려움
  - 기법마다 과제 집합·물체·장면·난도가 달라 교차 비교 신뢰도 낮음
  - 소비하는 로봇 시연 양이 달라 방법 차이와 데이터 효율 차이가 뒤섞임
  - 실물 평가는 비싸고 대규모 재현이 어려움
  - 시뮬레이션 손은 외형·물리가 실제 손과 달라 손 모션 재생은 재구성·접촉 오차, 직접 텔레오퍼레이션은 리타깃 오차 유발
  - SIMPLER·PolaRiS·RobotArena ∞는 로봇 데이터 정책에 한해 시뮬레이션의 실물 예측력을 보였고 H2R 기법에서는 미검증
- **핵심 방법** — 실제 인간 영상을 입력으로 두고 실물 장면을 시뮬레이션으로 재구성한 표준 프로토콜
  - 실물 물체·장면을 real-to-sim 파이프라인으로 재구성한 4개 조작 과제 — 단순 운반·배치부터 적층, 삽입, 순차 조작까지 정밀도·지평선 차등
  - 로봇 시연 예산을 고정하고 인간 시연 수만 바꿔 인간 데이터 규모 효과를 통제 측정
  - Phantom, Point Policy, AMPLIFY, GHOST 4개 기법을 같은 관측·액션 인터페이스에서 시드 3개·무작위 90회로 평가
- **차별점** — 로봇 데이터만 쓰는 정책이 아닌 인간 영상 학습 기법을 대상으로, 로봇 시연 예산 고정 아래 인간 시연 규모를 변수로 둠
- **핵심 기여** — 실물 재구성 H2R 벤치마크, 인간 시연 규모 효과 분석과 실패 유형 분류, 시뮬·실물 일치 검증
  - 인간 시연은 상위 수준 상호작용 행동을 가장 일관되게 개선하고 접촉 집약 과제의 후반 정밀 제어는 여전히 어려움
  - 단순 과제는 대부분 기법이 인간 시연 추가로 꾸준히 향상, 삽입은 이득이 작거나 불안정
  - 시뮬·실물 성공률 상관 — Pearson r = 0.894, Spearman ρ = 0.851, MMRV 0.06
- **가치** — 실물 배포 전에 H2R 기법을 시뮬레이션에서 싸게 비교하는 대리 평가 수단

### (c) 시사점

- 인간 데이터 규모 효과를 시뮬레이션에서 싸게 재는 경로
- 로봇 시연 고정·인간 시연 가변 설계가 인간 데이터 우선 전략의 효과 검증 틀로 바로 차용 가능
- 시뮬·실물 순위 보존(MMRV 0.06)이 실물 평가 비용 절감 근거

### (d) 먼저 확인할 점

- 인간 시연이 통제된 3인칭 카메라 기준 — 에고센트릭·야외 영상은 저자 명시 향후 과제
- 강체 위주 탁상 과제 4개, 그리퍼 이진 명령 액션 — 변형체·관절 물체·양팔·다지 손 미포함

## 🌱 논문 4 — 인접 분야 픽

**Benchmarking World Models for Continual Learning on Compositional Tasks**
[arXiv:2609.22055](https://arxiv.org/abs/2609.22055) · Haoyu Zhou, Joe Watson, Anson Lei, Ingmar Posner · adjacent field: continual learning / catastrophic forgetting (Slot A)

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — 초록 "More details are available on our project website" — 프로젝트 페이지뿐

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 월드 모델의 지식 재사용을 망각과 분리해 재는 CL 벤치마크
- **문제** — 월드 모델의 지속 학습(continual learning)에서 새 과제 학습 속도와 기존 지식 재사용이 한 지표에 뒤섞임
  - 저자 관점 — 환경 동역학은 소수의 재사용 가능한 메커니즘으로 설명되므로 재사용이 효율적 적응의 주 경로
- **기존 한계** — 기존 로봇 조작 CL 벤치마크가 재사용을 분리해 재지 못함
  - Continual World — Meta-World 과제를 단일 과제 단위로 이어 붙여 구성적 측면을 평가하지 못함
  - LIBERO — 공간·물체·목표 분포 이동이 인접 과제 간 쌍별 변화라 최근 변화에만 적응해도 높은 점수 가능
- **핵심 방법** — 앞선 기본 과제를 재조합한 구성 과제로 끝나는 커리큘럼과 행동·지각 축 분해
  - 행동 구성, 지각 구성, 전체 구성의 3개 유형, Meta-World 자산 기반 6개 과제 묶음
  - 월드 모델을 지속 학습할 과제 무관 백본과 그럴 필요 없는 과제별 헤드로 분리해 백본에만 CL 기법 적용
  - DreamerV3·TD-MPC2에 미세조정·ER·EWC·PackNet을 적용하고 전문가 혼합(MoE) 동역학의 모듈형 월드 모델 PWM과 비교
- **차별점** — 마지막 과제를 앞선 전부의 재조합으로 정의해 전방 전이(FWT)가 재사용만을 측정하도록 설계
- **핵심 기여** — 구성적 CL 벤치마크, 월드 모델의 백본·헤드 분리 원칙, 최신 월드 모델 평가
  - 기존 CL 기법은 전방 전이와 후방 전이(BWT) 중 하나를 내주는 절충에 머묾 — ER이 전방 전이 최고, PackNet이 망각 최소
  - 행동→지각→전체 구성 순으로 BWT 단조 악화
  - PWM은 6개 묶음 평균 BWT 3.85, FWT 36.18로 TD-MPC2(34.97, 38.11) 대비 망각을 거의 제거 — 단, 전체 과제 시연으로 사전학습 후 고정한 인코더라는 특권 조건에서만
- **가치** — 재사용과 망각을 분리한 측정으로 재사용형 월드 모델 설계의 진척을 비교할 기준 제시

### (c) 시사점

- 평가 설계 차용 후보 — 재사용과 망각의 분리 측정
- 기본 과제 재조합으로 마지막 과제를 정의하는 커리큘럼 구성이 조작 벤치마크 설계 참고점
- 행동·지각 축 분해가 어느 입력 모달리티에서 재사용이 막히는지 짚는 진단 틀

### (d) 먼저 확인할 점

- 시뮬레이션 전용 — 과제당 10^5–10^6 환경 스텝과 자동 리셋·조밀 보상 의존으로 실물 이식 미수행, 저자 명시 한계
- 그리퍼 기반 Meta-World 과제 — 다지 손·접촉 집약 과제 미포함
- PWM 우위가 특권 고정 인코더 조건에 한정, 그 외에는 TD-MPC2와 동급
- 코드 공개 언급 없이 프로젝트 페이지만 존재
