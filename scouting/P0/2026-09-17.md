## 🥈 논문 1 — 우선순위 ★★

**STAR: Sparse Tactile Representation Learning in Vision-Tactile-Language-Action Models for Dexterous Manipulation**
[arXiv:2609.12549](https://arxiv.org/abs/2609.12549) · Xiangcheng Liu, Tianhao Wu, Le Zheng 외 6인 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 다지 손 조작에는 다중 손가락 협응 제어와 촉각 피드백이 필요하나, 대규모 실환경 데이터 부재와 희소 촉각 신호에서 유효 표현 추출의 어려움이 공백으로 지적
- 자체 로봇 플랫폼·텔레옵 시스템을 구축해 시각·촉각·언어 동기화 주석을 갖춘 200시간 규모 양팔 다지 조작 데이터셋 신규 수집 — 65개 태스크에 걸친 10,576개 궤적, 이 중 69.5%가 다지 손 조작 포함
- 촉각 신호의 공간·시간·정보 희소성을 다루는 통합 학습 레시피 STAR 신규 제시 — 시각-촉각 공동 사전학습, 희소-전역 촉각 토큰 표현, 희소 미래 촉각 예측 3요소로 구성
- 해당 데이터셋으로 학습한 STAR가 4개 실환경 태스크에서 태스크당 100건 포스트트레이닝 궤적만으로 평균 성공률 61% 달성, 태스크 특화 포스트트레이닝 하 덱스트러스 성능 실증

### (c) 시사점
- 희소한 촉각/힘 데이터 축에 실로봇 텔레옵 기반 대규모(200시간) 시각-촉각-언어 동기화 코퍼스 추가 — 다지 손 조작 비중(69.5%)이 높아 촉각 사전학습 자원으로 직접 검토 가능
- 희소 촉각 신호 처리를 위한 3요소 학습 레시피(공동 사전학습·희소-전역 토큰·희소 미래 예측)가 설계돼 자체 비전-촉각-언어-액션 모델 아키텍처 설계에 참조 가능
- 소량(태스크당 100건) 포스트트레이닝만으로 실환경 성능이 확보돼 데이터 효율적 적응 전략 판단 근거로 활용 가능

### (d) 먼저 확인할 점
- 코드·데이터셋 공개 여부가 초록·arXiv comment 모두에 명시되지 않음 — 공개 시점·조건 확인 필요, 현재는 비공개로 처리
- 61% 평균 성공률의 베이스라인 비교·태스크별 분산이 초록 수준에서 제시되지 않음 — 본문 확인 필요
- 9인 규모 팀 산출물로 200시간 규모 텔레옵 파이프라인의 외부 재현 가능성 별도 확인 필요
