## 🥇 논문 1 — 우선순위 ★★★

**REBOOT: From Failure to Recovery - A Dataset and Benchmark for Precision Assembly**
[arXiv:2609.22591](https://arxiv.org/abs/2609.22591) · Nana Yaw Owusu Ofori-Ampofo, Samira Ebrahimi Kahou, Joseph Thekinen · arXiv preprint · source: citation-graph · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 조작 정책 학습 데이터가 성공 시연 위주로 구성되고 실환경 벤치마크가 이진 성공 여부로 성능을 단순화해 실패 유형 분석·복구 학습 신호가 부재하다는 공백 지적
- 실패를 1급 신호로 다루는 최초의 로봇 조작 벤치마크 REBOOT 신규 공개 — 18개 정밀 조립 태스크에 걸친 2,160건 시연, Align(pick)·Engage(pick)·Transport·Align(place)·Engage(place) 5단계로 분해한 페이즈 단위 평가 구조
- 각 페이즈에서 실패를 유도하고 시스템을 정상 상태로 복귀시키는 전문가 복구 궤적을 페어로 구성, 회전 대칭성·삽입 공차 등급·조립 방향까지 태스크별 주석
- 4개 시점 동기화 RGB-D 관측 + 페이즈 단위 성공·실패 자연어 설명 동반, 절반은 전문가 시연·절반은 모방학습 정책 롤아웃에서 관측된 실패를 반영한 복구 시연으로 구성
- 액션 청킹 트랜스포머·디퓨전·π0-FAST 세 정책을 페이즈 단위 완료율로 벤치마킹, 이진 평가에서는 드러나지 않는 모델별 실패 지점 규명

### (c) 시사점
- 벤치마크/이밸 하니스 축에 실패-복구를 1급 신호로 다루는 신규 진단 벤치마크 추가 — RoboVAD(09-21)의 이상탐지 축과 상호보완적인 페이즈 단위 실패 분석 인프라로 활용 가능
- 실패-복구 페어 시연 구조는 자체 복구 정책·재시도 트리거 설계 시 직접 참조 가능한 데이터 포맷
- 공개 데이터셋 + 코드가 즉시 재현 가능해 도입 장벽 낮음

### (d) 먼저 확인할 점
- 3인 소규모 팀 산출물로 18개 태스크·2,160건 규모의 장기 유지보수·확장 가능성 확인 필요
- 정밀 조립(peg-in-hole류) 태스크 중심 구성으로 다지 손(multi-finger) 조작 비중은 초록상 불명확
- 실패 유도 방식이 정책 롤아웃 관측 기반으로, 실제 자율 조작 중 자연 발생 실패와의 분포 차이 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**EgoWild2Dex: Learning Dexterous Robotic Manipulation from In-the-Wild Human Experience**
[arXiv:2609.23755](https://arxiv.org/abs/2609.23755) · Kunyang Lin, Xutao Wen, Jingxi Lin 외 8인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 기존 접근이 제약된·인위적으로 구성된 환경에서 에고센트릭 데이터를 수집하는 데 비해, 가정·공장·약국 등 실제 현장에서 머리 장착 카메라로 일상 작업을 수행하는 완전 인 더 와일드(in-the-wild) 수집 프로토콜 채택
- 장면 잡음·헤드모션에 따른 시점 변화(평균 누적 회전 15.93도/초)를 다루는 EgoWild2Dex 신규 제시 — 불안정한 에고센트릭 시점·인간 동작을 로봇 관측·액션에 정합하는 학습 프레임워크
- 노이즈가 섞인 인간 관측을 로봇 관측으로 워핑하는 미분 가능 기하 트랜스포머 GeoFormer 신규 도입, 제한적 로봇 지도학습만으로 임베디먼트 격차를 해소하는 인간-로봇 학습 스킴 설계
- 538.9시간 규모 인 더 와일드 에고센트릭 인간 데이터셋 EgoWild 신규 공개 — 179,049 에피소드, 125,961개 고유 태스크 설명, 1,282개 객체 카테고리 커버
- 실로봇 3개 장기수평 양팔 다지 조작 태스크에서 평균 성공률 96.7%, 미확인 객체 대상 제로샷 성공률 33.3% 실증

### (c) 시사점
- 에고센트릭/인간 비디오 데이터 축에 이례적 규모(538.9시간, 17만9천 에피소드)의 완전 인 더 와일드 신규 자원 추가 — 통제 환경 편향 없는 사전학습 자원으로 검토 가능
- GeoFormer 기반 노이즈 관측 정합 기법은 저품질·비제약 환경 에고센트릭 데이터 활용 파이프라인 설계에 직접 참조 가능
- 제한적 로봇 지도학습만으로 높은 실환경 성공률을 달성한 임베디먼트 격차 해소 전략은 데이터 효율적 적응 투자 판단 근거로 활용 가능

### (d) 먼저 확인할 점
- 데이터·모델·코드가 "will be released"로만 명시돼 현재 시점 공개 저장소 미확인 — 공개 시점 별도 확인 필요
- 96.7%·33.3% 성공률의 베이스라인 비교·태스크별 분산이 초록 수준에서 제시되지 않음 — 본문 확인 필요
- 179,049 에피소드 규모 데이터의 라이선스 조건·다지 손 임베디먼트 커버리지가 초록상 불명확

## 🥈 논문 3 — 우선순위 ★★

**LIBERO-VPro: Benchmarking Closed-Loop Visual Robustness of Robotic Foundation Models**
[arXiv:2609.24350](https://arxiv.org/abs/2609.24350) · Huiqiong Li, Zhiting Mei, Anirudha Majumdar 외 3인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 기존 로봇 파운데이션 모델 벤치마크가 실행 중 시각 관측이 깨끗·시의적절·일관적이라는 전제하에 평가된다는 공백 지적, 폐루프(closed-loop) 시각 강건성 진단 부재 문제 제기
- 실행 중 시각 증거를 체계적으로 교란해 폐루프 시각 강건성을 진단하는 벤치마크 LIBERO-VPro 신규 제시 — 시각 증거 열화·카메라 지연·시각 소스 일관성·태스크 연관 장면 변화 4개 축, 12개 세부 카테고리, 96개 실험 설정, 3,296개 태스크-조건 케이스로 구성
- VLA 3종·World-Action Model(WAM) 3종을 약 196,000건 시뮬레이션 에피소드 + Franka Research 3 기반 실로봇 롤아웃 200건으로 평가
- 강한 명목 성능이 시각적 근거·적응 능력의 취약점을 은폐할 수 있음을 규명 — 물체 수준 가림에는 강건하나 로컬 상호작용 단서 교란·익숙한 공간 사전지식 위반 시 급격히 저하
- VLA와 WAM이 서로 다른 강건성 프로파일을 보여 시각 강건성이 다차원적·아키텍처 의존적임을 실증

### (c) 시사점
- 벤치마크/이밸 하니스 축에 정적 성능만으로 가려지는 폐루프 시각 강건성 사각지대를 겨냥한 진단 벤치마크 추가 — VLA·WAM 구분 진단이 가능해 자체 아키텍처 선택 판단에 참조 가능
- 200건이나마 실로봇 롤아웃을 포함한 검증 체계로 시뮬레이션-실환경 격차 판단 근거 확보
- 12개 세부 카테고리·4개 축의 체계적 진단 프레임워크는 자체 강건성 평가 파이프라인 설계에 직접 참조 가능

### (d) 먼저 확인할 점
- 평가 규모의 대부분(약 196,000건)이 시뮬레이션 기반으로, 실로봇 검증은 200건 롤아웃에 한정 — 실환경 일반화는 제한적 규모로만 확인
- 프로젝트 페이지만 공개되고 코드·벤치마크 자산 저장소 URL은 초록·arXiv comment 수준에서 명시되지 않음 — 실제 다운로드 경로 별도 확인 필요
- VLA 3종·WAM 3종 한정 평가로 다지 손(multi-finger) 임베디먼트 커버리지는 불명확

## 🥈 논문 4 — 우선순위 ★★

**H2RBench: A Real-to-Sim Benchmark for Evaluating Human-to-Robot Transfer**
[arXiv:2609.24778](https://arxiv.org/abs/2609.24778) · Chuyang Xiao, Haotian Zhan, Sriram Krishna 외 4인 · CoRL 2026 · source: citation-graph · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 인간 비디오 시연으로부터 로봇 조작 정책을 학습하는 인간→로봇(H2R) 전이 기법들이 서로 다른 태스크 구성·씬 레이아웃·물체 인스턴스·로봇 지도학습량 하에 평가돼 방법 간 비교가 어렵다는 공백 지적
- 실제 인간 비디오 시연 + 시뮬레이션 로봇 시연을 결합한 표준화 프로토콜 Real2Sim 벤치마크 H2RBench 신규 제시 — 상이한 상호작용 요구를 아우르는 4개 조작 태스크로 구성
- 임베디먼트 격차를 해소하는 서로 다른 전략을 채택한 다수 대표 H2R 전이 기법을 평가, 인간 시연량 증가에 따른 스케일링 양상이 기법별로 크게 다름을 체계적으로 규명
- 시뮬레이션 성능이 실환경 로봇 성능을 광범위하게 예측함을 실증 — 방법-태스크 조합 전반에서 피어슨 상관계수 r=0.89, 스피어만 상관계수 ρ=0.85, MMRV 0.06
- CoRL 2026 게재 확정으로 커뮤니티 표준 비교 프로토콜로 자리잡을 가능성

### (c) 시사점
- 벤치마크/이밸 하니스 축에 H2R 전이 기법 비교를 표준화하는 벤치마크 추가 — 에고센트릭/인간 시연 우선순위 축의 다운스트림 평가 인프라로 즉시 참조 가능
- 시뮬레이션-실환경 성능 간 높은 상관관계(r=0.89) 실증은 저비용 시뮬레이션 평가로 실배포 전 방법 선별이 가능함을 시사, 자체 H2R 파이프라인 검증 비용 절감 근거로 활용 가능
- CoRL 2026 게재 확정으로 조기 채택 시 비교 우위 확보 가능

### (d) 먼저 확인할 점
- 코드·데이터 저장소 URL이 초록·arXiv comment 모두에 명시되지 않음 — 공개 여부 별도 확인 필요, 현재는 비공개로 처리
- 로봇 시연·평가 환경이 시뮬레이션 구성으로, 실로봇 상관관계 검증 태스크셋의 규모가 초록상 불명확
- 4개 조작 태스크 한정 구성으로 다지 손(multi-finger) 조작 비중·임베디먼트 다양성은 초록상 불명확

- Methodology 3 — 6개 모델을 약 196,000건 시뮬레이션 에피소드 + 실로봇 200건 롤아웃으로 다차원 평가
- Sim2Real 2 — 초록 "complemented by 200 real-world rollouts on a Franka Research 3" — 실로봇 검증 포함되나 평가 규모 대부분(약 196,000건)은 시뮬레이션

**H2RBench (11/15)**
- Relevance 3 — 인간→로봇 전이 기법 표준 비교 벤치마크로 D4ML·D6SE 이중 해당
- Novelty 3 — 상이한 평가 설정을 통일하는 최초 표준화 H2R 전이 벤치마크 + 스케일링 특성 규명은 기존 파편화된 개별 평가와 차별화
