## 🥇 논문 1 — 우선순위 ★★★

**HandEdit: A Unified Benchmark for Egocentric Human-to-Robot Dexterous Hand Image Editing**
[arXiv:2608.12122](https://arxiv.org/abs/2608.12122) · Zhenjie Yang, Xingyu Jiao, Guopeng Zhong 외 18인 · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 다지 로봇 조작 학습이 embodiment-aware 텔레옵 데이터 수집 고비용에 발목잡힘, 에고센트릭 인간 손 비디오가 스케일러블 대안이나 인간-로봇 간 외형·관절 구조·카메라 시점 격차가 co-training을 가로막는다는 문제 지적
- 에고센트릭 프레임 내 인간 손·팔을 다양한 다지 로봇 embodiment로 변환하는 대규모 embodiment-aware 이미지 편집 데이터셋+벤치마크 HandEdit 신규 공개
- 5개 소스 데이터셋 기반 2억(200M)건 이상 편집 인스턴스 구성, 손 전용(hand-only) 13종 + 손-팔(hand-arm) 13종 총 26개 URDF 커버
- Hand-only / Hand-Arm 2개 트랙의 URDF 조건부 평가를 지원하는 통합 벤치마크 프로토콜 수립
- 범용 유사도 지표·VLM 기반 판정·embodiment-aware 지표를 아우르는 다차원 지표 세트로 대표 이미지 편집 베이스라인 11종 평가

### (c) 시사점
- 에고센트릭 인간 비디오(D4ML)를 다지 로봇 embodiment로 직접 변환하는 이미지 단 브리징 계층 제시 — 리타겟팅 파이프라인 전 단계의 신규 자원
- 200M+ 규모·26 URDF 커버리지는 다지 핸드 특화 embodiment 전이 자원으로는 이례적 스케일
- 다지 손(hand-only)·손-팔(hand-arm) 트랙 분리 벤치마크가 자체 전이 파이프라인 평가 설계 시 참조 프레임워크로 활용 가능

### (d) 먼저 확인할 점
- 공개 저장소·라이선스·다운로드 경로가 초록상 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 이미지 편집 결과물이 실제 로봇 정책 학습 성능으로 이어지는지는 초록상 미검증 — 다운스트림 정책 전이 실험 별도 필요
- 21인 대규모 협업 산출물로 5개 소스 데이터셋 혼합 시 라이선스 조건 상충 가능성 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**GraspIT: A Dataset Bridging the Sim-to-Real gap and back for Validated Grasping SE(3) Pose Generation**
[arXiv:2607.05869](https://arxiv.org/abs/2607.05869) · Paul Koch, Adem Karakurt, André Sers · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D8SD](https://img.shields.io/badge/D8SD-d97706.svg)](#ref-D8SD)

### (b) 핵심 기여
- 신규 객체 로봇 그래스핑 학습에 포토리얼리스틱 RGB-D 관측 + 물리적으로 검증된 그래스핑 품질 주석 + 시뮬레이션-실환경 브리지를 동시에 제공하는 데이터셋 부재 문제 지적
- NVIDIA Isaac Sim 내 테이블탑 씬을 4단계 물리 슬립테스트(병렬 그리퍼 Franka Panda 인스턴스)로 주석화하는 데이터셋 GraspIT 신규 공개 — force-closure를 넘어선 궤적-도달성 검사 + 연속 품질 점수 산출
- 약 230만 그래스핑 후보 중 83%가 품질 기준(≥0.50) 통과, force-closure는 통과했으나 슬립테스트는 실패한 17%를 하드 네거티브로 별도 제공
- Real↔Sim 루프로 라벨을 100개 실환경 씬에 역투영, 약 31.6만 건 주석 RGBD 프레임 세트(시뮬 1,035 + 실환경 100 씬) 구성 — 인스턴스 마스크·6-DoF 포즈·물리적 객체 속성·점수화된 6-DoF 그래스핑 포함
- 전체 툴체인 오픈소스 + Docker 컨테이너화 공개, Isaac Sim 내 궤적 계획으로 고해상도 시연 스트리밍까지 지원해 조작 정책 학습·행동 복제로 확장 가능

### (c) 시사점
- force-closure만으로 판정하지 않는 물리 검증 그래스핑 품질 라벨 방식은 로봇-액션 데이터 축의 그래스핑 서브태스크 기준선으로 즉시 활용 가능
- 오픈소스+Docker 컨테이너화 공개로 재현 장벽 낮음 — 라이선스/사용성 기준에도 우호적
- 하드 네거티브(force-closure 통과, 슬립테스트 실패) 라벨링 방식이 그래스핑 실패 모드 학습 데이터로 별도 가치

### (d) 먼저 확인할 점
- 병렬 그리퍼(Franka Panda) 기준 설계로 다지 핸드 조작 축 직접 적용성은 낮음 — 다지 핸드 그래스핑으로의 전이 방법 별도 검토 필요
- 실환경 검증이 100개 씬으로 시뮬레이션(1,035 씬) 대비 상대적으로 작은 비중 — 실환경 일반화 폭 추가 확인 필요
- 저자 3인 소규모 팀 산출물로 약 230만 후보 규모 라벨링 파이프라인의 장기 유지보수 확인 필요

**RoboSynChallenge: Mastering Real-World Dexterity via Generalizing Synthesized Manipulation Skills**
[arXiv:2608.12416](https://arxiv.org/abs/2608.12416) · Runyi Zhao, Ruixin Wu, Chengkun Li 외 15인 · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 범용 로봇 조작 정책 학습이 실환경 데이터의 희소성·편중된 다양성에 발목잡힌다는 공백 지적, 모델 구조·학습 알고리즘 발전만으로는 해결되지 않는 문제로 규정
- 대규모 합성 데이터 생성 + 표준화된 실환경 로봇 평가를 통합하는 벤치마크/챌린지 RoboSynChallenge 신규 제시
- 참가자는 합성 상태-액션 시행을 활용한 정책 학습 개선을 유도하되, 최종 평가는 미공개(unseen) 실환경 조작 환경에서만 엄격 진행
- Transformer·Diffusion·Vision-Language-Action·World-Action-Model 4개 계열 베이스라인 구현을 재현성·비교가능성 확보 목적으로 동반 제공
- 시뮬레이션 기반 확장형 학습과 엄격한 실환경 검증을 결합해 데이터 효율적·범용 조작 시스템 개발 촉진 목표

### (c) 시사점
- 벤치마크/이밸 하니스 축에 합성-실환경 결합형 표준 평가 프로토콜 추가 — sim(생성) → real(평가) 파이프라인이 자체 평가 설계 참조 가능
- 4계열 베이스라인(Transformer/Diffusion/VLA/WAM) 동시 구현은 정책 아키텍처 비교 실험의 즉시 활용 가능한 출발점
- 챌린지 형식으로 운영돼 커뮤니티 참여를 통한 지속적 벤치마크 확장 가능성

### (d) 먼저 확인할 점
- 초록상 구체적 태스크 목록·난이도·다지 손 조작 비중이 불명확 — 실제 평가 태스크 구성 확인 필요
- 합성 데이터 생성 파이프라인의 공개 여부·라이선스가 초록상 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 챌린지 성격상 리더보드/평가 인프라의 장기 운영 지속성 확인 필요
