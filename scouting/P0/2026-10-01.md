## 🥇 논문 1 — 우선순위 ★★★

**FineART: Fine-grained Annotated Robotic Trajectory Dataset and Vision-Language-Action Model for Bimanual Manipulation**
[arXiv:2609.36416](https://arxiv.org/abs/2609.36416) · Jade Choghari, Pepijn Kooijmans, Mansi Agarwal 외 8인 · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 단일 팔 데이터셋은 에피소드당 상위 지시 1건에 그치고, 서브태스크를 라벨링한 양팔 데이터셋도 전체 시간의 일부만 주석한다는 공백 지적
- 40,543 에피소드·1,718시간·533,913 서브태스크·151 태스크 규모의 고밀도 주석 양팔 조작 데이터셋 FineART 신규 공개
- 다음 서브태스크를 스스로 예측하는 VLA 정책 FineART-VLA 제시, 해당 방식 미드트레이닝으로 공간 구분 태스크 성공률 32.0%에서 100.0%로 상승
- 사람의 단계별 서브태스크 안내 시 미확인 장기수평 태스크 성공률 16.0%에서 76.0%로 상승
- 신규 로봇 미세조정 시 미드트레이닝 없는 베이스라인 대비 데이터 10분의 1, 미확인 태스크 제로샷 일반화
- 데이터셋·모델 가중치·학습 코드 전체 오픈소스

### (c) 시사점
- 서브태스크 단위 밀도 주석을 갖춘 대규모 로봇-액션 코퍼스 확보 — 라벨 밀도 기준점으로 활용 가능
- LeRobot 포맷 통합 예정으로 도입 비용 낮음
- 다지 손·촉각 모달리티는 범위 밖, 보조 코퍼스 역할 한정

### (d) 먼저 확인할 점
- 양팔 그리퍼 중심 코퍼스로 손가락 수준 접촉 정보 부재 여부 확인 필요
- 라이선스 조항 초록에 미명시, 재사용 조건 확인 필요
- 32.0%에서 100.0%, 16.0%에서 76.0% 이득이 소수 태스크 기준이라 일반화 폭은 본문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**RoboChrono: A Real Robot Benchmark for Streaming Task Understanding**
[arXiv:2609.36605](https://arxiv.org/abs/2609.36605) · Yuzhou Wu, Longteng Fan, Zimeng Li 외 22인 · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 진행 중인 조작의 시각 관측을 상호작용 이력·태스크 진행도와 연결해 해석하는 능력의 평가 공백 지적
- 실로봇 실행과 맨손 인간 녹화로 구성한 39개 시나리오·34,713개 평가 인스턴스의 스트리밍 태스크 이해 벤치마크 RoboChrono 신규 공개
- 인식·정렬·시간 정위 3군 7개 태스크 구성 — 행동 이해·예측, 시각 대응, 시간 순서, 행동 위치 탐색 포함
- 18개 VLM 제로샷 평가 결과 태스크 간 격차 확인 — Frame Matching 98.3% 대비 Frame Ordering 68.3%
- 입력 제거 어블레이션 결과 Current Action Recognition은 22.1%p 하락, Next Action Prediction은 0.7%p 하락에 그쳐 태스크·행동 사전지식 의존 시사

### (c) 시사점
- 실로봇 실행과 인간 영상을 한 벤치마크에 묶은 진단 세트 확보 — 합산 점수가 가리는 능력별 격차 측정 가능
- 코드와 데이터셋 2종이 Hugging Face에 공개돼 도입 비용 낮음
- 인간 맨손 녹화 포함 구성은 인간-로봇 혼합 평가 설계 참조 가능

### (d) 먼저 확인할 점
- VLM 이해력 평가 위주로 정책 실행 성공률 평가 아님, 다지 손·접촉 집약적 조작 커버리지 확인 필요
- 평가 대상 로봇 플랫폼 구성과 손 형태 비중 본문 확인 필요
- 라이선스 조항 초록에 미명시, 재사용 조건 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**Unified Visual-Tactile-Action Modeling from Human Demonstrations for Dexterous Manipulation**
[arXiv:2609.34182](https://arxiv.org/abs/2609.34182) · Wenqiao Li, Qianyou Zhao, Jiawen Hao 외 5인 · arXiv preprint · source: citation-graph · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 다지 손 텔레옵은 조작자에게 촉각 피드백을 주지 못해 로봇 촉각 시연 확장이 어렵고, 인간 시연이 촉각 상호작용 다양성 확보에 더 유리하다는 문제 설정
- 영상·촉각 신호·손 동작을 동기 기록하는 촉각 모션캡처 시스템 구축
- 접촉 집약적 5개 태스크에 인간 시연 1,000건과 태스크당 로봇 시연 150건으로 구성한 UVTA 데이터셋 신규 구축
- 인간·로봇 양쪽 임베디먼트를 정렬된 촉각·액션 표현으로 사상하고 미래 액션과 촉각 궤적을 함께 예측하는 통합 모델 제시, 배포 시에는 로봇 액션만 실행
- 실로봇 5개 태스크 평균 성공률 70%, 최강 비주얼-촉각 베이스라인 29%·아키텍처 어블레이션 42% 대비 우위
- 태스크당 인간 시연 1,000건까지 성능 포화 없이 개선

### (c) 시사점
- 희소한 촉각 모달리티를 로봇 텔레옵이 아닌 인간 시연으로 확장하는 경로 확인 — 촉각 코퍼스 확보 전략 대안
- 인간 시연 규모에 따른 성능 곡선 공개로 데이터 수집량 산정 근거 확보
- 촉각 모션캡처 구성이 자체 촉각 수집 파이프라인 설계에 참조 가능

### (d) 먼저 확인할 점
- 초록상 프로젝트 페이지만 확인, 데이터셋·코드 공개 범위와 라이선스 확인 필요
- 5개 태스크 규모라 사전학습 규모 코퍼스와는 층위 상이
- 인간 촉각 장갑·센서 구성과 로봇 촉각 센서 간 정렬의 센서 종속성 확인 필요
