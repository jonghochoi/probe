## 🥇 논문 1

**ACTS: Learning Visuo-Tactile World Models from Human Physical Interaction**
[arXiv:2610.24285](https://arxiv.org/abs/2610.24285) · Yuxiang Ma, Weihan Xu, Pengfei Ye 외 5명 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — §1 "We will release the React dataset, trained models, and code upon acceptance."

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 사람이 쥔 촉각 센서 기록만으로 학습한 시각촉각 월드모델
- **문제** — 접촉 집약 조작의 월드모델에는 접촉 형성, 미끄러짐, 해제를 힘 변화별로 담은 데이터가 필요하고 그 수집이 병목
  - 접촉 위치와 힘의 작은 차이가 붙음, 미끄러짐, 끼임, 접촉 상실을 가름
  - 시각은 장면 움직임만 잡고 원인이 되는 국소 상호작용은 해상하지 못함
- **기존 한계** — 기존 시각촉각 월드모델은 로봇 상호작용 궤적으로 학습하고 일부는 핸드헬드 그리퍼 데이터를 병용
  - 로봇 원격조작은 촘촘한 접촉 탐색에 느리고 힘 피드백이 제한적
  - UMI, TacUMI 같은 로봇 없는 수집 인터페이스는 로봇을 빼지만 그리퍼의 고정된 접촉 기하가 남음
  - 두 경우 모두 행동이 수집 장치에 묶임
- **핵심 방법** — 사람이 GelSight 센서를 직접 쥐고 조작한 기록으로 사전학습 비디오 모델을 적응한 ACTS
  - 기록 — 3인칭·손목 영상, 촉각 이미지, 6자유도 센서 모션, 촉각 유래 수직 힘
  - 행동 — 센서 좌표계의 상대 모션에 법선 방향 힘 변화 변위를 더한 표현, 장면 뷰에 투영한 센서 기하도 함께 입력
  - 예측 — 관측 이력과 센서 행동에서 미래 장면·손목·촉각 관측을 함께 생성
  - 물체마다 모델 하나를 사람 데이터만으로 학습
- **차별점** — 행동을 손이나 그리퍼가 아닌 촉각 센서에서 정의해 사람 수집과 로봇 실행이 같은 행동 공간을 공유
- **핵심 기여** — 행동 표현, 데이터셋, 사람 데이터만으로 학습한 월드모델
  - React — 4.9시간 양팔 사람 시각촉각 데이터셋, 물체 3종, 멀티뷰 영상, GelSight Mini 2개 스트림, 추적된 센서 포즈, 촉각 유래 수직 힘
  - 사람 보류 데이터에서 장면 뷰 예측 PSNR이 React로 처음부터 학습한 시각촉각 월드모델 둘 중 강한 쪽보다 0.7–2.0dB 개선
  - 로봇 원격조작 롤아웃에 미세조정 없이 적용, PushT에서 프레임 복사 초과, Rope에서 혼재, Motherboard에서 미달
  - 검사한 롤아웃에서 예측 촉각 자국이 기록된 접촉과 함께 나타나고 사라짐
  - 데이터셋, 학습 모델, 코드는 채택 후 공개 예정
- **가치** — 로봇 없이 사람의 물리 상호작용에서 접촉 동역학을 모으고 로봇으로 옮기는 경로 제시

### (c) 시사점

- 촉각 데이터를 로봇 없이 사람 쪽에서 모으는 경로의 초기 증거
  - 힘 정보가 붙은 접촉 데이터를 원격조작 없이 수집하는 사례로 촉각 희소성 완화 후보
  - 접촉 동역학이 시각 외형보다 사람에서 로봇으로 안정적으로 전이된다는 저자 결론
  - 센서 단위 행동 표현은 수집 장치가 다른 코퍼스를 한 형식으로 묶는 설계 참고
  - 공개가 채택 후 예정이라 당장의 도입은 불가

### (d) 먼저 확인할 점

- **공개 상태** — 데이터셋, 모델, 코드 모두 채택 후 공개 예정이며 저장소 없음
- **저자 명시 한계** — 수직 힘만 추정하고 미끄러짐을 좌우하는 전단력은 미반영
  - 힘 추정 오차 0.318N(6.4%)은 CNC 보정 데이터 기준이며 사람 기록의 조작 중 오차는 미측정
  - 모든 스트림을 VAE 복원 정답 기준으로 채점, 접촉 형성 시점은 정성 평가뿐
  - OptiTrack 모션캡처에 의존해 계측된 한 실험실에 한정
- **전이 범위** — 물체 3종에 물체별 모델이며 시각 전이는 물체에 따라 갈림
  - 촉각 스트림은 6개 중 5개에서 프레임 복사가 PSNR이 더 높고 LPIPS는 5개에서 ACTS가 낮음
- **이식 주의** — 로봇 정책 실행 성공률이 아닌 예측 품질 평가, 로봇 쪽 배치에도 외부 추적 필요

**Ropedia W0: Scaling Loco-Manipulation World Models across Embodiments with Human Experience**
[arXiv:2610.26855](https://arxiv.org/abs/2610.26855) · Tianqi Liu, Hanfei Zhao, Qifeng Liang 외 12명 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — arXiv comment "Code: https://github.com/Ropedia/ropedia-w0"

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 인간 에고센트릭 1만 시간으로 사전학습한 이동조작 월드모델
- **문제** — 이동과 조작을 함께, 여러 구현체에 걸쳐 모델링하는 월드모델이 미해결
  - 기존 모델은 고정 베이스 그리퍼 조작에 치우쳐 이동에 따른 시점 변화와 손-물체 상호작용이 덜 다뤄짐
  - 학습에는 카메라 궤적, 손 동작, 과제 서술이 붙은 대규모 에고센트릭 영상이 필요
- **기존 한계** — 기존 월드모델은 구현체마다 별도 제어 인터페이스가 필요하고 공개 에고센트릭 데이터는 주석이 불완전
  - DreamDojo는 후학습에서 로봇별 행동으로 대체
  - Cosmos3는 백본을 공유해도 도메인별 행동 투영에 의존
  - 공개 에고센트릭 데이터셋은 미터 단위 카메라 궤적이 없거나 손 포즈가 부정확하고, 형식이 제각각이며 규모도 모자람
- **핵심 방법** — 카메라 포즈와 투영 스켈레톤을 묶은 공유 명시 기구학 표현으로 인간·로봇 영상을 함께 학습
  - 이동은 미터 단위 카메라 포즈, 조작은 투영 스켈레톤으로 표현
  - 스켈레톤은 인간 포즈 주석에 로봇 순방향 기구학(FK)과 수동 키포인트 보정을 결합
  - 같은 조건 인터페이스를 인간 사전학습, 인간-로봇 미드트레이닝, 선택적 후학습에 유지
  - 증류한 학생 모델로 실시간 분 단위 롤아웃과 VR 상호작용 지원
- **차별점** — 구현체별 행동 공간 대신 이미지에 정렬된 기구학 표현 하나로 구현체 고유 구조를 보존
- **핵심 기여** — 데이터, 모델, 벤치마크, 응용 검증
  - Xp-Data — 인간 에고센트릭 1만 시간과 로봇 3천 시간을 통일 주석으로 묶은 코퍼스
  - Xp-Teleop — 덱스터러스 휴머노이드 원격조작 기반 장기 이동조작 벤치마크
  - 5개 교차 구현체 벤치마크와 보류 인간 영상에서 최고 수준 예측, 제로샷부터 소량·전량 후학습까지 평가
  - 사전학습 데이터 1%만 후학습해도 공식 기반 가중치의 전량 후학습을 PSNR로 상회
  - 인간 사전학습 데이터를 늘릴수록 인간 영상과 로봇 벤치마크 예측이 단조 개선
  - 실제 Unitree G1에서 정책 평가 대리로 쓴 점수가 체크포인트 3종과 전문가 원격조작 기준의 정답 평가와 r=0.996
  - 실제 G1 계획 과제 진행도 55%, 무작위 선택 26%, 최선 고정 체크포인트 45%
- **가치** — 인간 에고센트릭 경험을 교차 구현체 월드모델의 확장 가능한 지도 자원으로 쓰는 근거 제시

### (c) 시사점

- 에고센트릭 우선 축을 로봇 성능 이득으로 연결하는 대규모 사례
  - 인간 사전학습 규모에 따른 로봇 전이 개선 곡선이 인간 영상 비중 판단의 근거
  - Xp-Data 1만 시간 인간 대 3천 시간 로봇 구성은 혼합 코퍼스 설계의 참고 비율
  - 코드는 공개되나 데이터와 체크포인트 공개는 확인 필요

### (d) 먼저 확인할 점

- **공개 상태** — arXiv comment에 코드 저장소 있음, 데이터와 체크포인트 공개 문구는 찾지 못함
- **평가 성격** — 핵심 지표는 영상 예측 품질이며 정책 성공률 이득은 응용 실험에 한정
  - 실물 수치는 G1 한 플랫폼의 정책 평가와 계획 과제 기준
- **재현 범위** — 시드 반복과 저자 명시 한계 서술을 찾지 못함
- **이식 주의** — 로봇 쪽 주석에 수동 키포인트 보정이 들어가 주석 비용 확인 필요
  - 데이터 라이선스는 본문에서 확인하지 못함

## 🥉 논문 3

**Kinematic Constraint-Referenced Evaluation for Articulated Object Manipulation**
[arXiv:2610.37550](https://arxiv.org/abs/2610.37550) · Baptiste Bonin, Caro Strickland, Audrey Durand · arXiv preprint · source: citation-graph

**점수 8/15** · R2 · N3 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 명령된 동작을 관절 축에 비추는 정책 평가 지표 CRS
- **문제** — 조작 정책 평가가 이진 성공 여부에 치우쳐 명령 동작이 대상 물체 운동학이 허용하는 동작인지 가리지 못함
  - 서로 다른 원인의 실패가 같은 점수로 기록됨
  - 틀린 동작으로 통과해도 성공으로 채점, 문으로 학습한 정책이 서랍을 문 특유의 호 동작으로 열어도 통과
- **기존 한계** — 더 풍부한 지표는 추가 정보를 요구
  - 시연 기준 거리는 물체마다 기록이 필요
  - 하위 목표 점수는 과제마다 단계 정의가 필요
  - 학습된 평가자는 판정 모델 학습이 필요
  - MetaFine은 동작을 평가하지만 기하 검사가 기술별 허용 오차의 통과·실패이고 안정성 점수에는 물체 모델이 없어, 명령 중 관절을 진행시키는 몫과 거스르는 몫을 부호 있는 연속값으로 주지 못함
- **핵심 방법** — 단단한 파지를 가정해 명령된 말단 트위스트를 물체 관절 축에 투영하는 Constraint-Referenced Strategy(CRS)
  - 관절 하나의 나사 축이 유효한 열림 방식을 모두 담아 기준이 방식에 무관
  - 두 채널 — 관절 방향 명령 진행과 제약 밖 낭비
  - 관절 모델과 이를 따르는 스크립트 컨트롤러만 필요, 시연이나 학습된 판정기 불필요
  - 기준 상태에서 채점
- **차별점** — 실현된 운동이 아니라 명령에서 읽음
  - 관절 달린 부품의 실제 운동은 구성상 항상 허용되어 제약 밖 행동이 부품 움직임에 흔적을 남기지 않는다는 저자 논지
- **핵심 기여** — 지표와 시뮬레이션 검증
  - ManiSkill의 GAPartNet 관절 물체 74개, 문 39개·서랍 22개·수도꼭지 13개에서 평가
  - OpenVLA-7B LoRA 시드 3개와 포인트클라우드 행동 복제 정책 시드 5개 사용
  - 성공률은 전이 실패 3종을 낮은 비율로만 기록하고 원인은 귀속하지 못하나, CRS 두 채널은 각각 다른 서명을 줌
  - 문 학습 행동 복제 정책이 서랍 110 에피소드 중 59개를 열었고, 통과 에피소드의 축 밖 회전 명령이 서랍 학습 정책의 약 40배(1.27 대 0.032rad/s)
  - 스크립트 컨트롤러를 같은 축으로 채점한 기준 대비 CRS 판정은 관절 축 오차 30도까지 불변, 절대 임계값은 약 8도까지 허용
- **가치** — 이진 성공이 가리는 동작 품질을 시연이나 판정기 없이 대규모 벤치마크에 붙이는 평가 신호

### (c) 시사점

- 성공률을 보완하는 동작 단위 평가 신호 후보
  - 관절 물체 벤치마크에서 성공률이 가리는 전이 실패를 귀속하는 평가 하네스 부가 지표
  - 관절 축만 있으면 채점되어 과제마다 시연이나 단계 정의를 붙일 필요 없음
  - 1자유도 관절과 시뮬레이션에 한정되어 인핸드 회전이나 도구 조작 평가에는 직접 적용 불가
  - 저장소 공개 신호가 없어 도입은 후속 공개에 달림

### (d) 먼저 확인할 점

- **공개 상태** — 코드 저장소와 공개 약속 없음
- **저자 명시 한계** — 단단한 파지와 단일 1자유도 관절을 가정하고 각도 낭비만 채점
  - 수도꼭지 사례는 단단한 파지 가정이 늘 성립하지 않음을 시사
  - 기구 3종의 시뮬레이션에서만 검증, 낭비의 물리 비용은 미측정
- **지표 해석** — 명령 속도 보정 기울기가 1 미만(0.49, 0.28, 0.60)이라 속도는 방향과 상대 비교로만 해석
- **이식 주의** — 실물 하드웨어 검증 없음, 관절 축 주석이나 추정이 선행되어야 함
