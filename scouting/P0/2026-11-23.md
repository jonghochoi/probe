## 🥇 논문 1

**Ego2X: Contact-aware Transfer from Egocentric Human Data to Any Robot**
[arXiv:2611.24138](https://arxiv.org/abs/2611.24138) · Xinke Lyu 외 2명 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 9/15** · R3 · N2 · M3 · Real0 · Repro1 — 초록 "We will publicly release our conversion pipeline and CORE-annotated dataset for dexterous hands and parallel grippers"

### (a) 관련 Pillar / 질문
[![P0](https://img.shields.io/badge/P0-fbd7d6.svg)](#ref-P0) / [![D2KT](https://img.shields.io/badge/D2KT-d97706.svg)](#ref-D2KT) [![D7HF](https://img.shields.io/badge/D7HF-d97706.svg)](#ref-D7HF)

### (b) 논문 요지

- 에고센트릭 영상을 접촉 중심 표현으로 로봇 데이터화
- **문제** — 로봇 상호작용 데이터 수집이 느리고 특정 하드웨어에 묶여, 에고센트릭 사람 영상을 로봇 관측과 동작으로 바꾸는 경로가 필요
  - 원격조작 시연은 수집 속도가 느리고 하드웨어에 종속
  - 단안 영상에서 접촉을 복원해 로봇이 실제로 실행할 수 있는 데이터로 옮기는 일에는 세 가지 어려움이 겹침
  - 손과 물체의 깊이·스케일 추정이 서로의 오차를 순환적으로 키움
  - 접촉은 가려진 표면에서 일어나며 시점, 표면 기하, 힘 분포를 영상이 직접 드러내지 않음
  - 복원한 접촉이 기구학과 접촉면이 다른 로봇을 구동하면서도, 영상에서 사람 팔을 지울 때 쥔 물체는 남아야 함
- **기존 한계** — 기존 영상-로봇 파이프라인이 옮기는 단위는 손 동작이며, 충실도를 주로 겉모습으로 판단
  - **Phantom** — 렌더링한 팔을 인페인팅한 손 위에 합성
  - **EgoMimic** — 사람과 로봇의 행동 공간을 정렬
  - **HuRo, Ego2Robot** — 복원한 3D 손 궤적을 역기구학으로 로봇 관절에 매핑
  - 단안 손 추정은 카메라 광선 방향으로 센티미터 단위로 어긋나는데 안정적 조작은 물체 표면에서 밀리미터 정밀도를 요구해, 손가락이 물체 옆에 뜨고 그리퍼가 빈 공간에서 닫힘
- **핵심 방법** — 접촉을 물체 좌표계 표현 CORE 하나로 기록하고 파이프라인 전 단계가 이를 공유
  - **CORE** — 접촉마다 표면 앵커, 바깥 법선, 미는 방향, 상대 힘, 파지 모드, 상호작용 상태를 기록하고, 촉각 타이밍과 카메라 광선-표면 교차에서 복원
  - **깊이 보정** — 물체 자세의 신뢰도를 진단해 깊이 추정을 분리하고, 손 스케일과 다시점 광선 삼각측량을 융합
  - **접촉 구동 역기구학** — URDF 컴파일러가 로봇 충돌 기하를 접촉 패드로 바꾸고, 다지 손은 패드를 CORE 앵커로 당기며 평행 그리퍼는 대척 파지를 합성
  - **제거·합성** — CORE 상태로 쥔 물체를 보존하며 팔을 지우고 로봇을 합성, 닫힌 루프 시뮬레이션 재생으로 과제 완료를 검증
- **차별점** — 손 동작 대신 물체 좌표계의 접촉을 옮기는 단위로 삼아 다지 손과 평행 그리퍼를 한 표현으로 다룸
- **핵심 기여** — 접촉 표현, 이를 쓰는 변환 파이프라인, 영상 기반 VLA 후학습
  - HOT3D에서 추적된 물체 자세 조건으로 접촉 중 손 광선 깊이 오차 33.7% 감소, 추정 자세 조건으로 단안 물체 위치 오차 30.4–47.3 mm 감소
  - EgoDex에서 다지 손 주석 접촉 실현율 62.9%, 공식 HuRo 파이프라인은 27.9%
  - EgoDex에서 평행 그리퍼 물리 접촉 적합 63.2%, Ego2Robot은 9.7%
  - RoboTwin 2.0 시뮬레이션 200개 짝지은 장면에서 X-VLA를 Ego2X 에피소드만으로 후학습해 성공률 제로샷 40.5%가 67.0%로 상승, 시뮬레이터 시연 없이 달성
  - 변환 파이프라인과 CORE 주석 데이터셋 공개 예정
- **가치** — 접촉 실현 여부로 변환 품질을 재는 기준과, 영상만으로 VLA를 후학습하는 경로 제시

### (c) 시사점

- 접촉 우선 맵을 영상 입력에서 접촉 실현율로 잰 근거
- **보존 대상** — 손끝 위치 대신 물체 표면 접촉을 지키는 리타게팅이 공식 HuRo 파이프라인보다 접촉 실현율 62.9% 대 27.9%로 높음
- **수율** — 변환한 데이터만으로 시뮬레이션 VLA 성공률 40.5%에서 67.0%, 변환 궤적이 학습에 쓸 만한지 보여주는 간접 지표
- **도입 비용** — 단안 영상 입력이라 수집 장비 부담이 낮으나 변환 파이프라인과 데이터셋은 공개 예정 단계

### (d) 먼저 확인할 점

- 실물 로봇 배치는 저자가 향후 과제로 밝혔고 정책 결과는 모두 RoboTwin 2.0 시뮬레이션
- 접촉 힘은 센서로 보정한 뉴턴 값이 아니라 시각-기구학 사전값
- 심한 가림에서는 물체 자세 추정 오차로 접촉 위치 복원이 제한됨
- 접촉 실현율은 주석된 접촉을 기준으로 한 지표라 정책 성공률로 이어지는 정도는 시뮬레이션 한 곳에서만 확인
- 코드와 데이터셋은 공개 약속만 있고 아직 없음

**CrowdMAPS: Crowdsourcing Multiple Actions per State for Real-World Imitation Learning**
[arXiv:2611.15078](https://arxiv.org/abs/2611.15078) · Yilong Song 외 3명 · CoRL 2026 · source: citation-graph

**점수 11/15** · R2 · N3 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문
[![P0](https://img.shields.io/badge/P0-fbd7d6.svg)](#ref-P0) / [![D8LC](https://img.shields.io/badge/D8LC-d97706.svg)](#ref-D8LC)

### (b) 논문 요지

- 방문한 상태마다 웹으로 대안 행동을 받아 데이터를 넓힘
- **문제** — 실물 로봇 데이터는 시연마다 물리 실행과 실시간 사람 조작이 필요해 비싸고, 한 상태에서 행동 라벨이 하나뿐
  - 로봇 한 대는 한 시점에 한 상태에서 행동 하나만 실행
- **기존 한계** — 웹 기반 크라우드소싱 원격조작은 기여마다 로봇 하드웨어가 필요한 동기식 구조
  - "한 사용자가 로봇 한 대를 조작" 모델이라 기여자가 로봇보다 많으면 대기하고, 처리량이 로봇 수와 궤적 실행 시간에 묶임
  - 잡음 섞인 시연은 전문가 데이터보다 표본 효율이 낮을 수 있음
- **핵심 방법** — 하드웨어가 필요한 상태 획득과 소프트웨어로 확장되는 행동 주석을 분리
  - **MAPS 수집** — 표준 수집 중이나 이후에 방문한 로봇 상태를 원격 주석자에게 배포하고, 웹 3D 인터페이스에서 대안 목표 자세 행동을 지정
  - **키프레임 목표 자세 주석** — 비전문가 주석자가 로봇 하드웨어 없이 참여
  - **학습** — 키포즈 정책과 궤적 정책 두 가지에 MAPS 데이터를 사용
- **차별점** — 군중을 궤적을 더 모으는 데 쓰지 않고, 이미 모은 궤적의 상태마다 유효한 행동 수를 늘리는 폭 방향 확장
- **핵심 기여** — 비동기 크라우드소싱 프레임워크, MAPS 데이터 구조, 실물 평가
  - 실물 탁상 조작 과제 5개에서 상태당 행동 수를 1개에서 10개로 늘리면 키포즈 정책 평균 성공률 35.6%p 상승, 로봇 시간 기준 표본 효율 향상
  - 궤적 정책은 폭 10 MAPS 데이터로 함께 학습하면 평균 성공률 33.0%p 상승
  - 같은 수이거나 더 많은 전문가 원격조작 궤적을 추가한 경우보다 일관되게 높음
  - 긴 과제와 다봉 분포 과제에서 이득이 더 큼
- **가치** — 하드웨어에 묶인 수집량을 늘리지 않고 소프트웨어 주석으로 실물 데이터의 지도 밀도를 올리는 경로 제시

### (c) 시사점

- 작업자 시간을 시연 대신 대안 행동 라벨에 쓰는 실물 근거
- **작업자 시간** — 로봇 없이 웹에서 하는 라벨링이 같은 수 이상의 원격조작 궤적 추가보다 효과적이라는 비교 기준점
- **시연과의 관계** — 기존 시연을 바탕으로 덧붙이는 방식이라 시연 수집을 대체하지 않고 보완
- **도입 비용** — 웹 3D 인터페이스와 과제별 CAD 모델이 필요하나 로봇 하드웨어 접근은 불필요

### (d) 먼저 확인할 점

- 행동 표현이 목표 자세라 밀집 원격조작보다 표현력이 낮고 모션 플래닝이 필요, 평가는 준정적 단일 팔 탁상 과제 중심
- 대안 행동은 실행되지 않아 후속 관측이 학습 데이터에 없고, 롤아웃에서 MAPS 이동이 생길 수 있음
- 연구자가 과제 관련성과 물리적 실현 가능성을 직접 검증해 주석자 전략이 연구자 선택으로 제한됨
- 가중치 방식과 궤적 정책의 목표 자세 보간 휴리스틱은 절제하지 않았다고 저자가 밝힘
- 초록과 도입부에 교정이나 자율 롤아웃 라벨링과의 직접 비교 언급 없음
- 코드 저장소나 공개 약속 없음

**NI-ACT: A Neural Intent Interface for Brain-Embodied Manipulation**
[arXiv:2611.19332](https://arxiv.org/abs/2611.19332) · Yinghao Li 외 6명 · adjacent field: 보철·신경과학 신경 신호 인터페이스 (Slot D)

### (b) 논문 요지

- 운동피질 신호를 한 번 읽어 정책의 의도 조건으로 사용
- **문제** — 피질내 뇌-컴퓨터 인터페이스는 사용자를 빠른 감각운동 루프 안에 묶어, 접근과 교정과 파지를 모두 신경 신호로 지정해야 함
  - 과제 수준 의도가 매 제어 단계마다 움직임 수준 명령으로 다시 표현되어 디코딩 잡음이 궤적에 그대로 쌓임
  - 신경 집단 활동이 상징적 명령 없이 학습된 정책의 과제 조건이 될 수 있는지는 미검증
- **기존 한계** — 기존 BCI 로봇 팔 제어는 디코더가 신경 활동을 끝점 속도 같은 연속 운동학으로 매 제어 단계 변환
  - 학습된 시각운동 정책은 언어 지시, 목표 이미지, 원핫 물체 라벨 같은 상징적 조건에 의존
- **핵심 방법** — 짧은 운동피질 신호를 한 번 읽어 지속 의도로 만들고 시각운동 정책이 루프를 닫는 계층 구조
  - **신경 인코더** — 시간 합성곱 인코더가 짧은 운동피질 활동 창을 지속 의도로 변환
  - **정책** — 의도로 조건화한 액션 청킹 정책이 시각과 고유수용감각만으로 파지를 실행
  - **반사실 과제** — 레이아웃마다 각 물체를 목표로 한 시연을 하나씩 두어 장면만으로는 목표를 우연 수준으로만 예측, 신경 활동을 다른 목표의 기록으로 바꿔 인과를 검증
- **차별점** — 신경 신호를 연속 속도 명령이 아니라 과제 수준 조건으로 정책에 한 번만 건넴
  - 원핫 방향 대신 집단 잠재 전체를 전용 의도 토큰으로 전달
- **핵심 기여** — 구조 제안과 신경 표현의 어디를 어떻게 읽는지에 대한 결과
  - 신경 의도만으로 로봇이 잡는 물체가 결정되고, 의도를 바꾸면 행동이 따라 바뀜
  - 보류 장면 132개에서 집단 잠재 전체를 의도 토큰으로 넘기면 파지 완료율 69%에서 81%로 상승, 연속 방향만 넘기면 원핫 라벨 대비 개선 없음
  - 이중 배열 한 세션에서 판독 창을 맞춘 조건으로 PMd 의도가 53%인 M1 의도보다 높은 77%의 파지를 완료
  - 센터아웃 과제에서 움직임 시작 전 PMd 활동만 읽은 의도로도 완전한 파지를 수행
- **가치** — 신경 신호의 표현 방식과 판독 위치·시점이 목표 전달 효과를 함께 좌우한다는 근거 제시

### (c) 시사점

- 사람 명령을 실행 중인 정책에 한 번 건네는 방식의 사례
- **합류 방식** — 사람 입력을 연속 명령으로 이어 붙이지 않고 지속 의도 토큰으로 주고 정책이 루프를 닫는 구조
- **작업자 입력** — 사람 쪽 입력이 목표 방향 하나뿐인 최소 구성이라 작업자 부담을 줄이는 방향의 참고점
- **도입 비용** — 피질내 신경 기록이 전제라 원격조작 현장에 직접 이식하기는 어려움

### (d) 먼저 확인할 점

- 신경 기록과 로봇 시연이 서로 다른 개체에서 와서 목표 방향으로만 정렬되며, 사용자가 루프에 들어간 평가가 아니고 신경 채널은 로봇 상태 피드백을 받지 않음
- 실물 로봇 결과 없음, 과제는 큐브 3개와 방향 7가지, 팔 한 대, 고정 시작 자세, 가림 없음
- 연속 디코더 기준선을 돌리지 않아 목표 수준 제어가 연속 디코딩보다 낫다는 주장은 성립하지 않음
- PMd 대 M1 비교는 한 동물의 한 세션에 기댄 가장 약한 근거
- 각 닫힌 루프 정책은 한 번만 학습, 날이 바뀌면 디코더 정확도가 떨어져 매일 보정 필요
- 코드 저장소나 공개 약속 없음
