## 🥈 논문 1 — 우선순위 ★★

**Reflex: Enabling Fast and Predictive Vision-Language-Action Models for Reaction-Critical Manipulation**
[arXiv:2608.14379](https://arxiv.org/abs/2608.14379) · Yuxuan Chen, Wanruo Zhang, Xiao Li · arXiv preprint · source: citation-graph · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 기존 VLA 조작 벤치마크가 정적 태스크 일반화 평가에 집중, 동적 상호작용 시나리오는 대부분 소외된다는 공백 지적
- 반응-critical 조작 평가를 위한 벤치마크 ReflexBench 신규 제시 — 6개 동적 태스크로 구성
- 시뮬레이터 스텝핑과 로봇 제어를 분리, 동기·비동기 추론 하에서 설정 가능한 지연시간을 지원하는 평가 프레임워크 동반
- 대규모 로봇 데이터 사전학습 없이 반응-critical 조작에 특화된 효율적 VLA 모델 ReflexVLA 함께 제시 — 잠재 미래 예측·비전 백본 내 다중 프레임 시간 융합으로 시간 추론 강화, 배치 비전 인코딩·CUDA Graph 재생으로 배포 지연시간 단축
- 동적 조작 성능 향상과 표준 정적 벤치마크에서의 경쟁력 있는 정확도를 동시 확인, 실환경 실험으로 실배포 조건 하 효과성 추가 검증

### (c) 시사점
- 벤치마크/이밸 하니스 축에 정적 태스크 중심 평가의 사각지대(동적 상호작용)를 겨냥한 진단 벤치마크 추가 — 반응 속도가 중요한 태스크의 정책 평가에 즉시 활용 가능
- 시뮬레이터 스텝핑-로봇 제어 분리 설계는 지연시간 민감 평가 인프라 구축 시 참조 가능한 아키텍처 패턴
- 실환경 배포 검증까지 포함돼 있어 도입 시 벤치마킹 비용이 낮음

### (d) 먼저 확인할 점
- 공개 저장소 링크 없이 프로젝트 웹사이트만 안내됨 — 실제 벤치마크 코드·태스크 자산 다운로드 경로 별도 확인 필요
- 6개 동적 태스크의 임베디먼트·다지 손 조작 포함 여부가 초록상 불명확
- 3인 소규모 팀 산출물로 벤치마크의 장기 유지보수·확장 가능성 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Monkey See, Can Monkey Do? A Benchmark for Evaluating Robot Skill Learning by Observation**
[arXiv:2609.08209](https://arxiv.org/abs/2609.08209) · Weiwei Gu, Anmol Gupta, Anant Sah 외 5인 · CoRL 2026 · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- Learning from Observation(LfO, 관찰 기반 학습) 방법론들이 가정·하드웨어·환경 설정이 제각각이라 성능 비교와 발전 추이 파악이 어렵다는 공백 지적
- 인간 시연 비디오로부터 조작 정책을 학습하는 모델을 통합 평가하는 벤치마크 RoboReel 신규 제시 — 실환경 인간 시연 비디오·시뮬레이션 로봇 궤적·평가 환경을 10개 조작 태스크에 걸쳐 결합 구성
- 시각적 방해물 강건성·장기 호라이즌 태스크 수행력 등 다축 평가를 위한 4개 테스트 스위트 구성
- 자체 VLA 기반 변형 포함 7종 이상 최신 LfO 알고리즘과 다양한 표현 선택의 효과를 벤치마크 내에서 비교
- 장기 호라이즌 태스크·낮은 허용오차 태스크가 현재 모델 전반에 여전히 도전적임을 정량 분석으로 규명

### (c) 시사점
- 에고센트릭/실환경 인간 시연에서 로봇 정책으로의 전이 방법론 평가를 표준화하는 벤치마크 확보 — 인간 시연 우선순위 축의 다운스트림 평가 인프라로 즉시 참조 가능
- CoRL 2026 게재 확정으로 커뮤니티 표준으로 자리잡을 가능성 높음 — 조기 채택 시 비교 우위 확보
- 7종 이상 알고리즘·다중 표현 비교 결과가 이미 확보돼 있어 자체 LfO 파이프라인 설계 시 벤치마킹 비용 낮음

### (d) 먼저 확인할 점
- 로봇 궤적·평가 환경이 시뮬레이션 기반으로 구성돼 실로봇 정책 실행 검증은 포함되지 않음 — 실배포 전이 성능은 별도 확인 필요
- 공개 저장소 링크 없이 프로젝트 웹페이지만 안내됨 — 실제 코드·데이터 다운로드 경로 별도 확인 필요
- 10개 조작 태스크의 다지 손(multi-finger) 조작 비중이 초록상 불명확

## 🥈 논문 3 — 우선순위 ★★

**CosmoH2G: A Hand-to-Gripper Transfer Dataset and Baseline Method for Object Manipulation with Complex Spatial Movements**
[arXiv:2609.07498](https://arxiv.org/abs/2609.07498) · Hongxiang Zhao, Mutian Xu, Zeyu Jin 외 3인 · SIGGRAPH Asia 2026 · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 인간 손 시연을 로봇 그리퍼로 전이하는 기존 기법이 단순 평면 태스크에 국한, 회전·뒤집기 등 복잡한 공간 궤적을 다루지 못한다는 공백 지적
- 손-그리퍼 페어 시연을 대규모로 수집하는 확장 가능 획득 파이프라인 신규 구축 — 핸드헬드 그리퍼로 동작을 그대로 모사하는 엄격한 프로토콜 적용
- 1,254개 고유 객체·6,189개 에피소드로 구성된 대규모 페어 데이터셋 신규 공개 — 기존 벤치마크 대비 현저히 높은 공간 복잡도
- 희소 그리퍼 키프레임 예측(1단계) 후 연속 동작 시퀀스 생성(2단계)으로 나누는 2단계 프레임워크, 그리퍼 방향은 학습하고 이동은 파지 휴리스틱·기구학적 일관성 기반 후처리로 누적 드리프트 완화
- 시뮬레이션과 실로봇 실험 양쪽에서 복잡한 공간 조작의 안정적·정밀한 전이를 확인, 기존 베이스라인 대비 우수한 성능 실증

### (c) 시사점
- 로봇-액션 보완 축에 회전·뒤집기 등 복잡 궤적을 다루는 손-그리퍼 페어 코퍼스 신규 추가 — 기존 평면 중심 리타겟팅 자원의 사각지대 보완
- 시뮬레이션+실로봇 병행 검증이 이미 확보돼 도입 시 벤치마킹 비용 낮음
- 희소 키프레임 우선 예측 후 연속 동작 생성이라는 2단계 설계는 복잡 궤적 리타겟팅 파이프라인 설계에 참조 가능

### (d) 먼저 확인할 점
- 공개 저장소 링크 없이 프로젝트 페이지만 안내됨 — 실제 데이터·코드 다운로드 경로 별도 확인 필요
- 픽업-이동형 조작 중심 검증으로 다지 손(multi-finger) 임베디먼트 적용성은 초록상 불명확
- 6인 소규모 팀 산출물로 1,254개 객체·6,189 에피소드 데이터셋의 장기 유지보수 확인 필요
