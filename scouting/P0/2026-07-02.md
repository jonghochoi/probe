## 🥇 논문 1 — 우선순위 ★★★

**RCT: A Robot-Collected Touch-Vision-Language Dataset for Tactile Generalization**
[arXiv:2606.31694](https://arxiv.org/abs/2606.31694) · Jingbo He, Michael Farber, Roberto Calandra · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여
- **로봇 수집 촉각 데이터셋** — DIGIT 센서 3개로 122종 산업 소재(7개 카테고리) 대상 29,279개 촉각 프레임 수집, 접촉 시퀀스 단위로 원본 보존
- **평가 누출(leakage) 문제 정량 실증** — 기존 촉각-언어 벤치마크(TVL/HCT)의 프레임-랜덤 split이 동일 접촉의 near-duplicate 관측을 학습·테스트에 동시 배치함을 발견, raw-pixel 최근접 이웃이 98.3% 확률로 정답 시퀀스를 복원
- **접촉 시퀀스 인식 평가 프로토콜 제안** — 소재·카테고리·센서·접촉 위치·접촉 시퀀스 축으로 held-out 평가 지원, 시퀀스 중복 제거만으로 Recall@1 17.7%p 하락 확인
- **미지 소재 일반화의 난이도 노출** — 학습 시점에 소재 자체를 배제하면 held-out-material Recall@1 25.1±6.1%로 급락

### (c) 시사점
- **촉각 벤치마크 신뢰성 재검토 필요** — 공개 촉각-언어 벤치마크의 기존 성능 수치가 데이터 누출로 부풀려졌을 가능성, 자체 촉각 평가 파이프라인 설계 시 접촉 시퀀스 분리 원칙 반영 필요
- **공개 데이터셋 즉시 활용 가능** — 데이터 공개 완료, 소재 일반화 사전학습·평가 소스로 바로 검토 가능
- **평가 방법론 자체가 산출물** — 데이터셋 규모보다 평가 설계의 엄밀성이 두드러지는 사례, 향후 벤치마크 심사 기준에 참고할 만함

### (d) 먼저 확인할 점
- **소재 범위가 산업용 참조물에 한정** — 실제 조작 대상(가정용 물체·유기물 등)으로의 전이 여부 미검증
- **DIGIT 센서 3개 특정 하드웨어 종속** — 타 촉각 센서(GelSight 등) 재현성 별도 확인 필요
- **정적 프레스 데이터 중심** — 슬라이딩·회전 등 동적 접촉 시퀀스 커버 여부 확인 필요

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

- **계층적 모방학습 구조** — 상위 손 서브골 예측 + 하위 목표조건 컨트롤러 결합, 그래스프 데이터로 하위 컨트롤러 사전학습 후 다운스트림 파인튜닝

- **도구 사용 평가축 확보** — DexCraft가 관절형 도구 조작 난이도를 표준화된 시뮬레이션 태스크로 제공
- **계층적 사전학습 레시피가 이식 가능한 패턴** — 상위/하위 분리 구조 자체가 다른 다지 파이프라인에도 적용 검토 가능

### (d) 먼저 확인할 점
- **코드·벤치마크 공개 여부가 abstract 상 불명** — 프로젝트 페이지(영상)만 확인, 실제 다운로드 가능한 데이터·벤치마크 아티팩트 존재 여부 별도 확인 필요

- **160만 프레임급 페어 데이터가 촉각 희소성 갭에 기여** — F/T 데이터 외에 별도 축의 대규모 촉각 코퍼스 후보
- **공개 예정** — 데이터셋·코드·체크포인트 모두 출판 시점 공개 예고, 확보 시 즉시 활용 검토 가능

### (d) 먼저 확인할 점
- **아직 미공개** — 프로젝트 페이지는 존재하나 현재는 공개 예고 상태, 실제 배포 여부 확인 필요
- **4종 센서 구성과 보유 하드웨어 정합성 확인 필요** — 이종 센서 조합 특성상 우리 촉각 하드웨어 스택과의 매칭 여부 사전 점검 필요
- **실세계 조작 태스크 평가 규모·난이도가 abstract 상 불명확** — 정량 성능 수치 미제시, 원문 확인 후 재평가 필요

## 💡 컨텍스트 제안

### Tracked literature
- **대상** — RH20T (arXiv:2307.00595, D25 핀 논문)
- **제안** — RH20T는 2023년 6축 F/T 촉각 코퍼스로 3년째 유일한 D25 핀 논문. 이번 주기에만 촉각-다지-인간형(RoboTacDex), 촉각 벤치마크 누출 실증(RCT), 이종 센서 공유 표현(HTT) 3편이 동시 등장 — D25 축 자체가 성숙 단계 진입. 다음 분기 리밸런싱 시 RH20T 유지 여부와 신규 촉각 코퍼스(공개 확정본) 교체 후보로 [arXiv:2606.31694](https://arxiv.org/abs/2606.31694) 검토 제안
- **근거** — RH20T 대비 RCT는 이미 공개 완료 + 접촉 시퀀스 평가 프로토콜까지 제공, RoboTacDex는 공개 시 다지+인간형 조합에서 RH20T보다 최신 축 대표 가능

### Decision Log
- **트리거** — D25 "Flag any new contact-modality release with high priority" — 본 리포트가 한 주기에 촉각 관련 데이터셋·프레임워크 3편(RCT, RoboTacDex, HTT)을 동시 표면화, 촉각 축 스카우팅 밀도가 최근 4개 리포트 대비 뚜렷이 상승
