## 🥇 논문 1 — 우선순위 ★★★

**RoboVAD: A Large Cross-Domain Evaluation Benchmark for Anomaly Detection in Robotic Arm Manipulation Videos**
[arXiv:2609.17843](https://arxiv.org/abs/2609.17843) · Alexandru-Bogdan Dura, Sebastian Balmus, Radu Tudor Ionescu · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 로봇팔 조작 비디오의 이상탐지(VAD)가 기존 연구자원 부족으로 제한적이었다는 공백 지적, 프레임 단위 주석과 크로스 도메인 평가 부재를 핵심 문제로 규정
- SO-ARM101 로봇 + LeRobot 프레임워크 기반 리더-팔로워 텔레옵으로 수집한 실환경 조작 에피소드 1,078건으로 구성된 벤치마크 RoboVAD 신규 공개 — 기존 데이터셋 대비 이상 인스턴스 3배 규모
- 태스크·이상 유형이 훈련 중 미노출인 크로스 도메인 평가 프로토콜(cross-task, cross-anomaly, cross-task+anomaly) 정식화, 프레임 단위 이상 구간 주석 동반
- 최신 VAD 기법 다수 + 로봇팔 조작 특화 신규 기법을 벤치마킹, 가장 어려운 설정에서 전 기법 프레임 단위 AUC 70% 미만에 그침을 정량 확인
- 데이터셋 + 코드를 Zenodo에 공개, 재현 가능한 벤치마킹 인프라 제공

### (c) 시사점
- 벤치마크/이밸 하니스 축에 실패·이상 탐지라는 신규 진단 벤치마크 추가 — FailBench(VLM 판정자 신뢰도)와 상호보완적인 프레임 단위 이상탐지 평가 인프라로 활용 가능
- 크로스 도메인(미확인 태스크·이상 유형) 평가 프로토콜은 자체 이상탐지·복구 트리거 시스템 설계에 참조 가능한 프레임워크
- 공개 데이터셋 + 코드가 즉시 재현 가능해 도입 장벽 낮음

### (d) 먼저 확인할 점
- 실환경 SO-ARM101 단일 로봇 플랫폼 기반 수집으로 다지 손(multi-finger) 조작·타 임베디먼트로의 일반화는 별도 확인 필요
- 3인 소규모 팀 산출물로 1,078건 규모의 장기 유지보수·확장 가능성 확인 필요
- 이상 유형이 텔레옵 오류 + 의도적 유발 이벤트 혼합 구성으로 실제 자율 조작 중 발생하는 자연 이상 유형과의 분포 차이 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**FolDeX: A Physical-World Benchmark for Long-Horizon Robotic Manipulation of Deformable Objects**
[arXiv:2609.10243](https://arxiv.org/abs/2609.10243) · Chenhuan Liu, Yi Xu, Feng Wu 외 7인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 시뮬레이션에서 우수한 방법이 실로봇 특히 장기수평 변형체(deformable-object) 조작에서 성능이 크게 저하된다는 공백 지적, 기존 실로봇 벤치마크가 단기·강체 태스크에 편중됐다는 문제의식
- 전량 실로봇 데이터로 구성된 물리 세계 벤치마크 FolDeX 신규 공개 — 의류 접기(garment folding)를 주요 태스크로 2,000시간 이상, 20개 이상 태스크, 10개 이상 임베디먼트 커버
- 이질적 실물리 경험의 효율적 재사용을 네 축(배포 중 수집된 인간 개입·복구 데이터, 태스크 간 전이, 장면 간 전이, 임베디먼트 간 전이)으로 구조화
- 외부 제출 정책을 표준화 태스크·홀드아웃 물체·통제된 초기화·통일 실행 프로토콜로 공정 평가하는 실로봇 평가 플랫폼 별도 제공

### (c) 시사점
- 벤치마크/이밸 하니스 축에 장기수평 변형체 조작이라는 사각지대를 겨냥한 실물리 벤치마크 추가 — 기존 단기·강체 편중 벤치마크를 보완
- 이질적 데이터 재사용 네 축(개입 데이터·태스크 전이·장면 전이·임베디먼트 전이) 프레임워크는 자체 실로봇 데이터 수집 전략 설계에 직접 참조 가능
- 외부 정책 제출·공정 평가 플랫폼이 이미 공개돼 자체 정책의 표준 벤치마킹 비용 낮음

### (d) 먼저 확인할 점
- 평가 플랫폼 URL은 공개되나 소스 코드 저장소·데이터 다운로드 경로는 초록 수준에서 명시되지 않음 — 공개 범위·라이선스 별도 확인 필요
- 의류 접기가 주요 태스크로 명시돼 있어 다지 손(multi-finger) 조작 비중이 초록상 불명확
- 10인 규모 협업 산출물로 2,000시간 이상 데이터·10개 이상 임베디먼트 구성의 장기 유지보수 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**FoldNet++: a Large-Scale Synthetic Dataset for Robotic T-Shirt Folding and Unfolding**
[arXiv:2609.12433](https://arxiv.org/abs/2609.12433) · Yuxing Chen, Zhiyuan Wei, Bowen Xiao 외 2인 · CoRL 2026 · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 의류의 높은 변형 자유도로 인해 T셔츠 접기·펼치기에 일반화 가능한 정책 학습이 어렵다는 공백 지적
- 6개 로봇 임베디먼트·T셔츠 1,000벌·환경 자산 1,000종·12만 건 에피소드로 구성된 대규모 합성 데이터셋 FoldNet++ 신규 공개
- 물리 시뮬레이션 가능한 T셔츠에 시맨틱 키포인트를 주석하는 FoldNet 파이프라인을 확장, 키포인트 기반 통합 규칙 프레임워크로 여러 임베디먼트의 조작 시연 자동 생성
- 합성 데이터만으로 학습한 비주오모터 정책이 미확인 실환경·미확인 T셔츠·임의 초기 배치에서 90% 이상 종단 간 태스크 성공률을 직접 실증

### (c) 시사점
- 로봇-액션 데이터 축(합성 증강)에 변형체(의류) 조작이라는 신규 하위 도메인 + 멀티임베디먼트 규칙 기반 시연 자동 생성 프레임워크 추가
- 합성 데이터 단독 학습으로 실환경 90% 이상 성공률을 달성한 sim-to-real 전이 실증은 자체 합성 데이터 파이프라인의 실전 활용 가능성 판단 근거로 활용 가능
- 시맨틱 키포인트 기반 규칙 프레임워크는 신규 임베디먼트·객체로의 시연 자동 생성 확장 설계에 참조 가능

### (d) 먼저 확인할 점
- 데이터셋 자체가 전량 합성으로 실물 변형체(원단) 물성과의 시뮬레이션 갭은 별도 검증 필요
- T셔츠 접기·펼치기라는 단일 카테고리 태스크로 니치 특화, 일반 조작 사전학습 자원으로서의 확장성은 제한적
- 프로젝트 페이지만 공개되고 코드·데이터 저장소 URL은 초록 수준에서 명시되지 않음 — 실제 다운로드 경로 별도 확인 필요
