## 🥇 논문 1 — 우선순위 ★★★

**Do as I Do: Dexterous Manipulation Data from Everyday Human Videos**
[arXiv:2606.19333](https://arxiv.org/abs/2606.19333) · Paliwal, Etukuru, Liang, Abbeel, Shafiullah, Malik (UC Berkeley) · source: keyword sweep (cs.RO, dexterous dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **단안 RGB 비디오 → 다지 로봇 손 실행 가능 액션 알고리즘 최초 제시**: 에고센트릭·엑소센트릭 인-더-와일드(in-the-wild) 영상 모두에서 손-물체 상호작용 재구성 후 다지 손(multi-fingered dexterous hand) 관절 명령으로 직접 리타겟
- **두 단계 갭 동시 해소**: (i) 손-물체 상호작용 추정 정확도 이전 SOTA 상회, (ii) 추정치를 실세계 실행 가능한 다지 조작 트래젝토리로 리타겟 — 기존 연구가 이 두 단계를 분리 취급하던 병목 통합 해결
- **실용 가이드 포함**: 온라인 클립에서 수집한 인간 비디오 데이터셋을 직접 실험 → 실무 데이터 수집 playbook 제안

### (c) 시사점

- **인터넷 규모 인간 비디오 → 다지 손 학습 데이터 실용화 경로**: 고비용 다지 텔레오퍼레이션 없이 기존 에고센트릭 코퍼스(EgoDex 829h, Ego4D 3,670h 등)를 다지 손 훈련 데이터로 직접 변환 가능
- **EgoEngine 대비 보완 위치**: EgoEngine(2606.12604, 이전 리포트 커버)이 에고센트릭 → 일반 로봇 데모 변환을 다루는 반면, Do as I Do는 **다지 손** 관절 수준 리타겟에 특화 — 두 파이프라인 병용으로 다지 조작 데이터 수집 전략 구체화
- **D24 실행 경로 추가 구체화**: 에고 우선 데이터 축의 "실제 수집 비용 없는 다지 데이터 확보" 경로를 Pieter Abbeel 그룹이 증명

### (d) 먼저 확인할 점

- **코드·데이터 공개 여부**: "experiments on datasets with ground truths and on a dataset of video clips collected online" — 수집 데이터셋·변환 결과 공개 여부 초록에서 미확인, 프로젝트 페이지 확인 필요
- **단안 RGB 추정 한계**: 손 폐색(occlusion)·물체 투명도 상황에서 3D 재구성 오류 누적 가능성 — 다지 조작 특성상 손가락 겹침 빈번, 실제 적용 시 오류율 확인 필요
- **가장 저렴한 확인**: arXiv 전문 + 프로젝트 페이지 → 다지 손 종류(LEAP, Shadow 등)별 리타겟 결과·라이선스·데이터 공개 URL 확인 → EgoDex에 적용한 샘플 출력 비교

## 🥇 논문 2 — 우선순위 ★★★

**EgoInfinity: A Web-Scale 4D Hand-Object Interaction Data Engine for Any-View Robot Retargeting and Learning**
[arXiv:2606.17385](https://arxiv.org/abs/2606.17385) · Wang, Ren, Morgan, Chen, Qian, Chanrungmaneekul et al. · source: keyword sweep (cs.RO, dexterous dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **정적 데이터셋 대신 범용 4D 데이터 엔진 제시**: 인터넷 임의 RGB 영상 → 에이전트-불가지론 4D 손-물체 표현(손 트래젝토리, 6-DoF 물체 자세, 접촉 상태) 자동 변환 파이프라인 — 정적 수집 대신 "엔진" 접근으로 커버 범위와 다양성의 스케일 제한 구조적 해소
- **임의 시점·임의 화각 지원**: 인간 신체가 부분만 보이는 영상(엑소 시점, 클로즈업 등)에서도 공간적으로 메트릭-일관된 3D 재구성 — 기존 에고센트릭 전용 파이프라인보다 소스 다양성 크게 확장
- **모듈식 설계 + 교차-모듈 메트릭 보정**: 인식·분할·재구성·상호작용 인식 정제·리타겟 각 모듈이 독립 개선 가능; 드리프트·접촉 비일관성 억제를 위한 메트릭 보정 내장
- **실제 로봇 검증**: 그래스핑, 자르기(cutting), 닦기(wiping), 붓기(pouring) 태스크에서 실제 로봇 실행 성공 확인

### (c) 시사점

- **인터넷 규모 다양성 확보 경로**: 실험실 수집·팩토리 수집의 스케일·다양성 한계를 우회 — EgoDex 829h와 달리 유튜브 영상 등 임의 RGB 소스를 직접 투입 가능
- **다중 로봇 형태(morphology) 리타겟 지원**: 동일 원본 영상에서 다양한 로봇 관절 트래젝토리 자동 생성 → 멀티-embodiment 사전학습 코퍼스(OXE급) 보완 데이터 파이프라인
- **D24 데이터 엔진 패러다임 선례**: Do as I Do(2606.19333)와 함께 "수집→변환" 경로의 구체적 인프라 두 편이 같은 주에 동시 등장 — D24 v1 "에고 우선 데이터 축" 실행 전략이 인프라 성숙기 진입 신호

### (d) 먼저 확인할 점

- **엔진 코드·실행 환경 공개 여부**: 모듈식 파이프라인 공개 일정 미확인 — 독립 재현 가능성 확인 필요 (D27 라이선스 바 적용)
- **접촉 집약 다지 태스크 한계**: 자르기·닦기·붓기는 검증됐으나 인핸드 회전·정밀 조립 등 고자유도 다지 태스크에서의 접촉 일관성 별도 확인 필요
- **가장 저렴한 확인**: 프로젝트 페이지 → 엔진 코드 공개 URL + 멀티-embodiment 리타겟 결과 샘플 확인 → EgoDex 829h에 적용 가능성 타진

## 🥈 논문 3 — 우선순위 ★★

**HT-Bench: Benchmarking and Learning Dexterous Full-Hand Tactile Representations with Egocentric Vision**
[arXiv:2606.19161](https://arxiv.org/abs/2606.19161) · Huang, Wu, Jiang, Lin, Aierken, Wang et al. · source: keyword sweep (cs.RO, benchmark dexterous tactile)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여

- **대규모 전체 손 촉각 벤치마크 최초**: 10M RGB 프레임 + 7.8M 촉각 프레임, 226개 태스크 — 기존 촉각 데이터셋이 손목 F/T 또는 단일 손가락 끝 중심인 것과 달리 전체 손(full-hand) 촉각 커버리지
- **에고센트릭 비전 + 전체 손 촉각 페어링**: 에고센트릭 RGB와 전체 손 촉각 데이터를 대규모로 짝지은 최초 벤치마크 — 비전-촉각 연계 학습의 스케일 기반 마련
- **4개 평가 태스크**: 미세 촉각 유사도 검색, 마스크된 촉각 인페인팅, 비전→촉각 합성, 멀티모달 촉각 프레임 예측 — 표현 학습의 다차원 평가
- **HandTouch 인코더 제안**: 벡터 양자화(vector-quantized) 비전-촉각 인코더로 4개 태스크 전반 베이스라인 상회 (유사도 검색 Recall@5: 74.65% → 85.23%)

### (c) 시사점

- **D25 "이기종 센서 통합" 방향 스케일 기반 확보**: FTP-1(2606.13102, 이전 리포트 커버)이 이기종 센서 간 통합 정책을 제시했다면, HT-Bench는 그 평가 기반(전체 손 촉각 대규모 벤치마크)을 제공 — D25 스카우팅의 "측정 가능한 갭" 도구
- **에고 비전 + 촉각 페어링의 scalable 방향**: 에고센트릭 시각만으로 촉각 추정하는 TouchAnything(2605.13083) 대신, 실제 전체 손 촉각 센서 데이터를 대규모로 수집·평가하는 보완 경로
- **`catalogs/datasets.md` + `benchmarks.md` 동시 추가 후보**: 데이터셋(10M+7.8M 프레임, 226 태스크) + 벤치마크(4개 평가 태스크) 두 역할 동시 수행 — D26 관점에서 다지 촉각 평가 표준화 선례

### (d) 먼저 확인할 점

- **전체 손 촉각 센서 종류 및 접근성**: 어떤 촉각 글러브/어레이를 사용했는지 초록에서 미확인 — 센서 가용성·비용이 D25 재현 경로의 핵심 제약
- **다운스트림 로봇 조작 검증 미포함**: 벤치마크 자체는 표현 학습 평가에 집중 — 실제 다지 로봇 정책 학습에 직접 기여하는지 별도 확인 필요
- **가장 저렴한 확인**: 데이터셋·벤치마크 공개 URL 확인 → 촉각 센서 종류·라이선스(D27 기준) 파악 → HT-Bench 4개 평가 태스크로 기존 촉각 인코더 비교 재현 가능성 검토

## 🥉 논문 4 — 우선순위 ★

**ContactWorld: What Matters in Vision-Tactile World Models for Contact-Rich Manipulation**
[arXiv:2606.13877](https://arxiv.org/abs/2606.13877) · Zhang, Zhou, Zhang, Desai, Amosa, Soleymanzadeh et al. · source: keyword sweep (cs.RO, tactile benchmark)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여

- **12개 접촉 집약 태스크 대상 비전-촉각 세계 모델 벤치마크**: 삽입(insertion)·분해(disassembly)·나사 조임(screwing)·탐색적 상호작용 등 고난도 다지 접촉 태스크 체계적 포괄
- **핵심 발견 1 — 표현 구조**: 포인트 클라우드 관측이 손목 뷰(20.7%), 정면 뷰(22.0%) 대비 계획 성공률 32.1%로 유의한 향상 → 공간 구조화 표현의 우위 정량 증명
- **핵심 발견 2 — 촉각 추가 조건**: 촉각 력장(tactile force-field) 표현과 포인트 클라우드 결합 시 36.1%로 최고 성능 — 단순 모달리티 추가보다 크로스-모달 표현 호환성이 선결 조건
- **장기 계획에서 촉각 기여 증가**: 오차 누적이 긴 계획 구간에서 촉각 정보의 상대적 기여가 커짐 — 다지 조작의 장기 계획 시 촉각 필수성 정량 근거

### (c) 시사점

- **D25 "촉각 데이터 어떻게 써야 하나" 물음에 처음으로 체계적 답변**: 어떤 촉각 포맷(합력 vs 력장 vs 어레이)이 계획에 실제로 도움이 되는지 — 촉각 코퍼스 수집 설계 시 "촉각 력장 표현 우선" 근거로 활용 가능
- **포인트 클라우드 + 촉각 력장 조합의 우선 탐색 방향**: RH20T(손목 F/T)를 촉각 데이터로 활용 시 공간 력장 변환 중간 표현이 장기 계획 효과를 높일 수 있음
- **D26 벤치마크 갭 일부 해소**: 접촉 집약 조작 특화 세계 모델 평가 벤치마크가 부재했던 공백 — 12개 태스크 설계 원칙을 다지 손 특화 확장 시 참조 가능

### (d) 먼저 확인할 점

- **시뮬레이션 전용 벤치마크 여부**: 발견 결과가 시뮬레이션 기반인지 실제 로봇 기반인지 초록에서 미확인 — Sim2Real 이전 성립 여부 핵심 확인 필요
- **태스크 범위**: 삽입·나사 조임이 포함됐으나 인핸드 회전·도구 사용 등 P0 핵심 다지 태스크 커버 여부 전문에서 확인 필요
- **가장 저렴한 확인**: 프로젝트 페이지 + 전문 확인 → 시뮬레이션/실제 환경 구분 + 벤치마크 코드 공개 여부 확인 → D26 다지 조작 특화 벤치마크 목록 추가 가능성 판단

- Relevance 3 — D25 직격(전체 손 촉각 대규모 벤치마크) + D26(촉각 표현 표준 평가 프레임)
