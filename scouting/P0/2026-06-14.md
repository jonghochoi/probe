## 🥇 논문 1 — 우선순위 ★★★

**EgoEngine: From Egocentric Human Videos to High-Fidelity Dexterous Robot Demonstrations**
[arXiv:2606.12604](https://arxiv.org/abs/2606.12604) · Liu, Cheng, Yin, Shin et al. · source: citation-graph (EgoDex)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **에고센트릭 비디오 → 고품질 다지 로봇 데모 자동 생성 프레임워크**: 에고센트릭 RGB 영상을 입력으로 받아 (i) 로봇 관찰 비디오, (ii) 로봇 실행 가능 액션 시퀀스를 동시 출력
- **두 가지 핵심 갭 동시 해소**:
  - 시각 갭(visual gap) — 인간 에고센트릭 카메라 시점·embodiment 외관 차이를 로봇 관찰로 변환
  - 액션 갭(action gap) — 인간 손 모션을 로봇 관절 명령으로 변환
- **확장 가능 설계**: EgoDex(829h) 등 기존 대규모 에고센트릭 코퍼스에 직접 적용 가능 — 고비용 텔레오퍼레이션 없이 다지 로봇 훈련 데이터 획득 경로

### (c) 시사점

- **D24 우선 데이터 축 실용화**: 에고센트릭 인간 비디오 → 로봇 데이터 직접 변환 파이프라인 실증 — 고비용 수집 없이 인터넷 규모 에고 비디오 활용 경로 개척
- **기존 코퍼스 재활용 승수**: EgoDex 829h 또는 Ego4D 3,670h에 파이프라인 적용 시 즉시 대규모 다지 로봇 데이터 확보 가능
- **What Matters Cotraining 결과와 상호 보강**: 지난 주 리포트가 에고 비디오 cotraining의 효과(+29.7%)를 정량화, EgoEngine은 그 데이터 생성을 자동화 — D24 전략의 실행 경로 구체화

### (d) 먼저 확인할 점

- **시각 갭 변환 품질**: 생성된 로봇 관찰 비디오가 실제 로봇 카메라 영상과 정렬되는지 정량 검증 필요 — 품질 부족 시 학습 신호 오염
- **다지 접촉 액션 갭 정확도**: 손가락 개별 관절 수준 매핑 오류 누적이 복잡한 다지 조작에서 어떤 수준인지 미확인
- **가장 저렴한 확인**: 공개 코드·변환 데이터 접근 → 변환 품질을 실제 텔레오퍼레이션 데모(RealDexUMI 등)와 비교 → 훈련 효율성 갭 평가

## 🥇 논문 2 — 우선순위 ★★★

**FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation**
[arXiv:2606.13102](https://arxiv.org/abs/2606.13102) · Yuan, Zhang, Zhou, Chen et al. · source: citation-graph (RH20T), keyword sweep (tactile)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여

- **이질적 촉각 센서 범용 foundation 정책 최초**: 이미지 기반·어레이 기반·상태 기반 촉각 입력을 단일 정책에서 처리 — 기존 촉각 정책의 "단일 센서 종속" 병목 최초 해소
- **이기종 인코더 → 통합 표현 변환**: 센서별 이기종 인코더(heterogeneous encoders)가 각 촉각 신호를 모폴로지-불가지론 통합 표현(morphology-agnostic unified representation)으로 정규화
- **크로스-센서 일반화 가능**: 하드웨어 재교체 없이 학습된 촉각 조작 능력을 신규 센서로 이전 — 접촉 집약 조작 전반 적용 대상

### (c) 시사점

- **이질적 촉각 코퍼스 통합 학습 경로**: RH20T(손목 6축 F/T), HapTile(손가락 촉각) 등 이기종 센서로 수집된 기존 데이터를 공동 학습에 활용 가능 — 촉각 데이터 풀 규모 확장 경로
- **촉각 데이터 수집 전략 단순화**: 특정 센서 표준화 없이 다양한 저비용 촉각 센서 조합으로 foundation 수준 성능 달성 가능성 — D25 "1등급 갭" 완화 새 경로
- **사전학습 데이터 구성이 D25 카탈로그 갱신의 근거**: FTP-1 학습에 사용된 센서별 데이터셋 목록 공개 시 촉각 코퍼스 카탈로그(`catalogs/datasets.md`) 갱신 우선 후보

### (d) 먼저 확인할 점

- **다지 손 인핸드 조작 커버 여부**: 단순 누르기·집기 외 회전·인핸드 재배치 등 고자유도 다지 태스크에서의 크로스-센서 일반화 범위 확인 필요
- **사전학습 데이터 공개 여부**: FTP-1 학습 데이터셋 목록 및 라이선스 미확인 — 공개 시 D27 기준 적용 후 촉각 코퍼스 추적 대상 추가
- **가장 저렴한 확인**: 프로젝트 페이지 → 사전학습 데이터셋 구성표 + 공개 모델 가중치 확인 → RH20T와 통합 학습 재현 가능성 검토

## 🥈 논문 3 — 우선순위 ★★

**YUBI: Yielding Universal Bidigital Interface for Bimanual Dexterous Manipulation at Scale**
[arXiv:2606.10244](https://arxiv.org/abs/2606.10244) · Ohkawa, Arima, Noguchi, Tateno et al. · source: keyword sweep (dexterous manipulation dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **손가락-정렬(finger-aligned) 이중 손 수집 인터페이스**: UMI(Universal Manipulation Interface)의 피스톨 그립 설계를 대체하는 "양보(yielding)" 방식 — 인간 손가락 움직임을 그리퍼 조(jaw) 동작에 직접 매핑
- **이중 팔(bimanual) 다지 조작 스케일 데이터 수집 특화**: 세밀한 두 손 협조 조작에서 직관적이고 에르고노믹한 데모 수집 가능
- **UMI 패러다임 다지 확장**: 기존 UMI 기반 파이프라인(데이터 수집 → 정책 학습)과 동일 구조 유지 — 기존 인프라 재사용 가능

### (c) 시사점

- **다지 조작 데이터 수집 공백 해소**: 기존 UMI로 커버되지 않던 양손 세밀 다지 태스크의 대규모 수집 경로 확보 — AgiBot World급 대형 다지 코퍼스 증설 방향
- **D24 데이터 다양성 확장**: 에고센트릭 비디오 외 직접 수집 경로로 이중 팔 다지 조작 시퀀스 확보 가능
- **데이터-배포 일관성**: YUBI로 수집한 데이터와 배포 시 동일 인터페이스 사용 → 배포 갭(deployment gap) 축소

### (d) 먼저 확인할 점

- **데이터셋 공개 여부·규모**: 논문과 함께 공개된 이중 손 조작 데이터셋의 트래젝토리 수·태스크 범위·라이선스 확인 필요 (D27 기준)
- **UMI 대비 실질 효율 검증**: 손가락-정렬 설계가 기존 피스톨 그립 대비 실제로 더 많은 다지 태스크 커버 가능한지 정량 비교 미확인
- **가장 저렴한 확인**: 프로젝트 페이지 + 공개 데이터 URL → 태스크 목록 및 다지 접촉 항목 포함 여부 확인 → `datasets.md` 추가 여부 판단

## 🥉 논문 4 — 우선순위 ★

**DuoBench: A Reproducible Benchmark for Bimanual Manipulation in Simulation and the Real World**
[arXiv:2606.11901](https://arxiv.org/abs/2606.11901) · Jülg, Bien, Hilber, Blei et al. · source: citation-graph (DROID)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여

- **FR3 Duo(Franka 이중 팔) 플랫폼 전용 이중 팔 벤치마크 최초**: 11개 태스크, 4개 협조 카테고리 — 기존 단일 팔 중심 벤치마크가 포착하지 못한 이중 팔 협조 실패 모드를 정량 평가
- **시뮬레이션 + 실세계 재현 가능**: 3D 프린터블 에셋과 재현 레시피 포함 → 타 실험실 복제 가능한 공개 평가 환경
- **단계 기반 평가 체계(stage-based evaluation)**: 최종 성공만이 아닌 중간 단계 진행 수준 정량 측정 — 실패 원인 분석 세밀화

### (c) 시사점

- **이중 팔 협조 조작 VLA 평가 표준화 기준점 확보**: 현재 공개된 이중 팔 전용 재현 가능 벤치마크 부재 공백 해소
- **다지 손재주 평가 확장의 선행 기준선**: 추후 다지 손 탑재 이중 팔 플랫폼 평가 시 DuoBench 설계 원칙(단계 평가, 재현 레시피) 재사용 가능
- **sim+real 일관성 검증 경로**: 동일 태스크를 시뮬레이션과 실물 모두에서 평가 — Sim2Real 갭 정량화 기반

### (d) 먼저 확인할 점

- **다지 손 특화 태스크 미포함**: FR3 Duo는 이중 팔 + 병렬 그리퍼 조합 — 다중 손가락 인핸드 조작 커버 미확인; P0 정체성 핵심 다지 태스크 미해당 가능
- **태스크 다양성 한계**: 11개 태스크가 테이블탑 이중 팔 범위 내 — 인핸드 회전·도구 사용 등 다지 평가 확장 여부 확인 필요
- **가장 저렴한 확인**: GitHub 태스크 목록 → 다지 손재주 항목 포함 여부 + 다지 손 확장 로드맵 확인 → D26 우선순위 최종 판단

## 🥉 논문 5 — 우선순위 ★

**Dense Force Estimation with an Event-based Optical Tactile Sensor**
[arXiv:2606.09451](https://arxiv.org/abs/2606.09451) · Politis, Zurbrügg, Cavinato · source: keyword sweep (tactile sensor, force estimation)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여

- **이벤트 기반 광학 촉각 센서로 밀집 3D 힘 장(dense 3D force field) 재구성 최초**: 기존 방법이 순 합력(net force)만 예측하던 것에서 공간적으로 밀집된 3D 힘 분포로 확장
- **마이크로초 시간 해상도**: 기존 프레임 기반 촉각 센서의 프레임 레이트 한계·모션 블러·대역폭 제약 극복
- **이벤트 촉각 센서의 새 활용 방향 제시**: 고속 다지 접촉 변화를 실시간 밀집 힘 신호로 포착 — 기존 F/T 센서(6축 합력)보다 공간 밀도 대폭 향상

### (c) 시사점

- **고속 다지 접촉 조작 촉각 레이블링 새 경로**: 마이크로초 해상도의 밀집 힘 분포는 인핸드 회전·슬립 감지 등 고속 접촉 변화 데이터 수집에 적합 — D25 스카우팅 우선 방향
- **RH20T 대비 공간 분해능 향상**: 손목 6축 F/T(RH20T)는 합력만 제공하나, 이벤트 기반 밀집 힘은 손가락 패드 수준 공간 분포 제공 가능
- **표준 촉각 센서 결합 잠재력**: 이벤트 촉각 센서가 상용화되면 기존 VLA 데이터 수집 파이프라인에 밀집 힘 레이블 추가 가능

### (d) 먼저 확인할 점

- **이벤트 촉각 하드웨어 가용성**: 이벤트 기반 광학 촉각 센서는 상용화 초기 단계 — 조달·제작 비용 및 내구성 확인 필요
- **실제 로봇 데이터 수집 검증 미확인**: 밀집 힘 추정 프레임워크가 실제 다지 로봇 조작 데이터 수집에 통합 적용되었는지 초록에서 미확인
- **가장 저렴한 확인**: 공개 코드 + 시뮬레이션 환경 → 밀집 힘 신호의 로봇 제어 루프 지연시간 검증 → D25 데이터 수집 파이프라인 통합 가능성 평가
