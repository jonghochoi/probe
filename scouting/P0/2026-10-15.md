### (b) 논문 요지

- 인간 영상 학습(LfO)을 한 잣대로 재는 RoboReel 벤치마크
- **문제** — 인간 영상에서 로봇 정책을 배우는 연구의 진척을 비교할 수 없음
  - 방법마다 시연 영상 가정, 하드웨어, 환경 구성이 달라 같은 조건의 비교 불가
  - 저자 진단은 두 가지, 장면의 시각 충실도와 이식 가능한 보정 환경의 부재
- **기존 한계** — 기존 방법과 벤치마크가 통일된 실제 인간 데이터와 짝지어진 테스트 환경을 함께 주지 못함
  - 인간 영상을 VLM으로 언어 지시로 바꾸는 계열, 영상에서 암묵 표현을 배우는 계열, 보정된 3D 인간 자세로 모방·인컨텍스트 학습하는 계열이 서로 다른 가정으로 학습·평가
  - 기존 관찰 학습 데이터셋과 벤치마크는 보정된 짝 테스트 환경과 궤적을 갖춘 통일 실제 인간 데이터셋을 제공하지 않음
- **핵심 방법** — 실제 인간 시연과 짝을 이루는 시뮬레이션 평가 환경을 한 묶음으로 구성
  - 생성형 방법으로 실제 물체 18개의 3D 메시를 복원해 시뮬레이션 디지털 트윈 구성
  - 탁상 10개 과제의 인간 시연 영상 2,000개, 참가자 6명, 외부 시점 3개와 헬멧 에고센트릭 시점 1개, RGB-D 동기화
  - 4개 테스트 스위트, 방해물 없음(ND), 학습 시 방해물(WD), 평가 시 방해물(ED), 인간 손목·키포인트 자세를 쓰는 자세 정의 스위트
- **차별점** — 인간 영상, 로봇 궤적, 평가 환경을 한 벤치마크에 묶은 최초의 통합 구성이라고 주장
  - 실제 환경에서 보정된 인간 시연과 짝지어진 시뮬레이션 환경으로 방법 간 동일 조건 비교
- **핵심 기여** — 벤치마크, 7개 이상 모델 평가, 시뮬레이션-실물 일치 검증
  - 10개 과제에 걸쳐 인간 시연 영상, 로봇 궤적, 평가 환경을 짝지어 공개 구성
  - UniSkill, Vid2Robot, PointPolicy, SeeDo, 자체 VLA 변형 등 7개 이상 알고리즘을 3개 계열로 나눠 평가
  - 시뮬레이션 ND·WD 스위트에서 영상 조건부 π0.5 변형 두 가지가 전반적으로 최고, ED 스위트에서는 키프레임 변형이 최고
  - 암묵 표현 방법이 명시 표현 방법을 전 과제에서 유의하게 앞섬
  - 장기 과제와 허용 오차가 작은 과제는 현 모델 모두에 어려움
  - 실물 3개 과제에서 영상 조건부 π0.5와 UniSkill의 6개 모델-과제 쌍을 시뮬레이션과 비교, Pearson r=0.92, Spearman ρ=0.94
- **가치** — 인간 영상 학습 연구에 재현 가능한 비교 기준점 제공
  - 시뮬레이션 순위가 실물 순위를 대체로 보존한다는 근거로 실물 평가 비용 절감 가능

### (c) 시사점

- 인간 영상 활용 방법의 공통 평가대 확보
  - 에고센트릭 영상 우선 전략의 효과를 방법 간 같은 조건으로 비교할 기준 후보
  - 짝지어진 시뮬레이션-실물 구조는 평가 하네스 설계의 참고 사례
  - 단일 팔 탁상 과제 중심이라 다지 손 접촉 평가의 직접 대체재는 아님

### (d) 먼저 확인할 점

- **저자 명시 한계** — 목표 기반 과제만 포함, 양팔 과제 없음, 연체 물체 없음
  - 복원 물체는 질량·마찰 등 물성을 재현하지 못하고 관절 물체는 라이브러리의 근사 모델로 대체
- **공개 범위** — 코드 저장소 문구 없이 웹페이지만 확인, 데이터 라이선스와 반입 가능 여부 확인 필요
- **이식 주의** — 실물 검증이 3개 과제 6개 쌍이라 상관계수의 표본이 작음

**점수 11/15** · R3 · N2 · M2 · Real3 · Repro1 — §5 "we will release our code, training recipes, and model checkpoints", 저장소 URL 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 에고센트릭 인간 데이터의 어떤 성질이 로봇 성능을 좌우하는지 분리한 연구
- **문제** — 에고센트릭 데이터가 시간 총량으로만 요약되어 무엇이 이득을 만드는지 불명확
  - 정렬 수준, 행동 범위, 행동 지도 유무, 규모 효과가 뒤엉켜 있음
  - 인간 행동 궤적은 카메라·손 자세 추정 비용과 라벨 신뢰도 문제를 동반
- **기존 한계** — 기존 연구는 인간 데이터 증가에 따른 유리한 스케일링을 보였으나 이득의 원천을 설명하지 못함
  - 인간 행동 예측 오차 같은 오픈루프 지표에 기대는 평가가 많다는 점을 저자가 지적
- **핵심 방법** — 월드-액션 모델(WAM) 백본을 고정하고 데이터 성질과 사용 전략만 바꾸는 통제 연구
  - 에고센트릭 데이터 피라미드, 로봇과 정렬된 시연에서 대규모 다과제 영상-행동 데이터, 행동 라벨 없는 영상까지 단계적으로 제약 완화
  - 영상 사전학습은 영상 예측 목적만, 미드트레이닝은 영상과 행동을 함께 최적화
  - 평가는 쌍팔 Piper 로봇 실물과 RoboDojo 폐루프 실행
- **차별점** — 데이터 시간 총량 하나로 보지 않고 정렬, 기간, 과제 다양성, 지도 수준, 사용 단계를 따로 통제
  - 행동 라벨 없는 영상도 월드 모델링 지도로 활용하는 경로를 같은 틀에서 비교
- **핵심 기여** — 요인별 결과와 실용 지침
  - 정렬된 인간 시연이 OOD 일반화를 개선, 실물 Place into the Basket에서 로봇 단독 정책은 물체 OOD 10%와 장면 OOD 0%, 해당 OOD 인간 시연을 더하면 물체 OOD 60%와 장면 OOD 20%
  - Fold Cloth에서 로봇 시연 300개를 100개로 줄여도 인간 데이터 500개를 더하면 ID 80%, 물체 OOD 60%, 장면 OOD 80% 회복, 20개까지 줄이면 회복 실패
  - 기간 1K–4K시간 확대는 일반화 5.0에서 7.8, 장기 과제 12.0에서 16.2, 과제 500–6K종 확대는 일반화 5.0에서 7.0, 정밀도는 장기 꼬리 과제가 늘며 하락
  - 영상 전용 사전학습으로 RoboDojo 평균 점수 6.39에서 14.13, 성공률 3.15%에서 9.45%
  - 같은 미드트레이닝도 영상 사전학습 없이는 10.28 / 6.42%에 그침
  - 사전학습 후 base에서 joint 공유 어텐션으로 바꾸면 14.13에서 20.29, 성공률 9.45%에서 14.35%
  - 실물 4개 과제 추가 평가, 수건 접기·병뚜껑 조이기·접시와 그릇 쌓기·전자레인지로 음식 데우기
- **가치** — 무엇을 얼마나 어떻게 모을지에 대한 데이터 수집 우선순위 근거 제공
  - 인간 데이터는 로봇 데이터를 줄일 뿐 대체하지는 못한다는 경계를 수치로 제시

### (c) 시사점

- 에고센트릭 우선 전략을 요인별로 검증한 근거
  - 총 시간 확대보다 정렬과 과제 범위를 먼저 챙기는 수집 설계의 근거
  - 행동 라벨이 없는 영상도 쓸 수 있어 손 추적 주석 비용이 낮은 코퍼스까지 후보 확대
  - 정밀도는 꼬리 과제 확대에서 하락해 수집 범위의 상한 판단에 참고

### (d) 먼저 확인할 점

- **통제 한계** — 영상 사전학습과 미드트레이닝은 계산량을 맞춘 비교가 아니라고 저자가 명시
- **범위 한정** — 단일 WAM 백본과 Piper 그리퍼 로봇 결과라 다지 손으로의 이전은 별도 확인 필요

## 🥉 논문 3

**OpenViTac: Learning and Benchmarking Visuo-Tactile Policies in a Unified Sim-and-Real Framework**
[arXiv:2610.10384](https://arxiv.org/abs/2610.10384) · Yifan Wu, Qin Li, Nan Min, Guojin Zhong, Haoyu Zhao, Zhiyuan Li 외 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 프로젝트 웹사이트만 있음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE) [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 시뮬레이션-실물 짝을 갖춘 시각-촉각 조작 벤치마크
- **문제** — 촉각을 쓰는 정책의 효과를 같은 조건에서 비교할 평가대 부재
  - 센서, 과제, 로봇, 프로토콜이 제각각이라 촉각의 기여가 불분명
- **기존 한계** — 기존 벤치마크가 촉각 조작을 덮지 못함
  - LIBERO, RoboTwin, RoboDojo는 시각 기반 정책 중심이고 촉각 미지원
  - Tabero, UniVTAC는 촉각 관측을 도입했으나 촉각 관련 능력의 폭, 하드웨어 구성의 다양성, 시뮬레이션-실물 대응이 부족하다고 저자가 주장
- **핵심 방법** — 촉각 능력 4축 벤치마크와 사전학습 VLA의 촉각 적응 연구
  - 능력 4축, 물성 인지, 취약 물체 조작, 접촉 집약적 조작, 정밀 조작
  - 시뮬레이션 과제 11개와 짝지어진 실물 과제 8개
  - 촉각 표현과 통합 위치를 바꿔 비교해 최선 조합을 OpenVTLA 프레임워크로 구성
- **차별점** — VLA, WAM, VTLA 정책을 시뮬레이션-실물 짝 설정에서 함께 비교
  - 촉각 표현과 통합 전략을 통제 비교한 뒤 그 결과를 방법으로 환원
- **핵심 기여** — 벤치마크, 촉각 적응 연구, 시뮬레이션-실물 공동학습 연구
  - 토큰 수준 연결 설정에서 촉각 표현 평균, AnyTouch2 68.7%, Sparsh 64.7%, SigLIP 59.5%, T3 58.1%
  - 무작위 초기화 인코더는 성능 저하, 촉각 이력을 현재 프레임 복사로 바꾸면 경도·무게 구분 저하
  - 통합 위치 비교에서 VLM 입력에 직접 넣는 토큰 수준 연결이 평균 최고
  - 평균 성공률, 시뮬레이션 OpenVTLA 68.7%와 최강 VLA 51.5%, WAM 53.3%, VTLA 61.2%
  - 평균 성공률, 실물 OpenVTLA 54.6%와 최강 VLA 43.1%, WAM 48.5%, VTLA 51.9%
  - 시뮬레이션-실물 일치도 Pearson r=0.967, MMRV=0.006
  - 공동학습, 실물 시연 100개에 시뮬레이션 500개를 더하면 π0.5가 USB 삽입 15%에서 40%, 기어 조립 35%에서 50%, OpenVTLA가 20%에서 40%, 50%에서 60% (설정당 20회 시행)
- **가치** — 촉각 정책을 시뮬레이션과 실물 양쪽에서 같은 잣대로 비교할 공개 평가대 제안
  - 사전학습 VLA에 촉각을 더하는 단순한 레시피 제시

### (c) 시사점

- 촉각 정책의 비교 기준점 후보
  - 촉각 능력 4축 구분은 접촉 집약적 평가 설계에 그대로 참고 가능
  - 촉각 이득의 로봇 정책 수준 실측 근거 확보
  - 조명 교란에서도 촉각 정책 성능이 덜 흔들렸다는 부수 결과

### (d) 먼저 확인할 점

- **공개 여부** — 프로젝트 웹사이트만 있고 코드·데이터 공개 문구 없음
- **저자 명시 한계** — 촉각 렌더링, 센서 모델링, 다중 모달 보정의 한계로 촉각 관측의 시뮬레이션-실물 격차 잔존
- **범위 한정** — 다지 손이 아닌 그리퍼 구성이고 변형 물체·장기 가사 과제는 향후 과제
- **공동학습 표본** — 두 과제 설정당 20회 시행이라 격차 해석에 주의
