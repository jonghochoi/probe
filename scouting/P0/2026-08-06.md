### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 로봇 조작 모방학습 연구가 비공개 데이터·비공개 하드웨어·비공개 학습 인프라에 의존해 재현·비교가 어렵다는 공백 지적
- 완전 오픈소스 행동복제(behavior cloning) 스택 ABC 제시 — 데이터셋, 하드웨어 설계, 학습 인프라, 시뮬레이션 파이프라인 전체를 하나의 릴리스로 통합
- 핵심 자산 ABC-130K 공개 — 195개 다양 태스크에 걸친 3,500시간·13만 에피소드 규모, 현재까지 최대 규모 오픈소스 텔레옵 데이터셋
- 시뮬레이션-실환경 상관성을 갖춘 400시간 규모 sim-teleop 데이터도 별도 공개, 실환경 평가 이전 저비용 대리 검증 지원
- Diffusion Transformer(DiT)와 VLA 계열 아키텍처 선택지를 동일 조건에서 비교하는 co-training 레시피 제시, 실환경 평가로 결과 검증
- 박스 접기·지갑에서 카드 빼내기 등 정밀 조작 태스크에서 정책 실행 성공 확인

### (c) 시사점
- 데이터·하드웨어·학습 인프라·시뮬레이션까지 전 스택 공개로 재현 장벽이 이례적으로 낮은 사례 — 자체 파이프라인 구축 시 참조 기준선으로 즉시 활용 가능
- 13만 에피소드 규모 오픈 텔레옵 코퍼스로 로봇-액션 데이터 축의 학습 기준선 데이터 확보
- sim-teleop 상관 검증 방법론이 실환경 평가 비용을 낮추는 방식으로 참조 가능

### (d) 먼저 확인할 점
- 텔레옵 하드웨어의 엔드이펙터 사양(병렬 그리퍼 vs 다지 핸드) 초록상 불명확 — 다지 손 조작 축 적합성 별도 확인 필요
- 195개 태스크의 접촉 집약도·난이도 분포 미제공 — 다지 조작 난도 검증 필요
- 3,500시간 규모 데이터의 라이선스 조건 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Ego2Robot: Scalable Robot Data Synthesis from Egocentric Human Data**
[arXiv:2608.02580](https://arxiv.org/abs/2608.02580) · Ye Wang, Peibin Lin, Xiong-hui Chen 외 12인 · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 에고센트릭 인간 조작 비디오를 VLA 사전학습 규모로 로봇 학습 데이터로 전환하는 기존 시도가 소규모 태스크별 정책 검증에 그쳤다는 공백 지적
- 액션 리타겟팅, 로봇팔 시각 합성, 다단계 품질 큐레이션을 결합한 확장형 파이프라인 Ego2Robot 제시
- 큐레이션 데이터셋과 야생(in-the-wild) 비디오 양쪽 지원, 15개 로봇 형태에 걸쳐 18,561시간 규모 로봇 학습 데이터 생성 — 현재까지 최대 규모 ego-to-robot 데이터셋
- 시각 외형·씬 배치·임베디먼트 형태·태스크 의미 4개 축을 분리한 perturbation 프로토콜로 RoboTwin2.0 확장, 일반화 평가 세분화
- Ego2Robot 합성 데이터와 실로봇 데이터 공동 사전학습이 여러 perturbation 유형에서 분포 외 일반화 일관되게 개선, 실로봇 배치로 이득 검증

### (c) 시사점
- 18,561시간 규모는 기존 ego-to-robot 합성 시도 대비 한 자릿수 이상 큰 스케일 — 에고센트릭 축 확장 사전학습 자원으로 즉시 검토 가능
- 큐레이션+야생 비디오 양쪽 지원 파이프라인이라 자체 보유 에고센트릭 원본 영상 재활용 경로로도 참고 가능
- perturbation 분리 평가 프로토콜이 자체 일반화 평가 설계 시 참조 가능한 세분화 축 제공

### (d) 먼저 확인할 점
- 18,561시간 데이터셋 자체의 공개 저장소·라이선스가 초록상 확인되지 않음 — 프로젝트 페이지 직접 확인 필요
- 다지 손 조작 비중이 초록상 불명확 — 15개 로봇 형태 중 다지 핸드 포함 여부 확인 필요
- 로봇팔 시각 합성 단계의 아티팩트가 하위 정책 학습에 미치는 영향 별도 검증 필요

## 🥉 논문 3 — 우선순위 ★

**ReTouch: Empowering Contact-Rich Dexterous Manipulation with Online-Refined Tactile Prediction**
[arXiv:2608.01824](https://arxiv.org/abs/2608.01824) · Shiqi Zhang, Xin Zhang, Yedong Shen 외 9인 · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 핵심 기여
- 접촉 집약적 다지 조작에서 촉각 신호 융합이 유효함에도 VLA 정책 내 온라인 촉각 피드백 통합이 충분히 탐구되지 않았다는 공백 지적
- 실행 중 들어오는 촉각 피드백으로 예측을 지속 정제하는 VLA ReTouch 제시 — 손가락별 식별과 국소 접촉 구조를 보존하는 Tactile-Patch Encoder + 촉각 상태·액션 청크를 동시 예측하는 고빈도 액션 모듈 결합
- XHand-UR7e 다지 핸드 플랫폼에서 접촉 집약 태스크 7종에 걸친 실물 시연 900건으로 구성된 XHT-Dataset 신규 수집
- 폐루프 실로봇 실험으로 검증, 표준·도전 조건 모두에서 최강 베이스라인 대비 성공률 18.4~23.8%p 개선

### (c) 시사점
- 다지 핸드 플랫폼(XHand-UR7e) 기반 촉각 시연 데이터 — RH20T 이후 희소한 촉각/힘 축에 신규 다지 손 특화 사례 추가
- 손가락별 촉각 패치 표현 방식이 향후 자체 촉각 데이터 스펙 설계 시 참조 가능한 구조
- 폐루프 온라인 정제 방식이 촉각 데이터의 활용 범위를 단순 관측 융합을 넘어 실행 중 보정으로 확장하는 사례

### (d) 먼저 확인할 점
- XHT-Dataset 900건의 공개 여부·라이선스·다운로드 경로가 초록상 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 900건·7태스크 규모로 기존 대형 촉각 코퍼스 대비 소규모 — 사전학습용보다 파인튜닝·검증용 자원으로 우선 검토 필요
- Tactile-Patch Encoder가 XHand 특정 센서 사양에 결합돼 있어 타 촉각 하드웨어로의 이식성 별도 확인 필요
