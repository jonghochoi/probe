## 🥇 논문 1

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu 외 11명 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — 초록 "We will release our code, models, and data to support further research." — 저장소 URL 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 500시간 전신 인간 데이터와 3단계 사전학습의 휴머노이드 VLA
- **문제** — 휴머노이드 이동 조작 학습에 필요한 전신 협응 데이터의 확보 곤란
  - 휴머노이드 원격조작 수집은 로봇 시간과 인력이 들어 과제·환경 규모 확장이 어려움
  - 휴머노이드가 물체에 다가가고 자세를 조정하고 쥔 채 옮기는 시간적 협응 지도가 필요
- **기존 한계** — 에고센트릭 인간 영상 기반 지도가 손목·손 궤적에 머묾
  - 영상에서 복원한 손목·손 궤적은 전신 협응을 충분히 담지 못함
  - 원격조작 기반 수집은 규모 확장이 어려움
- **핵심 방법** — 인간 경험을 전신 휴머노이드 정책으로 옮기는 3단계 학습의 VLA λ0
  - 1단계 — 다양한 에고센트릭 데이터셋에서 손 모션 중심으로 상호작용 학습
  - 2단계 — HumanVerse-500으로 몸통과 손 모션의 협응 학습
  - 3단계 — 하위 과제와 로봇 구현체에 맞춘 로봇 후학습
  - 단계 간 전이는 공유 표현 공간이 맡고, 인간·로봇 상태와 행동의 차이는 영역별 인터페이스가 처리
- **차별점** — 손 궤적 중심 지도에 전신 모션을 영상과 동기화해 더하고 이를 중간 학습 단계로 분리
- **핵심 기여** — 데이터셋, 정책, 스케일링 분석
  - HumanVerse-500 — 경량 웨어러블로 에고센트릭 영상과 몸·손 모션을 동기화한 500시간 개방 환경 데이터
  - SIMPLE에서 3.9%p, 실물 4개 과제에서 22.5%p 우위 — 가장 강한 평가 기준선 대비
  - 평가한 데이터 규모 범위에서 전신 인간 데이터 증가가 검증 손실을 낮추고 실물 과제 진행도를 개선
  - 두 인간 데이터 단계 중 전신 중간 학습이 실물 성공에 더 크게 기여, 인간 시연이 로봇 미경험 물체의 진행도를 개선
- **가치** — 전신 인간 데이터를 휴머노이드 이동 조작의 확장 가능한 지도 자원으로 보는 근거 제시

### (c) 시사점

- 에고센트릭 인간 데이터 축을 손에서 전신으로 넓히는 공개 예정 기준점
  - 500시간 규모 전신 동기화 코퍼스의 공개 시 인간 영상 중심 데이터 축의 보강 자원
  - 단계별 ablation이 전신 중간 학습의 비중을 수치로 제시
- 코드·모델·데이터 공개 약속만 있고 저장소가 없어 공개 시점 추적 필요

### (d) 먼저 확인할 점

- 하드웨어 한정 — Unitree G1과 BrainCo Revo 2 손 한 구성에서만 평가
- 스케일링 곡선은 단일 실행 적합으로, 시드 간 재현성은 논문이 주장하지 않음
- 공개 약속만 있고 저장소·라이선스 정보 없음

## 🥈 논문 2

**HuRo: Robotizing Human Videos for Scalable VLA Pretraining**
[arXiv:2609.10706](https://arxiv.org/abs/2609.10706) · Jinho Jeong 외 6명 · CoRL 2026 · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — arXiv comment "Accepted at CoRL 2026" — 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 인간 영상을 로봇 관측·행동으로 바꾼 63만 에피소드 사전학습
- **문제** — 이종 인간 영상이 확장 가능한 로봇 정합 지도 자원이 되는지의 불확실성
  - 실물 로봇 상호작용 데이터는 수집 비용이 큼
  - 인간 영상은 쉽게 모이지만 관측과 행동 양쪽의 구현체 격차 정합이 필요
- **기존 한계** — 관측·행동 동시 로봇화가 과제 일치 환경에 머묾
  - 기존 인간-로봇 파이프라인은 모션 리타게팅과 렌더링·이미지 편집 기반 시각 변환으로 격차를 메우되, 하위 로봇 과제에 맞춰 수집·변환한 인간 시연이 중심
  - 복원 모션으로 행동 지도를 주는 연구는 인간 중심 관측을 유지
  - 시각 로봇화를 쓴 연구는 시각 또는 보조 사전학습 목적에 한정
- **핵심 방법** — 시각 로봇화와 모션 리타게팅을 결합한 로봇화 파이프라인으로 VLA를 사전학습
  - 인간 손을 제거하고 렌더링한 로봇을 덮어씌우며 인간 손 모션을 로봇 행동으로 리타게팅
  - 주석 수준이 다른 영상에서 빠진 입력을 추정해 공통 로봇 관측·행동 형식으로 변환
  - 로봇화 에피소드로 사전학습 후 하위 로봇 시연으로 미세조정
- **차별점** — 과제 일치 시연이 아닌 이종 인간 영상 전반을 관측·행동 동시 정합 데이터로 변환하는 규모
  - 기존 로봇화 영상 사전학습 연구보다 한 자릿수 이상 큰 규모를 주장
- **핵심 기여** — 데이터셋과 세 가지 실험 결과
  - HuRo 데이터셋 — 인간 영상 5종 출처의 약 630K 로봇화 에피소드, 142M 처리 프레임
  - 실물 4개 과제에서 사전학습 데이터 증가에 따라 전체 완료율 51.5%에서 80.3%, OOD 완료율 34.9%에서 72.2%
  - 시각 로봇화가 OOD 강건성을 개선, 10% 오버레이 부분집합이 오버레이 없는 100% 변형을 능가
  - 리타게팅 행동을 쓴 종단 사전학습이 시각 전용 전이를 능가
- **가치** — 로봇화한 인간 영상을 실물 정책 학습의 확장 가능한 지도 자원으로 쓸 수 있다는 실증

### (c) 시사점

- 인간 영상의 로봇 정합 변환 효과를 규모별로 분리해 보여주는 사례
  - 행동 지도 유무와 시각 로봇화 유무가 각각 ablation으로 제시
  - 인간 영상 중심 데이터 축에서 시각 전용 활용 대비 행동 지도 포함 접근의 근거
- 데이터셋 공개 언급이 없어 활용 가능성은 후속 공개 확인 필요

### (d) 먼저 확인할 점

- 코드·데이터 공개 약속 없음, 프로젝트 페이지만 존재
- 실물 평가는 ALLEX 한 플랫폼의 4개 과제
- 논문 §6이 한계를 명시

## 🥉 논문 3

**ForceBench: Benchmarking Force Integration for Robotic Manipulation**
[arXiv:2610.19604](https://arxiv.org/abs/2610.19604) · Xuan Han 외 10명 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — arXiv comment "Project page: https://forcebench-platform.github.io/" — 프로젝트 페이지만, 코드 저장소 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 6축 손목 힘 통합 설계 6종을 비교하는 시뮬레이션 벤치마크
- **문제** — 힘 통합 설계들을 신뢰성 있게 비교할 통일된 프로토콜의 부재
  - 힘 인식 시스템마다 과제·시연·제어 설정이 달라 직접 비교가 막힘
  - 평균 성공률이 물성 추론, 저항 의존 상호작용, 접촉 집약적 조립 사이의 차이를 가림
- **기존 한계** — 기존 힘 통합 연구가 각자 다른 설정에서 평가
  - 힘 토큰과 시각·언어 특징의 적응적 융합, 고주파 피드백 기반 시간적 힘 인코딩
  - 접촉 예측으로 피드백 사용을 조절, 행동·렌치 결합 모델링 기반 강화학습 후학습
  - 배포 시 센서를 없애도록 힘 지식을 시각으로 증류
  - 시각 기반 조작의 표준 데이터·벤치마크는 성숙했으나 힘 인식 시스템 간 직접 비교는 어려움
- **핵심 방법** — 동일 π0.5 백본에 기준선 1종과 힘 통합 설계 6종을 같은 시연·학습 프로토콜로 비교
  - 현재 샘플 조건화 3종 — Token Fusion, Prompt Fusion, Cross-Attention
  - 미래 힘 예측 보조 지도를 더한 Token Fusion 변형
  - 시간적 기준 체계 2종 — Temporal Prompt, Dual-Path Fusion
  - ForceVLA는 외부 비교 대상
- **차별점** — 힘 통합 설계를 공유 관측·행동 인터페이스와 공유 시드 평가에서 한 백본으로 비교
- **핵심 기여** — 벤치마크, 비교 연구, 실물 검증
  - 8개 과제, 1,600개 동기화 다중 모달 시연, 과제·범주별 지표
  - 시뮬레이션 평균 성공률 Prompt Fusion 35.31%, 기준선 23.25%, 세 범주 모두에서 개선
  - 예측·시간 설계의 이득은 물성 추론에 집중, 두 시간 설계는 조립에서 기준선보다 낮음
  - 실물 5개 과제 8개 시스템 800회 시행 — Prompt Fusion과 Dual-Path Fusion 평균 63.00%, 기준선 40.00%, 모든 과제에서 개선한 것은 Prompt Fusion뿐
- **가치** — 비슷한 평균 성공률 뒤의 과제별 상충 관계를 드러내는 힘 통합 비교 기준점

### (c) 시사점

- 힘 모달리티의 효과를 설계별로 갈라 보여주는 공개 비교 기준점
  - 힘 통합의 이득이 과제 범주에 따라 달라 모달리티 도입 판단의 근거
  - 조립에서 시간 설계가 기준선 아래라는 결과가 접촉 집약적 과제의 주의점
- 힘·토크 계열 접촉 데이터 부족을 시뮬레이션 1,600개 시연으로 일부 메우는 자원

### (d) 먼저 확인할 점

- 벤치마크 본체가 시뮬레이션이고 실물은 정성적 경향 확인용
- 코드·데이터 저장소 없이 프로젝트 페이지만 있어 시연 접근성 확인 필요
- 비교가 π0.5 백본 하나에 한정되어 다른 백본으로의 일반화는 미검증
