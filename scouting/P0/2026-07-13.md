## 🥇 논문 1 — 우선순위 ★★★

**RoboSnap: One-Shot Real-to-Sim Scene Generation for Generalizable Robot Learning and Evaluation**
[arXiv:2607.06699](https://arxiv.org/abs/2607.06699) · Shujie Zhang, Jingkun Yi, Weipeng Zhong, Zirui Zhou, Yangkun Zhu, Hanqing Wang, Xudong Xu, Weinan Zhang, Chunhua Shen · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여
- 단일 RGB 이미지를 시뮬레이션 준비 완료 씬으로 전환하는 real-to-sim 프레임워크
- 물리 상호작용이 일어나는 전경(충돌 인식 자산)과 배경(3D 가우시안 스플래팅 시각층)을 분리하는 레이어드 설계
- DROID 씬 564개로 구성한 real-to-sim 동반 데이터셋 DROID-Sim 공개
- 실로봇 궤적 재현·정책 학습용 합성 데이터 생성·정책 평가 sim-real 상관관계 3가지 용도 정량 검증

### (c) 시사점
- 핀 논문 DROID의 실제 시연을 시뮬레이션 자산으로 재활용하는 파생 코퍼스 확보 — 신규 수집 없이 sim 학습·평가 데이터 확장 가능
- 정책 평가 시 sim 결과와 실로봇 결과 간 상관관계 정량화 — 저비용 sim 평가로 실로봇 검증을 일부 대체할 근거 확보
- 단일 이미지 입력만으로 씬 재구성 — 자체 환경 스캔 파이프라인 구축 비용 낮음

### (d) 먼저 확인할 점
- DROID-Sim 564개 씬이 다지 손 접촉·촉각 특화 조작을 포함하는지, 병렬 그리퍼 중심 씬 비중 확인 필요
- 프로젝트 페이지(robosnap.github.io) 존재하나 코드·데이터 라이선스 세부는 초록상 미확인
- 3D 가우시안 스플래팅 배경 충실도가 접촉 직전 근접 조작(마지막 수 cm)의 시각 정확도까지 보장하는지 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**RoboVista: Evaluating Vision Language Models for Diverse Robot Applications**
[arXiv:2607.04610](https://arxiv.org/abs/2607.04610) · Shuangyu Xie, Kai-Peng Chen, Ziyang Chen, S. Adebola, Yixuan Huang, Zehan Ma, Tianshuang Qiu, Wentao Yuan, Dhruv Shah, Pannag R. Sanketi, Ken Goldberg · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여
- 로봇 행동의 개별 의사결정 구성요소(모듈)를 분리 평가하는 Robot Question Answering(RQA) 프레임워크
- 실제 로봇 시스템·연구 논문·전문가 주석에서 큐레이션한 RoboVista 벤치마크 — VQA 474건, 39개 태스크 유형, 농업·산업·가정·수술·자율주행·오픈 로봇 데이터셋 포괄
- 최신 VLM들의 로봇 응용 추론 능력 간 실질 격차 정량화, RSS 2026 채택
- 물리 로봇 실험으로 RoboVista 점수와 실제 태스크 수행 성능 간 강한 상관관계 확인

### (c) 시사점
- VLM 기반 로봇 추론 능력을 세부 의사결정 단위로 쪼개 평가하는 벤치마크 축 확보 — end-to-end 정책 평가와 상보적
- 물리 로봇 실험으로 사전 검증된 벤치마크-실성능 상관관계, 자체 VLM 선정·검증 시 저비용 프록시로 참고 가능
- 프로젝트 페이지(berkeleyautomation.github.io) + RSS 동료심사 통과 — 공개·재현 신뢰도 상대적으로 높음

### (d) 먼저 확인할 점
- 다지 손 접촉·촉각 조작에 특화된 태스크 비중이 낮음 — 일반 로봇 응용 전반을 다루는 광범위 벤치마크라 P0 핵심 축과는 간접적 연결
- VQA 474건 규모가 39개 태스크 유형 대비 태스크당 표본 수 적음 — 세부 유형별 변별력 확인 필요
- 코드·전체 데이터 공개 범위(라이선스)가 초록상 명시 없음, RSS 논문 본문 확인 필요
