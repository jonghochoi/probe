## 🥇 논문 1 — 우선순위 ★★★

**What Matters When Cotraining Robot Manipulation Policies on Everyday Human Videos?**
[arXiv:2606.06627](https://arxiv.org/abs/2606.06627) · Li et al. (MIT, UIUC) · source: citation-graph (EgoDex, Ego-Exo4D)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **신규 데이터셋 공개**: 532개 일상 인간 비디오, 28시간, 삼각측량(triangulated) 3D 손 레이블 포함 — 큐레이션 데모가 아닌 인터넷 규모 비디오에 대한 최초 체계적 cotraining 연구 데이터
- **핵심 발견 1 — 손 포즈 품질**: 정확한 3D 손 레이블이 비디오-로봇 이전의 선행 조건; 품질 낮으면 다른 변수 효과 상쇄
- **핵심 발견 2 — embodiment 특화 필요**: 시각·정책 네트워크를 각 embodiment(인간/로봇)에 특화하지 않으면 모션 갭이 이전을 차단 — 공유 backbone 가정에 반례
- **실증 결과**: 제안 cotraining 레시피로 실제 로봇 조작 성공률 절대 **+29.7%** 향상

### (c) 시사점

- **일상 인터넷 비디오 유효성 확인**: 큐레이션된 데모 없이 인터넷 규모 인간 비디오로 실전 성능 향상 가능 — D24 우선 데이터 축의 강한 근거
- **3D 손 레이블 품질이 수집 설계의 핵심 변수**: EgoDex 등 고품질 손 트래킹이 있는 코퍼스 우선 확보 전략 유효
- **embodiment 특화 아키텍처 필요**: 단일 공유 인코더 방식으로는 인간→로봇 이전 한계 — 비전 백본 설계 결정에 직접적 영향

### (d) 먼저 확인할 점

- **소규모 데이터 일반화 위험**: 532개 비디오(28h)는 소규모 — 수천 시간 스케일에서의 동일 결과 재현 여부 미확인
- **embodiment 특화 인코더 비용**: 엔드이펙터 분리 설계가 다양한 로봇 embodiment 지원 시 파라미터 폭발 위험
- **가장 저렴한 확인**: 공개 코드·데이터 다운로드 후 EgoDex(829h) 손 레이블과 삼각측량 레이블 비교 → 품질 기준 도출

## 🥇 논문 2 — 우선순위 ★★★

**HapTile: A Haptic-Informed Vision-Tactile-Language-Action Dataset for Contact-Rich Imitation Learning**
[arXiv:2606.04825](https://arxiv.org/abs/2606.04825) · Alian et al. · source: citation-graph (RH20T), keyword sweep (tactile dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

  - 조작자 층위: 텔레오퍼레이터에게 햅틱 피드백을 주는 haptic glove
- **언어 조건화 + 다양한 접촉 집약적 태스크 커버**: 단일 태스크 전용이 아닌 다양한 조작 시나리오 포함
- **RH20T(손목 F/T) 대비 차별점**: 관절 수준이 아닌 손가락 수준의 공간 분해능 촉각 데이터 + VLA 형식 직접 정렬

### (c) 시사점

- **D25 '1등급 갭' 직접 해소**: P0가 명시한 대형 코퍼스의 촉각/F/T 결여 문제에 대한 최초 VLA 형식 응답
- **햅틱 텔레오퍼레이션의 데모 품질 향상 가능성**: 조작자도 촉각 피드백 수신 → 접촉 집약적 태스크의 데모 신뢰도 향상 경로
- **P2 관측 융합 실험의 상류 입력 후보**: 손가락 수준 촉각 신호를 관측 모달리티로 추가하는 실험 직접 지원

### (d) 먼저 확인할 점

- **데이터셋 공개 상태 미확인**: 초록 기준 공개 일정 불명확 — 접근 조건(라이선스, 신청 필요 여부) 확인 필요 (D27 기준 적용)
- **트래젝토리 수·태스크 다양성 규모**: 초록에서 구체적 수치 미제시 — 전문 열람 후 규모 적합성 재평가 필요
- **가장 저렴한 확인**: arXiv 전문 + 프로젝트 페이지 열람 → 데이터 공개 URL 및 라이선스 확인 → dataset.md 추가 여부 판단

## 🥈 논문 3 — 우선순위 ★★

**TouchAnything: A Dataset and Framework for Bimanual Tactile Estimation from Egocentric Video**
[arXiv:2605.13083](https://arxiv.org/abs/2605.13083) · Zhou et al. · source: citation-graph (EgoDex, UniHand-2.0, RH20T)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **에고센트릭 비디오만으로 촉각 추정**: 고비용 촉각 센서 없이 이중 손(bimanual) 접촉 상황의 촉각 신호를 시각에서 추정하는 최초 프레임워크
- **시각-촉각 쌍 데이터셋 공개**: 에고센트릭 비디오와 대응 촉각 레이블을 함께 제공 — 다운스트림 학습에 즉시 활용 가능
- **대규모 확장 경로 제시**: 전용 센서 없이 기존 에고센트릭 비디오(EgoDex 829h 등)에 촉각 레이블을 후처리로 부착하는 파이프라인 시연

### (c) 시사점

- **D25 갭을 비용 효율적으로 좁히는 경로**: 하드웨어 확장 없이 기존 에고센트릭 코퍼스에 촉각 커버리지 추가 가능 — 데이터 수집 비용 대비 효과 높음
- **EgoDex 연계 가능성**: 829시간 에고센트릭 손 추적 데이터에 TouchAnything 추정기를 적용하면 대규모 시각-촉각 의사 레이블(pseudo-label) 확보 경로
- **D24 데이터 축 강화**: 에고센트릭 비디오의 물리적 정보 밀도 향상 → 우선 데이터 축의 품질 업그레이드

### (d) 먼저 확인할 점

- **추정 정확도와 실제 촉각 일치도**: 시각 추정값이 실제 촉각 센서 측정과 얼마나 일치하는지 정량 검증 미확인 — 로봇 제어 활용 전 필수 점검
- **이중 손 특화 한계**: 단일 손 태스크나 물체가 많은 장면에서의 적용 가능성 별도 확인 필요
- **가장 저렴한 확인**: 공개 데이터셋 다운로드 → 기존 RH20T F/T 신호와 추정 촉각 신호 상관관계 비교 → 신뢰도 기준 설정

## 🥈 논문 4 — 우선순위 ★★

**RealDexUMI: A Wearable Universal Manipulation Interface for Dexterous Robot Learning**
[arXiv:2606.06033](https://arxiv.org/abs/2606.06033) · Xu et al. · source: citation-graph (UniHand-2.0)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여

- **착용형 범용 다지 조작 인터페이스**: 다지 손(dexterous hand) + 인핸드 비전 + 손가락 끝 촉각 감지를 단일 공유 엔드이펙터 모듈로 통합
- **리타겟팅 없는 직접 매핑**: 손바닥 측 등형(isomorphic) 텔레오퍼레이션 장갑이 인간 손가락 입력을 로봇 관절 명령에 직접 매핑 → 변환 오류 최소화
- **데이터 수집 ↔ 배포 일관성**: 동일 하드웨어 모듈로 데이터 수집과 실제 정책 실행 모두 수행 → 배포 갭(deployment gap) 구조적 제거

### (c) 시사점

- **다지 손 데이터 수집 공백 직접 해소**: 기존 UMI(병렬 집게)로 커버되지 않는 진정한 다지 조작 시연 가능 — D24 데이터 다양성 실질 확장
- **D25 촉각 데이터의 자연스러운 통합 플랫폼**: 손가락 끝 촉각을 데이터 수집 단계부터 내장 → 별도 센서 후처리 불필요
- **AgiBot World 등 대형 다지 데이터셋과 상보적**: 확장 가능한 저비용 수집 인터페이스로 기존 대형 코퍼스 보완 가능

### (d) 먼저 확인할 점

- **하드웨어 공개 및 재현 비용**: 다지 손 + 햅틱 장갑 조합의 BOM(자재 목록) 공개 여부 및 제작 비용 미확인
- **인간-로봇 키네마틱 차이 잔류 효과**: 리타겟팅 없는 직접 매핑도 손가락 길이·관절 범위 차이로 일부 태스크에서 동작 품질 저하 가능
- **가장 저렴한 확인**: 프로젝트 페이지 → 공개 데이터셋 규모 + 하드웨어 CAD/BOM 공개 여부 확인 → D27 라이선스 바 적용

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-ff7f0e.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

- **로컬-퍼스트(local-first) 설계**: 클라우드 의존 없이 자체 로봇 설정에서 즉시 재현 가능 — 진입 장벽 낮춤

### (c) 시사점

- **D26 벤치마크 공백 일부 해소**: 실제 로봇 조작 표준 평가 프로토콜 확보 — VLA 성능 비교 기준점 제공
- **공개·재현 가능 설계**: 동일 조건에서 모델 간 비교 가능 → 실험 커뮤니티 수렴에 기여
- **테이블탑 이상 확장 시 참조 설계**: 다지 손재주 평가 벤치마크 개발 시 UMI-Bench 설계 원칙 재사용 가능

### (d) 먼저 확인할 점

- **다지 조작 태스크 미커버**: 테이블탑 집기·놓기 위주 — 인핸드 회전·도구 사용 등 P0 정체성 태스크 포함 여부 확인 필요
- **UMI 중심 편향**: UMI 수집 방식 외 데이터(EgoDex, RH20T 등)와의 호환성 제한
- **가장 저렴한 확인**: GitHub 태스크 목록 열람 → 다지 손재주 항목 포함 여부 확인 → D26 우선순위 평가
