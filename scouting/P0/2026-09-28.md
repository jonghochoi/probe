## 🥇 논문 1 — 우선순위 ★★★

**MA-VLA: Multi-Arm Vision-Language-Action Model for Collaboration and Compositional Generalization**
[arXiv:2608.25864](https://arxiv.org/abs/2608.25864) · Zaibin Zhang, Jun-Lan Xiao, Zhong-Bo Zhang 외 11인 · arXiv preprint · source: citation-graph · 코드 공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 기존 VLA 모델이 언어 지시를 단일 전역 명령으로 취급해 팔별(arm-specific) 행동 할당·구성 메커니즘이 부재, 학습 중 관측되지 않은 협업 패턴으로의 전이가 제한된다는 공백 지적
- 협업 행동을 중간 수준 원자적 프롬프트로 분해해 개별 팔에 할당하는 멀티암 VLA 프레임워크 MA-VLA 신규 제시 — 명시적 서브골 지정·태스크 간 조합 재사용 지원
- 팔별 고정 실행 역할 의존을 줄이기 위해 관측·상태·할당 프롬프트를 팔 단위로 치환하는 학습 기법 Arm Shuffle 도입, 역할-불변 지시 따르기와 미확인 조합 패턴 재구성(멀티암 조합적 일반화) 지원
- 테스트 시 협업 패턴이 훈련셋에 부재하도록 구성한 벤치마크 신규 구축 — 시뮬레이션+실환경 평가에서 기존 SOTA VLA 대다수가 미확인 협업 패턴에서 실패하는 반면 MA-VLA는 일관된 성공 확인
- 코드·모델·데이터를 [GitHub 저장소](https://github.com/zhangzaibin/future-robots)에 공개

### (c) 시사점
- 벤치마크/이밸 하니스 축에 멀티암 협업 조합적 일반화라는 신규 진단 축 추가 — 팔 간 역할 재구성 평가 프레임워크로 자체 양팔·다중팔 정책 평가에 참조 가능
- Arm Shuffle 치환 학습 기법은 역할-불변 팔 정책 설계에 직접 재사용 가능한 학습 레시피
- 코드·모델·데이터 즉시 공개돼 벤치마크 재현·자체 정책 벤치마킹 도입 장벽 낮음

### (d) 먼저 확인할 점
- 실환경 평가 규모·태스크 수가 초록 수준에서 구체적으로 제시되지 않음 — 본문에서 실로봇 비중 확인 필요
- 기존 SOTA VLA 대비 성공률 정량 수치가 초록에 없어 우위 폭은 본문 확인 필요
- 14인 대규모 협업 산출물로 벤치마크·코드 저장소의 장기 유지보수 여부 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**From Rollout to Reset: A Graph-Based Harness for Autonomous Long-Horizon Manipulation Evaluation**
[arXiv:2609.19413](https://arxiv.org/abs/2609.19413) · Jing Jiang, Yue Yang, Xin-Kai Jiang 외 3인 · arXiv preprint · source: citation-graph · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 로봇 조작 정책의 실로봇 평가가 여전히 사람이 매 롤아웃 사이 씬을 리셋하는 방식에 의존, 오퍼레이터 시간 소모와 불명확한 초기 상태 분포로 재현성이 낮다는 공백 지적
- 단일 스텝 태스크에만 리셋·채점을 자동화하는 기존 AutoEval의 한계(장기수평 롤아웃은 종료 상태가 조합적으로 다양해 단일 리셋 정책으로 커버 불가) 극복, 학습된 원자적 리셋 스킬 라이브러리에 대한 계획 수립으로 씬을 복원하는 하니스 HALTER 신규 제시
- 포인트 클라우드·비전 파운데이션 모델로 온라인 공간 씬 그래프를 구축, LLM이 이 그래프 위에서 추론해 롤아웃 채점·리셋 계획·리셋 성공 검증까지 수행 — 태스크별 라벨링된 성공 이미지 수집 불필요
- Franka 팔 기반 4개 장기수평 태스크에서 씬 복원 성공률 76%(AutoEval 52%·모션플래닝 리셋 65% 대비 우위), 완료 스킬 비율 추정 정확도 90%(AutoEval 76% 대비), 리셋 검증 정확도 91%(AutoEval 78% 대비) 확인
- 3개 미확인 홀드아웃 태스크 기반 조합적 일반화 평가에서 HALTER 74.7% 복원 대비 태스크별 리셋 정책 1.3%에 그침을 정량 실증, 씬 표현·그래프 업데이트 주기 어블레이션 수행

### (c) 시사점
- 벤치마크/이밸 하니스 축에 장기수평 조작 평가의 리셋 병목을 해소하는 자율 평가 하니스 추가 — REBOOT(09-24)의 실패-복구 신호화와 상호보완적인 평가 인프라 축
- 그래프 기반 리셋 계획+LLM 씬 추론 조합은 자체 장기수평 평가 파이프라인의 오퍼레이터 개입 축소 설계에 직접 참조 가능
- 조합적 일반화(미확인 홀드아웃 태스크) 평가 방법론은 자체 정책의 일반화 폭 진단에 재사용 가능

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 초록에 명시되지 않음 — 공개 시점·계획 확인 필요, 현재는 비공개로 처리
- Franka 팔 1개 플랫폼·4개 태스크 한정 평가로 다지 손(multi-finger) 조작·타 임베디먼트 일반화는 별도 확인 필요
- 리셋 스킬 라이브러리 구축 비용이 태스크 복잡도에 따라 어떻게 스케일하는지 초록 수준에서 불명확
