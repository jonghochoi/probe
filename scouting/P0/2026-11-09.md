## 🥇 논문 1

**MotorSense: A Video-EMG Dataset of Motoric Representations for Action Understanding**
[arXiv:2610.41127](https://arxiv.org/abs/2610.41127) · Eadom Dessalene, Michael Maynord, Amir-Hossein Shahidzadeh 외 6명 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 11/15** · R2 · N3 · M3 · Real0 · Repro3 — NeurIPS 체크리스트 "We release the MotorSense dataset (synchronized video, bimanual EMG and IMU, ...), the trained models, and the training and evaluation code, together with instructions for reproducing the experiments"

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 에고센트릭 영상과 근전도를 짝지은 100시간 데이터셋
- **문제** — 비전 모델이 손 동작을 시각적 결과로만 학습해 근육 활동 같은 체화 신호에 접근하지 못함
  - 영상만으로는 행동 구조가 고차원 픽셀 흐름 속에 암묵적으로 남음
  - 손은 사람이 물리 세계를 바꾸는 통로라 손 관련 체화 신호가 특히 중요
- **기존 한계** — 힘 데이터셋과 영상 주석 데이터셋이 각각 다른 것을 내줌
  - FEEL, TouchScale, OpenTouch 같은 힘 데이터셋 — 신호가 덜 풍부하고 덜 조밀하며 손에 다는 센서가 시야와 상호작용을 가림
  - EPIC-Kitchens, Ego4D의 영상 주석 — 수작업 주석 비용, 사전 정의 온톨로지 설계, 주석 오류와 부정확성 세 가지 부담
- **핵심 방법** — 손목 밴드 근전도(EMG)와 에고센트릭 영상을 동기화해 수집하고 영상-EMG 대조 학습으로 영상 인코더를 정렬
  - 아래팔에 전극 8개를 두른 밴드로 EMG, 손목 IMU, 에고센트릭 안경 영상을 동기화
  - CLIP 방식 대조 목적식으로 영상 인코더와 EMG 인코더를 공유 임베딩 공간에서 함께 학습
  - EMG는 사전학습 때만 쓰는 특권 지도 신호이며 추론에서는 제외, 정렬된 영상 백본을 영상 전용 하위 과제로 전이
  - 생성 응용 — EMG를 VQ-VAE로 이산화한 모터 코드로 이미지-투-비디오 확산 모델을 조건화
- **차별점** — 수작업 주석 대신 센서로 직접 잰 근육 활동을 감독 신호로 쓰고 손에 다는 센서 없이 수집
  - 같은 MotorSense 영상과 손 크롭에서 RGB 전용 목적식(SimCLR, MoCo, BYOL 계열)을 사전학습해 EMG 기여를 분리하는 비교 설계
- **핵심 기여** — 데이터셋, 사전학습 방식, 모터 코드 조건화 세 가지
  - 비가림 손목 EMG 밴드와 에고센트릭 안경으로 비정형 손-물체 조작 100시간을 담은 첫 대규모 영상-EMG 쌍 데이터셋 공개
  - 행동 인식, 3D 손 복원, 3D 접촉 복원 네 개 과제와 영상 데이터셋 여덟 개에서 모든 기준선을 앞섬, 가장 큰 이득은 백본을 고정한 설정
  - 접촉 복원은 시드 세 개 평균으로 보고
  - 모터 코드 조건화로 손-물체 상호작용 영상의 생성 충실도 향상
  - 데이터셋, 학습된 모델, 학습·평가 코드와 재현 지침 공개를 체크리스트에 명시
- **가치** — 손의 힘과 손가락 움직임을 가림 없는 조밀한 신호로 얻는 경로를 열어 영상 표현 학습의 감독원 확장

### (c) 시사점

- 접촉 모달리티 공백을 영상 쪽에서 메울 새 신호원 후보
  - 촉각 장갑 없이 손에 닿는 힘 정보를 에고센트릭 수집과 짝지을 수 있다는 가능성
  - 3D 접촉 복원 하위 과제가 있어 접촉 지도 신호로 쓸 때의 이득을 직접 가늠 가능
  - 데이터, 모델, 코드가 함께 공개돼 에고센트릭 코퍼스 후보로 바로 검토 가능
  - 로봇 결과가 없어 로봇 학습 이득은 별도 확인 필요

### (d) 먼저 확인할 점

- **실물 결과 없음** — 사람 영상과 EMG, 영상 생성 평가뿐이고 로봇 정책 학습 이득은 보고되지 않음
- **저자 명시 한계** — 8채널 소비자용 EMG 밴드로 수집한 설정
- **공개 상태** — 체크리스트가 가리키는 저장소가 익명 처리 링크이며 라이선스는 확인 못함
- **이식 주의** — EMG는 사전학습 때만 쓰이고 추론에서 빠지므로 힘 크기를 직접 읽는 접촉 센서의 대체로 보기는 어려움

## 🥈 논문 2

**RLHND: Video Foundation Models as Physically Grounded Hand Trackers for Robot Learning**
[arXiv:2610.09455](https://arxiv.org/abs/2610.09455) · Seungjun Moon, Subin Jeon, Sangwoo Kim 외 2명 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R2 · N3 · M3 · Real2 · Repro1 — §Reproducibility "We will release the implementation of RLHND, along with the pre-trained weights."

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 단안 영상에서 손 자세와 접촉력을 함께 추정하는 트래커
- **문제** — 사람 영상을 로봇 학습에 쓰려면 사람과 로봇 에피소드 사이 두 간극을 메워야 함
  - 행동 공간 불일치 — 어떤 행동 공간을 택하든 3D 손 관절 위치 라벨이 필요한데 기존 복원은 신뢰하기 어려움
  - 물리 정보 부재 — 사람 데이터는 대체로 촉각 정보가 없음
- **기존 한계** — 손 복원은 2D 재투영 정렬에 맞춰 최적화되고 접촉 추정은 덜 연구됨
  - 깊이 축 떨림과 프레임마다 변하는 손 크기가 크고, 원인은 원근 투영의 스케일-깊이 모호성
  - 압력판이나 촉각 장갑 같은 계측 수집만 촉각을 제공
  - 영상 기반 접촉·힘 추정 모델이 나왔지만 자세 추정에 비해 미개척
  - 영상 확산 모델을 쓴 선행 연구는 깨끗한 영상을 노이즈 제거 백본에 그대로 입력
- **핵심 방법** — 사전학습 영상 확산 백본 Cosmos 3 Nano를 결정적 클립 단위 특징 추출기로 바꿔 자세 스트림과 촉각 전문가 스트림을 얹음
  - 깨끗한 영상을 사전학습 때 깨끗한 문맥 프레임을 받도록 설계된 조건 프레임 인터페이스로 입력
  - 형상 캐싱 — 영상 전체에 손 형상 값 하나를 쓰고 보정된 손 형상을 직접 주입 가능
  - 해부학적 자세 매개변수화 — MANO 회전 45자유도 대신 손가락이 돌 수 없는 축을 고정해 29자유도를 회귀
  - 분리된 촉각 전문가 — 자세 스트림을 고정한 채 학습해 촉각 지도가 자세를 흔들지 않음
  - LBS 기반 특징 확산 — MANO 스키닝 가중치로 뼈 단위 특징을 778개 정점에 퍼뜨려 정점별 어텐션 비용 회피
- **차별점** — 영상 파운데이션 모델 기반 손 추적을 자세에서 접촉·힘 추정까지 넓히고 형상 캐싱과 분리형 촉각 스트림으로 물리 정합성 확보
  - 깨끗한 영상을 노이즈 제거 백본에 그대로 넣는 접근과 달리 조건 프레임 인터페이스를 거침
- **핵심 기여** — 자세와 접촉 추정의 최고 성능, 로봇 학습 활용 시연
  - HOT3D, ARCTIC, 학습에서 제외한 EgoDex 세 벤치마크에서 모든 기준선보다 낫다고 보고, 접촉과 힘 추정도 여러 벤치마크에서 최고
  - 인간 시연을 손 다섯 종에 리타깃팅해 가장 낮은 평균 관절 오차와 매끄러운 명령을 보고
  - Dexterous Point Policy 실물 실험에서 RLHND 라벨로 학습한 쪽이 원래 트래커 라벨 쪽보다 나아지고 복잡한 양손 과제에서 이득이 큼
  - 인코더 교체, 해부학적 매개변수화, 외부 형상 주입 세 요소를 하나씩 뺀 ablation
  - 구현과 사전학습 가중치 공개 예정
- **가치** — 영상만으로 접촉이 붙은 로봇 학습용 사람 시연 라벨을 자동으로 만드는 경로 제시

### (c) 시사점

- 촉각 계측 없이 영상에서 접촉 라벨을 뽑는 도구 후보
  - 접촉이 없는 에고센트릭 코퍼스에 접촉·힘 라벨을 사후에 입힐 수 있는 가능성
  - 학습에서 제외한 EgoDex에서도 평가해 기존 대형 코퍼스 재주석에 연결 가능
  - 손 다섯 종으로의 리타깃팅 결과가 혼합 코퍼스 구성의 참고 자료
  - 구현과 가중치가 공개 예정이라 코퍼스 재주석은 공개 뒤에 판단

### (d) 먼저 확인할 점

- **공개 상태** — 코드와 가중치는 공개 약속뿐이며 라이선스는 확인 못함
- **실물 범위** — 실물 실험은 Dexterous Point Policy 단일 플랫폼이고 두 행은 같은 RLHND 접촉 라벨을 쓰고 손 키포인트만 달라 접촉 추정의 로봇 이득은 분리되지 않음
- **저자 명시 한계** — 고정 역기구학 리타깃팅과 휴리스틱 접촉 오프셋을 사용했고 이진 접촉을 넘는 힘 활용은 범위 밖
- **계산 비용** — 클립을 오프라인으로 처리하고 백본이 크롭 기반 회귀 트래커보다 훨씬 큼
- **이식 주의** — 영상에서 추정한 접촉은 실측 촉각이 아니어서 계측 데이터와의 오차 확인 필요

## 🌱 논문 3 — 인접 분야 픽

**Reconstruction-Augmented Visuomotor Pre-Training of 3D-Grounded Bimanual Dexterity from RGB-Only Human Videos**
[arXiv:2610.29716](https://arxiv.org/abs/2610.29716) · Xingyi He, Zhiwen Qiu, Adhitya Polavaram 외 5명 · adjacent field: 공간·기하 멀티모달 융합 표현 (Slot C)

**점수 10/15** · R2 · N2 · M3 · Real3 · Repro0 — arXiv comment "Project page"는 프로젝트 페이지뿐, 초록·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 복원한 3D 기하를 입력과 예측 목표로 쓴 인간 영상 사전학습
- **문제** — 양손 조작 학습에 공간 접지와 다양한 경험이 모두 필요한데 로봇 시연은 수집 비용이 커서 범위가 좁음
  - 웹의 RGB 전용 인간 영상은 장면 기하와 로봇 호환 행동 라벨이 없음
  - 영상에서 복원한 손 움직임과 장면 기하를 일관된 스케일로 맞추고 시간에 걸쳐 정렬해야 함
- **기존 한계** — 손 움직임 지도 중심 사전학습과 기하 단서 활용 연구가 있으나 둘의 결합이 부족
  - 인간 영상에 손목·손가락 움직임 지도를 주고 행동 공간 정렬로 전이하는 VLA 사전학습
  - 포인트 트랙 예측, 손-물체 키포인트 공유, 보정된 기하와 공간 언어·손목 지도 결합 같은 3D 단서 연구
  - 손과 일관된 스케일의 장면 기하 복원이 어렵고 스케일 오차가 공간 지도를 망침
  - 기하와 시각 특징을 합치거나 공간·인간 모션 지도를 결합해도 손 행동이 장면 변화와 어떻게 연결되는지는 직접 지도하지 못함
- **핵심 방법** — 영상마다 장면 기하와 손 움직임을 복원해 같은 스케일로 맞추고 이를 정책 입력과 예측 목표로 모두 사용
  - 3D 손 추정의 손 크기 사전 정보로 양손과 전 프레임에 걸친 공유 스케일 기하 보정
  - 복원 기하를 사전학습 VLM의 이미지 패치 특징과 점진적 이중 게이트 융합으로 결합해 VLM 시각 사전 지식 유지
  - 미래 장면 기하를 손목·손가락 행동과 함께 예측
  - 손가락 움직임은 예측한 양 손목 궤적에 조건화해 생성
  - 사전학습 뒤 소수의 로봇 시연으로 양손 조작 과제에 미세조정
- **차별점** — 기하를 입력으로만 쓰지 않고 미래 기하 예측으로 지도해 손 행동과 장면 변화의 연결을 직접 학습
- **핵심 기여** — 데이터 파이프라인, 사전학습 프레임워크, 시뮬레이션과 실물 평가
  - 기하와 손 움직임 주석이 정렬된 영상 클립 100만 개 생성 파이프라인
  - 시뮬레이션 아홉 과제와 두 구현체에서 평균 76.3%, 가장 강한 기준선 59.8%
  - 실물 여섯 과제 평균 81.7%, 가장 강한 기준선 43.3%이고 과제당 10회 시행에서 60회 중 49회 성공
  - 손 움직임만 쓴 사전학습보다 복원 기하를 쓴 사전학습이 14.2%p 높다는 동일 조건 비교
  - 기준선 일곱 종과 비교하고 구성 요소 ablation은 시드 세 개 평균으로 보고
- **가치** — 라벨 없는 웹 인간 영상에서 기하가 정렬된 양손 사전학습 데이터를 만드는 방식 제시

### (c) 시사점

- 인간 영상 코퍼스에 기하 주석을 입히는 재주석 레시피
  - 에고센트릭 코퍼스에 손 움직임뿐 아니라 일관된 스케일의 장면 기하를 같이 두는 구성이 사전학습 이득을 14.2%p 높였다는 근거
  - 영상 100만 클립 규모의 정렬 주석 사례가 코퍼스 주석 항목 설계 참고
  - 데이터 자체의 공개 신호는 없어 코퍼스 후보가 아닌 주석 방식 참고에 한정

### (d) 먼저 확인할 점

- **공개 상태** — 프로젝트 페이지뿐이며 코드, 데이터, 가중치 공개 약속 없음
- **비교 범위** — 가장 강한 기준선 대비 격차이며 시뮬레이션은 양손 협응 과제에서 이득이 크고 한 손 과제는 이득이 작음, Pick Bucket에서는 기준선이 앞섬
- **실물 규모** — 실물은 여섯 과제 과제당 10회 시행이라 표본이 작음
- **이식 주의** — 인접 분야 논문으로 정책 구조에 초점이 있어 코퍼스 구성과 라이선스 판단 근거는 아님
