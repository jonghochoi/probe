- 시연량 대 DAgger 교정 데이터의 스케일링 트레이드오프가 정량 확보돼 자체 데이터 수집 전략(순수 시연 확대 대 교정 데이터 투자) 의사결정에 참조 가능
- 오픈소스 공개 방침이 명시돼 있어 라이선스 확정 시 허용적 라이선스 선호 기준 충족 여부 검토 대상

## 🥈 논문 2 — 우선순위 ★★

**FailBench: How Reliable are VLMs at Judging Robot Task Success?**
[arXiv:2609.03611](https://arxiv.org/abs/2609.03611) · Zaruhi Navasardyan, Tatul Danielyan, Hrant Davtyan · arXiv preprint · source: citation-graph · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- VLM 기반 로봇 조작 성공·실패 판정 벤치마크 다수가 크로스 도메인 일반화 근거 부족하다는 공백 지적
- 12개 실환경 + 2개 시뮬레이션, 총 14개 공개 소스에서 취합한 2,197건 조작 시도로 구성된 실패 탐지 벤치마크 FailBench 신규 공개 — 실패의 75%는 자연 발생 상황에서 수집
- 최신 VLM 기반 탐지기 13종을 벤치마킹, 최고 성능 모델도 평균 균형정확도 0.77에 그침을 확인
- 실패 탐지 특화 파인튜닝 모델이 범용 VLM 및 자체 사전학습 베이스라인보다 오히려 낮은 성능을 보이는 역설적 결과 규명
- 접촉 집약적 조립 태스크에서 성능이 무작위 수준(0.60 미만)으로 저하되는 반면 물체 이동이 관측 가능한 태스크에서는 포화 성능에 근접함을 정량 확인, 모호한 증거 상황에서 성공을 예측하는 체계적 편향도 규명

### (c) 시사점
- 벤치마크/이밸 하니스 축에 VLM 판정자(judge) 신뢰도를 직접 검증하는 진단 벤치마크 추가 — 자동 성공판정 파이프라인 채택 전 신뢰도 점검 도구로 즉시 활용 가능
- 접촉 집약 태스크에서의 판정 성능 저하가 정량 확인돼 다지 조작 평가에 VLM 판정자를 쓸 때의 리스크 판단 근거 확보
- 입력 단 개입(결과 관련 영역만 크롭)으로 추가 학습 없이 성능 개선 가능함이 실증돼 저비용 개선 기법으로 참조 가능

### (d) 먼저 확인할 점
- 공개 저장소·데이터 접근 경로가 초록·arXiv comment 모두에 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 14개 소스 대부분이 병렬 그리퍼 조작 시도로 추정되며 다지 손 조작 실패 사례 비중은 초록상 불명확
- 3인 소규모 팀 산출물로 2,197건 취합 데이터셋의 장기 유지보수·소스별 라이선스 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**ZETA: A Controlled Study of Zero-Shot Cross-Embodiment VLA Transfer for Tabletop Manipulation**
[arXiv:2609.02546](https://arxiv.org/abs/2609.02546) · Mi Yan, Wenhao Zhang, Zhiqi Zhang 외 14인 · arXiv preprint · source: citation-graph · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 핵심 기여
- 로봇 임베디먼트가 다변화되는 가운데 미확인 임베디먼트로의 제로샷 전이가 중요하나 통일된 정의·통제된 평가 환경 부재로 체계적 이해가 제한된다는 공백 지적
- 목표 임베디먼트가 훈련 데이터에 전무한 strict 제로샷 전이와 사전학습에만 노출된 pretrain-exposed 전이를 구분 정식화
- 시뮬레이션+실환경에 걸친 14개 홀드아웃 목표 임베디먼트로 구성된 통제된 벤치마크 신규 제시
- 상태-액션 표현·사전학습 임베디먼트 다양성·보조 공동학습 목표·목표 임베디먼트 노출 4개 요인을 통제 분석, 각각 약 15·18·7 퍼센트포인트 향상 효과 정량 분리
- 목표 임베디먼트 데이터 5%만 사전학습에 추가해도 평균 진행도가 13.4 퍼센트포인트 개선됨을 확인, strict·pretrain-exposed 전이가 별도로 보고돼야 함을 실증

### (c) 시사점
- 벤치마크/이밸 하니스 축에 크로스임베디먼트 전이 요인을 분리 정량화하는 통제된 진단 벤치마크 추가 — 자체 멀티임베디먼트 정책 설계 시 어떤 요인에 투자할지 판단 근거 확보
- 로컬 엔드이펙터(EEF) 상태-액션 표현이 전이 성능에 가장 크게 기여함이 정량 확인돼 액션 표현 설계 선택에 직접 참조 가능
- 목표 임베디먼트 데이터 소량 혼합만으로 큰 개선을 보여 신규 임베디먼트 적응 비용 절감 전략 설계에 참조 가치

### (d) 먼저 확인할 점
- 공개 저장소·데이터 접근 경로가 초록·arXiv comment 모두에 명시되지 않음 — 프로젝트 페이지 직접 확인 필요
- 정지형 테이블탑 + 2지 그리퍼 환경 한정 검증으로 다지 손·모바일 베이스·장기 태스크로의 일반화는 저자도 향후 과제로 명시
- 17인 규모 협업 산출물로 14개 홀드아웃 임베디먼트 구성의 실환경 대 시뮬레이션 비중이 초록상 불명확
