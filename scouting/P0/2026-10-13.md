## 🥇 논문 1

**SoTa: Soft Tactile Skins for Dexterous Manipulation**
[arXiv:2610.02338](https://arxiv.org/abs/2610.02338) · Jingyun Yang 외 8명 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — §I "We will release the resources needed to fabricate and operate these skins." — 저장소 URL 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 인간·로봇 손 공통 202 택셀 촉각 스킨과 공동학습
- **문제** — 비주오택타일(visuo-tactile) 정책 학습의 규모가 비싼 로봇 데이터에 묶임
  - 다지 로봇 시연은 텔레오퍼레이션이 필요해 느리고 고가 하드웨어에 의존
  - 값싼 인간 시연으로 보충하려면 인간 손에도 로봇과 대응되는 촉각 신호가 필요
  - 요구 조건 — 손 전체 커버, 손 형상별 맞춤, 반복 접촉·굴곡 내구성, 두 구현체 간 같은 촉각 구조
- **기존 한계** — 기존 시각·촉각 시스템이 위 조건을 충족하지 못함
  - 손가락 끝 센서 위주 — 테이블 닦기·플러그 삽입처럼 손가락 마디·손바닥 접촉이 필요한 과제에서 접촉 누락
  - STAG·FlexGlove·OpenTouch 등 인간 착용 장갑은 손 전체를 덮지만 단일 구현체 전용
  - 두 구현체용 인터페이스는 기계적 정합 구조나 동일 센서를 써서 착용자를 로봇 전용 하드웨어에 묶거나 커버 범위가 손가락 끝·손바닥에 한정
  - FTP-1은 이종 센서의 인간·로봇 데이터를 센서별 인코더로 사전학습, 인간 힘 측정 연구는 손가락 끝 하나만 측정
  - 인간 시연을 쓰는 기존 촉각 정책 연구는 짝 시연이나 자동 생성 의사 짝(pseudo-pair)으로 인간·로봇 촉각 표현을 정렬
- **핵심 방법** — 손 형상별 맞춤 정전용량(capacitive) 촉각 스킨과 언어 지도 기반 인간·로봇 공동학습
  - 레이저 패터닝 다층 패브릭 전극 — 얇고 부드러운 스킨을 손마다 맞춰 자체 제작, 스킨당 재료비 10달러 미만
  - 202개 택셀(taxel)을 손가락·손바닥의 같은 의미 영역에 같은 인덱스로 배정 — 인간·로봇 관측이 하나의 촉각 인코더 공유
  - 인간 시연은 액션 라벨이 없어 인간·로봇 시각·촉각 관측에서 과제 단계를 예측하는 보조 목적함수로만 편입, 액션 지도는 로봇 데이터에서만
  - FTP-1 위에 구축 — 이미지·프롬프트·촉각 관측이 액션 전문가를 조건화
- **차별점** — 학습된 센서 간 매핑 없이 택셀 대응을 설계 단계에서 보장
  - 짝 시연·의사 짝 정렬 대신 공통 택셀 배치와 과제 단계 라벨을 써서 두 데이터셋 간 관측 짝이 불필요
  - 모션 리타깃팅이나 액션 라벨 없이 인간 시연 활용
- **핵심 기여** — 촉각 스킨, 센서 특성 분석, 인간 시각·촉각 시연을 로봇 정책 학습에 넣는 파이프라인
  - 센서 — 반응 범위 20mN–10N, 하중·제하 10,000회 후 초기 반응 폭 97% 이상 유지, 주먹 쥐기 굴곡 1,280회에도 배선 연속성 유지
  - 실물 3개 과제(상자 재배향, 컵 집기, 플러그 삽입) — 촉각 관측이 시각 전용 정책 대비 분포 내 성공률을 세 과제 모두 개선, 분포 밖 조건으로는 일관되게 이어지지 않음
  - 로봇 시연 예산 고정(과제당 50–75개) 아래 과제당 인간 시연 150개 추가 — 8개 평가 조건 평균 성공률 22.8%에서 45.9%, 분포 밖 5개 조건 모두 개선
  - Ablation — 로봇 데이터만 쓴 2단계 학습과 시각 전용 인간 공동학습 모두 전체 방법의 분포 밖 이득을 재현하지 못함
  - 제작 공정·센서 설계·판독 보드 Gerber 파일·펌웨어 공개 예정
- **가치** — 착용형 무선 장갑으로 로봇 없이 촉각 시연을 모으는 경로
  - 촉각 인간 시연이 비싼 로봇 텔레오퍼레이션을 보완하는 실용 수단이라는 근거

### (c) 시사점

- 인간 촉각 시연을 로봇 데이터 보조로 쓰는 실측 근거
- 로봇 시연 예산을 고정하고 인간 시연만 더한 설계 — 인간 데이터 우선 전략의 효과 검증 틀로 차용 가능
- 재료비 10달러 미만 자체 제작 스킨 — 손 전체 촉각 데이터 수집의 도입 비용 낮음
- 공통 택셀 배치로 센서 간 정렬 학습 단계가 불필요 — 인간·로봇 촉각 데이터 통합 비용 절감 후보

### (d) 먼저 확인할 점

- 인간 시연은 과제당 150개 고정 — 규모·다양성 확대 효과와 로봇 데이터 대체 정도는 미측정, 저자 명시 한계
- 학습된 센서 간 매핑 방식과의 비교 없음 — 저자 명시 한계
- 보조 학습 ablation이 인간 촉각의 기여만 따로 분리하지 못함 — 저자 명시
- 로봇 학습 데이터는 과제당 단일 물체, 인간 데이터는 3개 물체 — 분포 밖 이득 일부가 물체 다양성 효과일 수 있다는 저자 분석
- 공개 대상은 데이터셋이 아닌 제작·운용 자원이고 저장소 URL 없음 — 코퍼스로 쓰려면 자체 수집 필요
- 장기 착용 내구성 미평가

## 🥈 논문 2

**SimpleTouch: Can Vision-Language-Action Models Master Contact-Rich Manipulation Without Tactile Policy Pretraining?**
[arXiv:2610.02784](https://arxiv.org/abs/2610.02784) · Chen Yang 외 9명 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — 본문 재현성 고지 "We are preparing a public release of the complete codebase and model checkpoints, together with all training configurations and evaluation scripts, and will make these resources available in the near future."

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 촉각 정책 사전학습 없이 VLA에 촉각 전문가 결합
- **문제** — 사전학습 VLA에 촉각을 넣어도 자동으로 유용해지지 않음
  - 시각만으로는 접촉 기하·변형·미끄러짐 상태를 구분할 수 없어 촉각이 이를 보완
  - 촉각은 다수 VLA 백본의 사전학습 모달리티 밖 — 미세조정 단계에서 직접 넣으면 이득이 작거나 성공률이 떨어진다는 보고
  - 핵심 과제 — 접촉 정보를 보존하면서 소수 시연으로 과제별 사용법을 배우게 하는 입력 형식
- **기존 한계** — 기존 해법이 추가 데이터와 학습 단계를 요구
  - FTP-1 — 대규모 이종 촉각 조작 데이터로 촉각 정책 사전학습
  - VITaL — 별도의 시각·촉각 표현 정렬 단계
  - T3 등 사전학습 촉각 인코더는 표현만 제공하고 액션 인터페이스나 정책 학습 단계의 필요 여부는 규정하지 않음
- **핵심 방법** — π0.5에 촉각 전문가(tactile expert) 하나를 붙인 단일 단계 학습
  - 사전학습 T3 촉각 인코더를 고정하고 전역·공간 토큰 전부(센서당 197개) 유지
  - 촉각 전문가가 현재 촉각 특징을 시각·언어 백본과 분리 처리하고 액션 전문가가 층별 어텐션으로 읽음
  - 액션 지도와 함께 미래 촉각 잠재(latent)의 다중 지평 예측을 잠재 플로우 매칭(flow matching)으로 학습 — 예측은 학습 지도 신호로만 사용
  - π0.5 백본·액션 전문가와 촉각 전문가를 함께 미세조정, 추론 시 촉각 전문가의 층별 캐시 재사용
- **차별점** — 촉각 표현 획득(인코더)과 촉각 정책 학습을 분리해 정책 사전학습·정렬 단계를 생략
  - 같은 T3와 촉각 전문가를 쓰는 FTP-π0.5와 갈리는 지점 — 인코더 고정, 전 토큰 유지, 다중 지평 미래 촉각 예측
- **핵심 기여** — 단순한 촉각 VLA 레시피와 촉각 정책 사전학습 필요성에 대한 통제 비교
  - UniVTAC 시뮬레이션 6개 과제(과제당 시연 50개, 100회 평가) — 6개 과제 모두 1위, 평균 77.5%로 FTP-π0.5 45.2%·FTP-1 66.7% 대비 32.3·10.8%p 우위
  - 실물 4개 과제(PiPER 팔, 평행 그리퍼, GelSight Mini 2개, 과제당 20회) — 평균 71.3%로 FTP-1 62.5% 대비 8.8%p 우위, Insert USB는 둘 다 30%
  - Ablation(시뮬 4개 과제 평균) — 촉각 없음 39.0%, CLS 토큰만 57.5%, 전 토큰 74.3%, 인코더 학습 허용 70.5%, 미래 예측 없음 68.8%, 단일 지평 예측 68.5%
  - 데이터 효율 — 시연 10개에서 Put Bottle·Insert Hole 23%·43%, FTP-π0.5는 5%·14%
  - 코드·체크포인트·학습 설정·평가 스크립트 공개 준비 중
- **가치** — 사전학습 VLA와 촉각 인코더가 있으면 촉각 정책 사전학습 없이도 접촉 집약 조작이 가능하다는 더 단순한 경로

### (c) 시사점

- 과제 시연 50개로 촉각 정책 사전학습 모델 추월
- 촉각 코퍼스의 쓰임이 정책 사전학습보다 인코더 사전학습 쪽에 있을 수 있다는 근거
- 과제당 시연 50개 규모의 소량 촉각 데이터로 촉각 VLA 구축 가능 — 도입 비용 낮음
- UniVTAC 6개 과제 설정이 촉각 정책 비교의 공개 기준점

### (d) 먼저 확인할 점

- 실물 평가는 평행 그리퍼와 비전 기반 촉각 센서 한정 — 다지 손·다른 촉각 센서 미평가, 저자 명시 한계
- 고주파 촉각 피드백과 힘 기반 제어는 연구 범위 밖 — 저자 명시
- 결론의 범위는 평가 과제 한정 — 정책 사전학습이 일반적으로 불필요하다는 근거는 아님
- 큰 시연 예산에서 성능이 단조 증가하지 않음 — 저자는 스케일링 법칙이 아니라고 명시
- 공개 약속만 있고 저장소 URL 없음

## 🥉 논문 3

**Zeva-Ego: Egocentric Mid-Training with In-Context Causal Learning for Robot Manipulation**
[arXiv:2609.24411](https://arxiv.org/abs/2609.24411) · Bingjia Huang 외 7명 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 에고 영상 1만 시간 중간학습이 로봇 2천 시간과 대등
- **문제** — 에고센트릭 인간 영상을 로봇이 실행할 지식으로 바꾸는 일과 배포 후 적응
  - 액션 라벨이 있는 로봇 궤적은 과제·환경·구현체 전반으로 확장하기 비쌈
  - 에고 영상은 대부분 로봇 액션과 정렬된 궤적이 없음 — 카메라 운동·자기 가림·구현체 차이로 비슷한 모션이 다른 궤적에 대응
  - 배포 후 VLA 파라미터가 고정돼 학습 때 없던 물리 조건에 적응하지 못함
- **기존 한계** — 영상 기반 잠재 액션과 기존 적응 방식의 한계
  - LAPA·UniVLA·CLAP — 시각 동역학만으로 추론한 표현이 외형 변화 같은 방해 요인에 민감
  - 테스트 시간 학습은 그래디언트 업데이트에 의존
  - 기존 메모리 기법은 시각·의미 이력만 보존하고 액션이 환경을 어떻게 바꾸는지는 표현하지 않음
- **핵심 방법** — 오프라인 에고 중간학습(mid-training)과 온라인 ICCL 사후학습의 2단계
  - 1단계 — π0.5에서 초기화, Action-Centric Encoder(ACE)가 RGB 프레임 쌍에서 연속 액션 토큰 지도를 생성
  - 통합 16차원 엔드이펙터 표현과 카메라 좌표계 액션 청크로 인간 손목과 로봇 엔드이펙터 간 간극 축소
  - 중간학습 코퍼스 — 에고 쪽 EgoDex 약 830시간, EgoVerse 1,362시간, Ego4D 3,670시간, Egocentric-10K 중 4,439시간, 로봇 쪽 AgiBot World와 시뮬레이션 InternData-A1 7,434시간
  - 2단계 — In-Context Causal Learning(ICCL), Causal Transition Encoder가 시각 상태·실행 액션·관측 효과를 인과 상호작용 증거로 부호화
  - 시도 내 Brief Interaction Trace와 시도 간 Persistent Interaction Memory에 저장한 맥락을 액션 전문가에만 주입, 배포 중 파라미터는 고정
- **차별점** — 에고 영상에서 외형 대신 액션 중심 지도를 뽑고 배포 적응을 파라미터 업데이트 없이 인과 증거 메모리로 수행
- **핵심 기여** — 2단계 프레임워크, 에고 영상의 액션 토큰 처리 파이프라인, 액션 표현·데이터 규모·상호작용 적응 분석
  - 데이터 규모 — 같은 π0.5 초기화에서 에고 영상 10K시간 중간학습 시 RoboTwin(시뮬레이션) 성공률 63.8%에서 75.3%, 로봇 시연 2K시간의 74.7%와 대등 — 에고 영상 4–5시간이 로봇 시연 1시간에 상응
  - 실물 ChemLab-Evo 3개 원자 과제(ARX 양팔 로봇, 과제당 20회) — 과제 정합 에고 에피소드 50개 추가 시 로봇 시연 10개 조건에서 PickTube·PlaceBottle 성공률 55·40%p 향상, 에고 약 1.5개가 로봇 시연 1개에 상응
  - ACE 토큰 거리와 물리 액션 거리의 상관 — EgoDex–AgiBot 홀드아웃 0.801, EgoVerse 제로샷 0.724
  - ICCL — RoboTwin 10개 과제에서 첫 시도 58%, 네 번째 시도 89%, 파라미터 업데이트 없음
- **가치** — 대규모 에고 영상을 밀도는 낮지만 확장 가능한 물리 지도 신호로 쓰는 경로와 교환 비율 수치 제시

### (c) 시사점

- 에고 영상과 로봇 시연의 교환 비율 실측치 확보
- 같은 초기화·같은 시간축의 4–5:1 비율 — 데이터 확보 우선순위 판단의 정량 근거
- 과제 정합 에고 에피소드가 소수 로봇 시연을 보완한다는 실물 수치
- EgoDex·EgoVerse·Ego4D·Egocentric-10K를 한 액션 표현으로 묶는 전처리 설계가 참고점

### (d) 먼저 확인할 점

- 4–5:1 비율은 시뮬레이션 RoboTwin 기준 — 실물의 1.5:1은 과제 정합 에고 데이터를 쓴 별도 설정
- 저자도 4–5:1을 지도 신호 품질과 확장성의 절충으로 해석, 원시 영상 간 동등성은 아님
- 실물 평가는 양팔 그리퍼 로봇의 3개 원자 과제 — 16차원 엔드이펙터 스키마에서 손가락 수준 정보 보존 여부 확인 필요
- 반복 시드·분산과 한계 서술 없음
- 코드·데이터·체크포인트 공개 약속 없음, Ego4D 등 사용 조건이 붙은 코퍼스 포함

## 🌱 논문 4 — 인접 분야 픽

**VT-Bridge: Bridging Pretrained Foundation VLAs to VTLAs via Lightweight Residual Adaptation**
[arXiv:2609.22606](https://arxiv.org/abs/2609.22606) · Yansong Wu 외 7명 · adjacent field: PEFT — 경량 잔차 어댑터 (Slot A) · 코드 공개 예정

**점수 10/15** · R2 · N2 · M2 · Real3 · Repro1 — 본문 말미 고지 "Codex was also used to organize the codebase for open-source release." — 저장소 URL 없음, 초록의 프로젝트 페이지만

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 0.98M 잔차 어댑터로 사전학습 VLA를 VTLA로 전환
- **문제** — 과제 미세조정 후에도 VLA의 실물 접촉 집약 조작 성공률이 낮음
  - 시각·언어·운동학 상태 같은 비접촉 모달리티만으로는 물리 상호작용에 불충분
  - VTLA 개발은 데이터·모델 양쪽에서 비쌈 — 공개 데이터에서 시각·촉각 짝 궤적이 희소하고 촉각 시연 수집에 정밀 힘 조절이 필요
  - 촉각 인코더·융합 모듈이 파라미터와 학습 비용을 늘려 기존 VTLA의 과제 범위가 범용 VLA보다 좁음
- **기존 한계** — 기존 VTLA는 처음부터 학습하거나 구조를 바꿔 촉각을 융합
  - 통합 VTL 융합, 전문가 혼합(MoE) 융합, 액션 디코더·액션 전문가 주입, 예측 액션 보정 등 융합 전략 모두 대규모 시각·촉각 데이터와 연산 요구
  - VLA-Touch가 사전학습 VLA의 VTLA 전환을 처음 시도했으나 이 적응 패러다임의 잠재력은 미탐색
- **핵심 방법** — 사전학습 VLA 구조는 그대로 두고 실행 직전 액션을 촉각으로 보정하는 잔차 어댑터
  - Slow–fast 추론 — 저주파 VLA가 장면 해석과 액션 청크 생성, 고주파 어댑터가 실행 주기마다 접촉 변화에 반응
  - 어댑터 — 액션 청크 인코더와 최근 힘 창 인코더의 병렬 트랜스포머, MLP 디코더가 잔차 액션 예측
  - 접촉 신호 — 추정 외부 엔드이펙터 힘과 외부 관절 토크
  - 잔차 목표 — 시연의 목표(desired) 자세와 미세조정 VLA 예측 자세의 차
  - 같은 어댑터 구조에 백본별 가중치만 바꿔 π0·π0.5·SmolVLA에 적용
- **차별점** — VTLA를 새로 학습하거나 VLA 구조를 바꾸지 않고 실행 단계 잔차로만 촉각 반영
  - 대규모 사전학습으로 얻은 시각·언어 기반과 모션 생성 능력 보존
- **핵심 기여** — 과제당 시각·촉각 시연 최대 50개와 0.98M 파라미터 어댑터로 VTLA 구축
  - 실물 4개 과제(Pump Bottle, Clean Whiteboard, Insert Plug, Flip Rocker Switch, Franka Panda) — 3개 백본 평균 엄격 성공률(strict success) 11.7%에서 62.9%, 모든 과제·백본 조합에서 최고
  - 마지막 1인치 병목 — 기하적 근접 성공 조건부 완료율을 미세조정 VLA 대비 평균 58.8%p 개선, Pump Bottle 평균 90.6%, Insert Plug 85.9%(미세조정 VLA는 세 백본 모두 0%)
  - Ablation — 잔차 목표를 실행(executed) 자세로 만들면 엄격 성공률 12.1%, 목표 자세 사용 시 62.9%
  - 컴플라이언스로 생기는 목표·실행 자세 차가 접촉력 정보를 담는다는 분석 — Pump Bottle·Insert Plug 최대 접촉력 약 40N
- **가치** — 기존 오픈소스 VLA를 적은 데이터·학습 비용으로 촉각 인지형 VTLA로 바꾸는 경로

### (c) 시사점

- 소량 시각·촉각 시연으로 기존 VLA 재사용 경로
- 촉각 데이터 희소성을 코퍼스 확장 대신 소량 시연과 경량 어댑터로 우회하는 선택지
- 별도 촉각 센서 없이 로봇 내장 힘·토크 추정치로 접촉 신호 확보 — 도입 비용 낮음
- 엄격 성공과 조건부 완료율을 분리한 지표가 접촉 집약 평가의 실패 유형 진단 틀로 차용 가능

### (d) 먼저 확인할 점

- 접촉 신호가 촉각 센서가 아닌 Franka의 추정 외부 힘·관절 토크 — 촉각 패드·다지 손으로의 전이 미검증
- 단일 플랫폼 4개 과제, 반복 시드·분산과 자기 방법의 한계 서술 없음
- 임피던스 제어 전제 — 목표·실행 자세 차를 쓰는 잔차 목표 설계가 다른 제어기에서도 성립하는지 확인 필요
- 저장소 URL 없음, 프로젝트 페이지만 존재
