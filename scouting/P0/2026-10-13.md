## 🥇 논문 1

**$N_0$-Foundation: Towards the Age of Tactile Intelligence**
[arXiv:2608.29601](https://arxiv.org/abs/2608.29601) · NeoteAI Team, Fudan TEAI Team · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N3 · M2 · Real3 · Repro1 — 초록 "We release the dataset, the representation, and the benchmark" — 코드 저장소 URL 없음

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 3만 시간 시각-촉각 코퍼스와 평가 세트 일괄 공개
- **문제** — 대규모 조작 데이터가 시각 위주라 접촉 집약적(contact-rich) 조작에 필요한 접촉 정보 부재
  - 국소 힘, 마찰, 초기 미끄럼, 접촉 전이가 외부·손목 카메라로는 약하게만 관측됨
  - 변형 물체 조작, 정밀 삽입·조립, 섬세한 힘 제어, 지속 표면 접촉, 양팔 협조가 영향권
- **기존 한계** — 시각 편중과 촉각 모달리티 파편화, 두 가지 지적
  - 단일 embodiment 원격조작 코퍼스(Walke et al., Mandlekar et al.)부터 교차 embodiment 수집(O'Neill et al., Khazatsky et al.), UMI 계열 휴대 수집, 대규모 에고센트릭 영상까지 모두 시각 관측 중심
  - 카메라 기반 비주오택타일, 정전용량 어레이, 광섬유 센서가 하드웨어별 신호 형식을 써서 한 장치의 촉각 시연을 다른 장치에 재사용 불가
  - 그 결과 촉각 데이터 풀링과 규모 효과가 막힘
- **핵심 방법** — 하드웨어·데이터·표현·평가 네 축을 한 체계로 연결
  - 인프라 — 내구성 비전 기반 촉각 센서, 센서 내장 UMI 장치 `N0-TacUMI`, 로봇·UMI 겸용 시각-촉각 동기 수집 시스템
  - NeoData — 실물 원격조작과 UMI 시연을 섞은 30,000시간 이상, 6개 embodiment, 450개 이상 과제, 수십억 쌍의 RGB·촉각 프레임
  - OpenNeoData — 5,000시간 공개 부분집합, 6개 embodiment, 250개 이상 과제, 200개 이상 스킬
  - NeoForce — 조밀한 3축 힘장(force field)을 센서 공통 물리 지도 공간으로 삼는 하드웨어 무관 시각-촉각 표현 모델
  - 평가 — 실물 NeoReal 10개 과제와 시뮬레이션 NeoSim 스위트의 결합
- **차별점** — 센서 외형이 아닌 3축 힘장을 공통 표현으로 삼아 이종 촉각 장치의 데이터를 하나로 묶음
  - 정책이 이득을 보는 것은 장치별 촉각 이미지 외형이 아닌 물리적 접촉 상태라는 주장
- **핵심 기여** — 저자가 꼽은 다섯 가지
  - 촉각 인프라·대규모 데이터·표현 학습·표준 평가를 묶은 촉각 중심 체화 학습 패러다임
  - 촉각 수집 하드웨어와 파이프라인, `N0-TacUMI`
  - 교차 embodiment 시각-촉각 코퍼스 NeoData와 공개분 OpenNeoData
  - 힘 기반 통합 촉각 표현 NeoForce
  - 표준 평가 — 실물 NeoReal 10개 과제(과제당 무작위 롤아웃 20회)에서 π0.5가 평균 성공률 26.5%로 최고, LingBot-VA·Fast-WAM은 일부 과제만 성공
  - π0.5 고정 백본 위 촉각 통합 비교 — 모든 촉각 변형이 비전 전용보다 우위, 평균 진척 점수 38.1%(비전 전용)에서 47.5%(NeoForce 조건화)로 상승
- **가치** — 촉각을 대규모 체화 학습에 넣는 데이터·표현·평가 경로를 한 번에 제시

### (c) 시사점

- 공개 촉각 코퍼스 규모의 자릿수 도약
- **공개 기준점 확보** — 공개분만 5,000시간으로 추적 중인 촉각·힘 코퍼스 대비 규모 차이 큼
- **평가 재사용** — NeoReal은 실물 접촉 과제에서 현행 VLA·WAM 정책의 낮은 성공률을 수치로 보여 주는 기준선
- **센서 통합 경로** — 힘장 표현은 센서가 서로 다른 촉각 데이터를 한 학습 입력으로 묶는 참고 설계

### (d) 먼저 확인할 점

- **표현 범위** — 통합 표현은 평행 그리퍼용 비주오택타일 손가락 대상, 다지 손·비카메라 센서 확장은 저자도 향후 과제로 둠
- **공개 범위** — 전체 30,000시간 중 5,000시간만 공개, 코드 저장소 URL 없음
- **라이선스** — 본문에 라이선스 표기 없음, 사용 조건 확인 필요
- **통계** — 반복 시드·분산 보고 없음, NeoSim과 실물 배치의 연결 강화는 향후 과제로 남김

## 🥈 논문 2

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — 초록 "We will release our code, models, and data to support further research"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 전신 동작까지 담은 500시간 에고센트릭 인간 데이터
- **문제** — 휴머노이드 전신 이동 조작(loco-manipulation) 학습에 몸 움직임과 손-물체 상호작용을 함께 담은 시연 필요
  - 전신 원격조작 수집은 로봇 시간과 인력 소모가 커서 과제·환경 확장 곤란
- **기존 한계** — 에고센트릭 영상에서 손목·손 궤적만 복원하는 기존 방법은 전신 협조를 담지 못함
  - 손목·손 궤적을 액션 지도로 쓴 사전학습이 조작 성능을 높인다는 선행 결과는 있음
  - 물체 접근, 도달을 위한 자세 조정, 운반 중 파지 유지 같은 몸-손 시간적 협조는 손 궤적만으로 지도 불가
- **핵심 방법** — 웨어러블로 모은 전신 인간 데이터 HumanVerse-500과 3단계 학습 전신 휴머노이드 VLA 정책
  - 수집 — GoPro HERO13을 목 마운트로 로봇 머리 카메라 높이에 맞추고, PICO 4 Ultra 헤드셋·바디 트래커로 24관절 몸 동작 기록
  - 손 동작 — 같은 영상에서 Dyn-HaMR로 손당 21관절 재구성, 유효성 마스크로 가림 구간 처리
  - 1단계 — EgoDex 등 공개 에고센트릭 손-물체 데이터 7종으로 손 동작 사전학습
  - 2단계 — HumanVerse-500을 SONIC으로 Unitree G1 상태-액션 형식으로 변환해 전신 미드트레이닝
  - 3단계 — 로봇 시연으로 후학습, 인간·로봇 상태·액션 차이는 도메인별 인터페이스로 분리
- **차별점** — 손 궤적에 그치지 않고 몸 동작이 동기화된 인간 데이터를 중간 단계 지도로 사용
- **핵심 기여** — 데이터셋, 정책, 스케일링 분석 세 가지
  - HumanVerse-500 — 500시간, 32,993 에피소드, 8,700만 포즈 프레임, 827개 과제 유형의 개방 환경 인간 이동 조작 데이터
  - 공유 인간-로봇 표현 공간에서 3단계로 학습하는 전신 휴머노이드 VLA 정책
  - 실물 4개 과제(과제당 10회) 평균 성공률 62.5%, 가중 진척 80.4%로 최강 외부 베이스라인 대비 각각 22.5%p, 25.8%p 우위
  - 시뮬레이션 SIMPLE 전체 성공률 90.0%로 StarVLA 대비 3.9%p 우위
  - 전신 인간 데이터 증가에 따른 검증 손실 감소와 실물 진척 향상, 두 인간 데이터 단계 중 전신 미드트레이닝의 기여가 더 큼
  - 인간 시연이 로봇이 보지 못한 물체에서의 진척 향상
- **가치** — 로봇 없이 모은 전신 인간 경험을 휴머노이드 제어의 확장 가능한 지도 신호로 쓰는 근거

### (c) 시사점

- 손 추적을 넘어 전신 동작까지 담은 에고 코퍼스
- **데이터 축 확장 후보** — 에고센트릭 손 추적 데이터에 몸 동작 동기화를 더한 상위 형태
- **도입 비용 낮음** — 수집 장비가 GoPro와 PICO 상용품 조합이라 자체 수집 재현 용이
- **편입 판단 보류** — 데이터 공개 약속 단계, 실제 공개 시 포맷·라이선스 확인 후 판단

### (d) 먼저 확인할 점

- **embodiment 한정** — 평가가 Unitree G1에 한정, 전신 크기 휴머노이드 전이는 미검증 (저자 명시)
- **정렬 오차** — 카메라 정렬과 리타깃팅에도 신체 비율·시점·가능 동작 차이로 인간-로봇 정렬 불완전 (저자 명시)
- **스케일링 근거** — 스케일링 곡선은 단일 실행 결과로 시드 간 재현성 미확립 (§5.3)
- **손 라벨 정밀도** — 손 동작은 영상 재구성 결과라 손가락 단위 정밀도 확인 필요

## 🥉 논문 3

**TACROSS: An Efficient and Low-Cost Scalable Human Touch System Across Heterogeneous Tactile Sensors for Dexterous Robot Learning**
[arXiv:2610.11945](https://arxiv.org/abs/2610.11945) · Bo Chen 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — 초록 "We will open-source the TACROSS hardware and software system"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 저가 촉각 장갑의 인간 촉각을 로봇 손에 전이
- **문제** — 로봇 촉각 시연 수집은 비싸고 느림
  - 로봇 원격조작은 약 12,000달러 시스템에서 시간당 40 에피소드
  - 수집 시간 내내 대상 팔·손·센서를 점유하고 리셋·보정 비용 발생
- **기존 한계** — 감지 간극(Sensing Gap)과 액션 간극(Action Gap) 두 가지 지적
  - UniTouch·AnyTouch는 이종 비전 기반 촉각 센서 간 공유 표현을 학습하나, 변환 원리가 다른 압저항 장갑과 정전용량 로봇 손 사이에서는 원채널 직접 대응이 성립하지 않음
  - EgoMimic(도메인 정렬 공동 학습), DexPilot(인간 손 동작의 로봇 손 매핑)처럼 리타깃된 인간 손 동작을 정답 액션으로 쓰면 리타깃팅 오차가 정책에 유입
- **핵심 방법** — 저가 장갑, 접촉 의미 정렬, 로봇 시연 기반 정책 학습의 결합
  - 하드웨어 — 5층 압저항 장갑, 285개 감지점, 약 150Hz, 부품비 10.86달러
  - 정렬 — 유효성 마스크를 가진 캐노니컬라이저가 인간·로봇 신호를 공통 해부학적 접촉장으로 변환하고, 잔차 어댑터가 스케일·노이즈·드리프트·히스테리시스 차이를 보정
  - 인코더 — 손가락 간 어텐션을 쓰는 인과 시간 Transformer로 256차원 공유 촉각 잠재 생성
  - 정책 — ACT 백본, 로봇 시연만 정답 액션, 리타깃된 인간 손 목표는 신뢰도 가중 보조 지도
- **차별점** — 원 센서값이 아닌 접촉 이벤트 수준에서 이종 촉각을 정렬하고, 인간 데이터는 액션 정답이 아닌 보조 지도로만 사용
- **핵심 기여** — 수집 시스템, 정렬·정책 학습, 공개 자원 세 가지
  - 수집 효율 — Ego-R(2,150달러)·Ego-V(520달러)가 시간당 112·140 에피소드로 로봇 대비 2.8배·3.5배, 장비비 82.1%·95.7% 절감
  - 실물 4개 과제(정량 분주, 비커 간 액체 이송, 정밀 피펫팅, 순차 과일 집기)에서 로봇 30 + 인간 150 시연으로 평균 성공률 91.9%, 로봇 전용 51.3%
  - 로봇 시연 15개 고정 시 인간 시연을 0개에서 90개로 늘리면 평균 성공률 32.5%에서 85.6%로 상승
  - ablation — 로봇 30 + 인간 150 설정에서 인간 촉각 입력 제거 시 73.1%, 접촉 의미 정렬 제거 시 49.4%
  - 공개 예정 — 장갑 설계, 로봇 구성, 수집·처리·학습 소프트웨어, 183.95시간 기록(인간 159.09시간, 로봇 24.86시간)
- **가치** — 로봇을 계속 점유하지 않고 촉각 데이터를 늘리는 실용 경로 제시

### (c) 시사점

- 저가 장갑 기반 촉각 데이터 수집 경로
- **접촉 모달리티 코퍼스 후보** — 150시간 이상 인간 촉각 데이터셋 공개 예정
- **센서 통합 참고 설계** — 변환 원리가 다른 촉각 센서 데이터를 접촉 이벤트 수준에서 묶는 방식
- **도입 비용 낮음** — 장갑 부품비가 낮아 자체 수집 시도 부담 작음

### (d) 먼저 확인할 점

## 🌱 논문 4 — 인접 분야 픽

**CE$^4$L: Continual Ego, Exo, and Ego-Exo Learning**
[arXiv:2609.23492](https://arxiv.org/abs/2609.23492) · Hongwei Yan 외 · ICML 2026 · adjacent field: continual learning / PEFT · 코드 공개

**점수 10/15** · R2 · N3 · M3 · Real0 · Repro2 — 초록 "Our source code for benchmarks and methods is available at https://github.com/AnAppleCore/CE4L"

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 에고·엑소 멀티뷰 영상의 지속 학습 벤치마크
- **문제** — 체화 에이전트의 시각 입력은 시간 상관적이고 시점 의존적이나 지속 학습(continual learning, CL) 프로토콜이 이를 반영하지 못함
  - 기존 프로토콜이 강한 시점 편향과 이질적 의미 목표를 추상화해 버림
  - 시점 내 성능은 유지해도 교차 시점 불변성을 잃거나, 평가 시점이 바뀌어 망각처럼 보이는 경우가 얽힘
- **기존 한계** — 기존 CL 벤치마크·방법이 엑소 전용 인식이나 단일 시점 스트림에 치우침
  - vCLIMB(시간 일관성 정규화), Space-time Prompting·PIVOT(학습형 프롬프트), STSP(직교 부분공간 투영) 등 비디오 CL은 단일 시점·고립 인식 과제 중심
  - 이미지 CL 패러다임을 영상으로 늘리는 것만으로는 시점 편향 문제 미해결
- **핵심 방법** — EgoExoLearn 위 4개 CL 벤치마크와 어댑터 기반 기준 방법
  - 과제 — 교차 시점 참조 기술 평가, 시간적 행동 분할, 교차 시점 연관, 행동 예측·계획
  - 프로토콜 — 시점 내 유지, 제로샷 교차 시점 일반화, 멀티뷰 공동 학습 기준을 분리 측정
  - VISTA — 과제별 경량 어댑터를 저장하고, 2차 통계로 추정한 과제별 백색화 부분공간까지의 잔차 거리로 학습 없이 라우팅
- **차별점** — 리플레이 버퍼 없이 부분공간 기하로 과제를 추론하는 파라미터 효율적 기준 방법
- **핵심 기여** — 벤치마크, 방법, 진단 세 가지
  - 망각과 교차 시점 전이 능력을 분리하는 통합 CL 벤치마크(에고, 엑소, 혼합 시점)
  - 어댑터 기반 VISTA, CL 베이스라인 중 전체 최고 성능과 메모리·연산 효율
  - 리플레이·정규화·앙상블 방법의 효능이 과제별로 크게 달라지고, 시점 내 망각이 줄어도 시점 조건 불일치가 남는다는 진단
  - 벤치마크·방법 코드 공개
- **가치** — 체화 비전 CL 평가를 멀티뷰·이질 목표로 넓히는 기준 제공

### (c) 시사점

- 에고 데이터 순차 추가 시 망각을 재는 평가 틀
- **평가 프로토콜 차용** — 에고센트릭 데이터를 단계적으로 추가하는 학습에서 망각과 시점 전이를 분리 측정하는 틀로 활용 가능
- **도입 비용 낮음** — 벤치마크·방법 코드 공개
- **데이터 소스 아님** — 로봇 액션이 없는 인식 과제라 사전학습 코퍼스로 직접 쓰기 어려움

### (d) 먼저 확인할 점

- **코퍼스 단일** — EgoExoLearn 하나 위에 구성, 과제 경계 고정 가정 (저자 명시)
- **범위 밖** — 3D 공간 추론과 종단 의사결정은 다루지 않음, 로봇 결과 없음
- **확장성** — 과제마다 어댑터 하나를 저장해 긴 스트림에서는 병합·압축 필요 (저자 명시)
- **원본 데이터 조건** — EgoExoLearn 접근·라이선스 조건 확인 필요
