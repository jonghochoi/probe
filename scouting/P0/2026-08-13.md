**Ego-OSCAR: Egocentric Open source Stereo CAptuRe System**
[arXiv:2608.08285](https://arxiv.org/abs/2608.08285) · Gunjan Paul, Senthil Palanisamy, Satpal Singh Rathore 외 3인 · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D27](https://img.shields.io/badge/D27-d97706.svg)](#ref-D27)

### (b) 핵심 기여
- 헤드마운트형 스테레오-관성 캡처 장치 신규 공개 — 하드웨어 동기화 글로벌셔터 스테레오 카메라 + 6축 IMU + 온보드 Linux SBC 인코딩 + 실시간 워치독 마이크로컨트롤러로 구성
- 부품 단가 US$200 미만, 상용 부품·3D 프린팅 파츠만으로 제작 가능한 저비용 설계 — Project Aria류 연구용 고사양 장비 대비 진입장벽 대폭 낮춤
- 분산 기여자 네트워크를 통한 크라우드소싱 방식으로 실내 일상 환경에서 카메라당 약 550시간 에고센트릭 스테레오 영상 + 동기화 IMU 수집·공개
- 원본 영상이 아닌 주석 완료 상태로 공개 — 개방형 어휘 자유형 액션 캡션이 녹화 구간 전체를 커버, 프레임별 3D 손 복원 및 세션별 스테레오 캘리브레이션 동반
- 하드웨어 설계·소프트웨어 스택(레코딩 파이프라인, IMU 샘플링 데몬, 시간 동기화 툴, 워치독 펌웨어)·데이터셋 전체를 오픈소스로 공개

### (c) 시사점
- 에고센트릭 축 데이터를 소수 고사양 연구 장비가 아닌 크라우드소싱으로 스케일링하는 대안 경로 제시 — 수집 비용 구조 자체를 낮추는 접근
- 프레임별 3D 손 복원이 기본 주석으로 동반돼 손 추적 데이터 희소성 문제에 직접 기여
- 하드웨어·소프트웨어·데이터 전체 오픈소스 공개로 재현성과 재사용성 모두 확보 — 라이선스·사용성 기준에서도 우호적

### (d) 먼저 확인할 점
- 연구용 고사양 시스템 대비 캡처 정밀도는 낮음을 저자 스스로 명시 — 손 포즈 정확도가 다지 조작 학습에 충분한 수준인지 별도 검증 필요
- 6인 소규모 팀 산출물로 550시간 규모 크라우드소싱 수집·주석 파이프라인의 장기 유지보수·품질관리 체계 확인 필요
- 실내 일상 환경 위주 수집으로 조작 특화 태스크(파지·양손 조작 등) 커버리지 비중은 초록상 불명확 — 실제 다운로드 후 태스크 분포 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**XPolicyLab: A Unified Standard and Open Ecosystem for Robot Policy Evaluation and Deployment**
[arXiv:2608.09892](https://arxiv.org/abs/2608.09892) · XPolicyLab Community, Tianxing Chen, Yue Chen 외 64인 · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여
- 로봇 정책 평가·배포가 모델별 소프트웨어 의존성·데이터 표현·런타임 인터페이스로 파편화되어 N개 정책×M개 평가 환경 연결에 O(NM) 개별 통합이 필요하다는 문제 지적
- 공통 관측·액션·궤적 스키마 + 최소 어댑터 인터페이스(관측 업데이트·액션 예측·배치 실행·에피소드 리셋)를 규격화, 통합 비용을 O(N+M)으로 축소하는 오픈 에코시스템 XPolicyLab 제시
- 정책 추론과 환경 실행을 분리하는 의존성 격리 클라이언트/서버 아키텍처 도입 — 각 측이 자체 소프트웨어 스택을 유지하며 로컬·원격 실행 모두 지원
- 42개 로봇 정책을 통합, 설치·디버깅·서빙·평가 워크플로를 표준화 — 대표 정책 통합 소요시간을 5시간+ → 2시간, 패키지형 에이전트 스킬 적용 시 30분까지 단축
- RoboTwin·RoboDojo 시뮬레이션과 표준화된 실로봇 평가를 동일 인터페이스로 서빙, 재현 가능한 정책 비교·표준화 배포를 위한 공유 인프라로 공개

### (c) 시사점
- 다수 VLA/정책을 다수 평가 환경에 연결할 때의 통합 비용 문제를 정량 지표(시간 단축)로 실증 — 평가 인프라 표준화의 실질적 효용을 수치로 확인 가능
- sim(RoboTwin/RoboDojo)과 실로봇 평가를 하나의 인터페이스로 묶는 설계는 표준화된 벤치마크·이밸 하니스 확보 관점에서 참고 가치 높음
- 67인 규모 커뮤니티 협업 산출물로 다수 로봇 정책 생태계에 걸친 폭넓은 검증을 이미 거친 상태 — 조기 도입 시 벤더 종속 완화 기대

### (d) 먼저 확인할 점
- 초록상 통합 효율성(시간 단축) 지표 중심이며 정책 자체의 태스크 성공률·다지 조작 세부 성능 비교는 불명확 — 조작 태스크 단위 평가 결과 별도 확인 필요
- 42개 통합 정책 목록에 다지 손(multi-finger) 조작 특화 정책이 몇 개나 포함되는지 초록상 불명확
- 대규모 커뮤니티 프로젝트 초기 버전 특성상 어댑터 인터페이스 안정성·버전 호환성 정책 확인 필요
