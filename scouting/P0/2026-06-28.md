## 🥇 논문 1 — 우선순위 ★★★

**Scalable Behavior Cloning with Open Data, Training, and Evaluation**
[arXiv:2606.27375](https://arxiv.org/abs/2606.27375) · Allshire, Singh, Singh, Rashid, Choi, McAllister et al. · source: keyword-sweep (cs.RO+cs.LG, dexterous benchmark)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여

- **ABC-130K: 현존 최대 오픈소스 텔레오퍼레이션 데이터셋** — 3,500시간, 130K 에피소드, 195개 다양한 태스크; 기존 공개 로봇 액션 코퍼스 중 최대 규모
- **완전 오픈소스 스택**: 데이터셋 + 훈련 인프라 + 하드웨어 설정 + 시뮬레이션 파이프라인 전체 공개 — 커뮤니티 공동 기준선 구축 목표
- **400시간 sim-teleop 데이터 + 공동 훈련 레시피**: 시뮬레이션-실환경 상관 실험으로 실제 로봇 배포 전 모델 설계 ablation 가능 경로 제공
- **다지 태스크 실증**: 박스 접기, 지갑 카드 추출 등 정밀 다지 조작 실제 로봇 성공 확인
- **DiT vs VLA 아키텍처 체계적 비교**: Diffusion Transformer와 Vision-Language-Action 모델 비교 분석, 실환경 평가 기반 근거 제공

### (c) 시사점

- **공개 로봇 액션 코퍼스 규모 기준 상향**: OXE·DROID 대비 단일 오픈소스 텔레오퍼레이션 데이터셋 규모 최대 — 사전학습 코퍼스 구성 시 ABC-130K 기준선 확보 필요
- **sim+real 공동 평가 경로**: 400h sim-teleop + 상관 실험 설계로 실제 로봇 실험 전 ablation 가능 → 데이터 수집 효율화 실용 경로
- **하드웨어 공개로 재현 장벽 제거**: 동일 하드웨어로 수집·검증 가능 → 소규모 팀도 동일 평가 환경 구축 가능, 커뮤니티 공동 기준선

### (d) 먼저 확인할 점

- **다지 손 특화 범위**: 195개 태스크가 주로 병렬 그리퍼 중심인지 다지 손(multi-fingered) 특화 태스크 포함 여부 확인 필요
- **라이선스**: 완전 오픈소스이나 구체적 라이선스(Apache-2.0 / CC-BY 등) 확인 필요 (D27 기준)
- **가장 저렴한 확인**: 프로젝트 페이지 → 태스크 목록에서 다지 손재주 항목 포함 여부 + 라이선스 확인 → `catalogs/datasets.md` 추가 여부 판단

## 🥇 논문 2 — 우선순위 ★★★

**Human Universal Grasping**
[arXiv:2606.17054](https://arxiv.org/abs/2606.17054) · Wu, Zhou, Tu, Yan, Guzey, Fouhey · source: keyword-sweep (egocentric manipulation dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24) [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여

- **1M-HUGs: 대규모 에고센트릭 그래스핑 데이터셋** — 스마트 글라스(스테레오 카메라) 기반 수집, 1M 프레임(27.8시간), 6,707개 물체 인스턴스, 41개 건물 — 일상 환경 in-the-wild 스케일
- **HUG-Bench: 표준화 그래스핑 평가 벤치마크** — 90개 미관측 물체, 5개 기하 카테고리, 메트릭-스케일 3D 메시 포함 시뮬레이션 평가 환경
- **플로우 매칭 그래스핑 모델**: RGB+Depth → 손목 이동·회전·MANO 포즈 매개변수 예측 → 다양한 로봇 손으로 제로샷 리타겟팅
- **완전 공개**: 코드·데이터·벤치마크·체크포인트·인터랙티브 데모 모두 공개 (https://grasping.io)

### (c) 시사점

- **에고센트릭 데이터 + 벤치마크 동시 공개**: 27.8h 실제 에고센트릭 데이터 + HUG-Bench 평가 환경 — EgoDex(829h)의 다지 그래스핑 특화 보완재
- **스마트 글라스 기반 in-the-wild 수집**: Apple Vision Pro 수준의 고가 장비 없이 일상 환경 41개 건물에서 수집 — 저비용 에고센트릭 확장 수집 선례
- **제로샷 로봇 그래스핑**: 실제 로봇 환경에서 기존 SOTA 대비 +23%/+34% 성능 향상, 다양한 embodiment 검증

### (d) 먼저 확인할 점

- **손가락 수준 다지 조작 커버리지**: 그래스핑 특화 데이터셋 — 인핸드 조작·도구 사용 등 고자유도 다지 태스크로의 확장 범위 미확인
- **리타겟팅 정확도**: 인간 MANO 포즈 → 로봇 손 관절 변환 시 접촉 충실도·물리 타당성 확인 필요
- **가장 저렴한 확인**: HUG-Bench 90개 물체에서 기존 그래스핑 베이스라인 재현 → EgoDex 결합 시 다지 커버리지 시너지 평가

## 🥇 논문 3 — 우선순위 ★★★

**Wh0: Generative World Models as Scalable Sources of Egocentric Human Hand Manipulation Data**
[arXiv:2606.22136](https://arxiv.org/abs/2606.22136) · Chen, Chen, Wang, Li, Huo, Shi et al. · source: keyword-sweep (egocentric manipulation dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **생성형 세계 모델을 에고센트릭 데이터 소스로 활용**: 언어·물체·장면 조건으로 WM-H(50k 에피소드 에고센트릭 인간-손 조작 영상) 생성 — 정적 데이터셋 수집 없이 다양성 스케일 가능
- **세 갈래 트레이드오프 해소**: 텔레오퍼레이션(고비용) / 시뮬레이션(Sim2Real 갭) / 실제 에고센트릭(embodiment 불일치) 각각의 한계를 생성 모델 + 손 동작 재구성 + 시각 편집 결합으로 우회
- **18개 실세계 다지 조작 태스크 검증**: 제로샷 성공률 8.3% → 38.9% 향상 (로봇 데이터만 사용 대비)
- **오픈소스 코드 공개**

### (c) 시사점

- **"생성 → 에고 영상 변환 → 로봇 사전학습" 패러다임 선례**: Do as I Do / EgoInfinity(지난 리포트)가 인터넷 실제 영상 변환에 집중했다면, Wh0는 생성 세계 모델을 데이터 소스로 쓰는 보완적 경로 — 에고 데이터 생태계의 "세 번째 경로" 확립
- **장면·물체 다양성 스케일 가능**: 생성 모델 조건으로 물체·장면을 임의 지정 → 수집 커버리지 병목 구조적 해소 잠재력
- **소량 실제 로봇 데이터 공동 훈련**: WM-H 대규모 + 실제 로봇 데이터 소량 공동 훈련 → 수집 비용 대비 효과 극대화 경로

### (d) 먼저 확인할 점

- **생성 데이터 물리 일관성 한계**: 생성 세계 모델의 물리 타당성 — 복잡 접촉(인핸드 회전, 정밀 삽입) 시나리오에서 생성 데이터 품질 저하 가능
- **WM-H 데이터셋 공개 범위**: 생성 코드·파이프라인은 오픈소스이나 원본 에고 영상 공개 여부·라이선스 별도 확인 필요
- **가장 저렴한 확인**: 프로젝트 페이지 → WM-H 생성 파이프라인 재현 → EgoDex 또는 AgiBot World 공동 훈련 시너지 평가

## 🥈 논문 4 — 우선순위 ★★

**ForceBand: Learning Forceful Manipulation with sEMG**
[arXiv:2606.26093](https://arxiv.org/abs/2606.26093) · He, Wang, Kuang, Ghosh, Malik, Fermuller et al. (UC Berkeley, UMD) · source: keyword-sweep (cs.RO, tactile force sEMG dataset)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25) [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **sEMG 기반 손가락별 힘 주석 파이프라인 최초**: 손목 착용형 저비용 sEMG 시스템 → 인간 근활동 신호 → 손가락별 힘 예측 → 데모 데이터에 힘 레이블 자동 부착
- **10시간 멀티모달 데이터셋**: 에고센트릭 비디오 + sEMG + IMU + 손가락 끝 힘 측정 — 다양한 동작·물체 대상 수집
- **EMG2Force 모델 사전학습 + 단기 사용자별 캘리브레이션**: 비전 기반 베이스라인 대비 힘 예측 오류 50%+ 감소, 실세계 집기·누르기·놓기 태스크 87% 성공률
- **저비용 수집 확장 설계**: 별도 집기·테이블 설비 없이 ForceBand 착용만으로 임의 태스크 시연 중 힘 레이블 자동 획득

### (c) 시사점

- **D25 "힘 레이블 부재" 공백 저비용 해소 경로**: RH20T(손목 6축 F/T 전용)와 달리 일반 인간 데모 수집 파이프라인에 손가락별 힘 주석을 사후 부착 가능 — 기존 에고센트릭 코퍼스 재활용 경로
- **Jitendra Malik 그룹 연속 기여**: Do as I Do(2606.19333, 이전 리포트)와 동일 그룹 — 에고센트릭 인간 데이터 활용 전략의 연속적 구체화
- **sEMG+에고 비디오 조합**: 에고 비전 단독 힘 추정 대비 정확도 향상 — 수집 파이프라인의 sEMG 통합 고려 근거

### (d) 먼저 확인할 점

- **10h 데이터셋 공개 여부·라이선스**: 프로젝트 페이지(https://forceband-emg.github.io) 확인 필요 — 데이터 공개 URL 및 라이선스 미확인 (D27 기준)
- **sEMG 하드웨어 접근성**: 착용형 sEMG 밴드의 상용화 수준·비용·데이터 전송 지연 확인 필요
- **가장 저렴한 확인**: 프로젝트 페이지 → 데이터셋 공개 URL + sEMG 밴드 모델 정보 + 라이선스 확인 → D25 촉각 코퍼스 카탈로그 추가 가능성 판단

## 🥈 논문 5 — 우선순위 ★★

**HumanScale: Egocentric Human Video Can Outperform Real-Robot Data for Embodied Pretraining**
[arXiv:2606.20521](https://arxiv.org/abs/2606.20521) · Ma, Bi, Deng, Zhai, Zhang, Huang et al. · source: curated-list sweep (awesome-vla-wam)

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여

- **에고센트릭 비디오 > 텔레오퍼레이션 데이터 체계적 최초 증명**: 고정 후처리·검증 프로토콜 하에서 두 데이터 소스를 정량 비교 — 에고 데이터가 로봇 데이터를 성능에서 능가한다는 첫 체계적 실증
- **핵심 수치**: 동량 데이터 기준 에고 사전학습 모델이 실제 로봇 액션 예측 검증 손실 24% 감소, 분포 내 태스크 성공률 52.5% 향상, 분포 외 태스크 90% 향상
- **필터링+레이블링 파이프라인 설계**: 원시 에고센트릭 비디오를 효과적 사전학습 소스로 가공하는 처리 경로 제시 — "어떤 에고 비디오가 유효한가"에 대한 실용적 답변

### (c) 시사점

- **D24 에고센트릭 우선 데이터 축의 가장 강력한 정량 실증**: What Matters Cotraining(2606.06627, 2026-06-10)이 +29.7% 향상을 보였다면, HumanScale은 에고 데이터가 로봇 데이터를 구조적으로 앞선다는 패러다임적 근거 제공
- **"에고 사전학습 → 소량 로봇 적응" 패러다임 명확화**: 기존 로봇 데이터 중심 사전학습 패러다임에 대한 체계적 반론 — 데이터 수집 전략 우선순위 재설정 근거
- **OOD 일반화 90% 향상**: 분포 외 태스크에서의 성능 향상 — 다양한 다지 조작 환경 일반화를 위한 에고 사전학습 전략 강화 논거

### (d) 먼저 확인할 점

- **필터링+레이블링 파이프라인 공개 여부**: 파이프라인 설계가 핵심 기여이나 코드 공개 여부 초록에서 미확인
- **실험에 사용한 에고 코퍼스 규모·출처**: EgoDex(829h)/Ego4D(3,670h) 수준인지 — 스케일 효과 외삽 범위 확인 필요
- **가장 저렴한 확인**: 전문 확인 → 파이프라인 코드 공개 URL + 사용 에고 코퍼스 출처 + 라이선스 확인
