## 🥇 논문 1 — 우선순위 ★★★

**RoboDojo: A Unified Sim-and-Real Benchmark for Comprehensive Evaluation of Generalist Robot Manipulation Policies**
[arXiv:2607.04434](https://arxiv.org/abs/2607.04434) · Tianxing Chen, Yue Chen, Zixuan Li, Junyuan Tang, Kailun Su, Haoran Lu, Weijie Wan, Baijun Chen · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26)

### (b) 핵심 기여
- 시뮬레이션(Isaac Sim, 42 태스크) + 실로봇(18 태스크)을 통합한 generalist 조작 정책 평가 벤치마크
- 일반화·메모리·정밀도·장기 수행·개방형 지시 이행 5개 평가축을 분리 측정하는 프로토콜
- RoboDojo-RealEval — 원격 클라우드 접속 지원 실로봇 재현 평가 시스템, 표준 하드웨어·씬 리셋·배포 인터페이스 포함
- XPolicyLab을 통해 정책 1회 통합으로 sim/real 양쪽 평가 가능, 공개 리더보드에 30개 정책 등재·비교

### (c) 시사점
- 정책 평가 표준 벤치마크 확보 — 자체 sim/real 벤치마크 구축 비용 대체 가능
- 5축 분리 평가 프로토콜, 정책 실패 원인(정밀도 vs 장기 수행 vs 일반화)을 구조적으로 진단
- 원격 실로봇 평가 인프라 — 로컬 하드웨어 부재 상태에서도 실로봇 검증 경로 확보

### (d) 먼저 확인할 점
- sim 42 + real 18 태스크 구성이 다지 손 접촉·촉각 특화 과제를 포함하는지 세부 태스크 목록 확인 필요
- XPolicyLab 통합 인터페이스가 커스텀 정책 아키텍처와 호환되는지 최소 통합 비용 점검
- 공개 리더보드 점수의 재현성(동일 정책 재평가 시 분산) 확인

## 🥈 논문 2 — 우선순위 ★★

**WatchAct: A Benchmark for Behavior-Grounded Robot Manipulation**
[arXiv:2606.26443](https://arxiv.org/abs/2606.26443) · Baiqi Li, Ce Zhang, Yu Fang, Yue Yang, Shangzhe Li, Mingyu Ding, Gedas Bertasius · source: citation-graph

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D26](https://img.shields.io/badge/D26-d97706.svg)](#ref-D26) [![D24](https://img.shields.io/badge/D24-d97706.svg)](#ref-D24)

### (b) 핵심 기여
- 실제 인간 행동 영상 + 언어 지시 + 정렬된 시뮬레이터 씬 + 실행 가능 LIBERO 태스크를 짝지은 벤치마크
- 이벤트 파싱·절차 추론·암묵적 의도 추론·씬 변화 추적 4개 인지 영역, 14개 태스크·3,000개 장기 수행 인스턴스
- 영상→계획(VLM) 추론 / oracle 계획 하 정책 실행 / 통합 planner-policy 전체 완수, 3단계로 분리한 평가 프로토콜
- Franka Research 3 실로봇 + 시뮬레이션 양쪽에서 SOTA 파이프라인(Gemini-3.1-Pro + π0.5) 성능 정량화, 성공률 각각 16.3%(sim)·14.0%(real)로 현 시스템 한계 노출

### (c) 시사점
- 인간 시연 영상을 지시문이 아닌 관찰 대상으로 삼는 벤치마크 축 확보 — 언어만으로 부족한 절차·의도 정보 평가 가능
- VLM 계획 단계와 정책 실행 단계를 분리 측정하는 프로토콜, 파이프라인 병목 진단에 참고 가능
- 데이터셋·코드 공개로 재현 가능한 비교 기준점 확보

### (d) 먼저 확인할 점
- "인간 행동 영상"이 에고센트릭 시점인지 3인칭 촬영인지 논문 본문 확인 필요 (초록상 명시 없음)
- LIBERO 기반 시뮬레이터 태스크가 다지 손 접촉 조작을 포함하는지, 병렬 그리퍼 중심인지 확인
- 성공률이 매우 낮아(14~16%) 벤치마크 난도가 현 정책 세대에 과도한지, 평가축별 변별력이 있는지 점검

## 🥉 논문 3 — 우선순위 ★

**Deform360: A Massive Multi-view Visuotactile Dataset for Deformable World Models**
[arXiv:2607.05390](https://arxiv.org/abs/2607.05390) · Hongyu Li, Wanjia Fu, Xiaoyan Cong, Zekun Li, Binghao Huang, Hanxiao Jiang, Xintong He, Yiqing Liang · source: citation-graph + keyword-sweep

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D25](https://img.shields.io/badge/D25-d97706.svg)](#ref-D25)

### (b) 핵심 기여
- 변형 가능 물체 198종, 상호작용 시퀀스 1,980개, 215시간 이상 관측 규모의 대형 비주오택타일 데이터셋
- 41대 서라운드뷰 카메라 + 양손 촉각 그리퍼로 전역 움직임과 접촉 유발 국소 변형을 동시 포착
- 마커리스 비주오택타일 3D 트래킹 파이프라인으로 조밀 기하·모션 정보 추출
- 2D 픽셀 공간 vs 3D 기하 공간 월드 모델 패러다임을 동일 데이터로 정량 비교, 구조적 사전 지식과 확장성 간 트레이드오프 분석

### (c) 시사점
- 희소한 촉각/힘 모달리티 데이터축에 대형 규모 신규 후보 추가 — 변형체 조작 특화 하위 축 확보
- 2D vs 3D 월드 모델 비교 분석, 자체 월드 모델 설계 방향 결정에 참고 가능
- 마커리스 트래킹 파이프라인 — 향후 자체 촉각 데이터 수집 시 라벨링 비용 절감 참고 가능

### (d) 먼저 확인할 점
- 데이터셋·코드 공개 범위(라이선스, 다운로드 경로)가 초록에 명시 없어 실사용 가능성 확인 필요
- "예비 시연(preliminary demonstration)" 수준의 로봇 플래닝 검증만 제시 — 조작 정책 학습에 바로 활용 가능한지 별도 검증 필요
- 변형체 특화 데이터라 일반 강체 다지 조작 축과는 별도 트랙으로 취급해야 하는지 판단 필요
