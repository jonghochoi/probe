## 🥈 논문 1 — 우선순위 ★★

**RoboEdit: Turning Human Manipulation Videos into Scalable Robot Experience**
[arXiv:2608.18948](https://arxiv.org/abs/2608.18948) · Yaowei Guo, Zeng Tao, Yuxin Jiang 외 7인 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 핵심 기여
- 로봇 손-객체 상호작용 데이터 수집은 고비용·임베디먼트 종속적인 반면 풍부한 인간-객체 비디오는 그대로 로봇 학습에 활용 불가하다는 공백 지적
- 인간 조작 비디오를 행동-일관적이고 물리적으로 그럴듯한 로봇 비디오로 변환하는 human-to-robot 비디오 편집 스위트 RoboEdit 신규 제시
- RGB 비디오에서 3D 상호작용을 복원·재타겟팅하는 자동 파이프라인 RoboEdit-ADC로 7개 로봇 임베디먼트·다양한 장면·상호작용 유형을 아우르는 174K쌍(14M 프레임) 규모 대규모 데이터셋 RoboEdit-14M 생성
- 크로스임베디먼트 적응 모듈로 시간적 일관성을 유지하며 외형·모션을 적응시키는 편집 엔진 RoboEdit-Trans, 프레임별 손 상태를 복원하는 3D Robot-State Decoder 결합
- 편집 품질에서 최신 기법 대비 우수한 성능 확인, 실환경 조작 태스크에서 다운스트림 로봇 제어 정책 학습 지원까지 실증

### (c) 시사점
- 에고센트릭 인간 조작 비디오를 로봇 학습 자원으로 전환하는 브리징 계층에 비디오 단위(이미지 아님) + 3D 손 상태 지도 결합이라는 신규 자원 추가 — 리타겟팅 파이프라인 데이터 소스 확장에 참조 가능
- 174K쌍·7개 임베디먼트 규모는 크로스임베디먼트 학습 자원으로 이례적 스케일 — 자체 임베디먼트 전이 실험 설계 시 참조 가치
- 3D Robot-State Decoder로 프레임별 손 상태를 구조화 지도 신호로 제공하는 설계는 데이터 파이프라인의 감독 신호 설계에 참조 가능

### (d) 먼저 확인할 점
- 공개 저장소·데이터 다운로드 경로가 초록·arXiv comment 모두에 명시되지 않음 — 실제 공개 여부 별도 확인 필요
- 편집 품질·다운스트림 정책 성능의 구체적 정량 비교(베이스라인 대비 수치)는 초록 수준에서 제시되지 않음 — 본문 확인 필요
- 다지 손(multi-finger) 임베디먼트가 7개 로봇 임베디먼트에 포함되는지 초록상 불명확 — 다지 조작 적용성 별도 확인 필요
