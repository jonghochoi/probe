## 🥇 논문 1 — 우선순위 ★★★

**PLUME: Probabilistic Latent Unified World Modeling and Parameter Estimation for Multi-Finger Manipulation**
[arXiv:2606.11396](https://arxiv.org/abs/2606.11396) · Abhinav Kumar, Soshi Iba, Rana Soltani Zarrin, Dmitry Berenson · source: keyword-sweep (world model + dexterous)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D31](https://img.shields.io/badge/D31-d97706.svg)](#ref-D31) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **문제** — 다지 손 조작은 물체 형상·포즈·마찰 계수 등 미지 물리 파라미터에 민감; 도메인 랜덤화(DR)만으로 정밀 작업(나사 돌리기 등) 대응 불충분
- **모델 PLUME** — 물리 파라미터 믿음(belief) 업데이트와 액션-조건부 동역학(action-conditioned dynamics)을 하나의 공동 잠재 공간에서 반복 정제하는 확률론적 세계 모델
- **온라인 파라미터 추론** — 재훈련·파인튜닝 없이 배포 시점 실제 동역학에 정렬; 파라미터 별 조작 전략 적응 가능
- **평가 범위** — 시뮬레이션 나사 돌리기·밸브 회전·버킷 들기·디스크 튕기기 4종 + 실 하드웨어 나사 돌리기 제로샷 이전(zero-shot transfer)
- **우위** — 오프라인 RL + WM-증강 행동 복제(BC) 기준선 대비 성능 우월; 하드웨어 이전 성공

### (c) 시사점

- **잠재 공간 물리 파라미터 통합** — 물체 마찰·형상 불확실성을 세계 모델 잠재 공간 내 명시적 믿음으로 표현하는 방식; 기존 JEPA형 잠재 예측 세계 모델이 다루지 않던 파라미터 불확실성 처리 경로 제시
- **다지 손 실하드웨어 제로샷 이전 성공** — 시뮬레이션 훈련 정책이 실 하드웨어 나사 돌리기에 제로샷 이전 성공; 정밀 접촉 집약적 다지 조작에서 잠재 세계 모델의 실적 증거
- **설계 확장 방향** — 인핸드 조작·다지 손 파지에서의 접촉 파라미터(마찰·순응성) 불확실성을 세계 모델 잠재 공간에 포함하는 아이디어; 에고센트릭 데이터 기반 세계 모델과 결합 시 시너지 가능성

### (d) 먼저 확인할 점

- **손가락 구성 확인** — 평가 환경의 손가락 수·하드웨어 플랫폼 세부 사항 본문 확인 필요
- **온라인 추론 지연** — 믿음 업데이트 반복 계산 비용; 실시간 폐루프 제어(< 20 ms 사이클) 적용 가능 여부 미확인
- **자기중심 시점 의존성** — 에고센트릭 카메라 전제 여부·다시점 입력 필요성 확인 필요; DexWM과 동일 에고센트릭 설정인지 미확인

## 🥈 논문 2 — 우선순위 ★★

**World Pilot: Steering Vision-Language-Action Models with World-Action Priors**
[arXiv:2606.12403](https://arxiv.org/abs/2606.12403) · Zefu Lin, Rongxu Cui, Junjia Xu, Xiaojuan Jin, Wenling Li, Lue Fan, Zhaoxiang Zhang · source: citation-graph (World Guidance, Being-H0.7)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29)

### (b) 핵심 기여

- **동기** — VLA의 사전학습은 정적 이미지-텍스트 쌍 기반; 연속 접촉 동역학 미포착 → WAM(World-Action Model) 사전으로 보완
- **이중 경로 조향** — Latent Steering: 지각 레이어에 장면 진화 잠재 벡터 조건화 / Action Steering: 예측 궤적을 모션 사전(prior)으로 액션 생성기에 주입
- **사전훈련 WM 재사용** — 액션 사후훈련 없이 비디오 사전훈련 WM만으로도 Latent Steering 효과 유지; WAM 없이도 단독 비디오 WM 활용 가능
- **성능** — LIBERO-Plus 제로샷 OOD 84.7% 달성(SOTA); 뷰포인트·기하·변형 상태·포즈 변화 4가지 실로봇 태스크 전반 최고 성공률

### (c) 시사점

- **WAM→VLA 이중 주입 패턴 구체화** — 세계 모델 잠재 벡터를 VLA 인지 레이어와 액션 생성기 두 지점에 동시 주입하는 설계 패턴; Being-H0.7 스타일 잠재 world-action 공동훈련과 병합 검토 가능
- **비디오 WM 재사용 경로 확인** — 액션-사후훈련 없는 비디오 WM도 VLA 지각 조향에 유효; 기존 보유 비디오 사전훈련 자산을 추가 훈련 없이 즉시 활용하는 경로
- **OOD 평가 기준점** — 제로샷 OOD 4종(뷰포인트·기하·변형·포즈)이 세계 모델 통합 아키텍처 비교 기준으로 활용 가능

### (d) 먼저 확인할 점

- **이중 경로 간섭 여부** — Latent·Action 두 조향 경로가 서로 간섭하는지; 각 경로 단독 기여 분리 실험 본문 확인 필요
- **다지 손 환경 적용 확인** — LIBERO-Plus는 범용 매니퓰레이션; 다지 손·접촉 집약적 태스크 결과 및 WAM 선택 민감도 본문 확인 필요
- **WAM 공급원 민감도** — 어떤 비디오 WM을 사용하느냐에 따른 성능 편차 수준 미확인

## 🥈 논문 3 — 우선순위 ★★

**LUCID: Learning Embodiment-Agnostic Intent Models from Unstructured Human Videos for Scalable Dexterous Robot Skill Acquisition**
[arXiv:2606.11628](https://arxiv.org/abs/2606.11628) · Harsh Gupta, Guanya Shi, Wenzhen Yuan · source: citation-graph (DexWM)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **목적** — 고비용 로봇 시연 없이 인터넷 규모 비구조화 인간 동영상(unstructured human video)에서 다지 손 로봇 스킬 습득
- **2단계 구조** — (1) 인간 동영상에서 embodiment-agnostic 단기 인텐트(intent: 장면의 다음 상태 예측) 모델 학습 → (2) 대규모 병렬 시뮬레이션에서 구현-별 센서리모터 정책이 인텐트를 로봇 액션으로 변환
- **인터페이스 공유** — 동일 인텐트 모델이 다지 손·그리퍼 등 여러 embodiment에 공통 적용; 시각 인텐트 표현이 embodiment 경계 돌파
- **실로봇 5종 평가** — 젓기·닦기·버리기(인터넷 동영상 감독) + 밀기-T·케이블 연결(셀프 수집 스마트폰 동영상 각 1시간); 새 장면·물체 제로샷 이전

### (c) 시사점

- **인터넷 규모 자기중심 인간 동영상이 다지 손 WM 데이터원으로 실용** — 5가지 실로봇 태스크로 확인; DexWM 계열 데이터 파이프라인과 직접 비교 가능한 공개 기준점
- **Embodiment-agnostic 인텐트 → 다지 손·그리퍼 공통 인터페이스** — 손 조작 전용 세계 모델의 embodiment 범용화 방향 구체적 시사
- **데이터 수집 비용 하한** — 스마트폰 동영상 1시간으로 케이블 연결 학습; 인핸드 조작 데이터셋 구축 최소 비용 참고치

### (d) 먼저 확인할 점

- **인텐트 예측의 WM 수준 확인** — 시각 인텐트 예측이 액션-조건부 잠재 동역학(closed-loop action conditioning)인지 단순 관측 기반 예측인지 본문 확인 필요; 후자라면 Anti-topic 경계에 근접
- **접촉 집약적 정밀 태스크 일반화** — 젓기·닦기 수준 접촉 vs. 핑거 키포인트 세밀 제어 필요 인핸드 조작 태스크 적용 가능 여부 미확인
- **시뮬레이션 의존성** — embodiment-specific 정책은 대규모 병렬 시뮬레이션 훈련 전제; 시뮬레이션 없는 직접 실로봇 훈련 경로 부재

## 🥉 논문 4 — 우선순위 ★

**Making Foresight Actionable: Repurposing Representation Alignment in World Action Models**
[arXiv:2606.12217](https://arxiv.org/abs/2606.12217) · Lu Qiu, Yizhuo Li, Yi Chen, Yuying Ge, Yixiao Ge, Xihui Liu · source: citation-graph (WorldVLA)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29)

### (b) 핵심 기여

- **진단** — WAM 비디오 재구성 최적화 숨은 상태(hidden state)가 저수준 액션 제어에 필요한 표현 형태와 불일치 — "표현 불일치(representation mismatch)" 경험적 확인
- **원인** — 액션 디코더가 과제-관련 상호작용 영역에 집중 실패; 과제-무관 배경에 민감; 어텐션 분석 + 인과 개입(causal intervention) 실험으로 규명
- **AGRA** — Action-Grounded Representation Alignment: 비디오 디퓨전 중간 피처를 비주얼 인코더의 공간 일관 시맨틱 표현에 정렬하는 보조 목표(auxiliary objective)
- **실로봇 검증** — 실세계 매니퓰레이션 태스크에서 객체 위치 파악·어포던스 이해 향상 + OOD 일반화 개선 확인

### (c) 시사점

- **세계 모델 통합 시 WM-액션 인터페이스 핵심 병목 규명** — 시각 재구성 최적화 표현이 액션 제어에 부적합하다는 경험적 진단; 세계 모델 통합 아키텍처 설계 시 WM-액션 인터페이스 선택 기준 보강 근거
- **경량 보조 목표로 기존 WAM 개선** — 세계 모델 구조 변경 없이 정렬 목표 추가만으로 효과; Being-H0.7 스타일 잠재 world-action 공동훈련에 플러그인 적용 가능성
- **어텐션 분석 진단 방법론 재사용 가능** — 액션 헤드 어텐션 + 인과 개입 실험 프레임워크가 다른 WM 통합 아키텍처 사후 진단 도구로 활용 가능

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 환경 특화 검증 부재** — LIBERO 계열 범용 태스크 기반; 손-물체 정밀 접촉 환경 적용 여부 본문 확인 필요
- **기반 WAM 의존성** — 어느 WAM 구조에서 "표현 불일치"가 발생하는지; 잠재 공간 설계가 다른 WM(VLA-JEPA 등)에서도 동일 현상 여부 미확인
- **정렬 트레이드오프** — 시각 재구성 품질과 액션 유용성 간 정렬 트레이드오프 정량화 미확인
