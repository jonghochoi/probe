## 🥇 논문 1 — 우선순위 ★★★

**Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2606.08737](https://arxiv.org/abs/2606.08737) · Yunfan Lou, Yifan Ye, Yankai Fu et al. · source: citation-graph (WorldVLA 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D31](https://img.shields.io/badge/D31-d97706.svg)](#ref-D31)

### (b) 핵심 기여
- 미래 시각 관측·촉각 신호·행동을 하나의 diffusion transformer 로 공동 예측하는 통합 촉각-세계 액션 모델 제안
- 접촉 시점에만 촉각 신호를 선택적으로 결합하는 contact-gated visuotactile fusion 설계
- 접촉 상태에 따라 시각-촉각 교차 주의를 조절하는 contact-aware attention bias 도입
- 학습 2.9배·추론 1.8배 가속하는 dual-level 가속 전략 결합, 실시간 배포 지향
- 접촉 집약적 실제 로봇 태스크 6종에서 행동 정확도 평균 31.7% 개선, 공식 코드 공개

### (c) 시사점
- 접촉 정보를 시각 예측과 별도 모달리티로 명시 모델링하는 방식이 순수 시각 기반 예측 대비 뚜렷한 성능 이득 확보
- 접촉 게이팅·주의 편향 설계는 촉각 신호를 상시 융합하지 않고 필요 시점에만 선택적으로 반영해 계산 낭비 억제
- 학습·추론 가속 전략은 세계 모델 기반 예측을 폐루프 제어 주기 안에 넣을 때의 지연 우려를 완화하는 구체적 사례 제공

### (d) 먼저 확인할 점
- 6개 태스크 모두 단일 로봇 플랫폼(Franka) 기반 — 손가락 자유도가 높은 다지 핸드로 확장 시 촉각 센서 배치·해상도 재검증 필요
- 접촉 게이트가 프레임 단위 촉각 변화량에 의존 — 미끄러짐처럼 점진적으로 변하는 접촉 이벤트에서 게이트 민감도 검증 필요
- 기반 아키텍처(Cosmos Policy)에 대한 의존도가 높아 자체 백본으로 이식 시 성능 재현 여부 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**ImageWAM: Do World Action Models Really Need Video Generation, or Just Image Editing?**
[arXiv:2606.19531](https://arxiv.org/abs/2606.19531) · Yuyang Zhang, Wenyao Zhang, Zekun Qi et al. · source: citation-graph (Ctrl-World / VLA-JEPA 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- 비디오 생성 기반 세계 액션 모델의 다중 프레임 예측 비용 문제를 지적하고, 사전학습된 이미지 편집 모델을 행동 예측에 재활용하는 ImageWAM 제안
- 목표 프레임 하나만 변환을 모델링하는 이미지 편집이 행동과 무관한 시공간 디테일 낭비 없이 행동-관련 변화에만 집중한다고 주장
- 추론 시 목표 프레임을 디코딩하지 않고, 이미지 편집 디노이징 과정의 KV 캐시를 flow-matching 행동 전문가의 조건으로 직접 사용
- 시뮬레이션·실제 환경 실험에서 비디오 기반 WAM 대비 동등 이상 성능, FLOPs 1/6·지연 1/4로 대폭 경량화
- 주의 분석으로 편집 캐시가 실제 행동-관련 변화 영역에 집중함을 확인, 학습·평가 코드 및 체크포인트 공식 공개

### (c) 시사점
- 미래 예측을 반드시 비디오(다중 프레임) 형태로 생성해야 한다는 전제에 대한 구체적 반증 사례 확보
- 이미지 편집이라는 기존 대규모 사전학습 자산을 세계 모델 학습에 재활용하는 경로는 자체 사전학습 비용 절감 가능성 시사
- 목표 프레임 디코딩을 생략하고 중간 표현(KV 캐시)만 사용하는 설계는 지연시간 민감 파이프라인에 참고할 만한 패턴

### (d) 먼저 확인할 점
- 비교 대상 비디오 기반 WAM이 최신·최강 베이스라인인지, 벤치마크 선정에 유리한 비교군 편향 가능성 점검 필요
- 이미지 편집 프라이어가 정적 목표-변환 중심이라 다단계·장시간 접촉 상호작용의 동역학 표현력이 충분한지 별도 검증 필요
- 실제 환경 실험의 구체적 태스크 수·난이도가 시뮬레이션 대비 상대적으로 얕게 보고됐을 가능성, 본문 확인 필요

## 🥉 논문 3 — 우선순위 ★

**WALL-WM: Carving World Action Modeling at the Event Joints**
[arXiv:2606.01955](https://arxiv.org/abs/2606.01955) · Shalfun Li, Victor Yao, Charles Yang et al. · source: citation-graph (WorldVLA 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29)

### (b) 핵심 기여
- 고정 길이 액션 청크 단위 최적화 대신, 의미적으로 일관된 "행동 이벤트"를 학습의 최소 단위로 삼는 이벤트-정합 세계 액션 모델 제안
- 언어(의미적 목표·이벤트)·시각(연속적 장면 동역학)·행동(제어 시간축) 세 모달리티의 시간 단위 불일치 문제를 이벤트 경계 정렬로 해소
- 이벤트 수준 캡션·클러스터 균형 샘플링으로 구성한 데이터 생태계와 결합, 다양한 행동·장면·태스크에 걸친 확장 가능한 학습 지원
- 동일 이벤트-사전학습 백본에서 가변 길이 이벤트 모드와 고정 길이 청크 모드(Staircase Decoding)를 모두 지원하는 이중 추론 구조
- 대규모 사전학습 인프라(Muon 옵티마이저)와 결합해 실제 환경 일반화 평가에서 최고 성능 달성, 팀 공식 코드 저장소에 후속 공개

### (c) 시사점
- 미래 예측·행동 생성의 시간 단위를 "고정 청크"가 아닌 "의미적 이벤트"로 재정의하는 접근은 세계 모델 통합 방식의 대안적 축 제공
- 언어-시각-행동 간 시간 단위 불일치를 명시적 문제로 지목한 프레이밍은 향후 통합 아키텍처 설계 시 참고할 만한 진단 기준
- 이벤트 단위 데이터 큐레이션(캡션·클러스터 균형)은 대규모 확장 시 데이터 파이프라인 설계에 참조 가능

### (d) 먼저 확인할 점
- "이벤트" 경계 정의·주석 방식이 본문에 구체적으로 어떻게 자동화되는지, 수작업 의존도 확인 필요
- 실제 환경 일반화 평가의 태스크 구성이 손-객체 상호작용·다지 조작에 특화됐는지, 아니면 범용 조작 전반인지 본문 확인 필요
- 코드 저장소가 팀의 기존 범용 VLA 인프라(base stack) 위에 이 논문 전용 재현 자산을 얼마나 완전히 포함하는지 별도 확인 필요
