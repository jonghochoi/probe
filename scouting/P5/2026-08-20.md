## 🥇 논문 1 — 우선순위 ★★★

**RynnWorld-Teleop: An Action-Conditioned World Model for Digital Teleoperation**
[arXiv:2607.06558](https://arxiv.org/abs/2607.06558) · Haoyu Zhao, Xingyue Zhao, Hangyu Li, Biao Gong, Kehan Li, Siteng Huang et al. · Alibaba DAMO Academy · arXiv preprint · source: carry-forward 재검토 승격(2026-08-06 리포트에서 재현성 미달로 탈락, 이번 런 GitHub 저장소 공개 확인) · 코드 공개

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32) [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28)

### (b) 핵심 기여
- 물리적 원격조작을 완전히 우회하는 **디지털 텔레오퍼레이션** 패러다임 — 실제 로봇 대신 생성형 world model로 대체해 데이터 수집을 하드웨어·작업공간 제약에서 분리
- 오퍼레이터의 손-자세(hand-pose) 스트림이 로봇 중심 생성형 world model을 구동, 단일 참조 이미지로부터 고충실도 에고센트릭 비디오 합성
- 기록된 손-자세 스트림을 임베디먼트에 무관한 행동 라벨로 취급, 표준 리타게팅으로 임의 로봇에 전이 — 완전한 state-action 궤적을 물리 하드웨어 없이 확보
- depth-aware skeletal conditioning, human-to-robot 점진 학습, streaming autoregressive distillation을 결합해 단일 H100에서 40+ FPS 실시간 생성 달성
- 생성 데이터만으로 학습한 정책이 다지·양손 태스크에서 효과적인 zero-shot Sim2Real 전이 달성, 실환경 데이터에 증강 시 성공률 일관되게 향상
- GitHub 저장소 공개 확인

### (c) 시사점
- 텔레오퍼레이션 하드웨어·오퍼레이터 시간 병목을 world model로 정면 우회하는 데이터 엔진 레시피 — 손 중심 에고센트릭 데이터 확보 파이프라인과 직접 비교 가능
- 임베디먼트-무관 행동 라벨 설계라 사내 리타게팅 파이프라인에 바로 대입 가능한 형태
- 생성 데이터 단독 학습으로도 zero-shot 실환경 전이가 보고돼, 실물 로봇 수집량이 부족한 초기 단계에서 대체·보완 데이터원으로 검토 가치

### (d) 먼저 확인할 점
- "효과적인 zero-shot 전이"·"성공률 향상"이 abstract 수준에서는 정성적 서술에 가까워 구체 태스크 수·성공률 수치는 본문 확인 필요
- 손-자세 스트림 추출 및 리타게팅 정확도가 다지 조작의 미세 접촉(핀치, 파지 안정성) 수준까지 보존되는지 별도 검증 필요
- 가장 저렴한 전이 확인: 공개 저장소로 자사 손-자세 캡처 파이프라인 출력을 입력 삼아 소규모 에고센트릭 합성 데이터부터 재현

## 🥈 논문 2 — 우선순위 ★★

**EgoWAM: World Action Models Beyond Pixels with In-the-Wild Egocentric Human Data**
[arXiv:2607.08436](https://arxiv.org/abs/2607.08436) · Baoyu Li, Xinchen Yin, Mengying Lin, Yixin Zhang, Danfei Xu · Georgia Tech · arXiv preprint · source: citation-graph(VLA-JEPA 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- 에고센트릭 인간 데이터의 행동복제(behavior cloning) 학습이 전이 가능한 물체·장면·과제 의미와 전이 불가능한 인간 신체·머리 움직임·행동 스타일을 뒤섞는 문제를 정면 겨냥
- 정책 백본·액션 헤드·데이터 믹스를 고정한 채 world prediction target만 Pixel·DINO·3D motion flow 세 가지로 바꾸는 통제된 human-robot 공동학습 프레임워크 EgoWAM 제안
- 세 실환경 양손 태스크에서 world-action model 공동학습이 순수 행동복제보다 야생(in-the-wild) 에고센트릭 데이터로 더 효과적으로 확장됨을 실증
- Pixel 기반 예측은 전이 효과가 약한 반면, DINO는 분포 밖 물체·장면 일반화를 최대 4배, 3D flow는 분포 내 성능을 20–30% 개선
- 프로젝트 페이지 공개, 코드 공개는 명시되지 않음

### (c) 시사점
- "어떤 world prediction target이 인간→로봇 전이에 가장 유효한가"라는 질문에 고정 백본 통제 비교로 답한 드문 실증 사례 — D32 표현 선택에 직접 참고 가능
- 에고센트릭 human 영상을 손 중심 조작 학습에 결합할 때, 원시 픽셀 재구성보다 DINO 특징·3D flow 쪽이 일관되게 우위라는 정량 근거 확보
- 사내 에고센트릭 획득 파이프라인에 적용 시 어떤 예측 타깃을 우선 도입할지 결정하는 근거 자료로 활용 가능

### (d) 먼저 확인할 점
- 실환경 태스크가 3개로 한정돼 태스크 다양성·난이도(정밀 파지 포함 여부)가 본문 확인 필요
- DINO·3D flow 두 표현 간 우열이 태스크 유형에 따라 갈리는지, 아니면 일관되게 3D flow가 우세한지 세부 비교 필요
- 가장 저렴한 전이 확인: 자사 파이프라인의 world prediction target을 3D flow로 교체해 기존 pixel-기반 baseline과 소규모 A/B 비교

## 🥈 논문 3 — 우선순위 ★★

**Flex-π: A Multi-Stream World-Action Model with Compute Flexibility**
[arXiv:2608.10860](https://arxiv.org/abs/2608.10860) · Ge Yan, Jinghao Liu, Yuzhi Fan, Lei Cai, Minwen Liao, Jesse Zhang et al. · arXiv preprint · source: citation-graph(WorldVLA 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29)

### (b) 핵심 기여
- 기존 World-Action Model 대다수가 RGB 잠재만 픽셀 재구성 목적으로 예측, 3D 기하·객체 의미에 대한 명시적 신호가 없다는 한계 지적
- 동결된 비디오 생성 VAE가 RGB뿐 아니라 3D 포인트맵도 별도 학습 없이 거의 무손실로 인코딩한다는 "공짜 점심(free lunch)" 발견
- 이를 활용해 6B 파라미터 Flex-π가 새로운 센서·사전학습·추론 지연 비용 없이 RGB와 나란히 3D 기하·DINO 객체 의미를 함께 감독받도록 설계
- 모든 시각 신호를 공유 잠재 공간에 투영해 Mixture-of-Transformers 백본 내에서 행동과 공동 디노이징, 스트림별 dropout으로 단일 체크포인트가 action-only 경량 모드부터 전체 결합 생성까지 모두 지원
- 다지·정밀 실환경 양손 조작 태스크(분포 내·외 모두)에서 최강 baseline 대비 2–7배 개선, π0.5보다 빠른 추론 속도
- 프로젝트 페이지 공개, 코드 공개는 명시되지 않음

### (c) 시사점
- 신규 3D 센서·별도 3D 사전학습 없이 기존 비디오 생성 VAE만으로 기하 신호를 얻는 저비용 경로 — D30 예측 공간 확장에 직접 참고 가능
- 스트림별 dropout으로 단일 체크포인트가 여러 연산 예산에 대응하는 설계는 배포 하드웨어 다양성에 대응하는 실용적 패턴
- baseline 대비 2–7배 개선이 다지·정밀 조작에 특화돼 보고돼 있어, 손 중심 태스크 벤치마크로 활용 가치 높음

### (d) 먼저 확인할 점
- "동결 VAE가 3D 포인트맵을 무손실 인코딩한다"는 핵심 주장이 사내 비전 백본(VAE 종류)에도 동일하게 성립하는지 별도 검증 필요
- 6B 파라미터 규모의 추론 자원 요구치가 사내 목표 하드웨어 기준과 부합하는지 확인 필요
- 가장 저렴한 전이 확인: 공개 예정 코드로 3D 포인트맵 인코딩 진단 실험(기존 자사 VAE에 동일 프로빙 적용)부터 재현

## 🥈 논문 4 — 우선순위 ★★

**DREAMSTEER: Latent World Models Can Steer VLA Policies During Deployment Without Any Finetuning**
[arXiv:2607.02865](https://arxiv.org/abs/2607.02865) · Hanchen Cui, Sergio Arnaud, Arjun Majumdar, Daniel Dugas, Elie Aljalbout, Karthik Desingh et al. · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29)

### (b) 핵심 기여
- 사전학습된 VLA 정책이 배포 시점 분포 이동에서 강건성 저하·지시 이행 불일치를 겪는 문제를, 파인튜닝이나 파라미터 수정 없이 배포 시점에 조향(steer)하는 프레임워크 DREAMSTEER 제안
- 배포 중 VLA 정책과 사전정의 모션 프리미티브로부터 후보 액션 청크를 샘플링, action-conditioned 잠재 world model로 결과를 상상(imagine), 언어 조건화된 value model로 상상된 궤적을 순위화
- 파인튜닝 데이터 수집이나 목표 환경 시연을 전혀 요구하지 않는 순수 추론 시점(test-time) 개입 구조
- 미확인 물체를 포함한 네 개 실환경 조작 벤치마크에서 base VLA 대비 태스크 성공률 23.75%→66.25%, 지시 이행 정확도 38.75%→56.25%로 개선
- 프로젝트 페이지 공개, 코드 공개는 명시되지 않음

### (c) 시사점
- 배포된 VLA를 재학습하지 않고도 latent world model + value model 조합만으로 분포 이동에 대응하는 저비용 배포-시점 개입 레시피 확보
- 액션 전문가 구조를 그대로 둔 채 별도 상상·순위화 모듈만 추가하는 형태라, 기존 정책 스택에 얹는 도입 비용이 낮음
- 네 개 실환경 벤치마크에 걸쳐 큰 폭의 성공률·지시 이행 개선이 정량 보고돼 있어, 배포 시점 강건성 확보 수단의 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 후보 액션 청크 샘플링·순위화에 드는 추론 시점 연산 오버헤드가 실시간 제어 주기와 양립하는지 확인 필요
- 사전정의 모션 프리미티브의 커버리지가 손 중심 다지 조작의 세밀한 동작까지 포함하는지 본문 확인 필요
- 가장 저렴한 전이 확인: 공개 예정 코드로 자사 base VLA 하나에 대해서만 우선 조향 프레임워크를 얹어 분포 이동 조건 재현

- Relevance 3 — 파인튜닝 없는 배포-시점 latent world model 조향이 D28 auxiliary 예측 및 D29 액션 전문가 보존 구조와 정합
