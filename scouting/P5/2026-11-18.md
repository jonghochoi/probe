### (a) 관련 Pillar / 질문

### (b) 논문 요지

- 물체 상대 상호작용 기하를 지키는 학습형 기구학 리타게팅
- **문제** — 다지 손의 접촉 상호작용 데이터가 가장 부족하고, 사람 손-물체 모션캡처를 동역학적으로 실행 가능한 로봇 궤적으로 바꾸는 리타게팅이 그 공급 경로
  - 로봇 상호작용 데이터는 웹에서 긁어올 수 없고, 원격조작은 느리고 비싸며 다지 손은 원격조작 자체가 어려움
  - 리타게팅은 손이 어디로 가는지 정하는 기구학 단계와 물체와 어떻게 상호작용하도록 구동할지 정하는 동역학 단계로 구성
- **기존 한계** — 기구학 리타게팅이 손 형상만 맞추고 물체를 무시
  - **키포인트 벡터 매칭** — 사람·로봇 손 키포인트 사이 벡터를 맞추는 방식(AnyTeleop, DexPilot)은 자유도와 손 기하가 달라 형상이 비슷해도 과제상 같은 상호작용을 보장하지 못함
  - **상호작용 그래프 최적화** — 로봇-환경 관계를 지키는 기존 프레임별 최적화는 전신 이동 조작이 대상이라 손가락 수준 접촉을 다루지 않음
  - **물리 기반 파이프라인** — 물체·접촉 정보를 물리 정제 단계에서만 넣고 기구학 기준 자체를 접촉 목적으로 정제하지 않음(ManipTrans, DexMachina, SPIDER)
- **핵심 방법** — 상호작용 그래프 최적화로 시드 기준을 만들고, 신경망으로 상각한 뒤 접촉 손실로 미세조정해 잔차 강화학습(RL)의 기본 액션으로 사용
  - **라플라시안 최적화** — 사람-물체와 로봇-물체 상호작용 그래프의 라플라시안 좌표가 맞도록 손목 자세와 관절각을 프레임별로 풀어 시드 기준 생성
  - **상각 네트워크** — 사람 키포인트와 물체 점군을 조건으로 시드 기준을 프레임당 순전파 한 번에 재현하도록 지도 학습, 초기값에 민감한 프레임별 최적화를 대체
  - **객체 인지 미세조정** — 표면 접촉, 물체 부위, 접촉 방향, 비관통, 자기 충돌 손실로 손가락 배치를 최적화 출력보다 개선
  - **동역학 리타게팅** — 기구학 기준을 기본 액션으로 둔 잔차 RL이 남은 동역학 격차를 보정, 시뮬레이션 성공 롤아웃을 하드웨어에서 개루프 재생
- **차별점** — 물체·접촉 정보를 물리 정제 이전의 기구학 기준 단계에 넣음
  - 기준의 질이 동역학 단계가 보정할 오차량을 정한다는 가설, 동역학 단계는 접촉 위치 추론 대신 동역학에 집중
  - 학습 후에는 프레임별 최적화 없이 추론만으로 새 데이터에 적용
- **핵심 기여** — 객체 인지 기구학 리타게팅 파이프라인과 시뮬레이션·실물 결과
  - 손 형상만 보는 기준 대비 하류 RL 성공률 20.6%에서 48.2%로 상승
  - Inspire 손 OakInk-v2 성공률 39.5%에서 48.4%, ARCTIC ADD-AUC 62.7%에서 77.9%로 기존 최고 수준 대비 향상
  - ARCTIC Inspire 손에서 SPIDER 대비 물체 성공률 83.4 대 42.0
  - OakInk-v2로 학습한 리타게터가 ARCTIC으로 제로샷 전이, 가벼운 미세조정으로 도메인 내 성능에 근접
  - UR5와 Allegro 손 실물 개루프 재생 5개 과제 46/56 성공, 리타게터 학습에 없던 두 과제(노트북 닫기, 버튼 누르기) 각 10/12
- **가치** — 모션캡처 사람 시연을 실행 가능한 다지 로봇 데이터로 바꾸는 엔진의 기구학 단계 제시

### (c) 시사점

- 기구학 기준이 무엇을 지키는지가 RL 수율을 바꾼다는 근거
- **보존 대상** — 손 자세 대신 물체 상대 손끝 배치, 접근, 물체 운동을 지키는 맵이 같은 동역학 백엔드에서 성공률을 두 배 이상 올린 측정
- **수율** — 동역학 백엔드를 고정하고 기준만 바꾼 비교라 리타게팅 수율 논의의 기준점으로 사용 가능
- **도입 비용** — 학습 후 추론만으로 새 데이터에 적용, 데이터셋 규모에서 프레임별 최적화 비용 회피

### (d) 먼저 확인할 점

- 물체 메시와 모션캡처 물체 자세가 전제, RGB 영상 기반 입력은 향후 과제로 남김
- 실물 결과는 시뮬레이션 성공 롤아웃을 골라 개루프 재생한 반복성이라 시뮬레이션 성공을 조건으로 함
- 잔차 RL은 과제별 학습, 과제·손 공유 잔차 정책은 향후 과제
- 흔들기 같은 고동역학 과제에서 파지가 궤적 중간에 깨지는 실패 잔존, 실물 Unplug·Cut에서 물체 미끄러짐
- 코드 저장소나 공개 약속 없이 프로젝트 페이지만 있음

**CARD: Contact-Anchored Retargeting for Dexterous Manipulation**
[arXiv:2610.36539](https://arxiv.org/abs/2610.36539) · Cunxi Dai 외 9명 · arXiv preprint · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, arXiv comment "Project webpage: …"는 프로젝트 페이지뿐

### (a) 관련 Pillar / 질문
[![P5](https://img.shields.io/badge/P5-d5f2f0.svg)](#ref-P5) / [![D2KT](https://img.shields.io/badge/D2KT-d97706.svg)](#ref-D2KT) [![D7HF](https://img.shields.io/badge/D7HF-d97706.svg)](#ref-D7HF)

### (b) 논문 요지

- 접촉 힘 목표에 고정한 시뮬레이터·물체 없는 리타게팅
- **문제** — 원격조작, 착용형 외골격, 운동 교시는 사람이 로봇 몸을 거쳐 행동하게 해 손재주가 인터페이스에 묶이고, 이를 피하는 리타게팅은 접촉 동역학을 놓침
  - 접촉 조작에서는 수 mm의 구현체 불일치가 재생 궤적이 물체 위에 뜰지, 미끄러질지, 물체를 부술지를 정함
- **기존 한계** — 리타게팅을 손끝 위치나 관절각을 맞추는 기구학 문제로 취급
  - **기구학 리타게팅** — 손끝·관절 매핑만으로 과제 성공에 필요한 실제 접촉 동역학을 무시
  - **시뮬레이션 기반 리타게팅** — 장면 재구성 뒤 시뮬레이션 안의 무거운 최적화가 필요
  - **접촉 중심 정식화** — 최근 방식도 물체 모델이나 시뮬레이터를 전제
- **핵심 방법** — 시연에서 링크별 접촉 힘 목표(압력 중심, 미는 방향, 힘)를 뽑고, 의미상 대응하는 로봇 링크를 시연 마찰 원뿔 안의 각 목표에 놓는 로봇 자세를 풂
  - **통합 손-접촉 표현** — 단안 영상, 촉각 장갑, 마커 모션캡처를 손 부위별 접촉 힘 목표가 붙은 MANO 메시 시퀀스로 통일, 힘을 재지 않는 소스는 클립 단위로 힘 합성
  - **Vid-HACO** — 촉각 신호가 없는 단안 영상에서 손-물체 접촉을 추정하는 영상 접촉 모델
  - **접촉 고정 리타게팅** — 접촉 도달, 마찰 원뿔 정렬, 힘 가중, 접촉 안정성을 GPU 샘플링 최적화로 프레임별 최적화
  - **촉각 추적 컨트롤러** — 관절 임피던스 위의 적분 어드미턴스 루프로 하드웨어 재생 중 시연 접촉 힘 유지
  - **교차 구현체 이전** — 손 부위와 로봇 몸체 사이 의미 맵만으로 새 로봇에 적용
- **차별점** — 물체 기하 대신 사람 손 표면에 묶인 접촉 힘 목표를 리타게팅 대상으로 삼아 시뮬레이터, 물체 메시, 물체 자세 추정이 모두 불필요
  - 강체, 관절체, 변형체 물체를 별도 처리 없이 다룸
- **핵심 기여** — 접촉 충실도, 실물 재생, 물리 기반 리타게팅 개선
  - 영상·장갑·모션캡처 데이터와 GRAB에서 접촉 프레임의 43–78% 접촉 유지, 기구학 리타게팅 10% 미만, 물체 정보가 필요한 방식 22.5%
  - SHARPA Wave 실물 세 과제 각 10회, 촉각 추적기가 위치 전용 재생 대비 성공을 4/30에서 25/30으로 올림
  - SPIDER에 접촉 목적을 넣은 CARD-physics가 엄격한 과제 성공률을 GRAB 12%에서 32%, 모션캡처 40%에서 52%로 향상
  - 22자유도 다지 손부터 평행 그리퍼까지 네 로봇 손으로 교차 구현체 리타게팅
  - Vid-HACO가 영상 접촉 추정에서 최고 수준 성능이라는 주장
- **가치** — 접촉 보존을 사람 손재주를 로봇으로 옮기는 확장 가능한 인터페이스로 제시

### (c) 시사점

- 접촉 힘을 보존 대상으로 둔 맵의 직접 비교 근거
- **보존 대상** — 기구학, 물체 인지, 접촉 힘 세 방식을 같은 접촉 유지율로 비교, 기구학 방식의 접촉 손실 규모를 수치로 제시
- **수율** — 접촉 목적을 물리 기반 리타게팅에 넣으면 엄격한 성공률이 오른다는 결과, 물리 정제 단계의 초기화를 바꾸는 경로
- **도입 비용** — 물체 메시와 시뮬레이터 없이 손 부위-로봇 몸체 의미 맵만 필요, 영상·장갑·모션캡처를 한 형식으로 처리

### (d) 먼저 확인할 점

- 실물 평가는 학습 정책 없는 개루프 재생이라 이 데이터로 학습한 정책 성능은 미측정, 폐루프 정책 학습은 향후 과제
- 큰 물체 변위는 개루프 재생으로 복구 불가, 리타게팅 품질은 입력 시연에 묶임
- 촉각 추적기는 손끝 힘 감지가 있는 로봇 손이 전제
- 실물 정량은 과제당 10회 시행 세 과제
- 코드 저장소나 공개 약속 없이 프로젝트 페이지만 있음

### (b) 논문 요지

- 손끝 촉각으로 접촉을 맞추는 사람-로봇 시연 변환
- **문제** — 접촉 집약적 다지 조작에 필요한 대규모 시연을 로봇에서 직접 모으기는 느리고 작업자 부담이 큼

  - **기구학 리타게팅** — 손 자세, 손끝 위치, 손 중심 벡터를 맞추는 방식(DexPilot, UniDex 등)은 접촉을 명시적으로 담지 않아 접촉 손가락이 지지 영역에서 밀리거나 동시 접촉 관계가 뒤틀리거나 접촉이 끊김
  - **객체 인지·시뮬레이션 기반 방식** — 물리 일관성은 높이나 물체 메시, 물체 자세 추정, 환경 재구성, 시뮬레이션 롤아웃이 필요해 대규모 사람 데이터로 확장이 어려움
- **핵심 방법** — 사람·로봇 쪽 시각·촉각 감지를 맞춘 하드웨어와 촉각 조건 리타게팅을 묶은 변환 파이프라인
  - **TouchBridge-Cap** — RGB 관측, 손 동작, 손끝 촉각을 기록하는 착용형 수집 장치, 로봇 쪽 인터페이스가 손목 카메라-손 기하와 촉각 센서 배치를 근사적으로 맞춤
  - **Tac-Retarget** — 측정 접촉으로 동작 이전을 이끄는 촉각 조건 리타게팅
  - **접촉 패치 정렬** — 사람과 로봇 손끝의 촉각 접촉 영역을 정렬
  - **접촉 활성 그래프** — 한 손 안과 양손 사이 동시 접촉의 공간 관계 보존
  - **로봇 도메인 변환** — 로봇 도메인 시각 합성과 카메라 기준 액션 구성으로 사람 시연을 로봇 학습 시퀀스로 변환
- **차별점** — 측정된 접촉 자체를 구현체 간 대응으로 사용해 물체 메시, 물체 자세 추정, 물리 시뮬레이션 없이 접촉을 보존
- **핵심 기여** — 변환 프레임워크, 촉각 리타게팅, 수집 비용 절감
  - Moz1 양팔 로봇과 Wuji 손 두 개, 실물 네 과제(전구 끼우기, 소스 바르기, 깨지기 쉬운 물체 집기, 페이지 넘기기)를 과제당 20회 평가
  - 같은 정책·학습 조건에서 Tac-Retarget 평균 72.5%, DexPilot 대비 25.0%p, UniDex 대비 42.5%p 높음
  - 변환한 사람 시연 60개만으로 미세조정한 GR00T N1.7이 72.5%, 같은 수의 원격조작 로봇 시연은 77.5%
  - 성공 시연 하나의 수집 시간 11.7초 대 원격조작 81.7초, 7.0배 빠름
  - 시뮬레이션 접촉 오차 평균 4.667mm로 최저, 접촉 정렬이나 접촉 그래프를 빼면 오차와 정책 성공률 모두 악화
- **가치** — 로봇 수집 데이터에 가까운 효용을 유지하며 사람 경험으로 로봇 학습을 확장하는 실용 경로

### (c) 시사점

- 촉각 리타게팅과 손끝 벡터 방식을 같은 정책으로 비교한 실물 근거
- **보존 대상** — 손끝 벡터 매칭 기준선 대비 접촉 패치와 동시 접촉 관계를 지키는 맵이 정책 성공률을 25.0%p 올린 측정
- **작업자 시간** — 사람 시연 수집이 원격조작보다 7.0배 빠르고 정책 성공률 차이는 5.0%p, 시연 단가 비교의 기준점
- **도입 비용** — 물체 메시와 시뮬레이션은 불필요하나 사람·로봇 양쪽에 맞춘 손끝 촉각 하드웨어가 전제

### (d) 먼저 확인할 점

- 촉각 센서 배치를 맞춘 전용 수집 장치와 로봇 인터페이스가 필요, 다른 로봇 손으로의 이전은 미검증
- 과제당 시연 60개, 네 과제의 소규모 실험이라 저자도 더 크고 다양한 데이터로의 확장을 향후 과제로 명시
- 접촉 오차 분석은 한 과제(Grasp Egg Roll)의 시뮬레이션 재생 20개 기준
- 코드 저장소나 공개 약속 없음, arXiv comment도 비어 있음

## 🌱 논문 4 — 인접 분야 픽

**DoF-Query Transformer for Adaptive Fusion of Egocentric Vision and Forearm HD-sEMG in Continuous Hand Kinematics**
[arXiv:2611.20196](https://arxiv.org/abs/2611.20196) · Jiahang Liu 외 6명 · adjacent field: 멀티모달 융합 표현 — 시각·근전도 융합 (Slot C)

**점수 6/15** · R2 · N2 · M2 · Real0 · Repro0 — 초록·arXiv comment 모두 코드 저장소나 공개 약속 없음, 본문은 PDF 전용

### (a) 관련 Pillar / 질문
[![P5](https://img.shields.io/badge/P5-d5f2f0.svg)](#ref-P5) / [![D7HF](https://img.shields.io/badge/D7HF-d97706.svg)](#ref-D7HF)

### (b) 논문 요지

- 자유도별 쿼리로 시각과 근전도를 융합한 손 관절각 추정
- **문제** — 사람 손 운동학의 연속적이고 정확한 추정이 인간-기계 상호작용과 로봇 학습용 세밀한 조작 시연 수집에 필요
- **기존 한계** — 단일 감지 모달리티는 다양한 작동 조건에서 신뢰할 만한 추정에 불충분
- **핵심 방법** — 에고센트릭 RGB와 128채널 전완 고밀도 표면 근전도(HD-sEMG)에서 손 관절각 20개를 연속 회귀하는 손가락 비구속 멀티모달 프레임워크
  - **시각 인코더** — Vision Transformer 기반
  - **근전도 인코더** — Transformer 기반
  - **DoF 쿼리 융합 디코더** — 자유도마다 학습 가능한 쿼리를 따로 두어 자유도와 입력 조건별로 두 모달리티를 적응적으로 융합
- **차별점** — 시각·근전도 단서의 정보량이 관절 자유도와 입력 조건에 따라 다르다는 점을 자유도별 쿼리로 반영
- **핵심 기여** — 참가자 10명의 동기화 멀티모달 데이터에서 융합 모델 성능
  - 참가자 평균 R² 0.88, MAE 2.80°, 시각 전용 0.82·3.21°, 근전도 전용 0.68·5.13°
  - 평가한 대표 단일 모달 기준선과 대안 융합 설계보다 우수
  - 시각적으로 모호한 관절과 시야 조건에서 융합 이득이 크고, 합성 시각 가림에서 시각 전용보다 강건
- **가치** — 에고센트릭 시각과 전완 근전도의 상보성을 보여 사람 시연 수집용 세밀한 손 운동학 포착 경로 제시

### (c) 시사점

- 가림에 강한 손 자세 추정이 리타게팅 입력을 개선할 후보
- **리타게팅 입력** — 리타게팅 결과는 시작점인 사람 손 자세의 질에 묶임, 근전도 보완이 가림 구간 관절 오차를 줄일 가능성
- **수집 방식** — 손가락에 장치를 달지 않는 수집이라 맨손 시연 기록과 양립
- **도입 비용** — 128채널 전완 HD-sEMG 장비가 추가로 필요

### (d) 먼저 확인할 점

- HTML 원문 없음 — 요지는 초록 기준
- 로봇 결과 없음, 사람 손 관절각 추정만 평가
- 가림은 합성 시각 가림으로만 평가, 실제 조작 중 손-물체 가림에서의 이득은 미측정
- 참가자 10명 규모, 참가자 간 일반화 설정은 본문 확인 필요
