## 🥇 논문 1 — 우선순위 ★★★

**Wh0: Generative World Models as Scalable Sources of Egocentric Human Hand Manipulation Data**
[arXiv:2606.22136](https://arxiv.org/abs/2606.22136) · Yangtao Chen, Zixuan Chen, Peiyang Wang, Yong-Lu Li · source: keyword-sweep (cs.RO, "world model" + "hand")

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **문제 설정** — 다지 조작 스케일링의 데이터 트릴레마: 원격조작 데이터는 로봇 배포 정렬성 우수하나 수집 비용 과다; 시뮬레이션은 확장 가능하나 Sim2Real(시뮬레이션-실환경 이전) 갭 존재; 에고센트릭 실인간 동영상은 확장 가능하나 로봇 배포와 정렬 불일치
- **Wh0 프레임워크** — 생성적 영상 세계 모델을 다지 VLA 훈련 데이터 합성 공장으로 전환: 언어·물체·장면 조건화로 에고센트릭 인간-물체 상호작용 동영상 50,000 에피소드 데이터셋(WM-H) 자동 생성
- **로봇 학습 변환 파이프라인** — WM 생성 에고센트릭 동영상을 손 모션 재구성을 통해 로봇 훈련 가능 감독 신호로 변환; 사전학습 다지 조작 VLA 모델에 직접 파인튜닝 적용
- **스케일 확장성** — WM 기반 데이터 합성은 수집 비용 없이 다양한 물체·장면 조합에 걸쳐 확장 가능; 기존 데이터 소스 트릴레마 해소 시도

### (c) 시사점

- **세계 모델의 데이터 합성 역할 실증** — 세계 모델이 직접 에고센트릭 다지 조작 훈련 데이터를 합성할 수 있음을 구체 파이프라인으로 처음 제시; 세계 모델 롤아웃 합성이 실제 데이터 병목 해소 경로로 검증
- **DexWM 계열의 역방향 확장** — DexWM이 인간 동영상에서 세계 모델 학습 방법 제시했다면, Wh0은 학습된 세계 모델로 새로운 훈련 데이터를 역으로 합성하는 방향; 에고센트릭 손-물체 세계 모델 생태계의 선순환 구조 가능성 제시
- **WM-H 50k 데이터셋 기준점** — 공개 다지 VLA 파인튜닝 비교 데이터셋으로 활용 가능; 에고센트릭 합성 데이터 적용 효과 정량 기준 확보

### (d) 먼저 확인할 점

- **WM 생성 품질과 실로봇 성능 연결 확인** — WM이 생성한 에고센트릭 동영상의 충실도가 다지 VLA 성능 향상으로 실제 연결되는지; 손 모션 재구성 오류가 정책 품질에 미치는 영향 본문 확인 필요
- **평가 다지 조작 태스크 범위** — 파인튜닝에 사용된 다지 VLA 모델 종류와 평가 태스크 세부 사항 확인 필요; DexWM 핑거 키포인트 수준 정밀 인핸드 조작 설정 포함 여부 미확인
- **세계 모델 사전 의존성** — 어떤 기반 세계 모델 아키텍처를 사용하느냐에 따른 WM-H 품질 편차; 오픈소스 세계 모델로 재현 가능 여부 미확인

## 🥈 논문 2 — 우선순위 ★★

**WAM-RL: World-Action Model Reinforcement Learning with Reconstruction Rewards and Online Video SFT**
[arXiv:2606.17906](https://arxiv.org/abs/2606.17906) · Zezhong Qian, Xiaowei Chi, Yu Qi · source: keyword-sweep (cs.RO, "world action model")

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28)

### (b) 핵심 기여

- **동기** — 기존 World-Action 모델은 전문가 시연 궤적에 의존; 시연 분포 외 정밀 제어 획득 불가, 실환경 상호작용을 통한 자기 개선 경로 부재
- **WAM-RL 구조** — 세계 모델과 액션 모델을 실환경 온라인 상호작용으로 **공동 최적화**하는 강화학습 (RL) 프레임워크; 두 컴포넌트가 co-evolve하는 계층적 최적화 설계
- **재구성 보상(Reconstruction Rewards)** — 세계 모델의 미래 관측 재구성 품질을 강화학습 보상 신호로 직접 활용; 별도 보상 함수 설계 없이 세계 모델 내재적 품질 척도 사용
- **온라인 비디오 SFT** — 실환경 상호작용으로 수집된 동영상으로 세계 모델 실시간 업데이트; 오프라인 시연 데이터 의존도 감소
- **실환경 검증** — 정밀 조작 태스크에서 실환경 지속 개선 확인

### (c) 시사점

- **세계 모델의 강화학습 환경 역할 진입 신호** — 세계 모델을 강화학습 환경으로 활용하는 방향이 직전 두 보고서(PLUME·WEAVER) 신호에 이어 3회 연속 실증; 다지 손 정밀 제어에 이 역할 도입 시 세계 모델-액션 공동 최적화가 핵심 설계 결정이 될 전망
- **재구성 보상의 설계 자유도** — 접촉 집약적 다지 조작에서 보상 함수 설계 어려움을 세계 모델 재구성 품질로 우회하는 경로; 손-물체 접촉 세계 모델과 결합 시 접촉 품질 기반 내재적 보상 가능성
- **실환경 온라인 수집 데이터로 세계 모델 업데이트** — 오프라인 시연만으로 정적 학습하는 기존 WAM 대비 배포 후 자기 개선 경로 구체화; 실환경 분포 적응 세계 모델의 실용 방향

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 환경 적용 범위** — 제시된 정밀 조작 태스크 종류와 다지 손 특화 설정 여부 본문 확인 필요
- **공동 최적화 안정성** — 세계 모델과 액션 모델 공동 최적화 시 불안정성·모드 붕괴 위험; 학습 안정성 수치 및 민감도 확인 필요
- **재구성 보상 한계** — 시각적 재구성 품질이 조작 성공과 항상 일치하지 않을 가능성; 접촉 집약적 인핸드 조작에서 재구성 보상 vs. 태스크 보상 비교 미확인

## 🥈 논문 3 — 우선순위 ★★

**PAIWorld: A 3D-Consistent World Foundation Model for Robotic Manipulation**
[arXiv:2606.18375](https://arxiv.org/abs/2606.18375) · Yuhang Huang, Xuan Lv, Junyan Xu · source: keyword-sweep (cs.RO, "world model" + "manipulation")

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여

- **문제 규명** — 현 세계 기반 모델(WFM)은 단일 시점 중심; 다시점(에고센트릭·Eye-to-Hand·손목 카메라) 활용 시 뷰 간 객체 드리프트·깊이 불일치·텍스처 미정렬 발생
- **근본 원인 분리** — 뷰 간 명시적 교차 통신 메커니즘 부재 + 3D 기하학적 사전 부재 두 결함 규명; 두 결함 동시 해결이 필요충분조건임을 주장
- **PAIWorld** — 디퓨전-트랜스포머 WFM에 명시적 뷰 간 교차 통신과 3D 기하 사전을 통합; 에고센트릭·Eye-to-Hand·손목 다시점 카메라 입력에서 3D 일관된 미래 예측 달성
- **다시점 정책 학습 기준점** — 3D-일관 다시점 WFM이 단순 뷰 토큰 연결 방식 대비 정책 학습 품질 향상 실증

### (c) 시사점

- **다시점 세계 모델 통합 아키텍처 설계 기준** — 에고센트릭 + Eye-to-Hand + 손목 카메라 3종 동시 활용 시 단순 토큰 연결이 불충분함을 실증; 기하 제약 기반 크로스뷰 교환이 필요 조건으로 확인
- **3D-일관 예측 공간이 P2 DynaFLIP와의 접점** — 3D-flow 예측과 3D-일관 WFM 예측이 같은 기하 공간에서 수렴하는 신호; P2 DynaFLIP 기반 3D-flow와 P5 WFM 예측 공간의 통합 설계 가능성 제시
- **우리 설정 카메라 구성과의 정합** — 에고센트릭 + 손목 마운트 다시점 구성이 PAIWorld 입력 구성과 직접 정합; 세계 모델 통합 기준점으로 활용 가능

### (d) 먼저 확인할 점

- **3D 일관성 제약의 추론 비용** — 기하학적 사전 통합으로 인한 추론 속도 저하 수치; 폐루프 다지 손 제어 주기와의 정합 여부 미확인
- **3D 기하 품질과 다운스트림 성능 상관** — 뷰 간 3D 일관성 메트릭과 다운스트림 정책 성능 간 상관 관계 확인 필요
- **공개 범위 및 캘리브레이션 요건** — 코드·모델 공개 여부; 다시점 카메라 외부 캘리브레이션 요건 수준 미확인

## 🥉 논문 4 — 우선순위 ★

**World Action Models Enable Continual Imitation Learning with Recurrent Generative Replays**
[arXiv:2606.27374](https://arxiv.org/abs/2606.27374) · Manish Kumar Govind, Dominick Reilly, Smit Patel · source: keyword-sweep (cs.RO, "world action model")

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28)

### (b) 핵심 기여

- **동기** — 로봇 정책 지속 적응 시 재앙적 망각(catastrophic forgetting)이 주요 장벽; 원본 시연 데이터 재저장 없이 이전 태스크 복습 불가능
- **REGEN(Recurrent Generative Replay)** — WAM의 영상 생성 능력을 재생 완충재로 활용: 태스크 지시 + 현재 관측 조건화로 의사-재생 궤적을 재귀적으로 합성; 원본 시연 저장 불필요
- **정량 결과** — 순차적 파인튜닝 대비 재앙적 망각 최대 50% 감소; 특권(privileged) 경험 리플레이 기준에 근접한 성능
- **시뮬레이션·실환경 동시 검증** — 조작 설정에서 두 환경 모두 실증

### (c) 시사점

- **세계 모델 롤아웃 합성의 연속 학습 응용** — 세계 모델 롤아웃이 단순 데이터 증강을 넘어 의사-재생 메모리로 기능하는 패턴 제시; 세계 모델을 정책 공동학습 보조 이상으로 확장하는 새로운 역할 형태
- **원본 시연 없는 지속 스킬 습득 경로** — WAM 롤아웃만으로 이전 태스크 시연 재현 가능 수준; 다지 손 스킬 라이브러리 점진 확장 시나리오에서의 망각 방어 경로
- **실환경 50% 망각 감소 기준점** — 세계 모델 기반 생성 리플레이의 비용 대비 효과 수치; 정책 지속 학습 설계 시 참고 기준

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 태스크 평가 범위** — 검증된 조작 태스크 종류와 다지 손 특화 설정 여부 본문 확인 필요
- **재귀 합성 오류 누적** — WAM을 재귀적으로 반복 호출해 긴 의사-궤적 합성 시 누적 오류(hallucination drift); 다지 손 정밀 조작 설정에서의 합성 충실도 미확인
- **WAM 용량 한계** — 더 많은 태스크를 기억할수록 단일 WAM이 모든 태스크 시각 동역학을 충분히 포괄하기 어려울 가능성; 태스크 수 증가에 따른 성능 열화 추이 미확인
