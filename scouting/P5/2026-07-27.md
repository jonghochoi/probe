## 🥇 논문 1 — 우선순위 ★★★

**InternVLA-A1.5: Unifying Understanding, Latent Foresight, and Action for Compositional Generalization**
[arXiv:2607.04988](https://arxiv.org/abs/2607.04988) · Ma et al. (Shanghai AI Laboratory) · source: citation-graph (Being-H0.7·VLA-JEPA 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- **통합 VLM 백본에 경량 액션 전문가 부착** — Qwen3.5 기반 네이티브 VLM에 flow matching 액션 전문가를 공유 full-attention 레이어로 연결, 기존 VLM 사전학습 의미를 보존한 채 연속 액션 청크 생성
- **Foresight 토큰으로 미래를 잠재 질의화** — 소수의 학습 가능한 foresight 토큰이 멀티모달 문맥에서 과제 관련 미래를 압축, frozen 사전학습 비디오 생성 모델(WAN2.2-5B)의 지도 아래 학습, 픽셀 단위 생성 없이 동역학 사전 지식 흡수
- **추론 시 비디오 분기 제거** — 학습에만 비디오 예측 신호 활용, 추론에서는 비디오 분기를 버려 실시간 제어 지연시간 유지
- **6개 시뮬레이션 벤치마크 전역 최고 성능** — RoboTwin 2.0(93.2)·LIBERO(98.9)·LIBERO-Plus(84.8)·SimplerEnv(80.8)·DOMINO(27.7)·EBench(35.2) 전역 1위, 실제 로봇 과제(Sort/Insert/Move Tubes, MOF)에서도 held-out instruction 조합에 대한 일반화 우위 확인

### (c) 시사점
- **보조 헤드형 세계모델 통합의 실전 사례 확보** — 별도 세계모델 전체를 얹지 않고도 frozen 비디오 생성 모델 지도만으로 미래 예측 이점을 흡수하는 구조, 도입 난이도 낮음
- **VLM 사전학습 보존과 동역학 사전 습득 양립 가능성 확인** — 백본 의미 손상 없이 미래 예측 신호를 추가하는 설계가 대규모(로봇 120만 에피소드) 검증에서 성능으로 이어짐
- **공개 자산이 즉시 점검 가능한 수준** — 학습 코드·HuggingFace/ModelScope 체크포인트(벤치마크별 다중 모델) 전량 공개(InternRobotics/Shanghai AI Lab)

### (d) 먼저 확인할 점
- **실제 로봇 과제 규모가 4종(Sort/Insert/Move Tubes, MOF)으로 제한** — 조작 난이도·물체 다양성 확장 시 우위 유지 여부 별도 확인 필요
- **Foresight 토큰 수·frozen 비디오 모델 크기(WAN2.2-5B)에 따른 계산 비용 증가분 미명시** — 자사 규모 하드웨어에서 실시간성 재현 여부 확인 필요
- **가장 저렴한 이전 점검** — 공개 체크포인트로 LIBERO 벤치마크부터 재현 시도, 논문 5.3절 World Model Exploitation ablation이 foresight 토큰의 기여를 실제로 얼마나 분리해 보여주는지 우선 확인

### (b) 핵심 기여
- **액션 중심 정식화로 추론 시 비디오 생성 제거** — 학습 중에는 미래 시각 동역학을 조밀 지도로 활용(Action-Conditioned World Modeling + WAM 혼합 학습), 추론에서는 액션만 디코딩해 폐루프 실시간 배포 병목 해소

- **AutoResearch 파이프라인으로 학습 설정 자동 탐색** — 에이전트 기반 자동 실험 설계로 하이퍼파라미터 탐색 시간·수작업 개입 축소
- **실제 그리퍼 조작 과제 검증** — 실환경 그리퍼 기반 조작 설정에서 실제 로봇 시행 기반 평가 수행(논문 4.1절 Real-World Results)

### (c) 시사점
- **학습-추론 비대칭 설계가 WAM 실시간성 병목의 실질적 해법** — 학습에서만 무거운 비디오 동역학 신호를 쓰고 추론에서 버리는 패턴이 폐루프 배포 지연시간을 크게 낮춤을 재확인
- **자동화된 학습 설정 탐색이 반복 비용을 낮추는 사례** — AutoResearch류 파이프라인이 WAM 계열 하이퍼파라미터 튜닝 부담을 줄이는 방향성 제시
- **공개 자산 일부 확인** — HuggingFace 체크포인트 + 별도 오픈소스 C++ 추론 런타임(`wam.cpp`) 공개, 학습 코드·데이터셋 공개 여부는 저장소에서 별도 확인 필요

### (d) 먼저 확인할 점
- **실제 로봇 검증 범위가 그리퍼 조작 설정에 한정** — 다지·비-그리퍼 조작으로의 일반화는 별도 확인 대상
- **동일 팀의 이전 GigaWorld-Policy 대비 개선폭이 효율성 위주로 서술** — 정책 성능 자체의 절대적 향상 폭은 본문 표 기준 별도 확인 필요
- **가장 저렴한 이전 점검** — 공개된 `wam.cpp` 추론 런타임으로 지연시간 재현부터 시도, AC-WM+WAM 혼합 사전학습 ablation이 순수 WAM 대비 실제 이득 폭을 어떻게 분리하는지 확인
