### (a) 관련 Pillar / 질문

### (b) 논문 요지

- 이산 토큰 지도와 EEF·관절 두 스트림을 함께 둔 VLA
- **문제** — 에고센트릭 인간 영상에는 관절 위치와 액추에이터 명령이 없어 다지 손 로봇 정책을 지도하기 어려운 행동 격차
  - 인간 기록은 재타깃팅한 엔드이펙터(EEF) 행동만 제공하며, IK로 관절에 옮기면 신체별 대응에 기대고 분포 밖 팔 자세가 생김
  - 인간 데이터를 어떻게 지도할지와 배포 시 행동을 어떻게 읽어낼지 두 질문이 걸림
- **기존 한계** — 인간 데이터 지도와 배포 시 읽기 양쪽에서 선행 방식의 기여가 분리되지 않음
  - **연속 디코더 지도** — EEF 행동을 연속 디코더로만 지도해 백본 기울기가 그 디코더를 통해서만 전달
  - **이산 행동 토큰** — 백본을 이산 토큰으로도 학습시키는 VLA는 데이터와 구조가 함께 달라지거나 두 손실을 분리 없이 합쳐 이산 지도의 기여가 불분명
  - **관절 출력 병기** — EEF 출력 옆에 로봇 전용 관절 출력을 두고도 관절 출력만 실행
- **핵심 방법** — 백본의 이산 토큰 보조 과제와 공유 flow-matching 전문가의 병렬 두 스트림
  - **백본** — 각 EEF 청크의 이산 FAST 토큰을 인간·로봇 샘플 공통 어휘로 예측해 백본을 직접 지도
  - **EEF 스트림** — 인간과 로봇 데이터 양쪽으로 지도
  - **관절 스트림** — 사전학습에서 로봇 데이터로만 지도하되 백본과 전문가를 공유해 인간 사전학습의 이득을 받음
  - **배포** — 어느 스트림으로도 로봇 구동 가능
- **차별점** — 관절 출력만 실행하던 선행 정책과 달리 두 스트림을 모두 실행 가능 상태로 유지
  - 이산 지도와 인간 데이터를 켜고 끄는 일치 2×2 사전학습으로 두 선택의 효과를 분리
- **핵심 기여** — 이산 지도 효과, 이중 스트림 전문가, 두 가지 하류 설정의 결과
  - **이산 지도** — 인간 데이터 학습에서 백본 기울기와 과제 정렬 행동 표현을 이끈다는 결과
  - **이중 스트림** — 인간 관절 라벨 없이 인간 사전학습이 관절 제어로 전이
  - **사전학습 구성** — 인간 에고센트릭 2.8k시간, 로봇 텔레오퍼레이션 228시간(7-DoF 팔 둘과 22-DoF 손), 실물 1,680회 시행으로 평가
  - **로봇 시연 미세조정** — 실물 여섯 과제 0.80, π0.5 0.63
  - **인간 시연만 미세조정** — 과제별 로봇 데이터 없이 새 과제 학습
- **가치** — 값싼 에고센트릭 인간 데이터를 다지 손 정책의 사전학습과 직접 학습 자원으로 쓰는 경로 제시

### (c) 시사점

- 한 전문가에서 관절 읽기와 IK 경유 EEF 읽기를 맞댄 수치 근거
- **읽기 공간 비교점** — 로봇 시연 미세조정에서는 관절 직접 읽기, 인간에서 로봇으로의 전이에서는 IK 경유 EEF 읽기가 앞선다는 보고
- **XL-VLA 대비** — 손 관절 명령을 잠재로 대체한 XL-VLA와 달리 두 읽기를 모두 남긴 설계
- **도입 비용** — 코드 비공개이며 양팔 22-DoF 손 플랫폼과 인간 2.8k시간 데이터 필요

### (d) 먼저 확인할 점

- **공개 여부** — 프로젝트 페이지만 있고 저장소나 공개 약속 없음
- **통계 근거** — 과제당 20회 시행이며 분산 상한 μ(1−μ)를 가정한 z-검정으로 비교
- **플랫폼 한정** — 실물 결과가 22-DoF 손 양팔 한 플랫폼이며 다른 손으로의 전이는 본문에서 확인되지 않음
- **전이 주의** — 두 스트림이 한 전문가 안에 있어 부위별 전문가 분할과는 다른 축이며, 분할과 단일 디코더의 직접 비교는 아님

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (b) 논문 요지

- 팔별 토큰이 상대 팔을 참조하는 양팔 액션 토크나이저
- **문제** — 양팔 조작에서 두 팔은 움직임 레퍼토리를 공유하면서 상호보완 역할로 협응하는데, 액션 인터페이스가 이를 드러내지 못해 정책이 암묵적으로 학습
  - 물건 넘기기, 천 접기, 큰 물체 운반처럼 두 팔의 협응이 성패를 가름
- **기존 한계** — 대부분의 범용 토크나이저가 두 팔 행동을 하나의 벡터로 연결
  - **결합 토큰화** — 팔 간 공통 움직임 패턴이 공유되지 않고 팔 간 의존이 각 토큰 안에 얽힘
  - **팔별 토큰화** — 팔마다 따로 토큰화하면 각 팔 코드에서 상대 팔 맥락이 빠져 가장 강한 결합 토크나이저보다 낫지 않음
  - **기존 토크나이저 계열** — 주파수 영역 압축, 학습된 시간 추상화, 벡터 양자화, 조대-정밀 코딩 모두 행동 청크를 평탄한 벡터로 취급
- **핵심 방법** — 팔별 토큰 스트림을 유지하되 이산화 전에 상대 팔 맥락을 더하는 토크나이저
  - **공유 표현** — 오른팔을 왼팔 규약으로 사상해 거울 동작이 한 표준 궤적을 공유하고, 공유 인과 시간 인코더로 두 팔 인코딩
  - **상대 팔 조건** — 대칭 팔 간 어텐션이 공유 유한 스칼라 양자화(FSQ) 전에 상대 맥락을 더하고, 공동 디코더가 시간 쌍 코드에서 두 궤적 복원
  - **정책** — 팔별 토큰을 두 블록으로 예측하며, 각 팔 토큰은 병렬 생성하고 오른팔은 왼팔에 조건화
- **차별점** — 팔을 분리한 토큰 스트림을 유지하면서 상대 팔 맥락을 토크나이저 양쪽에서 주고받음
  - 복원 학습만으로 팔별 토큰을 만들고, 두 팔을 한 블록으로 예측하는 방식과 구분
- **핵심 기여** — 토크나이저, 시뮬레이션·실물 결과, 요인 분석
  - **BiCAT** — 거울 팔 간 움직임 표현을 공유하고 팔 간 상호작용을 토크나이저 안에 둔 팔별 토크나이저
  - **시뮬레이션** — RoboTwin 2.0 열 과제에서 일곱 계열 여덟 베이스라인 중 최강 대비 평균 성공률 +17.6pp, 단일팔 과제 1.5pp에서 긴밀 결합 과제 21.3pp로 증가
  - **실물** — 세 로봇의 여섯 과제 150회 중 113회 성공, OAT 74회
  - **지연** — 청크당 40.5ms, 토큰별 디코딩보다 지연 5.6× 이상 낮음
  - **요인 분석** — 팔 간 상호작용 제거나 두 팔 한 블록 예측 시 최강 베이스라인과 비슷한 수준
- **가치** — 액션 토크나이저가 양팔 협응을 모델링하는 자리라는 근거 제시

### (c) 시사점

- 팔 간 협응을 토크나이저 안에서 푼 양팔 사례
- **결합 방향 사례** — 대칭 어텐션으로 상호 조건화한 뒤 왼팔 먼저, 오른팔은 왼팔에 조건화해 생성하는 결합 구현
- **대조군 확보** — 같은 VLA 학습 프로토콜에서 연결 단일 벡터 방식과 팔별 분리 방식을 모두 맞댄 수치
- **InDex 대비** — 한 FiLM 지점의 단방향 조건화와 달리 두 스트림이 토크나이저 안에서 맥락을 주고받는 설계
- **도입 비용** — 토크나이저 학습과 자기회귀 VLA 필요, 코드 비공개

### (d) 먼저 확인할 점

- **공개 여부** — 저장소, 프로젝트 페이지, 공개 약속 모두 없음
- **실물 비교 범위** — 여덟 베이스라인 비교는 시뮬레이션이며, 실물은 FAST와 OAT 두 비교에 한정
- **대상 범위** — 팔 단위 협응이며 손가락이나 몸통 같은 다른 부위 분할은 본문에서 확인되지 않음
- **거울 가정** — 팔 기구학이 맞는 로봇을 전제로 거울 사상을 쓰므로 다른 구성의 팔에는 그대로 옮겨지지 않음

**RoboMorpher: Scaling Robot Morphology Representations for Cross-Embodiment Action Prediction**
[arXiv:2611.24816](https://arxiv.org/abs/2611.24816) · Wenwei Lin 외 14인 · arXiv preprint · source: citation-graph

**점수 7/15** · R3 · N2 · M2 · Real0 · Repro0 — arXiv comment "Website: https://robomorpher.github.io/" — 프로젝트 페이지만 있고 코드 문구 없음

### (a) 관련 Pillar / 질문

[![P5](https://img.shields.io/badge/P5-d0e4f8.svg)](#ref-P5) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 논문 요지

- 관절 각과 링크 자세를 함께 복원하는 형태 조건 토크나이저
- **문제** — 같은 관절 값이 로봇 형태에 따라 다른 링크 자세를 만들어, 관절 값만으로 학습한 교차 로봇 행동 표현이 한계
  - 범용 정책은 여러 플랫폼의 시연에서 배우지만 관절 공간 행동의 운동학적 의미는 형태에 의존
- **기존 한계** — 관절 공간 행동의 모호성을 기존 표현이 해소하지 못함
  - **공통 차원 패딩** — 관절 수를 맞출 뿐 모호성을 풀지 못함
  - **EE 제어** — 데카르트 목표를 주지만 로봇별 역기구학이 필요하고 전체 관절 구성을 특정하지 못함
- **핵심 방법** — 로봇 기구학을 감독 신호로 삼은 토크나이저 사전학습 후 동결해 VLA에 결합
  - **MorphGen** — URDF/MJCF 33개 조사에서 얻은 링크 길이 사전분포로 6·7관절 직렬 팔을 생성하고 충돌 인지 IK로 홈 자세를 고른 뒤 순기구학으로 링크 자세 목표 4천만 쌍 생성
  - **토크나이저** — 형태가 인코더와 디코더를 조건화하고 기구학 사슬 어텐션 편향이 관절의 상대 위치를 부호화하며, 관절 각과 링크 자세를 함께 복원
  - **정책** — 이산 가지가 행동 코드를 예측해 거친 궤적을 만들고 연속 flow-matching 가지가 정련하며, 형태 특징이 두 가지를 조건화
- **차별점** — 제어 좌표를 보존하는 관절 각 복원에 링크 자세 복원을 더해 제어 좌표와 운동학적 효과를 연결
  - 하류 URDF를 토크나이저 사전학습에서 제외하고 평가
- **핵심 기여** — 데이터 생성기, 토크나이저, 벤치마크와 결과
  - **MorphGen** — 조사 기반 로봇 형태 생성기와 대규모 기구학 사전학습 데이터
  - **EmbodiBench** — 과제당 생성 URDF 30개를 둔 열 개 탁상 과제 벤치마크
  - **시뮬레이션 성공률** — RoboTwin 2.0 56.40%, EmbodiBench 23.27%로 연속 관절 공간 제어 대비 +9.73pp와 +15.34pp
  - **절제** — 링크 자세 감독을 제거하면 EmbodiBench 성공률이 5.33%로 하락
- **가치** — 형태 인식 기하 감독이 관절 행동 표현 학습에 기여한다는 근거 제시

### (c) 시사점

- 관절 명령 대신 형태 인식 토큰을 내보내는 행동 공간 사례
- **행동 공간 비교점** — 손 관절 명령을 잠재로 바꾼 XL-VLA와 달리 직렬 팔 관절 명령을 형태 조건 토큰으로 대체
- **대조군 확보** — 같은 정책에서 연속 관절 제어와 토큰 예측을 맞댄 수치와 링크 자세 감독 절제 수치
- **도입 비용** — 4천만 쌍 사전학습과 URDF 기반 생성기가 필요하고 코드 비공개

### (d) 먼저 확인할 점

**DoF-Query Transformer for Adaptive Fusion of Egocentric Vision and Forearm HD-sEMG in Continuous Hand Kinematics**
[arXiv:2611.20196](https://arxiv.org/abs/2611.20196) · Jiahang Liu 외 6인 · adjacent field: 보철·신경과학 — 시각·근전도 손 운동학 추정 · arXiv preprint

### (a) 관련 Pillar / 질문

### (b) 논문 요지

- 시각과 근전도를 관절별 쿼리로 융합한 손 운동학 추정
- **문제** — 인간 손 운동학을 연속으로 정확히 추정해야 하며, 단일 감각 모달리티는 운용 조건에 따라 신뢰할 수 없을 수 있음
  - 직관적 인간-기계 상호작용과 로봇 학습용 정밀 인간 조작 시연 획득에 필요
- **기존 한계** — 단일 모달리티는 조건에 따라 정보가 부족하다는 것이 저자 주장
  - 초록이 개별 기존 방법을 지목하지 않아 세부 비판은 원문 확인 필요
- **핵심 방법** — 에고센트릭 RGB와 128채널 팔뚝 고밀도 표면 근전도(HD-sEMG)로 손 관절 각 20개를 연속 회귀
  - **인코더** — Vision Transformer 기반 시각 인코더와 Transformer 기반 근전도 인코더
  - **DoF 쿼리 융합 디코더** — 자유도마다 학습 가능한 쿼리를 두어 두 모달리티를 자유도별, 조건별로 적응 융합
- **차별점** — 자유도마다 별도 쿼리를 두어 모달리티 정보량이 관절마다 다르다는 점을 융합 가중에 반영
  - 비교 대상은 단일 모달리티 모델과 대안 융합 설계로 초록에 언급
- **핵심 기여** — 융합 구조와 평가 결과
  - **전체 성능** — 참가자 10명 평균 R² 0.88, MAE 2.80°, 시각 단독 0.82와 3.21°, 근전도 단독 0.68과 5.13°
  - **비교** — 대표 단일 모달리티 기준선과 대안 융합 설계도 능가
  - **자유도별 분석** — 시각적으로 모호한 관절과 시점 조건에서 융합 이득이 큼
  - **가림 실험** — 합성 시각 가림에서 시각 단독보다 강건
- **가치** — 손가락을 가리지 않는 센싱으로 정밀 손 운동학을 얻는 경로 제시

### (c) 시사점

- 관절 자유도마다 읽기를 나눈 인접 분야 사례
- **분할 단서** — 디코더가 자유도별 쿼리를 두는 구조가 대안 융합 설계를 앞섰다는 보고
- **전이 조건** — 로봇 액션 디코더가 아닌 인간 손 추정기라 쿼리 분할이 로봇 손 관절 명령 헤드에 해당하는지는 별도 확인
- **도입 비용** — 128채널 HD-sEMG 장비가 필요하고 코드 비공개

### (d) 먼저 확인할 점
