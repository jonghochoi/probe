**WEAVER, Better, Faster, Longer: An Effective World Model for Robotic Manipulation**

### (b) 핵심 기여
- 세계모델이 충족해야 할 세 요건(충실도·일관성·효율성)을 명시적으로 정의하고, 이를 동시에 달성하는 다중 뷰 세계모델 아키텍처 WEAVER 제안
- 미래 잠재 표현과 보상 값을 플로우 매칭 손실로 동시 예측하는 구조, 아키텍처·메모리·예측 목표 설계 결정을 체계적으로 정리

- 분포외(out-of-distribution) 시나리오에서도 기존 세계모델 대비 우수한 성능 확인
- 학습 코드·모델 체크포인트·평가 데이터셋을 MIT 라이선스로 전면 공개

### (c) 시사점
- 하나의 세계모델 아키텍처로 평가·정책 개선·실시간 계획 세 가지 역할을 모두 실기에서 검증한 사례 확보, 역할 확장 시 재설계 부담을 낮출 근거
- 실제 성공률과의 정량적 상관관계(0.870)를 직접 보고해, 세계모델을 정책 평가 대리자로 쓸 때의 신뢰도 판단 기준 제공
- 완전 공개된 코드·모델·데이터셋은 자체 스택에서 아키텍처·학습 목표를 그대로 재현·비교하는 진입 비용을 크게 낮춤

### (d) 먼저 확인할 점
- 멀티뷰 카메라 구성에 의존 — 자체 단일 시점 또는 제한된 카메라 구성에서도 동일 성능이 유지되는지 확인 필요
- 손-객체 접촉이 조밀한 다지 조작 태스크가 실험군에 포함됐는지, 평가 태스크 구성의 손 중심성 확인 필요
- 플로우 매칭 기반 보상 예측의 안정성이 장기 호라이즌·희소 보상 태스크에서도 유지되는지 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**Wh0: Generative World Models as Scalable Sources of Egocentric Human Hand Manipulation Data**
[arXiv:2606.22136](https://arxiv.org/abs/2606.22136) · Yangtao Chen, Zixuan Chen, Peiyang Wang et al. · source: citation-graph (DexWM 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여
- 사전학습된 생성형 비디오 세계모델을 활용해 언어·객체·장면 조건에 맞는 에고센트릭 인간 손-객체 상호작용 영상(WM-H, 5만 에피소드)을 합성하는 프레임워크 제안
- 합성 영상을 손 모션 재구성과 시각 편집을 통해 로봇이 직접 학습 가능한 감독 신호로 변환하는 2단계 파이프라인 구축
- 소량의 실로봇 데이터와 공동 학습해, 사전학습된 다지 조작 VLA 모델을 배포 가능한 수준으로 적응
- 실제 다지 조작 18개 태스크에서, 로봇 데이터만으로 후속학습한 모델 대비 미학습 태스크 제로샷 성공률을 8.3%에서 38.9%로 대폭 개선
- 생성 스케일 확장과 장면·임바디먼트 정합성이 성능 향상의 핵심 요인임을 어블레이션으로 확인, 코드 전체 공개

### (c) 시사점
- 값비싼 텔레오퍼레이션 수집이나 sim-to-real 격차 없이, 세계모델을 손-객체 상호작용 데이터의 확장 가능한 원천으로 쓰는 구체적 실증 사례 확보
- 실제 에고센트릭 인간 영상을 세계모델로 증강·편집해 로봇 학습에 재활용하는 경로는 사내 에고 데이터 확보 전략에 직접 참고 가능
- 소량의 실로봇 데이터만으로도 대규모 합성 데이터와의 공동 학습이 유효함을 확인, 실로봇 수집 부담을 낮추는 방향성 제시

### (d) 먼저 확인할 점
- 비교 베이스라인이 로봇 데이터 단독 학습 모델 1종에 한정, 다른 데이터 증강·도메인 랜덤화 기법 대비 상대적 우위는 별도 확인 필요
- 손 모션 재구성·시각 편집 파이프라인의 오차가 미세 손가락 접촉·힘 상호작용까지 충실히 보존하는지, 접촉 집약 태스크에서 별도 검증 필요
- G1 + Inspire Hand 특정 임바디먼트 기준 실험, 자체 다지 핸드 형상으로 이전 시 리타겟팅 품질 재검증 필요

## 🥉 논문 3 — 우선순위 ★

**GE-Sim 2.0: A Roadmap Towards Comprehensive Closed-loop Video World Simulators for Robotic Manipulation**
[arXiv:2605.27491](https://arxiv.org/abs/2605.27491) · Boxiang Qiu, Liliang Chen, Yue Liao et al. · source: citation-graph (Ctrl-World 인용)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- 실로봇 텔레오퍼레이션·접촉 집약 상호작용·온로봇 정책 배포 데이터 수천 시간으로 재학습한 액션 조건화 폐루프 비디오 세계 시뮬레이터 GE-Sim 2.0 제안
- 비디오 잠재로부터 고유수용감각 상태를 디코딩해 하류 정책의 다음-청크 예측을 돕는 상태 전문가(state expert) 모듈 도입
- 생성된 롤아웃을 태스크 지시문 대비 채점해 수작업 검수 없이도 기계-검증 가능한 성공 신호·보상을 산출하는 월드 저지(world judge) 모듈 결합
- 단일 H100에서 25프레임 롤아웃을 2.3초에 생성하고 추론 시 최대 4배 프레임 스킵을 지원하는 가속 프레임워크로 장기 호라이즌 평가 실용화
- 공개 리더보드(WorldArena)에서 20억 파라미터 규모로 전용 로봇 세계모델·비공개 범용 비디오 생성기 모두를 상회, 롤아웃·보상 기반 학습이 실제 정책 성능 개선으로 이어짐을 실증

### (c) 시사점
- 비디오 생성 기반 원시-픽셀 예측 경로가 계산 비용 문제를 딛고 실제 정책 평가·보상 산출까지 실용화 단계에 도달했음을 보여주는 구체적 사례 확보
- 수작업 검수 없는 기계-검증 가능한 성공 신호 산출 방식은, 세계모델을 정책 평가 대리자로 활용할 때 평가 파이프라인 자동화의 참고 설계로 활용 가능
- 기존 공개 프레임워크 위에 모듈을 얹어 확장한 개발 경로는, 자체 세계모델 구축 시 처음부터 새로 설계하지 않고 검증된 백본을 재사용하는 대안 제시

### (d) 먼저 확인할 점
- 원시-픽셀 비디오 생성 기반이라 추론 지연·연산 비용이 잠재 표현 기반 접근 대비 여전히 높음, 폐루프 제어 주기 내 통합 가능성 별도 확인 필요
- 월드 저지의 성공 판정 정확도가 손-객체 접촉처럼 미세한 성패 기준을 요구하는 다지 조작 태스크에서도 신뢰할 만한지 검증 필요
- WorldArena 리더보드 순위가 실제 다지 조작 태스크 분포를 얼마나 대표하는지, 벤치마크-실기 정합도 별도 확인 필요

## 💡 컨텍스트 제안

### Tracked literature
- WEAVER([arXiv:2606.13672](https://arxiv.org/abs/2606.13672))와 Wh0([arXiv:2606.22136](https://arxiv.org/abs/2606.22136))를 8편 캡 내 신규 편입 후보로 검토 제안 — 두 논문 모두 공식 GitHub 저장소(코드+모델+데이터 전면 공개)와 실제 로봇 하드웨어 정량 검증을 동시에 갖춰, 현재 핀 논문 중 재현성 근거가 상대적으로 약한 항목보다 강함

### Decision Log
- WEAVER가 정책 개선(co-trained dynamics prior 역할)과 정책 평가를 하나의 아키텍처로 동시에 실기 검증한 결과는, 현재 별도로 다루는 두 역할이 하나의 설계로 통합 가능함을 보여주는 근거로 참조 가능
- GE-Sim 2.0의 월드 저지 모듈(기계-검증 가능한 성공 신호·보상 자동 산출)은, 평가-대리 역할을 실용 단계로 진전시킨 구체적 사례로 참조 가능
- Wh0의 손 모션 재구성 + 시각 편집 기반 데이터 엔진 패턴은, 에고센트릭 인간 영상을 로봇 학습 가능 감독 신호로 변환하는 구체적 구현 사례로 참조 가능

### Anti-topics
