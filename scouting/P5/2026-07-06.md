## 🥇 논문 1 — 우선순위 ★★★

**Bridge-WA: Predicting Where and How the World Changes for Robotic Action**
[arXiv:2607.02195](https://arxiv.org/abs/2607.02195) · Yongjie Bai, Hanting Wang, Mingtong Dai, Qijun Zhong, Yang Liu, Liang Lin · source: citation-graph (WorldVLA·VLA-JEPA·Being-H0.7 3편 동시 인용)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D31](https://img.shields.io/badge/D31-d97706.svg)](#ref-D31)

### (b) 핵심 기여

- **문제 규명** — 기존 world-action model(WAM)은 무거운 생성적 세계 모델이나 조밀한 미래 롤아웃에 의존, 제어와 약결합된 시각 디테일에 용량 낭비
- **경량 증류 프레임워크** — 고정된 미래-변화 교사 모델(future-change teacher)을 세 가지 압축 사전 지식으로 증류: 의도된 결과를 담는 미래 토큰, 개입 지원을 담는 변화 맵, 국소 전이 방향을 담는 모션-플로우 맵
- **WorldBridge 아키텍처** — 다중-소스 어텐션 메모리 + 시공간 편향으로 액션 트랜스포머를 세 사전 지식에 조건화, 추론 시 교사 모델 완전 제거
- **장면-변화 중심 액션 생성** — 배경·조명·방해물 등 노이즈 외형 요인 억제, 분포外 시각 변화에서 특히 뚜렷한 강건성 확보
- **다중 벤치마크 검증** — VLABench·RoboTwin2.0·LIBERO-Plus 시뮬 벤치마크 + 실로봇 평가에서 성공률·진행도·강건성 개선

### (c) 시사점

- **모션-플로우 맵이 3D-플로우 예측 공간을 실전 코드로 구현** — 조밀한 생성이 아닌 압축 사전으로 픽셀 생성 비용 없이 액션 조건화 미래 신호 제공
- **추론 시 교사 모델 완전 폐기 설계** — 배포 비용을 낮추는 방향으로, 무거운 세계 모델 헤드를 유지하는 대안 설계들과 뚜렷이 대비되는 효율 지점 제공
- **분포外 강건성 정량 확보** — 카메라 변화·배경 변화에 대한 정책 강건성을 세계 모델 사전 지식으로 개선한 사례로, 실배치 신뢰도 논의에 참고 가능

### (d) 먼저 확인할 점

- **다지 손 특화 검증 없음** — VLABench·RoboTwin2.0·LIBERO-Plus는 그리퍼 기준 벤치마크로 추정, 다지 손 전이 별도 확인 필요
- **모션-플로우 맵의 구체적 표현 형식** — 3D인지 2D 광류인지, 손-물체 접촉 세밀도까지 포착하는지 본문 확인 필요
- **교사 모델 사전학습 비용** — 증류 대상인 future-change teacher 자체의 학습 비용·데이터 규모가 초록에 명시되지 않음, 전체 파이프라인 비용 재현 시 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**VT-WAM: Visual-Tactile World Action Model for Contact-Rich Manipulation**
[arXiv:2607.02503](https://arxiv.org/abs/2607.02503) · Shuai Tian, Yupeng Zheng, Yuhang Zheng, Songen Gu, Yujie Zang, Yuxing Qin, Weize Li, Haoran Li, Wenchao Ding, Dongbin Zhao · source: keyword-sweep (cs.RO, "world action model" + tactile/contact)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D31](https://img.shields.io/badge/D31-d97706.svg)](#ref-D31)

### (b) 핵심 기여

- **문제 규명** — 접촉 집약적 조작에 필요한 국소 변형·압력·미끄러짐·마찰 신호는 시간적으로 희소, 시각 관측만으로는 포착 불가; 기존 비주오택타일 정책은 촉각 관측을 액션 예측에 직접 투입할 뿐, 액션 생성 과정에서 촉각 변형 동역학을 명시적으로 모델링하지 않음
- **VT-WAM 프레임워크** — 미래 시각 예측·촉각 변형 예측·액션 예측을 하나의 플로우 매칭 프레임워크 안에서 공동 학습
- **비대칭 Mixture-of-Transformers(MoT) 어텐션** — 첫 프레임 시각 앵커와 시간적 촉각 동역학을 연결
- **접촉-게이트 Action-Visual-Tactile Attention Guidance(AVTAG)** — 접촉 국면에서 액션 쿼리가 촉각 증거에 의존하도록 유도
- **실로봇 검증** — 6종 실환경 접촉 집약적 조작 태스크에서 평균 성공률 71.67% 달성, Fast-WAM 대비 26.67%p·OmniVTLA 대비 35.84%p 개선, ablation으로 촉각 변형 동역학 모델링과 접촉-국면 어텐션 유도 각각의 기여 확인

### (c) 시사점

- **촉각을 액션 조건화 예측 공간에 명시적으로 포함하는 구체 사례** — 현재 latent/3D-flow 중심 예측 공간 논의에 촉각 변형 채널 추가 여지 제시
- **접촉 국면 한정 어텐션 게이팅** — 접촉 전후 구간을 구분해 촉각 신호 의존도를 동적으로 조절하는 설계, 접촉 집약적 다지 조작에서 참고 가능한 구조
- **동일 태스크군 내 두 베이스라인 대비 정량 우위** — 촉각 포함 WAM 계열 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점

- **다지 손 특화 검증 없음** — 접촉 집약적 조작이나 그리퍼/엔드이펙터 기준 실험으로 추정, 다지 손 촉각 센서 배치·해상도 차이에 따른 전이 확인 필요
- **코드·데이터 공개 여부 초록 기준 확인 불가** — 프로젝트 페이지 존재하나 접속 확인 실패(HTTP 403), 재현성 직접 검증 필요
- **베이스라인 비교의 태스크 중첩도** — Fast-WAM·OmniVTLA와 동일 태스크·동일 하드웨어 조건 비교인지 본문 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**Human-Centric Transferable Tactile Pre-Training for Dexterous Robotic Manipulation (TTP)**
[arXiv:2607.01067](https://arxiv.org/abs/2607.01067) · Chi Zhang, Penglin Cai, Ziheng Xi, Haoqi Yuan, Hao Luo, Wanpeng Zhang, Sipeng Zheng, Chaoyi Xu, Zongqing Lu · source: citation-graph (WorldVLA)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **문제 규명** — 촉각은 다지·접촉 집약적 태스크에 필수 모달리티이나 하드웨어·수집 시스템 한계로 기존 촉각 데이터셋은 소규모·좁은 접촉 커버리지에 그침; 촉각 포함 VLA는 동역학-무관 사후학습에 갇혀 성능 상한 제약
- **H-Tac 데이터셋** — 160시간 규모 에고센트릭 인간 동영상, 300개 이상 태스크, 13.5만 에피소드 규모 대형 촉각-액션 데이터셋 구축
- **Transferable Tactile Pre-Training(TTP)** — 인간 데이터 기반 촉각 사전학습을 세밀 로봇 태스크로 전이하는 시스템, 사전학습·사후학습 전 구간에서 통합 촉각·액션 공간 사용해 인간→로봇 전이 시 사전 지식 보존
- **촉각 전문가(tactile expert)의 미래 촉각 예측** — 접촉 동역학과 정밀 물리 상호작용을 명시적으로 모델링
- **검증** — 시뮬레이션과 실로봇 양쪽에서 우수한 성능, 강건한 일반화와 세밀 조작 능력 실증

### (c) 시사점

- **DexWM 계열의 대규모 데이터 축 확장** — 에고센트릭 인간 동영상에서 촉각까지 포함한 대규모 사전학습 데이터셋 구축 사례로, 손-물체 세계 모델의 데이터 병목 해소 경로에 촉각 채널 추가
- **미래 촉각 예측을 접촉 동역학 모델링 수단으로 사용하는 구조** — 예측 기반 동역학 사전에 촉각을 포함하는 구체적 구현 참고 가능
- **인간→로봇 통합 촉각·액션 공간** — 사전학습 지식을 사후학습까지 보존하는 설계로, 인간 동영상 기반 세계 모델의 로봇 전이 비용 절감 방향과 부합

### (d) 먼저 확인할 점

- **H-Tac 데이터셋 공개 여부 초록 기준 확인 불가** — 재현성 직접 검증 필요
- **정량 성능 수치 초록에 미기재** — 성공률·베이스라인 비교 구체 수치는 본문 확인 필요, 정성적 우수성 서술에 그침
- **다지 손 특화 검증 범위** — "세밀 조작" 태스크 종류와 다지 손 하드웨어 사용 여부 본문 확인 필요, 그리퍼 기준 실험 포함 가능성

## 🥉 논문 4 — 우선순위 ★

**DexFuture: Hierarchical Future-State Visuomotor Targeting for Bimanual Dexterous Tool Use**
[arXiv:2606.05699](https://arxiv.org/abs/2606.05699) · Runfa Blark Li, Kuang-Ting Tu, Nikola Raicevic, Dwait Bhatt, Xinshuang Liu, Keito Suzuki, Ki Myung Brian Lee, Nikolay Atanasov, Truong Nguyen · source: citation-graph (WorldVLA)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **문제 규명** — 양손 다지 도구 사용은 고차원 손 형상과 복잡한 손-도구-물체 동역학·접촉으로 어려움; 기존 제어 정책은 시연이 제공하는 미래 참조에 의존하거나, 미래 액션-조건화 세계 모델이 고차원 액션 시퀀스에 대한 느린 온라인 계획을 요구
- **DexFuture 계층 구조** — 고수준 Future-State Visuomotor Target Predictor(에고센트릭 RGB·고유수용감각·기하 이력 조건화, horizon-conditioned 트랜스포머로 다단계 미래 목표 궤적 생성)와 저수준 Target-Conditioned Structured Dexterous Policy(링크별 트랜스포머로 목표 추종) 결합
- **거친 미래 참조 생성과 세밀 액션 제어 분리** — 느린 장기 시맨틱 예측과 고빈도 실행을 분리하는 설계
- **정량 결과** — OakInk2 양손 도구 사용 태스크에서 특권-오라클 성능의 90% 달성(참조 없는 정책은 7%), 60Hz 동작 — DexWM 스타일 Cross-Entropy Method(CEM) 계획 대비 약 250배 빠름

### (c) 시사점

- **DexWM 대비 직접적인 속도·구조 델타 제시** — 이 파일럿의 최상위 핀 논문(DexWM)이 사용하는 느린 온라인 CEM 계획 방식과 정면으로 비교, 계층적 분리로 250배 가속이라는 구체 수치 확보
- **미래 상태 예측을 액션 계획과 분리하는 아키텍처 대안** — 세계 모델 예측과 정책 실행을 하나의 온라인 루프로 묶지 않고 별도 예측기·정책기로 나누는 설계, 통합 자기회귀형(D29 대안 방향)과 대비되는 참고 지점
- **양손 다지 도구 사용이라는 좁고 어려운 태스크군에서 검증** — 다지 손 특화 세계 모델 계열의 난이도 높은 벤치마크로 활용 가능

### (d) 먼저 확인할 점

- **실로봇 검증 여부 초록에 명시 없음** — OakInk2는 인간 손-물체 상호작용 데이터셋 기반 벤치마크로, 실로봇 배포 증거인지 시뮬레이션 평가인지 본문에서 가장 먼저 확인 필요
- **코드·데이터 공개 여부 초록 기준 확인 불가** — OakInk2는 공개 데이터셋이나 DexFuture 자체 구현체 공개 여부 별도 확인 필요
- **CEM 계획 대비 속도 비교의 공정성** — 동일 하드웨어·동일 정밀도 조건에서의 250배 수치인지, 온보드 vs 오프라인 계획 조건 차이 본문 확인 필요

- Methodology 3 — VLABench·RoboTwin2.0·LIBERO-Plus·실로봇 4종 벤치마크, 분포外 시각 변화 강건성 정량 비교
- Sim2Real 3 — 실로봇 평가 포함, 분포外 조건에서도 개선 정량 확인

**VT-WAM (12/15)**
- Relevance 3 — D28(촉각 변형 동역학 명시적 모델링)·D30(촉각 예측 공간 확장)·D31(접촉-게이트 액션 조건화) 동시 접촉

- Reproducibility 1 — 프로젝트 페이지 접속 확인 실패(HTTP 403), 코드·데이터 공개 여부 초록 기준 확인 불가

**DexFuture (10/15)**
