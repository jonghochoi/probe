## 🥇 논문 1 — 우선순위 ★★★

**PhysMani: Physics-principled 3D World Model for Dynamic Object Manipulation**
[arXiv:2607.01938](https://arxiv.org/abs/2607.01938) · Peng Yun, Shouwang Huang, Hao Li et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- 발산-없는(divergence-free) 3D 가우시안 속도장을 온라인 최적화로 학습하는 물리 원리 기반 세계 모델 제안
- 예측된 3D 장면 미래 동역학을 학습형 토큰 기반 cross-attention 모듈로 정책에 결합하는 future-aware 액션 정책 결합 구조
- 빠르게 움직이는 동적 물체 조작에 특화된 PhysMani-Bench(16개 태스크) 신규 벤치마크 공개
- 시뮬레이션·실제 로봇 실험 모두에서 강력한 베이스라인 대비 우수한 성공률 입증

### (c) 시사점
- 동적(이동) 물체 조작에서 물리 원리 기반 3D 표현이 순수 latent 예측 대비 경쟁력 있는 대안으로 부상
- 온라인 최적화 기반 속도장 방식은 별도 대규모 사전학습 없이도 물리적으로 타당한 미래 예측 가능성 시사
- 커스텀 벤치마크(PhysMani-Bench) 공개로 동적 조작 평가 기준점 추가 확보

### (d) 먼저 확인할 점
- 3D 가우시안 표현의 실시간 추론 비용 — 온라인 최적화 루프가 저지연 제어와 양립하는지 확인 필요
- PhysMani-Bench 16개 태스크의 난이도·다양성이 자체 조작 스위트 대비 대표성 있는지 검증 필요
- 실제 로봇 실험의 물체 형상·재질 범위가 제한적일 가능성 — 파지 대상 다양성 확장 시 재검증 필요

## 🥈 논문 2 — 우선순위 ★★

**RynnWorld-4D: 4D Embodied World Models for Robotic Manipulation**
[arXiv:2607.06559](https://arxiv.org/abs/2607.06559) · Haoyu Zhao, Xingyue Zhao, Siteng Huang et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여
- RGB·깊이·광학 흐름(RGB-DF)을 하나의 통합 diffusion 과정에서 동시 생성하는 4D 세계 모델 제안
- 외형·기하·모션이 일관되게 진화하도록 cross-modal attention과 frame-wise 3D RoPE를 결합한 tri-branch 아키텍처
- 에고센트릭 인간·로봇 조작 영상 2억 5,440만 프레임 규모의 Rynn4DDataset 신규 공개
- 4D 내부 표현을 단일 forward pass로 소비해 다단계 디노이징 없이 로봇 액션을 출력하는 역동역학(inverse dynamics) 정책 헤드 결합
- 실제 로봇 양손(bimanual) 다지 조작 태스크에서 최고 성능 달성, 특히 공간 정밀도·시간 협응이 요구되는 과제에서 우수

### (c) 시사점
- 깊이·광학 흐름을 명시적으로 결합한 표현이 순수 2D 픽셀 예측 대비 정책 학습과의 격차를 좁히는 근거 확보
- 대규모 에고센트릭 데이터셋 공개는 사내 에고 영상 확보 전략의 참조 기준점으로 활용 가능
- 역동역학 헤드가 다단계 생성 없이 폐루프 제어를 가능케 해, 세계 모델 도입 시 추론 지연 우려를 완화하는 설계 사례 제공

### (d) 먼저 확인할 점
- RGB·깊이·광학 흐름 3중 모달리티 동시 생성의 학습 비용 — 자체 스택 규모에서 재현 가능한 수준인지 확인 필요
- 254M 프레임 데이터셋의 깊이·광학 흐름 라벨이 의사(pseudo) 라벨 기반 — 라벨 품질이 하위 정책 성능에 미치는 민감도 점검 필요
- 양손 다지 조작 SOTA 주장의 비교 베이스라인 구성 — 논문 본문에서 공정성(동일 데이터·동일 백본) 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**RynnWorld-Teleop: An Action-Conditioned World Model for Digital Teleoperation**
[arXiv:2607.06558](https://arxiv.org/abs/2607.06558) · Haoyu Zhao, Xingyue Zhao, Hangyu Li et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여
- 물리적 텔레오퍼레이션을 대체하는 "디지털 텔레오퍼레이션" 개념 제안 — 실제 로봇 대신 생성형 세계 모델이 시연 데이터를 합성
- 오퍼레이터의 손-포즈 스트림이 로봇 중심 생성형 세계 모델을 구동해 단일 참조 이미지로부터 고품질 에고센트릭 영상 합성
- 기록된 포즈 스트림은 임바디먼트에 무관한 액션 라벨로, 표준 리타겟팅을 통해 임의의 목표 로봇에 이전 가능
- 깊이 인지 스켈레톤 조건화·인간→로봇 점진 학습·스트리밍 자기회귀 증류를 결합, 단일 H100 GPU에서 40+ FPS 실시간 생성 달성
- 합성 데이터만으로 학습한 정책이 다지·양손 태스크에서 제로샷 Sim2Real 전이 달성, 실제 데이터셋 증강 시 성공률 추가 개선

### (c) 시사점
- 물리적 텔레오퍼레이션 병목(하드웨어·작업공간에 종속된 오퍼레이터 시간)을 우회하는 데이터 확보 경로로서 세계 모델 활용 가능성 입증
- 손-포즈 스트림 기반 임바디먼트-무관 액션 라벨 방식은 사내 에고 데이터 확보·리타겟팅 파이프라인에 참조할 만한 설계
- 실시간(40+ FPS) 생성 성능은 세계 모델을 데이터 엔진으로 상시 가동하는 것이 현실적임을 시사

### (d) 먼저 확인할 점
- 오퍼레이터 손-포즈만으로 생성된 영상의 물리적 정합성(접촉·힘 상호작용) 검증 방식이 본문에 구체적으로 제시되는지 확인 필요
- 제로샷 Sim2Real 전이 결과가 특정 손-형태·로봇 임바디먼트 조합에 국한되지 않는지, 임바디먼트 다양성 확장 시 재검증 필요
- 실제 데이터 증강 효과의 크기가 태스크 난이도에 따라 편차가 큰지, 접촉 집약적 태스크에서의 저하 여부 확인 필요

## 🥉 논문 4 — 우선순위 ★

**GigaWorld-1: A Roadmap to Build World Models for Robot Policy Evaluation**
[arXiv:2607.02642](https://arxiv.org/abs/2607.02642) · GigaWorld Team, Angyuan Ma, Boyuan Wang et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28)

### (b) 핵심 기여
- 실제 로봇 텔레오퍼레이션 데이터와 매칭된 정책 롤아웃으로 구성한 WMBench 벤치마크 신규 구축
- 비디오 세계 모델 7종·액션 표현 4종·32만 4천여 개 시뮬레이션 롤아웃을 실제 로봇 실행과 정합 비교하는 대규모 체계적 연구
- 평가자 품질은 단기 시각적 사실성보다 장기간(long-horizon) 액션-충실 롤아웃 일관성에 좌우된다는 핵심 인사이트 도출
- 연구 결과를 반영해 정책 평가에 특화된 GigaWorld-1 모델 구축, 코드·모델·데이터셋·툴킷 전면 공개

### (c) 시사점
- 세계 모델을 정책 평가 대리자로 쓸 때 시각적 화질보다 장기 롤아웃의 행동 충실도가 더 중요하다는 정량적 근거 확보
- 아키텍처 선택(액션 인코딩·메모리 설계·평가자 특화 후속학습)이 실제 로봇 행동과의 정합도를 좌우한다는 설계 지침 제공
- 대규모 공개 벤치마크(WMBench)는 향후 자체 세계 모델 평가 시 외부 참조 기준으로 활용 가능

### (d) 먼저 확인할 점
- 로드맵·체계적 연구 성격이 강해 다지 조작 특화 평가는 상대적으로 얕을 가능성 — 손-객체 상호작용 세부 태스크 커버리지 확인 필요
- 32만여 시뮬레이션 롤아웃 대비 실제 로봇 실행 비교 규모가 상대적으로 작을 수 있어, 정합도 결론의 일반화 범위 점검 필요
- 평가자로서의 역할에 최적화된 모델이라 정책 학습용 동역학 사전(prior)으로 그대로 전용 가능한지는 별도 검증 필요

## 💡 컨텍스트 제안

### Tracked literature
- RynnWorld-4D([arXiv:2607.06559](https://arxiv.org/abs/2607.06559))·RynnWorld-Teleop([arXiv:2607.06558](https://arxiv.org/abs/2607.06558))를 8편 캡 내 교체 후보로 검토 제안 — 실제 로봇 양손 다지 조작에서의 정량적 결과가 현재 핀 논문 중 실기 검증이 상대적으로 약한 항목보다 강함
- PhysMani([arXiv:2607.01938](https://arxiv.org/abs/2607.01938))를 AHEAD의 대안적 3D 표현 사례로 병기 검토 제안 — 동일한 동적 조작 문제를 다른 표현(3D 가우시안 속도장)으로 접근

### Decision Log
- RynnWorld-4D의 RGB-깊이-광학흐름 결합 표현은 raw-pixel과 latent/3D-flow의 경계를 흐리는 사례 — 현재 raw-pixel 보류 방침의 재검토 트리거는 아니나 하이브리드 표현 사례로 참고할 가치
- GigaWorld-1의 "장기 롤아웃 행동-충실도가 시각적 화질보다 중요" 결론은 eval-in-imagination 역할이 향후 활성화될 때 설계 기준으로 참조 가능한 근거

### Anti-topics
- 이동(mobility)·조작(manipulation)을 동시에 다루는 WAM(예: 이번 회차에서 제외된 ABot-M0.5, Worldscape-MoE 계열)에 대해, 조작 전용 세부 평가가 없는 경우 배제 규칙을 명시적으로 추가하는 안 검토 제안
