## 🥇 논문 1 — 우선순위 ★★★

**Robot Self-Improvement via Human-Video Dynamics Models**
[arXiv:2606.21406](https://arxiv.org/abs/2606.21406) · Hanzhi Chen, Anran Zhang, Simon Schaefer, Kejia Chen, Shi Chen, Daniel Cremers, Oier Mees, Stefan Leutenegger · source: citation-graph (Ctrl-World)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여
- 인간 동영상에서 임베디먼트-불가지 액션·동역학·가치 표현 학습, 로봇 자체 롤아웃 평가·수정·개선에 필요한 예측 기반 제공
- Dynamics-Guided Action Correction(DGAC) — 학습-프리 방식, 실패 상태를 쿼리로 삼아 학습된 모델이 교정 액션 제안·순위화, 실패를 다음 정책 업데이트 지도 신호로 전환
- 모바일 매니퓰레이터·고정 매니퓰레이터 두 임베디먼트, 실로봇 태스크 7종에서 성공률 40%→81% 개선 실증

### (c) 시사점
- 별도 파인튜닝 없이 기존 정책 위에 붙는 교정 계층 — 도입 장벽 낮음
- 인간 동영상만으로 동역학·가치 표현 학습 — 로봇 시연 데이터 의존도를 낮추는 방향과 부합
- 실패 사례를 자동으로 학습 신호화 — 지속적 자기개선 루프 설계에 참고 가능

### (d) 먼저 확인할 점
- 프로젝트 페이지 존재하나 접속 확인 실패 — 코드·데이터 공개 여부 직접 재현성 검증 필요
- 다지 손 특화 검증 없음, 그리퍼/평행 집게 매니퓰레이터 중심 실험으로 추정 — 다지 손 전이 별도 확인 필요
- 학습-프리 특성상 교정 품질이 사전학습된 동역학·가치 모델 정확도에 강하게 의존 — 실패 모드 분석 부족

## 🥈 논문 2 — 우선순위 ★★

**GaussianDream: Feed-Forward 3D Gaussian World Model for Robotic Manipulation**
[arXiv:2605.20752](https://arxiv.org/abs/2605.20752) · Zijian Zhang, Yuqing Jiang, Qian Cheng, Xiaofan Li, Si Liu, Ding Zhao, Ping Luo, Weitao Zhou, Haibao Yu · source: citation-graph (WorldVLA)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여
- Feed-forward 3D Gaussian world-model plug-in — VLA 인코더에 학습 가능한 GaussianDream Query 삽입, 현재 프레임 3D 구조와 단기 미래 진화 동시 포착
- 학습 시 정적 재구성 헤드+미래 예측 헤드로 3D Gaussian 상태 감독(RGB·depth·pseudo 3D scene-flow), 추론 시 두 헤드 모두 제거하고 학습된 prefix만 액션 생성에 사용
- LIBERO 98.4%, RoboCasa Human-50 54.8%, 실로봇 태스크 50.0% 달성, 기존 비디오 기반 3D-강화 VLA 대비 추론 효율 우위

### (c) 시사점
- 추론 시점에 무거운 재구성·예측 헤드를 모두 버리는 설계 — 배포 비용 부담 낮음
- 3D 명시적 표현(Gaussian)을 world-model 보조 신호로 쓰는 대안 경로 — 잠재 표현 일변도 접근과 비교 지점 제공
- 다중 벤치마크(LIBERO·RoboCasa·실로봇) 동시 검증 — 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 다지 손 조작 특화 검증 없음, LIBERO/RoboCasa 대부분 그리퍼 기준 벤치마크로 추정 — 다지 손 전이 확인 필요
- 실로봇 성공률(50.0%)이 시뮬레이션 대비 상대적으로 낮음 — sim-to-real 격차 원인 분석 필요
- 코드·데이터 공개 여부 초록 기준 확인 불가 — 재현성 직접 검증 필요

## 🥉 논문 3 — 우선순위 ★

**Not All Actions Are Equal: Rethinking Conditioning for Dexterous World Model**
[arXiv:2606.27325](https://arxiv.org/abs/2606.27325) · Zizhao Yuan, Zhengtu Liang, Taowen Wang, Qiwei Liang, Yichi Wang, Yunheng Wang, Yu Fang, Lusong Li, Zecui Zeng, Renjing Xu · source: citation-graph (Ctrl-World)

### (a) 관련 Pillar / Decision
[![P5](https://img.shields.io/badge/P5-e0d5f5.svg)](#ref-P5) / [![D31](https://img.shields.io/badge/D31-d97706.svg)](#ref-D31) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여
- 고차원 다지 액션의 이질성(대규모 모션과 미세 신호가 여러 자릿수 스케일로 공존) 문제를 액션-컨디셔닝 관점에서 명시적으로 분석
- DexAC — 액션을 단일 압축 표현이 아닌 차원별 구조화 프로세스로 취급, 액션 토큰화로 차원별 시맨틱 보존 후 로컬 정제+글로벌 변조로 시각 동역학과 정렬
- 객체-장면 사전(prior)을 제공하는 시맨틱 브랜치 추가로 고수준 시맨틱 그라운딩 보완, EgoDex·EgoVerse에서 FID·FVD·PCK 개선, 다른 백본으로도 확장성 검증

### (c) 시사점
- 액션 컨디셔닝을 "균일 압축"이 아닌 "구조화 과정"으로 재정의하는 관점 — 다지 손처럼 자유도 높은 액션 공간 처리 방식에 직접 참고
- 시맨틱 브랜치 분리 설계 — 동역학 정밀도와 고수준 의미 이해를 별도 경로로 다루는 아키텍처 참고 가능
- 여러 백본에 이식 가능하다는 확장성 주장 — 특정 아키텍처 종속도 낮음

### (d) 먼저 확인할 점
- EgoDex·EgoVerse는 비디오 예측 벤치마크 — 실로봇 정책 배포·Sim2Real 증거 초록에 명시 없음, 가장 먼저 확인할 지점
- 코드·모델 공개 여부 불명 — 재현성 확인 필요
- 베이스라인·ablation 상세는 초록 기준 정성적 결론에 그침, 본문 확인 필요
