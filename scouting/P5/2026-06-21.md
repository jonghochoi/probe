## 🥇 논문 1 — 우선순위 ★★★

**WEAVER, Better, Faster, Longer: An Effective World Model for Robotic Manipulation**
[arXiv:2606.13672](https://arxiv.org/abs/2606.13672) · Arnav Kumar Jain, Yilin Wu, Jesse Farebrother, Gokul Swamy · source: citation-graph (Ctrl-World)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여

- **문제 설정** — 기존 조작 WM은 충실도·일관성·효율성 세 요건 중 두 개 이상에서 타협; 세 요건 동시 달성 사례 부재
- **WEAVER 구조** — 다시점(multi-view) WM; flow-matching 손실로 미래 잠재 표현 + 보상값 동시 예측
- **세 가지 역할 실하드웨어 동시 실증** — 정책 평가(ρ=0.870 실세계 성공률 상관), 정책 개선(π₀.₅ 대비 +38%), 테스트-타임 계획(+14%; 기존 WM 대비 5–10× 속도 향상)
- **OOD 강인성** — 분포 외 시나리오에서도 기존 WM 대비 성능 우세 확인
- **공개 범위** — 코드·모델·비디오 공개 (arnavkj1995.github.io/WEAVER)

### (c) 시사점

- **WM 역할 범위 설계 기준 확보** — "잠재 동역학 사전 + 미래 예측 보조" 역할이 정책 평가·개선·계획 세 방향으로 동시 확장 가능함을 단일 WM에서 최초 실증; 나중 단계 WM 통합 설계 시 역할 범위 출발점 확정
- **Flow-matching 잠재 예측 실용성 확인** — 픽셀 재구성 없이 잠재 표현 + 보상값 예측만으로 실로봇 +38% 개선; 잠재 예측 공간 v1의 실하드웨어 검증
- **비교 기준점 확보** — π₀.₅ 대비 policy improvement 수치와 test-time planning 수치가 공개; 이후 WM 설계 비교에 활용 가능

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 태스크 특화 여부** — π₀.₅ 기반 범용 조작 태스크; 다지 손·접촉 집약적 세부 환경에서의 성능 본문 확인 필요
- **Flow-matching WM 추론 절대 지연** — 기존 WM 대비 5–10× 빠르지만 ms 단위 절대 수치 확인 필요; 폐루프 다지 손 제어 주기와의 정합 여부 미확인
- **잠재 공간 호환성** — 다른 vision backbone(JEPA·DINOv2 등)과 통합 시 잠재 공간 정렬 요건 미확인

## 🥈 논문 2 — 우선순위 ★★

**μ₀: A Scalable 3D Interaction-Trace World Model**
[arXiv:2606.13769](https://arxiv.org/abs/2606.13769) · Seungjae Lee, Yoonkyo Jung, Jusuk Lee, Jonghun Shin · source: citation-graph (Ctrl-World)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) [![D32](https://img.shields.io/badge/D32-d97706.svg)](#ref-D32)

### (b) 핵심 기여

- **예측 단위** — 픽셀 재구성도, 직접 액션 라벨도 아닌 **B-스플라인 3D 트레이스**: 물체·도구·손·접촉 지점 등 상호작용 핵심 포인트의 3D 궤적 예측
- **TraceExtract** — 키포인트 자동 선택 → 전역 정렬 3D 트레이스 구성 → 계층적 언어 캡션 연관의 자동화 파이프라인; 별도 액션 라벨 없이 다양한 비디오 소스에서 학습 가능
- **아키텍처** — 사전학습 VLM 백본 + 모듈러 Trace Expert(각 쿼리를 B-스플라인 제어점으로 표현); 동결 후 embodiment별 액션 전문가와 결합
- **Action-free 사전학습** — 액션 라벨 없는 사전학습; trace-조건부 정책이 π₀(액션 감독 VLA) 대등 성능 달성
- **범용 cross-embodiment 인터페이스** — 동일한 μ₀이 여러 로봇 embodiment 액션 전문가와 결합 가능

### (c) 시사점

- **DexWM 계열 손·접촉 예측의 스케일 확장 경로** — 핑거 키포인트(DexWM) 수준을 3D 트레이스 자동 추출로 일반화; 인터넷 규모 에고센트릭 인간 동영상에서 손·접촉 트레이스 수집 비용 절감 가능성 시사
- **Action-free WM 사전학습 + 분리 액션 전문가 구조 검증** — VLA-JEPA two-stage 방향과 정합; WM 동결 후 태스크별 액션 헤드만 교체하는 모듈 구조 경로 구체화
- **잠재/3D-flow 예측 공간의 실용 구현 형태 제시** — B-스플라인 3D 궤적이 "3D-flow" 예측 단위의 구현체; 접촉 집약적 다지 조작 트레이스 특화 가능성

### (d) 먼저 확인할 점

- **손·접촉 트레이스 해상도 검증** — DexWM 핑거 키포인트 수준의 세밀한 손-물체 접촉 해상도 달성 여부 본문 확인 필요
- **실로봇 검증 규모** — "cross-embodiment manipulation" 언급이나 실하드웨어 태스크 수·성공률 상세 본문 확인 필요
- **TraceExtract 오류 전파** — 자동 3D 트레이스 추출 오류가 정책 품질에 미치는 영향 미확인; 접촉 밀집 환경에서의 키포인트 선택 안정성 미확인

## 🥈 논문 3 — 우선순위 ★★

**ImageWAM: Do World Action Models Really Need Video Generation, or Just Image Editing?**
[arXiv:2606.19531](https://arxiv.org/abs/2606.19531) · Yuyang Zhang, Wenyao Zhang, Zekun Qi, He Zhang · source: keyword-sweep (cs.RO)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여

- **문제 제기** — 비디오 WAM 세 가지 구조적 한계: 다중-프레임 토큰 추론 비용 / 태스크 무관 외관 변화에 모델 용량 소비 / 장기 오차 누적
- **ImageWAM** — 사전학습 이미지 편집 모델을 WAM으로 재활용; 비디오 생성 대신 현재→목표 프레임 변환을 세계 모델 사전(prior)으로 사용
- **추론 메커니즘** — 이미지 편집 디노이징의 KV 캐시를 잠재 world-action 컨텍스트로 flow-matching 액션 전문가에 주입; 추론 시 목표 프레임 자체는 디코딩 불필요
- **실용 수치** — 비디오 WAM 대비 FLOPs 1/6, 지연 1/4 감소
- **어텐션 분석** — 편집 캐시가 태스크 관련 변화 영역에 집중함을 확인; 이미지 편집이 유효한 world-action 사전임을 지지

### (c) 시사점

- **예측 공간 재설계 근거 추가** — 비디오 생성 대신 이미지 편집 사전만으로 policy conditioning 충분함을 실증; 불필요한 외관 모델링 부담 절감 방향 구체화
- **분리 WM + 액션 전문가 이중 구조 검증** — 독립 이미지 편집 WM(고정 사전학습) + flow-matching 액션 전문가 분리 구조; WM만 독립 교체 가능한 모듈 설계 경로
- **추론 속도 FLOPs 기준점** — 1/6 FLOPs·1/4 지연 수치가 WM 통합 실시간성 비교 기준으로 활용 가능

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 태스크 적용 여부** — 시뮬레이터·실세계 실험 포함이나 다지 손 특화 접촉 태스크 결과 본문 확인 필요
- **단일 프레임 목표의 장기 접촉 한계** — 장기 연속 접촉 동역학 예측이 현재→목표 단일 프레임 편집으로 충분한지 미확인; 다지 손 세밀 제어 연속성 미검증
- **이미지 편집 사전 모델 선택 민감도** — 어떤 이미지 편집 모델을 사용하느냐에 따른 성능 편차 미확인

## 🥉 논문 4 — 우선순위 ★

**LaWAM: Latent World Action Models for Efficient Dynamics-Aware Robot Policies**
[arXiv:2606.15768](https://arxiv.org/abs/2606.15768) · Jialei Chen, Kai Wang, Kang Chen, Shuaihang Chen · source: citation-graph (Being-H0.7, VLA-JEPA, World Guidance)

### (a) 관련 Pillar / Decision

[![P5](https://img.shields.io/badge/P5-17becf.svg)](#ref-P5) / [![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) [![D29](https://img.shields.io/badge/D29-d97706.svg)](#ref-D29) [![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30)

### (b) 핵심 기여

- **LaWM** — 사전학습 vision foundation 모델 잠재 공간에서 latent action model 훈련; forward decoder를 재활용해 미래 관측 특징(feature) 예측
- **LaWAM** — LaWM이 예측한 잠재 시각 서브골(subgoal)을 조건으로 액션 생성; 픽셀 재구성 불필요
- **벤치마크 성능** — LIBERO 98.6%, RoboTwin 91.22% 달성; 실세계 조작 태스크 포함
- **추론 효율** — 187 ms/action-chunk; 픽셀-공간 WAM 대비 최대 24× 지연 감소

### (c) 시사점

- **잠재 서브골 WAM의 실용성 재확인** — VLA-JEPA 방향과 정합하는 구현; LIBERO·RoboTwin·실세계 세 벤치마크 동시 검증으로 잠재 예측 공간 v1 실용성 뒷받침
- **Vision foundation decoder 재활용 경로** — 별도 WM 사전학습 없이 기존 vision foundation 모델의 forward decoder를 WM 예측기로 전환; 추가 사전학습 비용 절감 가능성
- **187 ms 지연 기준점** — 잠재 WAM 실시간 제어 가능 여부 판단에 사용 가능한 구체 수치

### (d) 먼저 확인할 점

- **다지 손·접촉 집약적 태스크 미명시** — LIBERO·RoboTwin은 범용 조작 벤치마크; 다지 손 접촉 집약적 환경 일반화 본문 확인 필요
- **Vision foundation 모델 의존성** — 사용 foundation 모델에 따른 성능 민감도 미확인; DINOv2·JEPA 등 대안 backbone과의 호환성 미확인
- **VLA-JEPA 대비 실질 차별화** — 잠재 예측 WM 방향은 동일; foundation 모델 decoder 재활용 방식의 정량적 이점 비교 필요

- **제안** — WEAVER ([arXiv:2606.13672](https://arxiv.org/abs/2606.13672)) 신규 추가
- **근거** — Ctrl-World는 raw-pixel 생성 분기(D30 deferred); WEAVER는 잠재 예측 기반으로 D28 세 역할(평가·개선·계획)을 단일 WM에서 실하드웨어 동시 달성, 코드·모델 공개. Ctrl-World의 "eval-in-imagination" 추적 역할을 WEAVER가 더 강력하게 흡수
- **트리거** — 코드·모델 검토 후 다지 손 접촉 집약적 태스크 적용 가능성 확인 시 교체 확정; Ctrl-World는 비핀 Methodology base로 이동 제안

### Decision Log

- **[![D28](https://img.shields.io/badge/D28-d97706.svg)](#ref-D28) deferred 역할 실현 신호 강화** — WEAVER가 policy eval·improvement·planning 세 역할을 단일 WM에서 실하드웨어 동시 달성; 직전 보고서(2026-06-14)의 PLUME RL-env 신호에 이어 D28 deferred 역할들의 현 세대 실현 가능성 재확인
- **단계** — D28 서술에 "deferred 역할들(eval, planning, improvement)이 현 세대 WM에서 실현 가능함 (WEAVER 선례)" 추기 여부 판단 권고
- **[![D30](https://img.shields.io/badge/D30-d97706.svg)](#ref-D30) 예측 공간 v1 수렴 확인 + 파생 후보 등장** — 이번 주 3편(WEAVER·μ₀·ImageWAM)이 모두 비디오 생성 대비 잠재·3D 트레이스·이미지 편집을 선택, D30 v1(잠재/3D-flow) 방향 수렴; "이미지 편집(ImageWAM 계열)"과 "3D 트레이스(μ₀ 계열)"를 D30 deferred 후보로 병기 여부 판단
