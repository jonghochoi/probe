## 🥇 논문 1 — 우선순위 ★★★

**TAM: Torque Adaptation Module for Robust Motion Transfer in Manipulation**
[arXiv:2606.06218](https://arxiv.org/abs/2606.06218) · Dongwon Son, Florian Shkurti, Jason Lee, Naman Shah, Beomjoon Kim, Dieter Fox · source: citation-graph (HORA)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 동일 로봇의 두 인스턴스 간, 혹은 시뮬레이션-실물 간 약간의 토크 불일치가 접촉 타이밍·모드를 무너뜨려 접촉 집약 동작 전체를 실패로 이끔; DR은 정책을 보수적으로 만들고, 시스템 식별(SysID)은 로봇·페이로드마다 실물 데이터 재수집 요구
- **TAM 핵심 설계** — 정책의 명령(action)과 로봇의 토크 인터페이스 사이에 삽입되는 학습 모듈
  - **이력 인코더**: 고유감각(proprioception) 이력을 잠재 상태로 임베딩
  - **토크 어댑터**: 잔차 토크 보정값(residual torque correction)을 출력해 이상적 로봇의 거동으로 수렴
  - **정책 독립성**: 고유감각 이력에만 의존 → 관절 목표·엔드이펙터 목표·직접 토크 등 다양한 행동 공간의 정책 재학습 없이 동일 TAM 가중치 재사용 가능
- **학습 방식** — 무작위화 시뮬레이션에서 다중 로봇 사전학습 후 로봇-특화 파인튜닝(실물 데이터 불필요); DR은 정책이 아닌 TAM에만 적용
- **실물 검증** — Franka Panda 제로샷 이전: 비전 기반 박스 푸시 RL 정책·플립 BC 정책·MPC 볼-온-플레이트 세 종류에서 온라인 SysID 및 RMA 기준선 대비 성능 향상
- **진정한 신규성** — 정책 학습에서 sim2real 어댑테이션을 완전히 분리한 첫 토크 수준 모듈; RMA 계열 적응을 손 수준 이하 인터페이스로 내려 적용 범위를 모든 정책 유형으로 확장

### (c) 시사점

- **System0 sim2real에서 DR 부담 분리 가능성** — System0 RL 정책 자체는 접촉 안정화 보상 설계에 집중하고, 접촉 동역학(마찰·강성·컴플라이언스) 격차는 TAM 계열 토크 어댑터가 런타임에 흡수하는 분리 구조 실현 가능성 확인
- **다정책 재사용 경로** — 동일 어댑터 가중치가 RL·BC·MPC 정책에 공통 적용; System1 위계 안에서 정책 교체 시 어댑터 재학습 불필요할 수 있음
- **실물 이전 비용 기준점** — 실물 데이터 0건 fine-tuning 검증; System0 실물 이전 단계에서 TAM 계열 토크 어댑터의 독립 ablation 비용 추정 근거

### (d) 먼저 확인할 점

- **고DoF 다지 손 미검증** — Franka 단관절 이력 기반 검증; 16-DOF LEAP·Shadow Dexterous Hand급 손가락 수준 접촉 안정화에서 고유감각 이력 차원이 커짐에 따른 인코더 스케일·레이턴시 적합성 별도 확인 필요
- **접촉 유지 특화 시나리오 부재** — 박스 푸시·플립·MPC 볼 균형 과제 검증; 슬립 전 전단력 이동 억제·파지 후 접촉 유지 등 System0 핵심 시나리오에서 잔차 보정이 충분한지 직접 실험 미제시
- **제어 루프 주파수 불명** — 500 Hz 이상 고주파 접촉 안정화에서 이력 인코더 추론 레이턴시가 허용 범위 안에 있는지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Impedance MPC with Disturbance Estimation for Dexterous Hand Control**
[arXiv:2606.14606](https://arxiv.org/abs/2606.14606) · Yongyan Cao · source: arXiv 키워드 스윕 (dexterous hand + contact)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D16](https://img.shields.io/badge/D16-d97706.svg)](#ref-D16) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 다지 손은 정밀 경로 추종과 안전한 컴플라이언트 접촉 유지라는 상충 목표를 동시에 달성해야 하나, 고정 게인 컨트롤러로는 두 목표 모두 만족 불가
- **Impedance MPC 핵심 설계** — actuator-agnostic(구동기 무관) 500 Hz Impedance MPC 프레임워크
  - 건식·케이블·공압·비틀림·직렬탄성 등 임의 건(tendon) 전달계를 상수계수 이중 적분기로 환원 → QP 비용 역행렬 오프라인 사전계산, 10-스텝 예측 지평 QP를 500 Hz에서 실행
  - 접촉력(ISO/TS 15066)·구동 한계·저크(jerk) 하드 제약 적용
  - 인코더 전용 증강 칼만 외란 추정기 → 임의 정상 접촉 부하 하에서 정상상태 오차를 0으로 구동
- **검증** — 유압 구동 손가락(실물) 500 Hz: 0.5 mrad RMS / 0.1 mrad 정상상태 / 6.6 mrad 피크(1.5 Nm 접촉 하), 고전 임피던스 대비 각 183×·1500×·23× 개선; 16-DOF LEAP Hand MuJoCo 시뮬레이션 2.5 N 파지 부하 외란에서 0.7 s 내 회복
- **진정한 신규성** — pHRI 아키텍처를 다지 손 손가락 수준에 최초 이식; 구동기 종류에 무관한 단일 프레임워크로 500 Hz 접촉력 하드 제약 달성

### (c) 시사점

- **500 Hz 손가락 수준 접촉력 제약 제어 실현 근거** — System0가 슬립 억제 명령을 이행하려면 하위 컨트롤러가 충분한 주파수로 접촉력 제약을 지켜야 함; Impedance MPC는 그 하한 주파수·정확도 기준점을 실물 데이터로 제시
- **저수준 컨트롤러 선택 근거** — RL 정책(System0)이 출력하는 손가락 관절 명령을 실제 구동기에 전달하는 저수준 레이어로 MPC 계열 또는 이와 동등한 주파수·정확도를 요구하는 조건 확인 가능; LEAP Hand 적용 가능성 시뮬레이션 수준 검증
- **접촉 부하 외란 회복 시간 기준** — 2.5 N 부하 외란에서 0.7 s 회복; System0 접촉 안정화 요구 반응 시간의 외부 검증 기준으로 활용 가능

### (d) 먼저 확인할 점

- **RL 정책과의 인터페이스 미검증** — Impedance MPC는 순수 모델 기반 제어; System0 RL 정책이 출력하는 관절 명령과 이 컨트롤러를 실시간으로 조합하는 인터페이스 설계 별도 필요
- **LEAP Hand 실물 미검증** — LEAP Hand는 MuJoCo 시뮬레이션만; 유압 손가락 단관절 실물 검증에서 다관절 전기 구동 다지 손으로의 동일 성능 이전 여부 확인 필요
- **단독 저자 사전 검토 권고** — 1인 저자 프리프린트; 안정성·재현성 보증 주장의 독립 재현 선확인 권고

## 🥉 논문 3 — 우선순위 ★

**EaDex: A Cross-Embodiment Dexterous Manipulation Framework from Low-Cost Demonstrations**
[arXiv:2606.03268](https://arxiv.org/abs/2606.03268) · Qian Zhao, Xin Tong, Chengdong Wu, Yang Yang, Yingtian Li · source: citation-graph (HORA)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 순수 RL은 대규모 탐색 필요, 모방 학습은 고품질 시연 수집 비용 높음; 저비용 RGB-D 단일 카메라 기반 인간 손 동작 캡처 + RL 결합 시 시연 품질이 낮아 초반 탐색 비효율
- **EaDex 핵심 설계** — 접촉 보상 기반 동적 시연 어닐링(dynamic demonstration annealing) 메커니즘
  - 초기 탐색: 시연 안내
  - 접촉 보상 누적에 따라 자율 최적화로 점진적 전환 — 시연 의존도를 보상 신호가 자동 조절
  - 데이터 수준: MANO 기반 손 모델링·정규화·모션 리타기팅으로 구조화된 시연 데이터 구성
- **검증** — 3개 다지 손(Inspire Hand, Shadow Hand, LEAP Hand)·3개 관절 물체 개방 과제·9개 크로스 임바디먼트 설정에서 어닐링 미적용 기준선 대비 55.3% 상대 향상
- **진정한 신규성** — 접촉 보상을 시연 감소 신호로 쓰는 첫 동적 어닐링 메커니즘; 저비용 RGB-D 단일 카메라 시연 → 다지 손 RL 학습 전 파이프라인 통합

### (c) 시사점

- **접촉 보상이 탐색 품질을 직접 조절** — 접촉 보상 누적 속도가 시연 안내 감소 속도를 결정하는 구조; System0 RL 초기화 시 슬립 억제·파지 보상 신호로 어닐링 조기 종료 여부를 판단하는 동일 패턴 적용 가능성
- **멀티 하드웨어 RL 전이 기준점** — LEAP·Shadow·Inspire 세 다지 손 실물 검증; System0 목표 하드웨어와 동일 계열에서 RL 정책 전이 비용 추정 근거
- **저비용 시연 파이프라인** — 텔레오퍼레이션 없이 단일 RGB-D 카메라로 시연 데이터 구성; System0 초기 정책 시드 비용 절감 경로 참고

### (d) 먼저 확인할 점

- **슬립 억제·파지 유지 특화 미검증** — 관절 물체 개방 과제 중심; 파지 후 접촉 유지·슬립 발생 전 억제 특화 시나리오와의 직접 대응 없음 → 전이 가능성 별도 확인 필요
- **접촉 보상 항목 미공개** — 어닐링 트리거로 사용한 접촉 보상의 구체 항목(접촉력·영역·지속 시간 조합) 논문에 명시 필요 여부 확인; System0 보상 설계에 그대로 적용 시 세부 재현 비용 평가 선행 권고
- **시연 품질 의존도** — RGB-D 단일 카메라 노이즈·폐색 조건에서 시연 품질 저하 시 어닐링 수렴 특성 변화 여부 미제시

## 🌱 논문 4 — 인접 분야 픽

**T-Rex: Tactile-Reactive Dexterous Manipulation**
[arXiv:2606.17055](https://arxiv.org/abs/2606.17055) · Dantong Niu, Zhuoyang Liu, Zekai Wang et al. · source: arXiv 키워드 스윕 (tactile + reinforcement learning) · adjacent field: 촉각 반응형 VLA / 대규모 촉각 데이터셋

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **문제** — 현행 VLA 모델은 촉각 모달리티를 무시하거나 정적 큐 인코더로만 처리; 고주파 촉각 신호를 기존 VLA 역량 저하 없이 통합하는 방법 미확립
- **T-Rex 핵심 설계** — 대규모 촉각 반응 조작 시스템
  - **데이터셋**: 초등 운동 프리미티브(elementary motor primitives) 중심의 100 시간 촉각 풍부 데이터 수집 방법론
  - **temporal tactile VQ-VAE 인코더**: 고주파 촉각 신호를 시간 압축·양자화 → 이산 잠재 시퀀스로 변환
  - **variable-rate Mixture-of-Transformers(MoT) 아키텍처**: 촉각 스트림과 언어/시각 스트림의 주파수 불일치를 가변 속도 라우팅으로 처리; 기존 VLA 역량 유지
- **검증** — 12개 조작 과제(정밀 힘 제어·변형체 조작) 실물 로봇 실험; 최강 기준선 대비 평균 성공률 30% 이상 향상
- **진정한 신규성** — 촉각 반응형 VLA를 위한 temporal VQ-VAE + variable-rate MoT 최초 결합; 100 시간 규모 공개 촉각 데이터셋 공개

### (c) 시사점

- **고주파 촉각 신호 압축 아키텍처 크로스폴리네이션** — temporal VQ-VAE가 고주파 촉각 스트림을 이산 잠재 시퀀스로 압축하는 방식은 System0 촉각 특징 추출기 설계 시 참조 가능; 고속 시퀀스를 저차원 잠재로 변환하면 RL 상태 공간 폭발 억제 효과 기대
- **촉각 반응이 30% 성능 향상 실증** — 비전만으로는 접촉 집약 과제에서 충분하지 않음을 100 시간·12 과제 스케일로 재확인; System0 촉각 루프의 상위 레벨 동기 강화
- **variable-rate 라우팅 패턴** — 고주파 촉각과 저주파 언어/시각을 별도 속도로 처리하는 MoT 구조; System0(고주파 접촉 안정화)와 System1(저주파 고수준 계획)의 주파수 분리 구조와 개념적으로 부합

### (d) 먼저 확인할 점

- **비전 포함·비RL 시스템** — VLA 아키텍처, 모방 학습 기반; P3 비전 배제·RL 루프와 직접 전환 없음 → 인코더 아키텍처 참조 목적에 국한
- **VQ-VAE 레이턴시 미명시** — 이산 코드북 조회 + 시간 압축 파이프라인의 실시간 추론 레이턴시가 System0 고주파 요구에 부합하는지 별도 측정 필요
- **System0 단독 구성 불가** — T-Rex 자체는 VLA 풀스택 의존; temporal VQ-VAE 인코더만을 System0 RL 상태 입력으로 분리·이식 시 재학습 비용 선확인 필요
