### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- VLA는 장면 동역학을 명시적으로 모델링하지 않고, WAM은 미세 조작에 필요한 태스크 관련 의미·공간 구조를 노출하지 않는다는 문제 지적
- 이해·생성 전문가를 Mixture-of-Transformers로 연결해 서브태스크 예측·affordance grounding이 시각-동역학·액션 생성을 flow matching으로 함께 유도하는 통합 임베디드 파운데이션 모델 ME-U0 제안
- 미래 RGB·깊이·표면 법선·광학 흐름을 함께 예측하는 다중 모달 시각 동역학으로 외형·기하·모션에 상보적 감독 제공, Multi-rate RoPE로 시각 동역학과 정밀 제어 정렬
- 약 4,200시간 규모 로봇·에고센트릭 데이터로 사전학습, RoboDojo 시뮬레이션 벤치마크 평균 17.66점, LIBERO 99.0%·LIBERO-Plus 82.5% 달성, 실로봇 조작 태스크로도 검증
- 다운스트림 지도 신호 없이도 제로샷 서브태스크 예측·affordance grounding·시각 동역학을 시뮬레이션·실환경 모두에서 시연
- 코드·모델 GitHub 공개, 프로젝트 페이지 확인

### (c) 시사점
- RGB·깊이·법선·광학 흐름을 하나의 통합 flow matching 목적함수로 함께 예측하는 다중 모달 시각 동역학 설계가, D9KS 압축·정보-밀집 예측 공간 선택에 구체적 확장 사례 제공
- 서브태스크 예측·affordance grounding을 시각-동역학·액션 생성과 하나의 Mixture-of-Transformers로 묶는 통합 아키텍처가, D8XB 통합 방식 선택지에 참고할 또 다른 구체적 청사진
- 코드·모델 전체 공개로 이 스택이 다중 모달 시각 동역학 설계를 직접 검증·재현 가능

### (d) 먼저 확인할 점
- 다지 손 기반 정밀 조작이 실로봇 검증 태스크에 포함되는지, 그리퍼 중심 태스크에 그치는지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation**
[arXiv:2609.24976](https://arxiv.org/abs/2609.24976) · Haoran Yuan, Zekai Wang, Boning Shao, Haoran Lu, Trevor Darrell, Ismini Lourentzou et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 최근 WAM이 시각 중심에 머물러 다지 조작을 좌우하는 접촉 동역학을 직접 모델링하지 못한다는 문제 지적
- 각 손가락 끝을 독립적으로 인코딩하고 손가락·자세 인지 촉각 압축기로 특징을 집약해 촉각 잠재를 비디오 확산 world model에 주입하는 시각-촉각 통합 world modeling DexTacWAM 제안
- 22자유도 양손 플랫폼 위 여섯 개 접촉 집약적 다지 조작 태스크 전 태스크에서 최고점 달성, 평균 70.6 대 최강 baseline 38.0
- 소거 실험으로 촉각을 예측된 world state의 일부로 모델링하는 것 자체가 이득의 원천임을 확인 — 촉각 world modeling만 제거하면 동일 촉각 특징·액션 전문가를 유지한 채로도 4태스크 평균이 74.7에서 26.6으로 급락
- 동결된 사전학습 비전 VAE 위에 4시간 촉각 인코더 적응만으로, 태스크당 약 100개 시연으로 촉각 미드트레이닝 없이 사전학습 비디오 모델을 촉각까지 확장 — 시각 예측 품질은 시각 전용 대비 0.5dB 이내 유지
- 압축기가 융합 전 접촉 recall의 89.4% 보존, 학습 2.26배·추론 1.29배 가속
- 프로젝트 웹사이트 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 촉각을 별도 조건화 신호가 아니라 예측된 world state 자체의 일부로 모델링해야 이득이 발생한다는 소거 실험 결과가, D9KS 접촉-관련 예측 공간이 촉각을 다룰 때 지켜야 할 설계 원칙으로 직접 참고 가능
- 동결된 사전학습 비전 백본 위에 소량의 촉각 적응만으로 다지 손 촉각 world model을 저비용 확장하는 레시피가, 데이터·연산 효율적인 촉각 확장 경로 제공
- 22자유도 양손 플랫폼·여섯 접촉 집약적 태스크 전 태스크 1위라는 정량 근거가, 촉각-비전 통합 world model 계열의 비교 기준점으로 활용 가치

### (d) 먼저 확인할 점
- 22자유도 양손 플랫폼의 구체 손가락 배치·촉각 센서 규격이 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 4시간 촉각 인코더 적응만으로 확보되는 일반화 범위가 새로운 물체·태스크로 어디까지 확장되는지 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 손가락·자세 인지 촉각 압축기 모듈만 우선 이 기존 시각 전용 WAM 파이프라인에 추가

## 🥈 논문 3 — 우선순위 ★★

**HapticWAM: Distilling Imagined Touch into a World-Action Model without Inference-Time Tactile Sensing**
[arXiv:2609.23888](https://arxiv.org/abs/2609.23888) · Mikhail Sannikov, Ilya Mikhalchuk, Konstantin Gubernatorov, Petr Kovalev, Ogunwoye Faith Oluwatobi, Dzmitry Tsetserukou · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 접촉 집약적 조작이 힘·미끄러짐·접촉 기하를 추정해야 하나 장면 이미지만으로는 이 신호들이 모호하게 남는다는 문제 지적, 광학 촉각 센서가 접촉면의 시각 관측과 기계적 측정을 함께 제공하지만 외형을 넘어 접촉을 표현하는 것과 배치 시 손끝 관측 없이 그 이득을 정책에 전이하는 것 두 과제가 남는다는 점도 지적
- 이질적 촉각 인코딩·구조화된 접촉 예측·교사-학생 증류를 결합한 world-action model HapticWAM 제안 — 교사는 젤 이미지와 변형·전단·분산력·합력·유도 접촉 상태를 동결된 비디오 백본에 함께 인코딩
- 촉각 픽셀만 예측하는 대신 액션과 미래 사건·역학을 서술하는 접촉 패키지를 함께 생성 — Anticipatory Contact Coupling이 이전에 상상된 패키지로 주의를 조건화해 직접 촉각 관측이 없을 때도 접촉 관련 입력을 보존
- Haptic-Imagination Distillation이 접촉 미래·액션 예측을 모두 학생에게 전이 — 학생은 생성적 접촉 헤드는 유지하되 손끝 입력 분기는 제거
- 실환경 세 접촉 집약적 픽앤플레이스 태스크에서 학생 모델이 태스크당 평균 성공률 77%(50회 중 41회, 통합 82%) 달성, 한 태스크에서는 95%로 교사·baseline 구성 모두 상회
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 배치 시 촉각 센서 없이도 상상된 접촉으로 정책을 안내하는 교사-학생 증류 구조가, D9KS 접촉-관련 예측 공간을 하드웨어 의존 없이 확보하는 저비용 경로로 참고 가능
- 접촉을 픽셀이 아닌 미래 사건·역학을 서술하는 패키지로 구조화하는 설계가, 촉각 예측을 배포 비용 없는 학습 신호로 재구성하는 또 다른 구체적 사례로 축적
- 학생 모델이 손끝 관측 없이 교사·baseline을 상회한 결과가, 촉각 하드웨어가 없는 로봇에도 촉각 world model의 이득을 전이할 수 있다는 근거로 활용 가치

### (d) 먼저 확인할 점
- 세 픽앤플레이스 태스크의 물체 종류·다지 손 사용 여부가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- Anticipatory Contact Coupling의 상상된 패키지가 실제 접촉과 어긋날 때의 실패 모드가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 Haptic-Imagination Distillation 목적함수만 우선 이 기존 촉각 보유 WAM 파이프라인에 적용

**AffordanceWAM: Affordance-Aware Joint World-Action Modeling for Robot Manipulation**
[arXiv:2609.22332](https://arxiv.org/abs/2609.22332) · Jiadi You, Qize Yu, Yue Chen, Minghong Cai, Zhide Zhong, Yuran Wang et al. · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- 일반화 가능한 로봇 조작은 장면이 어떻게 전개될지 예측하고 상호작용 가능한 위치를 식별하고 어떻게 행동할지 결정해야 하나, 로봇 비디오는 비싸고 다양성이 제한적이며 에고센트릭 human 비디오는 다양하나 로봇 액션이 없고 임베디먼트·외형이 다르다는 문제 지적
- 미래 World 안에서 물체 중심 시공간 affordance를 Scalar Affordance와 Affordance Heatmap 두 표현으로 나타내는 affordance-aware 생성적 World Action Model AffordanceWAM 제안 — 이 표현이 human·로봇 비디오에 공유되는 상호작용 목표 제공
- 사전학습 비디오 확산 Transformer 위에 World·Action 전문가를 분리 파라미터화하고 Masked Joint Self-Attention으로 결합, 미래 RGB·Scalar Affordance·Affordance Heatmap·연속 로봇 액션을 통합 flow matching으로 공동 예측
- human 비디오가 세 미래-World 스트림 전부를 감독하고 로봇 궤적이 추가로 액션 감독을 제공 — human 액션 라벨이나 리타게팅 없이 전이 가능
- RoboCasa·CALVIN ABC→D·실환경 조작에서 RGB 전용·로봇 데이터 전용 baseline 대비 일관된 개선, 고정 로봇 지도 하에서 affordance 주석 human 비디오를 늘릴수록 RoboCasa 성능이 단조 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- affordance를 human·로봇 비디오가 공유하는 상호작용 목표로 구조화하는 인터페이스가, D7VC가 아직 비워 둔 에고센트릭 hand-object 앵커에 affordance 축의 또 다른 구체적 참고점 제공
- human 액션 라벨·리타게팅 없이 human 비디오만으로 세 미래-World 스트림을 감독하는 구조가, human-to-robot 전이 비용을 낮추는 구체적 절차
- 로봇 지도를 고정한 채 affordance 주석 human 비디오만 늘려 성능이 단조 개선된다는 결과가, 값비싼 로봇 시연 대신 human 비디오로 스케일링하는 경로의 정량 근거

### (d) 먼저 확인할 점
- 로봇 데이터 전용 baseline 대비 개선 폭의 구체 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 다지 손 기반 정밀 조작이 실환경 조작 평가에 포함되는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 Scalar Affordance·Heatmap 예측 헤드만 우선 이 기존 human 비디오 미보유 WAM 파이프라인에 추가

- 노이즈-공간 VLA 사후학습에 액션-조건부 시각-토크 상상을 결합한 Imagine-RL 제안 — 각 후보 액션 청크에 대해 동결된 시각-토크 잠재 world model(VTLWM)이 픽셀 재구성 없이 압축된 미래 표현을 자기회귀적으로 예측
- 현재 이미지-상태-액션 쿼리가 관측 이력과 예측 미래에 함께 attend, 이전 윈도우 예측 잔차가 토큰별 신뢰도 사전으로 작용해 신뢰할 수 없는 미래 토큰을 억제
- 현재 증거와 예측 결과를 결합해 액션 critic이 후보 액션을 더 잘 평가하고 actor를 지도, VLA와 VTLWM은 모두 동결 유지
- 네 개 실로봇 태스크·태스크당 50회 평가에서 RL 궤적 단 100개만으로 DSRL 대비 평균 성공률 23.6% 개선, VLA baseline 대비 60% 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 동결된 world model의 상상된 미래로 RL critic을 보강하는 구조가, D3FQ가 아직 보류 중인 eval-in-imagination·RL-환경 역할의 구체적 실행 사례로 직접 대응
- 예측 잔차를 신뢰도 사전으로 재활용해 불확실한 미래 토큰을 억제하는 메커니즘이, 상상 기반 정책 개선에서 환각 위험을 걸러내는 또 다른 구체적 절차로 축적(HaWMPO, 2026-09-17)
- RL 궤적 단 100개만으로 큰 폭의 개선을 확인한 결과가, world model 보강 RL의 표본 효율성 상한을 가늠하는 참고 기준점

### (d) 먼저 확인할 점
- 네 개 실로봇 태스크의 물체 종류·손 형태(그리퍼 대 다지 손)가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 동결된 VTLWM의 사전학습 데이터 규모·도메인이 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 잔차-신뢰도 게이팅 메커니즘만 우선 이 기존 world model 미보강 노이즈-공간 RL 파이프라인에 추가

- Sim2Real 3 — Franka·Galbot 실로봇 제로샷 조작 태스크에서 직접 검증

**Think Like a World Model, Act Like a VLA (13/15)**
- Relevance 3 — world model의 생성 목적함수는 버리고 표현만 상속하는 증류가 D3FQ 예측 보조 역할을 추론 시점 world model 실행 없이 구현, D8XB 통합 아키텍처에 학습-시점 대안 제시
- Novelty 3 — 특징-정렬 항 하나만으로 교사 없이 배포되는 정책이 증류되지 않은 baseline과 완전히 동일하게 실행되면서도 이득을 얻는 최소주의 설계가 신규
- Reproducibility 1 — arXiv abstract "Project page: https://thaw-vla.trung-dt.com/"
- Methodology 3 — LIBERO 97.9%, RoboCasa-GR1 48.2%→50.5%, 학생 규모·백본·교사를 바꾼 강건성 검증까지 체계적 제시
- Sim2Real 3 — 단일팔·양팔 실하드웨어 양쪽에서 동일 목적함수의 전이 효과 직접 검증

**Skel-WAM (12/15)**
- Relevance 3 — human과 로봇 동작을 공통 손 토폴로지로 정렬하는 hand-skeleton 인터페이스가 D7VC의 비어 있던 에고센트릭 hand-object 앵커, D6FM 행동조건부 조건화에 직결
- Novelty 3 — skeleton overlay와 2.5-D keypoint를 결합한 명시적 기구학 인터페이스로 human-로봇 공유 동역학을 학습하는 설계가 이번 런 다른 인터페이스(affordance·잠재 액션) 대비 구분되는 신규 축
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — 실환경 네 태스크·시뮬레이션 일곱 태스크에서 79.86%·63.29%, 최강 baseline 대비 22.22%p·8.28%p 우위 정량 검증
- Sim2Real 3 — 실환경 양손 네 태스크에서 직접 검증, human-로봇 공동학습 효과(38.89%→86.11%)까지 확인

**Imagine-RL (12/15)**
- Relevance 3 — 동결된 world model의 상상된 미래로 RL critic을 보강하는 구조가 D3FQ의 보류 중인 eval-in-imagination·RL-환경 역할에 직접 대응
- Novelty 3 — 예측 잔차를 토큰별 신뢰도 사전으로 재활용해 불확실한 미래 토큰을 억제하는 residual-confidence cross-attention 메커니즘이 신규
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — 네 실로봇 태스크·태스크당 50회 평가, RL 궤적 100개만으로 DSRL 대비 23.6%·VLA 대비 60% 개선 정량 검증
- Sim2Real 3 — 네 실로봇 태스크에서 직접 검증

**What Matters in Designing World Action Models (11/15)**
- Relevance 3 — 인과 구조·잠재 공간·학습 목적함수를 분리한 통제 연구가 D8XB 통합 아키텍처, D9KS 예측 공간 선택 근거를 OpenWAM과 독립적으로 재확인
- Novelty 3 — 여섯 인과 구조×여덟 잠재 표현×네 학습 목적함수를 하나의 벤치마크 세트 위에서 통제 비교하는 연구 프로그램 자체가 개별 아키텍처 제안과 구분되는 신규 접근
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — RoboCasa-GR1·LIBERO·LIBERO-Plus 세 벤치마크에 걸친 구조적 통제 실험, DROID 실로봇 데이터 추가 검증까지 체계적 제시
- Sim2Real 2 — DROID 데이터셋의 실로봇 기록으로 핵심 발견을 검증하나, 라이브 배포 성공률 형태인지는 abstract 수준 미확인

**SkelWAM (12/15)**
- Relevance 2 — 팔 기하·TCP 자세·그리퍼 명령을 공유 표현으로 묶어 cross-embodiment 전이를 겨냥한 구조가 D9KS 압축 예측 공간, D6FM 행동조건부 조건화에 연결되나 다지 hand-object 중심 축과는 거리
- Novelty 3 — 공유 25차원 기하 표현과 임베디먼트-특화 제약 디코더로 관절 로봇에서 continuum robot까지 일대일 대응 없이 전이하는 설계, 신규 벤치마크 LIBERO-Cross10 도입이 신규
- Reproducibility 1 — arXiv abstract "Project page: http://www.liukepku.com/skelwam/index.html"
- Methodology 3 — LIBERO-Cross10 1,000 에피소드에서 43.3%·최강 baseline 대비 36.2%p 우위 정량 검증
- Sim2Real 3 — JAKA mini2 학습 정책을 Feagine A03 continuum robot 세 태스크탑 조작에 실제 배포 검증
