## 🥇 논문 1 — 우선순위 ★★★

**WALA: Learning Executable Latent Actions from Action-Labeled Robot Demonstrations and Action-Free Videos**
[arXiv:2607.11397](https://arxiv.org/abs/2607.11397) · Liu et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- **액션 라벨 없는 영상까지 감독 신호로 전환** — 로봇 액션 주석이 있는 시연 데이터와 액션 라벨이 없는 대규모 인간·로봇 영상을 하나의 잠재 액션 모델로 결합
- **픽셀 재구성 대신 특징 공간 예측** — 원시 픽셀이 아닌 DINOv3 특징 공간 + 깊이 공간에서 미래 델타를 예측, 외형 디테일에 대한 민감도를 낮추고 과제 관련 의미·기하 구조만 보존
- **이중 감독 정책 학습** — 사전학습된 인코더가 안정적 잠재 액션 타깃 제공, 디코더는 학습 가능한 세계모델 역할, 로봇 액션 예측·잠재 액션 정합·미래 동역학 예측 세 손실을 동시에 감독
- **벤치마크 성능** — RoboTwin 전역 검증 + RoboCasa 평균 성공률 75.2%로 신규 최고 기록, 실제 조작 과제에서도 정책 성능·일반화 개선 확인

### (c) 시사점
- **행동 라벨 부족 문제의 실질적 우회로 제시** — 액션 주석 없는 영상 자원을 그대로 동역학 감독 신호로 흡수하는 구조, 데이터 확보 비용 절감 여지
- **특징 공간 예측이 픽셀 생성보다 가벼운 대안임을 재확인** — 압축된 표현 공간에서 동역학을 배우는 접근이 실제 성능으로 이어짐을 입증
- **공개 코드로 즉시 점검 가능** — 공식 GitHub 저장소(`liujiahao2077/WALA`)에 학습·평가 코드, RoboCasa/RoboTwin 실행 예제 전체 공개 확인(체크포인트·데이터셋 자체는 별도 다운로드 필요)

### (d) 먼저 확인할 점
- **실제 조작 검증의 과제 수·플랫폼 규모가 초록 수준에서 불명확** — 실환경 결과가 언급되나 태스크 개수·성공률 구체 수치는 본문 확인 필요
- **액션-라벨 영상과 액션-프리 영상의 비율 민감도 미검증** — 두 데이터 소스 배합 비율에 따른 성능 변화가 소개되지 않아, 소량 라벨 상황에서의 강건성은 별도 확인 대상
- **가장 저렴한 이전 점검** — 공개 저장소의 RoboTwin 예제부터 재현 시도, DINOv3 특징 예측 손실이 손·물체 접촉 국면에서 얼마나 세밀한 신호를 주는지 우선 확인

## 🥈 논문 2 — 우선순위 ★★

**PAVXploreRL: World Model Reinforcement Learning for Physical-Action-Visual Targets with Out-of-Distribution Action Exploration**
[arXiv:2607.16602](https://arxiv.org/abs/2607.16602) · Wang et al. · source: citation-graph (Ctrl-World 인용)

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- **강화학습으로 세계모델 현실성 자체를 목표화** — 픽셀 재구성 손실 대신 물리적 타당성(Physical Plausibility)·액션 순응성(Action Adherence)·시각 충실도(Visual Fidelity) 세 보상을 직접 최적화하는 RL 프레임워크 제안
- **분포외 행동 탐색 결합** — 정상 시연 궤적과 노이즈 기반 분포외(OOD) 행동 탐색을 함께 활용, 영상 쌍 감독 없이도 행동 일반화 능력 개선
- **정책 평가기로서의 신뢰도 개선** — 기존 전문가 시연 전용 세계모델(비교 대상: 핀 논문 Ctrl-World) 대비 과대추정 편향 감소, 여러 벤치마크에서 평균 5.6% 성능 향상

### (c) 시사점
- **세계모델을 정책 평가기로 쓸 때의 핵심 약점(과대추정)에 직접 대응** — 상상 속 롤아웃으로 정책을 평가·비교하는 용도에서 신뢰도를 높이는 구체적 처방 제공
- **사전학습된 잠재 세계모델 위에 얹는 경량 개선 경로** — 전체 재학습이 아닌 보상 기반 미세조정으로 개선을 달성해, 기존 파이프라인에 붙이기 쉬운 형태
- **재현 자산이 가장 잘 갖춰진 후보** — 공식 GitHub 저장소에 환경 설정·체크포인트 다운로드·공개 데이터셋(AgiBotWorld-Alpha, DROID) 연동 스크립트까지 전부 확인, 즉시 실행 가능한 수준

### (d) 먼저 확인할 점
- **평가 지표가 영상 품질 지표(PSNR/SSIM/LPIPS 등) 중심** — 실제 로봇 위 태스크 성공률 검증이 아닌 실로봇 수집 데이터에 대한 오프라인 평가로, 라이브 배포 성능과의 간극은 별도 확인 필요
- **성능 향상 폭(평균 5.6%)이 크지 않음** — 보상 계수 선택 절차에 따라 결과가 민감할 가능성, 하이퍼파라미터 안정성 점검 필요
- **가장 저렴한 이전 점검** — 공개 체크포인트로 이 데이터 일부에 대한 추론부터 실행, VJEPA 예측기 유사도 보상이 손-물체 접촉 국면에서 이상치를 얼마나 잘 잡아내는지 우선 확인
