## 🥇 논문 1

**DRILL: Training World Models to Improve Policies, Not Predict Pixels**
[arXiv:2610.30814](https://arxiv.org/abs/2610.30814) · Zhaolu Kang, Tailong Luo, Lei Wei 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N3 · M3 · Real0 · Repro1 — §E.1 "Code. All training, evaluation, and analysis code, … will be released under"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 정책 개선 반환으로 영상 월드 모델을 학습하는 이중 최적화
- **문제** — VLA 강화학습 후처리에서 월드 모델이 한 스텝 픽셀 예측으로 학습되지만 실제 역할은 정책 학습 신호를 낼 상상 롤아웃 생성
  - 픽셀 MSE는 배경·로봇 형상·과제와 무관한 영역까지 균일하게 벌점, 정책 경사는 현재 정책이 방문하는 상태와 이점이 큰 행동을 강조
  - 픽셀 예측이 좋아도 학습 신호가 약할 수 있고, 평균 예측이 나빠도 정책 개선에 쓰이는 전이는 더 잘 받칠 수 있음
- **기존 한계** — 월드 모델을 상상 롤아웃 RL에 쓰는 기존 흐름이 여전히 한 스텝 영상 예측기로 학습
  - WMPO류 파이프라인 — 오프라인 시연으로 영상 월드 모델을 학습하고 그 안에서 GRPO 수행, 월드 모델 목적은 한 스텝 예측 그대로
  - Policy-Aware WM·ESNR — 픽셀 충실도가 정책 역량을 안정적으로 따라가지 않음을 진단하나 학습 목적함수는 제공하지 않음
  - RLVR-World — 예측 정확성을 보상으로 월드 모델을 후학습하나 예측기로서의 개선이며 상상 롤아웃이 만드는 정책 갱신을 직접 최적화하지 않음
- **핵심 방법** — 상상 롤아웃 위 GRPO 갱신 후 정책의 반환이 커지도록 월드 모델을 갱신하는 이중 최적화 틀 DRILL
  - 안쪽 루프 — 월드 모델이 만든 상상 롤아웃으로 GRPO 갱신
  - 바깥 루프 — 갱신된 정책이 대상 시뮬레이터에서 얻는 반환을 높이도록 월드 모델 갱신
  - DRILL-VWI — 정책 방문 빈도, 그룹 상대 GRPO 이점, 모델 신뢰도로 예측 오차를 재가중하는 닫힌 형태 대리 손실, 추가 시뮬레이터 롤아웃 불필요
  - DRILL-IMG — 안쪽 갱신을 잘린 헤시안-벡터 곱으로 미분하는 전체 메타 경사 방식, 바깥 갱신당 시뮬레이터 롤아웃 30개 사용
  - 이론 — VWI가 점수 호환성과 작은 잔차 가정 아래 IMG 메타 경사의 국소 한 스텝 성분을 복원, IMG는 잘린 역전파 아래 비점근 수렴률 제시
- **차별점** — 월드 모델의 목표를 다음 프레임 정확도에서 월드 모델 안에서 학습한 정책의 실제 반환으로 교체
  - 진단에 그친 기존 연구와 달리 학습 목적함수로 제시
  - 예측 정확성 보상 방식과 달리 상상 롤아웃이 만드는 정책 갱신을 직접 최적화
- **핵심 기여** — 문제 정식화, 두 구현, 이론, 진단 지표의 4건
  - 시뮬레이션 5종(LIBERO-Long, CALVIN ABC→D, RoboCasa, Meta-World MT50, SimplerEnv)과 VLA 2종에서 DRILL-IMG 평균 성공률이 WMPO보다 13.1점, RLVR-World보다 7.9점 높음 — 한 스텝 픽셀 MSE는 17% 더 높음
  - 헤드라인 결과 시드 5개, 절제 시드 3개
  - LIBERO-Long 연산량 정합 대조 — WMPO 추가 갱신은 64.2에서 최대 65.1, DRILL-IMG는 81.3
  - RLVR-World 사전학습 월드 모델에 적용하면 평균 3.2점 추가 향상
  - 절제 — 방문 빈도 단독 64.2, 부호 있는 이점 단독 66.8, 신뢰도 단독 60.1, 세 요소 결합 69.2, WMPO 58.2
  - 월드 모델 크기에 따라 WMPO 대비 마진이 3억 파라미터 7.9점, 12억 13.1점, 70억 16.4점으로 증가 (LIBERO-Long)
  - Policy-Utility Residual(PUR) — 픽셀 MSE 경사와 정책 개선 방향의 각도 차이를 재는 진단 지표, 낮을수록 성공률이 높은 경향
- **가치** — 영상 월드 모델의 평가 기준을 시각적 충실도에서 정책 학습 유용성으로 옮기는 근거와 학습 레시피 제시

### (c) 시사점

- 픽셀 충실도가 정책 유용성의 대리 지표가 아님을 직접 측정
- **판단 근거** — 픽셀 MSE가 17% 더 나빠도 평균 성공률이 WMPO보다 13.1점 높음 (시뮬레이션 5종, π0-3B 기준)
- **설계 함의** — 영상 월드 모델을 RL 환경으로 쓰는 선택지를 평가할 때 픽셀 사실성 대신 정책 반환 기준의 점검 항목이 생김
- **비용** — IMG는 잘린 역전파와 헤시안-벡터 곱으로 연산·메모리 부담, 예산이 빠듯하면 VWI가 대안이라고 저자가 명시
- **공개 기준점** — 코드 공개 약속만 있고 저장소 URL 없음

### (d) 먼저 확인할 점

- **시뮬레이션 한정** — 실물 로봇 결과 없음, 지각 잡음·구동 지연·안전 제약 민감도 미확인
- **학습 비용** — 헤드라인 실행에 H20 GPU 약 1.7만 시간, 24장 약 4주
- **예외 구간** — SimplerEnv에서 VWI와 IMG가 통계적으로 동률(64.0±1.9 대 63.1±2.6), RoboCasa OpenVLA도 동률
- **시뮬레이터 의존** — IMG는 바깥 갱신마다 시뮬레이터 롤아웃을 쓰므로 순수 오프라인 설정이 아님
- **코드 접근** — 저장소 URL 없이 공개 약속뿐, 백본도 코드와 함께 공개 예정

## 🌱 논문 2 — 인접 분야 픽

**Δ Flow Matching for Robot Foundation Models**
[arXiv:2610.15794](https://arxiv.org/abs/2610.15794) · Kuangji Zuo, Tuo An, Xinying Guo 외 · adjacent field: VLA 아키텍처 전반(플로우 매칭 정책)

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 고정 가우시안 대신 최근 이력에서 플로우 소스를 만드는 방식
- **문제** — 플로우 매칭 기반 VLA와 월드 액션 모델(WAM)이 가우시안 노이즈에서 생성을 시작해 학습과 추론이 모두 비쌈
  - 액션 전용 VLA도 학습 수렴이 느리고 추론에 많은 함수 평가가 필요해 제어 지연 증가
  - WAM은 미래 액션과 고차원 미래 시각 상태를 모두 노이즈에서 전달하므로 두 비용이 증폭
- **기존 한계** — 기존 가속은 추론 비용을 줄이되 전달 경로 자체의 학습 비용은 줄이지 못함
  - 효율적 샘플러·증류 — 주로 액션 생성용으로 개발되어 WAM의 시각 분기에서도 통하는지 미확인
  - 워밍스타트 — 별도로 학습한 예측기로 초기값을 주고 몇 스텝 정제
  - Fast-WAM·ImageWAM — 학습 때만 미래 예측을 쓰고 추론에서는 생략하며, 저자들의 실험에서는 추론 시 명시적 미래 예측을 빼면 분포 이동에서 성능 저하
  - 액션 이력을 소스로 쓰는 A2A 플로우 매칭 — 단일 모달리티에 한정
- **핵심 방법** — 소스를 최근 이력에 약한 노이즈를 더한 값으로 만들어 목표까지의 이동을 작은 잔차 Δ로 축소
  - VLA — 액션 분기의 가우시안 소스 교체
  - WAM — 시각 분기와 액션 분기 소스 모두 교체, 예측한 시각 미래에 액션을 조건화해 한 번의 플로우 스텝으로 함께 생성
  - 소스만 바꾸므로 네트워크 구조 수정과 추가 데이터 불필요
- **차별점** — 액션과 시각 두 모달리티의 이력을 함께 소스로 쓰고 미래 조건화를 추론에서도 유지
  - 미래 예측을 추론에서 생략하는 계열과 달리 시각 미래를 단일 스텝으로 함께 생성
  - 단일 모달리티 이력 소스 계열과 달리 두 분기를 한 틀에서 결합
- **핵심 기여** — 학습 효율, 추론 속도, 일반화, 학습 없는 적용의 4건 (LIBERO, 시뮬레이션)
  - 학습 효율 — ImageWAM이 1 에폭에 90% 성공(기존 6 에폭), Fast-WAM이 2 에폭에 95%(기존 8 에폭), LoRA 미세조정 π0.5가 1 에폭에 기준선의 5 에폭 성능 초과
  - 추론 속도 — 단일 스텝에서 π0.5 1.54배, ImageWAM 2.49배, Fast-WAM 4.45배
  - 부드러움 — ImageWAM에서 한 스텝 가우시안 샘플링 대비 액션 저크 4.5배 감소
  - 일반화 — LIBERO-Plus 7개 교란 범주 평균 88.55%, 액션 쪽만 적용 시 82.49%에서 85.82%, 시각까지 적용 시 88.55%
  - 사전학습 WAM의 가우시안 액션 소스를 재학습 없이 교체해도 한 스텝 샘플링으로 성공률 대부분 유지
  - 액션 표현 방식이 LIBERO-Plus 성공률을 14점 이상 바꾸고, 정지 경사가 성공률을 높인다는 설계 분석
- **가치** — 구조 변경 없이 소스만 바꿔 WAM의 학습·추론 비용을 함께 낮추는 경로 제시

### (c) 시사점

- 보조 시각 분기를 둔 정책의 추론 비용을 소스 교체로 절감
- **도입 비용** — 네트워크 구조와 데이터를 바꾸지 않고 소스 초기화만 교체
- **보조 헤드 구성과의 접점** — 미래 시각 표현을 정책과 함께 학습하는 구성에서 한 스텝 추론이 가능한지 검증하는 기준점
- **설계 분석** — 특징 공유와 경사 결합을 별개 설계 결정으로 다루라는 결과, 정지 경사가 미래 이미지 PSNR과 LIBERO-Plus 성공률을 모두 향상
- **공개 기준점** — 코드 공개 약속 없음, 프로젝트 웹사이트만 존재

### (d) 먼저 확인할 점

- **시뮬레이션 한정** — LIBERO·LIBERO-Plus뿐이며 실물 로봇 검증은 저자가 향후 과제로 명시
- **백본 범위** — π0.5, ImageWAM, Fast-WAM 3종뿐이고 더 많은 VLA 백본 검증은 향후 과제
- **노이즈 스케일** — 소스 노이즈 크기가 하이퍼파라미터이며 세 백본에 같은 값 사용, 이력 신뢰도가 궤적 내내 일정하지 않다고 저자가 언급
- **코드 접근** — 저장소 URL과 공개 약속 없음
- **이전 비용** — 최근 실행 이력이 소스이므로 이력이 부정확한 구간(접촉 직후 급변 등)에서의 거동은 별도 확인 필요
