**CoRA-VTLA: Contact-Guided Attention and Queryable Response Memory for Tactile Post-Training**
[arXiv:2611.23963](https://arxiv.org/abs/2611.23963) · Chengye Song, Rui Song, Shengqi Wang 외 · arXiv preprint · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — arXiv comment "Project page: https://cora-vtla.github.io/" — 프로젝트 페이지만, 코드 언급 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D1SX](https://img.shields.io/badge/D1SX-d97706.svg)](#ref-D1SX)

### (b) 논문 요지

- 촉각 사후학습에 반응 기억과 접촉 시선 지도를 결합
- **문제** — 사전학습 VLA를 접촉 집약적 정밀 조작에 맞출 때 접촉 뒤 교정 동작을 정할 단서 부족
  - 정렬 오차는 끼임으로, 과한 힘은 변형으로 이어지는 과제
  - 초기 맞물림과 지속된 끼임은 순간 하중이 비슷하지만 계속 삽입할지 물러나 재정렬할지가 달라짐
  - 촉각 데이터는 VLA 사전학습에 드물어 과제 시연으로 하는 사후학습이 현실적인 경로
- **기존 한계** — 단일 시점 촉각 관측은 최근 동작에 대한 접촉 반응을 모호하게 남김
  - 촉각 예측은 접촉 동역학 학습의 지도로 쓰이고 힘 이력은 과제 진행 추적에 쓰이나, 최근 반응 중 다음 교정에 무엇이 중요한지는 고르지 않음
  - 촉각을 곧바로 융합하면 시각 동역학 모델링을 방해하고 행동 전문가의 주의가 목표에서 벗어난다는 선행 보고를 인용
  - 이 논문의 MuJoCo 관측에서도 직접 융합 시 첫 행동 토큰의 메인 카메라 주의가 더 분산
- **핵심 방법** — 경량 촉각 모듈 두 개를 사전학습 VLA에 덧붙임
  - **질의형 행동-반응 기억** — 측정된 접촉 변화를 부호화해 두고 현재 접촉과 로봇 상태에 맞춰 관련 반응을 검색
  - **반응 사전학습** — 시연에서 다음 스텝 반응을 예측해 행동 쪽 촉각 인코더 초기화
  - **접촉 유도 시선 지도** — 촉각 의미 토큰의 시각 주의를 손가락 끝 접촉 투영 영역으로 유도
  - **행동 생성** — 행동 전문가가 검색된 반응, 즉시 촉각 피드백, VLM 과제 맥락을 합쳐 다음 행동 청크 생성
- **차별점** — 촉각을 직접 융합하지 않고 반응 이력의 검색과 시각 주의의 접촉 영역 정렬로 나눠 주입
  - 같은 센서 입력을 쓴 직접 융합과의 통제 비교로 효과를 분리
- **핵심 기여** — 두 모듈과 시뮬레이션·공개 벤치마크·실물 평가
  - **MuJoCo 3개 과제** — 150회 시행 기준 성공 110회, 73.33%, 기본 정책 31.33%, 직접 융합 50%, 변형 적용한 FTP-π0.5 44%
  - **실패 양상** — 시간 초과 기본 96회에서 36회로 감소, 안전 실패 7회에서 4회로 감소
  - **UniVTAC Insert Tube** — 광학 촉각 공개 벤치마크에서 기억 설계만으로 67%
  - **실물 3개 과제** — 컵 쌓기, 도장 찍기, 튜브 삽입 평균 66.7%(95% CI 59.3–74.0%), 가장 강한 기준선 44.7%
  - **주의 분석** — 튜브 삽입 사례에서 접촉 영역에 배정된 전방 카메라 주의 비율이 2.6%에서 12.6%로 상승
- **가치** — 촉각이 희소한 사전학습 VLA를 시연 기반 사후학습으로 접촉 교정에 적응시키는 설계 제시

### (c) 시사점

- 촉각 직접 융합 대비 약 23%p 우위의 통제 비교 근거
  - 같은 센서 입력에서 시각 주의 분산이 실패 원인이라는 해석을 주의 측정과 함께 제공
- 접촉 위치로 시각 주의를 정렬하는 학습 시 지도
  - 추론 경로를 바꾸지 않는 보조 손실이라 기존 VLA에 붙이는 비용 낮음
- 최근 접촉 반응을 검색하는 기억 토큰
  - 단일 시점 촉각으로 구분되지 않는 맞물림과 끼임을 가르는 입력 설계 후보
- 공개 벤치마크 UniVTAC 결과
  - 다른 시뮬레이터·촉각 방식에서의 비교 기준점

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 신호 없음, 프로젝트 페이지만 존재
- 실물 평가는 UR5e와 Robotiq 140 그리퍼, 손가락 끝 전자 피부 구성의 3개 과제로 다지 손 결과 아님
- MuJoCo 과제는 저자 제작 3종이라 외부 비교는 UniVTAC 한 과제에 한정
- 기억과 시선 지도 각각의 단독 기여 크기는 본문 ablation 표에서 확인 필요
- 못 삽입 과제에서 안전 실패 4회 잔존

## 🥈 논문 2

**3DTouch: A Tactile-aware VLA Model with 3D Geometric Relations for Dexterous Manipulation**
[arXiv:2611.23961](https://arxiv.org/abs/2611.23961) · Xin Zhang, Shiqi Zhang, Siyuan Cao 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 다섯 손가락 촉각과 장면 점군을 로봇 기준 좌표계로 통합
- **문제** — 다지 손 접촉 집약적 조작에서 시각만으로는 접촉 위치와 국소 기하를 파악하기 어려움
  - 손가락과 물체가 가려 국소 기하가 보이지 않음
  - 시각적으로 비슷한 장면도 상호작용 물체의 상대 위치가 달라 접촉 상태가 다름
- **기존 한계** — 3D 인식 VLA, 촉각 VLA, 3D 시각-촉각 방식이 각각 일부만 다룸
  - 3D 인식 VLA는 깊이를 위치 인코딩으로 융합하거나 재구성·점군에서 뽑은 기하 특징을 행동 전문가에 조건으로 부여
  - 촉각 VLA는 촉각을 시각-언어 토큰 옆 추가 입력 토큰으로 부호화
  - 3D 시각-촉각 방식은 시각과 그리퍼 촉각을 3D 점으로 표현하나 다지 손의 다중 손가락 촉각을 사전학습 VLA에 공간적으로 접지하는 방법은 미탐구
  - 다운샘플링한 장면 점군은 거칠고 다섯 손가락 파지 중 가림이 심해 작은 간극을 포착하지 못함
- **핵심 방법** — 3D 조건화 모듈 두 개로 사전학습 VLA의 행동 전문가를 조건화
  - **3D Tactile Grounding** — RGB-D 장면 점군과 다섯 손가락 촉각 측정을 로봇 기준 좌표계에 표현, 각 택셀의 3D 위치와 힘 벡터를 함께 부호화해 장면 토큰과 공간 정렬된 촉각 토큰 생성
  - **Geometric Relation Modeling** — 손 랜드마크와 추적한 물체 표면점으로 손-물체, 물체-물체 상대 변위와 거리를 담은 관계 토큰 구성
  - **행동 생성** — 장면·촉각·관계 토큰이 함께 VLA 행동 전문가를 조건화
- **차별점** — 촉각을 입력 토큰으로 덧붙이지 않고 모든 택셀의 위치와 힘을 장면과 같은 3D 공간에 배치
  - 관계 서술자를 명시적으로 만들어 미세한 정렬을 암묵 추론에 맡기지 않음
- **핵심 기여** — 두 모듈과 실물 5개 과제 평가
  - **실물 평가** — UR7e 팔과 XHand 다지 손, 5개 과제, 과제당 20회 시행
  - **기준선 비교** — 평균 65.0%, 대응 VLA 기본 정책 대비 42%p, 가장 강한 기준선 Tactile-VLA 대비 20.0%p, 기준선 7종 비교
  - **구성요소 ablation** — RGB 단독 23.0%에서 공간 촉각 35.0%, 점군 46.0%, 상호작용 기하 41.0%
  - **공유 접지 효과** — 손 국소 촉각 부호화 대비 11%p 상승
  - **관계 모델링 효과** — 명시적 상호작용 기하로 12%p 추가 상승
  - **자세 변화 강건성** — 깔때기 삽입과 플러그 조립에서 이동·회전·복합 변화 하 비교
- **가치** — 다지 손 촉각을 장면 기하와 같은 공간에 놓는 사전학습 VLA 조건화 경로 제시

### (c) 시사점

- 손 국소 촉각 대비 공유 3D 접지의 11%p 실물 이득
  - 촉각 토큰의 좌표계 선택이 성능에 영향을 준다는 정량 근거
- 택셀별 위치와 힘 벡터를 유지하는 토큰화
  - 손가락 귀속을 보존하는 촉각 입력 설계의 비교 후보
- 점군과 촉각 각각의 독립 기여 분리
  - 어느 입력이 이득을 내는지 가늠할 기준점
- 추적 기반 물체 자세 추정 의존
  - 도입 시 인식 모듈 비용이 추가됨

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 신호 없음
- 과제당 20회 시행에 반복 시드와 분산, 한계 서술 없음
- 물체 표면점이 자세 추정 파이프라인에 의존해 추정 오차가 관계 토큰으로 전파될 가능성
- UR7e와 XHand 단일 플랫폼 결과로 다른 손·촉각 센서 배치에서의 이식 경로 불명확
- 자세 변화 강건성 비교는 두 과제에서 π0.5 + tactile 한 기준선과만 수행

## 🌱 논문 3 — 인접 분야 픽

**QA-CMIF: Accurate and Lightweight Cross-Modal Latent Imputation and Fusion for Fault-Tolerant sEMG-Inertial Hand Gesture Recognition**
[arXiv:2611.20124](https://arxiv.org/abs/2611.20124) · Xinyu Tao, Shuang Huang, Yeyun Cai 외 · adjacent field: 의수·웨어러블 생체신호 기반 손 제스처 인식 · source: keyword-sweep

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 손상된 sEMG 채널을 관성 신호로 잠재 공간에서 복구
- **문제** — 일상 착용 중 소켓 미세 이동, 전극 들뜸, 선 단선이 sEMG 채널 일부를 알 수 없는 시점에 망가뜨림
  - 의수 제어와 웨어러블 인터페이스에서 실험실 정확도가 일상 착용에서 유지되지 않음
  - 고장은 전체 모달리티 손실이 아니라 일부 전극의 부분 손상으로 나타나고 나머지 채널과 기준 관성 센서는 정상
- **기존 한계** — 기존 융합 구조는 손상 채널의 영향을 막거나 복구하는 데 각각 한계
  - 채널 연결 CNN, 다중 특징 어텐션, HyFusion과 AiFusion 같은 융합망은 첫 합성곱에서 모든 채널을 섞어 전극 두세 개의 충격이 전체 잠재 특징을 오염
  - 채널 독립 부호화와 품질 게이팅은 손상 채널을 0으로 억제해 세밀한 40–52 클래스 구분에 필요한 동시 활성 단서를 버림
  - 순환 추정, 파형 잡음 제거, 마스킹 파형 복원은 2000Hz 파형 재구성의 인코더-디코더 부담과 합성 왜곡 위험이 있음
- **핵심 방법** — 채널별 부호화, 신뢰도 게이트, 잠재 공간 보간을 한 경량 구조로 결합
  - **채널 독립 부호화** — sEMG 채널마다 그룹 시간 합성곱으로 잠재 토큰 하나 생성
  - **연속 품질 게이트** — 네 가지 시간 영역 통계와 잠재 토큰으로 채널별 신뢰도 점수 산출
  - **잔차 우회** — 신뢰도가 높은 채널은 신뢰도 가중 잔차로 보호
  - **교차 어텐션 보간기** — 전극 식별 임베딩을 질의로 기준 관성 토큰과 정상 sEMG 토큰에서 정보를 가져와 손상 채널의 잠재 토큰 복구, 손상 채널에만 정렬 손실 부여
- **차별점** — 파형이 아니라 잠재 토큰 수준에서 손상 채널을 복구하고, 게이트로 끝내지 않고 다른 모달리티에서 채워 넣음
  - 게이트만 쓰는 방식의 정보 병목과 파형 복원의 연산 부담을 함께 피함
- **핵심 기여** — 구조와 다중 코호트 검증
  - **게이트 검출** — 보지 못한 시험 반복에서 AUROC 0.995 이상
