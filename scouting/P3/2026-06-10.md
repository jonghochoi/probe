## 🥇 논문 1 — 우선순위 ★★★

**TORL-VLA: Tactile Guided Online Reinforcement Learning for Contact-Rich Manipulation**
[arXiv:2606.09337](https://arxiv.org/abs/2606.09337) · Huaihang Zheng, Yi Yang, Kai Ma, Shenglin Xu, Tian Xie, Guozheng Li, Xiangyu Wang, Yiren Ma, Si Liu, Yinian Mao, Baoxu Liu · source: arXiv HTTPS 스윕 (force control + RL + contact)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D13](https://img.shields.io/badge/D13-d97706.svg)](#ref-D13) [![D14](https://img.shields.io/badge/D14-d97706.svg)](#ref-D14) [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 오프라인 VLA 정책은 훈련 분포 외 접촉 조건 이탈 시 온라인 대응 불가 → 부적절한 접촉력·비효율적 재시도 발생
- **TORL-VLA 구조** — 두 컴포넌트로 구성
  - **렌치-인식 VLA(wrench-aware VLA)** — 촉각 유래 렌치(wrist wrench) 신호를 조건으로 참조 행동 + 미래 렌치 시퀀스를 동시 예측
  - **경량 온라인 RL 모듈** — VLA가 예측한 참조 행동을 실시간으로 교정(refinement)
- **intervention-censored critic** — 인간 개입 데이터 학습 시 개입 이후 성공을 개입 이전 정책 행동으로 오귀인하지 않도록 차단하는 학습 안정화 메커니즘; 혼합 탐색 데이터(정책 생성 + 인간 개입)에서 크리틱 편향 방지
- **진정한 신규성** — 기존 VLA 온라인 적응은 IL 기반 수정 또는 보상 없는 파인튜닝에 국한; TORL-VLA는 렌치 예측 목표와 개입-검열 크리틱을 결합한 첫 온라인 RL 적응 프레임워크
  - 렌치 예측과 행동 정책을 하나의 VLA로 통합, 별도 힘 추정기 불필요
- **실물 검증** — 래치 조작(latch manipulation), 커피컵 거치(coffee-cup placement), 달걀 파지(egg handling) 3가지 장기 접촉 집약 과제에서 서브태스크 및 전체 태스크 성공률·시간 효율 개선 확인

### (c) 시사점

- **System0 역할과의 직접 대응** — 경량 RL 모듈이 고수준 정책 출력(참조 행동)에 렌치 기반 교정 적용 → 접촉 조건 이탈 시 실시간 안정화하는 저수준 루프의 온라인 실물 구현
  - 달걀 파지 성공: 연성 물체에서 수 N 이하 파지력 정밀 제어 요구 — System0 슬립 억제 시나리오와 동일 물리 체제
- **렌치 채널의 유용성 실증** — 손목 렌치(6축 힘-토크)만으로 접촉 분포 이탈 감지·교정이 실물에서 작동; D15 입력 설계에 렌치 채널 추가 타당성 근거
- **개입-검열 크리틱 재사용 가능성** — 인간 개입 데이터와 정책 탐색 데이터가 혼재하는 System0 실물 훈련 시나리오에서 동일 기법 적용 가능
  - 실물 데이터 없이 sim2real로만 학습하는 D18 경로 대비 대안적 데이터 전략

### (d) 먼저 확인할 점

- **VLA 결합 의존성** — RL 모듈이 VLA 참조 행동을 입력으로 요구 → System0 독립 모듈(D14 게이트 off 시 완전 독립)로 분리하려면 참조 행동 소스 재설계 필요
  - 현재 구조는 "항상 VLA가 있는 경우"의 잔차 교정, System1-gated 독립 루프와 동일하지 않음
- **렌치 vs. 택셀 촉각** — TORL-VLA는 손목 렌치 6축 사용; D15 v1이 가정하는 택셀 배열 촉각 피처와 해상도 차이 존재
  - 손끝 단위 슬립 발생 직전 신호(전단력 국소 변화)를 렌치 단독으로 포착 가능한지 미검증
- **코드 공개 미확인** — 논문 내 코드 링크 언급 없음; 재현 비용 선확인 필요

## 🌱 논문 2 — 인접 분야 픽

**Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2606.08737](https://arxiv.org/abs/2606.08737) · Yunfan Lou, Yifan Ye, Yankai Fu, Jun Cen, Xiaowei Chi, Yaoxu Lyu, Peidong Jia, Sirui Han, Zhihe Lu, Shanghang Zhang · source: arXiv HTTPS 스윕 (tactile, cs.RO) · adjacent field: 촉각 동역학 통합 세계 행동 모델 (P5 인접 분야; visuotactile 포함으로 P3 Anti-topic)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D14](https://img.shields.io/badge/D14-d97706.svg)](#ref-D14) [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) (인접 참조 — visuotactile 포함으로 P3 주 목록 기준 미충족)

### (b) 핵심 기여

- **Dream-Tac** — 행동·미래 시각 관측·촉각 동역학을 통합 모델링하는 Tactile-World Action Model
  - **contact-gated visuotactile fusion** — 접촉 상황에서만 촉각 신호를 선택적으로 통합(비접촉 상황에서 촉각 채널 차단)
  - **contact-aware attention bias** — 멀티모달 상호작용 크로스-어텐션을 접촉 인식으로 조절
- **듀얼 수준 가속** — 학습 2.9×, 추론 1.8× 빠른 설계; 실시간 배포 목표
- **성능** — 6개 접촉 집약 조작 태스크에서 행동 정확도 평균 31.7% 향상
- **코드 공개** — https://github.com/LYFCLOUDFAN/Dream-Tac
- **visuotactile 포함** — RGB 시각 신호 + 촉각 신호 동시 입력; P3 비전 배제 원칙과 상충으로 주 목록 등록 제외

### (c) 시사점

- **contact-gated 선택적 활성화** — 접촉 유무에 따라 촉각 처리 채널을 on/off하는 구조는 D14 이진 게이트(maintain_grasp on/off)와 기능 측면에서 유사
  - P5 세계 모델 영역에서 "접촉 게이팅"이 실제 6개 태스크에서 정확도 기여 실증 → System0↔System1 인터페이스 게이트 설계 유효성의 측면 근거
- **촉각 동역학 예측의 세계 모델 통합** — 접촉 집약 조작에서 미래 촉각 시퀀스를 사전 예측하면 행동 교정 정밀도 향상 → System0가 접촉 이력(contact-state history) 외에 미래 접촉 동역학 예측을 입력으로 사용하는 확장 방향의 크로스폴리네이션 신호

### (d) 먼저 확인할 점

- **비전 포함** — RGB 시각 스트림이 핵심 입력 중 하나; 비전-only ablation 데이터 없어 촉각 기여분의 독립적 재현 어려움
- **실물 로봇 미확인** — 초록에서 실물 검증 명시 없음; "six contact-rich manipulation tasks" 가 시뮬레이션인지 실물인지 논문 본문 확인 필요

### Decision Log

- **D15 입력 모달리티에 손목 렌치 채널 추가 검토 제안** — 근거: `arXiv:2606.09337`
  - D15 v1은 "tactile feature + finger joint position + velocity + joint torque (or motor current) + contact-state history"로 택셀 기반 촉각 피처와 관절 신호 조합
  - TORL-VLA가 손목 렌치(6축 힘-토크) 단독으로 접촉 조건 이탈 감지·교정 실물 성공 → 손목 렌치를 D15 채널 후보로 추가 검토
  - 제안: 초기 sim ablation에서 "렌치 단독 vs. 택셀 피처 단독 vs. 렌치+택셀 결합" 3-way 비교 추가; 렌치가 택셀을 대체 가능하면 하드웨어 복잡도 감소, 병렬 사용이면 D15 채널 확장

- **D14 게이트 구조 참조 추가 검토 제안** — 근거: `arXiv:2606.08737` (Dream-Tac)
  - D14 v1은 단순 이진 on/off 게이트; Dream-Tac의 contact-gated fusion은 비접촉→접촉 전환 시 촉각 채널을 점진 활성화하는 구조
  - 제안: D14 deferred 항목에 "연속 게이팅(soft contact gate)" 후보 추가 — 이진 on/off 대신 접촉 확률 연속 가중치로 확장 시 System0 반응성 개선 가능성

### Anti-topics

- **"VLA 온라인 파인튜닝 논문 (System0 독립 루프 아닌 경우)" 배제 기준 명문화 검토**
  - 이번 주 포함 최근 4회 리포트에서 VLA 결합 온라인 적응 논문(PaCo-VLA, TAM, TORL-VLA 등) 반복 유입

  - 제안: "VLA/System1 레이어 온라인 파인튜닝 (독립 System0 RL 구조 없는 경우)"를 Anti-topic 후보 항목으로 검토
