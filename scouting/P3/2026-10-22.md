## 🥇 논문 1

**PointWAM: 3D World Action Modeling for Dexterous Robotic Manipulation**
[arXiv:2610.02840](https://arxiv.org/abs/2610.02840) · Chunghyun Park, Beomjun Kim, Seungcheol Park 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — P2 2026-10-13 판정 유지

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 장면과 손을 3D 포인트 궤적으로 함께 예측하는 WAM
- **문제** — 다지 조작에 필요한 3D 공간 구조와 접촉 기하를 월드 액션 모델이 담지 못함
  - 다지 조작은 여러 손가락이 물체 표면에 대해 3D 동작을 정밀하게 조율해야 하는 과제
  - 기존 VLA는 관측에서 모터 명령으로 직행하며 장면이 어떻게 변할지 명시적으로 예측하지 않음
- **기존 한계** — 월드를 RGB 프레임이나 그 잠재로 표현하는 WAM, 점 기반 정책, 행동 조건 3D 월드 모델이 각각 한 축만 다룸
  - 비디오 생성 백본 기반 WAM — RGB 프레임 또는 잠재 표현이 3D 공간 구조와 행위자·환경 간 인과 관계를 담는 데 한계
  - 점 기반 정책 — 3D 점 궤적으로 행동을 예측하나 환경이 어떻게 변하는지는 모델링하지 않고, 과제 관련 물체를 사람이나 외부 인식 모델이 골라줘야 함
  - 행동 조건 3D 월드 모델 — 조밀한 3D 장면 궤적을 예측하나 로봇 행동을 예측 대상이 아닌 입력으로 취급
- **핵심 방법** — 장면 점과 손 키포인트를 공유 시공간 좌표계의 3D 궤적으로 함께 예측한 뒤 손 궤적을 로봇 행동으로 변환
  - 입력 — 컬러 포인트 클라우드와 언어 지시, 손은 손당 10개 키포인트
  - 궤적 예측기 — 동결된 Mosaic3D 인코더 특징을 1 cm 복셀 격자에 올려 희소 컨볼루션과 트랜스포머 인코더로 처리, 장면·손 궤적을 두 MLP 헤드로 출력
  - 행동 변환기 — 예측된 손 궤적과 로봇 상태를 트랜스포머 디코더에 넣어 행동 청크 생성, 장면 예측은 백본 지도에만 쓰고 변환기에는 들어가지 않음
  - 학습 — EgoDex·VITRA 인간 시연 영상으로 사전학습한 뒤 로봇 시연으로 미세조정
- **차별점** — 장면과 손을 분리해 같은 궤적 형식으로 표현하므로 인간 영상과 로봇 시연이 같은 목표를 공유
  - 과제별 물체나 키포인트를 미리 고를 필요 없음
  - 손 궤적이 장면에서 분리되어 로봇 손으로 리타깃팅하기 쉬움
- **핵심 기여** — 모델, 3D 월드 모델링 이득, 인간 영상 사전학습 이득의 3건
  - 시뮬레이션 DexJoCo 10개 과제 다중 과제 평균 성공률 69.0%, 최강 베이스라인 GR00T N1.6보다 11.7점, π0.5보다 19.0점 높음 — 과제당 50회 폐루프 에피소드, 평가 시드 3개
  - 장면 궤적 지도가 손 예측만 하는 모델보다 평균 10.9점 높고, 3D 인코더가 이미지 특징을 3D로 올린 방식보다 5.4점 높음
  - 인간 시연 사전학습이 처음부터 학습 대비 평균 56.9점 향상, 12.1%에서 69.0%
  - 실물 OpenArm 휴머노이드(Inspire 손 2개)에서 GR00T N1.6·π0.5보다 최대 25점 높음 — 과제 2개, 과제당 24회 시행
  - 실물 바나나 집기·놓기에서 처음 보는 상자 조건 58.3%, 베이스라인 16.7%·25.0% — 사각 핀 삽입 50.0%, 베이스라인 16.7%·25.0%
  - 그리퍼 기반 RoboDojo-Precision에서 로봇 데이터 없이 평균 점수 8.8, 성공률 4.8%로 GR00T N1.6의 6.2점, 2.3%보다 높음
- **가치** — 3D 포인트 궤적이라는 공통 표현으로 인간 영상에서 다지 조작을 배우는 경로 제시

### (c) 시사점

- 3D 포인트 궤적 예측이 이미지 잠재 예측보다 낫다는 직접 비교
- **판단 근거** — 같은 기준 모델에서 3D 궤적 예측 64.4%, DINOv3 이미지 잠재 예측 60.1%, 장면 예측 제거 53.5% (시뮬레이션 DexJoCo, EgoDex 사전학습 기준)
- **인간 영상 전이** — 손과 장면이 같은 궤적 형식이라 EgoDex 사전학습으로 12.1%에서 60.1%, 영상을 프레임으로 예측하는 Fast-WAM은 52.9%에서 54.3%로 거의 불변
- **설계 함의** — 접촉 기하를 점 단위로 직접 예측하는 선택지가 픽셀·잠재 예측과 같은 조건에서 비교 가능한 기준점으로 생김
- **공개 기준점** — 코드 공개 약속 없음, 재현 기준은 DexJoCo 공개 벤치마크

### (d) 먼저 확인할 점

- **실물 표본** — 실물 과제 2개, 과제당 24회 시행으로 표본이 작음
- **사전학습 의존** — 백본을 처음부터 학습해 인간 영상 사전학습 없이는 12.1%에 그침
- **해상도 한계** — 저자가 포인트 간격보다 미세한 디테일(인쇄 글자)과 깊이 센서로 잡히지 않는 투명 물체를 놓칠 수 있다고 명시
- **코드 접근** — 저장소 URL과 공개 약속 없음
- **이전 비용** — 깊이 센서의 컬러 포인트 클라우드 입력과 손 키포인트 리타깃팅이 전제라 RGB 전용 스택에는 별도 3D 입력 구성 필요

### (b) 논문 요지

- 인지·예측·계획 세 모드를 한 비디오 모델에서 통합 학습
- **문제** — 에고센트릭 다지 조작에는 관측된 상호작용 이해, 지정 행동의 결과 예측, 목표를 위한 행동 계획이 모두 필요
  - 저자들의 세 질문은 무슨 일이 있었는가, 이 행동을 하면 무슨 일이 생기는가, 목표를 이루려면 무엇을 해야 하는가
  - 세 능력은 3D 모션 지각, 행동 조건 월드 역학 예측, 행동과 예상 결과를 함께 내는 계획
- **기존 한계** — 세 능력이 서로 다른 갈래로 발전해 따로 학습되거나 일부만 결합
  - 에고센트릭 재구성 방법 — 영상에서 손 모션과 카메라 궤적 같은 구조화된 3D 정보를 복원
  - 행동 조건 월드 모델 — 지정된 모션 궤적 아래의 미래 관측을 예측
  - 월드 액션 모델 — 목표 지향 제어를 위해 행동과 미래 관측을 함께 생성
- **핵심 방법** — 사전학습 비디오 확산 트랜스포머 위에 양손 관절 포즈와 카메라 포즈를 압축 토큰으로 얹는 혼합 트랜스포머 구조
  - 백본 — Wan 비디오 DiT, 행동 전문가가 기본 가중치를 공유하고 모달리티별 LoRA로 적응
  - 모달리티 가시성 무작위화 — 영상만 주고 행동을 가리면 인지, 행동만 주고 미래 영상을 가리면 예측, 둘 다 가리면 계획
  - 계획 — 긴 시퀀스에서 계획 구간마다 시각적 하위 목표로 목표 배치를 지정
- **차별점** — 세 모드를 모드별 별도 모델이 아니라 가시성 무작위화만으로 한 모델·한 학습에 통합
  - 구조화된 3D 행동 표현을 사전학습 비디오 백본에 양방향 어텐션으로 연결
- **핵심 기여** — 모델, 통합 학습 프레임워크, 실험의 3건과 코드·체크포인트 공개 약속
  - 단일 모드 학습 대비 통합 학습이 세 모드를 모두 개선 — 같은 5,000 스텝, 데이터셋 4종
  - 인지 — 카메라 공간·루트 상대·PA 오차가 각각 23.46%, 14.23%, 5.69% 감소
  - 예측 — PSNR 17.356에서 18.138 dB, FVD 1105.95에서 1009.84
  - 계획 — VLM 심사 점수가 5개 항목 모두 상승, 시간·정체성 일관성 2.15에서 3.57, 목표 전이 1.98에서 3.29
  - 인지 — HaMeR·Dyn-HaMR 대비 4개 데이터셋 모두 최저 오차, 평균 카메라 공간 MPJPE-p 63.05 mm 대 145.34 mm와 231.54 mm
  - 계획 — Wan2.2 I2V-A14B·Cosmos 3-Nano 대비 행동 과정·지시 준수·물리 상호작용·목표 전이에서 더 높은 VLM 점수
  - 생성한 손 모션을 로봇 명령으로 변환해 실행한 시연 2건
- **가치** — 에고센트릭 영상에서 손 모션 복원, 행동 조건 예측, 목표 지향 계획을 한 모델로 얻는 경로 제시

### (c) 시사점

- 통합 학습 이득의 근거는 있으나 실물 검증은 시연 수준
- **판단 근거** — 같은 조건의 단일 모드 학습과 통합 학습을 맞대 세 모드 모두의 향상을 확인

- **주의** — 계획 품질은 VLM 심사자 점수로만 평가, 로봇 성공률 수치 없음
- **공개 기준점** — 코드와 체크포인트는 공개 약속 단계

### (d) 먼저 확인할 점

- **실물 검증 수준** — 생성한 손 모션을 로봇에 옮긴 시연 2건이며 성공률 수치 없음
- **개루프 실행** — 저자가 로봇 실험이 개루프이고 폐루프 피드백이 향후 과제라고 명시
- **3D 위치 모호성** — 단안 영상의 전역 3D 손 위치 추정이 본질적으로 모호하다고 저자가 명시, 촉각·깊이 보강 제안
- **평가 방식** — 계획 평가가 VLM 심사자에 의존해 실제 과제 성공과의 대응은 미확인
- **이전 비용** — Wan2.2-Fun A14B-Control에서 초기화한 대형 비디오 모델이라 학습·추론 비용이 큼

### (b) 논문 요지

- 에고센트릭 영상 100배 확장에도 객체 충실도는 정체
- **문제** — 데이터와 모델 크기만 키우면 월드 모델이 객체 반응까지 배운다는 규모 중심 관점이 직접 측정되지 않음
  - 월드 모델이 시뮬레이터나 계획용 예측기가 되려면 객체가 행동에 어떻게 반응하는지 예측해야 함

- **기존 한계** — 규모 중심 관점의 근거가 다운스트림 지표에 의존하고, 상호작용 중심 지도는 에고센트릭에 맞지 않음
  - 학습된 시뮬레이터와 물리 시뮬레이터 간 정책 성능 일치, 월드 모델을 정책으로 쓸 때의 오프라인 행동 오차 — 지각·에이전트 모션·객체 동역학·정책 오류가 누적되어 섞임
  - 상호작용 중심 지도(PhysisForcing) — 정적 카메라와 가림 없는 물체를 전제, 재구현한 결과 10k시간에서 스켈레톤 조건 기준 대비 개선 없음
- **핵심 방법** — Cosmos 3 비디오 월드 모델을 에고센트릭 영상 부분집합 사다리로 학습하고 에이전트와 객체 충실도를 따로 측정
  - 데이터 — 14k 참가자, 32k 과제, 116개 환경의 에고센트릭 영상에서 300시간부터 30,000시간까지 중첩 부분집합
  - 모델 — Cosmos 3 변형 3종과 행동 조건화 2종, 하나는 에이전트 몸 구성을 투영한 스켈레톤으로 공급
  - 평가 — 촬영 장비·장소·참가자가 다른 분포 외 벤치마크, 마스크 추적 IoU 기반 SCS로 에이전트와 객체를 분리 채점
  - 객체 중심 적응 노이즈 스케줄링 — `D4RT` 추적으로 동적 영역 맵을 만들고 그 영역의 노이즈 수준을 높여 외형 전파로는 맞출 수 없게 함
- **차별점** — 다운스트림 지표 대신 충실도를 직접 측정하고, 스켈레톤 조건화로 에이전트를 먼저 포화시켜 객체 한계를 분리
  - 조건화가 에이전트가 한계에 이르는 시점만 바꾸고 한계 자체는 바꾸지 않는다는 점을 이용
- **핵심 기여** — 규모 측정, 지도 방식 제안, 휴머노이드 전이의 3건과 평가 벤치마크 공개 약속
  - 에이전트 충실도 — 300시간에서 3k시간 사이 SCS +0.12, 3k시간에서 30k시간 사이 +0.06, 점근선 0.811
  - 스켈레톤 조건화 — 300시간에서 표준 조건화가 약 15k시간에 이르는 에이전트 충실도 도달(데이터 약 50배 절감), 점근선 0.800
  - 객체 충실도 — 스켈레톤 조건 아래 두 자릿수 규모에서 SCS +0.09, 점근선 0.565, 30k시간에서 93% 실현
  - 모델 4배 확대 — 에이전트는 거의 불변, 객체 점근선 +0.034
  - 객체 중심 적응 노이즈 — 30k시간에서 0.546 대 0.527(+3.7%), 무작위 영역으로 바꾸면 이득 대부분 소실, 시험한 개입 중 객체 충실도 상한을 올린 유일한 방법이며 간극은 여전히 큼
  - 휴머노이드 전이 — 시뮬레이션 양손 벤치마크 11개 과제, 인간 영상 사전학습이 손 SCS +0.07, 설계 기여는 그 두 배 이상
- **가치** — 월드 모델 개선이 데이터 양보다 학습 방식에 달렸다는 정량 근거 제시

### (c) 시사점

- 데이터 규모보다 학습 목표가 객체 예측을 좌우한다는 근거
- **판단 근거** — 에고센트릭 손-객체 영상에서 에이전트는 일찍 포화하고 객체 충실도가 병목임을 직접 측정
- **설계 함의** — 손 조건화가 데이터 약 50배 값어치라, 에고센트릭 영상 확보 계획에서 양보다 조건화와 지도 설계를 먼저 비교할 근거
- **주의** — 로봇 정책 성능이 아닌 생성 충실도 지표이며 픽셀 생성 모델 대상

### (d) 먼저 확인할 점

- **실물 결과 없음** — 인간 영상 평가와 시뮬레이션 휴머노이드 전이만 있음
- **점근선 낙관** — 저자가 데이터 사다리가 데이터량과 최적화 예산을 묶고 있어 보고한 상한이 낙관적이라고 명시
- **잠재 예측 미검증** — 저자가 잠재 예측 모델이 상호작용 동역학을 더 쉽게 담는지는 열린 문제라고 명시
- **난이도 의존** — 휴머노이드 시뮬레이션은 객체가 강체이고 커서 객체 충실도가 0.70–0.79로 높아, 결론이 평가 환경 난이도에 좌우
- **코드 접근** — 저장소 URL 없음
