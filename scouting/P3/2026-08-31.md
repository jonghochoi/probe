## 🥇 논문 1 — 우선순위 ★★★

**CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators**
[arXiv:2608.27406](https://arxiv.org/abs/2608.27406) · Kechen Liu, Ola Shorinwa · arXiv preprint · source: citation-graph(Ctrl-World 피인용) · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM) [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC)

### (b) 핵심 기여
- 기존 action-conditioned 비디오 모델이 단일 로봇 임베디먼트에 갇혀 인간·로봇을 아우르는 인터넷 규모 이종 비디오의 물리 신호를 활용하지 못하는 문제 지적
- 엔드이펙터 포즈·언어 지시·잠재 액션 세 가지 서로 다른 액션 표현을 하나의 프레임워크로 통합해 임베디먼트 간 액션 공간 불일치 해소
- 커리큘럼 기반 교차-임베디먼트 학습 — 레이블 없는 비디오에서 잠재 액션으로 물리 prior를 먼저 학습한 뒤, 엔드이펙터 액션 공간에 접지시켜 실환경 제로샷 배포로 이행
- DROID 등 도전적 환경에서 기존 단일-임베디먼트 비디오 모델과 대등하거나 상회하는 성능, few-shot 적응으로 성능 추가 향상
- 엔드이펙터·언어·잠재 액션 조건화 공간과 DROID·Bridge·양손 YAM·G1 휴머노이드를 아우르는 임베디먼트 스펙트럼 커버 — 가장 포괄적인 action-conditioned 비디오 world model 스위트로 제시
- 코드·모델 전체 공개 확인

### (c) 시사점
- 인간 비디오까지 포함한 인터넷 규모 이종 데이터를 하나의 액션 조건화 프레임워크로 흡수하는 레시피 — 사내 에고센트릭·human 비디오 확보 파이프라인을 로봇 비디오와 통합 학습에 바로 연결 가능
- 잠재 액션으로 물리 prior를 먼저 배우고 엔드이펙터 공간에 나중에 접지하는 2단계 커리큘럼이, 액션 라벨이 없는 human 비디오를 world model 학습에 안전하게 섞는 구체적 절차 제공
- 코드·모델이 전부 공개돼 있어 자체 스택에서 바로 재현·비교 가능한 기준점 확보

### (d) 먼저 확인할 점
- DROID에서의 "대등하거나 상회" 비교가 어떤 지표(비디오 예측 품질 vs 실제 정책 성공률) 기준인지 본문 확인 필요
- 다지 손 기반 정밀 조작까지 포함하는 임베디먼트인지, 양손 그리퍼·휴머노이드 수준에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 공개된 코드·모델로 이 에고센트릭 human 비디오 일부를 잠재 액션 사전학습 단계에 우선 투입해 재현

## 🥈 논문 2 — 우선순위 ★★

**Riemann-1.0: An Embodied World Action Model for Physical AI**
[arXiv:2608.27033](https://arxiv.org/abs/2608.27033) · Haofeng Sun, Jiangbo Pei, Fei Kang, Zexiang Liu, Yaokun Li, Boyi Jiang et al. · arXiv preprint · source: citation-graph(Ctrl-World 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- 기존 WAM들이 결합 생성, 비디오-우선 예측, 분리형 모델링 중 하나의 패러다임에 머무는 것과 달리, 다시점 시각 관측·로봇 상태·임베디먼트별 액션을 하나의 인과적 자기회귀 시퀀스로 통합하는 Riemann-1.0 제안
- 로봇 정책 실행과 액션조건부 world simulation을 단일 모델 안에서 통합 — 동일 모델이 실행 가능한 로봇 정책이자 멀티-임베디먼트 시각 world simulator로 동시에 기능
- 에고센트릭 인간 비디오·핸드헬드 그리퍼 시연·이종 로봇 궤적을 하나의 World Action Modeling 목적함수 아래 단계적으로 통합 학습하는 progressive embodied pretraining 프레임워크 도입
- 200K시간 이상의 상호작용 데이터로 사전학습, 대규모 임베디먼트 경험을 실행 가능한 로봇 조작 능력으로 점진 전이
- RoboTwin2.0 94.3%, LIBERO 99.0%, 장기 호라이즌 구성적 벤치마크 RoboCasa-365 62.6%(기존 최고 대비 8.4%p 우위), 실환경 장기 호라이즌 조작에서 Success Rate 85.0%·Progress Success Rate 94.4%(최강 오픈소스 baseline 대비 SR 15%p 우위) 달성
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 단일 모델이 정책 실행과 world simulation을 동시에 겸하는 완전 통합형 설계가, 공유 백본 위 보조 헤드 구조 대비 대안 아키텍처 축의 최신 실증 사례로 참고 가능
- 에고센트릭 인간 비디오·핸드헬드 시연·로봇 궤적을 하나의 목적함수로 단계적으로 통합하는 사전학습 레시피가, 이종 데이터원을 순차 통합하는 구체적 절차로 참고 가치
- 여러 공개 벤치마크와 실환경 모두에서 기존 최고 성능을 상회하는 정량 근거가 확보돼 있어, 통합형 아키텍처의 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 200K시간 규모 사전학습 데이터가 사내 데이터 파이프라인 규모 대비 현실적으로 재현 가능한 스케일인지 확인 필요
- 완전 통합 자기회귀 구조가 액션 전문가 성능에 미치는 간섭 여부가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 코드 미공개 상태라 가장 저렴한 전이 확인은 방법 설명만으로 progressive embodied pretraining의 단계 구성(에고센트릭→핸드헬드→로봇)을 이 소규모 데이터로 우선 재현

## 🥈 논문 3 — 우선순위 ★★

**Zero-WAM: In-Context World-Action Modeling from Human Videos for Open-Ended Task Generalization**
[arXiv:2608.26103](https://arxiv.org/abs/2608.26103) · Jiaming Zhou, Qihang Zhang, Gangwei Xu, Cunxin Fan, Yujie Zhao, Ruilin Wang et al. · arXiv preprint · source: citation-graph(World Guidance 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 학습에 없던 태스크를 그 자리에서 수행해야 하는 교차-태스크 일반화 문제를 겨냥, LLM의 인-컨텍스트 학습(ICL) 패러다임을 로봇 조작에 그대로 가져옴 — 파라미터 업데이트 없이 컨텍스트 안의 human 비디오만으로 새 태스크 명세
- 언어보다 human 비디오가 태스크 진행에 대한 시각적 단서를 더 풍부하게 제공한다는 주장 아래, in-context human 비디오 안내를 따라 미확인 태스크를 수행하는 인과적 비디오-액션 모델 Zero-WAM 제안
- 태스크-풍부한 human-robot 페어 데이터 부족 문제를 겨냥, 태스크 샘플링된 로봇 궤적을 의미적으로 매칭되는 human 비디오로 변환하는 자동 파이프라인으로 8.6K 태스크·7만4200쌍 규모의 HumanGen 데이터셋 구축
- 학습된 태스크에서의 지름길 학습을 억제하고 비디오 프롬프트에서 태스크 정보를 끌어오도록 강제하는 in-context future chunk prediction(IFP) 목적함수 도입
- RoboTwin 2.0 시뮬레이션의 미확인 태스크 7종에서 평균 성공률 47.0%, 최강 비디오-액션 baseline 대비 29.5%p 개선, 실환경에서도 human 비디오 안내로 다중 물체·장기 호라이즌·정밀 삽입 등 미확인 태스크 구성에 일반화 확인
- 프로젝트 페이지만 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 언어 지시 대신 human 시연 비디오를 태스크 명세로 쓰는 인-컨텍스트 패러다임이, 사내 human 시연 자산을 파라미터 재학습 없이 새 태스크 지시 수단으로 바로 활용할 수 있는 경로 제시
- 로봇 궤적을 자동으로 매칭된 human 비디오로 변환하는 파이프라인이, 사내 human-robot 페어 데이터 확보 비용을 줄이는 구체적 데이터 엔진 레시피로 참고 가능
- 미확인 태스크 구성(다중 물체·장기 호라이즌·정밀 삽입)에 대한 일반화가 실환경에서 확인돼, 태스크 커버리지 확장의 비교 기준점으로 활용 가치

### (d) 먼저 확인할 점
- 실환경 결과가 abstract 수준에서는 정성적 서술에 그쳐 구체 태스크 수·성공률 수치는 본문 확인 필요
- human 비디오가 3인칭 시점인지 에고센트릭 시점인지, 손 중심 미세 조작 신호까지 보존하는지 확인 필요
- 가장 저렴한 전이 확인: 이 human 시연 비디오 일부로 로봇-비디오 매칭 파이프라인의 소규모 버전만 우선 재현해 IFP 목적함수 효과 검증

## 🥈 논문 4 — 우선순위 ★★

**GaussianDream++: Efficient 3D Gaussian World Modeling for Robotic Manipulation**
[arXiv:2608.25659](https://arxiv.org/abs/2608.25659) · Yuqing Jiang, Zijian Zhang, Weitao Zhou, Jiawei Wang, Junjie He, Lei Yang et al. · arXiv preprint · source: citation-graph(WorldVLA 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 핵심 기여
- 행동모방 목적함수만으로는 정밀한 3D 구조·단기 물리 변화에 대한 감독이 약하다는 문제의식에서, 기존 GaussianDream의 조밀한 VGGT/TGE 접두(prefix)가 상태·동역학·액션조건화 정보를 한꺼번에 짊어지는 비효율을 지적
- VLA 백본에 World State Token과 World Prediction Token을 직접 삽입하는 경량 policy-native 확장 제안 — 학습 전용 World Representation Head가 이 토큰들을 공유 Gaussian 프리미티브 위의 현재-미래 표현으로 디코딩
- 정적-동적 요소를 분리해 지속적 구조는 보존하고 잔차 모션은 상호작용 관련 영역에 집중
- 추론 시 헤드·렌더러·보조 목적함수·VGGT/TGE 경로를 모두 제거, 온라인 Gaussian 디코딩·롤아웃 없이 20개 world token만 남겨 배포
- LIBERO 98.6%, LIBERO-Plus 87.8%(카메라·배치 변화 조건에서 뚜렷한 우위), 실환경에서 재현한 π0.5 대비 평균 성공률 29.2%→52.5%로 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 학습 시에만 3D Gaussian 기반 현재-미래 표현을 감독 신호로 쓰고 추론 시 완전히 제거하는 구조가, 배포 비용 증가 없이 3D 구조 감독을 취하는 저비용 레시피로 참고 가능
- 20개 토큰만 남기는 극단적 경량화가, 기존 Gaussian·포인트맵 기반 WAM 계열 대비 배포 오버헤드를 더 줄이는 구체적 지점 제시
- 실환경에서 baseline 대비 거의 2배에 달하는 성공률 개선이 정량 보고돼, 3D 구조 보조 감독의 비교 기준점으로 활용 가치

### (d) 먼저 확인할 점
- 동일 계열(3D Gaussian·포인트맵 기반 구조 감독) 최근 논문들과 핵심 아이디어가 근접해, 실제 성능 우위가 어느 구성 요소에서 오는지 소거 실험 기준 본문 확인 필요
- 다지 조작의 미세 접촉 수준까지 3D Gaussian 표현이 유효한지, 조작 대상이 강체 중심 태스크에 국한되는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 World State/Prediction Token 삽입 지점만 우선 이 VLA 백본에 재현

### (b) 핵심 기여
- 모바일 매니퓰레이션이 베이스-암 협응을 다뤄야 해 액션 공간이 고정-베이스 조작보다 훨씬 크고, 기존 VLA 정책은 명시적 태스크-공간 모션 계획 없이 전신 액션 청크를 직접 예측해 협응이 부정확해지는 문제, 예측된 청크를 오픈루프로 실행해 제어 오차·미모델링 접촉이 누적되는 문제 두 가지를 지적
- 의도 수준 엔드이펙터 궤적과 전신 액션 청크를 단일 액션 전문가에서 함께 예측해 궤적이 베이스-암 액션 생성을 명시적으로 안내하도록 하는 DreamTrajectory 제안
- 경량 궤적 world model이 후보 액션 청크가 유발할 궤적을 예측, 탐색-예측-채점 절차로 계획된 궤적과 가장 잘 정렬된 후보를 테스트 시점에 선택
- MS-HAB에서 궤적 안내로 평균 성공률 32.3%→47.5%, 테스트 시점 정제 추가로 54.8%까지 개선, 접촉이 많은 관절체 태스크에서 개선폭 최대
- 세 개 실환경 모바일 매니퓰레이션 태스크에서 각각 성공률 63.3%·81.7%·90.0% 달성
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 경량 궤적 world model로 후보 액션이 유발할 결과를 미리 상상해 채점하는 테스트 시점 개입이, 별도 파인튜닝 없이 배포 시점 강건성을 높이는 저비용 레시피의 또 다른 실증 사례로 참고 가치
- 전체 상태·이미지가 아니라 엔드이펙터 궤적만 예측 대상으로 좁힌 설계라, world model 예측 공간을 태스크-공간 모션으로 압축하는 구체적 대안 제시
- 세 개 실환경 태스크 모두에서 높은 성공률이 정량 보고돼 있어, 모바일 매니퓰레이션 협응 정확도의 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 궤적 world model이 예측하는 대상이 엔드이펙터 궤적으로 한정돼 있어, 손가락 수준 다지 조작의 접촉 세밀도까지 확장 가능한지는 미확인
- MS-HAB 시뮬레이션과 실환경 결과 사이 격차(협응 정확도 유지 여부)가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 탐색-예측-채점 절차만 우선 이 기존 액션 청크 정책에 얹어 재현

- Reproducibility 2 — arXiv abstract "We open-source all code and models. Project Website at https://omni-clap.github.io"
- Methodology 3 — DROID 등 여러 임베디먼트(로봇팔·양손 YAM·휴머노이드 G1)에 걸친 비교, few-shot 적응 추가 개선까지 제시

**Riemann-1.0 (12/15)**

- Novelty 3 — 에고센트릭 human 비디오·핸드헬드 시연·로봇 궤적을 하나의 목적함수 아래 단계적으로 통합하는 200K시간 규모 progressive pretraining 프레임워크가 기존 통합형 WAM 대비 신규
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

**Zero-WAM (12/15)**
- Relevance 3 — human 비디오를 인-컨텍스트 태스크 명세로 쓰는 causal video-action modelD7VC human-to-robot 전이, D3FQ co-trained 예측 역할에 부합
- Novelty 3 — LLM의 인-컨텍스트 학습 패러다임을 human 비디오 프롬프트 형태로 로봇 조작에 가져오는 프레이밍과 IFP 목적함수 조합이 기존 트랙과 구분되는 신규 결합
- Reproducibility 1 — arXiv comment "https://robbyant-research.github.io/Zero-WAM/" (프로젝트 페이지만 확인, 코드 공개 언급 없음)

- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
