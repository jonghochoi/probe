## 🥈 논문 1 — 우선순위 ★★

**TAM: Torque Adaptation Module for Robust Motion Transfer in Manipulation**
[arXiv:2606.06218](https://arxiv.org/abs/2606.06218) · Dongwon Son, Florian Shkurti, Jason Lee, Naman Shah, Beomjoon Kim, Dieter Fox · source: citation-graph (HORA, RMA)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 동일 정책이 로봇 인스턴스마다 동작이 달라지는 동역학 불일치(sim-to-real 격차, 알려지지 않은 페이로드, 개체 간 편차) 문제, 특히 접촉 집약 조작에서 타이밍·접촉 모드 동기화 실패로 이어짐
- **TAM 아키텍처** — 저수준 컨트롤러와 로봇의 토크 인터페이스 사이에 삽입, 두 컴포넌트로 구성
  - **히스토리 인코더** — 고유감각 이력을 잠재 상태로 임베딩
  - **토크 어댑터** — 잠재 상태 + 정책 토크 명령 → 잔차 토크 교정(residual torque correction) 계산
- **독립성** — 정책의 관측 공간·행동 공간에 의존하지 않으므로 서로 다른 행동 공간(관절 목표치, 말단 효과기 목표치, 직접 토크)을 가진 정책에 TAM 가중치 재사용 가능
- **학습 방식** — 실물 로봇 데이터 없이 랜덤화 시뮬레이션에서만 학습: 다중 로봇 사전학습(multi-robot pretraining) → 로봇별 파인튜닝
- **진정한 신규성** — 기존 DR·시스템 ID 방식은 보수적 정책 또는 로봇별 데이터 재수집 필요, TAM은 정책 자체 DR 없이 적응을 TAM에 위임
  - RMA와 달리 잠재 컨텍스트를 노출하지 않고 토크 인터페이스에서 직접 보정
  - 다중 로봇 사전학습으로 물리 파라미터 다양성을 체계적으로 커버
- **검증** — Franka Panda 실물에서 제로샷: 비전 기반 박스 밀기(RL 정책), 플립 동작(BC 정책), MPC 공-접시 균형 유지 3가지 다이나믹 조작 과제

### (c) 시사점

- **D18 sim2real 아키텍처 참조점 추가** — RMA 계열의 잠재 컨텍스트 인코더가 아닌 "토크 인터페이스 잔차 교정" 방식은 System0 sim2real 설계의 대안 경로
  - System0가 손가락 관절 토크 명령을 출력한다면, 같은 토크 인터페이스 위치에 TAM 패턴 적용 가능
  - 기존 D18 deferred "Phase-3 RL fine-tuning" 과는 독립적인 병렬 적응 층으로 활용 가능
- **무-실물-데이터 sim2real 경로 실증** — 다중 로봇 사전학습 + 파인튜닝 전략이 실물 데이터 없이 다이나믹 조작 sim2real을 해결
  - System0 손가락 관절 수(16–24 DoF)로 확장 시 동일 전략 적용 가능 여부 직접 검토 필요
- **다중 정책 재사용** — TAM 가중치가 RL 정책·BC 정책·MPC에 동일 재사용, System1(HandExpert)과 System0(RL 안정화)가 동일 TAM 적응층 공유 가능성

### (d) 먼저 확인할 점

- **팔 수준 → 손가락 수준 확장** — Franka Panda(6 DoF 팔)에서 검증, 다지 손(16–24 DoF 손가락)으로 확장 시 고유감각 이력 차원 대폭 증가 → 인코더 수렴 안정성 별도 검증 필요
- **접촉 신호 부재** — TAM 고유감각 이력에 촉각 신호 없음; System0는 D15에 따라 촉각 피처를 핵심 입력으로 사용, TAM 인코더가 촉각-포함 이력을 처리할 수 있는지 미검증
- **코드 공개 미확인** — 논문에서 코드 공개 여부 명시 없음, 재현 비용 선확인 필요

## 🌱 논문 2 — 인접 분야 픽

**Multi-Resolution Tactile Imitation Learning for Contact-Rich Robotic Manipulation (MiTaS)**
[arXiv:2606.06281](https://arxiv.org/abs/2606.06281) · Rickmer Krohn, Erik Helmut, Niklas Funk, Jan Peters, Vignesh Prasad, Georgia Chalvatzaki · source: citation-graph (AnyRotate) · adjacent field: 이종 촉각 센서 퓨전 기반 모방 학습 (P3 Anti-topic — 비전 포함 IL)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / — (D15 인접 참조, 비전 포함으로 주 목록 기준 미충족)

### (b) 핵심 기여

- **프레임워크 MiTaS** — 서로 다른 시간 해상도로 동작하는 이종 촉각 센서 복수를 활용해 접촉 집약 조작을 해결하는 표현 학습 프레임워크
  - GelSight Mini(비전 기반, 공간 고해상도) + Evetac 이벤트 센서(고주파 시간 해상도) + RGB 카메라 세 모달리티 퓨전
  - 모달리티 별 CNN 스템 + Transformer 기반 퓨전 아키텍처
  - 플로우 매칭(flow-matching) 정책으로 5가지 접촉 집약 과제 조건화
- **진정한 신규성** — 동일 물리 인터랙션을 서로 다른 시간 해상도로 측정하는 센서를 명시적으로 결합한 첫 프레임워크
  - 비전 단독(31%) → 비주오택타일(54%) → MiTaS(80%) 성공률 단계적 향상
  - Evetac 센서 없이 공동 학습만으로도 특정 과제 +10% 이상 향상(co-training 효과)
- **범위 한계** — 비전 포함 IL 프레임워크(P3 Anti-topic 해당), 주 목록 등록 제외

### (c) 시사점

- **이벤트 센서의 고주파 시간 정보 가치** — Evetac(마이크로초 타임스탬프)가 GelSight보다 빠른 순간 접촉 동역학 포착, 슬립 발생 직전 신호를 캡처할 가능성
  - System0가 슬립 억제에 고주파 접촉 변화 감지를 필요로 한다면 이벤트 기반 촉각 센서의 D15 도입 타당성 근거 추가
- **공동 학습으로 센서 부재 보상** — Evetac 없이 GelSight+RGB 공동 학습만으로 성능 유지, 평가 시 센서 서브셋만 사용 가능
  - System0 실물 배포 시 특정 촉각 센서 미장착 환경에서 공동 학습된 표현 활용 가능성

### (d) 먼저 확인할 점

- **비전 포함** — RGB 카메라 스트림이 핵심 모달리티, System0 D15 "비전 완전 배제" 원칙과 상충
  - 이벤트 센서 기여분이 비전 없이도 독립 재현되는지 ablation 데이터 없음
- **모방 학습 한정** — RL 없음, sim2real 검증 없음, System0 접촉 안정화 체제 직접 대응 없음
