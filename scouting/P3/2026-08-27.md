## 🥈 논문 1 — 우선순위 ★★

**DELE-w0.5: Inferring Action from Future Latent State for Robotic Manipulation**
[arXiv:2608.22067](https://arxiv.org/abs/2608.22067) · Fenghao Lei, Zhixiong Huang, Long Yang, Jiabao Chen, Peilin Huang, Han Fu et al. · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- video generation을 world-action model의 불필요한 중간 목표로 규정, 로봇 액션이 만들어내는 물리적 결과(미래 상태)만 포착하면 충분하다는 문제의식에서 출발
- 조밀한 미래 비디오 프레임 대신 압축된 미래 잠재 상태로부터 직접 액션 시퀀스를 추론하는 DELE-w0.5 제안 — 월드 모델링과 액션 생성 사이의 명시적 가교로 미래 잠재 상태 활용
- 시각 외형 변화가 아니라 로봇 액션에 의한 물리적 세계 변화 자체를 모델링한다는 설계 원칙으로, dense 비디오 표현의 고차원 시각 중복성 제거해 학습 비용 절감·추론 지연 저감
- 네 개 장기 호라이즌 조작 태스크의 480회 실로봇 시행에서 최강 비교 정책 대비 전체 성공률 47.5%p, 단계별 진행도 30.7%p 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 미래 비디오 프레임 생성을 완전히 생략하고 압축 잠재 상태만으로 액션을 추론하는 구조가, latent 예측 계열의 저비용 실행 경로로 참고 가능 — 다지 조작의 학습·추론 비용 절감 방향과 직결
- 480회라는 대규모 실로봇 시행 규모와 baseline 대비 큰 폭의 정량 개선치가 확보돼 있어, latent-only 액션 추론 방식의 비교 기준점으로 활용 가치 높음
- video-generation 의존을 정면으로 반박하는 논지가, 이 스택의 예측 공간 선택(픽셀 vs latent) 논의에 직접적인 참고 자료 제공

### (d) 먼저 확인할 점
- 압축 미래 잠재 상태의 구체적 차원·인코딩 방식이 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 네 개 장기 호라이즌 태스크의 구체 종류가 다지 조작의 미세 접촉 수준까지 포함하는지 미확인
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 미래-잠재-상태 예측 헤드를 이 latent WM 파이프라인에 우선 재현

## 🥈 논문 2 — 우선순위 ★★

**ForeTime-VLA: Causal Future-Token Distillation from a World Action Model for Conveyor-Belt Manipulation**
[arXiv:2608.20735](https://arxiv.org/abs/2608.20735) · Siyuan Ma, Yutian Zhang, Boshi Zhang, Qinglian Wu, Jiaqi Zhai, Dong Wei et al. · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 움직이는 물체 조작이 접촉 이벤트를 미리 예측해야 하나, 대부분의 VLA 정책은 현재 관측만으로 파인튜닝돼 이 요구를 충족하지 못한다는 문제의식
- 배포 비용이 큰 world-action model 교사를 학습 시에만 활용, 추론 시점에는 완전히 인과적으로 동작하는 미래-토큰 증류 방법 ForeTime-VLA 제안
- 오프라인에서 현재·미래 비디오 잠재를 압축한 화이트닝 64차원 타깃을 만들고, 온라인에서는 8프레임 히스토리 인코더가 이 타깃과 조작 단계·전환까지 남은 정규화 시간을 함께 예측
- 컨베이어벨트 조작 실로봇 평가에서 정지 물체 파지 성공률 81.1%, 저속 이동 물체 파지 성공률 58.9%로 차선 대비 각각 12.2%p·22.2%p 우위, 세 벨트 속도 전체에서 44/90 대 pi0.5의 23/90 성공
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 무거운 world-action model 교사를 배포 시점에 전혀 구동하지 않고도, 학습 시 증류한 압축 미래 표현만으로 움직이는 물체 조작 성능을 끌어올리는 저비용 레시피 — D3FQ co-trained auxiliary 방향의 구체적 실행 사례
- 정지 물체보다 저속 이동 물체에서 우위 폭이 더 크다는 결과는, 접촉 타이밍 예측이 정적 조작보다 동적 조작에서 더 큰 가치를 낸다는 정량적 근거
- paired-bootstrap 신뢰구간까지 포함한 통계적으로 엄밀한 비교 체계가, 이 실험 설계의 참고 기준으로 활용 가능

### (d) 먼저 확인할 점
- 컨베이어벨트라는 특정 동적 환경에 최적화된 결과라, 손 중심 다지 조작의 비정형 물체 움직임까지 일반화되는지 별도 확인 필요
- 64차원 화이트닝 타깃의 압축 방식이 접촉 세밀도를 얼마나 보존하는지 abstract 수준에서는 확인 불가
- 가장 저렴한 전이 확인: 코드 미공개 상태라 미래-토큰 압축·증류 목적함수만 우선 이 파이프라인에 이식해 정지 대비 이동 물체 조작 성능 차이 재현

## 🥈 논문 3 — 우선순위 ★★

**TrAct: Bridging Robot Control and Visual Prediction with Visual Tracks**
[arXiv:2608.24101](https://arxiv.org/abs/2608.24101) · Zhi Cao, Howard Ji, Kevin Zhang, Kuangzhi Ge, Li Fei-Fei, Jiajun Wu et al. · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 핵심 기여
- 로봇 액션이 임베디먼트에 종속적이라 이미지 공간의 시각 변화와 약하게만 정렬돼, world model의 조건화 신호로 쓰기에 한계가 있다는 문제 지적
- 임베디먼트에 무관한 시각 트랙을 제어-예측 사이의 중간 인터페이스로 삼는 프레임워크 TrAct 제안 — 현재 관측·언어 지시로부터 후보 액션과 대응 트랙을 함께 예측하는 VLAT, 트랙 조건화 world model TWM, 예측 결과를 언어-비전 보상으로 채점하는 VLAC 세 구성요소로 구성
- 추론 시 VLAT가 후보 액션-트랙 쌍을 생성, TWM이 시각적 결과를 롤아웃, VLAC가 지시를 가장 잘 만족하는 트랙을 선택 — 선택된 트랙에 대응하는 액션만 실행
- 자체 제안 LIBERO-INTEGRAL 벤치마크와 실환경 Franka 조작에서 강한 VLA baseline π0.5 대비 성공률 시뮬레이션 27%→55%, 실환경 49%→76%로 개선, TWM은 기존 action-conditioned world model 대비 비디오 예측 품질도 일관되게 향상
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 임베디먼트-특정 액션 대신 임베디먼트-무관 시각 트랙을 제어-예측 공유 인터페이스로 쓰는 설계가, D9KS 예측 공간을 재구성하는 대안적 축으로 참고 가능
- 트랙 예측·world model 롤아웃·보상 채점을 분리한 3단 파이프라인은, D8XB 단일 백본 보조-헤드 구조 대비 명시적으로 분리된 대안적 통합 패턴
- 실환경 성공률 개선폭(49%→76%)이 시뮬레이션 개선폭(27%→55%)보다 더 커, 시각 트랙 인터페이스가 sim-to-real 격차에도 강건할 가능성을 시사

### (d) 먼저 확인할 점
- 자체 제안 LIBERO-INTEGRAL 벤치마크가 외부에 얼마나 검증됐는지, 기존 LIBERO와의 난이도 차이가 본문 확인 필요
- 트랙 예측·롤아웃·채점 3단 파이프라인의 추론 시점 연산 오버헤드가 실시간 제어 주기와 양립하는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 트랙 조건화 world model(TWM) 모듈만 우선 이 기존 action-conditioned WM에 이식

## 🥈 논문 4 — 우선순위 ★★

**Latent Action as Intention Enables Efficient Future Imagination for World Action Models**
[arXiv:2608.24882](https://arxiv.org/abs/2608.24882) · Xiang Li, Yupeng Zheng, Songen Gu, Huailiang Ma, Feng Yu, Xian Nie et al. · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- world action model이 테스트 시점 미래 관측 생성으로 지연이 커지는 문제, 그렇다고 미래 예측 자체를 생략하는 Fast-WAM은 특히 데이터 희소·분포 밖 상황에서 일반화가 떨어진다는 관찰
- 컴팩트한 잠재 액션을 미래 의도의 연산 표현으로 삼아, 미래 관측 생성 없이도 효율적인 테스트 시점 미래 상상을 가능케 하는 LAWA 제안
- 액션-프리 사전학습으로 강화된 이산 토크나이저가 조작 중심 코드북 타깃을 생성, 연속 잠재 상태를 이 타깃에 고정하며 실행 가능한 액션 청크와 함께 공동 디노이징, 추론 시 미래-비디오 분기 생략
- RoboCasa에서 few-shot·전체 데이터 설정 각각 성공률 65.6%·80.8%로 SOTA 달성, 매칭된 Fast-WAM 대비 9.6·4.5%p 우위, 매칭 Joint-WAM 성능 수준 유지하며 추론 지연은 42.9% 낮음, LIBERO-Plus 제로샷 강건성·실환경 우수 성능 확인
- 코드·모델 공개 예정 명시

### (c) 시사점
- 미래 관측 전체를 생성하지 않으면서도 컴팩트 잠재 액션만으로 미래 상상의 이점을 유지하는 설계가, D3FQ co-trained auxiliary의 저지연 구현 사례로 참고 가능
- Fast-WAM(생략)·Joint-WAM(완전 생성)·LAWA(컴팩트 잠재 유지) 세 갈래 비교가 명확해, 이 스택의 지연-일반화 트레이드오프 결정에 직접 참고 가능한 비교 기준점 제공
- 코드·모델 공개 예정 상태라 가까운 시일 내 재현 가능성 높음

### (d) 먼저 확인할 점
- few-shot·전체 데이터 설정의 구체 샷 수·데이터 규모가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 실환경 우수 성능이 abstract 수준에서는 정성적 서술에 그쳐 구체 태스크 수·성공률 수치는 본문 확인 필요
- 가장 저렴한 전이 확인: 공개 예정 코드로 조작 중심 코드북 타깃 생성 토크나이저만 우선 이 Fast-WAM류 baseline에 얹어 지연·일반화 트레이드오프 재현

## 🥈 논문 5 — 우선순위 ★★

**Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning**
[arXiv:2608.24885](https://arxiv.org/abs/2608.24885) · Sixiang Chen, Jiaming Liu, Jixian Wu, Yichen Guo, Tinghao Wang, Siyuan Qian et al. · arXiv preprint · source: citation-graph(VLA-JEPA 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- action-conditioned world model이 정책 평가·개선의 학습된 시뮬레이터로 점점 더 쓰이지만, "생성된 미래가 임의의 유효한 액션을 충실히 반영한다"는 가정 자체는 검증된 적 없다는 문제 제기
- 전문가 시연에 국한된 기존 벤치마크의 한계를 넘어, 더 넓은 액션 분포에서 액션 추종을 진단하는 WorldEcho를 시각적 무결성·SE(3) 궤적 정합 기준으로 도입
- 진단 결과 현재 world model들이 전문가 액션은 합리적으로 실행하나, 전문가 궤적에서 벗어난 다양한 궤적에는 취약 — 지시된 액션을 무시하거나 시각적으로 무효한 롤아웃 생성
- 분포 커버리지 확장·Action-Forcing Expert를 통한 표현 접지·개입 효과 정합 세 축으로 액션 추종을 강화하는 WorldSync 제안
- RoboTwin 벤치마크와 실로봇 태스크에서 WorldEcho 지표 개선, 반복적 정책 개선에 더 신뢰할 수 있는 시뮬레이터로 기능해 정책 성공률 향상 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- action-conditioned world model이 실제로 명령된 액션을 따르는지 정면으로 검증하는 진단 축이, D6FM 행동조건부 예측의 신뢰성을 정량 평가하는 체계적 방법론으로 참고 가치
- off-expert 궤적에 대한 취약성이라는 구체적 실패 모드가, 이 world model 검증 시 전문가 시연 재현만으로는 놓칠 수 있는 문제를 미리 짚어줌
- 분포 커버리지·표현 접지·개입 효과 정합 세 축의 개선 레시피가, D6FM 검증·강화 절차의 구체적 체크리스트로 활용 가능

### (d) 먼저 확인할 점
- RoboTwin·실로봇 실험의 구체 태스크 수·정량 성공률 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 진단 대상 world model들이 어떤 아키텍처 계열인지, D9KS 예측 공간 선택에 따라 이 취약성의 정도가 달라지는지 미확인
- 가장 저렴한 전이 확인: 코드 미공개 상태라 WorldEcho 진단 지표만 우선 이 world model에 적용해 off-expert 취약성 여부부터 확인

### (b) 핵심 기여

- 표준 LIBERO 성능도 개선, RoboTwin·실환경 조작에서 긍정적 전이 경향 확인
- 코드·프로젝트 페이지 공개 언급 없음

- 동기화된 다시점 관측·프레임별 기하 파운데이션 모델 추론이 학습 단계에서 요구돼, 이 데이터 파이프라인이 다시점 캡처를 지원하는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 CLIP·VGGT 직접 증류 단계부터 우선 이 WAM에 재현

## 🥈 논문 7 — 우선순위 ★★

**LD4WAM: Learning Latent Dynamics from Human Videos for World Action Models**
[arXiv:2608.22403](https://arxiv.org/abs/2608.22403) · Zhenhao Shen, Jiaqi Liang, Jasper Lu, Feng Jiang, Yuran Wang, Chuanbo Wei et al. · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 인간 비디오가 world action model 학습에서 점점 중심적 역할을 하지만, 대부분 픽셀 수준 미래 프레임 예측만으로 학습해 직접 실행 가능하지 않은 동역학을 얻는 문제, 반대로 모션 리타게팅은 실행 가능한 액션을 복원하되 임베디먼트 간 큰 시각 격차를 남기는 문제를 동시에 지적
- 비디오 prior와 저수준 액션을 잇는 임베디먼트-무관 표현으로 모션-정렬 잠재 동역학 제안
- 시맨틱 재구성과 실제 모션 정렬로 학습되는 Latent Dynamics Model과, 미래 비디오 생성을 완전히 보존하면서 학습 가능한 쿼리로 이 잠재 동역학을 증류해 액션 조건화에 쓰는 Mixture-of-Transformers 기반 World Dynamics Action Model을 결합한 LD4WAM 제안
- 5,000시간 이상의 인간·로봇 통합 데이터셋으로 사전학습, RoboTwin 시뮬레이션과 그리퍼·다지 손 모두를 장착한 실로봇에서 강한 성능, 미확인 물체·배경에 대한 일반화 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 인간 비디오의 픽셀 예측(실행 불가능)과 모션 리타게팅(시각 격차)의 딜레마를, 모션-정렬 잠재 동역학이라는 중간 표현으로 조율하는 구체적 레시피 — D7VC 에고센트릭 hand-object WM 방향에 직접 대응하는 방법론적 사례
- 그리퍼뿐 아니라 다지 손 실로봇 평가가 명시돼 있어, DexWM 핀 논문과 나란히 비교 가능한 다지 조작 실증 근거
- 미확인 물체·배경 일반화가 보고돼 있어, 에고센트릭 데이터 확장 시 분포 밖 강건성 참고 자료로 활용 가능

### (d) 먼저 확인할 점
- 강한 성능·일반화 확인이 abstract 수준에서는 정성적 서술에 그쳐 구체 태스크 수·성공률 수치는 본문 확인 필요
- 5,000시간 규모 통합 데이터셋 구축이 데이터 파이프라인 규모 대비 현실적으로 재현 가능한 스케일인지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 모션-정렬 잠재 동역학 학습 목적함수만 우선 이 소규모 인간 비디오 데이터에 재현
