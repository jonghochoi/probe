## 🥇 논문 1 — 우선순위 ★★★

**Latent evolving World Action Model**
[arXiv:2609.27455](https://arxiv.org/abs/2609.27455) · Xueji Fang, Boqiang Duan, Hua Wu, Jingdong Wang, Guo-Jun Qi · arXiv preprint · source: citation-graph(VLA-JEPA 피인용) · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 영상 확산 모델(VDM) 기반 WAM이 대규모 영상 생성 사전학습에 성능·비용을 묶이는 구조적 한계 지적
- WAM 안에서 시각 표현이 행동 생성에 미치는 영향을 이론·실험으로 비교, VAE 압축 잠재보다 JEPA 예측 임베딩이 행동 생성에 유리함을 확인(I-JEPA 최고)
- LeWAM 제안 — JEPA 임베딩을 행동 생성 조건으로 쓰고, 같은 공간에서 미래 임베딩을 예측해 환경 변화를 모델링하며 영상 확산 백본 불필요
- 모방 학습이 더 나은 행동과 덜 나은 행동을 구분하지 못한다는 관찰에서, 시연만으로 선호 신호를 만드는 오프라인 정제 단계 DemoDPO 도입
- 학습 파라미터 0.4B, RoboTwin 2.0 평균 성공률 92.28% 보고, 최신 VLA·WAM과 대등

### (c) 시사점
- VLA-JEPA 핀이 제시한 잠재 예측 경로를 영상 생성 없이 WAM 전체로 확장한 공개 기준점 확보
- 예측 공간 선택(잠재 임베딩 vs 압축 픽셀 잠재)을 통제 비교로 뒷받침해, 사내 잠재 예측 선택의 외부 근거로 활용 가능
- 0.4B 규모와 공개 저장소로 도입 비용 낮음, 재현 실험 착수 용이

### (d) 먼저 확인할 점
- 실로봇 결과가 "practical effectiveness" 수준 서술뿐, 과제 수·성공률 정량치는 본문 확인 필요
- 주요 수치가 RoboTwin 2.0 시뮬레이션 기준, 촉각·접촉 집약 과제 일반화는 미검증
- DemoDPO가 오프라인 선호 정제의 이득인지 JEPA 표현의 이득인지 분리된 어블레이션 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**HapticWorld: an Interactive World Simulator with Real-time Torque Feedback**
[arXiv:2609.31924](https://arxiv.org/abs/2609.31924) · Shaoting Peng, Litian Liang, Yixuan Wang, Ming Yang, Katherine Driggs-Campbell, Mark Cutkosky, James Jingxi Xu · arXiv preprint · source: citation-graph(Ctrl-World 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 접촉 집약적 조작의 힘 정보 부재 문제 지적 — 실로봇 수집은 하드웨어에 묶이고, 물리 시뮬레이터는 접촉력 편차가 크며, 학습형 월드 시뮬레이터는 시각 전용
- 관측과 함께 관절 토크를 예측하고 조작자에게 실시간 촉각 피드백으로 되돌려주는 상호작용형 월드 시뮬레이터 HapticWorld 제안
- 접촉 집약 과제 3종에서 토크 피드백으로 데이터 수집 처리량 평균 1.6배 향상
- 생성 시연으로 학습한 정책이 실환경 54/60 성공, 실데이터 상한 56/60에 근접하고 시각 전용 베이스라인 19/60을 크게 상회
- 시뮬레이터 내부 성공률이 실환경 평가와 근접해 힘·토크 조건 정책 평가 플랫폼 가능성 제시

### (c) 시사점
- 월드 모델을 rollout 합성과 상상 내 평가 두 용도로 동시에 검증한 사례, 접촉 신호 예측의 실효 근거 확보
- 힘·토크 예측이 시각 전용 합성 데이터 대비 54/60 대 19/60 차이를 만든 점이 접촉 관련 예측 공간 선택의 직접 증거
- 다지 손에는 토크 외 촉각 채널 확장이 필요하나 구조 자체는 이식 가능

### (d) 먼저 확인할 점
- 프로젝트 페이지만 있고 코드·체크포인트 신호 없음
- 3개 과제, 그리퍼 기반 설정으로 보이며 다지 손 적용 범위는 본문 확인 필요
- 54/60 성공률의 시행 분포와 베이스라인 구성(토크 유무 외 교란 요인) 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**What Makes World Action Models Generalize? An Empirical Study of Test-Time Future Modeling**
[arXiv:2609.34981](https://arxiv.org/abs/2609.34981) · Renping Zhou 외 10인(Gao Huang 포함) · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 추론 시 미래 생성이 필요한지에 대한 논쟁을 통제 실험으로 검증 — 명시적 WAM은 미래 영상을 매번 디노이징하고, 잠재 WAM은 미래를 버려 가속
- 잠재 WAM이 분포 내 과제에서는 명시적 WAM과 같지만 환경 교란·데이터 효율·과제 일반화 3축 모두에서 일반화 이점을 잃음을 확인
- 백본·데이터·예산을 맞춘 비교에서, 행동 전문가가 미래 표현을 조건으로 받지 않을 때 3축 전부 일관되게 저하
- 격차가 거의 전적으로 첫 디노이징 단계에서 발생 — 이득은 미래를 생성하는 데가 아니라 미래를 준비하는 데 있음
- 미래 모델링을 완전 노이즈 영상 토큰의 단일 순전파로 줄이고 학습 노이즈 스케줄을 맞춘 Simple-WAM 제안, 명시적 WAM 수준 일반화와 잠재 WAM 수준 효율 동시 확보

### (c) 시사점
- 학습 전용 보조 예측이 추론 시 조건 입력 없이도 일반화 이득을 유지하는지에 직접 반하는 증거 확보
- 단일 순전파 미래 준비라는 저비용 대안이 제시돼, 추론 비용 제약 하의 설계 선택지 확대
- 시뮬레이션과 실환경 과제 모두에서 평가돼 실로봇 전이 검토 근거로 사용 가능

### (d) 먼저 확인할 점
- 프로젝트 페이지만 있고 코드 저장소 신호 없음
- 실환경 과제의 종류와 규모는 초록만으로 불명, 다지 조작 여부 본문 확인 필요
- 잠재 WAM 비교군이 어떤 인코더·학습 목적을 쓰는지에 따라 결론 범위가 달라질 수 있음
