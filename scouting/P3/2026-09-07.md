## 🥈 논문 1 — 우선순위 ★★

**WISE: World-model-guided Imagination Scheduling for Efficient Post-training of Vision-Language-Action Models**
[arXiv:2609.03681](https://arxiv.org/abs/2609.03681) · (저자 목록 arXiv 미기재) · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- VLA 정책 후처리(post-training)가 값비싼 전문가 시연 지도학습이나 불안정한 실환경 탐색 강화학습에 의존하는 문제 지적, world model이 상상된 미래로 후보 행동을 평가하는 대안 제시
- 단순 예측 정확도만으로는 부족, 언제·어디서 상상을 호출할지 스케줄링하고 신뢰 가능한 호라이즌 내로 제한하며 정책 지도 신호로 신뢰성 있게 변환하는 통합 프레임워크 WISE 제안
- 상호작용이 유의미한 상태에서만 선택적으로 상상을 호출, 다시점 롤아웃을 제한된 길이로 수행, 진행도·완료 신호로 후보 미래를 평가해 실제 상호작용 맥락에서 나온 행동을 정제
- π0·π0.5 두 파운데이션 정책 모두에서 다양한 조작 태스크 전반에 걸쳐 일관된 성능 개선 확인, 전체 상상 대비 GPU 연산 시간 약 80% 절감
- 다양한 실환경 분포 이동 조건에서 강건성·일반화 향상을 실환경 평가로 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- world model을 정책 학습 자체가 아니라 후보 행동 평가·정제 신호로 쓰는 eval-in-imagination 방향의 구체적 실행 사례 — 현재 이 스택이 보류 중인 역할 대안에 실제 이득을 붙인 참고 사례로 가치 높음
- 상호작용 유의미 시점에만 상상을 선택적으로 호출하는 스케줄링이, 상상 비용을 실제 배포 예산 안에서 감당 가능한 수준으로 낮추는 구체적 절감 레시피
- π0·π0.5라는 이미 확보된 파운데이션 정책 위에 후처리 단계로만 얹는 구조라, 기존 액션 전문가를 재학습하지 않고도 적용 가능한 저비용 도입 경로

### (d) 먼저 확인할 점
- 다양한 조작 태스크·실환경 평가의 구체 태스크 수·정량 성공률 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 상상 호출을 촉발하는 "상호작용 유의미 상태" 판별 기준이 다지 조작의 미세 접촉 전이까지 세밀하게 포착하는지 미확인
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 진행도·완료 신호 채점 로직만 우선 이 기존 world model+정책 파이프라인에 재현

## 🥈 논문 2 — 우선순위 ★★

**SA-WAM: Spatially Aware World Action Model via Geometric Latent Diffusion**
[arXiv:2609.02531](https://arxiv.org/abs/2609.02531) · (저자 목록 arXiv 미기재) · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 핵심 기여
- 기존 World Action Model이 대규모 사전학습 비디오 diffusion의 시각·물리 prior를 물려받으면서도 RGB 관측에만 배타적으로 작동해 3D 정보를 전혀 활용하지 못하는 한계 지적
- 깊이 신호를 고정된 VAE 토크나이저가 기대하는 유계 입력 범위로 매핑하는 비선형 인코딩을 도입, 3D 전용 파인튜닝 없이 기존 토크나이저를 그대로 재사용하면서 액션·RGB·깊이를 하나의 diffusion 백본에서 함께 예측하는 SA-WAM 제안
- 사전학습된 시각적 prior를 희생하지 않으면서 기하 정보를 결합 — 백본 구조 자체는 그대로 두고 입력 인코딩만 확장하는 저비용 통합
- RoboCasa·LIBERO-Plus 벤치마크에서 SOTA 달성과 동시에 미래 상태 예측 품질도 함께 개선, UR5 실로봇 평가에서 강한 baseline 대비 우위, 특히 랜덤화된 환경에서 큰 개선폭 확인
- world model 예측 품질과 롤아웃 성공률 사이 상관관계를 별도 분석해 WAM 성능 개선 방향에 참고 자료 제공
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 3D 전용 재학습 없이 깊이를 기존 프리트레인드 diffusion 백본의 입력 인코딩만 확장해 주입하는 방식이, 최근 반복 관찰되는 "3D 기하 신호를 저비용으로 WAM 표현에 주입" 패턴의 또 다른 구체적 메커니즘으로 참고 가능
- 예측 품질-롤아웃 성공률 상관관계 분석이, 이 스택에서 world model 품질을 성능 개선의 대리 지표로 쓸 수 있는지 판단하는 근거 자료로 활용 가치
- UR5 실로봇에서 랜덤화 환경 개선폭이 크다는 결과가, 접촉 집약적 다지 조작으로 확장 시 강건성 기준점으로 참고 가능

### (d) 먼저 확인할 점
- UR5 실로봇 평가의 구체 태스크 종류·정량 성공률 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 그리퍼 기반 UR5 평가라 다지 손 기반 정밀 조작까지 깊이 신호 주입이 유효한지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 깊이 신호의 비선형 인코딩·VAE 토크나이저 재사용 부분만 우선 이 기존 diffusion 기반 WAM에 재현

## 🥈 논문 3 — 우선순위 ★★

**Towards Predictive, Aligned, and Scalable Robot Learning (Lumo-2)**
[arXiv:2607.11270](https://arxiv.org/abs/2607.11270) · Peijun Tang, Shangjin Xie, Baifu Huang, Binyan Sun, Haotian Yang, Kuncheng Luo et al. · arXiv preprint · source: citation-graph(Ctrl-World 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 표준 재구성 기반 액션 토크나이징 목적함수가 저수준 신호 충실도로 편향된 표현을 유도, 재구성 품질과 다운스트림 제어 성능 사이 정렬 불일치를 일으킨다는 문제 지적
- 잠재 공간에서 world dynamics를 추론해 행동을 생성하는 latent world-action model Lumo-2 제안 — 학습된 잠재 동역학이 물리적으로 근거 있는 시각 전이를 포착해 미래 가능성을 인코딩하고 교차 모달 정렬의 공통 기반 제공
- 액션 표현을 잠재 world dynamics·비전·언어에 단계적으로 정렬시키는 multi-stage modality pre-alignment 전략 도입 — 교차 모달 일관성 강제, 추상화 촉진, 예측적 추론을 위한 구조화된 잠재 공간 유도
- latent world modeling과 modality alignment의 스케일링 법칙·분포 밖 일반화에서의 역할을 체계적으로 분석
- 강한 VLA·world-action model baseline 대비 일관된 우위, 시간적 추론·물리적 이해·높은 제어 복잡도가 요구되는 실환경 태스크(장기 호라이즌·다지 조작 포함)에서 개선 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 재구성 충실도가 아니라 다운스트림 제어 성능에 맞춰 액션 표현을 잠재 world dynamics에 단계적으로 정렬시키는 전략이, latent 예측 공간 설계 시 액션 토크나이징 목적함수 선택에 직접 참고할 근거
- 다지 조작을 포함한 실환경 태스크에서의 개선이 보고돼 있어, latent 통합형 world-action model 계열의 비교 기준점으로 활용 가능
- 스케일링 법칙·분포 밖 일반화 분석이, latent world modeling 투자 대비 이득을 가늠하는 참고 자료로 활용 가치

### (d) 먼저 확인할 점
- 강한 baseline 대비 우위·다지 조작 개선 모두 abstract 수준에서는 정성적 서술에 그쳐 구체 벤치마크명·정량 성공률 수치는 본문 확인 필요
- 액션 생성이 world dynamics 잠재 공간에 전적으로 의존하는 완전 통합형 구조라, 액션 전문가를 분리 보존하는 보조-헤드 구조 대비 간섭 위험이 있는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 multi-stage modality pre-alignment 단계만 우선 이 latent WM 파이프라인에 재현

**WISE (12/15)**
- Relevance 3 — world model이 상상한 미래로 후보 행동을 평가·정제해 VLA 후처리를 지도하는 구조가 D3FQ의 보류 중인 eval-in-imagination 역할, D6FM 행동조건부 예측 모두에 직결
- Novelty 3 — 상상을 상호작용 유의미 시점에만 선택적으로 호출하고 제한된 호라이즌·진행도 신호로 채점하는 스케줄링 프레임워크는, 상상 비용과 신뢰성을 동시에 해결하는 신규 결합
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — π0·π0.5 두 파운데이션 정책, 다양한 조작 태스크 전반의 일관된 개선, GPU 연산 시간 약 80% 절감까지 정량 제시
- Sim2Real 3 — 다양한 실환경 분포 이동 조건에서 강건성·일반화 향상을 실환경 평가로 직접 확인

**SA-WAM (11/15)**
- Relevance 3 — 액션·RGB·깊이를 하나의 diffusion 백본에서 함께 예측하는 구조가 D9KS 예측 공간의 3D 확장, D8XB 단일 백본 통합 패턴에 모두 부합
- Novelty 2 — 비선형 인코딩으로 기존 VAE 토크나이저를 재사용하며 깊이를 결합하는 구체적 메커니즘, 다만 "3D 기하 신호를 저비용으로 WAM에 주입"하는 최근 반복 관찰 패턴의 또 다른 사례
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 3 — RoboCasa·LIBERO-Plus SOTA, 예측 품질-롤아웃 성공률 상관관계 분석까지 포함한 정량 검증
- Sim2Real 3 — UR5 실로봇 평가에서 강한 baseline 대비 우위, 랜덤화 환경에서 큰 개선폭 직접 확인

**Lumo-2 (9/15)**
- Relevance 3 — 잠재 world dynamics를 추론해 행동을 생성하는 통합형 latent world-action model이 D3FQ 예측 보조 역할, D9KS latent 예측 공간에 직결
- Novelty 2 — 재구성 충실도 대신 다운스트림 제어에 맞춘 multi-stage modality pre-alignment로 액션-world dynamics 정렬 불일치를 해소하는 구체적 델타
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 2 — 스케일링 법칙·분포 밖 일반화를 체계적으로 분석하고 강한 baseline 대비 우위를 주장하나, 구체 벤치마크명·정량 성공률 수치는 abstract 수준 미확인
- Sim2Real 2 — 장기 호라이즌·다지 조작 포함 실환경 태스크에서 개선 명시, 다만 abstract 수준에서 구체 성공률 수치는 미확인
