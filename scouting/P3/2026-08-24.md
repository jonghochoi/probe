## 🥇 논문 1 — 우선순위 ★★★

**DeVA: Decoupled Video-Action Model with physical guidance for robot policy learning**
[arXiv:2607.24159](https://arxiv.org/abs/2607.24159) · Mengqi Zhang, Sahil Khose, Simar Kareer, Yuchen Song, Unnat Jain, Judy Hoffman · arXiv preprint · source: citation-graph(WorldVLA 피인용) · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 비디오 예측과 액션 생성을 하나의 백본에 결합하는 기존 방식 대신, 비디오 전문가와 액션 전문가를 분리한 **디커플드 구조** 제안
- 비디오 전문가의 여러 레이어에서 액션 전문가로 특징을 전달하는 다중 레벨 특징 전이(multi-level feature transfer)로, 정책 최적화를 어렵게 만들지 않으면서 풍부한 정보 교환 확보
- 어포던스·깊이 등 물리적으로 유의미한 신호로 비디오 중간 특징과 액션 스트림을 함께 감독하는 **physically salient guidance** 도입
- 시뮬레이션 벤치마크와 실환경 배포 양쪽에서 소량 데이터로 강한 성능, 단일 통합 아키텍처 대비 빠른 수렴, 물리적 가이던스에 따른 명확한 성능 향상 확인
- 프로젝트 페이지에서 비디오·코드·체크포인트 공개 확인

### (c) 시사점
- 단일 백본으로 비디오·액션을 결합하는 WorldVLA류 통합형과 달리, 두 전문가를 분리해 정책 학습을 더 다루기 쉽게 만드는 대안적 통합 방식 확보 — D8XB(공유 백본 위 보조 헤드)과 비교 가능한 세 번째 아키텍처 축
- 어포던스·깊이처럼 이미 확보 가능한 구조화 신호를 감독에 활용하는 저비용 물리 가이던스 레시피 — 손 중심 접촉 신호로 확장 여지
- 코드·체크포인트가 공개돼 있어 자체 스택에 바로 이식해 재현 가능

### (d) 먼저 확인할 점
- 실환경 배포 성능이 abstract 수준에서는 정성적 서술에 가까워 구체 태스크 수·성공률 수치는 본문 확인 필요
- 물리 가이던스(어포던스·깊이)가 다지 조작의 미세 접촉까지 확장되는지, 아니면 거친 도달·파지 수준에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 공개된 코드·체크포인트로 이 태스크 하나에 디커플드 구조를 얹어 통합형 baseline과 수렴 속도 비교

## 🥈 논문 2 — 우선순위 ★★

**HiTac-WAM: A Hierarchical Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2608.19574](https://arxiv.org/abs/2608.19574) · Chao Xue, Chaofan Zhang, Wenxuan Ma, Guocai Yao, Shaowei Cui, Shuo Wang · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 기존 촉각 인지형 world model이 미래 촉각을 이미지·잠재 스트림으로만 표현해 물리적 의존 관계를 구조화하지 못하는 문제 지적
- 접촉 상태·3D 변형 필드·슬립 위험을 **위계적으로 분리**해 예측하는 HiTac-WAM 제안 — 각 하위 단계가 앞 단계의 stop-gradient 신호에 조건화된 방향성 계층 구조
- 촉각 쿼리만 비디오·액션 컨텍스트를 참조하고 반대 방향은 차단하는 방향성 어텐션 마스크로 예측 방향을 강제
- 촉각 예측으로 후보 액션 청크를 순위화해 계획 수립, 예측-관측 촉각 불일치 발생 시 교정 재계획 트리거
- 접촉 F1 0.921, 위계 구조 도입 시 3D 변위 오차 17.6% 감소·슬립 AUPRC 60.4% 개선(각각 변형 전용·슬립 전용 예측기 대비), 칩 파지·칠판 지우기·USB 삽입 세 실환경 태스크에서 위계 예측 기반 선택으로 평균 성공률 31.1%에서 61.1%로, 전체 시스템은 72.2%까지 향상
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 접촉·변형·슬립을 하나의 잠재 벡터가 아니라 물리적 의존 순서를 따르는 위계로 분리하는 설계가, 촉각 신호를 world model 예측 공간에 넣을 때의 구체적 구조화 방법론으로 참고 가능 — D9KS 예측 공간 확장에 직접 적용 가능
- 촉각 예측을 액션 청크 순위화·교정 재계획에 쓰는 구조는 D3FQ의 보조 예측 역할을 접촉 집약적 다지 조작에 특화한 사례
- 세 개 실환경 태스크에서 위계 구조 도입 전후 성공률이 두 배 가까이 벌어진 정량 근거가 강해, 접촉 집약적 조작의 비교 기준점으로 활용 가치 높음

### (d) 먼저 확인할 점
- 코드·데이터·하드웨어 구성 공개가 전혀 확인되지 않아 자체 재현 시 촉각 센서·리그 사양부터 별도 확보 필요
- 세 태스크 모두 비교적 단순한 접촉 시나리오(파지·지우기·삽입)라 다지 조작의 복합 접촉(다중 손가락 동시 접촉)까지 일반화되는지 미확인
- 가장 저렴한 전이 확인: 이 촉각 센서 파이프라인에 접촉·변형·슬립 3단 위계 예측 헤드만 우선 이식해 소규모 접촉 태스크로 재현

## 🥈 논문 3 — 우선순위 ★★

**hint²: Hierarchical World Models for Inference-Time Temporal Logic Guidance**
[arXiv:2608.13678](https://arxiv.org/abs/2608.13678) · Moritz Zoellner, Anastasios Manganaris, Ahmed H. Qureshi, Rohan Paleja · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 핵심 기여
- 짧은 청크 단위로 재계획하는 정책이 대부분의 선형 시간 논리(LTL) 사양이 요구하는 장기 궤적 검증과 구조적으로 맞지 않는다는 문제 지적
- 고수준 모델은 태스크 관련 원자 명제의 미래 전이를 예측해 LTL 오토마톤 진행을 안내하고, 저수준 모델은 즉시 상태 변화를 예측해 정밀한 안전 가이던스를 제공하는 **두 단계 world model** 구조 hint² 제안
- 두 world model의 서로 다른 추상화 수준에서 각각 독립적인 가이던스 목적함수를 도출해 결합
- CALVIN에서 기존 LTL 가이드 확산 방법과 기존 추론 시점 조향 방법 모두를 상회, 복잡한 liveness·safety 제약을 언어 조건화 대안보다 자연스럽게 충족
- 실제 UR5e 매니퓰레이터에서 복잡한 지시 수행 시연
- 프로젝트 페이지(비디오)만 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 단일 world model 대신 고수준 의미 전이·저수준 물리 상태 전이를 분리해 각각 다른 목적함수로 가이드하는 이중 계층 구조가, D8XB의 보조-헤드 단일 구조 대비 대안적 통합 패턴으로 참고 가치
- 시간 논리 제약이라는 명시적 태스크 사양을 저수준 dynamics 예측과 결합하는 방식은 안전·순서 제약이 있는 다지 조작 시퀀스에도 적용 여지
- CALVIN 기준 기존 조향·가이던스 방법 대비 우위가 정량 비교로 제시돼 있어 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 실제 UR5e 시연이 abstract 수준에서는 정성적 서술에 그쳐 구체 태스크 수·성공률 수치는 본문 확인 필요
- 저수준 dynamics 모델의 상태 표현이 픽셀·잠재 중 무엇인지, 다지 조작의 접촉 수준 세밀도까지 포착하는지 미확인
- 가장 저렴한 전이 확인: 공개 예정 코드로 이 태스크의 순서 제약 하나를 LTL로 명세해 저수준 가이던스만 우선 재현

## 🥈 논문 4 — 우선순위 ★★

**Robust-WAM: Bridging Generative Pretraining and Semantic Foresight in World-Action Models**
[arXiv:2608.05903](https://arxiv.org/abs/2608.05903) · Haodong Yan, Junfeng Li, Junjie He, Zhide Zhong, MingMing Yu, Wenxuan Song et al. · arXiv preprint · source: citation-graph(WorldVLA 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 사전학습된 비디오 생성 모델(VGM)을 WAM에 전이할 때, VAE 잠재 공간이 픽셀 재구성에 최적화돼 있어 시각적 변화에 액션 예측이 취약해지는 문제 지적
- 시맨틱 잠재 공간 기반 WAM이 시각 변화에 강건하지만 대규모 VGM 사전학습을 활용하지 못하는 딜레마를 겨냥, VAE 기반 생성 경로를 유지한 채 액션 스트림에 경량 시맨틱 예견(foresight) 정렬 목적함수만 추가하는 **포스트-트레이닝 방법** Robust-WAM 제안
- 학습 가능한 쿼리 토큰이 미래 장면 시맨틱을 액션 스트림으로 가져오고, 대응하는 미래 시점의 액션 토큰과 동일한 위치 인코딩을 부여해 쿼리-미래 시점 간 시간적 대응 관계 확립
- 분포 밖 일반화 시뮬레이션 벤치마크와 실환경 셋업에서 여러 WAM 베이스라인의 분포 내 성능 저하 없이 성공률 일관되게 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 대규모 VGM 사전학습을 버리지 않으면서도 조명 변화 등 시각적 분포 이동에 강건한 액션 예측을 얻는 저비용 후처리 레시피 확보
- 기존 VAE 기반 WAM 파이프라인에 쿼리 토큰 정렬 목적함수만 추가하는 형태라, 처음부터 시맨틱 잠재 공간을 재설계하는 것보다 도입 비용이 낮음
- D9KS이 latent/3D-flow를 우선하되 raw-pixel을 완전히 배제하지 않는 방향과 정합 — 픽셀 기반 사전학습 자산을 재활용하는 경로로 참고 가능

### (d) 먼저 확인할 점
- "여러 WAM 베이스라인"·"실환경 셋업"이 abstract 수준에서는 구체 모델명·태스크 수·성공률 수치 없이 서술돼 본문 확인 필요
- 시맨틱 예견 정렬이 조명 등 외관 변화 강건성에 집중돼 있어, 손-객체 접촉 수준의 미세 조작 강건성까지 확장되는지 별도 확인 필요
- 코드 미공개 상태라 가장 저렴한 전이 확인은 방법 설명만으로 쿼리 토큰 정렬 목적함수를 이 기존 VAE 기반 WAM 학습 루프에 우선 재현하는 것

## 🥈 논문 5 — 우선순위 ★★

**LiLa-WAM: Lightweight Latent Reasoning World-Action Model for Robotic Manipulation**
[arXiv:2608.03701](https://arxiv.org/abs/2608.03701) · Fan Yang, Yuting Su, Xiaobo Wang, Yuncheng You, Fugui Fan, Yuting Wu et al. · arXiv preprint · source: citation-graph(WorldVLA·World Guidance·Being-H0.7 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 픽셀 공간 WAM은 제어와 무관한 시각 디테일에 과도한 용량을 쓰고, 일부 잠재 공간 WAM은 추론 공간 구성에 다단계 학습이 필요해 학습 비용이 큰 문제 지적
- 미래 상태 예측과 액션 생성이 함께 빚어내는 **컴팩트 잠재 추론 공간**을 도입해 단일 24GB GPU에서 종단간 학습 가능한 경량 WAM LiLa-WAM 제안
- 각 태스크를 시각 특징 공간상의 방향으로 인코딩하는 언어 비의존 태스크 표현 Visual Transition Token(VTT) 제안
- RoboTwin 2.0 50개 태스크에서 단일 GPU 학습으로 90.48% 성공률 달성, LIBERO·실환경 태스크에서도 효과 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 미래 예측과 액션 생성을 하나의 컴팩트 잠재 공간에 결합하면서도 다단계 학습 없이 단일 GPU로 종단간 학습이 가능하다는 점에서, D3FQ co-trained auxiliary 방향의 저비용 구현 사례로 참고 가능
- 언어 대신 시각 특징 공간 방향으로 태스크를 명세하는 VTT는, 언어 지시가 없거나 모호한 상황에서의 태스크 표현 대안으로 검토 가치
- 단일 24GB GPU 학습 가능이라는 자원 제약 명시가, 사내 목표 하드웨어 예산과 직접 비교 가능한 구체적 기준점 제공

### (d) 먼저 확인할 점
- RoboTwin 2.0 90.48%라는 헤드라인 수치 대비 LIBERO·실환경 결과는 abstract 수준에서 수치가 제시되지 않아 본문 확인 필요
- VTT가 방향 기반 태스크 인코딩이라 세밀한 순서·조건부 지시(예: "먼저 A를 하고 B가 실패하면 C")까지 표현 가능한지 미확인
- 코드 미공개 상태라 가장 저렴한 전이 확인은 컴팩트 잠재 추론 공간 설계만 우선 이 소규모 태스크에 재현해 단일 GPU 학습 가능성부터 검증
