**Direct Experience World-Model Optimization: Learning the World Beyond Action Imitation**
[arXiv:2609.37398](https://arxiv.org/abs/2609.37398) · Xiangcheng Zhan, Zirui Chen, Yicheng Zhao, Ziteng Gao, Shuo Yang · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 11/15** · R3 · N3 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 배포 후 학습으로 WAM의 세계 예측 자체를 개선
- **문제** — WAM의 배포 후 학습이 행동만 개선하고 세계 예측은 개선하지 못함
  - 다지 조작에서는 작은 실행 오차가 접촉을 바꿔 서로 다른 물리적 미래로 갈라지고, 오차가 누적되며 학습 분포 밖으로 이탈
  - 낯선 상호작용이 행동 생성과 이를 받치는 예측 표현을 함께 흔드는 결합 적응 문제
- **기존 한계** — 배포 후 학습의 기존 경로가 행동만 겨냥
  - 직접 행동 지도(Ross 2011, Liu 2023)와 가치 기반 강화학습(Amin 2026 외) — 배포 상호작용에 대한 더 나은 예측을 요구하지 않음
  - 실패한 연속 궤적은 모방 대상이 아니면서도 유효한 물리적 미래의 기록인데, 이 정보가 쓰이지 않음
- **핵심 방법** — 행동 모방과 함께 시각 경험으로 세계 표현을 정제해 행동 생성 조건을 개선하는 배포 후 학습 패러다임 DEWO
  - 리플레이 탐색 — 상호작용 전환점을 찾아 비슷한 맥락의 성공 연속과 실패 연속을 짝지어 수집
  - 결과 조건 월드 모델 학습 — 성공과 실패 두 결과가 각자의 결과 조건 아래 시각 지도를 제공하고, 행동 목표는 성공 연속에서만 취함
  - 진행도 게이트 가이던스 — 영상 표현 위의 가치 헤드가 과제 진행도를 추정하고, 진행이 정체될 때만 classifier-free guidance로 행동을 성공 조건 쪽으로 유도
- **차별점** — 행동 지도는 성공 궤적에 한정하고, 성공·실패 두 미래를 모두 예측 학습 신호로 사용
  - 배포 학습의 목표를 행동 개선에서 예측 개선으로 확장
- **핵심 기여** — 배포 후 학습 패러다임과 전환점 중심 프레임워크, 세 WAM 형식에서의 개선
  - DEWO 정식화 — 관측된 시각 미래에 기반한 지속적 월드 모델링 중심의 WAM 배포 후 학습
  - 프레임워크 — 리플레이 탐색, 결과 조건 월드 모델링, 진행도 게이트 가이던스를 연결
  - 시뮬레이션 DexJoCo 5과제 — 세 WAM 형식(결합 모델링, 영상 후 행동 역동역학, FastWAM) 평균 성공 개선, FastWAM 80.7%에서 82.3%, FACT 64.5%에서 81.2%, 두 경우 모두 SFT 상회
  - ablation — 성공·실패 시각 미래 지도가 행동 지도 단독보다 held-out 영상 손실을 낮추고 과제 성공도 높임
  - 실물 두 다지 손 플랫폼 4과제 — 배포 학습 2라운드로 전 위치 합산 성공 20.6%에서 28.9%, 초기 성공이 1회 이상인 셀 기준 51.0%에서 71.7%
- **가치** — 배포 경험으로 예측과 제어를 함께 개선하는 경로 제시, 월드 모델링을 WAM 적응의 능동 요소로 편입

### (c) 시사점

- 배포 후에도 예측 목표를 유지하는 학습 경로 확보
- 행동 모방만으로 적응하던 단계에 예측 감독을 더하는 설계, 월드 모델을 정책과 함께 갱신하는 보조 역할의 확장 사례
- 다지 손 실물 플랫폼 두 곳(Wuji, Sharpa)에서 정량 이득 보고, 손 중심 조작에 가까운 직접 근거
- 세 WAM 형식에 모두 적용돼 보조 헤드형·결합형 어느 구조에서도 이식 가능성 열려 있음

### (d) 먼저 확인할 점

- 초록·arXiv comment 어디에도 코드·프로젝트 페이지 신호 없음
- 실물 이득은 전 위치 합산 20.6%에서 28.9%로 작고, 51.0%에서 71.7%는 초기 성공이 있는 셀로 한정된 수치
- 시뮬레이션 FastWAM 개선폭은 1.6점으로 작아 이득이 형식에 따라 크게 다름
- 성공·실패 연속 쌍을 모으는 리플레이 탐색의 비용과 2라운드 이후 추세 확인 필요

## 🥈 논문 2

**Magic-W0: A Structured World-Action Foundation Model for Physical Intelligence**
[arXiv:2609.39870](https://arxiv.org/abs/2609.39870) · Xuhua Chen, Zhenhan Yin, Yuan Zhang 외 15인 · arXiv preprint · source: citation-graph · 코드 공개

**점수 11/15** · R3 · N3 · M2 · Real1 · Repro2 — arXiv comment "Code: GitHub - MagiclabRobotics/Magic-W0"

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 기하·3D 모션·미래 의미로 구조화한 WAM 파운데이션 모델
- **문제** — VLA의 지도가 비대칭이라 후보 행동이 일으키는 상태 변화가 독립된 예측 목표로 거의 제약되지 않음
  - 비전·언어 사전학습은 객체·장면 의미 사전지식을, 로봇 시연은 행동 매핑을 제공
  - 물리 상호작용은 행동을 맞추는 과정에서 암묵적으로만 습득
  - 두 질문 — 미래 세계를 어떤 구조로 표현할지, 행동 가설과 예측 전이가 서로 어떻게 조건화할지
- **기존 한계** — 미래 표현 방식과 행동 결합 방식 양쪽에 한계 지적
  - 관측 공간 미래 영상 예측 — 텍스처·조명·배경·시점 변화까지 담아 제어 관련 상태 변화와 어긋나고, 2차원 외형 변화로는 3차원 구조·모션이 드러나지 않음
  - 잠재 공간 예측(DINO-WM, Video Prediction Policy, Fast-WAM) — 관측 재구성은 피하나 미래를 어떻게 구조화할지는 풀지 못함, JEPA-WAM도 예측 잠재의 구조와 행동 표현 정렬에 설계 여지가 있다고 지적
  - 세계 예측을 보조 목표나 추가 조건으로만 쓰는 방식 — 진화하는 행동 가설이 미래 상태 예측에 계속 반영되지 않고, 예측된 변화도 행동 표현의 여러 단계로 피드백되지 않음
- **핵심 방법** — Structured World Transition과 층 정렬 세계-행동 상호작용
  - Current State — 비전·언어 문맥에 Current 3D Geometry를 결합
  - Transition — 3D Motion으로 행동이 일으키는 3차원 변화를 표현
  - Future State — Future Semantics로 과제 관련 결과를 표현
  - 층 정렬 결합 — 연속 행동 전문가와 세계 표현이 여러 네트워크 깊이에서 정보를 주고받아 행동 가설이 미래 전이 예측에 반영되고 예측 표현이 행동 갱신에 피드백
  - 지오메트리·3D 모션·미래 의미에 사전학습 시각 모델의 잠재 지도를 부여
- **차별점** — 세계 예측을 보조 목표나 마지막 단계 조건이 아니라 연속 행동 생성 내내 작동하는 내부 예측 표현으로 배치
- **핵심 기여** — 모델, 결합 구조, 이종 데이터 통합 인터페이스 세 가지와 평가 결과
  - 구조화 WAM 파운데이션 모델 Magic-W0 — 신체를 가로지르는 대규모 사전학습
  - 층 정렬 양방향 결합 — 세계 표현과 연속 행동 전문가가 다층에서 상호 조건화
  - 통합 34차원 상태-행동 인터페이스 — 에고센트릭 인간 조작, UMI, 실로봇, 시뮬레이션 데이터를 한 사전학습에 편입
  - RoboDojo-Sim 평균 점수 27.10, 비교한 WAM 중 최고
  - 추론 시 개입 분석 — 후보 행동이 바뀌면 구조화 표현이 체계적으로 반응하고, 행동 정보가 공유 3D 표현을 거쳐 미래 의미 예측으로 전파
  - 실로봇 여러 과제에서 제한된 다운스트림 데이터 미세조정 후 강한 성능 보고
- **가치** — 세계 전이를 제어 지향 구조로 정의하고 행동과 층별로 묶는 설계 제시, 에고센트릭 인간 데이터까지 한 사전학습에 포함

### (c) 시사점

- 3D 모션을 예측 목표로 둔 대규모 WAM 사전학습 사례 확보
- 3D 모션·기하 예측은 잠재·3D-flow 예측 선택과 같은 방향의 외부 사례
- 에고센트릭 인간 조작 데이터를 사전학습 코퍼스에 넣어, 손 중심 인간 영상 경로와 접점
- 행동 가설과 세계 예측의 층별 양방향 결합은 보조 헤드형과 다른 통합 구조 비교축

### (d) 먼저 확인할 점

- 실로봇 결과가 "strong downstream performance" 서술뿐, 과제 수와 성공률은 본문 확인 필요
- 정량 수치는 RoboDojo-Sim 평균 점수 27.10에 한정
- 코드 표기가 저장소 URL이 아닌 `GitHub - MagiclabRobotics/Magic-W0` 명칭이라 공개 상태 확인 필요
- 층 정렬 결합의 이득과 3D 모션 목표의 이득이 분리되는지, 다지 손 과제 포함 여부 확인 필요

## 🥉 논문 3

**Dexterous Tactile World Model**
[arXiv:2609.34286](https://arxiv.org/abs/2609.34286) · Ziyao Zeng, Xiatao Sun, Hao Wang 외 6인(Daniel Rakita 포함) · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N3 · M3 · Real0 · Repro1 — arXiv comment "Project page: https://adonis-galaxy.github.io/dtwm-project-page/"

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 촉각 장갑 신호로 에고센트릭 조작의 미래 프레임 예측
- **문제** — 월드 모델이 영상으로만 학습돼 접촉이 결정되는 시점의 사건을 정확히 예측하지 못함
  - 손이 접촉 영역을 가리고, 닿은 것과 세게 누른 것이 영상에서 거의 같아 보임
  - 생성 영상에서 손가락이 사라지거나 쥔 물체와 합쳐지거나 덜 움직이는 실패 발생
- **기존 한계** — 촉각을 영상 예측에 넣은 기존 월드 모델 네 편이 데이터·설정·설계에서 다름
  - 세 편(Higuera 2026, Ma 2026, Huang 2026)은 손끝·그리퍼 부착 센서의 로봇 궤적으로 학습, TouchWorld(Zhou 2026b)는 같은 인간 코퍼스로 학습한 뒤 로봇 손 한 쌍에 적응
  - 네 편 모두 로봇 설정에서 행동이나 하위 과제로 조건화해 계획·정책에 사용
  - 촉각을 전역 특징, 추가 토큰, 별도 촉각 이미지로 표현해 접촉이 일어나는 이미지 영역과 정렬되지 않음, 저자들은 이를 인덱싱 불일치로 명명
- **핵심 방법** — 사전학습 영상 확산 트랜스포머의 영상 토큰에 각 손의 촉각 신호를 손 위치에서 잔차로 더함
  - 렌더링한 손 골격으로 손 위치를 계산하고, 촉각 읽기를 임베딩해 가우시안 풋프린트로 주변 영상 토큰에 분산
  - 0 초기화 투영으로 잔차를 계산해 초기에는 사전학습 모델이 변하지 않음
  - 촉각은 관측 프레임에만 제공하고 인과 마스크로 예측 프레임이 미래 정보에 접근하지 못하게 차단, 13프레임을 관측해 다음 36프레임을 한 번에 예측
  - 백본·오토인코더·텍스트 인코더는 동결, 촉각 경로는 몇 개의 선형 사상만 추가
- **차별점** — 행동·미래 손 포즈·미래 촉각 없이 과거 관측만으로 에고센트릭 인간 조작을 예측하고, 촉각을 접촉 위치에 정렬해 주입
- **핵심 기여** — 모델과 평가 결과, 촉각 정보의 효용 분석
  - DTWM — 양손 촉각 장갑 신호와 에고센트릭 영상으로 영상 확산 트랜스포머를 미세조정
  - 구조·파라미터·학습이 같은 영상 전용 모델 대비 손 움직임 과소추정 23%에서 9%, 손 영역 지각 오차 7.4% 감소(모델당 3회 학습), 전체 프레임은 5.1% 감소
  - 예측 호라이즌이 길수록 이득 증가, 후반 청크의 개선이 첫 청크의 약 4.1배
  - 같은 설정에서 기존 시각-촉각 월드 모델 3종 대비 지각 오차 1.8–14.7% 낮음
  - 촉각 크기와 위치가 모두 중요 — 이진 접촉 상태(손별 또는 위치별)로 바꾸면 오차 증가
  - 추론 시 촉각이 없어도 학습 때 촉각을 쓰면 예측 개선
  - 코퍼스에서 힘이 유지되는 손에 비해 힘이 감소하거나 증가하는 손이 다음 0.5초 안에 놓을 가능성 1.8–2.5배
- **가치** — 접촉 시점 정보를 담은 촉각을 영상 월드 모델에 위치 정렬해 넣는 방식과 그 이득의 근거 제시

### (c) 시사점

- 학습 때만 촉각을 써도 이득이 남는 경로 확인
- 에고센트릭 손-물체 예측에 촉각을 더한 직접 사례, 손 중심 인간 영상 월드 모델 축에 촉각 입력의 근거 추가
- 추론 시 촉각 없이도 이득이 유지돼 배포 센서 부담 없이 촉각 장갑 데이터만 학습에 활용 가능성
- 세기와 위치 정보가 이진 접촉보다 유리해 접촉 관련 예측 공간 선택의 참고점

### (d) 먼저 확인할 점

- 평가가 영상 프레임 예측 지표에 한정, 로봇 실험이 없어 정책 성능 이득으로 이어지는지 미확인
- 프로젝트 페이지만 있고 코드 저장소 신호 없음
- 이득 폭이 작음 — 손 영역 지각 오차 7.4%, 전체 프레임 5.1%
- 학습 데이터가 촉각 장갑을 낀 인간 에고센트릭 영상이라 로봇 손 촉각으로 옮기는 비용 확인 필요
