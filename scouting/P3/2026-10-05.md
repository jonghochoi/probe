[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 3D 모션·미래 의미로 짠 구조화 월드-액션 모델
- **문제** — VLA의 지도 신호가 비대칭이라 후보 액션이 일으킬 상태 변화가 독립 예측 목표로 제약되지 않음
  - 비전-언어 사전학습은 장면 의미, 로봇 시연은 실행할 액션을 제약
  - 액션이 만드는 환경 변화는 액션을 맞추는 동안 암묵적으로만 학습
  - 두 질문 — 미래 세계를 어떤 구조로 표현할지, 액션 가설과 예측된 전이가 서로 어떻게 조건화할지
- **기존 한계** — 미래 표현과 액션 생성의 결합 방식이 모두 느슨함
  - 관측 공간 예측 — 미래 이미지·영상은 질감·조명·시점 변화까지 포함하고 3차원 구조와 모션을 드러내지 않음
  - 잠재 공간 예측(DINO-WM, Video Prediction Policy, Fast-WAM) — 완전 재구성은 피하나 미래를 어떻게 구조화할지는 미해결
  - 보조 목표나 조건 특징으로 쓰는 기존 결합 — 진화하는 액션 가설이 미래 예측에 계속 반영되지 않고, 예측된 변화도 여러 단계로 피드백되지 않음
- **핵심 방법** — 구조화 월드 전이 표현과 레이어 정렬 월드-액션 상호작용
  - 현재 상태 — 비전-언어 맥락에 현재 3D 기하를 결합
  - 전이 — 액션이 일으키는 3차원 변화를 3D 모션으로 표현
  - 미래 상태 — 과제 관련 결과를 미래 의미(Future Semantics)로 표현
  - 진화하는 액션 가설이 월드 전이 예측을 조건화하고, 예측된 월드 표현이 액션 생성에 지속 반영
  - 기하·3D 모션·미래 의미의 잠재 지도는 사전학습된 시각 모델에서 가져옴
- **차별점** — 월드 예측을 독립 보조 목표나 최종 단계 조건 특징이 아니라 연속 액션 생성 내내 쓰이는 내부 표현으로 둠
  - 여러 네트워크 깊이에서 월드 표현과 연속 액션 전문가가 정보를 주고받음
- **핵심 기여** — 구조화 월드-액션 파운데이션 모델과 코드 공개
  - 현재 상태–전이–미래 상태 구조의 월드 표현
  - 레이어 정렬 양방향 결합 아키텍처
  - 에고센트릭 인간 조작·UMI·실물 로봇·시뮬레이션 데이터를 34차원 상태–액션 인터페이스 하나로 묶은 사전학습
  - 시뮬레이션 RoboDojo-Sim 평균 점수 27.10, 비교 WAM 중 최고
  - 추론 시 개입 분석 — 후보 액션 변화에 월드 표현이 체계적으로 반응하고, 액션 정보가 공유 3D 표현을 거쳐 미래 의미 예측으로 전파
  - 제한된 하류 데이터 미세조정 후 여러 실물 로봇 과제 성능 보고
- **가치** — 월드 예측을 액션과 함께 진화하는 구조화 표현으로 쓰는 설계의 공개 기준점

### (c) 시사점

- 3D 모션 중심 예측 공간의 공개 기준점 확보
- 3D 모션과 미래 의미를 예측 대상으로 삼은 대규모 사전학습 사례
- 액션 가설이 예측을 조건화하는 구조라 액션 조건 예측 계열의 직접 비교 대상
- 보조 헤드가 아닌 레이어 단위 양방향 결합이라 공유 백본 보조 헤드 방식과 대조 가능
- 코드 공개로 재현·비교 비용 낮음

### (d) 먼저 확인할 점

- 초록의 실물 결과는 수치 없이 하류 성능이 강하다는 서술 수준
- 시뮬레이션 우위는 RoboDojo-Sim 평균 점수 27.10 비교 기준, 베이스라인 구성과 격차 확인 필요
- 대규모 이종 데이터 사전학습이라 구조화 표현의 이득과 데이터 규모 효과의 분리 필요
- 초록에 다지 손 과제 언급 없음, 손 접촉 장면에서의 3D 모션 지도 품질 확인 필요

## 🥈 논문 2

**Dexterous Tactile World Model**
[arXiv:2609.34286](https://arxiv.org/abs/2609.34286) · Ziyao Zeng 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 10/15** · R3 · N3 · M3 · Real0 · Repro1 — arXiv comment "Project page: https://adonis-galaxy.github.io/dtwm-project-page/"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 촉각 글러브로 에고센트릭 미래 프레임 예측
- **문제** — 접촉 시작·해제처럼 조작의 전개를 가르는 사건이 영상으로는 보이지 않아 월드 모델의 접촉 예측이 부정확
  - 손이 접촉 영역을 가리고, 접촉과 강한 누름이 영상에서 거의 같아 보임
  - 예측 영상에서 손가락 소실, 손과 물체 융합, 손 움직임 과소 추정이 나타남
- **기존 한계** — 기존 시각-촉각 월드 모델 4편은 설정과 촉각 표현이 다름
  - 3편은 지문·그리퍼 부착 센서의 로봇 궤적으로 학습
  - TouchWorld는 같은 인간 코퍼스로 학습한 뒤 로봇 손에 적응
  - 4편 모두 로봇 설정에서 월드 모델이 로봇 액션이나 하위 과제에 조건화되어 계획·정책에 쓰임
  - 촉각을 전역 특징, 추가 토큰, 별도 촉각 이미지로 표현해 접촉이 일어나는 이미지 영역과 정렬되지 않음
  - 장갑 판독은 피부 패치로, 비디오 트랜스포머는 이미지 위치로 색인되는 인덱싱 불일치
- **핵심 방법** — 사전학습 비디오 확산 트랜스포머에 손 위치 정렬 촉각 잔차를 주입
  - 렌더링한 손 골격으로 구한 손 위치에 양손 촉각 판독을 가우시안 풋프린트로 퍼뜨려 비디오 토큰에 더함
  - 0 초기화 투영의 잔차라 초기에는 사전학습 모델이 그대로 유지됨
  - 촉각은 관측 프레임에만 공급하고, 인과 마스크로 예측 프레임의 미래 정보 접근을 차단
  - 백본·오토인코더·텍스트 인코더는 동결하고 촉각 경로는 선형 사상 몇 개만 추가
- **차별점** — 촉각 판독을 영상 속 접촉 위치에 정렬해 주입하고, 액션 없이 과거 관측만으로 손 움직임까지 예측
- **핵심 기여** — 촉각 조건 에고센트릭 월드 모델과 촉각 정보 분석
  - 13프레임 관측 후 다음 36프레임을 한 번에 예측하는 설정
  - 구조·파라미터·학습이 같은 비전 전용 모델 대비 손 움직임 과소 추정 23%에서 9%, 손 영역 지각 오차 7.4% 감소, 모델당 3회 학습 기준
  - 예측 지평이 길수록 이득 증가, 뒤쪽 청크의 개선이 첫 청크의 약 4.1배
  - 같은 설정에서 기존 시각-촉각 월드 모델 3종보다 지각 오차 1.8–14.7% 낮음
  - 추론 시 촉각이 없어도 촉각 학습이 미래 프레임 예측을 개선
  - 힘의 크기와 위치가 모두 필요, 이진 접촉 상태로 바꾸면 오차 증가
  - 코퍼스에서 힘이 유지되면 파지가 이어지고, 힘이 감소·증가하면 0.5초 안에 놓을 확률이 1.8–2.5배
- **가치** — 영상으로 보이지 않는 접촉 사건을 촉각으로 직접 읽어 손-물체 상호작용 예측 정확도를 높이는 경로 제시

### (c) 시사점

- 에고센트릭 손-물체 예측에서 촉각 이득을 정량 확인
- 에고센트릭 인간 영상의 손-물체 상호작용이 예측 대상이라 우리 월드 모델 관심 축과 일치
- 힘의 시간 변화가 놓음 예측 신호라 접촉 예측 보조 신호로 활용 가능
- 촉각 글러브를 동반한 에고센트릭 수집의 효용 근거
- 프로젝트 페이지만 공개, 코드·가중치 공개 여부는 별도 확인

### (d) 먼저 확인할 점

- 실물 로봇 결과 없음, 인간 조작 영상 예측만 다루며 저자도 로봇 계획기·정책에 바로 넣을 수 없다고 명시
- 액션 조건 없이 과거 관측만으로 예측해 액션 조건 예측과 직접 대응하지 않음
- 코퍼스 약 20시간으로 비디오 모델 기준 소규모, 양손 촉각을 함께 공개한 데이터가 이 하나뿐
- 손 위치가 외부 재구성 결과라 일부 프레임 누락
- 평가가 지각 오차와 손 움직임 지표이고 조작 성공률은 측정하지 않음

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 촉각 미래를 픽셀이 아닌 표현 공간에서 예측
- **문제** — 월드 액션 모델의 예측이 시각 중심이라 가림 아래 삽입·정렬 같은 접촉 상태와 힘을 풀지 못함
  - 촉각 월드 액션 모델은 미래 촉각 관측을 비디오 생성 방식으로 재구성
  - 배치 중 접촉 위치·힘의 작은 변화가 촉각 이미지를 크게 바꾸지만, 접촉 진화 자체는 예측 가능
- **기존 한계** — 촉각을 다루는 기존 모델은 현재 이해에 그치거나 픽셀 재구성에 묶임
  - 비전-촉각-언어-액션 모델 — 현재 촉각만 이해하고 변화를 예측하지 않아 촉각 피드백에 반응적
  - 촉각 월드 액션 모델 — 같은 VAE로 카메라·촉각 프레임을 인코딩하고 반복 디노이징으로 미래 촉각 잠재를 생성, 추론이 느리고 픽셀 재구성에 묶임
  - 시연은 올바른 접촉 근처만 덮어 폐루프 오차로 분포가 벗어나면 취약
  - N0-VTLA — 고정 DINOv2 특징 공간에서 단일 지평 순변화만 예측, 정적 이미지로 학습한 공간이라 프레임 간 촉각 진화를 담지 못하고 중간 접촉 사건도 가림
- **핵심 방법** — 동역학 인지 촉각 목표 공간과 이종 전문가의 관절 어텐션
  - TacRep — 촉각 클립의 마스킹 시공간 예측으로 학습하고 관계 구조 증류로 정규화한 목표 공간
  - 시각 전문가와 암묵 촉각 동역학 전문가가 별도 파라미터·목표 공간에서 미래 표현을 예측
  - 두 전문가를 레이어마다 관절 어텐션으로 결합하고 액션 전문가가 둘을 모두 사용
  - 촉각 전문가는 한 번의 순전파로 여러 지평의 미래 표현과 현재 대비 변화를 예측
  - 읽기 전용 촉각 이해 메모리가 현재 촉각 상태를 공급
  - 단계적 학습으로 촉각 모듈을 사전학습 전문가에 점진 통합
- **차별점** — 미래 촉각을 재구성하지 않고 접촉 진화를 동역학 인지 표현 공간에서 예측해 픽셀 변화에 둔감
- **핵심 기여** — 촉각 표현 공간과 월드 액션 모델, 시뮬레이션·실물 결과
  - UniVTAC 시뮬레이션에서 제공 시연만으로 평균 성공률 81.5%, 대규모 시각-촉각 궤적으로 사전학습한 모델과 경쟁
  - 픽셀 재구성·정적 대안 대비 TacRep의 이점과 두 촉각 경로의 ablation
  - 실물 5개 과제 평균 성공률 71.0%, 촉각 정책 FTP-1보다 16%p 높음
  - 약 6,000개 실물 시각-촉각 궤적의 중간 규모 사전학습으로 85.0%
- **가치** — 접촉 집약적 조작에서 촉각 예측 대상을 픽셀 대신 표현으로 옮기는 설계 근거

### (c) 시사점

- 촉각 예측의 표현 공간 이동 사례 확보
- 추적 중인 변형 접촉 예측 사례와 대비되는 표현 공간 예측이라 예측 공간 선택의 비교 대상
- 한 번의 순전파 다지평 예측으로 추론 비용 낮음
- 실물 5개 과제 정량 결과로 다과제 근거 확보

### (d) 먼저 확인할 점

- 초록·arXiv comment에 코드·프로젝트 페이지 신호 없음, 본문 재현성 진술의 보충 자료 코드는 공개 링크 없음
- TacRep과 촉각 전문가가 한 종류의 시각-촉각 센서로만 학습, 저자도 센서 간 일반화를 향후 과제로 둠
- 이미지형 촉각 센서 전제라 다지 손의 taxel 계열 촉각 적용은 별도 확인 필요
- 초록에 다지 손 과제 언급 없음
