## 🥇 논문 1

**Magic-W0: A Structured World-Action Foundation Model for Physical Intelligence**
[arXiv:2609.39870](https://arxiv.org/abs/2609.39870) · Xuhua Chen 외 17인 · arXiv preprint · source: citation-graph · 코드 공개

**점수 11/15** · R3 · N2 · M2 · Real2 · Repro2 — arXiv comment "Code: GitHub - MagiclabRobotics/Magic-W0"

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 현재 상태·전이·미래 의미를 구조화한 월드-행동 모델
- **문제** — VLA가 후보 행동이 일으킬 환경 변화를 독립된 예측 목적으로 거의 제약받지 못함
  - 시각-언어 사전학습은 장면 의미를, 로봇 시연은 행동을 지도하나 상태 변화는 행동을 맞추는 과정에서 암묵적으로만 학습
- **기존 한계** — 미래 표현 방식과 예측-행동 결합 방식 두 곳에서 한계 지적
  - 미래 영상·이미지 예측 — 질감·조명·시점 변화까지 포함해 제어와 무관한 정보가 섞이고, 2차원 외관 변화로는 3차원 구조와 운동이 드러나지 않음
  - 잠재 공간 예측(DINO-WM, Video Prediction Policy, Fast-WAM) — 관측 복원은 피하지만 미래 세계를 구조적으로 어떻게 표현할지는 미해결
  - 기존 WAM 결합 — 월드 예측이 보조 목적이나 추가 조건에 머물러, 진화하는 행동 가설이 미래 상태 예측에 계속 반영되지 않고 예측도 여러 단계의 행동 표현에 되먹임되지 않음
- **핵심 방법** — 상호작용을 Structured World Transition으로 표현하고 연속 행동 생성과 층 단위로 결합
  - Current State — 시각-언어 맥락과 Current 3D Geometry 결합
  - Transition — 행동이 유발한 3차원 변화를 3D Motion으로 표현
  - Future State — 과제 관련 결과를 Future Semantics로 표현
  - 층 정렬 상호작용 — 여러 네트워크 깊이에서 행동 가설이 전이 예측을 조건화하고 예측된 월드 표현이 행동 갱신에 되먹임
  - 지오메트리·3D 모션·미래 의미에 사전학습 시각 모델의 잠재 감독 부여
- **차별점** — 월드 예측을 보조 목적이나 최종 단계 조건이 아니라 연속 행동 생성 전 과정의 내부 표현으로 사용
- **핵심 기여** — 구조화 월드 표현, 층 정렬 결합, 이종 데이터 통합 인터페이스 세 가지
  - Magic-W0 — 에고센트릭 인간 조작, UMI, 실로봇, 시뮬레이션 데이터로 사전학습한 월드-행동 파운데이션 모델
  - 34차원 통합 상태–행동 인터페이스로 이종 데이터를 한 사전학습에 사용
  - 시뮬레이션 RoboDojo-Sim 평균 Score 27.10, 비교 WAM 중 최고
  - 제한된 다운스트림 데이터로 미세조정한 다수 실로봇 과제에서 강한 성능 보고, 수치는 초록에 없음
  - 추론 시 개입 분석 — 후보 행동 변화에 월드 표현이 체계적으로 반응하고 행동 정보가 공유 3D 표현을 거쳐 미래 의미 예측으로 전파
  - 코드 공개
- **가치** — 제어 지향으로 구조화한 월드 표현과 행동 생성의 층 단위 결합 설계 및 공개 코드를 WAM 연구의 기준점으로 제공

### (c) 시사점

- 3D 기하·운동 잠재 예측 경로의 공개 기준점
- 3D 모션 잠재 감독이 접촉 관련 예측 공간의 구체 선례, 압축 잠재 예측과 비교할 대조군
- 후보 행동 변화에 월드 표현이 반응함을 개입으로 확인해 행동 조건화 검증 방식 확보
- 에고센트릭 인간 조작 데이터를 사전학습에 포함한 사례
- 공개 저장소 있어 재현 실험 착수 용이

### (d) 먼저 확인할 점

- 실로봇 결과가 초록상 "multiple real-robot tasks" 수준, 과제 수와 성공률은 본문 확인 필요
- 주 수치가 RoboDojo-Sim 평균 Score 기준, 비교 WAM 구성과 격차 폭 확인 필요
- 지오메트리·3D 모션·미래 의미 세 감독이 각각 얼마나 기여하는지 분리 확인 필요
- 다지 손과 접촉 집약 과제 적용 여부는 초록에 없음

## 🥈 논문 2

**World Tokens: Enhancing Embodied Policies with Training-Time World Modeling**
[arXiv:2608.09730](https://arxiv.org/abs/2608.09730) · Qu Tang, Benhui Zhuang, Bo Yuan, Xue Yu, Longteng Guo, Junlan Feng · arXiv preprint · source: citation-graph · 코드 미공개

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — P4 2026-09-03 판정 유지

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 학습 때만 월드 모델링, 배포 땐 VLA 지연 유지
- **문제** — 이미지-텍스트 사전학습은 접촉·가림·물체 이동 같은 행동 관련 시간 전이를 거의 지도하지 않음
  - 정책이 시각-언어 데이터보다 훨씬 적은 로봇 시연에서 이 전이를 배워야 함
- **기존 한계** — 영상 월드 모델의 이득은 추론 비용과 묶이고, 가벼운 예측 목적은 행동 표현을 바꾸지 못함
  - 영상 디노이징 기반 WAM — 반복 영상 디노이징이나 수십억 파라미터 백본 유지로 제어 지연 증가
  - Fast-WAM — 영상 공동학습의 이득을 보이나 배포 제어기에 영상 DiT, 큰 행동 DiT, 언어 인코더 유지
  - 가벼운 예측 목적 — 배포 시 영상 백본은 불필요하나 예측 지도가 병렬 분기로만 작용, 행동 전문가가 전체 VLM 문맥을 그대로 받아 월드 모델링이 만든 부분공간을 무시 가능
- **핵심 방법** — World Adapter가 VLM 특징을 고정 개수의 월드 토큰으로 바꿔 미래 영상 디노이저와 행동 전문가가 함께 사용
  - 월드 토큰 256개가 미래 영상 디노이저의 조건이자 행동 전문가의 유일한 시각-언어 문맥
  - 배타적 라우팅 — 행동 전문가는 전체 VLM 시퀀스에 병렬 접근 불가
  - 월드 모델의 첫 프레임 조건을 에지 맵으로 약화해 토큰이 시각-의미 내용을 담도록 유도
  - 배포 시 월드 모델 분기 제거, VLM·World Adapter·행동 전문가만 추론
- **차별점** — 예측 지도가 행동 표현을 우회하지 못하도록 월드 토큰 경유만 허용하고 월드 모델은 학습에만 사용
- **핵심 기여** — 구조, 모듈, 벤치마크·실물 결과 세 가지
  - World Tokens — 영상 월드 모델과 VLA 정책을 공동학습하고 배포에서 영상 분기 제거
  - World Adapter — VLM 시퀀스를 256개 월드 토큰으로 변환
  - 2B 모델, 로봇 행동 사전학습 없이 LIBERO 98.2%, SIMPLER-WidowX 71.5%, SIMPLER-GoogleRobot 82.1%로 보고된 최고 평균
  - 실로봇 R1 Pro 4과제 96시행 합산 성공률, 동일 조건 행동 단독 기준선(Qwen-GR00T) 59.4%에서 76.0%
  - 행동 청크 생성 지연은 VLA 수준
- **가치** — 영상 모델 추론 비용 없이 예측 학습의 이득을 정책 표현에 이식하는 배포 가능한 인터페이스 제시

### (c) 시사점

- 추론 비용 없는 보조 월드 모델링의 실물 사례
- 예측 지도를 학습 전용으로 두고 배포 시 제거하는 경로가 VLA 지연으로 실로봇 이득을 보인 직접 사례
- 행동 전문가가 월드 토큰만 보게 하는 배타적 라우팅이 예측 지도의 행동 표현 반영을 강제하는 구체 설계
- 로봇 행동 사전학습 없는 2B 규모라 비교 실험 부담 낮음

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음, 재현은 논문 기술 기준
- 실물 평가가 R1 Pro 한 플랫폼의 과일 집어 놓기 4과제, 망고는 격차 없음
- 월드 모델 분기가 학습 비용을 크게 늘리고 에지 앵커가 수작업 설계라는 저자 한계
- 다지 손과 접촉 집약 과제 일반화는 미검증

**HiTac-WAM: A Hierarchical Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2608.19574](https://arxiv.org/abs/2608.19574) · Chao Xue, Chaofan Zhang, Wenxuan Ma, Guocai Yao, Shaowei Cui, Shuo Wang · arXiv preprint · source: citation-graph · 코드 미공개

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 후보 행동별 촉각 결과를 계층 예측해 실행 전 선택
- **문제** — 접촉 집약 조작에서 시각 롤아웃만으로는 후보 행동의 물리 결과를 구분하지 못함
  - 접촉이 가림 때문에 간접 관측, 비슷해 보이는 롤아웃도 접촉 실패·압력 부족·미끄러짐·측면 걸림으로 갈림
  - 실행 전에 후보 행동 청크마다 촉각 결과를 예측하는 것이 핵심 과제
- **기존 한계** — 촉각 활용이 접촉 이후 반응이거나 예측 구조가 물리 의존을 담지 못함
  - 촉각 정책, 느린-빠른 제어기 — 측정된 촉각에 반응하므로 접촉이 일어난 뒤에만 대응
  - 예측형 모델 — 목표 촉각 이미지 비교 선택, 미끄러짐 사전 추정 등을 각각 별도 시스템으로 구현
  - 시각-촉각 행동 모델 — 미래 촉각 이미지·잠재를 학습하나 접촉 상태·계면 변형·미끄러짐 위험을 한 스트림에 얽거나 독립 타깃으로 취급
- **핵심 방법** — 후보 행동 청크마다 미래 촉각 상태 시퀀스를 접촉 상태, 3D 변형장, 미끄러짐 위험의 방향성 계층으로 분해해 예측
  - 상위 단계 신호를 stop-gradient로 하위 단계에 전달
  - 방향성 어텐션 마스크 — 촉각 쿼리는 후보의 영상-행동 문맥을 보고 영상·행동 쿼리는 촉각 토큰을 보지 못함
  - 계획 — 촉각 예측과 과제 진행도 추정으로 후보 청크 순위화
  - 실행 — 선택된 촉각 예측을 기준으로 유지, 예측과 관측의 불일치가 지속되면 교정 재계획
- **차별점** — 촉각 미래를 단일 스트림이나 독립 타깃 대신 물리 의존에 맞춘 방향성 계층으로 분해하고, 후보와 짝지은 예측으로 선택과 실행 중 검증까지 한 모델에서 수행
- **핵심 기여** — 계층 촉각 예측, 예측 유도 행동 선택, 온라인 검증 세 가지
  - 평균 접촉 F1 0.921, 동일 학습 예산에서 변형 단독 예측기 대비 3D 변위 L2 오차 17.6% 감소, 미끄러짐 단독 예측기 대비 slip AUPRC 60.4% 향상
  - 실로봇 3과제(칩 잡기, 칠판 지우기, USB 삽입) 평균 성공률, 단일 후보 실행 31.1%에서 촉각 예측 선택 61.1%
  - 고정 생성 예산에서 과제 진행도 순위만 쓴 경우는 35.6%
  - 온라인 예측 검증까지 포함한 전체 시스템 평균 72.2%
- **가치** — 접촉 결과를 실행 전에 비교하고 실행 중 검증하는 구조화 촉각 예측으로, 시각 롤아웃으로 구분되지 않는 후보를 가려내는 경로 제시

### (c) 시사점

- 접촉 결과를 후보별로 미리 보는 촉각 WAM 사례
- 접촉 상태·변형장·미끄러짐 위험 분해가 접촉 관련 예측 공간의 구체 설계, 후보 선택 31.1%에서 61.1% 상승으로 효과 확인
- 예측과 관측의 불일치로 교정 재계획을 거는 방식이 월드 모델 활용 방식의 하나로 이식 가능
- 행동 조건부 촉각 예측이라 후보 행동 단위 조건화와 직접 연결

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 평가가 IMETA-Y1 로봇의 3개 과제, 다지 손 적용 범위는 본문 확인 필요
- 후보 수 K=4 고정 예산 기준 결과, 후보 수 증가에 따른 이득과 지연 비용 확인 필요
- 실행 중 실측 촉각 입력을 전제, 촉각 센서 없는 플랫폼에는 그대로 적용 불가
