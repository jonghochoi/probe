## 🥇 논문 1 — 우선순위 ★★★

**FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation**
[arXiv:2606.13102](https://arxiv.org/abs/2606.13102) · Chengbo Yuan, Zicheng Zhang, Mingjie Zhou, Wendi Chen, Yi Wang et al. · source: arXiv 키워드 스윕 (tactile + contact-rich)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **문제** — 촉각 정책은 센서 이기종성(heterogeneity)으로 인해 고정 임바디먼트·센서 구성에 묶임; 범용 촉각 인코더 부재로 새 하드웨어마다 처음부터 학습 재수행 필요
- **FTP-1 구조** — 이기종 인코더(heterogeneous encoder) → 형태 인식 잠재 토큰(morphology-aware latent token) → 공유 촉각 트랜스포머 전문가(shared tactile Transformer expert) 3단 파이프라인
  - 이미지형·배열형·상태형 촉각 입력 3종을 단일 잠재 공간으로 통합
- **사전학습 규모** — 약 3,000시간 촉각 조작 데이터, 26개 출처, 21개 센서(인간·로봇 데모 혼합)
- **전이 성능** — 학습 시 보지 못한 2종 촉각 센서에 제로샷 전이 성공률 +31%; 학습 센서 구성에서 +17.2%
- **진정한 신규성** — 다양한 센서·임바디먼트를 아우르는 첫 범용 촉각 기반 모델; 공개 모델·데이터·학습 코드 제공(ftp1-policy.github.io)

### (c) 시사점

- **System0 촉각 인코더 설계 기준점 확보** — 이미지·배열·상태형 신호를 하나의 잠재 공간으로 통합하는 구조가 실물 5개 하드웨어 구성에서 검증됨; 다양한 촉각 센서로 System0 프로토타입을 확장할 때 재학습 없이 활용 가능한 참조 인코더
- **형태 인식 잠재 토큰의 이전 가능성** — 센서 레이아웃·택셀 배열 정보를 잠재 표현에 포함하는 설계가 학습 시 미노출 센서 구성으로도 전이됨; System0의 촉각 특징 추출기 설계 시 동일 접근 방향 적용 가능성
- **공개 사전학습 체크포인트 재활용 가능** — 3,000시간 규모 사전학습 체크포인트 공개; System0 촉각 인코더 초기화 기반으로 파인튜닝 비용 대폭 절감 가능성

### (d) 먼저 확인할 점

- **IL 전용 파이프라인** — 순수 모방학습 기반 사전학습; System0의 RL 접촉 안정화 루프에 FTP-1 인코더를 연결할 때 RL 그라디언트로 인한 표현 붕괴 여부 미검증
- **슬립·파지 유지에 특화 미흡** — 접촉 집약 조작 범주이지만 슬립 억제·파지력 유지 시나리오 직접 검증 없음; 다지 손 전용 실험 비중 확인 필요
- **고주파 제어와의 호환성** — System0가 요구하는 고주파 접촉 제어(≥100 Hz)에서 트랜스포머 추론 지연이 병목이 될 가능성; FTP-1 추론 주기 실측 필요

## 🥈 논문 2 — 우선순위 ★★

**PLUME: Probabilistic Latent Unified World Modeling and Parameter Estimation for Multi-Finger Manipulation**
[arXiv:2606.11396](https://arxiv.org/abs/2606.11396) · Abhinav Kumar, Soshi Iba, Rana Soltani Zarrin, Dmitry Berenson · source: Citation-Graph (HORA)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 다지 손 조작은 마찰계수·물체 형상·자세 등 물리 파라미터에 민감; 표준 도메인 랜덤화(DR) 단독으로는 나사돌리기처럼 파라미터 의존적 전략 전환이 필요한 정밀 접촉 과제에서 충분하지 않음
- **PLUME 구조** — 물리 파라미터(마찰·형상·자세)와 시스템 동역학을 잠재 공간에서 통합 모델링하는 확률적 세계 모델(probabilistic world model)
  - 파라미터 신념(belief)을 배포 시 온라인 추론으로 갱신 → 재학습·파인튜닝 없이 불확실성 처리
  - 부분 관측 보상(partially-observable reward)도 잠재 공간에 통합해 플래닝에 활용
- **평가** — 시뮬레이션: 나사돌리기·밸브돌리기·버킷들기·디스크 튕기기 4개 과제; 실물: 나사돌리기 제로샷 이전 성공 + 오프라인 RL·세계모델 행동복제 기준선 모두 능가
- **진정한 신규성** — DR 대신 온라인 파라미터 추론으로 시뮬레이션 불확실성을 처리하는 첫 다지 조작 세계 모델; RMA 교사-학생 방향과 대칭되는 "신념 추론(belief inference)" 방향 제안

### (c) 시사점

- **DR 충분성 가정에 대한 실증적 반론** — "표준 DR은 정밀 접촉 과제에서 충분하지 않다"는 직접 주장 + 실물 실험 근거; System0 Sim2Real 경로 설계 시 DR 단독 접근의 한계 재검토 필요
- **온라인 파라미터 추론 방향 근거 마련** — 마찰·컴플라이언스 파라미터를 배포 시 실시간 신념 추론하는 세계 모델이 다지 손 실물에서 작동 확인; RMA 교사-학생 대안으로 신념 기반 적응 방향 추가 검토 가능
- **접촉 민감 과제의 파라미터 변동성 대응** — 물체별·표면별 마찰 분산이 큰 시나리오(System0의 다양한 파지 객체)에서 DR 범위 확장보다 추론 기반 적응이 더 안정적일 가능성

### (d) 먼저 확인할 점

- **다지 손 하드웨어 확인 필요** — 논문의 "multi-finger" 과제(나사·밸브·버킷)가 LEAP/Allegro 수준 다지 손인지, 아니면 다자유도 로봇 팔인지 본문 구분 필요
- **슬립·파지 유지 미검증** — 파라미터 추론 세계 모델이 파지 획득(과제 완수) 중심 실험; 파지 후 슬립 억제·접촉 유지 시나리오로의 전이 검증 없음
- **코드 공개 여부 미확인** — 프로젝트 웹사이트(plume-world-model.github.io) 공개, 코드 공개 명시 없음; 재현 비용 선확인 필요

## 🥉 논문 3 — 우선순위 ★

**Mana: Dexterous Manipulation of Articulated Tools**
[arXiv:2606.13677](https://arxiv.org/abs/2606.13677) · Zhao-Heng Yin, Guanya Shi, Pieter Abbeel, C. Karen Liu · source: Citation-Graph (AnyRotate) + arXiv 키워드 스윕

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 관절형 도구 조작(가위·펜 등)은 내부 자유도 조율 + 접촉 집약 상호작용 동시 필요; 강체 물체 중심 선행 연구에서 관절 도구 조작은 크게 미개척
- **Mana 파이프라인** — 다지 조작을 컴퓨터 애니메이션 문제로 재정의
  - 절차적 파지 키프레임(procedurally-generated grasp keyframe) 자동 생성(도구당 마우스 클릭 ≤1분)
  - 모션 플래닝 + 강화학습으로 키프레임 → 조작 궤적 변환(coarse-to-fine)
- **진정한 신규성** — 관절형 도구 파지·인핸드 조작을 단일 파이프라인으로 자동화하는 첫 프레임워크
- **실물 검증** — 4개 도구 유형(서로 다른 스케일·조인트 타입)에서 파지 + 인핸드 조작 모두 제로샷 Sim2Real 이전 성공

### (c) 시사점

- **절차적 키프레임 + RL 조합의 Sim2Real 효율** — 파지 자세를 수작업 데이터 없이 자동 생성한 뒤 RL로 궤적을 다듬는 패턴이 다지 실물에서 작동; 다중 역할(파지·유지·교정) 병존 환경에서 훈련 데이터 자동화에 개념 전이 가능성
- **다지 실물 제로샷 이전 사례 추가** — 4종 관절 도구에서 파라미터 튜닝 없이 시뮬레이션→실물 이전 달성; Sim2Real 파이프라인 구현 시 비교 기준점 확보

### (d) 먼저 확인할 점

- **접촉 안정화와 목적 차이** — Mana는 관절 도구 기능적 사용(가위 자르기 등)이 목표; 슬립 억제·파지 유지 후 접촉 안정화가 주 목적이 아님 → System0 핵심 역할과 직접 대응 미흡
- **촉각 센서 미사용** — 비전 기반 접근 가능성; 촉각 센서 없이 고유감각과 시각만으로 접촉 상태를 처리한다면 System0의 촉각 입력 중심 설계와 상충 여부 본문 확인 필요
- **코드·데이터 공개 여부 미확인** — 초록에 공개 링크 없음; 재현 방향 사전 파악 권고
