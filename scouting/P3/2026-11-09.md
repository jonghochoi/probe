## 🥇 논문 1

**La-JEPA: Compact Robot Policies with Latent World Modeling**
[arXiv:2611.08156](https://arxiv.org/abs/2611.08156) · Mateo Clémente, George Z. Xue, Amin Abyaneh 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — arXiv comment "Code: https://github.com/mt-clemente/lajepa"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 사전학습 JEPA 특징 공간에서 처음부터 학습하는 소형 월드 액션 정책
- **문제** — 로봇 정책이 영상·언어 생성용 대형 트랜스포머 구조를 물려받아야만 경쟁력을 갖는지 불명확
  - 월드 액션 모델(WAM)은 사전학습 영상 생성기를, 비전-언어-액션(VLA) 모델은 언어 생성 트랜스포머를 이어받아 구조와 추론 비용이 생성 모델에 묶임
  - 처음부터 학습한 소형 월드 액션 트랜스포머가 이들 성능에 닿을 수 있는지가 질문
- **기존 한계** — 대부분의 WAM은 영상 VAE 잠재 공간 기반
  - 영상 VAE는 제어에 불필요한 픽셀 수준 충실도에 용량을 씀
  - 기존 JEPA 계열은 VLM이나 영상 생성 모델을 JEPA 공간에 정렬하거나 정책과 함께 JEPA식 잠재 공간을 학습하는 방식
  - 저자들이 아는 한 사전학습 JEPA 특징 공간에서 소형 월드 액션 정책을 처음부터 학습한 선행 연구 없음
- **핵심 방법** — 사전학습 V-JEPA 2.1 인코더의 조밀한 시공간 특징 공간에서 미래 특징 예측과 액션 생성을 함께 학습
  - World DiT와 Action DiT를 처음부터 초기화해 시각 인코더와 독립적으로 구조와 용량 선택
  - Fast-WAM을 따라 액션이 미래 토큰을 참조하지 않아 학습 때만 미래 예측이 정책을 형성하고 추론은 액션만 생성
  - 설계 연구 — 예측 감독, 특징 공간, 시간 인코딩(정적·튜브·튜브-모션), 토큰 축소, 카메라·고유수용감각 드롭아웃, 인코더 LoRA 적응
- **차별점** — 생성 모델 백본 없이 JEPA 특징 공간만으로 월드 액션 정책 구성
  - 같은 조건에서 Wan2.2 VAE 잠재와 V-JEPA 특징을 맞대어 예측 공간 자체를 변수로 측정
- **핵심 기여** — 소형 정책의 벤치마크·속도·실물 결과와 설계 근거
  - 로봇 사전학습 없는 정책 중 RoboTwin 2.0 clean·randomized, 보정한 지시문의 LIBERO-Plus에서 최고, 배포 파라미터는 차순위의 약 1/4
  - Fast-WAM 대비 최대 5배 빠른 추론(최적화 빌드, 소비자 GPU 한 대)
  - 가장 가까운 JEPA 기반 LeapBot-WA와 JEPA-WAM을 LIBERO-Plus와 RoboTwin 2.0에서 능가
  - 미래 예측 도입 효과 — RoboTwin clean +7.0점, randomized +3.7점, LIBERO-Plus는 시드 3개 모두 평균 +2.1점
  - V-JEPA 특징이 Wan2.2 VAE 잠재 대비 RoboTwin clean +15.9점, randomized +16.0점, LIBERO-Plus +6.0점, LIBERO +2.0점
  - Franka 실물 4개 과제(과제당 20회) 평균 성공률이 π0.5와 비슷하고 실물 사전학습 없는 기준선보다 높음
  - 공식 LIBERO-Plus 평가기가 대부분 변형에 지시문을 오염시킴을 확인, 최대 19점 차이를 내며 기준선을 보정 지시문으로 재평가
- **가치** — 제어용으로 설계한 소형 구조가 생성 모델 계승 구조를 대체할 수 있다는 근거와 JEPA 특징 공간 설계 지침

### (c) 시사점

- 잠재 공간 예측과 영상 VAE 예측을 같은 정책 틀에서 직접 맞댄 공개 기준점
- 영상 VAE 대비 JEPA 특징의 이득이 분포 밖에서 가장 큰 점이 잠재 예측 선택의 근거
- 학습 때만 미래를 예측하고 추론 때는 액션만 내는 구조라 배포 비용 부담 낮음
- 코드와 설정이 공개돼 있어 자체 정책에 JEPA 특징 보조 예측을 붙여 보는 실험 비용 낮음
- 평가기 오염 보정은 LIBERO-Plus 기반 비교 결과를 읽을 때 쓸 기준

### (d) 먼저 확인할 점

- 실물 평가가 Franka 한 대, 4개 과제에 한정되어 폭넓은 조작 요구에서의 동등성은 미확인
- 로봇 사전학습 없이 목표 시연만으로 학습해 사전학습 규모 확대 시 이득이 유지되는지 미검증
- 학습률·가중치 감쇠·드롭아웃 등을 체계적으로 탐색하지 않았고 RoboTwin 규모 확대가 단조롭지 않음
- randomized RoboTwin에서는 일부 로봇 사전학습 정책이 더 높음
- 체크포인트 공개는 본문에 없음
- 접촉 집약적 과제는 Push T 한 개뿐이고 촉각·힘 신호는 다루지 않음

## 🥈 논문 2

**ForceLDM: A Force-aware Latent Dynamics Model for Contact-Rich Manipulation**
[arXiv:2611.03294](https://arxiv.org/abs/2611.03294) · Peiyuan Tang, Yao Li, Xiaodong Zhang 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — 초록 "Project page and code are available at https://tpy001.github.io/ForceLDM/"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 힘·광학 흐름의 미래 동역학을 교사에서 학생으로 증류하는 접촉 집약적 조작 정책
- **문제** — 접촉 집약적 조작(USB 삽입, 조립)은 시각만으로 접촉 상태와 힘 크기를 추정하기 어려움
  - 힘·토크 신호는 시공간적으로 희소하고 접촉 단계에서만 유효해 모델이 시각 단서에 치우침
  - 현재 관측에서 액션으로의 사상만 학습하면 시연에 과적합되어 낯선 환경에서 일반화 한계
- **기존 한계** — 힘 인식 연구가 힘·토크를 추가 입력으로만 취급하고 미래 상호작용 동역학은 모델링하지 않음
  - ForceVLA — 모달리티별 전문가 혼합(MoE)으로 시각·힘 특징을 적응적으로 융합
  - TA-VLA — 관절 토크를 액션 생성 모듈에 주입
  - 저속 시각과 고속 힘을 결합하는 이중 시스템 구조
  - 영상 생성 기반 월드 모델은 물리적으로 일관된 접촉 동역학을 못 잡을 수 있고 힘 관측으로 미세조정하려면 계산과 동기화 데이터가 많이 듦
  - 미래 관측을 직접 예측하면 배경·외형·센서 잡음이 과제 관련 동역학과 얽힘
- **핵심 방법** — 미래 힘/토크와 광학 흐름을 특권 신호로 쓰는 교사 네트워크의 잠재 특징을 현재 관측만 보는 학생에게 증류
  - 교사 — 미래 관측에서 액션 예측을 통해 제어에 유용한 압축 동역학 특징 추출
  - 학생 — 학습 가능한 질의 토큰으로 교사의 잠재 표현을 맞추어 미래 동역학을 상상, 배포 시 미래 센싱 불필요
  - 점진적 노이즈 주입 — 커리큘럼으로 학생 질의 토큰에 노이즈를 늘려 미래 특징 과의존 완화
  - π0 위에 구축, 카메라 2개와 10단계 힘/토크 이력 입력
- **차별점** — 미래 관측을 재구성하지 않고 압축한 잠재 동역학을 증류
  - 영상 재구성 보조 지도를 쓰는 Seer, 미래 힘을 직접 예측하는 TA-VLA와 달리 힘과 광학 흐름을 함께 증류
- **핵심 기여** — 미래 동역학 표현, 증류 구조, 실물 검증
  - xArm 7 실물 5개 과제(과제당 20–30회 롤아웃, 시연 80–100개) 평균 성공률 87.1%로 가장 강한 기준선 Seer 대비 14.9점 우위
  - 분포 밖 설정(설정당 15회) 평균 68.9%로 가장 강한 기준선 대비 20.0점 우위
  - 미래 예측 목표 ablation — 힘+광학 흐름 90.7%, 힘 단독 68.0%, 광학 흐름 단독 70.7%, 힘에 RGB를 더해도 개선 없음
  - 증류 손실 제거 시 평균 85.1%에서 42.8%, 직접 예측으로 대체하면 62.1%, 점진적 노이즈 제거 시 74.1%
  - 부록 두 번째 플랫폼 Piper-X 70%
- **가치** — 힘 신호를 입력이 아니라 미래 동역학의 지도 신호로 쓰는 경로 제시

### (c) 시사점

- 영상 재구성 없이 잠재 증류로 접촉 동역학을 넣는 실물 근거
- 미래 목표 조합 ablation이 접촉 관련 신호와 움직임 신호의 상보성을 직접 보여 줌
- 배포 시 현재 관측만 쓰는 학생 구조라 추가 센서 비용이 추론 단계에 없음
- 증류 손실 제거와 직접 예측 대체의 큰 낙폭이 보조 예측 설계 시 비교 기준으로 쓸 수 있는 수치
- 힘/토크 센서가 있는 플랫폼이 전제

### (d) 먼저 확인할 점

- 코드 저장소 주소가 초록에 보이지 않고 프로젝트 페이지만 확인됨
- 데이터가 소규모라 데이터 확대 시 이득이 유지되는지 저자도 미확인
- 광학 흐름 추정이 가림·모션 블러에 흔들릴 수 있고 2D 흐름에는 깊이 정보 없음
- Gear Assembly에서는 공간 지각 한계로 TA-VLA에 뒤짐
- 본문 두 번째 플랫폼 결과는 부록 한 곳뿐
- 주 실험이 xArm 7 한 플랫폼에 한정, 학습에 필요한 미래 힘/토크 기록 수집 부담

## 🥉 논문 3

**Trace-WAM: Learning to Act via 3D Motion Prediction for World Action Models**
[arXiv:2610.36840](https://arxiv.org/abs/2610.36840) · Xu Hu, Changjie Wu, Linzhe Shi 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — arXiv comment는 프로젝트 페이지 "https://trace-wam.github.io/"뿐, 초록·본문에 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 영상·액션 월드 모델에 미래 3D 모션 예측을 보조 목표로 더한 학습
- **문제** — 조작 성패는 로봇과 과제 관련 물체가 시간에 따라 어떻게 변하는지에 달렸는데 미래 RGB 예측은 질감·조명·배경까지 모델링해야 함
- **기존 한계** — 영상 예측에 깊이·기하, 의미 특징, 어포던스·목표 영역 같은 보조 감독을 더하는 방식
  - 프레임 또는 영역 단위 목표만으로는 같은 물리 위치가 상호작용 내내 어떻게 변하는지 짚지 못함
  - 4D-WAM — 사전학습 4D 추적 모델의 시간적 특징 변화와 출발-도착 관계에 정렬하는 방식으로 궤적 지식 전이
- **핵심 방법** — 영상·모션·액션 세 전문가를 둔 3분기 트랜스포머 혼합(Tri-MoT)으로 영상 예측, 3D 모션 예측, 액션 생성을 함께 학습
  - 모션 표현 — 현재 이미지의 고정 격자에 고정한 궤적, 이미지 평면 변위와 초기 위치 대비 깊이 변화를 결합, B-스플라인으로 압축
  - 구조화된 어텐션 마스크 — 액션 전문가는 예측 궤적을 입력으로 쓰지 않음
  - 추론 때 Fast-WAM 경로를 유지해 현재 RGB를 한 번 처리하고 액션 청크를 디노이징, 미래 영상·모션 예측 불필요
  - 백본 Wan2.2-5B
- **차별점** — 사전학습 4D 추적 모델과 정렬하는 대신 궤적을 직접 예측하는 보조 목표
  - 모션 잠재를 액션 전문가에 주입하거나 영상-모션 양방향 어텐션을 두는 대안보다 보조 목표로만 쓰는 쪽이 높은 성공률
- **핵심 기여** — 보조 모션 감독의 성능과 설계 ablation
  - RoboCasa-GR1 few-shot 63.6%로 Fast-WAM 대비 18.8점, Joint-WAM 대비 8.8점 우위, 전체 데이터 80.3%
  - LIBERO 평균 98.7%(Fast-WAM 97.6%, Joint-WAM 98.5%), 학습 때 못 본 LIBERO-Plus 교란 7종 전체에서 Fast-WAM 상회, 평균 84.5%로 Fast-WAM 대비 18.3점, Joint-WAM 대비 5.8점 우위
  - LIBERO-Plus ablation — 모션 주입 81.6%, 영상-모션 양방향 어텐션 80.3%, 깊이 제거 82.4%, B-스플라인 제거 83.4%
  - Piper 실물 3개 과제(과제당 시연 50개, 20회 평가) 평균 85.0%로 Fast-WAM 63.3%를 상회
- **가치** — 영상 예측 학습에서 조작에 유효한 상호작용 동역학으로 표현을 이끄는 보조 목표 후보 제시

### (c) 시사점

- 3D 모션을 보조 목표로 두어도 추론 경로가 늘지 않는다는 점이 도입 비용 측면의 장점
- 보조 목표와 액션 조건화를 맞댄 ablation이 모션을 보조로만 두는 쪽을 지지
- 깊이 변화 성분의 이득이 분포 교란 구간에서 커서 3D 신호의 가치를 보여 줌
- 실물 Place and Close Drawer 55.0%에서 95.0%로 개선, 순차 조작 과제에서의 효과 시사
- 모션 주석 생성 파이프라인이 도입 시 부담

### (d) 먼저 확인할 점

- 코드 저장소나 공개 약속이 없어 재현은 프로젝트 페이지에 한정
- 실물 평가가 Piper 한 플랫폼, 과제당 20회
- 실물 비교 대상이 Fast-WAM 하나뿐
- 접촉 집약적 과제의 모션 표현 적합성은 검증하지 않음(촉각·힘 신호 없음)
- 점 궤적 주석 생성 비용과 추적 잡음의 영향은 추가 확인 필요
