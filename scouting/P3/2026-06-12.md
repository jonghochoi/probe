## 🥇 논문 1 — 우선순위 ★★★

**Blind Dexterous Grasping via Real2Sim2Real Tactile Policy Learning**
[arXiv:2606.11767](https://arxiv.org/abs/2606.11767) · Shengcheng Luo, Xiyan Huang, Zhe Xu, Wanlin Li · source: arXiv 키워드 스윕 (tactile + RL + contact)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D13](https://img.shields.io/badge/D13-d97706.svg)](#ref-D13) [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 다지 손의 촉각 전용 블라인드 파지: 촉각 Sim2Real 격차 + sparse 촉각 신호의 낮은 표현력으로 실물 배포 어려움
- **3-컴포넌트 파이프라인**:
  - **Real2Sim 촉각 교정 파이프라인** — 실물 촉각 측정값으로 접촉-교정(contact-calibrated) 디지털 트윈 구성; 시뮬레이터가 실물 촉각 신호를 재현하도록 역방향 교정
  - **레이아웃-인식 촉각 인코더(layout-aware tactile encoder)** — 센서 배치 기하 사전 지식을 자기지도(self-supervised) 사전학습으로 통합, sparse 촉각 신호 표현력 향상
  - **객체별 RL 전문가 → Diffusion Policy 집성** — 교정 시뮬레이터에서 객체별 RL 전문가 학습, 성공 궤적을 촉각 조건부 Diffusion Policy로 집성
- **실물 검증** — LEAP Hand(분산 촉각 감지), 10개 학습 객체 + 10개 미지 객체; 실물 파지 성공률 27%, 실물 파지 시연·시각 입력 없음
- **진정한 신규성** — DR로 시뮬레이터를 넓히는 기존 방향과 달리 실물 측정으로 시뮬레이터를 좁히는 Real2Sim 방향을 촉각 영역에 처음 적용; 레이아웃-인식 인코더 + Diffusion Policy 집성 조합이 촉각 전용 블라인드 파지에 첫 실물 성공 사례

### (c) 시사점

- **Real2Sim 촉각 교정 방향 실증** — 실물 촉각 측정 → 시뮬레이터 교정 역방향이 실물에서 작동; DR + 광범위 무작위화 없이도 촉각 Sim2Real 격차 해소 가능성
  - D18 경로에 "Real2Sim 촉각 교정"을 DR 기반 접근과 병렬 대안으로 추가 검토 가능
- **sparse 촉각 신호의 실용 인코딩 참조점 확보** — 4×4 택셀 수준 저해상도에서도 레이아웃-인식 인코더가 접촉 특징을 학습; D15 입력 표현 설계 시 직접 참조 가능
- **비전 완전 배제 RL 파이프라인 실물 검증** — 촉각 + 고유감각만으로 미지 객체 20종 실물 파지 달성; P3 비전 배제 원칙의 실현 가능성에 현재까지 가장 강력한 실물 근거
- **Diffusion Policy 집성 패턴의 응용 가능성** — 복수의 객체별 RL 전문가를 하나의 조건부 정책으로 집성하는 패턴을 System0의 다중 시나리오(슬립 억제·파지력 유지·자세 교정)에 응용 가능성

### (d) 먼저 확인할 점

- **파지 획득 vs. 파지 유지 간극** — 논문은 파지 획득(grasp acquisition)에 초점; System0 핵심 역할인 파지 후 슬립 억제·접촉 유지(post-grasp retention)와 직접 대응하는 실험 없음 → 동일 접근법이 파지 유지에도 작동하는지 별도 검증 필요
- **27% 성공률의 분해** — 학습 객체·미지 객체 분리 성공률 미보고; 미지 객체 일반화 수준 별도 확인 필요
- **Real2Sim 교정 비용** — 신규 로봇/센서 도입 시 실물 촉각 데이터 수집 후 교정 재수행 필요 → D18 DR 경로 대비 초기 비용 비교 필요
- **Diffusion Policy 추론 지연** — 실시간 고주파 접촉 안정화(예: ≥100 Hz) 요구 시 Diffusion Policy 추론 지연 문제 가능성; 실물 제어 주기 확인 필요

## 🌱 논문 2 — 인접 분야 픽

**TacForeSight: Force-Guided Tactile World Model for Contact-Rich Manipulation**
[arXiv:2606.11184](https://arxiv.org/abs/2606.11184) · Yujie Zang, Yuhang Zheng, Xian Nie, Yupeng Zheng · source: arXiv 키워드 스윕 (tactile + RL + contact) · adjacent field: 힘 조건부 촉각 세계 모델 (비주오택타일 포함으로 P3 비전 배제 기준 미충족; P5 인접)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **TacForeSight** — 고주파 손목 힘/토크(wrist F/T) 신호를 조건으로 단기 촉각 잠재 동역학을 예측하는 경량 촉각 세계 모델(TacForceWM) + 예측 잠재 벡터를 예비 접촉 사전 정보로 활용하는 정책(Predictive Tactile-Conditioned Policy)
  - 이중 손가락 촉각 관측 + 손목 F/T → 단기 촉각 잠재 예측 → 크로스-어텐션으로 현재→미래 촉각 진화 모델링
  - 촉각-유도 게이팅(tactile-guided gating)으로 비주오택타일 특징 적응 퓨전, 실시간 추론에 적합한 경량 구조
- **실물 실험** — 5개 대표 과제 + 3개 진행 중 외란 설정에서 기존 기준선 대비 일관된 성능 향상; 코드·데이터 공개 예정
- **범위 한계** — 비주오택타일(비전 포함) + IL 기반; RL 없음

### (c) 시사점

- **힘 조건부 촉각 예측의 실물 검증** — 손목 F/T 고주파 신호를 촉각 잠재 세계 모델 조건으로 활용해 예비 접촉 추론 실물 달성 → D15 입력 구성에서 손목 F/T를 촉각 예측 보조 신호로 활용하는 설계 방향의 크로스폴리네이션 신호
- **접촉 사전 정보(anticipatory contact prior) 개념** — 미래 촉각 동역학 예측으로 사전 교정 가능; System0의 슬립 발생 직전 선제 대응 확장 방향과 개념적 유사성

### (d) 먼저 확인할 점

- **비전 포함** — 비주오택타일 퓨전 구조; P3 비전 배제 원칙과 상충, 비전 없는 ablation 결과 없음
- **RL 없음** — 순수 IL 기반; System0 RL 안정화 루프와 직접 대응하지 않음
- **sim2real 검증 없음** — 시뮬레이터 학습→실물 이전 분석 부재
