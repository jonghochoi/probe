## 🥈 논문 1 — 우선순위 ★★

**WLA³: World Latent Action Modeling for Semantics, Dynamics, and Kinematics**
[arXiv:2609.15870](https://arxiv.org/abs/2609.15870) · Peidong Liu, Zhiyuan Xiang, Mingyang Li, Wenhao Li, Jiale Zhang, Jiahao Sun et al. · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- 이종 데이터로 정책 모델을 스케일링하는 데 통일된 저잡음 액션 지도 신호가 부족하다는 문제 지적, 관측된 world transition을 데이터 소스 전반의 공통 액션 지도 신호로 활용하는 접근 제시
- 동기화된 카메라 시점·가용 임베디먼트 상태 변화로부터 로컬 구간 세계 상태 변화를 압축 로컬 잠재 액션과 풍부한 전이 특징으로 인코딩하는 World Latent Action Model(WLAM) 제안
- 로컬 잠재 액션이 행동-민감 물리 동역학 모델링을 지원하고, 세그먼트 단위 특징이 VLM을 직접 지도하며, 액션 전문가가 잠재 액션과 임베디먼트별 로봇 제어를 함께 예측하는 세 축(의미·동역학·기구학) 재사용 구조 WLA³ 구축
- human video는 확장 가능한 전이 지도 신호를 제공하고 로봇 궤적은 공유 표현을 실행 가능한 제어에 접지 — human-to-robot 전이 지원
- LARYBench에서 32차원 잠재 액션 분류 정확도 67.89%, 여섯 개 실로봇 태스크에서 평균 성공률 81.9%(π0.5 대비 66.2%) 달성, 제너럴리스트 정책 중간학습 데이터 규모 확대에 따른 성능 개선도 확인
- 코드 공개 언급 없음, 프로젝트 페이지 공개

### (c) 시사점
- 에고센트릭 human video로부터 손-물체 상호작용 세계 상태 변화를 압축 잠재 액션으로 학습해 로봇 제어까지 접지하는 구조가, 아직 corpus 앵커가 없는 방향에 처음으로 구체적 참고점 제공
- 로컬 잠재 액션 하나를 물리 동역학·VLM 지도·로봇 제어 세 용도로 재사용하는 설계가, human video 확보 파이프라인의 활용도를 한 번의 학습으로 세 배 늘리는 저비용 경로로 참고 가능
- π0.5 대비 81.9% vs 66.2%라는 여섯 개 실로봇 태스크 정량 격차가, 손-물체 중심 world latent action 계열의 비교 기준점으로 활용 가치 높음

### (d) 먼저 확인할 점
- 여섯 개 실로봇 태스크가 다지 손 기반 정밀 조작을 포함하는지, 그리퍼 중심 태스크에 그치는지 확인 필요
- LARYBench 32차원 잠재 액션 분류의 구체 태스크 정의·평가 프로토콜이 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 로컬 잠재 액션 인코더(WLAM) 부분만 우선 이 기존 world model 파이프라인에 재현

## 🥈 논문 2 — 우선순위 ★★

**Modality-Autoregressive World-Action Models (ModAR)**
[arXiv:2609.17524](https://arxiv.org/abs/2609.17524) · Adam Hung, Bardienus P. Duisterhof, Deva Ramanan, Jeffrey Ichnowski · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 기존 world-action model이 대개 미래를 RGB 이미지로 예측하나, 깊이·사전학습 시각 특징·포인트 트랙 같은 다른 시각 모달리티가 기하·의미·모션 정보를 더 효율적으로 포착할 수 있다는 문제 제기
- 여러 미래 모달리티를 액션 예측 이전에 순차적으로 자기회귀 디노이징하는 최초의 WAM ModAR 제안 — 각 예측이 이전에 생성된 모달리티에 조건화
- 처음부터 학습해 학습 데이터 구성·예측 모달리티·WAM formulation이 성능에 미치는 영향을 체계적으로 연구 — 포인트 트랙·DINO 특징·깊이 맵 예측은 이득을 주나 RGB 추가 예측은 일관된 이득을 주지 않음을 확인
- ModAR의 순차 생성이 기존 WAM formulation 대비 우위, 모든 평가 데이터 규모에서 최고 평균 성공률 달성
- 비디오 모델로 초기화된 WAM Flex-π를 동일 데이터로 파인튜닝한 대조군 대비, 사전학습 없이 약 20배 적은 학습 FLOPs로 근소하게 더 높은 평균 성공률(75% vs 72%) 달성
- 세 개 실환경 양팔 태스크에서 baseline 대비 우위, human video로 추가 개선 확인
- 코드 공개 언급 없음, 프로젝트 페이지 공개

### (c) 시사점
- 미래 모달리티로 무엇을 예측할지(RGB·깊이·포인트 트랙·사전학습 특징)를 통제 실험으로 직접 비교한 결과가, 압축 잠재·3D-flow 예측 공간 선택에 실증적 근거 제공
- RGB 예측이 일관된 이득을 주지 않는다는 반직관적 관찰이, 예측 공간을 압축된 정보-밀집 표현으로 좁히는 방향의 근거로 참고 가능
- 20배 적은 학습 FLOPs로 비디오 사전학습 기반 WAM과 대등한 성능을 낸다는 결과가, 예측 백본 투자 우선순위 판단에 참고 가치

### (d) 먼저 확인할 점
- 세 개 실환경 양팔 태스크의 물체 종류·다지 손 사용 여부가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 자기회귀 모달리티 순서(어떤 모달리티를 먼저 디노이징하는지)가 성능에 미치는 영향의 구체 수치 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 포인트 트랙·DINO 특징 예측 헤드만 우선 이 기존 RGB 중심 WAM 파이프라인에 추가

## 🥈 논문 3 — 우선순위 ★★

**Memory as Plans: World-Action Modeling with Memory-Grounded Planning (MaP-WAM)**
[arXiv:2609.11561](https://arxiv.org/abs/2609.11561) · Sizhe Zhao, Haozhe Xie, Weiyu Zhao, Chenchu Zhang, Huan Wang, Chenyang Wang et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 실제 매니퓰레이션 태스크 다수가 비-마르코프적이라 현재 관측을 넘어서는 장기 메모리가 필요하나, 기존 메모리 메커니즘(언어 요약·확장 시각 윈도우)은 세밀한 시각 증거 손실이나 이력 커버리지-실행 효율 트레이드오프에 부딪힌다는 문제 지적
- 메모리 의존 world-action modeling을 메모리-그라운드 계획과 계획-조건부 실행으로 분해하는 MaP-WAM 제안 — 장기 멀티모달 에피소드 맥락을 계획 시점 증거로만 사용, 실행기에 전체 이력을 반복 조건화하지 않음
- 메모리를 언어 지시·희소 시각 맥락을 담은 완결 세그먼트 기록으로 표현, 이를 다음 세그먼트 언어 계획·시각 가이던스로 압축하는 World-Action-Progress(WAP) 모델이 각 계획을 알 수 없는 지속 시간 동안 실행하며 액션 청크와 실행 진행도를 함께 예측
- 계획-관측 정렬로 예측 진행도를 보정해 적응적 세그먼트 전환·폐루프 맥락 갱신 수행, 실행기 맥락 길이를 고정해 계획·실행 양쪽에 key-value 캐싱 가능
- RMBench에서 83.3% 성공률로 SOTA, 실로봇 태스크에서 78.0% 성공률 달성, 태스크 이력이 늘어나도 실행기 추론 지연이 거의 일정하게 유지됨을 확인
- 코드 공개 언급 없음, 프로젝트 페이지 공개

### (c) 시사점
- 실행기에 전체 이력을 반복 조건화하지 않고 계획 시점에만 장기 맥락을 압축해 사용하는 설계가, 장기 호라이즌 다지 조작에서 실행 효율을 유지하며 메모리를 결합하는 구체적 경로로 참고 가능
- 액션 청크와 실행 진행도를 함께 예측하는 구조가, 최근 반복 관찰되는 "진행도-조건부 예측 활용"(FARM·ProWAM) 패턴의 또 다른 구체적 사례로 축적
- 태스크 이력 증가에도 거의 일정한 추론 지연이 유지된다는 결과가, 장기 호라이즌 메모리 결합의 배포 비용 상한을 가늠하는 참고 기준점

### (d) 먼저 확인할 점
- RMBench·실로봇 태스크가 다지 손 기반 정밀 조작을 포함하는지, 그리퍼 중심 태스크에 그치는지 확인 필요
- 세그먼트 경계를 결정하는 구체 임계값·실패 시 재계획 절차가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 진행도-조건부 계획 압축 모듈만 우선 이 기존 world-action model 파이프라인에 추가

## 🥈 논문 4 — 우선순위 ★★

**XPACE: Joint World and Action Modeling from Heterogeneous Experience**
[arXiv:2609.17372](https://arxiv.org/abs/2609.17372) · Jiacheng Wei, Jerry Bai, Xiaoyu Yue, Zidong Wang, Xiaoyang Guo, Cheng Chen et al. · arXiv preprint · source: citation-graph(Being-H0.7·Ctrl-World 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 핵심 기여
- 범용 로봇이 이종 경험을 활용해 액션을 선택하고 그 액션이 세계를 어떻게 바꿀지 예견해야 한다는 문제의식에서, world action model(실행 가능 액션·미래 비디오 동시 예측)과 world simulator(지정 액션의 시각적 결과 예측) 역할을 겸하는 통합 embodied world model XPACE 제안
- 정책과 시뮬레이터가 비디오 백본을 공유 — 액션-비표기 비디오로 시각 동역학을, 액션-표기 human·로봇 시연으로 비디오·액션 예측을 공동 학습
- 로봇 제어를 점진적으로 강조하면서도 human 경험을 유지하는 coarse-to-fine 학습 커리큘럼으로, 로봇 시연 범위를 넘어서는 행동까지 정책이 학습하도록 지원
- 시뮬레이터를 자신이 생성한 맥락에 적응시켜 전문가 시연 주변의 편차-회복 궤적을 합성하고, 필터링된 회복 예시로 정책을 파인튜닝 — 시뮬레이터 스스로가 회복 지도 신호를 추가 생성
- XPENG의 IRON 휴머노이드 실로봇 실험에서 이종 학습이 강건성을 개선하고 로봇 시연에 없는 태스크로 human 관찰 스킬 전이를 가능케 함을 확인, 자체 시뮬레이터가 생성한 회복 데이터가 실환경 태스크 완수를 추가 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- world-action model과 world simulator 역할을 하나의 공유 비디오 백본으로 겸하는 구조가, 보조-헤드 통합 아키텍처 선택지에 데이터 증강용 롤아웃 합성을 자연스럽게 결합하는 구체적 청사진 제공
- 시뮬레이터가 스스로 생성한 맥락에 적응해 회복 궤적을 합성하는 폐루프가, 기존 rollout synthesis 관찰(AnyWorld, 2026-09-03) 대비 "자기생성 회복 데이터 루프"라는 한 단계 더 나아간 구체적 변형으로 참고 가치
- human 경험을 유지하며 로봇 제어를 점진 강조하는 커리큘럼이, 에고센트릭 human video와 로봇 시연을 함께 쓰는 학습 스케줄 설계에 참고 가능

### (d) 먼저 확인할 점
- 이종 학습·회복 데이터 개선 효과의 구체 정량 성공률 수치가 abstract 수준에서는 정성적 서술("improves robustness")에 그쳐 본문 확인 필요
- IRON 휴머노이드가 다지 손을 탑재하는지, 그리퍼 엔드이펙터인지 확인 필요
