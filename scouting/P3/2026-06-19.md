## 🥇 논문 1 — 우선순위 ★★★

**TactSpace: Learning a Physics-enriched Shared Latent Space for Tactile Sim-to-Real Transfer**
[arXiv:2606.18959](https://arxiv.org/abs/2606.18959) · Arunim Joarder, Arjun Bhardwaj, René Zurbrügg, Mayank Mittal, Florin Püntener · source: arXiv 키워드 스윕

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 현행 시뮬레이터는 촉각 센서 변형·변환 역학을 정확히 재현 불가 → 촉각 Sim2Real 이전 막혀 있음; 기존 해결책(도메인 랜덤화 또는 Real2Sim 교정)은 원시 신호 정확도에 의존하는 공통 한계 보유
- **TactSpace 핵심 접근** — 이질적 촉각 모달리티(시뮬레이션 침투 깊이 vs. 실물 정전용량 신호)를 공유 잠재 공간(shared latent space)에 정렬하는 다중 모달 표현 학습 프레임워크 제안
  - 모달리티별 인코더로 다양한 촉각 관측을 단일 공통 임베딩 공간으로 투영
  - 자기·교차 재구성(self/cross-reconstruction) 목표 + 대조 정렬(contrastive alignment)로 모달리티-불변 표현 학습
  - 원시 신호 정밀 시뮬레이션 요구 없이 접촉 관련 정보 보존
- **검증 결과** — 시뮬레이션 단독 학습 → 실물 센서 측정값 직접 테스트(제로샷 Sim2Real): 힘 예측 오차 16.7% 감소, 형상 재구성 오차 45.8% 감소; 다중 물리 시뮬레이션 모달리티 통합 시 다운스트림 과제 전반에서 임베딩 품질 향상
- **부가 기여** — Isaac Lab용 Warp 기반 효율적 촉각 시뮬레이션 모델 구현 공개; 스케일 가능한 촉각 데이터 생성 기반 제공
- **진정한 신규성** — DR 또는 Real2Sim 없이 잠재 공간 정렬만으로 제로샷 촉각 Sim2Real을 달성한 최초 멀티모달 정렬 프레임워크; 두 선행 방향과 직교하는 신규 경로

### (c) 시사점

- **촉각 Sim2Real 새 경로 확보** — DR 범위 추정·실물 촉각 교정 없이 잠재 공간 정렬만으로 제로샷 이전 달성; System0 촉각 입력 표현 설계 시 DR-only 파이프라인의 독립 대안으로 공유 잠재 인코더 방향 검토 가능
- **이질 센서·시뮬레이션 동시 통합** — 시뮬레이션(침투 깊이)과 실물(정전용량) 같은 물리적으로 상이한 신호를 같은 잠재 공간에 수용; 하드웨어 교체 시 인코더 재학습만으로 대응 가능성
- **Isaac Lab 구현 즉시 활용 가능** — Warp 기반 촉각 시뮬레이터 공개 → System0 RL 학습 환경에 촉각 데이터 생성 파이프라인으로 바로 편입 가능

### (d) 먼저 확인할 점

- **RL 정책 통합 미검증** — 형상 식별·힘 예측·기하 재구성 등 지각 과제만 검증; 공유 잠재 표현을 RL 상태 입력으로 연결한 접촉 안정화 실험 미제시 → System0 통합 전 별도 검증 필요
- **슬립·전단력 감지 특화 평가 부재** — 침투 깊이·힘 크기 중심 과제; 고주파 슬립 발생 직전 국소 전단력 이동을 공유 잠재 표현이 충분히 포착하는지 별도 확인 필요
- **센서 다양성 한정** — 정전용량 기반 1종으로 실물 검증; 택셀 배열형·저해상도 센서, 다지 손 끝 배치 조건으로의 동일 제로샷 이전 성립 여부 선확인 필요

## 🥈 논문 2 — 우선순위 ★★

**TopoRetarget: Interaction-Preserving Retargeting for Dexterous Manipulation**
[arXiv:2606.16272](https://arxiv.org/abs/2606.16272) · Jielin Wu, Shenzhe Yao, Guanqi He, Xiaohan Liu, Zhaoqing Zeng · source: Citation-Graph (HORA) + arXiv 키워드 스윕

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 인간 손 시연을 다지 로봇 손 RL 정책 학습에 활용하려면 리타기팅이 필요하나, 기존 방법은 손 자세·물체 접촉 구조를 동시에 보존하지 못해 RL 다운스트림 성능 저하 및 접촉 아티팩트 발생
- **TopoRetarget 핵심 접근** — 접촉 구조를 위상적으로 보존하는 리타기팅 프레임워크
  - 손·물체 키포인트 위에 희소 상호작용 그래프(sparse interaction graph) 구성
  - 거리 가중 라플라시안 변형(distance-weighted Laplacian deformation) + 방향 일관성 + 운동학 제약 + 침투 처리로 최적화
  - 단일 파라미터 세트로 다양한 리타기팅 조건 대응
- **검증 결과** — ContactPose 데이터셋 전 기준선 대비 최고 접촉 정밀도·정렬; Pen-Spin 훈련 성공률 기존 기준선 대비 +40.6pp; Wuji Hand 하드웨어에서 정육면체 재배향·펜 돌리기 제로샷 이전 달성
- **진정한 신규성** — 인간-물체 상호작용의 접촉 위상을 보존하면서 로봇 다지 손으로 리타기팅하는 첫 단일 통합 프레임워크; 기존 방법 대비 Pen-Spin +40.6pp

### (c) 시사점

- **접촉 구조 보존 참조 모션 → RL 학습 효율 향상 근거** — 인간 시연의 접촉 위상이 RL 참조 모션에 충실히 전달될 때 접촉 집약 정책 수렴이 빨라짐; System0 RL 초기화에 인간 시연을 활용할 경우 동일 위상 보존 리타기팅 방법론 적용 가능성
- **단일 파라미터 다조건 대응** — 다양한 하드웨어·과제 조건에 재학습 없이 대응; 새 다지 손 도입 시 System0 RL 훈련용 참조 모션 생성 비용 추정 기준점

### (d) 먼저 확인할 점

- **슬립 억제·파지 유지 특화 미검증** — Pen-Spin·정육면체 재배향 과제 중심; 파지 후 슬립 억제·접촉 유지 특화 시나리오와의 직접 대응 없음 → 전이 가능성 별도 확인 필요
- **리타기팅 기여분 분리 미검증** — 리타기팅 품질이 RL 성능에 기여하는 비율의 독립 ablation 미제시; 단순 리타기팅 개선이 System0 수준 접촉 안정화에 미치는 독립 효과 확인 필요
- **코드 공개 여부 미확인** — 논문 내 공개 링크 미확인; 재현 비용 선확인 권고
