**Amortising Trajectory Optimisation for Residual MPC via Implicit Contact Differentiation (8/15)**
- Relevance 1 — 접촉-풍부 궤적최적화·잔차 MPC 구조, RL이 아닌 미분가능 시뮬레이션 기반 암시적 미분(IFT), [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) 인접(잔차 정책 구조 개념은 유사하나 RL 정책 학습 아님)
- Novelty 3 — 정칙화된 접촉의 stationarity residual을 Implicit Function Theorem으로 미분해 solver unrolling·수작업 KKT 유도 없이 일정 메모리 유지(256 접촉에서 20배 절감)
- Reproducibility 1 — MuJoCo MJX 기반 구현 명시, 코드 공개 언급 없음
- Methodology 3 — Finger·Franka·Unitree 3개 플랫폼 정량 비교, 반복횟수별 메모리 성장률 실측 제시

**TacWAM: Anchor-Guided World Action Model with Mechanics-Aware Tactile Prediction (7/15)**
