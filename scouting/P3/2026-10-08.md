## 🥇 논문 1

**Unified Visual-Tactile-Action Modeling from Human Demonstrations for Dexterous Manipulation**
[arXiv:2609.34182](https://arxiv.org/abs/2609.34182) · Wenqiao Li 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R3 · N2 · M2 · Real3 · Repro1 — 초록 "Project page is available at https://uni-vta.github.io/"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 인간 촉각 시연으로 다지 손 정책을 키우는 통합 모델
- **문제** — 다지 손 로봇의 촉각 시연은 규모를 키우기 어려움
  - 다지 손 원격조종은 조작자에게 촉각 피드백을 거의 주지 못함
  - 시각·촉각·액션이 동기화된 궤적 수집 비용이 커서 객체·환경·접촉 패턴 다양성이 제한
- **기존 한계** — 인간 데이터를 쓰는 기존 경로가 접촉 동역학을 담지 못함
  - 대규모 인간 영상은 시각 표현 학습과 장기 제어에 쓰이는 수준
  - 모션 복원·리타깃팅·인간-로봇 공동학습은 손 형태·기구학·센서 배치·액션 공간 차이로 직접 대응이 불안정
  - 영상만으로는 성패를 가르는 국소 접촉 동역학이 드러나지 않음
- **핵심 방법** — 인간·로봇 궤적을 정렬된 촉각·액션 표현으로 사상하고 미래 액션과 촉각 궤적을 공동 예측
  - 착용형 촉각 모션 캡처 시스템 — 손목 중심 영상, 지단 촉각, 손 모션을 동기 기록
  - 인간 시연은 접촉 인지 표현 학습만 지도하고 배치 시에는 로봇 액션만 실행
- **차별점** — 손 형태가 다른 두 주체 사이의 모션 대응 대신 상호작용 물리를 전이 매개로 사용
  - 접촉 형성·변형·미끄러짐·해제는 주체가 달라도 공유 구조를 가진다는 전제
- **핵심 기여** — 수집 장비, 데이터셋, 모델과 실물 검증
  - 로봇 원격조종 없이 영상·촉각·손 모션을 기록하는 촉각 모션 캡처 시스템
  - UVTA 데이터셋 — 접촉 집약 5개 과제, 과제당 인간 시연 1,000개와 로봇 시연 150개
  - 실물 5개 과제 평균 성공률 70%, 최강 시각-촉각 기준선 29%, 아키텍처 ablation 42%
  - 인간 시연이 늘수록 성능이 계속 오르며 과제당 1,000개에서도 포화 없음
- **가치** — 로봇 원격조종 없이 모은 인간 촉각 데이터를 다지 손 정책의 확장 자원으로 쓰는 경로 제시

### (c) 시사점

- 인간 촉각 시연 전이의 실물 정량 근거 확보
  - 미래 촉각 예측을 액션과 함께 쓰는 보조 목표가 인간-로봇 공통 신호로 작동한다는 사례
  - 에고센트릭 인간 데이터에서 접촉 예측을 얻는 방향과 맞닿는 첫 실물 수치
- 도입 비용 중간 — 촉각 장갑형 수집 장비와 촉각 센서 전제 필요

### (d) 먼저 확인할 점

- 코드·데이터 미공개, 프로젝트 페이지만 존재
- 비교 기준선이 같은 인간 데이터를 쓰는지 본문 확인 필요
- 인간 장비와 로봇 손의 촉각 센서 배치 차이를 맞추는 교정 절차에 대한 의존
- 5개 과제 모두 접촉 집약 과제라 비촉각 과제로의 일반화 근거 없음

## 🥈 논문 2

**HiTac-WAM: A Hierarchical Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2608.19574](https://arxiv.org/abs/2608.19574) · Chao Xue 외 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 후보 액션별 계층 촉각 예측으로 선택과 재계획
- **문제** — 시각 롤아웃이 비슷해도 후보 액션의 접촉 결과는 서로 다름
  - 같은 시각 이력·상태·지시에서 독립 노이즈로 뽑은 후보들이 정렬된 그리퍼 같은 그럴듯한 롤아웃을 내도 접촉 누락·압력 부족·미끄러짐·측방 끼임으로 갈림
  - 엔드이펙터-환경 경계의 접촉은 가림 때문에 간접 관측만 가능
  - 실행 전에 후보마다 촉각 결과를 예측하는 일이 핵심 과제
- **기존 한계** — 촉각 정책과 예측 모델이 각각 시점이나 구조에서 부족
  - 측정 촉각 조건 정책과 저속-고속 컨트롤러는 접촉이 일어난 뒤에야 반응
  - 목표 촉각 이미지 비교 선택과 슬립 예측은 개별 시스템으로 존재
  - 최근 시각-촉각 액션 모델은 미래 촉각 이미지·잠재를 정책 특징과 함께 학습하는 수준
  - 접촉 상태·계면 변형·슬립 위험을 한 스트림에 얽거나 독립 목표로 다뤄 방향성 의존을 반영하지 않음
  - 예측·후보 평가·온라인 보정이 하나의 메커니즘으로 묶이지 않음
- **핵심 방법** — 후보 액션 청크마다 촉각 미래를 예측하고 순위와 실행 중 검증에 사용
  - 계층 예측 — 접촉 상태, 접촉 조건부 3D 변형장, 슬립 위험 순서로 하위 단계가 상위 단계의 stop-gradient 신호를 조건으로 받음
  - 방향성 어텐션 마스크 — 촉각 질의는 후보의 비디오-액션 문맥을 보고 비디오·액션 질의는 촉각 토큰을 보지 못함
  - 후보 선택 — 촉각 예측과 예측 비주얼 롤아웃 기반 과제 진행 추정으로 순위화
  - 온라인 검증 — 선택된 촉각 예측을 기준으로 유지하고 지속적 불일치 시 교정 재계획
- **차별점** — 촉각 예측을 인과 의존 순서로 분해하고 후보 액션과 짝지은 채 순위와 검증까지 한 메커니즘으로 구성
- **핵심 기여** — 계층 예측, 예측 기반 선택, 온라인 검증
  - 평균 접촉 F1 0.921, 동일 학습 예산에서 변형 단독 예측기 대비 3D 변위 L2 오차 17.6% 감소, 슬립 단독 예측기 대비 AUPRC 60.4% 향상
  - 실물 칩 잡기·칠판 지우기·USB 삽입 평균 성공률 — 단일 후보 실행 31.1%, 계층 예측 기반 선택 61.1%
  - 고정 생성 예산에서 과제 진행 추정만으로 순위화한 경우 35.6%
  - 온라인 검증까지 포함한 전체 시스템 72.2%
- **가치** — 미래 촉각 예측을 학습 신호에 그치지 않고 실행 전 선택과 실행 중 감시의 기준으로 쓰는 설계 제시

### (c) 시사점

- 예측 접촉을 추론 시점 선택에 쓴 실물 정량 근거
  - 접촉 변형 예측을 비디오·액션과 한 모델에서 함께 뽑는 계열에 계층 분해와 방향성 마스크를 더한 변형
  - 학습 보조에 머물지 않고 후보 랭킹과 재계획으로 이어지는 사용처 확인
- 도입 비용 높음 — 다수 후보 생성에 따른 추론 비용과 촉각 센서 전제

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 실물 3개 과제 결과의 시행 횟수와 분산 본문 확인 필요
- 31.1%→61.1% 비교가 단일 후보 대비라 후보 수 증가만의 효과와 촉각 예측 효과 분리 필요
- 3D 변형장과 슬립 라벨을 얻는 촉각 센서 하드웨어 전제

## 🥉 논문 3

**PointWAM: 3D World Action Modeling for Dexterous Robotic Manipulation**
[arXiv:2610.02840](https://arxiv.org/abs/2610.02840) · Chunghyun Park 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N3 · M2 · Real1 · Repro1 — arXiv comment "Preprint. Project page: https://chrockey.github.io/PointWAM"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 장면과 손을 3D 점 궤적으로 함께 예측하는 WAM
- **문제** — 다지 조작에 필요한 3D 구조와 접촉 기하를 기존 월드 표현이 못 담음
  - 다지 손은 여러 손가락이 물체 표면에 맞춰 3D 움직임을 협응해야 함
  - VLA는 장면이 어떻게 변할지를 명시적으로 예측하지 않음
- **기존 한계** — 월드 표현과 액션 예측 방식이 각각 3D 인과 구조를 놓침
  - RGB 프레임과 잠재 표현 기반 WAM은 3D 공간 구조와 행위자-환경 인과 관계를 포착하기 어려움
  - 점 기반 정책은 3D 액션 궤적은 예측하나 환경의 진화를 모델링하지 않고, 과제 관련 객체를 사람이나 외부 인지 모델이 골라야 함
  - 액션 조건 3D 월드 모델은 조밀한 장면 궤적을 예측하나 액션을 입력으로만 취급
- **핵심 방법** — 장면과 손을 공유 시공간 좌표계의 3D 점 궤적으로 분해해 함께 예측하고 로봇 액션으로 변환
  - 입력 — 컬러 포인트 클라우드와 언어 지시
  - 관측된 모든 장면 점과 손 키포인트의 궤적을 예측
  - 액션 리타게터가 예측된 손 궤적을 로봇 액션으로 변환
- **차별점** — 손과 장면을 분리한 점 표현으로 과제별 객체·키포인트 선택 없이 인간 영상 사전학습 가능
  - 손 궤적이 장면과 분리돼 있어 로봇 손으로의 리타게팅에 유리
- **핵심 기여** — 3D 월드 모델링 효과와 인간 영상 사전학습 효과의 정량화
  - 장면 궤적 지도로 DexJoCo 평균 성공률 손 단독 예측 대비 10.9%p 상승, 3D 인코더는 리프팅한 이미지 특징 대비 5.4%p 우위
  - EgoDex·VITRA 인간 시연 영상 사전학습으로 DexJoCo 평균 성공률 처음부터 학습 대비 56.9%p 상승
  - DexJoCo 10개 과제에서 기존 최고 다중 과제 성공률 대비 11.7%p 우위
  - 실물 로봇에서 로봇 사전학습 VLA 대비 최대 25%p 우위
- **가치** — 손과 장면의 3D 공동 진화를 인간 영상에서 배워 다지 조작 정책에 연결하는 월드 액션 모델 경로 제시

### (c) 시사점

- 3D 점 궤적 예측과 인간 영상 사전학습을 묶은 새 표현
  - 에고센트릭 인간 영상에서 손-물체 상호작용 예측을 얻는 계열의 3D 변형
  - 액션을 예측 대상으로 포함하는 3D 월드 모델이라 per-frame 액션 입력 방식과 구분됨
- 도입 비용 중간 — 포인트 클라우드 입력과 액션 리타게터 구성 필요

### (d) 먼저 확인할 점

- 코드 미공개, 프로젝트 페이지만 존재
- 실물 결과는 초록에 수치가 없어 실물 과제 수·시행 횟수 본문 확인 필요
- 주요 수치가 시뮬레이션 DexJoCo 기준이라 실물 전이 폭 별도 검증 필요
- 포인트 클라우드 품질과 인간 영상 손 복원 오차에 대한 민감도 확인 필요
