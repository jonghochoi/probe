## 🥇 논문 1 — 우선순위 ★★

**LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion**
[arXiv:2609.28431](https://arxiv.org/abs/2609.28431) · Ning Chen, Yan-Kai Fu, Jun-Kai Zhao, Qian-Pu Sun, Guo-Cai Yao, Peng-Wei Wang, Zhong-Yuan Wang, Shang-Hang Zhang · arXiv preprint · source: citation-graph(Being-H0.7 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- VLA는 물리 동역학에 대한 세밀한 이해가 부족하고 반복 생성 기반 예측 모델은 추론 지연이 커, 양손 다지 조작에 필요한 장기 예측과 실시간 반응이 서로 충돌하는 문제 지적
- 느린 시스템(희소한 장기 시공간 의도 생성)과 빠른 시스템(조밀한 고빈도 모션 정제)을 비동기로 분리하는 계층적 생성 프레임워크 LiMA 제안
- 희소 의도 예측과 조밀 액션 궤적을 정합시키기 위해 엔트로피 정규화 확률적 수송 과정으로 정제 단계를 공식화하는 Latent Schrödinger Bridge Coupling 메커니즘 도입
- 비동기 분리로 기존 WAM 계열 대비 추론 지연 45.8% 감소, 양손 다지 조작 6개 과제에서 종합 성공률 70.8%·평균 서브태스크 성공률 78.9% 달성, 미확인 시나리오에서도 성능 유지 보고

### (c) 시사점
- 장기 예측(상상)과 실시간 실행을 분리하면서 둘 사이 정합을 유지하는 구조 설계 사례로, 통합 아키텍처 선택 논의의 참고점 확보
- Cosmos-Policy 계열 기존 WAM 대비 정량 지연 개선 수치를 함께 보고해, 지연-성능 트레이드오프 판단에 바로 쓸 수 있는 근거 확보
- 실로봇 양손 다지 조작 플랫폼에서 직접 검증돼, 사내 파이프라인의 실로봇 전이 검토 시 비교 대상으로 채택 가능

### (d) 먼저 확인할 점
- 코드 저장소 미공개, 프로젝트 페이지만 존재 — 재현에는 저자 공개 대기 필요
- 미확인 시나리오 성능 유지를 주장하나 일반화 범위(과제 수·물체 종류)의 구체 한계는 초록상 불명확
- 6개 과제의 난이도·물체 다양성이 사내 목표 태스크와 어느 정도 겹치는지 본문 확인 필요
