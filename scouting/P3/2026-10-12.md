## 🥇 논문 1

**Juno: Taming Predictive Latents for Vision-Language-Action Models**
[arXiv:2610.09940](https://arxiv.org/abs/2610.09940) · Yuchen Zhu 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R3 · N3 · M2 · Real2 · Repro1 — arXiv comment "Project Page: https://juno-policy.github.io/"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 행동 조건 JEPA 하나로 사전학습·정책학습·배포를 잇는 VLA
- **문제** — 예측 잠재를 VLA 수명주기 전 단계에서 쓸모 있게 만드는 일
  - 사전학습 — 인터넷 영상 표현은 시각적으로 강하나 구현체별 제어 가능 모션과 맞지 않음
  - 정책학습 — 예측 목표가 공유 비전-언어 경로에 붙어 예측 그래디언트가 제어와 간섭하고, 미래 정렬 상태가 액션으로 디코딩된다는 보장 없음
  - 배포 — 심한 분포 이동에서는 교사 자체가 오보정되고, 배포 데이터의 다수인 실패 롤아웃은 정책 목표로 쓸 수 없음
- **기존 한계** — 단계마다 기존 접근이 하나씩 빠뜨린 부분이 있음
  - 잠재 월드 모델·미래 표현 정렬·예견 토큰·잠재 서브골 계열은 예측이 도움 된다는 점은 보였으나 전 단계에 걸친 활용법은 다루지 않음
  - 예측 목표를 공유 비전-언어 경로에 접목하는 방식은 간섭 문제를 안음
  - 배포 적응 방식은 신뢰할 수 있는 동결 교사를 전제
- **핵심 방법** — 행동 조건 JEPA 하나를 표현 백본·예측 교사·적응형 동역학 모델의 세 역할로 사용
  - 제어 정렬 사전학습 — 정책 학습과 같은 구현체 궤적으로 픽셀에서 학습하고, 동적 CLS 손실로 모션 가중 패치 동역학을 압축 전역 토큰에 전달
  - 분리형 예측 추론 — 현재 프레임 JEPA 패치를 VLA 시각 토큰에 융합하고, 별도 변환 파라미터를 가진 추론 쿼리 분기를 동결 교사의 미래 잠재 상태에 증류
  - 추론 분기의 은닉 상태가 플로우 매칭 액션 디코더를 조건화하며 미래 관측은 학습 시에만 사용
  - 동역학 우선 테스트 시점 적응 — 실패 롤아웃을 포함한 모든 전이로 월드 모델을 적응하고 교사를 동결한 뒤, 검증된 실행에서만 LoRA 어댑터와 액션 헤드로 정책을 재정렬
- **차별점** — 실패한 행동은 나쁜 정책 목표이나 그 결과는 여전히 유효한 동역학 지도라는 비대칭 활용
  - 보상·전문가 교정 없이 월드 모델을 먼저 적응하고 그다음에 정책을 보수적으로 재정렬
- **핵심 기여** — 세 단계별 제안과 시뮬레이션·실물 결과
  - 동적 CLS 손실, 그리고 교사를 구현체·제어 분포에 맞추는 일이 사전학습 규모만큼 중요할 수 있다는 관찰
  - SimplerEnv 평균 성공률 60.9%에서 68.5%로 상승(최강 기준선 Qwen3GR00T 대비), 테스트 시점 적응 후 72.7%
  - 실물 로봇에서 배경·높이·물체 이동 조건 성공률 70–75% 유지, 기본 정책은 0%로 붕괴
- **가치** — 예측 잠재를 사전학습부터 배포 적응까지 한 모델로 일관되게 쓰는 설계 제시

### (c) 시사점

- 학습 시 보조 예측을 배포 시점 월드 모델 적응까지 확장
  - 백본 구조를 바꾸지 않고 분리 분기로 예측을 붙이는 방식이라 액션 전문가 보존과 양립
  - 실패 롤아웃을 동역학 지도로 되살리는 경로 확보
- 도입 비용 중간 — 구현체 일치 궤적으로 JEPA 사전학습, 배포 중 월드 모델 재학습 필요

### (d) 먼저 확인할 점

- 코드는 공개 예정이며 프로젝트 페이지만 존재
- 실물 결과가 초록에는 비율 구간만 있어 과제 수·시행 횟수 본문 확인 필요
- 주 수치 60.9%에서 72.7%는 SimplerEnv 시뮬레이션 기준
- 테스트 시점 적응의 배포 중 연산량과 안전성(오적응 시 복구) 별도 검증 필요

## 🥈 논문 2

**LeWAM: A JEPA World Action Model with Diffusion-Steering-Based MPC**
[arXiv:2610.12407](https://arxiv.org/abs/2610.12407) · Shashank Hegde 외 · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 8/15** · R3 · N3 · M2 · Real0 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 디코더 없는 JEPA 잠재 WAM과 정책 노이즈 공간 계획
- **문제** — 재구성 기반 표현이 과제와 무관한 시각 세부까지 잠재에 담아 후속 예측을 방해
  - 시각적으로 복잡한 환경에서는 모델 용량이 잡음성·중복 정보에 소모
- **기존 한계** — 재구성형 WAM과 분리형 JEPA 모델이 각각 한쪽을 놓침
  - 기존 WAM은 픽셀 수준 재구성으로 표현을 빚어 디코더가 그릴 수 있는 모든 세부를 잠재에 강제
  - 디코더 없는 JEPA 계열은 정책과 동역학 모델을 분리하고 WAM의 통합 다중 모달 구조가 없음
  - 원 행동 공간에서 샘플링 MPC를 돌리면 학습된 동역학의 부정확성을 계획기가 악용해 환각된 미래에 최적화
- **핵심 방법** — 양방향 트랜스포머 하나로 정방향·역방향·역동역학·정책 예측을 디코더 없는 JEPA 잠재에서 종단 학습
  - 인코더는 정칙화로 붕괴를 막으며 픽셀에서 바로 학습하고, 예측기는 행동으로 조건화
  - 계획 시 결정 변수를 행동 공간에서 플로우 매칭 정책 헤드의 결정론적 노이즈 공간으로 이동
  - 제안을 샘플러의 전형 집합에 투영해 정책 헤드가 학습한 행동 범위 안에서만 탐색
- **차별점** — 픽셀 디코더·토크나이저·픽셀 손실 없이 동역학 예측과 행동 생성의 이중 목표만으로 표현을 형성
- **핵심 기여** — 정렬·행동·계획 세 축의 결과
  - 선형 프로브가 일반 정방향 전용 JEPA 월드 모델보다 로봇·물체 상태를 잘 읽고, 시각 방해물은 무시하며 재구성 기반 WAM보다 크게 우수
  - 같은 인코더 위 일반 플로우 매칭 정책과 같은 크기에서 닫힌 루프 성능이 맞고 월드 모델까지 제공
  - 정책 노이즈 공간 계획이 원 행동 샘플링 MPC보다 닫힌 루프 성능을 개선
  - 시각 방해물을 덧붙인 사람 시연 데이터셋에서 평가
- **가치** — 재구성 없는 잠재 월드 모델과 정책을 한 모델로 묶고, 계획 오류를 정책 분포로 억제하는 방법 제시

### (c) 시사점

- 재구성 없는 JEPA 잠재 위에 정책과 월드 모델을 함께 학습하는 사례
  - 예측 공간을 잠재로 두는 선택에 방해물 무시 정렬 근거 추가
  - 추론 시 월드 모델 활용을 노이즈 공간 계획으로 연결하는 접점
- 도입 비용 중간 — 인코더 종단 학습과 정칙화 튜닝 전제

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 실물 로봇 결과 없음, 시뮬레이션과 선형 프로브만
- 닫힌 루프 이득의 크기와 과제 수는 초록에 수치가 없어 본문 확인 필요
- 노이즈 공간 계획이 샘플 수·계획 비용과 맞바꾸는 지연 별도 확인 필요

## 🥉 논문 3

**MiniWAM: Learning Compact Future Targets for Efficient World-Action Modeling**
[arXiv:2610.12194](https://arxiv.org/abs/2610.12194) · Jie Chen 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 8/15** · R3 · N2 · M2 · Real0 · Repro1 — 초록 "The project page is available at: https://j1dan.github.io/MiniWAM."

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 미래를 압축 표현으로 예측해 WAM 학습 비용을 낮춤
- **문제** — WAM이 미래 상태를 고차원 시각 표현으로 예측해 학습 비용이 큼
  - 비디오 VAE 잠재처럼 조밀한 시공간 토큰열 처리가 월드 모델링을 비싸게 만듦
  - 원 특징 공간의 세부를 모두 보존할 필요가 있는지 불분명
- **기존 한계** — 효율화 연구가 월드 모델링 목표 자체는 그대로 둠
  - 미래 생성 비용 절감, 월드-액션 상호작용 희소화, 시각 예측 모델·토큰 예산 축소 계열은 풍부한 시각 표현을 여전히 목표로 유지
  - 잠재 미래 지도 계열은 미래 정보를 정책 내부 상태나 보조 조건 공간으로만 반영
- **핵심 방법** — 표현 학습과 예측을 두 단계로 분리
  - 1단계 PRISM — 병목 인코더가 현재·미래 시각 특징을 소수의 잠재 토큰으로 압축하고, 역동역학 지도로 전이 정보를, 특징 복원으로 미래 상태 내용을 보존
  - 2단계 — 인코더를 동결하고 현재 관측에서 PRISM 목표와 로봇 액션을 함께 예측
  - 병목이 시각 표현 아래에 놓여 WAN2.1 VAE 특징과 DINOv3 특징 모두에 적용
- **차별점** — 같은 미래의 비용을 줄이는 대신 월드 모델 분기가 예측하는 대상 자체를 바꿈
- **핵심 기여** — 압축 목표의 성능과 효율
  - 원 미래 특징 토큰 대비 65배 적은 토큰
  - 원 미래 특징 직접 예측보다 일관되게 우수하며 WAM 학습 속도 최대 8배
  - 0.25B 파라미터로 LIBERO·LIBERO-Plus·RoboTwin 2.0 시뮬레이션에서 훨씬 큰 WAM과 대등
  - 역동역학 지도를 더하면 병목 용량 전반에서 복원 전용보다 성능이 오르고, 표현 분석이 행동 구조 기여를 지지
- **가치** — 원 시각 미래를 예측하지 않고도 월드-행동 모델링이 성립할 수 있다는 증거와 효율적 학습 목표 제시

### (c) 시사점

- 잠재 공간 보조 목표의 학습 비용을 낮추는 압축 미래 표현
  - 예측 공간을 압축 잠재로 두면서 역동역학 신호로 제어 관련 정보를 보존하는 구성
  - 보조 예측 분기의 연산 부담을 줄여 경량 정책에 붙이기 쉬운 형태
- 도입 비용 낮음 — 인코더 동결 후 보조 목표만 교체

### (d) 먼저 확인할 점

- 코드 미공개, 프로젝트 페이지만 존재
- 평가가 LIBERO·RoboTwin 시뮬레이션뿐이며 실물 결과 없음
- PRISM 학습에 필요한 현재-미래 전이 데이터와 특권 정보 요구 범위 확인 필요
- 대형 WAM과 대등하다는 비교의 설정(사전학습 여부) 본문 확인 필요
