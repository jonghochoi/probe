## 🥇 논문 1 — 우선순위 ★★★

**Beyond Binary: Sim-to-Real Dexterous Manipulation with Physics-Grounded Contact Representation**
[arXiv:2605.28812](https://arxiv.org/abs/2605.28812) · Jiahe Pan, Stelian Coros, Jitendra Malik, Toru Lin · source: citation-graph (HORA) + keyword-sweep (dexterous/sim2real)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D13](https://img.shields.io/badge/D13-d97706.svg)](#ref-D13) [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **공백** — 기존 촉각 Sim2Real은 접촉 정보를 이진(coarse binary contact)으로 축소해 정보 손실을 감수하거나, 택셀 원시값을 그대로 써 시뮬레이터-실환경 노이즈 불일치에 취약
- **Center-of-Pressure(CoP, 압력 중심)** — 물리 법칙에 근거한 중간 촉각 표현 제안, 밀집 접촉 정보 보존 + 센서 원시값의 노이즈 불일치에 강건
- **센서 보정** — 실측 힘 측정 없이 택셀 방향(taxel orientation)을 추정하는 미분 가능 동역학 기반 보정으로 전문 계측 장비 없이 보정 파이프라인 완결
- **제로샷 이전** — 페그-인-홀 삽입 + 공 균형 유지 두 과제에서 다지 손 위 제로샷 Sim2Real 달성, 이진 접촉 기준선·원시 택셀 기준선 모두 상회
- **잠재 상태 분석** — CoP 조건부 정책이 물체 질량 등 태스크 관련 물리 속성을 부산물로 내부 인코딩함을 확인

### (c) 시사점

- **촉각 피처 선택 근거** — CoP가 택셀 원시값보다 도메인 이전성이 높다는 실험적 근거, 시뮬레이터 촉각 관측을 CoP로 구성하는 비교 실험의 출발점
- **최소 충분 집합** — 이진 접촉만 쓰면 성능 급락, CoP 도입 시 회복하는 절제 결과가 전단력 성분·법선력·압력 중심 2D 좌표를 입력 최소 충분 집합으로 뒷받침
- **비-RL 상한선** — 삽입 유지 태스크를 제로샷 Sim2Real로 해결한 CoP 규칙-제어 결과는 RL 정책의 부가가치를 수치화할 베이스라인으로 활용 가능

### (d) 먼저 확인할 점

- **센서 전제** — CoP 계산이 비주오택타일 센서(GelSight 계열, 카메라 내장 젤 패드) 전제, 영상에서 접촉 지도 추출 후 물리 모델로 전단력·법선력 계산
- **센서 이식성** — 저항/자기 기반 촉각 센서에서는 동일 CoP 추출 파이프라인이 이식되지 않을 수 있음, 출력 신호에서 택셀별 법선력·전단력 분리 가능 여부 선확인 필요
- **일반화 범위** — 페그-인-홀은 손가락 자세 변화가 제한된 정적 삽입 과제
  - 그립 유지(post-grasp grasp maintenance) 일반화 미확인
  - 인핸드 안정 접촉 유지 일반화 미확인
  - 다양한 물체 형상·동적 접촉 상태 전환 일반화 별도 확인 필요

## 🌱 논문 2 — 인접 분야 픽

**Tactile-Proprioceptive Sensor Fusion for Contact Wrench Estimation in Whole-Body Physical Human-Robot Interaction**
[arXiv:2605.28412](https://arxiv.org/abs/2605.28412) · Junha Min, Junghyeon Ma, Jiwung Kwon, Sunggyu Bae, Joohyung Kim, Kyungseo Park · adjacent field: 물리적 인간-로봇 상호작용(pHRI) + 전신 접촉 감지

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **공백** — 기존 모터 전류 기반 힘 추정은 접촉 마찰과 외부 힘을 분리하려고 명시적 마찰 모델 필요
- **접촉 지시자 활용** — 기압식 피부 패드 촉각 신호를 접촉 지시자(contact indicator)로 써 마찰 잔차와 외부 힘 분리를 우회
- **히스테리시스 완화** — 스틱-슬립 전환 구간 마찰 히스테리시스 완화에 TCN(Temporal Convolutional Network) 활용
- **검증** — 촉각 단독·고유감각 단독 기준선 대비 다중 축 접촉 힘 추정 정확도 개선을 실물 로봇 팔에서 입증

### (c) 시사점

- **신호 협력 원리** — 촉각 피처가 마찰 분리 모호성을 제거하고 결합 추정은 고유감각이 담당하는 메커니즘, 촉각 + 관절 토크(모터 전류) 입력 설계의 인접 확인
- **관측 스택 구조** — 촉각 피처를 접촉 상태 분류기 앞단에 배치하는 구조(contact indicator → wrench-free proprioceptive path) 검토 후보

### (d) 먼저 확인할 점

- **Sim2Real 부재** — Sim2Real 설계 없이 실물 기압식 피부 센서 + 로봇 팔에서만 검증(Sim2Real = 1), 시뮬레이터 TCN 학습 후 실환경 이전 가능성 미확인
- **스케일 적용성** — 소규모 손가락 관절 수준 적용 가능성 별도 확인 필요
- **센서 타입 의존** — 기압식 피부 패드는 지정 촉각 센서 형식이 아님, 마찰 모호성 해소 원리가 다른 센서 타입에서도 동일 작동하는지 검증 필요
