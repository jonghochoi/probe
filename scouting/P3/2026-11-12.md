## 🥇 논문 1

**ACTS: Learning Visuo-Tactile World Models from Human Physical Interaction**
[arXiv:2610.24285](https://arxiv.org/abs/2610.24285) · Yuxiang Ma, Weihan Xu, Pengfei Ye 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — P0 2026-10-29 판정 유지

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 인간의 시각·촉각 상호작용 데이터만으로 학습한 월드 모델
- **문제** — 접촉 집약적 조작의 월드 모델에 필요한 접촉 형성·미끄러짐·해제 데이터를 모으기 어려움
  - 접촉 위치와 힘의 작은 차이가 붙음·미끄러짐·걸림·접촉 상실을 가르는데 시각만으로는 국소 상호작용을 풀어내지 못함
  - 로봇 원격조작은 조밀한 접촉 탐색에 느리고 힘 피드백이 제한적
- **기존 한계** — 기존 비주오택타일 월드 모델은 로봇 상호작용 궤적으로 학습
  - 하나는 핸드헬드 그리퍼 데이터를 섞었으나 그리퍼가 접촉 기하를 고정
  - UMI·TacUMI 같은 로봇 없는 수집 인터페이스도 액션이 수집 장치에 묶임
- **핵심 방법** — 액션을 손이 아닌 촉각 센서에서 정의해 사람과 로봇이 같은 액션 공간을 공유
  - 운영자가 핸드헬드 GelSight 센서를 직접 쥐고 조작, 6-DoF 센서 자세와 시각·촉각 관측을 동기 기록
  - 액션은 센서 상대 운동에 촉각으로 추정한 법선 힘에서 얻은 힘 변위를 더한 표현
  - 사전학습 영상 모델에서 출발해 관측 이력과 센서 액션을 받아 미래 장면·손목·촉각 관측을 함께 예측
  - 액션은 국소 센서 좌표계의 힘 반영 운동과 장면 뷰에 투영한 센서 기하로 이중 제공
- **차별점** — 수집 장치가 아니라 센서 수준에서 액션을 정의
  - 사람이 모은 데이터로 학습한 모델을 미세조정 없이 로봇 원격조작에 적용
- **핵심 기여** — 데이터셋, 액션 표현, 사람 데이터 전용 월드 모델
  - React — 3개 물체, 4.9시간의 양손 상호작용 데이터셋(다시점 영상, GelSight Mini 2개 스트림, 추적한 센서 자세, 촉각 유래 법선 힘)
  - 물체별 모델 1개를 사람 데이터만으로 학습, 보류한 사람 데이터에서 장면 뷰 예측이 시각·촉각 월드 모델 두 기준선 중 강한 쪽보다 PSNR 0.7–2.0dB 향상
  - 로봇 원격조작 영점 이전 — PushT는 카메라 예측이 프레임 복사를 상회, Rope는 혼재, Motherboard는 프레임 복사 아래
  - 검토한 로봇 롤아웃에서 예측한 촉각 자국이 기록된 접촉과 같이 나타나고 사라짐
  - React 데이터셋·학습 모델·코드는 채택 후 공개 예정
- **가치** — 접촉 동역학이 외형보다 사람에서 로봇으로 더 안정적으로 이전된다는 초기 근거

### (c) 시사점

- 접촉 동역학이 시각 외형보다 이전이 안정적이라는 측정이 예측 공간 선택의 근거
- 센서 수준 액션 표현이 사람 수집과 로봇 실행을 잇는 공통 인터페이스 후보
- 로봇 텔레오퍼레이션 없이 접촉 데이터를 모으는 경로라 데이터 수집 비용 부담 완화 가능
- 액션 조건화를 힘 변화까지 넓힌 사례로 힘 정보를 가진 액션 입력 설계의 참고점
- 공개 전이라 현재는 설계 참고 수준

### (d) 먼저 확인할 점

- 로봇 쪽 결과가 점검한 롤아웃 중심의 정성 판단이고 로봇 과제 성공률은 없음
- 시각 이전이 불안정, Motherboard는 모든 카메라 스트림에서 프레임 복사보다 낮고 손목 뷰는 흐려지거나 기록에 없는 물체 구조를 만들어 냄
- 촉각 스트림은 6개 중 5개에서 프레임 복사가 PSNR 더 높고 ACTS는 LPIPS가 더 낮음
- 힘 추정기는 법선 힘만 예측하고 오차 0.318N(6.4%)은 CNC 보정 데이터 기준, 사람 조작 중 오차는 미측정
- 모든 스트림이 VAE 복원 정답 대비 점수라 VAE와 공유하는 오류는 검출되지 않음
- 센서 자세를 OptiTrack으로 얻어 한 개의 계측 실험실에 묶이고 로봇 수집·배포에도 외부 추적이 필요
- 물체별 모델 1개씩이라 물체 일반화는 미확인

## 🥈 논문 2

**An Action Is Worth One Patch: Unified World-Action Modeling with PatchWAM**
[arXiv:2609.25961](https://arxiv.org/abs/2609.25961) · Tianheng Wang, Zhou Xie, Heng Jia 외 · arXiv preprint · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 액션을 시각 잠재 토큰으로 써서 액션 전문가를 없앤 월드-액션 모델
- **문제** — 연속 제어에 별도 액션 전문가가 필요한지, 시각 생성 경로로 액션을 직접 예측할 수 있는지가 질문
  - 사전학습 영상·이미지 생성 모델은 객체와 공간 관계의 시각 사전지식을 갖고 있고 액션 예측도 같은 디노이징 목표로 정식화 가능
- **기존 한계** — 기존 접근은 저차원 상태와 고차원 시각 표현을 잇기 위해 학습 가능한 액션 헤드나 별도 액션 전문가를 도입
  - 학습 가능한 액션 인코더, 액션 전용 출력 투영, 별도 액션 전문가가 시각 경로와 분리된 계산 경로를 만듦
- **핵심 방법** — 고정 코덱 Action-as-Patch가 액션 한 스텝을 시각 잠재 공간의 토큰 하나로 사상
  - 액션 차원이 시각 토큰 폭보다 작아 반복과 영 채움으로 정보 보존 사상, 고정 디코더가 그룹 평균으로 액션 복원
  - 언어·고유수용감각·현재 이미지를 조건으로 액션 청크와 미래 시각 끝점을 함께 예측
  - 액션·미래 이미지 토큰에 같은 잡음 수준으로 독립 가우시안 잡음을 주고 결합 플로우 매칭 목표로 학습
  - 공유 DiT 하나가 두 토큰 묶음을 함께 디노이징, 추론은 액션 토큰만 디코딩하며 미래 영상 RGB 복원 불필요
- **차별점** — 학습 가능한 액션 전용 모듈 없이 백본의 기존 시각 처리 경로를 액션에 재사용
  - 학습된 선형 인터페이스는 고정 코덱보다 낫지 않다는 대조 포함
- **핵심 기여** — 고정 액션 인터페이스, 결합 예측, 시뮬레이션 평가
  - RoboTwin 2.0 매칭 이중 전문가 대조 — 학습 윈도우 시작 20개 중 1개만 유지한 설정에서 평균 성공률 88.0% 대 78.4%, 학습 가능 파라미터 감소
  - RoboTwin 2.0 clean·randomized·증강 시연 전체 데이터 평균 96.12%, 증강 학습 LIBERO-Plus 91.8%
  - clean-to-random 전이에서 randomized 66.72%, clean·random 평균 79.14%, randomized 점수는 가장 강한 기준선 아래
  - 전체 데이터 설정에서 액션과 미래 프레임 토큰 사이 가시성 제거 시 0.58점 하락
  - RoboDojo Score 29.39, 2026-09-15 리더보드 항목 중 최고
- **가치** — 액션 생성 능력을 새로 붙이기보다 생성 백본이 물려받을 수 있다는 근거, 제약은 용량이 아니라 새 신호를 쓰는 인터페이스

### (c) 시사점

- 액션 전문가를 보존하는 구성과 단일 경로 통합 구성을 맞댄 시뮬레이션 대조 한 건 확보
- 통합 경로의 이득이 학습 윈도우 20분의 1 설정에 한정되어 일반화 근거로 쓰기는 이른 단계
- 학습 가능 파라미터가 줄어도 매 디노이징 단계에서 이미지와 액션을 갱신해 추론 지연이 줄지는 않음
- 액션 전문가 보존 쪽 선택을 흔들 근거는 아직 부족, 실물과 시드 반복 결과가 나오면 재평가 대상

### (d) 먼저 확인할 점

- 실물 로봇 결과가 없고 저자도 모든 결과가 실물 검증 대기라고 밝힘
- 이중 전문가 대비 이득의 원인을 가르려면 매칭 설정의 추가 대조와 독립 시드가 필요하다고 저자가 인정
- 대조가 파라미터 공유와 어텐션 구성의 효과를 분리하지 않음
- 벤치마크 비교는 데이터 구성이 서로 달라 매칭 대조와 따로 읽어야 함
- 공동 디노이징 탓에 추론이 이중 전문가 대조보다 느림
- 코드 저장소나 공개 약속이 없어 재현 경로 없음

## 🥉 논문 3

**WorldFlow: Joint Video and 3D Motion Prediction via Large-Scale Pretraining**
[arXiv:2610.39278](https://arxiv.org/abs/2610.39278) · Yuhao Lu, Jiongxu Chen, Hexiang Wei 외 · arXiv preprint · source: keyword-sweep

**점수 7/15** · R3 · N2 · M2 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 미래 영상과 질의 기반 3D 궤적을 한 백본에서 함께 예측하는 월드 모델
- **문제** — 물리 세계의 외형 변화와 공간 구성 변화를 함께 포착하는 구현체 월드 모델이 필요
  - 영상 생성 모델은 예측을 픽셀로 표현해 3D 동역학이 암묵적으로 남음
- **기존 한계** — 월드 액션 모델은 액션 감독 수집이 비싸고 액션 표현이 특정 로봇 구성에 묶임
  - 밀집 3D 장면 흐름 생성은 계산 비용이 큼
  - 장면 수준 방법은 성긴 격자에서 모션을 예측해 과제와 무관한 영역에 토큰을 쓰고 공간 해상도 때문에 미세한 모션 경계를 놓침
  - 3D 궤적 주석은 구하기 비싸고 흐름 단독 감독은 물리 동역학에 대한 학습 신호가 제한적
- **핵심 방법** — 질의 점 위치에서 3D 궤적을 예측하고 영상 예측과 같은 백본에서 함께 디노이징
  - 입력은 관측 이미지, 언어 지시, 희소한 3D 질의 점, 질의 위치의 모션은 장면 전체를 맥락으로 예측
  - 궤적은 정규화한 프레임 간 3D 변위와 초기 점 기하를 담은 연속 토큰으로 표현해 영상 토큰과 시공간 정렬
  - 통합 Mixture-of-Transformers 백본이 하나의 rectified-flow 목표로 두 모달리티를 함께 디노이징
- **차별점** — 흐름 단독 감독 대신 같은 미래의 조밀한 시각 감독을 궤적 학습에 결합
- **핵심 기여** — 모델, 대규모 코퍼스, 벤치마크
  - 시뮬레이션과 실세계 약 144만 객체 수준 샘플(49프레임 16FPS 기준 1,224시간)
  - WorldFlowBench — 11개 데이터 소스 1,678 평가 샘플, 공간 추론 평가셋 SpatialCog 포함
  - 세 평가셋 모두에서 평가한 학습 기반 방법 중 최저 ADE와 FDE
  - SpatialCog에서 ADE 0.060m, 가장 강한 외부 기준선 대비 54.2% 감소
  - 흐름 단독 변형 대비 SpatialCog ADE 55.9%·FDE 68.5% 감소, Sim7 ADE 48.5% 감소
- **가치** — 영상 보조 감독이 3D 모션 예측 정확도를 높인다는 근거와 확장 가능한 궤적 예측 학습 틀

### (c) 시사점

- 3D 흐름 단독 예측과 영상 결합 예측을 같은 구조에서 맞댄 수치 확보
- 흐름 공간 예측이 조밀한 시각 감독을 곁들일 때 가장 잘 작동한다는 점이 예측 공간 선택의 참고
- 평가가 궤적 오차(ADE·FDE)라 정책 성공으로의 이전은 별도 확인 대상
- 학습용 3D 궤적을 자동 추출해 쓰므로 주석 파이프라인 비용이 도입 시 변수

### (d) 먼저 확인할 점

- 로봇 실행 성공률이 없고 실세계 데이터는 학습·평가용 궤적 데이터에 한정
- 액션 조건화가 없어 조작 정책과의 결합은 논문 범위 밖
- 시드 반복과 한계 진술을 본문 검색에서 확인하지 못함
- 코드 저장소나 공개 약속이 없고 타 데이터 재사용만 언급

## 🌱 논문 4 — 인접 분야 픽

**Spatial-UMI-Dream: Scaling World Action Models with Metric Geometry for UMI Manipulation**
[arXiv:2611.07229](https://arxiv.org/abs/2611.07229) · Weiduo Yuan, Ze Yuan, Sihan Liu 외 · adjacent field: 공간 기하 표현(P2 인접) · arXiv preprint

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음 — 프로젝트 페이지만

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 미래 RGB와 함께 미터 단위 깊이를 예측하는 UMI용 월드 액션 모델
- **문제** — UMI의 움직이는 근거리 그리퍼 카메라에서는 카메라 운동과 물체 운동이 얽혀 정밀 조작에 필요한 미터 기하가 RGB에 암묵적으로만 남음
  - 고정 3인칭 시점이 없고 양손 조작에서는 두 시점이 독립적으로 움직여 모델이 두 그리퍼의 공유 3차원 작업 공간을 조율해야 함
  - 도메인 내 성공률만으로는 UMI 정책 평가가 부족하고 환경 변화와 로봇 구현체 이전을 함께 시험해야 함
- **기존 한계** — RGB 기반 월드 액션 모델은 장면 척도와 공간 관계를 RGB만으로 추론해야 함
  - 비전-언어-액션 모델은 사전학습 비전-언어 모델을 기반으로 하고 월드 액션 모델은 사전학습 영상 생성 모델을 기반으로 함
  - UMI 데이터에 이를 적용할 때 기하가 암묵적이라는 점을 저자들이 지적
- **핵심 방법** — 5B 공간 월드 액션 모델이 미래 RGB, 어안 정렬 미터 깊이, 액션을 함께 예측
  - 보정된 스테레오 관측에서 미터 깊이를 복원해 원본 어안 RGB와 정렬
  - 두 그리퍼의 정렬 RGB-D를 하나의 영상 캔버스에 배치, 사전학습 영상 토크나이저와 월드 액션 백본 유지
  - 2단계 학습 — UMI RGB-D 관측에 맞춘 월드 전용 적응 후 월드와 액션 결합 학습
- **차별점** — 깊이를 별도 입력 모듈이 아니라 영상 캔버스의 예측 대상으로 통합
  - 같은 사전학습 설정에서 RGB 전용과 RGB-D를 맞댄 ablation 포함
- **핵심 기여** — 모델, 벤치마크, 실물 결과
  - 605시간 RGB-D UMI 데이터 사전학습
  - RoboTwin-UMI — RoboTwin 위에 UMI 손목 어안 관측을 재현한 20개 과제 시뮬레이션 벤치마크, 환경·구현체 변화를 따로 또 함께 평가
  - RoboTwin-UMI 도메인 내 79.10%로 가장 강한 평가 기준선 대비 4.65점 우위, 환경·구현체 복합 변화 72.15%로 10.30점 우위
  - 구현체 이전에서 성공률 하락이 평가한 정책 중 최소
  - 매칭 사전학습 ablation에서 RGB 전용은 도메인 내 성공률 5.75점 하락
  - 실물 6개 과제 평균 85.0%, 가장 강한 기준선 60.8% 대비 24.2점 우위(과제당 20회)
- **가치** — 로봇 비종속 시연 수집 데이터로 정책이 구현체와 환경 변화에 일반화되는지를 재는 공통 프로토콜과 기하 반영 사전학습 근거

### (c) 시사점

- 미래 RGB 곁에 미터 깊이를 두는 예측 공간이 잠재·3D 흐름 외 후보로 추가
- 같은 사전학습에서 RGB 전용 대비 5.75점 차이를 낸 ablation이 깊이 예측의 효과 근거
- 인접 분야의 기하 표현을 손목 카메라 기반 조작에 이식할 때의 이득을 보여 주는 사례
- 도입하려면 스테레오 장비로 깊이를 모으는 비용이 전제

### (d) 먼저 확인할 점

- 코드 저장소나 공개 약속이 없고 프로젝트 페이지만 확인됨
- 5B 모델과 605시간 RGB-D UMI 사전학습이 전제라 소규모 설정에서의 이득은 미확인
- 평가한 기준선은 일반 VLA와 월드 액션 모델 몇 종이고 시드 반복·한계 진술은 확인되지 않음
- 시뮬레이션 평가가 저자들이 만든 벤치마크라 외부 비교 기준점 부족
- 손목 어안 UMI 관측을 전제로 해 3인칭 설정으로의 이전은 미검증
- 접촉 집약적 과제 평가가 중심이 아니고 촉각·힘 신호는 다루지 않음
