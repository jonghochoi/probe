## 🥇 논문 1 — 우선순위 ★★★

**Bridge-WA: Predicting Where and How the World Changes for Robotic Action**
[arXiv:2607.02195](https://arxiv.org/abs/2607.02195) · Yongjie Bai, Hanting Wang, Mingtong Dai, Qijun Zhong, Yang Liu, Liang Lin et al. · source: citation-graph (WorldVLA, Being-H0.7, VLA-JEPA 피인용)

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 일반 목적 VLA가 "행동에 따라 장면이 어디를, 어떻게 변화시킬지" 예측하는 능력이 부족하다는 문제의식에서 출발
- 대형 생성형 world model이나 조밀한 미래 롤아웃 대신, 고정(frozen)된 future-change teacher를 미래 토큰·변화 맵·모션-플로우 맵 세 갈래의 경량 prior로 증류
- WorldBridge 모듈이 multi-source attention memory와 spatial-temporal bias로 액션 트랜스포머를 세 prior에 조건화, teacher는 추론 시 완전히 제거
- VLABench·RoboTwin2.0·LIBERO-Plus 공개 벤치마크와 실로봇 평가에서 태스크 성공률·진행도·강건성 개선, 분포 이동(OOD) 조건에서 개선폭이 특히 뚜렷
- 장면 변화의 위치·방식에 집중해 배경·조명·방해물 등 nuisance 요인 억제, 배포 시 dense 미래 이미지 생성 불필요
- 코드·시각화 자료 공개 확인

### (c) 시사점
- 대형 world model 전체를 배포 파이프라인에 얹지 않고도 "어디가, 어떻게 변하는가"라는 압축 신호만 증류해 action 예측에 결합하는 저비용 레시피 확보
- teacher를 추론 시 완전히 제거하는 구조라 배포 비용 증가 없이 학습 단계에서만 구조화된 미래 감독을 취하는 방식 — 도입 비용 낮음
- 여러 공개 벤치마크에 걸쳐 일관된 개선폭이 보고돼 있어 자체 스택 대비 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 실로봇 평가의 구체적 태스크 수·성공률 수치가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 대상 태스크가 범용 조작 벤치마크(VLABench, RoboTwin2.0, LIBERO-Plus) 중심이라 손 중심 다지 조작·정밀 파지까지 결과가 일반화되는지는 미확인
- 가장 저렴한 전이 확인: 공개된 코드로 motion-flow map 증류 파이프라인을 자체 태스크의 OOD 조건에 먼저 재현

## 🥈 논문 2 — 우선순위 ★★

**LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments**
[arXiv:2607.23969](https://arxiv.org/abs/2607.23969) · Pei Liu, Nan Zheng, Lang Zhang, Daojie Peng, Yanan Zhang, Feilong Kong et al. · source: citation-graph (Being-H0.7, VLA-JEPA 피인용)

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 픽셀 수준 비디오 생성에 의존하는 기존 World Action Model의 표현 용량 낭비·시각적 방해 요인 취약성 문제 지적
- JEPA(Joint-Embedding Predictive Architecture)를 "World-Anchor"로 운용하는 Predictive-Latent 패러다임 제안 — 시각 합성 대신 잠재 공간에서 직접 물리적 동역학 추출
- 비-가우시안 JEPA 예측 특징과 diffusion prior 간 모달리티 격차를 메우는 Isotropic Semantic Autoencoder(ISAE)로 anchor 잠재 공간을 diffusion 친화적 매니폴드로 재구성
- 비대칭 Mixture-of-Transformers 구조 — 학습 시 Anchor Diffusion Transformer가 특권(privileged) 동역학 전문가로 Action Diffusion Transformer를 가이드, 추론 시 해당 무거운 분기를 제거해 zero-overhead 실행
- 대규모 궤적 사전학습 없이 LIBERO에서 predictive 계열 모델 중 최고 성능, RoboTwin 2.0에서 top-tier 생성형 WAM과 동등 수준 달성, 미확인 환경 zero-shot 강건성 및 실환경 전이 성공 보고
- 코드 공개(GitHub) 확인

### (c) 시사점
- 픽셀 재구성 없이 JEPA 잠재 표현만으로 물리 동역학을 포착하는 접근이 대규모 궤적 사전학습 없이도 경쟁력 있는 성능에 도달한다는 근거
- 학습 시에만 무거운 privileged 동역학 전문가를 쓰고 추론 시 완전히 제거하는 구조라, 배포 비용 증가 없이 latent 예측의 이점을 취함
- diffusion 기반 action head와 JEPA 잠재 표현을 안전하게 결합하는 구체적 방법(ISAE)이 제시돼 있어, 잠재 표현 결합 시 겪는 모달리티 불일치 문제에 직접 참고 가능

### (d) 먼저 확인할 점
- "실환경 전이 성공"이 정성적 서술에 그쳐 구체적 태스크 수·성공률 수치는 본문 확인 필요
- 대규모 궤적 사전학습을 생략한 조건에서의 결과라, 사전학습을 포함할 때 상한이 어떻게 달라지는지 별도 확인 필요
- 가장 저렴한 전이 확인: 공개된 코드로 ISAE 모듈만 분리해 기존 latent 예측 파이프라인에 이식 가능한지 우선 검토

**LeapBot-WA (11/15)**
- Relevance 3 — JEPA 기반 World-Anchor + 추론 시 제거되는 privileged 동역학 전문가 구조가 JEPA 계열 latent 예측 및 auxiliary-head 방향에 정합
- Novelty 2 — JEPA 특징-diffusion 모달리티 격차를 겨냥한 ISAE는 기존 JEPA 계열 world model과 구분되는 구체적 해법
- Reproducibility 2 — 코드 공개(GitHub) 확인
- Methodology 2 — LIBERO·RoboTwin 2.0 비교 결과 제시, 다만 소거 실험 세부 수준은 abstract에서 미확인
- Sim2Real 2 — 실환경 전이 성공 명시, 다만 구체 수치는 미확인

이번 런에서 다섯 차원(Relevance/Novelty/Reproducibility/Methodology/Sim2Real) 모두 ≥2를 통과한 논문은 Bridge-WA·LeapBot-WA 2편. 근접 후보 다수는 Reproducibility(코드 미공개·공개 예정 문구뿐) 또는 Sim2Real(로봇 배포 근거 부재) 미달로 탈락 — 상세 사유는 🚫 섹션 참조. 3편 미만이므로 채우지 않음.
