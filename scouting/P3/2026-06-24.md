## 🥇 논문 1 — 우선순위 ★★★

**Tactile Genesis: Exploring Tactile Sensors at Scale for Learning Dexterous Tasks**
[arXiv:2606.22332](https://arxiv.org/abs/2606.22332) · Trinity Chung, Kashu Yamazaki, Dhruv Patel, Alexis Duburcq, Yiling Qiao, Katerina Fragkiadaki, Aran Nayebi · source: arXiv 키워드 스윕 (contact force + policy)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 어떤 촉각 추상화 수준이 정책에 필요한지, 더 풍부한 촉각 필드가 하드웨어 비용을 정당화하는지 경험적으로 연구 불가; 각 센서가 사실상 새로운 로봇을 정의하고, 동일 학습 실험을 모든 센서 구성에서 재현할 수 있는 실험실 없음
- **Tactile Genesis 플랫폼** — GPU-병렬 촉각 센서 시뮬레이션 플랫폼
  - **7종 모달리티 통합**: 이진 접촉, 접촉 깊이, 택셀별 동역학 힘/토크(kinematic force/torque), 엘라스토머 마커 변위, 기하 인식 근접도, 접촉 음향, 복셀화 온도장(세계 최초)
  - 단일 GPU에서 20,000개 이상 병렬 환경·택셀 1,000개 이상 지원; 기존 촉각 시뮬레이터 대비 처리량 3~20배 향상
  - 현실 노이즈 모델(드리프트·히스테리시스·불량 택셀·크로스토크) 구성 가능
- **교사-학생 정책 ablation** — 3개 다지 과제에서 센서 유형·배치·해상도·노이즈를 독립 변수로 ablation; XHand1 실물 이전 검증
- **핵심 발견 4가지** (전 과제 일관)
  - 고유감각 단독으로는 전 과제 불충분
  - **배치 > 유형**: 손끝 전용이 손 전체 커버리지 대비 크게 열세; 손바닥·근위 지절 추가만으로 격차 대부분 해소
  - **커버리지 > 해상도**: 전체 손에 200 택셀 분산 배치로 전 과제 충분
  - **택셀별 힘/토크**가 가장 유용한 단일 센서 유형
- **진정한 신규성** — 7종 촉각 모달리티를 단일 GPU-병렬 플랫폼에 통합한 최초 사례; 배치·해상도·유형의 동시 ablation + 실물 이전을 동일 플랫폼에서 수행한 최초 연구

### (c) 시사점

- **D15 입력 설계에 가장 직접적인 실험 근거 확보** — 택셀별 힘/토크 + 전체 손 200 택셀 분산 배치 조합이 최소 실용 구성으로 제시; System0 입력 채널 확정 전 ablation 재현 없이 즉시 참조 가능한 설계 기준점
- **D17 학습 인프라 방향 부합** — 20,000 병렬 env × 1,000 택셀 스케일이 Isaac Lab 8k~16k 환경 설계와 정확히 부합; 촉각 포함 RL 학습 시간·비용 추정에 직접 활용 가능한 처리량 기준
- **D18 교사-학생 구조 XHand1 실물 이전 검증** — 동일 플랫폼에서 실물 다지 손으로의 교사→학생 sim2real 이전 성공; 촉각 ablation + sim2real 분리 실험이 가능한 유일한 공개 인프라

### (d) 먼저 확인할 점

- **슬립 억제·파지 유지 특화 과제 미포함** — ablation 3과제가 다지 조작 일반 범주; 파지 후 접촉 유지·슬립 발생 전 전단력 감지 특화 시나리오에서 동일 권장 구성이 최적인지 추가 확인 필요
- **XHand1 단일 하드웨어 실물 이전** — LEAP·Shadow·Allegro급 다지 손에서 동일 200 택셀 전체 배치 구성의 유효성 별도 검증 필요
- **온도장·음향 등 희귀 모달리티의 실물 활용 미검증** — 시뮬레이션 ablation 수준; 실물 센서 구현 비용·노이즈 특성에 따라 채택 여부 추가 평가 필요

## 🥈 논문 2 — 우선순위 ★★

**TacCoRL: Integrating Tactile Feedback into VLA via Simulation**
[arXiv:2606.11743](https://arxiv.org/abs/2606.11743) · Siyu Ma, Yuqi Liang, Chang Yu, Yunuo Chen, Hao Su, Yixin Zhu, Yin Yang, Chenfanfu Jiang · source: arXiv 키워드 스윕 (tactile + contact + reinforcement)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — VLA 정책은 강력한 시각·언어·행동 사전을 제공하지만, 시연에서 드물고 실물 수집 위험한 접촉 임계 구간(near-failure states)에서 촉각 기반 행동 조정 능력 부재; 대규모 촉각 사전학습이나 실물 접촉 탐색 없이 이를 주입하는 방법 미확립
- **TacCoRL 설계** — 시뮬레이션 기반 공동학습(sim-real co-training) + RL 통합 프레임워크
  - **실물 정렬 시뮬레이터**: 접촉 상호작용 폐루프 학습 환경으로 사용
  - **혼합 warm-start**: 시뮬레이션 + 실물 궤적으로 촉각 조건부 행동을 사전학습 정책에 초기화
  - **검증 보상 기반 RL**: 시뮬레이션 접촉 롤아웃에서 near-failure 상태의 촉각 조건부 행동을 과제 완료로 이어지도록 강화; 실물 궤적 지도 목표로 배포 분포 앵커링
  - 시뮬레이션 특권 상태 불필요, 실물 온라인 RL 불필요
- **검증** — 4개 bimanual 접촉 집약 과제 실물 실험; 최종 비주오택타일 정책 평균 72.5% 성공률 (기준선 50.0% 대비 +22.5pp)
- **진정한 신규성** — "시연에서 드문·실물 수집 위험한 근실패 접촉 구간"을 명시적 RL 탐색 대상으로 삼는 첫 시뮬레이션 기반 촉각-VLA 통합 프레임워크

### (c) 시사점

- **접촉 임계 구간 특화 RL이 실물에서 작동** — near-failure 상태를 명시적으로 RL 학습 대상으로 정의하면 일반 시연에서 드문 상황을 효율적으로 강화 가능; 이 패턴이 System0의 "retention-critical 구간 게이팅" 개념과 구조적으로 부합함을 실물로 확인
- **시뮬레이션 접촉 롤아웃 + 실물 warm-start 혼합 패턴** — 실물 온라인 RL 없이 접촉 안정화 특화 RL이 가능한 학습 인프라 방향; System0 RL 학습 시 실물 데이터 요구량 최소화 경로 참조
- **근실패 구간 커리큘럼** — 접촉 임계 구간을 별도 커리큘럼으로 정의 시 탐색 효율 향상; D17 System0 정책 학습 설계에서 유사 커리큘럼 구조 도입 가능성 검토 근거

### (d) 먼저 확인할 점

- **비전 포함 VLA 의존 구조** — 상위 모션 계획에 시각 입력 필수; P3 비전 배제 원칙과 상충 → 촉각 기반 행동 조정 메커니즘만 분리 이식 시 별도 설계 필요
- **근실패 상태 정의의 보상 엔지니어링 의존도** — 과제 완료가 명시적으로 검증 가능한(verifiable) 삽입·조립 등에 적합; 슬립 억제·파지 유지처럼 연속적·경계 불명확한 보상 설계가 어려운 시나리오에서 동일 패턴 적용 가능성 별도 검토 필요
- **bimanual 구조 의존** — 양팔 협력 과제 검증; 단일 다지 손 독립 접촉 안정화 루프 전환 시 bimanual 협력 요소 제거 후 성능 보존 여부 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement**
[arXiv:2606.18953](https://arxiv.org/abs/2606.18953) · Kinam Kim, Namiko Saito, Heecheol Kim · source: arXiv 키워드 스윕 (residual RL + manipulation)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 순수 시뮬레이션 학습 잔차 RL 정책이 실물 VLA를 제로샷으로 보강 가능한가; 기존 잔차 RL의 특권 상태(privileged-state) 방법은 배포 시 distillation 손실, 이미지 기반 방법은 시각 Sim2Real 격차로 어려움
- **Object-Centric Residual RL 설계** — 고정(frozen) VLA 정책 위에 순수 시뮬레이션 학습 잔차 교정 RL 정책 추가
  - **객체 중심 상태 표현(object-centric state representation)**: 특권 상태·이미지 없이 sim2real 격차를 상태 표현 수준에서 해소
  - 시뮬레이션 전용 학습 → 실물 VLA에 제로샷 적용
  - 정밀 접촉 과제에서 실물 VLA 성능 향상 검증
- **진정한 신규성** — 특권 상태·이미지 없는 객체 중심 상태로 제로샷 sim2real 잔차 RL을 최초 제안; VLA 기반 정책 재학습 없이 접촉 정밀 과제 보강

### (c) 시사점

- **잔차 RL의 System0 구조 유사성** — 잔차 RL이 기반 정책(VLA) 위에서 교정 서브 정책으로 작동하는 구조가 System0의 System1 보완 아키텍처와 설계 수준에서 부합; 기반 정책 재학습 없이 교정 서브 정책만 개선하는 분리 전략의 외부 근거
- **DR 없는 sim2real 경로** — 특권 상태·도메인 랜덤화 없이 객체 중심 상태 표현만으로 제로샷 sim2real 잔차 정책 달성; D18 v1의 마찰 분할 DR 접근과 직교하는 대안 경로 확인
- **정밀 접촉 과제 특화 잔차 정책** — 일반 VLA가 컴파운딩 오류로 실패하는 정밀 접촉 구간에서 잔차 RL이 보강; System0가 주로 활성화되는 접촉 정밀 구간과 동일 맥락

### (d) 먼저 확인할 점

- **VLA 기반 정책 의존** — 잔차 RL이 VLA 위에서 작동; System0가 System1과 독립 모듈로 구성될 경우 이 패턴의 직접 이식 불가 → System1 정책 형태 확정 후 전이 가능성 재평가 필요
- **세부 수치·코드 공개 미확인** — 과제 종류·성공률 상세 수치 및 코드 공개 여부 본문 별도 확인 필요
- **접촉 안정화 특화 미검증** — VLA 정밀 접촉 과제 일반 범주; 슬립 억제·파지 유지 특화 System0 시나리오에서 잔차 정책이 충분한 교정력을 갖는지 확인 필요

### Decision Log

- **D15 System0 촉각 입력 모달리티에 "택셀별 힘/토크 + 전체 손 커버리지 200 택셀" 권장 사양 명시화 검토 제안** — 근거: [arXiv:2606.22332](https://arxiv.org/abs/2606.22332)
  - D15 v1은 "tactile feature + 고유감각 이력" 채널 열거 수준; 어떤 촉각 유형·배치·해상도를 써야 하는지 미정
  - Tactile Genesis ablation 답변: 택셀별 힘/토크가 가장 유용, 배치 > 유형, 커버리지 > 해상도(전체 손 200 택셀 충분)
  - 제안: D15 v1에 권장 촉각 유형("택셀별 힘/토크 우선") + 최소 커버리지 기준("전체 손 배치, 200 택셀 수준") 항목 추가 검토; 손끝 전용 배치 배제 근거로 명기 가능

- **D18 sim2real deferred 옵션에 "객체 중심 상태 기반 잔차 RL" 경로 추가 검토 제안** — 근거: [arXiv:2606.18953](https://arxiv.org/abs/2606.18953)
  - D18 v1(DR over friction split + RMA 교사-학생)은 시뮬레이터 파라미터 분포 확장 방향
  - Object-Centric Residual RL은 특권 상태·DR 없이 객체 중심 표현 + 잔차 정책으로 제로샷 sim2real 달성 → 독립 대안 경로
  - 제안: D18 deferred 후보에 "객체 중심 상태 기반 잔차 정책 sim2real" 항목 추가; System1 정책 형태 확정 후 이식 가능성 ablation 권고

## 🔄 직전 리포트 대비 종합

- **중복 없음** — 이번 채택 3편(arXiv:2606.22332·2606.11743·2606.18953) 모두 직전 4개 리포트(2026-06-22·06-19·06-17·06-15) 미채택
- **촉각 시뮬레이션 인프라 신호 형성** — Tactile Genesis가 처음으로 "어떤 촉각 센서를 어디에 배치할 것인가"라는 하드웨어 설계 질문에 실물 ablation 답변 제공; 이전 시퀀스(인코더·정책·Sim2Real 층위)에서 "인프라 설계" 층위로 신호 확장
- **잔차 정책 패턴 2회 연속 등장** — TacCoRL(근실패 구간 RL 강화)과 Object-Centric Residual RL(객체 중심 잔차 정책)이 서로 다른 메커니즘으로 "기반 정책 위 교정 서브 정책" 패턴을 실물 검증; System0 독립 모듈 설계 방향의 누적 근거 형성
- **🌱 슬롯 제외** — 2026-06-22 리포트에서 T-Rex(인접 분야 픽) 이미 채택; 월 1회 원칙에 따라 이번 회차 🌱 슬롯 불포함. 이번 창에 필터 통과 후보(Geometric Reconstruction of Extrinsic Contact, arXiv:2606.22251 — 촉각+고유감각으로 공구 선단 접촉 궤적 재구성, D15 인접)가 🌱 없이 남음 → 다음 월 시작 첫 회차에서 재검토 권고
