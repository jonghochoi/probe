## 🥇 논문 1 — 우선순위 ★★★

**Dense Force Estimation with an Event-based Optical Tactile Sensor**
[arXiv:2606.09451](https://arxiv.org/abs/2606.09451) · Agis Politis, René Zurbrügg, Valentina Cavinato · source: arXiv 키워드 스윕 (tactile + contact + reinforcement learning)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 비전 기반 촉각 센서(GelSight 계열)는 밀집 접촉력 추정이 가능하나 카메라 프레임 속도·모션 블러·대역폭에 제약; 이벤트 기반 촉각 센서는 마이크로초 시간 해상도를 제공하지만 기존 방법은 합력(net force)만 예측 가능
- **이벤트 기반 광학 촉각 센서에서 밀집 3D 접촉력 필드(dense 3D force field) 추정하는 첫 프레임워크**
  - **전단 변위(shear displacement)**: 이벤트 기반 마커 추적 알고리즘으로 복원
  - **법선 변위(normal displacement)**: 동기화 데이터셋으로 학습한 CNN으로 예측
  - **변위 → 접촉력**: 역 유한요소법(iFEM, inverse Finite Elements Method)으로 매핑
- **성능** — 힘 범위 (4 N, 4 N, 20 N) 대비 MAE (0.14 N, 0.10 N, 0.93 N); **100 Hz** 연속 동작
- **진정한 신규성** — 이벤트 기반 촉각에서 공간 밀집 3D 접촉력 추정 최초 달성; 기존 연구는 단일 합력 예측에 한정

### (c) 시사점

- **100 Hz 밀집 접촉력 필드 → System0 고주파 입력 설계 기준점** — 마이크로초 시간 해상도 + 공간 밀집 3D 힘 분포가 슬립 발생 직전 전단력 이동 조기 감지에 직결; 촉각 입력 채널 설계 시 이벤트 기반 iFEM 구조를 참조 아키텍처로 검토 가능
- **파지력 분포 → 슬립 예측 연계** — 밀집 힘 분포 변화로 슬립 전 전단력 이동을 선제 감지 가능; 접촉-상태 이력 구성에 이벤트 기반 프레임 추가 시 System0 슬립 예측 품질 향상 여지
- **모션 블러 없는 고주파 측정** — 고속 접촉 이벤트(충격·슬립 전이)에서 비전 기반 촉각 대비 측정 신뢰도 우위; 제어 루프 프레임 드롭 위험 최소화

### (d) 먼저 확인할 점

- **감지 → 제어 루프 미연결** — 논문은 촉각 센서 힘 추정 정확도만 검증; 해당 힘 표현을 RL 정책 입력으로 연결하는 제어 루프 실험 미제시 → System0 통합 전 별도 검증 필요
- **센서 장착 호환성** — 이벤트 카메라 기반 촉각 센서의 다지 손 끝 통합 방식·충격 내구성 불명; 하드웨어 적합성 사전 확인 필요
- **파이프라인 지연 일관성** — 이벤트 마커 추적 + CNN + iFEM 파이프라인이 접촉 다양성 증가 시에도 100 Hz를 안정적으로 유지하는지 실측 필요

## 🥈 논문 2 — 우선순위 ★★

**Transferring Contact, Not Just Motion: Compliant Grasping Across Dexterous Hands**
[arXiv:2606.15516](https://arxiv.org/abs/2606.15516) · Soofiyan Atar, Yao-Ting Huang, Michael Yip · source: arXiv 키워드 스윕 (slip + grasp + dexterous)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D13](https://img.shields.io/badge/D13-d97706.svg)](#ref-D13) [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **문제** — 기존 크로스-임바디먼트 다지 정책은 손 자세 재타기팅·잠재 행동으로 모션을 통합하지만, 힘 피드백은 각 손의 감지·구동에 종속되어 이전 불가; 슬립·변형·시각 폐색 중 적절한 물체 부하 유지 실패
- **크로스-임바디먼트 힘-위치 인터페이스**
  - 모션 의도: 공유 손 자세 잠재 공간에서 표현
  - 힘 신호: 시스템 식별(system identification)으로 물리 관절 토크(N·m)로 교정 → 손가락 끝 힘 + 퍼-핑거 부하 디스크립터(per-finger load descriptor)로 매핑
  - 정책에 위치·부하 두 채널을 동일 형태로 제공 → 하드웨어 간 일관된 접촉 관측 가능
- **학습** — 플로우 매칭 비주오모터 정책; 파지 관련 폐색 시 힘 의존 유도를 위한 **구조적 비주얼 마스킹(structured visual masking)** 도입
- **진정한 신규성** — 이기종 다지 손 간 물리적으로 일관된 힘 교정 인터페이스로 접촉 부하를 통합한 첫 크로스-임바디먼트 컴플라이언트 파지 프레임워크

### (c) 시사점

- **슬립·변형 중 접촉 부하 유지의 실물 검증** — 파지 접촉이 슬립·변형되는 상황에서도 적절한 물체 부하 유지가 이기종 다지 실물 손에서 작동; System0의 파지 유지 핵심 시나리오를 다양한 하드웨어에서 달성 가능함을 시사
- **힘 교정 파이프라인 → 하드웨어 교체·업그레이드 시 재교정 비용 표준화 참조** — 시스템 식별 기반 관절 토크 교정 + 퍼-핑거 부하 디스크립터 방식; 새 다지 손 도입 시 System0 적응 전이 비용 추정 기준점
- **구조적 비주얼 마스킹 → "힘-우선" 학습 방향 신호** — 폐색 조건에서 비주얼 마스킹으로 힘 피드백 의존을 유도하는 패턴이, 비전 배제 원칙의 학습 측면 탐색 방향으로서 크로스폴리네이션 가능성

### (d) 먼저 확인할 점

- **IL 기반·비전 포함** — 플로우 매칭 모방 학습; 비전이 상위 수준 모션 계획에 포함. RL 접촉 안정화 루프와 직접 대응하지 않으므로 동일 힘 교정 인터페이스를 RL 정책에 적용 시 별도 설계 필요
- **제어 주기 미명시** — 컴플라이언트 파지 제어 주기가 System0 요구 고주파 루프에 부합하는지 본문 확인 필요
- **단일 손 특화 성능 미검증** — 실험이 이기종 손 간 전이에 초점; System0 단일 하드웨어 특화 접촉 유지 성능 직접 수치 없음

## 🌱 논문 3 — 인접 분야 픽

**ViTaL: Inference-time Policy Steering via Vision and Touch**
[arXiv:2606.14981](https://arxiv.org/abs/2606.14981) · Yilin Wu, Zilin Si, Zeynep Temel, Oliver Kroemer, Andrea Bajcsy · source: arXiv 키워드 스윕 (tactile + contact + reinforcement learning) · adjacent field: 추론 시점 조향(Inference-time Steering) + 비주오택타일 확산 정책

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15)

### (b) 핵심 기여

- **문제** — 추론 시점 조향(inference-time steering)은 배포 중 생성 정책을 검증·선택하지만, 비전 단독으로는 접촉 집약 조작에서 성공 조건 판별 불충분
- **ViTaL: 비주오택타일 이중 수준(bi-level) 조향 프레임워크**
  - **상위 수준**: 시각 샘플링·검증으로 장기적 행동 모드 선택
  - **하위 수준**: **촉각 유도 확산 편집(tactile-guided diffusion editing)**으로 단기 접촉 요건 충족하도록 행동 시퀀스 정제
- **핵심 혁신** — **텍스트 조건부 촉각 보상(text-conditioned tactile reward)**: 미래 촉각 잠재 공간에서 예측 촉각 시퀀스를 직접 채점; 언어 조건 + 촉각 세계 모델 + 확산 편집 통합
- **실물 성능** — 3개 접촉 집약 과제에서 기본 정책 대비 +51%, 단일 모달 조향 대비 최소 +33%

### (c) 시사점

- **촉각 미래 예측 기반 접촉 검증 개념** — 미래 촉각 잠재 시퀀스 예측으로 현재 행동의 접촉 품질을 사전 평가하는 패턴; System0의 슬립 발생 전 선제 감지 확장 방향 탐색 시 크로스폴리네이션 가능성
- **텍스트 조건부 촉각 보상 → 언어-촉각 정렬 보상 실물 시연** — 접촉 이벤트를 언어로 명세해 촉각 미래 잠재 공간에서 채점하는 방식이 실물에서 작동; 다양한 슬립·파지 유지 시나리오를 언어로 기술하는 보상 설계 방향 탐색 신호

### (d) 먼저 확인할 점

- **비전 포함·비RL** — 상위 수준에 비전 필수; IL 기반 확산 정책의 추론 시점 정제 → P3 비전 배제·RL 루프와 직접 접점 없음
- **고주파 지연 미검증** — 비주오택타일 잠재 세계 모델 + 확산 편집의 실시간 지연이 System0 고주파 접촉 안정화 요구와 양립하는지 미확인
- **슬립 억제·파지 유지 특화 시나리오 미검증** — 접촉 집약 조작 일반 범주 검증; 슬립 억제·파지 후 접촉 유지 특화 실험 없음
