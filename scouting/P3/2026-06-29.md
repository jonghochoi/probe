## 🥇 논문 1 — 우선순위 ★★★

**VibeAct: Vibration to Actions for Contact-Rich Reactive Robot Dexterity**
[arXiv:2606.27344](https://arxiv.org/abs/2606.27344) · (저자 미상, 프로젝트 https://vibeact.github.io) · source: keyword-sweep (in-hand/dexterous + contact + sim2real)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **문제** — 다지 조작에서 접촉 이벤트는 빠르고 국소적이며 시각적으로 가려짐; 압전 마이크는 고대역폭 진동촉각(vibrotactile) 감지 수단이나, 원시 진동·음향 신호를 시뮬레이터에서 충실히 재현하기 어려워 엔드투엔드 Sim2Real 정책 학습에 적용 불가
- **VibeAct 핵심 설계** — 실물 진동촉각 감지와 시뮬레이션 기반 RL을 접촉·슬립의 **물리적 공유 표현(shared physical representation)**으로 연결
  - 다지 손에 압전 마이크 내장 → 텔레오퍼레이션으로 진동·음향 데이터 수집 → 보정된 디지털 클론에서 재생하여 손가락별 접촉·슬립 자동 라벨링
  - 진동촉각 추정기(tactile estimator): 실물 마이크 파형 → 접촉·슬립 예측 학습
  - 조작 정책: 시뮬레이터에서 동일 접촉·슬립 표현으로 직접 학습 → 원시 오디오 시뮬레이션 불필요
- **검증** — 재파지·인핸드 재방향·삽입 포함 5개 접촉 집약 과제에서 고유감각+포인트클라우드 기준선 대비 성능 향상; 지속적 반응 제어 과제에서 슬립 크기(slip-magnitude) 연속 채널이 가장 유용한 관측 채널
- **실물 이전** — 물리 다지 손-팔 플랫폼으로 정책 이전 성공, 배포 성공률 향상 실증
- **신규성** — 진동촉각 물리 표현 공유라는 새로운 Sim2Real 브리징 방식; 음향 시뮬레이션 정확도 요건을 우회하는 최초 접근

### (c) 시사점

- **비전 배제 고대역폭 촉각 입력의 실물 검증** — 압전 마이크 진동촉각이 비전 없이 손가락별 접촉·슬립 연속 추정 제공 가능; 기존 GelSight·정전용량 계열과 다른 하드웨어 경로에서 동일한 비전-배제 원칙 실증
- **슬립 크기 연속 채널 우위** — 이진 접촉 대비 슬립 크기 연속 신호가 반응 제어에 현저히 유리; 슬립 억제 서브루프 설계에서 연속 슬립 크기를 핵심 관측 채널로 우선 고려 근거
- **음향 시뮬레이션 불필요 Sim2Real 경로** — 원시 신호 재현 대신 물리 표현 공유로 Sim2Real 달성; 촉각 Sim2Real 병목을 우회하는 구조적으로 독립적인 새 경로

### (d) 먼저 확인할 점

- **압전 마이크 특화 가정** — GelSight·DIGIT·ReSkin 등 광학·정전용량 계열 촉각 센서와의 직접 비교 미제공; 손 하드웨어 선택에 따라 진동촉각 경로 채택 가능 여부 별도 평가 필요
- **이중 파이프라인 학습 비용** — 추정기 학습에 별도 실물 텔레오퍼레이션 데이터 필요; 데이터 수집 비용과 추정기·정책 공동 최적화 복잡도 사전 평가 필요
- **슬립 억제 특화 시나리오 미포함** — 5과제는 일반 접촉 집약 과제; 파지 후 장기 접촉 유지·슬립 조기 감지 특화 시나리오에서 동일 채널 구성의 유효성 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**TopoRetarget: Interaction-Preserving Retargeting for Dexterous Manipulation**
[arXiv:2606.16272](https://arxiv.org/abs/2606.16272) · (저자 미상) · source: citation-graph (HORA)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **문제** — 인간 손-물체 시연 동작을 다지 로봇 손으로 retargeting할 때 접촉 구조가 무너지면 RL 정책 학습에서 접촉 타이밍·모드가 붕괴됨; 자세(pose)만 맞추는 기존 retargeting은 과제 관련 손-물체 상호작용 위상(topology)을 보존하지 못함
- **TopoRetarget 핵심 설계** — 손·물체 키포인트에 희소 상호작용 그래프(sparse interaction graph)를 구성하고, 거리-가중 Laplacian 변형 + 방향 일관성 + 운동학 제약 + 침투 처리로 접촉 위상 보존 최적화
- **단일 파라미터 세트** — 다양한 retargeting 조건에 재학습 없이 동일 파라미터 적용
- **검증** — ContactPose Dataset: 모든 기준선 대비 접촉 정밀도·정렬 최상; Pen-Spin RL 훈련 성공률 40.6pp 향상; Wuji Hand 하드웨어 제로샷 이전: 큐브 재방향·펜 돌리기 검증
- **신규성** — 접촉 위상 보존 retargeting이 RL 정책 학습에 측정 가능한 영향을 미침을 최초 체계적으로 입증

### (c) 시사점

- **접촉 구조 보존 참조 동작이 RL 성능에 직접 영향** — 데모 기반 RL 설계 시 retargeting 품질이 핵심 변수임을 실험적으로 확인; 참조 동작 품질 관리 중요성 외부 근거 확보
- **Wuji Hand zero-shot 이전 검증** — 참조 동작 접촉 구조 품질 → RL 정책 sim2real 이전 성능 연결 경로 시사; 데모 참조 RL 구조 도입 시 retargeting 단계를 병목 요소로 관리 근거
- **손 형태 독립적 파라미터화** — 새로운 다지 손 형태에 대한 재학습 없이 동일 retargeting 프레임워크 적용 가능성

### (d) 먼저 확인할 점

- **retargeting 도구로서의 성격** — 슬립 억제·접촉 안정화 서브루프 자체가 아닌 RL 학습 데이터 품질 향상 도구; System0 슬립 억제 특화 RL 학습에서도 동일 효과 발생 여부 별도 확인 필요
- **reference-tracking RL 구조 전제** — TopoRetarget이 참조 동작 추적 기반 RL 학습을 전제; System0가 순수 보상 기반 RL로만 설계될 경우 직접 활용 경로 제한
- **정밀 자세 추정 의존** — 손-물체 키포인트 추출에 정밀 자세 추정 전제; 실물 배포 환경에서 키포인트 품질 저하 시 retargeting 보존 효과 감소 가능성
