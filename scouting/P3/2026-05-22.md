## 🥇 논문 1 — 우선순위 ★★★

**Learning Robust Dexterous In-Hand Manipulation from Joint Sensors with Proprioceptive Transformer**
[arXiv:2605.21330](https://arxiv.org/abs/2605.21330) · Senlan Yao, Chenyu Yang, Jaehoon Kim, Aristotelis Sympetheros, Robert K. Katzschmann (ETH Zurich) · source: keyword-sweep (in-hand)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D18](https://img.shields.io/badge/D18-d97706.svg)](#ref-D18)

### (b) 핵심 기여

- **핵심 질문** — 비전도 촉각도 없이 관절 센서(motor encoder 또는 direct joint sensing)만으로 강인한 인핸드 조작 가능 여부
- **구성** — 텐던 구동(tendon-driven) 손의 고유감각(proprioceptive) 정보만 입력으로 쓰는 Proprioceptive Transformer 제안
  - 모터 인코더 vs. 직접 관절 센싱의 우열 체계적 연구
  - 관절 이력에서 환경 정보(contact state, object properties) 추출 방법 연구
- **선행 대비 새로움** — 핀 논문 HORA([arXiv:2210.04887](https://arxiv.org/abs/2210.04887))가 촉각을 교사 관측에 통합하고 RMA로 실환경 이전 달성한 반면, 촉각을 완전히 제거한 상태에서 관절 감지만으로 인핸드 조작 강인성 상한선을 측정한 최초의 체계적 연구
  - Proprioceptive Transformer가 고유감각 시퀀스에서 접촉 상태·객체 파라미터 내재적 추정
  - 텐던 구동 손에서 모터 인코더 신호가 직접 관절 각도보다 풍부한 접촉 정보 함유함을 실험 증거로 제시

### (c) 시사점

- **촉각 필요성 검증 경로** — 관절 감지 단독 충분 여부에 따라 System0 촉각 입력 항목을 소거 실험으로 정당화 또는 재고 가능
  - 관절만으로 슬립 억제·그립 유지에 불충분 시 촉각 포함의 정당성 실험적 확보
- **extrinsics 인코더 참조** — 관절 이력 기반 환경 정보 추정 구조를 teacher-student extrinsics 인코더 입력 설계의 참조점으로 활용 가능
  - 촉각 미사용 extrinsics 인코더 variant를 비교 조건 후보로 검토

### (d) 먼저 확인할 점

- **태스크 특성 차이** — Proprioceptive Transformer는 인핸드 재배향(reorientation)을 주 평가 환경으로 사용
  - System0는 슬립 억제·그립 유지·삽입 유지의 세 이질적 정적(static) 체제가 주 범위 → 지속 변화 접촉 시퀀스와 요구 사항 상이
- **정적 유지 구간 신호 충분성** — 관절 감지만으로 정적 그립 유지 구간에서 슬립 예측에 충분한 신호 존재 여부(접촉력 일정 시 모터 인코더 변화량 식별 가능 수준인지) 시뮬레이터 사전 확인 필요

## 🥉 논문 2 — 우선순위 ★

**KaRMA: A Kinematic Metric for Fine Manipulation Ability in Robotic Hands**
[arXiv:2605.15548](https://arxiv.org/abs/2605.15548) · Martin Peticco, Pulkit Agrawal (MIT) · source: keyword-sweep (grasp)

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D13](https://img.shields.io/badge/D13-d97706.svg)](#ref-D13)

### (b) 핵심 기여

- **구성** — KaRMA(Kinematic Rolling Manipulation Ability), 초기 파지 상태에서 접촉을 유지하며 객체 자세를 얼마나 바꿀 수 있는가를 두 손가락 정밀 핀치(two-finger precision pinch)의 기구학 구름(kinematic rolling) 분석으로 수치화
  - 그립 유지(stable grasp maintenance)의 기구학적 실현 가능 범위를 하드웨어 독립적으로 계산하는 도구
- **선행 대비 새로움** — 선행 손 능력 지표가 정적 파지 안정성(force closure, manipulability) 측정에 그친 반면, 접촉 유지하며 객체 자세를 연속 변화시키는 가용 범위를 구형 테스트 객체의 접촉 구름 운동학 기반으로 처음 정량화
  - 구현 없이 기구학 모델만으로 계산 가능 → 하드웨어 설계 단계 사전 평가 가능
  - 실제 손 하드웨어 측정값과 일치 검증

### (c) 시사점

- **손 능력 상한 사전 계산** — System0 구동 손의 기구학적 그립 유지 범위 상한을 절제 실험 전 미리 계산, RL 정책이 그 상한 대비 몇 %를 실제 활용하는지를 성과 지표로 등록 가능
- **체제 경계 정확화** — 접촉 유지하며 변화 가능한 자세 범위가 System0 개입 기구학적 경계를 명시 → 경계 밖 자세 변화는 System1 처리 영역임을 정량적으로 구분, 향후 regrasp 확장 판단 근거

### (d) 먼저 확인할 점

- **단순화 가정** — KaRMA는 두 손가락 정밀 핀치라는 단순화된 기구학 모델 가정
  - System0 구동 다지(multi-finger) 손은 손가락 수 많고 접촉 형상 복잡 → 두 손가락 등가 근사 오차 발생 우려
- **확장성** — 사용 중 손 모델에 KaRMA 계산이 구현 가능한지, 두 손가락 이상 접촉 기구학까지 확장되는지 우선 확인 필요

## 🌱 논문 3 — 인접 분야 픽

**roto 2.0: The Robot Tactile Olympiad**
[arXiv:2605.21429](https://arxiv.org/abs/2605.21429) · Elle Miller, Jayaram Reddy, Ayush Deshmukh, Trevor McInroe, David Abel, Oisin Mac Aodha, Sethu Vijayakumar (University of Edinburgh / Google DeepMind) · adjacent field: 촉각 강화학습 벤치마크 인프라

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-2ca02c.svg)](#ref-P3) / [![D15](https://img.shields.io/badge/D15-d97706.svg)](#ref-D15) [![D17](https://img.shields.io/badge/D17-d97706.svg)](#ref-D17)

### (b) 핵심 기여

- **위치** — 촉각 기반 강화학습(RL)용 GPU-병렬 벤치마크, 인접 분야 픽 사유는 시뮬레이터 전용(실물 로봇 이전 미포함)
  - 기존 촉각 RL 연구가 단일 방향 과제(주로 재배향) 집중·환경/기준성능 파편화 문제 해결 지향
  - 16-DOF~24-DOF 4종 로봇 형상에서 end-to-end "blind" 조작(비전·상태 정보 없이 고유감각 + 촉각만) 표준화
- **선행 대비 새로움** — 선행 촉각 RL이 개별 환경에서 별개 기준성능 보고한 반면, GPU-병렬 4형상 통합 벤치마크 + 강건하게 조정된 기준 정책을 함께 오픈소스 공개 → 동일 조건 알고리즘 비교 가능
  - Baoding ball 회전 과제에서 현재 최고 성능 대비 1자릿수 빠른 13회전/10초 달성, blind 조작 성능 상한 향상

### (c) 시사점

- **외부 기준선 확보** — 공개된 GPU-병렬 촉각 환경 코드로 System0 PPO 기준성능과 비교 가능한 외부 baseline 확보, 자체 구현 샘플 효율을 업계 기준으로 교차 검증 가능
  - 형상 불일치로 환경 코드 직접 사용은 어려우나, 관측 구성(고유감각+촉각, 비전 없음)·보상 설계 패턴을 참조 구현으로 활용

### (d) 먼저 확인할 점

- **실물 미검증** — 현재 순수 시뮬레이터 벤치마크, Sim2Real 이전 프로토콜 미포함 → 벤치마크 상 고성능의 실물 재현 여부 미확인
- **물리 특성 차이** — System0 Sim2Real 설계를 roto 2.0 환경에 적용 시 시뮬레이터 물리 특성(마찰·접촉 강성) 상이 가능 → 도메인 랜덤화(DR) 파라미터 재조정 전제
