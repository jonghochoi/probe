## 🥇 논문 1

**JEPA4R: Embodied JEPA World Models with 4D Point Planning**
[arXiv:2611.19771](https://arxiv.org/abs/2611.19771) · Jiarui Dong, Zhiheng Liang, Yanjun Li 외 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 11/15** · R3 · N2 · M3 · Real1 · Repro2 — arXiv comment "Code: https://github.com/AIGeeksGroup/JEPA4R"

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 단일 깊이 카메라 점 구름의 잠재 공간에서 예측하고 행동하는 JEPA
- **문제** — 조작이 기대는 미터 단위 3D 기하를 JEPA 세계 모델이 다루지 못하고, 모델이 상상한 내용이 숨겨져 있음
  - 2D 이미지는 기하를 외형·시점과 얽힌 채 암묵적으로 두므로 픽셀 모델이 깊이를 스스로 추정해야 함
  - JEPA 잠재는 재구성이 아니라 예측 가능성으로 학습돼 상상한 3D 장면을 볼 수 없고 디버깅과 실물 안전 점검이 막힘
- **기존 한계** — 기존 JEPA 세계 모델은 2D 입력을 읽고 단기 계획으로만 평가됨
  - LeWM은 픽셀로 학습해 OGBench Cube에서 DINO-WM보다 낮음(74% 대 86%)
  - 점 구름 JEPA는 대체로 행동 없이 인코더만 사전학습하거나 LiDAR 점유를 예측해 기하가 예측·행동 모델까지 닿지 않음
  - 계획이 잘 되는 LeWM 잠재가 정책 학습으로는 잘 이전되지 않는다는 보고가 있고 시뮬레이션 평가에 그침
  - 동결 인코더 모방 학습 벤치마크에는 JEPA 세계 모델이 거의 올라가지 않음
- **핵심 방법** — 점 구름 인코더, 잠재 예측기, 동결 잠재 위의 정책 헤드와 디코더로 구성
  - 같은 시점 이미지와 쌍을 이룬 점 구름을 파라미터를 맞춘 인코더로 읽어 2D JEPA와 같은 궤적에서 비교
  - 행동에 조건화한 예측기가 컨텍스트 프레임에서 잠재 시퀀스를 자기회귀로 생성
  - 동결한 세계 모델 위에 정책 헤드를 학습해 행동을 냄
  - 동결 세계 모델에 붙인 디코더가 상상한 잠재 롤아웃을 4D 점 구름으로 복원
- **차별점** — 예측·계획·행동을 점 구름 잠재 한 공간에서 수행하고 상상을 디코딩해 점검 가능하게 함
  - 2D 이미지 입력 JEPA와 같은 정책 학습 프로토콜에서 짝지어 비교
- **핵심 기여** — 4D 점 계획, 잠재 공간 재구성, 벤치마크와 실물 검증
  - OGBench Cube-Single, Cube-Double, Cube-Triple, Scene에서 픽셀 JEPA 모델 상회
  - CortexBench에서 MetaWorld 98.4%, Adroit Relocate 88.0%로 1위이며 차순위 R3M은 96.0%와 65.3%
  - 디코더가 200 환경 스텝에 걸쳐 평균 점 오차 1.1 cm 이내로 상상한 롤아웃 복원
  - 디지털 트윈에서만 학습해 RealMan RM75-B 팔에서 평행 그리퍼와 다지 손 모두 제로샷 구동
  - 디코더 백본, 점 구름 인코더, 시간 창, 학습 하이퍼파라미터 ablation
- **가치** — 기하를 담은 잠재 예측이 정책 학습에 쓸모 있다는 비교 기준과 상상 내용을 점검하는 도구 제시

### (c) 시사점

- 점 구름 잠재와 픽셀 잠재를 같은 정책 학습 프로토콜에서 맞댄 수치 확보
- 세계 모델을 동결하고 정책 헤드만 붙이는 구성이라 사전학습 예측기 재사용 경로의 참고점
- 디코더로 상상을 직접 볼 수 있어 예측이 정책에 쓸 만한지 점검하는 수단
- 코드가 공개돼 있어 점 구름 잠재 예측 구성을 자체 환경에 붙여 보는 비용 낮음
- 다지 손 실험이 정성 시연 수준이라 접촉 집약적 과제에서의 이득은 근거 없음

### (d) 먼저 확인할 점

- 실물 결과가 과제당 한 번의 실행 장면으로 성공률 수치 없음
- 일부 격차가 50회 시작 추정치의 변동 범위 안(약 ±6점)이라고 부록이 밝혀 작은 차이의 유의성 제한
- 정책 평가가 OGBench와 CortexBench 중심이라 접촉 집약적 조작에서의 결과는 미확인
- 세계 모델과 정책 헤드를 디지털 트윈에서만 학습해 실물 이전 신뢰도는 환경 정합에 의존
- 점 구름 입력이 전제라 깊이 카메라 없는 플랫폼에는 그대로 적용 불가

## 🥈 논문 2

**DexForesight: Grounding Dexterous Policies with Implicit Spatial Foresight**
[arXiv:2611.11166](https://arxiv.org/abs/2611.11166) · Zhongxi Chen, Yi Yang, Xinyi Chen 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 동결 공간 세계 모델의 예측을 정책 잠재에 정렬해 이식
- **문제** — 다지 손 제어에는 손가락과 장면이 행동에 따라 어떻게 변하는지에 대한 공간 예지가 필요
  - 손가락이 카메라에 가려져도 손 기하는 알아야 하고, 장면 깊이만으로는 가려진 손가락이 관측되지 않음
  - 배포 때 깊이 추정이나 미래 생성을 요구하면 제어 단계마다 계산이 늘어남
- **기존 한계** — 기존 월드 액션 모델은 추론 때 미래 이미지·모션·공간 상태를 명시적으로 생성
  - 배포 때 깊이를 쓰는 방식은 온라인 재구성 파이프라인에 의존
  - 미래 전체를 재구성하면 행동 선택과 무관한 질감·배경 세부까지 담을 수 있음
  - WLA는 세계 전문가를 켜고 Cosmos3는 미래 영상과 행동을 함께 생성해 추론 비용이 큼
- **핵심 방법** — 행동 조건 공간 세계 모델을 따로 학습한 뒤 동결하고 정책 질의를 그 질의에 정렬
  - **세계 모델** — 오프라인 장면 깊이, 로봇 기구학 손 기하, 시연 궤적으로 학습하고 3D 손 점 이동과 시각 특징 변화를 함께 예측
  - 순기구학 덕에 카메라에 가려진 손가락의 움직임까지 감독에 포함
  - **정렬** — 정책 질의가 VLM 은닉층을 읽어 동결된 세계 질의와 맞춰지고 그 특징이 행동 전문가를 조건화
  - **배포** — RGB, 언어, 로봇 상태만 쓰고 세계 모델 실행, 깊이, 미래 생성 없음
- **차별점** — 예측 헤드를 정책에 직접 붙이지 않고 동결 세계 모델의 예측 표현을 정책 잠재로 옮김
  - 감독을 행동 조건 손 모션으로 두어 미래 행동 목표나 행동 없는 문맥 질의와 구분
- **핵심 기여** — 방법, 세계 모델 데이터, 시뮬레이션과 실물 결과
  - 60개 과제 약 370시간 시연으로 세계 모델 학습
  - DexJoCo 11개 시뮬레이션 과제 전체 성공률 49.4%에서 60.5%로 상승, 최강 기준선 Fast-WAM보다 9.6점 높음
  - 실물 3개 과제(과제당 20회) 58.3%, WLA 50.0%, GR00T N1.7 48.3%, Cosmos3 30.0%, Fast-WAM 10.0%
  - **직접 예측 헤드 대비** — 손 흐름 헤드 53.1%, 두 헤드 병용 49.5%이고 정렬 방식 60.5%
  - **선형 프로브 오차** — 0.54초 뒤 손 점 변위 13.59 mm에서 10.01 mm로 26.3% 감소
  - 정책 추론 시간 227.4 ms에서 230.4 ms로 3.0 ms 증가, Cosmos3는 16프레임 영상 생성에만 930 ms
- **가치** — 배포 때 세계 모델 없이도 예측 지식을 다지 손 정책에 남기는 경로 제시

### (c) 시사점

- 예측 헤드를 직접 붙이는 방식과 동결 세계 모델 정렬 방식을 같은 정책에서 맞댄 수치 확보
- 행동 조건 유무, 미래 행동 목표, 행동 섞기 대조가 행동 조건화의 효과를 분리해 보여 줌
- 추론 비용 증가가 1.3%라 배포 부담 낮음
- 손 모션을 순기구학으로 만들어 쓰므로 손 중심 정책과 궁합이 좋음
- 코드 공개 없음, 오프라인 깊이 추정과 대규모 시연이 선행 조건

### (d) 먼저 확인할 점

- 코드와 공개 약속 없음, 프로젝트 페이지만 확인됨
- 실물 비교의 WLA와 Fast-WAM은 구조와 학습이 달라 한 변수만 바꾼 통제 비교가 아니라고 저자가 밝힘
- 실물 평가가 3개 과제와 과제당 20회로 표본이 작고 반복 시드 없음
- 실물 58.3%는 절대 수준이 높지 않고 최강 기준선과 8.3점 차이
- 오프라인 깊이를 빼면 시뮬레이션 10.8점, 실물 15.0점 하락해 깊이 추정 품질에 의존

## 🥉 논문 3

**ForceWAM: Decoupling Future and Response Learning from Demo and Play Data for Contact-Rich Manipulation**
[arXiv:2610.18852](https://arxiv.org/abs/2610.18852) · Zijun Xu, Wendi Chen, Xinkai Wang 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — arXiv comment "Project page: https://force-wam.github.io/" — 프로젝트 페이지만 있고 코드 문구 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 영상·힘 미래를 예측하는 세계 모델과 역동역학으로 접촉을 실행
- **문제** — 접촉 집약적 과제는 움직임만이 아니라 상호작용 힘이 어떻게 변하는지로 성패가 갈림
  - 시연은 성공 실행만 보여 행동에 따라 힘이 어떻게 반응하는지의 범위가 좁음
  - 과제와 무관한 놀이 데이터는 더 넓은 접촉 경험을 주지만 과제 목표를 담지 않음
- **기존 한계** — 끝단 힘 인지 학습기는 두 질문을 한 과제 감독 사상에 묶음
  - 과제를 진전시키는 전이가 무엇인지와 어떤 행동이 그 전이를 실현하는지를 함께 학습
  - 영상 계획과 역동역학 방식은 시각 미래만으로는 원하는 접촉 힘의 변화를 지정하지 못함
  - 힘·촉각 인지 모델은 접촉 신호 예측을 반응형 제어에 쓰는 가치를 보였으나 두 데이터 출처를 나눠 쓰지는 않음
- **핵심 방법** — 시연으로 힘 세계 모델을, 시연과 놀이로 역동역학 모델을 학습
  - **힘 세계 모델**(ForceWM) — 성공 시연으로 미래 영상과 6축 힘·토크 궤적을 함께 생성
  - **역동역학 모델**(IDM) — 과제와 놀이 구간에서 현재 관측과 기록된 시각·힘 미래를 행동에 사상
  - **배포** — 세계 모델이 생성한 미래가 기록된 미래를 대신하고 IDM이 새로 측정한 힘 피드백으로 행동 청크 안에서 반응적으로 갱신
- **차별점** — 접촉 실행을 시각·힘 미래에 조건화한 역동역학으로 정식화해 서로 다른 데이터가 서로 다른 지식을 감독
  - 놀이 구간은 과제를 끝내지 않아도 행동과 접촉 결과가 기록돼 있으면 감독이 됨
- **핵심 기여** — 방법 정식화, 놀이 데이터 효과, 미래 조건화 ablation
  - 실물 힘 조절 슬라이딩, 외란 유무의 박스 뒤집기, 링 배치에서 평균 성공률 85–95%이며 세계 모델링과 반응형 기준선 상회
  - 놀이 에피소드 추가로 성공률 15–45점 상승, 슬라이딩 40%에서 85%, 박스 뒤집기 75%에서 95%, 외란 있는 뒤집기 65%에서 85%
  - 시각·힘 미래를 함께 조건화하면 시각 미래만 쓸 때보다 뒤집기, 외란 뒤집기, 하노이, 슬라이딩에서 55점, 55점, 20점, 70점 높음
  - 미래 조건화가 없는 경우보다 40–70점 높고 어느 한 미래만으로는 일관된 개선 없음
  - 미래 조건화 증강 ablation
- **가치** — 과제 데이터와 놀이 데이터가 각기 다른 접촉 지식을 준다는 분업 구조와 힘 미래의 쓸모를 실물에서 제시

### (c) 시사점

- 픽셀 미래에 힘 미래를 더해야 이득이 난다는 같은 조건의 실물 비교 수치
- 시각 미래만으로는 미래 조건화 이득이 일관되지 않아 픽셀 예측의 접촉 과제 한계를 뒷받침
- 세계 모델이 목표 미래를 내고 역동역학이 행동으로 옮기는 분업이 목표 공급 구성의 참고점
- 놀이 데이터가 접촉 반응 학습에 15–45점을 더해 데이터 수집 계획의 근거
- 힘·토크 센서가 있는 플랫폼이 전제이고 코드 공개 없음

### (d) 먼저 확인할 점

- 코드 문구 없이 프로젝트 페이지만 확인됨
- 반복 시드와 분산이 확인되지 않아 15–45점 이득 외의 작은 차이는 유의성 미확인
- 단일 모달리티 미래의 비일관 이득은 저자의 학습·배포 설정 안에서만 성립
- 힘·토크 입력이 필요해 힘 센서 없는 손에는 그대로 옮길 수 없음
- 과제가 슬라이딩, 뒤집기, 링 배치로 한정돼 다지 손 접촉 과제로의 이전은 미확인
