## 🥇 논문 1

**WiTac: Wrist-Informed Tactile Representations for Contact-Rich Manipulation**
[arXiv:2611.21057](https://arxiv.org/abs/2611.21057) · Haotian He, Yiyang Chen, Congsheng Xu 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 프로젝트 페이지만 있음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 촉각을 손목 시야와 먼저 융합해 손가락별 접촉 토큰 생성
- **문제** — 같은 손가락 하중이라도 손·물체·목표의 배치에 따라 필요한 교정 동작이 달라 국소 촉각 변형만으로는 접촉 해석이 모호
  - 배터리를 슬롯에 넣을 때 비슷한 하중이 서로 다른 정렬 상태에서 나타남
  - 손목 카메라가 손, 쥔 물체, 근처 목표 기하를 보여 접촉 해석의 공간 기준을 제공한다는 진단
- **기존 한계** — 기존 시각-촉각 설계는 촉각을 시각과 따로 다루거나 시각 쪽을 조정하는 데 그침
  - GR00T와 π0.5 같은 범용 VLA는 카메라 영상을 받지만 파지·접촉 상태를 접지할 촉각과의 사전 융합이 없음
  - 독립 촉각 특징을 시각 스트림 옆에 공급하는 방식은 국소 촉각을 주변 시각 기하에 접지하지 못함
  - 촉각으로 시각 특징을 변조하는 방식과 시각이 예측한 촉각의 이산 잔차를 부호화하는 방식은 손목 시각 맥락 안에서 세밀한 촉각을 보존하는 연속 접촉 표현을 직접 만들지 못함
- **핵심 방법** — 촉각 이력·손 기구학·손목 영상을 정책에 넣기 전에 융합하는 사전학습 인코더와 동결 후 주입
  - **촉각 토큰** — 손가락마다 8프레임 촉각 이력을 요약하고 로봇 상태와 손목 기준 지문 위치 기구학으로 공간 앵커링
  - **교차 어텐션 융합** — 손목 영상 패치 특징에 질의해 10개 손가락 수준 접촉 토큰 형성
  - **사전학습 목표** — 접촉 상태·이력 복원, 마스킹된 손목 특징 복원, 행동 조건부 렌치 응답 예측을 함께 지도
  - **정책 주입** — 동결한 인코더를 경량 게이트 교차 어텐션 인터페이스로 VLA의 기존 시각·언어·상태 입력 옆에 연결
- **차별점** — 촉각 특징을 정책에 따로 공급하지 않고 손목 시각과 먼저 융합해 정책에 주입
  - 손가락 수준 토큰을 유지한 채 시각 맥락을 교차 어텐션으로 합치는 설계
- **핵심 기여** — 사전학습 접촉 인코더와 실물·표현 분석 결과
  - **인코더** — SharpaDex v1.0의 약 300시간 동기화 다지 조작 데이터로 사전학습
  - **실물 4개 과제** — 배터리 삽입, 그릇 닦기, USB 재삽입, 캐비닛 열기를 Sharpa North 양팔 로봇에서 과제당 200개 시연으로 학습, 방법·과제당 20회 시행
  - **VLA 비교** — 비전 단독 기본 정책 대비 평균 성공률 GR00T N1.7 +28.8%, π0.5 +15.0%
  - **손목 영상 효과** — 손목 정보 없는 변형 WiTac-NW 대비 GR00T +18.8%, π0.5 +7.5%
  - **사전학습 ablation** — GR00T 기준으로 사전학습 없는 변형은 평균 53.8%, 사전학습 포함 66.3%
  - **표현 분석** — 접촉 복원 정확도, 과제-접촉 동시 판별, 촉각 잡음 아래 특징 안정성, 행동 방향 판독 모두 손목 정보 없는 부호화보다 우위
- **가치** — 다지 손 촉각을 시각 기하에 접지한 접촉 표현을 사전학습 모듈로 떼어 여러 VLA에 연결하는 경로 제시

### (c) 시사점

- 다지 손 촉각 입력을 손목 시각과 먼저 융합하는 설계의 실물 정량 비교 근거
  - 손목 정보를 뺀 동일 구조 변형과 두 VLA 백본에서 비교해 융합 효과만 분리
- 손가락별 접촉 토큰 위에 시각 맥락을 얹는 구조
  - 손가락 귀속을 유지한 채 융합하는 후보로 촉각 입력 설계의 기준점
- 동결 인코더를 게이트 교차 어텐션으로 연결하는 구조
  - 정책 본체를 바꾸지 않고 촉각을 붙이는 경량 경로, 도입 비용 낮음
- 사전학습 유무 ablation의 12.5%p 차이
  - 촉각 인코더 사전학습에 쓸 다지 손 데이터 규모를 가늠할 근거

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 신호 없음, 프로젝트 페이지만 존재
- 사전학습 데이터 SharpaDex v1.0과 Sharpa North·Sharpa Wave 하드웨어 전제로 다른 손·센서에서의 재현 경로 불명확
- 과제당 20회 시행에 반복 시드 서술 없음
- 비교 대상 중 독립 촉각 정책 두 종과 시각-촉각 인코더 한 종은 사전학습 데이터나 주입 방식이 달라 융합 효과만의 비교는 아님
- 손목 카메라 시야가 가려지는 상황에서의 성능은 본문 확인 필요

## 🥈 논문 2

**ActGaze: Learning Action-Grounded Gaze through Counterfactual Visual Interventions for High-Precision Manipulation**
[arXiv:2609.28955](https://arxiv.org/abs/2609.28955) · Jinxuan Zhu, Jiaheng Wang, Chao Tang 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D1SX](https://img.shields.io/badge/D1SX-d97706.svg)](#ref-D1SX)

### (b) 논문 요지

- 행동 손실 변화로 정책이 볼 영역의 지도 신호 생성
- **문제** — VLA의 시각 주의가 과제와 무관한 영역으로 흩어져 고정밀 조작에서 실패
  - 삽입·조립처럼 일부 영역만 현재 행동에 결정적인 과제에서 두드러짐
  - 표준 end-to-end 학습은 행동 예측만 지도하고 어디를 볼지는 직접 제약하지 않음
- **기존 한계** — 이미지 공간 지도를 주는 기존 방식은 추가 공간 지도 확보 비용이 큼
  - 사람 시선 기록, 수동 마스크·키포인트 주석, 외부 모델이 만든 의사 레이블에 의존
  - 추가 노력이 필요해 널리 쓰기 어렵다는 지적
- **핵심 방법** — 학습된 VLA를 반사실 개입으로 탐침해 얻은 영역 중요도로 시선 헤드를 학습하고 VLA 주의를 그에 정렬하는 두 단계
  - **반사실 시각 개입** — 한 영역의 시각 증거를 지우고 나머지는 두었을 때 행동 예측 손실이 얼마나 커지는지 측정
  - **계층적 탐침** — 카메라 시점과 이미지 영역 단위로 개입해 중요 영역 추정
  - **행동에서 시선으로 증류** — 손실 증가가 큰 영역을 지도 신호로 다시점 시선 헤드 학습
  - **시선에서 행동으로 정련** — 학습된 시선을 VLA의 행동 어텐션에 정렬
- **차별점** — 공간 지도를 외부 주석이나 접지 모델 없이 정책 자신의 행동 목적함수에서 도출
  - 위 세 가지 외부 지도원을 모두 쓰지 않음
- **핵심 기여** — 방법과 실물 결과
  - **ActGaze** — 개입에 따른 행동 예측 변화로 공간 지도를 만드는 시선 학습 방법
  - **단계 학습** — 반사실 개입과 공간 지식 증류, 정책 정련을 잇는 단계 학습
  - **실물 4개 과제** — 빨대 삽입, 호스 삽입, 레고 조립, 커넥터 결합, 밀리미터에서 서브밀리미터 정밀도
  - **성공률** — 기본 VLA 평균 77.0%에서 91.5%로 상승
  - **외부 접지 대비** — CoT Grounding보다 32.5%p, Implicit Grounding보다 25.0%p 높은 평균 성공률
  - **ablation** — 반사실 지도를 빼면 빨대 삽입과 레고 조립 평균이 92.5%에서 37.5%로 하락
- **가치** — 주석 없이 정책 스스로 어디를 읽을지 지도하는 경로 제시

### (c) 시사점

- 읽을 영역 선택을 외부 라벨 없이 행동 손실에서 얻는 후보
  - 학습 때만 주의를 정렬하는 방식이라 추론 경로 변경 없음
- 접촉 직전 정밀 정렬 과제에서 시각 주의 오배치를 줄이는 방법
  - 주석 비용 없이 기존 VLA 위에 얹는 정련 단계로 도입 비용 낮음
- 반사실 개입이 시점과 영역 단위로 중요도를 주는 구조
  - 어느 카메라와 어느 영역이 행동에 기여하는지 진단하는 용도로도 사용 가능

### (d) 먼저 확인할 점

- 코드 공개 신호 없음
- 저자 한계 서술 — 개입이 물리 환경이 아니라 시각 수준의 반사실이고 분포 이동의 영향을 받아 강한 인과 효과가 아닌 관련성 추정으로 해석
- 지도가 초기 정책에서 나오므로 정책의 편향이 증류 뒤에도 남아 추가 개선을 제한
- 평가가 다지 손이나 촉각 없는 팔 조작 4개 과제
- 비교한 시각 접지 기법 두 종 외에 어디를 읽을지 직접 고르는 구조와의 비교는 확인되지 않음

## 🥉 논문 3

**On the Utility of Pre-Trained Visual Representations for Policy Learning of Contact-Rich Insertion Tasks**
[arXiv:2611.17631](https://arxiv.org/abs/2611.17631) · Leon Kim, Dinesh Jayaraman, Michael Posa · arXiv preprint · source: keyword-sweep

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P3](https://img.shields.io/badge/P3-d6f3d5.svg)](#ref-P3) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 삽입 과제에서 범용 시각 표현과 접촉 중심 표현을 통제 비교
- **문제** — 로봇에 어떤 사전학습 시각 표현이 맞는지 합의가 없고 접촉 집약적 조작에서는 더 불분명
  - 기존 연구가 넓지만 성긴 과제 분포를 다뤄 결론이 갈리고 과제·설정 의존성이 크다는 진단
  - 접촉 집약적 과제는 강체 접촉의 민감한 동역학, 끼임 같은 회복 어려운 실패, 접근 시 가림으로 시각 피드백이 사라지는 문제를 가짐
- **기존 한계** — 넓은 과제 군을 훑는 선행 비교는 과제 의존성의 크기를 가림
  - 선행 연구는 접촉 집약적 과제가 접촉 표현에서 더 이득을 볼 것이라는 잠정 결론을 냄
  - 촉각 또는 근접 정보를 정책에 넣는 시도들이 있으나 표준 시각 사전지식 대비 가치는 불분명
- **핵심 방법** — 거의 같은 삽입 과제 두 개에 가림과 물리 허용오차를 통제 변인으로 가해 표현별 정책 성공률 비교
  - **정책** — ResNet-18 인코더가 U-Net 노이즈 제거기를 조건화하는 확산 정책
  - **기준선** — 처음부터 학습, DINOv2, Theia, 분할 마스크
  - **접촉 중심 특징** — 깊이 영상에서 접촉 영역 확률 열 지도, 접촉까지 거리 지도, 법선 지도를 추정하는 개념 증명 모델
  - **과제** — 시뮬레이션 펙인홀과 책 삽입, 실물 책 삽입 유사 과제
- **차별점** — 넓은 과제 분포 대신 좁은 삽입 영역에서 변인을 통제해 과제 의존성을 드러냄
  - 시점 이동으로 가림을, 공차로 물리 허용오차를 조절
- **핵심 기여** — 세 가지 결론
  - **표현 순위의 과제 의존성** — 최고 표현이 과제마다 달라 Theia는 실물 과제에서 최고였으나 시뮬레이션 과제에서는 기준선 수준
  - **분할 마스크** — 한 시뮬레이션 과제에서 최고였으나 가림이 들어가면 성능 저하
  - **정답 접촉 정보** — 모든 설정에서 다른 표현보다 일관되게 우수
  - **추정 접촉 특징** — 심한 가림이나 실물 센서 잡음에서는 정답 성능에 못 미침
  - **가림이 작을 때** — 분할 마스크도 접촉 특징만큼 좋은 결과
- **가치** — 접촉 집약적 조작에서 표현 선택에 정해진 처방이 아직 없고 접촉 지각 개선이 과제임을 통제 실험으로 제시

### (c) 시사점
