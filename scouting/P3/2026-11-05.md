## 🥇 논문 1

**FloMo: 3D Scene Flow as a World Action Model Intermediate for Learning from Human Video**
[arXiv:2611.05062](https://arxiv.org/abs/2611.05062) · Jeremy Collins, Namra Patel, Ayush Agarwal 외 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 프로젝트 페이지만

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC)

### (b) 논문 요지

- 영상 대신 3D 장면 흐름을 예측 목표로 삼은 월드 액션 모델
- **문제** — 사전학습 영상 생성 모델의 움직임 지식을 로봇 액션으로 옮기는 데 어떤 예측 목표가 가장 직접적인지
  - 영상은 질감·조명·배경이 달라도 같은 액션을 뜻하는 고엔트로피 신호
  - 픽셀을 예측하는 월드 액션 모델(WAM)은 액션과 무관한 외형에 용량을 씀
- **기존 한계** — 기존 WAM은 모두 미래 픽셀을 예측 목표로 공유
  - 영상 예측을 함께 학습하는 DreamZero와 희소한 2D 포인트 트랙을 중간 표현으로 쓰는 AMPLIFY가 가장 가까운 대안으로 비교됨
  - 영상 목표(VMA, VA 변형)와 2D 트랙 모두 이동 물체·과제·동작 분포 변화에서 성능 하락
- **핵심 방법** — 3D 장면 흐름을 RGB 이미지로 렌더링해 사전학습 영상 VAE로 인코딩하고, 영상과 같은 잠재 공간에서 장면 흐름과 액션 토큰을 플로우 매칭(flow matching)으로 예측
  - 백본은 Wan 2.2 5B DiT, 새 토크나이저 없이 백본만 미세조정
  - 액션 라벨 없는 에고센트릭 인간 영상(EgoVerse 약 81시간)과 액션 라벨 있는 양팔 YAM 원격조작 데이터를 함께 학습
- **차별점** — 예측 목표를 픽셀에서 카메라 이동에 무관한 3D 움직임으로 교체
  - 영상 목표를 움직임 옆에 추가하면 도움이 아니라 간섭으로 작용한다고 주장
- **핵심 기여** — 움직임 목표가 영상 목표보다 낫다는 실물 로봇 비교와 인과 분석
  - 분포 내 실물 3개 과제(과제당 15회) 평균 성공률 FloMo 91%, VMA 51%, VA 40%
  - 분포 밖 실물 3개 조건(조건당 10회) 평균 성공률 FloMo 60%, AMPLIFY 20%, DreamZero 20%, VMA와 VA 각 7%
  - 인간 영상 제거 시 분포 밖 평균 성공률 60%에서 7%로 하락(조건당 5회)
  - RoboTwin 5개 과제(과제당 100회, Easy 설정) 평균 FloMo 63.6%, π0.5 44.8%, FAST-WAM 41.0%, BC 19.2%
  - 정답 미래를 조건으로 준 역동역학 프로브에서 액션 데이터 1% 시 움직임 조건이 영상 조건보다 액션 오차 약 22% 낮음, 10% 이상에서는 격차 1–2%로 수렴
  - 액션 쿼리 어텐션이 움직임 토큰에 영상보다 약 3배 쏠림
- **가치** — 영상 사전학습의 이득이 예측 목표가 아니라 백본 가중치에 있음을 보이고, 액션 라벨 없는 인간 영상을 로봇 정책으로 옮기는 중간 표현의 후보 제시

### (c) 시사점

- 잠재 예측 vs 픽셀 예측을 실물에서 직접 맞댄 드문 비교
- 영상 목표를 함께 두면 성공률이 내려간다는 결과가 픽셀 예측 병행 구성의 비용 근거
- 인간 영상 제거로 분포 밖 성공률이 크게 하락, 에고센트릭 인간 영상을 쓰는 방향의 근거
- 3D 흐름 예측은 접촉 기하를 직접 담는 쪽이라 접촉 집약적 과제와 궁합이 좋음
- 오프라인 장면 흐름 추출 비용이 도입 시 핵심 부담

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 약속 없음, 재현은 프로젝트 페이지 자료에 한정
- 분포 밖 평가는 조건당 10회, 인간 영상 제거 실험은 조건당 5회라 표본이 작음
- 실물 평가가 양팔 YAM 한 플랫폼에 한정
- 장면 흐름을 전면 카메라 한 대로만 예측해 대상이 가려지면 움직임 추정 저하
- 예측한 움직임과 액션이 어긋나는 경우가 있고 추적기 잡음이 학습 목표에 섞임
- 모든 클립에 오프라인 장면 흐름 추출 단계 필요

## 🥈 논문 2

**WorldBridge: Bridging Video and Action for Task Generalization in World Action Models**
[arXiv:2610.40748](https://arxiv.org/abs/2610.40748) · Jun Cen, Yubo Guo, Hao Li 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 프로젝트 페이지만

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 영상 일반화와 액션 일반화를 분리해 과제 전이를 측정한 월드 액션 모델
- **문제** — 학습 과제 밖의 새 과제를, 해당 로봇 시연이 적거나 없어도 수행하는 과제 일반화
  - 물체 배치·시점·조명 변화에 대한 강건성과 달리, 원래 학습 과제를 넘어서는 행동이 필요
- **기존 한계** — 기존 WAM 연구는 영상 선행 지식의 이점을 보였으나 영상 감독과 액션 감독이 전이에 각각 얼마나 기여하는지는 분리하지 않음
  - DreamZero는 영상 선행 지식으로 미지 과제 실행과 영상 전용 시연 전이를 보임
  - Zero-WAM은 문맥 내 인간 영상 안내로 과제 일반화를 탐색
  - 예측한 영상이 맞아도 이를 실행 가능한 액션으로 옮기는 접지가 부족할 수 있음
- **핵심 방법** — 영상 전문가와 액션 전문가를 분리하고 구조적 어텐션 마스크로 연결해 결합 플로우 매칭(flow matching)으로 학습
  - Mixture-of-Transformers 구조, 관측 문맥 → 미래 영상 표현 → 액션 예측으로 흐르는 단방향 정보 경로
  - 단기·장기 두 시간 규모의 시각 메모리와 액션 포싱(청크 내 액션마다 독립 노이즈 수준 부여)
  - 로봇 궤적과 에고센트릭 손 궤적을 공유 46차원 액션 표현으로 표준화하고, 차원별 유효 마스크로 부분 감독 유지
- **차별점** — 새 과제의 영상만 추가하는 경우와 과제당 시연 1개를 더하는 경우를 분리해 영상 감독과 액션 감독의 기여를 따로 측정
- **핵심 기여** — 과제 전이의 분해 실험, 모델, 데이터 파이프라인, 시뮬레이션과 실물 평가
  - RoboTwin 2.0 분포 밖 과제 성공률: 분포 내 영상·액션만 25.07%, 분포 밖 과제 영상 추가 55.90%, 과제당 액션 시연 1개 추가 70.70%
  - 시뮬레이션 평균 성공률 RoboTwin 2.0 96.23%(전체 데이터), 클린-랜덤 설정 80.9%, RoboCasa GR1 TableTop 82.8%, DOMINO Level-1 57.6%
  - 실물은 AgiBot G2와 ARX AC-1 두 플랫폼에서 평가, G2에서 꽃꽂이 70%와 컵 걸기 85%(π0.5는 65%와 75%), AC-1에서 책 담기 80%와 나사 분류 55%
  - 동일한 사전학습 체크포인트를 플랫폼별로 미세조정
- **가치** — 영상 범위 확대가 기존 역동역학 능력을 통해 과제 전이를 만들고 소량의 액션 감독이 이를 보강한다는 설명 틀 제시

### (c) 시사점

- 액션 라벨 없는 영상이 과제 전이의 큰 몫을 낸다는 정량 근거
- 액션 조건 없는 영상 감독과 소량 액션 감독을 나눈 분해 설계가 액션 조건화 방식 비교의 참고점
- 에고센트릭 손 궤적을 공유 액션 공간에 편입한 데이터 처리 방식이 손 중심 데이터 계획과 맞닿음
- 영상 전문가와 액션 전문가 분리 구조는 액션 전문가 보존 쪽과 호환

### (d) 먼저 확인할 점

- 25.07% → 55.90% → 70.70% 분해는 시뮬레이션 RoboTwin 2.0 결과이며 실물에서 같은 분해는 미확인
- 실물 비교 기준선이 π0.5 위주이고 시드 분산이나 한계 진술은 확인되지 않음
- 코드·체크포인트 공개 약속 없음
- 최고 성능 주장은 비교 대상으로 고른 방법 사이에서만 성립
- 메모리와 액션 포싱의 기여는 별도 ablation 표로만 확인 가능

## 🥉 논문 3

**How Much Can Best-of-N Help a World Action Model? Measuring Selectable Headroom and Realizing It in Closed Loop**
[arXiv:2610.37196](https://arxiv.org/abs/2610.37196) · Haojia Gao, Yue Cao, Yumin Liu 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 9/15** · R3 · N2 · M3 · Real0 · Repro1 — 본문 §1 "We package the protocol and the branching data as HeadroomBench (Sec. 6), which will be publicly released"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 월드 액션 모델의 Best-of-N 선택 이득 상한을 재측정하고 실현한 연구
- **문제** — 후보 액션 청크를 여러 개 뽑아 상상한 미래로 고르는 테스트 시점 선택이 WAM에서 얼마나 이득을 줄 수 있는지
  - 이득의 상한은 선택기와 무관하게 후보 풀에서 최선 후보가 실제로 얼마나 나은가(선택 가능 여유)로 정해짐
- **기존 한계** — 후보를 한 번씩만 실행하는 기존 반사실 분기 측정이 여유를 과대 추정
  - 이후 모든 정책 질의가 무작위라서 최선 결과 후보는 연속 과정이 운 좋게 풀린 후보를 일부 포함(optimizer's curse)
  - 학습한 가치, 이미지 유사도, VLM 판단은 이 이득을 거의 회수하지 못한다고 기존 연구가 보고
- **핵심 방법** — 비트 단위 재현 가능한 시뮬레이터 스냅샷에서 후보마다 여러 번 연속 실행하는 탈잡음 반사실 프로토콜
  - 일부 연속 실행으로 선택하고 다른 연속 실행으로 채점하는 보류 오라클, 분산 분해, 공통 난수
  - 이 측정을 바탕으로 실패 게이트(정책 청크를 벗어날지 결정)와 순위 학습기(어디로 갈지 결정)를 결합한 선택기 구성
- **차별점** — 후보당 연속 실행 1회 대신 여러 번 실행해 후보 효과와 무작위 효과를 분리
  - 사전 등록한 검정으로 결과를 뒷받침
- **핵심 기여** — 네 개 WAM, 두 벤치마크, 10만 회 넘는 분기 롤아웃 기반의 측정 결과
  - 단일 연속 오라클 12.3점 이득 중 연속 실행 3회 관측 선택기는 새 연속에서 9%만 실현, 후보별 결과 변동의 98%가 연속 시드를 바꾸면 다시 뽑힘
  - 후보당 연속 17회로 본 선택 가능 비중은 세 WAM에서 24%–66%
  - 원래 샘플은 거의 같아 여유가 거의 없고, 로봇 축 방향으로 정책 청크를 옮긴 제안은 최대 16점 여유 생성
  - 액션 조건화 상상을 가진 두 WAM에서 상상한 미래가 실제 미래와 검출 가능한 손실 없이 후보 결과 정보를 담음, Cosmos Policy의 가치 헤드는 이를 쓰지 못함
  - 보류 에피소드 폐루프 성공률 76.9% → 81.6%, 미지 과제 62.6% → 69.8%
  - 프로토콜과 분기 데이터를 HeadroomBench로 공개 예정
- **가치** — 테스트 시점 연산을 어디에 쓸지 정하는 구체적 처방 제시, 선택 전에 얻을 수 있는 이득을 미리 추정하는 방법

### (c) 시사점

- 상상한 미래가 후보 결과를 가려낸다는 측정이 월드 모델을 평가·선택에 쓰는 역할의 근거
- 정책 학습 보조로 쓰는 현재 방향과 다른 역할이라 비교 기준점으로 유용
- 기본 샘플링의 선택 여유가 거의 없다는 결과가 단순 Best-of-N 도입의 기대 이득을 낮춤
- 이득의 측정 프로토콜 자체가 도입 전 사전 검증 도구

### (d) 먼저 확인할 점

- 평가가 LIBERO-Plus와 RoboCasa 시뮬레이션에 한정, 실물 결과 없음
- 물리 로봇에서는 상태를 정확히 복원할 수 없어 같은 분기 프로토콜 적용이 한계로 명시됨
- HeadroomBench와 코드는 공개 약속만 있고 저장소 주소 없음
- 폐루프 이득은 4.7–7.2점 수준으로 크지 않음
