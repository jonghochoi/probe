## 🥇 논문 1

**JEPA Policy: Diffusion-Free Imitation Learning via Paired Action and Future Representation Prediction**
[arXiv:2609.09630](https://arxiv.org/abs/2609.09630) · Jie Xu, Kangjin Yu, Ziyi Jin 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — arXiv comment "Code: https://github.com/jiejie567/JEPA-Policy"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- 행동과 미래 표현을 한 트랜스포머에서 함께 예측하는 확산 없는 모방 학습
- **문제** — 행동 라벨만 지도하는 행동 복제가 그 행동이 만드는 미래 상태를 제약하지 못함
  - 시연 구간은 전문가 행동과 그 뒤 관측된 미래라는 정렬된 라벨 두 개를 주지만 표준 행동 복제는 행동만 사용
  - 관측만으로 미래를 회귀하면 같은 장면에서 갈라지는 서로 다른 결과를 평균내는 모호성 존재
- **기존 한계** — 확산 정책, 순수 잠재 JEPA, 분리 분기 JEPA 모두 행동과 미래의 결합이 약함
  - Diffusion Policy — 반복 디노이징으로 결정 한 번에 네트워크를 N회 호출, 목적함수가 행동이 닿는 미래를 제약하지 않음
  - 순수 잠재 미래 JEPA — 행동 지도와 EMA 타깃 인코더 같은 붕괴 방지 장치가 없어 표현 붕괴 가능
  - ACT-JEPA — 컨텍스트 인코더는 공유하나 예측기·디코더 분기가 나뉘어 행동 경로와 미래 경로의 결합이 느슨
- **핵심 방법** — 행동 토큰과 미래 표현 토큰을 하나의 공유 트랜스포머에 두고 두 번의 순전파로 정제
  - MIP(minimal iterative policy)의 coarse-to-refined 2단계 예측을 행동과 미래 표현의 동시 생성으로 확장
  - 두 토큰이 모든 층의 셀프 어텐션에서 서로 보여 미래 목적이 행동 생성 표현을 직접 형성
  - 미래 타깃은 같은 인코더가 만든 표현에 stop-gradient만 적용, EMA·동결 인코더·분산–공분산 정규화 없음
  - 시각 인코더는 무작위 초기화 후 정책과 end-to-end 학습
  - 실행 후 실제 미래 표현과 예측 표현의 오차를 롤아웃 진단 신호로 사용
- **차별점** — 행동 지도 자체가 미래 표현 예측의 붕괴 방지 제약으로 작동
  - 표현이 붕괴하면 물체 위치·접촉 상태 구분이 사라져 행동 예측 오차가 바로 상승한다는 논리
  - 듀얼 브랜치와 그래디언트 라우팅 통제로 이득이 보조 예측 헤드가 아닌 공유 구조 덕임을 분리
- **핵심 기여** — 방법, 확산 없는 2단계 예측기, 붕괴 방지 논거, 배포 시 진단의 4건
  - 시뮬레이션 9개 과제 평균 성공률 MIP 77.4에서 83.0으로 +5.6, Diffusion Policy 75.1 대비 9개 과제 모두 우위 — 30회 평가 중 최고 체크포인트 기준, 시드 3개
  - MIP 모델 지연에 0.29ms만 추가
  - 실물 5개 과제 630 에피소드에서 같은 풀링 순위
  - 표현 붕괴 감사에서 행동 지도 하에 완전한 붕괴 없음
  - 미래 예측 오차가 과제 조건부 실패 순위 신호를 제공
- **가치** — 반복 생성 샘플링 없이 저지연 시각운동 모방 학습에 미래 표현 지도를 얹는 실용 경로 제시

### (c) 시사점

- 보조 미래 예측의 이득이 공유 구조에서 나온다는 통제 증거
- **판단 근거** — 듀얼 브랜치·그래디언트 라우팅 대조에서 미래 지도가 행동 표현을 직접 형성할 때 이득이 확인됨
- **설계 함의** — 보조 예측 헤드를 백본에 붙일 때 헤드를 분리하기보다 행동·미래 토큰이 같은 어텐션을 쓰게 두는 선택지가 비교 대상
- **도입 비용 낮음** — 추가 지연 0.29ms, 추가 주석 불필요, 코드 공개
- **진단 활용** — 예측 오차를 배포 시 실패 모니터링 신호로 재사용할 여지

### (d) 먼저 확인할 점

- **결정론적 회귀** — 다중 모드 미래를 모델링하지 않으며 저자도 한계로 명시
- **최고 체크포인트 보고** — 마지막 체크포인트 기준으로 MIP 9개 과제 평균이 77.4에서 62.5로 하락, 절대 수준은 낙관적
- **Tool Hang 편중** — Diffusion Policy 대비 마진 중 상당 부분이 한 과제 몫, 제외하면 평균 차 +5.4
- **단일 풀링 임베딩** — 미래 타깃이 패치 시퀀스가 아닌 전역 임베딩 하나라 접촉 부위 같은 국소 예측과 거리 있음
- **사후 진단** — 오차는 미래 도달 후에야 계산되어 행동 실행 자체를 막지 못하고, 전용 모니터와의 직접 비교는 향후 과제

## 🥈 논문 2

**LeWAM: End-to-End World and Action Modeling with JEPAs**
[arXiv:2610.12818](https://arxiv.org/abs/2610.12818) · Minghao Fu, Tavis Siebert, Eryk Halicki 외 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — §5 "The project website and code repository are linked on the first page."

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 표현·잠재 동역학·확률적 정책을 한 단계로 학습하는 JEPA
- **문제** — 잠재 세계 모델로 제어하려면 별도 온라인 솔버나 사후 학습 행동 예측기가 필요
  - 기존 JEPA 파이프라인은 시각 표현과 행동 조건 동역학을 먼저 학습한 뒤 제어 정책이나 솔버를 얹음
- **기존 한계** — 잠재 세계 모델, 샘플링 플래너, 사후 행동 예측기가 각각 제어 정보 보존이나 탐색 비용에서 막힘
  - DINO-WM, LeWorldModel(LeWM) — 행동 조건 잠재 세계 모델을 제어에 쓰나 사전학습 인코더나 SIGReg로 만든 표현이 제어 관련 정보를 안정적으로 보존하지 못한다고 지적
  - CEM 같은 샘플링 플래너 — 넓은 가우시안 사전분포에서 시작해 행동 차원·계획 길이가 커질수록 롤아웃 다수 필요, 접촉 전이로 국소 최적화도 어려움
  - GC-IDM, PRISM 같은 사후 행동 예측기 — 동결 JEPA 임베딩 위에서 학습해 행동 지도가 표현 학습과 단절
- **핵심 방법** — 다음 잠재 상태 예측과 행동 플로우 매칭(flow matching)의 공동 목적에 SIGReg 잠재 정규화를 더한 단일 단계 학습
  - Mixture-of-Transformers 예측기 — 깨끗한 행동은 잠재 동역학 예측에, 노이즈 행동은 플로우 매칭 정책 학습에 사용해 두 목적이 시각 표현을 공유
  - 직접 정책 실행과 계획을 모두 지원, 학습한 정책에서 후보 행동열을 샘플링한 뒤 학습 동역학을 통한 경사 하강으로 정제
  - 약 17M 파라미터, 잠재 정규화 가중치 하나
- **차별점** — 인코더를 먼저 학습하고 정책을 붙이는 대신 표현·동역학·정책을 동시에 학습
  - SIGReg를 뺀 변형과 비교해 잠재 정규화의 기여를 분리
- **핵심 기여** — 계획 성능, 행동 복제 성능, 해석 분석의 3건
  - 기존 JEPA 시각 계획 대비 접촉 집약 과제 성공률 28.6%에서 89.7%, 장기 과제 10.9%에서 46.2%, 계획 32.3배 빠름 — 시뮬레이션
  - 시뮬레이션 10개 이종 환경에서 LeWM 대비 목표 도달 성공률 향상
  - 행동 복제에서 시뮬레이션·실물 모두 기존 방법과 경쟁적, 실물 Pick and Place T·Push-T·Tape Stack 과제별 30회 시행을 Diffusion Policy·π0.5와 비교
  - 선형 프로브로 물리 상태·행동 정보 복원 확인, 플래너 ablation으로 확률적 행동 제안의 기여 측정
- **가치** — 소형 단일 모델이 정책 실행과 계획을 겸하는 경로 제시

### (c) 시사점

- 정책과 잠재 동역학을 한 백본에서 함께 학습하는 선례
- **판단 근거** — 행동 플로우 매칭과 잠재 예측을 같은 표현에 공동 학습한 모델이 실물에서 Diffusion Policy·π0.5와 경쟁적
- **설계 함의** — 행동 전문가를 유지한 채 잠재 예측 목적을 같은 표현에 공동 학습하는 구조의 비교 기준점
- **추가 기능** — 같은 모델을 후보 행동 평가용 플래너로도 쓰는 경로가 열림
- **도입 비용 낮음** — 약 17M 규모, 코드 공개

### (d) 먼저 확인할 점

- **소규모 단일 과제** — 과제·체화별 개별 학습이며 저자가 한계로 명시
- **다지 손 부재** — 확인한 실물 과제 목록에 다지 손 조작 없음
- **VLA 백본 결합 없음** — 약 17M 모델 기준이며 대형 모델 확장은 저자가 향후 과제로 명시
- **데이터 범위** — 전문가 시연과 비전문가 상호작용이 제한된 규모, 접촉 전이 일반화는 별도 확인 필요
- **계획 비교 범위** — 시각 계획 이득은 목표 조건 기준선 4종 대비이며 시뮬레이션 결과

## 🥉 논문 3

**Rethinking Representations for World-Action Modeling**
[arXiv:2609.38163](https://arxiv.org/abs/2609.38163) · Haoyi Jiang, Liu Liu, Xinjiang Wang 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — arXiv comment "https://github.com/hustvl/ReWAM"

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- 행동 손실로만 표현을 다듬는 DINO 기반 월드-액션 모델
- **문제** — 월드-액션 모델(WAM)에서 제어와 예측 사이의 인터페이스인 표현 공간을 어떻게 정의할지
  - 많은 WAM이 Video-VAE 잠재를 쓰는데 이 공간은 재구성에 최적화되어 제어 관련 정보를 우선하지 않음
- **기존 한계** — 재구성 지표와 지각 특징 모두 제어 효용을 보장하지 못함
  - 비디오 생성기 기반 WAM — 시각 재구성에 맞춘 Video-VAE 잠재를 예측 공간으로 사용
  - 표현 공간 WAM — 비교 연구들이 재구성 충실도만으로는 제어 효용을 평가할 수 없다고 지적
  - 프레임별 지각 특징 — 시간 변화를 명시적으로 담지 않고 통계가 확산 학습과 맞지 않을 수 있음
- **핵심 방법** — 사전학습 DINO 특징 위에 세 구성요소
  - Feature Calibration — 다층 집계, 정규화, 표현 인지 노이즈 스케줄로 RoboTwin 2.0 평균 성공률 12.20%p 상승
  - Temporal Representation Bottleneck — 특징을 압축 월드 상태로 구성
  - Action-Grounded Representation Shaping — 행동 손실 그래디언트만 병목에 전달해 정책이 표현 내용을, 세계 모델이 표현의 변화 방식을 담당
- **차별점** — 생성형 비디오 사전학습 없이, 예측 손실이 표현을 갱신하지 않도록 그래디언트를 비대칭 라우팅
  - 이 역할 분담을 그래디언트 라우팅 ablation으로 검증
- **핵심 기여** — 통제 비교, 모델, 벤치마크 결과의 3건
  - 비디오 사전학습이 없을 때 raw DINO 특징이 SSIM은 낮은데도 Video-VAE 잠재보다 RoboTwin 2.0에서 우수
  - RoboTwin 2.0 clean·random 설정 모두 성공률 93.6%
  - RoboDojo에서 약 600시간 체화 사전학습으로 평균 점수 12.29, 성공률 8.28%
  - 실물 3개 과제에서 60회 중 55회 성공(91.7%), Fast-WAM은 48회(80.0%)
- **가치** — 생성형 비디오 사전학습 없이 지각 표현과 제어 기반 표현 형성으로 WAM을 만드는 경로 제시

### (c) 시사점

- 재구성 충실도와 제어 효용이 어긋남을 보이는 통제 비교
- **판단 근거** — 픽셀 재구성 SSIM이 낮은 raw DINO 특징이 Video-VAE 잠재보다 정책 성능이 높음
- **설계 함의** — 예측 대상 공간을 정할 때 재구성 품질 대신 제어 효용을 기준으로 삼는 근거
- **그래디언트 분리** — 예측 손실이 표현을 갱신하지 않게 하는 설계가 공유 백본 보조 목표 설계의 선택지
- **도입 비용 낮음** — 코드 공개, 생성 비디오 사전학습 불필요

### (d) 먼저 확인할 점

- **시드·한계 서술 없음** — 반복 시드나 분산, 한계 서술이 본문에 없음
- **시뮬레이션 비중** — 주요 수치는 RoboTwin 2.0과 RoboDojo, 실물은 3개 과제 과제당 20회 시행
- **사전학습 데이터** — 체화 사전학습 약 600시간은 자체 수집 데이터라 재현에 동급 데이터 필요
- **동결 DINO 의존** — 특징 추출기를 고정한 구성이라 다른 인코더로의 전이는 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**Data-Free Continual Learning for World Action Model with Rectified Generative Replay**
[arXiv:2610.18038](https://arxiv.org/abs/2610.18038) · Kaipeng Fang, Hangxu Liu, Chaojian Shi 외 · adjacent field: 지속 학습·파괴적 망각 · 코드 공개 예정

**점수 11/15** · R2 · N2 · M3 · Real3 · Repro1 — §5 "Code will be released upon publication."

### (a) 관련 Pillar / Decision

[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 논문 요지

- WAM이 자기 과거 롤아웃을 재생성해 데이터 없이 연속 학습
- **문제** — 가중치만 배포된 정책은 이전 과제 시연이 없어, 순차 미세조정 시 새 과제는 빨리 익혀도 이전 과제를 잊음
- **기존 한계** — 파라미터 제약 계열과 경험 재생 모두 로봇 정책에 맞지 않음
  - 정규화 — 로봇 정책에서는 보존 효과가 작음
  - 파라미터 격리 — 테스트 시 과제 식별자 필요
  - 경험 재생(ER) — 이전 과제 시연 버퍼를 전제하는데 실제로는 시연이 남아 있지 않은 경우가 많음
- **핵심 방법** — 지시문만으로 이전 과제 롤아웃을 WAM이 재생성하고, 보정한 뒤 새 과제 데이터와 섞어 미세조정(LingBot-VA 기반)
  - 완료 인지 적응형 절단 — 에이전트형 평가기가 과제 완료를 탐지해 롤아웃을 자르고 완료 후 무의미한 동작 제거
  - 흐름 기반 물리 일관성 필터링 — URDF로 정의된 로봇만 시뮬레이터에서 생성 행동을 실행해 얻은 광학 흐름과 생성 관측에서 추정한 흐름의 일치도로 순위를 매겨 상위만 재생
- **차별점** — 외부 데이터 없이 WAM 자신의 생성 능력으로 재생하되 재생 전에 두 가지 결함을 보정
  - 원시 롤아웃 재생은 실제 데이터 재생에 크게 못 미침
- **핵심 기여** — 방법, 정량 결과, 망각 진단의 3건
  - LIBERO 4개 스위트와 실물 5개 과제에서 순차 미세조정 대비 망각 90% 이상 감소, ER과 약 2%p 차이
  - 절단과 필터링 둘 다 필요하다는 ablation
  - 망각이 역동역학 모델링에 집중되고 관측 예측은 대체로 보존된다는 분석
- **가치** — 학습 데이터 없이 가중치만 받은 세계-액션 모델을 이어 학습시키는 경로 제시

### (c) 시사점

- 망각이 행동 쪽에 몰리고 관측 예측은 남는다는 진단
- **판단 근거** — 망각된 WAM도 그럴듯한 관측을 생성하는데 생성 행동은 실패하므로 미래 예측 능력 보존이 행동 보존을 보장하지 않음
- **설계 함의** — 미래 예측 보조 목표를 함께 학습한 모델을 순차 과제로 확장할 때 행동 쪽 검증이 별도로 필요
- **전이 후보** — 데이터 없는 재생 기법을 가중치만 전달받은 정책의 연속 적응으로 가져올 여지

### (d) 먼저 확인할 점

- **코드 공개 예정** — 현재 저장소 없음
- **ER과의 격차** — 장기 과제에서 가장 크며 저자가 관측–행동 드리프트가 완전히 해소되지 않았다고 명시
- **가소성 저하** — 실물 실험에서 재생 기반 방법의 새 과제 학습 능력 저하를 저자가 한계로 명시
- **구성 의존** — 에이전트형 평가기와 로봇 URDF 시뮬레이터가 필요하고 LingBot-VA 기반이라 다른 WAM으로의 일반화는 확인 필요
