## 🥇 논문 1 — 우선순위 ★★★

**PointZero: 3D Point Track Completion for Learning Transferable 3D Dynamics**
[arXiv:2609.19142](https://arxiv.org/abs/2609.19142) · Bardienus P. Duisterhof, Kaifeng Zhang, Adam Hung, Bowen Wen, Stan Birchfield, Yunzhu Li et al. · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 로봇 액션 라벨을 요구하는 기존 action-conditioned 3D dynamics 학습 방식이 웹 비디오 데이터를 학습 풀에서 배제한다는 문제 지적
- 단일 RGB-D 관측과 희소 부분 3D 궤적으로부터 관측된 모든 점의 미래 3D 트랙을 예측하는 3D 점 트랙 완성을 로봇 액션 라벨 없는 사전학습 목적함수로 제시
- 변형체·관절체·강체를 아우르는 290만 프레임 규모 합성 데이터셋을 직접 구축해 PointZero 학습에 사용
- 사전학습된 표현을 엔드이펙터 자세 조건부 3D 동역학 예측, 모방학습 두 다운스트림에 각각 파인튜닝해 유효성 입증 — PGND 3D 동역학 벤치마크에서 baseline 대비 우위, 시뮬레이션·실환경을 포함한 7개 조작 태스크 중 6개에서 baseline 대비 우위 또는 동등
- 아키텍처 자체의 이득과 사전학습 목적함수·데이터셋의 이득을 분리하기 위해 처음부터 학습하는 대조군까지 별도 검증
- 데이터셋·체크포인트·전체 학습 레시피 공개

### (c) 시사점
- 로봇 액션 라벨 없이 웹 규모 비디오로 3D 동역학 prior를 학습하고 이후 액션조건부로 파인튜닝하는 2단계 경로가, corpus의 μ0(2606.13769)가 보여준 액션-비표기 사전학습 노선과 같은 계열의 또 다른 구체적 사례
- 3D 점 트랙 완성이라는 구체적 목적함수 선택이, D9KS 압축 잠재·3D-flow 예측 공간 후보 중 3D-flow 축의 실증 근거를 직접 강화
- 데이터셋·체크포인트·학습 레시피 전체 공개로, 이 스택이 직접 재현·확장 가능한 실험 기반 확보

### (d) 먼저 확인할 점
- 7개 조작 태스크 중 시뮬레이션과 실환경의 구체적 분할·태스크별 정량 성공률이 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 다지 손 기반 정밀 조작이 평가 태스크에 포함되는지, 그리퍼 중심 태스크에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 공개된 데이터셋·체크포인트로 3D 점 트랙 완성 사전학습 목적함수만 우선 이 기존 3D 예측 파이프라인에 적용해 재현

## 🥈 논문 2 — 우선순위 ★★

**Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control**
[arXiv:2609.20761](https://arxiv.org/abs/2609.20761) · Hanchu Zhou, Brendan Lynch, Raman Goyal, Dechen Gao, Begum Kasap, Boqi Zhao et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- 최근 촉각 WAM들이 접촉 집약적 물리 동역학 포착을 위해 대규모 사전학습 생성 백본에 의존해 추론 효율성·유연한 배포에 제약이 있다는 문제 지적
- 시각·촉각 관측을 공유 잠재로 인코딩해 비전-촉각-액션 직접 플로우 매칭 과정으로 액션 청크와 미래 시각·촉각 잠재를 함께 생성하는 경량 Agile-WAM 제안
- 시각·촉각 신호가 서로 다른 시간 스케일로 변화한다는 관찰(인접 시각 프레임은 유사, 촉각은 접촉 시 급변)에 착안해 시각 잠재는 더 큰 시간 오프셋으로, 촉각 잠재는 다음 프레임 단위로 예측하는 multi-horizon multimodal 예측 구조 도입
- 9개 시뮬레이션·5개 실환경 접촉 집약적 조작 태스크 전반에서 최강 baseline 대비 우위 확인, 실환경 실험에서 성공률 상대 29.4% 개선과 11.9ms 추론 지연 동시 달성
- 코드 공개 언급 없음, 프로젝트 페이지 공개

### (c) 시사점
- 시각·촉각을 서로 다른 예측 호라이즌으로 분리해 처리하는 multi-horizon 구조가, D9KS 접촉-관련 예측 공간을 촉각까지 확장하면서도 연산 비용을 억제하는 구체적 설계 원칙으로 참고 가능
- 대규모 사전학습 생성 백본 없이 경량 아키텍처로 촉각 WAM을 구현한 결과가, 배포 지연과 성능을 동시에 만족하는 실용적 기준점 제공
- 실환경 태스크 상대 29.4% 개선이라는 정량 근거가, 촉각-비전 결합 WAM 계열의 비교 기준점으로 활용 가치

### (d) 먼저 확인할 점
- 다섯 개 실환경 태스크의 물체 종류·손 형태(그리퍼 대 다지 손)가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 촉각 잠재의 다음-프레임 예측 호라이즌이 다지 손의 손가락별 미세 접촉 전이까지 포착 가능한 해상도인지 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 multi-horizon multimodal 예측 헤드만 우선 이 기존 촉각 미분리 WAM 파이프라인에 추가

## 🥈 논문 3 — 우선순위 ★★

**DexTouch-WM: Learning Action-Conditioned Tactile World Models from Human Touch for Dexterous Robot Manipulation**
[arXiv:2609.20649](https://arxiv.org/abs/2609.20649) · Yan Qin, Yue Chen, Wenwei Lin, Shujia Liu, Chuqiao Lyu, Kailun Su et al. · IROS 2026 Workshop RoBoWoMo · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- 접촉 집약적 다지 조작의 예측 모델 학습이 조밀한 촉각 상호작용 데이터를 요구하나, 실로봇에서 이를 스케일링하는 비용이 높고 임베디먼트-특화 센서에 종속된다는 문제 지적
- 사람 손과 다지 로봇 손에 동일 배치의 유연 압저항 촉각 어레이를 장착, 사람 동작을 로봇 액션 공간으로 리타게팅해 사람 상호작용이 로봇 예측과 동일한 동역학 모델을 지도하도록 만드는 DexTouch-WM 제안
- 사전학습된 비디오 전문가에 경량 촉각 전문가를 해부학적 인지 촉각 토큰과 정렬된 액션 조건화로 결합해 미래 RGB 관측과 양방향 촉각 동역학을 함께 예측
- 실로봇 지도 5시간을 고정한 채 사람 상호작용 데이터를 0시간에서 100시간까지 늘리는 human-to-robot 스케일링 실험에서, 사람·로봇 태스크 집합이 겹치지 않는데도 held-out 로봇 도메인 시각·기하·접촉 예측이 크게 개선됨을 확인
- world model을 정책 평가용 대리 환경, 실로봇 정책 학습용 합성 궤적 생성기로도 활용해 사람 상호작용이 로봇 데이터를 보완하는 축임을 입증
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 사람 손과 로봇 손에 동일 촉각 센싱 레이아웃을 적용해 사람 촉각 데이터로 로봇 예측 모델을 직접 지도하는 구조가, D7VC가 아직 corpus 앵커 없이 비워 두었던 에고센트릭 hand-object world model 방향에 촉각 축의 첫 구체 참고점 제공
- 로봇 시연을 5시간으로 고정한 채 사람 상호작용만 늘려 held-out 예측 성능을 개선한 스케일링 결과가, 값비싼 실로봇 촉각 데이터 수집을 사람 상호작용으로 대체·보완하는 구체적 비용 절감 경로로 참고 가능
- world model을 대리 평가 환경이자 합성 궤적 생성기로 겸용하는 구조가, rollout synthesis 트랙에 촉각 모달리티를 결합하는 또 다른 구체적 사례로 축적

### (d) 먼저 확인할 점
- 사람-로봇 손의 촉각 센서 배치가 동일하다는 전제가 다른 촉각 센서 규격에도 일반화되는지, 이 스택이 확보한 센서 규격과 호환되는지 확인 필요
- 실로봇 정책 학습에서의 구체 성공률 수치가 abstract 수준에서는 정성적 서술에 그쳐 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 해부학적 인지 촉각 토큰 정렬 구조만 우선 이 기존 촉각 미보유 world model 파이프라인에 추가

## 🥈 논문 4 — 우선순위 ★★

**TacSushi: Tactile-Grounded World-Action Modeling for Dexterous Sushi Manipulation**
[arXiv:2609.19613](https://arxiv.org/abs/2609.19613) · Haodi Hu, Kaen Kogashi, Toshiaki Koike-Akino · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- 변형·가림·불확실한 접촉 아래에서의 다지 음식 조작이 정밀 제어를 요구한다는 문제 설정, 현재 관측에 기반해 행동하면서 기록된 미래 결과로부터 학습하는 촉각 접지 world-action 정책 TacSushi 제안
- 현재 RGB·언어·손 상태를 인코딩하는 백본에 손끝 촉각 특징을 특징별 게이트 융합으로 결합, 학습 중에는 시연 액션 청크에 조건화된 디코더가 기록된 미래 시각 관측·태스크 진행도·상대 접촉 위험·촉각 요약을 예측하고 배포 시 이 디코더는 제거
- 실패 시행이 모방 학습 대상에서는 제외되지만 미래-결과 예측 지도 신호로는 활용되는 구조로, 성공 340건·실패 50건 실로봇 시행으로 학습
- 3개 in-distribution 태스크·2개 out-of-distribution 재료 변형 태스크, 총 600회 롤아웃에 걸쳐 여섯 가지 방법 비교 — 사람 평가 5개·VLM 평가 3개를 동일 가중치로 결합한 앵커드 시각-품질 프로토콜로 최종 결과 평가
- Full TacSushi가 in-distribution 평균 성공률 68.3%, out-of-distribution 37.5% 달성 — 미래-결과 지도 신호 제거 시 36.7%/10.0%, 직접 촉각 연결 시 25.0%/17.5%로 하락해 게이트 융합·예측 지도 신호 각각의 기여 확인
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 미래 결과 예측을 배포 시 제거되는 학습-전용 지도 신호로 구조화하는 설계가, D9KS 접촉-관련 예측 공간을 학습 손실로만 활용해 추론 비용을 지지 않는 저비용 경로로 참고 가능
- 실패 시행을 모방 대상에서는 제외하되 결과 예측 지도 신호로는 재활용하는 구조가, 실패 데이터를 안전하게 활용하는 구체적 절차 제공
- 68.3%→36.7%, 37.5%→10.0%로 벌어지는 소거 실험 격차가, 예측-지도 신호 유무에 따른 정량 상한을 가늠하는 참고 기준점

### (d) 먼저 확인할 점
- 사람+VLM 혼합 평가 프로토콜이 표준 성공률 지표 대비 얼마나 엄격한지, 다른 태스크 도메인에 이식 가능한 평가 방식인지 확인 필요
- 손끝 촉각 특징의 구체 차원·센서 규격이 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 미래-결과 예측 지도 신호만 우선 이 기존 촉각 게이트 융합 파이프라인에 추가

- 새로운 물체·태스크에 로봇을 적응시키려면 상호작용 경험이 필요하나 이를 확보하는 비용이 높다는 문제 지적, 변형체 조작을 위한 접촉-중심 world model WorldContact를 제한된 고품질 궤적 집합으로부터 구축해 추가 학습 데이터를 효율적으로 생성하는 접근 제시
- 급격한 움직임을 해소하고 상호침투를 막기 위해 작은 적분 스텝을 요구하는 원본 수치 시뮬레이터보다 더 큰 시간 스텝으로 물체 동역학을 예측
- 16개 쇼핑백 조작 태스크에 걸쳐 검증 — 단일 H100 GPU에서 렌더링·디스크 입출력을 제외한 상태-롤아웃 측정 기준 원본 시뮬레이터 대비 10배 속도 향상 확인
- 생성된 데이터로 기존 vision-language-action 정책을 파인튜닝해 실로봇에 직접 배포 — 백 들어올리기 태스크에서 원본 시뮬레이션 데이터만으로 파인튜닝 시 단일 시도 성공률 65%, WorldContact로 확장한 데이터셋으로 파인튜닝 시 95%로 개선
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 원본 수치 시뮬레이터보다 큰 시간 스텝으로 접촉-중심 동역학을 예측해 데이터 생성을 가속하는 구조가, D3FQ rollout synthesis 트랙에 변형체 조작이라는 새로운 도메인 사례를 추가
- 10배 속도 향상이라는 정량 근거가, 대규모 롤아웃 합성이 필요한 상황에서 신경망 대리 시뮬레이터 도입의 비용 절감 상한을 가늠하는 참고 기준점
- 원본 시뮬레이션 데이터만 사용한 파인튜닝 대비 WorldContact 확장 데이터 파인튜닝의 30%p 격차가, 접촉-중심 world model을 통한 데이터 증강의 정량적 상한선으로 참고 가치

### (d) 먼저 확인할 점
- 16개 쇼핑백 조작 태스크가 모두 그리퍼 기반 파지인지, 다지 손 기반 정밀 조작을 포함하는지 확인 필요
- 변형체 도메인 특화 설계가 강체·관절체 등 다른 물체 클래스로 일반화되는지 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 접촉-중심 대리 동역학 모델만 우선 이 기존 rollout synthesis 파이프라인에 적용

## 🥈 논문 6 — 우선순위 ★★

**MoWAM: Explicit Future Motion Prediction for Efficient World Action Models**
[arXiv:2609.20709](https://arxiv.org/abs/2609.20709) · Jiayu Wang, Bin Zhu, Yue Yu, Jingjing Chen · arXiv preprint · source: citation-graph(WorldVLA 피인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- 미래 비디오를 명시적으로 생성하는 기존 WAM이 추론 시 상당한 연산 오버헤드를 유발하나, 미래 생성을 아예 제거하면 미래 동역학이 관측 특징에 암묵적으로만 인코딩돼 분포 이동 아래 강건성이 제한된다는 트레이드오프 지적
- 완전한 미래 장면 재구성 대신 로봇이 현재 장면·상호작용 제약 아래 어떻게 진화할지를 압축된 미래 동역학 추상으로 포착하는 구조적 로봇 모션으로 대체하는 MoWAM 제안
- Mixture-of-Transformer 아키텍처가 학습 중 미래 시각 동역학을 학습하면서 모션과 액션을 함께 예측 — 추론 시에는 비디오 생성을 완전히 제거하면서도 미래에 대한 명시적 표현은 유지
- 압축된 모션 표현이 모션·액션 후보 쌍을 여러 개 샘플링하고 모션-인지 태스크-진행도 검증기로 선별하는 추론-시점 스케일링을 가능케 함
- LIBERO·LIBERO-Plus·실환경 조작 태스크에서 강한 in-distribution 성능, 개선된 out-of-distribution 강건성, 대표 WAM baseline 대비 더 높은 평균 실환경 성공률 달성 — 후보를 더 많이 탐색할수록 성능이 개선됨을 확인해 명시적 미래 모션이 효과적인 추론-시점 스케일링 기반임을 입증
- 코드·프로젝트 페이지 공개 언급 없음

### (c) 시사점
- 완전한 미래 장면 대신 압축된 로봇 모션 추상만 예측해 추론 시 비디오 생성을 제거하는 설계가, D9KS 압축 잠재 예측 공간 선택을 뒷받침하는 구체적 실행 사례로 참고 가능
- 학습 중에만 완전한 미래 동역학을 학습하고 추론 시 경량 표현만 남기는 구조가, D3FQ 보조 예측 역할을 저비용으로 구현하는 절차 제공
- 압축 모션 표현 위에서 후보를 늘릴수록 성능이 개선된다는 결과가, 추론-시점 연산 예산과 성능 사이 조절 가능한 트레이드오프로 참고 가치

### (d) 먼저 확인할 점
- LIBERO·LIBERO-Plus·실환경 각각의 구체 정량 성공률 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 다지 손 기반 정밀 조작이 실환경 조작 태스크에 포함되는지, 그리퍼 중심 태스크에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 코드 미공개 상태라 방법 설명만으로 모션-인지 태스크-진행도 검증기만 우선 이 기존 WAM 추론-시점 스케일링 파이프라인에 추가

DexTouch-WM([arXiv:2609.20649](https://arxiv.org/abs/2609.20649))은 D7VC의 비어 있던 에고센트릭 hand-object 앵커에 촉각 축의 첫 구체 후보로 관찰. 6개 고정 한도가 모두 채워져 있어 즉시 교체를 제안하지는 않으나, 다음 분기 리밸런싱 시 두 논문 모두 우선 검토 권장.
