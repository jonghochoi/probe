## 🥇 논문 1 — 우선순위 ★★★

**OpenWAM: An Open, Modular Exploration Towards Systematic World-Action Model Pretraining**
[arXiv:2609.07398](https://arxiv.org/abs/2609.07398) · Yuran Wang, Siqiao Huang, Mingleyang Li, Chenhao Zhang, Jiaqi Liang, Weiyang Jin et al. · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 기존 World-Action Model들이 생성 백본·시각 표현·아키텍처·정보 흐름·추론 절차·학습 데이터를 하나로 결합한 monolithic 구조라, 어떤 설계 선택이 실제로 성능을 좌우하는지 불분명하다는 문제 지적
- WAM 설계 공간을 구성 가능한 모듈로 분해해 통제된 실험 프로그램으로 전환하는 오픈 연구 스택 OpenWAM 제안 — 인프라(OpenWAM-Infra)와 통제 실험(OpenWAM-Study) 두 축으로 구성
- 통제 실험으로 세 원칙 도출: 충분히 강력한 생성 백본과 압축된 정보-밀집 잠재 공간을 통해 상류 지식이 전이됨, world-action 시너지에는 전용 액션 용량·명시적 world-to-action 정보 흐름·동기화된 공동 디노이징이 필요함, embodied pretraining은 주로 분포 밖 일반화를 개선하며 에고센트릭·로봇 데이터 단일 단계 co-training이 world 커버리지와 액션 접지를 통합함
- 세 원칙을 조합해 약 6,400시간 규모 에고센트릭 인간·로봇 데이터로 사전학습한 OpenWAM-α 구축, 단일팔·양팔·다지 손을 아우르는 여덟 개 시뮬레이션 벤치마크와 실로봇 실험 모두에서 최상위권 성능 유지
- 인프라·평가 프로토콜·사전학습 모델·데이터 레시피 전체를 코드·모델·데이터 저장소로 공개

### (c) 시사점
- WAM 설계 선택지를 통제 실험으로 검증한 세 원칙(생성 백본+압축 잠재 공간, 전용 액션 용량+명시적 world-to-action 흐름+동기화 디노이징, 에고센트릭-로봇 단일단계 co-training)이 D3FQ 역할·D8XB 통합 아키텍처·D9KS 예측 공간 선택 각각의 근거로 직접 대응
- 인프라·평가 프로토콜·사전학습 모델·데이터 레시피 전체가 공개돼 있어, 이 스택의 WAM 설계 선택을 직접 검증·재현할 수 있는 실험 기반 확보
- 다지 손을 포함한 임베디먼트 스펙트럼에서 단일팔부터 다지 손까지 최상위권 성능이 유지된다는 결과가, 접촉 집약적 조작으로의 일반화 가능성을 뒷받침

### (d) 먼저 확인할 점
- 통제 실험이 다룬 구체 벤치마크명·정량 성공률 수치가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 6,400시간 규모 사전학습 데이터가 데이터 파이프라인 규모 대비 현실적으로 재현 가능한 스케일인지 확인 필요
- 가장 저렴한 전이 확인: 공개된 코드·모델로 OpenWAM-Infra의 통제 실험 설정 중 world-to-action 정보 흐름 원칙 하나만 우선 이 기존 WAM 파이프라인에 적용해 재현

## 🥇 논문 2 — 우선순위 ★★★

**TacPAC: Tactile Prediction and Real-Time Action Correction in World-Action Models for Contact-Rich Manipulation**
[arXiv:2609.05266](https://arxiv.org/abs/2609.05266) · Zipei Ma, Xiaofei Wei, Junzhe Jiang, Shunlin Lu, Li Zhang · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-d5def5.svg)](#ref-P3) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ)

### (b) 핵심 기여
- world-action model이 예측된 미래 관측으로 액션 생성을 안내하지만, 시각 중심 예측은 접촉 집약적 조작을 좌우하는 국소 접촉 단서를 놓친다는 문제 지적 — 미래 촉각 관측을 추가 뷰로 단순 예측하면 달성 가능한 이득의 3분의 1만 회수됨을 실험으로 확인
- 예측은 실행에 앞서고 촉각 피드백은 실행 중 도착한다는 타이밍 불일치를 겨냥, 촉각 예측을 실시간 액션 보정으로 전환하는 TacPAC 제안
- 베이스 모델이 액션 청크를 계획하면 그 계획이 조건화된 예측 접촉과 계획 표현을 함께 캐시, 새로 관측되는 촉각 이미지마다 촉각 전문가가 이 캐시에 대조해 아직 실행되지 않은 액션을 보정 — 청크 재생성 대비 20.7배 저렴한 단일 패스로 처리
- 정밀 삽입·취약물 처리·물체 재배치·장기 호라이즌 조작을 아우르는 다섯 개 실로봇 태스크 전체에서 비전 전용 베이스 모델 대비 평균 성공률 22%→64%로 개선, 전 태스크에서 1위
- 코드 GitHub 공개 확인

### (c) 시사점
- 촉각 예측을 별도 모달리티 예측 대상이 아니라 실시간 액션 보정 신호로 재구성하는 설계가, D9KS 접촉-관련 예측 공간을 촉각까지 확장하는 저비용 실행 경로로 참고 가능
- 예측-실행 타이밍 불일치를 정면으로 겨냥한 캐시-대조 보정 메커니즘이, 접촉 집약적 다지 조작에서 촉각 피드백을 안전하게 통합하는 구체적 절차 제공
- 다섯 개 실로봇 태스크 전체 1위·20.7배 연산 절감이라는 정량 근거가, 촉각 보조 예측 계열의 비교 기준점으로 활용 가치 높음

### (d) 먼저 확인할 점
- 다섯 개 실로봇 태스크의 물체 종류·손 형태(그리퍼 대 다지 손)가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 촉각 전문가가 대조하는 예측 접촉 표현의 구체 차원·인코딩 방식 확인 필요
- 가장 저렴한 전이 확인: 공개된 코드로 캐시-대조 보정 모듈만 우선 이 기존 촉각 미보유 world-action model 파이프라인에 이식

### (b) 핵심 기여

- 순환 베이스라인·보조 헤드·촉각 마스킹·WSM 모달리티 헤드에 대한 소거 실험으로 예측적 world modeling·클린-깊이 감독·촉각 접촉 단서가 각각 학습된 상태에 기여함을 확인
- 9개 z축 물체로 사전학습한 WSM을 49개 물체 다운스트림 정책 학습의 재사용 가능한 prior로 활용, 미확인 물체·교란-복구·sim-to-real 전이에서 정량·정성 근거 확보
- 프로젝트 웹사이트만 확인, 코드 공개는 명시되지 않음

- world model을 잠재 상상·정책 최적화 대신 순환 태스크 컨텍스트로 쓰는 역할 변형이, D3FQ 역할 목록(co-trained auxiliary·eval-in-imagination·RL 환경·rollout synthesis)에 없는 다섯 번째 사용 방식으로 참고 가치
- 잡음 섞인 깊이 입력에서 클린 깊이 타깃을 복원하도록 world model을 학습시키는 설계가, 실로봇 배포 시 센서 잡음에 강건한 기하 상태 확보의 구체적 레시피
- 9개 물체 prior를 49개 물체로 확장하는 재사용 검증이, 다지 조작 world model prior의 물체 일반화 폭을 가늠하는 참고 기준점

### (d) 먼저 확인할 점
- 소거 실험의 구체 정량 수치(태스크별 성공률)가 abstract 수준에서는 제시되지 않아 본문 확인 필요
- 미끄러짐 감지·접촉 신호가 손가락 수준 세밀도까지 포착되는지, 아니면 물체 수준 자세 추정에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 클린-깊이 복원 감독 목적함수만 우선 이 기존 촉각 강화학습 파이프라인에 얹어 재현

- 시뮬레이션 없이 순수 실환경 강화학습으로 16자유도 다지 손 전체를 학습시킨 결과가, 다지 조작 world model의 실환경 데이터 효율성 상한을 가늠하는 참고 기준점
- 조작자 개입 부담 84% 감소라는 정량 근거가, 실환경 다지 강화학습 배포 비용을 낮추는 구체적 절감 레시피로 활용 가치

### (d) 먼저 확인할 점

### (b) 핵심 기여
- world-action model이 대부분 사전학습된 비디오 생성기를 상속해, WAM 자체의 사전학습·스케일링은 충분히 탐구되지 않았다는 문제 지적
- 생성·액션 구성요소 전체를 조작 데이터로 처음부터 학습하는 world-action model GE-Act 2.0 제안 — 제어-지향 오토인코더(CoAE), 단일-스텝 시각 플래너(SVP), 역동역학 모델(IDM) 세 구성요소로 구성
- CoAE가 액션·지시 관련 정보를 공격적 압축 아래 유지, SVP가 한 번의 미분 가능한 패스로 완전한 미래 상태를 산출해 시각 플래닝과 역동역학을 상호보완적 데이터로 분리 사전학습 가능케 함
- 예측된 미래가 기록된 액션과 행동적으로 호환되는지 선별해 불일치 감독을 줄이는 knowledge-aligned selective optimization(KASO)으로 구성요소를 공동 학습
- 태스크별 파인튜닝 없이 held-out 장면·배경·조명·물체 인스턴스를 아우르는 20개 조작 스킬 그룹 100개 태스크에서 직접 평가, co-training 데이터를 300시간에서 3만 시간으로 늘리자 G1-OP 성공률 17.1%→44.1%, G2-90D 13.4%→31.1%로 개선, 스킬 커버리지와 분포 밖 제로샷 성공률 사이 강한 상관관계(Pearson r=0.80) 확인
- 프로젝트 페이지만 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 사전학습된 비디오 생성기 상속 없이 조작 데이터만으로 WAM 생성·액션 구성요소를 처음부터 학습하는 레시피가, D8XB 통합 아키텍처·D3FQ 예측 보조 역할 선택에 직접 참고할 대안 사전학습 경로
- CoAE·SVP·IDM 세 구성요소로 시각 플래닝과 역동역학을 분리 사전학습 가능케 하는 설계가, D9KS 압축 잠재 공간 선택의 구체적 구현 사례
- co-training 데이터 규모와 스킬 커버리지가 분포 밖 제로샷 성공률과 강하게 상관한다는 정량 근거가, 이 스택의 WAM 사전학습 데이터 투자 우선순위 결정에 참고 가능

### (d) 먼저 확인할 점
- G1-OP·G2-90D 평가가 실로봇 배포 기준인지 시뮬레이션 벤치마크 기준인지 abstract 수준에서는 명확히 확인되지 않아 본문 확인 필요
- 다지 손 임베디먼트가 20개 스킬 그룹 평가에 포함되는지, 그리퍼 중심 임베디먼트에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 프로젝트 페이지 코드 공개 여부 확인 후 KASO 선별 감독 목적함수만 우선 이 기존 WAM 파이프라인에 이식
