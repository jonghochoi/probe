## 🥇 논문 1 — 우선순위 ★★★

**Bridge-WA: Predicting Where and How the World Changes for Robotic Action**
[arXiv:2607.02195](https://arxiv.org/abs/2607.02195) · Yongjie Bai, Hanting Wang, Mingtong Dai, et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- **경량 World-Action 증류** — 고정된 future-change teacher 모델을 미래 토큰·변화 맵(change map)·모션-플로우 맵 세 가지 압축 prior 로 증류, 추론 시 teacher 완전 제거
- **WorldBridge 조건화** — action transformer 를 multi-source attention memory 와 spatial-temporal bias 로 조건화, 밀집 미래 이미지 생성 없이 행동 관련 장면 변화만 포착
- **노이즈 억제** — 배경·조명·distractor 등 제어 무관 외형 변화는 무시, 장면이 "어디서 어떻게" 변하는지에만 집중해 일반화 강화

### (c) 시사점
- 픽셀 단위 미래 생성 없이도 world-model 신호를 저비용으로 action 생성에 결합 가능함을 실증
- VLABench·RoboTwin2.0·LIBERO-Plus·실로봇 전 구간에서 성능 향상, 특히 분포 밖(OOD) 시각 변화에서 강건성 확보
- 코드·시각화 공개 — 검증 비용 낮음

### (d) 먼저 확인할 점
- teacher 모델 사전학습 비용 및 증류 파이프라인 복잡도 별도 확인 필요
- 모션-플로우 맵 prior 가 hand-object 접촉 수준의 미세 상호작용까지 포착하는지 미검증 (평가는 tabletop 조작 위주로 추정)
- 실로봇 평가 규모(태스크 수·시행 횟수)가 초록만으로 불명확, 본문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments**
[arXiv:2607.23969](https://arxiv.org/abs/2607.23969) · Pei Liu, Nan Zheng, Lang Zhang, et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- **Predictive-Latent 패러다임** — 픽셀 단위 비디오 생성 대신 JEPA 스타일 latent 공간에서 물리 dynamics 를 추출하는 World-Anchor 를 명시적으로 정식화
- **Isotropic Semantic Autoencoder (ISAE)** — non-Gaussian predictive feature 와 diffusion prior 간 modality gap 해소, latent 공간을 diffusion-friendly manifold 로 재구성
- **비대칭 Mixture-of-Transformers** — 학습 시 Anchor Diffusion Transformer 가 특권적으로 dynamics 를 가이드하고, 추론 시 해당 heavy branch 를 제거해 zero-overhead 실행

### (c) 시사점
- 대규모 trajectory 사전학습 없이 LIBERO SOTA·RoboTwin2.0 top-tier 매칭 — 데이터 효율적 latent world-model 경로의 실증 사례
- 학습-추론 비대칭 설계로 추론 비용 증가 없이 world-model 신호 활용 가능 — 배포 비용 우려 완화
- 코드 공개 — 재현 검증 가능

### (d) 먼저 확인할 점
- ISAE 의 diffusion-friendly manifold 변환이 hand-object 접촉 예측처럼 고주파 세부 동역학에도 유효한지 미검증
- 실로봇 전이가 "성공적"이라고만 서술 — 정량 수치는 본문 확인 필요
- LIBERO/RoboTwin2.0 은 dexterous 인핸드 조작보다 pick-place 위주 벤치마크로, hand-centric 세팅 전이는 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2606.08737](https://arxiv.org/abs/2606.08737) · Yunfan Lou, Yifan Ye, Yankai Fu, et al. · source: citation-graph

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- **Tactile-World Action Model** — action·미래 시각 관측·촉각 dynamics 를 하나의 모델에서 공동 예측
- **Contact-gated visuotactile fusion** — 접촉 여부에 따라 촉각 신호를 선택적으로 통합하는 게이팅 메커니즘, contact-aware attention bias 로 모달리티 간 상호작용 규제
- **이중 가속 전략** — 학습 2.9배, 추론 1.8배 가속(contact-aware bias 재정식화 + cache 기반 diffusion 가속), 실시간 배포 지향

### (c) 시사점
- 접촉 집약적 6개 태스크 평균 action accuracy 31.7%p 개선 — 촉각 조건화의 정량적 효과 확인
- 실시간 추론 가속 설계로 배포 비용 부담 낮음
- 코드 공개 — 재현 검증 가능

### (d) 먼저 확인할 점
- 6개 평가 태스크가 실로봇인지 시뮬레이션인지 초록만으로 불명확, 본문에서 Sim2Real 근거 확인 필요
- 촉각 센서 하드웨어 의존성(센서 종류·해상도) 명시 필요 — 이 하드웨어 스택과의 호환성 별도 확인
- 동시기 경쟁 tactile world-action model(ContactWorld, ViTacWorld 등) 대비 상대적 이점 불명확
