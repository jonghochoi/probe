## 🥈 논문 1 — 우선순위 ★★

**PHR-VLA: Planning Horizon Reasoning for Vision-Language-Action Models**
[arXiv:2608.27609](https://arxiv.org/abs/2608.27609) · Davood Soleymanzadeh, Kaidi Zhang, Zhiyuan Zhang, Bihao Zhang, Xiao Liang, Yu She et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 핵심 기여
- 대부분 VLA가 현재 관측에만 액션 예측을 조건화해, 접촉 집약적 조작에 필요한 미래 태스크 동역학 추론 메커니즘이 부재하다는 문제 지적
- 학습 시점에만 미래 관측에서 추출한 잠재 동역학을 VLA 내부 표현에 정렬시키는 경량 보조 미래 헤드로 플래닝-호라이즌 추론 도입 — 추론 시점에는 별도 미래 예측 없이 원래 VLA 그대로 배포
- 손목 카메라 기준 국소·접촉 중심 패치 단위 잠재 동역학 감독이 3인칭 카메라 패치 단위 감독보다 더 큰 개선폭을 낸다는 결과 확인
- LIBERO 84.1%→88.4%, 실환경 분해 조작 태스크 63.3%→82.5%, Meta-World 56.70%→57.8%로 세 설정 모두 정량 개선
- 프로젝트 페이지만 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 추론 시점에 미래 예측 분기를 완전히 제거하면서도 학습 시 미래 동역학 정렬만으로 성능을 끌어올리는 구조가, 배포 비용 증가 없는 저비용 도입 경로로 참고 가능
- 손목 카메라 접촉 중심 패치 단위 감독이 3인칭 전역 패치 감독보다 더 크게 기여한다는 결과가, 다지 조작의 접촉 신호 설계에 직접 참고할 근거
- 실환경 분해 조작에서 확보된 정량 개선치가, 접촉 집약적 태스크의 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 손목 카메라 패치 감독과 3인칭 패치 감독의 개선폭 차이가 구체적으로 어느 정도인지 본문 수치 확인 필요
- 실환경 분해 조작 태스크의 물체 종류·다지 손 사용 여부가 abstract 수준에서는 확인되지 않아 본문 확인 필요
- 가장 저렴한 전이 확인: 코드 공개 예정 상태라 방법 설명만으로 손목 카메라 패치 단위 미래 잠재 동역학 정렬 목적함수만 우선 이 기존 VLA 백본에 얹어 재현

## 🥈 논문 2 — 우선순위 ★★

**AnyWorld: Factorized Egocentric World Models for Cross-Embodiment Generalization**
[arXiv:2608.29242](https://arxiv.org/abs/2608.29242) · Cheng Chen, Jerry Bai, Jiacheng Wei, Boyu Chen, Xiaoji Zheng, Fan Wu et al. · arXiv preprint · source: citation-graph(DexWM 피인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P3](https://img.shields.io/badge/P3-e0d5f5.svg)](#ref-P3) / [![D7VC](https://img.shields.io/badge/D7VC-d97706.svg)](#ref-D7VC) [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 핵심 기여
- 접촉 집약적 로봇 시연을 대규모로 수집하기 어렵다는 병목 지적, 인간 에고센트릭 비디오가 풍부한 물리적 상호작용을 제공하지만 각 비디오가 단일 신체·카메라 경로·환경의 좁은 경험 조각만 포착한다는 한계 지적
- 단일 인간 상호작용을 액션·카메라·임베디먼트 세 요소로 분해, 페어링된 인간-로봇 시연 없이도 다양한 로봇-네이티브 롤아웃으로 재구성하는 AnyWorld 제안
- 대규모 인간 상호작용 사전학습 후 혼합 임베디먼트 파인튜닝으로 학습, 임베디먼트·시점·장면을 독립적으로 재조합 가능한 제어 가능성 확인
- RoboCasa GR1 탁상 벤치마크와 실제 IRON 휴머노이드 로봇 모두에서 생성 데이터의 조작 성능 개선 효과 확인, 통제된 개입 실험으로 액션-only 반사실 개입이 언어 기반 공간 타겟 선택 학습에는 실패함을 별도 확인
- 프로젝트 페이지만 확인, 코드 공개는 명시되지 않음

### (c) 시사점
- 페어링된 인간-로봇 시연 없이 단일 인간 비디오를 임베디먼트·시점·장면 축으로 독립 재조합해 로봇-네이티브 경험을 늘리는 레시피가, 에고센트릭 human 비디오 확보 파이프라인의 활용도를 직접 높이는 방법
- 액션-only 반사실 개입이 실패하고 시각 재조합이 함께 필요하다는 통제 실험 결과가, human 비디오를 world model 학습에 안전하게 섞는 조건을 구체적으로 짚어줌
- 실제 휴머노이드 로봇에서 확인된 개선 효과가, 에고센트릭 hand-object 방향 데이터 증강 레시피의 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점
- RoboCasa GR1·실제 IRON 로봇에서의 구체 성공률 수치가 abstract 수준에서는 정성적 서술("aggregate gains")에 그쳐 본문 확인 필요
- 다지 손 기반 정밀 조작까지 임베디먼트 재조합이 유효한지, 그리퍼·휴머노이드 수준에 그치는지 확인 필요
- 가장 저렴한 전이 확인: 프로젝트 페이지 코드 공개 여부 확인 후 이 에고센트릭 human 비디오 일부로 액션·카메라·임베디먼트 분해 재조합 파이프라인의 소규모 버전만 우선 재현

- Novelty 3 — 상호작용을 액션·카메라·임베디먼트 세 축으로 분해해 독립 재조합하는 프레이밍이 기존 페어링 기반 인간-로봇 전이 계열과 구분되는 신규 결합
- Reproducibility 1 — arXiv comment "Project page: https://xpeng-robotics.github.io/anyworld/"
- Methodology 3 — RoboCasa GR1·실제 IRON 로봇 두 벤치마크 비교, 액션-only 반사실 개입 대조군까지 포함한 통제 실험 제시
- Sim2Real 2 — 실제 IRON 휴머노이드 로봇에서 개선 확인, 다만 abstract 수준에서 구체 성공률 수치는 미확인
