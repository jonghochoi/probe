## 🥇 논문 1 — 우선순위 ★★★

**Learning Action Priors for Cross-embodiment Robot Manipulation**
[arXiv:2606.26095](https://arxiv.org/abs/2606.26095) · Dong Jing, Tianqi Zhang, Jiaqi Liu, Jinman Zhao, Zelong Sun, Li Erran Li, Zhiwu Lu, Mingyu Ding · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **기존 VLA의 구조적 병목 명시** — VLM 백본에 액션 모듈을 부착 후 처음부터 공동 학습 시, 액션 모듈이 시각-언어 크로스 정렬과 시간적 운동 구조 학습을 동시에 수행해야 하는 이중 부담 발생; 크로스-에브디먼트 환경에서 부담 심화
- **2단계 프레임워크**:
  - **Stage 1** — 가벼운 flow-matching 인코더-디코더 액션 모듈을 시각·언어 토큰 없이 레이블 없는 행동 궤적(unconditioned action trajectories)만으로 독립 사전 학습 → 크로스-에브디먼트 시간적 운동 구조 습득
  - **Stage 2** — Stage 1 디코더를 재사용 + 초기 단계 잠재 증류(early-stage latent distillation)로 시각-언어 특징을 액션 임베딩 공간과 정렬; 전체 end-to-end 미세조정 허용
  - **히스토리 인코더** — Stage 1 인코더가 상태-행동 이력을 단일 시간적 컨텍스트 토큰으로 압축 → 추가 비용 없이 이력 인식 모델링 제공
- **실험**: 시뮬레이션 + 실세계 플랫폼 통합 13개 크로스-에브디먼트 태스크; 사전 학습 없는 VLA 대비 빠른 수렴, 높은 성공률, 데이터 희소 실세계 태스크에서 실질적 향상; Stage 1 행동 데이터 규모 확대 시 다운스트림 VLA 성능 직접 향상
- **진정으로 새로운 점** — 레이블 없는 행동 궤적만으로 액션 모듈을 독립 사전 학습한 뒤 VLM 정렬을 수행하는 2단계 구조 최초; 별도 사전 학습된 디코더 재사용 + 잠재 증류 결합

### (c) 시사점

- **액션 전문가 독립 사전 학습의 외부 정당화** — VLM 백본 정렬 전에 운동 구조를 먼저 학습하면 학습 효율·성능이 모두 향상됨을 직접 실증; 바디·핸드 액션 전문가를 백본과 별도로 초기화·사전 학습하는 아키텍처 분리의 독립 근거 확보
- **디코더 재사용(Stage 2) 패턴** — Stage 1에서 학습한 디코더를 재사용하는 방식이 π0 행동 전문가 슬라이싱(D7 v1) 방향성과 구조적으로 수렴; "행동 전문가 분리 초기화 후 VLM 정렬"이라는 공통 설계 경로 재확인
- **규모 확장 경로** — 레이블 없는 행동 데이터로 Stage 1 독립 확장 가능; 핸드 운동 궤적 데이터를 별도 확장해 핸드 액션 전문가 품질만 독립 향상할 수 있는 경로 시사

### (d) 먼저 확인할 점

- **코드 미공개** — 제출 2일 후; flow-matching 인코더-디코더 세부 구조·Stage 1 학습 데이터 형식 본문 확인 필요
- **고-DoF 다지 조작 태스크 포함 여부** — 13개 크로스-에브디먼트 태스크가 손목 포즈 수준 조작인지 고-DoF 손가락 관절 포함인지 본문에서 확인 필요
- **저렴한 점검** — Stage 1을 바디(손목 포즈) 전용과 핸드(손가락 관절) 전용 궤적으로 각각 사전 학습 후 Stage 2 성능 비교: 이질 분리 사전 학습이 합산 학습 대비 유리한지 소규모로 1차 확인 가능

## 🥈 논문 2 — 우선순위 ★★

**Flowing With Purpose: Latent Action Guided Flow Matching Policies For Robotic Manipulation**
[arXiv:2606.23420](https://arxiv.org/abs/2606.23420) · Bruno Machado, Alexandre Chapin, Emmanuel Dellandrea, Liming Chen · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **기존 flow-matching 정책의 구조적 불일치 명시** — state-of-the-art flow matching 정책들이 전 태스크에 걸쳐 고정된 등방성 가우시안(isotropic Gaussian) 소스 분포를 사용하지만, 실제 로봇 행동 공간은 강하게 단편화(fragmented)되어 있고 이분산성(heteroscedastic) 구조를 가짐; 등방성 초기화가 고도로 얽힌 벡터 필드(highly entangled vector fields)를 학습하도록 강제 → 학습 효율 저하 및 성능 한계
- **LAFM(Latent Action Guided Flow Matching) 프레임워크**:
  - 단일 고정 가우시안을 **학습된 사전 분포 라이브러리(adaptive library of learned prior distributions)**로 대체
  - 잠재 행동 모델(latent action model)이 현재 관측을 이산 운동 원시 패턴(discrete motion primitives)에 매핑 → 구조적으로 정렬된 전문화 기반 분포(specialized base distribution) 선택
  - 이분산성을 자연스럽게 수용; 전달 궤적(transport trajectories)이 더 짧고 덜 얽힘
- **성능** — 실세계 배포 성공률 +23.4%(절대값), LIBERO-90 벤치마크 +10.4%; 훨씬 작은 아키텍처로 대규모 VLA 사전 학습 모델 능가

### (c) 시사점

- **이분산 행동 공간이 단일 소스 분포를 실패시킨다는 직접 증거** — 손목 포즈(바디)와 손가락 관절(핸드)은 통계적으로 이질적인 분포를 가짐; 단일 가우시안으로 처리하는 것이 구조적으로 잘못됐다는 정량 근거 제공
- **D1·D3 v1 선택의 이분산성 관점 정당화** — 바디·핸드 출력을 별도 분포로 처리하는 분리 헤드 아키텍처가 단일 소스 분포 디코더 대비 수렴성·성능에서 유리함을 이론적·실험적으로 뒷받침; CoorDex(2026-06-24 ★★★)의 RL 수렴 근거와 독립적으로 일치
- **소형 모델로 대형 VLA 능가 패턴** — 분포 정렬 설계만으로 사전 학습 규모 차이 극복; 이질 분리 아키텍처 자체가 스케일 효율성 제공 가능성 시사

### (d) 먼저 확인할 점

- **코드 미공개** — 잠재 행동 모델 구조·사전 분포 라이브러리 수 설정 방법 본문 확인 필요
- **고-DoF 다지 조작 공간 적용성** — 논문이 주로 손목 포즈 수준 태스크를 대상으로 실험했을 가능성; 손가락 관절 공간은 단편화 정도가 훨씬 커 LAFM 이점이 더 클 수도 있으나 별도 검증 필요
- **저렴한 점검** — 표준 π0 flow-matching baseline에 LAFM 소스 분포 적용: 바디·핸드 이분산성 공간에서 수렴 속도 차이 소규모 측정으로 D3 v1 설계에 대한 1차 민감도 추정 가능

## 🥉 논문 3 — 우선순위 ★

**LaST-HD: Learning Latent Physical Reasoning from Scalable Human Data for Robot Manipulation**
[arXiv:2606.23685](https://arxiv.org/abs/2606.23685) · Jiaming Liu, Yinxi Wang, Chenyang Gu, Siyuan Qian, Xiangju Mi, Hao Chen, Jiawei Chen, Qingpo Wuwu et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **배경 문제**: 기존 역방향 키네매틱스 기반 리타게팅은 기하학적 대응만 확립하고 물리적 동역학 정렬 미반영 → 인간-로봇 간 실제 접촉 품질 차이 미해소
- **LaST-HD 패러다임**:
  - "reasoning-before-acting" VLA를 기반으로, 인간-핸드·로봇 시연을 **공유 잠재 추론 공간(shared latent reasoning space)**에서 정렬
  - 보조 **행동 조건화 세계 모델(action-conditioned world model)**을 비쌍(unpaired) 인간-핸드·로봇 궤적에서 학습 → 공유 잠재 타깃 합성
  - 공유 순방향-역학 공간(shared forward-dynamics space)에서 크로스-에브디먼트 표현 정렬 → 잠재 추론 과정 직접 감독
- **OOL Glove(Out-of-Lab)** — 저비용 모션 캡처 글러브: 정밀 키포인트 + 그리퍼·다지 핸드에 범용 행동 감독으로 활용 가능
- **학습 레시피**: 혼합 인간-로봇 공동 학습(mixed co-training) → 인간 핸드 온라인 교정 후 학습(online correction post-training)
- **성능**: 신규 객체·장면·위치에서 일반화; OOL Glove 20분 데이터만으로 90%+ 정확도 달성

### (c) 시사점

- **핸드 조인트 명령 학습의 데이터 병목 해소 경로** — 기하학 정렬만으로는 불충분한 핸드 학습에서, 공유 잠재 추론 공간을 통해 물리적 동역학까지 정렬하면 데이터 효율이 극적으로 향상; 핸드 전문가(D3) 훈련 데이터 확보 비용 대폭 절감
- **저비용 인간 핸드 데이터 수집 파이프라인 확인** — OOL Glove 20분 → 90%+ 정확도 패턴; 다지 핸드 시연 규모 확장 근거, 핸드 액션 전문가 사전 학습 데이터 확보 방법론
- **VLA 백본 통합 방향 참조** — "reasoning-before-acting" VLA 확장 방식이 π0 계열 백본에도 원칙적으로 적용 가능; 인간 핸드 데이터를 기존 VLA 잠재 공간에 직접 정렬하는 경로 시사

### (d) 먼저 확인할 점

- **고-DoF 다지 핸드 성능 수치 별도 확인** — 그리퍼·다지 핸드 모두 지원한다고 명시했으나 20+ DoF 핸드에서의 성능 수치와 실패 모드 개별 확인 필요
- **비쌍 데이터 요건** — 행동 조건화 세계 모델이 비쌍 인간-로봇 궤적을 사용하는데, 로봇 기준 시연 데이터의 최소 요구량 확인 필요
- **저렴한 점검** — OOL Glove 데이터를 Leap Hand 또는 Inspire Hand 규격으로 리타게팅 시 기하학 차이에 따른 잠재 공간 정렬 품질 저하 여부 소규모 실험으로 1차 확인 가능
