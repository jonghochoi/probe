## 🥇 논문 1 — 우선순위 ★★★

**Learning Robust Dexterous In-Hand Manipulation from Joint Sensors with Proprioceptive Transformer**
[arXiv:2605.21330](https://arxiv.org/abs/2605.21330) · Senlan Yao, Chenyu Yang, Jaehoon Kim, Aristotelis Sympetheros, Robert K. Katzschmann (ETH Zurich) · source: keyword-sweep (cs.RO proprioceptive dexterous finger)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **Proprioceptive Transformer(PT)** — tendon-driven 다지 핸드에서 시각·촉각 입력 없이 손가락 관절 센서(joint sensing)만으로 연속 정육면체 회전(cube rotation) 수행
  - 던지는 질문 — 모터 엔코더 vs. 직접 관절 측정 중 더 나은 고유수용(proprioceptive) 피드백 제공처, 관절 측정치에서 환경 정보 추출 방식, 외부 지각(exteroception) 없는 경쟁적 실세계 성능 달성 여부
- **공백** — 기존 다지 핸드 조작은 물체 상태 추적에 시각·촉각 감지를 필수 입력으로 전제, 특히 tendon-driven 핸드는 모터-관절 비선형성이 커 관절 센서만으로 정보 부족이 통설
- **학습 체계** — 특권 물체 정보(privileged object information)로 RL 학습한 교사 정책을 관절 위치·속도 이력만 입력으로 쓰는 학생 정책으로 증류(distillation)
  - Transformer가 시간적 패턴에서 암묵적 물체 상태 정보 추출에 특히 효과적
- **결과** — 실세계 ORCA 핸드에서 기준선 대비 3.1배 빠른 회전 속도, 큐브 위치 추정 RMSE에서 MLP 기준선 대비 23.4% 낮은 오차
  - 핀 논문 중 tendon-driven 다지 핸드에서 시각·촉각 없이 이 수준 인핸드 조작 달성 사례 부재

### (c) 시사점

- **관절 명령 인터페이스 정보 용량 검증** — 관절 명령이 단순 출력만이 아니라 충분한 상태 추정 정보를 내포, 관절 위치·속도 이력에서 물체 pose를 암묵 추론 가능
- **프로프리오셉션 1순위 근거** — 시각·촉각 없는 성공이 핸드 입력 모달리티 분리에서 프로프리오셉션 채널의 1순위 위치를 뒷받침, 촉각 채널 역할 조정 시 참고 기준점
- **외부 성능 기준점** — 3.1배 속도 향상이 관절 센서 기반 인핸드 조작의 새로운 성능 기준점

### (d) 먼저 확인할 점

- **단일 task 특화** — RL + 특권 교사 증류로 단일 고정 task(정육면체 연속 회전)에 특화, 파지·삽입·조립 등 task 다양성 하에서 관절 이력 기반 물체 상태 추정 유지 여부 미검증
- **하드웨어 적합성** — ORCA 핸드(직접 관절 측정 가능) 전제, tendon 경로·센서 노이즈 특성이 다른 Sharpa·xhand에서 동일 Transformer 구조 동작 여부 미확인
- **저비용 점검** — task 다양성 2~3개로 늘린 소규모 IL 실험에서 관절 이력 기반 물체 상태 추정 오차 측정

## 🥈 논문 2 — 우선순위 ★★

**Phase-Conditioned Imitation Learning with Autonomous Failure Recovery for Robust Deformable Object Manipulation**
[arXiv:2605.29407](https://arxiv.org/abs/2605.29407) · Dayuan Chen, Kai Tang, Yukuan Zhang, Kazuhiro Kosuge, Y. Hirata · source: keyword-sweep (cs.RO action chunking separate arm)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4)

### (b) 핵심 기여

- **FiLM 조건부 ACT 인코더(FiLM-conditioned ACT encoder)** — 변형 가능 물체(deformable object) 조작용 계층적 모방 학습 프레임워크, 현재 task phase에 따라 FiLM이 인코더 feature 추출을 변조(modulate)
  - 단일 통합 정책이 phase-specific 행동 생성과 다단계 액션 다이나믹스 공유를 동시 달성
- **공백** — 기존 ACT 계열 모방 학습은 마르코프 가정에 의존, 시각적으로 유사하나 상이한 액션이 필요한 상태 충돌(state aliasing)에 취약
- **새로운 점** — FiLM 변조가 feature 공간에서 phase-specific 분리를 유도(t-SNE 분석으로 확인)
  - Ablation에서 FiLM 변조 > 비조건 기준선 > 토큰 수준 조건화 순으로 성능 우월 (실세계 검증)
- **결과** — 다관절 듀얼암 T-shirt 걸기·제거 task에서 닫힌 루프 자율 오류 복구로 성공률 56% → 87% 향상, 코드·영상 공개(https://leledeyuan00.github.io/phaser/)

### (c) 시사점

- **바디→핸드 conditioning 동형 증거** — task phase conditioning이 바디 액션이 핸드 헤드 입력을 변조하는 구조와 동형, FiLM이 명시적으로 작동하는 외부 ablation 증거 확보
- **단일 지점 FiLM 우위 근거** — FiLM single-point 변조가 토큰 수준 조건화를 능가, 단순 변조 경로 선택의 외부 근거
- **저차원 병목 힌트** — multi-modal phase predictor(vision + force + pose 융합)에서 phase를 저차원 임베딩으로 압축해도 충분 분리 달성 시, 바디 액션 → 변조 경로도 저차원 병목 구성이 안정적

### (d) 먼저 확인할 점

- **이산 phase 입력 전제** — FiLM 입력이 사전 정의된 이산 task phase(접근·접촉·걸기), 연속 바디 액션 벡터가 입력일 때 변조 생성 네트워크 표현력 미검증
- **그리퍼 한정** — deformable object task가 finger joint DoF 없는 일반 그리퍼 듀얼암 시나리오, 다지 핸드 고 DoF 출력 공간(20+ DoF)에서 동등 feature 분리 유도 여부 별도 검증 필요
- **저비용 점검** — 바디 액션을 이산화(phase codebook, K=8)한 버전과 연속 직접 입력 버전의 핸드 정책 학습 안정성 비교

## 🌱 논문 3 — 인접 분야 픽 (2026년 6월 첫 런)

**IsaacIPC: Coupling High-Fidelity Simulation and Realistic Rendering for Contact-Rich Robotic Systems**
[arXiv:2605.24339](https://arxiv.org/abs/2605.24339) · Qixin Liang, Zhongqing Han · adjacent field: 접촉 역학 시뮬레이션 / 컴퓨터 역학

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **IsaacIPC** — GPU 가속 Incremental Potential Contact(IPC) 시뮬레이션을 IsaacSim/Lab과 결합한 접촉 집약적 로봇 시스템용 시뮬레이션 프레임워크
- **공백** — 기존 시뮬레이터(MuJoCo·IsaacSim)는 GPU 속도와 렌더링 현실성을 분리 파이프라인으로 처리, 접촉 모델이 마찰 cone 근사에 머물러 세밀한 촉각 압력 분포 재현 불가
- **GMCP(Geometric Mortar Contact Potential)** — 촉각 표면 접촉 샘플에 배리어 포텐셜(barrier potential)을 정의해 기존 시뮬레이터보다 정밀한 접촉 압력 분포 재현
  - IPC 배리어 포텐셜 GPU 가속
  - 변형 메시(deformation mesh)를 시뮬레이션-시각 메시 간 매핑해 실시간 사실적 렌더링 통합
- **결과** — 다지 핸드·UMI 그리퍼 시뮬레이션에서 기존 접촉 벤치마크 대비 향상된 압력 정확도 보고

### (c) 시사점

- **촉각 데이터 합성 인프라** — 핸드 전문가 학습 때 촉각 데이터를 시뮬레이션에서 생성할 경우, GMCP 기반 시뮬레이터가 실제 촉각 센서(Sharpa fingertip 어레이 등) 압력 분포와의 Sim2Real 갭 축소 경로 제공
- **전환 가능 입력 설계** — 촉각 입력 소스를 real / simulated 전환 가능한 인터페이스로 설계하고 simulated GMCP 데이터 사전 학습 후 real sensor fine-tuning 방식 검토 가치

### (d) 먼저 확인할 점

- **실세계 이전 미보고** — 실세계 로봇으로의 실제 Sim2Real 이전 결과 미보고, GMCP 압력 정확도 향상이 실제 다지 핸드 탄성·마찰 특성과의 일치로 이어지는지 별도 검증 필요
- **스택 교체 비용** — IsaacSim/Lab 의존성으로 기존 MuJoCo 기반 스택과 교체 비용 존재
- **사전 점검** — GMCP 생성 촉각 데이터 학습 정책 vs. real sensor 데이터 학습 정책의 성능 갭을 pinch grasp task에서 측정

## 💡 컨텍스트 제안

### Tracked literature

- **대상** — Proprioceptive Transformer(arXiv:2605.21330), 이번 런 최고 점수(12/12)이자 finger joint command 인터페이스의 정보 용량을 직접 검증하는 비핀 방법론 베이스
- **제안** — D3 v1 finger joint command 핸드 입력 파이프라인 검증 사례로 비핀 방법론 목록 추가 검토

### Decision Log

- **D3 deferred 조건 재검토** — 근거 Proprioceptive Transformer(2605.21330). finger joint command가 단일 task에서 3.1배 회전 속도 달성, 단 RL + 특권-증류 체계 결과로 IL 기반 멀티태스크 재현 미확인. D3 deferred 트리거("stiff position control causes excessive contact force") 유지, 트리거 조건에 "IL 기반 멀티태스크에서 joint command tracking 오차 > 5 deg" 추가 제안
- **D4 FiLM 구현 우선순위 확인** — 근거 Phase-Conditioned IL(2605.29407). FiLM single-point > token-level conditioning ablation 확인. D4 v1 single-point FiLM 구현을 첫 실험에서 우선 채택, D4 deferred(cross-attention, multi-layer) 발동 트리거를 "single-point FiLM로 contact precision metric < 목표치"로 구체화 제안
