## 🥇 논문 1 — 우선순위 ★★★

**A Minimalist Retargeting-Guided Reinforcement Learning Recipe for Dexterous Manipulation (REGRIND)**
[arXiv:2607.11874](https://arxiv.org/abs/2607.11874) · Yunhai Feng, Natalie Leung, Jiaxuan Wang, Lujie Yang, Haozhi Qi, Preston Culbertson · source: keyword-sweep / π0 citation-graph

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **핵심 문제 정의**: 인간 동작 리타겟팅→RL 레시피가 로코모션에서 성공한 이유는 접촉이 단순하기 때문 — 다지 조작은 접촉 모드·접촉력 정밀 제어가 근본적으로 다르며, 기존 키포인트 추적만으로는 동역학이 무너짐을 실증
- **REGRIND 파이프라인**: 단 하나의 인간 시연으로 다지 조작 정책 학습 — (1) 손-물체 운동을 로봇 기준 참조 동작으로 리타겟팅(공간·접촉 관계 명시 보존), (2) 물체 중심 키포인트 추적 잔여 RL 정책 시뮬레이션 학습, (3) 시스템 식별 기반 제로샷 실기 이전
- **다지 손 범용성**: Allegro Hand + LEAP Hand 2종 플랫폼에서 동일 파이프라인으로 가위 사용·나사 돌리기 등 접촉 집약적 도구 사용 태스크 성공 — 인간다운 유동적 손 동작 구현
- **Sim-to-Real 인과 분석**: 시스템 식별 파라미터 × 보상 설계 × 참조 추적 강도의 구조적 ablation — 다지 조작 시뮬→실기 이전의 핵심 변수 실험적 규명
- **코드·영상 공개**: https://yunhaifeng.com/REGRIND

### (c) 시사점

- **손가락 관절 직접 RL 유효성 확인**: 잠재 공간 경유 없이 손가락 관절 명령 공간에서 잔여 RL이 단일 시연으로 접촉 집약적 도구 사용 달성 — 손 출력 공간의 직접 RL 최적화 가능성을 2종 플랫폼에서 실증
- **단일 시연 확장성**: 고품질 다량 시연 없이 한 번의 인간 시연 + 리타겟팅만으로 접촉 집약적 도구 사용 달성 — Hand Expert 학습 데이터 효율 경로로 직접 참조 가능
- **접촉 관계 보존 리타겟팅**: 손-물체 공간적·접촉적 관계를 명시적으로 보존하는 리타겟팅이 계층적 손 동작 생성 방식 설계에 참조 가능

### (d) 먼저 확인할 점

- **도구 사용 태스크 한정**: 가위·나사돌리기 2개 태스크 — 보다 다양한 접촉 패턴(집기·삽입·조립 등)으로의 일반화 별도 확인 필요
- **팔(arm) 통합 부재**: 손 단독 조작 설정 — Body/Hand 결합 아키텍처에서 팔 동작과 손 잔여 RL의 상호작용 설계 별도 필요
- **시뮬레이터 의존성**: 시스템 식별 기반 sim-to-real — 플랫폼 변경 시 파라미터 재식별 비용 발생

## 🥈 논문 2 — 우선순위 ★★

**Towards Human-level Dexterous Teleoperation (TeleDexter)**
[arXiv:2607.11481](https://arxiv.org/abs/2607.11481) · Puhao Li, Zeyuan Chen, Yingying Wu, Pengkun Wei, Yuyang Li, Tianyu Wang et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **TeleDexter**: 조작자 의도를 학습된 저수준 접촉 실행으로 변환하는 손-물체 동시 추적 컨트롤러 — 키포인트 추적만으로는 물체 재배향·도구 사용에서 실질적 물리 접촉이 성립하지 않는 한계를 접촉 실행 레이어로 해결
- **학습 구조**: 인간 참조 동작에서 추출한 연속 co-tracking 서브골 기반, 희소 서브골 목표와 밀집 추적 보상 결합 하이브리드 보상 — 단일 단계 RL, 무작위 액션 마스킹·도메인 랜덤화로 제로샷 실기 이전
- **다지 손 범용성**: 물체 재배향·장기 도구 사용 7개 태스크, 다지 손 2종 플랫폼, 전 기준선 실패 대비 평균 75% 성공률 달성
- **BC 정책 생성 검증**: TeleDexter 수집 시연으로 행동 복제(BC) 자율 정책 학습 성공 — 텔레옵 수집 데이터가 자율 정책 학습에 충분한 품질임을 실증

### (c) 시사점

- **접촉 실행 레이어의 필요성 실증**: 키포인트 추적만으로는 물리 접촉이 달성되지 않는다는 대조 실험 근거 — 손 출력 공간에서 단순 궤적 추적을 넘어 명시적 접촉 조건화가 필요함을 지지
- **2단 손 제어 구조의 효과 확인**: 서브골(고수준)→접촉 실행(저수준) 2단 구조가 7개 태스크에서 단일단계 기준선 대비 압도적 성능 격차 — 분리 구조(고수준 의도+저수준 실행)의 실환경 검증
- **BC 데이터 생성 경로**: TeleDexter 시연→자율 BC 정책 루프가 Hand Expert 학습 데이터 수집 경로로 활용 가능 — 고품질 다지 조작 데이터 획득 비용 절감 방향

### (d) 먼저 확인할 점

- **코드·데이터 미공개**: arXiv 기준 공개 코드 없음 — 재현 불가, 공개 여부·시점 모니터링 필요
- **플랫폼 미명시**: 다지 손 플랫폼 구체적 기술 부재 — 타 embodiment 전이 가능성 논문 본문 별도 확인 필요
- **팔 동작 분리 불명시**: 손 단독 텔레옵 설정인지 팔+손 통합 설정인지 논문 본문 확인 필요 — Body/Hand 결합 아키텍처와의 직접 대응 여부 검토

## 🥉 논문 3 — 우선순위 ★

**Mixture of Frames Policy: Multi-Frame Action Denoising for Bimanual Mobile Manipulation (MoF)**
[arXiv:2607.11884](https://arxiv.org/abs/2607.11884) · Dian Wang, Jisang Park, Xiaomeng Xu, Han Zhang, Shuran Song, Jeannette Bohg · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **핵심 관찰**: 단일 좌표계 액션 표현이 이분 조작 실패의 구조적 원인 — 말단장치 프레임에서 단순한 로컬 동작이 베이스 정렬 프레임에서는 복잡한 분포가 되는 비대칭 구조 실험적 확인
- **MoF(Mixture of Frames Policy)**: 단일 정준(canonical) 확산 상태를 복수의 태스크 관련 좌표계로 재표현, 프레임별 전문 디노이저 적용, 정준 프레임으로 노이즈 예측 합산 — SE(3) 컬럼 기반 6D 회전 표현으로 노이즈 상태의 미분 가능 프레임 변환 지원
- **실험적 검증**: 시뮬레이션 9개 양팔 태스크에서 오라클 단일 프레임·표준 MoE 기준선 초과; 실기 2개 양팔 모바일 조작 태스크에서 전 단일 프레임 기준선 초과
- **프레임 선택의 태스크 의존성**: 최적 좌표계가 태스크별로 다름을 실증 — 단일 고정 프레임 가정의 구조적 한계 명시

### (c) 시사점

- **Body 출력 좌표계 선택의 실증 근거**: end-effector 프레임과 베이스 정렬 프레임 선택이 성능에 직접 영향 — 양 손목/말단장치 자세 표현 설계 시 단일 프레임 고정 가정 재검토 근거 마련
- **프레임 전문화 = 암묵적 행동 분리**: 프레임별 전문 디노이저가 공유 트렁크 위에서 동작하는 구조는 분리 헤드 아키텍처의 양팔 조작 측 구현 사례 — 분리 구조 유효성의 양팔 측 지지
- **실기 양팔 모바일 조작 검증**: 실제 모바일 양팔 로봇에서 프레임 혼합 정책의 우위 확인 — 좌표계 설계 논의를 실환경으로 직접 연결하는 드문 사례

### (d) 먼저 확인할 점

- **손가락 수준 분리 부재**: 프레임 분리가 양팔(wrist) 수준에 한정 — 손가락 관절 명령(Hand Expert)까지 프레임 분리 확장 여부 논문 본문 확인 필요
- **코드 미공개**: 프로젝트 페이지(mofpo.github.io) 존재, 코드 공개 미확인
- **손가락 접촉 집약적 과제 부재**: 9개 시뮬+2개 실기 태스크가 양팔 이동·배치 중심 — 다지 접촉 집약적 과제에서의 검증 별도 확인 필요
