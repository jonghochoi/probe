**Hierarchical Policy Learning via Spectral Decomposition**

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **주파수 분해 기반 시맨틱 분해** — DCT(이산 코사인 변환) 분석으로 로봇 행동 시퀀스에 두 계층이 실존함을 실증: 저주파 성분 = 전체 궤적(글로벌 모션 의도), 고주파 성분 = 접촉·타이밍·정렬(실행-레벨 정제)
- **Causal Spectral Policy (CSP)** — 인과적 조대-세밀 (coarse-to-fine) 생성 구조: 관측·언어 조건에서 글로벌 모션 예측 후, 예측된 글로벌 모션을 조건으로 실행 세부 정보 정제
- **신규성** — 스펙트럼 도메인에서 태스크-레벨 모션 의도와 실행-레벨 정제의 분리 가능성을 체계적으로 입증한 첫 시도

### (c) 시사점

- **D6 설계 독립 검증** — "글로벌 바디 모션(저주파) 먼저, 접촉·정밀 실행(고주파) 나중"의 인과 방향이 스펙트럼 분석으로 실증적 근거 확보
- **바디→핸드 계층 흐름의 주파수 해석** — Body 전문가 출력(광역 궤적)이 저주파에 대응하고, Hand 전문가 출력(접촉 정밀도)이 고주파에 대응하는 주파수 도메인 유추 제공
- **코어스-투-파인 합성 가능성** — 현재 FiLM 컨디셔닝 방식과 주파수-분리 방식을 비교 검토할 수 있는 비교군 프레임워크

### (d) 먼저 확인할 점

- **실제 로봇 검증 여부 미확인** — 초록 상 실제 로봇 실험 언급 없음; 시뮬레이션 전용 가능성 확인 필요
- **저주파 모션과 Body 출력 공간 일치 여부** — DCT 저주파가 "양손목/공구 플랜지 포즈"와 동일 스케일인지, 고주파가 "손가락 관절"에 실제로 대응하는지 검증 필요
- **인과 방향 제약의 의존성** — 글로벌 모션 예측 오류가 실행 정제에 누적 전파되는 구조적 취약점 확인

**UniTacVLA: Unified Tactile Understanding and Prediction in Vision Language Action Models**
[arXiv:2606.31723](https://arxiv.org/abs/2606.31723) · Xidong Zhang, Yichi Zhang, Jiaxin Shi, Fucai Zhu · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

- **기존 VTLA 한계 진단** — 기존 Vision-Tactile-Language-Action 방법은 촉각 신호를 수동적 보조 입력으로만 처리 → 촉각 의미론 및 미래 물리적 상호작용 모델링 불가

- **신규성** — 촉각을 단순 보조 입력에서 시맨틱 예측 대상으로 격상; 접촉-집약적 다지 조작에서 VLA의 촉각 맹점 해소

### (c) 시사점

- **촉각 독립 모달리티 분리 필요성 실증** — 시각만으로는 접촉력 정보 불충분; 촉각을 독립 입력 채널로 분리해 다지 조작 VLA에 통합하는 것이 실질적 성능 향상으로 이어짐
- **수동 보조 vs 능동 예측의 설계 선택지 제시** — 두 방식의 성능 차이가 입력 모달리티 분리 설계(D5)에서 촉각 처리 방식을 구체화하는 데 직접 활용 가능
- **접촉 집약적 조작 벤치마크 레퍼런스** — 촉각 통합 VLA 비교 기준점으로 활용 가능

### (d) 먼저 확인할 점

- **2026-06-30 제출 최신 논문** — 코드/데이터 미공개 가능성 높음; 재현성 확보 시점 확인 필요
- **촉각 센서 종류 및 배치 특이성** — 어떤 종류의 촉각 센서(지압, 비주오택타일 등)를 어느 손가락 부위에 배치하는지; 우리 하드웨어 구성과 호환성 확인

## 🥉 논문 3 — 우선순위 ★

**DexCompose: Reusing Dexterous Policies for Multi-Task Manipulation with a Single Hand**
[arXiv:2606.28323](https://arxiv.org/abs/2606.28323) · Dihong Huang, Zhenyu Wei, Zhuxiu Xu, Yunchao Yao · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **문제 정의** — 단일 손으로 여러 태스크 동시 수행 시, 겹치는 손가락과 접촉 모드에서 충돌하는 요구가 기존 정책 간 파괴적 간섭(destructive interference) 발생
- **Role-Aware Residual Composition** — 각 손가락에 명시적 태스크 소유권(ownership) 부여: 어느 손가락이 어느 태스크의 동작을 담당하는지 명시적 파티셔닝
- **잔차 합성(residual composition)** — 사전 훈련된 전손가락-정책(full dexterous policy) 재사용; 새 태스크 추가 시 기존 정책 보존하며 잔차만 학습

### (c) 시사점

- **손가락-레벨 역할 분리의 효용성 실증** — Body/Hand 전문가 분리 개념의 세밀화 버전; 역할 명시화 없이 단순 합산하면 파괴적 간섭이 발생함을 정량적으로 보임
- **소유권 기반 파티셔닝 원리** — 손가락 관절 명령 공간에서 "역할 명시화 → 간섭 방지"가 효과적이며, 액션 공간 분리 설계 시 소유권 개념이 핵심임을 시사
- **정책 재사용성 향상** — 잔차 합성으로 새 태스크 추가 비용을 낮추는 구조 → 도입 후 기능 확장 비용 저감 가능

### (d) 먼저 확인할 점

- **실제 로봇 실험 비율** — 초록에 시뮬레이션 vs 실제 검증 비율 미명시; 논문 본문에서 실제 로봇 태스크 수·태스크 종류 확인 필요
- **손가락 DoF 커버리지** — 실험이 2–3 손가락 부분 태스크에 집중하는지, 전체 손가락 DoF를 사용하는 일반적 사례에서도 성립하는지 확인
- **소유권 할당 방법** — 역할(소유권) 할당이 수작업 설계인지 자동 학습인지; 새 태스크 추가 시 소유권 재할당 절차 확인

## 🥉 논문 4 — 우선순위 ★

**SA-VLA: State-aware Tokenizer for Improving Vision-Language-Action Models**
[arXiv:2606.30113](https://arxiv.org/abs/2606.30113) · Tengyue Jiang, Chunpu Xu, Jiayue Kang, Yao Mu · source: citation-graph (π0 + Dexora)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **문제 진단** — 자기회귀 VLA의 이산 액션 토크나이저: 동일 이산 코드 → 고정 연속 액션 프로토타입 매핑 → 현재 관절 구성 무시로 인해 "동일 토큰, 다른 제어" 실패 발생
- **State-Aware Tokenizer** — 현재 고유감각(proprioceptive) 상태를 조건으로 이산 코드에서 연속 로봇 행동 복구; 동일 토큰도 현재 관절 구성·오브젝트 상태에 따라 다른 연속 명령 생성
- **신규성** — 이산 토크나이저와 연속 행동 복구 사이의 상태 컨디셔닝 갭을 최초로 체계적 정의 및 해결

### (c) 시사점

- **고유감각 컨디셔닝 필요성 실증** — 손가락 관절 명령 출력 시 현재 관절 구성에 따른 상태 컨디셔닝이 없으면 정밀 조작에서 체계적 오류 발생; 핸드 헤드 설계 시 상태 입력 포함 권고 근거
- **이산 vs 연속 액션 VLA 비교 기준** — 이산 토크나이저 방식의 한계를 명시화함으로써 플로우 매칭 등 연속 액션 방식과의 설계 선택 비교 시 체크포인트 제공
- **조작 태스크 특화 고유감각 활용** — 범용 VLA보다 조작 특화 VLA에서 고유감각 상태가 더 중요함을 실험적으로 보임

### (d) 먼저 확인할 점

- **손가락 관절 DoF 스케일 검증** — 논문이 wrist/end-effector 위주로만 평가하는 경우, 14+ DoF 손가락 관절 명령에서도 상태 컨디셔닝 효과가 유지되는지 별도 확인
- **고유감각 상태 입력 형식** — 관절 각도 직접 입력 vs 임베딩 방식; 손가락 관절 수가 많을 때 입력 차원 증가에 따른 처리 방식 확인
- **플로우 매칭 기반 정책과 비교** — 연속 액션 출력 방식(π0 스타일)과의 직접 비교 결과 유무 확인
