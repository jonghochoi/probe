## 🥇 논문 1 — 우선순위 ★★★

**T-Rex: Tactile-Reactive Dexterous Manipulation**
[arXiv:2606.17055](https://arxiv.org/abs/2606.17055) · Dantong Niu, Zhuoyang Liu, Zekai Wang et al. · source: keyword-sweep (dexterous manipulation tactile VLA)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **촉각 반응형 VLA의 구조적 장벽 명시** — 기존 VLA가 촉각 모달리티를 배제하거나 정적 인코더에 한정된 세 가지 원인 진단:
  - 다양한 촉각 학습 데이터 부재
  - 현행 VLA 단일 동기 클럭(synchronous clock) 제약 — 자연적으로 고주파인 촉각 신호를 시각 처리 속도에 강제 종속
  - 정적 촉각 인코더의 시계열 신호 처리 한계
- **가변 속도 전문가 혼합 트랜스포머(variable-rate Mixture-of-Transformers, MoT)** — 모달리티별 독립 속도로 업데이트하는 분리형 트랜스포머 전문가 구조
  - 촉각 전문가: 고주파 처리 (접촉 과도·transient 포착)
  - 시각·언어 전문가: 저주파 처리 (전역 씬 이해)
  - 기존 VLA 사전학습 역량을 보존한 채 촉각 채널만 선택적 고속 처리
- **시간적 촉각 VQ-VAE 인코더(temporal tactile VQ-VAE)** — 시계열 촉각 신호를 압축된 이산 토큰으로 변환, 접촉 변화율 명시적 보존
- **100시간 촉각 풍부 데이터셋** — 초등 모터 프리미티브 위주 레시피로 효율적 수집
- **진정으로 새로운 점**
  - 기존 VLA는 단일 동기 클럭으로 고주파 촉각 신호 처리 구조적 불가 → MoT로 클럭 의존성 해소한 최초 사례
  - 정밀 힘 제어·변형 가능 물체 조작 12개 실제 태스크에서 최강 기준선 대비 30%+ 성공률 향상

### (c) 시사점

- **D5 rate separation 최초 아키텍처 레벨 해법** — 이전 8회 런(MiTaS·TORL-VLA·CT-VAM·DAM-VLA·FTP-1 등)이 촉각·시각 처리 속도 분리 필요성을 데이터·센서 수준에서 누적 입증했다면, T-Rex는 가변 속도 MoT라는 아키텍처 구현체를 실제 로봇에서 처음 실증 — 촉각 채널을 시각 클럭과 독립 처리하는 작동 중인 VLA 아키텍처 확보
- **D1 MoT 분리 형태 원칙 공명** — 촉각·시각·언어 전문가를 독립 트랜스포머로 분리하는 MoT 구조는, 바디·핸드 전문가를 분리된 헤드로 운영하는 hybrid split 설계 원칙과 공명 — 속도(rate) 분리를 전문가(expert) 분리로 구현한 직접 참조 사례
- **핸드 전문가 고주파 채널 구현 경로** — temporal tactile VQ-VAE + variable-rate MoT 결합으로 다지 핸드 촉각 채널을 시각 처리 클럭과 독립 처리하는 구체 아키텍처 등장; 핸드 전문가 입력 경로 설계 시 즉시 참조 가능

### (d) 먼저 확인할 점

- **데이터 다지 핸드 비율 미확인** — 100시간 데이터가 그리퍼 기반인지 다지 핸드 전용인지 불명; 20+ DoF 다지 핸드에서 MoT가 손가락별 다채널 촉각 신호를 충분히 처리할 수 있는지 확인 필요
- **속도 배수(rate multiplier) 하이퍼파라미터** — 촉각·시각 처리 속도 비율 결정 방식 불명; 다지 핸드 환경의 최적 비율이 단일 그리퍼 환경과 다를 가능성
- **저렴한 점검** — 단일 손가락 삽입 태스크에서 T-Rex MoT(가변 속도) vs. 단일 속도 촉각 채널 비교, 접촉 과도 포착이 핀치 성공률에 미치는 영향 소규모 측정

## 🥈 논문 2 — 우선순위 ★★

**Universal Manipulation Exoskeleton: Learning Compliant Whole-body Policies with Real-time Torque Feedback**
[arXiv:2606.14218](https://arxiv.org/abs/2606.14218) · Litian Liang, Jingxi Xu, Xinda Qi et al. · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **수집 파이프라인의 힘·토크 데이터 공백 명시** — 기존 대부분의 데이터 수집 파이프라인이 힘·토크 신호 수집 미지원 → 능동 컴플라이언스(active compliant) 정책 학습 구조적 불가
- **UME(Universal Manipulation Exoskeleton)** — 상지 외골격으로 실시간 햅틱 토크 피드백 + 전완 구성 + 관절 토크 신호를 동시 기록
  - 저가·경량·휴대형, 내장 IMU로 모바일 조작 텔레오퍼레이션 지원
  - 범용 리타겟팅 알고리즘: 7DoF OpenArm, 7DoF Franka, 6DoF X-ARM 등 이종 로봇 동시 지원
  - 투명한 토크 피드백 — 운동학적 구속 물체를 시각 차폐(blindfolded) 상태에서도 분리 가능
- **능동 컴플라이언스 정책 통합 학습** — 양손(bimanual), 전신(whole-body), 능동 컴플라이언스 정책을 단일 파이프라인으로 학습
  - 장기 지평 모바일 조작, 힘 매개 박스 뒤집기, 시각 차폐 박스 밀기, 공간 제약 탁상 조작에서 높은 성공률 달성
- **진정으로 새로운 점**
  - 기존 데이터 수집 시스템 대다수 — 힘·토크 신호 미지원으로 능동 컴플라이언스 학습 불가
  - 저가 외골격으로 실시간 토크 피드백 + 이종 로봇 범용 리타겟팅 + 능동 컴플라이언스 정책 학습을 동시 실증한 최초 사례; 오픈소스 공개

### (c) 시사점

- **D2 바디 출력 공간 힘·토크 확장 외부 근거** — 순수 Cartesian 손목 포즈에 관절 토크 신호를 추가하면 능동 컴플라이언스·시각 차폐 조건에서도 성공적 정책 학습 가능; 바디 출력 공간에 힘/토크 신호 포함이 실용 배포 환경에서 중요함을 실세계 확인
- **양손 순종 정책 기준점 확보** — bimanual + whole-body 능동 컴플라이언스를 저가 외골격으로 달성; 다지 핸드 배포 환경에서 힘 제어가 필요할 때 참조 비용·성능 기준점 획득
- **오픈소스 파이프라인 즉시 진입 가능** — 코드·데이터 공개로 토크 인식 바디 전문가 데이터 수집 파이프라인을 별도 구축 없이 시작 가능

### (d) 먼저 확인할 점

- **손가락 레벨 토크 부재** — UME는 전완·어깨 수준 관절 토크 수집; 다지 핸드 손가락 끝 접촉력 동시 기록 경로는 별도 필요
- **다지 핸드 리타겟팅 미지원** — 범용 리타겟팅이 7DoF 암 로봇 수준을 지원하나 20+ DoF 다지 핸드 리타겟팅 지원 여부 불명
- **저렴한 점검** — 단순 삽입 태스크에서 관절 토크 피드백 유무 ablation; 바디 전문가 출력에 토크 신호 추가 시 접촉력 프로파일·성공률 변화 1차 측정

## 🥉 논문 3 — 우선순위 ★

**Hierarchical Advantage Weighting for Online RL Fine-Tuning of VLAs from Sparse Episode Outcomes**
[arXiv:2606.17043](https://arxiv.org/abs/2606.17043) · Tongyan Fang, Siyuan Huang, Naiyu Fang et al. · source: keyword-sweep (bimanual VLA hierarchical RL fine-tuning)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **희소 이진 에피소드 결과로 VLA를 온라인 RL 파인튜닝하는 신호 문제 명시**
  - 이진 성공/실패 단일 스칼라 신호가 "실현 가능성(viability)"과 "효율성(efficiency)" 두 목적을 혼합 → 기본 성공 달성 후 추가 기울기 없음
  - 자율 실행 구간·인간 개입 구간 혼재 시 에피소드 결과를 구간 전체에 무차별 부과 → 잘못된 크레딧 부여
- **HABC(Hierarchical Advantage-Weighted Behavior Cloning)** — 두 독립 크리틱 헤드로 계층적 어드밴티지 가중 행동 복제
  - **실현 가능성 크리틱**: 기본 목표 달성 여부 감독 — 성공 불확실 시 우선 활성화
  - **효율성 크리틱**: 완료 속도·품질 감독 — 실현 가능성 고도화 후 선택적 활성화
  - 상태 적응 게이트 $g_t$: 실현 가능성 상승 시 효율성 크리틱 가중치 자동 상향
  - 개입 인식 크레딧 부여: 자율 실행 구간에만 에피소드 결과 레이블 제한
- **실제 로봇 접촉 집약적 양손 조작 3개 태스크 검증**
  - SFT 기준선 36% → HABC 92% (+56%p)
  - SFT 기준선 44% → HABC 88% (+44%p)
  - SFT 기준선 12% → HABC 38% (+26%p)
- **진정으로 새로운 점**
  - 기존 VLA RL FT: 단일 스칼라 어드밴티지, 자율·개입 구간 크레딧 혼합
  - 실현 가능성·효율성 독립 크리틱 분리 + 개입 인식 크레딧 제한의 결합이 최초; 실제 로봇 접촉 집약 양손 태스크에서 최대 +56%p 달성

### (c) 시사점

- **VLA 백본 RL FT 다목적 분리 크리틱 이득 확인** — 단일 리워드가 아닌 두 목적 분리 크리틱이 최대 +56%p 성공률 향상; π0 백본 RL 파인튜닝 시 계층적 다목적 분리 구조의 실효성을 실제 로봇에서 확인
- **거시 목표 확보 후 미시 정밀화 계층 논리** — 실현 가능성 크리틱이 먼저 목표 접근을 보장하고, 이후 효율성 크리틱이 정밀도를 높이는 계층 구조; 바디가 물체 접근을 보장하고 핸드가 접촉 정밀도를 담당하는 D6 계층 흐름 원칙과 직접 공명
- **실세계 희소 결과 기반 VLA RL 파이프라인** — 희소 이진 에피소드 결과만으로 실제 로봇 접촉 집약 태스크에서 RL이 수렴한 실용 사례; 다지 핸드 전문가 RL FT 설계 시 참조 파이프라인 확보

### (d) 먼저 확인할 점

- **실험 태스크 범위 한계** — 3개 접촉 집약 양손 태스크 한정; 다지 핸드(20+ DoF) 인핸드 조작 환경에서 동일 이득 유지 여부 독립 확인 필요
- **효율성 크리틱 지표 정의 불명** — "효율성"이 완료 속도인지 접촉력 최소화인지 미명시; 다지 핸드 환경에서 효율성 지표 재설계 필요
- **저렴한 점검** — 단일 팔 + 그리퍼 삽입 태스크에서 HABC(이중 크리틱) vs. 단일 크리틱 RL 수렴 속도·성공률 비교, 계층 분리 이득 소규모 확인

## 🔄 직전 리포트 대비 종합

- **중복 없음** — 직전 4개 리포트(2026-06-15·2026-06-12·2026-06-10·2026-06-08) 수록 논문 전원과 이번 3편(T-Rex·UME·HABC) 중복 없음
- **D5 신호 9회 연속 + 아키텍처 전환점 도달** — 이전 8회 런(MiTaS·TORL-VLA·CT-VAM·DAM-VLA·FTP-1 등)이 rate separation 필요성을 데이터·센서·클럭 수준에서 누적 입증했다면, T-Rex는 가변 속도 MoT라는 아키텍처 레벨 구현체를 12개 실제 태스크에서 처음 실증 — D5 rate separation 트리거 발화 검토 시점 도달, 다음 런부터 핸드 전문가 입력 경로 전환 실험 설계 시작 권장
- **D2 두 번째 직접 신호** — UME가 관절 토크 신호 추가로 능동 컴플라이언스·시각 차폐 조건 정책 학습 달성; 이전 RealDexUMI(2026-06-08)가 wrist pose + finger joint command 공동 수집 경로를 제시했다면, UME는 바디 출력 공간에 힘/토크 신호 포함의 성능 이득을 정량화
- **D7 RL FT 신호 첫 등장** — HABC가 접촉 집약 양손 VLA RL FT에서 계층 분리 크리틱으로 최대 +56%p 달성; InDex(2026-06-12)가 D7 backbone FT 리스크를 확인했다면, HABC는 FT 이후 RL 단계에서 계층 분리 이득을 처음 정량화
