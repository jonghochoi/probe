## 🥇 논문 1 — 우선순위 ★★★

**ω-0: A Latent Predictive World Action Model for Concurrent Humanoid Loco-Manipulation**
[arXiv:2608.06375](https://arxiv.org/abs/2608.06375) · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **구조**: 언어 지시 + 현재 시각 관측 + 고유감각 상태 → 컨트롤러 호환 전신 액션 잠재 변수 직접 예측; 미래 비디오 재구성 없이 경량 잠재 예측 목표 사용
- **생성**: 확산 기반 전신 액션 생성 + 잠재 시각 예지 결합; 자기중심 RGB / 타자중심 RGB / 타자중심 Depth 입력 지원
- **그라운딩**: 컨트롤러 기반 시뮬레이션 재현으로 공개 시각-동작 사전 → 로봇 실행 가능 액션 잠재 접지
- **데이터**: ω-HOME — 40시간 이상 실제 가정환경 데이터 (멀티뷰 관측 + 전신 SMPL 동작 + 로봇 상태 + 액션 잠재 동기화)
- **결과**: 실제 로봇 11개 가정 태스크; 모방학습 / VLA / 인간형 / WAM 베이스라인 전원 능가; 단일 모델로 보행·조작 동시 수행

### (c) 시사점

- **비교 기준점 확보**: 전신 단일 잠재 생성 방식의 성능 상한 → Body/Hand 분리 구조의 차별점 검증에 필요한 baseline 확보
- **조율 방향 근거**: 논문 진단 — "기존 인간형 정책은 이동·조작을 분리"; 계층적 흐름(D6) 설계 방향과 일치; 동시 수행을 단일 잠재로 달성 시 훈련 복잡도 급증
- **데이터 프로토콜 참조**: SMPL 전신 동작 + 로봇 상태 동기화 방식 → Body/Hand 분리 데이터 수집 설계 참조 가능

### (d) 먼저 확인할 점

- **손가락 정밀도 미검증**: 보행+조작 동시 수행 중심 → 접촉 집약적 손가락 제어 정밀도 수치 부재; Hand 출력 공간 요건과 직접 비교 불가
- **컨트롤러 인터페이스 종속**: 컨트롤러 호환 잠재 변수는 특정 인터페이스 종속 → wrist+finger 분리 스택 이전 시 호환성 선행 확인
- **태스크 포화 미검증**: 11 가정 태스크 커버 확인 → 세밀한 손가락 조작 요구 태스크에서 성능 포화 여부 미검증

## 🌱 논문 2 — 인접 분야 픽

**CAAT: Contact-Aware Attention Scaling and Tactile Masking for Data-Efficient Contact-Rich Manipulation**
[arXiv:2608.01102](https://arxiv.org/abs/2608.01102) · adjacent field: visuo-tactile policy learning (P2) · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **문제**: 트랜스포머 기반 비주오택타일 정책의 토큰 연결·학습 가능 게이팅은 명시적 접촉 사전 부재 → 크로스모달 표현 학습 비효율
- **방법**: 접촉 전 시각 토큰 강조 / 접촉 중 촉각 토큰 강조; 비접촉 기준 촉각과 비교해 정적 배경 토큰 억제 (동적 촉각 마스킹)
- **설계 원칙**: 액션 디코더 수정 없이 ACT / Diffusion Policy / π0에 플러그인 가능 (경량 모듈식)
- **결과**: 시뮬레이션 ACT+CAAT — 직접 융합 대비 +18.0pp; 실세계 UMI 플랫폼 평균 60.0%, 최고 베이스라인 대비 +21.1pp

### (c) 시사점

- **접촉 단계 인식 신호의 효용**: 접촉 전후 최적 입력 모달리티가 달라짐 → Body→Hand 조율에서 접촉 이벤트 감지 시 Hand 입력 가중치 전환 설계 가능
- **FiLM 조건부 신호 확장 힌트**: 현 FiLM 조건부 신호(arm action)에 접촉 상태 임베딩 추가 → Hand 헤드 정밀도 향상 가능성; CAAT +21pp가 실증적 근거
- **관측 설계의 독립 기여 확인**: 액션 디코더 구조 변경 없이 관측 바인딩 레이어에서만 +21pp → 관측 설계와 액션 전문가 구조의 직교적 분리 원칙 실증

### (d) 먼저 확인할 점

- **촉각 센서 하드웨어 의존성**: UMI 플랫폼 촉각 센서 특화 → 우리 손 플랫폼의 촉각 인터페이스 호환 여부 선행 확인
- **접촉 감지 오류 전파**: 동적 마스킹은 접촉 이벤트 정확 감지 의존 → 감지 오류가 Hand 액션 품질 저하로 직접 전파
- **P2 영역 한계**: 핵심 기여는 관측 융합(P2) → P1 함의는 Hand 헤드 입력 설계에 국한; 전체 Body/Hand 분리 아키텍처 변경에 대한 함의는 간접적
