## 🥇 논문 1 — 우선순위 ★★★

**LAMP: Latent Motion Prior-Guided Real-World Learning for Dexterous Hand Manipulation**
[arXiv:2607.06323](https://arxiv.org/abs/2607.06323) · Xinye Yang, Zhiyuan Ma, Hongze Yu, Yuanpei Chen et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **문제 진단** — 고차원 손가락 관절 명령 공간에서 IL 오차 증폭 + RL 탐색 중 접촉 파괴(contact-breaking)가 실기 다지 조작 학습의 핵심 장벽임을 실증
- **잠재 모션 사전(Latent Motion Prior) 모듈** — 최근 손 동작 이력을 이력 조건부 잠재 사전으로 압축하고, 연속적 잠재 명령을 고차원 손 목표로 디코딩하는 경량 모듈 LAMP 제안
- **3단계 실세계 학습 프레임워크** — (1) 시연 데이터로 LAMP 사전학습, (2) 팔(arm) 네이티브 명령 + 잠재 핸드 오프셋을 동시 예측하는 비주모터 정책 학습, (3) 동일 잠재 공간에서 온라인 잔여 RL로 정책 개선
- **설계 핵심 — arm/hand 분리 인터페이스** — 팔 명령은 원래 표현 그대로(native), 손 명령만 잠재 공간 경유; 잔여 탐색이 접촉 일관적 손 동작 근방에서만 이루어지도록 제한해 하드웨어 안전성 확보
- **성과** — 실제 로봇 4개 다지 조작 과제, raw / linear / discrete 인터페이스와 비교: IL 단독 56.25% → RL 이후 98.75% 평균 성공률, 3개 과제 100% 달성

### (c) 시사점

- **손 출력 공간 설계 실증적 확인** — 원시 손가락 관절 명령 공간 대신 잠재 압축 공간을 경유하면 IL·RL 모두에서 현저히 효율적임을 실기 4과제로 확인; 손 출력 표현에 잠재 구조 도입의 타당성 지지
- **arm 네이티브 + 손 잠재 분리 인터페이스** — 팔과 손 명령을 서로 다른 표현 공간에서 예측하는 구조가 실기에서 유효함을 입증; P1 이종 Body/Hand 출력 공간 분리 설계에 직접적인 경험적 근거 제공
- **온라인 RL 편입 경로** — LAMP 잔여 RL 프레임워크는 모방 데이터 부족 상황에서 Hand Expert를 점진적으로 보완하는 실용적 전략으로 참조 가능

### (d) 먼저 확인할 점

- **코드·데이터 미공개** — arXiv 기준 코드·데이터 릴리스 언급 없음; 재현 가능성 낮음, 릴리스 일정 확인 필요
- **단일 플랫폼 제한** — 구체적 로봇 플랫폼·손 하드웨어 미명시; 타 embodiment 전이 가능성 논문 본문에서 확인 필요
- **잠재 공간 설계 비용** — 시연 사전학습 단계 추가 필요; 시연 수·품질 요구 조건 논문 본문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Cross-Embodiment Robot Manipulation via a Unified Hand Action Space**
[arXiv:2607.03570](https://arxiv.org/abs/2607.03570) · Luis Felipe Casas, Robert Teal, Keval Shah, Abhijit Tadepalli · source: citation-graph (Dexora)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **문제 진단** — 기존 조작 정책이 특정 로봇 손 embodiment에 종속, 기구학 구조가 다른 플랫폼으로 전이 불가
- **UHAS(Unified Hand Action Space)** — 구 기반(sphere-based) 통합 행동 표현: 로봇 손 동작을 정준 구의 기하학적 변형으로 표현하고, Cascade Inverse Kinematics(CIK)로 공유 표현을 embodiment별 관절 명령으로 사상
- **RL 기반 학습** — UHAS 공간에서 직접 다지 조작 정책을 RL로 학습; 인핸드 큐브 재배향(in-hand cube reorientation) 과제에서 평가
- **교차 embodiment 검증** — Allegro Hand, LEAP Hand, Shadow Hand, MANO Human Hand 4종에서 시뮬레이션 + 실기 평가; 미관측 손으로 제로샷 전이(zero-shot transfer) 및 빠른 파인튜닝 성공
- **실기 배포 성공** — 복수 로봇 손 플랫폼에서 실제 배포 확인

### (c) 시사점

- **손 출력 공간의 기하학적 통합** — 다양한 손 기구학을 하나의 기하학 공간으로 흡수하는 접근은 Hand Expert 출력 표현을 embodiment-agnostic하게 설계할 때 직접 참조 가능
- **제로샷 전이 가능성** — 단일 정책 학습 후 이종 플랫폼 무훈련 전이 검증; Hand Expert를 플랫폼 독립적으로 만드는 방향성 확인
- **기구학 이질성 흡수** — Cascade IK로 공유 표현 → 관절 명령 변환; Body/Hand 분리 아키텍처에서 손 하드웨어 이질성을 손 명령 레이어에서 흡수하는 방법론으로 참조 가능

### (d) 먼저 확인할 점

- **과제 단일성** — 인핸드 큐브 재배향 단일 과제; 다양한 접촉 패턴을 요구하는 조작 과제(물체 집기·삽입 등)로의 일반화 논문 본문 확인 필요
- **팔(arm) 통합 부재** — 손 명령 통합 공간만 다루고 팔 명령과의 연동 미명시; Body/Hand 협조 메커니즘은 별도 설계 필요
- **코드 공개 여부** — 실기 실험 있으나 코드·데이터 릴리스 시기 미확인

## 🥉 논문 3 — 우선순위 ★

**CoRE-VLA: Towards Scalable and Robust Vision-Language-Action Modeling via Conditional Routing of Experts**
[arXiv:2607.03693](https://arxiv.org/abs/2607.03693) · Haozhe Zhang, Sixian Li, Yifei Zhang, Zezheng Huai · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **문제 진단** — 현실 로봇은 이종 센서 구성 + 센서 장애 + embodiment별 센서 부재 등 3가지 이질성에 노출; 기존 VLA는 고정 센서 세트에 종속된 밀집 연산으로 취약
- **CoRE-VLA** — 컨텍스트 조건부 희소 연산으로 행동 생성을 재구성: (i) 센서 가용성이 모달리티 전문가를 게이팅하여 센서 부재 시 무훈련 열화(graceful degradation) 구현, (ii) 태스크 의도가 행동-측(action-side) 표현을 태스크 관련 전문가로 라우팅하여 다중 과제·장기 서브골 전문화
- **깊이(depth) 보조 모달리티 집중** — 주요 보조 센서로 깊이 카메라를 선택하여 가용·부재 모달리티 분석 수행
- **검증** — LIBERO, RoboCasa GR1 Tabletop, 실기 양팔 조작에서 밀집 행동 생성 비교군·강한 사전학습 VLA 기준선 대비 우위; 미관측 시나리오 제로샷 일반화 포함

### (c) 시사점

- **태스크 조건부 행동-측 라우팅 — D1 비교군 확보** — 공유 백본 + 태스크 라우팅 행동 전문가 구조는 P1의 Body/Hand 해부학적 분리(D1)에 대한 최신 최강 비교군; 분리 기준을 태스크 의도에서 해부학적 부분공간으로 전환했을 때의 이점을 논증할 공개 기준점 확보
- **모달리티 전문가 게이팅 참조** — 센서 가용성 기반 전문가 게이팅이 입력 모달리티 분리(D5) 구현에서 모달리티 전문가를 조건부 활성화하는 방식으로 직접 참조 가능
- **장기 서브골 전문화** — 태스크 의도 라우팅이 장기 서브골 간 전문화를 달성; Body→Hand 역할 전환 타이밍 신호 설계에 개념적 참조 가능

### (d) 먼저 확인할 점

- **행동-측 라우팅의 태스크 vs. 해부학적 기준 차이** — 태스크 의도 기반 라우팅이 Body/Hand 해부학적 분리와 정확히 어떻게 다른지 직접 대조 실험 없음; 논문 본문에서 행동 전문가 구조 상세 확인 필요
- **P1 관련성 경계** — 모달리티 게이팅은 P2(관측 융합) 영역에 더 가까운 설계; P1 행동 공간 설계 기여는 행동-측 라우팅 부분에 한정
- **센서 조합 의존성** — 깊이 보조 센서에 집중; 촉각·고유감각 등 다른 보조 모달리티로의 확장 여부 논문 본문 확인 필요
