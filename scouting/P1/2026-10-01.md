**DexWeave: Learning Dexterous Humanoid Loco-Manipulation from Human Demonstrations**
[arXiv:2609.34724](https://arxiv.org/abs/2609.34724) · Sun Naichuan, Shen Haotian, Zhang Yizhang 외 5인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- 해부학적 영역별 구조화 토큰 + 방향성 마스크 어텐션으로 신체-손 의존성을 명시 모델링하는 anatomy-aware Transformer 정책 설계 — D3GS 분리 헤드 구조의 어텐션 마스크 기반 구현 최초 사례
- 상체 상호작용 체인 결합 정제·하체 지지 독립 보존의 2단계 리타게팅 파이프라인 — 인간 시연 전달 정밀도와 접촉 일관성 동시 향상
- 사전 추적 정책·교사-학생 증류·잔차 정제 없이 RL 직접 훈련 — D6JW π0 슬라이싱 없이 단일 단계 수렴 달성
- Unitree G1 + Inspire 다관절 손 실제 로봇 배포 — MLP 기준선 대비 조작 성능·정책 수렴 속도 개선 정량 실증

### (c) 시사점

- 구조화 토큰 단위 방향성 어텐션이 D3GS 혼합 구조(공유 트렁크 + 분리 헤드)의 헤드 간 정보 흐름을 마스크로 명시화한 첫 사례 — 분리 헤드 안의 어텐션 위상 설계가 독립 성능 변수임을 시사
- 상체 상호작용 체인에만 결합 정제를 적용하고 하체를 독립 보존 → D4QX 손목·플랜지 포즈와 D1QT 손가락 관절의 운동학적 연쇄 제약 조건이 명시적으로 분리 가능함을 실증
- 교사-학생 증류 제거가 수렴 속도 향상을 동반 → 분리 구조가 단일 단계 RL 훈련과 호환됨을 시사, D6JW π0 의존 없이 해부학적 분리 달성 가능 방향 확인

### (d) 먼저 확인할 점

- 방향성 마스크 어텐션이 어느 영역 쌍(신체→손, 손→신체, 신체↔루트) 간 흐름을 허용·차단하는지 — 논문 §3 마스크 설계 상세 확인 필요
- 실험에서 보고된 "higher manipulation performance" 수치가 어떤 과제 분포에서 측정되었는지 — 정적 테이블탑 vs. 이동 조작 과제 비중 확인
- 프로젝트 페이지의 영상 공개 범위 확인 — 실패 모드 및 조작 실패 비율 데이터 존재 여부

## 🥈 논문 2 — 우선순위 ★★

**Uni-VLaT: Whole-Body Tactile Adaptation of VLA Policies for Humanoid Loco-Manipulation**
[arXiv:2609.35450](https://arxiv.org/abs/2609.35450) · Wang Zihao, Liu Shutong, Zheng Siqi 외 5인 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP)

### (b) 핵심 기여

- 전신 촉각 경로를 독립 전문가로 분리하고 미래 촉각·고유감각·시각 표현 예측을 보조 목표로 훈련하는 예측적 감각 지도 설계 — Tier 2 촉각-비전 이종 전문가 최초 VLA 통합
- 촉각 없는 기준선 대비 평균 +43포인트, 예측 감독 없는 촉각 기준선 대비 +7포인트 — 촉각 경로 분리 기여분과 예측 감독 기여분 ablation으로 분리 정량화
- 두 가지 상이한 사전 훈련 VLA 백본에서 Table Sweeping +30포인트, Back-Tap Walking +85~90포인트 — 백본 독립적 적용 확인
- 5종 실제 로봇 과제(촉각 트리거 이동·지속 상호작용·인간-로봇 접촉·이동 조작) 75% 평균 성공률 달성

### (c) 시사점

- 촉각 경로 독립 분리 + 예측 감독 조합이 D1MZ 입력 모달리티 분리 효과를 촉각 축으로 확장 — 시각·고유감각 이외 제3 전문가 모달리티의 독립 분리 가치 실증
- 43포인트 중 예측 감독 기여분 7포인트 분리 → D9ZP FiLM 단일 점 조건 부여를 넘어 미래 표현 예측 기반 정보 공유가 추가 성능 원천임을 시사
- 두 VLA 백본 모두에서 개선 → D6JW 백본 파티션 방식에 무관하게 촉각 전문가 분리 이득 전이

### (d) 먼저 확인할 점

- 촉각 경로의 갱신 주기가 VLA 백본과 동기화되어 있는지 — D1MZ 공유 레이트 vs. TacForcing(2608.25798) 블록 단위 처리 방식과 비교 필요
- 12페이지, 5그림 — 전신 분포 촉각 센서 사양과 실제 배포 비용 확인 필요
- 폐색 환경에서 촉각 예측 기반 보정이 시각 기반 기준선 대비 유효한지 — 가림 상황 ablation 존재 여부

## 🥉 논문 3 — 우선순위 ★★

**WB-WAM: Heterogeneous Body-Hand Pre-training for Humanoid Loco-Manipulation**
[arXiv:2609.34199](https://arxiv.org/abs/2609.34199) · Chuan Qin, Shaoting Zhu 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- 신체(body)·루트(root)·다관절 손 어노테이션을 이종 데이터 소스에서 단일 공유 물리 행동 공간으로 통합 — 1,880.2시간 전신 훈련 데이터 확보
- HumanoidArena 벤치마크 81.9% + 5종 실제 로봇 과제 84.0% 평균 성공률 달성
- 이종 소스(신체 전용·손 전용·전신 통합) 어노테이션 혼합 훈련 파이프라인 — 각 소스 편향 보정 전략 포함

### (c) 시사점

- 신체·루트·손 어노테이션을 단일 물리 공간에 통합하는 사전 훈련이 D4QX 손목·플랜지 포즈와 D1QT 손가락 관절 출력을 데이터 단에서 동시 지원 — 아키텍처 분리 없이 이종 어노테이션 통합 시 성능 상한 기준점 확보
- 1,880.2시간 이종 소스 혼합 → D3GS 하이브리드 구조와 단일 공유 공간의 데이터 효율 비교 실험 착수 가능한 기준선
- 84.0% 실제 로봇 성공률 — 분리 전문가 구조 도입 전 단일 공간 통합 전처리의 기여 분리 실험 설계 가능

### (d) 먼저 확인할 점

- 공유 행동 공간이 아키텍처적으로 단일 헤드인지 분리 헤드인지 — 프로젝트 페이지·논문 §3 구조 상세 확인 필요
- 신체·손 어노테이션 불균형 처리 방법과 훈련 안정성 ablation 여부
- 실제 로봇 성공률 84.0%가 어떤 과제 유형 분포에서 측정되었는지 — 이동 조작 vs. 정적 조작 비중 확인
