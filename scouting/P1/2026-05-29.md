## 🥇 논문 1 — 우선순위 ★★★

**Beyond Binary: Sim-to-Real Dexterous Manipulation with Physics-Grounded Contact Representation**
[arXiv:2605.28812](https://arxiv.org/abs/2605.28812) · Jiahe Pan, Stelian Coros, Jitendra Malik, Toru Lin · source: keyword-sweep (cs.RO dexterous) / Author Watch (Toru Lin)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P1](#ref-P1)의 [D3](#ref-D3)(Hand 출력 공간 — finger joint command)과 [D5](#ref-D5)(입력 모달리티·제어 속도 분리 — modality-separated + shared rate)에 직접 닿습니다. 이 논문은 다지 핸드 정책의 입력 표현으로서 이진 접촉 신호나 raw taxel 값을 대체하는 **Center-of-Pressure(CoP)** 물리 기반 촉각 표현을 제안합니다. CoP는 정상 힘 성분($F_n$)과 압력 중심 위치($C$)를 보존하면서도 sim-to-real 전이가 가능하도록 설계되어, zero-shot 시뮬레이션-실환경 이전을 다지 핸드에서 처음 달성하였습니다. D3 v1이 finger joint command를 채택할 때 그 command를 구동하는 입력 표현의 풍부도가 핸드 전문가의 성능 상한에 직접 영향을 미침을 보여 주는 직접 증거입니다. CoP는 촉각 센서 전용 입력 채널을 핸드 전문가에게 배속해야 한다는 D5 v1의 modality-separation 가설도 실험적으로 뒷받침합니다.

### ✨ (b) 진정으로 새로운 점

기존 sim-to-real 촉각 연구는 접촉 여부(이진)나 taxel raw 값을 직접 정책에 입력하는 방식에 의존하였고, 이는 시뮬레이터와 실세계 사이의 탄성·마찰 차이로 인한 도메인 갭 문제를 해결하지 못하였습니다. CoP는 물리 원리로부터 유도된 압력 중심 좌표로, 세부 taxel 노이즈에 둔감하면서도 접촉 역학에 필요한 정보 밀도를 유지합니다. 여기에 **미분 가능 동역학 기반 센서 캘리브레이션**(ground-truth 힘 측정 없이 taxel 방향 추정)을 추가하여, peg-in-hole 삽입과 구 균형 유지 두 과제에서 다지 핸드의 zero-shot Sim2Real (시뮬레이션-실환경 이전)을 달성하였습니다. 핀 논문 중 어느 것도 zero-shot sim-to-real을 다지 핸드 수준에서 CoP 같은 물리 기반 단일 표현으로 달성한 사례는 없었습니다.

### ⚙️ (c) 의사결정 함의

- **D3 핸드 출력 공간 입력 설계**: P1의 finger joint command 출력에 대응하는 핸드 전문가 입력 파이프라인에 CoP 표현을 채택하면, 시뮬레이션에서 학습한 finger joint policy를 실세계로 zero-shot 이전할 수 있는 경로가 열립니다. 구체적 config key: `hand_tactile_repr: binary | raw_taxel | cop_fn_center`. 첫 번째 ablation은 `cop_fn_center`로 시작합니다.
- **D5 modality 분리 구현 시 촉각 채널 규격**: CoP의 두 채널($F_n$, $C$)은 시각·언어 채널과 독립적으로 핸드 전문가에게 배속되어야 합니다. `hand_tactile_input_dim: 3` (CoP 2D 좌표 + 정상 힘 스칼라)으로 인터페이스를 고정하고, 바디 전문가의 입력 파이프라인과 분리된 전처리 경로를 구성합니다.
- **CP1 sim ablation 외부 기준 성능**: peg-in-hole 삽입 성공률 및 구 균형 유지 시간이 다지 핸드 CoP 정책에서 zero-shot 달성된 수치는, CP1 시뮬레이션 ablation의 D3 입력 표현 비교 기준점으로 삼을 수 있습니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

CoP는 다지 핸드의 손끝(fingertip) 접촉을 전제로 하며, 손가락 관절 움직임 중에 taxel 방향이 변화하는 상황에서 캘리브레이션 정확도가 유지되는지 논문이 충분히 검증하지 않습니다. 또한 미분 가능 동역학 기반 캘리브레이션은 물리 엔진의 contact model이 실세계와 충분히 일치할 것을 가정합니다. 우리 스택에서 사용하는 Sharpa 핸드나 xhand의 taxel 배열 밀도와 캘리브레이션 프로토콜이 CoP 추출에 적합한지 사전 확인이 필요합니다. 가장 저렴한 점검: 정적 접촉 상태에서 $F_n$과 $C$를 측정하고, 동일 접촉이 시뮬레이터와 실세계에서 CoP 값이 10% 이내에서 일치하는지 확인합니다.

## 🥈 논문 2 — 우선순위 ★★

**Tabero: Learning Gentle Manipulation with Closed-Loop Force Feedback from Vision, Touch, and Language**
[arXiv:2605.27886](https://arxiv.org/abs/2605.27886) · Qiwei Wu, Rui Zhang, Xin Xiang, Tao Li, Weihua Zhang, Junjie Lai, Renjing Xu · source: citation-graph (π0, π0.5)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P1](#ref-P1)의 [D3](#ref-D3)(Hand 출력 공간 — finger joint command deferred: 임피던스)과 [D5](#ref-D5)(입력 모달리티 분리 — 핸드 = 촉각·시각·언어)에 집중적으로 닿습니다. Tabero의 핵심 기여는 **분리된 힘-위치 명령 인터페이스(decoupled force-position command interface)**입니다. VLA가 직접 finger joint command 대신 힘(force) 목표값과 위치(position) 목표값을 분리하여 출력하고, 이를 고정 하이브리드 컨트롤러가 실시간으로 실행합니다. 이 구조는 D3 v1("finger joint command")의 보완 경로인 deferred 옵션 iii("grip-force / impedance → trigger: stiff position control causes excessive contact force")가 실제 VLA 아키텍처 수준에서 어떻게 구현될 수 있는지를 보여 주는 첫 번째 완전한 외부 사례입니다. D5 v1의 modality 분리 측면에서도 시각(vision)·촉각(touch)·언어(language) 세 채널을 핸드 정책에 통합하는 벤치마크 파이프라인을 제공합니다.

### ✨ (b) 진정으로 새로운 점

기존 VLA 모델은 촉각 피드백을 보조 학습 신호로 사용하거나 정책 입력에 추가하는 방식에 머물렀습니다. Tabero는 이와 달리 VLA 출력 인터페이스 자체를 힘-위치 분리형으로 설계하여, **닫힌 루프(closed-loop) 힘 피드백**이 VLA 추론 주기보다 짧은 주기로 실행되도록 구성합니다. 이를 지원하기 위해 공개 데이터셋에서 비주오택타일(visuotactile) 데이터를 합성하는 데이터 파이프라인과, 접촉력 품질을 동시에 평가하는 다차원 평가 프로토콜을 함께 제안합니다. 실세계에서 부드러운 조작 지시(gentle instruction)에 따라 평균 그립 힘을 70% 이상 낮추는 결과를 달성하였으며, 코드는 공개되어 있습니다(https://github.com/NathanWu7/Tabero).

### ⚙️ (c) 의사결정 함의

- **D3 deferred 임피던스 경로의 VLA 수준 구현 참조**: Tabero의 `force_target`·`position_target` 분리 출력 구조는 D3 deferred 옵션 iii를 CP2에서 구현할 때 참조할 구체적 인터페이스 설계입니다. CP1 코드 초안에서 `hand_output_space: joint_cmd | force_position_decoupled`를 인터페이스 레벨로 준비해 둡니다.
- **D5 촉각·언어 통합 데이터 파이프라인 활용**: Tabero의 공개 데이터 합성 파이프라인은 visuotactile-language 정렬 데이터가 희소한 상황에서 P1 핸드 전문가 학습 데이터를 보강하는 데 직접 사용할 수 있습니다. `tactile_data_source: real_sensor | tabero_synthetic`을 학습 설정에 추가합니다.
- **점촉력 평가 지표 도입**: Tabero의 다차원 평가 프로토콜(task success rate + force quality score)은 P1 CP1 평가에서 "접촉 정밀도(contact precision)" 메트릭을 구체화하는 데 참조합니다. 구체적으로 `eval_metric: success_rate | contact_force_excess_rate`를 P1 ablation 메트릭 목록에 추가합니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

Tabero의 하이브리드 컨트롤러는 "고정된(fixed)" 저수준 제어기를 전제합니다. 이는 접촉 상태가 급변하는 고속 다지 조작(fast in-hand rotation)에서 컨트롤러 고정 가정이 성립하지 않을 수 있음을 의미합니다. 또한 힘-위치 분리 출력 구조는 VLA가 힘 목표값을 정확하게 추론해야 한다는 요구를 부과하는데, 현재 π backbone의 flow-matching 출력 분포가 force 값의 연속 분포를 충분히 포괄하는지 확인이 필요합니다. 가장 저렴한 사전 점검: Tabero 공개 코드의 force_position 출력 헤드를 π0 backbone과 연결하는 toy 실험을 구성하고, force 목표값 예측 오차가 허용 범위(예: `force_error_threshold: 0.5 N`) 안에 드는지 시뮬레이션에서 확인합니다.

## 🥉 논문 3 — 우선순위 ★

**Learning High-Frequency Continuous Action Chunks in Latent Space**
[arXiv:2605.24931](https://arxiv.org/abs/2605.24931) · Kunyun Wang, Yuhang Zheng, Yupeng Zheng, Jieru Zhao, Wenchao Ding · source: citation-graph (π0, π0.5)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P1](#ref-P1)의 [D5](#ref-D5)(입력 모달리티·제어 속도 분리 — deferred (β) rate separation)에 직접 닿습니다. 이 논문은 60 Hz 고주파 제어 환경에서 action chunking이 시공간 비일관성을 초래하는 원인을 분석하고, VAE 기반 잠재 공간(latent space) 학습과 **Reuse-then-Refine** 전략으로 이를 해결합니다. D5 v1은 rate separation을 deferred로 유지하고 있으나("trigger: finger precision needs higher-frequency loop than body"), 이 논문은 60 Hz 수준의 고주파 루프가 접촉 집약적 조작(contact-rich manipulation)에서 실제로 요구되는 조건임을 실세계 실험으로 확인합니다. D3 관점에서도 세밀한 finger joint command를 높은 주파수에서 안정적으로 생성하려면 단순 action-space chunking 이상의 표현이 필요함을 시사합니다.

### ✨ (b) 진정으로 새로운 점

고주파 정책 학습의 병목은 인접 청크 간 불연속성(action chunk boundary artifacts)과 asynchronous inference로 인한 시간 지연 축적입니다. 기존 action chunking은 action 공간에서 직접 청크를 학습하여 이 두 문제에 취약합니다. 이 논문의 핵심 기여는 두 가지입니다. 첫째, VAE로 action trajectory를 잠재 표현으로 압축하여 고주파 청크의 시공간 일관성을 잠재 공간에서 학습합니다. 둘째, **Reuse-then-Refine** 전략: 이전 청크의 잠재 코드를 재사용하면서 현재 관측에 맞게 부분 수정하여 청크 경계에서의 불연속성을 제거합니다. 세 가지 실세계 접촉 집약적 과제에서 코드와 데이터가 공개된 상태로 검증되었습니다(https://github.com/tars-robotics/RTR).

### ⚙️ (c) 의사결정 함의

- **D5 deferred (β) rate separation의 구체 주파수 기준**: 이 논문의 60 Hz 조작 성공 결과는 D5 deferred 조건 `hand_ctrl_hz`의 실험적 기준치를 제공합니다. 이번 런으로 60 Hz 이상 핸드 제어 루프의 필요성을 지지하는 외부 증거가 5번째(AT-VLA·MoSS·PT·TactileReflex·본 논문)가 됩니다. CP1 코드 초안에서 `hand_ctrl_hz: 12 | 25 | 60 | body_rate` 인터페이스를 준비합니다.
- **VAE 잠재 공간 action chunking의 π backbone 적용 가능성**: P1의 π0 flow-matching backbone에서 high-frequency finger joint command를 안정적으로 생성하려면, 논문의 VAE 잠재 압축 원리를 flow-matching denoising 경로에 통합하는 방안을 검토합니다. 구체적 config: `action_chunk_repr: direct_space | vae_latent`, `reuse_refine: enabled | disabled`.
- **공개 코드 재현성**: 코드와 데이터가 공개되어 있어 `hand_ctrl_hz: 60` 조건을 P1 시뮬레이션 환경에서 즉시 재현 검증 가능합니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

이 논문의 실험은 단일 팔 manipulator 환경에서 수행되었으며, 바디(arm) + 핸드(hand)의 이질적 제어 루프가 동시에 동작하는 P1 아키텍처에서 Reuse-then-Refine이 동일하게 동작하는지 검증되지 않았습니다. VAE 인코더·디코더의 추론 지연이 60 Hz 루프에서 청크 경계 시점에 축적될 경우, 논문이 해결하려는 asynchronous inference 문제가 오히려 악화될 수 있습니다. 가장 저렴한 사전 점검: Franka-Allegro 환경에서 `hand_ctrl_hz: 60` + VAE latent chunking을 별도 루프로 설정하고, 바디 루프(예: 10 Hz)와 핸드 루프(60 Hz)가 동시 동작할 때 VAE 추론 지연이 `hand_ctrl_hz`에서 허용 가능한지(1/60초 이내) 측정합니다.

**D5 deferred (β) rate separation 누적 증거 갱신**: 이번 런에서 60 Hz 고주파 핸드 제어 루프 필요성을 지지하는 외부 증거가 5회 누적되었습니다. D5 deferred (β) 트리거("finger precision needs higher-frequency loop than body")는 CP2 이전에 인터페이스 수준으로만 준비하는 현행 계획을 재확인합니다.
