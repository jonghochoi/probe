## 🥇 논문 1 — 우선순위 ★★★

**Beyond Binary: Sim-to-Real Dexterous Manipulation with Physics-Grounded Contact Representation**
[arXiv:2605.28812](https://arxiv.org/abs/2605.28812) · Jiahe Pan, Stelian Coros, Jitendra Malik, Toru Lin · source: keyword-sweep (cs.RO dexterous) / Author Watch (Toru Lin)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **공백** — 기존 sim-to-real 촉각 연구는 접촉 여부(이진)나 taxel raw 값을 정책에 직접 입력, 시뮬레이터-실세계 탄성·마찰 차이로 인한 도메인 갭 미해결
- **Center-of-Pressure(CoP) 표현** — 이진 접촉이나 raw taxel을 대체하는 물리 기반 촉각 표현
  - 정상 힘 성분($F_n$)과 압력 중심 위치($C$)를 보존하면서 sim-to-real 전이 가능하도록 설계
  - 세부 taxel 노이즈에 둔감하면서도 접촉 역학에 필요한 정보 밀도 유지
  - 다지 핸드에서 zero-shot Sim2Real(시뮬레이션-실환경 이전)을 처음 달성
- **미분 가능 동역학 기반 센서 캘리브레이션** — ground-truth 힘 측정 없이 taxel 방향 추정
- **결과** — peg-in-hole 삽입 + 구 균형 유지 두 과제에서 다지 핸드 zero-shot Sim2Real 달성, 핀 논문 중 물리 기반 단일 표현으로 이 수준을 달성한 사례 부재

### (c) 시사점

- **핸드 입력 표현 강화 경로** — 핸드 출력 표현(손가락 관절 명령)을 유지하면서 입력 파이프라인을 CoP로 보강하면 시뮬레이션 학습 정책의 실세계 zero-shot 이전 경로 확보
- **촉각 채널 독립 배속 근거** — CoP 두 채널($F_n$, $C$)은 시각·언어 채널과 독립적으로 핸드 전문가에 배속 가능, 모달리티 분리 가설의 실험적 뒷받침
- **외부 성능 기준점** — peg-in-hole 성공률·구 균형 유지 시간이 다지 핸드 입력 표현 비교의 시뮬레이션 기준점

### (d) 먼저 확인할 점

- **캘리브레이션 안정성 불명** — 손끝(fingertip) 접촉 전제, 손가락 관절 움직임 중 taxel 방향 변화 시 캘리브레이션 정확도 유지 여부 미검증
- **물리 엔진 가정** — 미분 가능 동역학 캘리브레이션은 contact model이 실세계와 충분히 일치할 것을 전제
- **하드웨어 적합성** — Sharpa·xhand taxel 배열 밀도·캘리브레이션 프로토콜이 CoP 추출에 적합한지 사전 확인 필요
- **저비용 점검** — 정적 접촉에서 $F_n$·$C$ 측정, 동일 접촉의 시뮬레이터·실세계 CoP 값이 10% 이내 일치 여부 확인

## 🥈 논문 2 — 우선순위 ★★

**Tabero: Learning Gentle Manipulation with Closed-Loop Force Feedback from Vision, Touch, and Language**
[arXiv:2605.27886](https://arxiv.org/abs/2605.27886) · Qiwei Wu, Rui Zhang, Xin Xiang, Tao Li, Weihua Zhang, Junjie Lai, Renjing Xu · source: citation-graph (π0, π0.5)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **공백** — 기존 VLA는 촉각 피드백을 보조 학습 신호나 추가 입력으로만 활용
- **분리된 힘-위치 명령 인터페이스(decoupled force-position command interface)** — VLA가 손가락 관절 명령 대신 힘 목표값과 위치 목표값을 분리 출력, 고정 하이브리드 컨트롤러가 실시간 실행
  - 핸드 출력의 임피던스 경로가 VLA 아키텍처 수준에서 어떻게 구현되는지 보여 주는 첫 완전한 외부 사례
- **닫힌 루프(closed-loop) 힘 피드백** — VLA 추론 주기보다 짧은 주기로 실행
- **데이터·평가** — 공개 데이터셋에서 비주오택타일(visuotactile) 데이터를 합성하는 파이프라인 + 접촉력 품질 동시 평가 다차원 프로토콜
- **모달리티 통합** — 시각·촉각·언어 세 채널을 핸드 정책에 통합하는 벤치마크 파이프라인 제공
- **결과** — 부드러운 조작 지시(gentle instruction)에서 평균 그립 힘 70% 이상 감소, 코드 공개(https://github.com/NathanWu7/Tabero)

### (c) 시사점

- **힘-위치 분리 인터페이스 참조** — `force_target`·`position_target` 분리 출력 구조가 임피던스 경로 구현 시 참조할 구체적 인터페이스 설계
- **데이터 보강 활용** — 공개 데이터 합성 파이프라인이 visuotactile-language 정렬 데이터 희소 상황에서 핸드 전문가 학습 데이터 보강에 직접 사용 가능
- **접촉력 평가 지표** — task success rate + force quality score 다차원 프로토콜이 접촉 정밀도(contact precision) 메트릭 구체화의 참조점

### (d) 먼저 확인할 점

- **고정 컨트롤러 가정** — 하이브리드 컨트롤러가 "고정된" 저수준 제어기를 전제, 접촉 급변 고속 다지 조작(fast in-hand rotation)에서 가정 불성립 가능
- **힘 분포 포괄성** — 힘-위치 분리 출력은 VLA가 힘 목표값을 정확히 추론해야 함, π backbone의 flow-matching 출력 분포가 force 연속 분포를 충분히 포괄하는지 확인 필요
- **저비용 점검** — Tabero 공개 코드의 force-position 출력 헤드를 π0 backbone에 연결하는 toy 실험으로 force 목표값 예측 오차가 허용 범위 안에 드는지 시뮬레이션 확인

## 🥉 논문 3 — 우선순위 ★

**Learning High-Frequency Continuous Action Chunks in Latent Space**
[arXiv:2605.24931](https://arxiv.org/abs/2605.24931) · Kunyun Wang, Yuhang Zheng, Yupeng Zheng, Jieru Zhao, Wenchao Ding · source: citation-graph (π0, π0.5)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **공백** — 고주파 정책 학습 병목은 인접 청크 간 불연속성(action chunk boundary artifacts) + asynchronous inference 시간 지연 축적, 기존 action chunking은 action 공간에서 직접 청크를 학습해 두 문제에 취약
- **VAE 기반 잠재 공간(latent space) 청킹** — action trajectory를 잠재 표현으로 압축, 고주파 청크의 시공간 일관성을 잠재 공간에서 학습
- **Reuse-then-Refine 전략** — 이전 청크 잠재 코드를 재사용하며 현재 관측에 맞게 부분 수정, 청크 경계 불연속성 제거
- **결과** — 60 Hz 고주파 제어 환경에서 접촉 집약적 조작이 실제로 요구하는 조건임을 실세계로 확인, 세 가지 실세계 접촉 집약적 과제에서 코드·데이터 공개 검증(https://github.com/tars-robotics/RTR)

### (c) 시사점

- **고주파 루프 기준치** — 60 Hz 조작 성공 결과가 핸드 제어 루프 주파수 기준의 실험적 근거 제공
- **외부 증거 누적** — 60 Hz 이상 핸드 제어 루프 필요성을 지지하는 외부 증거가 5번째(AT-VLA·MoSS·PT·TactileReflex·본 논문)
- **π backbone 적용 검토** — VAE 잠재 압축 원리를 flow-matching denoising 경로에 통합해 고주파 손가락 관절 명령을 안정 생성하는 방안 검토 가치
- **재현성** — 코드·데이터 공개로 60 Hz 조건을 시뮬레이션 환경에서 즉시 재현 검증 가능

### (d) 먼저 확인할 점

- **단일 팔 한계** — 실험이 단일 팔 manipulator 환경, 바디(arm) + 핸드(hand) 이질 제어 루프 동시 동작 환경에서 Reuse-then-Refine 동일 동작 여부 미검증
- **추론 지연 악화 우려** — VAE 인코더·디코더 추론 지연이 60 Hz 루프 청크 경계 시점에 축적되면 asynchronous inference 문제가 오히려 악화 가능
- **저비용 점검** — Franka-Allegro 환경에서 바디 루프(예: 10 Hz)와 핸드 루프(60 Hz) 동시 동작 시 VAE 추론 지연이 허용 범위(1/60초 이내)인지 측정
