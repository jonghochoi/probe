## 🥇 논문 1 — 우선순위 ★★★

**MotionWAM: Towards Foundation World Action Models for Real-Time Humanoid Loco-Manipulation**
[arXiv:2606.09215](https://arxiv.org/abs/2606.09215) · Jia Zheng, Teli Ma, Yudong Fan, Zifan Wang, Shuo Yang · source: keyword-sweep (cs.RO body action space humanoid)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **현행 계층형 패러다임의 실패 진단** — 조작 정책이 상체만 제어하고 하체 컨트롤러는 조잡한 기저 명령을 추적하는 구조가 "상체와 하체를 불일치 액션 공간(inconsistent action spaces)에 배치"한다고 명시
  - 하체가 균형 보행 기능으로 격하되어 전신 협응 가능성 차단
  - 고수준 조작 정책과 저수준 컨트롤러의 액션 표현 불일치가 핵심 실패 원인으로 지목
- **MotionWAM** — 실시간(real-time) 휴머노이드 로코매니퓰레이션을 위한 경량 World Action Model
  - 반복 디노이징(iterative denoising) 대신 고차원 비디오-액션 잠재 변수를 압축한 one-step 생성으로 실시간성 확보
  - 상체·하체를 단일 일관된 전신 액션 공간에서 공동 표현, 계층형 불일치 구조 해소
- **진정으로 새로운 점**
  - 기존 WAM은 고차원 비디오-액션 잠재 변수 반복 디노이징으로 실시간 휴머노이드에 부적합
  - 액션 공간 일관성(action space consistency)을 전신 학습의 필수 설계 원칙으로 명시 정의한 WAM 선례 부재
  - 로코매니퓰레이션(이동 + 조작 동시)을 단일 통합 WAM으로 처리한 최초 실시간 접근

### (c) 시사점

- **D1 분리 형태 설계 기준 외부 확인** — 상체(조작)/하체(이동) 계층 분리가 "불일치 액션 공간"을 낳는다는 독립 실증; 이질적 body/hand 분리(D1)를 설계할 때 두 전문가의 표현 공간 일관성이 선결 조건임을 외부 문헌에서 확인
- **D2 바디 출력 공간 우선순위 근거 추가** — Cartesian 손목 포즈와 하체 속도 명령이 분리될 때 전신 협응 불가; Body 전문가가 단일 표현 공간에서 wrist/flange pose를 정의하는 현행 설계 방향 지지
- **D6 계층 흐름 한계 사례** — 무조건적 고수준→저수준 계층 흐름이 표현 불일치를 낳아 성능을 제한; body→hand 계층 흐름에서도 두 전문가 표현 공간의 일관성 관리가 중요함을 보여주는 외부 사례

### (d) 먼저 확인할 점

- **휴머노이드 전신 특화** — 상체/하체 전신 제어 문제; P1 타겟인 bimanual arm + dexterous hand 환경(상체만 사용)에서 액션 공간 불일치가 같은 방식으로 나타나는지 직접 확인 필요
- **WAM 아키텍처 의존** — MotionWAM은 비디오 예측 prior를 사용하는 WAM 계열; P1의 플로우 매칭 기반 액션 전문가 디코더와 아키텍처 원리 상이, 발견의 이전성 한계 존재
- **저렴한 점검** — 시뮬레이션에서 body 전문가(Cartesian wrist)와 finger 전문가(joint command)를 공통 잠재 공간에 임베딩할 때 vs. 별도 head로 분리할 때 coordination consistency 측정, 불일치 크기 정량화

## 🥈 논문 2 — 우선순위 ★★

**TORL-VLA: Tactile Guided Online Reinforcement Learning for Contact-Rich Manipulation**
[arXiv:2606.09337](https://arxiv.org/abs/2606.09337) · Huaihang Zheng, Yi Yang, Kai Ma, Shenglin Xu, Tian Xie · source: keyword-sweep (cs.RO tactile VLA contact-rich manipulation)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **TORL-VLA** — 촉각(tactile) 피드백으로 VLA 정책을 온라인 RL로 실시간 개선하는 프레임워크
  - 기존 촉각 VLA는 오프라인 정책으로 배포 후 접촉 조건 분포 이탈 시 적응 불가 — 부적절한 접촉력·반복 실패 발생
  - 촉각 피드백을 온라인 RL 보상 신호와 상태 조건화 입력으로 동시 활용
  - 접촉 조건 변화 시 정책을 실시간으로 개선하는 폐루프(closed-loop) 구조
- **진정으로 새로운 점**
  - 기존 촉각 VLA 연구 전반은 offline 정책으로 배포 — 배포 후 접촉 분포 이탈 대응 불가
  - 촉각 채널을 online RL 루프에 통합해 정책을 실시간 개선하는 VLA 선례 부재
  - 촉각 modality를 별도 입력 채널(상태 조건화)이자 보상 신호(policy refinement)로 이중 활용

### (c) 시사점

- **D5 촉각 채널 온라인 적응 경로 확보** — 손가락 끝 촉각 채널을 별도 입력 모달리티로 분리하면 offline 학습 이후 online RL 적응 루프 구성 가능; 핸드 전문가 촉각 채널의 배포 후 유용성(post-deployment value) 추가 근거
- **촉각→접촉력 제어 경로** — 촉각 피드백이 "부적절한 접촉력"을 직접 수정하는 보상 신호로 기능; finger joint command 출력과 촉각 입력 채널을 결합한 온라인 fine-tuning 루프 설계 시 참조 구조
- **데이터 효율성** — offline 학습 기준에서 소량의 online 촉각-RL 업데이트로 성능 수렴; 다지 핸드 실세계 촉각 데이터 수집 비용 절감 경로 제시

### (d) 먼저 확인할 점

- **그리퍼 특화 가능성** — 실험이 단일/이중 지(finger) 그리퍼 중심 접촉 집약 태스크로 구성된 것으로 추정; 20+ DoF 다지 핸드에서 손가락별 촉각 채널 독립 RL 루프 구성 시 상태·보상 공간 복잡도 급증
- **온라인 RL 안전성** — 배포 후 온라인 RL 초기 탐색 단계에서 과도한 접촉력·하드웨어 손상 위험; 다지 핸드 적용 전 force limit, exploration bound 등 안전 제약 설계 필수
- **저렴한 점검** — 소규모 삽입 태스크에서 TORL-VLA 방식으로 촉각 신호를 online RL 보상으로 추가할 때 offline 기준선 대비 성공률 개선 및 접촉력 감소 여부를 시뮬레이션으로 1차 검증

## 🥉 논문 3 — 우선순위 ★

**CT-VAM: A Cerebello-Thalamic-Inspired Vision-Action Model for Efficient Visuomotor Control**
[arXiv:2606.09572](https://arxiv.org/abs/2606.09572) · Jiacheng Li, Yize Guo, Jiabin Guo, Qingchen Liu, Jiahu Qin · source: keyword-sweep (cs.RO visuomotor modality separation hierarchical)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **CT-VAM** — 소뇌-시상(cerebello-thalamic) 신경 구조에서 영감을 받은 계층형 시각-액션 모델
  - 고수준: 언어로 태스크 의도(task intent) 지정 — 고빈도 실행 루프에서 매 스텝 재처리 불필요
  - 저수준: 이중 시점(dual-view) 시각 관측 + 고유감각(proprioception) + 경량 태스크 조건만으로 액션 청크 예측
  - 클라우드-엣지 패러다임: 언어 처리 클라우드 측, 시각-액션 실행 로컬(엣지) 측 분리 가능
- **진정으로 새로운 점**
  - 기존 VLA는 언어 토큰을 고빈도 실행 루프에서 매 스텝 재처리 → 추론 지연·불필요한 계산 비용
  - 언어를 경량 태스크 조건 임베딩으로 격하하고, 시각+고유감각만으로 고빈도 액션 청크 실행하는 분리 아키텍처
  - 소뇌(빠른 반사·실행) vs. 시상(느린 계획·통합) 역할 분리를 VLA 아키텍처로 구현한 최초 사례
  - 통합 VLA 대비 추론 효율성 개선과 경쟁적 조작 성능 동시 달성 주장

### (c) 시사점

- **D5 모달리티 분리 설계 외부 검증** — 언어(저빈도) vs. 시각+고유감각(고빈도)의 입력 모달리티 분리가 추론 효율성과 성능을 동시 개선; 모달리티 분리(D5 v1) 선택의 외부 검증 사례
- **D6 계층 흐름의 생물학적 타당성** — 고수준 언어 태스크 → 저수준 시각-액션 실행 계층 흐름이 소뇌-시상 신경 구조와 정합; body→hand 계층 흐름(D6 v1)의 생물학적 합리성 추가 지지
- **핸드 전문가 추론 속도 기준** — 언어 처리 없이 시각+고유감각만으로 고빈도 실행 루프 구성 시 핸드 전문가 제어 주파수 확보 용이; D5 구현 시 CT-VAM 방식 참조

### (d) 먼저 확인할 점

- **실세계 다지 조작 미확인** — 초록 기준 실세계 다지 핸드 실험 미확인; "potentially enabling a practical cloud-edge paradigm" 표현으로 미루어 클라우드-엣지 배포 사례 실증 부재 가능
- **언어 조건 압축 품질 의존** — 경량 태스크 조건 임베딩의 품질이 실행 정밀도에 직결; 언어 지시의 미묘한 의미 손실이 접촉 집약 태스크에서 치명적 실패 유발 위험
- **저렴한 점검** — 표준 조작 벤치마크에서 CT-VAM 방식 언어 분리(경량 임베딩)와 전체 언어 토큰 처리 방식의 태스크 성공률 차이 측정, 특히 접촉 집약·장기 지평 태스크에서 비교
