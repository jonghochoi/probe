## 🥇 논문 1 — 우선순위 ★★★

**Acting While Understanding: Asynchronous Semantic-Action Decoupling for Real-Time Vision-Language-Action Models**
[arXiv:2606.15285](https://arxiv.org/abs/2606.15285) · Shenhao Yan et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- 동일 VLA 내 의미 이해(저주파)와 행동 생성(고주파)을 비동기 분리 — 별도 디코더 추가 없이 기존 모델(π0.5, UniVLA) 위에 플러그인 방식으로 적용
- 과거 행동 이력을 현재 스텝 조건으로 재투입(historical action conditioning)하여 "의미 업데이트 지연"을 보상; 시간 불일치 학습(time-misalignment training)으로 스테일 시맨틱 하에서도 안정적 행동 생성
- π0.5 기반 최종 추론 속도 35.6 Hz 달성 — 기존 π0.5 대비 ~7× 가속, 실시간 조작 배포 가능 수준

### (c) 시사점

- D5 실천 경로 구체화 — 시맨틱·액션 디커플링을 π 백본 교체 없이 적용 가능함을 실증; P1 v1 설계에서 별도 분기 처리 불필요
- π0.5 기반 손가락 제어 루프에 직접 이식 가능한 방법론 — 고주파 손가락 명령과 저주파 언어 계획의 분리 근거로 활용
- D7 보강 — "백본 의미 특징을 행동 전문가에 어떻게 전달할 것인가"에 역사적 행동 이력 경유 방식이라는 구체적 해답 제시

### (d) 먼저 확인할 점

- 코드 미공개 — 재현을 위해 비동기 분기 및 시간 불일치 학습 파이프라인 자체 구현 필요
- 실험 태스크 대부분 wrist-pose 수준의 그리핑; 손가락 관절 명령이 포함된 고 dexterity 태스크에서의 효과 미검증
- 역사적 행동 이력 버퍼 크기·형태가 손가락 다자유도 명령에서도 충분한지 별도 측정 필요

## 🥈 논문 2 — 우선순위 ★★

**Benchmarking Action Spaces in Reinforcement Learning for Vision-based Robotic Manipulation**
[arXiv:2606.18594](https://arxiv.org/abs/2606.18594) · Seyed Alireza Azimi et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- RL 비전 기반 조작에서 포즈 증분 / 포즈 속도 / 관절 위치 증분 / 관절 속도 4종 행동 공간을 동일 조건(시뮬레이터, 카메라 배치, 보상) 아래 체계적 비교
- 관절 속도 표현이 부드러운 궤적·태스크 성능 모두에서 우위; 포즈 기반 공간은 안전 제약 처리가 단순하나 다관절 정밀 제어에서 성능 열위 확인
- sim-to-real 전이 결과 포함 — 시뮬레이터 격차(physics gap) 하에서도 관절 기반 표현이 보다 일관된 전이 품질 유지

### (c) 시사점

- D2 RL 도메인 확증 — 기존 IL(모방학습) 도메인에서의 Demystifying(2602.23408) 결론과 동일 방향; IL+RL 양 도메인에서 관절 기반 Body Output Space 지지 근거 강화
- 시뮬레이터 검증 단계에서 관절 속도 기반 행동 공간을 기본값으로 채택할 경우 sim-to-real 리스크 감소 기대
- 비교군이 pick-and-place·push로 제한되나, 저 dexterity 베이스라인으로서 충분한 참조점 확보

### (d) 먼저 확인할 점

- 손가락 관절을 포함한 고 dexterity(다지 손 제어) 시나리오는 미포함 — Body wrist 수준 결론을 Hand 디코더에 직접 외삽 시 주의
- 실험 환경이 단일 시뮬레이터에 집중; 실제 하드웨어 다양성(컨트롤러 지연·마찰 모델) 검증 범위 제한적

## 🥉 논문 3 — 우선순위 ★

**Motion-Focused Latent Action Enables Cross-Embodiment VLA Training from Human EgoVideos**
[arXiv:2606.18955](https://arxiv.org/abs/2606.18955) · Runze Xu et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- Hybrid Disentangled VQ-VAE — 물리 마스크 기반 모션 다이나믹스·배경 분리로 교차 embodiment 행동 코드북 학습; 레이블 없는 사람 에고비디오에서 사전 훈련 가능
- VLM이 행동 의도(intent)를 예측, 동결 시각 인코더가 상태 특징을 액션 전문가에 공급하는 의도-인식 디커플링 구조 — "백본 의도 → 액션 전문가" 연결 방식의 구체적 구현
- 50궤적 적응(adaptation)으로 완전 레이블 VLA 수준 경쟁력 달성; 사람 동작 데이터에서 로봇으로의 교차 embodiment 전이 실증

### (c) 시사점

- D7 구현 힌트 — 의도 예측을 백본에, 상태 인식을 별도 인코더에 분리하는 설계가 cross-embodiment 전이에서 실용적임을 입증
- 사전 훈련 데이터 병목 해소 방향 — 고가 로봇 레이블 없이 사람 에고비디오만으로 행동 코드북 초기화 가능 → P1 핸드 데이터 부족 문제 완화 가능성
- InDex(6월 12일 리포트)에 이은 의도-인식 디커플링 두 번째 등장 → D7 내 설계 선택지 구체화

### (d) 먼저 확인할 점

- Semantic Scholar 미인덱싱(HTTP 404) — 논문 공개 직후로 인용 그래프 추적 불가; 동료 검토 전 사전 검증 상태
- 사람 에고비디오의 손 형태와 로봇 그리퍼·다지 핸드 간 운동학적 불일치가 코드북 품질에 미치는 영향 미정량화
- 실험 환경이 테이블 탑 집기 수준; 정밀 손가락 제어(인-핸드 조작)에서의 전이 가능성 미검증
