## 🥇 논문 1 — 우선순위 ★★★

**FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation**
[arXiv:2606.13102](https://arxiv.org/abs/2606.13102) · Chengbo Yuan, Zicheng Zhang, Mingjie Zhou, Wendi Chen, Yi Wang · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **범용 촉각 정책 기반 모델 부재 문제 명시** — 기존 촉각 기반 정책이 특정 하드웨어·센서에 고정, 센서 구성 변경 시 재학습 불가피
  - 이미지·어레이·상태 기반 등 이종(heterogeneous) 촉각 신호가 하드웨어마다 상이 → 단일 인코더 방식으로는 범용화 구조적 불가
- **FTP-1** — 이종 촉각 센서에 걸쳐 이전 가능한 접촉 집약적 조작 전용 범용 촉각 기반 모델
  - 촉각 신호 유형별 전용 인코더(image-, array-, state-based) → 통합 형태 인식(morphology-aware) 잠재 토큰으로 변환
  - 공유 tactile Transformer expert가 통합 잠재 토큰을 공동 모델링
  - 사전학습 규모: ~3,000시간 촉각 조작 데이터, 26개 소스, 21종 센서
- **성능**
  - 파인튜닝 시 확인된(seen) 센서 구성 +17.2%, 미확인(unseen) 센서 구성 +31% 성공률 향상
  - 5개 하드웨어 구성 다운스트림 실험으로 이전성 검증
- **진정으로 새로운 점**
  - 기존 촉각 VLA — 단일 센서·고정 하드웨어 전용, 범용 촉각 기반 모델 선례 부재
  - 센서 유형별 독립 인코더 + 공유 Transformer expert 구조로 미확인 센서 구성에 첫 양성 이전 결과 달성
  - 사전학습 모델·데이터셋·학습 코드 전체 오픈소스 공개

### (c) 시사점

- **D5 촉각 채널 독립 인코더 설계의 대규모 외부 검증** — 손가락 끝 촉각 신호를 image/array/state 유형별로 분리 인코딩 후 공유 잠재 공간 통합; 핸드 전문가 촉각 채널 설계 시 센서 유형별 독립 인코더 경로의 가장 큰 규모 외부 근거
- **미확인 센서 이전성(+31%)** — 배포 환경 하드웨어가 수집 환경과 달라도 촉각 채널 성능 유지 가능성 정량 확인; 다지 핸드 배포 시 촉각 채널 재수집 부담 절감 경로
- **오픈소스 파인튜닝 기준점** — 모델·데이터·코드 전체 공개로 다지 핸드 촉각 채널 ablation 실험 시 FTP-1 파인튜닝 경로 즉시 진입 가능; 직접 사전학습 없이 촉각 채널 ROI 1차 추정

### (d) 먼저 확인할 점

- **사전학습 규모 의존** — ~3,000시간·26개 소스·21종 센서 규모에서 cross-sensor 일반화 달성; 다지 핸드 전용 소규모 촉각 데이터로 동일 수준 이전성 재현 가능한지 별도 확인 필요
- **다지 핸드 데이터 비율 미공개** — 26개 소스 중 20+ DoF 다지 핸드 전용 데이터 비율 불명; 손가락 끝 촉각 조합(20+ 채널)이 통합 잠재 토큰에 충분히 표현되는지 검증 필요
- **저렴한 점검** — FTP-1 파인튜닝 경로로 다지 핸드 단일 태스크(삽입·파지)에서 촉각 채널 유무 ablation 성능 차이 측정; 핸드 전문가 촉각 채널 투자 우선순위 정량 기준 확보

## 🥈 논문 2 — 우선순위 ★★

**AIR-VLA+: Decoupling Movement and Manipulation via Cascaded Dual-Action Decoders**
[arXiv:2606.12859](https://arxiv.org/abs/2606.12859) · Jianli Sun, Bin Tian, Qiyao Zhang, Zijian Liu, Yutong Wang · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **항공 조작의 이질 액션 공간 표현 결합 문제 명시** — UAV 이동(movement)과 암(arm) 조작(manipulation)이 액션 규모·동역학·제어 목표에서 근본적 차이 → 단일 end-to-end 디코더가 두 이질 공간을 강제 결합(coupling)
  - 단일 π0.5 head baseline 대비 종합 태스크 완성 점수 +80.2% 개선
- **AIR-VLA+** — 플로우 매칭 기반 캐스케이드(cascaded) 이원 액션 디코더 아키텍처
  - **조작 디코더**: 접촉 정밀도 담당 암/그리퍼 제어 (독립 학습, 이동 역전파 격리)
  - **이동 디코더**: UAV 포지셔닝, 조작 디코더 출력을 단방향(unidirectional)으로 관측
    - Implicit Visual Grasp Projector — 그리퍼-물체 상호작용 상태 지각 후 이동 디코더에 주입
    - 전역 의미 특징 압축 주입
    - 이동 디코더 내 암묵적 MoE: 태스크 단계별 이동 전문가 자발적 분화
  - **비대칭 경사 격리**: UAV 이동 정보의 역전파가 암 조작 학습 안정성에 미치는 영향 구조적 차단
- **진정으로 새로운 점**
  - 기존 항공 조작 — 단일 모놀리식 디코더 또는 규칙 기반 분리, 플로우 매칭 캐스케이드 이원 디코더 선례 부재
  - 접촉 정밀 제어기(암)가 거친 이동 제어기(UAV)를 단방향 조건화하되, 이동 역전파는 조작 학습에 간섭하지 않도록 비대칭 격리

### (c) 시사점

- **이질 액션 공간 캐스케이드 분리의 직접 정량 근거** — 이동·조작 두 이질 액션 공간을 캐스케이드 디코더로 분리했을 때 +80.2% 성능 개선; 바디(arm)-핸드(finger) 이질 분리가 동일 원리에서 성능 이득을 기대할 수 있는 외부 정량 근거
- **비대칭 경사 격리 설계 원칙** — 이질 디코더 분리 시 cross-decoder 역전파를 격리해 조작 안정성 확보; 핸드 전문가 역전파가 바디 전문가 수렴을 오염하지 않도록 격리하는 설계 원칙 참조
- **Implicit Visual Grasp Projector 아이디어** — 그리퍼-물체 접촉 상태를 이동 디코더 조건화 신호로 주입; 바디 전문가가 핸드-물체 접촉 상태를 실시간 수신하는 설계 후보 경로

### (d) 먼저 확인할 점

- **항공 도메인 특화** — UAV 이동 + 암 조작 환경 전용; P1 타겟인 bimanual 팔 + 다지 핸드(이동 없음) 환경에서 동일 캐스케이드 원리의 성능 이득 유지 여부 독립 확인 필요
- **정보 흐름 방향 차이** — AIR-VLA+에서 정밀 조작기(암)→거친 이동기(UAV) 방향; P1의 D6 body→hand 계층 흐름과 방향이 반대 — 어느 방향이 더 효과적인지 bimanual + 다지 핸드 환경에서 ablation 필요
- **저렴한 점검** — bimanual 팔 + 그리퍼 시뮬레이션에서 캐스케이드 바디/핸드 디코더로 body→hand 단방향 vs hand→body 단방향 비교, 정보 흐름 방향 우위 1차 측정

## 🥉 논문 3 — 우선순위 ★

**See Selectively, Act Adaptively: Dual-Level Structural Decomposition for Bimanual Manipulation**
[arXiv:2606.13279](https://arxiv.org/abs/2606.13279) · Yoon-Ji Choi, Young-Chae Son, Soo-Chul Lim · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **양손 조작의 단일 공유 표현·경로 한계 명시** — 기존 모놀리식 VLA가 다양한 시각 입력과 팔 간 상호작용 패턴을 단일 표현·액션 생성 경로로 처리 → 시각 관련성과 양손 구조를 분리 처리 실패
- **이중 수준 구조 분해(Dual-Level Structural Decomposition)** — 시각 수준 + 액션 수준 동시 분해
  - **View-Selective Visual Router**: 태스크 단계·맥락에 따라 각 손목 카메라(wrist-view) 기여도를 동적 조정, 관련 시각 단서 선택적 강조
  - **Interaction-Aware Action MoE**: 액션 생성을 협조(coordinated) 경로와 팔별(arm-wise) 경로로 분해
    - 양손 상호작용 모드(협조·독립)에 따라 적응적 전환
- **성능**
  - RoboTwin 2.0 6개 시뮬레이션 태스크: 모놀리식 baseline 대비 평균 +27.7%
  - 실세계 3개 장기 지평 태스크: +43.3%
- **진정으로 새로운 점**
  - 기존 양손 VLA — 협조/독립 모드를 단일 디코더 암묵적 혼합 처리
  - 시각 라우터(선택적 시점) + 액션 MoE(협조/팔별 분해)를 동시 설계한 이중 수준 구조 최초 도입

### (c) 시사점

- **팔 분리 비교군으로서 MoE의 실세계 정량 검증** — 협조·팔별 경로로 액션 생성 분리 시 실세계 +43.3% 향상; 해부학적 분리(P1 body/hand)가 MoE 암묵 라우팅 분리 대비 추가 이득을 갖는지 비교 실험 기준점 확보
- **상호작용 모드 적응 설계 아이디어** — 바디-핸드 상호작용이 태스크 단계에 따라 협조·독립 모드로 전환될 때 Interaction-Aware 라우팅이 이를 자연스럽게 처리; body/hand 조건화 강도를 태스크 단계별 동적 조정하는 설계 후보
- **View-Selective Visual Router 참조** — 손목 카메라 기여도 동적 조정이 손가락 끝 카메라·전방 카메라 간 모달리티 기여도 조정 설계에 직접 참조 가능

### (d) 먼저 확인할 점

- **MoE 라우팅의 암묵성** — 팔별 분리가 MoE 내 암묵 라우팅으로 구현 → P1 해부학적 분리(별도 바디/핸드 네트워크)와 달리 분리 경계가 유동적; 실험 없이 "팔별" 경로가 실제 팔별 액션 분리를 학습했는지 확인 불가
- **양손 팔 대칭 구조 전제** — 두 팔이 대칭적으로 동등한 wrist-view 보유; P1의 비대칭 구조(바디=손목 포즈, 핸드=손가락 관절)에서 팔-핸드 비대칭을 동일 MoE로 처리 시 라우터 혼란 가능
- **저렴한 점검** — 단일 팔 + 다지 핸드 환경에서 Interaction-Aware Action MoE(coordinated vs arm-wise)를 body/hand split 구조로 대응하여 MoE 라우팅 vs 명시적 분리 성능 차이 측정
