## 🥇 논문 1

**TouchTwin: Scaling Human Touch Data via Real-to-Sim-to-Real**
[arXiv:2611.17619](https://arxiv.org/abs/2611.17619) · Huiwen Han, Nuo Chen, Ziyao Zeng 외 6명 · arXiv preprint · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — P0 2026-11-18 판정 유지

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 측정한 사람 촉각으로 영상 복원 시뮬레이션의 힘을 보정
- **문제** — 사람 시연을 시뮬레이션에서 복원해 늘리는 파이프라인이 접촉력을 담지 못함
  - 영상은 손과 물체의 움직임만 복원하고 어느 손가락이 언제 얼마나 세게 닿는지는 관측하지 못함
  - 손 자세는 손가락이 멈춘 자리를 보일 뿐 얼마나 더 닫아 쥐는지는 보이지 않음
- **기존 한계** — 영상 기반 복원의 두 표준 용법이 서로 반대 방향으로 실패
  - **자세 모방** — 기록된 힘의 0.31배로 쥠
  - **영상 추적 자세의 물리 재생** — 기록된 힘의 1.55배로 쥠
  - **장갑·웨어러블 선행 연구** — 손-물체 동역학 모델링, 촉각과 영상의 상호 변환, 정책 지도에는 쓰였으나 측정 촉각으로 구동하는 물리 시뮬레이션으로 상호작용을 복원한 사례는 없다는 지적
  - **영상에서 예측한 촉각** — 같은 픽셀로 장갑 신호를 재현하도록 학습되어 픽셀에 안 보이는 힘을 복원하지 못하고 기록 조건을 바꾸지도 못함
- **핵심 방법** — 선별한 TouchScale 기록을 MuJoCo로 복원하고 기록된 촉각이 손가락별 접촉과 닫는 힘을 정함
  - **물체** — 코딩 에이전트가 물리 시험을 거친 프로그램으로 작성
  - **손** — 헤드·손목 카메라 양쪽에서 추적한 피험자별 손 모델에 촉각 센서를 배치
  - **재생** — 기록 촉각이 눈에 보이는 자세를 넘어 손가락마다 접촉 위치, 시점, 세기를 지정
  - **데이터 엔진** — 각 재생이 접촉·힘 라벨이 붙은 교란 시연과 새 시점·장면의 사실적 영상을 시드
- **차별점** — 영상으로 힘을 추정하지 않고 장갑이 잰 촉각으로 시뮬레이션의 접촉과 힘을 직접 정함
  - 한 번의 기록을 새 조건에서 다시 재생할 수 있음
- **핵심 기여** — 시뮬레이션 실험 결과와 데이터 엔진
  - 보류 기록에서 촉각 접지 재생으로 학습한 정책이 기록 힘의 0.99배로 쥠
  - 접촉 예측기가 실제 접촉 프레임을 놓치는 비율 13%, 영상 기반 재생 32%
  - 보류 기록 20회 중 20회, 처음 보는 교란 36회 중 35회 성공
  - **TouchScale** — 머리·손목 RGB-D 카메라와 880 택셀 장갑으로 기록한 코퍼스에서 일부를 선별해 사용
  - 재생에서 교란 시연과 접촉·힘 라벨이 붙은 영상 생성
- **가치** — 부족한 촉각 기록을 추가 수집 없이 힘 라벨이 붙은 데이터로 늘리는 경로 제시

### (c) 시사점

- 촉각 장갑 기록이 영상 복원의 힘 공백을 메운다는 근거
  - **접촉 데이터 공백** — 영상 추정 갈래가 못 채우는 힘을 측정 촉각이 채운다는 정량 비교
  - **데이터 증폭** — 장갑 기록 한 건에서 힘 라벨이 붙은 교란 시연을 만드는 구성
  - **코퍼스 항목** — 880 택셀 장갑 기록 규모와 라이선스는 TouchScale 쪽 확인 필요

### (d) 먼저 확인할 점

- **실물 결과 없음** — 정책은 시뮬레이션 자산에서 개루프로만 시험, 로봇 손 전이와 실물 실험이 남은 과제라고 저자가 인정
- **평가 범위** — 보류 기록이 작고 정책·접촉 실험이 머그잔 과제 하나뿐
  - 보류 클립이 이미 접촉 중인 손으로 시작해 접촉 개시는 시험하지 못함
- **복원 오차** — 두 손 재생에서 손 안 미끄러짐 12–23 mm가 남고 생성 영상이 시뮬레이션 오차를 물려받음
- **공개 여부** — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

## 🥈 논문 2

**Hidden Variables Behind Real-Robot Data Quality: Lessons from Hundreds of Thousands of Hours**
[arXiv:2611.22388](https://arxiv.org/abs/2611.22388) · Maniformer Real-World Manipulation Team 외 41명 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R2 · N3 · M3 · Real3 · Repro0 — arXiv comment "Technical report. Project page: https://teleop.agibot.com/" — 프로젝트 페이지만, 코드 언급 없음

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 실물 수집 시스템 설계가 시연 품질과 정책에 미치는 영향
- **문제** — 로봇 데이터 수집이 커질수록 수집 시스템 설계가 효율과 시연 품질을 함께 좌우
  - 느린 영상 피드백이 만든 멈춤, 우회, 교정 동작이 성공한 시연 안에 그대로 기록됨
  - 작업 영역 한계와 조작 모드 전환도 같은 보정 동작을 유발
- **기존 한계** — 과제 성공만으로는 시연 품질이 드러나지 않는다는 저자 주장
  - 보정 동작 일부를 정책이 그대로 재현
  - 카메라 밖 시각 단서로 고른 행동은 정책에 근거가 남지 않고, 관절 영점 보정 차이는 같은 기록값을 다른 자세로 만듦
- **핵심 방법** — 세 관점으로 실험
  - **구현체** — 쌍팔 로봇 25종의 기구학 모델로 방향까지 고려한 작업 영역 포괄도와 관절 한계 여유 분석
  - **원격조작 제어** — 제어 병렬화, 모션 매핑, 컴플라이언트 제어, 지연, 주변기기를 대표 과제와 통제 실험으로 비교
  - **데이터 품질** — π0.5 미세조정과 실물 로봇 평가로 시각 단서 누락, 영점 보정 불일치, 중복 동작의 영향 측정
- **차별점** — 수집 시스템 설계와 시연 품질을 함께 평가해야 한다는 관점
  - 수집 전에 작업 영역, 제어 효율, 관측 완전성, 보정 정렬, 동작 품질을 점검하라는 권고로 이어짐
- **핵심 기여** — 설정별 수치가 붙은 실증 결과와 수집 권고
  - **구현체** — 위치 도달만 보면 휴머노이드와 휠 리프트 팔이 시상면 55%와 53%를 닿지만 도구 방향 포괄도는 41%와 33%, 탁상형 팔은 91%와 75%
  - **구현체** — 어깨 15 cm 이동 허용 시 도달 단면 3.4–5.5배 확대
  - **제어 병렬화** — 허리를 IK로, 베이스와 머리를 헤드셋으로 옮겨 과제 완료 시간 43–53% 단축
  - **컴플라이언트 제어** — 힘 제어 성공률 100%, 위치 제어 80–87%, 최대 접촉력 55–71% 감소
  - **시각 단서** — 능동 탐색 시연으로 팔 선택 정확도가 무작위 50%에서 100%로 상승
  - **보정** — 추론 쪽 보정 불일치 시 30회 전부 실패, 추론 정렬 부분집합을 남기면 66.7%, 없으면 26.7%
  - **동작 품질** — 정책이 불필요한 경로 길이의 약 90%와 저크의 45%를 유지, 우회 80% 시연으로 실행 29% 느려짐
- **가치** — 실물 데이터를 늘리기 전에 수집 설정을 점검할 근거와 기준 제시

### (c) 시사점

- 수집 시스템 점검 항목이 코퍼스 품질 기준이 될 여지
  - **로봇 행동 코퍼스** — 성공 여부 외에 경로 효율, 연속성, 보정 정렬, 관측 완전성을 시연 채택 기준으로 쓰는 안
  - **규모 근거** — 수집 20만 시간대 운영 경험이 근거이며 접촉 집약 과제가 207k 수집 시간의 18.5%
  - **코퍼스 메타데이터** — 보정 버전과 영점 확인 기록을 코퍼스 항목에 남기는 설계 참고

### (d) 먼저 확인할 점

- **공개 여부** — 프로젝트 페이지만 있고 코드, 데이터 공개 약속이 초록·comment에 없음
  - 코퍼스 자체가 공개되는지 확인 필요
- **저자 인정 한계** — 대표 과제 몇 개, 제한된 운영자·장치 구성, 단일 정책 모델과 하나의 액션 표현
  - 일부 실험은 인위적으로 주입한 오프셋이나 단일 학습 실행
- **일반성** — 효과 크기와 일반성은 더 많은 과제와 정책 구조에서 검증 필요라고 저자가 명시
- **손재주 범위** — 구현체와 제어 분석은 쌍팔 로봇 중심, 다지 손 시연의 품질 문제는 초록에 없음

## 🌱 논문 3 — 인접 분야 픽

**DoF-Query Transformer for Adaptive Fusion of Egocentric Vision and Forearm HD-sEMG in Continuous Hand Kinematics**
[arXiv:2611.20196](https://arxiv.org/abs/2611.20196) · Jiahang Liu 외 6명 · adjacent field: 보철·신경과학 감지 — 전완 근전도 (Slot D)

**점수 6/15** · R2 · N2 · M2 · Real0 · Repro0 — P0 2026-11-18 판정 유지

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 자유도별 쿼리로 시각과 근전도를 융합한 손 관절각 추정
- **문제** — 사람 손 운동학의 연속적이고 정확한 추정이 인간-기계 상호작용과 로봇 학습용 세밀한 조작 시연 수집에 필요
- **기존 한계** — 단일 감지 모달리티는 다양한 작동 조건에서 신뢰할 만한 추정에 불충분
- **핵심 방법** — 에고센트릭 RGB와 128채널 전완 고밀도 표면 근전도(HD-sEMG)에서 손 관절각 20개를 연속 회귀하는 손가락 비구속 멀티모달 프레임워크
  - **시각 인코더** — Vision Transformer 기반
  - **근전도 인코더** — Transformer 기반
  - **DoF 쿼리 융합 디코더** — 자유도마다 학습 가능한 쿼리를 따로 두어 자유도와 입력 조건별로 두 모달리티를 적응적으로 융합
- **차별점** — 시각·근전도 단서의 정보량이 관절 자유도와 입력 조건에 따라 다르다는 점을 자유도별 쿼리로 반영
- **핵심 기여** — 참가자 10명의 동기화 멀티모달 데이터에서 융합 모델 성능
  - 참가자 평균 R² 0.88, MAE 2.80°, 시각 전용 0.82·3.21°, 근전도 전용 0.68·5.13°
  - 평가한 대표 단일 모달 기준선과 대안 융합 설계보다 우수
  - 시각적으로 모호한 관절과 시야 조건에서 융합 이득이 크고, 합성 시각 가림에서 시각 전용보다 강건
- **가치** — 에고센트릭 시각과 전완 근전도의 상보성을 보여 사람 시연 수집용 세밀한 손 운동학 포착 경로 제시

### (c) 시사점

- 에고센트릭 손 추적 주석에 근전도를 더하는 보강 후보
  - **에고센트릭 코퍼스** — 가림이 잦은 영상 손가락 추적에 전완 근전도를 보조 신호로 두는 구성
  - **수집 방식** — 손가락에 장치를 달지 않는 수집이라 맨손 시연 기록과 양립
  - **도입 비용** — 128채널 전완 HD-sEMG 장비가 추가로 필요

### (d) 먼저 확인할 점

- HTML 원문 없음 — 요지는 초록 기준
- 로봇 결과 없음, 사람 손 관절각 추정만 평가
- 가림은 합성 시각 가림으로만 평가, 실제 조작 중 손-물체 가림에서의 이득은 미측정
- 코퍼스 공개 신호 없음, 참가자 10명 규모
- 코드 저장소나 공개 약속 없음
