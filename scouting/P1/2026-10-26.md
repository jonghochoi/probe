## 🥇 논문 1

**VLA-Fabric: Learning Interaction for Composable Multi-Arm VLA Agents**
[arXiv:2610.23018](https://arxiv.org/abs/2610.23018) · Chenglong Zhang, Shuaijun Liu, Feiyang You 외 3인 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — §Sx2 "The project website links the code release, including both VLA realizations and 2/3/4-agent workflows."

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 논문 요지

- 팔마다 완전한 VLA를 두고 내부 표현으로 협응
- **문제** — 여러 팔이 하나의 물리 목표를 위해 협응하는 시스템에서, 완전한 VLA 정책끼리 액션 생성 중 어떻게 상호작용할지의 부재
  - 팔 수와 역할이 늘어도 팔 단위 모듈성을 유지하면서 긴밀한 협응을 지원해야 함
- **기존 한계** — 기존 다팔 VLA는 협응을 세 곳 중 한 곳에 둠
  - 결합 정책 내부 — RDT-1B, ET-VLA, TwinVLA, Dexora가 팔 사이 의존성을 하나의 정책에 흡수
  - 정책 위 계층 — MA-VLA가 원자 행동을 팔별로 할당
  - 관측을 통한 간접 협응 — CHORUS가 팀원을 관측하고 반응하는 지역 실행 정책으로 런타임 메시지 없이 분산 협응
- **핵심 방법** — 팔별 완전한 VLA가 지역 지각과 액션 소유를 유지하고, 선택된 피어 표현이 각자의 계산을 조건화
  - 분해 가능한 양팔 VLA(Eagle2 VLM 기반 SingleVLA)에서 팔 사이 의존성을 분리한 뒤 상호작용 진입점, 집계 연산, 미세조정 전략의 조합 공간을 통제 탐색
  - 공유 맥락, 피어별 잠재 정보, 액션 단계의 세 지점이 서로 보완하는 기능으로 확인됨
  - 같은 기능을 π0.5에 계산 경계에 맞춰 재구현하고 3팔과 4팔 팀으로 확장
- **차별점** — 팔 사이 의존성을 결합 정책에 넣지 않고, 완전한 정책 경계를 가로지르는 학습된 상호작용으로 처리
  - 피어 정보를 더 많이 노출한다고 협응이 보장되지 않으며 상호작용 구조와 적응 방식이 좌우한다는 것이 통제 연구의 결론
- **핵심 기여** — 상호작용 아키텍처, 교차 아키텍처 이식, 다팔 확장
  - 두 VLA 구현(SingleVLA, π0.5)에서 같은 협응 구성 재현
  - 시뮬레이션과 실물 3팔·4팔 과제 4개에서 Full 상호작용이 독립 학습 지역 정책보다 16–40%p 높은 성공률, 정책 설정당 실물 25회 시행
- **가치** — 구성 VLA의 발전과 팀 구성 방식의 발전을 분리해 각각 진전시킬 수 있는 다팔 협응 구조 제시

### (c) 시사점

- 정책 경계에서 어디에 어떤 정보를 넣을지 비교한 통제 연구
- **정보 공유 지점** — 단일 변조 지점이 아니라 맥락, 중간 잠재, 액션 단계 세 곳의 상호작용이 보완 관계라는 측정
  - 한 번의 조건화로 충분한지 가늠할 때 비교 기준점
- **조정 방향** — 팔 사이 피어 정보를 교환하는 구성이라 몸통→손 위계 흐름과 다른 방향의 사례
- **도입 비용** — 팔 수만큼 완전한 VLA를 두는 구조라 몸·손 분할에는 그대로 옮기기 어려움

### (d) 먼저 확인할 점

- **분할 단위** — 몸통과 손이 아니라 팔 단위 분할이라 이음새가 다름
- **저장소 URL** — 본문에는 프로젝트 사이트가 코드 공개를 링크한다는 서술만 있고 저장소 URL은 직접 나오지 않음
- **저자 명시 한계** — 동질 팀과 고정 역할, 최대 4팔 범위이고 상호작용 구조는 정적
  - Arch Building 같은 장기 고정밀 조작은 여전히 어려움
- **비교 대상** — 실물 비교가 독립 학습 정책 대비이고, 결합 정책과의 실물 직접 대조는 확인되지 않음

## 🥈 논문 2

**Interaction Latents as Actions for Contact-Rich Manipulation**
[arXiv:2610.18855](https://arxiv.org/abs/2610.18855) · Yuhang Zheng, Yujie Zang, Yuchen Liu 외 3인 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX)

### (b) 논문 요지

- 동작·접촉·힘을 한 잠재로 묶어 액션 단위로 사용
- **문제** — 접촉 집약적 조작에서 접촉 상태, 힘 크기, 그 시간 전개를 반영한 동작 생성
  - 비슷한 동작도 접촉 패턴이 다르고, 같은 과제도 동작과 힘의 조합이 달라질 수 있음
- **기존 한계** — 정책이 액션을 주로 동작 궤적으로 표현하고 촉각은 입력이나 보조 예측 목표로만 사용
  - RDP, T-Rex 같은 시각-촉각 정책 — 고주파 촉각 피드백으로 접촉 변화에 적응하나 액션 단위 자체는 동작 궤적
  - VT-WAM, N0-TWAM 같은 월드 액션 모델 — 미래 시각·촉각·액션을 함께 예측하나 생성된 액션 단위가 동작과 촉각 복원을 동시에 받치도록 요구하지 않음
  - 접촉과 힘 정보가 액션 표현에서 사라져 동작-접촉 협응을 제한할 수 있다는 것이 저자 주장
- **핵심 방법** — 동작·접촉·힘 전개를 복원 가능한 잠재로 학습하고 정책이 이 잠재를 생성
  - 액션과 촉각 시퀀스를 공유 병목으로 인코딩, 시간 조건 암시적 디코더가 액션, 촉각 변형장, 총 변형을 복원
  - 잠재를 플로우 매칭 생성 목표로 써서 VLA와 월드 액션 모델(WAM)을 사후학습하고 플로우 매칭 정책은 처음부터 학습
  - 공유 디코더가 생성된 잠재를 실행 가능한 액션으로 변환
- **차별점** — 촉각을 조건으로 넣는 대신 액션 단위 자체에 접촉 전개를 담음
  - 직접 동작 생성, 촉각 조건화, 액션-촉각 동시 예측과의 대조로 액션 단위의 역할을 분리
- **핵심 기여** — 액션 표현, 같은 잠재 공간의 오프라인 개선, 세 정책 계열 실물 검증
  - 실물 4개 과제(오이 껍질 벗기기, 달걀 뒤집기, 셀러리 썰기, 접시 닦기)에서 과제당 20회 시행, 촉각 조건 직접 액션 기준선 대비 평균 성공률 21.0–36.5%p 향상
  - 전문가 시연으로 정의한 일관성 보상으로 성공 롤아웃을 가중하고 실패 예측을 참조로 교정
  - 오이 껍질 벗기기에서 힘 대리 오차 75% 감소와 성공률 75%에서 85%
- **가치** — 힘과 접촉을 액션 표현에 넣으면 생성, 평가, 개선이 한 잠재 공간에서 이루어진다는 근거

### (c) 시사점

- 액션 목표에 접촉 전개를 넣은 효과의 실물 측정
- **출력 공간 대조** — 직접 액션 생성 대 잠재 액션 단위를 세 정책 계열에서 맞댄 결과라, 손 출력 표현을 바꿀 때의 이득을 가늠하는 자료
  - 손가락 관절 명령을 잠재로 대체한 선행 결과와 같은 방향
- **적용 범위** — 월드 액션 모델과 VLA 사후학습에도 붙여 쓸 수 있어 기존 백본 위 실험 비용이 낮을 가능성
- **오프라인 개선** — 같은 잠재에서 보상과 교정을 얻는 경로라 추가 수집 없이 정책 개선에 참고

### (d) 먼저 확인할 점

- **코드 미공개** — 초록에 프로젝트 웹사이트 링크만 있고 저장소나 공개 약속 없음
- **방법론 범위** — 반복 시드나 한계 서술이 본문에 없고 과제당 20회 시행 규모
- **분할 구조 아님** — 몸통과 손의 분리가 아니라 액션 표현 연구라 분할 구조와의 직접 대응은 제한적
- **센서 의존** — 학습에 촉각 변형장이 필요해 촉각 센서가 없는 손에는 그대로 적용 불가

## 🥉 논문 3

**TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model**
[arXiv:2610.00638](https://arxiv.org/abs/2610.00638) · Enyi Wang, Mingxin Wang, Quan Shi 외 3인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R2 · N3 · M3 · Real3 · Repro1 — P3 2026-10-19 판정 유지

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 논문 요지

- 미래 촉각 픽셀 대신 접촉 전개를 별도 전문가가 예측
- **문제** — 촉각 월드 모델이 무엇을 예측해야 하는가
  - 접촉 위치나 힘이 조금만 달라도 촉각 이미지는 크게 변하지만 접촉 전개 자체는 예측 가능한 경우가 많음
  - 시연은 올바른 접촉 근처의 촉각 이미지만 담아 폐루프 오차로 분포를 벗어나면 픽셀 예측이 불안정
- **기존 한계** — 기존 촉각 월드 액션 모델이 영상 생성 파이프라인을 재사용
  - 같은 VAE로 카메라와 촉각 프레임을 인코딩하고 영상 백본이 미래 촉각 잠재를 반복 디노이징해 추론이 느리고 픽셀 복원에 묶임
  - N0-VTLA — 동결된 DINOv2 특징 공간에서 단일 지평의 순변화만 예측, 정적 자연 이미지로 학습된 표현이라 촉각 전개 포착에 최적화되지 않음
  - 단일 순변화는 눌림이나 미끄러짐이 비슷한 최종 상태로 돌아올 때 중간 접촉 사건을 가림
- **핵심 방법** — 시각 전문가와 암시적 촉각 동역학 전문가(ITDE)가 별도 파라미터와 목표 공간에서 예측하고 조인트 어텐션으로 결합
  - TacRep — 촉각 클립에서 마스킹 시공간 예측으로 학습하고 관계 구조 증류로 정규화한 동역학 인지 목표 공간
  - ITDE — 미래 표현과 그 변화를 여러 지평에서 한 번의 순전파로 예측, 반복 디노이징 없음
  - 읽기 전용 촉각 이해 메모리가 현재 촉각 상태를 공급하고 단계별 학습으로 촉각 모듈을 사전학습 전문가에 통합
- **차별점** — 미래 촉각 관측 복원 대신 목표 공간에서 접촉 전개를 예측하는 별도 전문가
- **핵심 기여** — 시뮬레이션과 실물 결과
  - UniVTAC에서 제공 시연만으로 평균 성공률 81.5%, 대규모 시각-촉각 사전학습 모델과 경쟁 수준
  - 실물 5개 과제에서 과제별 시연만으로 평균 71.0%, 촉각 정책 FTP-1 대비 16%p 높고 약 6,000개 실물 시각-촉각 궤적의 소규모 사전학습으로 85.0%
  - 어블레이션 — 두 촉각 경로와 TacRep이 픽셀 복원과 정적 대안보다 우위
- **가치** — 촉각 월드 모델이 픽셀 복원 없이 접촉 전개만 예측해도 성능과 추론 속도에서 이득이 난다는 근거

### (c) 시사점

- 촉각을 별도 전문가로 떼어 시각 전문가와 어텐션으로 잇는 구성
- **분할 유형** — 몸통과 손이 아니라 시각과 촉각의 전문가 분리라, 분리된 전문가를 어떤 지점에서 결합할지 가늠하는 증거
  - 매 층 조인트 어텐션으로 결합해 단일 변조 지점보다 결합이 촘촘한 사례
- **입력 분리** — 입력 모달리티별 전문가와 한 번의 순전파 예측이 결합된 구성이라 추론 비용 측면에서도 참고
- **도입 비용** — 사전학습된 전문가에 촉각 모듈을 단계별로 붙이는 방식

### (d) 먼저 확인할 점

- **코드 미공개** — Repro 판정은 P3 2026-10-19 리포트에서 유지, 공개 약속 수준
- **센서 한정** — 저자가 TacRep과 ITDE가 한 종류의 시각-촉각 센서로만 학습되었다고 명시

## 🌱 논문 4 — 인접 분야 픽

**NestedVLA: Learning to Consolidate and Generate Skills for Vision-Language-Action Models**
[arXiv:2610.23271](https://arxiv.org/abs/2610.23271) · Guodong Du, Wanyu Lin · adjacent field: VLA 아키텍처 확장(스킬 통합) · NeurIPS 2026 · 코드 공개

**점수 9/15** · R2 · N2 · M3 · Real0 · Repro2 — arXiv comment "Code: https://github.com/WanyuGroup/NeurIPS2026-NestedVLA"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 논문 요지

- 하이퍼네트워크가 과제별 액션 전문가 갱신을 생성
- **문제** — 같은 백본에서 따로 미세조정한 VLA 정책들을 원 학습 데이터 없이 하나로 통합
  - 과제마다 체크포인트를 따로 저장하면 대부분의 파라미터가 중복
  - 데이터를 모아 공동 학습하는 방식은 원 데이터가 없으면 불가
- **기존 한계** — 파라미터 갱신을 하나의 체크포인트로 병합하는 방식
  - 단순 평균은 개별 정책 성능 대부분을 잃음
  - 가중치 공간 분석에서 주요 파라미터 그룹 사이 정렬이 약하고, 액션 전문가에서 특히 제어에 직접 영향
  - MergeVLA도 액션 전문가 층에 분산된 의존성이 교차 스킬 병합의 주된 장애물이라고 지적
- **핵심 방법** — 파라미터 집계 대신 파라미터 생성
  - VLA에 내장된 하이퍼네트워크가 대상 과제에 조건화된 희소 액션 전문가 갱신을 생성
  - 압축된 과제별 VLM 잔차는 따로 보관하고, 두 갱신을 동결된 기반 VLA에 더해 과제별 정책 구성
  - 순전파 구조 변경과 라우팅 지도 없음
- **차별점** — 갱신을 하나로 합치지 않고 과제별 구조를 보존
- **핵심 기여** — 통합 성능과 저장 효율
  - MetaWorld, ManiSkill, CALVIN의 세 정책 통합에서 평균 성공률 66.7%, 가장 강한 병합 기준선 대비 41.1%p 향상
  - ManiSkill에서 과제별 미세조정과 1%p 이내, CALVIN에서 격차를 크게 좁힘
  - 세 정책 설정에서 총 저장량이 단일 전체 체크포인트의 1.5배
- **가치** — 학습 데이터 없이 여러 VLA 스킬을 한 기반 위에 공존시키는 경로 제시

### (c) 시사점

- 동결 기반 위에서 액션 전문가 갱신만 따로 생성하는 방식
- **백본 분할** — 액션 전문가를 기반에서 분리해 갱신하는 구조라 π 백본에서 전문가를 떼어 내고 미세조정하는 방식을 고를 때 비교 자료
  - 액션 전문가가 제어에 가장 직접 영향한다는 가중치 분석이 분할 경계 선택에 참고
- **도입 비용** — 저장량 1.5배로 과제별 정책을 보존해 부담이 낮음

### (d) 먼저 확인할 점

- **시뮬레이션 한정** — 저자가 실물 하드웨어는 평가하지 않았다고 명시
- **분할 아님** — 과제 간 스킬 통합이라 몸통과 손의 분리와는 다른 문제
- **적용 범위** — 세 벤치마크, 세 정책 설정, 손가락 수준의 다지 조작은 포함하지 않음
- **저자 명시 한계** — 부록 H에 네 가지 한계를 기술
