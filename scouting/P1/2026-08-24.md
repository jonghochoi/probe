## 🥇 논문 1 — 우선순위 ★★

**τ₀-VLA: a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation**
[arXiv:2608.16885](https://arxiv.org/abs/2608.16885) · Cai et al. · arXiv preprint · source: citation-graph (π0) · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **계층 구조**: 고수준 서브태스크 생성 정책 + 저수준 실행 정책 두 계층 명시 분리; 실행 메모리를 통해 이전 서브태스크 컨텍스트 보존
- **테스트타임 컴퓨팅 확장**: 어려운 의사결정 구간에서 서브태스크 대안 탐색 후 확정; 단일 포워드 패스에서 가변 컴퓨팅 배분으로 전환
- **스케일**: 40,115시간 이종 실세계 데이터 + 멀티모달 공동학습; 복수 로봇 이보디먼트 저레벨 정책 통합
- **결과**: 도메인 내·분포 이동 양측에서 테스트타임 컴퓨팅 증가 시 서브태스크 예측 정확도 향상; 장기 조작 클로즈드루프 성공률 상승

### (c) 시사점

- **고수준-저수준 분리 기준점**: 서브태스크 계층 분할이 40k시간 실세계 스케일에서 장기 조작에 유효; 복수 이보디먼트 저레벨 정책 통합 아키텍처 설계 시 참조 가능
- **테스트타임 컴퓨팅 배분**: 어려운 의사결정 구간에 컴퓨팅 집중이 클로즈드루프 성공률 직결; 계층 액션 전문가 추론 설계 시 참조

### (d) 먼저 확인할 점

- **고수준-저수준 경계 기준 미명시**: 어떤 조건에서 고수준 정책이 개입하는지 구체적 기준 확인 필요
- **저레벨 정책의 손가락 DoF 범위**: 장기 조작 태스크에서 접촉 집약적 손가락 제어 요구 시 저레벨 정책 DoF 범위 확인 필요
- **코드 미공개**: 프로젝트 페이지(https://tau0-vla.github.io/) 공개; 구현 재현은 릴리즈 후 가능

## 🥈 논문 2 — 우선순위 ★★

**DECOWAM: Decoupled Whole-Body World-Action Model for Legged Mobile Manipulation**
[arXiv:2608.20114](https://arxiv.org/abs/2608.20114) · Ma et al. · arXiv preprint · source: citation-graph (π0) · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **분리 조건부 인터페이스**: 로코모션(베이스)·팔 액션·카메라 자기운동 세 요인을 전용 조건부 채널로 명시 분리; 기존 WAM이 혼합하던 요인을 독립 변수로 처리
- **적응 구조**: FastWAM 백본 동결 + 잔차 어댑터 학습; 특권 관측에서 증류된 액션 등가 미래 병목 + 적대적 잠재 변수 분리
- **ARMDOG 데이터셋**: 비디오·전신 상태·액션·언어를 동기화한 이족보행 이동 조작 실제 로봇 데이터셋 신규 공개
- **결과**: 79회 클로즈드루프 실험에서 FastWAM 대비 액션 MSE 21.7% 감소; 전신 협조 및 베이스 변위 견고성 최고 기록 (태스크 완수율은 기준선과 유사)

### (c) 시사점

- **이보디먼트 인식 분리 유효성**: 바디 파트별 명시 분리가 이동 조작 WAM에서 예측 정확도·협조를 개선; 팔/손 분리 설계의 동기 지지
- **ARMDOG 참조 가능성**: 멀티모달 전신 동기 데이터 형식이 Body·Hand 관측 동기화 설계 시 구조적 참조 가능
- **적응 전략**: 동결 백본 + 잔차 어댑터 패턴이 분리 액션 헤드 도입 비용 절감 경로 시사

### (d) 먼저 확인할 점

- **팔·손 레벨 미분리**: 이 논문의 분리는 베이스(이동)·팔 수준; 손가락 관절 수준 분리로의 확장성 별도 확인 필요
- **태스크 완수율 동등**: 액션 MSE 개선에도 클로즈드루프 태스크 완수율이 최강 기준선과 유사; 분리 효과가 태스크 수준 성능까지 이어지는지 추가 확인 필요
- **코드·데이터셋 미공개**: 재현 불가; ARMDOG 데이터 공개 여부 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**Pre-training Visual Dexterity in Simulation**
[arXiv:2608.15917](https://arxiv.org/abs/2608.15917) · Kamat et al. · arXiv preprint · source: keyword sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **SPD 사전학습 파이프라인**: 운영자가 VR 헤드셋 안에서 가상 객체를 직접 손으로 조작 → 온-이보디먼트 경로 + 하드웨어 없이 다지 조작 시연 수집; 5인 운영자·1주간·75시간 멀티태스크 수집
- **모델**: 인과 트랜스포머 시퀀스 모델링으로 시뮬레이션 데이터 사전학습; 히스토리 컨디셔닝 포함
- **실환경 전이**: 물리 시연 1–2시간 파인튜닝으로 56-DoF 양손 다지 로봇 실환경 태스크 수행; BC from scratch 대비 우수
- **분석**: 히스토리 컨디셔닝·짧은 액션 청크의 반응형 제어 기여 ablation 포함

### (c) 시사점

- **Hand 전문가 사전학습 비용 경로**: 물리 텔레오퍼레이션 없이 대규모 다지 조작 사전학습 가능성 확인; Hand 헤드 학습 데이터 비용 절감 방안 탐색 시 참조 가능
- **짧은 청크 반응성**: 짧은 액션 청크가 접촉 집약적 다지 조작에서 반응형 제어 향상; 손 제어 출력 설계 시 참조

### (d) 먼저 확인할 점

- **실환경 전이 스케일 제한**: 물리 파인튜닝이 1–2시간 소량 데이터에 의존; 복잡한 접촉 집약적 태스크로의 확장성 미검증
- **기준선 단순**: BC from scratch 하나만 비교; 최신 다지 VLA 기준선과의 직접 비교 미제시
- **코드·데이터셋 미공개**: 프로젝트 페이지([spd.bot](https://spd.bot)) 공개; 릴리즈 후 재현 가능
