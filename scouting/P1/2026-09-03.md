## 🥇 논문 1 — 우선순위 ★★

**Facet-0: Learning Contact-Rich Manipulation with Action-Wrench Prediction**
[arXiv:2609.01596](https://arxiv.org/abs/2609.01596) · Haoyuan Deng, Haichao Liu, Wenkai Guo, Yuan Ling et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 핵심 기여

- 행동-렌치 공동 예측(Action-Wrench Proposal) 제안 — 플로우 매칭으로 행동 청크와 미래 손목-렌치 프로파일을 동시 출력하는 분리 헤드 구조
- Action-Wrench Critic 도입 — 접촉 결과를 구분하는 분포형 RL 비평기, 기존 행동 비평기 대비 접촉 다양성 처리 개선
- ManuFacet-1K 데이터셋 공개 예정 — 힘-동기화 1,000시간 데모, 3종 embodiment 포괄
- 5개 서브-mm 조립 과제에서 성공률 82% 달성(베이스라인 15%), 위치 정밀도 0.5 mm, 명령 지연 50 ms

### (c) 시사점

- 정책 루프 내 접촉 신호 처리 — 20Hz 렌치 예측으로 별도 고속 제어 루프 없이 서브-mm 조립 달성; D5DQ 개방 질문에 대한 실증 데이터 확보
- 분리 보조 렌치 헤드 패턴 — 분할 헤드 설계의 실제 조립 과제 유효성 확인
- Cartesian 행동 출력 — 실제 제조 환경 3종 embodiment 전이 적용 가능성 검증

### (d) 먼저 확인할 점

- 프로젝트 페이지만 공개(코드·데이터 미공개) — 방법론 재현 불가, 상세 구현 확인 제한
- 제조 도메인 특화 — 손가락 관절 명령 없음, 다지 구동기 전이 가능성 미검증
- 렌치 예측 ≠ 렌치 제어 — 보조 예측 헤드이며 직접 힘 제어 루프 아님; 미끄러짐 감지 한계

## 🥈 논문 2 — 우선순위 ★★

**Knowing When to Stop: Attention Entropy as a Signal for Adaptive Action Chunking**
[arXiv:2609.00908](https://arxiv.org/abs/2609.00908) · Runze Xu, Xiaolong Shan, Shuang Dai, Yu Wang · arXiv preprint · source: keyword-sweep · 코드 미공개

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- 크로스-어텐션 엔트로피가 예측 구간 연장에 따라 상승함을 발견 — 지속적 고엔트로피 구간을 학습 없이 탐지해 청크 실행을 조기 종료
- 기존 어텐션 가중치 활용 — 추가 파라미터·학습 불필요, 기존 VLA에 플러그인 형태로 적용
- π0.5·X-VLA 결합, RoboTwin 2.0·LIBERO·실제 로봇 3개 과제에서 고정 구간 및 적응형 청킹 베이스라인 대비 성공률 향상

### (c) 시사점

- 공유 제어율 정책에서의 적응적 실행 구간 — 별도 학습 없이 행동 청크 종료 타이밍 자동 결정, 제어율 분리 설계에 보완 가능
- 학습-프리 플러그인 적용성 — body→hand 전환 타이밍 결정 보조 신호로 활용 검토 가능
- 엔트로피 기반 전환 신호 — 명시적 정지 분류 헤드 없이 계층 전환 시점 추론 경로 제시

### (d) 먼저 확인할 점

- 코드 미공개 — 재현 불가, 엔트로피 임계값 설정 방법 미확인
- 단일 조작 암 중심 실험 — body+hand 이기종 분리 설계에서의 동작 미검증
- SparkVLA(2608.16172) 적응형 청킹 선행 연구와의 차별화 — 학습-프리 엔트로피 신호 여부가 주요 분기점

## 🥉 논문 3 — 우선순위 ★★

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- SUN Program 제안 — 기하·접촉 관계를 타입 안전 실행 파일로 컴파일하여 MPC 비용·만족 술어·RL 보상·전환 가드·진단 생성
- Kuafu 시스템 — VLM이 언어·장면으로부터 SUN Program 자동 합성
- 9개 과제에서 매크로 성공률 82.03%(희소 보상 35.67%, Stage-BC 24.75% 대비); 궤적 생성 효율 10.57배 향상; 물리 로봇(Franka+Kinova) 34.7% 달성

### (c) 시사점

- 접촉 조건 형식화 — 전환 가드를 접촉 술어로 정의, body→hand 전환 트리거 설계에 형식 의미론 적용 경로 제시
- 단계 조건부 정책 — 프로그램 단계별 다중 전문가 구조, 계층적 body/hand 분리 설계와 직접 대응
- 타입 안전 접촉 의미론 — 단계 경계 형식 설계를 위한 구체적 구현 사례 확보

### (d) 먼저 확인할 점

- 코드 미공개 — 재현 불가, SUN Program 컴파일러 구현 미확인
- 그리퍼 전용 로봇(Franka·Kinova) — 다지 손가락 관절 명령 전이 가능성 미검증
- 과제 수준 접촉 술어 — 손가락 관절 수준 접촉 신호가 아님; 세밀한 조작 전이 한계 명확
