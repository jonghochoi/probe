## 🥇 논문 1

**DexJoCo-X: Benchmarking Action Representations for Multi-Hand Dexterous Manipulation**
[arXiv:2610.03278](https://arxiv.org/abs/2610.03278) · Xiangwei Jiang, Yao Mu, Lixin Duan 외 1인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 8/15** · R3 · N2 · M2 · Real0 · Repro1 — arXiv comment "Project website: https://darenrenjian.github.io/DexJoCo-X-website/"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 논문 요지

- 7종 손을 같은 조건에서 비교하는 액션 표현 벤치마크
- **문제** — 손 형태와 구동 방식이 달라 손마다 데이터 수집과 정책 학습을 따로 해야 하는 비용
  - 형태별 특수성은 보존하면서 조작 구조는 공유하는 통합 표현이 교차 손 학습의 전제
- **기존 한계** — 서로 다른 표현을 쓴 선행 결과가 손, 데이터셋, 과제 프로토콜이 달라 공통 기준의 우열 판단 불가
  - UniDex와 XL-VLA — 서로 다른 표현으로 다손 학습 가능성을 보고하나 같은 평가 기준에서 비교되지 않음
  - DexArt, Bi-DexHands, DexJoCo, DexVerse — 관절 물체, 양손 제어, 기능 과제, 과제·embodiment 범위를 넓혔으나 동일 조건의 표현 비교는 남김
- **핵심 방법** — DexJoCo 위에 7개 손 인터페이스, 6개 단일 팔·양손 과제, 2,100개 시연, 재사용 가능한 수집 파이프라인 구성
  - π0.5를 Ego-Pi 프로토콜로 미세조정한 손별 다중 과제 정책 7개를 기준선으로 사용
  - 핵심 비교는 Being-H0.5 정책 하나를 7개 손에 공동 학습하고 Native, FAAS(기능 정렬 슬롯), DexLatent 세 표현을 바꿔 평가
- **차별점** — 같은 손, 과제, 시연, 정책 백본, 성공 기준과 공통 실행 인터페이스로 표현만 바꾸는 통제 비교
  - 새 표현을 손 제어 파이프라인 재구성 없이 꽂아 평가할 수 있는 공용 인터페이스 제공
- **핵심 기여** — 벤치마크, 수집 툴킷, 균형 데이터셋과 표현 비교 결과
  - 7개 손과 6개 과제가 평가 장면, 성공 기준, 제어 인터페이스를 공유
  - 글러브-손 매핑을 7개 손 모두에 맞게 재설계한 텔레오퍼레이션과 자동 장면 확장·궤적 검증 툴킷
  - 42개 손-과제 쌍마다 50개 궤적, 총 2,100개 시연의 균형 데이터셋
  - π0.5를 80차원 양손 출력으로 확장하면 성공률 거의 0
  - Ego-Pi는 사전학습 액션 헤드를 보존해 손별 다중 과제 학습을 지원하나 7개 손 공동 학습은 손별 모델보다 크게 낮음
  - Being-H0.5 안에서 FAAS 평균 성공률 47.7%, Native 47.0%, DexLatent 33.1%이며 시뮬레이션 벤치마크 기준
  - FAAS는 양손 과제, Native는 단일 팔 과제에서 우세하고 세 표현 모두 양손 과제에서 낮음
- **가치** — 교차 손 표현의 성패가 액션 좌표만이 아니라 사전학습과 아키텍처를 포함한 전체 학습 시스템에 달렸다는 통제 증거

### (c) 시사점

- 손 출력 공간 선택이 아키텍처와 묶여 평가되는 공개 기준점 확보
- 80차원 양손 단일 출력은 거의 0, 형태 인식 전문가(embodiment-aware experts)를 결합한 구조는 7개 손 단일 정책 성립 — 출력 분할 쪽 근거
- 관절 좌표 그대로의 Native가 기능 정렬 슬롯과 0.7%p 차이 — 손 출력을 관절 명령으로 두는 선택의 비교 기준
- 학습형 잠재 DexLatent가 가장 낮아 잠재 표현 우위가 이 설정에서 재현되지 않음
- 양손 과제 성공률 하락이 공통이라 몸과 손 협응이 남는 병목

### (d) 먼저 확인할 점

- 모든 결과가 시뮬레이션, 실물 검증 없음
- FAAS 47.7%와 Native 47.0%의 차이는 작아 3회 독립 50회 롤아웃 평가의 분산 확인 필요
- 표현 비교가 Being-H0.5 한 아키텍처 안에서만 이뤄져 다른 백본에서도 순위가 유지되는지 미확인
- π0.5 기준선은 손별 정책이라 공동 학습 표현과 직접 비교 불가
- 프로젝트 웹사이트만 있고 코드 공개 확인 안 됨

## 🥈 논문 2

**AgenticTactileVLA: Contact-Guided Execution-Time Supervision for Generalizable Dexterous Manipulation without VLA Retraining**
[arXiv:2610.04391](https://arxiv.org/abs/2610.04391) · Elizaveta Semenyakina, Ivan Snegirev, Mikhail Kiselev 외 4인 · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 9/15** · R2 · N2 · M3 · Real2 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 논문 요지

- 고정 VLA 아래에서 손가락 접촉을 보정하는 실행 감독기
- **문제** — VLA가 접근은 맞게 내도 객체의 기하와 컴플라이언스 차이로 손가락 지지 부족, 부적합한 말단 구성, 연약 객체 과압축 발생
  - 닫힘 중 손이 접촉 부위를 가려 시각 피드백으로는 해결하기 어려움
- **기존 한계** — 촉각 조건 VLA 적응과 실행 모니터링·복구를 선행 연구로 들고 저자들은 둘의 교차에 위치
  - 선행 각각의 결함에 대한 구체 서술은 서론에 없음
  - 객체별 재학습 없이 물리적 실현을 맞추는 방식이 필요하다는 동기만 제시
- **핵심 방법** — VLA는 접근과 손 목표를 내고 상태를 가진 감독기가 닫힘 말단에서 지지 증거를 평가해 개입 여부를 결정
  - 지지가 충분하면 투명하게 통과, 아니면 몸 기준 진행을 멈추고 지지 없는 손가락만 개별 보정
  - 보정이 수락되면 유지, 거절되면 손 오버라이드를 풀고 VLA에 제어를 돌려 재시도
  - 손가락 위치와 모터 부하 피드백을 고유수용 접촉 증거로 사용하며 촉각 센서와 VLA 재학습 불필요
  - 사전 정의한 컴플라이언트 모드와 위치 제어 중 하나를 닫힘 전에 선택, 명시적 취급 단서나 VLM의 이미지·과제 맥락 판단 사용
- **차별점** — VLA의 접근 정책을 대체하거나 잔차 액션 모델을 학습하지 않고, 손가락 굴곡 수정과 몸 기준 진행 게이트만 담당
  - 닫힘을 더 길게 하는 효과와 분리하려고 무조건 close-to-stall 제어를 같은 예산으로 비교
- **핵심 기여** — 감독기 설계, 고유수용 접촉 메커니즘, 실물 평가
  - Unitree G1과 BrainCo Revo2 손에서 VLA 학습에 없던 5개 객체, 무작위 매칭 블록 평가 기준 완료율 기본 VLA 61.3%, 무조건 close-to-stall 72.0%, 감독기 84.0%
  - 모든 객체에서 이득이 양수이고 완만한 자세 교란에서도 유지
  - 선택적 트리거가 완료율 변화 없이 보정 에피소드를 65.7% 감소
  - 수락 판정이 객체 유지를 예측하는 비율 88.9%, 컴플라이언트 객체에서는 보수적 오거절 노출
  - 얇은 벽 컵에서 맥락 기반 컴플라이언트 모드 전환이 항상 컴플라이언트 기준과 일치
- **가치** — 객체별 재학습 없이 고정 VLA의 객체 수준 일반화를 물리 실현 쪽 적응으로 높이는 경로 제시

### (c) 시사점

- 정책이 낸 접근 위에서 손가락 접촉 보정을 별도 층이 맡는 분담 사례
- 힘 센서 없이 손가락 위치와 모터 부하만으로 접촉 증거 확보, 도입 비용 낮음
- 손 쪽 감독기가 몸 기준 진행을 멈추는 구조라 몸에서 손으로 흐르는 조율과 반대 방향의 비교 사례
- 정책 밖 접촉 보정이 완료율을 올린 실물 증거이나 감독기 루프 주기는 초록에서 확인 안 됨

### (d) 먼저 확인할 점

- 동결 VLA 위에 얹는 후처리 성격이라 정책 자체의 분포 한계를 푸는지는 별개
- 서론이 밝힌 적용 범위는 실현 가능한 접근의 보정, 호환되지 않는 접근 오류의 복구는 범위 밖
- 단일 플랫폼과 5개 객체, 컴플라이언트 객체에서 보수적 오거절 확인
- 감독기 실행 주기와 접촉 이벤트 대비 반응 시간 실측 여부는 §V 한계 확인 필요
- 코드와 프로젝트 페이지 신호 없음
