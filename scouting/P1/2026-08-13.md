## 🥇 논문 1 — 우선순위 ★★★

**TEMPO: Semantic-Action Decoupled RL Post-Training for Vision-Language-Action Models**
[arXiv:2608.07314](https://arxiv.org/abs/2608.07314) · Ziheng Liu / Quantao Yang · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- **문제**: SFT는 분포 불일치에 취약; 기존 RL 사후 학습은 의미(semantic) 표현과 저수준 액션 모두 균일하게 갱신 → 빠른 액션 업데이트가 고수준 의미 표현 불안정화
- **구조**: VLM 백본 동결 + 의미론적 프로젝션 레이어(slow loop, 낮은 빈도 갱신) + 액션 전문가(fast loop, 높은 빈도 갱신) 이중 속도 RL 프레임워크 (TEMPO)
- **결과**: CALVIN 벤치마크 + 실제 로봇 두 가지 조작 태스크에서 SFT 및 단일 속도 RL 기준선 모두 능가; 높은 평가 리워드 유지

### (c) 시사점

- **Body/Hand 분리 설계 검증**: 의미(semantic) 레이어와 모터 액션 전문가를 별도 최적화 단위로 취급하면 학습 안정성 향상 → Body/Hand 이중 헤드 각각의 독립 학습 루프 타당성 실증적 근거
- **π0 파인튜닝 전략 보강**: 백본 동결 + 액션 전문가 집중 갱신 패턴D6JW과 방향 일치 → 학습 시 Body 헤드와 Hand 헤드에 서로 다른 갱신 빈도 적용 검토 근거
- **body→hand 흐름 확인**: 의미 프로젝션 → 액션 전문가 단방향 조율D5SH 계층적 흐름 구조와 일치 → 역방향 조율 필요성 낮음

### (d) 먼저 확인할 점

- **손가락 제어 미검증**: 실세계 태스크가 손목 수준 제어 중심 → Hand 헤드(손가락 관절 명령) 수준에서 이중 속도 분리 효과 별도 확인 필요
- **단일 액션 전문가 가정**: TEMPO는 단일 통합 액션 전문가 → Body/Hand 이중 헤드에서 각 헤드에 별도 fast loop 운용 시 설계 조정 필요
- **백본 완전 동결 vs. FT**: D6JW은 "FT both sides" 포함 → 백본 완전 동결 TEMPO 설계와의 성능 차이 및 Body/Hand 분리 시 trade-off 선행 확인

## 🥈 논문 2 — 우선순위 ★★

**World Tokens: Enhancing Embodied Policies with Training-Time World Modeling**
[arXiv:2608.09730](https://arxiv.org/abs/2608.09730) · Qu Tang / Benhui Zhuang / Bo Yuan · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW) [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP)

### (b) 핵심 기여

- **구조**: World Adapter가 VLM 피처 → 고정 크기 world tokens로 압축 변환 → 미래 비디오 디노이저 + 액션 전문가 동시 컨디셔닝 (공유 컨디셔닝 신호)
- **학습-배포 분리**: 학습 시에만 세계 모델(미래 디노이저) 활성화; 배포 시 해당 브랜치 제거 → VLA 수준 추론 지연시간 유지
- **결과**: 2B 백본 + embodied 사전학습 없이 LIBERO 경쟁력 확보; SIMPLER 최고 보고 평균 달성; R1 Pro 실세계 성능 향상 (액션 전용 기준선 대비 유의미)

### (c) 시사점

- **D6JW VLM→액션 전문가 인터페이스 구체화**: VLM 중간 피처 → World Adapter → world tokens → 액션 전문가 경로가 π0 슬라이스 후 액션 전문가 입력 설계를 구체화; World Adapter 역할을 Body/Hand 공유 트렁크 설계에 참조 가능
- **D9ZP 공유 컨디셔닝 구조 유사성**: World tokens가 디노이저+액션 전문가 동시 컨디셔닝 → FiLM 단일 포인트(D9ZP) 대신 고정 토큰 방식으로 Body 헤드·Hand 헤드 동시 컨디셔닝 가능성 시사
- **배포 효율 설계 참조**: 학습-배포 분리로 세계 모델 비용 제로 → Body/Hand 이중 헤드 배포 시 훈련 전용 보조 브랜치 설계에 적용 가능

### (d) 먼저 확인할 점

- **World Adapter 정보 병목**: 고정 크기 world tokens 압축 → Body tokens·Hand tokens 각각을 세분화할 경우 용량 재설계 필요
- **접촉 집약적 태스크 미검증**: LIBERO/SIMPLER는 주로 pick-and-place; 손가락 정밀 조작에서 world tokens 효과 미확인

## 🥉 논문 3 — 우선순위 ★

**Real-World Cooperative Bimanual Dexterous Grasp of Large Objects from Single-View Observations**
[arXiv:2608.10383](https://arxiv.org/abs/2608.10383) · Ziming Li / Mingxuan Wu / Jiaqi Zhang · source: keyword sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- **문제**: 실세계 바이매뉴얼 다지 파지 — 기존 연구는 순차 조작 또는 시뮬레이션 한정; 완전 3D 객체 모델 없이 물리적으로 타당한 파지 생성 어려움
- **방법**: 관절 수준(joint-level) 파지 구성 생성에 DDPM 적용; 세그멘테이션 포인트 클라우드 단일 뷰 입력; 온라인 파지 정제로 물리적 안정성 보장
- **데이터**: 관절 각도 + 시각 관측 + 힘 신호 멀티모달 데이터셋 신규 구축
- **결과**: 이중팔 로봇에서 미지 객체(다양한 형상·포즈) 고성공률; 핵심 구성요소 어블레이션 포함

### (c) 시사점

- **D1QT 실세계 유효성 확보**: 손가락 관절 수준 명령이 실세계 협동 파지에 충분 → D1QT(finger joint command) 선택의 실증적 근거 추가
- **D3GS 비교 기준점**: 암-손 해부학적 분리 없이 단순 관절 명령 DDPM으로도 실세계 파지 성공 → Body/Hand 분리 VLA의 차별적 기여 측정을 위한 real-world 비교 기준선 확보
- **멀티모달 데이터셋 가치**: 관절+시각+힘 동기화 데이터 공개 → Body/Hand 분리 정책 학습 데이터 구성 시 참조 포맷

### (d) 먼저 확인할 점

- **정책 아키텍처 기여 없음**: DDPM 기반 파지 계획 → VLA 수준 일반화 정책 아키텍처와 직접 비교 불가; P1 액션 디코더 설계 시사점은 간접적
- **태스크 범위 한정**: 대형 객체 협동 파지 특화 → 소형·접촉 집약적 정밀 조작으로의 이전 가능성 별도 확인 필요

## 🥉 논문 4 — 우선순위 ★

**LIRA: Local Cross-Layer Information Routing for Vision-Language-Action Decoding**
[arXiv:2608.07596](https://arxiv.org/abs/2608.07596) · Zhewei Zhang / Puyue Wang / Guanren Qiao · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- **문제**: VLM→액션 디코더 인터페이스 — 기존 설계는 좁은 표현 계층 노출 또는 레이어별 고정 1:1 매칭으로 상보적 깊이별 증거 접근 제한
- **방법**: 깊이 인식 로컬 크로스 레이어 라우팅 (LIRA) — 각 Parallel Fusion Block에 대응 VLM 레이어 중심 로컬 윈도우 할당; task-token 피처 + LIRA Query 피처(중간 VLM 상태) 집계 후 고유감각 입력과 결합
- **적용**: 백본 아키텍처·액션 디코더·학습 레시피 변경 없이 플러그인 적용 가능
- **결과**: LIBERO-Plus 제로샷 이전 59.1% → 78.0% (+18.9pp); LIBERO/LIBERO-Plus/CALVIN ABC→D/실세계 전반 개선

### (c) 시사점

- **D9ZP FiLM 단일 포인트 너머**: 단순 단일 레이어 추출보다 인접 깊이 레이어 집계가 제어 피처 품질 향상 → Body 헤드·Hand 헤드에 서로 다른 VLM 깊이 로컬 윈도우 배정 가능성; D9ZP(단일 포인트 FiLM) 개선 후보
- **D6JW 슬라이스 위치 설계**: π0 액션 전문가 슬라이스 깊이 선택에 LIRA의 깊이별 라우팅 효과 근거 활용 가능
- **낮은 통합 비용**: 백본·액션 디코더 구조 불변 플러그인 → Body/Hand 분리 스택에 낮은 비용으로 통합 가능

### (d) 먼저 확인할 점

- **이중 헤드 미검증**: LIRA는 단일 액션 디코더 가정 → Body 헤드·Hand 헤드 각각에 별도 라우팅 적용 시 설계 조정 필요
- **손가락 관절 제어 미검증**: LIBERO/CALVIN은 주로 손목 수준 조작 → 손가락 관절 명령에서 멀티 깊이 라우팅 효과 확인 필요
