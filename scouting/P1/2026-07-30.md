## 🥇 논문 1 — 우선순위 ★★★

**πR²: Reactive Real-time Flow Policies**
[arXiv:2607.26055](https://arxiv.org/abs/2607.26055) · Sungjae Park, Shubham Tulsiani · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- **문제 진단**: 액션-청킹 플로우 정책이 청크 단위 오픈-루프 실행 — 청크 실행 중 새 감각 입력에 반응 불가, 자주 재계획하면 대형 백본+다단계 디노이징 지연으로 현실 폐루프 제어 불적합
- **πR²의 핵심 아이디어 1 — 조건부 채널 이분화**: 고유감각(proprioception)을 매 틱마다 갱신되는 **fast 채널**, 비전-언어 피처를 비동기 갱신되는 **slow 채널**로 분리 — 청크 내에서도 고유감각 변화에 즉각 반응, 스테일 비전 허용
- **πR²의 핵심 아이디어 2 — 잠재 적응형 플로우 스케줄**: 비행 중인 액션을 인페인팅 조건으로 처리, 호출당 단일 디노이징 스텝으로 액션 출력 — 하드웨어 지연 변화에 하나의 학습된 모델이 적응
- **적용 플랫폼**: GR00T-N1.7 기반 파인튜닝, 실제 xArm6+XHand(팔+손 통합) 플랫폼 배포 — 약 25 Hz 재계획 (~40 ms/호출)
- **성과**: 기준선 대비 시뮬레이션 성공률 최대 +23%, 실제 로봇 +30%

### (c) 시사점

- **고유감각 fast 채널의 실증**: 비전-언어를 slow 채널로 분리하면 대형 백본을 유지하면서도 고유감각에 즉각 반응 가능 — 입력 모달리티 분리(D1MZ) 방향의 구체적 구현 사례이자 성능 근거
- **공유 속도(shared rate) 너머의 가능성**: 현재 D1MZ 기본값(shared rate)에서 async rate 방향으로의 확장 타당성 — 실제 팔+손 플랫폼에서 검증된 첫 사례로, D1MZ 결정 재검토의 외부 트리거
- **π 백본 통합 패턴 일반화**: GR00T-N1.7 기반 파인튜닝으로 π0 계열 외에도 대형 사전학습 정책에 동일 패턴 적용 가능함을 시사 — 백본 통합(D6JW) 설계의 이식성 근거 확보

### (d) 먼저 확인할 점

- **코드 미공개**: 프로젝트 페이지(pi-r2-flow.github.io) 존재, 공식 코드 릴리스 미확인 — 재현 비용 존재(Reproducibility=1)
- **slow 채널 갱신 주기**: 비전-언어 피처가 얼마나 stale해도 성능이 유지되는지의 경계 — 동적 물체 조작 등 고속 시각 변화 과제에서 성능 한계 가능성
- **팔+손 분리 미명시**: 팔(xArm6)과 손(XHand) 간의 제어 분리 구조가 논문에 명시되지 않음 — Body/Hand 이질적 디코더와의 통합 설계는 별도 검토 필요

## 🥈 논문 2 — 우선순위 ★★

**DeVA: Decoupled Video-Action Model with physical guidance for robot policy learning**
[arXiv:2607.24159](https://arxiv.org/abs/2607.24159) · Mengqi Zhang, Sahil Khose, Simar Kareer, Yuchen Song, Unnat Jain, Judy Hoffman · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- **문제 제기**: 기존 Video-Action Model — (1) 공유 백본에 비디오+액션 예측을 결합(coupled)하면 정책 적응 최적화 난이도 상승, (2) 비디오 정보 활용을 단일 레이어로 제한하면 물리 사전 지식 손실
- **DeVA 구조**: **전용 비디오 전문가(Video Expert)** + **전용 액션 전문가(Action Expert)** 의 명시적 분리 + 비디오 전문가의 복수 레이어에서 액션 전문가로 **다계층 피처 전이(multi-level feature transfer)**
- **물리 유도 감독(physically salient guidance)**: 어포던스(affordance)·심도(depth) 신호를 중간 비디오 피처 및 액션 스트림에 추가 감독 — 물리 동역학 관련 표현 강화
- **성과**: 시뮬레이션 벤치마크 + 실제 로봇 배포에서 단일화(unified) 아키텍처 대비 빠른 수렴, 제한 데이터에서 성능 향상; 물리 감독 도입으로 추가 성능 이득

### (c) 시사점

- **비디오-액션 분리가 Body-Hand 분리의 비교 참조군**: 입력 모달리티(비디오) 처리와 액션 생성을 별도 전문가로 분리하는 것이 단순 결합 대비 우수 — D3GS 분리 형태(split form)의 유사 사례로 설계 타당성 외부 근거 제공
- **다계층 피처 전이의 이점**: 단일 레이어 특징이 아닌 복수 레이어 피처를 액션 전문가에 주입 — Body↔Hand 간 정보 공유(D9ZP) 구현 방식 비교군으로 활용 가능
- **물리 감독의 실질 효과**: 어포던스·심도를 중간 표현에 주입하면 제한 데이터 환경에서도 수렴 가속 — 소규모 데모 상황에서 Body/Hand 전문가 학습 안정성 힌트

### (d) 먼저 확인할 점

- **코드 미공개**: 공식 릴리스 미확인 (Reproducibility=1)
- **Body/Hand 이질성 미다룸**: 비디오-액션 분리이지 팔-손 이질적 제어 분리는 아님 — P1 직접 적용 시 팔+손 이질 구조와의 매핑 추가 설계 필요
- **어포던스·심도 레이블 의존**: 물리 감독 신호가 별도 레이블 필요 — 실제 데이터 수집 비용 및 레이블 획득 가능성 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Ordered Action Tokens for Visuomotor Policy Learning**
[arXiv:2607.21670](https://arxiv.org/abs/2607.21670) · Chaoqi Liu, Yue Zhao, Haonan Chen, Xiaoshen Han, Jiawei Gao, Ehsan Adeli, Yilun Du · source: citation-graph (π0) + keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- **OAT (Ordered Action Tokenization)**: 연속 액션 청크를 이산 토큰으로 변환하는 학습된 토크나이저 — 세 가지 설계 기준(높은 압축률 / 완전 디코딩 가능성 / 순서 있는 토큰 공간) 동시 충족
- **순서 있는 토큰 공간**: 초기 토큰 = 거친 제어 정보, 후속 토큰 = 잔차 세부 정보 — 어느 토큰 접두사든 유효한 액션 청크로 디코딩 가능, 추론 비용-정확도 anyime 트레이드오프 실현
- **구현**: 트랜스포머 레지스터 + 유한 스칼라 양자화(finite scalar quantization) + 순서 유도 학습 메커니즘
- **범용성 검증**: 자기회귀 정책(token 생성) + 토큰 공동학습 정책(플로우 기반 액션 전문가 컨텍스트 조형) — 3개 백본, 5개 시뮬 벤치마크 + 실제 환경 총 60개 이상 과제

### (c) 시사점

- **Body/Hand 출력 공간 이산화 참조**: 팔·손 액션 청크를 각각 ordered token 형태로 표현하면 Body 토큰(coarse 배치) → Hand 토큰(fine 파지)의 계층적 순서 구조가 자연스럽게 형성될 가능성 — D4QX·D1QT 출력 표현 설계의 대안 탐색 출발점
- **anyime 트레이드오프의 실용적 가치**: 추론 중간에 팔 토큰만 먼저 디코딩하고 손 토큰을 이어서 처리하는 파이프라인 — Body→Hand 순차 실행 구조(D5SH)와 정합
- **광범위 검증 기반**: 60개 이상 과제·복수 백본에서 일관된 성능 — 새로운 액션 표현이 특정 아키텍처에 편향되지 않음을 시사

### (d) 먼저 확인할 점

- **코드 미공개**: 현재 공식 릴리스 미확인; Yilun Du 그룹 과거 공개 이력 있음 (Reproducibility=1)
- **연속 vs 이산 트레이드오프**: 이산 토큰화는 양자화 오차를 수반 — 접촉 집약적 손가락 제어에서 정밀 finger joint command와의 정확도 비교 필요
- **팔-손 혼합 토큰 미검토**: 현재 논문은 단일 액션 청크 기준 — 팔과 손의 이질적 토큰 시퀀스를 하나의 OAT 공간에서 처리할 때 순서 구조가 유지되는지 별도 확인 필요
