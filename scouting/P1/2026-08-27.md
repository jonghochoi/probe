## 🥉 논문 3 — 우선순위 ★★

**SparkVLA: Stop-Aware Hierarchical VLA with Adaptive Action Chunking for Long-Horizon Manipulation**
[arXiv:2608.16172](https://arxiv.org/abs/2608.16172) · Xunyao Lei, Renjun Wu, Tianlin Huo, Xuesong Li · arXiv preprint · source: citation-graph (π0) · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- 계층적 VLA에서 정지(stop) 신호와 청크 길이를 공동 최적화하는 Stop-Aware Hierarchical 설계 제안
- 적응적 action chunking으로 과제 단계별 제어 속도 자동 조정
- LIBERO-Long 기준 47.12% 성공률; 공식 계층 베이스라인 대비 +30.57%, 최강 재현 가능 방법 대비 +26.83%; 실제 로봇 멀티-스텝 과제 검증

### (c) 시사점

- 계층 분리 + 적응적 제어 속도 공동 최적화 — body/hand 계층 설계의 제어 속도 분리 정책 수립에 실증적 근거 제공
- 정지 조건 공동 최적화 — 장기 조작에서 body expert 전이 타이밍 결정 문제에 직접 시사
- 실제 로봇 멀티-스텝 과제 검증 — 계층 VLA Sim2Real 적용 가능성 확인

### (d) 먼저 확인할 점

- 코드·학습 코드 미공개 — LIBERO 이외 환경 재현 불가
- 단일 조작 암(single-arm) 실험 — body+hand 이기종 분리로의 직접 전이 가능성 미확인
- 정지 신호 별도 분류 헤드 — 계층 body/hand 설계 통합 시 추가 헤드 복잡도 발생
