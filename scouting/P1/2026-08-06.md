## 🥇 논문 1 — 우선순위 ★★★

**How Should Vision-Language-Action Models Use Proprioceptive State?**
[arXiv:2608.03052](https://arxiv.org/abs/2608.03052) · et al. · source: π0 citation graph

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **연구 문제** — 고유감각(proprioceptive) 상태를 VLA에 주입하는 위치·방법이 표준 없이 혼재; 텍스트 직렬화·VLM 프리픽스·액션 전문가 직접 입력 등 방식이 불일치
- **5가지 주입 인터페이스** — discrete state prompt / VLM prefix / action prefix / state expert / feature modulation(FiLM 류)을 동일 백본·데이터·액션 표현·평가 프로토콜 하에 통제 비교
- **65태스크 체계적 평가** — 세 가지 태스크 패밀리 45개 원자 태스크 + 20개 복합 태스크에서 각 인터페이스 성능 측정
- **상태 이력 스윕** — 1–96 프레임 이력 길이 전범위 탐색; 이력 편익이 진정한 시간적 변화인지 단순 conditioning capacity 증가인지 구분
- **3가지 실증 질문 답변** — ① 상태 정보가 폐루프 제어에 유익한 태스크 범위 ② 최적 이력 길이 및 메커니즘 ③ 백본 vs. 액션 생성 모듈 중 주입 위치 → 설계 원칙으로 귀결

### (c) 시사점

- **D5 직접 근거** — "어느 모달리티 경로에 상태를 넣는가"는 D5(입력 모달리티 분리)의 핵심 선택; 5가지 인터페이스 결과가 Body/Hand 각 헤드별 고유감각 주입 경로 설계에 직접 활용 가능
- **feature modulation 우위 확인 시 D4 보강** — FiLM 류 인터페이스가 타 방식보다 우위를 보이면, D4(FiLM으로 Body $a_b$ → Hand 헤드 조절)와의 설계 일관성이 강화됨
- **이력 길이 분리 가능성** — 96 프레임 스윕 결과는 Body 매크로 모션과 Hand 접촉 제어 각각에 최적 이력 길이가 다를 수 있다는 가설 검증의 기반

### (d) 먼저 확인할 점

- **벤치마크 범위 미명시** — 65태스크가 시뮬레이션(LIBERO 류) 위주인지 실 로봇 포함인지 초록에서 불명확; Sim2Real 전이 검증 별도 필요
- **코드 미공개** — 2026-08-04 게시 기준 공개 저장소 없음; 재현 전 릴리즈 확인
- **단일 출력 스트림 가정** — 단일 VLA 출력 스트림 대상 연구; 이질적 Body·Hand 헤드 각각에 다른 주입 인터페이스를 조합하는 효과는 미탐구

## 🥈 논문 2 — 우선순위 ★★

**Faster-WAM: Do World Action Models Need Deep Action Modules?**
[arXiv:2608.02365](https://arxiv.org/abs/2608.02365) · et al. · source: π0 citation graph

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **핵심 질문** — World Action Model(WAM)에서 액션 모듈 깊이를 비디오 백본 깊이와 비례시켜야 하는가? 기존 공유 백본·Mixture-of-Transformers 설계의 과도한 연산 비용 문제 제기
- **DoT(Dock of Transformer) 원칙** — 사전학습된 비디오 Transformer를 표현 허브로 두고, 경량 출력 헤드를 도킹 인터페이스로 연결; 전체 레이어 표현에 직접 접근 가능
- **Faster-WAM 구현** — 30레이어 비디오 백본 + 단층 액션 헤드 조합; RoPE 재정렬 + 전 레이어 KV 융합으로 백본 표현 활용
- **속도·성능 균형** — LIBERO·RoboTwin 2.0 경쟁 성능 + LIBERO-Plus OOD 강인성 + 추론 지연 66.5 ms (Fast-WAM 대비 $3.2\times$ 가속)

### (c) 시사점

- **D1 설계 가이드** — 단층 액션 헤드가 30층 백본과 결합해 경쟁 성능 달성 → Body/Hand 헤드 각각의 깊이를 최소화해도 충분할 가능성; hybrid split(v1) 구현 시 헤드 복잡도 하한선 참고
- **D7 구현 레퍼런스** — DoT "도킹 인터페이스"는 π0 액션 전문가를 비디오 백본에 연결하는 방식과 개념적으로 일치; D7(π0 액션 전문가 분할 + 양측 파인튜닝) 구현 복잡도 낮출 힌트
- **지연 기준점 확보** — 66.5 ms/inference; 분리 아키텍처(Body+Hand 헤드 추가)의 지연 허용 타깃 설정 기준

### (d) 먼저 확인할 점

- **실 로봇 결과 없음** — LIBERO·RoboTwin 2.0 전 결과 시뮬레이션 벤치마크; Sim2Real 갭 미검증
- **비디오 WAM 특화** — 비디오 백본 없는 π0 기반 구조와 직접 비교 시 도킹 방식 차이 존재; D7 π0 파티션 범위 별도 조정 필요
- **코드 미공개** — 2026-08-03 게시; DoT 재현 전 릴리즈 확인

## 🥉 논문 3 — 우선순위 ★

**Why Does Action Chunking Improve Behavioral Cloning Performance in Robotic Control?**
[arXiv:2608.02547](https://arxiv.org/abs/2608.02547) · et al. · source: π0 citation graph + keyword sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **기존 3가설 전면 반증** — 액션 청킹이 성능을 높이는 이유로 제시된 세 가설 — 시간적 일관성, 지평선 축소, 표현 학습 — 모두 시뮬레이션·실 로봇 실험에서 설명 실패 확인
- **새 메커니즘 규명** — 통제된 실험으로 실제 원인 추적; 구체 발견은 본문 확인 필요
- **이중 검증** — 시뮬레이션과 실 로봇 환경 양쪽에서 리고러스 실험; Sim2Real 유효성 확보

### (c) 시사점

- **D5 청크 크기 설계 근거** — Body/Hand 공유 제어율(α: shared rate) 아래 청킹 크기 N 선택 시, 청킹 이득의 실제 원인이 명확해지면 Body(매크로 모션)·Hand(접촉 제어) 각각에 최적 청크 크기가 다를 가능성 평가 가능
- **분리 제어율 논거 마련** — 반증된 가설 중 "지평선 축소" 실패 결과는 D5의 shared rate(α) 선택 근거에 영향; 대안 메커니즘에 따라 Body·Hand 분리 청킹 실험 가치 재검토 가능

### (d) 먼저 확인할 점

- **구체 원인 초록 미공개** — 발견 내용 전체가 본문에 있음; 전문 확보 후 D5 연관성 최종 판단 필요
- **코드 미공개** — 2026-08-03 게시; 방법론 재현 전 릴리즈 대기
- **단일 액션 스트림 가정** — Body·Hand 분리 스트림에서 이질적 청크 크기 조합 효과는 미탐구

### (c) 시사점

- **D1 해부학적 분리 외부 근거** — HRI 원격조작 커뮤니티가 동일 이질 채널 분리에 독립적으로 도달; Body/Hand 분리가 VLA 아키텍처만의 주장이 아님을 뒷받침
- **데이터 파이프라인 호환** — Teleopit 방식으로 수집된 전신 데이터는 Body·Hand 채널이 이미 분리되어 있어 P1 이질 헤드 학습에 최적화된 형태로 활용 가능

### (d) 먼저 확인할 점

- **학습 정책 미포함** — 시스템 논문; 수집 데모로 VLA 학습 결과 미제시

- **휴머노이드 특화** — 탁상 로봇팔+손 플랫폼으로 이전 시 Body·Hand 매핑 방식 별도 조정 필요
