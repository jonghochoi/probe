**HiFun: a Hierarchical Framework for Efficient Functional Dexterous Manipulation Learning**

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 논문 요지

- 손 스킬과 팔 협응 정책으로 나눈 실물 RL
- **문제** — 다지 손으로 기능적 조작을 실물에서 학습하는 일
  - 정밀 접촉, 팔-손 협응, 실행 오류에서의 반응형 복구가 한꺼번에 필요
  - 슬립이나 이른 힘 인가 같은 작은 편차가 접촉 실패로 이어짐
- **기존 한계** — 세 학습 경로가 각각 부분만 해결
  - 시뮬레이션 학습 — 기능적 조작의 복잡한 접촉 동역학 때문에 Sim2Real(시뮬레이션-실환경 이전)이 어려움
  - 모방 학습(IL) — 팔 동작, 다지 접촉, 접촉 타이밍을 한 번에 시연해야 해 수집이 비싸고 잡음이 크며, 성공 사례 위주라 복구 근거가 빈약
  - 실물 강화학습(RL) — 팔-손 전체 행동 공간에서 직접 탐색하고 사람이 교정하는 방식은 복구 학습에 비효율
- **핵심 방법** — 제어 복잡도를 기능적 손 스킬과 팔-손 협응 정책으로 분리한 계층형 실물 RL
  - 손 스킬 — 키네스테틱 손 동작 사전지식에 잔차 RL(residual RL)과 실제 접촉 피드백을 더해 정밀 접촉 실행을 담당
  - 협응 정책 — 손 스킬을 고정된 액션 프리미티브로 두고 팔 동작과 스킬 활성화만 학습, DMP(Dynamic Movement Primitive) 증강 롤아웃으로 초기 커버리지 확보
  - 온라인 미세조정 — 사람 교정을 손 스킬 인터페이스로 입력, 멀티헤드 크리틱으로 팔 정렬과 스킬 활성화의 시간 협응을 학습하고 개입 어드밴티지 가중(IAW)으로 유용한 교정에 비중
- **차별점** — 접촉 실행을 고정된 손 스킬로 묶어 협응 정책이 팔과 스킬 활성화 시점만 다룸
  - 비교 대상 HIL-SERL은 팔-손 전 자유도를 직접 출력하는 평평한(flat) 정책
  - 저자들은 개입 품질과 탐색 효율 두 곳에서 이득이 난다고 설명
- **핵심 기여** — 계층 분리 프레임워크, 잔차 RL 손 스킬, 스킬 조건 협응 정책
  - 실물 6개 과제와 손 2종(Franka Research 3 팔에 Sharpa 손과 XHand) 평균 성공률 98.3%, RL 데이터 수집 18.8분과 온라인 학습 46.2분
  - 베이스라인 — HIL-SERL 변형은 같은 개입 인터페이스를 써도 평균 13.7%, 모방 학습은 시연 200개로도 BC가 전력 드릴 작동 15%와 피펫 12%, DP가 비트 제거 36%와 피펫 26%
  - 교란 시험 과제당 20회 — 6개 중 4개 과제 20/20, 전력 드릴 작동과 피펫 분주 18/20
  - 어블레이션 — DMP 롤아웃은 사람 시연과 같은 100% 성공률에 수집 시간 약 4배 절감, 멀티헤드 크리틱 제거 시 100%에서 85%와 75%로 하락, IAW를 균등 가중으로 바꾸면 60%이고 개입 모방을 빼면 40%
  - 손 스킬 단독 — 20회 시험 전 과제 20/20, 키네스테틱 재생은 비트 제거 5/20이고 나머지 과제 실패
  - 조작자 3명 사이 최종 성공률 차이 약 2–3%p
- **가치** — 실물 RL을 전 자유도 공간에서 풀지 않고 접촉 실행과 협응으로 나누면 한 시간 안팎의 온라인 학습이 가능하다는 근거

### (c) 시사점

- 팔 정책 위에 손 스킬을 얹는 분할이 평평한 정책보다 유리
- **분할 근거** — 같은 개입 인터페이스를 쓴 평평한 정책 13.7%와 계층형 98.3%의 직접 대조라, 분할이 탐색 효율에서 이득을 주는지 가늠하는 실물 측정
  - 손 스킬만 공유한 Skill-HIL 대조에서도 성능이 회복되지 않아 이득이 스킬 재사용만으로 설명되지 않음
- **조정 방향** — 협응 정책이 손 스킬 활성화 시점을 정하는 몸통→손 위계 흐름의 실물 사례
  - 멀티헤드 크리틱 제거 시 활성화 오차가 2.00cm에서 4.58cm(95번째 백분위)로 커져 활성화 타이밍이 핵심 부담임을 확인
- **도입 비용** — 사람 교정을 손 스킬 인터페이스로 받아 텔레오퍼레이션 잡음을 줄이는 구성이라 실물 RL 설정에 옮길 때 참고 가치

### (d) 먼저 확인할 점

- **코드 미공개** — 초록, arXiv comment, 본문 어디에도 저장소나 공개 약속 없음, 프로젝트 페이지만 제공
- **스킬 집합 한정** — 저자가 학습된 손 스킬 범위를 벗어나는 접촉 거동이 필요한 과제는 실패할 수 있다고 명시
- **정책 구조 차이** — 공유 트렁크 위 분할 헤드가 아니라 고정된 스킬과 별도 협응 정책의 이단 구조라 아키텍처 비교로는 직접 대응되지 않음

- **조작자 범위** — 사람 개입이 학습의 일부인데 조작자 3명 사이 차이만 보고, 그 밖의 조작자에서의 재현은 미확인

[arXiv:2610.26584](https://arxiv.org/abs/2610.26584) · Langzhe Gu, Chengkai Hou, Meng Li 외 12인 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH) [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 논문 요지

- 휴머노이드 액션을 단계별로 디노이징하는 VLA
- **문제** — 사전학습 VLA를 휴머노이드 전신 이동 조작(loco-manipulation)에 적응시키는 일
  - 보행, 자세, 시선, 양팔 조작을 고차원 전신 행동 공간에서 함께 조율해야 함
  - 기저나 허리 동작이 부정확하면 상체가 공격적으로 보상 동작을 하며 정밀도와 안정성이 저하
- **기존 한계** — 기존 VLA와 월드 액션 모델은 고정형, 양팔, 바퀴형 매니퓰레이터에서 성과를 냈으나 휴머노이드의 구조화된 액션 공간과 불안정한 이족 동역학을 고려해 설계되지 않음
  - 단일 단계 액션 생성기를 그대로 쓰면 보행, 자세, 조작이 비구조적으로 얽혀 불안정한 기저 동작이나 상체 보상 동작이 발생
- **핵심 방법** — 사전학습 플로우 매칭(flow matching) VLA 위에 단계별 액션 플로우와 단계 간 KV 캐시 조건화를 얹음
  - 비전-언어 접두 인코더와 액션 전문가 가중치를 물려받고 학습형 단계 임베딩 추가
  - 한 번에 전체 청크를 만들지 않고 보행·머리 명령, 허리 정련, 전신 조작 순으로 공유 전신 행동 공간을 점진적으로 디노이징
  - 마지막이 아닌 단계가 끝나면 깨끗한 액션 예측을 공유 액션 전문가로 다시 인코딩해 액션 KV 캐시를 만들고 다음 단계를 조건화
- **차별점** — 몸 부위별 단계 순서와 앞 단계 출력을 뒷 단계가 수정할 수 있는 연성 정련
  - 앞 단계 액션 차원을 고정하는 Hard-Freeze 66.7%, 단계 출력을 이어 붙이는 Stage-Concat 46.7%로 제안 방식에 못 미침
  - 모든 단계에서 전체 행동 공간을 쓰는 All-Joint는 73.3%
- **핵심 기여** — 계층형 액션 플로우 정식화, 단계 간 KV 캐시 조건화, 실물 검증
  - 휴머노이드 Tian Gong 3.0과 2.0, 실물 6개 과제에서 정규화 점수 평균 π0.5 53.3%를 68.3%로 +15.0%p, 6개 과제 모두 최고 또는 공동 최고
  - 베이스라인 4종 — π0.5, ACT, GR00T N1.7, Cosmos Policy
  - Box Carry 어블레이션(시연 120개) — 보행→허리→팔 순서 86.7%, 허리 우선 70.0%, 팔 우선 60.0%, 캐시 없는 학습 50.0%
  - 총 디노이징 횟수를 30단계로 맞춘 단일 단계 π0.5는 30.0%로 86.7%에 못 미침
  - 분포 이동 5종 모두 π0.5보다 높은 점수, 타깃 테이블 30cm 이동 시 73.3% 대 40.0%
- **가치** — 휴머노이드 전신 행동에서 몸 부위 순서를 따른 생성 구조가 사전학습 VLA의 적응 경로가 될 수 있다는 근거

### (c) 시사점

- 몸 부위별 단계 순서와 앞 단계 조건화가 단일 패스 생성보다 유리
- **흐름 방향 근거** — 순서를 바꾼 대조(허리 우선, 팔 우선)와 연성 정련 대 동결·이어 붙이기 대조가 한 논문 안에 있어, 앞 단계가 뒷 단계를 조건화하는 위계 흐름을 직접 가늠할 수 있음
- **조정 매체** — 단계 간 정보를 KV 캐시로 전달하는 구성이라 몸통 출력이 손 출력을 어떻게 조건화할지 비교할 때 참고
  - 앞 단계 출력이 뒷 단계에서 수정되는 연성 정련이 완전 동결보다 낫다는 점이 핵심
- **분할 유형** — 보행·허리·팔과 손을 하나의 공유 행동 공간에서 단계별로 푸는 방식이라 별도 전문가가 아닌 공유 트렁크 내 순차 생성의 사례
- **지연 비용** — 단계 수만큼 디노이징이 늘어 추론 시간 0.123초로 π0.5 10단계 0.075초보다 증가

[arXiv:2610.14854](https://arxiv.org/abs/2610.14854) · Zan Huang, Yibo Qiu, Kan Ding 외 4인 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 접촉 단계에만 힘 전문가를 두는 이중 전문가 VLA
- **문제** — 접촉 집약적 조작에서 단계마다 필요한 감각이 달라지는 충돌
  - 접근과 정렬에서는 비전과 고유수용감각이 핵심이고 힘은 정보가 적어 방해가 될 수 있음
  - 접촉 뒤에는 힘이 핵심이 되지만 무관한 시각 세부와 시연 진행과 상관된 로봇 상태가 지름길이 됨
- **기존 한계** — 힘 활용 연구가 두 갈래로 나뉘어 따로 다뤄짐
  - 힘을 언제 넣을지 — FoAR는 예측한 미래 접촉으로 힘 융합을 조절, Reactive Diffusion Policy는 빠른 촉각·힘 조건 루프를 도입
  - 힘을 어떻게 쓸지 — ForceVLA는 단계 인지 융합, FACTR와 CRAFT는 정책이 물리 피드백을 무시하는 경향을 다룸
  - 단계 인지 융합은 힘이 들어오는 시점만, 힘 주목 방식은 모달리티 의존만 바꿀 뿐 힘 특화 최적화를 전용 전문가나 접촉 단계 데이터로 국한하지 않음
- **핵심 방법** — 과제 적응된 기반 전문가를 유지하고 접촉 단계 데이터로만 힘 인지 접촉 전문가를 추가 학습
  - 공유 비전-언어 백본과 기반 전문가는 동결, 접촉 전문가는 기반 전문가에서 초기화
  - 실행 중에는 가벼운 단계 인지 라우터가 활성 전문가를 선택
  - 접촉 국소화 힘 주목 커리큘럼 — 시각 억제와 상태 토큰 마스킹을 점진적으로 풀며 접촉 전문가에만 적용
- **차별점** — 힘 특화를 접촉 단계의 별도 전문가로 국한하고 기반 전문가는 건드리지 않음
  - 한 전문가 전체에 힘 토큰이나 커리큘럼을 전 과제 사후학습으로 적용한 대조군이 직접 비교 대상
  - 이 전역 적용은 비접촉 성공률을 떨어뜨림(조작 비정렬과 시각 파지 실패 증가)
- **핵심 기여** — 이중 전문가 구조, 접촉 국소화 커리큘럼, 실물 검증
  - 실물 3개 과제(피펫 팁 부착, 양팔 피펫 흡입, 화이트보드 지우기)에서 방법당 20회 시행, 전체 성공률 70%, 50%, 90%로 각 과제 최고 대안 대비 +40, +20, +20%p
  - 접촉 단계 성공률(앞 단계 성공 조건) 14/15, 10/20, 18/20
  - 힘 토큰만 추가한 단일 전문가는 팁 부착과 지우기에서 기본 π0.5보다 전체 성공률이 낮아짐
  - 기본 π0.5의 비접촉 단계 성공률은 90%, 95%, 100%이며 저자는 이 수준이 유지된다고 주장
  - 피펫 잡는 높이를 시연에 없던 값으로 바꾼 일반화 시험에서 두 피펫 과제 모두 50%
  - 상태 토큰 마스킹 어블레이션 — 접촉 국소화 커리큘럼을 뺀 변형은 팁 부착 20%
- **가치** — 감각 적응을 해당 피드백이 정보가 되는 단계로 국한하면 기존 과제 성능을 잃지 않고 힘을 쓸 수 있다는 근거

### (c) 시사점

- 접촉 단계 전용 전문가가 전역 적응보다 유리
- **전문가 분리 근거** — 단일 전문가에 힘을 전역으로 먹인 대조군이 비접촉 성공률을 35%와 50%까지 떨어뜨려, 힘 입력을 접촉 전문가에만 연결하는 분리의 값어치를 보여 주는 실물 측정
- **분할 유형** — 몸통과 손이 아니라 비접촉과 접촉의 시간 단계로 나눈 전문가라 다른 이음새에서의 이득과 비용을 가늠하는 증거
  - 기반 전문가 동결과 접촉 전문가 초기화 방식이라 π 계열 백본에서 전문가를 떼어 내는 방법에도 참고
- **도입 비용** — 사후학습 단계에서 전문가 하나만 추가하는 구조라 도입 비용 낮음

### (d) 먼저 확인할 점

- **코드 미공개** — 초록, arXiv comment, 본문 어디에도 저장소나 공개 약속 없음
- **그리퍼 기반** — Mercury B2 양팔과 손목 힘/토크 센서 구성이라 다지 손의 손가락별 접촉으로는 검증되지 않음
- **과제 범위** — 저자가 세 과제군 평가로 한정된다고 명시, 시행 20회 규모
- **수동 전환** — 화이트보드 지우기는 전문가 전환을 수동으로 수행, 자동 라우팅은 향후 과제
- **절대 성공률** — 양팔 피펫 흡입 50%, 시연에 없던 파지 높이 50%로 접촉 단계 병목이 남아 있음
