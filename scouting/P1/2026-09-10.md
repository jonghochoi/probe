## 🥇 논문 1 — 우선순위 ★★★

**TacPAC: Tactile Prediction for Real-Time Action Correction**
[arXiv:2609.05266](https://arxiv.org/abs/2609.05266) · 저자 미확인 · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 핵심 기여

- 촉각 신호(tactile signal)를 캐시(cache) 기반으로 실시간 예측해 행동 수정(action correction)으로 연결하는 TacPAC 프레임워크 제시
- 별도 고속 루프 없이 정책 루프(policy loop) 내부에서 촉각 피드백을 처리하는 최초 수준의 접근
- 실제 로봇 5개 태스크에서 22% → 64% 성공률 도약 — 강건한 실물 검증 완비
- 코드 공개(GitHub: LogosRoboticsGroup/TacPAC)로 재현성 보장

### (c) 시사점

- 정책 루프 내부에서 촉각을 처리하는 방식이 별도 접촉 루프 없이도 접촉 반응 가능함을 실증
- 캐시 예측 메커니즘이 속도 분리 논의에 실질적 대안 제시 — 25 Hz 이하에서도 빠른 접촉 대응 가능성 확인
- 손 전문가(hand expert) 입력 모달리티 분리 여부 설계 선택에 실증 데이터 제공

### (d) 먼저 확인할 점

- 촉각 센서 하드웨어 의존성 — 일반 로봇 핸드로의 전이 가능 여부 미확인
- 5개 태스크가 유사한 접촉 레짐만 포괄하는지, 다양한 slip 속도 조건을 포함하는지 확인 필요
- 캐시 예측의 지연 허용 한계(latency tolerance)가 실제 slip 발생 속도 대비 충분한지 미검증

## 🥈 논문 2 — 우선순위 ★★

**Dex-X: Dexterous Manipulation via Simulation as Tactile Completion**
[arXiv:2609.07747](https://arxiv.org/abs/2609.07747) · Ruoqu Chen, Feixiang Ruan, Liu Cao, Zihao Wang · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- 시뮬레이션을 촉각 완성(tactile completion) 엔진으로 활용하는 신규 패러다임 제안
- 손-팔 통합 플랫폼(hand-arm platform)에서 제로샷 sim-to-real 전이 달성
- 실제 로봇 큐브 피킹 태스크 93% 성공률 — 다관절 손 제어에서 이례적 수준
- 프로젝트 페이지(https://dexx-code.github.io/dexx-code/) 공개, 코드 출시 예정

### (c) 시사점

- 시뮬레이션 기반 촉각 보완이 손 전문가 출력 공간(finger joint command) 학습 비용을 낮출 수 있음을 시사
- 제로샷 전이 성공은 도메인 갭 없이 손가락 관절 명령 정책을 훈련할 수 있음을 시사
- 실제 로봇 데이터 수집 없이 손 전문가 부분을 독립 학습 가능한 경로 제시

### (d) 먼저 확인할 점

- 큐브 피킹 외 다양한 접촉-풍부 태스크로의 확장성 미검증
- 시뮬레이터 촉각 신호의 충실도 — 실제 센서 대비 정밀도 수준 확인 필요
- 코드 미공개 상태 — 재현 실험 전까지 재현성 신뢰도 제한

## 🥉 논문 3 — 우선순위 ★★

**CC-VLA: Compliance-Controlled VLA with Adaptive Force Feedback** [제목 약칭]
[arXiv:2609.05832](https://arxiv.org/abs/2609.05832) · 저자 미확인 · IEEE RA-L (accepted) · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 핵심 기여

- 힘(force) + 비전-언어를 결합한 MoE(Mixture of Experts) 행동 전문가 구조 제안
- 적응형 컴플라이언스 컨트롤러(adaptive compliance controller)를 정책 출력 인터페이스에 통합
- IEEE RA-L 게재 승인 — 실제 로봇 광범위 실험 포함한 심사 완료 수준의 완성도
- 힘 피드백 기반 접촉 제어를 VLA 프레임워크 안에서 직접 처리하는 통합 접근

### (c) 시사점

- MoE 행동 전문가 + 힘 피드백 통합이 접촉 루프 분리 없이 고품질 접촉 제어 가능함을 시사
- 컴플라이언스 컨트롤러를 정책 출력단에 결합하는 패턴 — 손/팔 분리 설계에 이식 가능한 구조
- RA-L 심사를 통과한 실험 규모가 접촉 루프 존재 여부 논의에 실질 데이터 제공

### (d) 먼저 확인할 점

- 코드 미공개 — 재현 실험 불가 상태
- MoE 전문가 수 및 라우팅 전략의 논문 내 공개 상세 수준 확인 필요
- 힘 센서 하드웨어 의존성 — 센서 미장착 플랫폼에서 이식성 제한 가능성

**CAT: Continuous Action Trajectory Representation for Policy Learning**
[arXiv:2608.24111](https://arxiv.org/abs/2608.24111) · Tong Yang, Jingkai Jia, Yuecheng Xu, Xueyao Chen, Chi Zhang, Wenqiang Zhang · arXiv preprint · source: 🔍 승격 (직전 리포트 근접 후보) · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX)

### (b) 핵심 기여

- 궤적 수준(trajectory-level) 연속 행동 표현(continuous action representation) 학습 프레임워크 제안
- 청크(chunk) 기반 행동 대신 궤적 연속체(continuum)로 제어 입력을 재정의하는 접근
- LIBERO, MimicGen, 실제 로봇 장기 조작(long-horizon manipulation) 태스크에서 검증

### (c) 시사점

- 연속 궤적 표현이 청크 행동 대비 장기 태스크에서 유리한 경우 존재 — 제어 주파수 분리 논의에 추가 관점 제공
- Body 출력 공간 선택(팔 목표점 표현 방식)과 궤적 연속성 가정의 상호작용 확인 필요
- LIBERO + MimicGen + 실제 로봇 다중 벤치마크가 비교 기준선 확보에 활용 가능

### (d) 먼저 확인할 점

- 코드 미공개 — 재현 불가
- 연속 표현 학습이 고자유도 손 관절 명령 공간에서도 동일 이점을 유지하는지 미확인
- 실제 로봇 실험 세부 프로토콜(태스크 종류, 반복 횟수) 논문 내 상세 확인 필요

## 🌱 논문 5 — 인접 분야 픽 (월 1회)

**Memory Anchors for Continual Robot Learning**
[arXiv:2608.26545](https://arxiv.org/abs/2608.26545) · Maximilian Du, Zhanyi Sun, Chen Xu, Paarth Shah, Masha Itkina, Shuran Song · adjacent field: continual learning / catastrophic forgetting · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1)

### (b) 핵심 기여

- 연속 로봇 학습(continual robot learning)에서 충돌 영역(conflict-region) 기반 메모리 앵커(Memory Anchors) 제안
- 새 기술 학습 시 이전 기술의 파국적 망각(catastrophic forgetting)을 4.5배 감소
- 실제 로봇 2-태스크 시퀀스 데모로 망각 감소 효과 검증
- 프로젝트 페이지(https://robot-adaptation.github.io/MemoryAnchors) 공개, 코드 출시 예정

### (c) 시사점

- 손/팔 분리 전문가 구조를 순차 파인튜닝(fine-tuning)할 경우, 기학습 전문가의 망각 방지 전략 사전 설계 필요
- 충돌 영역 기반 메모리 앵커 방식이 PEFT 기반 적응에 직교적으로 결합 가능
- 장기 배포 환경에서 새 태스크 추가 시 재학습 비용 절감 경로 제시

### (d) 먼저 확인할 점

- 2-태스크 시퀀스만 검증 — 더 긴 시퀀스에서의 확장성 미확인
- 충돌 영역 식별이 고자유도 정책 네트워크(backbone + 분리 헤드)에서 계산 가능한지 미검증
- 코드 미공개 상태
