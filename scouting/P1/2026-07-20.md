## 🥇 논문 1 — 우선순위 ★★★

**DexPIE: Stable Dexterous Policy Improvement from Real-World Experience**
[arXiv:2606.09615](https://arxiv.org/abs/2606.09615) · (저자 미명시, 프로젝트 페이지: siiuuuuuu.github.io/DexPIE) · source: citation-graph (DexGrasp-VLA)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **문제 진단**: 다지 조작 모방 학습의 2가지 구조적 장벽 — 고차원 액션 공간에서의 복합 오차 누적, 실기 배포 후 충분한 커버리지 확보 불가
- **DexPIE 포스트-트레이닝 프레임워크**: DAgger 스타일 실기 배포를 통한 경험 수집 + 비동기 추론(asynchronous inference) 기반 상대 액션 공간(relative action space)으로 전환 — 모방 시연과 실기 롤아웃 간 시간 노이즈 정렬
- **연속 최적성 지표(optimality indicator) 조건화**: 데이터 품질을 세분화된 스칼라로 정책에 피딩 — 데모·롤아웃 혼합 데이터의 품질 이질성 흡수
- **다중 단계 DAgger 커버리지**: 초기 단계와 중간 단계별 인터벤션 시스템으로 다지 손 다음 상태 탐색 범위 확대
- **성과**: 실제 로봇 다지 조작 3개 과제에서 모방 기반 기준 정책 대비 **37% 성공률 향상**, 전 비교 기준선 초과; 코드·데이터 공개 예정

### (c) 시사점

- **상대 액션 공간의 정렬 효과**: 절대 관절 명령 대신 상대적 변화량(relative)으로 다지 손 출력을 표현하면 모방 데이터와 롤아웃 분포 간 시간 불일치가 완화 — 손 관절 명령 설계 시 표현 공간 선택이 포스트-트레이닝 호환성에 직접 영향
- **실기 피드백 루프**: 고정 모방 데이터 없이 실기 경험만으로 다지 정책 개선 가능 — 시연 수집 비용 없이 Hand Expert 정책을 점진적으로 보완하는 실용적 경로
- **DAgger + 품질 조건화**: 최적성 지표 조건화로 좋은 롤아웃과 나쁜 롤아웃을 분리 학습 — 탐색 중 접촉 파괴 문제를 신호 기반으로 완화하는 방식 참조 가능

### (d) 먼저 확인할 점

- **플랫폼 미명시**: 구체적 다지 손 하드웨어·embodiment 불명시 — 타 플랫폼 이전성 논문 본문 확인 필요
- **코드·데이터 공개 미완료**: 프로젝트 페이지 존재, 실제 릴리스 시점 미확인 — 공개 전 재현 불가
- **팔(arm) 통합 언급 부재**: 다지 손 조작 중심, 팔+손 통합 포스트-트레이닝 설계는 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**UniDexTok: A Unified Dexterous Hand Tokenizer from Real Data**
[arXiv:2606.10683](https://arxiv.org/abs/2606.10683) · (저자 미명시) · source: citation-graph (Dexora)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **핵심 문제 진단**: 이종 다지 손 하드웨어(기구학·관절 정의·DoF 차이) → 다지 조작 데이터 단편화 → 공동 학습 불가
- **UDHM(Unified Dexterous Hand Model)**: 인간 및 로봇 손 상태를 공유 22-DoF 의미론적 인터페이스로 매핑 — 리타겟팅 없이 표준화된 실제 관절 상태에서 직접 학습
- **UniDexTok**: UDHM 기반 embodiment-조건부 이산 토큰(discrete token) 학습기 — 시뮬레이션·리타겟팅 데이터 의존 없이 실제 관절 상태에서 직접 토큰화
- **성능**: 기준선 UniHM 대비 MPJAE 15.63°→0.16°(98.98% 감소), MPJPE 18.51mm→0.18mm(99.03% 감소) — 센티미터 수준 오차를 서브-밀리미터로 압축
- **교차 embodiment 이득 확인**: 타 embodiment 데이터가 목표 embodiment 재구성 정확도를 향상 — 이종 다지 손 공동 학습 가능성 실증
- **제로샷·퓨샷 일반화**: 미관측 다지 손 도입 시 제로샷·퓨샷 재구성 성공

### (c) 시사점

- **손 출력 공간 이산화 경로**: 연속 관절 명령 공간 대신 이산 토큰화를 적용해 22-DoF 통합 인터페이스를 구현하는 방식 — 고차원 손 출력 공간의 표현 압축 및 embodiment-agnostic 설계 방향 제시
- **교차 embodiment 공동 학습 가능성**: 동일 토크나이저로 서로 다른 다지 손 데이터를 공동 훈련했을 때 각 embodiment 재구성 정확도 향상 — Hand Expert 사전학습 시 다양한 플랫폼 데이터 활용 근거 마련
- **리타겟팅-프리 설계**: 기존 손 리타겟팅 방법의 기구학 근사 오차를 원천 차단 — 실제 관절 상태 기반 토큰화로 손 행동 표현의 신뢰도 향상

### (d) 먼저 확인할 점

- **토크나이저 → 조작 정책 연결 미검증**: 재구성 정확도(MPJAE/MPJPE)는 검증됐으나 다운스트림 조작 정책 성능에 대한 end-to-end 실험 별도 확인 필요
- **코드·데이터 미공개**: 추상 기준 릴리스 언급 없음 — 재현 불가, 공개 시점 모니터링 필요
- **이산 토큰 제어 지연**: 이산 토큰화가 연속 관절 명령 대비 제어 주파수·잠재 지연에 미치는 영향 논문 본문 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Beyond Implicit Force: Evaluating Explicit Force-Torque Proxies in Action Chunking with Transformers**
[arXiv:2607.14578](https://arxiv.org/abs/2607.14578) · (저자 미명시) · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **핵심 발견**: 리더-팔로워 텔레옵 방식 ACT 정책의 '힘 인식'이 숨겨진 신호(암묵적 추종 오차)에 의존 — 이 신호 제거 시 접촉 임계 단계에서 심각한 성능 저하 발생
- **실험 설계**: 팔로워 관절 상태 예측 방식(observation-centric ACT) 도입으로 암묵적 텔레옵 오차 제거 → 모터 전류·관절 토크 기반 단순 프록시(torque proxy)로 대체 가능 여부 검증
- **4개 실기 과제**: 표면 추종, 삽입, 강성 판별, 힘 기반 정지 — 각각 독립적인 접촉 집약 시나리오
- **주요 결과**: 토크 증강(torque-augmented) 정책이 암묵적 신호와 동등 또는 초과 성능 달성 — 외부 F/T 센서 없이 온보드 모터 전류만으로 접촉 인식 정책 복구 가능

### (c) 시사점

- **손 입력 스트림 설계 근거**: 모터 전류/관절 토크가 추가 외부 센서 없이 접촉 집약 과제에서 시각 단독 대비 성능을 유의미하게 향상 — 손 제어 입력 스트림에 고유감각(proprioceptive) 토크 채널 추가의 실증적 근거
- **모달리티 분리 vs. 암묵적 신호 경제성**: 명시적 토크 모달리티를 분리 처리하면 텔레옵 하드웨어 의존 없이 접촉 감지 가능 — 수집 파이프라인 표준화 및 모달리티 분리 설계 방향 지지
- **삽입·표면 추종 과제 기준선 확보**: 접촉 집약 과제의 힘 제어 필요성을 4개 독립 과제에서 정량화 — 유사 과제 평가 시 직접 비교 기준선 제공

### (d) 먼저 확인할 점

- **ACT 기반 한정**: Transformer 기반 행동 청킹(ACT) 아키텍처에서의 결과 — 플로우 매칭·디퓨전 기반 정책으로의 전이 가능성 별도 확인 필요
- **코드 미공개**: 실험 설정 상세 기술, 코드 릴리스 언급 없음 — 재현 별도 구현 필요
- **다지 손 미적용**: 4개 과제가 로봇 아암 말단(gripper) 수준 접촉 집약 과제 — 다지 손 관절별 토크 신호 통합 설계는 별도 확인 필요
