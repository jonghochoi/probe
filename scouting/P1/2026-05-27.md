## 🥇 논문 1 — 우선순위 ★★★

**Safe and Steerable Geometric Motion Policies for Robotic Dexterous Manipulation**
[arXiv:2605.21811](https://arxiv.org/abs/2605.21811) · Albert Wu, Riccardo Bonalli, T. Lew, C. Karen Liu · source: keyword-sweep (cs.RO+dexterous)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **SafePBDS** — "이질적 기하학적 공간(heterogeneous geometric spaces)" 개념으로 팔 구성 공간(R^7)과 손가락 관절 공간을 분리하고 상위 정책이 잔차 동작(residual motion)을 주입하는 task manifold action interface 제시, body→hand 계층적 흐름을 기하학적 제어 수준에서 선행 구현
- **Pullback Control Barrier Function(CBF)**
  - 팔(R^7 구성 공간)·손가락(관절 공간)·장애물 회피(R 공간)에 정의된 목표·제약을 단일 최적화 문제로 통합
  - 이질적 공간을 직접 연결하는 "pullback" 구조가 신규
- **task manifold action interface**
  - 고수준 정책이 저차원 잔차 입력만 주입하면 저수준 자율 동작이 안전·최적성 유지
  - "zero input = 자율 동작 회복" 설계는 손가락 전문가가 기본 동작을 보유하고 팔 body action이 조건화 신호로만 개입하는 구조와 동형
- **결과** — 23-DOF Franka Panda-Allegro Hand 실세계 플랫폼에서 grasping 92.5%(120 시도), in-hand reorientation >360° yaw, 4개 손가락 중 1개를 1-차원 action으로 제외하는 3-finger grasp 94.4%

### (c) 시사점

- **Body SE(3) 출력 지지** — 팔 목표를 SE(3) 엔드이펙터 포즈로 표현하고 pullback으로 구성 공간 가속도로 변환, Cartesian 표현이 계층 구조 중간 인터페이스로 자연스럽게 쓰인다는 수학적 근거
- **Hand 관절 명령 지지** — 구성 공간 가속도가 관절 명령과 동형, 과접촉 트리거 발생 전까지 관절 명령 방식으로 충분함을 실세계 in-hand rotation 결과가 직접 뒷받침
- **계층 인터페이스 구현 양식** — "상위 정책 → 잔차 입력 → 자율 손가락 동작"이 body→hand 흐름의 구체 구현 양식, residual injection이 참조 구현 제공
- **in-hand rotation 기준치** — 23-DOF Panda-Allegro >360° yaw 수치가 sim-ablation 성공률 목표 설정의 외부 참조 기준치

### (d) 먼저 확인할 점

- **모델 기반 통합 불명** — 모델 기반(model-based) 기하학적 제어 프레임워크로, 흐름-매칭 학습 정책(π backbone)과 최적제어 기반 자율 동작의 통합 방식 불분명
- **동역학 모델 가정** — pullback CBF는 정확한 동역학 모델 가정, 비정형 물체·마찰 불확실성에서 모델 오류가 안전 보장 위반 우려
- **과제 일반화** — 단일 물체 grasping·in-hand reorientation 집중, 다단계 공구 조작(tool articulation)처럼 연속 접촉 변화 과제 일반화 미검증
- **최저비용 사전 점검** — 시뮬레이션에서 task manifold action interface를 π0 backbone body action 출력과 연결하는 프로토타입을 만들고, 학습된 body action이 잔차 입력일 때 손가락 자율 동작이 안정적으로 조건화되는지 확인

## 🥈 논문 2 — 우선순위 ★★

**X-DiffVLA: X-Embodied Diffusion Action Heads for Vision-Language-Action Models**
[arXiv:2605.25044](https://arxiv.org/abs/2605.25044) · Boyu Li, Chaoyi Xu, Haoqi Yuan, Xinrun Xu, Börje F. Karlsson · source: keyword-sweep (cs.RO+cross-embodied)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **X-DiffVLA** — "공유 로봇 베이스 + 이질적 말단 이펙터(그리퍼 vs 다지 핸드)" 구조를 단일 diffusion action head로 처리, "공유 트렁크 + 분리된 Body/Hand 헤드" 설계와 가장 가까운 외부 실증 사례
- **Embodiment Forcing**
  - Classifier-Free Guidance(CFG)를 확장해 단일 가이던스 신호로 말단 이펙터 유형(그리퍼·다지 핸드) 조건화
  - 별도 이펙터 분류 헤드·명시적 라우터 없이 action 생성 방향을 이펙터 유형에 맞게 암묵 조정
  - 기존 VLA의 이펙터별 fine-tuning과 달리 단일 action head에서 이질성 처리
- **Morphological Tree Diffusion**
  - 이펙터 형태 계층(gripper → simple hand → complex dexterous hand)을 트리로 표현, 트리 인접 노드 간 행동 연속성 제약을 diffusion 프로세스에 내재화
  - 그리퍼 데모에서 다지 핸드 행동으로 지식 이전
- **결과** — RoboCasa(+15.3%), Isaac Gym(+12.5%)에서 기준선 대비 유의미한 향상 + 실세계 검증

### (c) 시사점

- **분리 형태 비교 기준** — Embodiment Forcing이 명시적 해부학적 분리 없이 이질적 말단 이펙터를 처리한 결과는 "공유 표현 + body/hand-specific latent"가 경쟁력 있는 선택지임을 시사
- **조건화 메커니즘 옵션** — Morphological Tree Diffusion이 이펙터 형태 계층으로 body→hand 행동 연속성을 표현, "형태 계층 유도 cross-attention"이라는 새 설계 옵션 제시
- **diffusion vs flow-matching 이식성** — X-DiffVLA는 diffusion(DDPM 계열), P1 backbone은 flow-matching(π0). CFG가 score-based 모델에서 성립하므로 flow-matching 이식이 비자명, 적용 가능성 검토 필요

### (d) 먼저 확인할 점

- **이질성 층위 차이** — "이질적 말단 이펙터"는 그리퍼 로봇 vs 다지 핸드 로봇 간 cross-embodiment 이전, P1의 "단일 로봇 내 팔(body) + 손가락(hand) 해부학적 분리"와 구조적으로 상이
- **역방향 이전 비보장** — cross-embodiment 이질성 처리가 단일 로봇 내 팔/손 분리로 자동 성립하지 않음
- **형태 트리 적용성** — Morphological Tree가 "팔 링크 트리 → 손가락 링크 트리"의 단일 로봇 전신 형태 계층에도 적용 가능한지 확인 필요
- **최저비용 사전 점검** — Franka Panda-Allegro 형태 트리를 정의하고 Morphological Tree 구조가 팔 관절→손가락 관절 계층을 올바르게 표현하는지 시뮬레이션에서 우선 검증

## 🥉 논문 3 — 우선순위 ★

**TactileReflex: Noise-Statistics-Driven Vision-Tactile Reflex Control for Force-Sensitive Manipulation**
[arXiv:2605.23568](https://arxiv.org/abs/2605.23568) · Ziyan Feng, Yulong Fu, Zheng Li, Yuxin He, Jieji Ren, Lujia Wang, Jinni Zhou, Yudong Zhong, Qian Nie · source: citation-graph (π0 인용)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **공백** — 기존 촉각 기반 VLA는 촉각 신호를 정책 입력에 추가하거나 tactile reward를 학습 목표에 포함하는 방식에 집중
- **noise-statistics-driven calibration** — 보정 비용·외부 힘 측정 없이 센서 내재 노이즈 통계만으로 제어 임계값 도출
  - 정적 홀드-언로드(static-hold-and-unload) 프로토콜로 노이즈 특성 파악
  - shear intensity($S_y$), contact intensity($F_n$), center of pressure($C$) 세 채널 임계값 직접 계산
- **채널별 우선순위 반사 제어** — 미끄럼 억제 > 무게 적응 > 힘 보호를 ~12 Hz로 실행, 재료별 캘리브레이션·시행착오 없이 얇은 벽 용기 조작 9/10 실세계 성공
- **위치 부여** — 논문 결론부에서 VLA 정책 하단의 "plug-and-play safety layer"로 명시

### (c) 시사점

- **과접촉 회피 경로 확보** — contact intensity 채널($F_n$)이 과도한 접촉력을 ~12 Hz로 감지·조정, position command를 유지하면서 과접촉 문제 해결 경로 확인
- **고주파 루프 정량 기준** — ~12 Hz 촉각 루프가 body와 분리된 고주파 Hand 루프의 실험적 하한선 제시
- **고주파 Hand 반응 근거 누적** — hand 루프가 body보다 높은 주파수로 반응해야 한다는 외부 증거가 이번 런으로 4번째(AT-VLA·MoSS·PT·TactileReflex)

### (d) 먼저 확인할 점

- **센서 전제** — 비주오택타일(visuotactile) 센서(예: GelSight 계열) 전제, Sharpa / xhand가 표준 미지원이면 contact·shear intensity를 wrist force/torque·motor current로 대리 추정해야 하고 노이즈 통계 기반 임계값 도출 직접 적용 불가
- **정적 노이즈 가정** — "단순 정적 홀드-언로드 프로토콜"이 손가락 관절이 움직이는 동적 in-hand manipulation에서도 노이즈 특성 동일 유지 가정, 관절 움직임이 동적 노이즈 추가 시 임계값 추정 부정확 우려
- **최소 사전 점검** — Sharpa / xhand 관절 전류 신호가 접촉력과 선형 관계인지 정적 측정으로 확인, $F_n$ 추정 대리 신뢰도 평가
