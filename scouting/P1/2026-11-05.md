## 🥇 논문 1

**TF²-Steering: Action Refinement with Tactile Forecasts and Feedback via Velocity-Field Steering**
[arXiv:2611.01483](https://arxiv.org/abs/2611.01483) · Yiming Chen, Xiaofei Wei, Chun Gu, Wei Xiao, Peidong Liu, Li Zhang · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 프로젝트 페이지만

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 논문 요지

- 촉각 전문가가 액션 전문가의 속도장을 보정
- **문제** — 비전 중심 기초 정책에 촉각을 어떻게 넣을지, 촉각을 피드백으로만 쓸지 예측으로도 쓸지
  - 촉각 신호의 시간적 희소성과 촉각 데이터의 적은 규모 때문에 입력에 단순 추가하면 무시되거나 사전학습된 시각 표현을 해침
  - 접촉 집약적 조작은 시각만으로 접촉 순간을 추정하기 어려움
- **기존 한계** — 촉각을 격리하려는 잔차 경로와 게이팅 방식의 약점 지적
  - 잔차 경로 — 별도로 학습한 보정 가지가 이미 생성된 액션만 고칠 수 있어 잘못된 계획을 되돌리기 어려움
  - 게이팅 — 학습된 게이트가 액션 헤드에 닿기 전에 촉각 특징을 약화시켜 기여가 약하거나 불안정
  - 반응형 촉각 피드백 연구와 미래 촉각 예측 연구는 있으나 하나의 인과적 액션 보정 과정으로 통합되지 않음
- **핵심 방법** — 플로우 매칭 액션 전문가 옆에 촉각 전문가를 두고, 델타 속도를 더해 생성 중 속도장을 보정
  - 월드-액션 백본 — LTX-Video, Q-Former, 플로우 매칭 액션 전문가로 구성되고 액션 청크 생성에 240ms(RTX 4090 한 장)
  - 촉각 월드 모델 — 약 500M 파라미터, 미래 촉각 특징을 예측해 청크 실행 전에 한 번 만들고 고정
  - 촉각 전문가 — 예측 촉각과 실시간 촉각을 각각 전담하는 하위 전문가로 나누고 시그모이드 가중으로 독립 조절
  - 단방향 어텐션과 stop-gradient — 액션 전문가는 촉각 특징에 접근하지 못하고 보정 손실이 액션 전문가를 갱신하지 않음
  - 이중 속도 — 저속 월드 모델이 계획 사전정보를 주고 고속 액션·촉각 전문가가 블록 단위로 남은 액션을 재생성
  - 3단계 학습 — 촉각 예측 사전학습, 촉각 속도 조향 사전학습(촉각 없는 샘플 10% 혼합), 과제별 미세조정
- **차별점** — 이미 생성된 액션을 고치는 후처리가 아니라 액션 생성 중 속도장에서 보정
  - 원 액션 전문가는 촉각 입력 없이도 독립된 기본 액션 공급원으로 유지
  - 예측 촉각과 실시간 촉각을 한 보정 과정 안에서 함께 사용
- **핵심 기여** — 이중 속도 프레임워크, 속도장 조향 알고리즘, 시뮬레이션과 실물 평가
  - 시뮬레이션 UniVTAC 여섯 과제 평균 성공률 68.3%, 최강 기준선 FTP-1 대비 초록 기준 10.7%p 우위(본문 4.2는 10.6%p)
  - 실물 양손 UR5e와 22-DoF Sharpa 손, 여섯 과제 평균 진행 성공률 71.5%, 최강 기준선 T-Rex 대비 9.1%p 우위
  - 기준선 다섯 종 — ViTacFormer, π0.5, π0.5 + tactile, T-Rex, FTP-1
  - 촉각 이미지를 π0.5에 직접 붙인 변형은 시뮬레이션 55.7%에서 56.0%로 거의 변화 없고 실물 40.2%에서 35.2%로 하락
  - 실물 ablation — 촉각 제거 61.7%, 예측 촉각만 63.0%, 실시간 촉각만 69.7%, 둘 다 72.3%
  - 액션 공간 잔차 보정 61.3%로 촉각 없는 변형과 비슷하고, 어텐션 마스크와 stop-gradient를 함께 제거하면 62.7%
- **가치** — 사전학습된 비전 중심 정책의 능력을 해치지 않고 촉각을 더하는 경로 제시
  - 촉각 예측과 실시간 피드백의 상보성을 같은 틀에서 분리 측정

### (c) 시사점

- 촉각을 입력에 합치지 않고 별도 경로로 분리하는 쪽의 직접 근거
- **직접 결합의 열세** — 촉각 이미지를 기초 정책 입력에 붙이면 실물 평균이 40.2%에서 35.2%로 하락
- **분리 설계의 이득** — 보정 경로가 속도장에 개입하는 방식이 액션 공간 잔차(61.3%)보다 높음
- **호출 시점** — 블록 단위 재생성으로 정책 루프 안에서 촉각 갱신 빈도를 추론 시 조절 가능
- **도입 비용** — 월드 모델 두 개와 3단계 사전학습이 필요해 도입 비용 높음

### (d) 먼저 확인할 점

- **공개 여부** — 프로젝트 페이지만 있고 저장소나 공개 약속 없음
- **통계 근거** — 실물 과제당 20회 시행의 진행 성공률이며 반복 시드나 분산 보고 없음
- **수치 표기** — 시뮬레이션 우위가 초록 10.7%p, 본문 4.2는 10.6%p로 달라 표 원문 확인 필요
- **ablation 기준** — 실물 ablation의 완전 모델 72.3%가 본문 주 결과 71.5%와 달라 설정 차이 확인 필요
- **기준선 설정** — T-Rex는 평가에서 촉각 갱신 간격을 네 스텝으로 고정해 비교
- **전이 조건** — 촉각 사전학습이 OpenNeoData, T-REX, FTP-1-Sharpa 데이터와 Sharpa 손 센서 구성에 기대고 있어 다른 손으로의 이전은 별도 확인 필요
