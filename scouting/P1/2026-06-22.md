## 🥇 논문 1 — 우선순위 ★★★

**Co-VLA: Coordination-Aware Structured Action Modeling for Dual-Arm Vision-Language-Action Systems**
[arXiv:2606.20285](https://arxiv.org/abs/2606.20285) · Yandong Wang et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **모놀리식 액션 헤드의 암묵적 협조 한계 명시** — 양팔 태스크가 긴밀하게 결합될수록 암묵적 end-to-end 협조만으로는 신뢰성·해석 가능성·안정성 보장 불가; 기존 양팔 VLA의 구조적 공백
- **Co-VLA** — 양팔 조작에 명시적 구조 사전(structural prior)을 주입하는 프레임워크
  - **Structured Action Expert (SAE)**: 모놀리식 액션 헤드를 대체; 공유 잠재(shared latent) + 팔별 잔여 잠재(residual latent)로 분리
    - 공유 잠재: 태스크 수준 협조 의도(coordination intent) 인코딩
    - 잔여 잠재: 각 팔의 실행 조정(execution adjustment) 독립 포착
  - **모달리티별 협조 인식 손실(coordination-aware loss)**: 태스크별 구조에 따라 공유·잔여 잠재 형성을 직접 감독
  - **Latent-Aware Controller (LAC)**: 학습된 잠재 표현 실시간 해석 → 동기화 강도·실행 비대칭성·궤적 부드러움·안전 제약 실시간 변조; 표준 관절 명령 파이프라인과 완전 호환
- **성능** — 긴밀 협조 태스크 SR +27%p, OOD 실세계 시나리오 SR 13%→27%(2배↑), 태스크 완료 시간 최대 25% 단축
- **진정으로 새로운 점**
  - 기존 양팔 VLA: 단일 모놀리식 헤드, 협조 구조 암묵적 학습에 전적 의존
  - 액션 생성 수준에서 공유·잔여 잠재를 명시 분리하는 SAE + 실시간 협조 변조 LAC 결합 최초

### (c) 시사점

- **양팔 VLA에서 명시적 분리 구조의 정량 이득 확인** — 공유 잠재(협조 의도) + 팔별 잔여 잠재(실행 조정) 분리로 +27%p 및 OOD 2배 향상; 바디·핸드 이질 분리가 동일 원리에서 성능 이득을 기대할 수 있는 세 번째 독립 정량 근거(AIR-VLA+ +80.2%, GeoHAT +23.7% 이후)
- **LAC 실시간 협조 변조 패턴** — 잠재 해석 기반 컨트롤러가 동기화 강도·비대칭성을 태스크 국면별 동적 조정; 바디→핸드 정보 흐름 강도를 동작 단계에 따라 변조하는 설계 후보 경로
- **비대칭 실행 처리 경험** — 잔여 잠재가 팔별 실행 조정을 독립 포착; 운동학적으로 이질적인 바디(손목 포즈)·핸드(손가락 관절) 쌍의 비대칭성을 동일 잔여 잠재 분리 원칙으로 처리 가능

### (d) 먼저 확인할 점

- **arXiv 제출 직후, Semantic Scholar 미인덱싱** — 코드·데이터 공개 여부 미확인; SAE 아키텍처 및 LAC 세부 구현을 논문 본문 확인 전 재현 불가
- **대칭 양팔 구조 전제** — SAE의 공유·잔여 분리가 두 팔이 동등한 자유도를 갖는 대칭 구조를 전제; 운동학적으로 이질적인 바디(7DoF 팔)·핸드(20+ DoF 손가락) 쌍에서 공유 잠재 품질 유지 여부 독립 검증 필요
- **LAC 하이퍼파라미터 튜닝 부담** — 실시간 협조 변조 매개변수(동기화 강도·비대칭성 등)가 LAC에 집중; 바디·핸드 간 협조 제약이 더 복잡한 다지 환경에서 LAC 튜닝 부담 가능성

## 🥈 논문 2 — 우선순위 ★★

**Transferring Contact, Not Just Motion: Compliant Grasping Across Dexterous Hands**
[arXiv:2606.15516](https://arxiv.org/abs/2606.15516) · Soofiyan Atar et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4)

### (b) 핵심 기여

- **포즈 전용 교차 embodiment 정책의 한계 명시** — 기존 방법이 운동 의도(motion intent)를 재타겟팅 손 포즈·잠재 액션으로 통합하나, 힘 피드백은 각 하드웨어의 감지·구동 능력에 종속 → 교차 embodiment 이전 시 컴플라이언스 보장 불가
- **교차 embodiment 힘-위치 인터페이스**:
  - **공유 손 포즈 잠재(shared hand-pose latent)**: 운동 의도를 하드웨어 독립적으로 표현
  - **시스템 식별(system identification) 기반 관절 토크 보정**: 각 손의 effort 신호를 물리적 관절 토크(N.m)로 캘리브레이션 → 손끝 힘 및 **손가락별 부하 기술자(per-finger load descriptor)**로 매핑
  - 결과: 손이 어디로 이동해야 하는지(위치)와 물체가 어떻게 로드되는지(힘) 두 정보를 정책에 균등 제공
- **플로우 매칭 비주오모터 정책** — 시각·고유감각·보정 접촉 신호 조건 학습; 파지 관련 시야 차폐(occlusion) 상황에서 힘 의존을 유도하는 **구조적 시각 마스킹** 도입
- **성능** — 구조적으로 상이한 다지 핸드 간 이전 실험에서 보정 접촉 피드백이 이전 가능 컴플라이언스 파지 실현; 장기 지평 파이프라인에서 학습 프리미티브 재사용 확인

### (c) 시사점

- **손가락 출력 공간에 힘/토크 포함의 실세계 근거** — 손가락 관절 명령만으로는 교차 embodiment 컴플라이언스 이전 불가; 관절 토크 보정 + per-finger 부하 기술자 추가 시 이종 하드웨어 간 이전 성공; 손가락 출력 공간 확장 필요성 최초 정량 확인
- **핸드 전문가 독립 접촉 피드백 채널 필요성 시사** — 보정 접촉 신호가 바디 전문가 조건화 신호 외에 독립적으로 핸드 전문가에 필요함을 외부 실증; 단일 바디→핸드 FiLM 조건화만으로 접촉 집약적 파지 지원 불충분 가능성
- **교차 embodiment 재사용 가능성** — 시스템 식별 기반 토크 보정이 손마다 다른 구동 특성을 정규화; 다지 핸드 교체 시 재수집 없이 핸드 전문가 정책 재사용 경로 외부 확인

### (d) 먼저 확인할 점

- **시스템 식별 비용** — 각 새 손에 대해 effort → N.m 토크 캘리브레이션 과정 필요; 20+ DoF 다지 핸드에서 손가락별 독립 식별 가능 여부 및 소요 시간 미확인
- **per-finger 부하 기술자 설계 범위** — 기술자의 구체 표현(차원·갱신 주기) 불명(논문 전체 미확인); 인핸드 조작처럼 손가락 끝이 연속 재배치되는 환경에서 기술자 안정성 미검증
- **저렴한 점검** — 단일 다지 핸드로 손가락 관절 명령 전용 vs. 관절 토크 포함 명령 비교: 시야 차폐 파지 성공률 차이 소규모 측정으로 출력 공간 확장 필요성 1차 추정

## 🥉 논문 3 — 우선순위 ★

**GeoHAT: Geometry-Adaptive Hybrid Action Transformer for Mobile Manipulation**
[arXiv:2606.13394](https://arxiv.org/abs/2606.13394) · Xiangyu Zhu et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **모바일 조작의 이질 액션 공간 단일 벡터 인코딩 문제 명시** — 기존 정책이 팔(arm)과 베이스(base)를 단일 액션 벡터로 인코딩, 두 서브시스템의 상이한 제어 요구(control demand)를 무시
- **GeoHAT** — 기하학 적응형 인식 + 하이브리드 전신 액션 디코더를 결합한 확산(diffusion) 기반 end-to-end 프레임워크
  - **Fourier 공간 인코더**: 밀집 픽셀별 3D 좌표를 추가 3D 백본 없이 경량 기하학 토큰으로 변환
  - **깊이 유효성 게이팅 융합(depth validity gated fusion)**: 기하학 토큰을 신뢰 가능한 영역에만 per-token 게이팅으로 선택적 주입 → 비전 파운데이션 모델의 시맨틱 사전 보존
  - **Hybrid Whole-Body Action Decoder**: 팔·베이스를 별개 서브스페이스로 분해; 각 액션 모달리티가 태스크 관련 시각 컨텍스트를 희소 크로스 어텐션으로 독립 수신; 인과 시간 모델링으로 타임스텝 내 협조 + 타임스텝 간 의존성 포착
- **성능** — ManiSkill-HAB 시뮬레이션 79.3% 평균 SR(최강 기준선 대비 +23.7%p); 실세계 다양한 태스크에서 전체 기준선 대비 일관된 향상 확인

### (c) 시사점

- **팔+베이스 이질 분해로 +23.7%p** — 이질 쌍을 별개 서브스페이스로 분해하는 하이브리드 디코더가 단일 액션 벡터 대비 실증 우위; 바디·핸드 이질 분해의 성능 이득을 독립 도메인에서 세 번째로 정량화(AIR-VLA+ +80.2%, Co-VLA +27%p 이후)
- **태스크 관련 시각 컨텍스트 희소 선택** — 각 액션 전문가가 자신에게 관련된 시각 토큰만 희소 크로스 어텐션으로 수신; 핸드 전문가가 손가락 끝 근접 시각 특징만 선택 수신하는 설계 후보 경로
- **기하학 주입 + 시맨틱 사전 보존 양립** — 게이팅 기반 선택적 주입이 비전 파운데이션 모델 사전 손상 없이 공간 정보 추가; 백본 사전 보존 원칙과 공명하는 구현 패턴

### (d) 먼저 확인할 점

- **모바일 조작 전용 도메인** — 팔+베이스(수평 이동) vs. 바디+핸드(다지 손가락)의 이질성 종류와 DoF 격차 상이; 손가락 DoF가 10배 이상인 다지 핸드에서 희소 크로스 어텐션 별도 서브스페이스 분해가 동일 이득 유지 가능한지 독립 검증 필요
- **깊이 유효성 게이팅 신뢰도** — 손가락 끝 근접 촬영에서 뎁스 노이즈가 높을 경우 게이팅 신뢰도 저하 → 기하학 정보 손실 가능
- **저렴한 점검** — 단일 팔+그리퍼 고정 조작에서 Hybrid Action Decoder(팔+그리퍼 별도 서브스페이스)와 단일 액션 벡터 기준선 비교; 분해 이득 소규모 확인 후 다지 핸드 확장 결정
