## 🥇 논문 1 — 우선순위 ★★★

**Dexora: Open-source VLA for High-DoF Bimanual Dexterity**
[arXiv:2605.18722](https://arxiv.org/abs/2605.18722) · Zongzheng Zhang, Jingrui Pang, Zhuo Yang, Kun Li, Minwen Liao · source: keyword-sweep (cs.RO+dexterous)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **Dexora** — 데이터 수집 단계에서 팔(arm) 거시 운동과 손가락(finger) 정밀 동작을 명시적으로 분리한 첫 공개 소스 VLA 시스템, 해부학적 Body/Hand 분리를 데이터·아키텍처 양 단에서 동시 지원
- **분리형 원격 조종(decoupled teleoperation)**
  - 팔 거시 운동학(gross arm kinematics) — 커스텀 외골격 배낭으로 캡처
  - 손가락 정밀 동작(fine finger motion) — Apple Vision Pro 마커리스 추적으로 캡처
  - 두 축을 단일 채널로 묶어 수집하는 기존 단일 그리퍼 VLA(예: π0.5) 대비 출력 공간을 수집 단계에서 그대로 분리
- **품질 인식 훈련(data-quality-aware training)** — 오프라인 판별기(offline discriminator)가 클립 단위 가중치로 저품질 시연 기여도 절감, 확산-트랜스포머 정책(diffusion-transformer policy) 학습
- **결과** — 10만 건 시뮬레이션 + 1만 건 실세계 궤적 코퍼스, 실제 이중 팔·이중 손(dual-arm dual-hand) 플랫폼에서 기본 과제 90% / 다지 조작 과제 평균 66.7%(기준선 51.7%) 성공률

### (c) 시사점

- **분리 파이프라인 외부 구현 확보** — "팔 외골격 + 손가락 비전 추적" 분리가 우리 데이터 수집 단계 분리 설계와 동형, 입력 채널 분리 인터페이스의 직접 참조점
- **출력 공간 분리 검증** — 팔 궤적은 wrist pose(SE(3)), 손가락 궤적은 finger joint angle로 독립 저장 가능함 확인
- **backbone 확장 경로** — π0.5 스타일 확산-트랜스포머를 고-DoF 이중 손 출력으로 확장, 단일 팔→이중 팔·손 확장 시 코퍼스 조합 전략(시뮬 100K + 실세계 10K) 참조
- **품질 가중 도입 옵션** — 원격 조종 데이터 품질 변동이 클 때 오프라인 판별기를 선택적 add-on으로 도입 가능

### (d) 먼저 확인할 점

- **하드웨어 비용** — 외골격 + Apple Vision Pro 파이프라인은 전용 하드웨어 비용 높음
- **wrist pose 추정** — Sharpa / xhand 인터페이스 사용 시 팔 외골격 없이 wrist pose 추정 필요, 수집 단계 팔·손 분리 정확도 저하 우려
- **단일 팔 일반화** — 이중 팔·손 설정에서만 검증, 단일 팔 + 단일 손에서 분리 파이프라인 성능 유지 여부 미확인
- **최저비용 사전 점검** — wrist velocity + joint position 신호만으로 팔·손 분리 수집 가능한지, 시뮬레이션에서 소규모 in-hand rotation 과제로 우선 검증

## 🥈 논문 2 — 우선순위 ★★

**Learning Robust Dexterous In-Hand Manipulation from Joint Sensors with Proprioceptive Transformer**
[arXiv:2605.21330](https://arxiv.org/abs/2605.21330) · Senlan Yao, Chenyu Yang, Jaehoon Kim, Aristotelis Sympetheros, Robert K. Katzschmann · source: keyword-sweep (cs.RO+dexterous)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **공백** — 대다수 인핸드 조작(in-hand manipulation) 연구는 시각·촉각 센서로 물체 상태 추적
- **관절 센서만(exteroception-free)** 으로 텐던-구동형 다지 핸드(tendon-driven hand)에서 연속 정육면체 회전(continuous cube rotation) 달성
- **Proprioceptive Transformer(PT)** — 관절 위치·속도 이력(joint position·velocity history)에서 암묵적 물체 상태(implicit object state)를 추출하는 Transformer 구조
- **특권-교사→학생 증류(teacher–student distillation)** — 특권 물체 정보 학습 교사를 PT로 증류, 외부 지각 없이 동등 성능
- **결과** — 실세계 ORCA 핸드 실험에서 기준선 대비 회전 속도 3.1배, 정육면체 위치 추정 RMSE 23.4% 감소, 촉각·시각 없이 관절 고유감각만으로 in-hand rotation 가능함을 최초 실증

### (c) 시사점

- **Hand 입력 축소 가능성** — 촉각·로컬 시각 없이도 in-hand rotation 달성 가능하다는 직접 증거, 촉각 센서 미확보 단계에서 proprio-only 베이스라인이 충분할 가능성
- **물체 추적 모듈 생략 가능성** — 관절 이력에서 물체 상태를 암묵 추출하므로 별도 물체 추적 없이 접촉 정보 표현 가능
- **고주파 Hand 루프와의 연계** — PT가 고주파 관절 이력을 입력으로 쓰면 body와 분리된 고주파 Hand 전문가 루프 설계로 자연 연결

### (d) 먼저 확인할 점

- **과제·하드웨어 범위** — 텐던-구동형 ORCA 핸드의 단일 정육면체 회전 과제 한정, Sharpa / xhand가 다른 관절 센서거나 과제가 다지 접촉 정밀 조작이면 동일 추출 가능 여부 불분명
- **증류 전제** — 교사-학생 증류는 시뮬레이션 특권 정보(물체 pose) 가용 가정, 다른 핸드 재현 시 추가 교사 학습 필요
- **최소 사전 점검** — Sharpa / xhand 관절 센서 샘플링 레이트·신호 노이즈 확인, PT 입력 형식 호환성 측정

## 🥉 논문 3 — 우선순위 ★

**SkiP: When to Skip and When to Refine for Efficient Robot Manipulation**
[arXiv:2605.15536](https://arxiv.org/abs/2605.15536) · Mingtong Dai, Guanqi Peng, Yongjie Bai, Feng Yan, Chunjie Chen, Lingbo Liu, Liang Lin, Xinyu Wu · source: citation-graph (π0.5 인용)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **공백** — 기존 imitation learning 정책은 조작 궤적의 모든 스텝을 동등 취급
- **Motion Spectrum Keying(MSK)** — 수동 주석 없이 'Skip(자유 공간)' 구간과 'Key(접촉·파지)' 구간을 자동 분리하는 알고리즘
- **action relabeling** — Key 구간에서만 dense 예측, Skip 구간에서는 다음 Key 진입 액션으로 직접 도약
- **구조** — 계층적 구조나 별도 skip 계획기 없이 단일 통합 네트워크로 구현, 기존 hierarchical 접근과 상이
- **결과** — 72개 시뮬레이션 + 3개 실세계 과제에서 실행 스텝 15–40% 절감하며 성공률 유지·향상, 코드·프로젝트 페이지 공개

### (c) 시사점

- **전환 시점 자동 결정 참조** — action signal의 local motion complexity로 Key 구간을 탐지하는 방식이 body 동작 종료 후 hand 활성화 시점을 데이터 기반으로 결정하는 참조 알고리즘
- **핸드오버 지점 자동 추출** — SkiP의 "Key segment entrance action"을 hand 전문가 조건 신호로 해석하면 body→hand 조건화 경계를 데이터에서 자동 추출 가능
- **동적 조건화로 확장** — FiLM 조건화 시점을 정적 고정 대신 동적 선택하는 설계로 확장 여지

### (d) 먼저 확인할 점

- **구조 불일치** — 단일 통합 정책 네트워크로 동작, 명시적 Body/Hand 전문가 분리 구조와 상이
- **구간 일치 불확실** — MSK가 탐지하는 "Key 구간"이 hand 전문가 활성화 시점과 항상 일치한다는 보장 없음, 특히 전 구간 접촉 집약적인 in-hand rotation에서는 구간 분리 의미 약화 우려
- **정책류 차이** — action relabeling이 imitation learning(BC) 기반, 플로우 매칭 정책(π0 backbone) 적용에 추가 설계 수정 필요
- **최저비용 사전 점검** — in-hand rotation 과제에서 MSK 탐지 Key/Skip 구간 분포를 시각화해 hand 전문가 활성화 구간과 일치도 확인
