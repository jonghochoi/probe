## 🥇 논문 1 — 우선순위 ★★★

**CoorDex: Coordinating Body and Hand Priors for Continuous Dexterous Humanoid Loco-Manipulation**
[arXiv:2606.23680](https://arxiv.org/abs/2606.23680) · Sikai Li, Shuning Li, Zhenyu Wei, Yunchao Yao et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **이동 중 바디-핸드 동시 제어의 실패 패턴 명시** — 기존 방법: low-DoF 그리퍼·stop-and-go 방식에 한정; 이동 중 고 DoF 손(20-DoF)을 제어하려면 단순 관절 공간 PPO·모놀리식 잠재 예측으로는 동일 보상 예산 하에서 수렴 자체가 불가
- **CoorDex 파이프라인**:
  - 시뮬레이션에서 인간형 바디(보행) 전용 특권 교사 + 다지 핸드 전용 교사를 **별도** 학습
  - 두 교사를 각각 **고유감각 조건화 잠재 사전**(proprioception-conditioned latent prior)으로 독립 증류
  - 증류된 잠재 사전을 고정(frozen) 행동 공간으로 사용 → 하류 강화학습에서 **잔여 제어**(residual control) 학습
  - **조율 잠재 잔여 정책**: 공유 태스크 컨텍스트 + 별도 바디 잔여 헤드 + 별도 핸드 잔여 헤드로 구성
- **Ablation** — joint-space PPO, joint-space 핸드 제어, 모놀리식 잠재 예측 세 방식 전부 수렴 실패; 잠재 사전 인터페이스 + 조율 잔여 구조만 수렴 성공
- **실세계 태스크** — Unitree G1 + 20-DoF WUJI 핸드: 비정지 보행 중 병 잡기·운반, 이동 중 냉장고 문 열기, 큐브 집어 회전
- **진정으로 새로운 점** — 바디 잠재 사전 + 핸드 잠재 사전을 공유 태스크 컨텍스트로 묶으면서 별도 잔여 헤드로 독립 조정하는 아키텍처 최초; 연속 이동 중 고 DoF 다지 조작 최초 달성

### (c) 시사점

- **분리 구조가 "성능 향상"이 아닌 "수렴 가능 여부"를 결정** — 공유 컨텍스트 + 별도 바디·핸드 잔여 헤드 구조가 모놀리식과의 경쟁에서 정량적 우위를 넘어 학습 가능성 자체를 가르는 경계임을 직접 실증; 분리 아키텍처 채택의 가장 강력한 외부 정당화
- **잠재 사전 수준 조율 경로 확인** — 바디·핸드를 공유 태스크 컨텍스트로 묶는 방식이 출력 수준 단일 지점 조건화보다 깊은 조율 달성; 핸드 전문가 설계 시 잠재 표현 수준 조율 방식과 출력 수준 FiLM 조건화를 직접 비교하는 실험 설계 가능
- **바디→핸드 계층 흐름의 RL 도메인 독립 검증** — 이동 중에서도 바디 잠재 → 핸드 잔여 정보 흐름이 안정적 조율 달성; IL 기반 스택의 계층 흐름 방향 선택에 RL 도메인 독립 근거 추가
- **Sim2Real 잠재 사전 재사용 패턴** — 시뮬레이션 교사에서 증류한 잠재 사전을 실세계 잔여 학습의 고정 행동 공간으로 재사용; 시뮬레이션-실환경 이전 비용 분산 경로 외부 확인

### (d) 먼저 확인할 점

- **RL 기반 학습 비용** — 하류 강화학습으로 잔여 정책 학습; 보상 설계·학습 시간이 모방 학습 대비 대폭 증가; flow-matching 기반 IL 스택에서 잔여 학습 결합 가능 여부 미확인
- **고정 잠재 사전 제약** — 증류된 잠재 사전이 고정; 하류 태스크에서 사전 분포 변경이 요구될 경우 재증류 필요; 태스크 다양성 확대 시 사전 병목 가능
- **VLM 사전학습 미포함 파이프라인** — 순수 RL 파이프라인; 언어·시각 VLM prior 없음; π0 백본 통합과 직접 결합 경로 불명
- **저렴한 점검** — 단일 고 DoF 핸드 고정 조작에서 모놀리식 잠재 vs. 바디-핸드 별도 잠재 사전 비교: 수렴 속도 차이 소규모 측정으로 분리 필요성 1차 추정

## 🥈 논문 2 — 우선순위 ★★

**UniFS: Unified Fast-to-Slow Architecture for Vision-Language-Action Models**
[arXiv:2606.22794](https://arxiv.org/abs/2606.22794) · Lin Sun, Zhiwei Guan, Conglin Wang, Zihong Chen · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **Fast-Slow VLA의 구조적 딜레마 두 가지 명시**:
  - 큰 업데이트 간격 → 스테일 컨텍스트에서 시맨틱 드리프트
  - 작은 업데이트 간격 → 계산 절약 이점 소멸
  - 추가 문제: 액션 전문가가 VLM 최종 레이어 표현만 단일 고정 주파수로 수신 → 중간 특징 폐기, 정밀도 제한
- **UniFS 세 가지 핵심 설계**:
  1. **VLM 레이어 계층화**(layer stratification) — 레이어를 주파수 그룹으로 분류: 얕은 레이어는 고주파 업데이트(빠른 변화), 깊은 레이어는 저주파 캐시(안정적 시맨틱)
  2. **잠재 벡터 역전 메커니즘**(latent vector inversion) — 다중 스케일 VLM 특징과 액션 전문가 간 상호작용 순서 재설계: 빠른 표현 → 세밀한 액션 디코딩, 느린 표현 → 거친 계획
  3. **다중 레벨 감독**(multi-level supervision) — 시간적 스케일에 걸친 거친→세밀한(coarse-to-fine) 학습 계층 강제
- **성능** — LIBERO 98.3% 평균 성공률(VLA-Adapter 대비 +2.5%p); 추론 지연 36.5ms → 17.8ms(2.1× 가속); Franka 실로봇 검증
- **코드 오픈소스** — GitHub 공개
- **진정으로 새로운 점** — "VLM 최종 레이어 전용" 한계를 레이어 계층화 + 잠재 역전으로 해결; 단일 VLM 백본 내 다중 시간 스케일 특징 전달 최초

### (c) 시사점

- **VLM 중간 레이어 활용의 공개 구현체 확보** — 액션 전문가에 최종 레이어 이외 다중 스케일 VLM 특징을 전달하는 구체적 방법의 코드 공개 구현체; VLM-액션 전문가 결합 방식 설계 시 즉시 참조 가능한 기준점
- **고주파 손가락 제어 루프 도입의 추론 속도 요건 완화** — 2.1× 가속 + 정밀도 유지 동시 달성; 손가락 관절 고주파 업데이트 추가 시 추론 지연 제약을 과도한 정밀도 손실 없이 충족 가능성 시사
- **레이어별 업데이트 주파수 분리 외부 검증** — "얕은 레이어=빠른 변화 포착·깊은 레이어=안정적 시맨틱 캐시" 분리가 조작 정밀도에 기여함을 정량화; 모달리티별 처리 속도 분리 설계 타당성 독립 확인
- **Acting While Understanding(6월 19일)과 다른 경로로 동일 문제 해결** — 비동기 디커플링(플러그인 방식) vs. 레이어 계층화+잠재 역전(백본 재설계) 두 독립 구현체 확보; 우리 스택에서 선택 기준 비교 가능

### (d) 먼저 확인할 점

- **그리퍼 기반 실험 범위** — LIBERO·Franka 실험 모두 그리퍼/손목 수준; 손가락 관절 명령 포함 고 DoF 시나리오에서 레이어 계층화 이점 독립 검증 필요
- **레이어 계층화 그룹 수·빈도 비율 튜닝** — 최적 그룹 수·빈도 비율이 하드웨어·태스크에 따라 달라질 가능성; 범용 기준점 미제공
- **저렴한 점검** — π0.5 기반 파이프라인에서 최종 레이어 전용 vs. 다중 레이어 중간 특징 경유 비교: 손목 포즈 수준 태스크에서 정밀도 차이 소규모 측정 후 다지 핸드 확장 결정

## 🥉 논문 3 — 우선순위 ★

**OpenHLM: An Empirical Recipe for Whole-Body Humanoid Loco-Manipulation**
[arXiv:2606.22174](https://arxiv.org/abs/2606.22174) · Yingdong Hu, Haodong Zhu, Boyuan Zheng, Yihang Hu, Tong Zhang · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **전신 단일 VLA의 현실적 어려움 체계적 탐색** — 기존 대부분 시스템: 상체·하체를 분리 컨트롤러로 분해 → 결과적으로 "바퀴 달린 양팔 플랫폼"과 유사 동작에 한정
- **OpenHLM** — 언어+픽셀을 인간형 로봇 전 자유도에 직접 매핑하는 전신 네이티브(whole-body native) VLA 레시피
  - 3단계(전신 원격조작 → VLA 모델 설계 → 이기종 공동훈련) 1변수-at-a-time 실험 로드맵
  - **핵심 발견 ①**: 관절 기반 전신 원격조작 인터페이스가 일부 자유도만 노출하는 대안 대비 우위
  - **핵심 발견 ②**: 정적·바퀴 양팔 플랫폼 데이터로 사전학습한 VLA가 전신 인간형 DoF로 놀랍도록 잘 이전됨
  - **핵심 발견 ③**: HuMI(인간형 UMI 아날로그) 공동훈련으로 추가 전신 원격조작 없이도 새 객체·지시어 확장 가능
- **성능** — 광범위 수직 범위 장기 지평 태스크에서 GR00T N1.6 및 Ψ₀ 대비 우세; 시연 시간 절반 이하
- **오픈소스** — 코드·훈련 데이터·모델 체크포인트 전체 공개

### (c) 시사점

- **전신 단일화 vs. 분리 컨트롤러의 비용-이익 데이터** — 전신 단일화가 "바퀴 플랫폼 한계 극복" 효과를 내지만, 전용 원격조작 파이프라인·이기종 공동훈련·VLA 재설계 전 비용 동반; 바디·핸드 분리 전문가 구조의 복잡도 비교 기준점 제공
- **관절 기반 출력 공간 세 번째 독립 근거** — 전 자유도 관절 기반 원격조작 인터페이스 우위 확인; IL(Demystifying, 2602.23408)·RL(Benchmarking, 2606.18594)에 이어 전신 원격조작 도메인에서 동일 방향 세 번째 수렴
- **이기종 공동훈련 데이터의 높은 이전성** — 그리퍼·손목 수준 사전학습 VLA가 전신 인간형 DoF로 잘 이전됨; 그리퍼 수준 사전학습 VLA를 바디·핸드 분리 액션 공간으로 확장 시 이전 비용이 낮을 가능성 간접 시사
- **공개 비교 기준선 확보** — GR00T N1.6·Ψ₀ 대비 우위 수치 공개, 코드·데이터·체크포인트 전체 오픈; 전신 인간형 VLA 비교군으로 즉시 활용 가능

### (d) 먼저 확인할 점

- **다지 손가락 미포함 범위** — 전신 상체+하체(로코모션+조작) 범위; 20+ DoF 다지 핸드 없음; 바디·핸드 분리 전문가와 직접 비교 시 DoF 구성 상이
- **분포 외 일반화 한계 미제시** — 새 객체·지시어 확장이 공동훈련으로 가능하나 OOD 환경에서의 실패 패턴 미제시
- **저렴한 점검** — 기존 그리퍼 수준 양팔 VLA 기준선에 상체 전 자유도 관절 기반 출력 추가 후 분리 전문가와 비교: D1 설계 검증의 저비용 출발점
