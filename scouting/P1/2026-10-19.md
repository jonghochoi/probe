## 🌱 논문 1 — 인접 분야 픽

**Data-Free Continual Learning for World Action Model with Rectified Generative Replay**
[arXiv:2610.18038](https://arxiv.org/abs/2610.18038) · Kaipeng Fang, Hangxu Liu, Chaojian Shi 외 5인 · adjacent field: continual learning / catastrophic forgetting · 코드 공개 예정

**점수 12/15** · R2 · N3 · M3 · Real3 · Repro1 — P2 2026-10-15 판정 유지

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 논문 요지

- WAM이 자기 롤아웃을 교정해 재생하는 데이터 무접근 연속 학습
- **문제** — 순차 미세조정한 월드 액션 모델(WAM)이 새 과제에는 잘 적응하나 이전 과제를 파국적으로 망각
  - 경험 재생(ER)은 이전 과제 시연 보관을 전제하나, 정책이 가중치만으로 배포되는 현실에서는 학습 데이터가 손에 없음
  - 저자들의 질문 — WAM이 자기 생성 능력만으로 ER만큼 효과적인 데이터 무접근 연속 학습을 이룰 수 있는가
- **기존 한계** — 연속 학습의 두 갈래를 모두 지적
  - 파라미터 정규화 — 로봇 정책에서는 유지 효과가 작음
  - 파라미터 격리 — 테스트 시 과제 식별자가 필요
  - ER — 가장 효과적이고 견고하나 이전 과제 시연의 누적 접근이 전제
  - 생성한 원시 롤아웃을 그대로 재생하면 ER에 크게 못 미침 — 저자들이 두 원인을 지목
- **핵심 방법** — 교정 생성 재생(R2-WAM), 지시문만으로 이전 과제 롤아웃을 WAM이 재생성하고 교정한 뒤 새 과제 데이터와 섞어 미세조정
  - 첫째 원인 — WAM이 과제 완료를 인식하지 못해 완료 뒤에도 무의미한 동작을 계속 생성
  - 완료 인식 적응형 절단 — 에이전트형 평가기가 완료 시점을 찾아 롤아웃을 잘라냄
  - 둘째 원인 — 개루프 생성에서 생성 액션이 생성 관측에서 점차 이탈
  - 흐름 기반 물리 일관성 필터 — URDF로 정해지는 로봇 전용 시뮬레이터에서 생성 액션을 실행한 광류와 생성 관측에서 추정한 광류의 일치도로 순위를 매겨 일관된 롤아웃만 유지
  - 기반 모델은 LingBot-VA
- **차별점** — 이전 과제 실데이터 없이 모델 자신의 생성 능력으로 재생 데이터를 만들고, 생성 액션과 관측의 불일치를 광류로 거름
  - 원문이 대비한 ER은 실데이터 재생이며 상한선 역할
- **핵심 기여** — 방법, 정량 결과, 진단
  - 데이터 무접근 상태에서 원시 재생성 롤아웃 재생만으로도 망각이 줄고, 교정하면 ER에 근접한다는 관찰
  - LIBERO 네 스위트(시뮬레이션) — 평균 성공률 92.7%, NBT 2.33으로 ER보다 평균 1.9%p 낮을 뿐이며, 원시 롤아웃 재생은 70.4%, 순차 미세조정 계열은 평균 11–15%
  - 실물 5개 과제 — 순차 미세조정 28.5%, R2-WAM 89.5%, ER 91.8%
  - 절단과 필터링 각각을 뺀 ablation에서 모두 성능 하락
  - 진단 — 망각은 역동역학 모델링에 집중되고 관측 예측 능력은 대체로 보존, 망각된 WAM도 그럴듯한 관측을 생성하나 액션은 실패
- **가치** — 학습 데이터가 공유되지 않는 배포 가중치만으로 로봇 정책을 이어 학습하는 경로 제시
  - 망각 점검 때 관측 생성이 아닌 액션 쪽을 확인해야 한다는 근거

### (c) 시사점

- 새 과제를 더할 때 생기는 망각을 데이터 없이 줄이는 인접 분야 근거
- **백본 미세조정과의 접점** — 분할한 π 계열 백본을 몸통·손 양쪽에서 미세조정하다 새 몸체나 손 과제를 더하면 겪을 망각과 같은 종류의 문제
  - 이전 과제 데이터를 보관하지 않고도 생성 재생으로 보전할 수 있다는 실물 수치(89.5% 대 ER 91.8%)
- **망각 위치** — 관측 생성은 남고 역동역학이 무너진다는 진단, 몸통·손 액션 전문가의 출력 쪽을 점검 지점으로 삼을 근거
  - 생성이 그럴듯해도 액션은 실패할 수 있어 망각 평가는 액션 성공률 기준 필요
- **적용 거리** — 인접 분야 결과이며 이질적 몸통·손 분할과 π 계열 백본에서 직접 시험한 것은 아님, 어느 한쪽을 택해 비교한 증거도 아님

### (d) 먼저 확인할 점

- **코드 공개 예정** — 재현성 진술에 게재 시 공개한다는 문구뿐
- **단일 백본** — LingBot-VA 기반 설정만 검증, 다른 WAM이나 VLA로의 일반화 미확인
- **ER 대비 격차** — 평균 1.9%p, 장기 과제 LIBERO-10에서 5.2%p로 최대, 저자도 관측-액션 불일치 누적을 한계로 명시
- **가소성 저하** — 실물에서 재생 방식이 순차 미세조정보다 가소성 4–5%p 손실, 과제 간 간섭은 미해결
- **이전 비용** — 재생성 롤아웃은 로봇 URDF 기반 시뮬레이터의 광류 비교에 의존하므로 다지 손 관절이 얽힌 몸통·손 롤아웃에서 필터가 성립하는지 별도 검증 필요
