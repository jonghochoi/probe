## 🥇 논문 1 — 우선순위 ★★

**FWBC-VLA: Force-Aware Whole-Body Compensation for Contact-Rich Loco-Manipulation**
[arXiv:2609.03889](https://arxiv.org/abs/2609.03889) · Yutian Zhang, Siyuan Ma, Liwen Yang, Yang Li, Ce Hao · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH) [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 핵심 기여

- HSR-Force 제안 — 별도 토크 센서 없이 사지 동역학으로 접촉력 추정; 추정된 접촉 정보를 접촉 토큰으로 변환해 VLA 행동 전문가에 직접 주입
- VLA+WBC 분리 합산 구조 — VLA가 조작 행동 출력, WBC가 보정 기저 행동 출력, 두 출력 합산으로 전신 접촉 일관성 유지
- 바퀴형 이족 로봇 실제 검증 — 화이트보드 닦기·도어 개폐(도어 클로저 포함) 과제에서 VLA 단독 대비 안정성·성공률 향상 확인

### (c) 시사점

- 정책 루프 내 접촉 토큰 주입 실증 — 별도 서브-정책율 루프 없이 정책 루프 내에서 접촉 정보를 조건화하는 설계의 실제 로봇 검증 사례 확보
- VLA+WBC 병렬 분리 패턴 — 조작 전문가(VLA)와 전신 보상 전문가(WBC) 병렬 분리 후 합산; 해부학적 body/hand 분리 설계와 상보적 비교 자료
- 합산 기반 복수 전문가 출력 — 서로 다른 출력 공간(VLA 행동·WBC 보정 행동) 합산 방식; 분리 헤드 출력 결합 설계의 구체적 구현 패턴

### (d) 먼저 확인할 점

- 코드·데이터 미공개 — 재현 불가, HSR-Force 추정기 구현 세부 절차 미확인
- 바퀴형 이족 전용 — 다지 손가락 관절 명령 전이 가능성 미검증; 손끝 접촉 해상도 제한
- WBC 보정 기여 분리 미제시 — VLA 단독 행동과 WBC 보정 기여 각각의 효과 분리 분석 없음; 전문가별 기여 비율 불명확

## 🥈 논문 2 — 우선순위 ★★

**VISTA: Visually Inferred Spatial ConTact Attention for Contact-Rich Manipulation**
[arXiv:2608.25872](https://arxiv.org/abs/2608.25872) · Jiayi Chen, Wenlong Dong, Yan Huang, Xianglin Chen · arXiv preprint · source: citation-graph(π0) · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- VDF(Visual Deformation Field) 제안 — 유연 그리퍼의 3D 변형량을 시각 접촉 대용 신호로 활용; 전용 촉각 센서 없이 접촉 상태·강도 추론
- 3단계 파이프라인 — Physics-Aware Encoding(물리 기반 변형 인코딩) + Energy Aggregation Denoising(에너지 집계 디노이징) + Deformation-Augmented Policy(변형 증강 정책)
- Cross-Scale Object Grasping·캡 열기·붓글씨 쓰기 3개 접촉 풍부 과제에서 3D Diffusion Policy 및 촉각 베이스라인 대비 성능 향상 확인

### (c) 시사점

- 시각 기반 접촉 신호 — 전용 촉각 하드웨어 없이 카메라 영상만으로 접촉 품질 추론; 입력 모달리티 구성 재검토 기준점 확보
- 정책 루프 내 접촉 신호 통합 — 외부 루프 없이 정책 내에서 변형 신호를 직접 조건화; 별도 고속 루프 없는 접촉 처리 경로의 시각 버전
- 도입 비용 낮음 — 기존 카메라 인프라 재사용 가능, 촉각 센서 추가 없이 접촉 인식 달성; 비용-성능 트레이드오프 기준점

### (d) 먼저 확인할 점

- 코드 미공개(프로젝트 페이지만 공개) — VDF 학습 세부 절차·데이터 요구량 미확인
- 유연 그리퍼 의존 — 경질 그리퍼·다지 손가락 구동기로의 변형 신호 적용 가능성 미검증
- 시뮬레이션-실제 변형 갭 — VDF 학습용 시뮬레이션 변형 모델과 실제 재료 특성 간 도메인 갭 분석 미제시

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- 의미적 의도 희소성 발견 — 의미적 의도는 조작 패턴 전환 시점에만 변화하며, 연속 제어는 물체-손 관계 진화에 주로 의존함을 규명
- 두 가지 파라미터-프리 시각 인터페이스 — 이미지-공간 의미 하이라이팅(이미지 수준 의도 주입) + 어텐션-프라이어 주입(피처 수준 의도 조건화); 추가 학습 파라미터 없음
- 장기 과제 3종·분포 외 변형에서 두 기반 정책 대비 의도 이해·과제 진행·종단 성공률 일관 향상 확인

### (c) 시사점

- 희소 상위 의도·밀집 하위 제어 시간 분리 패턴 — 조작 패턴 전환마다 의미 의도 갱신, 그 사이는 물체-손 관계로 연속 제어; 계층적 흐름의 실증 사례
- 추가 파라미터 없음 — 기존 정책 아키텍처 유지, 의도 신호만 주입; 낮은 통합 비용
- 두 기반 정책 호환 확인 — π0·RT-2 계열 모두 유효; 범용 계층 조건화 신호 설계 가능성 시사

### (d) 먼저 확인할 점

- 코드 미공개(프로젝트 페이지만 공개) — 의미 하이라이팅·어텐션 주입 구현 세부 절차 미확인
- 단일 암 조작 전용 — 양손·다지 구동기 전이 가능성 미검증
- 의도 전환 시점 자동 결정 미공개 — 조작 패턴 경계 감지 트리거 신호 설계 상세 불명확
