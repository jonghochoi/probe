## 🥇 논문 1 — 우선순위 ★★★

**G0.5: One Autoregressive Stream for Robot Reasoning and Action**
[arXiv:2608.11739](https://arxiv.org/abs/2608.11739) · Yicheng Liu et al. · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW) [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 핵심 기여

- **구조 비판**: VLM + 별도 플로우 매칭 액션 전문가 방식의 근본 한계 지적 — VLM이 맥락 인코더로 전락, 의사결정 주체 기능 상실
- **G0.5 단일 자기회귀 스트림**: 하나의 트랜스포머 디코더가 추론 토큰과 액션 토큰을 단일 목적함수 하에 동시 생성
- **세 가지 핵심 구성요소**:
  - 이종 로봇 액션을 공유 어휘로 매핑하는 학습 가능한 크로스-엠보디먼트 액션 토크나이저
  - 작업 분해·객체 그라운딩·액션 힌트를 액션 토큰과 인터리빙하는 네이티브 Chain-of-Thought 스트림
  - 비전 인코더를 통해 멀티초 히스토리를 주입하는 시각 메모리 모듈
- **7개 독립 평가 체계 SOTA**: R1lite·R1pro 실제 로봇 76.7% vs. π0.5 53.3% (+23.4pp), BEHAVIOR Challenge 50개 장기 태스크 31.4% vs. 26.3%, LIBERO 98.9%, RoboTwin 2.0 93.3%, SimplerEnv-Bridge 87.3%, DROID 제로샷 이전 82.5%

### (c) 시사점

- **액션 전문가 분리 구조의 이점 재검토 필요**: 단일 스트림이 7개 독립 벤치마크에서 π0.5·GR00T-N1.7 모두 제압 → Body/Hand 이중 헤드 분리 설계의 성능 우위를 직접 실증해야 하는 압력 증가
- **이종 액션 공간 공유 어휘화 방안 등장**: Body(손목 포즈)·Hand(손가락 관절) 명령을 단일 크로스-엠보디먼트 토크나이저로 통합하는 접근이 명시적 이중 헤드의 대안으로 부상
- **추론·액션 통합의 언어 조건부 정밀성**: Chain-of-Thought 추론이 액션 출력에 직접 영향 → 별도 액션 전문가 방식 대비 고수준 의미 지시 처리 성능 비교 필요

### (d) 먼저 확인할 점

- **다지 조작 수준 검증 없음**: 평가 태스크 대부분 이동 조작·pick-and-place 수준 → 손가락 관절 정밀 제어에서 이산 토큰화의 분해능 한계 미확인
- **대규모 사전학습 의존**: 대형 VLM + 대규모 로봇 데이터 사전학습 전제 → 소규모 재현 어려움
- **이산 토크나이저의 연속 정밀도 미공개**: 크로스-엠보디먼트 토크나이저가 연속 손가락 관절 명령 표현 시 quantization 오차 수준 미공개

## 🥈 논문 2 — 우선순위 ★★

**C2Dex: Contact-Consistent Reconstruction and Retargeting for Dexterous Manipulation from Monocular Video**
[arXiv:2608.07045](https://arxiv.org/abs/2608.07045) · Jie Ren et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- **C2Dex 프레임워크**: 단안(monocular) RGB 비디오에서 다지 로봇 조작 궤적을 자동 추출
- **핵심 표현 — 안정적 객체 측 접촉점**: 노이즈 있는 프레임별 HOI 관측치를 정준 객체 공간에서 집계 → 시간 일관성 있는 물리적 타당 접촉 정보 확보
- **이중 역할**: ① 물리적으로 타당한 손-물체 상호작용 궤적 재구성의 궤적 수준 제약, ② 라플라시안 상호작용 최적화로 손 형상 간 국소 기하학 보존하며 다지 로봇 손에 접촉 전이
- **잔류 RL 정제**: 시뮬레이션 내 잔류 강화학습(RL)으로 궤적 보완 후 실제 로봇 리플레이
- **결과**: DexYCB 57.78% vs. 기준선 17.78%, TACO 26.67% vs. 기준선 10.00% — 40pp 이상 우위

### (c) 시사점

- **손가락 관절 명령 학습 데이터 비용 절감**: 텔레오퍼레이션 없이 모노큘러 인간 영상에서 다지 궤적 자동 생성 → 손가락 수준 학습 데이터 확보 경로 다양화
- **접촉 기하 보존 전이 프레임워크 참조 가능**: 손-물체 접촉 기하를 시스템 경계에서 유지하는 방법론 → Body/Hand 분리 아키텍처에서 손가락 제어 학습 데이터 생성 파이프라인에 적용 검토
- **공개 벤치마크 성능 확인**: DexYCB·TACO 기준 기존 방법 대비 2–3배 향상 → 다지 궤적 추출 품질의 객관 비교 기반 확보

### (d) 먼저 확인할 점

- **리플레이 vs. 온라인 정책 학습 미검증**: 궤적 리플레이 성공률은 확인; VLA 학습 데이터로 사용 시 downstream 정책 성능 미확인
- **단안 재구성 오차 의존**: 손목 3D 위치 추정 오차가 손가락 관절 전이 정확도에 직접 영향 → RGBD 또는 마커 기반 방법 대비 정량 비교 필요
- **손 형상 의존**: 실험에 특정 다지 손 모델 사용 → 타 손 하드웨어로 이전 시 라플라시안 최적화 세팅 재조정 필요
