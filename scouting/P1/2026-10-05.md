## 🥇 논문 1

**LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion**
[arXiv:2609.28431](https://arxiv.org/abs/2609.28431) · Ning Chen, Yankai Fu, Junkai Zhao 외 3인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 11/15** · R2 · N2 · M3 · Real3 · Repro1 — abstract "The project website is available at https://ccdcs.github.io/LiMA_repo/"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- 장기 의도 생성과 고빈도 반응 정제를 비동기로 분리한 이중 시스템
- **느린 시스템**은 희소한 장기 시공간 의도 생성, **빠른 시스템**은 조밀한 고주파 동작 정제 담당
- 잠재 슈뢰딩거 브리지 결합(Latent Schrödinger Bridge Coupling)으로 희소 의도와 조밀 행동 궤적 정렬, 엔트로피 정규화 확률 수송으로 정제 정식화
- Cosmos-Policy 대비 추론 지연 45.8% 감소
- 양손 다지 조작 6과제 전체 성공률 70.8%, 하위 과제 평균 78.9%, 미학습 시나리오 성능 유지

### (c) 시사점

- 느린 계획과 빠른 정제를 시간 축으로 가른 두 번째 이음매 사례
- 지연 절감이 비동기 분리에서 나옴, 정책 주기 아래 루프의 필요 규모를 가늠할 근거
- 양손 다지 과제 6종 실로봇 검증이라 분리 이득의 전이 범위 확인 가능

### (d) 먼저 확인할 점

- 지연 감소 비교 대상이 Cosmos-Policy 하나뿐, 다른 비동기 기준선과의 차이 미확인
- 느린 시스템 갱신 주기와 빠른 시스템 주기의 구체 수치 확인 필요
- 접촉 순간 반응을 분리 구조가 직접 개선하는지, 전체 성공률만 오르는지 확인 필요

## 🥈 논문 2

**Toward Real-Time VLAs: Stage-Aware Two-Step Flow Denoising and System-Level Evaluation**
[arXiv:2609.39822](https://arxiv.org/abs/2609.39822) · Di Wu, Rongtian Shen, Ping Liu 외 3인 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 11/15** · R2 · N2 · M3 · Real2 · Repro2 — arXiv comment "Code: https://github.com/MagiclabRobotics/Inference"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- VLA 추론 주기와 로봇 실행 주기 사이 시간 격차의 종단 지연 실측
- 플로 매칭(Flow Matching) 반복 디노이징이 추론 비용의 큰 몫, 로봇 측 지연은 인지 획득·통신 스케줄링·물리 응답에서 발생
- 2단계 비균일 디노이징으로 10단계를 2단계로 축소, 모델 추론 61.557ms에서 21.956ms로 단축
- 추론·행동 발행·로봇 제어 주기를 독립시킨 분산 실시간 프레임워크, 행동 출처 로깅 포함
- π0.5 기준 장기 의류 접기 과제에서 실행 방식 6종 비교, Legato가 학습 기반 중 최고, Temporal Smoothing이 비학습 중 최고

### (c) 시사점

- 정책 주기 루프가 감당할 지연의 크기를 실측으로 제시
- 인지·통신·물리 응답 지연이 모델 추론과 별개 항목임을 분리 제시
- 주기를 독립시킨 구조의 실행 방식별 비교표가 공개 기준점 역할

### (d) 먼저 확인할 점

- 실로봇 검증이 의류 접기 한 과제, 접촉 집약적 손 조작과의 거리 확인 필요
- 2단계 디노이징의 성능 저하가 소폭이라는 서술의 정량 수치 확인 필요
- 다지 손 제어 주기에서 같은 지연 분해가 성립하는지 미검증

## 🥉 논문 3

**TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model**
[arXiv:2610.00638](https://arxiv.org/abs/2610.00638) · Enyi Wang, Mingxin Wang, Quan Shi 외 3인 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지·공개 신호 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D9ZP](https://img.shields.io/badge/D9ZP-d97706.svg)](#ref-D9ZP)

### (b) 핵심 기여

- 미래 촉각 픽셀 복원 대신 암묵 촉각 동역학을 예측하는 이종 시각-촉각 월드 액션 모델
- 시각 전문가와 암묵 촉각 동역학 전문가가 서로 다른 목표 공간에서 예측하고 joint attention으로 상호작용
- 촉각 전문가가 한 번의 순전파로 여러 시점의 미래 표현과 변화량 예측
- UniVTAC 평균 성공률 81.5%, 제공된 시연만 사용
- 실로봇 5과제 평균 71.0%, 소규모 사전학습 후 85.0%

### (c) 시사점

- 촉각 전문가를 시각 전문가 곁에 둔 분리 구조의 이득 근거
- 전문가 간 joint attention이 단일 FiLM 점을 넘는 정보 공유 형태의 사례
- 촉각 픽셀 복원보다 동역학 표현 예측이 배치 변동에 강하다는 ablation 근거

### (d) 먼저 확인할 점

- 촉각 경로와 픽셀 복원 대안의 ablation 폭 확인 필요
- 공개 신호 없음, 재현 경로 불투명
- 몸통·손 분리가 아닌 시각·촉각 분리라 해부학적 이음매로의 전이는 별도 검증 필요
