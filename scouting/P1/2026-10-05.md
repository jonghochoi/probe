## 🥇 논문 1

**Toward Real-Time VLAs: Stage-Aware Two-Step Flow Denoising and System-Level Evaluation**
[arXiv:2609.39822](https://arxiv.org/abs/2609.39822) · Di Wu 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 11/15** · R2 · N2 · M3 · Real2 · Repro2 — arXiv comment "Code: https://github.com/MagiclabRobotics/Inference"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 논문 요지

- 추론 지연 분해와 2단계 비균등 디노이징 제안
- **문제** — VLA의 저속 추론과 고속 로봇 제어 사이의 시간 척도 불일치
  - 액션 청크 실행에서 새 청크는 추론 시작 시점 관측에 조건화되고, 로봇은 생성 중에도 과거 관측 기반 액션을 계속 실행
  - 청크 간 불연속과 청크 내 불일치가 함께 발생
  - 카메라 노출·판독, 고유수용감각 피드백, 통신·스케줄링, 물리 응답이 추가 지연으로 겹침
- **기존 한계** — 기존 실시간 VLA 연구가 세 수준에서 따로 진행되어 비교 기준 부재
  - 모델 측 — 증류, 샘플링 단계 축소, 스플라인 제어점 같은 저차원 액션 표현
  - 실행 측 — 실행된 액션 접두부 조건화, 최근 관측 기반 액션 수정, 미래 로봇 상태 예측
  - 시스템 측 — 센서 타이밍 보정, 다중 모달 동기화, 궤적 리타이밍
  - 연구마다 베이스 모델·플랫폼·과제·추론 하드웨어가 달라 결과 비교 어려움
  - Flow Matching 생성 과정의 단계별 역할 미규명
  - 모델 추론·지각·로봇 응답을 아우르는 종단 지연 측정 부재
- **핵심 방법** — 지연 측정, 비균등 디노이징, 분산 실행 프레임워크의 세 요소
  - $\pi_{0.5}$ 기준으로 모델 측과 로봇 측 지연을 함께 측정
  - 속도장의 크기·방향이 초기 적분에서 안정적이고 종단 단계에서 방향 보정이 커지는 단계 이질성 분석
  - 적분 시간 1 → 0.3 → 0 의 2단계 구성 — 긴 구간은 표준 Flow, 짧은 종단 구간은 SnapFlow 정제
  - 추론·액션 발행·로봇 제어 속도를 독립 설정하는 스레드 분리형 프레임워크
- **차별점** — 개별 기법이 아니라 같은 베이스 정책·학습 데이터·로봇 플랫폼 위에서 여러 실행 방법을 한 틀로 비교
  - 지연 원천별 측정과 실행 방법 비교를 한 프레임워크에서 수행
- **핵심 기여** — 측정 절차, 샘플링 전략, 오픈소스 프레임워크
  - 함수 평가 횟수(NFE) 10에서 2로 감소, 모델 추론 시간 61.557ms에서 21.956ms로 단축(2.804배)
  - Naive Asynchronous, Temporal Smoothing, Inference-time RTC, Training-time RTC, Legato, VLASH 6종을 양팔 티셔츠 접기에서 비교
  - 방법당 30회, 총 180회 실물 시행 — Agilex Piper 2대 양팔 플랫폼, 3종 티셔츠
  - 학습 기반 중 Legato, 비학습 중 Temporal Smoothing이 종합 최상
  - 2단계 디노이징 결합 시 추론 속도 향상 1.676배와 2.804배, 과제 성능은 소폭 저하
- **가치** — 실시간 VLA 성능이 모델 계산과 시스템 지연에 함께 묶임을 보인 비교 가능한 기준점

### (c) 시사점

- 정책 루프 속도 상한을 모델·시스템 지연으로 분해한 수치
- 모델 추론 21.956ms는 단순 환산 시 약 45Hz 상당, 시스템 지연은 별도 항목으로 남음
- 정책 루프가 접촉에 반응하는 한계의 계측 기준으로 재사용 가능
- 추론·액션 발행·제어 속도 독립 설정 구조는 속도 분리 설계의 공개 구현 참고
- 비균등 디노이징은 슬라이스한 액션 전문가에도 적용 시도 가능

### (d) 먼저 확인할 점

- 실물 결과가 양팔 티셔츠 접기 1과제뿐이며 손가락 수준 접촉 과제 없음
- 베이스 정책이 $\pi_{0.5}$이므로 슬라이스한 액션 전문가 구조에서 2단계 디노이징의 품질 저하 재확인 필요
- 2단계 디노이징 결합 시 과제 성능 소폭 저하, 저하 폭이 접촉 집약적 과제에서 커지는지 미확인
- 데이터·체크포인트 공개 여부 진술 없음, 재현은 코드 저장소 기준

## 🥈 논문 2

**TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model**
[arXiv:2610.00638](https://arxiv.org/abs/2610.00638) · Enyi Wang 외 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 논문 요지

- 촉각 동역학을 픽셀 복원 없이 예측하는 이종 WAM
- **문제** — 촉각 세계 모델이 무엇을 예측해야 하는가
  - 접촉 위치·힘의 작은 변화가 촉각 이미지를 크게 바꾸지만 접촉 진행 자체는 예측 가능
  - 전문가 시연은 올바른 접촉 근처 촉각 이미지만 포함, 폐루프 오차로 분포 이탈 발생
- **기존 한계** — 기존 촉각 세계 모델이 영상 생성 파이프라인을 그대로 재사용
  - 같은 VAE로 카메라·촉각 프레임을 인코딩하고 미래 촉각 잠재를 반복 디노이징
  - 추론 속도가 느리고 예측이 픽셀 복원에 묶임
  - VTLA 계열은 현재 촉각 상태만 이해하고 변화는 예측하지 못해 촉각 피드백에 반응적
  - $N_{0}$-VTLA는 동결 DINOv2 특징 공간에서 단일 시점의 순변화만 예측, DINOv2는 정적 자연 이미지로 학습되어 촉각 진행을 포착하도록 최적화되지 않음
- **핵심 방법** — 분리된 파라미터와 목표 공간을 갖는 시각 전문가와 촉각 전문가
  - TacRep — 촉각 클립에 대한 마스크 시공간 예측으로 학습하고 관계 구조 증류로 정규화한 동역학 인지 목표 공간
  - 시각 전문가는 미래 시각 잠재, Implicit Tactile Dynamics Expert는 TacRep 공간의 미래 표현과 그 변화를 여러 시점에서 예측
  - 두 전문가를 레이어마다 joint attention으로 결합해 액션 전문가가 양쪽을 사용
  - 촉각 전문가는 반복 디노이징 없이 한 번의 순전파
  - 읽기 전용 Tactile Understanding Memory가 현재 촉각 상태 공급, 단계별 학습으로 촉각 모듈 통합
- **차별점** — 미래 촉각 관측을 복원하지 않고 다중 시점 표현과 변화량을 예측
  - 최종 상태가 비슷한 압착·미끄러짐에서 순변화 하나가 중간 접촉 사건을 가리는 문제를 다중 시점 예측으로 회피
- **핵심 기여** — 모델, 표현 공간, 시뮬레이션·실물 결과
  - UniVTAC에서 제공 시연만으로 평균 성공률 81.5%, 대규모 시각·촉각 사전학습을 쓰는 $N_{0}$-VTLA·$N_{0}$-TWAM과 경쟁
  - $N_{0}$-TWAM은 파라미터가 약 2배
  - 두 촉각 경로와 TacRep이 픽셀 복원·정적 대안보다 낫다는 ablation
  - 실물 5과제에서 과제별 시연만으로 평균 71.0%, 촉각 정책 FTP-1보다 16포인트 높음
  - 실물 시각·촉각 궤적 약 6,000개의 소규모 사전학습으로 85.0%
- **가치** — 촉각 예측 목표를 픽셀에서 동역학 표현으로 옮겨 추론 비용과 분포 이탈 취약성을 함께 낮출 수 있다는 근거

### (c) 시사점

- 촉각 전문가를 시각 전문가 옆에 별도 목표 공간으로 두는 설계의 실물 근거
- 해부학적 분리가 아닌 모달리티 분리 사례로, 분리 이득의 이전 가능성을 보는 증거 풀
- 한 번의 순전파 예측은 정책 루프 안에서 촉각 반응을 얻는 저비용 경로의 후보
- 다중 시점 변화 예측은 접촉 사건 포착의 설계 힌트
- 손가락 단위가 아닌 촉각 이미지 입력 전제라 손 전문가 입력으로 쓰려면 재설계 필요

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 공개 신호 없음, 재현은 부록 기술에 의존
- TacRep과 촉각 전문가가 단일 유형 비전 기반 촉각 센서 전제, 힘·택셀 배열 등 비이미지 모달리티 일반화는 저자 한계로 명시
- UniVTAC 81.5%는 시뮬레이션 벤치마크 결과이며 실물은 5과제 평균 71.0%
- 분리 축이 시각 대 촉각이라 몸통·손 분해에 그대로 대응하지 않음
