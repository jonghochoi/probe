## 🥇 논문 1

**FP2: Equipping Robotic Foundation Models with Force Control**
[arXiv:2609.37433](https://arxiv.org/abs/2609.37433) · Hongjie Fang 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 11/15** · R3 · N3 · M2 · Real2 · Repro1 — 초록 "Project website: http://force-policy.github.io/fp2"

### (a) 관련 Pillar / Decision
[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 논문 요지

- 파운데이션 정책 옆에 고주파 힘 제어 정책을 분리해 부착
- **문제** — 파운데이션 모델이 과제 수준 동작은 내도 접촉 집약적 상호작용은 불안정
  - 기하·마찰·컴플라이언스의 작은 불확실성에도 과도한 힘, 불안정 접촉, 끼임 발생
  - 과제 수준 동작 생성 능력이 올라갈수록 물리 상호작용이 남은 병목
- **기존 한계** — 힘을 모델 입력 모달리티로 넣는 force-aware VLA 계열
  - 힘은 대규모 파운데이션 모델 사전학습에 없는 모달리티
  - 새 모달리티가 사전학습 관측 인터페이스를 바꾸고, 기존 시각운동 표현과의 정렬을 하류 데이터로 학습해야 함
- **핵심 방법** — 동작 생성과 상호작용 조절을 나누는 action-regulation 분해
  - 과제 적응이 끝난 파운데이션 정책은 고정, 과제 수준 행동 생성 담당
  - 별도 힘 제어 정책이 구조화된 힘 제어 파라미터만 예측
  - 파운데이션 정책의 문맥 토큰열을 자기지도로 압축해 wrench·고유수용감각 이력과 결합
  - 힘 정보는 하류 힘 제어 정책 학습 때만 도입
- **차별점** — 힘 제어를 파운데이션 모델 안에서 학습하지 않고 동작 재생성 없이 조절만 분리
  - 기존 Force Policy의 힘 제어 정식화 위에서 하류 동작 재생성을 중복하지 않음
- **핵심 기여** — 4개 파운데이션 모델 백본 × 실물 접촉 집약 4과제
  - 해당 파운데이션 정책 대비 과제 성능 향상, 정규화 힘 오차는 대체로 감소
  - 과제별 힘 제어 정책 및 force-aware VLA와 비교해 대등 이상
  - ablation — 정책 문맥과 물리 피드백이 상호 보완, 동작 생성 보존이 효율과 새 물체 일반화를 개선
  - 실패 분석 — 상호작용 관련 실패를 주로 억제, 과제 수준 동작 오류는 범위 밖
  - 데이터·체크포인트·코드·평가 영상 공개 예정이라고 명시
- **가치** — 기존 모델의 센싱·행동 인터페이스를 바꾸지 않고 힘 제어를 얹는 실용 경로 제시

### (c) 시사점

- 느린 정책 아래 빠른 접촉 루프를 두는 두 번째 이음매의 직접 사례
- 백본 4종에서 같은 이득이 나와 특정 정책에 묶이지 않는 분해로 읽힘
- 정책 문맥을 힘 루프에 조건으로 넘기는 경로가 별도 접촉 루프의 입력 설계 참고점
- 동작 생성 보존이 새 물체 일반화에 기여한다는 ablation은 백본을 건드리지 않는 분할의 근거

### (d) 먼저 확인할 점

- 초록에 실물 수치가 없어 본문 표에서 과제별 성공률과 힘 오차 확인 필요
- 힘 제어 루프의 실제 제어 주기가 초록·서론에 명시되지 않음
- 파운데이션 정책의 동작이 틀리면 복구 불가라는 저자 한계, 접촉 전 거동은 범위 밖
- 힘 제어 정책이 과제별 학습이라 다과제 재사용은 미검증
- 저장소 URL 없이 프로젝트 페이지만 확인됨

## 🥈 논문 2

**LiMA: Bridging Long-term Imagination to Real-time Dexterous Manipulation via Asynchronous Diffusion**
[arXiv:2609.28431](https://arxiv.org/abs/2609.28431) · Ning Chen 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 11/15** · R2 · N2 · M3 · Real3 · Repro1 — P3 2026-09-28 판정 유지

### (a) 관련 Pillar / Decision
[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ) [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 논문 요지

- 느린 의도 생성과 빠른 동작 정제를 비동기로 나눈 이중 시스템
- **문제** — 다지 조작은 장기 예측과 빠른 반응 제어를 함께 요구
  - 모델의 의도가 빠르게 변하는 접촉 상황에 적응하지 못하는 시간적 불일치
- **기존 한계** — VLA와 월드-액션 모델(WAM) 두 갈래
  - VLA — 물리 세계의 연속적 변화를 예측·대응하는 명시적 메커니즘 부재
  - 역동역학형 WAM(IDM) — 영상 모델이 미래 관측을 상상한 뒤 행동을 조건화, 순차 조건화라 시각 상상과 행동 예측의 결합이 느슨
  - 통합형 WAM — 영상·행동을 한 디노이징으로 생성하나 잠재 특징 공간이 길어 추론 지연이 커서 고주파 반응 요건 미충족
- **핵심 방법** — 서로 다른 시간 스케일을 맡는 비동기 이중 시스템
  - 느린 시스템 — 희소한 장기 시공간 의도 생성
  - 빠른 시스템 — 조밀한 고주파 동작 정제
  - Latent Schrödinger Bridge Coupling — 추상 의도에서 모터 명령으로의 전이를 연속 확률 수송 과정으로 모델링
  - Spatiotemporal Adaptive Modulation — 장기 예측을 실시간 물리 관측에 접지
- **차별점** — 통합형 WAM의 잠재 수준 결합은 유지하면서 의도 생성과 반응 실행을 비동기로 분리
- **핵심 기여** — 구조, 결합 메커니즘, 평가의 세 항목
  - 장기 상상과 반응 실행을 분리한 비동기 이중 시스템 프레임워크
  - 의도와 행동의 특징 정렬을 위한 잠재 슈뢰딩거 브리지와 적응 변조
  - 양손 다지 조작 6과제 실물 평가, 전체 성공률 70.8%, 평균 하위과제 성공률 78.9%, 미학습 시나리오에서도 성능 유지
  - Cosmos-Policy 대비 추론 지연 45.8% 감소
  - 기준선 — VLA 2종(Gr00T N1.6, InternVLA-a1)과 WAM 2종(VPP, Cosmos-Policy), 과제당 20회 시행
- **가치** — 생성형 장기 예측을 실시간 다지 제어에 쓸 수 있는 지연 수준으로 낮추는 설계 제시

### (c) 시사점

- 속도 축 분리가 지연과 성공률을 함께 개선한다는 실물 정량 증거
- 느린 의도 층과 빠른 정제 층의 결합 방식이 두 전문가 사이 정보 전달 설계의 참고점
- 몸·손 분해가 아니라 시간 스케일 분해라서 해부학적 이음매의 직접 근거는 아님

### (d) 먼저 확인할 점

- 저자 한계 — 심한 가림과 낮은 시각 변이에서 성능 저하, 촉각 통합은 후속 과제
- 지연은 배포용 최적화 없는 일반 구현 기준 측정이라 절대 수치는 환경 의존
- 정제 시스템의 실제 제어 주기와 접촉 반응 성능을 따로 분리한 실험인지 확인 필요
- 저장소 URL 없이 프로젝트 페이지만 확인됨

## 🥉 논문 3

**IronMind: Scaling Humanoid Dexterous Manipulation via Camera-Space Ego-Centric Pretraining**
[arXiv:2609.39403](https://arxiv.org/abs/2609.39403) · Huimin Pan 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 10/15** · R2 · N2 · M2 · Real3 · Repro1 — arXiv comment "https://xpeng-robotics.github.io/ironmind/"

### (a) 관련 Pillar / Decision
[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX)

### (b) 논문 요지

- 카메라 공간 액션 표현으로 에고센트릭 영상을 사전학습에 직결
- **문제** — 휴머노이드 다지 조작은 로봇 시연이 느리고 비싸 확장이 막힘
  - 에고센트릭 인간 영상은 저비용 데이터지만 두 간극이 존재
  - 임바디먼트 간극 — 사람 손과 로봇 말단장치의 기구학·관절 수 차이
  - 품질 간극 — 손 추정 잡음, 약하게 정렬된 텍스트, 조작 없는 구간
- **기존 한계** — 인간 영상을 로봇 관절 공간으로 리타게팅하는 방식
  - 저가 에고센트릭 기록은 몸통 기구학이 없어 강체 척추 같은 가정이 필요
  - 관측되지 않은 몸통 기구학에 대한 가정이 라벨 잡음으로 유입
- **핵심 방법** — 카메라 공간 표현과 데이터 정제, 듀얼 전문가 구조
  - SLAM 카메라 운동과 카메라 기준 손 운동으로 인간·보정된 로봇 궤적을 같은 표현으로 기술, 액션 차원은 의미 단위로 정렬
  - 규칙 기반 필터링, 원자 과제 재주석, 프레임별 품질 가중의 다단계 정제
  - Mixture-of-Transformers — 시각-언어 전문가와 플로우 매칭 액션 전문가를 공유 어텐션으로 연결
  - 선택적 월드 프라이어 — 동결 영상 생성 모델로 미래 프레임을 예측, 추론 시에는 학습된 질의 토큰만 잔존
- **차별점** — 인간-로봇 신체 리타게팅을 건너뛰고 영상의 고유 참조 공간에서 바로 학습
- **핵심 기여** — 4개 항목
  - 총 10,000시간 이상 에고센트릭 인간 영상과 이종 로봇 데이터의 사전학습 레시피, 검증 손실이 데이터 예산에 로그-선형 감소
  - 월드 프라이어 지도를 선택적으로 얹는 듀얼 전문가 VLA
  - 오픈루프 접근·파지 지표, 정책-인-더-루프 롤아웃, 실물 평가를 묶은 평가 체계
  - 실물 휴머노이드 6개 미학습 과제에서 10,000시간 모델 성공률 55.0%, 5,000시간 이하 예산은 최대 11.7%, 사전학습 없음 5.0%
  - 같은 예산에서 카메라 공간 표현 55.0%, 몸통 좌표계 기준선 26.7%
- **가치** — 몸통 기구학 없는 대규모 에고센트릭 영상을 휴머노이드 사전학습 자원으로 쓰는 확장 경로 제시

### (c) 시사점

- 액션 공간 선택이 사전학습 확장성을 좌우한다는 같은 예산 비교 증거
- 카메라 공간 표현이 몸통 좌표계보다 높아 말단장치 기준 출력 공간 논거에 반대 방향의 비교점
- 시각-언어와 액션을 나눈 이중 전문가 구조라 분할 설계의 공개 참고 사례

### (d) 먼저 확인할 점

- 저자 한계 — 실물 평가가 1개 임바디먼트, 6개 OOD 과제, 과제당 10회 시행
- 긴 호흡·넓은 접촉 집약 과제 미검증, 카메라 외부 보정과 실로봇 후학습은 여전히 필요
- 비교가 InternVLA-A1.5 이외로 확장되지 않아 타 모델 대비 위치는 미확인
- 저장소 URL 없이 프로젝트 페이지만 확인됨
