## 🥇 논문 1 — 우선순위 ★★

**AdvDex: Learning Dexterous Manipulation from Human Demonstrations via Joint-Aligned Actions and Adversarial Learning**
[arXiv:2608.14028](https://arxiv.org/abs/2608.14028) · et al. · arXiv preprint · source: citation-graph (π0) · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **연구 문제** — 다지 조작 스케일 확장의 두 가지 병목: ① 로봇 데모 수집 비용, ② 이종 이보디먼트 간 액션 공간 불일치로 인한 시각 표현의 이보디먼트 특화 오염
- **JAAS(Joint-Aligned Action Space)** — SE(3) 손목 포즈(바디 출력) + 15개 손가락 관절(핸드 출력) 표준 액션 표현: 인간 손·다지 로봇 손·병렬 그리퍼를 동일 공간으로 기능적 정렬
- **OmniShare 데이터셋** — 텔레오퍼레이션 없이 고품질 운동학 감독 + 촉각 측정을 제공하는 대규모 인간 조작 데모 멀티모달 데이터셋 신규 구축
- **도메인 적대 학습** — 이보디먼트 특화 외형 정보를 시각 표현에서 제거, 태스크 관련 시각 단서만 보존
- **결과** — 핸드 액션 예측 및 실세계 다지 조작 개선; 미지 객체·환경 일반화; zero-shot 인간→로봇 스킬 이전; 데이터 효율적 few-shot 적응 확인

### (c) 시사점

- **D2·D3 결합 정규화 실증 기준점** — JAAS의 SE(3) 손목(D2 v1과 일치) + 15 손가락 관절(D3 v1과 일치)이 실세계 다지 조작에서 유효; 분리 액션 공간의 cross-embodiment 정렬 최초 대규모 실증
- **Body/Hand 분리 설계의 이전 가능성 구체화** — 인간·로봇·그리퍼 세 이보디먼트를 단일 JAAS로 통합 → 분리 헤드의 cross-embodiment 일반화 경로 확인
- **OmniShare 참조 가능성** — 텔레오퍼레이션 없이 다지 조작 데이터 확보 → Hand 헤드 학습 데이터 비용 절감 방안 탐색 시 참조 가능

### (d) 먼저 확인할 점

- **코드·데이터셋 미공개** — OmniShare·JAAS 구현 공개 전; 재현 불가
- **15 손가락 관절의 실제 제어 분해능** — SE(3)+15 관절 정규화가 특정 다지 로봇 하드웨어에서 접촉력·정밀 조작에 미치는 영향 미공개
- **VLA 백본 통합 방법 미명시** — JAAS 기반 정책을 π0 등 기존 VLA 백본과 통합하는 방법 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**StructRL: Structured Action-Space Exploration for Flow-Based VLAs**
[arXiv:2608.15139](https://arxiv.org/abs/2608.15139) · et al. · arXiv preprint · source: citation-graph (π0) · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **현상 발견 — Structured Noise Dilution** — 플로우 중간 시점에 구조적 노이즈 삽입 시 이후 디노이징 단계가 노이즈를 희석; 탐색 신호가 실행 전에 약화되는 구조적 병목 최초 분석
- **StructRL 3가지 연결 설계** — ① 결정론적 ODE 디코더, ② 액션 공간에 직접 삽입된 구조적 노이즈(액션 그룹별 상이한 스케일), ③ last-step replay(중간 디노이징 상태에 우도 할당 회피)
- **핵심 속성** — 시간적으로 부드럽고 액션 그룹별 차별 스케일 적용 → 탐색 신호가 실행 액션에 직접 연결
- **검증** — 세 가지 flow-based VLA 모델 + 복수 시뮬레이션 벤치마크 + 두 가지 실세계 태스크에서 선행 in-chain 기준선 대비 탐색 효율·OOD 성능 향상

### (c) 시사점

- **액션 그룹별 이종 처리의 탐색 이점** — 바디/핸드 이중 헤드에서 두 액션 그룹의 노이즈 스케일이 다를 때 탐색 효율 향상 → D1 분리 헤드 설계의 RL 적응 단계에서 그룹별 차별 스케일 설계 참조 가능
- **flow-based VLA RL 적응 전략** — 플로우 디코더 ODE 결정론화 + 직접 액션 공간 탐색 조합 → Body/Hand 분리 스택의 RL 파인튜닝 시 적용 검토
- **[StructRL 프로젝트 페이지](https://flyfaerss.github.io/structrl/) 공개** — 코드 공개 시 구체적 구현 참조 가능

### (d) 먼저 확인할 점

- **액션 그룹 정의 미명시** — "action groups"의 구체적 정의(바디·핸드 vs. 조인트 집합) 논문 본문에서 확인 필요
- **다지 손가락 수준 적용 미검증** — 실세계 2개 태스크가 손가락 관절 수준 정밀 제어를 포함하는지 미확인; 손가락 관절 수준 구조적 탐색 효과 별도 확인 필요
- **코드 공개 전** — 세 VLA 모델 중 어느 것에서 결과가 가장 강력한지 재현 불가

## 🥉 논문 3 — 우선순위 ★★

**HAF: Adapting Generalist VLAs to Humanoid Whole-Body Loco-manipulation via Hierarchical Action Flow and Spectral Latent RL**
[arXiv:2608.16837](https://arxiv.org/abs/2608.16837) · et al. · arXiv preprint · source: citation-graph (π0) · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **문제** — 단일 단계 VLA 아키텍처는 고차원 인간형 전신 조작(보행·허리·양팔 협조)에서 비일관적 전신 액션 생성; BC 사후 RL 파인튜닝은 대형 VLA 백본 갱신에 과도한 계산 요구
- **HAF-VLA** — 사전 학습된 flow-matching VLA 기반 계층적 액션 흐름 생성기: 전신 액션 디노이징을 3단계(보행·허리·양팔) 순차 처리; 단계 임베딩 + cross-stage KV 캐시로 단계 간 운동학 의존성 보존
- **HAF-Steer** — 플로우 매칭 역전환성과 DCT 기반 차원 축소로 RL 최적화를 소형 노이즈 부분공간으로 제한; 대형 VLA 백본 갱신 없이 정규화된 SAC 정책 학습
- **결과** — 7개 실세계 인간형 로봇 loco-manipulation 태스크에서 단일 단계 VLA 기준선 대비 전신 협조·태스크 성능 향상

### (c) 시사점

- **D1·D6 계층 흐름의 인간형 전신 스케일 검증** — 3단계 순차 분할(locomotion→waist→arms)이 7개 실세계 태스크에서 단일 단계 대비 우위 → Body/Hand 분리 헤드 설계의 계층 흐름 정당성 강화
- **Spectral Latent RL의 대형 VLA 호환성** — 백본 동결 + 소형 노이즈 부분공간 RL 조합 → Body/Hand 이중 헤드의 RL 정제 시 계산 효율 방안 참조
- **cross-stage KV 캐시의 정보 공유 방식** — 단계 간 운동학 의존성 보존 → D4(Body↔Hand 정보 공유) 설계의 토큰 기반 대안으로 참조 가능

### (d) 먼저 확인할 점

- **손가락 수준 다지 제어 미포함** — "전신 loco-manipulation"은 보행+팔 수준; 손가락 관절 명령(D3) 포함 여부 별도 확인 필요
- **HAF-Steer RL 소형 부분공간의 표현 한계** — DCT 기반 차원 축소가 바디·핸드 이종 노이즈 구조를 충분히 포착하는지 미확인
- **프로젝트 페이지만 공개** — 코드·학습 레시피 미공개; 재현 불가
