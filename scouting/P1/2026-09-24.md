## 🥇 논문 1 — 우선순위 ★★★

**Dexterous Robot Manipulation from Human Demonstrations via Contact-Anchored Retargeting and Residual Policy Learning**
[arXiv:2609.24093](https://arxiv.org/abs/2609.24093) · Zihao Yang, Chengyuan Liu, Yu Zhou, Runze Lv et al. · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- **접촉 구조(contact structure)** 기반 재타겟팅 — 손 형상 변경 시 보존되는 것은 관절 모션이 아니라 어떤 손가락 영역이 어느 객체 위치에 어떤 순서로 닿는지임을 전제로, 모폴로지 독립 재타겟팅 목적함수 설계
- **3단계 파이프라인**: 시뮬 MANO 손으로 접촉·힘 복원 → 접촉 앵커 기반 재타겟팅 → 잔차 RL 정책으로 실제 로봇 액추에이션 적응; 단일 공유 잔차 정책이 다양한 시연 전체를 커버
- 단일 손 25,454개 궤적 성공률 7.3% → 59.3%, 양손 25개 태스크 16.0% → 62.4%; 4종 형태 다른 로봇 핸드에 이전 +62.4 pp; 실제 로봇 접촉 집약 양손 태스크 4종(실제 로봇 훈련 데이터 없이)
- 코드 공개: [github.com/DexGEM-Lab/real2sim2real](https://github.com/DexGEM-Lab/real2sim2real)

### (c) 시사점

- 접촉 구조가 4종 로봇 핸드에 모폴로지 독립적으로 이전 가능함을 실증 — 손 출력 공간에서 관절 모션보다 접촉 구조가 핵심 이전 단위임을 뒷받침하는 최초 수준 정량 데이터 확보
- 잔차 RL이 인간 시연 기반 동작의 물리적 일관성 결여를 단일 공유 정책으로 복원 — 기반 정책 위 잔차 전문가 계층 구조의 일반성 실증
- 실제 로봇 훈련 데이터 없이 다종 핸드 이전 성공 → 손 전문가 모듈의 하드웨어 독립성 방향 데이터

### (d) 먼저 확인할 점

- 3단계 파이프라인 전체가 오프라인 처리 — 실시간 정책 루프 통합 경로 확인 필요
- 단일 손 59.3%: 절대 수치 제한적 — 인핸드 재배향 등 정밀 접촉 집약 태스크 적용 범위 확인 필요
- 잔차 RL이 시뮬 기반만으로 4종 핸드에 이전 가능한 sim-to-real 갭 한계 및 실패 모드 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**GALA: Geometry-Aware Latent Action Modeling for Vision-Language-Action Model Pretraining across Embodiments**
[arXiv:2609.21948](https://arxiv.org/abs/2609.21948) · Yichen Liu, Puzhen Yuan, Xiang Zhu, Yanjiang Guo, Jianyu Chen · arXiv preprint · source: citation-graph(XL-VLA) · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- **UEMR(Unified End-effector Motion Representation)** — 3D 포인트 클라우드 기반 손끝 기하 모션을 시각 잠재 행동과 결합; 단순 포인트 클라우드 결합 시 교차 구현 의미 공유가 손상되는 문제 해결
- 장면 수준 시각 잠재 행동 + 손끝 기하 잠재 행동의 이중 표현으로 VLA 사전학습 — 행동 레이블 없는 자아 중심 인간 영상에서 손가락 수준 아티큘레이션 포착 가능
- RoboCasa-GR1 68.3% + 실세계 75.5% 성공률; 교차 구현 검색·손끝 탐침 평가에서 기존 LAM 대비 일관 우위
- 프로젝트 페이지: [puzhenyuan.github.io/GALA-website](https://puzhenyuan.github.io/GALA-website/)

### (c) 시사점

- UEMR이 장면 수준 시각 잠재 행동만으로는 포착 불가능한 손끝 기하 운동을 담당함을 실증 — 손 출력 공간에서 기하학적 잠재 표현 경유 경로의 유효성 데이터 추가
- 교차 구현 이전: 인간 손→다지 로봇 핸드 이전이 UEMR 표준화로 가능함을 실증 — 손 전문가 구현 독립성 확보 방향의 사전학습 설계 참조점 제공
- 행동 없는 인간 영상 활용 → 손 전문가 데이터 효율 향상 가능성 시사

### (d) 먼저 확인할 점

- UEMR 포인트 클라우드 계산 비용 — 실시간 정책 루프에서 허용 가능한 지연 범위 확인 필요
- GR1 전신 휴머노이드 맥락 평가 — P1 팔·손 해부학적 분리 세임과 직접 대응 여부 신중 검토 필요
- 코드 공개 예정이나 시점 미확정

## 🥈 논문 3 — 우선순위 ★★

**Opt2VLA: Force-Aware Vision-Language-Action for Contact-Rich Humanoid Whole-Body Manipulation**
[arXiv:2609.23968](https://arxiv.org/abs/2609.23968) · Fukang Liu, Yipu Chen, Jaehwi Jang, Danfei Xu et al. · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ)

### (b) 핵심 기여

- **VLA-제어 인터페이스에 명시적 힘 명령 도입** — 단일 멀티태스크 VLA가 기하 모션 목표와 연속 접촉력 참조를 동시 예측; 태스크별 RL 기반 전신 컨트롤러가 힘 참조 추적
- 전신 궤적 최적화(TO)로 동역학적으로 타당하고 접촉 일관된 훈련 데이터 생성 — 물리 근거 있는 토크 감독 확보
- 접촉 집약 휴머노이드 태스크 3종에서 모션 전용 대비 힘 조절 정확도·일관성 개선 실증; 시뮬레이션 + 실제 휴머노이드 하드웨어 평가

### (c) 시사점

- VLA가 기하 목표와 힘 참조를 동시 예측 가능함을 실증 — 별도 접촉 서브루프 없이 VLA 레이어에서 힘 조절 가능한 구조의 비교 데이터 추가
- 태스크별 RL 전신 컨트롤러가 VLA 위 전문화된 힘 추적 레이어로 동작하는 패턴 — 전문가 계층 구조의 대안 데이터

### (d) 먼저 확인할 점

- 3개 태스크 평가 — 접촉 다양성·이전성 확인 필요
- 실제 로봇 결과가 시뮬 대비 정량 수치 격차 확인 필요
- 힘 참조 예측 오류 → 컨트롤러 추적 실패로 이어지는 빈도·실패 모드 확인 필요

## 🥈 논문 4 — 우선순위 ★★

**RouteRLT: Learning When and Which RL Specialist Should Control a Vision-Language-Action Policy**
[arXiv:2609.26467](https://arxiv.org/abs/2609.26467) · Chongyu Zhu, Jaden Hinds, Hyegang Kim, Juan Sebastian Rojas et al. · IROS 2026 Workshop(IARL) · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 핵심 기여

- **학습된 라우터(RouteRLT)** — 단계 선택기·안정화기·행동 경계 관리자 조합으로 일반주의 VLA와 정밀 단계 전문 RL 정책 간 전환을 단계 경계 지식 없이 자동 결정
- 학습된 라우팅이 단계 경계를 명시 입력으로 제공한 기준선과 동등 성능 달성 — 단계 인식 필요성 제거
- LIBERO 시뮬레이션 + 실세계 케이블 픽업·포트 삽입 태스크 검증; IROS 2026 Workshop 수락

### (c) 시사점

- 전문가 전환 타이밍을 학습으로 결정 가능함을 실증 — 전문가 분리 구조에서 조정자(coordinator) 설계에 명시 단계 신호 불필요 방향 데이터
- 행동 경계 관리자(action-boundary manager) 패턴 — 청크 기반 전문가 출력 이음매 처리 방법론, 몸통·손 전문가 전환 설계 참조 가능

### (d) 먼저 확인할 점

- 전문가가 태스크 단계 수준(pickup/insertion)으로 분리 — P1 해부학적 몸통·손 세임과 다름, 직접 이식 시 신중한 매핑 필요
- 워크숍 논문(8페이지) — 분산·시드·추가 기준선 보고 깊이 제한적
- 케이블·삽입 2개 태스크 — 다지 조작 태스크 이전성 확인 필요
