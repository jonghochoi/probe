## 🥇 논문 1 — 우선순위 ★★★

**AT-VLA: Adaptive Tactile Injection for Enhanced Feedback Reaction in Vision-Language-Action Models**
[arXiv:2605.07308](https://arxiv.org/abs/2605.07308) · Xiaoqi Li, Muhe Cai, Jiadong Xu, Juan Zhu, Hongwei Fan, Yankun Shen, Guangrui Ren, Hao Dong · source: citation-graph (π0·π0.5 인용)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4)

### (b) 핵심 기여

- **AT-VLA** — 촉각을 단순 입력 채널로 추가하던 기존 통합 방식과 달리, 두 가지 구조적 메커니즘으로 사전학습 VLA의 시각-언어 표현 간섭 최소화
- **Adaptive Tactile Injection** — 촉각을 항상 주입하지 않고, 촉각이 행동 생성에 유의미하게 기여하는 시점·위치를 동적 결정
- **Tactile Reaction Dual-Stream** — 지각 처리를 속도 기준으로 명시 분리
  - 저주파 시각-언어 스트림 — ambient visual reasoning, low-frequency
  - 고주파 촉각 제어 스트림 — real-time contact, 0.04초 응답 = 25 Hz 루프
- **델타** — 기존 정책에서 단일 추론 경로로 묶여 있던 지각·제어를 속도 기반으로 분리한 첫 VLA-수준 구현
- **검증** — 실세계 접촉 집약적 조작 과제 여러 개에서 확인

### (c) 시사점

- **제어 속도 분리 외부 증거** — 손가락 정밀 제어가 몸체보다 높은 주파수 루프를 요구한다는 가설을 이중 스트림이 실증, 몸체와 손 제어 주파수를 독립으로 두는 구조의 사전 확보 근거
- **고정 조건화 재검토** — 적응적 주입의 timing·location 선택 로직이, 몸체 행동을 단일 포인트로 손에 고정 조건화하는 방식과 대조되는 비교 사례
- **실시간 경로 하한선** — 0.04초 응답(25 Hz)이 손가락 명령 루프의 실질 주파수 하한선 제시, 위치 제어를 유지하되 고주파 촉각 교정 경로를 병렬로 다는 방안 참조점

### (d) 먼저 확인할 점

- **촉각 센서 전제** — visuotactile 센서(예: GelSight 계열) 가정, 손 인터페이스가 미지원이면 wrist force/torque 또는 proprioception 으로 대체 필요
- **주입 판정 위험** — 적응적 주입의 기여 판정 로직이 훈련 분포 밖에서 오작동(항상 주입 또는 항상 억제)하면 이중 스트림 이점 소멸
- **저비용 사전 점검** — 하드웨어의 촉각/force 인터페이스 가용 여부 확인 후, 없으면 wrist force 를 촉각 대리 신호로 쓴 최소 Dual-Stream 프로토타입이 속도 분리 효과를 시뮬레이션에서 재현하는지 우선 검증

## 🥈 논문 2 — 우선순위 ★★

**Modular Sensory Stream for Integrating Physical Feedback in Vision-Language-Action Models**
[arXiv:2604.23272](https://arxiv.org/abs/2604.23272) · Jimin Lee, Huiwon Jang, Myungkyu Koo, Jungwoo Park, Jinwoo Shin · source: citation-graph (π0.5 인용)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- **MoSS(Modular Sensory Stream)** — 물리 신호를 다루는 폭과 결합 방식 양면에서 기존 촉각 통합 연구와 차별화
- **이질 물리 신호 동시 통합** — 단일 물리 신호에 그치던 기존과 달리, 촉각(tactile)·토크(torque) 두 이질(heterogeneous) 신호를 동시에 통합, 단일 모달 대비 시너지(synergistic) 성능 향상 실험 확인
- **분리 스트림 + 결합** — 단순 concat 이나 FiLM 조건화 대신, 분리된 모달리티 스트림(decoupled modality streams)을 joint cross-modal self-attention 으로 action stream 에 통합, 각 물리 신호가 자기 스트림을 유지한 채 상호작용하는 명시적 분리 구조
- **두 단계 학습** — 1단계 VLA 동결 + sensory stream 만 학습, 2단계 전체 학습, 사전학습 표현 보존하며 새 모달리티 안정 도입

### (c) 시사점

- **손 입력 모달리티 구현 방향** — 손 입력 집합(촉각·proprio·local visual·VLA intent)을 분리 스트림 + joint cross-modal self-attention 으로 구현하면 각 모달리티가 독립 유지하다 attention 으로 합쳐지는 경로 확보
- **cross-attention 구현 참조** — joint cross-modal self-attention 이 몸체 hidden state 기반 cross-attention 경로의 가장 직접적 구현 참조, 신호별 독립 스트림으로 multi-modal 조건화의 정보 병목 완화
- **안전한 warm-start** — 2단계 학습(동결→전체)이 미세조정 시작 시 sensory adapter 먼저 수렴 후 전체 개방하는 방식으로 VLM prior 훼손 완화

### (d) 먼저 확인할 점

- **두 센서 요구** — 별도 촉각 센서·토크 센서 모두 요구, torque 미제공이면 single-modal(tactile only)로 축소되어 이질 두 신호 시너지 효과 재현 불가
- **auxiliary 비용** — auxiliary future physical signal prediction 태스크가 추가 훈련 비용 상승, 컴퓨팅 예산 제한 환경에서는 이 태스크 기여를 절제(ablate)해 필수 여부 우선 판별 필요

## 🥉 논문 3 — 우선순위 ★

**Tube Diffusion Policy: Reactive Visual-Tactile Policy Learning for Contact-rich Manipulation**
[arXiv:2604.23609](https://arxiv.org/abs/2604.23609) · Teng Xue, Alberto Rigo, Bingjian Huang, Jiayi Shen, Zhengtong Xu, Nicholas Colonnese, Amirhossein H. Memar · source: citation-graph (π0·π0.5 인용)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **공백** — 기존 action-chunking 모방 학습은 청크 실행 도중 예상치 못한 접촉 불확실성에 반응하기 어려움
- **TDP(Tube Diffusion Policy)** — "action tube" 개념이 핵심, 명목 action chunk 주변에 관측-조건부 feedback flow 를 학습해 청크 전체 재생성 없이 chunk 내 즉각 교정(step-wise correction) 수행
- **효과** — diffusion 모델 표현력을 유지하면서 실시간 고주파 반응 제어 실현
- **검증** — Push-T 벤치마크 + 시각-촉각 dexterous 과제 3종, 실세계 2개 실험에서 접촉 불확실성·외부 교란 강건성 확인

### (c) 시사점

- **계층적 흐름 + 청크 내 교정 결합** — 손 head 가 몸체 행동을 받아 단일 청크를 출력하는 계층 구조에 tube 패턴을 결합하면, 손 청크 내에서 촉각 피드백으로 step-wise 교정 가능
- **속도 분리 상호보완** — 명시적 이중 스트림 없이도 청크 내 고주파 반응 제공, 제어 속도 분리 미구현 상태에서도 손 expert 의 접촉 집약 반응성이 일정 수준 확보됨을 시사
- **접촉력 과잉 완화** — tube 교정이 접촉력 과잉을 청크 내에서 교정하면, 강성 위치 제어로 인한 과도 접촉력 대응(impedance 도입)의 실제 필요 시점이 뒤로 늦춰질 가능성

### (d) 먼저 확인할 점

- **diffusion ↔ flow matching 간극** — TDP 는 diffusion policy 기반, P1 스택은 flow matching(π0 backbone)이라 "action tube"를 ODE trajectory 위에서 정의하는 방법이 불분명, trajectory bundle 또는 local perturbation flow 로 재해석하는 비자명한 이론 수정 필요
- **검증 범위 한계** — 실세계 실험이 Push-T 등 비교적 단순한 접촉 시나리오 집중, 인핸드 회전·도구 관절 조작 등 복잡한 다지 접촉 과제 일반화는 미검증
