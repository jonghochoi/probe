## 🥇 논문 1 — 우선순위 ★★★

**Multi-Resolution Tactile Imitation Learning for Contact-Rich Robotic Manipulation**
[arXiv:2606.06281](https://arxiv.org/abs/2606.06281) · Rickmer Krohn, E. Helmut, Niklas Funk, Jan Peters, Vignesh Prasad, Georgia Chalvatzaki · source: keyword-sweep (cs.RO dexterous manipulation)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **MiTaS(Multi-Resolution Tactile Sensing)** — 다른 시간 해상도에서 동작하는 이종 촉각 센서 다수를 모방 학습에 동시 활용하는 표현 프레임워크
  - 입력 구성: RGB 카메라(저주파) + GelSight Mini 비전 기반 촉각 센서(중주파) + Evetac 이벤트 기반 촉각 센서(고주파)
  - 모달리티별 독립 컨볼루션 스템(modality-specific convolutional stem) + 트랜스포머 기반 융합 → 플로우 매칭 (flow matching) 정책 조건화
- **진정으로 새로운 점**
  - 기존 비주오택타일(visuotactile) 연구는 단일 속도 촉각 신호(하나의 센서 또는 동일 샘플링 주기)를 병합
  - 시간 해상도가 다른 촉각 센서를 모달리티별 전용 인코더로 분리하고 트랜스포머로 비동기 융합한 최초 사례
  - 5개 접촉 집약적 조작 태스크 평균 성공률: MiTaS 80% vs. 단일 속도 비주오택타일 54% vs. 시각 전용 31%
  - 멀티 촉각 데이터 공동 학습(co-training) 시 Evetac 미사용 조건에서도 일부 태스크 +10%p 이상 향상
  - 어텐션 분석으로 태스크 단계별 센서 기여도 양화(quantify)

### (c) 시사점

- **D5 rate separation 트리거 직접 근거** — D5 v1 "shared rate" 대비 다중 시간 해상도 분리(multi-resolution)가 +26%p(80% vs 54%) 차이를 만든 결과; 이벤트 기반(고주파) 채널이 빠른 접촉 과도(contact transient) 포착에 핵심임을 어텐션 분석으로 확인
- **모달리티별 인코더 설계 참조** — 핸드 전문가 입력 파이프라인에서 고주파 촉각(이벤트·capacitive) / 저주파 비전·촉각 이미지 두 경로를 분리 인코딩하는 구조로 변경 시 성능 상단 추정 가능
- **공동 학습 비용 절감** — 고가 이벤트 촉각 센서 없이도 공동 학습만으로 +10%p 확보, 데이터 수집 단계에서만 고해상도 센서 사용하고 배포 시 저가 센서로 대체 가능한 경로 제시

### (d) 먼저 확인할 점

- **단순 그리퍼 한정** — 실험은 단일 손가락 접촉 또는 2지(two-finger) 그리퍼 수준 태스크. 다지 핸드 20+ DoF 출력 공간에서 동일 멀티 해상도 융합 효과 유지 여부 미검증
- **이벤트 센서 위치** — Evetac는 손가락 끝(fingertip)이 아닌 손바닥 측 부착 가능성. 다지 핸드 각 손가락 관절 독립 이벤트 센서 배치 시 채널 수 급증과 트랜스포머 입력 규모 관리 필요
- **저렴한 점검** — 현행 D5 v1 "shared rate" 단일 촉각 채널 기준선 대비, 고주파 이벤트 채널을 별도 인코더로 분리했을 때 삽입·회전 태스크 성공률 변화를 소규모 IL로 측정

## 🥈 논문 2 — 우선순위 ★★

**RealDexUMI: A Wearable Universal Manipulation Interface for Dexterous Robot Learning**
[arXiv:2606.06033](https://arxiv.org/abs/2606.06033) · Chaoyi Xu, Yixuan Jiang, Jiahui Huan, Yuhui Fu, Haoyu Zhou, Weitian Yuan · source: keyword-sweep (cs.RO dexterous manipulation)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **RealDexUMI** — 수집·배포 하드웨어를 동일하게 유지하는 '제로 갭(zero-gap)' 다지 조작 데이터 수집 인터페이스
  - 공유 다지 엔드이펙터 모듈: 경량 다지 핸드 + 인핸드 카메라 + 손가락 끝 촉각 센서를 수집·배포 양쪽에서 동일 사용
  - 손바닥 측 등형 텔레오퍼레이션 글러브: 인간 손가락 입력 → 로봇 핸드 관절 명령으로 리타겟팅 없이 직결
- **진정으로 새로운 점**
  - 기존 다지 데이터 수집 파이프라인은 글러브→리타겟팅→로봇 변환 또는 로봇 특화 텔레오퍼레이션 중 하나 선택 → 배포 엔드이펙터와 갭 발생
  - 수집과 배포에 동일 핸드·센서를 공유해 인핸드 관측·촉각 신호·관절 액션이 완전히 일치하는 최초 인터페이스
  - 실세계 8개 태스크(미세 조작·접촉 집약·장기 지평·양손 조작) 평균 성공률 88.75%
  - 미지(unseen) 초기 포즈 일반화 및 3개 이형 구현체(embodiment) 이전 성공
- **Website**: https://research.beingbeyond.com/realdexumi

### (c) 시사점

- **D3 7번째 독립 검증** — 손가락 관절 명령(finger joint command) 인터페이스로 8개 다양한 실세계 다지 태스크 달성, 종전 6편(Proprioceptive Transformer·Phase-Conditioned IL·ConTrack 등) 이후 추가 확인
- **D2·D3 공동 데이터 확보 경로** — 동일 하드웨어로 wrist pose(D2)와 finger joint command(D3)를 동기 수집하는 가장 직접적 방법, 핸드 전문가 학습 데이터 파이프라인 설계 기준점
- **D5 인핸드 센서 배치 확인** — 수집·배포 동일 인핸드 카메라 + 촉각 센서 = 데모 품질과 배포 관측이 동일한 모달리티 공간, D5 "modality-separated" 채널 배치 결정 시 실험 인프라로 활용 가능

### (d) 먼저 확인할 점

- **하드웨어 의존성** — 공유 하드웨어 모듈 제약: 특정 경량 다지 핸드 형태·관절 수에 최적화, Sharpa·xhand 등 타겟 하드웨어 교체 시 인터페이스 재설계 및 재수집 필요
- **독립 핸드 전문가 평가 필요** — 88.75%는 수집·배포 동일 핸드 환경. 수집 하드웨어와 배포 하드웨어가 다를 때(교차 embodiment 3개 이전 수치는 논문 참조 필요) 일반화 폭 별도 확인
- **저렴한 점검** — 소규모 삽입 태스크에서 제로 갭 RealDexUMI 수집 데이터 vs. 기존 리타겟팅 수집 데이터로 학습한 핸드 정책의 성공률 격차 측정

## 🥉 논문 3 — 우선순위 ★

**HapTile: A Haptic-Informed Vision-Tactile-Language-Action Dataset for Contact-Rich Imitation Learning**
[arXiv:2606.04825](https://arxiv.org/abs/2606.04825) · Amirhosein Alian, Yongqiang Zhao, Shiyi Gu, Xuyang Zhang, Zhuo Chen, Christopher E. Mower · source: keyword-sweep (cs.RO arm hand hierarchical manipulation)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **HapTile** — 텔레오퍼레이터 측 햅틱 피드백 + 로봇 손가락 끝 촉각 센서를 동시 결합한 비주오택타일-언어-액션 데이터셋
  - 수집 플랫폼: 텔레오퍼레이션 컨트롤러에 햅틱 피드백 직결 → 조작자가 접촉 정보 실시간 지각
  - 로봇 엔드이펙터: 맞춤 설계 손가락 끝 촉각 센서 장착
  - 데이터 내용: 집기·접기·누르기·쌓기 등 일상 태스크 + 언어 조건화 + 동기화 비주오택타일 관측 + 액션 궤적
  - 두 기준 모델을 이용한 접촉 집약 정책 학습 벤치마크 포함
- **진정으로 새로운 점**
  - 기존 VLA 데이터셋은 시각 전용이거나 촉각 포함 시 태스크 다양성·언어 조건화·액션 궤적 중 하나 결여
  - 텔레오퍼레이터 햅틱 피드백 → 데모 품질 향상 + 로봇 촉각 센서 → 배포 시 접촉 신호 제공, 두 경로를 동시 구축한 최초 데이터셋

### (c) 시사점

- **D5 촉각 채널 훈련 데이터 확보** — 손가락 끝 촉각을 별도 모달리티로 수집·학습하는 기준 데이터셋, 핸드 전문가 1차 촉각 채널 ablation 실험 설계 참조
- **햅틱 텔레오퍼레이션 데모 품질 가설 검증** — 햅틱 피드백 있음/없음 데모의 접촉 집약 태스크 성공률 비교 지표 제공, 수집 파이프라인 설계 시 촉각·햅틱 피드백 투자 우선순위 근거로 활용

### (d) 먼저 확인할 점

- **데이터셋 논문 한계** — 아키텍처 설계보다 데이터 수집 인프라에 집중, 핸드 전문가 디코더 분리·정보 공유 설계와는 간접 연관
- **단일 DoF 그리퍼 기반** — 집기·접기·누르기는 단일 DoF 그리퍼 수준 태스크, 다지 핸드(20+ DoF) 환경에서 동일 촉각 모달리티 구조 유지 여부 별도 검증 필요
- **저렴한 점검** — HapTile 기반 정책 학습 실험에서 촉각 채널 유무 ablation(비주오택타일 vs. 시각 전용)의 태스크별 성공률 격차를 핸드 전문가 촉각 채널 ROI 기준점으로 사용
