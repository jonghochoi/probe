## 🥇 논문 1 — 우선순위 ★★★

**The Lie We Tell: Correcting the Euclidean Fallacy in Vision Language Action Policies via Score Matching on Tangent Space**
[arXiv:2606.01847](https://arxiv.org/abs/2606.01847) · Bing-Cheng Chuang, I-Hsuan Chu, Bor-Jiun Lin, Yuanfu Yang, Mingshan Sun, Chungwoo Lee · source: citation-graph (π0, π0.5)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **문제 명명** — Diffusion 기반 VLA 정책이 범하는 근본적 기하학 오류를 "Euclidean Fallacy"로 명명
  - SE(3) 포즈를 플랫(flat) $`\mathbb{R}^{12}`$ 벡터로 표현 시 SO(3) 제약 위반 매니폴드 드리프트(manifold drift)
  - 좌표 변환 하 등가성(equivariance) 파괴
  - 과도한 운동학적 비용의 비지오데식(non-geodesic) 궤적 발생
- **LDA(Lie Diffuser Actor)** — SE(3) 다양체 위에서 내재적(intrinsic)으로 노이즈 주입(좌불변 SDE), 접공간(tangent space)에서 스코어 예측, 지수 사상(exponential map)으로 샘플 복원
  - 매니폴드 드리프트 구조적 제거, 좌표 등가성·지오데식 최적성 보장
- **진정으로 새로운 점**
  - 기존 Diffusion VLA(3D Diffuser Actor, RDT 등)는 SE(3) 포즈를 $`\mathbb{R}^{12}`$ 또는 각도+위치 벡터로 표현, 유클리드 공간에서 노이즈 예측 → SO(3) 리만 기하 처리 생략으로 회전 행렬이 제약 이탈
  - 좌불변 SDE로 SE(3) 위 브라운 운동 직접 정의, 접공간에서 리에 대수(Lie algebra) 원소로 스코어 예측 후 지수 사상으로 복원
  - SE(3) 리에 군 구조로 VLA body pose 출력 분포를 내재적 모델링한 선례 부재
  - CALVIN ABC→D 평균 태스크 길이 3.27→3.51(+7.3%), 실세계 로봇에서도 기준선 대비 대다수 태스크 우위

### (c) 시사점

- **Cartesian 표현의 기하학 리스크 정량화 필요** — Body 전문가 wrist/flange pose 디노이징에서 SO(3) 드리프트 누적 가능성, 유클리드 표현 대비 SE(3)-intrinsic 표현의 일관적 우위 경향을 ablation 해석 기준점으로 활용
- **드리프트 측정 프로토콜** — 디노이징 체인 중간 스텝에서 회전 행렬 SO(3) 제약 위반(det(R)-1, R^T R - I 프로베니우스 노름) 측정 logging 추가 후보
- **성능 기준선 참조** — CALVIN +7.3%는 단일 팔 + 그리퍼 결과이므로 다지 핸드 환경에 직접 이전 불가, 경향성만 참조

### (d) 먼저 확인할 점

- **bimanual 미검증** — LDA는 단일 팔 + 그리퍼(CALVIN, 실세계 탁상 조작)에서만 검증, 양손목(both-wrist) 동시 출력 시 두 SE(3) 성분 간 상관성의 리에 군 표현 미수록
  - 두 wrist SE(3) 조인트 분포를 단일 확산 프로세스로 모델링 시 접공간 예측 차원 급증 → 학습 안정성 저하 우려
- **flow matching 적용성** — LDA는 diffusion 기반(π0.5, 3D Diffuser Actor)과 비교, π0 backbone의 플로우 매칭(flow matching) ODE 경로에서 좌불변 SDE·접공간 스코어 예측이 동일 적용 가능한지 별도 검토 필요
- **저렴한 점검** — 단일 wrist 세팅에서 SO(3) 드리프트가 실험적으로 측정 가능한지, π0 flow-matching ODE 경로를 리만 지오데식 예측으로 대체 가능한지 확인

## 🥈 논문 2 — 우선순위 ★★

**ConTrack: Constrained Hand Motion Tracking with Adaptive Trade-off Control**
[arXiv:2606.03177](https://arxiv.org/abs/2606.03177) · Yutong Liang, Quanquan Peng, Ri-Zhao Qiu, Xiaolong Wang · source: citation-graph (π0.5)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **프레임워크** — 인간 시연 장거리(long-horizon) 접촉 집약적 다지 핸드 궤적을 실세계 로봇에서 실행하는 강화학습(RL) 프레임워크
- **이중 목표 분리(dual-objective separation)** — 물체 추적(object tracking)을 RL 제약(constraint)으로, 관절·접촉 충실도(joint and contact fidelity)를 잔여 제어 권한으로 분리
  - 관절 명령 기반 추적이 장거리 접촉 집약 조작에서도 성립함을 실세계 로봇으로 검증
  - 물체 추적 = 상위 조건 신호, 핸드가 잔여 접촉 정밀도 처리 → body→hand 계층 흐름과 구조적 동형
- **진정으로 새로운 점**
  - 기존 다지 핸드 RL 추적은 물체 포즈·관절 운동을 단일 보상에 결합 → 시퀀스마다 수동 보상 조율, 긴 예산에서 붕괴
  - **Adaptive Dual-Variable Update** — 물체 추적을 라그랑주 제약으로 형식화, 이중 변수(dual variable)를 온라인 갱신해 제약 위반에 따라 물체/관절 트레이드오프 동적 조정 (보상 설계 없이 추적 품질 보장 + 관절 충실도 최대화)
  - **Adaptive Mid-Trajectory Reset Library** — 도달 가능한 시뮬레이터 상태 재활용으로 장거리 궤적 학습 안정성 향상
  - 물체 추적을 제약으로, 관절 정확도를 목표로 이분하여 다지 핸드 조작을 학습한 선례 부재
  - 시뮬레이션 및 실세계 LEAP Hand 실험에서 물체 포즈 정확도·관절 충실도 모두 기준선 대비 유의미한 향상

### (c) 시사점

- **finger joint command 출력의 장거리 추적 검증** — joint command 인터페이스로 장거리 접촉 집약 다지 조작 추적 성공, 단순 행동 복제(BC) 추적 품질 저하 시 제약 기반 RL을 보조 fine-tuning 단계로 추가 검토
- **계층 흐름의 제약-목표 형식화 참조** — "제약 = 상위 조건, 잔여 권한 = 하위 목표" 구조를 body→hand conditioning의 수학적 형식화로 참조, dual-variable 조건화가 FiLM 방식 대비 contact precision을 개선하는지 확인
- **학습 안정성 참조** — 장거리 다지 조작 시뮬레이션 학습 불안정 시 Adaptive Mid-Trajectory Reset 전략 적용 후보

### (d) 먼저 확인할 점

- **단일 물체·RL 특화** — ConTrack은 단일 물체 추적 RL 특화, 핸드 전문가는 다양한 파지·삽입·도구 조작을 모방 학습으로 일반화 필요
- **물체 포즈 ground-truth 의존** — dual-variable update는 시뮬레이션 물체 포즈 ground-truth 가용 전제, 실세계 다단계 task에서 포즈 미가용 시 제약 자체가 정의 불가
- **하드웨어 갭** — LEAP Hand는 타겟 하드웨어(Sharpa, xhand)와 관절 수·구조·제어 인터페이스 상이 가능
- **저렴한 점검** — 시뮬레이션 환경(Franka-Allegro 또는 Panda + Sharpa 모델)에서 dual-variable 제약 RL이 finger joint command 기반 in-hand rotation 추적 RMSE를 BC 기준선 대비 개선하는지 검증

## 🥉 논문 3 — 우선순위 ★

**OASIS: Observation-Action Space Alignment via SE(3) Trajectory Prediction for Robotic Manipulation**
[arXiv:2605.25829](https://arxiv.org/abs/2605.25829) · Xinzhe Chen, Sihua Ren, Liqiu Huang, Haowen Sun, Mingyang Li, Xingyu Chen, Zeyang Liu, Xuguang Lan · source: citation-graph (π0.5)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- **OASIS** — VLA 정책의 중간 표현(intermediate representation)을 SE(3) 엔드이펙터 궤적 예측으로 액션 공간과 정렬하는 비주오모터 정책
  - 3D 인식 특징 인코더(비전-언어 + 메트릭 깊이) + SE(3) 궤적 예측기 결합, 예측기의 포즈-지도된(pose-supervised) 숨은 상태를 액션 디코더에 조건화
  - both-wrist / tool-flange pose의 SE(3) 예측 경로를 선행 구현한 사례
  - LDA가 포즈 출력 분포를 SE(3) 위에서 직접 모델링하는 반면, OASIS는 SE(3) 예측을 중간 조건화 표현으로 사용 → 액션 디코더가 강체 운동과 일치하는 액션 청크 생성 유도
- **진정으로 새로운 점**
  - 기존 VLA·세계 액션 모델은 관측 공간(observation space) 보조 특징·미래 시각 상태 예측 활용 → 액션 공간 강체 기하학을 공유하지 않아 디코더가 암묵적 복원 필요
  - 카메라-프레임 SE(3) 엔드이펙터 궤적을 포즈-지도 중간 표현으로 도입해 관측 공간과 액션 공간을 기하학적 정렬
  - 3D 인식 특징 인코더 + SE(3) 예측기 협동, 포즈-지도된 숨은 상태가 디코더에 조건화되는 구조가 핵심 기여
  - 시뮬레이션·실세계에서 VLA 및 세계 액션 모델 기준선 대비 성공률·분포 외 일반화 향상, 프로젝트 코드 공개

### (c) 시사점

- **SE(3) 중간 표현 경로 확보** — SE(3) 엔드이펙터 궤적을 Body 전문가 최종 출력이 아닌 중간 조건화 신호로 사용하는 설계 경로 제시, 직접 출력(both-wrist Cartesian) 경로와 SE(3) 중간 표현 경유 경로 두 가지를 ablation에 등록 후보
- **Body↔Hand 정보 공유에 응용** — 관측-액션 기하학 정렬 원리를 Body→Hand 정보 공유로 확장, Body SE(3) 숨은 상태를 Hand에 FiLM 조건화하는 현재 설계가 기하학적으로 정렬된 표현을 전달하는지 확인 실험 필요
- **재현성 활용** — 코드 공개로 SE(3) 중간 표현이 단일 팔 + 그리퍼 환경에서 성능을 얼마나 향상시키는지 즉시 재현 가능, 외부 참조로 활용

### (d) 먼저 확인할 점

- **메트릭 깊이 의존** — SE(3) 예측기는 카메라-프레임 엔드이펙터 궤적 예측에 메트릭 깊이 입력 필요, 깊이 카메라 미배치 시 깊이 추정이 SE(3) 예측 정확도에 직접 영향
- **bimanual·다지 미검증** — 단일 팔 + 그리퍼에서만 검증, both-wrist 출력이나 다지 핸드 관절 공간 결합 미수록, finger joint command 결합이 SE(3) 중간 표현에 도입하는 추가 기하학적 복잡도 미검증
- **저렴한 점검** — 시뮬레이션 Panda + Allegro 환경에서 wrist SE(3) 궤적을 body 전문가 중간 조건화 신호로 사용할 때 hand 정책 contact precision이 직접 Cartesian 조건화 대비 개선되는지 확인
