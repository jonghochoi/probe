## 🥇 논문 1 — 우선순위 ★★★

**MA-VLA: Multi-Arm Vision-Language-Action Model for Collaboration and Compositional Generalization**
[arXiv:2608.25864](https://arxiv.org/abs/2608.25864) · Zaibin Zhang, Junlan Xiao, Zhongbo Zhang, Yifan Wang et al. · ECCV 2026 · source: citation-graph (π0) · 코드 공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D2](https://img.shields.io/badge/D2-d97706.svg)](#ref-D2)

### (b) 핵심 기여

- 멀티 암 VLA 제안 — 각 팔을 독립 에이전트로 모델링, 구조화된 암별 원자 액션 할당(per-arm atomic action assignment)으로 협조 조작 처리
- 구성적 일반화(Compositional Generalization) — 훈련 시 없던 암 협조 패턴을 테스트 시 조합 생성 가능; 단일 에이전트 VLA 한계 극복
- ECCV 2026 채택 + 코드·모델·데이터 공개 — 시뮬레이션·실세계 평가 모두에서 경쟁 시스템 대비 일관된 성공률 우위

### (c) 시사점

- 암별 분리 출력 헤드 실증 — 공유 트렁크 위에 암별 헤드를 분리하는 구조가 실제 다중 암 조작에서 작동함을 ECCV 수준으로 검증; 분리 헤드 설계 비교 기준점 즉시 확보
- 복수 손목 포즈 독립 생성 사례 — 각 암의 tool-flange 포즈를 독립 헤드에서 생성하는 접근이 협조 성능 향상에 기여하는 패턴 확인
- 코드·모델·데이터 공개 — Methodology base 추가 시 재현 비용 낮음; 8편 상한 내 슬롯 여유

### (d) 먼저 확인할 점

- 바이매뉴얼 ≠ body+hand 이기종 분리 — 양 팔 역할 분리이며, 다지 손가락 관절 명령 직접 포함 여부 및 hand 출력 공간 기여 미확인
- 멀티 암 전용 설계 — 단일 암 + 다지 손 구성의 이기종 분리에 직접 전이 가능성 별도 검증 필요
- 구성적 일반화 평가 범위 — 실험 태스크 대부분 pick-and-place 수준; 다지 정밀 조작에서의 일반화 검증 없음

## 🥈 논문 2 — 우선순위 ★★

**V-Link: Recovering Lost Visual Representations in Action DiT for Vision-Language-Action Models**
[arXiv:2608.25308](https://arxiv.org/abs/2608.25308) · Yehao Lu, Jiarui Yang, Yuning Su, Yufeng Xie et al. · arXiv preprint · source: citation-graph (π0) · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- Action DiT(Diffusion Transformer)에서 시각 표현이 희석되는 병목 최초 진단 — VLA 액션 디코더가 입력 시각 특징을 점진적으로 소실시킴을 정량 분석
- V-Link 메커니즘 제안 — 소실된 시각 표현을 액션 DiT 중간 레이어에 재주입하는 플러그인 모듈
- LIBERO·LIBERO-Plus·RoboTwin 2.0 성능 향상; AGIBOT A3 Ultra 휴머노이드 실세계 조작 +20%·+24% 달성

### (c) 시사점

- π 계열 Action DiT 아키텍처 내 시각-액션 정보 흐름 병목 진단 — π 백본 통합 설계 시 시각 표현 유지 전략 구체화에 직접 참조 가능
- 플러그인 재주입 접근 — 기존 π 백본 구조 수정 없이 시각 표현 복원; body·hand 이기종 헤드에 독립 적용 가능성
- 휴머노이드 실세계 +20%·+24% — 시각 표현 복원이 실제 조작 성능에 직접 기여함을 인간형 로봇에서 검증

### (d) 먼저 확인할 점

- 코드·구현 미공개 — 재현 및 비교 기준점 활용 불가
- AGIBOT A3 Ultra 전용 실세계 실험 — 하드웨어 특화 결과; 타 플랫폼 일반화 여부 미검증
- 시각 재주입이 body·hand 분리 헤드 각각에 미치는 영향 분석 미포함

## 🥉 논문 3 — 우선순위 ★★

**Act with Intent: Distilling Behavior Intent for Vision-Language-Action Models**
[arXiv:2608.23478](https://arxiv.org/abs/2608.23478) · Sangoh Lee, Sangwoo Mo, Wook-Shin Han · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1) [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7)

### (b) 핵심 기여

- 행동 의도(Behavior Intent) 증류 프레임워크 INDI 제안 — VLA 액션 디코더 학습 시 상위 레이어 의도 신호를 추출해 하위 액션 예측에 주입, 구조 변경 없이 적용 가능
- 의도 정렬 학습으로 장기 과제 누적 오류 감소 — SimplerEnv-Bridge·RoboCasa Kitchen 벤치마크 + 실세계 로봇 평균 성공률 62.0% → 68.7%(최대 +12pp 향상)
- 플러그인 방식 — 기존 π 계열 VLA 액션 디코더에 추가 훈련 오버헤드 최소로 적용 가능

### (c) 시사점

- 액션 디코더 학습 개선 접근 — 분리 헤드 구조에서 body·hand 각 헤드의 의도 정렬 학습에 독립 적용 가능성; 이기종 출력 공간의 의도 신호 설계 탐색 근거
- 장기 과제 최대 +12pp — 의도 정렬이 멀티 스텝 체인에서 오류 누적 억제에 기여; 장기 body→hand 전이 시나리오에 직접 시사
- 프로젝트 페이지 공개 — 코드 공개 예정; 아키텍처 세부 사항 사전 검토 가능

### (d) 먼저 확인할 점

- 코드 미공개(프로젝트 페이지만) — 공식 구현 없이 재현 제한; 코드 공개 시 우선 재검토 대상
- 의도 증류 교사 신호 의존 — 교사 표현 품질이 성능 상한 결정; 다지 손 특화 의도 신호 설계 미검증
- 단일 암 실험 위주 — body+hand 이기종 분리 구조에서 의도 증류 직접 검증 없음
