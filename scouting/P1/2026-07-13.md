## 🥇 논문 1 — 우선순위 ★★★

**TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation**
[arXiv:2607.07287](https://arxiv.org/abs/2607.07287) · Jianyi Zhou, Feiyang Hong, Yunhao Li et al. · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5) [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6)

### (b) 핵심 기여

- **계층 분리 3단 아키텍처**: High-Level Planning Layer(서브태스크 계획 + 촉각 서브목표 예측) → 비주오택타일 목표 조건부 액션 생성 → 고주파 촉각 잔차 보정의 3계층 명시적 분리 설계
- **예측·반응 이중 촉각 루프**: 계획 계층이 촉각 서브목표를 사전 예측해 액션 생성에 전달하고, 보정 계층이 슬립·정렬 오차를 온라인 수정 — 단일 모노리식 루프와 구분
- **실환경 6태스크 검증**: 클린 환경 65.0%, 인간 perturbation 환경 53.7% 성공률 — 최강 베이스라인 대비 각 +15.7 pp·+18.5 pp 개선

### (c) 시사점

- **비전/촉각 모달리티 분리의 실증**: 느린 계획(비전·언어)과 빠른 피드백(촉각)을 타임스케일 단위로 분리하는 방식이 접촉 집약적 다지 조작 성능에 직접 기여 — P1 모달리티 분리 원칙의 실환경 검증 사례
- **계층적 흐름의 구조 동형성**: 계획→액션 생성→고주파 보정의 3단 흐름이 P1 body→hand 계층 흐름과 구조적으로 동형 — 타임스케일 차이가 아키텍처 분리를 정당화하는 경험적 근거
- **접촉 게이팅 아이디어 참조 가치**: AVTAG(Action-Visual-Tactile Attention Guidance)가 접촉 단계에서 액션 쿼리에 촉각 신호를 집중시키는 설계 — 접촉 단계 조건화 메커니즘 아이디어 참조 가능

### (d) 먼저 확인할 점

- **촉각 센서 의존성**: 고품질 촉각 배열 필수 — 동일 하드웨어 없으면 직접 도입 비용 높음, 플랫폼 적합성 선확인 필요
- **코드·데이터 미공개**: 프로젝트 페이지만 존재 — 구현 재현 불가, 공개 시점 모니터링 필요
- **태스크 범위 한정**: 6개 접촉 집약적 태스크 — 다양한 물체·구성에서 일반화 폭 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**VT-WAM: Visual-Tactile World Action Model for Contact-Rich Manipulation**
[arXiv:2607.02503](https://arxiv.org/abs/2607.02503) · Shuai Tian, Yupeng Zheng, Yuhang Zheng, Songen Gu, Yujie Zang · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4](https://img.shields.io/badge/D4-d97706.svg)](#ref-D4) [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **통합 플로우 매칭 프레임워크**: 시각 예측·촉각 변형 예측·액션 예측을 하나의 플로우 매칭 프레임워크로 결합 — 기존 방식이 촉각을 직접 액션 예측에 피딩하는 것과 달리 촉각 동역학까지 모델링
- **비대칭 MoT(Mixture-of-Transformers) 어텐션**: 첫 프레임 시각 앵커와 시계열 촉각 동역학을 비대칭으로 브릿지 — 모달리티별 처리 수준 분리
- **AVTAG(contact-gated Action-Visual-Tactile Attention Guidance)**: 접촉 단계에서만 액션 쿼리가 촉각 증거에 의존하도록 게이팅 — 6개 실태스크 71.67% 성공률, Fast-WAM 대비 +26.67%, OmniVTLA 대비 +35.84%

### (c) 시사점

- **모달리티 비대칭 처리의 효과 입증**: 시각(저주파, 전역)과 촉각(고주파, 국소)을 동등하게 처리하지 않고 비대칭 MoT로 구조적 분리 — P1 모달리티 분리 원칙의 구체적 구현 사례
- **접촉 단계 게이팅**: 접촉 중에만 촉각 신호에 액션 어텐션을 집중시키는 조건화 설계 — body→hand 정보 흐름에서 '접촉 트리거' 조건화 설계 아이디어 참조 가능
- **정량 ablation 제공**: 촉각 동역학 모델링과 AVTAG 각각의 기여 분리 — 설계 선택별 효과 검증 가능

### (d) 먼저 확인할 점

- **촉각 센서 요구**: TouchWorld와 동일 — 전용 촉각 배열 없이는 직접 적용 불가
- **코드·데이터 미공개**: 프로젝트 페이지(vt-wam.github.io) 존재하나 코드 미확인
- **arm-hand 이분 구조 비명시**: 모달리티 분리 원칙의 참조 포인트로 적합 — P1 body/hand 아키텍처와 직접 대응 전 추가 검토 필요

## 🥉 논문 3 — 우선순위 ★

**Worldscape-MoE: A Unified Mixture-of-Experts World Model for Scalable Heterogeneous Action Control**
[arXiv:2607.03964](https://arxiv.org/abs/2607.03964) · Jianjie Fang, Yongyang Xu, Ziyou Wang, Chen Gao, Yu-Chen Huang · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **이종 액션 제어 통합 MoE 프레임워크**: 카메라 궤적·로봇 액션·손 관절 신호를 하나의 Diffusion Transformer 기반 MoE 세계 모델로 통합 — 제어 인터페이스별 단절을 스케일링 병목으로 규정
- **핵심 관찰**: 서로 다른 제어 신호는 동일한 물리 세계의 서로 다른 인터페이스 — 공유 세계 동역학 보존 + 제어 특화 전문가(expert) 결합 구조
- **진행적 MoE 튜닝 + 확장성 검증**: 기존 능력 보존하며 새 액션 모달리티 순차 추가 가능 — WorldArena, 로코모션, 손 제어 지표 개선, OOD 일반화 및 스케일링 행동 확인

### (c) 시사점

- **MoE 비교군 최신 구현체**: 공유 트렁크 + 제어 특화 전문가 구조가 P1 이종 디코더(body/hand 분리)의 직접 비교군 — 양측 장단점을 분리 평가할 수 있는 실증 기반 확보
- **이종 제어 동시 학습의 이득 확인**: 카메라·로봇 팔·손 관절 제어를 동시에 학습할 때 개별 제어 능력이 향상 — 공유 트렁크 설계가 body/hand 모두에 이득을 주는지 검토 근거
- **스케일링 가능성 증거**: 새 액션 모달리티 추가가 기존 능력을 저하시키지 않는다는 점 — 미래 확장 아키텍처 선택 시 참조 데이터

### (d) 먼저 확인할 점

- **세계 모델 중심 설계**: 직접 정책(VLA)이 아닌 world model 기반 제어 — VLA 정책 아키텍처와의 직접 비교에는 추가 실험 필요
- **실환경 검증 부재**: WorldArena·시뮬레이션 기반 — 실제 로봇 환경에서 이종 제어 효과 미검증
- **코드 미공개**: 공식 구현 없음 — 재현 및 직접 비교 불가
