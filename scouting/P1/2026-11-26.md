**ViTacLab: Physically Consistent Visuo-Tactile Simulation, Benchmarking, and Representation Learning for Robotic Manipulation**
[arXiv:2611.32476](https://arxiv.org/abs/2611.32476) · Linjing You, Zeming Yang, Zhenhao Shen 외 15명 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE) [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL)

### (b) 논문 요지

- 촉각 시뮬레이터·벤치마크·정책을 묶은 비주오택타일 풀스택
- **문제** — 촉각 기반 로봇 학습이 시각 기반 학습만큼 누적 진전을 보이지 못하는 상황
  - 접촉이 많은 조작에서 로봇이 물체를 가리거나 서브센티미터 정밀도가 필요하면 시각이 약해지고 접촉 역학이 주된 상태 정보
- **기존 한계** — 시뮬레이션, 평가, 구조 세 곳의 미해결 과제를 지적
  - **GPU 병렬 촉각 시뮬레이터** — 관통 깊이에서 촉각을 뽑아 법선 반응이 솔버 깊이 한계에서 포화하고 정지 마찰 구간에서 접선력이 미결정
  - **고충실도 시뮬레이터** — 명시적 접촉 역학으로 풀지만 대규모 정책 학습에는 비용이 큼
  - **기존 촉각 벤치마크** — 평행 그리퍼와 시각 또는 촉각 한쪽이 지배하는 구간에 치우쳐 다지 손과 양팔 시스템이 덜 다뤄짐
  - **기존 비주오택타일 정책** — 센서 수와 배치가 고정되고 힘 배열과 촉각 이미지를 단순 연결로 융합해 모달리티 간 물리 정렬이 없음
- **핵심 방법** — 시뮬레이터 ViTacSim, 벤치마크 ViTacBench, 정책 ViTacPolicy 세 요소로 구성
  - **ViTacSim** — 희소 접촉력 격자, 조밀 힘 배열, 촉각 이미지의 세 모달리티 촉각 단위를 PhysX 접촉 솔버 출력에 고정
  - **ViTacSim 보정** — 국소 강성 정렬로 법선을 바로잡고 분리된 슬립-스틱 구간으로 접선력을 복원하며 전역 렌치 투영으로 솔버 렌치를 보존
  - **ViTacBench** — 평행 그리퍼, 다지 손, 양팔 시스템에 걸쳐 시각 지배·비주오택타일·촉각 지배 구간으로 과제를 배열
  - **ViTacPolicy** — 공간 자세 임베딩과 Transformer로 가변 개수의 이종 촉각 입력을 모으고 공유 코드북 두 갈래 VQ-VAE로 힘 배열과 촉각 이미지를 한 이산 표현에 정렬
- **차별점** — 촉각 출력을 관통 깊이가 아니라 접촉 솔버 출력에 고정
  - GPU 병렬성을 유지하면서 법선·접선 불일치를 바로잡는 설계
- **핵심 기여** — 시뮬레이터 충실도, 벤치마크, 정책, 실물 전이를 함께 평가
  - **힘 충실도** — 통제된 헤르츠 기준 압입과 실제 센서 슬라이딩 시험에서 법선·접선 힘 RMSE를 2.31·1.85N에서 0.42·0.53N으로 감소
  - **처리량** — 병렬 환경 256개에서 촉각 파이프라인 2,482.9 FPS
  - **시뮬레이션** — 대표 6개 과제 중 4개에서 전체 ViTacPolicy가 최고, 평가한 외부 베이스라인을 모두 상회하고 5개 시드와 200개 시뮬레이션 에피소드로 평가
  - **실물 전이** — 시뮬레이션 사전학습 후 실물 미세조정을 그리퍼 과제 3개에서 과제당 50회로 측정, 사전학습 없는 변형 대비 합산 이득은 있으나 과제별로는 유의하지 않음
  - **어려움 공개** — 촉각 지배 구간의 Blind Grasp는 모든 방법이 3% 이하
- **가치** — 촉각 시뮬레이션·평가·학습을 한 틀에서 비교할 수 있는 공통 기반 제시

### (c) 시사점

- 다지 손까지 덮는 촉각 지배 평가 구간의 후보
- **평가 도구** — 시각 지배에서 촉각 지배까지 구간을 나눈 벤치마크가 접촉 집약 조작의 난이도 사다리로 쓰일 여지
- **접촉 데이터 공백** — 측정 코퍼스를 대신해 힘이 정렬된 시뮬레이션 촉각을 대량으로 만드는 경로
- **도입 비용** — PhysX 기반이라 같은 솔버를 쓰는 환경이면 접목이 쉬운 편

### (d) 먼저 확인할 점

- **공개 여부** — 초록·comment·본문에 코드 저장소나 공개 약속 없음
  - 시뮬레이터와 벤치마크를 받을 수 있는지 확인 필요
- **실물 범위** — 정량 실물 시험은 그리퍼 과제 3개뿐이고 다지 손·양팔 실물 배치는 정성 수준
  - 과제별 95% 신뢰구간이 넓고 과제별 Fisher 검정은 모두 비유의, 합산 분석만 유의
- **저자 인정 한계** — 변형 물체, 접착, 마모, 큰 탄성체 변형은 아직 모델링하지 못함
  - 조밀 공간장 오차와 촉각 이미지 충실도는 측정하지 않음
- **벤치마크 난이도** — 일부 과제에서는 사전학습 없는 변형이 더 높아 사전학습 이득이 과제 의존적

## 🥈 논문 2

**EgoStudy: How Does Scaling Egocentric Data Affect VLA and WAM Pretraining?**
[arXiv:2611.30490](https://arxiv.org/abs/2611.30490) · Puzhen Yuan, Yanjiang Guo, Yichen Liu 외 7명 · arXiv preprint · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — arXiv comment "Project Page: https://puzhenyuan.github.io/EgoStudy-website" — 프로젝트 페이지만, 코드 언급 없음

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D4ML](https://img.shields.io/badge/D4ML-d97706.svg)](#ref-D4ML)

### (b) 논문 요지

- 에고센트릭 데이터 규모가 VLA와 WAM에 미치는 효과의 통제 연구
- **문제** — 에고센트릭 사람 영상을 로봇 기반 모델 사전학습에 늘려 쓸 때 무엇이 효과를 내는지 불분명
  - 처리·사전학습 선택, 행동 성분별 이득, 모델 계열별 규모 효과의 세 질문
- **기존 한계** — 선행 연구들의 결론이 서로 비교되지 않음
  - 연구마다 로봇 데이터, 행동 표현, 모델 구조, 최적화 예산, 평가 방식이 달라 개선이 사람 경험, 처리 선택, 모델별 학습법 중 무엇에서 왔는지 가릴 수 없음
  - 평가 대부분이 합산 행동 손실만 보고해 다지 제어의 어느 성분이 이득을 보는지, 오프라인 이득이 폐루프 제어로 이어지는지 열려 있음
- **핵심 방법** — VLA와 WAM을 같은 사전학습·평가 규약에서 비교
  - **공유 행동 인터페이스** — 손목 운동과 손끝 자세를 기술하는 행동 공간으로 에고센트릭 사람 시연과 양팔 로봇 데이터를 묶음
  - **통제 변수** — 로봇 데이터와 노출량은 고정하고 에고센트릭 데이터의 규모와 구성(에피소드 선별, 출처 다양성, 캡션 상세도, 시간 샘플링)만 변경
  - **평가** — 보류 샘플, 행동 성분별 지표, 로봇 데이터 검증 손실을 쓰고 표준 로봇 후학습 뒤 목표 로봇 영역에서 평가
- **차별점** — 한 규약 안에서 VLA와 WAM을 나란히 놓고 에고센트릭 데이터만 움직임
  - 사전학습 선택이 배포 성과로 이어지는지까지 후학습으로 확인
- **핵심 기여** — 규약, 종합 실험, 실용 지침
  - **전이 요인** — 의미가 완결된 에피소드, 상세한 언어 캡션, 출처 다양성, VLA는 고정 스텝 샘플링과 WAM은 사건 단위 샘플링이 검증 손실을 낮춤
  - **행동 성분** — 규모를 키우면 손목 운동 예측이 손가락 운동 예측보다 더 개선
  - **모델 계열** — 에고센트릭 데이터가 적을 때는 WAM이, 데이터가 늘수록 VLA가 더 큰 이득
  - **시각 특징·백본** — VLA 규모 효과는 공유 행동 모델링에서, WAM 규모 효과는 비디오 백본의 흡수 용량에서 나올 가능성
- **가치** — 사람 에고센트릭 데이터를 처리하고 쓰는 방식에 실증 지침 제공

### (c) 시사점

- 에고센트릭 코퍼스의 규모 대비 손가락 이득이 작다는 근거
- **손가락 공백** — 규모만 키워서는 손가락 수준 예측이 크게 개선되지 않아 손가락 수준 감독이 따로 필요할 여지
- **코퍼스 구성** — 에피소드 완결성, 캡션 상세도, 출처 다양성이 데이터량 못지않은 선택 기준
- **모델 선택** — 데이터가 적은 단계에서는 WAM, 늘어난 단계에서는 VLA라는 단계별 지침

### (d) 먼저 확인할 점

- **실물 결과 없음** — 실물 로봇 XHand 보류 데이터의 행동 예측과 Robocasa-GR1 시뮬레이션 보류 평가이며 실물 실행 성공률은 없음
- **공개 여부** — 프로젝트 페이지만 있고 코드 공개 약속 없음
  - 사전학습 코퍼스 구성과 처리 도구를 받을 수 있는지 확인 필요
- **일반성** — 로봇 데이터를 고정한 한 구성의 결과로 다른 로봇 데이터와 모델 구조로의 전이는 미확인
  - 시드 3개 평균과 오차 막대를 보고하나 오프라인 지표 위주

## 🥉 논문 3

**TouchBench: Can Vision-Language Models Feel Invisible Physical Properties?**
[arXiv:2611.26883](https://arxiv.org/abs/2611.26883) · Ziyao Zeng, Ziyi Kou, Chuan Qin 외 6명 · arXiv preprint · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문
[![P1](https://img.shields.io/badge/P1-fddcc2.svg)](#ref-P1) / [![D1AL](https://img.shields.io/badge/D1AL-d97706.svg)](#ref-D1AL) [![D6SE](https://img.shields.io/badge/D6SE-d97706.svg)](#ref-D6SE)

### (b) 논문 요지

- 카메라에 안 보이는 물성을 묻는 영상-촉각 벤치마크
- **문제** — 병의 내용물이나 물체의 순응도처럼 이미지로 복원되지 않는 물성을 VLM이 다루는지 평가 수단이 없음
  - 다루는 방식을 결정하는 많은 속성이 만져야만 드러남
- **기존 한계** — 물리·직관 추론 벤치마크가 입력 영상에서 답할 수 있는 질문으로만 구성
  - 점수가 낮을 때 지각 부재 때문인지 과제 난이도 때문인지 가르지 못함
  - 촉각을 모델에 넣는 통상 방식인 인코더 학습은 다지 조작에서 드문 쌍 데이터를 요구
- **핵심 방법** — 시각적 답변 가능성을 통제 변수로 둔 벤치마크와 촉각 텍스트 인터페이스
  - **TouchBench** — 머리 장착 영상과 동기화된 137채널 전손 촉각을 짝지은 클립, 속성·질문·선택지를 공유하고 촬영 조건만 다른 Tier A와 Tier B 구성
  - **Tactile-as-Prompt(TaP)** — 힘, 접촉 기하, 진동, 손목 운동의 해석 가능한 통계 34개를 프롬프트 텍스트로 제공
- **차별점** — 촉각을 학습 인코더 토큰이 아닌 텍스트로 전달
  - 학습과 모델 가중치가 필요 없어 비공개 모델에도 적용 가능
- **핵심 기여** — 벤치마크, VLM 평가, 촉각 인터페이스
  - **벤치마크** — 참가자 5명의 11개 과제 900개 클립, 절대 질문 900개와 상대 질문 4,102개
  - **VLM 평가** — 최신 VLM 4종이 Tier A 상대 질문 평균 66.4%, Tier B는 49.8%로 우연 수준 50%에 근접하며 Tier B 답이 클립 순서에 의존
  - **TaP 효과** — Tier B 상대 질문 제로샷 정확도 62.9%, 참가자 한 명을 제외하는 방식의 미세조정 뒤 73.1%로 영상 단독 67.4%와 학습 토큰 67.3%를 상회
  - **일반화** — 처음 보는 물체와 사용자로 이득이 이어지고 20시간 실환경 코퍼스에서 접촉 질문 정확도가 67.1%에서 75.5%
- **가치** — 시각만으로 닿지 않는 물리 추론의 한계와 촉각 인터페이스의 효과를 한 평가 틀에서 확인

### (c) 시사점

- 전손 촉각 코퍼스의 평가 과제 후보
- **접촉 데이터 공백** — 시각으로 복원되지 않는 접촉 정보를 장갑 촉각이 채운다는 정량 근거
- **평가 도구** — 시각 답변 가능성을 통제 변수로 둔 설계가 촉각 이득을 분리해 재는 방식
- **도입 비용** — 학습 없이 텍스트로 촉각을 넘기는 TaP는 낮은 비용의 기준선
