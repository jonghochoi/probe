## 🥈 논문 1 — 우선순위 ★★

**Towards High-DoF Dexterous Manipulation through VLA Post-Training**
[arXiv:2609.19666](https://arxiv.org/abs/2609.19666) · Junlei Zhu, Shenzhe Yao, Chaogui Huang, Wenkai Zhu · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- **고자유도 손 액션 코덱(temporal hand-action codec)** 도입 — 사전학습 VLA를 절대 다지 손 명령 인터페이스에 적응; 손 출력 공간과 VLA 백본 사이의 표현 정렬 문제 직접 해결
- 4단계 포스트트레이닝 파이프라인(코덱 SFT → DAgger → 잠재 잔차 RL) — 버퍼드 롤백, 포즈 정렬, 부드러운 명령 블렌딩으로 DAgger 오염 문제 해결
- 양손 이전, 인핸드 재배향, 도구 사용 5개 실제 로봇 태스크에서 태스크당 20회 시도 전원 100% 성공 — VLA 기반 다지 손 제어 최초 수준의 성능 실증

### (c) 시사점

- 손 출력 코덱이 VLA와 다지 손 명령 공간 사이 인터페이스 역할 가능함을 실증 — 손 출력 공간 설계 논의에 구체적 구현 참조점 확보
- 잠재 잔차 RL이 코덱 포착 공간 내로 탐색을 제한 — 고자유도 손 정책 학습 비용 절감 경로 제시
- 4단계 파이프라인 전체가 단일 VLA 백본 위에서 작동 — 백본 분할 논의에 통합 포스트트레이닝 대안 데이터 추가

### (d) 먼저 확인할 점

- 코드 미공개 — 코덱 구조, DAgger 버퍼드 롤백, 잔차 RL 구현 재현 불가
- 5개 태스크가 모두 독립 테이블탑 환경 — 이동 조작·접촉 집약 태스크로의 확장성 미검증
- 코덱 차원 선택이 손 출력 표현력과 학습 효율에 미치는 민감도 분석 부재

## 🥈 논문 2 — 우선순위 ★★

**MoPA: Coordinated Mobile Manipulation via Subsystem-Specific Perception Alignment**
[arXiv:2609.12081](https://arxiv.org/abs/2609.12081) · Guangyu Chen, Qiwei Liang, Shaolong Zhu, Tianxing Chen et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- **이중 지각 스트림(Dual Perceptual Streams)** — 상호 마스킹 쿼리 뱅크로 이동 베이스와 팔 조작에 대한 독립 지각 표현 추출; 공유 시각-언어 컨텍스트에서 서브시스템별 지각-행동 대응 명시화
- Mixture-of-Transformers 디코더의 각 레이어에서 지각 쿼리와 행동 스트림을 **동시 갱신(Perception2Action Adaptation)** — 레이어별 서브시스템 정보 교환 허용
- 결합 조건부 플로우 매칭(coupled conditional flow matching)으로 베이스·팔 행동 청크 **공동 생성** — 기구학 결합 보존하며 분리 지각 처리
- ManiSkill-HAB 3개 태스크 전부 SOTA, 실제 로봇 4개 태스크 76.3% 평균 성공(최상위 기준선 대비 +12.5pp)

### (c) 시사점

- 서브시스템별 지각 정렬이 행동 성능에 +12.5pp 기여 — 지각 모달리티 분리가 행동 품질 개선에 실증 효과
- MoT 레이어별 지각-행동 동시 갱신 패턴 — 모달리티 분리 논의(D1MZ)에 구현 레벨 대안 아키텍처 제공
- 플로우 매칭 공동 생성에서 분리 지각 표현이 협조 유지 가능함을 실증 — 분리 전문가 출력 결합 설계의 비교 근거

### (d) 먼저 확인할 점

- 이동 베이스·팔 세그멘테이션(base vs arm seam) — P1의 해부학적 body/hand 분리와 세임(seam)이 다름, 직접 이식 시 신중한 매핑 필요
- 실제 로봇 4개 태스크 상세 프로토콜(태스크 종류, 반복 횟수, 기준선 구성) 논문 확인 필요
- 프로젝트 페이지 공개 중, 코드 공개 시점 미확정

## 🥈 논문 3 — 우선순위 ★★

**X-WBC: A Cross-Embodiment Foundation Model for Humanoid Whole-Body Control**
[arXiv:2609.15213](https://arxiv.org/abs/2609.15213) · Juntong Zhang, Chun Gu, Li Zhang · CoRL 2026 · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 핵심 기여

- 공유 모션 의미론(shared human motion semantics)과 **로봇별 물리 실행(embodiment-specific physical execution)**을 분리하는 교차 구현 전신 제어 프레임워크 — 구현별 경량 모듈이 공유 표현을 각 로봇 고유 공간에 매핑
- 인간 중심 커맨드 토큰이 전신 모션·로봇 참조 모션·희소 VR 관찰을 정렬 — 데이터 출처 혼합 학습 가능
- 시뮬레이션 9종 로봇 + 실제 로봇 4종 검증 — CoRL 2026 수락, 교차 구현 공동 학습이 개별 학습 대비 추적 성능 개선 실증

### (c) 시사점

- 공유 트렁크 + 구현별 헤드 구조가 9종 로봇에서 일관 동작함을 CoRL 수준 실험으로 확인 — 분리 전문가 아키텍처(D3GS) 설계 근거 보강
- 구현별 경량 모듈이 공유 표현 품질을 저하하지 않음을 실증 — 헤드 분리 비용 수치화에 기준 데이터 추가
- 교차 구현 데이터 공동 학습 패턴 — 몸통·손 전문가 독립 데이터 혼합 학습에 구조적 참조점

### (d) 먼저 확인할 점

- 전신 제어(WBC) 중심 평가 — 다지 손가락 관절 명령이 포함된 접촉 집약 조작 태스크로의 확장성 미검증
- CoRL 2026 수락이나 코드 미공개 — 경량 모듈 구조 세부 재현 불가
- 공유 표현과 구현별 헤드 간 정보 병목 발생 여부 ablation 미제시

## 🥈 논문 4 — 우선순위 ★★

**TacBPM: A Tactile-conditioned Behavior Prior Model for Dexterous Reorientation**
[arXiv:2609.18174](https://arxiv.org/abs/2609.18174) · Jie Yin, Wanli Xing, Zeyuan Zhao, Xuezhou Zhu · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5DQ](https://img.shields.io/badge/D5DQ-d97706.svg)](#ref-D5DQ) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 핵심 기여

- 다중 크기 구체(multi-scale sphere) 전문가 정책들을 잠재 컨트롤러로 증류 — 하위 정책 재사용을 **잔차 잠재 행동(residual latent actions)**으로 구현, 원시 관절 명령 탐색 비용 제거
- 잠재 행동 사전이 촉각-고유수용감각 이력(tactile-proprioceptive history)을 조건으로 삼아 현재 손-객체 상호작용 반영 — 접촉 감지 정보가 손 정책 내부에서 처리됨을 실증
- 임의 포즈 이전, 지령축 회전, 팔-손 Grasp-to-AnyPose 태스크에서 원시 행동 PPO 대비 안정적 정책 달성 + sim-to-real 전이 성공

### (c) 시사점

- 촉각-고유수용감각 조건부 잠재 사전이 손 전문가 탐색 비용 대폭 절감 가능함을 실증 — 손 출력 인터페이스(D1QT) 설계에 잠재 표현 경유 경로 데이터 추가
- 접촉 이력을 정책 루프 내부에서 조건화하는 패턴 — 별도 접촉 서브루프 없이 접촉 응답 가능함을 보여주는 추가 증거
- Grasp-to-AnyPose 태스크가 팔-손 협조 파이프라인 전체를 평가 — 분리 전문가 구조에서 팔·손 순차 처리 가능성 시사

### (d) 먼저 확인할 점

- 구체 전문가에서 증류한 사전이 비구형·비대칭 물체로의 이전 범위 실험 규모 확인 필요
- 코드 미공개 — 증류 절차, 잠재 컨트롤러 구조, sim-to-real 세부 재현 불가
- 잔차 잠재 행동의 최대 보정 범위(correction budget)가 분포 외 물체 형상에서 충분한지 미검증
