## 🥇 논문 1

**VioLA: Learning Generalist Humanoid Control Policies from Human Data**
[arXiv:2610.12435](https://arxiv.org/abs/2610.12435) · Mert Albaba et al. · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 13/15** · R3 · N3 · M3 · Real3 · Repro1 — 초록 "Code and checkpoints will be released"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX) [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS)

### (b) 논문 요지

- 몸·손 모션 잠재를 액션 공간으로 쓰는 휴머노이드 범용 정책
- **문제** — 휴머노이드 범용 정책의 두 장애물, 전신 협응 학습 부담과 로봇 시연 부족
  - 다리·몸통·팔·손가락이 함께 움직여야 하므로, 관절 명령을 예측하는 정책은 협응과 과제 선택을 동시에 학습해야 함
  - 휴머노이드 원격조작은 로봇과 조작자가 모두 필요해 다과제·다환경 시연 수집 비용이 큼
- **기존 한계** — 기존 휴머노이드 범용 정책과 인간 데이터 활용 경로 각각의 비용
  - 기존 휴머노이드 범용 정책 — 목표 과제마다 추가 로봇 시연으로 미세조정, 새 과제 배치 때마다 데이터 재수집 필요
  - 인간 녹화 — 사람 모션만 담겨 있고, 정책이 예측할 로봇 관절 명령은 없음
  - 사람을 로봇이 따라 하며 녹화하는 방식 — 시연마다 다시 로봇이 필요
  - 인간 모션을 로봇으로 리타깃팅해 정책을 지도하는 방식 — 저자들이 대비시키는 또 하나의 우회 경로
  - 기존 잠재 모션 제어기 — 사람·로봇 몸 모션은 같은 잠재 공간에 매핑하나 손 명령은 다루지 않음
- **핵심 방법** — 정책은 관절 명령 대신 몸·손 모션 잠재 청크를 예측하고, 동결된 제어기가 이를 관절 명령으로 변환
  - 입력 — 에고센트릭 이미지, 지시문, 고유수용감각
  - 몸 — SONIC 몸 인코더·전신 제어기(동결)가 몸 잠재를 균형을 유지하는 관절 명령으로 변환
  - 손 — 같은 구조로 따로 사전학습한 손 모듈(동결), 사람·로봇 손 인코더가 잠재 공간을 공유하고 손 제어기가 손가락 명령 생성
  - 학습 타깃 — 동결된 인간·로봇 모션 인코더가 시연을 잠재 타깃으로 변환, 인간 녹화는 원래 이미지·지시문 유지
  - 액션 — 몸 64좌표, 손 64좌표
- **차별점** — 인간 모션을 리타깃팅하지 않고, 사람·로봇 공유 잠재 공간 자체를 정책의 액션 공간으로 사용
  - 정책은 어디로·언제 움직일지만 선택하고, 관절을 어떻게 움직일지는 동결된 제어기가 담당
  - 그 결과 로봇 관절 명령이 없는 인간 시연도 같은 정책의 지도 신호로 사용 가능
- **핵심 기여** — 모션 잠재 액션 공간 정책, 인간 데이터 학습 경로, 실물 제로샷 평가와 백본 비교
  - VioLA — 몸·손 모션 잠재를 예측하고 사전학습 제어기가 협응된 관절 명령으로 변환하는 범용 휴머노이드 정책
  - 학습 데이터 781시간(1억 4,060만 프레임), 그중 93.2%가 인간 시연
  - 실물 Unitree G1, 과제별 미세조정 없이 새 환경·다른 물체 인스턴스에서 이동 30/30(100%), 조작 31/35(88.6%)
  - 같은 조건에서 공개 GR00T N1.7은 조작 0/35, Ψ0는 3/35(8.6%)
  - 같은 레시피를 VLA 2종과 WAM 1종 백본에 적용 — 조작 성공 GR00T N1.7 기반 88.6%, π0.5 기반 45.7%, DiT4DiT 기반 25.7%
  - 인간 시연만으로 학습한 변형이 실물 이동 지시 12/30(40%) 성공 — 로봇 시연 없이 인간 모션 지도가 로봇 행동으로 이전
- **가치** — 인간 녹화를 휴머노이드 범용 정책의 액션 지도로 직접 쓰는 경로 제시, 로봇 시연 수집 의존 완화

### (c) 시사점

- 몸·손 출력을 나눈 정책의 실물 휴머노이드 기준점
- **분할 구조** — 몸 잠재와 손 잠재를 따로 내고 각자의 동결 제어기가 실행, 해부학적 분할의 실물 사례
- **출력 공간 대비군** — 몸 출력이 손목·플랜지 자세가 아닌 전신 모션 잠재, 손 출력이 손가락 관절 명령이 아닌 손 잠재
- **데이터 경로** — 출력 공간 선택이 인간 데이터 93% 활용 가능 여부까지 결정한다는 근거
- **백본 영향** — 같은 출력 분할 위에서 백본만 바꿔도 조작 성공이 88.6%, 45.7%, 25.7%로 갈림, 백본 선택이 분할만큼 중요하다는 신호

### (d) 먼저 확인할 점

- **접촉력 부재** — 손 디코더는 접촉력 피드백 없이 손가락 위치 명령만 출력, 저자 스스로 접촉 피드백 통합을 과제로 명시
- **평가 규모** — 주 평가는 Unitree G1 한 대, 13개 과제, 과제당 5회
- **미해결 과제** — 병 운반 과제는 모든 변형이 0/5, 포함 시 조작 성공 31/40(77.5%)
- **인간 데이터 이득의 범위** — 로봇 데이터만 학습한 변형이 조작 33/35(94.3%)로 더 높음, 인간 데이터 이득은 이동에 한정
- **이전 비용** — SONIC 같은 잠재 전신 제어기와 손 모듈 사전학습이 전제, 다른 손에 적용하려면 손 모듈부터 다시 필요

## 🥈 논문 2

**EigenDEXplore: Structured Exploration for Dexterous Manipulation with Human Priors**
[arXiv:2610.07681](https://arxiv.org/abs/2610.07681) · Harsh Gupta et al. · arXiv preprint · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — §1 "We release benchmarking code, a plug-and-play implementation, and pretrained PCA models for six dexterous hands" · 초록 "Project page: eigendexplore.github.io"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT)

### (b) 논문 요지

- 인간 손 시너지를 액션 공간 대신 탐색 노이즈에 쓴 방법
- **문제** — 다지 손의 유효한 협응 동작이 고차원 액션 공간의 작은 영역에만 있어 탐색이 어려움
  - 강화학습(RL)과 샘플링 기반 궤적 최적화는 관절별 독립 가우시안 섭동으로 탐색, 협응 동작 발견이 비효율적
  - 그 결과 많은 연산과 정교하게 설계한 보상·비용·커리큘럼이 필요
- **기존 한계** — 인간 모션 기반 저차원 액션 공간의 표현력·중복 문제, 이득의 원천도 불분명
  - PCA 선형 고유공간·VAE 비선형 잠재 공간 — 협응 동작은 직접 명령하나 일반 조작에 필요한 독립 관절 제어를 표현하지 못함
  - 학습 액션과 독립 관절 액션의 결합 — 표현력은 회복하나 액션 차원이 늘고 중복 발생
  - 이득이 협응 동작의 직접 제어, 노이즈가 유도한 탐색, 차원·표현력 변화 중 어디서 오는지 미분리
- **핵심 방법** — 관절 공간 액션은 유지하고, 인간 손 PCA 방향 섭동과 독립 관절 노이즈를 합친 탐색 분포 사용
  - 대규모 인간 영상에서 복원한 손 모션을 각 로봇 손으로 리타깃팅해 PCA 기저 구성, 과제별 궤적 불필요
  - PCA 방향 섭동은 협응 동작 유도, 독립 관절 노이즈는 탐색 범위 유지
  - RL 학습 후 고유기저는 버리고 정책을 결정론적으로 배치
  - RL과 궤적 최적화(SPIDER) 양쪽에 적용
- **차별점** — 인간 prior를 액션 공간 제약이 아닌 탐색 분포에만 사용
  - 체계적 비교에서 인간 모션 prior의 주된 이득은 상관된 탐색에서 나오며, 액션 제약이나 중복은 오히려 성능을 해칠 수 있다는 진단
- **핵심 기여** — 방법, 이득 원천 규명, RL·궤적 최적화·실물 검증, 공개 산출물
  - SimToolReal(시뮬레이션) — 초기 학습 연속 성공 34% 증가, 장기 학습에서 더 큰 이득
  - DeXtreme(시뮬레이션) — 연속 성공 40% 증가
  - 실물 이전 — SimToolReal 4개 도구 과제 평균 진척 33% → 82%(Sharpa 손-팔, 물체·궤적 조합당 10회), DeXtreme 연속 성공 41% 증가
  - DexMachina 양손 참조 유도 RL — 접촉 보상 설계·커리큘럼 없이 물체 추적 정확도 평균 28% 향상, 고자유도 손일수록 이득 큼
  - SPIDER 궤적 최적화 — 6종 손 평균 리타깃팅 비용 16% 감소, 고자유도 손일수록 이득 큼
  - 대규모 에고센트릭 영상이 소규모 과제 특화 모션 캡처 데이터셋보다 강한 prior를 준다는 분석, PCA 차원 선택 검증
  - 벤치마크 코드, 플러그인 구현, 6종 다지 손용 사전학습 PCA 모델 공개
- **가치** — 관절 공간 표현력을 잃지 않고 인간 협응 패턴을 쓰는 단순한 탐색 분포, 다지 손 RL·궤적 최적화에 바로 적용 가능

### (c) 시사점

- 손가락 관절 명령 출력 유지에 무게를 싣는 비교 증거
- **출력 공간 비교군** — 인간 prior를 출력 공간에 넣기보다 관절 공간 출력과 구조화된 탐색이 낫다는 결과
- **반대 방향 증거** — 손 출력을 잠재로 바꾸는 계열(같은 주의 VioLA 등)과 정반대 결론, 두 결과를 함께 읽을 가치
- **도입 비용 낮음** — 공개된 6종 손 PCA 모델로 RL 기반 손 정책 학습의 탐색 기법을 바로 시험 가능

### (d) 먼저 확인할 점

- **맥락 차이** — RL·궤적 최적화의 탐색 결과이며 모방 학습 VLA 디코더의 출력 공간 비교가 아님, 이전 시 가장 큰 간극
- **고정 선형 기저** — 데이터에 없는 협응이나 비선형 시너지는 독립 관절 노이즈로만 탐색 (저자 명시)
- **손 형태 의존** — 키네마틱 리타깃팅에 의존해 인간과 형태가 크게 다른 손에서는 효과 저하 가능, 저자유도 손에서는 이득이 작음
- **시간 상관 없음** — 노이즈를 시간 단계마다 독립 샘플링, 시간 상관 탐색은 향후 과제

## 🥉 논문 3

**SkillWeave: Weaving Heterogeneous Demonstrations into Long-Horizon Manipulation Skills**
[arXiv:2610.12046](https://arxiv.org/abs/2610.12046) · Ryosei Tamura et al. · IROS 2026 Workshop on Haptics and Dexterous Manipulation · source: keyword-sweep · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — 초록 "Videos and code are available at skillweave-authors.github.io"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 논문 요지

- 구간마다 다른 시연 방식으로 학습한 정책을 이어 붙인 장기 조작
- **문제** — 자유 공간 이동과 접촉 집약적 상호작용이 번갈아 나오는 장기 다지 조작을 한 가지 시연 방식으로는 잘 담지 못함
  - 정책은 데이터에 담긴 상태·상호작용만 배우므로 시연 수집 방식이 곧 정책의 능력과 실패 모드를 결정
- **기존 한계** — 시연 방식 각각의 약점과 단순 기술 합성의 분포 불일치
  - 원격조작 — 과제 진행과 공간 커버리지는 담지만 리타깃팅과 간접 접촉 피드백 탓에 다지 접촉 구간의 정밀도 제한
  - 키네스테틱 교시 — 로봇이 실행 가능한 접촉 형상을 직접 주지만 시연자의 손이 영상에 가려 기록됨
  - 단순 기술 합성 — 선행 정책의 종단 상태가 후행 정책 시연의 초기 상태에서 벗어나는 분포 불일치, 하위 과제가 이어질수록 누적
  - 인페인팅으로 시연자를 지우는 기존 방식(KineDex 등) — 상호작용 영역 근처의 보이지 않는 내용을 복원해야 함
- **핵심 방법** — 하위 과제별 시연 방식 배정, 정책 경계 연결, 물체 마스크 조건 정책의 세 요소
  - 원격조작은 장기 커버리지와 자유 공간 도달, 키네스테틱 교시는 접촉 집약적 정밀 구간에 사용, 하위 과제마다 확산 정책을 따로 학습
  - successor-aware terminal steering — 선행 정책의 실제 종단 상태에서 후행 정책의 시연 초기 상태 영역으로 짧은 연결 동작 삽입
  - 물체 마스크 조건 확산 정책 — SAM 3로 학습용 물체 마스크를 오프라인 생성, 배치 시에는 학습된 마스크 예측기가 마스크 공급
- **차별점** — 시연자 가림을 복원하지 않고 물체 마스크를 조건으로 주며, 정책 경계 불일치는 후행 정책의 초기 상태 분포 쪽으로 조향해 해소
  - 온라인 제어 루프에서 SAM 3와 이미지 인페인팅을 제거
- **핵심 기여** — 다중 시연 프레임워크, terminal steering, 마스크 조건 정책과 실물 장기 과제 검증
  - 팔 수준 도달·재배치·배치 하위 과제 — 원격조작 평균 64%, 키네스테틱·KineDex 평균 4.5% (실물, 정책당 20회)
  - 손가락 수준 정밀 하위 과제 — 원격조작 평균 5%, 마스크 조건 키네스테틱 65%
  - 정밀 하위 과제의 시각 처리 비교 — 원시 키네스테틱 10%, KineDex 20%, 마스크 조건 65%
  - 실물 장기 과제 3종 종단 성공 — Cube Reorientation 45%, Nut Removal and Storage 15%, Kettle Preparation 20%, 평균 27% (과제당 20회)
  - 단일 방식 기준선 3종은 장기 과제에서 성공 0회, steering 없이 합성하면 평균 5%
- **가치** — 구간 특성에 맞춰 시연 방식을 섞고 독립 학습한 정책을 합성하는 실용적 데이터 수집 레시피

### (c) 시사점

- 거시 이동과 접촉 정밀을 다른 데이터로 나눈 실물 근거
- **분할의 데이터 측 근거** — 원격조작은 팔 수준 거시 동작, 키네스테틱은 손 수준 정밀 동작에 맞는다는 정량 대비 (64% 대 4.5%, 5% 대 65%)
- **넘김 지점 설계 참고** — 선행 정책 종단 상태를 후행 정책 초기 분포로 조향하는 steering, 순차형 협응 흐름의 경계 처리 사례
- **축 차이** — 분할이 해부학 축이 아닌 시간(하위 과제) 축, 직접 비교가 아닌 간접 근거로 읽어야 함

### (d) 먼저 확인할 점

- **분할 단위** — 몸/손 전문가가 아니라 하위 과제별 독립 정책의 순차 합성, 한 정책이 팔과 손을 함께 출력
- **절대 성능** — 장기 과제 종단 성공 평균 27%
- **통계 부족** — 반복 시드·분산 보고와 한계 서술 없음, 결론 절에는 향후 과제만 서술
- **수동 설계** — 과제 분해와 시연 방식 배정을 사람이 결정, 자동화는 향후 과제
- **발표 형식** — 정식 학회 본 트랙이 아닌 워크숍 발표

## 🌱 논문 4 — 인접 분야 픽

**MobiAgent: Dual-Loop Recursive Policy Self-Improvement for Long-Horizon Mobile Manipulation**
[arXiv:2610.03476](https://arxiv.org/abs/2610.03476) · Chenzhi Liu et al. · CoRL 2026 · adjacent field: continual learning, policy self-improvement · 코드 공개

**점수 12/15** · R2 · N2 · M3 · Real3 · Repro2 — 표제부 "GitHub: https://github.com/kaiknower/MobiAgent"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D3GS](https://img.shields.io/badge/D3GS-d97706.svg)](#ref-D3GS) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 논문 요지

- 스킬별 액션 전문가를 배포 데이터로 계속 갱신하는 이중 루프
- **문제** — 장기 모바일 조작은 내비게이션과 정밀 파지를 번갈아 수행해야 함
  - 실행 오류가 단계마다 누적
  - 이동과 팔 제어라는 이질적 감각-운동 매핑을 한 모델로 학습할 때 용량 간섭(capacity interference) 발생
- **기존 한계** — 모놀리식 VLA와 계층형 에이전트 프레임워크 각각의 병목
  - OpenVLA, π0, π0.5와 모바일 확장(Mobi-π, N2M) — 단기 반응형 모놀리식 정책, 장기 과제의 의미적 분해와 폐루프 재계획에 필요한 계층적 추론 부족
  - LLM/VLM 계층형 에이전트 — 고정 조작 환경에 한정
  - 하위 과제마다 고립된 정책 배정 — 계획이 미리 정한 목록에서의 선택으로 축소, 하위 과제가 늘수록 확장성 저하
  - 경직된 정책 대응 — 검증 실패 후 재계획이 번거로움, 모바일 조작의 공간적 오류 복구에 치명적
  - 평생 학습 관점의 개루프 — 데이터 큐레이션과 정책 자기 개선 파이프라인 부재, RoboClaw는 자동 데이터 수집에 그침
- **핵심 방법** — 배포 시 Inner Loop와 오프라인 학습 Outer Loop로 나눈 이중 루프 에이전트 시스템
  - Inner Loop, Task Planner — 원자 스킬을 즉석 조합하고 계획 완료마다 재계획
  - Inner Loop, Skill Executor — π0.5 기반, 공유 VLM trunk 위에 스킬별 독립 flow-matching 액션 전문가를 두고 액션 청크 생성
  - Inner Loop, Reflection Critic — 연속 시각 검증으로 재계획 유발
  - Outer Loop — VLM 기반 Data Curator가 시연·배포 rollout을 분할·검증·캡션, Skill Generator가 지시문 군집으로 원자 스킬 어휘 구성, Skill Trainer가 스킬 정책 지속 미세조정
- **차별점** — 하위 과제 단위 고립 정책 대신 더 잘게 쪼갠 원자 스킬별 액션 전문가를 공유 trunk 위에 두고, 배포 데이터를 사람 주석 없이 스킬별 학습 데이터로 재활용
  - 같은 하위 동작을 쓰는 여러 하위 과제가 하나의 액션 전문가를 재사용
- **핵심 기여** — 이중 루프 시스템과 시뮬레이션·실물 검증
  - BEHAVIOR-1K 4개 장기 과제(시뮬레이션, 과제당 10회) — 평균 성공 65.0%, 과제별 모델 π0.5-TA 42.5% 대비 22.5%p, 최장 과제 fetch-beer에서 50%p 차이
  - RoboCasa365 Composite-Seen(시뮬레이션) — π0.5 7.50%, CaP-X 5.00% 대비 1라운드 18.75% → 3라운드 27.50%, 4–6라운드 25.00–27.50%에서 정체
  - 실물 Astribot S1 4개 과제 — 모놀리식 π0.5 10.0%, MobiAgent 부트스트랩 32.5% → 두 차례 갱신 후 57.5%
  - BEHAVIOR-1K에서 동적 계획, 스킬별 전문가, 시각 검증 각각의 구성요소 ablation
  - 코드 저장소 공개
- **가치** — 장기 모바일 조작에서 스킬 라이브러리를 사람 주석 없이 배포 경험으로 계속 키우는 폐루프 경로 제시

### (c) 시사점

- 공유 trunk 위 전문가 분할을 지속 학습과 묶은 사례
- **분할 방식 참고** — π0.5 공유 VLM trunk 위 스킬별 액션 전문가, π 계열 백본에서 액션 전문가를 나누는 실물 사례
- **같은 동기** — 이동과 팔 제어의 용량 간섭을 전문가 분할로 피한다는 논리가 몸/손 분할 논리와 같은 모양
- **확장 비용 참고점** — 전문가를 계속 늘릴 때 공유 백본 간섭이 남는다는 저자 진단

### (d) 먼저 확인할 점

- **분할 축** — 원자 스킬(의미) 단위 분할, 몸·손 해부학 분할 아님
- **간섭 미해결** — 새 스킬 추가가 공유 VLA 백본의 기존 행동과 간섭 가능 (저자 명시), LoRA·지속 학습 기법은 제안만
- **실행 약점** — 자세 보정 반복, 배치 복구 부정확, 일시적 가림에서 critic 표류 (저자 명시)
- **실물 범위** — Astribot S1 한 플랫폼, 4개 과제, 최종 성공 57.5%
- **시스템 비용** — 계획·검증·데이터 큐레이션이 LLM/VLM 호출에 의존, 이전 시 구성 부담 큼
