## 🥇 논문 1 — 우선순위 ★★★

**Cross-Embodiment Robot Manipulation via a Unified Hand Action Space**
[arXiv:2607.03570](https://arxiv.org/abs/2607.03570) · Luis Felipe Casas, Robert Teal, Keval Shah, Abhijit Tadepalli, Wanxin Jin · source: citation-graph (Dexora)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1QT](https://img.shields.io/badge/D1QT-d97706.svg)](#ref-D1QT) [![D4QX](https://img.shields.io/badge/D4QX-d97706.svg)](#ref-D4QX)

### (b) 핵심 기여

- **문제 제기**: 다지 손 조작 정책이 특정 로봇 손 embodiment에 종속 — 기구학적 구조가 다른 플랫폼 간 이전(transfer) 불가
- **UHAS (Unified Hand Action Space)**: 표준 구(sphere)의 기하학적 변형(geometric deformation)으로 모든 로봇 손의 액션을 표현하는 embodiment-agnostic 통합 공간
- **CIK (Cascade Inverse Kinematics)**: UHAS 변형을 각 로봇 손의 embodiment-specific 관절 각도로 변환하는 알고리즘 — 단일 정책이 다수 플랫폼을 지원
- **강화학습 기반 정책**: RL로 UHAS 공간에서 직접 인핸드 큐브 재배향 과제 학습
- **검증 범위**: Allegro Hand, LEAP Hand, Shadow Hand, MANO Human Hand — 4종 실제 로봇 손 zero-shot 이전 + 빠른 파인튜닝 성공

### (c) 시사점

- **손 액션 공간 추상화의 실용 경로**: 관절 각도 직접 출력 대신 기하학적 추상 공간을 쓰면 동일 정책이 여러 손 플랫폼에 재사용 — Hand Expert 아키텍처의 embodiment 범용성 확보 가능성 제시
- **CIK 분리의 이점**: 정책 학습과 IK 매핑을 모듈로 분리하면 새 embodiment 추가 시 IK 재학습만 필요 — Hand Expert 재활용 비용 절감
- **손 출력 공간 선택의 외부 근거**: finger joint command 기본값이 embodiment에 묶이는 데 비해 UHAS는 cross-embodiment 기준점을 제공 — 손 액션 표현 재검토의 실증적 출발점

### (d) 먼저 확인할 점

- **강화학습 전용**: 모방 학습(IL)/VLA 통합 없이 RL만 사용 — π0 계열 데모 기반 정책과의 결합 방법 미검토
- **코드 미공개**: 논문 기준 공식 릴리스 확인 불가 — 재현 선행 비용 존재 (Reproducibility=1)
- **과제 범위 제한**: 인핸드 큐브 재배향 단일 과제 중심 — 다양한 접촉 집약적 조작으로의 일반화 별도 검증 필요
- **팔+손 통합 미언급**: 손 조작 집중, 팔과의 계층 통합 정책 설계는 추가 연구 과제

## 🥈 논문 2 — 우선순위 ★★

**Asynchronous Multimodal Diffusion Policy Composition via Latency-Aware Guidance Fusion**
[arXiv:2607.17257](https://arxiv.org/abs/2607.17257) · Zihao He, Hongjie Fang, Shirun Tang, Cewu Lu, Haoshu Fang · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D1MZ](https://img.shields.io/badge/D1MZ-d97706.svg)](#ref-D1MZ)

### (b) 핵심 기여

- **문제 진단**: 다중 모달리티 확산(diffusion) 정책에서 모달리티별 감지 속도·추론 지연이 상이 — 동기식(synchronous) 융합은 고주파 피드백을 늦추거나 새 모달리티 확장성 저하
- **LAG-Fusion (Latency-Aware Guidance Fusion)**: 각 모달리티 정책을 네이티브 속도로 독립 실행하고, 가용 시점마다 디노이징 가이던스(denoising guidance)로 기여 — 동기식 배리어 제거
- **Reference-frame rebasing 규칙**: 상대 액션 표현(relative action representation) 하에서 지연된 가이던스를 정렬(rebase) — 비동기 합성(composition)의 수학적 일관성 보장
- **실증**: 저주파 비전 정책 + 고주파 힘(force) 정책 합성 — 이종 지연 환경에서 동기 융합 기준선 및 force-aware 기준선 대비 응답성·과제 성공률 향상

### (c) 시사점

- **제어율 분리의 구체적 구현**: 비전(저주파)과 힘/촉각(고주파)을 서로 다른 속도로 운용하면서 단일 확산 정책 성능 유지 — 입력 모달리티 분리 설계의 실증적 근거
- **rebasing의 이식성**: 상대 액션 표현이 선행되면 rebasing을 수식으로 도출 가능 — 기존 Body/Hand 정책 위에 비동기 촉각·힘 채널 추가 경로로 활용 가능
- **VLA 외부 증거로서의 가치**: 확산 정책 기반이지만, 모달리티별 비동기 합성 패턴은 Body(시각)·Hand(힘·촉각) 이종 제어율 설계 참조로 직접 적용 가능

### (d) 먼저 확인할 점

- **비VLA 아키텍처**: π0·π0.5 계열 플로우 매칭이 아닌 확산 정책 기반 — π 백본과의 통합 방식 별도 설계 필요
- **모달리티 제한**: 비전+힘 2채널 검증 — 촉각·고유감각 등 3채널 이상 비동기 확장 시 rebasing 안정성 미확인
- **코드 공개 예상**: Cewu Lu 그룹 공개 이력 기반 Reproducibility=2로 처리, 현재 미확인 — 공개 전 재현 제한 가능

## 🥉 논문 3 — 우선순위 ★

**Grasp, Handover, Rotate: Bimanual Object Reorientation via Compositional Diffusion and Energy-Based Optimization**
[arXiv:2607.21341](https://arxiv.org/abs/2607.21341) · Wun Lam Yeung, Wenjun Liu, Yui Cheung Yu, Zhengyan Qin, Qijin She, Heng Li · source: keyword-sweep (bimanual)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D5SH](https://img.shields.io/badge/D5SH-d97706.svg)](#ref-D5SH)

### (b) 핵심 기여

- **BiCompoDiff**: 바이매뉴얼 물체 재배향(pick → 핸드오버 → 재파지 → 배치)을 위한 합성적(compositional) 확산 + 에너지 기반 모델(EBM) 프레임워크
- **구성**: 사전 학습된 파지(grasp) 확산 모델 + 바이매뉴얼 계획 EBM — 역방향 확산 중 그래디언트 가이던스로 충돌 회피·궤적 부드러움(미분 가능 IK)·핸드오버 실현성·재파지 안전성 동시 충족
- **Annealed MCMC 샘플링**: 복합 에너지 환경에서 파지 포즈 정제
- **성과**: 가정용 물체 재배향 과제에서 강력한 샘플링 기반 기준선 대비 성공률 20% 이상 향상, 관절 변위 기준 궤적 부드러움 37% 개선; 실제 로봇 검증 확인

### (c) 시사점

- **바이매뉴얼 협조 설계의 참조점**: 팔 간 핸드오버와 재파지 시퀀싱 — Body(팔 이동)→Hand(파지·재파지) 계층 흐름의 구체적 사례로 참조 가능
- **EBM 기반 다중 제약 융합**: 충돌·부드러움·핸드오버·재파지 제약을 단일 에너지로 통합 최적화 — Body↔Hand 경계에서 상충 제약 표현 방식 참조
- **sim-to-real 달성**: 가정용 물체 실제 환경 검증 — 바이매뉴얼 재배향 성능 기준점으로 활용 가능

### (d) 먼저 확인할 점

- **VLA 아키텍처 미포함**: IL/VLA 없이 계획(planning) 중심 설계 — 액션 디코더 아키텍처 직접 기여 없음, P1 참조 범위 제한적
- **코드 미공개**: 공식 릴리스 미언급 (Reproducibility=1), 재현 비용 존재
- **단계 경계 명시적 분리**: pick·handover·rotate를 단계별 모델로 설계 — 엔드-투-엔드 학습과의 통합 방식 미검토
