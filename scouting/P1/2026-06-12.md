## 🥇 논문 1 — 우선순위 ★★★

**Bridging the Morphology Gap: Adapting VLA Models to Dexterous Manipulation via Intent-Conditioned Fine-Tuning**
[arXiv:2606.12109](https://arxiv.org/abs/2606.12109) · Chuanke Pang, Junyi Huang, Zhijun Zhao, Yaobing Wang, Kun Xu, Xilun Ding · source: keyword-sweep (arm hand dexterous hierarchical)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D7](https://img.shields.io/badge/D7-d97706.svg)](#ref-D7) [![D3](https://img.shields.io/badge/D3-d97706.svg)](#ref-D3)

### (b) 핵심 기여

- **형태 간극(morphology gap) 문제 정의** — 기존 VLA 파이프라인 대다수가 저-DoF 병렬 그리퍼에 고정되어 있어, 고-DoF 다지 핸드 적용 시 두 가지 실패 동시 발생
  - 직접 end-to-end 파인튜닝 → 공간 추론(spatial reasoning) 파국적 망각(catastrophic forgetting)
  - 데이터 희소성 → 다지 핸드 액션 매니폴드 붕괴(action manifold collapse)
- **InDex** — Cross-Morphology Semantic Inheritance 기반 데이터 효율적 적응 프레임워크
  - 그리퍼 학습에서 확립된 의미론적 의도(semantic intent)를 다지 핸드 공간으로 이전
  - 의도 조건부 파인튜닝(intent-conditioned fine-tuning)으로 VLM 사전(prior) 보존 + 손가락 관절 명령 공간 선택적 적응 병행
- **진정으로 새로운 점**
  - 기존 다지 VLA 연구는 다지 전용 학습 또는 단순 혼합(naive mixing) 파인튜닝 — 파국적 망각 또는 표현 불일치 불가피
  - 그리퍼→다지 핸드 적응에서 "의미론적 상속(semantic inheritance)"을 통한 VLM prior 보존 개념 최초 도입
  - 데이터 효율적 VLA→다지 핸드 적응 전용 프레임워크 선례 부재

### (c) 시사점

- **backbone FT 전략 위험 요소 확인** — π0 VLA를 다지 핸드에 전면 end-to-end 파인튜닝할 때 공간 추론 능력이 실질적으로 붕괴한다는 외부 실증; both-sides FT 전략의 파국적 망각 리스크를 인식하고 보완 방법 설계 필요
- **의도 조건부 선택적 FT 경로 확보** — VLM prior를 고정하고 액션 전문가만 intent 조건부로 교체하는 방식이 대안 후보; 다지 핸드 실험 진입 전 어느 레이어를 고정·어느 레이어를 교체할지 결정 시 InDex 방식 참조
- **그리퍼 데이터 재활용 가능성** — 다지 핸드 전용 데이터 없이 그리퍼 데모의 semantic intent를 이전 가능 시 고비용 다지 텔레오퍼레이션 수집 규모 절감; finger joint command 학습의 데이터 병목 완화 경로

### (d) 먼저 확인할 점

- **실세계 검증 범위 미확인** — 초록 기준 실세계 다지 핸드 실험 포함 추정이나 구체 태스크·성공률 불명; 시뮬레이션 전용 가능성 배제 불가
- **intent 표현 이전성 한계** — semantic intent가 유사 태스크 분포 내에서만 이전 가능할 경우, 분포 외 다지 조작(인핸드 회전·미세 삽입)에서 inheritance 실패 우려
- **저렴한 점검** — 소규모 삽입·파지 태스크에서 InDex(의도 조건부 FT) vs. end-to-end FT 비교: 성공률 및 VLM 시각 특징 보존 지표(CLIP 유사도) 측정

## 🥈 논문 2 — 우선순위 ★★

**DAM-VLA: Decoupled Asynchronous Multimodal Vision Language Action Model**
[arXiv:2606.12105](https://arxiv.org/abs/2606.12105) · Pankhuri Vanjani, Zhuoyue Li, Jakub Suliga, Moritz Reuss, Gianluca Geraci, Xinkai Jiang · source: keyword-sweep (finger joint dexterous hand policy)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D5](https://img.shields.io/badge/D5-d97706.svg)](#ref-D5)

### (b) 핵심 기여

- **동기 클럭 불일치 문제 명시** — 기존 VLA가 시각-언어 사전학습에서 물려받은 "단일 동기 클럭(shared synchronous clock)"이 물리적 상호작용과 근본적으로 불일치
  - 언어: 에피소드 전체 고정(static) → 매 스텝 재처리 불필요
  - 비전: 수 Hz 수준으로 느리게 변화
  - 고주파 입력(촉각·관절 상태): 수백 Hz — 단일 클럭 아래에서 구조적 병목(bottleneck)
  - "동기 VLA는 느린 모달리티를 과잉 샘플링하고 빠른 모달리티를 과소 샘플링, 액션 생성 속도를 최저 유효 주파수로 제한"
- **DAM-VLA** — 모달리티별 독립 시간 해상도 비동기 처리 아키텍처
  - 각 입력 모달리티가 자체 센서 속도로 독립 업데이트·유지
  - 언어·비전·고주파 입력의 시간적 결합(temporal coupling) 해제
- **진정으로 새로운 점**
  - 기존 VLA 가속화 연구는 추론 지연(latency) 최소화 중심 — 모달리티별 클럭 불일치를 근본 아키텍처 문제로 명시한 선례 부재
  - 동기 클럭이 고주파 채널(촉각·고유감각) 처리를 구조적으로 병목 유발한다는 인식 자체가 신규
  - 모달리티별 비동기 업데이트를 VLA 아키텍처 수준으로 구현한 최초 사례

### (c) 시사점

- **고주파 입력 채널 병목 해소 경로 확보** — 다지 핸드(20+ DoF)의 촉각·관절 상태가 수백 Hz로 변화 → 비전 처리 클럭과 시간적 분리 시 손가락 제어 주파수 병목 구조적 제거 가능
- **모달리티 분리 설계의 클럭 근거 추가** — CT-VAM(2026-06-10 수록)의 언어 분리 접근보다 포괄적인 모달리티별 비동기 처리 아키텍처; 입력 채널 분리(language static / vision slow / tactile fast)를 클럭 수준에서 구현하는 구체 경로
- **rate separation 트리거 발화 조건 구체화** — 모달리티별 클럭 분리가 표준 조작 벤치마크에서 성능 개선을 실증할 경우, 다지 핸드 전문가 고주파 채널을 비동기 처리로 전환하는 가장 직접적 근거 확보

### (d) 먼저 확인할 점

- **실세계 다지 핸드 검증 미확인** — 초록에 "물리적 상호작용" 언급이나 구체 실세계 로봇·다지 핸드 실험 포함 여부 불명
- **비동기 학습 복잡도** — 모달리티별 비동기 업데이트는 미니배치 내 시간 정렬(temporal alignment) 문제를 내재; 다지 핸드처럼 빠른 채널과 느린 채널 혼재 시 시간 정렬 오차가 정책 학습 안정성에 미치는 영향 검증 필요
- **저렴한 점검** — 단일 팔 + 그리퍼 설정에서 language/vision/action 클럭 분리 전후 액션 생성 주파수 및 성공률 변화 소규모 IL로 측정; 다지 핸드 환경 확장 가능성 1차 추정

## 🥉 논문 3 — 우선순위 ★

**What Matters in Orchestrating Robot Policies: A Systematic Study of Hierarchical VLA Agents**
[arXiv:2606.10267](https://arxiv.org/abs/2606.10267) · Jiaheng Hu, Mohit Shridhar, Caden Lu, Dhruv Shah, Hao-Tien Lewis Chiang, Jie Tan · source: citation-graph (π0)

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-1f77b4.svg)](#ref-P1) / [![D6](https://img.shields.io/badge/D6-d97706.svg)](#ref-D6) [![D1](https://img.shields.io/badge/D1-d97706.svg)](#ref-D1)

### (b) 핵심 기여

- **Hi-VLA 설계 원칙 부재 문제 지적** — 기존 계층형 VLA(Hi-VLA) 시스템들이 고수준 VLM 플래너 + 저수준 VLA 컨트롤러 구조를 공유하지만, 플래너·컨트롤러 선택, 연결 방식, 전환(switching) 메커니즘, 관측·메모리 표현이 시스템마다 상이 — 통일된 설계 원칙 부재
- **첫 번째 체계적 Hi-VLA 비교 연구** — 위 설계 차원들을 독립 변수로 분리한 통제 실험 제시
  - 고수준 플래너 선택(언어 모델 vs. VLM), 저수준 컨트롤러 선택, 전환 메커니즘, 메모리 표현 각각의 성능 기여 분리 측정
  - 설계 차원별 영향 패턴 기반 Hi-VLA 설계 원칙 도출
- **진정으로 새로운 점**
  - 개별 Hi-VLA 시스템 제안 논문은 다수이나, 설계 차원을 독립 변수로 분리한 체계적 비교 실험 연구 선례 부재
  - 어떤 설계 선택이 성능에 실질 기여하는지 분리 측정 후 통일 원칙을 도출한 최초 연구

### (c) 시사점

- **계층 흐름 설계 실증 기준 확보** — 고수준 플래너→저수준 컨트롤러 계층에서 어떤 연결 방식·전환 메커니즘이 성능에 실질 기여하는지 통제 실험 근거; body→hand 계층 흐름 구현 시 conditioning 방식 선택의 외부 참조
- **분리 설계 유효성 외부 실증 기대** — shared trunk + split heads 형태의 이질 분리 구조가 Hi-VLA 계층에서도 유효한지 확인 시 P1 hybrid split 설계의 외부 지지 근거 추가
- **ablation 설계 방법론 참조** — body↔hand 전문가 분리 ablation 설계 시 본 연구의 단일 변수 통제 실험 방법론(설계 차원 독립 분리) 직접 차용 가능

### (d) 먼저 확인할 점

- **구체 결과 미확인** — 초록 기준 구체 수치·설계 원칙 결론 미확인; 연구 결과가 단일 팔 + 그리퍼 표준 조작 벤치마크 한정 가능
- **추상화 수준 차이** — Hi-VLA 플래너-컨트롤러 계층(태스크 분해 수준)과 body→hand 계층(동작 수준) 간 시간 해상도·정보 추상화 수준 상이 → 직접 이전 한계 존재
- **저렴한 점검** — 논문 공개 후 플래너-컨트롤러 전환 메커니즘 결과를 확인하여 body→hand conditioning 방식(FiLM 단일 포인트 vs. multi-point cascade) ablation 우선순위 재조정
