## 🥇 논문 1 — 우선순위 ★★★

**See like a Robot: Robot-Centric Pointmaps for Vision-Language-Action Models**
[arXiv:2607.11498](https://arxiv.org/abs/2607.11498) · Byungkun Lee, Dongyoon Hwang, Dongjin Kim, Hojoon Lee, Minho Park 외 · source: citation-graph (VGGT 인용)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- 로봇 팔의 3D 좌표계로 표현되는 액션과 카메라 프레임으로 관측되는 장면 사이의 불일치 문제를 정면 지적
- 로봇 중심 pointmap(각 픽셀이 로봇 좌표계 상의 3D 점을 담는 이미지) 제안 — 기존 2D VLA가 기대하는 H×W 그리드 형태를 유지해 최소 구조 변경으로 삽입 가능
- RoboCasa 벤치마크에서 pi0.5·SmolVLA 두 정책 모두에 적용해 성능 향상 확인, 카메라뷰포인트 인코딩·3D-aware 대표 baseline 대비 우위
- 실로봇 실험에서 학습 시 보지 못한 카메라 배치로 이동했을 때 RGB-only 정책 대비 격차가 더 벌어짐을 확인

### (c) 시사점

- 다중 카메라 셋업이 학습-배포 간 달라지는 상황에서, 카메라 프레임이 아닌 로봇 프레임 기준 관측 표현이 일반화에 실질적 이득
- 기존 사전학습 2D 정책에 최소 구조 변경으로 삽입 가능하다는 점에서 도입 장벽 낮음
- 카메라 재배치·플랫폼 교체가 잦은 셋업일수록 우선 검토 가치

### (d) 먼저 확인할 점

- 로봇 좌표계 pointmap 생성에 필요한 카메라 캘리브레이션 정밀도 요구 수준 — 초록만으로는 오차 허용 범위 불명확
- 코드·데이터 공개 여부 프로젝트 페이지 확인 필요, 재현 비용 사전 파악 필요
- RoboCasa는 병렬조 그리퍼 중심 벤치마크로 추정 — 다지 손 조작으로 확장 시 pointmap 밀도·손가락별 접촉 표현 방식 추가 검증 필요

### (b) 핵심 기여

- 저비용 플랫폼에서도 동작 확인됨 — 하드웨어 스펙 제약이 있는 셋업에서도 적용 여지

### (d) 먼저 확인할 점

- 검증 플랫폼이 범용 로봇팔·그리퍼 중심 — 다지 손 손가락 관절 단위로 확장 시 정밀도·응답속도 추가 검증 필요
- 접촉확률 게이트의 오탐/미탐 비율이 초록에 미기재 — 다운스트림 정책에 미치는 영향 확인 필요
- 트랜스포머 실시간 추론이라 명시하나 실제 제어 주기 상 지연 수치는 본문 확인 필요

**NoContactNoWorries: Estimating Contact through Vision and Proprioception for In-Hand Dexterous Manipulation**

### (b) 핵심 기여

- 사람이 신체 자세 감각과 시각을 결합해 접촉을 추론하는 능력에서 착안, 로봇도 비전+고유수용감각만으로 접촉을 추론할 수 있는지 검증

- 여러 물체에 대해 단일 모델을 학습, 추론된 접촉 신호를 하류 강화학습(인핸드 물체 재정렬) 에이전트에 학습 신호로 제공해 미학습 물체로 일반화 확인

- 의사-촉각 신호를 강화학습 훈련 신호로 바로 활용한 사례 — 접촉 이진 신호의 최소 활용 형태를 보여줌
- 물체 일반화 확인됨 — 특정 물체 형상에 과적합되지 않는 방향의 근거

### (d) 먼저 확인할 점

- 이진 접촉(접촉/비접촉)만 다루며 접촉 강도·위치·미끄러짐 등 세분화된 신호는 다루지 않음 — 정밀 조작으로 확장 시 한계
- 실제 촉각 센서 기반 baseline과의 정량 비교가 초록에 없음 — 촉각 하드웨어 대비 성능 격차 확인 필요
- 단일 손(그리퍼 추정) 기준 검증으로 보임 — 다지 손 손가락별 접촉 귀속으로 확장 시 추가 검증 필요

**MECo-WAM: Learning 4D Geometric Priors for Inference-Efficient World Action Models**
[arXiv:2607.05468](https://arxiv.org/abs/2607.05468) · Jianjun Zhang, Jian Zhu, Taiyi Su, Chong Ma, Zitai Huang 외 · adjacent field: World Model (P5) → P2 D8/D9 · source: keyword-sweep (dynamics-aware+representation)

### (b) 핵심 기여

- 기존 비디오-액션 공동학습이 외형 중심 잠재표현에 치우쳐 정밀 조작에 필요한 시간적 기하 변화를 충분히 포착하지 못한다는 문제 지적
- 동결된 VGGT 인코더가 제공하는 관계형 타깃으로 지도되는 경량 4D 전문가를 비디오·액션 전문가와 함께 공동학습하는 구조 제안
- 비대칭 전문가 가시성으로 보조 기하 정보에서 액션 생성으로 향하는 비인과적 지름길을 차단
- decayed 4D read-mask attention으로 학습 초반에는 기하 정보를 강하게 제공하다 점진적으로 의존도를 낮춤
- 배포 시 보조 4D 컴포넌트를 전부 제거해 원래의 경량 추론 그래프를 유지하면서도 LIBERO 98.2%·RoboTwin 2.0 92.6%·실로봇 조작 과제에서 성능 개선

### (c) 시사점

- 기하 그라운딩 인코더를 학습 단계의 "교사" 로만 쓰고 배포 단계에서 제거하는 설계 — 관측 인코더 교체 없이도 기하 정보의 이득을 취하는 대안 경로 제시
- 지름길 학습을 막기 위한 비대칭 가시성 설계 — 보조 모달리티를 지도 신호로만 쓸 때 겪는 실패 모드에 대한 참조점
- 월드모델·액션 모델 계열에서 기하 그라운딩 인코더의 효용을 정량적으로 재확인한 사례

### (d) 먼저 확인할 점

- 코드·모델 공개 여부 확인 안 됨 — distillation 절차 재현 난이도 사전 파악 필요
- 4D 전문가 지도에 쓰인 "관계형 타깃"의 정확한 정의가 초록만으로 불명확 — 원문에서 확인 필요
- LIBERO·RoboTwin은 병렬조 그리퍼 중심 벤치마크로 추정 — 다지 손 조작 과제로의 이전 효과는 별도 검증 필요

- Reproducibility 2 — 아키텍처·distillation 절차 상세 기술, 공개 벤치마크(LIBERO·RoboTwin 2.0) 사용, 코드 공개 여부 미확인
- Methodology 3 — LIBERO 98.2%·RoboTwin 2.0 92.6% 및 실로봇 조작 과제 검증, 배포 시 보조 4D 컴포넌트 제거로 추론 비용 미증가 확인
- Sim2Real 2 — 시뮬레이션 벤치마크 2종 + 실로봇 조작 과제 검증
