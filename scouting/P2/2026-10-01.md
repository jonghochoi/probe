## 🥇 논문 1 — 우선순위 ★★

**Unified Visual-Tactile-Action Modeling from Human Demonstrations for Dexterous Manipulation**
[arXiv:2609.34182](https://arxiv.org/abs/2609.34182) · Wen-Qiao Li, Qian-You Zhao, Jia-Wen Hao, Xue-Zhou Zhu, Teng-Yu Liu 외 · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 이미지·촉각·손 동작을 동기 기록하는 촉각 모션캡처 시스템과 UVTA 데이터셋 구축, 5개 접촉 집약 과제 기준 사람 시연 1,000회와 과제당 로봇 시연 150회
- 사람 손과 로봇 손을 정렬된 촉각·액션 표현으로 사상하고 미래 액션·촉각 궤적을 공동 예측하는 Unified Visual-Tactile-Action Model 제안
- 배포 시 로봇 액션만 실행, 사람 시연은 접촉 인지 표현 학습의 지도 신호로만 활용
- 실물 5과제 평균 성공률 70%, 최강 비주오택타일 베이스라인 29%, 아키텍처 어블레이션 42%
- 사람 시연 증가에 따라 성능이 일관되게 상승, 과제당 1,000회에서도 포화 없음

### (c) 시사점
- 로봇 텔레오퍼레이션으로 얻기 어려운 촉각 데이터를 사람 시연으로 보충하는 경로의 정량 근거 확보
- 손 형태가 달라도 접촉 물리는 공통이라는 전제 위에서 이종 손 사이 촉각 표현 정렬 사례 확보 — 센서·손 교체에 강한 표현 설계 참고 가능
- 미래 촉각 예측을 공동 목적으로 두는 구조 — 촉각 토큰 학습 신호 설계 참고 가능

### (d) 먼저 확인할 점
- 코드 저장소 서술 없음, 프로젝트 페이지만 확인
- 사람 촉각 장비와 로봇 손 센서 사이의 정렬 가정 — 센서 물리가 크게 다른 손으로의 이식 여부 별도 확인 필요
- 손가락 단위 접촉 귀속 여부는 초록상 서술 없음 — 본문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**TACTIC: Understanding Tactile Encoders and Conditioning for Contact-rich Robot Manipulation Policies**
[arXiv:2609.30969](https://arxiv.org/abs/2609.30969) · Seongjin Bien, Débora Oliveira Makowski, Carlo Kneissl, Reihaneh Mirjalili, Pankhuri Vanjani 외 · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여
- 촉각 인코더 백본과 퓨전 전략을 동일 파이프라인·동일 실험 설정에서 통제 비교하는 종합 연구
- 접촉 집약 과제 여러 종에서 실물 롤아웃 2,000회 이상으로 평가, 시뮬레이션 비교 연구의 한계를 보완
- 핵심 결과로 모든 과제에 통하는 최적 표현·퓨전 전략은 없으며 최적 인코더·퓨전은 과제에 크게 의존

### (c) 시사점
- 퓨전 방식 선택이 성능을 좌우한다는 것을 대규모 실물 통계로 측정한 자료 — 연결 방식 대비 비용의 정량 기준점
- 과제 의존성 결과 — 단일 퓨전 구조 고정 전에 과제별 비교 실험 설계 필요성 시사

### (d) 먼저 확인할 점
- 초록에 코드·프로젝트 페이지 서술 없음
- 비교 대상 중 손가락 단위 귀속 구조 포함 여부는 초록상 서술 없음 — 본문 확인 필요
- 사용 하드웨어의 손가락 수와 센서 종류 미서술 — 다지 손 적용성 별도 확인 필요

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여
- 손끝 국소 촉각 반응과 관절 토크 피드백을 결합해 촉각 범위 밖 접촉의 하중 전달까지 포착하는 힘 인지 정책 HACo 제안
- Compliance Grounding Module이 게이트 방식 햅틱 크로스어텐션으로 진화하는 햅틱 상태에 액션 생성을 접지
- 컴플라이언스 조절 텔레오퍼레이션으로 액션 타깃 생성, 명령-상태 불일치를 보조 지도로 사용
- 실물 벤치마크 과제별 20회 시행 평균 성공률 83%, 최강 베이스라인 35%

### (c) 시사점
- 촉각과 관절 토크를 게이트 크로스어텐션으로 묶어 접촉 범위 밖 하중까지 반영하는 구조의 정량 근거 확보
- 힘 센서 없이 관절 토크로 촉각 공백을 메우는 경로 — 힘 모달리티 대체 신호 후보

### (d) 먼저 확인할 점
- 코드·프로젝트 페이지 서술 없음, arXiv comment 필드 자체가 비어 있음
- 과제별 20회 시행, 시드 변동성 서술 없음 — 본문 확인 필요
- 손가락별 토큰 구성 여부는 초록상 서술 없음
