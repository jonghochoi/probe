## 🥇 논문 1 — 우선순위 ★★★

**TORL-VLA**
[arXiv:2606.09337](https://arxiv.org/abs/2606.09337) · Huaihang Zheng, Yi Yang, Kai Ma et al. · source: keyword-sweep (tactile AND manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 기존 VLA 정책은 오프라인 사전학습 후 고정 배포; 배포 중 촉각·힘 피드백을 활용한 실시간 적응 메커니즘 부재
- **TORL-VLA 핵심 설계**
  - 손목 렌치(torque/force wrench) 신호를 관측 채널에 추가하여 VLA 입력으로 통합
  - **Intervention-censored critic** — 촉각 접촉 이벤트 구간 동안 환경 보상 대신 촉각 신호 기반 크리틱 가중치로 전환; 과도한 힘 인가·슬립 없이 정교한 파지 유도
  - 온라인 RL 루프: 배포 중 실시간 정책 가중치 갱신 — 오프라인 데모만으로 획득 어려운 접촉 민감 기술 학습
- **실험** — 실 로봇 3종 태스크(latch 열기, 컵 파지, 달걀 파지); 시뮬레이터 없이 직접 실 로봇 적용
- **진정으로 새로운 점** — VLA 온라인 RL과 렌치 기반 촉각 퓨전의 단일 프레임워크 통합; intervention-censored critic 구조는 기존 VLA·RLHF 문헌 미보고

### (c) 시사점

- **이종 모달리티 퓨전 경로 실효성 직접 검증** — 촉각·힘 토큰을 VLA 관측에 추가 시 온라인 RL 적응 루프 형성 가능함을 실 로봇에서 입증
- **Intervention-censored critic → fragile object 처리 전략** — 달걀·세라믹 등 깨지기 쉬운 객체 파지 시 과도한 힘 억제 훈련 기법으로 즉시 차용 가능
- **시뮬레이터 없이 직접 도입** — demo 데이터 + 온라인 RL 조합으로 접촉 적응 기술 획득; 초기 프로토타입 구축 경로로 활용 여지

### (d) 먼저 확인할 점

- **렌치 센서 종류 미확인** — 손목 6축 F/T 센서 기반인지 손가락 개별 촉각 센서 기반인지에 따라 토큰 구성과의 통합 경로 차이; 논문 내 명시 여부 확인 필요
- **Intervention 감지 기준 미명시** — 접촉 임계값 설정 방법, 촉각 노이즈 민감도 확인 권장
- **온라인 RL 수렴 비용 미보고** — 실용적 도입 전 수렴 에피소드 수, 리셋 비용, 안전 경계 설정 방법 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**AetheRock**
[arXiv:2606.09777](https://arxiv.org/abs/2606.09777) · Hong Li, Yue Xu, Yihang Tang et al. · source: keyword-sweep (tactile AND manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 촉각 표현이 특정 센서 하드웨어(sensor fidelity)에 종속; 센서 교체 시마다 표현 재학습 필요
- **AetheRock 핵심 설계**
  - **팔 착용형(arm-worn) 티칭 장치** — 인간 교사가 팔에 착용하고 조작하는 동안 force + vision 쌍 자연스럽게 수집
  - **ForceVT** — force 신호와 비전 신호를 결합하여 "충실도-무관(fidelity-agnostic)" 촉각 latent 표현 학습; 특정 센서 모델에 종속되지 않는 중간 잠재 공간 형성
  - **Teacher-student 구조** — force+vision → ForceVT teacher → 촉각 latent; 배포 시 촉각 센서 없이도 vision으로 teacher latent 근사 가능
- **실험** — 실 로봇 조작 태스크; 착용형 데이터 수집 → ForceVT 학습 → 정책 적용 파이프라인 엔드-투-엔드 검증
- **진정으로 새로운 점** — 촉각 표현이 센서 모델에 독립되도록 force+vision 교사로 학습하는 fidelity-agnostic 구성; 착용형 수집과 센서-독립 표현의 단일 파이프라인 통합

### (c) 시사점

- **센서 교체 비용 감소** — 충실도-무관 표현은 "swappable sensor head + common token format" 방향과 직결; 센서 업그레이드 시 재학습 없이 동일 latent 유지 가능성 제공
- **Force + vision → 촉각 교사 역할** — 고급 촉각 센서 미탑재 환경에서도 force 센서 + 카메라 조합으로 표현 획득; 도입 초기 센서 구성 유연성 확보
- **착용형 수집 → 시연 비용 절감** — 별도 조작 인터페이스 없이 인간 자연 시연 데이터 확보; 초기 데이터 파이프라인 간소화

### (d) 먼저 확인할 점

- **Teacher-student latent 정렬 품질 미정량화** — 촉각 센서 없이 vision만으로 teacher latent 근사 시 접촉 민감 태스크에서 성능 저하 수준 수치 확인 필요
- **착용형 티칭의 도메인 갭** — 인간 팔 동역학과 로봇 팔 동역학 차이 처리 방식 명시 여부 확인 권장
- **일반화 태스크 수 제한** — 실험 태스크 수가 fidelity-agnostic 주장을 충분히 뒷받침하는지 검토 필요

## 🥉 논문 3 — 우선순위 ★

**EgoPhys**
[arXiv:2606.16202](https://arxiv.org/abs/2606.16202) · Hyunjin Kim, Ri-Zhao Qiu, Guangqi Jiang, Xiaolong Wang · source: citation-graph (VGGT 인용)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **문제** — 변형 가능 물체(deformable object)의 강성·탄성 등 물리 특성을 RGB만으로 추정하기 어려움; 물리 엔진 기반 접근은 매개변수 식별 오버헤드 큼
- **EgoPhys 핵심 설계**
  - 에고센트릭(egocentric) RGB 비디오에서 **역 물리 코드북(inverse-physics codebook)** self-supervised 학습 — 물체 변형 패턴으로부터 강성·탄성 latent 코드 추정
  - 비디오 내 객체 변형 시퀀스 분석 → 코드북 인덱스로 물리 특성 이산화 → 정책 입력 채널 추가
  - 실 xArm6 로봇에서 foam·cloth 등 다양한 변형 특성 객체 대상 조작 계획 검증
- **진정으로 새로운 점** — 특수 물리 센서 없이 에고센트릭 RGB만으로 역 물리 특성 추론 코드북을 self-supervised로 학습; 변형 가능 객체 물리 추론의 센서-free 경로 개척

### (c) 시사점

- **동역학-인식 인코더의 물리 조건화 채널 추가 경로 제시** — 변형 특성 코드북을 관측 인코더 입력으로 추가하면 강성 적응 정책 구성 가능; 기존 RGB 스트림에서 동역학 인식 표현 확장 방법 제시
- **변형 가능 객체 영역 확장** — 딱딱한 물체 중심이던 동역학-인식 인코더 적용 범위를 soft-object까지 확장하는 근거 제공
- **도입 비용 낮음** — 추가 센서 없이 기존 로봇 카메라 스트림에서 물리 특성 추론; 설정 오버헤드 없이 변형 물체 태스크 적응

### (d) 먼저 확인할 점

- **코드북 이산화 한계** — 강성이 연속 변수임에도 이산 코드북 표현 시 세밀한 차이 구분 가능 여부 확인 필요
- **에고센트릭-로봇 카메라 도메인 갭** — 인간 에고센트릭 비디오로 학습한 코드북이 로봇 손목·헤드 카메라 스트림에 직접 적용되는지 도메인 갭 검증 필요
- **변형 물체 유형 일반화 미검증** — foam·cloth 외 rubber·gel 등 다른 변형 특성 객체 일반화 실험 미확인; 초기 물체 종류로 한정된 성능일 가능성

## 🌱 논문 4 — 인접 분야 픽 (월 1회)

**μ₀**
[arXiv:2606.13769](https://arxiv.org/abs/2606.13769) · Seungjae Lee, Yoonkyo Jung, Jusuk Lee et al. · adjacent field: World Model / Video-to-3D Interaction Trace (P5)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **핵심 아이디어** — 비디오에서 "3D 인터랙션 트레이스(interaction trace)"를 예측하는 세계 모델: 손·물체·도구·**접촉 영역(contact region)**의 3D 위치를 B-스플라인 곡선으로 명시적 표현
- **구성**
  - 멀티뷰 비디오 입력 → 손·물체·도구·접촉 영역의 과거+미래 3D 위치를 B-스플라인 파라미터로 예측
  - 접촉 영역까지 명시적으로 추적 — 힘 전달 지점의 3D 궤적 포함; 단순 손/물체 위치 예측을 넘어 접촉 의미론 명시화
  - Cross-embodiment: 인간 손부터 로봇 그리퍼까지 동일 트레이스 표현으로 정책 사전학습 및 전이
- **성능** — π₀(Physical Intelligence) 대비 경쟁적 cross-embodiment 조작 성능 달성
- **진정으로 새로운 점** — 접촉 영역까지 포함한 완전한 "인터랙션 트레이스" 개념; B-스플라인 3D 파라미터화로 smooth하고 compact한 궤적 표현

### (c) 시사점

- **접촉 영역 3D 궤적이 멀티카메라 그라운딩의 핵심 anchor** — 다중 카메라 공간 정합 시 접촉 위치 3D 궤적을 주요 anchor로 활용하는 아이디어 직접 시사; 다중 뷰 통합 전략에 반영 가능
- **B-스플라인 → 경량 동역학 인식 표현** — 고차원 포인트클라우드 대신 B-스플라인 파라미터를 동역학-인식 인코더 핵심 입력으로 사용하는 compact 경로 제시
- **Cross-embodiment 전이** — 인간 비디오 기반 인터랙션 트레이스 학습 → 로봇 직접 전이; 비용이 높은 로봇 전용 데이터 없이 인간 비디오 활용 루트 확보

### (d) 먼저 확인할 점

- **B-스플라인 해상도 선택 기준** — 빠른 접촉 이벤트(슬립, 힘 급변)를 B-스플라인이 얼마나 세밀하게 표현하는지, 제어 포인트 수 선택이 성능에 미치는 영향 확인 필요
- **접촉 영역 추적 정밀도** — 실 로봇 실험에서 접촉 영역 3D 위치 추적 정밀도 수치 확인 권장
- **직접 P2 통합 경로 미제시** — 세계 모델의 트레이스 출력을 관측 인코더 특징으로 변환하는 방법은 이 논문 범위 밖; 실제 통합 시 추가 브리지 설계 필요
