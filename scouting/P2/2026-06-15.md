## 🥇 논문 1 — 우선순위 ★★★

**FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation**
[arXiv:2606.13102](https://arxiv.org/abs/2606.13102) · Chengbo Yuan, Zicheng Zhang, Mingjie Zhou, Wendi Chen et al. · source: citation-graph (ViTacFormer 인용) + keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 기존 촉각 기반 정책들이 특정 하드웨어·센서 구성에 고정; 이미지 기반·배열 기반·상태 기반 촉각 신호의 이질성으로 크로스-센서 일반화 불가
- **FTP-1** — 다양한 촉각 센서와 임바디먼트에서 이전 가능한 촉각 조작 능력을 사전학습한 최초의 범용 촉각 파운데이션 정책
  - **이질 인코더(heterogeneous encoders)** — 이미지·배열·상태 기반 촉각 입력 유형별 전용 인코더로 처리 후 **형태-인식 잠재 토큰(morphology-aware latent tokens)** 투영
  - **공유 촉각 트랜스포머 전문가(shared tactile Transformer expert)** — 이질 잠재 토큰을 단일 Transformer가 공동 모델링
  - 26개 출처, 21개 센서, 약 3,000시간 인간·로봇 촉각 데이터 사전학습
- **진정으로 새로운 점** — 촉각 센서 유형 전반의 크로스-센서 이전 가능한 파운데이션 모델 최초; 사전 미인식 촉각 센서 설정으로 +31% 성공률 향상 — 학습 시점에 보지 못한 센서로 이전 가능함을 실증
- **결과** — 5개 하드웨어 구성 다운스트림 파인튜닝: 기인식 센서 구성 +17.2%, 미인식 센서 2종 +31% 성공률 향상; 코드·데이터셋·사전학습 모델 전체 공개 (ftp1-policy.github.io)

### (c) 시사점

- **swappable sensor head 설계의 대규모 실증** — 센서 유형별 이질 인코더 → 통합 형태-인식 토큰 → 공유 Transformer 구조가 21개 센서, 5개 하드웨어 구성에서 정량 입증; 이 아키텍처를 per-finger 촉각 토큰 파이프라인 초기화 경로로 직접 참조 가능
- **크로스-센서 이전 실증** — 미인식 센서 +31%: 학습 시 존재하지 않은 센서 하드웨어가 교체되더라도 공통 토큰 형식이 이전 가능한 수준의 유연성 수치로 확인
- **3,000h 공개 데이터** — 이 규모의 촉각 사전학습 데이터가 공개됨으로써 per-finger 촉각 인코더 초기화·파인튜닝 경로 확보 가능

### (d) 먼저 확인할 점

- **10개 손가락 다지 설정 미명시** — 21개 센서가 어떤 손 구조(2지, 4지, 다지 등)를 커버하는지 초록 미명시; 10개 손가락 동시 접촉 규모 지원 여부 본문·프로젝트 페이지에서 확인 필요
- **형태-인식 토큰 상세 구조 미공개** — 토큰 수·차원·어그리게이션 방식이 초록에 미명시; 공개 코드에서 실제 토폴로지 정보 반영 여부 확인 권장
- **손가락별 독립 접촉 귀속 불명** — 공유 Transformer가 손가락별 독립 접촉 신호를 분리 유지하는지, 전체 손 수준으로 병합하는지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**MV-Actor: Aligning Multi-View Semantics and Spatial Awareness for Bimanual Manipulation**
[arXiv:2606.10899](https://arxiv.org/abs/2606.10899) · Yinchen Tian, Huan Li, Muyao Peng, Xi Wang et al. · source: keyword-sweep (multi-camera+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제** — 기존 다중 카메라 정책들이 각 뷰를 독립 처리하거나 얕게 퓨전해 뷰 간 의미론적 지각 공유 불가; 소비자급 깊이 센서 노이즈로 공간 인식 신뢰도 저하
- **MV-Actor** — 바이매뉴얼 조작을 위한 통합 의미-공간 표현(semantic-spatial representation) 구축 다중뷰 인식 프레임워크
  - **Multi-view Semantic Interaction** — 뷰 간 크로스-어텐션으로 의미론적 지각 공유
  - **Semantic-Spatial Token Interaction** — 피드-포워드 재구성 모델(VGGT 계열) 특징으로 의미론적 토큰에 공간 인식 접지(grounding)
  - **Guided Metric Depth Repair** — 소비자급 깊이 노이즈를 보정해 신뢰 가능한 메트릭 앵커 확보
- **진정으로 새로운 점** — 의미 공유(Semantic Interaction) → 공간 접지(Spatial Grounding) → 깊이 보정을 계층적으로 통합; PerAct2 바이매뉴얼 벤치마크 SOTA 87.8% 달성
- **결과** — PerAct2 시뮬레이션 87.8% 평균 성공률; 실세계 바이매뉴얼 평가에서 뷰 변화·불안정 깊이 조건 하 RGB/RGB-D 기준선 대비 우세

### (c) 시사점

- **뷰 간 의미 정렬 후 3D 접지 순서 실증** — 뷰 간 의미 먼저 정렬 후 피드-포워드 3D FM으로 공간 접지하는 두-단계 설계가 단독 각 접근 대비 우수함을 정량 입증; 다중 카메라 임베딩 통합 아키텍처 설계 순서 참조 근거
- **바이매뉴얼 다중 카메라 환경 일반화 확인** — VGGT 계열 피드-포워드 3D FM 특징 주입이 단일 팔을 넘어 바이매뉴얼 다중 카메라 설정에서도 공간 인식 신뢰도를 높임을 실증
- **소비자급 깊이 보정 실용 경로** — Guided Metric Depth Repair로 저비용 깊이 센서에서도 신뢰 가능한 공간 임베딩 품질 유지; 예산 제약 하드웨어 환경에서의 적용 가능성 확인

### (d) 먼저 확인할 점

- **다지 손 근접 카메라 확장 미검증** — PerAct2 설정(손목 카메라 수 수준)에서 검증; 10개 손가락 근접 뷰 추가 시 Multi-view Semantic Interaction 비용 증가 여부 확인 필요
- **VGGT 계열 3D FM 실시간 지연** — 피드-포워드 재구성 모델이 실시간 스트리밍 제어 루프 내 지연 허용 내에서 작동하는지 미명시
- **코드 미공개** — 초록 내 저장소 링크 미언급; 구현 세부 사항 재현 전 공개 확인 필요

## 🥉 논문 3 — 우선순위 ★

**A Cross-view Fusion Framework for Robust 6-DoF Grasp Pose Estimation**
[arXiv:2606.06878](https://arxiv.org/abs/2606.06878) · Kangjian Zhu, Haobo Jiang, Jianjun Qian, Jin Xie · source: citation-graph (VGGT 인용)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제** — 6-DoF 파지 포즈 추정에서 코너뷰(corner view) 폐색 시 단일 카메라 기반 추정 강건성 저하; 기존 다중뷰 재구성은 태스크-비특이적이고 계산 비용 과다
- **크로스뷰 융합 프레임워크** — 보조 뷰(auxiliary view)를 병행해 폐색 완화; 태스크-비특이적 전체 3D 재구성을 피하는 포스트-퓨전(post-fusion) 방식
  - **자기지도 대조 학습** — 크로스뷰 대응점/비대응점 쌍 학습으로 포인트 클라우드 피처의 공간 일관성 및 방향 변별력 강화
  - **크로스뷰-정렬 원통 통합 모듈** — 크로스뷰 포인트를 유사도 기반 정렬 후 원통 좌표계 등록 → 회전-대칭 기하학 강조; 로컬 셀프-어텐션 + 시드 크로스-어텐션 교차 적용
- **진정으로 새로운 점** — 크로스뷰 대조 학습 + 원통 좌표 통합 조합으로 GraspNet-1Billion 강한 성능; 태스크-비특이적 재구성 없이 실시간 크로스뷰 정렬로 강건성 확보
- **코드 공개** — github.com/KJZhuAutomatic/Cross-view-Grasp

### (c) 시사점

- **뷰 간 대조 학습의 공간 일관성 강화 효과** — 크로스뷰 포인트 쌍 대조 학습이 피처 공간의 공간 일관성을 크게 향상시킴을 실증; 다중 카메라 통합 인코더 설계 시 뷰-일관성 손실(cross-view consistency loss) 추가 근거 확보
- **포스트-퓨전 계산 효율** — 전체 3D 재구성 없이 보조 뷰 정보를 파지 관련 피처에 선택적 통합; 실시간 조작 루프에서 다중 카메라 결합 비용 절감 경로 참조 가능
- **실세계 파지 강건성 실증** — 소비자 RGB-D + 보조 뷰 조합으로 코너뷰 폐색 조건에서 실세계 파지 성공; 다중 카메라 관측 인코더의 실용적 폐색 대응 선례

### (d) 먼저 확인할 점

- **파지 특화 기하학** — 원통 좌표계가 파지 방향 대칭성에 최적화; 인핸드 조작(손가락 수준 접촉)에서의 적용 가능성은 별도 확인 필요
- **단일 모달리티(포인트 클라우드)** — 촉각·힘 등 추가 모달리티와의 결합 방법은 논문 범위 밖; 이질 모달리티 퓨전 설계로의 직접 이전에는 추가 설계 필요
- **테이블-탑 파지 편향** — GraspNet-1B 시나리오에서 검증; 다지 손 인핸드 조작 환경으로 이전 시 회전-대칭 가정 재검토 필요

## 🌱 논문 4 — 인접 분야 픽

**WEAVER: An Effective World Model for Robotic Manipulation**
[arXiv:2606.13672](https://arxiv.org/abs/2606.13672) · Arnav Kumar Jain, Yilin Wu, Jesse Farebrother, Gokul Swamy et al. · adjacent field: 다중뷰 세계 모델 (P5) → 다중뷰 잠재 표현 일관성

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제** — 기존 세계 모델들이 충실도(fidelity)·일관성(consistency)·효율성(efficiency) 세 요건을 동시 충족하지 못함; 장기 다이나믹 조작 태스크에서 실패
- **WEAVER (World Estimation Across Views for Embodied Reasoning)** — 세 요건을 동시 달성하는 다중뷰 세계 모델
  - **다중뷰 미래 잠재 벡터 공동 예측** — 플로우-매칭(flow-matching) 손실로 미래 잠재 벡터와 보상 값을 뷰 전반에 걸쳐 일관되게 예측
  - **세 가지 활용 모드** — 정책 평가(ρ=0.870), 정책 개선(π₀.₅ 대비 +38%), 추론 시간 계획(+14%, 5–10× 속도 향상)
- **진정으로 새로운 점** — 단일 모델이 평가·개선·계획 세 역할을 동시 달성; 실하드웨어 검증으로 다중뷰 세계 모델의 다운스트림 활용 체계 최초 실증
- **코드·모델 공개** — arnavkj1995.github.io/WEAVER

### (c) 시사점

- **다중뷰 플로우-매칭 잠재 예측의 시공간 일관성** — 뷰 전반에 걸친 미래 잠재 예측이 실하드웨어 수준(ρ=0.870)의 충실도 달성; 다중 카메라 공간 임베딩의 시공간 일관성 목표 설정 근거 강화
- **플로우-매칭 다중뷰 확장 가능성** — 단일 시점 접촉-구동 플로우 매칭이 다중 카메라 잠재 공간 예측으로 확장 가능함을 시사; 이질 모달리티 퓨전 손실 설계에 간접 참조 근거
- **관측 인코더 품질이 세계 모델 충실도에 직결** — +38% 정책 개선이 다중뷰 표현 품질에 의존함을 내포; 고품질 다중 카메라 관측 인코더의 P5 세계 모델 파급 효과 시사

### (d) 먼저 확인할 점

- **테이블-탑 조작 위주 검증** — π₀.₅ 기반 실험; 손가락 수준 접촉 집약적 다지 조작으로의 이전 가능성 미검증
- **카메라 구성 고정 가정** — π₀.₅ 표준 다중뷰 설정 기반; 동적 카메라 추가·제거 환경에서의 일반화 미검증
- **인접 분야 간접 활용** — P2 관측 인코더 설계에 직접 적용되는 것은 다중뷰 잠재 표현 일관성 부분에 한정; 촉각·힘 등 이질 모달리티 통합은 논문 범위 밖

## 💡 컨텍스트 제안

### Tracked literature

- **FTP-1 ([arXiv:2606.13102](https://arxiv.org/abs/2606.13102)) — P2 Methodology base 등재 제안**
  - **제안** — 코드·데이터셋·사전학습 모델 공개 완료; P2 Methodology base에 `FTP-1` 항목 추가 즉시 검토
  - **Overlap** — 이질 인코더 → 통합 형태-인식 토큰 → 공유 Transformer 파이프라인이 swappable sensor head + common token format 설계와 직접 대응(D11); 크로스-센서 이질 퓨전(D10)
  - **Difference vs. P2** — 단일 모달리티(촉각)에 특화; 시각+촉각+고유감각 복합 퓨전 및 per-finger 토폴로지 명시는 미검증
  - **Watch trigger** — 다지 손(10개 손가락) 동시 접촉 규모 실험 공개 시, 또는 FTP-1 파인튜닝을 통한 per-finger 토큰 구성 사례 등장 시

### Decision Log

- **D11 이질 인코더 초기화 경로 deferred 추가** — 근거 FTP-1(2606.13102). D11 v1 per-finger proprio-tactile binding / swappable sensor head 스펙에 "FTP-1 이질 인코더 아키텍처(21개 센서 이전 가능 실증, 공개 사전학습 모델)"를 deferred 촉각 인코더 초기화 경로로 추가 제안. 트리거 — 새 촉각 하드웨어 도입 시 초기 학습 데이터 부족이 swappable head 교체 일정을 지연시킬 때; FTP-1 사전학습 → 파인튜닝으로 초기 데이터 의존성 해소 가능

- **D8 의미-공간 통합 설계 순서 근거 보강** — 근거 MV-Actor(2606.10899). D8 v1 geometry-grounded multi-view encoder 스펙에 "뷰 간 의미 정렬(semantic cross-view attention) 후 3D FM 공간 접지(spatial grounding) 순서"를 설계 원칙으로 추가 제안. 근거 — MV-Actor가 이 순서가 단독 각 접근 대비 우수함을 PerAct2 SOTA 수치로 입증; 크로스뷰 대조 학습의 공간 일관성 강화 효과(Cross-view Grasp)가 독립 보완 근거로 누적

### Anti-topics

- **경계 유지** — Tac-DINO(2606.12069, 로봇 정책 실험 없는 촉각 표현 학습)·Stream3D-VLM(2606.06891, 로봇 조작 없는 3D 이해 VLM)이 각각 "P2 입력 결합 없는 순수 표현 학습"·"로봇 액션 없는 VQA" 경계로 자연 탈락; 추가 경계 명확화 불필요
