## 🥇 논문 1 — 우선순위 ★★★

**Lift3D-VLA: Lifting VLA Models to 3D Geometry and Dynamics-Aware Manipulation**
[arXiv:2607.06564](https://arxiv.org/abs/2607.06564) · Jiaming Liu, Qingpo Wuwu, Nuowei Han, Hao Chen, Zhuoyang Liu, Fan Fei · source: citation-graph (VGGT 인용)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- 2D 모델-리프팅 전략 확장 — 사전학습 2D 위치 임베딩에 3D 포인트를 기하학적으로 정렬해, VLA 비전 인코더 내부에서 포인트클라우드를 직접 인코딩하면서 공간 정보 손실 최소화
- Geometry-Centric Masked Autoencoding(GC-MAE) — 현재 포인트클라우드 재구성 + 미래 기하학적 변화 예측을 동시에 수행하는 이중 목적 자기지도학습으로 3D 구조와 물리적 동역학을 함께 내재화
- 계층별 시간 액션 모델링 — LLM의 여러 레이어가 협력해 액션 청크를 예측, 시간적으로 일관된 액션 생성 확보
- 시뮬레이션 22개 과제(MetaWorld·RLBench) + 실물 8개 조작 과제 전 구간 검증 — 최고 성능 기존 VLA 대비 각각 +10.8pp·+11.1pp, 최강 실물 baseline 대비 +4pp; 분포 외 교란에 대한 일반화도 강함

### (c) 시사점

- 3D 기하 정렬과 미래 기하 예측을 하나의 자기지도 목적함수로 묶는 설계 — 기하 그라운딩(D8)과 동역학-인식 인코딩(D9)을 별도 구현이 아닌 단일 사전학습 목적으로 동시 달성하는 구체적 참조 아키텍처 확보
- 포인트클라우드를 2D 위치 임베딩에 직접 정렬하는 방식 — 기존 VGGT/eVGGT류의 별도 기하 인코더 병렬 추가 경로와 다른, 비전 인코더 내부 통합형 대안 제공
- 실물 8과제 + 미노출 교란 조건까지 포함한 폭넓은 검증 — 두 축(기하·동역학)을 동시에 다루는 설계의 실물 타당성을 비교적 두터운 증거로 뒷받침

### (d) 먼저 확인할 점

- "이전 작업 Lift3D 기반"이라는 서술 외 코드·모델 공개 여부 본문·comment 필드 미기재 — 재현 비용 확인 필요
- 22개 시뮬 과제가 MetaWorld·RLBench 두 벤치마크에 한정 — 다지 손 접촉 집약적 조작으로의 일반화는 실물 8과제 세부 확인 필요
- GC-MAE의 미래 기하 예측이 액션-조건 없이 이루어지는지, 액션 시퀀스와 함께 학습되는지 원문에서 명확히 구분 필요

## 🥈 논문 2 — 우선순위 ★★

**Feeling the Unexpected: ResTacVLA for Contact-Rich Manipulation via Residual Tactile Representation**
[arXiv:2607.03387](https://arxiv.org/abs/2607.03387) · Pengwei Zhang, Bin Xie, Ce Hao, Xinpan Meng, Xinyu Guo · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- 예측 부호화(Predictive Coding) 이론 차용 — 시각-촉각 통합 시 고대역폭 시각 특징이 저대역폭 촉각 단서를 압도하는 "모달리티 붕괴" 문제를 명시적으로 재정의
- Residual Tactile Representation — 촉각 원시 신호 대신 시각적 사전 기대와 실제 물리 감각 사이의 불일치(잔차)를 인코딩, 시각으로 예측 가능한 동역학을 걸러내 희소 촉각 신호를 고정보 신호로 전환
- Latent Contact Primitives — 벡터 양자화(VQ) 병목으로 잔차를 이산화해 시각이 놓치는 핵심 접촉 이벤트를 포착
- 불확실성-기반 적응적 게이팅 — 시각 사전 확신도가 낮은 구간에서만 촉각 잔차 의존도를 우선시해 시각 지배 현상을 명시적으로 방지
- 다양한 접촉 집약적 조작 과제 전반에서 전 baseline 대비 일관된 우위, 예기치 못한 동적 교란에도 강건성 유지

### (c) 시사점

- 촉각을 "복원할 결측 신호"가 아니라 "시각 예측의 잔차"로 재정의하는 프레임 — flat-concat이 촉각 신호를 왜 잃어버리는지(대역폭 불균형)에 대한 명시적 이론적 근거 제공
- VQ 이산화 + 불확실성 게이팅 조합 — 접촉/비접촉 구간을 동적으로 구분하는 기존 게이팅 방식(AVTAG 등)과 달리, 시각 예측 신뢰도 자체를 게이팅 신호로 사용하는 대안적 구현 경로
- 신경과학적 예측 부호화 프레임이 촉각-시각 비대칭 퓨전 설계의 이론적 정당화 축을 하나 더 추가

### (d) 먼저 확인할 점

- 실험 결과가 "전 baseline 대비 일관된 우위"로만 서술 — 구체적 성공률 수치·과제 목록·baseline 명단 본문 확인 필요
- 시뮬레이션 검증인지 실물 로봇 검증인지 초록에서 명시적으로 구분되지 않음 — project 페이지(awilekong.github.io/ResTacVLA) 통해 확인 필요
- VQ 병목의 코드북 크기·이산화 손실이 미세한 슬립·힘 크기 조절이 필요한 과제에서 정보 손실을 일으키는지 별도 검증 권장

## 🥉 논문 3 — 우선순위 ★

**Current as Touch: Proprioceptive Contact Feedback for Compliant Dexterous Manipulation**
[arXiv:2607.03529](https://arxiv.org/abs/2607.03529) · Chenyang Ma, Yunchao Yao, Zhenyu Wei, Ruogu Li, Daniel Szafir · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- 문제 재정의 — 촉각·힘 센서 없이 저비용 로봇 손에서도 컴플라이언스를 구현하기 위해, 모터 전류 + 관절 상태만으로 접촉-인지 컴플라이언스 단서를 학습하는 프레임워크 제안
- 컴플라이언스 기준 위치 예측 — 외부 렌치 추정이나 토크 명령 대신, 표준 PD 컨트롤러의 목표 관절 위치(적정 위치 오차가 적정 파지력을 유도)를 예측하는 위치-기반 정식화
- 모터 전류를 힘 프록시이자 학습 가능한 고유 수용 접촉 신호로 동시 활용 — 텔레오퍼레이션·정책학습 파이프라인과 호환되는 형태로 실시간 상호작용력 적응
- 다수 다지 손·다양한 접촉 집약적 과제(취약 물체 취급·지속적 표면 접촉·얇은 물체 회수·동적 하중 적응)에서 안정적 컴플라이언트 파지, 더 안전하고 효율적인 텔레오퍼레이션, 다운스트림 정책학습 향상 확인

### (c) 시사점

- 촉각·힘 센서 완전 배제 경로 — NoContactNoWorries(비전+고유 수용, 이진 접촉)와 상호 보완적으로, 순수 고유 수용(모터 전류)만으로 연속적 컴플라이언스 신호까지 확장하는 사례
- D11 "스와핑 가능한 센서 헤드" 요구의 극단 — 별도 하드웨어 없이 기존 액추에이터 전류값만 재사용하므로, 센서 부재 플랫폼에서도 즉시 적용 가능한 가장 저비용 경로
- 위치-기반 정식화가 기존 PD 컨트롤러·텔레오퍼레이션 파이프라인과 호환 — 아키텍처 전면 교체 없이 접촉-인지 컴플라이언스를 추가하는 실용적 삽입 지점 제공

### (d) 먼저 확인할 점

- 정량 성공률·baseline 비교 수치가 초록에 구체적으로 제시되지 않음 — 본문에서 확인 필요
- 모터 전류-토크 매핑의 액추에이터별 캘리브레이션 필요 여부 — 하드웨어 교체 시 재보정 비용 확인 필요
- 관절 수가 적은 저자유도 핸드에서 손가락별 세밀한 접촉 구분이 가능한지, 다지 손 전용 정밀도 별도 확인 권장

## 🌱 논문 4 — 인접 분야 픽

**TACO: TActile World Model as a Self-COrrector for Scalable VLA Post-Training**
[arXiv:2607.02840](https://arxiv.org/abs/2607.02840) · Shengbang Liu, Yueru Jia, Yuyang Yan, Jiaming Liu, Xinran Zhang · adjacent field: World Model (P5) → P2 D10 · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- Recognize-Imagine-Label 루프 — 실물 로봇 실행 실패 인접 상태를 진행률 추정으로 인식, 시각-촉각 생성 모델이 국소 교정 구간을 상상, 진행률-액션 모델이 실행 가능한 교정 액션으로 라벨링하는 3단계 파이프라인
- 촉각-인지 세계 모델 — 순수 시각 세계 모델이 시각적으로는 그럴듯하지만 접촉 물리와 불일치하는 궤적을 상상하는 문제를, 시각-촉각 생성 모델로 보완
- 지식-격리 촉각 적응 + 어드밴티지-조건화 학습 — 상상된 교정으로 VLA를 후속학습하되 사전학습된 시각-언어 프라이어 손상 방지
- 실물 접촉 집약적 조작 과제에서 기본 정책 대비 절대 성공률 +44pp, 지식-격리 촉각 적응 미적용 대비 +32pp

### (c) 시사점

- 세계 모델이 상상하는 "교정 롤아웃"에 촉각 일관성을 명시적으로 요구하는 설계 — 순수 비전 세계 모델의 맹점(시각적으로 그럴듯하나 접촉 물리 위반)을 촉각 신호로 보완하는 구체적 사례
- P5 세계 모델 경로에서 촉각-비전 이질 모달리티를 결합하는 방식이, P2 D10의 비대칭 퓨전 설계에 참조 가능한 또 다른 통합 지점(정책 입력단이 아닌 후속학습 교정 루프)으로 제시
- 사전학습 프라이어 보존과 신규 모달리티(촉각) 통합을 동시에 달성하는 지식-격리 적응 방식 — MuSe(2607.02 리포트)의 "모달리티 추가 시 기존 성능 보존" 방향과 궤를 같이함

### (d) 먼저 확인할 점

- 세계 모델(WAM) 프레이밍이 핵심이라 P2의 관측 인코더·퓨전 아키텍처 자체보다 후속학습 파이프라인 기여가 중심 — D10 인코더 설계로 직접 이식 가능한 부분과 후속학습 전용 구성요소 구분 필요
- 단일 로봇/과제 스위트 범위 초록만으로 불명확 — 과제 다양성·일반화 범위 본문 확인 필요
- 코드·모델 공개 여부 초록 미명시 — 재현 비용 확인 필요
