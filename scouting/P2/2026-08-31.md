## 🥈 논문 1 — 우선순위 ★★

**VISTA: Visually Inferred Spatial ConTact Attention for Contact-Rich Manipulation**
[arXiv:2608.25872](https://arxiv.org/abs/2608.25872) · Jiayi Chen, Wenlong Dong, Yan Huang, Xianglin Chen, Zijian Lin 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 유연 그리퍼의 3D 변위를 담은 Visual Deformation Field(VDF)를 시각만으로 도출해 접촉 상태를 고차원 시각-물리 피드백으로 대체하는 VISTA-Policy 제안
- 실시간 VDF 디코딩을 맡는 Physics-Aware Encoding Engine, 실제 상호작용 신호만 분리하는 Energy Aggregation Denoising Mechanism, 점진적 그리퍼 액션으로 폐루프 보정을 수행하는 Deformation-Augmented Policy Network 세 요소로 구성
- 크로스스케일 물체 파지·뚜껑 풀기·서예 쓰기 세 실물 과제에서 순수 비전 기준선(3D Diffusion Policy)과 촉각 기준선 양쪽 대비 우위 확인

### (c) 시사점
- 촉각·힘 센서 하드웨어 없이도 접촉 반응성 확보 가능함을 실증 — 센서 비용·캘리브레이션 부담을 우회하는 대안 경로
- 학습 시 보지 못한 물체 스케일로의 일반화, 동적 교란 상황 강건성까지 확보 — 배포 조건 다양성에 대한 여유 확보
- 순수 비전 정책과 촉각 정책 양쪽을 능가 — 시각 기반 접촉 추론이 실제 촉각 센서를 대체할 잠재력의 근거 사례 축적

### (d) 먼저 확인할 점
- 컴플라이언스를 가진 특수 그리퍼 구조 전제 — 일반 강성 그리퍼로의 이식 가능성 별도 확인 필요
- 코드 저장소 공개 서술 없음, 영상·보충자료 페이지만 확인
- 세 과제 모두 단일 팔·단일 그리퍼 기준 — 다지 손 세밀 조작으로의 확장 여부 미검증

## 🥈 논문 2 — 우선순위 ★★

**V-Link: Recovering Lost Visual Representations in Action DiT for Vision-Language-Action Models**
[arXiv:2608.25308](https://arxiv.org/abs/2608.25308) · Yehao Lu, Jiarui Yang, Yuning Su, Yufeng Xie, Yu Zhong 외 · arXiv preprint · source: citation-graph (VGGT) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- VLA 액션 전문가가 VLM 특징 내 3D 기하·2D 의미 정보에 접근이 제한된다는 구조적 한계를 실증적으로 규명
- 시각-언어에서 액션으로의 특징 전이 과정에서 손실된 시각 표현을 비대칭 경로로 복원하는 V-Link 제안 — Spatial Query는 기하 조건화, Semantic Query는 기존 VLM 이미지 토큰 보완을 각각 전담
- 기저 모델 GR00T N1.6 대비 세 시뮬레이션 벤치마크와 실물 휴모노이드 두 과제 전반에서 일관된 성능 향상 확인

### (c) 시사점
- 액션 생성 단계에 기하 조건화를 별도 경로로 주입하는 설계 — 기존 VLA 파이프라인에 소규모 모듈 추가로 적용 가능한 이식 경로
- 실물 휴모노이드 조작에서 20%p대 성능 향상 확인 — 시뮬레이션 개선폭이 실물로 이어짐을 직접 검증
- 기하·의미 정보를 분리된 경로로 다루는 비대칭 구조 — 관측 인코더 개선과 정책 아키텍처 개선을 독립적으로 조합 가능한 참고 사례

### (d) 먼저 확인할 점
- 코드 저장소·체크포인트 공개 서술 전무 — 재현 가능성 미확정
- 벤치마크별 향상폭 편차 큼(LIBERO +1.9%p, LIBERO-Plus +31.2%p) — 벤치마크 특성에 따른 민감도 원인 별도 확인 필요
- Spatial/Semantic Query 두 경로의 학습 비용·추론 오버헤드 초록상 불명확
