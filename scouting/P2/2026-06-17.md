## 🥇 논문 1 — 우선순위 ★★★

**T-Rex: Tactile-Reactive Dexterous Manipulation**
[arXiv:2606.17055](https://arxiv.org/abs/2606.17055) · Dantong Niu, Zhuoyang Liu, Zekai Wang, Boning Shao et al. · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 기존 VLA 모델이 촉각 모달리티를 생략하거나 정적 촉각 인코더(static tactile encoder)에 한정; 데이터 부족·아키텍처 제약·정적 인코더 한계 세 원인이 복합 작용
- **T-Rex 핵심 설계**
  - **가변-속도 Mixture-of-Transformers(MoT) 아키텍처** — 시각(저주파)·촉각(고주파) 스트림을 가변 속도로 독립 처리; 기존 VLA의 동기 클록 병목 해소
  - **시간적 촉각 VQ-VAE 인코더** — 고주파 터치 신호를 시간 축 상에서 이산 코드북으로 압축; 정적 인코더가 놓치는 접촉 역동성(contact dynamics) 포착
  - **100시간 촉각-풍부 데이터셋** — 기본 모터 프리미티브 중심 수집 레시피로 데이터 효율화
- **진정으로 새로운 점** — VLA의 정적 촉각 인코더 한계를 시간적 VQ-VAE + 가변-속도 MoT 조합으로 체계적 해결한 첫 사례; 기존 고주파 촉각 통합 시도가 개별 문제를 다뤘다면 T-Rex는 세 병목을 동시 해결
- **결과** — 12개 조작 태스크(섬세한 힘 제어 + 변형 물체 조작); 최강 기준선 대비 평균 성공률 30%+ 향상; 실제 로봇 검증

### (c) 시사점

- **고주파 촉각 토큰 통합 경로 실증** — 가변-속도 MoT가 촉각·시각 스트림의 시간 해상도 불일치를 아키텍처 수준에서 해소; 이질 모달리티 퓨전 설계에 "비동기 속도 분리 + 고주파 압축 코드북"이라는 구체 구현 경로 제공
- **시간적 VQ-VAE의 촉각 인코더 재설계 근거** — 기존 정적 CNN 인코더의 시계열 정보 손실을 정량 입증; 하드웨어 비종속 공통 토큰 포맷 설계 시 시간 축 압축 단계 추가 검토 근거
- **100h 공개 데이터셋** — 초기 촉각 인코더 사전학습 데이터 부족 문제에 대한 즉시 활용 가능한 외부 자원 확보

### (d) 먼저 확인할 점

- **10개 손가락 동시 접촉 규모 미명시** — 12개 태스크에서 어떤 핸드 구성(손가락 수)을 사용했는지 초록 미명시; 5지·10지 규모 동시 접촉 지원 여부 본문 확인 필요
- **VQ-VAE 코드북 크기·압축율 미공개** — 고주파 촉각 신호 대역 손실 여부와 슬립(slip) 검출 정밀도 유지 여부 확인 필요
- **코드 저장소 미확인** — 초록 내 공개 링크 미언급; 재현 전 저장소 공개 상태 확인 권장

## 🥈 논문 2 — 우선순위 ★★

**ViTaL: Inference-time Policy Steering via Vision and Touch**
[arXiv:2606.14981](https://arxiv.org/abs/2606.14981) · Yilin Wu, Zilin Si, Zeynep Temel, Oliver Kroemer · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- **문제** — 기존 추론-시간 조정(inference-time steering) 방법이 시각 관측만으로 후보 액션 검증; 접촉 집약적 태스크에서 시각 단독으로는 국소 접촉력 포착 불가
- **ViTaL 이중-수준 최적화**
  - **고수준(시각 기반)** — 시각 샘플링·검증으로 장기 모드 선택(어떤 행동을 실행할지 결정)
  - **저수준(촉각 기반)** — 촉각-가이드 확산 편집으로 선택된 액션 시퀀스를 단기 수평에서 국소 접촉 요건 충족 방향으로 정제
  - **비주오택타일 잠재 세계 모델** — 시각·촉각 미래 예측을 잠재 공간에서 공동 모델링
  - **텍스트-조건부 촉각 보상** — 예측된 촉각 미래를 잠재 공간에서 직접 점수화하는 촉각 보상 함수
- **진정으로 새로운 점** — 비주오택타일 이중-수준 최적화 프레임워크 최초; 단순 멀티모달 결합 대비 확산 편집 + 잠재 촉각 보상 조합이 접촉 정밀도 향상에 기여함을 실증
- **결과** — 실제 로봇 3개 접촉 집약적 태스크; 기본 정책 대비 +51%, 단일-모달 조정 대비 +33%, 단순 멀티모달 퓨전 대비 +20% 성공률 향상; 프로젝트 페이지 공개

### (c) 시사점

- **단순 멀티모달 퓨전의 한계 정량 입증** — "단순 멀티모달 퓨전 대비 +20%"는 퓨전 구조 자체가 성능 병목임을 수치로 확인; 이질 모달리티 퓨전 설계에서 "어떻게 결합하는가"가 "무엇을 결합하는가"만큼 중요함을 실증
- **비대칭 수준 분리 설계의 실용성** — 시각(장기·전역)과 촉각(단기·국소)의 역할 비대칭을 이중-수준 최적화로 구현; 이 수준 분리 원칙을 퓨전 아키텍처 계층 설계에 적용 검토 가능
- **잠재 공간 촉각 보상** — 픽셀 수준 예측 없이 잠재 공간에서 촉각 미래 점수화; 공통 토큰 포맷 활용 시 인코더 효율 유지하는 보조 보상 설계 방향 참조

### (d) 먼저 확인할 점

- **추론-시간 오버헤드** — 확산 편집 + 샘플링·검증 루프가 실시간 제어 루프에서 지연 허용 범위 내인지 미명시; 고주파 접촉 반사 루프 통합 시 레이턴시 측정 필요
- **촉각 센서 종속성** — 사용 촉각 센서 유형과 세계 모델 학습 데이터 규모 미명시; 다른 센서 유형으로의 이전 가능성 확인 필요
- **다지 손 10개 손가락 설정 미확인** — 3개 태스크에서 어떤 말단 장치(end-effector) 사용했는지 초록 미명시

## 🥉 논문 3 — 우선순위 ★

**WT-UMI: Tactile-based Whole-Body Manipulation via Force-Supervised Contact-Aware Planning**
[arXiv:2606.13232](https://arxiv.org/abs/2606.13232) · Jaehwi Jang, Zhaoyuan Gu, Alfred Cueva, Zimeng Chai et al. · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 벌크·변형·공유-하중 물체 전신 조작 시 분산 접촉 감지와 명시적 힘 조절 필요; 기존 모방 학습 정책은 접촉력을 암묵적으로만 처리
- **WT-UMI 설계**
  - **착용형 전신 촉각 인터페이스** — 인간 시연·휴머노이드 원격조종 양쪽 모드에서 촉각 이미지·접촉력·말단 자세 동시 수집
  - **힘-조건부 목표 자세 보정 모듈** — 인간 자세 측정값을 원격조종 데이터로 학습한 보정 함수를 통해 접촉-인식 로봇 목표로 변환
  - **힘-감독 플래너** — 말단 자세 청크(end-effector pose chunks)와 접촉력 궤적을 동시 예측; 예측 접촉력이 촉각 기반 어드미턴스 컨트롤러(admittance controller)의 참조값
- **진정으로 새로운 점** — 인간 시연(자연스러운 힘 조절 포함)과 원격조종(로봇 실행 가능 액션 포함)의 보완 모달리티를 착용형 인터페이스 하나로 통합; 힘 감독 플래너 + 촉각 어드미턴스 컨트롤러의 계층 결합 최초
- **결과** — 5개 접촉 집약적 태스크(변형·벌크 강체·인간-휴머노이드 협업); 4개 정책 기준선 대비 성공률 향상·접촉 위치 추적 오류 감소; 프로젝트 페이지(wt-umi.github.io/WTUMI/) 공개

### (c) 시사점

- **힘-촉각 분리·계층 구조의 실용 검증** — 힘(전역·저해상도)을 플래너 감독 신호로, 촉각(국소·고해상도)을 컨트롤러 피드백으로 역할 분리하는 구조가 실제 휴머노이드에서 정량 입증; 힘·촉각 비대칭 퓨전 설계의 구체 참조 선례
- **시연-원격조종 보완 데이터 전략** — 자연 힘 조절이 풍부한 인간 시연 + 실행 가능 액션이 포함된 원격조종을 동시 활용하는 방법; 촉각 데이터 수집 파이프라인 설계에 간접 참조
- **어드미턴스 컨트롤러 통합 패턴** — 예측 접촉력을 실시간 컨트롤러 참조값으로 직접 연결하는 피드포워드 방식; 접촉 토큰 보조 목표(contact-binary aux head)와 컨트롤러 통합 설계 방향 참조

### (d) 먼저 확인할 점

- **전신 조작 → 다지 손 적용 간극** — 분산 접촉 감지가 손가락 수준 독립 귀속까지 세분화되지 않음; 10지 독립 접촉 구분으로의 확장 별도 검토 필요
- **착용형 인터페이스 교정 비용** — 힘-조건부 보정 모듈이 원격조종 시연 데이터로 학습되므로 새 하드웨어 구성마다 재수집 필요 여부 확인 권장
- **촉각 센서 유형 미명시** — 어떤 촉각 이미징 방식인지 초록에 미명시; 변형 이미징 방식과 호환성 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**WAM4D: Fast 4D World Action Model via Spatial Register Tokens**
[arXiv:2606.14048](https://arxiv.org/abs/2606.14048) · Ying Li, Xiaobao Wei, Jiajun Cao, Hao Wang et al. · adjacent field: 세계 액션 모델 (P5) → 경량 공간 등록 토큰을 통한 기하학 사전 이전

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **문제** — 기존 세계 액션 모델(WAM)이 2D 비디오·잠재 공간에서 동작해 정밀 조작에 필요한 3D 공간 제약·폐색 접촉 기하학을 놓침; 밀집(dense) 4D 표현 전체를 예측하면 기하학 디코딩 비용 과다로 인과 액션 생성 속도 저하
- **WAM4D 핵심 설계**
  - **공간 등록 토큰(spatial register tokens)** — 학습 시 미래 깊이 판독기로 사용해 VGGT 스타일 사전학습 기하학 사전을 인과 비디오-액션 트랜스포머로 이전; 추론 시 분기 제거로 경량화
  - **인과 혼합 어텐션** — MoT(Mixture-of-Transformers) 백본 내 비디오·액션·기하학 토큰 간 모달리티별 가시성 정의; 비인과 지름길(non-causal shortcut) 방지
- **진정으로 새로운 점** — 밀집 4D 예측 없이 경량 등록 토큰만으로 기하학 사전을 액션 모델에 이전; 기하학 프라이어를 오버헤드 없이 흡수하는 "학습-이전-추론-분리" 패러다임 최초
- **결과** — RoboTwin 2.0 + 실세계 조작 태스크; 공간 일관성 개선·경쟁력 있는 액션 예측·효율적 추론 동시 달성

### (c) 시사점

- **기하학 사전 이전의 효율 경로** — VGGT 스타일 기하학 인코더를 완전 실행하지 않고 경량 등록 토큰만으로 3D 공간 사전을 액션 모델에 주입; 다중 카메라 공간 임베딩 구성 시 비용-효과 균형 설계 참조
- **공간 등록 토큰 아이디어의 P2 적용 가능성** — 기하학 사전 이전 토큰을 관측 인코더(observation encoder) 설계에 재해석하면 전체 3D 재구성 없이 뷰 등록 정보를 임베딩에 주입하는 경량 확장 가능
- **인과 혼합 어텐션의 모달리티 분리 패턴** — 비디오·액션·기하학 토큰의 모달리티별 가시성 정의가 이질 모달리티 퓨전 설계의 어텐션 마스킹 설계와 직접 연결

### (d) 먼저 확인할 점

- **P5 세계 모델 → P2 관측 인코더 직접 이전 한계** — 공간 등록 토큰이 세계 모델 내부 기하학 이전 용도; 관측 인코더 직접 대체가 아니므로 P2 적용 시 설계 재해석 필요
- **촉각·힘 모달리티 부재** — 3D 기하학(시각)만 다루며 촉각·힘·고유감각 이질 모달리티 통합은 논문 범위 밖
- **실세계 실험 상세 미공개** — 어떤 실세계 조작 태스크인지 초록에 미명시; 접촉 집약적 다지 손 설정 검증 여부 확인 필요
