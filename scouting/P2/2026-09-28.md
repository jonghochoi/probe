## 🥇 논문 1 — 우선순위 ★★★

**MachEmbodied-U0: Unified Understanding and Generation Model for Embodied Intelligence**
[arXiv:2609.25627](https://arxiv.org/abs/2609.25627) · Haoran Wen, Wenfu Wang, Kunsong Shi, Jingke Wang, Wancheng Feng 외 · arXiv preprint(기술 보고서) · source: citation-graph (VGGT) · 코드 공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- 이해·생성 전문가를 Mixture-of-Transformers로 연결해 서브태스크 예측과 어포던스 그라운딩이 미래 RGB·깊이·표면법선·광류의 시각 동역학 예측과 액션 생성을 플로우 매칭으로 공동 안내하는 MachEmbodied-U0(ME-U0) 제안
- 멀티레이트 회전 위치 인코딩(MRPE)으로 시각 동역학 예측과 세밀 제어 신호를 정렬
- 로봇·에고센트릭 데이터 약 4,200시간으로 사전학습, 다운스트림 벤치마크 고유 지도 신호만 사용해 RoboDojo 평균 17.66점, LIBERO 99.0%, LIBERO-Plus 82.5% 달성
- 실물 로봇 조작 과제로 시뮬레이션 밖 효과 검증, 다운스트림 지도 없이도 서브태스크 예측·어포던스 그라운딩·시각 동역학의 제로샷 시연 확인

### (c) 시사점
- 시각 동역학(깊이·법선·광류 포함)을 액션 생성과 하나의 흐름으로 공동 예측하는 구조가 여러 시뮬레이션 벤치마크에서 동시에 통하는 근거 확보 — 개별 벤치마크 전용 헤드 없이 범용 동역학 인지 표현을 노리는 설계 참고 가능
- 서브태스크·어포던스 그라운딩이 제로샷으로도 나온다는 근거 — 다운스트림 미세조정 없이 새 과제에 붙일 수 있는 관측 표현 후보로 검토 가능
- 코드가 실제 저장소로 공개돼 재현 검증 진입 장벽이 낮음

### (d) 먼저 확인할 점
- 실물 로봇 검증이 정성적 서술에 그침 — 정량 성공률·베이스라인 비교 수치는 초록상 확인되지 않아 본문 확인 필요
- 촉각·힘 등 비시각 모달리티 결합 없음 — 시각 동역학 축에 한정된 기여로, 이종 모달리티 퓨전 범위와는 별개
- 18인 대규모 저자·4,200시간 사전학습 규모 — 재현에 필요한 컴퓨팅·데이터 접근성 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**TACIT: Tactile Contact Supervision for Spatial Attention in Dexterous Manipulation**
[arXiv:2609.24507](https://arxiv.org/abs/2609.24507) · Yanhou Lai, Fucai Zhu, Ruiqiang Wang, Koichi Hashimoto · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 사람 라벨링이나 시각 모델 기반 공간 사전 대신, 텔레오퍼레이션 시연에서 측정된 촉각 접촉 자체로 공간 어텐션을 지도하는 TACIT 제안
- 선행 카메라 포인트클라우드 위 가우시안 타깃으로 어텐션 헤드를 학습 시점에만 지도하고, 그 풀링된 출력이 비주오택타일 확산 정책을 조건화 — 촉각 관측 자체는 추론 시에도 입력으로 유지
- 실물 로봇 벤치마크(과제당 시연 10회, 배치 영역 5곳)에서 공 배치 66.7%·펙 삽입 73.3% 성공률 달성, 입력 매칭 3D 비주오택타일 퓨전(10.0%·20.0%)과 비전 단독 DP3(20.0%·43.3%) 대비 큰 격차
- 학습 시드 3종에 걸친 비교로 어텐션 지도 신호 자체의 기여를 아키텍처 매칭 대조군과 분리 검증

### (c) 시사점
- 촉각 접촉을 별도 라벨링 없이 공간 어텐션 지도 신호로 직접 쓰는 경로 확인 — 사람 라벨링·시각 사전 모델 의존을 낮추는 근거
- 학습 시점에만 지도 신호로 쓰고 추론 시점엔 제거되는 설계 — 배포 시 추가 연산 부담 없이 지도 학습의 이점만 취하는 경로로 참고 가능
- 입력 매칭 콘캣형 퓨전 대비 큰 성공률 격차를 실물 데이터로 실증 — 촉각을 어떻게 결합하느냐가 결과를 가른다는 근거를 새로 추가

### (d) 먼저 확인할 점
- 손·그리퍼 하드웨어 구체 사양(다지 손 여부·손가락 수)이 초록상 확인되지 않음 — 손끝 단위 접촉 귀속으로의 확장 가능성 별도 확인 필요
- 실물 벤치마크가 공 배치·펙 삽입 2과제·시행 30회로 협소 — 더 넓은 조작 과제로의 일반화 여부 별도 확인 필요
- 코드·저장소·프로젝트 페이지 공개 서술 없음
