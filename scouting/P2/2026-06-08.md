## 🥇 논문 1 — 우선순위 ★★★

**Multi-Resolution Tactile Imitation Learning for Contact-Rich Robotic Manipulation**
[arXiv:2606.06281](https://arxiv.org/abs/2606.06281) · Rickmer Krohn, E. Helmut, Niklas Funk, Jan Peters, Vignesh Prasad, Georgia Chalvatzaki (TU Darmstadt) · source: keyword-sweep (`cat:cs.RO AND tactile`, `cat:cs.RO AND GelSight`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- **공백** — 이기종(heterogeneous) 촉각 센서가 서로 다른 시간 해상도로 동작할 때 이를 동시에 활용하는 학습 프레임워크 부재
- **MiTaS (Multi-Resolution Tactile Sensing)** — 3중 이기종 입력 통합
  - RGB 카메라(저주파 시각 스트림) + GelSight Mini(비전 기반 촉각, 중주파) + Evetac(이벤트 기반 촉각, 고주파)
  - 모달리티별 독립 컨볼루션 스템(modality-specific convolutional stem) → 트랜스포머 기반 퓨전
  - 합성 표현이 플로우 매칭(flow-matching) 정책을 조건화
- **결과** — 5개 접촉 집약적 태스크 실제 로봇 검증
  - MiTaS 80% vs. 비전 단독 31% vs. 단일 비주오택타일(visuotactile) 54%
- **전이성 발견** — Evetac 없이 평가하더라도 Evetac 포함 공동 학습(co-training) 시 일부 태스크에서 +10%p 이상 성능 향상 유지
  - 학습 시 더 풍부한 센서 구성 → 배포 시 센서 일부 제거 가능하다는 직접 증거
- **프로젝트 페이지** — http://mitas-touch.github.io

### (c) 시사점

- **다중 해상도 접촉 포괄** — 저주파 변형 이미징 + 고주파 이벤트 신호를 함께 써야 접촉 초기와 슬립 검출 모두 안정화됨이 실증; 단일 변형 이미징 방식의 시간 해상도 한계를 보완하는 고주파 채널 추가 검토 근거
- **co-training 전이성 → 배포 시 센서 교체 가능성** — 배포 환경에서 고가 이벤트 카메라(Evetac)를 제거해도 co-training 효과가 유지됨; 학습 시 풍부하게, 배포 시 공통 포맷으로 흡수하는 swappable-head 설계의 타당성 확인
- **트랜스포머 기반 집계 재확인** — 이기종 센서 간 트랜스포머 퓨전이 손 수준 집계에서도 효과적임을 간접 확인; 자기 주의(self-attention) 기반 손 수준 집계 설계 방향 지지

### (d) 먼저 확인할 점

- **손가락 수 불명** — 초록이 몇 손가락 단말인지 명시 없음; GelSight Mini + Evetac 조합이 10개 손가락에 각각 부착될 수 있는지 하드웨어 스펙 확인 필요
- **Evetac 단가·폼팩터** — 이벤트 카메라 기반 손끝 센서는 일반 GelSight 대비 단가 및 폼팩터 불이익 존재; swappable head로 편입 시 비용 검토 필요
- **플로우 매칭 조건화 포맷** — 현재 정책 아키텍처와의 입력 인터페이스 호환성(특징 차원·시간 축 정렬) 구체 확인 요망
- **코드 공개 여부 미확인** — 프로젝트 페이지 공개이나 소스 코드 저장소 여부 미확인

## 🥈 논문 2 — 우선순위 ★★

**RealDexUMI: A Wearable Universal Manipulation Interface for Dexterous Robot Learning**
[arXiv:2606.06033](https://arxiv.org/abs/2606.06033) · Chaoyi Xu, Yixuan Jiang, Jiahui Huan, Yuhui Fu, Haoyu Zhou · source: keyword-sweep (`cat:cs.RO AND dexterous`), Citation-Graph 확장(DexViTac 인용 논문으로 발견)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **대상** — 다지 조작 데이터 수집 파이프라인의 두 구조적 결함
  - 레타기팅(retargeting)·임바디먼트 변환 과정에서 손-물체 세밀 상호작용 정보 손실
  - 로봇별 특수 원격조작 장비 → 직관적 접촉 제어 부재, 확장 비용 과도
- **RealDexUMI** — 공유 단말 모듈(shared dexterous end-effector module)로 경량 다지 손 + 인핸드(in-hand) 비전 + 손끝 촉각 센서 통합
  - 손바닥 측 동형(isomorphic) 텔레오퍼레이션 글러브: 인간 손가락 입력 → 로봇 손 관절 명령 직접 매핑, 레타기팅 불필요
  - 수집-배포 동일 하드웨어(zero-gap end-effector): 수집 시 인핸드 관측·촉각 신호·접촉 정보·손 액션이 배포 시 그대로 재현
- **결과** — 8개 실제 로봇 태스크(세밀한 접촉·접촉 집약적·장기 수평·양팔): 평균 성공률 88.75%
  - 미관측 초기 포즈 일반화 + 3개 임바디먼트(embodiment) 간 이전 확인
  - 웹사이트: https://research.beingbeyond.com/realdexumi
- **진정으로 새로운 점** — UMI(Universal Manipulation Interface) 패러다임을 다지 손 + 손끝 촉각 영역으로 최초 확장; zero-gap 설계가 임바디먼트 격차를 원천 제거

### (c) 시사점

- **per-finger 관절 명령 데이터 수집 경로 실증** — 동형 글러브가 레타기팅 없이 손가락별 관절 명령을 직접 기록; 관측·액션의 동일 하드웨어 보장이 손가락 토큰 피처 학습에 필요한 데이터 충실도를 확보
- **손끝 촉각 + 인핸드 비전 통합 플랫폼** — swappable sensor head 구조의 실현 가능성을 8태스크 실제 로봇 규모에서 검증; 촉각·비전·관절 명령 3채널 동기화 데이터 수집 표준 사례
- **3 임바디먼트 이전** — 공통 단말 모듈이 임바디먼트 간 이전을 가능케 했다는 결과는 공통 토큰 포맷 설계의 타당성을 간접 지지

### (d) 먼저 확인할 점

- **촉각 센서 유형 미명시** — 초록이 손끝 촉각 센서 방식(변형 이미징 vs. 다른 방식) 미명시; 공개 웹사이트에서 하드웨어 스펙 확인 필요
- **임바디먼트 이전 범위 불명** — 3개 임바디먼트가 동일 형태 다지 손 간인지 또는 이종(그리퍼 포함) 이전인지 명확화 필요
- **데이터 규모 의존** — UMI 패러다임은 데이터 수량에 비례 성능 향상 전제; 소규모 데이터 체제에서 zero-gap 이점이 유지되는지 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★

**MoDex: A Diffusion Policy for Sequential Multi-Object Dexterous Grasping**
[arXiv:2606.05407](https://arxiv.org/abs/2606.05407) · Haofei Lu, Hongji Liu, Yifei Dong, Florian T. Pokorny, Jens Lundell · source: keyword-sweep (`cat:cs.RO AND dexterous`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9) [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **대상** — 단일 다지 손으로 기존에 파지한 물체를 놓지 않고 순차적으로 복수 물체를 추가 파지하는 새 태스크
- **opposition space** — 현재 파지에 참여하는 손가락 집합을 명시하는 구조화된 조건 표현
  - 활성(grasp) 손가락과 대기(available) 손가락을 입력 수준에서 분리
  - 포인트 클라우드(point cloud) + opposition space → 확산 정책(diffusion policy)으로 다음 그리퍼 포즈 예측
- **학습** — 모방 학습(imitation learning) 선행 후 2단계 Sim-to-Real 이전
- **진정으로 새로운 점** — 손가락 역할(활성/대기)을 입력 수준에서 구조화하는 opposition space 개념 최초 제안; 기존 파지 정책은 전체 자유도를 단일 목표에 투입해 순차 파지 불가

### (c) 시사점

- **손가락 역할 마스크 입력 설계 근거** — 현재 파지 중인 손가락과 다음 파지를 위해 예약된 손가락을 명시적으로 구분하는 입력 구조가 순차 접촉 전환 태스크에서 유효함을 실증
- **토폴로지 인식의 동적 갱신 아이디어** — 키네마틱 체인 기반 토폴로지 인식을 "현재 어느 손가락이 어떤 역할인가"로 실시간 업데이트하는 입력 설계의 타당성 근거; 다점 동시 접촉 + 순차 접촉 전환 태스크에서 역할 인식 필요

### (d) 먼저 확인할 점

- **P1 경계 인접** — opposition space는 액션 정책 조건 입력에 가깝고 proprio-tactile 바인딩(P2 핵심)에 직접 대응은 아님; 관련성은 간접적
- **실제 로봇 실험 상세 미공개** — sim-to-real 이전을 언급하나 실제 로봇 태스크 다양성·성공률이 초록에 미명시
- **코드 공개 미확인** — opposition space 인터페이스 구현 공개 여부 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**WristCompass: Kinematic Coupling as a Learnable Visual Concept for Ego-Camera Orientation**
[arXiv:2605.30671](https://arxiv.org/abs/2605.30671) · (저자 초록 미확인) · source: keyword-sweep (`cat:cs.RO AND in-hand`); 인접 분야: 자기중심 카메라(egocentric camera) 오리엔테이션 복원

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **문제** — 자기중심 조작 비디오에서 카메라 오리엔테이션 복원은 손-카메라 운동 분리(hand vs. camera motion disentanglement)의 전제
  - 손이 프레임을 가릴 때 장면 기하학(VGGT 1B 파라미터 모델)이 상수 예측기보다 오히려 낮은 성능
- **핵심 아이디어** — 손이 시야를 가리는 그 순간에 역설적으로 강력한 신호 등장: 키네마틱 커플링 다이내믹스(kinematic coupling dynamics)
  - 손목 운동과 카메라 운동 사이의 구조적 물리 관계를 학습 가능한 시각 개념으로 활용
  - 장면 기하학이 부재한 상황에서 키네마틱 커플링이 오리엔테이션 복원 신호로 작동
  - TACO 벤치마크(조작 비디오 기반)에서 검증
- **Sim2Real 미달 — Sim2Real = 1** — 현재 비디오 데이터셋 기반 검증; 실제 로봇 배포 실험 미포함으로 필터 기준 미달

### (c) 시사점

- **인핸드 카메라 퓨전 전처리 후보** — 멀티카메라 사전 융합 시 인핸드 카메라가 손에 의해 가려지는 구간에서 키네마틱 커플링으로 카메라 오리엔테이션 복원 가능; 융합 전 카메라 정렬 단계 설계 시 참고 후보
- **한계** — 실제 로봇 환경으로의 이전 미검증; 손목-카메라 강체 연결 가정이 로봇 진동·충격 시 깨질 수 있음

### (d) 먼저 확인할 점

- **실제 로봇 검증 부재** — TACO가 인간 조작 비디오 기반; 로봇 인핸드 카메라 시나리오로 직접 이전 시 별도 검증 필요
- **강체 가정** — 손목과 카메라 간 고정 강체 연결 전제; 로봇 진동 환경 유효성 불명
