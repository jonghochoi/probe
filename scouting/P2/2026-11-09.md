### (b) 논문 요지

- 같은 촉각 스트림에서 단서별 기여를 실물로 분리 측정
- **문제** — 비전 기반 촉각 센서 한 장의 영상에 접촉 외관, 기하, 압입 깊이, 접선 방향 변형이 섞여 있어 어느 물리 단서가 정책 학습에 기여하는지 알기 어려움
- **기존 한계** — 기존 시각-촉각 정책이 촉각 관측을 그대로 이미지로 처리
  - 어떤 물리 단서가 기여하는지 가려짐
- **핵심 방법** — 같은 촉각 스트림에서 단서별 신호를 뽑아 같은 시연과 같은 정책 백본으로 비교하는 통제 실험
  - 촉각 RGB 이미지(접촉 외관), 법선·깊이 맵(기하), 마커 플로우 필드(접선 방향 변형) 세 가지를 도출
  - LeRobot 플랫폼에 자체 시각-촉각 지각 시스템을 얹어 사용
  - 단서 단독 기여와 조합 기여를 평가하고, 촉각 인코더와 시각-촉각 융합 방식도 추가 비교
- **차별점** — 촉각을 한 덩어리 이미지로 넣지 않고 물리적으로 해석 가능한 단서로 쪼개 통제 비교
  - 시연과 정책 백본을 고정해 차이를 단서와 처리 방식 탓으로 돌릴 수 있게 구성
- **핵심 기여** — 실물 로봇 720회 시행에서 얻은 네 가지 결과
  - 촉각 지각 추가로 전체 성공률 57.8%에서 78.9%로 상승, 기여는 과제 단계에 따라 다름
  - 마커 플로우가 가장 효과적인 단일 단서로 성공률 74.4%, 이미 형성된 접촉을 조절하는 구간에서 특히 중요
  - 단서별로 나눠 인코딩하는 방식이 일관되게 성능 개선, 단서마다 맞는 처리가 다르다는 해석
  - 촉각 융합 효과는 과제 의존적이며 교차 어텐션이 사전학습 촉각 인코더와 비슷한 성능을 내는 경량 대안
- **가치** — 촉각을 어떤 형태로 정책에 넣을지 실물 정량 근거로 고를 수 있는 기준점 제공

### (c) 시사점

  - 비전 기반 촉각 센서의 변형 신호를 우선 추출 대상으로 검토할 근거
- 교차 어텐션이 사전학습 촉각 인코더에 근접한다는 결과

## 🥈 논문 2

**What Makes a Good Visual Representation for Spatial Understanding in MLLMs?**
[arXiv:2610.17844](https://arxiv.org/abs/2610.17844) · Xiaohu Huang, Yumin Guo, Kai Han · arXiv preprint · source: keyword-sweep

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 어떤 표현을 어떻게 옮겨야 공간 이해가 나아지는지 통제 비교
- **문제** — 다중모달 LLM(MLLM)의 시각 토큰에 3D 구조가 빠져 있어 공간 추론이 약함
  - 사전학습이 2D 이미지-텍스트 쌍 위주라 시각 인코더가 2D 의미 인식을 겨냥
  - 공간 구조가 언어 모델이 받는 토큰에 없는 경우가 많다는 진단
- **기존 한계** — 외부 표현을 가져오는 기존 방법들이 왜 효과적인지는 묻지 않음
  - 포인트클라우드, RGB-D 스캔, 객체 제안, 재구성 장면 표현 같은 명시적 3D 입력 방식은 추론 때 쓰기 어려운 3D 센싱이나 재구성에 의존
  - 기하 인지 인코더, 재구성 토큰, 단계적 공간 학습, 기하-언어 모듈 등 최근 방법은 외부 시각 표현을 MLLM에 들이는 공통 동작을 하며 전이가 도움이 된다는 점만 보임
  - 표현 자체의 어떤 성질이 효과를 만드는지는 거의 탐구되지 않았다고 지적
- **핵심 방법** — 무엇을 옮기는지와 어떻게 옮기는지를 분리하고 기반 구조와 학습 레시피는 고정한 통제 연구
  - 원천 모델 — 시각 기하 모델, 자기지도 이미지 모델, 비전-언어 모델, 생성 모델, 자기지도 비디오 모델
  - 표현 형태 — 백본 잠재 특징 대 기하 모델이 내놓는 명시적 깊이·포인트 맵
  - 전이 방식 — 증류(학습 때 지도 목표)와 융합(학습과 추론에서 보조 입력)
  - 각 표현을 전이 전에 오프라인으로 평가해 다운스트림 이득과 상관되는 지표를 탐색
  - 연구 결과를 모아 잠재 특징과 명시적 기하를 하나의 MLLM에 함께 증류하는 통합 모델 구성
- **차별점** — 전이가 도움이 되는지가 아니라 표현의 어떤 성질이 도움이 되는지를 변수 분리로 측정
  - 후보를 옮겨 보기 전에 오프라인 지표로 평가할 수 있다고 주장
  - 통합 모델은 추론 때 외부 보조 모델이나 깊이 센서 없이 RGB 비디오만 입력
- **핵심 기여** — 통제 프레임워크, 비교 결과, 예측 지표, 통합 모델 네 가지
  - 잠재 특징은 증류와 융합이 비슷하고, 명시적 기하는 증류가 훨씬 낫고 특히 사전학습된 VGGT 방식 DPT 디코딩 헤드와 함께일 때 이득이 큼
  - 잠재 특징은 시점 간 일관성이 클수록 이득이 크고 2D 특징 구조 지표는 상관이 약함, 명시적 기하는 깊이·재구성 정확도가 이득과 함께 움직임
  - 기하는 단일 객체 계측 질문(개수, 크기, 절대 거리)에, 특징은 다객체 관계·시간 질문에 강해 둘을 함께 옮기는 근거
  - 구성 요소 ablation에서 특징 증류만으로는 SPAR-Bench와 CV-Bench-3D에서, 기하 증류만으로는 ViewSpatial에서 기본 모델보다 낮고 둘을 합치면 모든 열에서 기본 모델을 상회
  - VSI-Bench 전체 62.2%로 VLM-3R 60.9, VG-LLM 47.3, Spatial-MLLM 47.0, Gemini-2.5 Pro 53.6을 앞섬(RGB 비디오 입력)
  - DSR-Bench 동적 4D 추론은 학습 분할에서 추가 미세조정한 뒤 전체 70.7%
- **가치** — 3D 구조를 시각 표현에 넣는 방법을 감이 아니라 측정 가능한 성질로 고르게 하는 지침 제공

### (c) 시사점

- 기하 표현을 인코더에 넣는 방식의 선택 기준 제시
  - 명시적 기하는 융합보다 증류와 디코딩 헤드 조합이 낫고 잠재 특징은 둘이 비슷하다는 비교
- 기하 증류 인코더(eVGGT)처럼 입력은 그대로 두고 학습 때만 기하를 주입하는 방향과 같은 계열의 근거
  - 추론 때 보조 모델이 필요 없는 구조라 배포 경로 부담 없음
- 시점 간 일관성을 오프라인 지표로 써서 후보 인코더를 사전 선별하는 방법
  - 다시점 정합 후보를 정책에 붙이기 전에 걸러내는 데 재사용 가능
- 기하 증류와 특징 증류의 보완 관계
  - 한쪽만 옮기면 일부 벤치마크에서 기본 모델보다 낮아지므로 단일 표현 선택 위험을 가늠하는 근거

### (d) 먼저 확인할 점

- 로봇 입력이나 액션 정책이 없는 MLLM 공간 추론 벤치마크만 평가, 조작 성능으로의 이전은 별도 검증 필요
- 저자 한계 서술 — 진단이 중간 규모의 사전학습 모델 풀과 정적 실내 장면에 기반
- 이전 NeurIPS 2025 논문(3DRS)의 확장판이라 일부 결과는 선행 보고와 겹침
- DSR-Bench 수치는 학습 분할 미세조정 후 결과라 제로샷 비교 아님
- 코드 공개 신호 없음

## 🌱 논문 3 — 인접 분야 픽

**WorldRoPE: Probabilistic World-Centric Rotary Embedding for Multi-View Attention**
[arXiv:2610.16337](https://arxiv.org/abs/2610.16337) · Mijeong Kim, Kyujin Lim, Bohyung Han · adjacent field: 공간-기하 융합 표현(다시점 어텐션의 위치 인코딩) · arXiv preprint

**점수 6/15** · R2 · N2 · M2 · Real0 · Repro0 — arXiv comment는 [프로젝트 페이지](https://cv.snu.ac.kr/research/WorldRoPE)뿐, 본문의 GitHub 링크는 모두 기준선 저장소

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 깊이 불확실성을 담은 세계 좌표 기반 회전 위치 인코딩
- **문제** — 다시점 트랜스포머의 이미지 공간 회전 위치 인코딩(RoPE)은 좌표가 이미지마다 따로 정의됨
  - 같은 3D 점이 시점마다 다른 좌표를 갖고 이미지에서 가까운 위치가 3D에서는 멀리 떨어진 물체일 수 있음
  - 이미지 공간 관계만으로는 시점 간 대응을 세우기에 불충분
- **기존 한계** — 카메라 인지 방식은 패치를 하나의 선 위 점으로 다룸
  - GTA와 PRoPE는 상대 카메라 포즈와 투영 변환으로 시야 기하를 어텐션에 반영
  - 광선 기반 회전 인코딩(RayRoPE, URoPE)은 예측 깊이나 사전 정한 깊이 앵커로 토큰을 카메라 광선 위에 놓고 쿼리 시점에 투영
  - 패치는 시야 절두체 전체를 보며 깊이가 다른 여러 물체를 담을 수 있고 깊이 추정도 불확실하다는 점을 놓침
- **핵심 방법** — 토큰마다 깊이 가설을 확률 분포로 3D에 올려 쿼리 시점에서 회전 연산을 적분
  - 층마다 토큰 특징에서 깊이 가설, 불확실성, 혼합 가중치를 예측
  - 각 패치 토큰을 공유 세계 좌표의 부피형 가우시안 프리미티브 집합으로 역투영
  - 프리미티브를 쿼리 시점에 투영해 키 토큰이 나타날 위치의 분포를 정의
  - 그 분포 위에서 회전 연산자를 폐형식으로 적분해 어텐션을 유도, 특징을 래스터화하거나 워핑하지 않음
  - 예측 기하가 어텐션을 이끌고 갱신된 특징이 다음 층 기하 예측을 다듬음
- **차별점** — 광선 위 점 위치 대신 대안 깊이 가설, 깊이 불확실성, 패치 절두체의 유한한 공간 범위를 함께 담는 3D 지지 영역 사용
  - 지지 영역이 한 점으로 붕괴하면 결정론적 RoPE로 환원
  - 불확실한 키 위치에 어텐션이 덜 민감해짐, 유효 감쇠의 역수가 토큰 적응형 온도로 해석됨
- **핵심 기여** — 방법, 폐형식 유도, 실험 세 가지
  - 부피형 가우시안으로 토큰 지지 영역을 모델링하는 확률적 세계 중심 RoPE 제안
  - 투영된 가우시안 분포 위의 회전 기댓값 폐형식 유도와 층 간 기하 예측-특징 갱신 결합
  - LVSM 위 RE10K와 Objaverse 새 시점 합성에서 Plücker, GTA, PRoPE, RayRoPE, URoPE 기준선 대비 PSNR, SSIM, LPIPS 전 지표 우위, RE10K에서 최강 기준선 대비 PSNR 0.49 dB 개선
  - 성분 ablation에서 어느 성분을 빼도 RE10K 성능 하락, 깊이 추정과 순방향 3D 재구성에도 적용
- **가치** — 다시점 어텐션이 시점 간 대응을 세울 때 깊이 불확실성을 위치 인코딩에 직접 반영하는 틀 제시

### (c) 시사점

- 다시점 정합을 토큰 병합이 아닌 어텐션 위치 인코딩에서 처리하는 후보
  - 카메라별 토큰을 이어 붙이는 방식 대비 시점 간 대응이 위치 단계에서 유지됨
- 깊이 가설과 불확실성을 함께 쓰는 점
  - 패치가 전경과 배경을 함께 담는 조작 장면의 물체 가장자리와 얇은 구조에 이득이 날 수 있는 방향
- 결정론적 RoPE로 환원되는 성질
  - 기존 다시점 어텐션에 끼워 넣어 비교할 때 도입 비용 낮음 가능

### (d) 먼저 확인할 점

- 평가가 새 시점 합성, 깊이 추정, 3D 재구성뿐이고 로봇 정책이나 조작 결과 없음
- 쿼리 시점 투영을 전제하므로 카메라 파라미터가 주어지는 설정으로 보이며 보정 오차 민감도는 본문 확인 필요
- 층마다 깊이 가설을 예측하고 가우시안을 적분하는 추가 연산의 지연 비용 확인 필요
- 코드 공개 신호 없음, 프로젝트 페이지만 있음
- 인접 분야 논문이라 정책 입력으로 옮겼을 때의 효과는 미검증

## 🔄 직전 리포트 대비 종합

- **기준 통과 2편에 인접 분야 픽 1편** — 3편에 못 미치는 주에도 채우지 않음, 근접 후보 없음
- **융합 방식 비교 흐름 지속** — Physical Tactile Cues(2611.06673)는 교차 어텐션이 사전학습 촉각 인코더와 비슷하다고 보고
  - 직전 리포트의 TF²-Steering(2611.01483)이 촉각 이미지를 입력에 덧붙이면 실물 진행 성공률이 내려간다고 한 것과 융합 방식 문제를 다른 각도에서 다룸
  - 다만 이 논문은 단서 분해와 인코더 비교이고 덧붙이기 대 다른 결합의 직접 비교는 아님
- **기하 접지 쟁점 지속** — Spatial Understanding in MLLMs(2610.17844)는 명시적 기하가 융합보다 증류와 디코딩 헤드에서 이득이 크다고 보고
  - 직전 회차 Viewpoint-Generalizable Policies(2609.32762)가 로봇 좌표 위치 인코딩에서 이득이 나온다고 한 것과 이어지나 MLLM 벤치마크와 정책 실물 평가로 설정이 다름
