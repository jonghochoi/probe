### (b) 핵심 기여
- 시뮬레이션 관통깊이·실물 정전용량 등 이종 촉각 모달리티를 공유 잠재공간에 정렬하는 멀티모달 표현학습 프레임워크
- 모달리티별 인코더 + 자기·교차 재구성 목적함수 + 대조 정렬로 모달리티 불변이면서 정보 보존적인 임베딩 확보
- 정밀한 촉각 시뮬레이터 없이도 형상 식별·힘 예측·기하 복원 세 다운스트림 과제에서 시뮬레이션 학습 후 실물 센서로 제로샷 전이 검증

### (c) 시사점
- 촉각 시뮬레이터의 물리 충실도 한계를 우회하는 대안 경로 — 정밀 접촉역학 시뮬레이션 없이도 sim2real 촉각 표현 확보 가능
- 힘 예측 오차 16.7%↓, 형상 복원 오차 45.8%↓ 정량적 개선폭 확보
- IROS 2026 채택으로 동료 심사 통과 근거 확보

### (d) 먼저 확인할 점
- Isaac Lab 기반 구현 공개 서술은 있으나 전체 모델·데이터 공개 여부 원문 별도 확인 필요
- 검증 과제가 형상 식별·힘 예측·기하 복원에 한정 — 조작 정책 성능으로의 직접 전이는 별도 확인 필요
- 이종 촉각 모달리티가 시뮬레이션 관통깊이·실물 정전용량 두 종류에 한정 — 다른 촉각 센서 유형으로의 일반화 여부 미확인

## 🥈 논문 2 — 우선순위 ★★

**TacWAM: Anchor-Guided World Action Model with Mechanics-Aware Tactile Prediction**
[arXiv:2607.28391](https://arxiv.org/abs/2607.28391) · Lei Jin, Yiding Ma, Xin Zhang, Chen Gao, Wei Wu, Yong Li · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 촉각 외형·조밀 힘장·변형 흐름을 공유 잠재 예측공간으로 매핑하는 Spatially Aligned Fusion(SAF) 촉각 인코더 제안
- 촉각 이력 인코더로 시간적 맥락을 부여해 미래 촉각 예측이 현재 관측을 넘어 힘·변형 변화를 반영하도록 설계
- Anchor-Guided Tri-Modal(AGT) Attention으로 현재 비전·촉각 앵커, 미래 예측 토큰, 액션 토큰을 분리 — 미래 촉각이 액션 분기에서 직접 읽히지 않으면서도 학습을 감독

### (c) 시사점
- 접촉 상태를 외형뿐 아니라 힘·변형까지 포함한 물리 정보로 확장 — 촉각 융합 설계의 표현 폭을 넓히는 참조 사례
- 파손 취급·지속 접촉·동적 인핸드 조작 등 실물 4개 태스크에서 평균 성공률 75.0%, 최강 베이스라인 대비 37.5%p 우위
- 촉각 이력 제거·미래 예측 접근 제한 시 성능 저하를 어블레이션으로 직접 확인 — 설계 요소별 기여도 명확

### (d) 먼저 확인할 점
- 코드·체크포인트 공개 서술 없음 — 재현 가능성 미확정
- 손가락 단위 귀속이 아닌 전체 촉각 신호 기준 융합 — 다지 손 세밀 제어로의 확장 여부 미검증
- 실물 4개 태스크에 한정된 검증 — 태스크 다양성 확장 시 일반화 여부 확인 필요

- Geometry-Centric Masked Autoencoding(GC-MAE)으로 현재 포인트클라우드 재구성과 미래 기하 변화 예측을 동시에 학습하는 이중목적 자기지도 프레임워크 제안

- 분포 외 교란 조건에서도 강건성 강화 확인 — 기하·동역학 인지 표현이 일반화에 기여하는 근거

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 공개
- 이전 자체 연구(Lift3D)의 확장판 — 포인트클라우드 획득 비용·정확도 의존성 별도 확인 필요
- 실물 8개 태스크 규모가 시뮬레이션 22개 대비 작음 — 실물 검증 다양성 확장 여지

### (d) 먼저 확인할 점

- 실물 조작 결과가 "긍정적 전이 경향"으로만 서술 — 구체 정량 수치 별도 확인 필요
- 3D Gaussian field 구성에 필요한 다중뷰 동기화·기하 파운데이션 모델 추론 비용 초록상 불명확

**VT-MUSE: Multimodal Unified Sequential Visuotactile Representation Learning for Manipulation**

- 시뮬레이션 벤치마크 전체 태스크에서 최강 베이스라인 대비 11%p 우위, 실물 실험에서도 유의미한 개선 확인
- 시각-촉각 인코더 공동 적응과 정책 통합을 분리한 2단계 설계 — 표현학습과 정책학습 각각 최적화 여지

### (d) 먼저 확인할 점
- 코드·프로젝트 페이지 공개 서술 없음
- 실물 실험 개선폭이 "유의미한 개선"으로만 서술 — 구체 정량 수치 별도 확인 필요
- 마스킹 기반 학습의 마스킹 비율 등 하이퍼파라미터 민감도 초록상 불명확

- 인간 시연으로부터 물체 질량·마찰계수 클래스, 연속 강성을 추정하는 시각-촉각 프레임워크 및 데이터 수집 시스템 제안
- 시간적 시각-촉각 모델링, 크로스어텐션 멀티모달 퓨전, 비전-언어 모델 기반 의미적 사전(prior)을 결합
- 제한된 로봇 원격조작 데이터·로봇 스타일 비디오 증강·매칭된 액션의 인간 시연을 활용해 인간 도메인에서 로봇 도메인으로 전이, 적응형 파지의 온라인 모듈로 배포

### (c) 시사점
- 물체의 물리적 속성을 명시적으로 추정·조건화하는 정책 설계 — 시각 정보만으로는 포착하기 어려운 접촉 반응(파지력 등) 조정 근거 제공
- 재현·미지 물체 양쪽에서 물성 추정 정확도 87.5–98.8%, 강성 MAPE 5.51–9.08% 확보, 미지 물체 파지 성공률 83.4%
- 미지 물체에서 인간 원격조작과 유사한 힘 프로파일 확보 — 물성 조건화가 실제 접촉 거동에 부합함을 시사

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
- 60개 강체·변형체 물체 기준 검증 — 손가락 단위 세밀 조작이 아닌 전체 파지력 조정에 한정
- 인간 도메인에서 로봇 도메인으로의 전이가 제한된 원격조작 데이터에 의존 — 전이 비용·확장성 별도 확인 필요

**TacWAM (11/15)**
- Relevance 3 — 촉각 외형·힘장·변형흐름을 공유 잠재공간으로 결합하는 SAF 인코더 + 비전-촉각-액션 분리 어텐션 구조, D2DV 이종 모달 퓨전 핵심
- Novelty 3 — 접촉 상태를 외형이 아닌 힘·변형 물리량으로 확장한 미래 촉각 예측 + 액션 분기 비직접 노출 설계, 기존 촉각-이미지 예측 방식과 차별화
- Reproducibility 0 — 초록·arXiv comment 모두 코드·체크포인트 공개 서술 없음
- Methodology 2 — 촉각 이력 제거·미래 예측 접근 제한 어블레이션으로 설계 요소별 기여 분리 확인
- Sim2Real 3 — 파손 취급·지속 접촉·동적 인핸드 조작 등 실물 4개 태스크에서 평균 성공률 75.0%, 최강 베이스라인 대비 37.5%p 우위

**Lift3D-VLA (11/15)**
- Relevance 3 — 2D 위치 임베딩에 3D 포인트를 정렬하는 모델-리프팅 + GC-MAE 미래 기하 예측, D8EJ 기하 그라운딩과 D9NB 동역학 인지 인코딩 동시 충족
- Novelty 2 — 포인트클라우드 재구성과 미래 기하 변화 예측을 동시 학습하는 이중목적 자기지도 프레임워크, 기존 3D-VLA 대비 기하-동역학 결합 강화
- Reproducibility 1 — arXiv comment "Project website: https://lift3dvla.github.io/" — 코드 저장소 서술 없음
- Methodology 2 — MetaWorld·RLBench 시뮬레이션 22개 + 실물 8개 태스크, 기존 최고 VLA 대비 정량 비교
- Sim2Real 3 — 실물 8개 조작 태스크에서 최강 베이스라인 대비 4%p 우위 직접 검증

**TacImag (11/15)**
- Relevance 3 — 시각·고유수용성 기반 촉각 상상으로 하드웨어 촉각 센서 의존을 우회, D2DV/D3AG 융합 설계의 대안 축에 직접 연결
- Novelty 2 — 힘장 상상과 촉각 이미지 상상의 과제-표현 정합성 차이를 실증한 접근, 기존 촉각 결측치 복원 방식과 재해석 관점에서 차별화
- Reproducibility 1 — arXiv comment "Project website: https://tacimag.github.io/" — 코드 저장소 서술 없음
- Methodology 2 — 시뮬레이션 6개 + 실물 4개 과제, 힘장 vs 촉각 이미지 상상 비교 어블레이션 수행
- Sim2Real 3 — 실물 조작 과제에서 접촉-민감 44.4%, 텍스처-민감 23.3% 정량 개선 직접 검증

**GaussianWAM (10/15)**
- Relevance 3 — 3D Gaussian field로 기하·의미 지도를 WAM 현재-관측 표현에 학습 시점 전용 주입, D8EJ 기하 그라운딩과 D9NB WAM 동역학 인코딩 동시 해당
- Novelty 2 — 이종 교사 신호(깊이·카메라파라미터·의미특징)를 Gaussian 프리미티브로 통합 증류하는 구조, 직접 CLIP·VGGT 증류 베이스라인 대비 추가 개선 확인
- Reproducibility 0 — 초록·arXiv comment 모두 코드·체크포인트 공개 서술 없음
- Methodology 3 — LIBERO-Plus·LIBERO·RoboTwin 다중 벤치마크, 직접 증류 베이스라인 대비 정량 개선(FastWAM 52.05%→71.29%) 어블레이션 제시
- Sim2Real 2 — RoboTwin·실물 조작에서 긍정적 전이 경향 명시, 구체 성공률 수치는 초록상 미제시

**VT-MUSE (10/15)**
- Relevance 3 — 시각-촉각 교차모달 시간 정렬 + 조건부 변분 잠재모델을 게이트 크로스어텐션으로 정책에 통합, D2DV 비-concat 이종 퓨전 핵심
- Novelty 3 — 접촉의 시간적 진화를 명시적 학습 대상으로 삼는 2단계(모달 공동적응 + 시퀀스 잠재모델) 구조, 기존 순간-관측 기준 퓨전과 차별화
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 서술 없음
- Methodology 2 — 시뮬레이션 벤치마크 전체 태스크에서 최강 베이스라인 대비 11%p 개선 정량 제시, 실물 개선폭은 서술로만 제시
- Sim2Real 2 — 실물 실험에서 유의미한 개선 명시, 구체 성공률 수치는 초록상 미제시

**ViTacPhys (11/15)**
- Relevance 2 — 시각-촉각 크로스어텐션 퓨전으로 물체 물성을 추정·조건화하는 구조, 촉각·force까지 포괄하는 D2DV 전체 범위 대비 물성 추정에 특화된 좁은 적용
- Novelty 2 — 인간 시연에서 물성 추정 후 제한된 로봇 데이터로 도메인 전이하는 접근, 기존 물성-비조건화 파지 정책과 차별화
- Reproducibility 1 — arXiv comment "Project page: https://vitacphys.github.io/ViTacPhys/" — 코드 저장소 서술 없음
- Methodology 3 — 60개 강체·변형체 물체, 재현·미지 물체 양쪽 물성 추정 정확도(87.5–98.8%)·강성 MAPE(5.51–9.08%) 정량 제시, ACT 베이스라인과 힘 프로파일 비교
