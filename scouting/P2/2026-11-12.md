## 🥇 논문 1

**DynaSlots: Slot-Centric 3D Dynamics Pretraining for Robot Manipulation**
[arXiv:2610.32330](https://arxiv.org/abs/2610.32330) · Meng Li, Lijiang Chen, Qi Zhao, et al. · arXiv preprint · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — 초록 "Code is available at" 프로젝트 페이지 URL

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 점 구름을 슬롯으로 나눠 슬롯별 잠재 액션을 학습
- **문제** — 조작은 국소 변화인데 장면 전체를 전역 특징 하나와 전역 잠재 액션 하나로 요약하는 3D 사전학습
  - 컵을 집으면 컵만 움직이고 주변 장면은 그대로인 상황이 일반적
- **기존 한계** — 정적 외형 중심 3D 사전학습과 장면 수준 동역학 사전학습을 함께 지적
  - 마스크 오토인코딩·교차모달 목적 기반 3D 사전학습은 장면 구조만 담고 상태 전이를 담지 못함
  - 장면 수준 동역학 사전학습은 역동역학 모델(IDM)의 전역 잠재 액션 하나로 요약
    - 의미 중첩 — 서로 다른 영역의 유사한 움직임이 비슷한 전역 특징 차이를 만듦
    - 상호작용 의존성 비명시 — 한 영역의 변화가 다른 영역과 어떻게 이어지는지 전역 벡터가 표현하지 못함
    - 방해 요소 민감 — 과제와 무관한 장면 변화가 전역 표현을 흔듦
- **핵심 방법** — 프레임마다 점 구름을 K개 슬롯으로 분해하고 슬롯 단위로 동역학을 모델링, 레이블 없이 끝단 학습
  - 시간적 슬롯 전파 — 프레임별 슬롯 어텐션이 슬롯 순서를 뒤섞는 문제를 막고 프레임 간 슬롯 일관성 유지
  - 슬롯별 IDM — 특징 차이에서 슬롯마다 잠재 액션 하나를 추출
  - 교차 슬롯 확산 순방향 동역학 모델 — 슬롯별 미래 상태를 예측하며 자기지도 상호작용 헤드가 슬롯 간 접촉·동시 운동 관계를 복원
  - 분산-불변-공분산 정규화와 EMA 타깃 인코더로 학습
- **차별점** — 잠재 액션을 장면이 아니라 슬롯마다 정의
  - 행동 레이블, 분할 정답, 재구성 지도 모두 불필요
- **핵심 기여** — 저자들이 주장하는 세 가지
  - 슬롯 기반 동역학 인식 3D 시각 사전학습 프레임워크를 최초로 제시했다는 주장
  - 시간적 슬롯 전파와 상호작용 헤드를 갖춘 교차 슬롯 순방향 동역학 모델
  - Meta-World·Adroit 시뮬레이션과 RealMan RM65-B 실물 4개 과제에서 장면 수준 기준선 대비 우위
  - 실물은 과제마다 5개 초기 배치에 배치당 10회 시행, 4개 시드로 학습한 정책으로 평가
  - 기준선은 대규모 사전학습, 정적 3D, 정책 단독, 동역학 인식 계열
  - 구성요소 ablation과 슬롯 할당 분석, 혼잡 장면과 미학습 물체 평가 포함
- **가치** — 다중 이동체 장면에서 영역별 변화와 영역 간 의존을 분리하는 사전학습 표현의 경로 제시

### (c) 시사점

- 동역학 인식 인코더를 장면 수준에서 슬롯 수준으로 세분하는 후보
  - 정적 3D 인코더와 동역학 인식 기준선을 같은 표에서 비교한 근거 확보
- 과제와 무관한 장면 변화에 덜 흔들리는 표현이 목표
  - 혼잡 장면 실물 평가가 인코더 선택 기준점
- 행동 레이블 없이 학습하는 구조
  - 인간 영상 등 라벨 없는 데이터로 사전학습을 넓힐 여지

### (d) 먼저 확인할 점

- 초록·본문에 저장소 없음, 프로젝트 페이지만 있어 재현 경로 불명확
- 입력이 점 구름이라 깊이 센서나 3D 복원 경로 필요
- 실물은 RealMan RM65-B 단일 팔 4개 과제, 다지 손과 촉각 입력 없음
- Adroit 시뮬레이션 외에 손 조작 근거 부재

## 🥈 논문 2

**Spatial Representation Distillation and Knowledge Routing for Vision-Language-Action Models**
[arXiv:2611.10443](https://arxiv.org/abs/2611.10443) · Jungin Park, Chaoran Zhu, Changjae Oh, et al. · NeurIPS 2026 · source: citation-graph · 코드 공개

**점수 13/15** · R3 · N2 · M3 · Real3 · Repro2 — 초록 "Code is available at https://github.com/park-jungin/spark-vla"

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 3D 전문가 증류와 라우터로 VLA의 공간 이해 보강
- **문제** — 다중 카메라 2D 특징을 합쳐도 시점 간 기하 일관성이 확보되지 않아 VLA의 공간 인식이 병목
  - 물체 위치·방향·크기·로봇과의 관계가 파지·배치에 필요
- **기존 한계** — 3D 정보를 넣는 두 방향 모두 한계가 있다는 지적
  - 명시적 3D 통합(깊이 맵, 점 구름 등)은 로봇 플랫폼과 데이터셋마다 균일하지 않은 추가 센싱이나 복원 입력에 의존
  - 암묵적 2D-3D 정렬은 원래 2D 표현 공간을 왜곡해 사전학습 VLM의 지각 능력을 약화
- **핵심 방법** — 사전학습 VLM의 비전 백본에 저랭크 어댑터 병렬 경로를 두고 두 경로를 라우터로 결합
  - 공간 표현 증류 — 원래 시각 경로는 동결, 어댑터 경로가 동결 3D 전문가(VGGT 등)의 기하 표현을 어텐션 응답 증류로 학습
    - 어댑터의 쿼리를 전문가의 키·값과 공유해 쿼리가 모은 기하 정보를 학습
  - 지식 라우터 — 지시문에 조건화된 점수로 일반 토큰과 공간 토큰 중 언어 모델에 넘길 토큰을 선택
    - 행동 손실의 라우터 게이트 기울기에서 라우팅 타깃을 얻어 수동 주석 불필요
  - 추론 시 외부 3D 입력이나 전문가 불필요
- **차별점** — 원래 시각 경로를 보존한 채 병렬 공간 경로를 학습하고 행동 기울기로 두 경로를 선별
- **핵심 기여** — 시뮬레이션과 실물 결과
  - 0.5B 언어 백본과 약 53M 학습 파라미터로 더 큰 VLA에 필적하거나 상회한다는 LIBERO·CALVIN 결과
  - 같은 평균 성공률에 학습 파라미터 약 11배 감소
  - 추가 학습 없이 LIBERO-Plus에 일반화
  - 구성요소 분석에서 행동 기반 라우터가 대안 둘보다 높은 98.0%
  - 실물 6개 과제 평균 성공률 52.0%로 최고, 과제당 10회 시행, 데이터가 적은 조건에서 더 큰 기준선 상회
- **가치** — 사전학습 VLM의 지각을 유지하며 3D 센서 없이 기하 지식을 이식하는 파라미터 효율적 경로 제시

### (c) 시사점

- 다중 시점 기하 접지를 VGGT 증류로 비전 분기에 넣는 후보
  - 추론 때 외부 3D 입력이 필요 없어 로봇 플랫폼이 바뀌어도 센서 구성 유지
- 원래 시각 경로를 보존하는 구조
  - 사전학습 지각 손실 우려를 낮추는 설계 기준점
- 병렬 경로와 라우터를 LoRA 규모로 구성
  - 도입 비용 낮음

### (d) 먼저 확인할 점

- 저자 스스로 실물 평가의 과제 다양성과 규모가 제한적이라 밝힘(실물 6개 과제, 평균 52.0%)
- 평가가 LIBERO·CALVIN과 팔 조작 중심, 다지 손과 촉각 입력 없음
- 라우터가 고르는 토큰이 손가락 접촉 영역 같은 좁은 영역에서도 유지되는지 확인 필요

## 🥉 논문 3

**From Predictive Geometry to Action: Learning Complementary Predictive Representations for Embodied Manipulation**
[arXiv:2610.28164](https://arxiv.org/abs/2610.28164) · Xiaoxu Xu, Hao Li, Hongtao Zhang, et al. · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — 초록 "The code will be available at https://github.com/xuxiaoxxxx/CPR"

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 예측 기하와 모터 표현을 따로 학습해 정책에 전이
- **문제** — 기하 구조와 그 예측된 변화를 행동 생성에 가장 도움이 되도록 어떻게 표현할지
  - 기하는 행동이 실행되는 공간 구조를, 그 변화는 장면이 어떻게 바뀔지의 단서를 제공
- **기존 한계** — 기하를 정책에 넣는 두 방향을 모두 지적
  - 입력 중심 방식(깊이, 점 구름, 3D 좌표, 사전학습 기하 특징)은 현재 관측 장면의 부가 맥락으로 쓰며 센싱이나 기하 추정 파이프라인에 의존
  - 예측 중심 방식(미래 RGB-D, 미래 기하 상태 지도)은 타깃이 조밀한 관측이나 통짜 잠재 상태라, 제어 관련성이 제각각인 기하 정보까지 표현이 보존해야 함
  - 두 방식 모두 행동 관련 정보와 일관된 세계 표현에 필요한 기하를 명시적으로 구분하지 않음
- **핵심 방법** — 다시점 영상 클립에서 예측 기하 표현과 모터 표현을 학습하는 2단계 프레임워크
  - 사전학습 — 동결 3D 파운데이션 모델의 조밀 기하 특징을 계층적 쿼리 인코더로 압축해 시간 상태로 구성
    - 기하 재구성, 마스크 표현 예측, 기하 전이 예측으로 장면 구조와 시간 변화를 보존
    - 연속한 예측 기하 상태 사이 전이에 행동 지도를 적용해 모터 표현 추출
  - 사후학습 — 현재 입력에서 예측 기하 표현을 추론하는 기하 쿼리를 학습하고, 행동 생성 경로의 중간 특징을 모터 표현에 정렬
  - 미래 관측과 사전학습 표현 모델은 학습 중 특권 지도에만 쓰고 추론 때는 불필요
- **차별점** — 두 역할을 한 표현에 맡기지 않고 둘로 분리
  - 예측 기하는 완결된 장면 구조를, 모터 표현은 제어에 정보가 되는 전이를 담당
- **핵심 기여** — 보완적 표현 학습과 정책 사이 전이
  - 예측 기하와 모터 표현의 보완적 역할 규명
  - 기하 쿼리와 모터 정렬 두 경로로 전이하는 2단계 프레임워크
  - LIBERO, LIBERO-Plus, SimplerEnv와 실물 양팔·단일 팔 과제에서 여러 정책 구조와 로봇에 걸쳐 일관된 개선
  - WidowX 평가에서 절대 10.4%p 향상
  - 여러 VLA 구조와 월드 액션 모델(WAM)로 전이, WAM에서 미래 세계와 행동 예측 개선
  - 실물 4개 과제(양팔 협응, 기하 지각, 접촉 민감 조작, 장기 과제) 모두에서 최고 성공률
- **가치** — 기하 사전학습을 행동 지향 표현으로 이어 주는 설계 원리와 구조 간 전이 가능성 제시

### (c) 시사점

- 기하 증류 인코더의 대안으로 예측 기하와 모터 표현의 이중 구조를 비교할 근거
  - 부록에서 DINO와 VGGT를 기반 인코더로 비교해 기하 쪽 이득 측정
- 추론 때 미래 관측과 3D 모델이 필요 없는 구조
  - 현재 입력과 정책만 배포
- 여러 VLA와 WAM으로 전이한 결과
  - 특정 정책 구조에 묶이지 않는 인코더 사전학습 후보

### (d) 먼저 확인할 점

- 코드 저장소는 공개 예정 표기로, 공개 시점과 체크포인트 포함 여부 미확인
- Methodology 2 — 시드 반복과 한계 진술 확인되지 않음
- 실물은 Flexiv 양팔과 단일 팔의 4개 과제, 다지 손과 촉각 입력 없음
- 사전학습에 동결 3D 파운데이션 모델과 대규모 이종 영상 필요
