## 🥇 논문 1

**GaussianWAM: Distilling Geometry and Semantics from 3D Gaussian Fields into World-Action Models**
[arXiv:2608.24714](https://arxiv.org/abs/2608.24714) · Zijian Zhang, Yuqing Jiang, Weitao Zhou 외 6인 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 8/15** · R3 · N2 · M2 · Real1 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 3D 가우시안 필드로 WAM 잠재에 기하·의미를 증류
- **문제** — WAM의 비디오 잠재가 시각 예측 위주로 학습되어 교차 뷰 기하와 물체 단위 의미를 보존하도록 제약받지 않음
  - 조작은 3차원 공간에서 일어나는데 RGB 재구성·예측만으로 학습한 잠재는 기하적으로 느슨
  - 언어 조건만으로는 시각 토큰이 과제 관련 물체와 그 위치에 대응한다는 보장 없음
- **기존 한계** — 기하·의미 지도를 넣는 두 갈래 모두 한계 지적
  - 기하 교사와 의미 교사를 따로 증류 — 서로 다른 표현 공간·시점·신뢰도의 특징에 별도 손실을 걸 뿐, 같은 3D 구조에 의미를 묶어 주는 공유 매개 없음
  - 명시적 3D/4D 월드 모델 — 추가 3D 인코더·디코더·렌더링 모듈·기하 주석·미래 3D 롤아웃이 필요해 학습 복잡도와 추론 비용 증가
- **핵심 방법** — 동기화된 다중 뷰 관측으로 3D 가우시안 필드를 만들고 렌더링한 의미·깊이·커버리지 신호를 WAM의 현재 관측 표현에 증류
  - 동결된 기하·비전 파운데이션 모델이 깊이, 카메라 파라미터, 밀집 의미 특징 제공
  - 이질적인 신호를 같은 가우시안 프리미티브에 결속하고 WAM 백본의 토큰 격자에 맞춰 렌더링
  - 렌더링 커버리지 신호로 유효한 기하와 가우시안 기여가 있는 위치에만 지도 한정
  - 교사 모델·가우시안 구성요소·보조 예측 헤드는 학습 뒤 모두 제거
- **차별점** — 기하와 의미를 각자의 2D 특징 공간에서 따로 증류하지 않고 하나의 3D 가우시안 필드에 묶어 증류하며, 추론 경로는 원래 WAM 그대로
- **핵심 기여** — 가우시안 필드 증류 프레임워크와 학습 전용 강화 전략, 두 WAM 백본에서의 향상
  - FastWAM과 Cosmos Policy 두 구조에 적용, LIBERO·LIBERO-Plus·RoboTwin·실물 조작에서 일관된 향상을 보고
  - LIBERO-Plus(시뮬레이션) FastWAM 52.05%에서 71.29%, Cosmos Policy 71.52%에서 77.30%
  - CLIP·VGGT 직접 증류만으로 FastWAM 69.37%, 가우시안 필드 통합으로 71.29%
  - 표준 LIBERO 향상, RoboTwin·실물 조작은 향상 경향 서술이며 초록에 수치 없음
- **가치** — WAM의 배포 구조와 추론 비용을 바꾸지 않고 기하·의미 감독을 넣는 경로 제시

### (c) 시사점

- 추론 모듈 추가 없이 다중 뷰 기하를 인코더에 넣는 학습 시 증류 사례
  - 관측 단계에서 통합 3D 임베딩을 두는 방식의 대안으로, 같은 목적을 학습 시점 비용으로 처리
  - 기하 증류 인코더가 일반 인코더보다 낫다는 방향과 일치
  - 도입 비용은 학습 시 교사 추론과 가우시안 적합에 한정, 배포 지연 증가 없음

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 증거 대부분이 LIBERO 계열 시뮬레이션, 실물은 수치 없는 향상 경향 서술
- 가우시안 통합의 몫은 CLIP·VGGT 직접 증류 69.37% 대비 1.92점으로 작음
- 시각 다중 뷰만 다루며 촉각·고유수용감각 융합은 범위 밖
- 동기화된 다중 뷰 관측과 오프라인 교사 캐시를 전제

## 🥈 논문 2

**TouchScale: 500 Hours of Human Vision and Touch for Visual-Tactile Learning**
[arXiv:2610.10288](https://arxiv.org/abs/2610.10288) · Dayou Li, Hao Wang, Qianqian Yang 외 23인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 10/15** · R2 · N2 · M2 · Real3 · Repro1 — arXiv comment "Project page: https://touch-scale.github.io/"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 단일 장치로 모은 500시간 인간 시각-촉각 데이터와 스케일 효과
- **문제** — 인간 에고센트릭 영상은 손의 움직임만 담고 접촉과 압력은 기록하지 않음
  - 시각-촉각 데이터셋 대부분이 30시간 미만이라 규모 효과를 한 데이터셋 안에서 연구하기 어려움
  - 여러 데이터셋을 합치면 센서와 수집 절차 차이가 비교를 교란
  - 수백 시간 규모의 통일된 촉각 데이터가 시각-촉각 학습과 로봇 조작에 이득인지 불분명
- **기존 한계** — 기존 시각-촉각 자원의 규모와 일관성 부족
  - 에고센트릭 시각-촉각 데이터셋 — 대부분 30시간 미만
  - 이를 합친 대형 자원 — 센서·주석 절차가 섞여 데이터 양의 효과를 분리 불가
- **핵심 방법** — 하나의 웨어러블 수집 장치로 500시간을 기록해 동기화된 에고센트릭 RGB-D, 손목 RGB, 양손 전손 촉각 장갑 측정 제공
  - 약 2K개 과제 설명, 1.5K개 이상 물체, 9개 수집 설정, 800개 이상 장면 구성
  - 수동 행동 주석 없이 참가자와 환경을 바꿔 반복 배치 가능
  - 로봇 정책에는 인간 손 동작 리타깃팅 없이 N0-VTLA의 시각-촉각 미드트레이닝에만 사용
- **차별점** — 같은 센서 세대와 동기화 파이프라인을 끝까지 유지해 센서 변수를 고정하고 데이터 양만 바꿔 규모 효과를 분리
- **핵심 기여** — 데이터셋과 수집 방식, 지각에서 로봇 제어까지의 평가, 규모 실험
  - 500시간 데이터셋과 확장 가능한 수집 방식, 데이터셋 공개 예정
  - 미지 촉각 센서(EgoTactile) 영샷 접촉 IoU — 16시간 크기 맞춤 부분집합 0.181 대 EgoTouch 학습 분할 0.134, 전체 데이터 0.383
  - 사전학습한 시각 인코더가 비교 데이터셋 중 행동 인식 정확도 최고, 벤치마크 3종
  - 실물 접촉 집약 4개 과제 평균 성공률 22.5%에서 57.5%
  - 규모 실험 — 영샷 접촉 IoU 0.311에서 0.383(전체의 10분의 1에서 전체), 실물 성공률 30.0%에서 57.5%(미드트레이닝 데이터 5분의 1에서 전체)
- **가치** — 일관된 센서로 모은 대규모 인간 촉각이 지각과 로봇 조작 모두에 이득이라는 규모 근거 제시

### (c) 시사점

- 일관된 센서로 모은 대규모 인간 촉각의 로봇 이전 근거
  - 손 전체 양손 촉각이라 손가락별 토큰 설계의 사전학습 소스 후보
  - 미지 센서로의 영샷 이전 수치는 센서 교체형 토큰 형식의 필요를 뒷받침
  - 시각 인코더에 촉각 감독을 넣는 사전학습은 동역학 인지 인코더 쪽 증거
  - 데이터 공개 뒤 내려받아 쓰는 구조라 도입 비용 낮음

### (d) 먼저 확인할 점

- 데이터셋은 공개 예정, 저장소와 체크포인트 신호 없이 프로젝트 페이지만 확인
- 실물 평가는 접촉 집약 4개 과제와 단일 정책 N0-VTLA에 한정
- 인간 장갑 촉각과 로봇 지단 촉각 센서 사이의 격차는 직접 검증되지 않음
- 규모 효과는 전체적 상승 경향으로 서술, 검증한 규모 범위 안에서만 해당

## 🥉 논문 3

**PointWAM: 3D World Action Modeling for Dexterous Robotic Manipulation**
[arXiv:2610.02840](https://arxiv.org/abs/2610.02840) · Chunghyun Park, Beomjun Kim, Seungcheol Park 외 5인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 8/15** · R2 · N2 · M2 · Real1 · Repro1 — arXiv comment "Preprint. Project page: https://chrockey.github.io/PointWAM"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ) [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ)

### (b) 논문 요지

- 장면과 손을 3D 점 궤적으로 분리 예측하는 WAM
- **문제** — 다지 조작은 손가락이 물체 표면에 맞춰 3D로 협응해야 하는데 기존 WAM이 3D 구조와 행위자-환경 인과를 담지 못함
- **기존 한계** — 세 갈래 모두 한계 지적
  - RGB 프레임이나 잠재 기반 WAM — 3D 공간 구조와 행위자-환경 인과 관계 포착이 약함
  - 점 기반 정책 — 3D 점 궤적을 예측하지만 환경이 어떻게 변하는지 모델링하지 않고, 과제 관련 물체를 사람이나 외부 지각 모델이 골라야 함
  - 행동 조건 3D 월드 모델 — 밀집 3D 장면 궤적을 예측하지만 로봇 행동을 입력으로 취급할 뿐 예측 대상이 아님
- **핵심 방법** — 컬러 포인트 클라우드와 언어 지시에서 장면 점과 손 키포인트의 궤적을 공통 시공간 좌표계에 함께 예측하고, 행동 리타게터가 예측한 손 궤적을 로봇 행동으로 변환
  - 3D 궤적 예측기가 장면과 손의 공진화를 모델링
  - 행동 리타게터가 손 궤적을 로봇 손 행동으로 변환
  - 인간 시연과 로봇 시연을 함께 쓰는 학습
- **차별점** — 장면과 손을 분리 표현하되 같은 3D 공간에서 함께 예측, 과제별 물체나 키포인트를 미리 고를 필요 없음
- **핵심 기여** — 3D 월드 행동 모델과 DexJoCo 결과
  - 장면 궤적 감독으로 DexJoCo 평균 성공률 10.9점 향상, 3D 인코더가 리프트한 이미지 특징보다 5.4점 우위(시뮬레이션)
  - EgoDex와 VITRA 인간 시연 사전학습으로 DexJoCo 평균 56.9점 향상(처음부터 학습 대비)
  - DexJoCo 기존 최고 다과제 성공률을 11.7점 상회, 실물 로봇에서 로봇 사전학습 VLA를 최대 25점 앞섬
- **가치** — 인간 시연 영상을 다지 조작 사전학습 자원으로 쓰는 3D 표현 경로 제시

### (c) 시사점

- 손 중심 3D 궤적을 로봇 손 행동으로 옮기는 경로
  - 손 키포인트를 장면과 분리해 다루는 구조는 손 단위 집계 설계와 맞닿음, 손가락 위상 인코딩 검증은 아님
  - 인간 영상 사전학습 향상 폭 56.9점은 인간 데이터 활용 근거
  - 포인트 클라우드 입력은 다중 카메라 융합과 별개의 3D 입력 선택지

### (d) 먼저 확인할 점

- 정량 결과 대부분이 DexJoCo 시뮬레이션, 실물 우위 폭은 최대 25점이라는 서술만 확인
- 코드는 공개 예정, 프로젝트 페이지만 확인
- 컬러 포인트 클라우드 입력은 깊이 센서와 캘리브레이션 전제
- 촉각·고유수용감각 융합은 범위 밖
