**NAT: Scaling Causal Neural Action Tokenizers Across Embodiments**
[arXiv:2611.28873](https://arxiv.org/abs/2611.28873) · Ahad Jawaid, Alexander Swerdlow, Yu Xiang · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 49k시간 행동 데이터로 학습한 인과적 범용 행동 토크나이저
- **문제** — 신체와 수집 방식이 다른 행동을 하나의 어휘로 인코딩하는 범용 행동 토크나이저, 학습에 없던 신체까지 포함
  - 로봇 데이터는 신체마다 행동 공간·제어 주파수·가동 범위가 다름
  - 원격조작, 핸드헬드 그리퍼(UMI), 시뮬레이션, 인간 손 기록으로 수집 방식도 갈림
- **기존 한계** — 행동 토큰화 세 갈래가 각자 비용을 남김
  - **균등 구간화** — 대부분의 로봇에 적용되나 토큰열이 길어 추론이 느림
  - **FAST** — 주파수 변환과 바이트 쌍 인코딩으로 짧은 시퀀스를 만들고, 공개된 FAST+는 로봇 궤적 1M개로 학습
  - **학습형 신경 토크나이저** — FAST보다 적은 토큰으로 행동을 표현하나 대부분 비교적 작은 데이터로 학습해 대규모·다양 데이터에서의 거동이 미탐색
- **핵심 방법** — 인과적 디코더를 가진 신경 토크나이저 NAT
  - **인코딩** — 행동 청크를 다중 시간 스케일의 유한 스칼라 양자화(FSQ)로 짧은 토큰열에 압축
  - **인과 디코더** — 토큰이 생성되는 동안 행동을 디코딩해 실행을 시작, 시간 순서 토큰으로 실행 중인 행동에 다음 청크를 조건화
  - **정책 연결** — NAT 토큰으로 VLA를 사전학습하고, 토큰으로 구동하는 경우와 플로우 매칭 행동 헤드로 구동하는 경우를 비교
- **차별점** — 156개 데이터셋 49k시간(실물 로봇·UMI·시뮬레이션·인간 손)으로 토크나이저를 학습하고 미보유 신체에서 평가
  - 학습 신체 밖에서 평가해 범용성을 직접 측정
- **핵심 기여** — 토크나이저 성능, 데이터 구성 효과, VLA 사전학습·구동 결과
  - **미보유 신체** — 시뮬레이션 4개 벤치마크에서 FAST, OAT, ActionCodec, NAC보다 평균 성공률 높음
  - **인간 손 모션만 학습** — 로봇 데이터로 학습한 토크나이저에 근접, 모든 소스를 쓴 경우에도 거의 동등
  - **VLA 사전학습** — 로봇 데이터 1.8k시간을 NAT 토큰으로 VLM에 추가 학습한 뒤 미세조정하면 VLM 직접 미세조정보다 시뮬레이션 4개 벤치마크 평균 성공률 상승
  - **FAST+ 대비** — 시뮬레이션 4개 벤치마크와 Trossen AI Solo 팔 실물 4개 과제(원격조작 시연 481개로 미세조정)에서 상회
  - **플로우 헤드 대비** — 토큰 구동은 첫 행동이 더 빠르고 LIBERO에서 95% 구간 안에서 동등, 일부 벤치마크에서는 여전히 뒤처짐
  - **산출물** — 토크나이저 체크포인트 공개
- **가치** — 이종 신체 데이터를 한 이산 행동 어휘로 묶을 수 있는지와 인간 손 데이터만으로 행동 공간을 학습할 수 있는지에 대한 대규모 근거

### (c) 시사점

- 이산 행동 코드의 대규모 기준점 확보
- **행동 표현** — 이산 토큰과 연속 플로우 매칭 헤드를 같은 VLA에서 맞댄 측정, DQ-RISE의 이산 손 코드가 한 설정에 머문 것과 대비
- **코퍼스 구성** — 인간 손 모션만으로 학습한 토크나이저가 로봇 데이터 학습 결과에 근접, 인간 영상 코퍼스를 행동 공간 학습에 쓰는 근거
- **도입 비용** — 체크포인트만 공개되어 재현은 직접 구현 필요

### (d) 먼저 확인할 점

- 토큰 구동이 일부 벤치마크에서 플로우 매칭 헤드에 뒤처지며 저자도 한계로 명시
- 청크당 토큰 수 고정, 단일 청크 길이 학습
- 정책 학습 데이터는 LIBERO로 고정하고 토크나이저 코퍼스만 키워, 정책 코퍼스와 함께 키운 효과는 미검증
- 인간 손 모션만 학습한 결과는 로봇 데이터 학습에 근접한 수준이며 동등으로 단정 불가
- 실물 검증은 한 팔 플랫폼에 한정, 코드 저장소·공개 약속 없음

## 🥈 논문 2

**Awaken-HI: Scaling Humanoid Intelligence with Whole-Body Human Experience**
[arXiv:2611.26420](https://arxiv.org/abs/2611.26420) · EngineAI · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — arXiv comment "project page: https://engineai-robotics.github.io/Awaken-HI" — 프로젝트 페이지만, 코드 언급 없음

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 논문 요지

- 5만 시간 에고센트릭 영상과 전신 모션을 묶은 휴머노이드 사전학습
- **문제** — 휴머노이드 전신 이동 조작 정책에 쓸 로봇 시연이 전신 원격조작 비용 때문에 과제와 환경 범위가 좁음
  - 영상만으로는 전신 모션의 명시적 목표가 없음
- **기존 한계** — 인간 모션을 로봇 행동으로 리타깃팅해 목표를 얻는 방식과 기존 에고센트릭 데이터셋의 공백
  - **리타깃팅** — 체형과 관절 구조 차이로 자세와 손 궤적이 인간 시연에서 벗어남
  - **기존 에고센트릭 데이터** — 다수가 영상만 있거나 머리와 손만 추적하고, Nymeria는 짝지어진 기록이 수백 시간에 그침
- **핵심 방법** — 원래 인간 모션과 리타깃팅된 로봇 행동을 한 액션 전문가가 함께 예측
  - **데이터** — 에고센트릭 스테레오 영상과 동기화된 전신 모션을 짝지은 Awaken-Human, 100개 넘는 기술, 3D 손 모션 복원과 하위 과제 설명·프레임별 깊이 주석 부여
  - **사전학습** — 공유 액션 전문가가 카메라 좌표계 손목 자세도 예측하고 별도 헤드가 현재·미래 깊이와 현재 하위 과제를 추정
  - **적응** — T800 원격조작 약 150시간으로 같은 로봇 행동 인터페이스에서 후학습
- **차별점** — 리타깃팅 결과만 쓰지 않고 원래 인간 궤적을 공유 액션 전문가의 직접 지도로 유지
  - 리타깃팅 후에도 원래 인간 모션이 유효한 사전학습 목표라는 주장
- **핵심 기여** — 데이터셋, 모델, 데이터 규모 효과와 실물 결과
  - **Awaken-Human** — 약 50,000시간 에고센트릭 스테레오 영상과 전신 모션
  - **스케일링** — 인간 사전학습 데이터를 5,000시간에서 50,000시간으로 늘리면 보류 로봇 행동 예측 오차가 경험적 멱법칙으로 감소하고, 같은 후학습 시연으로 가정 과제 3개의 평균 성공률도 상승
  - **절제** — 인간 모션 지도를 더하면 리타깃팅 행동만으로 사전학습한 경우보다 행동 예측 오차가 줄고 실물 성공률이 개선
  - **실물 비교** — T800 개별 과제 8개 평균 성공률 93.75%로 GR00T N1.7과 π0.5를 모두 상회하고 장기 과제에서도 우위
  - **일반화** — 후학습에 없던 물체와 익숙한 물체·목적지의 새 조합에서도 동작
- **가치** — 불완전하게 리타깃팅되는 인간 전신 모션을 대규모 사전학습 지도로 쓰는 경로와 데이터량 대비 효과 곡선 제시

### (c) 시사점

- 인간 데이터량 대 로봇 성공률의 실물 곡선 확보
- **코퍼스 구성** — 에고센트릭 5,000시간에서 50,000시간까지 데이터량을 바꿔 행동 예측 오차와 실물 성공률을 함께 보고한 드문 사례
- **행동 전문가** — 인간 모션과 로봇 행동을 하나의 공유 전문가가 함께 예측하는 구조, 로봇 전용 전문가를 따로 두는 설계와 대비
- **도입 비용** — 약 50,000시간 전신 모션 수집과 휴머노이드 플랫폼이 전제

### (d) 먼저 확인할 점

- 비교 기준선이 GR00T N1.7과 π0.5 둘이고 반복 시드와 자체 한계 진술이 없음
- 스케일링 법칙은 5,000시간에서 50,000시간 구간의 경험식
- 실물 평가가 T800 한 플랫폼이며 과제당 10회 시행
- 데이터셋과 코드 공개 문구 없음, 프로젝트 페이지만 있음

## 🥉 논문 3

**SCAP: Stochastic Context for Action Expert Pretraining**
[arXiv:2611.27187](https://arxiv.org/abs/2611.27187) · Xiao Lin 외 11명 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW)

### (b) 논문 요지

- 시각·텍스트 토큰을 무작위 마스킹하는 액션 전문가 사전학습 단계
- **문제** — 시연의 장면과 지시 사이 상관이 시각 지름길을 낳아 정책이 언어를 무시하는 현상
  - 액션 전문가는 무작위 초기화라 이 편향을 쉽게 물려받고, 공동 미세조정 중 역전파로 사전학습된 VLM 표현을 해칠 수 있음
- **기존 한계** — 한 모달리티만 보여주는 사전학습 단계가 시각·언어 결합 경로를 닫을 수 있음
  - **시각-행동 사전학습** — APT와 BayesVLA가 시각 운동 사전지식을 먼저 학습한 뒤 언어를 도입
  - **언어-행동 사전학습** — LA4VLA가 시각 없이 지시와 행동의 연관을 학습
  - **공통 한계** — 결합 계산을 직접 지도하지 않으면서 이를 받치는 파라미터가 계속 바뀌어, 이후 전체 입력 학습으로도 경로를 되살리지 못한다는 것이 저자의 진단 모델 결과
- **핵심 방법** — 전체 입력 학습에 앞선 마스킹 단계를 넣는 두 단계 학습
  - **1단계** — VLM에 들어가기 전 시각·텍스트 토큰을 무작위로 가리고 액션 전문가만 갱신
  - **2단계** — 완전한 시각·언어 입력으로 모델 전체를 갱신
  - **일반화** — 시각-행동, 언어-행동, 전체 입력 사전학습은 마스크 분포를 달리한 특수한 경우
- **차별점** — 한 모달리티를 통째로 빼는 대신 두 모달리티의 가림 정도를 섞어 결합 경로를 열어 둠
  - 상호 보완적인 단서가 보이는 경우가 충분히 잦으면 결합 경로가 닫히지 않는다는 분석
- **핵심 기여** — 진단과 방법, 평가 프로토콜
  - **진단** — 한 모달리티 사전학습이 결합 경로를 끄고, 이후 완전한 입력 학습으로도 복구되지 않는 진단 모델
  - **시뮬레이션** — RoboTwin 2.0과 RoboCasa-GR1에서 네 VLA 구조 전반과 여러 모델 규모에서 다른 사전학습 방식보다 일관되게 개선
  - **실물** — 지시 조건형 조작 과제 3개 평균 성공률 76.67%로 전체 입력 사전학습보다 25%포인트 높음(지시당 10회 시행)
  - **프로토콜** — 다과제 시뮬레이션, 지시 문장 개입 쌍, 실물 결합 접지를 묶은 통제 평가
- **가치** — 액션 전문가 사전학습 단계의 입력 구성이 이후 적응의 언어 의존과 VLM 표현 보존을 좌우한다는 설계 지침

### (c) 시사점

- 액션 전문가 사전학습 단계 설계의 대조 기준
- **단계 분할** — 시각·언어 마스킹 단계와 전체 입력 단계로 나누는 레시피가 한 단계 혼합 학습보다 앞서는지 같은 조건에서 비교
- **행동 전문가** — 무작위 초기화된 전문가를 VLM 위에서 학습하는 방식의 손상 경로를 진단
- **도입 비용** — 마스크 분포만 바꾸는 단계라 구조 변경은 작으나 코드 공개 없음

### (d) 먼저 확인할 점

- 진단 결과는 단순화한 모델과 모집단 경사 흐름 가정 아래의 분석
- 반복 시드와 자체 한계 진술이 없음
- 실물 평가가 과제 3개, 지시당 10회 시행
- 사전학습에 쓴 약 120만 궤적 규모와 구성이 결과에 얼마나 묶이는지 미확인
- 코드 저장소·공개 약속 없음

## 🌱 논문 4 — 인접 분야 픽

**TouchTwin: Scaling Human Touch Data via Real-to-Sim-to-Real**
[arXiv:2611.17619](https://arxiv.org/abs/2611.17619) · Huiwen Han 외 8명 · adjacent field: 보철·신경과학 — 인간 촉각 계측 · arXiv preprint

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — P0 2026-11-18 판정 유지

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 측정한 인간 촉각으로 시뮬레이션 재현의 접촉력을 채움
- **문제** — 영상 기반 실제-시뮬레이션 재구성은 손이 어떻게 움직였는지만 복원하고 어느 손가락이 언제 얼마나 세게 누르는지 알 수 없음
  - 손 자세는 손가락이 멈춘 위치만 보여주고 닫는 힘은 보여주지 않으며 접촉도 자주 가려짐
- **기존 한계** — 영상에서 재구성하는 두 가지 쓰임이 반대 방향으로 실패
  - **자세 모방** — 기록된 힘의 0.31배로 쥠
  - **영상 기반 재현** — 기록된 힘의 1.55배로 쥠
  - **영상에서 예측한 촉각** — 같은 픽셀에서 장갑 신호를 재현하도록 학습되어 픽셀에 없는 힘을 복원하지 못하고 기록 조건을 바꾸지도 못함
  - **기존 장갑 활용** — 손-물체 동역학 모델링, 촉각과 영상 사이 변환, 정책 지도에 쓰였으나 측정 촉각으로 구동하는 물리 시뮬레이션으로 상호작용을 재구성한 사례는 없다는 것이 저자 주장
- **핵심 방법** — 촉각 장갑 기록을 MuJoCo에서 재구성해 재생
  - **입력** — 머리·손목 RGB-D 카메라와 880개 택셀 장갑으로 기록한 TouchScale 녹화
  - **물체** — 코딩 에이전트가 물리 시험을 거친 프로그램으로 작성
  - **손** — 피험자별 촉각 손 모델이 재생하며 기록된 촉각이 접촉과 손가락별 닫는 힘을 결정
  - **데이터 엔진** — 각 재생이 접촉·힘 라벨이 붙은 교란 시연의 씨앗이 되고 새 시점·장면의 영상으로 렌더링
- **차별점** — 영상에서 촉각을 추정하지 않고 측정한 촉각으로 시뮬레이션의 접촉과 힘을 정함
  - 한 녹화를 새 조건에서 다시 재생 가능
- **핵심 기여** — 시뮬레이션 실험 결과
  - **힘 비율** — 촉각 기반 재생으로 학습한 정책이 기록된 힘의 0.99배로 쥠(자세 모방 0.31배, 영상 기반 재현 1.55배)
  - **보류 녹화** — 시뮬레이션에서 20/20회 성공, 보지 못한 교란 36개 중 35개 성공
  - **접촉 예측기** — 실제 접촉 프레임을 놓치는 비율이 13%로 영상 기반 재현의 32%보다 낮음
- **가치** — 영상으로 만든 시뮬레이션 데이터에 접촉력을 더할 수 있다는 경로

### (c) 시사점

- 영상에 없는 접촉력을 측정 촉각이 채우는지 확인할 사례
- **코퍼스 구성** — 에고센트릭 영상에서 손 위치와 접촉 시점은 얻어도 힘이 빠진다는 공백을 장갑 촉각으로 메우는 방법
- **도입 비용** — 880택셀 장갑 녹화가 전제, 시뮬레이션 결과이고 로봇 손 이전은 미검증

### (d) 먼저 확인할 점

- 모든 정책이 시뮬레이션 자산에서 개루프로 시험되었고 로봇 손과 실물 실험은 후속 과제
- 정책·접촉 실험은 머그컵 과제 하나이고 보류 집합이 작음
- 보류 클립이 손이 이미 접촉한 상태에서 시작해 접촉 시작 시점은 미시험
- 양손 재생에서 손 안 미끄러짐 12–23mm, 생성 영상이 시뮬레이션 오차를 물려받음
- 코드 저장소·공개 약속 없음
