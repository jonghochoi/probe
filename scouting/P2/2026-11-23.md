## 🥇 논문 1

**SHAPE: Discrete Supervision and Parallel Continuous Streams for Learning Dexterous Manipulation from Egocentric Human Data**
[arXiv:2611.24585](https://arxiv.org/abs/2611.24585) · Yaping Li 외 12명 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음 — 프로젝트 페이지만

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 이산 토큰 보조 지도와 병렬 두 스트림으로 인간 영상을 학습
- **문제** — 에고센트릭 인간 영상은 저렴하지만 관절 위치와 구동 명령이 없어 로봇 정책 지도 신호로 쓰기 어려움
  - 추적된 손은 공유 EEF 공간으로 리타깃팅되지만, 관절로 옮기는 IK는 신체별 대응에 의존하고 분포 밖 팔 자세를 낳음
  - 인간 데이터로 어떻게 지도할지, 배포 때 행동을 어떻게 읽어낼지 두 질문이 걸림
- **기존 한계** — 두 갈래의 기존 정책이 각각 불명확한 지점을 남김
  - **연속 디코더 지도** — 공유 EEF 행동을 연속 디코더로 지도해 백본에는 디코더를 거쳐서만 기울기가 전달됨
  - **이산 토큰 학습** — 데이터와 구조가 동시에 달라지거나 두 손실을 분리하지 않고 합쳐서, 이산 지도가 인간 데이터 학습에 도움이 되는지 불명확
  - **관절 출력만 실행** — 로봇 전용 관절 출력을 EEF 출력 옆에 두고도 관절 출력만 실행
- **핵심 방법** — 백본의 이산 보조 과제와 공유 플로우 매칭 전문가의 이중 스트림
  - **이산 지도** — 백본이 EEF 청크의 FAST 토큰을 인간·로봇 샘플에 같은 어휘로 예측
  - **이중 스트림 액션 전문가** — 공유 플로우 매칭 전문가가 EEF 스트림(인간·로봇 데이터 지도)과 관절 스트림(사전학습에서 로봇 데이터만 지도)을 독립 출력
  - **배포** — 두 스트림 모두 실행 가능해 시험 때 한쪽을 골라 구동
- **차별점** — 이산 지도를 보조 손실로만 두고 실행은 연속 스트림이 담당
  - 인간 관절 라벨 없이 공유 백본과 전문가를 거쳐 인간 사전학습이 관절 스트림까지 전달됨
- **핵심 기여** — 통제된 2×2 사전학습과 실물 1,680회 시행
  - **통제 비교** — 인간 데이터와 이산 손실 유무만 바꾸고 구조, 로봇 데이터, 학습 예산을 고정한 모델 4종, 인간 에고센트릭 2.8k시간과 로봇 텔레오퍼레이션 228시간
  - **실물 결과** — 로봇 시연 미세조정에서 6개 과제 평균 0.80, π0.5는 0.63
  - **스트림 선택** — 로봇 시연이 있으면 관절 읽기가 24쌍 중 23쌍에서 우세, 인간 시연만 있으면 관절 스트림 0/240, EEF 스트림 32/240 성공
  - **시뮬레이션** — 사전학습에 없던 두 번째 로봇에서 네 모델과 두 기준선 평가
- **가치** — 인간 영상 사전학습에서 이산 지도의 효과를 분리 검증하고 읽기 경로 선택 기준 제시

### (c) 시사점

- 인간 영상 지도 신호 비교에 쓸 통제된 이산 대 연속 기준점
- **행동 표현** — 이산 토큰이 연속 전문가를 대체하지 않고 보조 지도로 병행될 때의 이득을 같은 조건에서 측정, DQ-RISE의 이산 손 코드와 대비되는 설계
- **코퍼스 구성** — 인간 2.8k시간 대 로봇 228시간 혼합에서 인간 데이터 효과를 표현·기울기 수준에서 분석
- **도입 비용** — 22자유도 손 양팔 플랫폼 전제, 공개 코드 없음

### (d) 먼저 확인할 점

- 비교 기준선이 π0.5 포함 둘뿐이고 실물 평가가 한 플랫폼의 20회 시행 과제에 한정
- 읽기 경로 결과가 저자의 인간 리타깃팅 파이프라인과 표준 제어 구성에 묶여 있음
- 프로젝트 페이지만 있고 코드·체크포인트 공개 문구 없음
- 저자가 더 큰 인간 영상 코퍼스와 더 많은 신체로의 확장을 후속 과제로 남김

## 🥈 논문 2

**Finetuning VLAs for Dexterous Manipulation: The Right Checkpoint Is All You Need**
[arXiv:2611.23676](https://arxiv.org/abs/2611.23676) · Artur Kuramshin 외 5명 · CoRL 2026 Workshop on Dexterous Manipulation · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- 조종 가능성으로 VLA 미세조정 레시피 다섯 가지를 비교
- **문제** — 병렬 그리퍼 중심 사전학습 VLA를 소수 시연으로 다지 손에 적응시키는 방법
  - 다지 손 데이터는 사전학습에 드물고 텔레오퍼레이션 수집 비용이 커서 적응이 필수
- **기존 한계** — 어느 파라미터를 어떤 비율로 갱신할지가 논쟁 중이며 결론이 최고 SFT 체크포인트 성공률에만 근거
  - 언어 모델이나 비전 인코더를 동결하면 적응이 나빠진다는 보고가 있음
  - 행동 경로의 기울기를 백본에 넣지 않는 기본값을 택한 연구도 있음
  - 적응이 잠재 노이즈 조종으로 끝날 때 SFT 체크포인트는 초기값일 뿐이라는 점이 평가에서 빠짐
- **핵심 방법** — 다섯 SFT 레시피를 만든 뒤 DSRL 조종으로 비교
  - **레시피 축** — 액션 전문가만, 비전 경로 추가, 전체 모델 학습, 언어 모델과 액션 전문가를 전체 또는 LoRA로 갱신
  - **평가** — π0.5와 16자유도 LEAP 손, RoboCasa 기반 시뮬레이션 두 과제 CoffeePressButton·ScrewLightbulb에서 SFT 체크포인트별 조종 전후 성공률 측정
- **차별점** — SFT 직후 성공이 아니라 잠재 노이즈 조종 이후 성공으로 레시피를 평가
- **핵심 기여** — 세 가지 결과와 권고 레시피
  - SFT 성공률은 조종 후 성공률과 유의한 양의 상관이 없고 CoffeePressButton에서는 역상관
  - 액션 전문가만 학습하는 레시피가 모든 평가 구성에서 일관되게 조종되고 두 과제 학습 배치에서 95–100%
  - 언어 모델을 갱신하는 세 레시피가 가장 낮고 LoRA 두 변형도 보호 효과 없음
  - ScrewLightbulb 8k 스텝에서 액션 전문가만 학습한 경우 학습 배치 100%, 외삽 배치 88%, 나머지 레시피는 모두 33% 이하
  - 권고는 VLM 동결과 액션 전문가 전체 학습, SFT 성공률을 체크포인트 선택 지표로 쓰지 않기, 기술을 처음 재현하는 가장 이른 체크포인트 사용
- **가치** — 조종 기반 적응 파이프라인에서 레시피와 체크포인트 선택 기준 제시

### (c) 시사점

- 적응 단계에서 백본 학습 범위를 조종 가능성으로 비교한 기준점
- **적응 범위** — 동결 VLM과 액션 전문가 전체 학습, LoRA, 전체 미세조정을 같은 π0.5와 같은 손에서 대조
- **체크포인트 선택** — 최고 SFT 성공 체크포인트가 조종 초기값으로는 최선이 아니라는 측정, ConSFT 같은 배포 적응 접근에서 선택 지표 점검 대상
- **도입 비용** — 레시피 변경만으로 적용 가능, 별도 데이터 불필요

### (d) 먼저 확인할 점

- 평가가 시뮬레이션 두 과제뿐이고 실물 검증 없음
- 초기 ScrewLightbulb 체크포인트는 전구를 잡지 않고 손바닥으로 돌려 성공해 초기 체크포인트 성공이 쓸 만한 기술을 과대평가
- 레시피마다 SFT를 한 번만 수행해 세 개의 RL 시드가 SFT 분산을 담지 못함
- 코드 저장소나 공개 약속 없음

## 🥉 논문 3

**ScaleVLA: Scaling Vision-Language-Action Models to 552 Billion Parameters**
[arXiv:2611.21607](https://arxiv.org/abs/2611.21607) · Ruixi Yu 외 11명 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R2 · N3 · M3 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문

[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- 552B VLM 백본을 액션 DiT에 연결해 백본 규모를 비교
- **문제** — 최전선 VLM의 지식이 더 강한 로봇 정책의 기반이 될 수 있는지
  - 시각 인식, 공간 이해, 추론을 담은 대규모 사전학습 표현이 로봇 시연에서 얻은 것이 아님
- **기존 한계** — 대부분의 VLA가 작은 VLM 백본에 머묾
  - GR00T N1.7의 2B Cosmos-Reason2가 예로 제시됨
  - 이런 백본이 최전선 VLM의 지식을 충분히 담지 못할 수 있다는 것이 저자의 주장
- **핵심 방법** — 552B VLM을 학습 가능한 액션 DiT에 연결
  - **백본** — DeepSeek-V4.1-Flash의 희소 전문가 혼합 구조, 토큰당 일부 파라미터만 활성화
  - **액션 헤드** — GR00T의 액션 전문가 구조를 따른 DiT가 다중모달 표현을 연속 행동으로 변환
  - **추론** — VLM 인과 인코더 특징만 추출하고 자기회귀 추론이나 텍스트 생성 없음
- **차별점** — 액션 구조, 초기화, 로봇 시연, 최적화 예산을 고정하고 백본 크기만 2B부터 552B까지 변화
  - 추가 행동 지도나 사전학습된 행동 전문가를 쓰지 않음
- **핵심 기여** — 세 능력에서 큰 백본의 이득 보고
  - **표본 효율** — LIBERO-Goal에서 시연 10개로 87.8%, 시연 50개로 학습한 2B 백본은 85.6%
  - **일반화** — LIBERO-PRO 교란에서 평균 45.1%, 더 작은 백본은 최대 31.3%
  - **정밀 조작** — 실물 양팔 충전기 삽입 기준 배치 10회 중 9회 성공, 2B 백본은 4회, 개선은 접근과 파지가 아닌 접촉 민감한 정렬과 삽입에 집중
  - **지연** — 네 개의 H200에서 액션 청크당 중앙값 216ms
  - **실행 시간** — 성공 시행 중앙값 114.4초, π0.5 + 액션 헤드의 132.0초보다 13% 짧음
- **가치** — 최전선 VLM을 고수준 추론기가 아니라 빠른 학습형 정책의 표현 기반으로 쓸 수 있다는 근거 제시

### (c) 시사점

- 사전학습 백본 규모가 적응 데이터량을 줄이는지 직접 측정한 사례
- **백본 선택** — 같은 액션 구조에서 2B–552B를 비교해 시연 10개로 2B의 50개 결과를 넘는 수치 제시
- **적응 비용** — 규모 이득이 시연이 적거나 환경이 바뀔 때 크다는 저자 해석, 사전학습 백본 선택 기준에 반영 가능
- **도입 비용** — 학습에 H200 64장, 추론에 H200 4장이 필요해 높음

### (d) 먼저 확인할 점

- 실물 평가가 충전기 삽입 한 과제의 10회 시행
- 표본 효율 수치가 LIBERO-Goal 한 스위트의 결과
- 저자가 작은 백본보다 하드웨어 비용이 높다고 인정
- 손재주 평가는 시뮬레이션 DexJoCo 수준
- 코드 저장소나 공개 약속 없음

## 🔄 직전 리포트 대비 종합

- **필터 상태** — 242편 제외, 중복 2편, Anti-topic·범위 밖 200편, R/N 미달 40편
- **상충 가능성** — Finetuning VLAs for Dexterous Manipulation(2611.23676)의 VLM 동결 우세는 직전 리포트의 VLA Finetuning(2611.09964)에서 VLM 동결 시 π 계열이 하락한 결과와 방향이 엇갈림
  - 앞선 리포트의 HuGe(2610.34186)가 전체 미세조정이 LoRA를 앞선다고 본 결과와는 LoRA 열세 방향이 같음
  - 평가 기준(SFT 성공률 대 조종 후 성공률)과 설정(LIBERO 대 시뮬레이션 다지 손)이 달라 직접 모순으로 단정하지 않음
