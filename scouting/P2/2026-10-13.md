## 🥇 논문 1

**From Wearable Interfaces to Dexterous Policies: Contact Shifts and Tactile Representations**
[arXiv:2610.08870](https://arxiv.org/abs/2610.08870) · Ruitong Tian, Fang Xu, Noah B. Wilson et al. · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음 — 본문은 기존 "released DexUMI" 파이프라인 재사용만 언급

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 착용형 수집 기구 형상과 촉각 표현의 정책 기여 분리
- **문제** — 착용형 시연 수집 기구 자체가 시연을 만드는 물리 상호작용의 일부, 기구 형상이 기록 촉각과 정책 성능을 바꾸는지 미확인
  - 로봇 정합 외골격은 사람 손가락을 12-DoF XHand 명령 공간에 사상, 로봇 유래 손가락 간격·관절 여유·링크 형상을 사람 손에 강제
  - 특히 엄지의 대립·회선 운동이 로봇 기구 구조와 어긋나 신체 부담·동작 제한·국소 불편 유발
  - 제한적 링크는 파지 궤적을, 센서 주변 재질은 촉각면의 물체 도달 여부를 바꿀 수 있음
- **기존 한계** — 기존 수집 방식과 촉각 입력 각각의 공백 지적
  - 인간 손 비디오·모션 캡처 — 로봇 없이 수집 가능하나 정밀 접촉과 로봇 실행 가능 관절 명령 복원이 어려움
  - 로봇 측 텔레오퍼레이션·hand-over-hand 인터페이스 — 배포 신체에 가까운 액션이나 수집 시 실물 로봇 손 필요, 접촉 집약적 과제에서 번거로움
  - DexUMI 계열 착용형 외골격 — 로봇 정합이 강점이나 그 정합이 사람 손과의 설계 긴장 유발
  - 이진 집계 촉각 입력(공개 DexUMI 기준선) — 손가락별 접촉 발생은 남기나 패드 내 접촉 위치·힘을 버림, 기록된 접촉 차이가 정책 도달 전에 사라질 수 있음
- **핵심 방법** — 손 쪽 형상만 다른 DexUMI 계열 외골격 두 버전의 통제 비교
  - 두 버전이 XHand 명령 정의·엔코더 배정·보정 절차·촉각 모듈 종류·로봇 플랫폼을 공유, 손 쪽 형상만 개정
  - 운영자 경험·촉각 패드 접근성, 일치 시연의 접촉 위치·발생 빈도, 정책 성능 순으로 측정
  - 같은 저장 촉각 배열(엄지·검지·중지, 손끝당 120 택셀 3축 힘)에서 두 입력 구성
    - 이진 집계 — 손가락당 접촉 플래그 1개
    - 공간+힘 — 360 택셀 이진 접촉 맵과 손끝별 합산 3축 힘 벡터, 369차원
  - 수집 인터페이스 2종과 촉각 입력 2종을 교차해 Diffusion Policy 학습, 같은 XHand(Franka 팔 장착)에서 셀당 20회 평가
- **차별점** — 로봇 명령·사상·보정·감지 파이프라인을 고정한 채 수집 기구 형상과 촉각 표현을 별개 요인으로 분리
  - 원시 촉각 배열을 수집 시 보존해 재수집 없이 표현 비교 가능
- **핵심 기여** — 수집 기구 형상이 촉각 데이터를 바꾼다는 실측과 두 요인의 정책 기여 분리
  - 개정 인터페이스 — 보고된 신체 부담 감소, 기준 형상에서 기계적으로 막힌 정밀 파지의 촉각 접근 회복
  - 뚜껑 돌리기 — 엄지 접촉 중심이 패드 평면에서 8.6mm 이동(세션 단위 순열 검정 p<0.001)
  - 계란판 열기 — 검지 접촉 프레임 비율 0.09에서 0.18로 증가(p=0.003), 활성 택셀 수는 2.7에서 3.0으로 변화 작음
  - 실물 촉각 표현 비교 — 공간+힘 입력이 이진 집계보다 6개 과제·인터페이스 비교 전부 우위, 통합 성공률 0.35에서 0.52(공통 오즈비 2.1, p=0.010)
  - 실물 인터페이스 비교 — 개정 인터페이스 시연이 4개 공유 과제 비교 전부 우위, 통합 성공률 0.39에서 0.59(공통 오즈비 2.5, p=0.013)
  - 인터페이스 이득이 두 입력에서 비슷한 크기(0.20–0.25, 0.15–0.20), 두 요인이 별개로 기여
  - 실물 과제 4개 — 뚜껑 돌리기·계란판 열기·USB 삽입·납땜 인두 집어 놓기, 셀당 20회
- **가치** — 착용형 수집 하드웨어를 운영자 경험뿐 아니라 기록 가능한 촉각과 정책 성능으로 평가해야 한다는 근거 제시

### (c) 시사점

- 패드 내 위치·힘 보존이 이진 접촉보다 실물 우위
- **접촉 정보 보존의 실측** — 같은 데이터에서 패드 내 위치·힘을 남긴 입력이 손가락별 접촉 플래그보다 4개 실물 과제 전부 우위, 접촉 이진 요약만으로는 부족하다는 근거
- **수집 장비도 데이터 조건** — 인간 시연 수집 장비의 형상이 기록 촉각 분포를 바꿈, 인간 데이터 기반 촉각 학습 시 수집 기구를 데이터 조건으로 기록 필요
- **원시 배열 보존의 이점** — 원시 촉각 배열을 저장해 두면 재수집 없이 표현 비교 가능, 저비용 실험 설계 참고

### (d) 먼저 확인할 점

- **평탄 결합 정책** — 두 입력 모두 이미지 임베딩에 촉각 벡터를 이어 붙인 전역 조건, 고유수용감각 입력 없음, 손가락별 결속 구조와의 비교 아님
- **요인 미분리** — 공간 구조와 힘 정보 각각의 기여는 분리하지 않은 표현 수준 비교, 저자 명시
- **단일 학습 인스턴스** — 조건당 정책 1개, 롤아웃 분산은 초기 상태 변동만 반영
- **센서 전이** — 홀 효과 3축 택셀 배열(손끝당 120점) 기준, 이미지형 촉각으로 옮기면 공간 맵 구성부터 재설계 필요
- **계측 범위** — 엄지·검지·중지 3개 손끝만 계측, 손바닥 미포함

**Temporal Forcing: 4D Representation Alignment for Vision-Language-Action Models**
[arXiv:2608.30643](https://arxiv.org/abs/2608.30643) · Xingyu Ding, Yuzhong Zhao, Chunhai Zhao et al. · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M2 · Real2 · Repro1 — 초록 "Code will be publicly available."

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 4D 기하 목표로 VLA 이력 토큰과 그 변화를 지도
- **문제** — 장기 조작에서 VLA가 현재 관측을 넘어 장면 상태와 그 변화를 추적해야 함
  - 예 — 블록 하나를 불투명 상자에 넣으면 이후 보이지 않아, 서랍을 닫을지 정하는 데 필요한 진행 정보가 현재 관측에 없음
- **기존 한계** — 이력을 넣어도 이력 표현이 무엇을 담을지는 지도되지 않음
  - 시간 모듈·메모리로 과거 관측을 넣는 기존 VLA — 압축된 이력 표현이 무엇을 보존할지 직접 정하지 않음
  - 액션 지도는 이력 표현을 액션 예측을 통해 간접적으로만 제약, 병목은 이력 접근이 아니라 잠재 시간 상태의 지도
- **핵심 방법** — 이력 경로와 4D 기하 정렬, 정렬 부분은 학습 시에만 사용
  - History Pathway — 제한된 과거 관측 창을 소수 이력 토큰으로 압축, 게이트로 백본에 주입
  - 사전학습 4D 파운데이션 모델 StreamVGGT가 더 긴 인과 맥락에서 이력 조건 기하 목표 추출, 오프라인 사전 계산
  - 상태 지도 — 시점별 이력 특징을 기하 목표에 정렬
  - 잠재 전이 지도 — 시점 간 이력 표현 변화를 4D 기하 특징 변화에 일치
  - 현재 프레임 정렬 — VLA 백본의 현재 프레임 특징을 밀집 기하 특징에 정렬
  - 4D 모델과 정렬 헤드는 추론 경로에서 제거
- **차별점** — 이력 입력만 주는 대신 이력 표현의 상태와 전이를 4D 기하로 직접 지도
  - 프레임별 독립 3D 목표가 아닌 이력 조건 4D 목표 사용
- **핵심 기여** — 이력 VLA의 지도 병목 규명, 4D 정렬 프레임워크, 시뮬레이션·실물 검증
  - LIBERO(시뮬레이션) 평균 96.6%에서 98.8%, LIBERO-Long 93.8%에서 97.2%
  - RoboTwin 2.0 12개 과제(시뮬레이션) 53.5%에서 62.8%
  - 실물 UR3 다단계 숨김 배치 과제 30회 — 전체 성공 6/30(20.0%)에서 13/30(43.3%), 기반 모델 StarVLA-OFT 대비
  - LIBERO 통제 절제(10k 스텝 학습) — 이력 경로만 추가하면 평균 90.7%에서 88.2%로 하락, 이력 경로와 두 정렬 목적 결합 시 93.6%
  - 같은 절제에서 4D 목표가 프레임별 3D 목표보다 우위, 85.0% 대 93.6%
  - 선형 탐침 — 이력 토큰의 말단·물체 변위 예측 R² 0.83·0.90, 액션 지도만으로는 0.44로 미학습 경로(0.48) 수준
- **가치** — 이력을 쓰는 VLA에서 이력 표현이 실제로 장면 변화를 담도록 하는 학습 시 지도 경로 제시

### (c) 시사점

- 학습 전용 기하 정렬로 시각 특징에 장면 변화 주입
- **기하 증류의 시간 확장** — 프레임별 3D 기하보다 이력 조건 4D 기하 목표가 우위라는 통제 비교, 동역학 인지 인코더 설계의 비교 근거
- **단순 추가의 비용 실측** — 지도 없는 이력 입력은 오히려 성능 하락, 입력을 덧붙이는 것과 표현을 지도하는 것의 차이를 수치화
- **도입 비용 낮음** — 4D 모델·정렬 헤드가 학습 전용, 액션 청크당 추론 45ms에서 58ms 증가에 그침
- **다중 카메라 설정** — 정적 카메라와 손목 카메라를 함께 쓰고 카메라별 평균 제거 후 정렬

### (d) 먼저 확인할 점

- **실물 규모** — UR3 단일 과제 30회, 블록 배치·서랍 닫기로 다지 손·촉각 미포함
- **분산 미보고** — 반복 시드·분산과 한계 서술 없음
- **절제 조건** — 절제는 10k 스텝 단축 학습 기준이라 본 결과 98.8%와 수치 직접 비교 불가
- **LIBERO 포화** — 기반 모델이 이미 96.6%, 개선 폭 대부분은 Long·RoboTwin에 집중
- **이전 비용** — StreamVGGT 목표 사전 계산 필요, 카메라 구성이 바뀌면 목표 재계산

### (b) 논문 요지

- 디코더를 약화해 NVS로 기하 인코더를 자기지도 학습
- **문제** — DUSt3R·MASt3R·VGGT류 기하 표현은 대규모 3D 주석 학습에 의존, 밀집 3D 정답 수집 비용이 병목
  - 자세가 주어진 이미지만으로 학습하는 새 시점 합성(NVS)은 3D 구조 추론을 요구해 대안 신호로 유력

  - 픽셀 공간 재구성 목표 — 3D 구조와 약하게 관련된 고주파 통계까지 모델링하게 해 표현 학습 저해

- **핵심 방법** — SNAP, 자기지도 인코더-디코더 트랜스포머
  - 자세 없는 다중 뷰 인코더를 공간 백본으로 사용
  - PRoPE 기반 자세 조건 국소 디코더 — 질의 뷰 셀프 어텐션에 BlockNN 마스크로 수용 영역 제한, 기하 구조가 인코더 장면 표현에 머물도록 강제
  - 잠재 공간 재구성 목적 — RGB 대신 고정 DINOv3 ViT-B 패치 특징을 재구성 목표로 사용
  - 하위 평가는 고정 인코더 특징과 경량 과제 헤드
- **차별점** — 재구성 충실도를 높이는 대신 디코더 용량을 제한해 기하를 인코더에 남김
  - 저자 결론 — 표현 품질이 재구성 충실도와 일치하지 않음
- **핵심 기여** — 백본, 기제 분석, 5개 과제 평가
  - 3D 주석 없이 고정 2D 의미 잠재 위에서 비대칭 NVS 목적과 잠재 목표로 기하 전이 표현을 학습하는 백본
  - 수용 영역 스윕·예측 공간 실험으로 디코더 표현력과 예측 공간의 독립 영향 분리
  - 점 대응·시각 위치추정·자세 추정·깊이 추정·로봇 조작 5개 과제에서 자기지도 기준선과 대등 이상, 기하 지도 방법과 경쟁
  - 점 대응 — RealEstate10K에서 자기지도 기준선 대비 모든 픽셀 임계값 우위, VGGT 절반 해상도(256 대 518) 입력
  - 로봇 조작(시뮬레이션) — MimicGen 3개 과제, 카메라 0.0–1.0 라디안 이동, 고정 인코더 기준
    - DINOv3·ResNet은 0.2 라디안을 넘으면 급락
    - SNAP은 DINOv3 교사보다 높고 Adapt3R를 대체로 앞서며 VGGT에 근접
- **가치** — 3D 정답 없이 자세 있는 영상만으로 기하 전이 표현을 학습하는 사전학습 경로 제시

### (c) 시사점

- 기하 주석 없는 다중 뷰 인코더 후보, 시점 이동에 강건
- **일반 인코더 대비 실측** — 의미 중심 2D 인코더가 카메라 이동에 무너지는 반면 기하 표현은 완만히 저하, 일반 이미지 인코더 대비 기하 인코더 선택의 근거
- **증류 없는 기하 인코더** — VGGT급 기하 지도 없이 자세 있는 영상만으로 학습, 로봇 자체 영상으로 사전학습할 여지
- **연산 부담 낮음** — 256×256 입력·패치 16으로 뷰당 256 토큰, VGGT의 뷰당 1369 토큰 대비 짧은 시퀀스

### (d) 먼저 확인할 점

- **실물 결과 없음** — 로봇 평가는 MimicGen 시뮬레이션 3개 과제뿐, 본문 수치는 그림 5 비교로만 제시
- **정적 장면 사전학습** — 자세 있는 영상·정적 질감 장면 기준, 동적 영상 확장은 저자도 향후 과제로 명시
- **조작 범위** — 평행 그리퍼 MimicGen 과제(Stack Three·Square·Coffee), 다지 손·촉각 미포함
- **재현 경로** — 코드 공개 언급 없음, 프로젝트 페이지만
