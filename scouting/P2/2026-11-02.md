## 🥇 논문 1

**DexTouch-WM: Learning Action-Conditioned Tactile World Models from Human Touch for Dexterous Robot Manipulation**
[arXiv:2609.20649](https://arxiv.org/abs/2609.20649) · Yan Qin, Yue Chen, Wenwei Lin 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — arXiv comment "Accept to IROS 2026 Workshop RoBoWoMo (Lightning Talk)", 초록·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 해부학 구조 촉각 토큰으로 인간 촉각을 로봇 월드모델에 이식
- **문제** — 접촉이 지배하는 다지 조작에서 영상만으로는 접촉 압력, 미끄러짐을 관측할 수 없고 촉각 궤적 수집은 로봇 한 대에 묶여 확장 불가
  - 기존 시각-촉각 월드모델은 텔레오퍼레이션으로 촉각을 모아 데이터가 작고 평행 그리퍼나 단일 지문 센서에 한정
- **기존 한계** — 기존 시각-촉각 월드모델은 데이터가 특정 로봇과 센서 구성에 결합
  - 장갑 촉각 맵을 규칙적인 이미지 격자로 다루면 떨어진 지문과 손바닥 영역의 물리 토폴로지와 어긋남
- **핵심 방법** — 사전학습 비디오 전문가와 경량 촉각 전문가를 Mixture-of-Transformers 블록으로 결합한 행동 조건 월드모델
  - 해부학 인지 촉각 토크나이저 — 지문과 손바닥 영역을 물리 센싱 위상에 따라 따로 인코딩(Split-Hands)
  - 초기 촉각 관측에 고정한 잔차 잠재 — 정적 압력 배경이 아닌 행동 유발 접촉 변화만 예측
  - 이중 속도 행동 조건화 — 손과 카메라 움직임을 각 모달리티의 원래 시간 해상도로 주입하고, 로봇 중심 자세 표현으로 인간과 로봇 동작을 한 조건 공간에 사상
  - 인간과 로봇 손에 같은 배치의 유연 압저항 어레이 장착(장갑당 360 taxel 중 320개 사용)
- **차별점** — 촉각 맵을 하나의 공간 캔버스로 취급하는 Grid 기준선 대신 손의 해부학 구조를 보존
  - 행동 주입을 교차 어텐션 대신 AdaLN으로 구성
- **핵심 기여** — 모델, 데이터, 활용 실험 세 가지
  - 50개 과제 100시간 에고센트릭 양손 인간 상호작용 데이터셋과 5시간 로봇 데이터, 공유 인간-로봇 센싱·행동 인터페이스
  - 촉각 표현 — Split-Hands가 Grid보다 재구성 오차가 낮고 Contact-IoU 수렴이 빠름
  - 행동 주입 — 교차 어텐션 방식은 궤적 정확도를 약 0.88에서 0.85로 낮추고, AdaLN은 PSNR 22.1에서 23.5, Contact-IoU 0.39에서 0.42로 개선
  - 로봇 5시간 고정, 인간 데이터 0에서 100시간 증가 시 미관측 로봇 에피소드에서 PSNR 23.47에서 27.10, Contact-IoU 0.42에서 0.59, Contact-F1 0.55에서 0.71
  - 정책 평가기로 쓸 때 실물 점수와의 평균 Pearson 상관이 로봇 전용 0.646에서 인간 혼합 0.844로 상승, 일부 과제의 순위 반전은 남음
  - 월드모델 생성 합성 궤적을 실물 로봇 정책 학습에 활용
- **가치** — 로봇 데이터를 늘리지 않고 인간 촉각 상호작용으로 접촉 예측을 확장하는 경로 제시

### (c) 시사점

- 손 해부학 구조를 보존한 촉각 토큰화의 우위를 직접 측정
  - 격자 대비 Split-Hands의 재구성, 접촉 수렴 이점이 지문-손바닥 구분 토큰 구성의 근거
- 촉각 스트림을 교차 어텐션으로 붙이면 상위 수준 동역학에 간섭이 생기고 AdaLN 변조가 이를 줄인다는 비교 결과
- 인간 장갑과 로봇 손에 같은 센싱 배치를 쓰는 구성이 센서 헤드 교체 가능성의 한 사례

### (d) 먼저 확인할 점

- 압저항 장갑 센서 기준의 결과, 비전 기반 촉각 센서로의 이전은 별도 검증 필요
- 접촉 예측 이득은 월드모델 지표에 대한 것이고 정책 성공률 상승은 아님
- 정책 평가기 상관은 과제별로 갈리며 Stand Bottle은 순위 반전이 남음
- 반복 시드, 한계 서술 없음
- 코드 공개 신호 없음, IROS 워크숍 채택만 확인

**An Empirical Study on What Matters for Viewpoint-Generalizable Policies in Visual Imitation Learning**
[arXiv:2609.32762](https://arxiv.org/abs/2609.32762) · Mino Nakura, Sriram Krishna, Yufei Wang 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — arXiv comment 없음, 초록·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 시점 일반화에 효과적인 설계 요소를 통제 분리한 연구
- **문제** — 모방학습 시각 정책이 학습 때의 카메라 구성에 과적합해 배포 시점이 바뀌면 급락
  - 특히 로봇이 화면 밖에 있을 때 정책이 로봇 위치를 잡을 시각 기준이 없음
- **기존 한계** — 시점 강건성을 위한 기존 접근이 각기 무엇을 놓치는지 지적
  - 포인트클라우드·복셀 정책 — 장면 중심 좌표라 시점에 강하나 대규모 사전학습이 없고 밀집 관측을 다운샘플해야 제어 주기를 맞춤
  - 정규 시점 재투영 — 투영으로 생긴 구멍이 사전학습 이미지 백본에 분포 밖 입력을 만듦
  - VGGT 인코더와 확산 정책을 결합한 VGGT-DP — 완만한 카메라 회전에서도 급락
  - 명시적 카메라 기하 조건화 — 저자들은 카메라 위치 대신 픽셀의 로봇 기준 위치가 필요하다는 가설로 대비
- **핵심 방법** — 보정된 RGB 다시점을 시각 기하 파운데이션 모델 구조로 처리하는 기본 정책 위에 설계 축을 하나씩 바꿔 비교
  - 압축 대신 밀집 패치 토큰 유지
  - 시각 기하 파운데이션 모델 구조 채택
  - 시각, 고유수용감각, 액션 토큰 전부를 4D RoPE로 로봇 좌표계에 접지
  - 이 조합을 Agp로 지칭
- **차별점** — 새 구조가 아니라 기존 요소의 기여를 같은 데이터셋, 같은 액션 헤드 아래 분리
  - 이미지 공간 위치 인코딩을 로봇 좌표계 위치 인코딩으로 교체
- **핵심 기여** — 설계 선택별 효과와 실물 전이
  - 로봇 좌표계 4D RoPE가 Cabinet 무작위 카메라에서 정규화 열기 성능을 39.5에서 64.4로 개선
  - 시뮬레이션 무작위 카메라에서 2D와 3D 대안(DP3 포함) 대비 우위, 고정 카메라 성능에 근접
  - 시뮬레이션만으로 학습해 Franka 실물에서 미지의 카메라 포즈로 제로샷 전이, 정규 시점과 Plücker 레이맵보다 파지 성공률과 열기 성능이 높음
  - 외부 보정 오차와 깊이 잡음에 대한 민감도 곡선 제시
- **가치** — 3D 정책의 시점 강건성과 이미지 백본 사전학습 이점을 함께 얻는 설계 지침 제공

### (c) 시사점

- 다시점 정합은 토큰을 로봇 좌표에 접지하는 위치 인코딩에서 나온다는 통제 측정
  - 이미지 공간 인코딩 대비 큰 폭 개선이 카메라별 토큰 병합 대안의 약점을 보여줌
- 파운데이션 기하 인코더만으로는 시점 강건성이 부족하다는 선행 관찰과 일치
- 기하 인코더 선택과 위치 인코딩 설계를 분리해 평가하는 실험 틀로 재사용 가능

### (d) 먼저 확인할 점

- 평행 그리퍼 Franka 열기·파지 과제 중심, 다지 손과 촉각 입력 없음
- 로봇 좌표 접지는 보정된 외부 파라미터와 깊이에 의존, 잡음 민감도 분석은 Cabinet 한 과제 기준
- 실물 평가는 마이크로웨이브 열기 한 플랫폼
- 코드 공개 신호 없음

## 🥉 논문 3

**UniDex-ViTac: Learning Unified Visuo-Tactile Dexterous Manipulation Policy from Human Video Data**
[arXiv:2609.16504](https://arxiv.org/abs/2609.16504) · Hyesung Lee, Si-Hwan Heo, Sungwook Yang · arXiv preprint · source: citation-graph

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — arXiv comment "Project page: https://unidex-vitac.github.io/", 프로젝트 페이지만 있고 코드 문장 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 지문 라벨과 접촉 토큰의 이중 경로로 접촉 정보를 정책에 주입
- **문제** — 인간 영상은 로봇이 실행할 동작과 촉각 측정이 없어 접촉 조건부 다지 정책을 직접 학습시키기 어려움
- **기존 한계** — 인간-객체 기하 참조는 초기 궤적만 안내
  - 로봇 자체의 기구학과 접촉 동역학 아래서 잡아 올릴 수 있음을 보장하지 못함
- **핵심 방법** — 인간 영상 유도 시뮬레이션으로 동작과 지문 접촉 관측이 짝지어진 로봇 시연을 생성
  - 주석 달린 인간-객체 상호작용 참조로 객체별 잔차 강화학습 전문가를 학습
  - 성공 롤아웃의 최종 동작 목표와 로봇 측 지문 접촉 관측을 짝지음
  - 인간 시연 50개, 객체 10종에서 시뮬레이션 궤적 10,000개를 모아 ACT 기반 단일 일반 정책 학습
  - 정책 입력 — 포인트클라우드, 고유수용감각, 4비트 지문 접촉
  - 4비트 접촉을 순기구학 지문 점의 라벨로 쓰는 경로와 별도 접촉 토큰 경로로 이중 인코딩
- **차별점** — 접촉 비트를 지문 위치 라벨(공간 앵커)과 별도 접촉 토큰(패턴 직접 표현) 두 경로로 동시에 사용
  - 배포 시 인간 참조, 객체 식별, 객체 자세가 필요 없음
- **핵심 기여** — 데이터 생성 파이프라인과 접촉 표현, sim-to-real 결과
  - 인간 영상 유도 잔차 RL 전문가로 동작-접촉 시연을 합성하는 파이프라인
  - 접촉 융합 비교 — 지문 라벨만 56.8%, 토큰만 56.4%, 둘 다 68.3%, 포인트클라우드 단독 55.5%
  - 실물 로봇 시연이나 미세조정 없이 실물 73/110 성공(66.4%), 접촉 없는 기준선 60/110(54.5%), 객체는 학습 6종과 미학습 5종
- **가치** — 촉각 측정이 없는 인간 영상에서 접촉 조건부 정책을 학습하는 경로 제시

### (c) 시사점

- 지문별 접촉 라벨과 별도 접촉 토큰의 결합 이득이 가산적이지 않다는 측정
  - 단일 경로는 0.9–1.3p 개선, 이중 경로는 12.8p 개선
- 지문 위치에 접촉을 귀속시키는 구성이 평평한 접촉 토큰 추가보다 낫다는 근거 후보
- 시뮬레이션에서 만든 이진 접촉으로 실물까지 전이한 사례

### (d) 먼저 확인할 점

- 접촉 신호가 4비트 이진값이라 힘 크기와 접촉 위치 정보를 버림
- 시뮬레이션 지문 패드 접촉 영역과 실제 센서 감지 영역이 달라 접촉 활성화에 sim-to-real 불일치
- 파지-들어올리기 한 기술, 한 로봇 팔-손 시스템에 한정
- 두 경로 결합 이득이 객체별로 순위가 갈림
- 코드 공개 신호 없음, 프로젝트 페이지만 있음

- **중복 제외** — 28편, 최근 8주 리포트·기존 재작성본·추적 문헌과 겹쳐 검색 단계 제외, 게이트 통과 4편은 전원 신규
- **최근 결과와의 긴장** — ME-Dex 1.0(2609.21449)은 현재 촉각 입력을 0으로 바꿔도 RoboTwin 성공률이 91.92%에서 91.74%로 거의 변하지 않아 이 설정의 현재 촉각 의존이 낮다고 보고
  - 최근 리포트의 HACo(2609.36596)가 게이트 햅틱 교차 어텐션이 단순 결합을 크게 앞선다고 보고한 것과 대비
  - 다만 ME-Dex는 시뮬레이션 WAM 설정, HACo는 다지 손의 촉각·관절 토크 설정으로 조건이 다름
- **융합 방식 비교 흐름 지속** — DexTouch-WM(2609.20649)은 촉각 스트림을 교차 어텐션으로 붙이면 궤적 정확도가 낮아지고 AdaLN이 이를 줄인다고 보고
  - 최근 리포트의 TACTIC(2609.30969)의 조합별 비교와 같은 융합 방식 문제를 다른 축에서 다룸
- **기하 접지 쟁점 지속** — Viewpoint-Generalizable Policies(2609.32762)는 시각 기하 파운데이션 모델 구조 위에서 이득이 로봇 좌표 위치 인코딩에서 나온다고 보고
  - 직전 회차 What Matters for World Modeling in Vision-Language-Action Models?(2610.19825)가 VGGT 이득이 통합 방식에 따라 갈린다고 보고한 흐름과 이어지나 지도 목표와 정책 입력으로 설정이 다름
- **필터 상태** — 후보 401편 제외, R·N 미달 373편, 중복 28편, 근접 후보 없음
