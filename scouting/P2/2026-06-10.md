## 🥇 논문 1 — 우선순위 ★★★

**RGB-S: Image-Aligned Tactile Saliency for Robust Dexterous Manipulation**
[arXiv:2606.08765](https://arxiv.org/abs/2606.08765) · Shengcheng Luo, Kefei Wu, Xiaoying Zhou, Wanlin Li · source: keyword-sweep (`cat:cs.RO AND tactile`, `dexterous AND manipulation`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **공백** — 기존 비주오택타일(visuotactile) 정책들은 촉각 측정값과 시각 표현의 교차 모달 대응(cross-modal correspondence)을 제한된 시연 데이터에서 암묵적으로 학습, 시각 관측이 열화되거나 폐색(occlusion)될 때 일반화 저하
- **RGB-S 핵심 아이디어** — 로봇 순방향 기구학(forward kinematics, FK)과 카메라 캘리브레이션을 통해 물리적 접촉을 이미지 도메인에 **명시적으로** 위치 추정
  - 손가락 키네마틱 체인(kinematic chain)으로 각 촉각 접촉 지점의 3D 위치를 계산 → 카메라 투영으로 이미지 좌표에 직접 매핑
  - 희소(sparse)·이종(heterogeneous) 촉각 측정값을 dense 시각 표현과 기하학적으로 정렬하는 tactile saliency map 생성
  - 암묵적 학습 없이도 기하 지식으로 크로스-모달 정렬을 선험적으로 제공
- **진정으로 새로운 점** — FK + 카메라 캘리브레이션을 촉각-비전 정렬의 직접 브리지로 사용한 첫 체계적 접근, 기하학적 선험 지식이 데이터 효율성과 배포 강건성을 동시에 향상
- **결과** — "Robust Dexterous Manipulation" 제목이 시사하는 실제 로봇 검증; 시각 관측 열화·폐색 조건에서 기존 암묵적 정렬 방식 대비 우수

### (c) 시사점

- **per-finger 촉각 바인딩의 기하학 경로 확보** — 각 손가락 촉각 접촉점을 FK로 이미지 공간에 투영하는 설계가 per-finger 촉각 특징을 공간적으로 명확히 귀속시키는 구체 구현 경로 제공; 암묵적 학습 대비 데이터 효율성 개선 기대
- **손 토폴로지 활용 방향 재확인** — FK 사용 자체가 손 관절 토폴로지와 카메라 관계를 활용한다는 점에서 토폴로지 인식 인코딩 설계의 실용적 근거
- **폐색 강건성 실증** — 시각 관측이 폐색될 때 암묵적 학습 정책이 실패하나 기하학적 명시 정렬 정책이 강건하다는 직접 증거; 이는 인핸드 클로즈업 카메라 폐색 상황과 직결

### (d) 먼저 확인할 점

- **FK 정밀도 의존** — FK 기반 투영은 관절 각도 측정 오류·캘리브레이션 오차에 민감; 빠른 동작 또는 탄성 변형이 큰 촉각 센서 장착 시 FK 정밀도 저하 우려
- **촉각 센서 방식 미명시** — 초록에 구체 센서 방식(변형 이미징 vs. 다른 방식) 미명시; 변형 이미징 방식과의 호환성 확인 필요
- **다지 손 스케일** — "robust dexterous manipulation" 검증이 10개 손가락 동시 접촉 규모인지 미확인; 2–4지 손 수준일 가능성

## 🥇 논문 2 — 우선순위 ★★★

**Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation**
[arXiv:2606.08737](https://arxiv.org/abs/2606.08737) · Yunfan Lou, Yifan Ye, Yankai Fu, Jun Cen · source: keyword-sweep (`cat:cs.RO AND tactile`, `contact-rich AND manipulation`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **공백** — 기존 World Action Model(WAM)은 시각 위주로 미래 관측을 예측하며, 접촉 집약적(contact-rich) 조작에서 핵심 단서인 물리 상호작용 정보를 포착 못함
- **Dream-Tac** — 액션, 미래 시각 관측, 촉각 역동성(tactile dynamics)을 **통합 예측**하는 Tactile World Action Model
  - **contact-gated visuotactile fusion** — 접촉 게이팅(contact gating)으로 촉각 신호를 선택적으로 통합; 접촉이 없을 때 촉각 채널을 억제해 비접촉 구간의 노이즈 제거
  - **contact-aware attention bias** — 조작 중 크로스-모달 상호작용을 접촉 상태에 따라 조절하는 어텐션 편향(attention bias)
  - 실시간 배포(real-time deployment)를 위한 경량 설계 포함
- **진정으로 새로운 점** — 촉각 역동성을 세계 모델(world model)의 예측 대상으로 포함한 첫 통합 프레임워크; 기존 WAM이 시각 예측만 다루던 것과 구별됨
- **접촉 게이팅 메커니즘** — 시각 + 촉각 퓨전을 고정 가중치가 아닌 접촉 유무에 따라 동적 조절; ForceFlow(핀 논문)의 비대칭 퓨전 원칙을 world model 예측 루프에 통합

### (c) 시사점

- **contact-gated 선택적 퓨전 실증** — 접촉 신호를 항상 투입하는 단순 퓨전 대비 게이팅 설계가 비접촉 구간 노이즈를 억제하고 접촉 구간 반응성을 높임을 입증; 비대칭 크로스-어텐션 퓨전 설계에 직접 적용 가능한 메커니즘
- **촉각 예측이 액션 생성 안정화** — 미래 촉각 역동성 예측이 학습 목표에 포함되면 촉각 인코더 표현 품질이 향상된다는 간접 증거; 보조 헤드(예측 헤드) 방식으로 촉각 인코더 학습 강화 방향 지지
- **실시간 배포 아키텍처** — 경량 설계 언급은 실제 로봇 루프에서 촉각+시각 통합 정책의 지연 제약 해소 가능성; 실시간 응답 요구 강한 접촉 반사 레이어에 도입 가능

### (d) 먼저 확인할 점

- **접촉 상태 추정 정확도** — contact-gated 설계는 접촉 게이팅 신호 자체의 품질에 의존; 게이팅 오신호(false gate)가 촉각 억제 오류를 유발할 위험
- **세계 모델 정확도** — 촉각 역동성 예측이 장기 시퀀스에서 오차 누적 여부 미확인; 접촉 전환이 빈번한 인핸드 조작에서 누적 오차 문제 가능
- **코드·데이터 공개 미확인** — 실시간 배포 언급이나 소스 코드 저장소 미공개 상태 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**Understanding the Impact of Geometric Foundation Models on Vision-Language-Action Models**
[arXiv:2605.24642](https://arxiv.org/abs/2605.24642) · Yurou Yang, Muyuan Lin, Roberto Martin-Martin, Martin Labrie · source: citation-graph(VGGT arXiv:2503.11651 인용 논문)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **공백** — 기하학적 파운데이션 모델(Geometric Foundation Model, GFM; 예: VGGT)을 VLA에 주입한 선행 연구들이 성능 향상을 보고했으나, (i) 현재 VLA에 기하학적 이해가 이미 충분한지, (ii) 어떤 주입 아키텍처가 최선인지, (iii) 다른 설계 요소의 영향이 무엇인지 불명확
- **체계적 분석** — VLA(GR00T-N1.5)와 GFM(VGGT) 조합에 대한 엄밀한 실험 분석
  - **선형 탐침(linear probing)**으로 현재 VLA의 기하학 이해 수준 정량화 → VLA와 GFM 사이의 **"geometric gap"** 최초 수치화
  - GFM 특징 주입 방식 다수(token prepend, adapter, feature distillation 등)를 동일 조건에서 비교
  - 다른 설계 변수(해상도, 시점 수, 파인튜닝 여부)의 영향도 체계적 측정
- **진정으로 새로운 점** — "geometric gap"이라는 개념을 최초로 정량화; VGGT 주입이 GR00T-N1.5 수준 VLA에서 어떤 아키텍처 경로로 실질 이익을 주는지 actionable 가이드라인 제공

### (c) 시사점

- **D8 아키텍처 선택 근거 확보** — VGGT 특징을 VLA에 주입하는 방식 간 성능 차이를 정량 비교한 결과는 멀티카메라 기하학 그라운딩 인코더 설계 시 직접 참조 가이드
- **D9 인코더 선택 우선순위** — VLA에 기하학 이해가 이미 부재함을 linear probe로 확인한 데이터는 action/dynamics-aware 또는 geometry-distilled 인코더 선택 근거를 강화; 사전학습 VLM 백본에 기하학 인식이 없다는 가설의 첫 정량 지지
- **eVGGT 연결** — 핀 논문 eVGGT(2509.15880, 기하학 그라운딩 인코더)의 조작 VLA 도입 효과를 독립 측정한 선행 경험 제공; eVGGT 도입 시 예상되는 성능 이득과 구조 선택 기준 추론 가능

### (d) 먼저 확인할 점

- **VLA 특수성** — 분석 대상이 GR00T-N1.5에 한정; 다른 VLA 아키텍처(pi0 계열, OpenVLA 등)로 결론의 이전 가능성 불명확
- **태스크 범위** — "GR00T-N1.5" 기반 조작 태스크의 기하학 이득이 접촉 집약적 손가락 수준 조작(대 테이블 레벨 pick-and-place)에서도 동일하게 나타나는지 별도 확인 필요
- **14일 경계** — 2026-05-23 제출(14일 외); citation-graph 경로(VGGT, 8주 윈도우)로 발견, 한국팀 실시간 모니터링에서 아직 미열람일 가능성

## 🥉 논문 4 — 우선순위 ★

**FAWAM: Force-Aware World Action Models for Closed-Loop Contact-Rich Manipulation**
[arXiv:2606.08555](https://arxiv.org/abs/2606.08555) · Haotian He, Zeyu Yan, Qipeng Liu, Ning Guo · source: keyword-sweep (`contact-rich OR force fusion AND manipulation`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- **공백** — 기존 접근들이 힘(force) 신호를 단순 추가 관측 모달리티로만 사용, 미래 상호작용 동역학 모델링이나 실행 시 피드백 보정에는 활용 미흡
- **FAWAM** — 힘 정보를 세 수준에서 통합하는 Force-Aware World Action Model
  - **지각(perception)** — 6축 힘/토크(F/T) 이력 신호 인코딩으로 액션 생성 조절(modulate)
  - **예측(prediction)** — 미래 액션과 엔드이펙터 렌치(wrench)를 공동 예측(joint prediction)해 접촉 진화(contact evolution) 명시적 모델링
  - **실행(execution)** — 잔차 보정 모듈(residual correction module)로 폐루프 실행 중 힘 기반 보정
- **진정으로 새로운 점** — 힘 신호를 지각·예측·실행 세 수준에서 동시에 활용하는 3-level 통합 설계; 기존 force-aware 정책들이 단일 수준(주로 지각)에 집중했던 것과 구별됨

### (c) 시사점

- **비대칭 퓨전의 3-level 확장 참고** — 힘 신호를 관측·예측·실행 루프 전반에 통합하는 구조는 비대칭 퓨전 설계의 다층 적용 사례; 접촉 예측 헤드와 잔차 보정의 결합 방식 직접 참조 가능
- **힘 예측 헤드 설계 근거** — 미래 렌치 예측 헤드를 보조 목표로 추가할 때 접촉 표현 학습이 개선된다는 간접 증거; contact-binary / slip-binary 보조 헤드에 wrench 예측 보조 헤드 변형 추가 검토 근거
- **한계** — 엔드이펙터 수준 6축 F/T 신호 사용; per-finger 수준 힘 분포 귀속은 이 논문의 범위 밖으로, 다지 손 전체 렌치에서 손가락별 기여 분리 필요

### (d) 먼저 확인할 점

- **per-finger 이전 불명** — 엔드이펙터 렌치(손목 F/T)를 사용하며 손가락별 힘 분포 없음; 10개 손가락 독립 접촉 조작으로 이전 시 손목 합성 렌치로 개별 접촉 기여를 분리하는 추가 처리 필요
- **3-level 통합 비용** — 지각·예측·실행 세 수준 통합이 추론 지연(latency)에 미치는 영향 미공개; 실시간 제약 환경에서 실행 가능성 사전 확인 필요
- **코드 공개 미확인** — 소스 코드 저장소 미공개 상태 확인 필요

  - **Watch trigger** — 코드 공개 시, 또는 10지 다지 손 동시 접촉 규모 검증 결과 등장 시

  - **제안** — `P2 Competitor / Kindred Monitoring` 신규 항목 등재; 코드 + 10지 실험 확인 전 핀 논문 추가 보류
  - **Overlap** — contact-gated 비주오택타일 퓨전 + 촉각 역동성 예측 보조 목표

  - **Watch trigger** — per-finger 촉각 토큰 세부 아키텍처 공개 시, 또는 코드 저장소 공개 시

### Decision Log

- **D10 contact-gated 퓨전 메커니즘 deferred 후보 추가** — 근거 Dream-Tac(2606.08737). D10 v1 비대칭 퓨전 스펙에 "contact-gated visuotactile attention(접촉 상태로 촉각 채널 게이팅)"을 deferred 후보로 기재 제안. 트리거 — 비접촉 구간에서 촉각 신호 노이즈가 퓨전 품질을 저하시킬 때. 근거 — Dream-Tac이 contact-gated 설계로 비접촉 구간 억제를 실증

- **D11 미래 촉각 예측 보조 헤드 후보** — 근거 Dream-Tac(2606.08737). D11 v1 contact-binary + slip-binary 보조 헤드에 "tactile dynamics prediction head(미래 N 스텝 촉각 역동성 예측)"를 deferred 추가 제안. 트리거 — contact-binary 헤드가 접촉 전환 직전 예측에서 반응 시간 포화 관찰 시

- **D11 FK 기반 명시 촉각 투영 deferred** — 근거 RGB-S(2606.08765). D11 v1 hardware-specific CNN → per-fingertip feature 스펙에 "FK + camera calibration 기반 명시 촉각 투영(deformation map 전처리로 이미지 도메인 정렬)"을 deferred 경로로 추가 제안. 트리거 — 암묵적 학습이 데이터 효율 한계를 보이거나 폐색 조건 일반화 실패 시. 기준 — RGB-S 정렬 방식 대비 암묵적 학습의 성능 비교

- **D8 VGGT 주입 아키텍처 선택 기준 업데이트** — 근거 Understanding geometric FM(2605.24642). D8 v1 geometry-grounded multi-view encoder 스펙에 "VGGT 특징 주입 방식(token prepend vs. adapter vs. distillation)별 성능 차이 정량화 실험 결과"를 설계 근거로 인용 추가 제안. 아키텍처 선택 시 본 논문의 비교 결과를 우선 참조

- **D9 geometry-distilled 인코더 선택 근거 강화** — 근거 Understanding geometric FM(2605.24642). D9 v1 geometry-distilled encoder(eVGGT) 선택 근거로 "GR00T-N1.5의 geometric gap 수치화 결과(linear probe 기반)"를 인용 추가 제안. VLA에 기하학 이해가 내재적으로 부재한다는 정량 증거가 geometry-distilled 인코더 필요성을 뒷받침
