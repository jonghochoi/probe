## 🥈 논문 1 — 우선순위 ★★

**DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation**
[arXiv:2609.24976](https://arxiv.org/abs/2609.24976) · Haoran Yuan, Zekai Wang, Boning Shao, Haoran Lu, Trevor Darrell 외 · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- 각 손끝을 독립적으로 인코딩하고 손가락·자세 인지 압축기로 집약한 촉각 특징을 비디오 확산 월드모델에 주입해 시각-촉각 공동 월드모델링을 수행하는 DexTacWAM 제안
- 22-DOF 양팔 플랫폼 접촉 집약 과제 6종 전원에서 최고 점수 달성, 평균 70.6점으로 최강 베이스라인 38.0점 대비 큰 격차
- 촉각 월드모델링 제거 시 4과제 평균 점수가 74.7에서 26.6으로 급락하는 어블레이션으로, 이득의 원천이 단순 촉각 조건화가 아닌 접촉 진화를 예측 상태의 일부로 모델링하는 데 있음을 규명
- 동결된 사전학습 비전 VAE에 4시간의 촉각 인코더 적응만으로 과제당 약 100회 시연으로 비디오 모델을 촉각까지 확장, 시각 예측 품질은 비전 전용 대비 0.5dB 이내로 유지

### (c) 시사점
- 손끝 단위 독립 인코딩과 자세 인지 집약 구조가 접촉 진화 예측에 실질적 이득을 낸다는 정량 근거로 활용 가능
- 사전학습된 비디오 프라이어에 소량 적응만으로 촉각 모달리티를 확장하는 경로 확인 — 처음부터 재학습하는 부담을 낮추는 참고점
- 압축기가 접촉 재현율 89.4%를 유지하면서 학습·추론 속도를 함께 높인다는 근거 — 효율과 표현력을 동시에 확보하는 설계 참고 가능

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
- 22-DOF 양팔 플랫폼 단일 하드웨어 기준 검증 — 이종 손·센서 규격으로의 이식 가능성 별도 확인 필요
- 촉각 인코더 적응이 4시간·과제당 약 100회 시연 규모에서 검증 — 더 큰 촉각 어휘·과제 다양성으로 확장 시의 적응 비용 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**ForeTac-VLA: A Forecasting-Based Tactile-Vision-Language-Action Model for Contact-Rich Robotic Manipulation**
[arXiv:2609.20980](https://arxiv.org/abs/2609.20980) · Zhengyu Tao, Xin Li, Xin Wang · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- 최근 촉각 관측을 시간 표현으로 인코딩해 비전-언어 특징과 양방향 크로스어텐션으로 결합하고, 트랜스포머 기반 예측 모듈이 다중 스텝 미래 촉각 상태를 예측해 관측된 접촉과 예상 접촉을 함께 반영하는 ForeTac-VLA 제안
- 초기 예측이 불안정한 학습 구간에서 정답-예측 혼합 커리큘럼을 적용해 학습 안정화
- 실물 접촉 집약 과제 4종에서 평균 성공률 95% 달성 — 파인튜닝된 VLA 대비 36.25%p, 기존 촉각 강화 VLA 최고 성능 대비 22%p 이상 개선
- 저조도·시각적으로 혼잡한 조건에서도 성능 유지 확인

### (c) 시사점
- 촉각 신호를 사후 반응이 아닌 사전 예측으로 다루는 접근이 반응형 촉각 강화 VLA 대비 뚜렷한 성능 우위를 낸다는 정량 근거 확보
- 저조도·혼잡 조건에서도 성능이 유지된다는 근거 — 시각 신호가 저하되는 상황에서 촉각 예측이 보완 경로로 기능할 여지 시사
- 정답-예측 혼합 커리큘럼이 예측 불안정 초기 학습 구간을 안정화하는 실용적 학습 기법으로 참고 가능

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 비디오 데모 페이지만 확인
- 손끝 단위 세밀 접촉 귀속이 아닌 시간적 촉각 표현 기준 검증 — 다지 손 손가락별 판별로의 확장 여부 미검증
- 다중 스텝 미래 촉각 예측 자체의 정확도에 대한 정량 지표는 초록상 확인되지 않음 — 예측 오차가 누적되는 장기 과제에서의 강건성 별도 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**When Does Touch Matter? Charting the Vision-Interaction Gap in Cluttered Dexterous Grasping**
[arXiv:2609.24068](https://arxiv.org/abs/2609.24068) · Hao Jiang, Luis Dominguez, Daniel Seita · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 다지 시스템에서 비전, 손끝·손목 렌치 추정, 분산 손끝 택셀을 결합해 비전 단독·렌치·택셀·결합 정책과 표현·퓨전 베이스라인을 통제된 실물 환경 5개 조건에서 비교하는 최초 연구

- 어블레이션으로 렌치·택셀 피드백이 상호 보완적임을 규명
- 상호작용 피드백이 불충분한 파지의 조기 거부, 들어올리기 전 재파지, 더 안정적인 파지를 가능케 한다는 행동 비교 제시

### (c) 시사점
- 시각 기하만으로는 부족하고 상호작용 신호가 필요한 조건을 실물 데이터로 정량 구획 — 언제 촉각·힘 센싱을 추가할지 판단하는 기준점으로 활용 가능
- 렌치·택셀 두 상호작용 신호가 상호 보완적이라는 어블레이션 근거 — 손끝 단위 촉각과 손목 힘 감지를 함께 결합하는 설계의 타당성 뒷받침
- 혼잡 다지 파지를 상호작용 센싱 필요 여부를 가르는 벤치마크로 제안 — 향후 비교 실험의 기준 과제로 참고 가능

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
- 통제된 실물 5개 조건 중심 검증 — 훈련 분포를 벗어난 물체·장면으로의 일반화 여부 별도 확인 필요
- 표현·퓨전 베이스라인의 구체 구조는 초록상 상세 확인 필요
