## 🥇 논문 1 — 우선순위 ★★★

**Tactile Genesis: Exploring Tactile Sensors at Scale for Learning Dexterous Tasks**
[arXiv:2606.22332](https://arxiv.org/abs/2606.22332) · Trinity Chung, Kashu Yamazaki, Dhruv Patel, Alexis Duburcq, Yiling Qiao · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **GPU-병렬 촉각 센서 시뮬레이션 플랫폼** — 이진 접촉·접촉 깊이·taxel별 F/T·탄성체 마커 변위·기하학-인식 근접도·접촉 오디오·voxel화 온도 필드 등 7가지 촉각 모달리티를 단일 인터페이스로 제공; GPU 한 장으로 20,000개 이상 병렬 환경 + 1,000 taxel 지원, 기존 대비 3–20배 처리량 향상
- 세 다지 태스크에서 교사-학생 정책을 훈련하며 **센서 유형·배치·해상도·노이즈를 체계적 ablation** — 실물 XHand1 이전 검증
- **핵심 발견 1: taxel별 F/T가 일관되게 가장 유용한 센서 유형** — 이진 접촉·탄성체 변위 등 타 모달리티 모두 상회; 태스크 전반에서 반복 확인
- **핵심 발견 2: 센서 배치가 센서 유형보다 결정적** — 손가락 끝(fingertip-only) 커버리지가 전체 손(whole-hand) 커버리지 대비 크게 열위; 손바닥 + 근위 지절(proximal phalanges) 추가 시 특권 교사와의 격차 대부분 해소
- **핵심 발견 3: 해상도보다 커버리지** — 전체 손 200 taxel로 태스크 전반에 충분; taxel 수 증가의 수익 급감

### (c) 시사점

- **10+2 토큰 구조 외부 검증** — "taxel별 F/T 최선" + "전체 손 커버리지(손가락 + 손바닥 + 근위 지절) 필수"가 현 설계(10손가락 + 2손바닥 토큰, per-fingertip F/T 바인딩)의 핵심 가정을 체계적 ablation으로 최초 직접 검증
- **손바닥·근위 지절 포함 근거 구체화** — "팔마 추가 → 격차 해소" 발견이 손바닥 2토큰 포함 결정의 외부 정량 근거 확보; D12 집계 범위 설정에 직접 활용 가능
- **시뮬레이션 인프라** — 20,000 환경 병렬 플랫폼이 다지 손 10개 손가락 규모 촉각 학습 데이터 병목 해소; 인코더 사전학습 인프라로 즉시 활용 가능

### (d) 먼저 확인할 점

- **태스크 범위 제한** — 세 다지 태스크만 검증; 인핸드 조작·섬세한 핀치·슬립 제어에서 동일 순위 유지 여부 본문 확인 권장
- **XHand1 이전 수치 미공개** — 실물 이전 성공률 수치 초록 미명시; 시뮬 ablation 결론이 실 로봇에서 동등하게 유지되는지 확인 필요
- **온도·오디오 모달리티 미평가** — 플랫폼이 지원하지만 이번 ablation에서 직접 평가하지 않음; 조작 태스크에서 가치 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**Blind Dexterous Grasping via Real2Sim2Real Tactile Policy Learning**
[arXiv:2606.11767](https://arxiv.org/abs/2606.11767) · Shengcheng Luo, Xiyan Huang, Zhe Xu, Wanlin Li, Ziyuan Jiao · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **Real2Sim2Real 프레임워크** — 시각 없이 촉각만으로 다지 손 실물 파지를 달성하는 세 구성요소 통합 파이프라인
  - **Real2Sim 촉각 교정 파이프라인** — 실물 촉각 신호를 재현하는 접촉-교정 디지털 트윈 시뮬레이터 구축; 시뮬-실물 접촉 이벤트 일관성 정량 향상
  - **레이아웃-인식 촉각 인코더(layout-aware tactile encoder)** — 센서 배치 기하학 선험 지식을 자기지도 사전학습으로 주입; 희소 촉각 신호의 표현력 향상
  - **객체별 RL 전문가 → 촉각-조건부 확산 정책 집계** — 교정된 시뮬레이터에서 전문가 궤적 합성 후 Diffusion Policy로 통합
- 실물 LEAP Hand (10개 손가락 분산 촉각 감지): 확인 10개 + 미확인 10개 물체에서 통합 **27% 실물 파지 성공률** — 실세계 파지 시연 없이, 시각 입력 없이 달성
- 레이아웃-인식 사전학습이 시뮬-실물 접촉 이벤트 일관성에 기여함을 정량 실증 (센서-수준 평가)
- **진정으로 새로운 점** — 접촉 교정(contact-event calibration) + 기하학-인식 촉각 표현 + 확산 정책 집계의 단일 파이프라인 통합; 실물 시연 없이 10지 다지 손 파지 달성 최초

### (c) 시사점

- **레이아웃-인식 = 토폴로지-인식 인코딩의 실물 선례** — 센서 배치 기하학을 자기지도 사전학습으로 주입하는 방법이 현재 설계가 지향하는 토폴로지-인식 인코딩의 직접 구현 사례; 손가락 위치·손바닥-상대 자세 등 구조 정보를 라벨 없이 인코더에 내재화하는 방법 참조 가능
- **Real2Sim 교정 → 공통 토큰 포맷 일관성 검증** — 실물 신호를 디지털 트윈으로 재현하는 교정 파이프라인이 센서 교체 시 공통 표현 일관성을 검증하는 방법론으로 참조 가능
- **LEAP Hand 10지 분산 감지 실증** — 10개 손가락 분산 촉각 감지를 실물 정책과 연결한 사례; 현재 설계 규모(10+2 토큰)의 실물 작동 가능성 간접 지지

### (d) 먼저 확인할 점

- **시각 없는 순수 촉각 설정** — 비주오택타일 융합 맥락으로 확장 시 레이아웃-인식 인코더가 시각 토큰과 어떻게 결합되는지 추가 설계 필요; 시각 정보 제외로 현 설정과 직접 비교 어려움
- **27% 절대 성공률 수준** — 실세계 시연 없이 달성한 점은 의미 있으나 다지 조작 정책 기준선 대비 충분 여부 검토 권장
- **LEAP Hand 특화 가능성** — 레이아웃-인식 인코더가 LEAP Hand 특정 배치로 학습됨; Allegro·Shadow 등 다른 손 형태로의 이전 가능성 본문 확인 필요

### (a) 관련 Pillar / Decision

### (b) 핵심 기여

- **촉각-구동 적응 전략(tactile-driven adaptation strategy)** — 원격조종 파이프라인 위에서 접촉-풍부 다지 조작을 가능하게 하는 실시간 최적화 루프 제안
  - 촉각 감지로 **정확한 접촉점 추정** + 손가락 끝 힘 감지 프로파일(fingertip force-sensing profile) 활용
  - 대략적인 인간 추적 의도 → 임바디먼트 갭 해소 → 작업 공간 자코비안(operational space Jacobian)으로 관절 각도 국소 보정량 동적 계산
- 양손(bimanual) 다지 프레임워크 DexTeleop-0에 인스턴스화; 시뮬레이션 + 실물 하드웨어 검증
- 강건 파지·외란-회복 조작·복잡한 다지 태스크에서 기준선 대비 성공률 향상 및 실행 효율 개선
- **진정으로 새로운 점** — 임바디먼트 갭 해소를 위한 촉각-구동 자코비안 보정을 양손 다지 원격조종에 통합; 촉각+힘 결합 실시간 순응 보정(compliance correction)의 양손 규모 최초 적용

### (c) 시사점

- **손가락 끝 촉각 → 실시간 접촉점 추정 실용성 확인** — 손가락 끝 F/T 프로파일로 접촉점을 온라인에서 추정하는 패턴이 per-fingertip 접촉 이진 분류(contact-binary) 보조 목표 설계에 참조 가능
- **촉각-힘 비대칭 역할 분리 재확인** — 촉각(접촉 감지·위치 추정)과 힘/자코비안(순응 보정) 분리 구조가 비대칭 이질 모달리티 융합 방향과 일치; ViTaL·TORL-VLA에 이어 세 번째 독립 경로 확인
- **양손 동시 처리 가능성** — 양손 원격조종에서 촉각 신호 동시 처리 실증; 두 손 20개 손가락 규모 확장 타당성 간접 지지

### (d) 먼저 확인할 점

- **원격조종 제어 → VLA 관측 인코더 전환 간극** — 촉각-힘 신호를 자코비안 보정에 사용하는 제어 루프는 VLA 관측 인코더 설계와 목적이 다름; 촉각 토큰으로 직접 전환 가능한지 추가 설계 검토 필요
- **촉각 센서 유형 미명시** — 어떤 손가락 끝 F/T 센서를 사용하는지 초록 미명시; Deform Map 기반 비전-촉각 센서와의 호환성 확인 권장
- **독립 배포 실험 미포함** — 원격조종 데이터 수집 파이프라인에 특화; 수집된 데이터로 학습한 정책의 독립 배포 성능 별도 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**World Pilot: Steering Vision-Language-Action Models with World-Action Priors**
[arXiv:2606.12403](https://arxiv.org/abs/2606.12403) · (저자 미확인) · adjacent field: World Action Model (P5) → 지각 계층 동역학-인식 조건화의 P2 D9 함의 · source: curated-list (Awesome-WAM)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **두 경로로 WAM 선험 지식을 VLA 의사결정 체인에 주입**
  - **Latent Steering(잠재 조향)** — 세계 액션 모델의 장면 진화(scene-evolution) 잠재 벡터로 VLA의 **지각 계층(perception layer) 직접 조건화**
  - **Action Steering(액션 조향)** — 예상 궤적을 모션 사전(motion prior)으로 액션 생성기에 공급
- 비디오 사전학습만 된(액션 사후학습 없는) WAM에서 추출한 장면 진화 사전도 지각 조건화에 충분히 효과적임을 실증
- **LIBERO-Plus 제로샷 OOD 벤치마크** Total 성공률 **84.7% (SOTA)** 달성; 시점·기하학·변형·자세 변화 4가지 실물 태스크 전반 최고 성공률
- **진정으로 새로운 점** — 지각 계층을 세계 모델 잠재로 조건화하는 Latent Steering 개념 최초; 기존 WAM 보강이 액션 수준에만 머물렀던 것과 달리 관측 인코딩 단계에서 동역학 사전 주입

### (c) 시사점

- **지각 계층 동역학-인식 조건화의 효과 대규모 실증** — 관측 인코딩 단계에서 장면 진화 잠재를 주입하면 제로샷 OOD 시점·기하학 변화 전반에서 84.7% 성공률 달성; 동역학-인식 인코더의 가치가 관측 표현 품질에 직결됨을 SOTA 수치로 확인
- **액션 사후학습 없는 WAM으로도 지각 이득** — 비용이 낮은 비디오 사전학습 WAM으로도 지각 조건화 효과 달성; 동역학-인식 인코더 초기화 비용 절감 경로 시사
- **OOD 일반화와 관측 표현 품질의 연결** — 시점·변형 변화에서 최대 마진으로 우위; 고품질 관측 인코딩이 OOD 일반화의 핵심 변수임을 간접 확인

### (d) 먼저 확인할 점

- **순수 시각 장면 진화 잠재** — 촉각·힘 모달리티 없는 비전 전용 WAM 잠재; 이질 모달리티를 포함한 장면 진화 잠재로 확장 시 WAM 재설계 필요
- **외부 WAM 의존성** — Latent Steering은 별도 WAM을 실시간으로 병렬 실행해야 함; 동역학 사전 지식을 인코더 자체에 내재화하는 DynaFLIP/eVGGT 방향과 상호보완 관계이지 직접 대체 아님
- **LIBERO 시뮬레이션 위주 평가** — OOD 벤치마크가 LIBERO 기반 시뮬레이션 중심; 접촉 집약적 다지 조작에서의 이점 별도 확인 필요
