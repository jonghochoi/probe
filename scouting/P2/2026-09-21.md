## 🥈 논문 1 — 우선순위 ★★

**Touch2Trace: Tactile-Driven Imitation Learning for Dexterous Cable Tracing**
[arXiv:2609.15921](https://arxiv.org/abs/2609.15921) · Matteo Grimaldi, David Klee, Ziling Chen, Tong Jian, Wonju Lee 외 · CoRL 2026 · source: citation-graph (ViTacFormer) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여
- 다지 손 케이블 트레이싱 과제에서 촉각 인코더 사전학습·제어 주기·시간 컨텍스트·공간 해상도 네 요소가 정책 성능에 미치는 영향을 실물 환경에서 체계적으로 규명한 최초 사례
- 32×32 피에조레지스티브 센서(TacV5)에 자기지도학습으로 사전학습한 촉각 인코더와 경량 트랜스포머 정책을 결합한 조합이 최적 레시피로 확인, Tesollo DG-5F 손에 60Hz로 배포
- 비전이나 명시적 케이블 상태 추정 없이 촉각 피드백만으로 평균 이탈 거리를 0.2cm에서 20.1cm로, 성공률을 0%에서 93%로 끌어올림 — 고유수용감각 전용 베이스라인 대비
- 미학습 케이블·경로 조건으로의 제로샷 전이 확인

### (c) 시사점
- 촉각 인코더 설계 선택(사전학습 방식·제어 주기·해상도)이 손끝 조작 성능에 미치는 영향을 정량 비교한 근거 자료로 활용 가능
- 비전 없이 촉각 신호만으로도 정밀 손끝 조작이 가능함을 실증 — 시야가 가려지는 조작 국면의 대안 신호 경로로 참고 가능
- 사전학습된 촉각 인코더가 미지 조건으로 제로샷 전이된다는 근거 — 센서 교체 시 재학습 부담을 가늠하는 참고점 제공

### (d) 먼저 확인할 점
- 엄지·검지 두 손가락 중심 검증 — 다섯 손가락 전체로의 확장 여부 별도 확인 필요
- 코드·저장소 공개 서술 없음, CoRL 2026 채택 정보만 확인
- 비전 결합 없이 촉각 단독으로 검증 — 시각 신호와의 결합 방식은 미검증

## 🥈 논문 2 — 우선순위 ★★

**TacSushi: Tactile-Grounded World-Action Modeling for Dexterous Sushi Manipulation**
[arXiv:2609.19613](https://arxiv.org/abs/2609.19613) · Haodi Hu, Kaen Kogashi, Toshiaki Koike-Akino · arXiv preprint · source: citation-graph (ViTacFormer) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- 현재 관측(RGB·언어·손 상태)을 인코딩하는 백본에 손끝 촉각 특징을 게이트 방식으로 결합해 액션 표현에 반영하는 TacSushi 제안 — 단순 연결 방식과 직접 비교
- 학습 시점에만 동작하는 디코더가 시연 액션 청크 조건으로 미래 시각 관측·과제 진행도·상대적 접촉 위험·촉각 요약을 예측, 배포 시점에는 제거되는 구조
- 실패 시연도 결과 감독 신호로 활용하되 그 액션 자체는 모방학습 대상에서 제외
- 실물 시연 340회 성공·50회 실패로 학습, 6가지 방법을 분포내 과제 3종·분포외 재료 변형 2종에서 600회 개별 롤아웃으로 비교

### (c) 시사점
- 게이트 방식 촉각 결합이 단순 연결 방식보다 분포내·분포외 성공률 모두에서 큰 격차로 우월함을 정량 확인 — 촉각을 어떻게 합칠지가 결과를 가른다는 실증 근거
- 미래 결과 예측을 학습 보조 신호로만 쓰고 배포에서 제거하는 설계 — 실시간 추론 비용 증가 없이 예측 학습의 이점만 취하는 경로 제시
- 사람 평가와 비전-언어모델 평가를 함께 쓰는 결과 채점 방식 — 성공 여부를 넘어 결과 품질까지 정량화하는 평가 설계 참고 가능

### (d) 먼저 확인할 점
- 변형·점착성 높은 단일 음식 조작 과제 한정 검증 — 강체·비변형 물체 등 더 넓은 조작 대상으로의 일반화 여부 별도 확인 필요
- 코드·저장소 공개 서술 없음
- 분포외 조건에서 성공률이 분포내 대비 크게 하락 — 재료 변형 폭이 커질 때의 강건성 한계 별도 확인 필요

- 손끝 단위로 라벨링된 이진 접촉 신호를 별도 토큰으로 결합하는 구조가 포인트클라우드 단독보다 실물 성공률을 끌어올림 — 접촉 신호 결합의 실질적 이득 확인
- 실물 파인튜닝이나 추가 시연 없이 시뮬레이션 학습 정책이 미지 물체로 전이됨을 실증

### (d) 먼저 확인할 점

- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
- 사람-물체 상호작용 참조의 품질에 따라 잔차 강화학습 적응 성능이 좌우될 가능성 — 참조 품질 민감도 별도 확인 필요

- 과거 관측 영역이 시야에서 사라져도 장면 표현이 유지됨을 실증 — 오클루전이 잦은 조작 환경에서의 강건성 확보 여지 시사
- 실물 로봇에서 기존 범용 정책(OpenVLA-7B) 대비 뚜렷한 성공률 우위 확인

### (d) 먼저 확인할 점
- 시뮬레이션 벤치마크(LIBERO·MetaWorld) 중심 검증, 실물 비교는 단일 베이스라인(OpenVLA-7B) 한정 — 더 다양한 실물 베이스라인 대비 우위는 별도 확인 필요
- 코드 저장소 공개 서술 없음, ICRA 2027 제출 상태만 확인
- 구성 요소별(다중뷰 감독 유무, 생성 모델 선택 등) 개별 기여를 분리하는 어블레이션 서술은 초록상 확인되지 않음

## 🥈 논문 5 — 우선순위 ★★

**Acting in Meters: Learning Metric Interactions for Precise Robotic Manipulation**
[arXiv:2609.18243](https://arxiv.org/abs/2609.18243) · Lijie Wang, Zheng Lu, Yiming Wang, Heyang Yu, Kenghou Hoi 외 · arXiv preprint · source: citation-graph (VGGT) · 코드 미공개

- 2단계 적응 방식으로 소수 추가 파라미터·학습 스텝만으로 다양한 기존 VLA·WAM 베이스라인에 결합 가능
- LIBERO +0.80%p, RoboTwin 2.0 +3.59%p, 실물 과제 +6.80%p, 실물 분포외 변형 +7.45%p 성공률 개선

- 여러 서로 다른 VLA·WAM 베이스라인에서 일관된 개선을 보인다는 결과 — 특정 아키텍처에 종속되지 않는 범용 보정 계층으로서의 가능성 시사
- 실물 분포외 조건에서 개선폭이 분포내보다 더 크게 나타남 — 기하 조건부 보정이 일반화 강건성에 기여할 여지 시사

### (d) 먼저 확인할 점
- 개선폭이 벤치마크별로 1%p 미만에서 7%p대까지 편차가 큼 — 과제 난이도·기하 복잡도에 따른 효과 편차 원인 별도 확인 필요
- 코드 저장소 공개 서술 없음
- 다중 카메라 등록이 아닌 단일 장면 포인트클라우드 기준 조건화 — 다중뷰 융합 맥락에서의 정합 방식은 별도 확인 필요
