## 🥇 논문 1

**How Many Demonstrations Does a VLA Need? On the Sample Efficiency of VLA Finetuning**
[arXiv:2611.09964](https://arxiv.org/abs/2611.09964) · Rahul Chand, Miguel Villa Floran · CoRL Workshop · source: citation-graph

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- VLA 6종의 데모 수별 적응 효율을 LIBERO에서 비교
- **문제** — 사전학습 VLA의 가치는 제로샷 성능과 적은 데모로 적응하는 비용에 달렸으나 후자를 재는 비교가 없음
  - 실제 배포는 데모 수가 제한된 경우가 많아 데모 예산 아래의 적응성이 중요한 척도
- **기존 한계** — VLA는 제로샷 평가나 전체 데이터 미세조정 성공률로 비교되어 적응 비용이 드러나지 않음
  - LIBERO-Spatial 전체 데이터에서는 6종 중 5종이 97–99%로 수렴하나 데모 50개에서는 31–94%로 벌어짐
  - 제로샷이 더 강한 모델도 전체 데이터에서 앞 세대와 같아지는 데 최대 2배의 데이터나 연산을 요구
- **핵심 방법** — 행동 복제 미세조정에서 데모 수와 학습 스텝을 바꿔 가며 두 계열의 적응 효율을 측정
  - 비교 대상 — π0, π0.5(같은 PaliGemma VLM과 플로우 매칭 액션 전문가, 사전학습 레시피가 다름)와 GR00T N1, N1.5, N1.6, N1.7(VLM과 디퓨전 트랜스포머 액션 헤드)
  - 계열 내부의 모델들을 사전학습 레시피에 대한 자연 실험으로 취급, 비싼 사전학습 ablation을 대체
  - 사전학습 선택 하나를 적응 중에 탐침 — 미세조정 때 VLM을 동결하고 액션 헤드만 학습
- **차별점** — 사전학습을 직접 바꾸지 않고 공개 체크포인트들의 적응 곡선으로 사전학습 선택의 효과를 읽음
  - 제로샷·전체 데이터 점수 대신 데모 예산별 성공률을 비교 기준으로 사용
- **핵심 기여** — 대규모 적응 효율 측정과 VLM 동결 탐침
  - 120회 미세조정, 약 1,400회 체크포인트 평가, 55만 에피소드 이상의 시뮬레이션
  - π0.5가 π0보다 데모를 2–5배 적게 필요로 하고 모든 예산에서 GR00T 전 모델보다 높음, 장기 과제 스위트에서 격차가 가장 큼
  - GR00T 안에서 N1.5가 제로샷이 더 강한 N1.6, N1.7보다 네 스위트 중 세 곳에서 효율적
  - VLM 동결 시 π 계열은 Spatial에서 23점 하락(74–75%), Long에서 π0 85%에서 30%, π0.5 98%에서 47%
  - 같은 동결에서 GR00T N1.5, N1.6, N1.7은 −6에서 +1점 변화에 그침
- **가치** — 배포 데모가 적은 환경에서 어떤 사전학습 계열이 싸게 적응되는지 고르는 측정 기준 제공

### (c) 시사점

- 동결 기본값이 계열에 따라 거의 공짜이거나 치명적이라는 직접 측정
- **적응 범위** — VLM을 사전학습 때 함께 학습한 계열(π)은 동결 시 크게 손상, 사전학습 때 동결한 계열(GR00T)은 거의 영향 없음
  - 우리 쪽이 택한 PaliGemma 계열의 동결 기본값에 대한 반대 방향 근거
- **계통 선택** — 같은 전체 데이터 점수에서도 데모 50개 기준 최대 3배 차이, 후보 비교에 예산별 곡선 필요
- **도입 비용** — 공개 체크포인트와 LIBERO만으로 같은 비교를 우리 후보 계통에 되풀이 가능

### (d) 먼저 확인할 점

- 모든 실험이 LIBERO 시뮬레이션이고 실물 실험은 후속 버전 예정으로 명시
- 계열 간 차이가 데이터, 구조, 규모까지 함께 달라 동결 효과만 분리한 비교는 아님, 저자도 상관 증거로 한정
- 동결 실험은 Spatial과 Long 두 스위트 중심이라 다른 과제로의 일반화는 근거 없음
- 시드는 π 42, GR00T 43으로 고정, 반복 시드 분산은 보고되지 않음

## 🥈 논문 2

**Controlling Action-Head Co-Adaptation to VLM Representation Anisotropy**
[arXiv:2611.04006](https://arxiv.org/abs/2611.04006) · Ruijie Zhang 외 10명 · arXiv preprint · source: citation-graph

**점수 11/15** · R2 · N3 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- VLM 출력 이방성에 맞춘 파라미터 없는 재가중 AdaIE
- **문제** — 제어용으로 학습되는 액션 헤드가 시각-언어 목적으로 사전학습된 VLM의 특정 특징 차원에 점점 의존하는 현상의 정체와 영향이 불분명
  - VLM은 시각-언어 이해에, 액션 헤드는 제어에 최적화되어 두 목적이 다름
- **기존 한계** — VLM과 액션 헤드를 잇는 표현 인터페이스가 상대적으로 덜 연구됨
  - 기존 VLA 연구는 데이터 파이프라인, 구조, 학습에 진전이 집중
  - 인터페이스는 교차 어텐션이나 연결 같은 가벼운 조건화로 두고 표현 기하가 어떻게 노출되는지를 다루지 않음
- **핵심 방법** — 액션 헤드의 민감도를 추정해 학습 중 VLM 표현을 채널별로 재가중하는 AdaIE
  - 관찰 — VLM 출력에 강한 채널별 이방성, 학습이 진행될수록 액션 모델이 고분산 차원에 민감도를 집중
  - 통제 실험 — 민감도 패턴을 강화하는 Exploit과 줄이는 Equalize를 원래 학습과 비교
  - 민감도 추정과 균등화 두 단계, 추가 파라미터 없음
- **차별점** — VLM 표현을 고정된 입력으로 두지 않고 진행 중인 하류 민감도로 인터페이스를 조절
  - 표현과 과제가 어긋난 조건에서 민감도 집중을 줄이는 쪽이 유리하다는 통제 비교에 근거
- **핵심 기여** — 현상 규명, 방법, 여러 설정의 성능 향상
  - 백본-헤드 공적응 규명 — 헤드가 사전학습 백본 표현의 고분산 차원에 민감도를 집중
  - 시뮬레이션 RoboCasa-GR1 최대 +5.28pp, RoboTwin 2.0 +1.68pp
  - 실물 다섯 과제 평균 +19pp, 과제당 20회 시행(좌우 손 각 10회)
  - 디퓨전 정책과 월드 모델로 확장, LeWorldModel 변형은 5개 시드 평균과 표준편차 보고
- **가치** — VLM과 하류 모델을 결합할 때 표현 인터페이스 자체를 최적화 대상으로 세움

### (c) 시사점

- 동결·부분·LoRA 선택과 별개로 인터페이스 조절이 적응 성능에 영향을 준다는 실물 근거
- **적응 범위** — 백본을 얼마나 열지의 선택 이전에 백본 출력이 헤드에 노출되는 방식도 변수라는 관찰
  - 동결 백본에서도 헤드 쪽 재가중으로 이득을 볼 수 있는 후보
- **도입 비용** — 추가 파라미터 없는 재가중이라 기존 액션 전문가 학습에 얹는 비용이 낮음
- **실물 근거** — 휴머노이드 다섯 과제 정량 결과라 시뮬레이션 수치보다 비중 큼

### (d) 먼저 확인할 점

- 시뮬레이션 이득은 최대 +5.28pp, +1.68pp로 작고 기준 모델에 따라 달라질 수 있음
- 실물은 휴머노이드 단일 플랫폼 다섯 과제이고 과제당 20회 시행
- 효과는 표현-과제 불일치 조건에서 확인된 것, 일치 조건에서는 이득이 줄거나 없을 가능성
- 동결 기본값 아래 효과나 사전학습 계통에 따른 차이는 본 논문이 직접 비교하지 않음

## 🥉 논문 3

**Native Action-Prior Learning from Videos for World Action Models**
[arXiv:2610.03391](https://arxiv.org/abs/2610.03391) · Zhaochong An 외 12명 · arXiv preprint · source: citation-graph

**점수 10/15** · R2 · N3 · M2 · Real3 · Repro0 — arXiv comment "Project Page: https://zhaochongan.github.io/projects/NAVA-WAM" — 프로젝트 페이지뿐, 코드 문구 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-f9efc6.svg)](#ref-P2) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 관측 전용 영상으로 액션 정책을 직접 사전학습
- **문제** — 월드 액션 모델(WAM)은 액션이 주석된 로봇 궤적이 비싸고 구현체별 표준화가 어려워 확장이 막힘
  - 액션 라벨 없는 대규모 영상에서 액션 정책 학습에 도움이 되는 사전지식을 얻는 방법이 핵심 과제
- **기존 한계** — 관측 전용 영상 활용 두 갈래가 모두 액션에 간접적으로 닿음
  - 시각 표현 학습 — 영상 사전지식이 시각 중심 표현에 머물러 로봇 학습 단계에서야 액션과 연결
  - 잠재 행동 학습 — 별도 잠재 행동 모델링 단계가 필요하고 목표 관측 복사 지름길을 막는 구조·최적화 제약이 복잡도를 높이며 잠재 행동 공간의 표현력을 제한
- **핵심 방법** — 미래 영상 예측 지도로 Action-DiT를 직접 사전학습하고 액션 라벨 데모로 후속 학습하는 NAVA-WAM
  - 구조 — Video-DiT와 Action-DiT가 결합 어텐션으로 상호작용하며 모달별 파라미터를 유지하는 혼합 트랜스포머
  - 1단계 — Video-DiT를 동결하고 전이 구조 결합 어텐션으로 미래 영상 플로우 매칭 지도만으로 Action-DiT 학습
  - 2단계 — 액션 라벨 데모로 영상-액션 플로우 매칭 후속 학습
  - 비대칭 어텐션으로 영상 스트림을 캐시해 미래 영상 생성 없이 액션만 추론
- **차별점** — 중간 표현이나 잠재 행동 공간 없이 영상 예측 목적이 액션 정책 파라미터를 직접 최적화
- **핵심 기여** — 사전학습 방식, 성능, 라벨 효율
  - 사전학습 영상 — Open X-Embodiment, AgiBotWorld, EgoDex의 관측 전용 23만 5,790 에피소드 1,054.3시간
  - RoboTwin 2.0 Random 설정에서 가장 강한 기준선 대비 17.9점, Clean에서 3.5점 향상
  - 과제당 25개 데모에서 72.0%, 표현 기반 60.6%와 잠재 행동 기반 65.0%를 앞섬
  - 25개 데모의 NAVA-WAM이 50개로 학습한 모든 기준선보다 높음
  - Franka FR3 실물 세 과제 14/15(93.3%), DreamZero 10/15(66.7%), π0.5 8/15(53.3%)
  - 관측 전용 데이터 규모가 커질수록 Random 도메인 성공률이 일관되게 상승
- **가치** — 액션 라벨 로봇 데이터를 넘어 영상으로 액션 정책을 확장하는 단순한 경로 제시

### (c) 시사점

- 영상 데이터를 액션 정책 사전학습에 쓰는 방식의 직접 비교
- **데이터 구성** — 영상 사전학습을 표현형, 잠재 행동형, 직접형으로 나눠 같은 후속 학습 조건에서 비교한 결과
  - 로봇 액션 데이터가 적은 구간에서 격차가 커진다는 점이 에고센트릭 영상 활용 논의와 맞닿음
- **단계 구성** — 영상 단계에서 액션 모듈만 학습하고 후속 학습에서 액션 라벨로 적응하는 2단계 레시피
- **도입 비용** — 액션 라벨 없는 영상이 이미 있으면 별도 잠재 행동 모델 없이 쓸 수 있음

### (d) 먼저 확인할 점

- 사전학습 영상은 로봇 중심 코퍼스에 에고센트릭 EgoDex가 섞여 에고센트릭 단독 대 혼합 질문을 분리한 비교는 아님
- 실물은 과제당 5회 시행 세 과제라 표본이 작음
- 코드 문구 없이 프로젝트 페이지만 있어 재현 여부는 확인 불가
- 반복 시드 분산과 한계 진술은 본문에서 확인되지 않음, 세밀한 제어와 복잡한 지시 이해는 한계로 남음
