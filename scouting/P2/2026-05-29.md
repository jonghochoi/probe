## 🥇 논문 1 — 우선순위 ★★★

**Beyond Binary: Sim-to-Real Dexterous Manipulation with Physics-Grounded Contact Representation**
[arXiv:2605.28812](https://arxiv.org/abs/2605.28812) · Jiahe Pan, Stelian Coros, Jitendra Malik, Toru Lin · source: citation-graph (ViTacFormer 인용) + keyword-sweep

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **반론 대상** — sim-to-real 다지 손 조작에서 촉각을 저차원 특징(접촉 이진값 등)으로 압축하는 기존 관행에 정면 반론
- **Center-of-Pressure(CoP)** — 센서 전체의 조작 중 압력 분포를 실시간 통합한 접촉 무게중심 좌표, 물리 기반 촉각 표현
  - 밀집 접촉 정보를 보존하면서도 sim-to-real 이전에 견고한 표현
  - 미분 가능 동역학 기반 센서 보정으로 실제 힘 측정값 없이 탁셀(taxel) 방향 추정
- **진정으로 새로운 점** — CoP가 contact-binary 베이스라인과 raw-taxel 베이스라인 양쪽을 동일 실험 조건에서 모두 능가
  - 물리 원리(압력 중심점) 기반 표현이 단순화 표현보다 이전 성능 우위라는 경험적 증거를 다지 손 실제 로봇에서 최초 제시
- **검증 태스크** — peg-in-hole 삽입 + 공 균형 유지, 두 맹목적 접촉 집약적 태스크에서 다지 손 완전 제로샷 sim-to-real 이전 입증

### (c) 시사점

- **촉각 특징 형태 재검토** — 단순 접촉 이진값 대신 물리 기반 표현이 이전 성능을 높인다는 직접 증거
- **저비용 구현** — CoP 계산은 taxel 배열의 1차 모멘트 연산, 인코더 출력 이후 선형 투영 한 레이어면 구현 가능
- **토큰 차원 영향** — 손가락 토큰의 촉각 성분을 이진값 2개에서 CoP 좌표(2-3차원)로 교체 시 per-finger 토큰 차원이 달라짐

### (d) 먼저 확인할 점

- **센서 전제** — CoP는 균일 배열 탁셀(taxel) 격자 센서(특히 팁 기반 GelSight 계열) 전제
- **변형 이미징 호환성** — 실리콘 내부 변형을 전면 이미징하는 연속 변형 필드는 이산 탁셀 격자가 아님
  - 연속 변형 필드에서 CoP 좌표를 추출하는 방법을 먼저 풀어야 함
  - 변형 크기가 접촉 압력에 선형 대응하는지 소규모 시뮬레이션 검증 필요
- **모달리티 세팅** — 실험이 촉각 단일 모달리티(비전 없음) 특수 세팅, 비주오택타일 멀티모달 파이프라인에서 동일 우위 여부 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Learning Robust Dexterous In-Hand Manipulation from Joint Sensors with Proprioceptive Transformer**
[arXiv:2605.21330](https://arxiv.org/abs/2605.21330) · Senlan Yao, Chenyu Yang, Jaehoon Kim, Aristotelis Sympetheros, Robert K. Katzschmann · source: keyword-sweep (`cat:cs.RO AND dexterous AND tactile`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **Proprioceptive Transformer(PT)** — 비전·촉각 없이 관절 센서만으로 인핸드 조작 수행
  - 건방식(tendon-driven) 다지 손 ORCA에서 모터 인코더 vs. 직접 조인트 센싱 중 더 나은 고유감각(proprioceptive) 피드백 비교
  - Transformer가 관절 위치·속도 시간 이력에서 물체 상태를 암묵적 추출
- **학습 방식** — 교사 정책(특권 물체 정보)을 학생 정책(관절 센서만)으로 증류
- **결과** — 실제 ORCA 손에서 베이스라인 대비 3.1배 높은 회전 속도 달성
- **진정으로 새로운 점** — 관절 센서만으로 큐브 인핸드 회전에서 경쟁력 있는 성능 달성, 관절 이력 시간 패턴에서 물체 상태 정보 추출 가능성을 체계적 입증
  - 건방식 손에서 직접 조인트 센싱보다 모터 인코더가 더 풍부한 고유감각 피드백 제공한다는 경험적 비교
  - PT는 위치·속도 양쪽 사용 시 MLP 대비 23.4% 낮은 RMSE

### (c) 시사점

- **관절 데이터 소스 근거** — 건방식 손에서 모터 인코더 신호가 직접 조인트 센싱보다 접촉 상태 정보를 더 내포
- **속도 이력 추가** — 관절 상태 인코딩에 위치뿐 아니라 최근 T 스텝 속도 이력을 포함하는 변형 검토 근거
- **촉각 기여 측정 기준선** — 촉각 성분이 없는 PT 성능은 촉각 포함의 실제 기여를 측정하는 ablation 기준선으로 활용 가능

### (d) 먼저 확인할 점

- **구동 방식 차이** — ORCA 건방식 구조에서 모터 인코더 우위 결과가 직접 구동 방식 다지 손에서도 동일 적용되는지 불명확
- **태스크 범위** — 단일 태스크(cube 인핸드 회전)에서만 검증, 복잡한 접촉 전환 태스크(나사 조임·플러그 삽입)에서 관절 센서만의 한계 노출 가능성
- **촉각 이득 미측정** — PT 목적이 "가장 쉽게 구할 수 있는 모달리티로 얼마나 가는가" 탐색이라 촉각 추가 시 실질 이득은 별도 실험으로만 확인

## 🥉 논문 3 — 우선순위 ★

**Tabero: Learning Gentle Manipulation with Closed-Loop Force Feedback from Vision, Touch, and Language**
[arXiv:2605.27886](https://arxiv.org/abs/2605.27886) · Qiwei Wu, Rui Zhang, Xin Xiang, Tao Li, Weihua Zhang, Junjie Lai, Renjing Xu · source: keyword-sweep (`VLA+tactile`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **Tabero** — 접촉 힘 감지가 필요한 "부드러운(gentle)" 언어 조건부 조작용 벤치마크 + 모델 스위트
- **데이터 파이프라인** — 오픈소스 조작 궤적을 재활용해 비전-촉각-언어 데이터를 효율적으로 생성
- **Tabero-VTLA** — 힘-위치 분리 명령 인터페이스(decoupled force-position command interface)를 갖춘 VLA 아키텍처
  - 힘·위치 분리 명령을 고정 하이브리드 컨트롤러가 실행 → 실시간 힘 인식 조작
- **진정으로 새로운 점** — 힘-위치 명령을 VLA 출력 공간에서 분리, 언어 지시어("부드럽게", "조심스럽게")가 힘 채널에 직접 영향
  - 비전-촉각-언어 정렬 데이터 희소성을 기존 궤적 재활용 파이프라인으로 해결
- **결과** — 부드러운 지시어 조건에서 평균 파지력 70% 이상 감소를 실제 로봇에서 입증, 코드 공개

### (c) 시사점

- **촉각 채널 역할 재검토** — 비전 스트림만 통합하는 구조에 촉각 신호를 추가 스트림으로 포함하되 힘-위치 분리 출력 공간을 두는 설계 참고
- **연속 힘 크기 후보** — 접촉 이진값과 기능적으로 다른 연속 힘 크기(continuous force magnitude) 출력을 보조 헤드 후보로 검토 가능

### (d) 먼저 확인할 점

- **하이브리드 컨트롤러 전제** — 힘-위치 분리를 위해 고정 하이브리드 컨트롤러가 하위 레이어에 존재, 컨트롤러 없는 보조 헤드 설계에 직접 이식 가능한지 확인 필요
- **하드웨어 불명** — 촉각 센서 하드웨어가 논문에서 명확하지 않아 변형 이미징 센서와의 호환성 판단 어려움
- **저비용 첫 단계** — 공개 코드에서 촉각 입력 포맷과 하이브리드 컨트롤러 구현 확인

### Decision Log

- **D11 촉각 특징 형태 후보 확장 — CoP 추가** — 근거 Beyond Binary(2605.28812). `context/P2.md` §8.A "Tactile feature form (image / force / pressure / contact-map) → 비교: CP1" 미결 항목에 Center-of-Pressure 좌표(cop_contact_representation)를 추가 후보로 기재 제안. 근거 — CoP가 contact-binary와 raw-taxel 양쪽을 동일 조건에서 능가, D11 v1 기본값(contact-binary + slip-binary) 재검토 충분
- **D8 finger token 관절 상태 인코딩 명시화** — 근거 Proprioceptive Transformer(2605.21330). D8 v1 스펙에 관절 상태 데이터 소스를 `motor_encoder_position`으로 명시하는 주석 추가 제안. 근거 — 건방식 손에서 모터 인코더가 직접 조인트 센싱보다 접촉 상태 정보를 더 내포
- **D11 aux head 확장 — 연속 힘 크기** — 근거 Tabero(2605.27886). D11 deferred 목록에 `force_continuous` 연속 힘 크기 출력을 contact-binary·slip-binary와 함께 CP1 절제 후보로 기재 제안. 트리거 — contact-binary 포화(saturation) 발생 시 연속 힘 피드백이 더 나은 접촉 제어를 제공하는지 검증하는 시점
