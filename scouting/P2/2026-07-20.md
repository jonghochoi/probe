## 🥇 논문 1 — 우선순위 ★★★

**VistaVLA: Geometry- and Semantic-Aware 3D Gaussian-Grounded VLA for Robotic Manipulation**
[arXiv:2607.12356](https://arxiv.org/abs/2607.12356) · Mohan Liu, Zhihao Gu, Xuanyu Chen, Haitian Zhang, Kaimin Mao 외 · source: keyword-sweep (geometry-grounded+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- 기존 3D-aware VLA(깊이맵·포인트클라우드 활용)가 저수준 기하 구조만 포착하고 고수준 의미 그라운딩이 부재하다는 한계 지적
- 다중 시점 비전-언어 특징을 3D 가우시안 프리미티브로 리프팅해, 기하와 의미를 동시에 담는 "3D 의미 인지 지도" 구성 — 인간의 시점-불변 공간 인지 방식에서 착안
- Merge-then-Query(MtQ) 토큰 요약 메커니즘 — 조밀한 가우시안 프리미티브를 액션-관련 3D 레이아웃·의미를 보존하면서 99% 압축, VLA 정책이 다루기 쉬운 소수 토큰으로 변환
- 시뮬레이션 + 실물 로봇 양쪽 검증 — 실물 7개 과제 평균 성공률 22.8%p 향상, 미노출 분포 외 과제에서 VLA-Adapter baseline 대비 30.0%p 향상

### (c) 시사점

- 기하 정보만 담는 병렬 인코더(VGGT/eVGGT류)를 넘어, 의미 그라운딩까지 통합한 3D 표현이 실물 조작 성능 마진으로 이어짐을 실증 — 통합 3D 임베딩 설계의 "의미 보강" 방향 근거 확보
- 99% 토큰 압축이라는 공격적 요약에도 성능이 유지된다는 결과 — 다중 카메라 기하 임베딩을 정책에 주입할 때 토큰 예산 문제를 해결하는 구체적 참조 기법 제공
- 분포 외 과제에서 마진이 더 커진다는 결과 — 시점-불변 의미 그라운딩이 일반화에 특히 기여함을 시사

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 공개 여부 초록에 미기재 — 재현 비용 사전 파악 필요
- 다중 시점 가우시안 리프팅에 필요한 카메라 수·캘리브레이션 요구 수준 본문 확인 필요
- 실물 7개 과제가 병렬조 그리퍼 기준인지 다지 손 기준인지 초록만으로 불명확 — 손가락별 접촉 표현과의 결합 여부 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**KineFuse: Kinematic-Aware Haptic Fusion for In-Hand Occluded-Object Pose Tracking**
[arXiv:2607.14842](https://arxiv.org/abs/2607.14842) · Chanyoung Ahn, Jaesung Lee, Sungwoo Park, Donghyun Hwang · source: keyword-sweep (proprioception+cross-attention)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- 다지 손 인핸드 조작 중 손가락이 물체를 가려 시각 포즈 추적이 실패하는 문제를 겨냥, 사전학습된 시각 포즈 트래커를 보완하는 희소 햅틱 신호(고유수용·근위 힘/토크·이진 접촉) 구조화 방법 제안
- 키네마틱-인지 손가락별 인코더 — 4개의 컴팩트 손가락-레벨 토큰만으로 평탄(flat) 퓨전·관절-레벨 표현 등 4개 대안 설계 대비 우위 확인
- 프레임 단위·순차 개루프 추적·폐루프 조작의 3단계 평가 체계 도입 — 프레임 단위 평가는 인코더 품질을 구분하지 못하지만 순차 추적 평가는 아키텍처 차이를 최대 15배까지 증폭한다는 발견
- 구조화된 인코더가 명시적 지도 없이도 과제-특화 교차-모달 게이팅을 스스로 학습 — 이동(translation)에는 시각을, 회전(rotation)에는 촉각 전용 어텐션 헤드를 배정
- 개선된 추적 성능이 하류 재정렬(reorientation) 과제 성공률 향상으로 이어짐을 확인, 실물 정성 시연 제공, IEEE/RSJ IROS 2026 채택

### (c) 시사점

- 손가락별 컴팩트 토큰화가 평탄 퓨전·관절-레벨 표현보다 우수하다는 정량 비교 — 손가락/팔목 단위 토큰 설계의 구체적 근거 확보
- 프레임 단위 평가로는 인코더 설계 차이가 드러나지 않고 순차·폐루프 평가에서만 증폭된다는 발견 — 향후 퓨전 설계 검증 시 단일 프레임 벤치마크만으로는 불충분할 수 있음을 시사
- 명시적 감독 없이 이동/회전에 따라 모달리티 의존도를 스스로 분배하는 게이팅 학습 — 손가락별 접촉 귀속 설계가 최소한의 구조만 제공해도 유의미한 역할 분화를 유도할 수 있음을 실증

### (d) 먼저 확인할 점

- 실물 검증이 "정성적 시연" 중심으로 서술 — 정량 성공률·baseline 비교 수치는 본문 확인 필요
- 4개 손가락 토큰 구성이 특정 핸드 자유도(4-토큰)에 맞춰진 설계인지, 자유도가 다른 핸드로 이식 시 토큰 수 재설계가 필요한지 불명확
- 폐색(occlusion) 상황에서의 포즈 추적이 핵심 과제라, 비폐색 일반 조작 과제로의 일반화 여부 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Representation-Aligned Tactile Grounding for Contact-Rich Robotic Manipulation**
[arXiv:2607.14609](https://arxiv.org/abs/2607.14609) · Ruilin Chen, Jingkai Jia, Tong Yang, Xinyu Zhou, Qiao Sun 외 · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- VLA 정책 내부에 지각 인코딩부터 모터 예측까지 서로 다른 역할의 표현이 존재하는데, 미래 촉각 예측 지도 신호를 어느 위치에 걸어야 하는지가 불명확하다는 문제를 "표현-정합" 문제로 재정의
- 선형 프로브 분석 — 미래 촉각 상태는 비전-언어 특징이나 최종 액션 상태보다 액션-전문가 중간 표현에서 가장 잘 예측됨을 실증적으로 규명
- Latent Tactile Predictor(LTP) — 식별된 중간 표현으로부터 컴팩트한 미래 촉각 임베딩만 예측하는 경량 모듈, 잡음 섞인 원시 촉각 신호 직접 예측을 회피
- 실물 접촉 집약적 조작 과제에서 표현-정합 촉각 그라운딩이 정합도가 낮은 대안·다중 인터페이스 촉각 예측 대비 우위 확인

### (c) 시사점

- "촉각 신호를 정책의 어디에 주입할지"를 실증적으로 규명한 사례 — 크로스-어텐션 퓨전 설계 시 촉각 토큰의 주입 위치 자체를 프로브 분석으로 사전 검증할 수 있다는 방법론 제공
- 원시 촉각 신호 대신 컴팩트 임베딩만 예측하는 경량 설계 — 촉각 예측 헤드를 정책에 추가할 때의 계산 비용 부담을 낮추는 실용적 패턴
- 중간 액션-전문가 표현이 촉각 예측의 최적 지점이라는 발견 — 관측 인코더와 액션 디코더 사이 경계에서 촉각 지도 신호를 걸어야 한다는 구체적 설계 지침

### (d) 먼저 확인할 점

- "덜 정합된 대안·다중 인터페이스 촉각 예측 대비 우위"라는 서술 외 구체적 성공률 수치·baseline 명단 초록 미제시 — 본문 확인 필요
- 코드·프로젝트 페이지 공개 여부 초록 미기재 — 재현 비용 확인 필요
- 선형 프로브 분석이 특정 VLA 백본·액션 전문가 구조에 종속적인 발견인지, 다른 아키텍처로 일반화되는지 별도 검증 필요

## 🌱 논문 4 — 인접 분야 픽

**Causally Debiased Latent Action Model for Embodied Action Conditioned World Models**
[arXiv:2607.09185](https://arxiv.org/abs/2607.09185) · Yufan Wei, Kun Zhou, Lingjun Mao, Zijun Zhang, Ziming Xu · adjacent field: World Model (P5) → P2 D9 · source: keyword-sweep (dynamics-aware+representation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- 무라벨 비디오에서 잠재 액션을 추론하는 기존 Latent Action Model(LAM)이 복원-전용 목적함수로 학습되어, 액션-관련 동역학과 배경·미접촉 물체 같은 액션-무관 시각 요인이 뒤섞이는 문제("잠재-액션 편향")를 규명
- CD-LAM — 임바디먼트-중심 재구성, 액션-중심 대조학습, 잠재 공간 캘리브레이션 3개 경량 미세조정 목적함수를 결합한 인과적 편향 제거 프레임워크
- 잠재-액션 편향·액션 추종도·강건성을 정량화하는 평가 지표 신규 도입
- 2B·14B 규모 액션-조건부 세계모델 백본에서 검증 — baseline 대비 6천 스텝·12배 적은 로봇-액션 적응 업데이트만으로 제어 가능성·시각 충실도·적응 효율 모두 개선

### (c) 시사점

- 무라벨 비디오로 액션-조건부 표현을 사전학습할 때 "무엇이 액션에 의해 설명되는가"를 명시적으로 분리하는 접근 — 동역학-인식 인코더 학습 시 배경·정적 요소로부터의 오염을 걸러내는 목적함수 설계 참조 사례
- 세 가지 경량 미세조정 목적함수 조합으로 큰 백본에 소수 스텝만 투입해 개선 — 사전학습된 동역학 표현을 저비용으로 재정렬하는 실용적 패턴 제시
- 잠재-액션 편향을 정량화하는 평가지표 신규 도입 — 동역학-인식 인코더 후보를 비교할 때 액션 추종도·편향을 분리 측정하는 기준으로 참조 가능

### (d) 먼저 확인할 점

- 평가가 "로봇-액션 추종도" 지표 중심으로 서술되어 실물 로봇 검증인지 비디오 기반 벤치마크 평가인지 초록만으로 불분명 — 본문 확인 필요
- P5 세계모델·잠재 액션 프레이밍이 중심이라, P2 관측 인코더로 직접 이식 가능한 부분과 세계모델 전용 구성요소(임바디먼트-중심 재구성 등) 구분 필요
- 코드·모델 공개 여부 초록 미기재 — 재현 비용 확인 필요
