## 🥇 논문 1 — 우선순위 ★★★

**VT-WAM: Visual-Tactile World Action Model for Contact-Rich Manipulation**
[arXiv:2607.02503](https://arxiv.org/abs/2607.02503) · Shuai Tian, Yupeng Zheng, Yuhang Zheng, Songen Gu, Yujie Zang et al. · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- 통합 흐름-매칭(flow matching) 프레임워크 내에서 미래 시각 예측 + 촉각 변형 예측 + 액션 예측을 동시 학습하는 Visual-Tactile World Action Model
- 비대칭 Mixture-of-Transformers(MoT) 어텐션 — 첫 프레임 시각 앵커와 시간적 촉각 동역학을 연결
- 접촉-게이트 Action-Visual-Tactile Attention Guidance(AVTAG) — 접촉 구간에서 액션 쿼리가 촉각 증거에 의존하도록 유도
- 실물 접촉 집약적 조작 6개 과제 평균 성공률 71.67% — Fast-WAM 대비 +26.67pp, OmniVTLA 대비 +35.84pp
- 촉각 변형 동역학 모델링과 접촉 구간 촉각 어텐션 유도 둘 다 ablation으로 기여도 확인

### (c) 시사점

- 촉각을 액션 예측에 그대로 넣는 대신 "변형 동역학" 자체를 별도로 예측하는 구조 — 촉각 신호의 시간적 특성을 명시적으로 모델링하는 참조 아키텍처 확보
- 접촉 구간에서만 촉각 의존도를 높이는 게이팅 방식 — 항상 균등하게 융합하는 방식 대비 접촉·비접촉 구간을 구분하는 설계 근거 제공
- 두 개의 최근 세계-액션 모델 baseline 대비 큰 마진의 실물 성공률 향상 — 비대칭 퓨전 방향의 실물 타당성 재확인

### (d) 먼저 확인할 점

- 6개 과제 모두 접촉 집약적 조작에 한정 — 비접촉 조작·장기 과제에서의 일반화 여부 본문 확인 필요
- 코드·모델 공개 여부 초록 미명시 — project 페이지(vt-wam.github.io) 확인 후 재현 가능성 판단 필요
- Fast-WAM·OmniVTLA 두 baseline의 세부 구성(파라미터 규모·학습 데이터) 비교 조건 동등성 원문 확인 권장

## 🥈 논문 2 — 우선순위 ★★

**Imagining the Sense of Touch: Touch-Informed Manipulation via Imagined Tactile Representations**
[arXiv:2607.01684](https://arxiv.org/abs/2607.01684) · Zhiyuan Zhang, Adeesh Desai, Jyun-Chi Hu, Yosuke Saka, Quan Khanh Luu et al. · source: citation-graph (ViTacFormer 인용) + keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- TacImag: 비전 + 고유 수용(proprioception)으로부터 촉각 관측을 예측해 정책을 안내하는 "촉각 상상(tactile imagination)" 프레임워크
- 페어드 비주오택타일 시연으로 학습 — 배포 시점에는 시각 관측만으로 촉각-정보 조작 수행 가능
- 시뮬레이션 6개 + 실물 4개 조작 과제 전반에서 상상된 촉각이 일관되게 성능 향상
- 상상된 힘장(force field)이 접촉-민감 과제에서 평균 44.4% 향상, 상상된 촉각 이미지가 질감-민감 과제에서 23.3% 향상 — 촉각 표현과 과제 요구의 매칭이 효과를 좌우함을 실증
- 핵심 발견 — 촉각 상상이 단순히 누락된 촉각 측정치를 복원하는 것이 아니라, 미세한 시각적 상호작용 단서를 정책이 활용하기 쉬운 형태로 변환하는 접촉-인지 지도(supervision) 역할 수행

### (c) 시사점

- 하드웨어-프리 접촉 감지 계열을 이진 신호에서 힘장·질감까지 포함하는 풍부한 촉각 표현으로 확장 — 촉각 센서 없는 배포 경로의 표현력 상한을 끌어올림
- 촉각 표현 종류(힘장 vs. 이미지)와 과제 요구 사이 정합이 성능을 좌우한다는 발견 — 촉각 토큰 설계 시 어떤 촉각 표현을 우선할지 판단하는 근거로 활용 가능
- "상상은 복원이 아니라 지도"라는 프레이밍 — 촉각 인코더를 센서 대체재가 아니라 시각 신호를 정제하는 보조 학습 신호로 보는 관점 제공

### (d) 먼저 확인할 점

- 실물 4개 과제의 하드웨어 구성(다지 손 종류) 초록 미명시 — 다지 손 규모에서의 일반화 확인 필요
- 외부 baseline과의 정량 비교 부재 — 자체 ablation(상상 촉각 유무) 중심이라 절대적 성능 위치 파악 어려움
- 페어드 비주오택타일 시연 수집 비용 — 학습 데이터 확보 난이도가 배포 시 촉각 센서 제거로 상쇄되는지 비용-편익 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Human-Centric Transferable Tactile Pre-Training for Dexterous Robotic Manipulation**
[arXiv:2607.01067](https://arxiv.org/abs/2607.01067) · Chi Zhang, Penglin Cai, Ziheng Xi, Haoqi Yuan, Hao Luo et al. · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- H-Tac: 160시간 에고센트릭 인간 비디오, 300개 이상 과제, 13.5만 에피소드 규모 대규모 촉각-액션 데이터셋
- Transferable Tactile Pre-Training(TTP): 인간 데이터로 촉각 기반 사전학습 후 세밀한 로봇 과제로 전이하는 시스템
- 사전학습·후속학습 전 과정에서 통합 촉각·액션 공간 사용 — 인간→로봇 전이 시 사전 지식 보존
- 촉각 전문가(tactile expert)가 미래 촉각을 예측하도록 학습 — 접촉 동역학과 물리적 상호작용을 명시적으로 모델링
- 시뮬레이션 + 실물 로봇 광범위 실험에서 강건한 일반화와 세밀한 조작 능력 확인

### (c) 시사점

- 대규모 인간 비디오로 촉각 표현을 사전학습하는 경로 — 로봇 촉각 데이터 수집 병목을 완화하는 스케일 확보 전략으로 활용 가능
- 촉각을 미래 예측 대상으로 명시적으로 모델링하는 방식 — 손가락별 토큰의 동역학-인식 사전학습 초기화 후보로 참조 가능
- 인간-로봇 통합 촉각·액션 공간 설계 — 서로 다른 센서·임바디먼트 간 공통 포맷 요구에 대한 구체적 구현 사례 제공

### (d) 먼저 확인할 점

- "광범위 실험"의 정량 성공률·baseline 비교 수치가 초록에 구체적으로 제시되지 않음 — 본문에서 확인 필요
- 인간 촉각 신호와 로봇 촉각 센서 간 도메인 갭 처리 방식 불명확 — 매핑·보정 절차 확인 권장
- 데이터셋·코드 공개 여부 초록 미명시 — 재현 비용 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**PhysMani: Physics-principled 3D World Model for Dynamic Object Manipulation**
[arXiv:2607.01938](https://arxiv.org/abs/2607.01938) · Peng Yun, Shouwang Huang, Hao Li, Jinxi Li, Jianan Wang et al. · adjacent field: World Model (P5) → P2 D9 · source: keyword-sweep (geometry-grounded+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- 물리-원리 기반 3D 가우시안 세계 모델과 미래-인지 액션 정책 모델을 결합한 PhysMani 프레임워크
- 발산-없는(divergence-free) 가우시안 속도장을 온라인 최적화로 학습 — 빠르고 물리적으로 근거 있는 미래 동역학 예측
- 예측된 3D 장면 미래 동역학을 학습 가능한 토큰 기반 크로스-어텐션 모듈로 정책에 통합
- PhysMani-Bench(16개 과제) 신규 벤치마크 도입 — 시뮬레이션 + 실물 로봇 양쪽에서 강한 baseline 대비 우수한 성공률

### (c) 시사점

- 물리 법칙(발산-없음 제약)을 명시적으로 인코딩한 동역학 예측이 동역학-인식 인코더의 또 다른 구현 경로로 실증 — 동역학-인식이 액션-조건화 외에 물리 제약으로도 달성 가능함을 시사
- 예측된 3D 동역학을 크로스-어텐션으로 정책에 주입하는 패턴 — 인코더 내재화가 아닌 별도 세계 모델 경로의 대안적 통합 구조 제공
- 빠르고 다이나믹한 물체 조작이라는 어려운 태스크 범위에서 검증 — 동역학-인식 표현의 가치가 가장 두드러지는 영역에서의 실증

### (d) 먼저 확인할 점

- 촉각·힘 등 비전 외 모달리티 미포함 — 순수 3D 시각 동역학에 한정된 결과
- 온라인 최적화 기반 속도장 추정의 실시간 처리 비용(레이턴시) 초록 미명시
- PhysMani-Bench가 신규 벤치마크라 기존 벤치마크와의 상대적 난이도·비교 가능성 원문 확인 필요
