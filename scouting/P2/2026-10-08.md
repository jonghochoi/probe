## 🥇 논문 1

**Self-Supervised Anchoring of Fingertip Sensing to Proprioception and Proactive Actions for Robot Imitation Learning**
[arXiv:2609.29822](https://arxiv.org/abs/2609.29822) · Tomohiro Motoda, Masaki Murooka, Keisuke Shirai 외 6인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M2 · Real2 · Repro1 — arXiv comment "Project page is available at https://tomohiromotoda.github.io/nia.propra/"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 지단 센서 이력을 고유수용감각·행동에 각각 정렬하는 사전학습
- **문제** — 근접·촉각 지단 센서가 조작의 서로 다른 국면에서만 유익해 소량 시연으로는 정책이 활용하기 어려움
  - 카메라는 가림과 낮은 시간 해상도 탓에 지단 부근의 물체 근접, 접촉 시작, 파지 상태를 보기 어려움
  - 근접 센서는 접촉 전, 촉각 센서는 접촉 후에 유익하며 파지 결과는 접촉 전 상태에 크게 좌우
- **기존 한계** — 센서를 이어붙이거나 서로 직접 정렬하는 방식은 국면별 유익성 차이를 다루지 못함
  - 단순 이어붙이기 — 센서 간 경쟁 효과로 일부 과제에서 정책이 오히려 저하
  - 모달리티끼리 직접 정렬 — 한 모달리티가 무신호인 구간에서는 동시 발생이 약하거나 모호한 지도 신호
  - 이미지 앵커 정렬 — 단일 시점의 시각 관측에 의존
- **핵심 방법** — 조작 내내 쓸 수 있는 고유수용감각과 행동 청크를 공통 기준으로 삼는 대조 사전학습 PROPRA
  - 지단 센서별 이력을 현재 고유수용감각, 로봇의 의도 동작을 담은 행동 청크와 독립적으로 정렬
  - 과거, 현재, 근미래 상호작용을 한 센서모터 기준에 연결
  - 사전학습 인코더를 모방 학습 정책에 통합
- **차별점** — 단일 시점 이미지 대신 항상 쓸 수 있는 몸 상태와 행동을 앵커로 삼아, 국면이 다른 센서를 서로 강제로 맞추지 않음
- **핵심 기여** — 지단 센싱 시스템, 정렬 문제 정식화와 PROPRA, 실물 성공률 향상
  - 접촉 전 근접과 접촉 후 촉각을 결합한 지단 센싱 시스템, 실로봇 파지 과정의 상보적 상태 포착
  - 비전 단독 정책과 이미지 앵커 사전학습 대비 평균 성공률 향상, 초록은 수치 미제시
  - 표현 분석에서 접촉 전 상태 정보를 더 풍부하게 보존, 정책 실행 기록에서도 확인
- **가치** — 센서 정보가 구간에 따라 희소할 때 어떤 기준에 맞춰 표현을 학습할지에 대한 답 제시

### (c) 시사점

- 이미지 대신 몸 상태에 센서를 묶는 정렬 목표의 실물 사례
  - 손가락별 센서 이력을 고유수용감각에 묶는 구조는 손가락 귀속 토큰의 사전학습 목표 후보
  - 단순 추가가 비전 단독보다 낮아질 수 있음을 측정, 추가 대비 정렬의 근거
  - 행동 청크까지 앵커에 넣는 설계는 별도 주석 없이 쓸 수 있다는 실용적 이점

### (d) 먼저 확인할 점

- 항상 우월하지 않음 — OpenLid에서 이미지 앵커 76.7%가 PROPRA 73.3%보다 높음, 센서 정보가 궤적 전반에 풍부하면 이점 감소를 저자도 한계로 명시
- 파지 중심 과제, 기존 그리퍼에 개조 장착한 센서 2종, 시연 50회 규모 — 다지 손의 손가락별 귀속 검증과는 거리
- 특정 촉각 장치용 대규모 파운데이션 모델과 비교 없음
- 초록에 성공률 수치 없음, 본문 표 확인 필요
- 코드는 미공개, 프로젝트 페이지만 확인

### (b) 논문 요지

- 동결 재구성 특징을 미터법 토큰으로 묶어 액션 전문가에 주입
- **문제** — 사전학습 VLA·WAM이 미터법 기하를 암묵으로 남겨, 올바른 물체와 동작 순서를 고르고도 파지 위치를 빗나감
  - 부족한 것은 거친 행동이 아니라 접촉 수준의 정밀도
  - 두 백본 모두 장면을 픽셀로 읽어 척도와 표면 위치 개념이 없음
- **기존 한계** — 3D 정보를 더하는 공간 행동 모델에 세 가지 공백이 남음
  - 한두 벤치마크와 단일 호스트에서만 검증되어 이득을 기하 덕으로 귀속하기 어려움
  - 시뮬레이터의 특권 라벨, 전용 깊이·점군 센서, 에피소드에 걸친 지도 등 배포 로봇에 없는 입력에 의존
  - 정책 계열마다 3D 구조를 새로 만들어 스크래치 학습해 강한 사전학습 호스트로 옮기기 어려움
- **핵심 방법** — 재구성 모델의 잠재를 로봇 기준 좌표에 결속한 공간 뱅크를 만들어 액션 전문가에 접목
  - 뱅크 — 동결 재구성 모델의 각 잠재를 격자 위치의 미터법 좌표와 각 말단장치로부터의 오프셋에 결속
  - 접목 — 뱅크 토큰을 호스트 액션 전문가 마지막 블록에 교차 어텐션으로 주입, 뱅크 외 경로로는 도움이 되지 않게 라우팅
  - 입력은 RGB, 카메라 보정, 측정 또는 예측 깊이뿐, 분할·물체 상태·지도 불필요
  - 추가 파라미터는 3–5B 호스트의 4–5%
- **차별점** — 재구성 출력을 명시적 표현으로 바꾸지 않고 잠재 공간 자체를 로봇 기준에 결속, 호스트 지각 경로는 그대로 두어 사전학습 이득 유지
- **핵심 기여** — 결속 잠재, 접목 인터페이스, 광범위한 평가
  - bank-off와 bank-shuffle ablation으로 이득이 추가 용량이 아닌 결속된 내용에서 나옴을 확인
  - 제로 뱅크는 호스트 출력을 바꾸지 않음(Proposition 1), 공개 체크포인트의 VLA 2종과 WAM 2종 모두 향상
  - RoboTwin 2.0 접목 π0.5가 clean 94.0%, randomized 92.4%, 최강 공개 3D 조건 정책 WAM4D(93.8%, 89.9%) 상회
  - BEHAVIOR-1K 6과제 중 5과제에서 2025 챌린지 우승 정책을 상회, 최대 Q-score 0.47
  - RoboPRO 두 호스트의 8개 호스트-조건 항목 전부 개선, 실물 3개 플랫폼(단일팔, 양팔, 휴머노이드) 평가
- **가치** — 호스트별 재설계 없이 사전학습 정책에 미터법 기하를 얹는 범용 인터페이스 제시

### (c) 시사점

- 호스트 지각 경로를 건드리지 않는 기하 이식 사례
  - 보정 기반 정합으로 뷰를 묶는 방식과 달리 기하를 액션 전문가 쪽에서 교차 어텐션으로 공급하는 경량 경로
  - 말단장치 상대 오프셋 결속은 손과 손가락 기준 좌표로 확장할 만한 구조
  - 분할·지도 없이 RGB, 보정, 깊이만 쓰므로 도입 비용 낮음

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 초록은 실물 3개 플랫폼을 언급하나 수치를 인용하지 않음, 본문 확인 필요
- 저자가 밝힌 한계 — 플로 매칭 액션 전문가만 평가, 호스트마다 워밍업 길이가 달라짐, 동결 백본의 깊이·특징 오차가 고정밀 접촉의 상한
- BEHAVIOR-1K 신발 걸기 과제는 0.720에서 0.590으로 하락, 평가는 공개 인스턴스 20개 기준이라 공식 채점 10개와 다름
- 결속 단위가 말단장치라 다지 손의 손가락별 귀속 검증과는 거리

## 🥉 논문 3

**Uni-VLaT: Whole-Body Tactile Adaptation of VLA Policies for Humanoid Loco-Manipulation**
[arXiv:2609.35450](https://arxiv.org/abs/2609.35450) · Zihao Wang, Shutong Liu, Siqi Zheng 외 5인 · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 촉각을 앵커로 미래 촉각·몸·시각 표현을 예측
- **문제** — 시각과 고유수용감각만으로는 접촉을 암묵적으로만 조절해 지속 상호작용이 불안정하고 위험할 수 있음
  - 휴머노이드 정책은 위치 기준을 저수준 제어기가 추종, 작은 자세 오차와 부하 변화가 부족하거나 과도한 접촉을 초래
  - 분산 전신 촉각은 가려진 넓은 접촉까지 접촉 위치와 전개를 직접 드러냄
- **기존 한계** — 촉각 스트림을 하나 더 붙이는 것만으로는 접촉을 몸 반응과 장면 변화에 연결하지 못함
  - 사전학습 VLA는 이런 신호를 의미·행동 표현과 정렬하도록 학습되지 않음
  - TACT, WT-UMI, HTD 등 전신 촉각 연구는 전용 정책이나 계획 구조에 의존, 범용 사전학습 정책에 접목하는 방법이 불명
  - 예측 감독이 있어도 미래 촉각·힘 중심, 접촉이 몸 상태와 시각과 함께 전개되는 모습은 다루지 않음
- **핵심 방법** — 사전학습 VLA 안에서 촉각 중심 다중모달 문맥을 만들고 세 가지 미래 표현을 예측하게 학습
  - 촉각 특징이 시각, 언어, 고유수용감각, 행동 표현과 상호작용한 뒤 촉각 앵커 문맥 형성
  - 세 예측기가 미래 촉각, 고유수용감각, 시각 표현을 각자의 잠재 공간에서 추정
  - 모달리티별 표현을 하나의 구분 없는 표현으로 뭉치지 않음
- **차별점** — 촉각을 입력 하나 더가 아니라 물리 상호작용을 잇는 앵커로 쓰고, 예측 대상을 촉각에서 몸과 시각으로 넓힘
- **핵심 기여** — 촉각 앵커 학습, 사전학습 VLA 촉각 적응, 휴머노이드 평가
  - Unitree G1 실물 5과제 평균 75%, 촉각 없음 대비 43점, 예측 감독 없는 촉각 입력 대비 7점 상회
  - 두 VLA 백본 모두에서 Table Sweeping 30점 향상, Back-Tap Walking 85–90점 향상
  - ablation — 문맥화된 촉각 예측과 절대 미래 목표가 성능에 핵심
- **가치** — 사전학습 VLA를 전신 접촉 과제로 확장하는 촉각 적응 레시피 제시

### (c) 시사점

- 몸 전체 촉각을 VLA에 붙이는 예측 감독 사례
  - 촉각을 이어붙이지 않고 고유수용감각·시각 예측과 묶는 비대칭 융합의 실물 정량 증거
  - 예측 감독 유무 7점 차이로 단순 입력 추가와 결속의 이득이 분리됨
  - 신체 부위 단위 촉각 문맥은 손가락·손바닥 토큰 구성에 응용할 후보

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음
- 대상은 전신 휴머노이드 촉각, 손가락별 귀속이 아닌 신체 부위 단위
- 저자 명시 한계 — 어레이 센서가 노이즈와 장착 편차에 민감, 전신 촉각 시뮬레이션 부재로 대규모 견고성 연구 제한
- 5과제 규모, 촉각 입력 유무만으로 이득이 나는 Back-Tap Walking과 지속 접촉 적응 과제를 구분해 읽어야 함

### (b) 논문 요지

- 동결 V-JEPA 잠재 위에 미래 예측기와 액션 전문가 학습
- **문제** — 월드-액션 모델이 대규모 사전학습 생성 모델을 통째로 상속해야 하는지, 예측형 시각 잠재 공간만으로 충분한지 검증
  - 생성 모델을 가져오면 예측 지식이 그것을 학습한 백본과 함께 딸려옴
- **기존 한계** — 사전학습 영상 생성 모델이나 이미지 편집 모델을 적응시키는 기존 월드-액션 모델
  - 영상 생성 모델 — 움직임과 장면 변화의 사전지식을 생성 백본째 상속
  - 이미지 편집 모델 — 지시 조건 시각 변환의 사전지식을 같은 방식으로 상속
- **핵심 방법** — 동결 V-JEPA 2.1 인코더 위에 두 모듈을 단일 하류 단계에서 스크래치 학습
  - 지시 조건 미래 잠재 예측기 — 관측 잠재 토큰과 미래 위치 학습 질의를 합쳐 한 번의 순전파로 미래 잠재 예측
  - 플로 매칭 액션 전문가 — 공유 어텐션 트랜스포머 혼합 구조에서 예측기의 미래 반영 문맥 키-값 상태로 조건화
  - 총 0.9B 파라미터, 학습 대상 0.6B
- **차별점** — 생성기를 상속하지 않고 예측형 잠재만으로 월드-액션 모델을 구성, 미래 모델링이 행동 생성을 직접 형성
- **핵심 기여** — 모델, 시각 기반 비교, 행동 라벨 없는 예측기 사전학습
  - LIBERO 97.25%, LIBERO-Plus 79.25%, RoboCasa-GR1 50.92%, 대표 월드-액션 모델과 VLA 기준선과 경쟁적
  - 같은 하류 프레임워크와 예산에서 판별형, 재구성형, 영상 이해형 대안보다 V-JEPA 잠재가 우수, 분포 이동에서 격차 확대
  - DROID 영상-지시 쌍으로 예측기만 사전학습하면 LIBERO-Plus가 79.25%에서 91.50%로 상승해 연장 학습 81.64% 상회
  - 서론 기준 실물 양팔 2과제 평균 45%, 예측기 사전학습 후 80%
- **가치** — 행동 라벨 없는 일반 영상에서 얻은 미래 모델링 지식을 같은 잠재 공간에서 제어로 옮기는 경로 제시

### (c) 시사점

- 예측형 잠재를 관측 인코더 후보로 보는 통제 비교 근거
  - 같은 조건에서 판별형·재구성형보다 분포 이동에 강하다는 결과는 동역학 인지 인코더 선호의 외부 근거
  - 행동 라벨 없는 영상으로 예측기만 사전학습해 데이터 조달 부담이 낮음
  - 시각 단일 모달이라 촉각·고유수용감각 융합 문제는 다루지 않음

### (d) 먼저 확인할 점

- 초록 기준 평가는 시뮬레이션 3종뿐, 점수의 Real0은 초록 기준이며 서론의 실물 양팔 수치는 점수에 반영되지 않음
- 실물 평균 45%는 절대치가 낮음, 80%는 예측기 사전학습 후 결과라 구분 필요
- 하류 학습 컴퓨트 확대는 일반화에서 수익 체감, 사전학습이 더 효과적이라는 비교는 평가된 예산 안의 결과
- 조작 관측 퓨전이 아닌 월드-액션 모델 연구라 인접 분야 참고용
