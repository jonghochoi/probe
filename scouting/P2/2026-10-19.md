## 🥇 논문 1

**PACE: Temporal-Role Tactile Conditioning for Chunk-Based Insertion Policies**
[arXiv:2610.16308](https://arxiv.org/abs/2610.16308) · Zhiyuan Chen, Shixiong Xu, Shuai Chen et al. · CoRL 2026 · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — P1 2026-10-15 판정 유지

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 한 촉각 스트림을 세 시간 역할로 나눠 청크 정책에 연결
- **문제** — 소형 클리어런스 삽입에서 접촉 이후의 국소 보정을 영상만으로 제때 추정하기 어려움
  - 접촉 뒤에는 엔드이펙터와 부품이 가장 정보량 높은 영역을 가림
  - 촉각 피드백은 접촉 상태, 접촉 사건, 접촉 결과라는 서로 다른 시간 역할을 가짐
- **기존 한계** — 기존 시각촉각 청크 정책은 촉각을 생성 시점의 단일 융합 경로로만 입력
  - 접촉 상태·접촉 사건·접촉 결과가 하나의 표현 안에서 암묵적으로 학습됨
  - 임피던스·하이브리드 힘/위치 제어 같은 고전 방식은 기하와 제어 파라미터를 정밀 지정해야 하며 다양한 형상으로의 일반화가 약함
- **핵심 방법** — ACT 스타일 액션 청킹 정책 위에 같은 촉각 스트림을 세 경로로 배분
  - 접촉 상태 조건화 — 서서히 변하는 접촉 상태가 액션 청크 생성을 유도
  - 접촉 사건 보정 — 급격한 접촉 사건이 이미 생성된 청크를 교정
  - 접촉 결과 예측 — 학습 때만 미래 접촉 결과 예측이 액션 표현을 형성
- **차별점** — 촉각 입력 위치를 하나 더하는 대신 같은 신호를 시간 역할별 경로로 나눠 청크 연속성은 유지
- **핵심 기여** — 프레임워크, 검증, 일반성, 시연 데이터 비교 네 가지
  - 실물 삽입 5개 과제 평균 성공률 90.7%, 비전 단독·생성 시점 촉각 융합 기준선보다 44%p 넘게 높음
  - ManipulationNet 벤치마크에서 6개 형상·클리어런스 조합 평균 88.7%, 0.1mm 클리어런스 포함
  - 기준선 — 비전 단독 ACT·Diffusion Policy·π0 미세조정, 촉각 교차 어텐션, 촉각 단순 연결
  - ablation — 사건 보정 제거 66.7%, 상태 조건화 제거 78.7%, 결과 예측 제거 85.3%, 상태 조건화 단독 60.0%
  - Diffusion Policy로 이식 가능, 엔드이펙터 힘/토크나 관절 전류로 촉각 센서 대체 가능
  - 힘 피드백 원격조작이 같은 장치·조작자 조건에서 더 일관된 시연을 만든다는 통제 비교
- **가치** — 접촉 피드백을 하나의 융합 입력이 아닌 시간 역할별 경로로 설계하는 근거 제시

### (c) 시사점

- 단일 경로 융합 대비 역할별 비대칭 경로의 실물 우위 측정
- **융합 위치의 분리** — 생성 입력, 생성 후 보정, 학습 전용 예측으로 나눈 설계가 사건 보정 제거 시 24.0%p 하락, 비대칭 경로 선택의 정량 근거
- **센서 비의존 단서** — 힘/토크나 관절 전류로도 같은 구조가 작동, 센서 헤드 교체에 둔감한 설계 방향
- **저비용 보조 지도** — 결과 예측은 학습 전용이라 배포 계산량 증가 없음

### (d) 먼저 확인할 점

- **코드 미공개** — 프로젝트 페이지만 있고 코드 저장소 문구 없음
- **삽입 과제 한정** — 정밀 삽입만 검증, 접촉 단계 구조가 다른 과제는 저자가 미검증으로 명시
- **손가락 귀속 없음** — 단일 촉각 스트림을 시간 축으로 나눈 구조, 손가락별 접촉 귀속과는 다른 문제
- **병진 시 기울어짐 실패** — 약한 파지에서 들어올림과 병진이 겹치며 물체가 기울면 사건 보정이 실패
- **보정 품질 의존** — 사건 보정은 물리 피드백 품질에 의존

## 🥈 논문 2

**ForceBench: Benchmarking Force Integration for Robotic Manipulation**
[arXiv:2610.19604](https://arxiv.org/abs/2610.19604) · Xuan Han, Zinuo Jin, Tianlin Li et al. · arXiv preprint · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — arXiv comment "Project page: https://forcebench-platform.github.io/" — 프로젝트 페이지만, 코드 저장소 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 같은 π0.5 위에서 여섯 가지 힘 통합 설계를 비교
- **문제** — 힘 인식 VLA 시스템 간 과제·시연·제어 설정이 달라 힘 통합 설계를 직접 비교할 수 없음
  - 평균 성공률은 물성 추론, 저항 의존 상호작용, 접촉 집약적 조립 사이의 차이를 가림
- **기존 한계** — 힘 통합 선행 연구가 각자 다른 설정에서 평가
  - 힘 토큰과 시각·언어 특징의 적응형 융합, 고주파 피드백 기반 시간 인코딩
  - 접촉 예측으로 피드백 사용량을 조절하는 반응형 실행, 행동-렌치 결합 모델링을 통한 강화학습 사후학습
  - 추론 때 센서를 없애려 힘 지식을 비전으로 증류하는 방식
  - 위 접근 모두 표준화된 데이터와 벤치마크 없이 서로 비교되지 않음
- **핵심 방법** — 시뮬레이션 벤치마크와 통제된 비교 연구
  - 8개 과제, 1,600개 동기화 시연, 공유 관측·액션 인터페이스, 공유 시드 평가
  - 일곱 과제는 물성과 저항 조건 변화, 한 과제는 기하 제약이 있는 조립
  - 힘 없는 기준선과 여섯 설계 — 현재 샘플 조건화 Token Fusion, Prompt Fusion, Cross-Attention, 미래 힘 예측을 더한 Token Fusion, 시간 기준 체계 Temporal Prompt, Dual-Path Fusion
  - ForceVLA를 외부 비교 대상으로 사용
- **차별점** — 새 융합 방식 제안 없이 같은 백본·시연·학습 절차에서 통합 방식만 바꿔 설계 효과를 분리
- **핵심 기여** — 벤치마크, 비교 연구, 실물 검증 세 가지
  - 시뮬레이션에서 Prompt Fusion 평균 35.31%, 힘 없는 기준선 23.25%이며 세 과제 범주 모두 향상
  - 예측 감독과 시간 표현의 이득은 물성 추론에 집중, 두 시간 설계는 조립에서 기준선 하회
  - 실물 Franka Research 3 위 5개 과제, 8개 시스템, 과제당 20개 초기 조건으로 총 800회 시행
  - Prompt Fusion과 Dual-Path Fusion 평균 63.00%, 기준선 40.00%, Prompt Fusion만 전 과제에서 기준선 초과
- **가치** — 비슷한 평균 성공률 뒤에 과제별 상충이 숨는다는 점을 드러낸 힘 통합 설계의 비교 기준점

### (c) 시사점

- 입력 결합 방식이 과제 범주에 따라 갈린다는 통제 측정
- **전 과제 향상 설계 확인** — 현재 샘플을 프롬프트로 주입하는 방식이 실물 5개 과제 모두에서 기준선 초과, 단순 주입도 과제별 검증 필요
- **시간 표현의 양면성** — 물성 추론에는 이득이나 조립에서 기준선보다 낮아 시간 축 확장이 만능이 아님
- **평가 설계 참고** — 범주별 지표로 나눠 보는 방식은 융합 방식 비교 실험에 그대로 차용 가능

### (d) 먼저 확인할 점

- **코드 미공개** — 프로젝트 페이지만 있고 코드 저장소 없음
- **시뮬레이션 중심** — 주 비교는 시뮬레이션, 실물은 질적 경향 일치 확인용
- **손목 힘 한정** — 6축 손목 힘/토크만 다루며 손가락별 촉각과 비전 기반 촉각은 범위 밖
- **다지 손 미포함** — 손가락별 접촉 귀속 문제와는 거리가 있음
- **백본 단일** — π0.5 위 비교라 다른 정책 구조로의 일반화는 미확인

## 🥉 논문 3

**Targeted Modality Dropout for Real-Robot Manipulation Robust to Intermittent Vision Loss**
[arXiv:2610.09566](https://arxiv.org/abs/2610.09566) · Genki Shikada, Kazuki Osamura, Masaru Ide et al. · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 어텐션으로 지배 모달리티를 찾아 골라서 떨어뜨리는 학습
- **문제** — 다중 모달 모방 학습이 정보량 큰 비전에 과의존해, 추론 중 비전을 잃으면 실행이 무너짐
  - 카메라 고장과 가림은 실제 배포에서 발생하는 견고성 문제
- **기존 한계** — 모달리티 의존 편중을 다루는 기존 접근 다섯 갈래의 한계 지적
  - 융합 구조 설계 — 특정 정책 구조에 묶임
  - 과제 단계별 가중 — 모든 모달리티가 유지된다고 전제
  - 학습 중 시각 열화 — 어느 모달리티가 지배적인지 보지 않음
  - 그래디언트 재균형 — 모달리티 부재를 다루도록 학습하지 않음
  - 무작위 모달리티 드롭아웃 — 지배 모달리티를 고려하지 않음
- **핵심 방법** — Targeted Modality Dropout(TMD)
  - 어텐션에서 모달리티별 의존도를 추정해 가장 지배적인 모달리티를 선택적으로 제거
  - 의존도 분포에 엔트로피 정규화를 더해 한 모달리티로의 쏠림을 완화
  - 비전·언어·고유수용감각 세 모달리티를 하나의 정책에 입력
- **차별점** — 드롭할 모달리티를 사전 지식이나 무작위가 아닌 학습 중 추정한 의존도로 결정
- **핵심 기여** — 방법, 실물 검증, 무작위 드롭아웃 대조 세 가지
  - 양팔 CobotMagic 실물 6개 과제에서 비전 손실 시 기준선 성공률이 크게 하락하는 반면 TMD는 실행 유지
  - 비전 손실 때 도착한 청크로 인한 액션 명령 교란이 TMD에서 더 적음
  - 무작위 선택 RMD는 비전 손실이 없어도 여러 과제에서 실패
- **가치** — 모달리티 결손 상황의 실물 폐루프 견고성을 평가하고 개선하는 방법 제시

### (c) 시사점

- 지배 모달리티 표적 제거로 결손 견고성 확보
- **무작위 드롭아웃의 비용** — 선택 규칙 없이 무작위로 떨어뜨리면 정상 조건에서도 실패, 모달리티 드롭아웃은 설계 없이 쓰면 위험
- **결손 대비 학습 레시피** — 촉각이나 힘 입력이 추가된 융합 정책에서도 센서 이상 시 우아한 성능 저하를 노릴 수 있는 방식
- **어텐션 기반 진단** — 학습 중 모달리티 의존도 궤적을 직접 관찰하는 수단

### (d) 먼저 확인할 점

- **코드 미공개** — 코드 저장소나 공개 약속 문구 없음
- **시행 수 적음** — 조건당 5회 시행, 소수 성공 횟수 차이는 오차 범위일 수 있음
- **정상 조건 이득 없음** — 정밀 파지 과제(지퍼 닫기 등)에서는 기준선보다 낮음, 가치는 비전 손실 견고성에 한정
- **원인 분리 한계** — TMD와 RMD가 선택 규칙뿐 아니라 엔트로피 정규화 유무도 달라 차이를 선택 규칙만으로 귀속 불가
- **인과 미입증** — 의존도 교정이 견고성을 낳는다는 설명은 저자 스스로 해석이라 명시
- **단기 손실만 평가** — 추론 청크마다 독립적으로 생기는 짧은 비전 손실만 다루며 지속 손실은 미평가
- **손가락 귀속 무관** — 모달리티 단위 드롭아웃이며 다지 손 촉각 구조는 다루지 않음
