## 🥇 논문 1 — 우선순위 ★★★

**DAM-VLA: Decoupled Asynchronous Multimodal Vision Language Action model**
[arXiv:2606.12105](https://arxiv.org/abs/2606.12105) · 저자 미확인(S2 미인덱싱) · source: keyword-sweep (contact-rich OR visuotactile)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여

- **문제** — 기존 VLA는 사전학습에서 비롯된 동기 클록(synchronous clock)을 그대로 사용; 고주파 모달리티(수백 Hz)·저주파 시각·에피소드 상수 언어를 단일 속도로 처리
  - 느린 모달리티 과표집, 빠른 모달리티 과소표집 → 최저 유효 주파수로 액션 생성률 상한 설정
- **DAM-VLA** — 모달리티별 시간 처리를 분리(decouple)해 각 스트림을 고유 주파수로 처리하는 비동기 멀티모달 VLA 아키텍처
  - 시각·언어·고주파 제어 모달리티(proprio / tactile / force)를 독립 클록으로 처리
  - 아키텍처 수준에서 "fast-path + slow-path" 분리 구조 도입
- **진정으로 새로운 점** — 멀티모달 VLA의 동기 클록 문제를 처음으로 체계화하고 아키텍처적으로 해결; 이전 비대칭 퓨전 연구는 모달리티 가중치 차이를 다뤘지만 시간 축 처리 주파수 불일치를 직접 해결한 첫 설계

### (c) 시사점

- **이질 모달리티 퓨전 설계 기준 강화** — 시각/proprio/촉각/힘이 서로 다른 시간 해상도를 요구하며 동기 처리가 저하를 유발함을 정량 입증; 비동기 fast-path 설계 채택의 구체 근거
- **고주파 모달리티 경로 분리 구현 아이디어** — proprio + tactile + force를 빠른 경로로, vision을 느린 경로로 처리하는 분리 구조가 swappable sensor head 아키텍처와 자연 결합 가능
- **액션 생성 빈도 제약 해소** — 동기 VLA의 최저-주파수 병목이 제거되면 접촉 반사 루프가 요구하는 고주파 응답 달성 가능

### (d) 먼저 확인할 점

- **fast-path / slow-path 동기화 상세 미공개** — 비동기 경로 간 동기화 메커니즘(phase alignment, latency compensation)이 초록에 미명시; 통합 지점에서 정렬 오차 발생 가능성
- **per-finger 적용 범위 불명** — 고주파 모달리티 경로가 손가락 수준 proprio+tactile 토큰 구조를 지원하는지 본문에서 확인 필요
- **S2 미인덱싱** — arXiv 초록 기반 평가; 코드 저장소 공개 여부 미확인

## 🥇 논문 2 — 우선순위 ★★★

**TacForeSight: Force-Guided Tactile World Model for Contact-Rich Manipulation**
[arXiv:2606.11184](https://arxiv.org/abs/2606.11184) · Yujie Zang, Yuhang Zheng, Xiangli Nie, Yupeng Zheng, Shuai Tian, Songen Gu · source: keyword-sweep (tactile AND manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **공백** — 기존 모방 학습 방법들이 촉각 또는 힘 피드백을 추가 모달리티로 포함하지만, 전역 힘(global force)과 국소 촉각(local tactile)의 비대칭 시공간 역할을 모델링하지 않음
- **TacForeSight** — 힘 조건화 촉각 예측(foresight) 경량 프레임워크
  - **TacForceWM** — 손목 힘/토크(wrist F/T) 고주파 신호로 조건화해 쌍지(dual-finger) 촉각 관측의 단기 잠재 역동성(latent dynamics) 예측하는 촉각 세계 모델
  - **Predictive Tactile-Conditioned Policy** — 예측된 잠재 벡터를 예측 접촉 사전(anticipatory contact prior)으로 활용; 현재→미래 촉각 진화를 크로스-어텐션으로 모델링 + tactile-guided gating 모듈로 비주오택타일(visuotactile) 특징 적응적 융합
  - 잠재 공간 내 예측으로 실시간 추론 지원
- **진정으로 새로운 점** — 힘 신호(coarse global)를 촉각 예측(fine local)의 조건화 신호로 사용하는 비대칭 계층 설계 최초; ForceFlow의 비대칭 퓨전 원칙을 세계 모델 예측 루프로 확장
- **결과** — 실제 로봇 5개 태스크 + 3개 인-프로세스 교란(perturbation) 조건; 동적 접촉 교란 하 기준선 대비 일관 우세; 코드·데이터셋 공개 예정

### (c) 시사점

- **비대칭 퓨전 구체 구현 경로 확보** — 전역 힘(손목 F/T)을 빠른 조건화 채널로, 국소 촉각(손가락 변형 맵)을 예측 출력으로 다루는 비대칭 설계; 크로스-어텐션 퓨전 설계 시 직접 참조 가능한 선례
- **예측 기반 촉각 prior** — 미래 촉각 역동성 예측을 정책 조건으로 삼으면 접촉 전환 전 선제 대응 가능; contact-binary + slip-binary 보조 헤드에 tactile foresight 목표 병행 검토 근거
- **경량 + 실시간 가능성** — 잠재 공간 예측 방식은 픽셀 수준 예측 대비 연산 비용 우세; 고주파 접촉 반사 루프 통합 가능성 확인

### (d) 먼저 확인할 점

- **쌍지(2-finger) 한정** — 현재 dual-finger 촉각 관측 기반; 10개 손가락 동시 접촉 규모로 TacForceWM 확장 시 잠재 공간 크기·계산 비용 증가 우려
- **힘 센서 의존** — 손목 F/T 센서 고주파 신호에 의존; 저비용 팔에서는 F/T 추정 대체 필요
- **교란 실험 규모** — 인-프로세스 교란 실험이 현재 2지 규모; 10개 손가락 독립 접촉 전환 태스크에서 일반화 별도 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**TacCoRL: Integrating Tactile Feedback into VLA via Simulation**
[arXiv:2606.11743](https://arxiv.org/abs/2606.11743) · 저자 미확인(S2 미인덱싱) · source: keyword-sweep (contact-rich OR visuotactile)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — VLA 시각 관측만으로는 접촉 집약적 태스크에서 국소 접촉 상태 포착 불가; 대규모 촉각 사전학습이나 방대한 실세계 접촉 탐색 없이 촉각 피드백을 VLA에 통합하는 확장 가능한 방법 부재
- **TacCoRL** — 시뮬레이션 기반 sim-real 공동학습(co-training) + 시뮬레이션 강화학습(RL)으로 실세계 접촉 탐색 없이 VLA에 촉각 피드백을 주입하는 확장 가능 프레임워크
  - 대규모 촉각 사전학습 불필요
  - 시뮬레이션에서 촉각 정책을 충분히 학습 후 실세계 이전
- **진정으로 새로운 점** — 실세계 대규모 촉각 데이터 없이 시뮬레이션만으로 VLA에 촉각을 통합하는 실용적 경로 제시; 기존 접근의 데이터 수집 병목 해소

### (c) 시사점

- **swappable sensor head의 시뮬레이션 보정 경로** — 촉각 센서 유형과 무관하게 시뮬레이션에서 촉각 토큰을 훈련하는 방식은 swappable sensor head + common token format 설계와 자연 결합; 새 하드웨어 도입 시 실세계 재수집 없이 sim-real co-training으로 보정 가능
- **VLA 진입 비용 저감** — 대규모 촉각 사전학습 불필요 → 촉각 인코더 도입 초기 비용 절감; 표준 VLA 파이프라인에 촉각 모달리티를 점진적으로 추가하는 단계적 접근 가능
- **RL 기반 촉각 정책 품질** — 접촉 탐색이 풍부한 시뮬레이션 RL로 촉각 신호 활용 최대화; contact-binary + slip-binary 보조 헤드 학습에도 sim RL 접근 적용 검토

### (d) 먼저 확인할 점

- **sim-real 촉각 간극** — 시뮬레이션 촉각 신호와 실세계 변형 이미징 센서 신호의 sim2real 간극 극복 방법 상세 미공개; 본문에서 보정 방법 구체 확인 필요
- **사용 촉각 센서 방식 미명시** — 초록에 어떤 촉각 센서 모델을 시뮬레이션 이전에 사용하는지 미명시; 변형 이미징 방식과의 호환성 확인 필요
- **S2 미인덱싱** — arXiv 초록 기반 평가; 코드 저장소 공개 여부 미확인

## 🥈 논문 4 — 우선순위 ★★

**GEAR-VLA: Learning Geometry-Aware Action Representations for Generalizable Robotic Manipulation**
[arXiv:2606.08530](https://arxiv.org/abs/2606.08530) · Yuan Zhang, Shiqi Zhang, Yedong Shen, Shuai Dong, Jiajun Deng · source: citation-graph (VGGT arXiv:2503.11651 인용 논문)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **공백** — 기존 VLA들이 낮은 수준 궤적 감독(low-level trajectory supervision), 3D 특징 정렬 불일치(misaligned 3D features), 임바디먼트 차이의 세 가지 문제로 실세계 일반화 저하; 공통 원인: 통합 기하학 인식 표현(unified geometry-aware representation) 부재
- **GEAR-VLA** — 통합 기하학 인식 액션 표현 학습 VLA 프레임워크
  - 3D 공간 구조를 인식하는 통합 표현 학습으로 위 세 가지 실패 모드 동시 해소
  - 기하학 기반 특징 정렬로 미관측 물체·배경 변화·이종 임바디먼트 일반화
- **진정으로 새로운 점** — 기하학 인식 표현을 VLA 표현 전반에 통합해 3D 기하학 간극(geometric gap)을 표현 수준에서 해소; VGGT를 인용하면서 독립적인 geometry-aware 설계 경로를 검증

### (c) 시사점

- **D8 설계의 외부 독립 확증** — "misaligned 3D features"가 일반화 실패의 핵심 원인이라는 독립 진단; geometry-grounded multi-view encoder 필요성의 추가 외부 근거
- **3D geometry alignment ROI 재확인** — 기하학 정렬이 미관측 물체 및 이종 임바디먼트 이전을 동시 해결함을 실증; 멀티카메라 공간 임베딩 통합 우선순위 재확인
- **geometry-distilled 인코더 선택 근거 보강** — VGGT/eVGGT 스타일 기하학 인식 인코더가 VLA 일반화에 기여함을 독립 경로로 실증; D9 인코더 선택에 외부 근거 추가 누적

### (d) 먼저 확인할 점

- **액션 표현 vs. 관측 인코딩 경계** — 논문이 액션 표현 측을 강조하며 관측 인코더(observation encoder) 아키텍처 상세는 초록에 미공개; P2는 관측 측이므로 본문에서 관측 인코더 구조 확인 필요
- **전체 아키텍처 세부 미공개** — S2 abstract 절단으로 멀티카메라 구조 포함 여부 확인 필요
- **다지 손 특화 미확인** — 기하학 표현 학습이 다지 손 + 촉각 통합 설정에서도 유효한지 별도 확인 필요

### Decision Log

- **D10 비동기 모달리티 처리 후보 추가** — 근거 DAM-VLA(2606.12105). D10 v1 cross-attention/asymmetric fusion 스펙에 "decoupled asynchronous multi-rate processing(vision slow-path + proprio/tactile/force fast-path)"을 deferred 후보로 기재 제안. 트리거 — 동기 퓨전이 고주파 접촉 반사 루프에서 레이턴시 병목 관찰 시. 근거 — DAM-VLA가 VLA 동기 클록 문제를 정량 입증

- **D10 힘→촉각 조건화 비대칭 퓨전 deferred 추가** — 근거 TacForeSight(2606.11184). D10 v1 ForceFlow-style 비대칭 퓨전 스펙에 "wrist F/T high-frequency conditioning → local tactile latent prediction(predictive foresight)"을 deferred 경로로 추가 제안. 트리거 — 비대칭 퓨전 설계에서 접촉 전환 직전 예측 선행 반응 부족 관찰 시

- **D11 sim-real co-training 보정 경로 deferred** — 근거 TacCoRL(2606.11743). D11 v1 swappable sensor head + common token format 스펙에 "simulation-based tactile co-training(시뮬레이션 RL + sim-real transfer로 per-finger tactile encoder 보정, 실세계 대규모 수집 없이)"을 deferred 보정 경로로 추가 제안. 트리거 — 새 촉각 하드웨어 도입 시 실세계 데이터 수집 비용이 swappable head 교체 일정을 지연시킬 때

- **D8 geometry alignment 근거 보강** — 근거 GEAR-VLA(2606.08530). D8 v1 geometry-grounded multi-view encoder 스펙에 "misaligned 3D features가 VLA 일반화 실패의 핵심 원인임을 독립 진단한 GEAR-VLA 결과"를 설계 근거로 인용 추가 제안. 기하학 정렬 우선순위를 정당화하는 외부 독립 증거 확보

### Anti-topics

- **경계 유지** — HiMem-WAM(2606.10363, 장기 기억 게이팅 WAM)·PaCo-VLA(2606.00515, 수동성 컴플라이언스 prior)·FACTR 2(2606.12406, 외부 힘 추정)가 각각 "P5 세계 모델 기억 구조", "P3 System0 안정화 영역", "팔 관절 토크 추정 — D11 per-finger 귀속 아님" 경계로 자연 탈락; 추가 경계 명확화 불필요
