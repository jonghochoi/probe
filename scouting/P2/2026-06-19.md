## 🥇 논문 1 — 우선순위 ★★★

**Geometric Action Model for Robot Policy Learning**
[arXiv:2606.17046](https://arxiv.org/abs/2606.17046) · Jisang Han, Seonghu Jeon, Jaewoo Jung, René Zurbrügg et al. · source: citation-graph (VGGT 인용) + curated-list (awesome-vla-wam)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **문제** — 기존 VLA 및 세계-액션 모델(WAM)이 2D 이미지 프레임 또는 2D 파생 잠재 공간에서 작동; 접촉 집약적 조작에 필요한 3D 기하학이 암묵적으로만 처리
- **GAM(Geometric Action Model) 핵심 설계**
  - **GFM 중간 레이어 분할(split)** — 사전학습된 기하학 파운데이션 모델(GFM, VGGT 계열)을 중간 레이어에서 분할: 앞쪽 블록이 관측 인코더, 분할 지점에 삽입된 인과 미래 예측기(causal future predictor)가 언어·고유감각·액션 이력 조건으로 미래 잠재 토큰 예측, 나머지 블록이 특징 전파 및 액션 디코딩
  - **단일 백본 이중 출력** — 동일 GFM 백본이 미래 기하학과 액션을 동시 생성; 아키텍처 변형 최소화로 기하학 선험 지식(geometric prior) 보존
  - **언어 조건부 시간적 세계 모델링** — GFM의 풍부한 기하학 공간 표현을 그대로 활용하면서 언어·액션 조건부 시간 추론 능력 추가
- **진정으로 새로운 점** — VGGT 스타일 GFM을 관측 인코더, 시간 예측기, 액션 디코더의 단일 공유 기반으로 재활용하는 설계; 기존 연구가 기하학 특징을 보조 손실이나 별도 브랜치로 주입했다면 GAM은 GFM 자체를 정책의 척추(spine)로 삼음
- **결과** — 시뮬레이션 + 실제 로봇 조작 벤치마크 전반에서 파운데이션-모델 규모 기준선 대비 더 정확하고 강건하며 빠르고 가벼움을 실증

### (c) 시사점

- **D8 관측 인코더를 GFM 앞쪽 블록으로 구현 가능** — VGGT 계열 GFM을 완전 실행하지 않고 분할 전 블록만 관측 인코더로 사용; 기하학적으로 정렬된 다중 카메라 임베딩을 추가 모듈 없이 확보하는 경량 경로 제시
- **D9 기하학 선험 지식이 동역학 인식 표현으로 이어짐** — 기하학 사전학습 → 시간적 미래 예측 조합이 정적 이미지 인코더보다 풍부한 액션-인식 특징을 제공함을 실증; 기하학 선험과 동역학 인식이 동일 아키텍처 내에서 상호 강화됨
- **단일 백본 효율** — 관측 인코더·시간 예측기·액션 디코더를 별도로 설계할 필요 없이 하나의 분할된 GFM으로 통합; 추론 비용과 학습 복잡도 감소

### (d) 먼저 확인할 점

- **GFM 분할 지점 민감도** — 어떤 레이어에서 분할하는지에 따라 관측 인코더 품질과 액션 디코딩 품질이 변화; 최적 분할 지점 선택 기준이 초록에 미명시
- **다중 카메라 규모 미명시** — 실험에서 사용한 카메라 구성(손목·전방·이고센트릭 등 몇 개) 미명시; 10개 손가락 근접 뷰 추가 시 GFM 토큰 수 급증 여부 확인 필요
- **코드 공개 미확인** — 초록 내 저장소 링크 미언급; GFM 분할 구현 세부 사항 재현 전 코드 공개 여부 확인 권장

## 🥈 논문 2 — 우선순위 ★★

**TactSpace: Learning a Physics-enriched Shared Latent Space for Tactile Sim-to-Real Transfer**
[arXiv:2606.18959](https://arxiv.org/abs/2606.18959) · Arunim Joarder, Arjun Bhardwaj, René Zurbrügg, Mayank Mittal et al. · source: keyword-sweep (tactile+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11)

### (b) 핵심 기여

- **문제** — 현재 시뮬레이터들이 촉각 센서의 복잡한 변형·변환 역학을 충실히 모델링하지 못함; 원시 신호(raw signal) 시뮬레이션 없이도 관련 접촉 정보를 보존하는 표현이 필요
- **TactSpace 핵심 설계**
  - **모달리티별 전용 인코더** — 시뮬레이션 관통 깊이(penetration depth)와 실세계 정전용량(capacitance) 등 이질적 촉각 입력 유형마다 전용 인코더로 처리 후 공통 임베딩 공간에 투영
  - **자기·교차 재구성 목표 + 대조 정렬** — 모달리티 불변(modality-invariant)하면서도 정보 풍부한 표현 학습; 물리적으로 유사하지 않은 신호 표현 사이에서도 접촉 의미론(contact semantics) 보존
  - **멀티-물리 시뮬레이션 모달리티 추가** — 단일 시뮬 신호 대비 다중 물리 시뮬 모달리티 결합 시 더 풍부한 임베딩 형성
- **진정으로 새로운 점** — 원시 신호 시뮬레이션 정확도에 의존하지 않고 공통 잠재 공간 정렬만으로 0-shot 시뮬레이션→실세계 이전 달성; 기존 촉각 sim-to-real 연구가 도메인 랜덤화나 특정 센서 모델에 의존했다면 TactSpace는 모달리티 독립 잠재 정렬로 일반화
- **결과** — 시뮬레이션 단독 학습 후 실제 센서 측정값에 0-shot 이전 실증; 힘 예측 오류 16.7% 감소, 형상 재구성 오류 45.8% 감소; Isaac Lab 기반 Warp 촉각 시뮬레이션 구현체 공개

### (c) 시사점

- **swappable sensor head 설계의 구체 경로 제시** — 모달리티별 전용 인코더 → 공통 잠재 공간 정렬 구조가 새 촉각 하드웨어 도입 시 전용 인코더만 교체하면 공통 공간 재사용 가능; 하드웨어 종속성 없는 공통 토큰 포맷 설계의 직접 참조 선례
- **0-shot sim-to-real 이전 실증** — 새 촉각 센서 타입에 대한 실데이터 수집 없이 시뮬레이션만으로 실세계 이전 가능성을 처음 정량화; 초기 D11 인코더 학습에 실데이터 의존성 최소화 경로
- **Isaac Lab Warp 시뮬레이션 공개** — 효율적인 촉각 데이터 생성 인프라 확보; 다지 손 10개 손가락 규모 학습 시 시뮬 데이터 부족 문제 해소 가능

### (d) 먼저 확인할 점

- **단순 기하학 태스크 한정 평가** — indenter 형상 식별·힘 예측·형상 재구성 등 단순 오프라인 태스크만 평가; 실제 다지 조작 정책에서 sim-to-real 이전 품질 확인 필요
- **다지 손 10개 손가락 규모 미검증** — 현재 평가는 단일 접촉 지점 위주; 10개 손가락 동시 접촉에서 공통 잠재 공간 표현 충분성 확인 필요
- **접촉 이진 분류(contact-binary)·슬립(slip) 보조 목표 미포함** — 힘·형상 예측에 집중한 표현; 슬립 검출 등 per-finger 동적 접촉 이벤트 포착 능력 추가 확인 권장

## 🥉 논문 3 — 우선순위 ★

**Zero-Shot Long-Horizon Dexterous Manipulation via Multi-View 3D-Grounded VLM Reasoning**
[arXiv:2606.19340](https://arxiv.org/abs/2606.19340) · Jisoo Kim, Sangwon Baik et al. · source: keyword-sweep (multi-view+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제** — 단일 뷰 RGB-D 기반 VLA 기준선이 장거리 3D 접지 오류·미인식 물체 조작·도구 사용에서 실패; 언어-조건부 3D 태스크 계획을 교육 없이 실행 가능한 형태로 변환하는 체계 부재
- **프레임워크 설계**
  - **VLM 기반 2D 키포인트 생성** — 보정된 다중뷰 RGB 이미지에서 VLM으로 기준 프레임 접지 + 프리미티브 수준 2D 키포인트 추출
  - **다중뷰 3D 리프팅** — 뷰별 VLM 접지의 삼각측량(triangulation)과 기준뷰 레이 투표(reference-view ray voting)를 결합해 기하학적으로 일관된 후보 탐색; 인접 뷰 간 교차 검증
  - **다지 실행** — 리프팅된 3D 파지 키포인트 → 태스크 조건부 파지 어포던스 영역 확장 → 팔-손 동작 생성기로 실행 가능한 파지-동작 쌍 생성
  - **폐쇄 루프 재계획** — 상태 검증 후 재계획으로 장거리 조작 연속 실행
- **진정으로 새로운 점** — 훈련 없이(zero-shot) 교정된 다중뷰 카메라만으로 언어 지시를 3D 실행 계획으로 변환하는 완전 파이프라인; 삼각측량 + 레이 투표 조합이 단일 뷰보다 기하학 일관성 향상을 실세계 실험으로 입증
- **결과** — 단일 뷰 RGB-D 접지 및 파인튜닝 VLA 기준선 대비 3D 접지 정밀도·실행 신뢰성 모두 향상; 미인식 물체·도구 사용 태스크에서 0-shot 실행 실증

### (c) 시사점

- **다중 카메라 기하학 정렬의 실용 파이프라인 참조** — 삼각측량 + 레이 투표 조합이 센서 없이 순수 교정된 다중뷰 RGB만으로 기하학 일관성 확보; 저비용 다중 카메라 설치만으로도 3D 공간 등록 품질이 크게 향상됨을 실증
- **다지 손 파지 실행 통합 확인** — 3D 리프팅 결과가 팔-손 통합 동작 생성으로 직결; 다중 카메라 관측 인코더 → 다지 손 실행까지 전체 경로의 현실적 참조
- **엔드투엔드 vs. 모듈식 설계 비교 근거** — 모듈형 VLM+기하학+실행 파이프라인이 파인튜닝 VLA 대비 미인식 물체에서 우월함을 보임; 관측 인코더 표현 품질이 태스크 일반화에 미치는 영향 평가 참조 데이터

### (d) 먼저 확인할 점

- **엔드투엔드 정책 미포함** — 모듈식 파이프라인이 실시간 연속 제어 루프로 전환 가능한지 미검증; 접촉 집약적 힘 제어 태스크에서의 반응 속도 한계 존재
- **교정 비용** — 다중뷰 카메라 교정(calibration) + 레이 투표 기준뷰 설정이 새 환경마다 필요; 동적 카메라 배치 시 자동 재교정 없음
- **다지 손 실험 규모 미명시** — 초록에 구체적 손가락 수·파지 복잡도 미명시; 10개 손가락 동시 접촉 수준의 복잡 인핸드 조작 지원 여부 본문 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**PAIWorld: A 3D-Consistent World Foundation Model for Robotic Manipulation**
[arXiv:2606.18375](https://arxiv.org/abs/2606.18375) · Yuhang Huang, Xuan Lv, Junyan Xu, Zhiyuan Yu et al. · adjacent field: 세계 파운데이션 모델 (P5) → 기하학 인식 다중뷰 어텐션 설계의 P2 D8 함의

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제** — 기존 다중뷰 세계 모델이 뷰 토큰을 단순 연결(concat)해 크로스-뷰 물체 이탈(drift)·깊이 불일치·텍스처 정렬 오류 발생; 명시적 뷰 간 소통 메커니즘과 3D 기하학 선험 지식 부재가 원인
- **PAIWorld 세 핵심 컴포넌트**
  - **기하학-인식 크로스-뷰 어텐션(Geometry-Aware Cross-View Attention)** — 뷰 간 명시적 경로를 통해 뷰 간 기하학 정합 정보 전파
  - **기하학적 회전 위치 인코딩(Geometric RoPE)** — 카메라 레이 방향 + 외부 파라미터(extrinsic pose)를 어텐션 메커니즘에 직접 인코딩
  - **잠재 3D-REPA** — 동결된(frozen) 3D 파운데이션 모델로부터 3D-인식 특징을 잠재 공간에 증류(distillation)
- **진정으로 새로운 점** — 세계 모델에서 뷰 간 기하학 일관성 달성을 위해 세 가지 상호보완 컴포넌트를 동시 적용; WorldArena 리더보드 1위, AgiBot-Challenge2026 2위
- **결과** — 다중뷰 3D 일관성 기준 SOTA; 모델 기반 계획·세계-액션 모델·다중뷰 정책 사후 학습(post-training) 다운스트림 활용 실증

### (c) 시사점

- **뷰 간 기하학 어텐션 설계의 대규모 실증** — 단순 뷰 토큰 연결 대비 기하학-인식 크로스-뷰 어텐션이 다중 카메라 표현 품질을 결정적으로 향상시킴을 SOTA 수치로 확인; D8 다중 카메라 공간 임베딩 설계의 어텐션 마스킹·위치 인코딩 설계 참조 근거
- **Geometric RoPE의 P2 관측 인코더 적용 가능성** — 카메라 레이 방향 + 외부 파라미터를 위치 인코딩으로 흡수하는 패턴이 세계 모델에서 관측 인코더로 이전 가능; 추가 기하학 모듈 없이 카메라 정보를 토큰 위치 인코딩에 반영하는 경량 설계 방향
- **3D 기하학 증류의 관측 인코더 초기화 경로** — 3D-REPA가 동결된 3D FM으로부터 기하학 표현을 잠재 공간에 이전; eVGGT 계열 geometry-distilled 관측 인코더 설계와 직접 연결되는 선행 연구

### (d) 먼저 확인할 점

- **P5 세계 모델 → P2 관측 인코더 직접 이전 한계** — PAIWorld의 세 컴포넌트가 세계 모델 미래 예측 품질 최적화 맥락에서 설계됨; P2 관측 인코더에 직접 이식 시 태스크 목표가 달라 재해석 필요
- **촉각·힘·고유감각 모달리티 부재** — 순수 시각 다중뷰 세계 모델; 이질 모달리티 이질 퓨전(D10/D11)으로의 확장은 논문 범위 밖
- **다운스트림 정책 실험 규모 미공개** — 다중뷰 정책 사후 학습 응용이 어떤 태스크·성공률로 검증됐는지 초록에 미명시
