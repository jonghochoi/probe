## 🥇 논문 1 — 우선순위 ★★★

**NoContactNoWorries: Estimating Contact through Vision and Proprioception for In-Hand Dexterous Manipulation**
[arXiv:2606.24450](https://arxiv.org/abs/2606.24450) · Soham Patil, Avirup Das, Sourabh Bhosale, Spandan Roy · source: keyword-sweep (proprioception+force+fusion)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10) [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **문제 재정의** — 전용 촉각 하드웨어(비용·취성·통합 복잡도)를 우회하는 비전+고유 수용(proprioception) 기반 바이너리 접촉 추정 프레임워크 제안; 바이너리 접촉 감지에 한정해 하드웨어 없는 스케일러블 대안 주장
- **NoContactNoWorries 아키텍처** — RGB-D 비전 + 로봇 관절 상태(joint states)를 트랜스포머 기반 멀티모달 프레임워크로 융합; 결과 신호를 pseudo-tactile 대체재로 활용
- **실물 검증 범위** — 단일 접촉 예측 모델을 다수 객체에 학습 후 인핸드 물체 재배향(in-hand object reorientation) 강화학습 정책의 접촉 보상으로 공급; 시뮬레이션 + 실물 로봇 양쪽 검증; 새로운 객체에 대한 일반화 실증
- **신규성 핵심** — 전용 촉각 센서 없이 비전+관절 상태 퓨전만으로 바이너리 pseudo-tactile 신호 생성 후 RL 다운스트림 태스크에서 유효성 최초 검증

### (c) 시사점

- **하드웨어-프리 접촉 감지 경로 확보** — 비전+고유 수용 퓨전만으로 바이너리 접촉 신호 생성; 촉각 센서 없는 플랫폼에서 접촉 인식 즉시 활용 가능
- **이질 모달리티 퓨전의 간소화 경로 실증** — RGB-D + 관절 상태의 이질 신호를 단일 트랜스포머 퓨전으로 통합; 비대칭 멀티모달 퓨전의 실물 타당성 직접 확인
- **현 접촉 추정 설계의 baseline 확보** — per-finger 바이너리 접촉 보조 목표 설계에 대해, 순수 비전+고유 수용 기반이 달성하는 수준이 명시적 촉각 센서 기반 대비 어느 정도 차이인지 비교 기준선 역할 가능

### (d) 먼저 확인할 점

- **바이너리에 한정** — 접촉 깊이·슬립·힘 크기 없는 이진 신호만; 섬세한 파지나 슬립 제어에서 충분성 별도 검증 필요
- **손 하드웨어 미명시** — 어떤 다지 손에서 실물 검증했는지 초록 미명시; Allegro·LEAP 등 다지 손 일반화 여부 본문 확인 권장
- **관절 수 의존성** — 관절 상태만으로 접촉을 추정하므로 관절 수가 적은 플랫폼에서 성능 저하 위험; per-finger 고유 수용 결합 시 세부 설계 검토 필요

## 🥈 논문 2 — 우선순위 ★★

**UniviewVLA: A Unified Multiview Vision-Language-Action Model with World Modeling**
[arXiv:2606.21501](https://arxiv.org/abs/2606.21501) · Tao Xu, Runhao Zhang, Zhijian Huang et al. · source: keyword-sweep (multi-view+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **문제 설정** — 추가 물리 카메라 없이, 명시적 3D 재건 비용 없이 폐색(occlusion) 해소를 위한 멀티뷰 정보를 표준 2카메라(agent-view + wrist-view)에서 추론하는 통합 프레임워크
- **UniviewVLA 3요소**:
  - **월드 모델 기반 멀티뷰 future-view 생성** — 학습된 세계 모델이 현재 관측으로부터 폐색 정보를 포함하는 가상 멀티뷰 미래 장면 합성; 명시적 기하학 정합 없이 암묵적 멀티뷰 통합
  - **Motion-Informative Token Compression** — 생성된 뷰를 625 토큰 → 16 토큰으로 압축; 뷰당 레이턴시 6–7초 → 0.2–0.3초로 단축
  - **Action-Entropy View Selection** — 추론 단계별 가장 액션-정보적인 뷰를 무학습(training-free) 동적 선택
- **실험 결과** — LIBERO 95.8%, CALVIN ABCD→D 4.60; 폐색 집중 커스텀 태스크 40.0% → 73.3% 향상; 실물 로봇 평균 성공률 +33.4 포인트

### (c) 시사점

- **명시적 기하학 정합 없이 멀티뷰 효과 달성 가능성 확인** — 세계 모델 생성 뷰를 통해 암묵적으로 멀티뷰 정보 통합; VGGT식 명시적 기하학 정합의 대안 경로 실증; 추가 카메라 배치 없이 폐색 해소
- **테스트 시 카메라 파리티 제거** — 훈련-추론 간 카메라 수 일치 요구사항 해소; 배포 유연성 향상
- **세계 모델-인코더 연결 설계 참조** — 관측 인코더 앞단에 세계 모델 생성 뷰를 주입하는 구조가, 기하학 정합 경로와 별도로 폐색 문제를 해결하는 실용적 선택지 제시

### (d) 먼저 확인할 점

- **암묵적 통합의 신뢰도 한계** — 명시적 기하학 정합 없이 생성 뷰에 의존; 생성 품질이 낮은 장면(반사·투명 물체 등)에서 신뢰성 저하 위험
- **월드 모델 추가 비용** — 별도 세계 모델 학습 및 병렬 실행; 인코더 내재화 경로(DynaFLIP·eVGGT)와 비용 대비 효과 비교 필요
- **폐색 없는 시나리오의 이득 제한** — 표준 LIBERO 등 폐색-프리 벤치마크에서 성능 우위가 제한적; 비폐색 일반 다지 조작에서의 추가 효용 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Dexterity-BEV: Aligning 3D World and Actions for Generalizable Robot Policies Learning**
[arXiv:2606.02274](https://arxiv.org/abs/2606.02274) · Huayi Zhou, Wei Gao, Dekun Lu, Ruiji Liu et al. · source: keyword-sweep (multi-view+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D8](https://img.shields.io/badge/D8-d97706.svg)](#ref-D8)

### (b) 핵심 기여

- **2D VLM 한계 극복을 위한 픽셀 단위 3D 표현**:
  - **Aligned Vertex Map + Vertex Spectrum** — 카메라 캘리브레이션과 선택적 depth를 활용해 2D RGB 입력을 픽셀 단위 3D 좌표로 격상; VLM 2D 일반화와 3D 공간 인식 결합
  - **정규 버즈아이뷰(BEV) 정렬 프레임** — 각 카메라 뷰의 픽셀별 3D 정보와 로봇 액션을 공유 좌표계(BEV)로 투영; 카메라 포즈 변화에 무관한 view-invariant 표현 생성
  - **시간 정렬 스킴** — 다양한 로봇·운영자·데이터셋의 궤적을 정규 시간 축으로 정렬; 이종 데이터 통합 학습 지원
- pretrained checkpoint + 소스 코드 + 데이터 처리 파이프라인 공개 (hnuzhy.github.io/projects/Dex-BEV)

### (c) 시사점

- **카메라-무관 3D 공간 정렬 방법론 확보** — BEV 정규 프레임이 다중 카메라·다중 embodiment 설정에서 입출력 공간 정렬을 달성; 다중 카메라 공간 정합 구현의 실용적 참조 가능
- **공개 코드·데이터·체크포인트** — 즉시 기준선으로 활용 가능; 기하학 정합(VGGT/eVGGT 스타일) 구현 후 BEV 정렬 기준선 대비 정량 비교 가능
- **Depth 선택 옵션** — depth 없이도 vertex map만으로 동작 가능; 깊이 센서 없는 환경에서도 3D 정렬 적용 가능성 확인

### (d) 먼저 확인할 점

- **BEV 투영 근거리 왜곡** — 손목 근거리 조작에서 BEV 투영이 깊이 해상도를 손실할 수 있음; 세밀한 손-물체 접촉 영역 표현 품질 확인 권장
- **캘리브레이션 의존성** — 카메라 캘리브레이션 정밀도가 vertex map 품질에 직결; 현장 캘리브레이션 오차 강건성 평가 필요
- **다지 손 특화 실험 미확인** — 로봇 조작 일반에 대한 검증; 손가락 단위 접촉 집약적 태스크에서의 성능 별도 확인 권장

## 🌱 논문 4 — 인접 분야 픽

**MotionVLA: Injecting Geometric Motion into Vision-Language-Action Model**
[arXiv:2606.08288](https://arxiv.org/abs/2606.08288) · Shanglin Yuan, Weiheng Zhao, Xianda Guo, Wei Sui, Li Yu, Wenyu Liu · adjacent field: 비디오 동작 표현(video motion encoding) → 동역학-인식 관측 인코딩의 P2 함의 · source: keyword-sweep (multi-view+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **패러다임 전환 제안** — VLA에 "과거 프레임을 기억"하는 대신 "프레임을 연결하는 동작(motion)을 기억"하는 motion-history interface 제안; 모션-비일관적 증거 주입이 기하학 드리프트·불안정 액션 유발한다는 분석
- **Trajectory-field 토큰** — 짧은 과거 비디오 윈도우 → 시간-연속 궤적 필드(trajectory field)로 인코딩 → 컴팩트 모션-일관적 히스토리 토큰 생성; 현재 시각 토큰이 이 모션 표현을 query하여 태스크 관련 동작 정보 검색
- **Trajectory-grounded supervision** — 궤적 필드 학습에 명시적 감독 제공
- 시뮬레이션 벤치마크 + 예비 실물 로봇 롤아웃에서 장기 조작 성능 향상 및 더 부드러운 실행 경로 확인

### (c) 시사점

- **동역학 인식의 가벼운 대안 경로** — DynaFLIP(트라이모달 동역학 사전학습)과 달리 과거 비디오 히스토리에서 모션 일관성을 추출하는 방식; 대규모 동역학 사전학습 없이 관측 인코딩에 동역학 신호를 주입하는 가벼운 경로 제시
- **관측 시퀀스 압축 효율** — 히스토리를 trajectory-field 토큰으로 압축; 시간-연속 동역학 표현의 효율적 병합 방안 참고 가능

### (d) 먼저 확인할 점

- **비디오 모션 추정 품질 의존** — 입력 모션 추정 정확도에 결과가 직결; 빠른 동작·조명 변화 시 히스토리 품질 저하 위험
- **예비 실물 결과 단계** — 실물 검증이 초기 단계; 접촉 집약적 다지 조작에서의 궤적 일관성 효과 별도 확인 필요
- **장기 누적 오류** — 궤적 필드의 시간 연속성이 장기 조작에서 누적 오류로 이어질 가능성; 히스토리 윈도우 길이 한계 확인 권장
