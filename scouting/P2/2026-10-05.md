## 🥇 논문 1

**FINGR: Learning Dexterous Hand Control for Real-World Rubik's Cube Solving**
[arXiv:2609.33973](https://arxiv.org/abs/2609.33973) · Yutong Liang, Quanquan Peng, Matthew Kim, Xiaolong Wang · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — P1 2026-10-01 판정 유지

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 손끝 기준 기하와 미래 토큰으로 큐브 층 회전 99.0%
- **문제** — 단일 다지 손으로 큐브 층을 연속 회전시키는 지속적 접촉 집약 제어
  - 일부 손가락은 큐브를 지지하고 다른 손가락은 층을 밀고 접촉을 풀고 복귀하는 역할 분담 필요
  - 한 번의 밀기 성공만으로는 부족, 다음 동작을 받쳐 줄 손-큐브 배치까지 유지 필요
- **기존 한계** — 큐브는 전역으로, 손가락은 따로 인코딩하는 방식이 손가락과 표면 사이 상대 관계를 정책의 추론에 맡김
  - 행동 모방만으로는 관측 인코더가 접촉과 운동이 어떻게 전개될지 학습하도록 명시 지도되지 않음
- **핵심 방법** — 손끝 상대 기하와 다중 시간 척도 미래 예측을 결합한 관측 표현으로 플로우 정책을 조건화
  - 큐브 점을 다섯 손끝 원점 기준으로 옮겨 손가락별 상대 위치 인코더와 대칭 집계로 손가락별 기하 특징 산출, 각 손가락 상태 토큰에 직접 가산
  - 세 시간 지평의 학습 미래 토큰이 관측 토큰과 트랜스포머 인코더에서 상호작용, 접촉력 변화·목표 층 진행도·손가락 관절 변위를 예측
  - 미래 토큰 예측은 학습 시 보조 지도, 배포 시에는 인코딩된 토큰이 액션 생성을 직접 조건화
- **차별점** — 큐브를 한 번 전역 인코딩하지 않고 손끝마다 상대 좌표로 표현, 점 순서에 불변
  - 예측 목표를 접촉·층 진행·손가락 운동이라는 물리 사건에 직접 연결
- **핵심 기여** — 연속 층 회전 기반 실물 큐브 풀이 시스템과 두 표현 요소
  - 손끝에 정렬된 순열 불변 기하 인코딩
  - 접촉·층 진행·손가락 운동을 함께 지도하는 다중 지평 미래 토큰 예측
  - 실물 방법당 300회 층 회전 시도에서 국소 기하가 79.7%를 92.7%로, 미래 토큰 예측이 99.0%로 상승
  - 섞은 2×2×2 큐브 10개 전부 풀이, 집기·재파지·배치·복귀 포함 전체 시스템 평균 약 137초
- **가치** — 손가락 단위 상대 기하와 접촉 예측 지도가 장기 접촉 집약 다지 조작 성공률을 실물에서 끌어올린다는 근거 제시

### (c) 시사점

- 손가락 단위 기하 결합이 실물 성공률을 끌어올림
- 손끝별 상대 좌표 특징을 각 손가락 상태 토큰에 더하는 구조 — 손가락 귀속을 유지한 관측 구성의 실물 정량 사례
- 미래 접촉력 변화를 보조 지도로 쓰는 방식 — 촉각 토큰 학습 신호 설계 참고
- 기본 플로우 정책 위에 인코더 쪽 변경으로 얹는 구성 — 도입 비용 낮음

### (d) 먼저 확인할 점

- 코드 저장소 서술 없음, 프로젝트 웹사이트만 확인
- 평가 대상이 큐브 한 종류 — 다른 물체로의 일반화는 별도 확인 필요
- 미래 토큰 지도에 쓰는 접촉력 변화 신호의 센서 출처는 초록상 서술 없음 — 본문 확인 필요

## 🥈 논문 2

**Self-Supervised Anchoring of Fingertip Sensing to Proprioception and Proactive Actions for Robot Imitation Learning**
[arXiv:2609.29822](https://arxiv.org/abs/2609.29822) · Tomohiro Motoda, Masaki Murooka, Keisuke Shirai, Hanbit Oh, Ryoichi Nakajo 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R3 · N3 · M2 · Real2 · Repro1 — arXiv comment "Project page is available at https://tomohiromotoda.github.io/nia.propra/"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 논문 요지

- 고유수용감각 앵커링으로 손끝 센서 표현 사전학습
- **문제** — 손끝 근접·촉각 센서는 서로 다른 조작 단계에서만 유효해 적은 시연으로는 활용이 어려움
  - 근접 센서는 접촉 전, 촉각 센서는 접촉 후에 정보를 줌
  - 접촉 전 상태 인식이 이후 접촉과 파지 결과를 좌우
- **기존 한계** — 센서를 단순 결합하면 일부 과제에서 센서 경쟁 효과로 정책이 나빠지고 비전 단독 정책보다 낮아질 수 있음
  - 모달리티를 직접 정렬하는 표현 학습은 한 모달리티가 무정보인 구간에서 시간 동시 발생이 약하거나 모호한 지도 신호
  - 이미지 앵커 방식은 단일 시점 시각 관측에 의존
- **핵심 방법** — PROPRA, 센서별 손끝 이력을 고유수용감각과 액션 청크에 독립적으로 정렬하는 대조 사전학습
  - 과거 손끝 이력, 현재 고유수용감각, 가까운 미래 액션 청크를 시간적으로 연결
  - 사전학습된 센서 인코더를 모방 학습 정책에 결합
- **차별점** — 이미지 대신 조작 내내 쓸 수 있는 고유수용감각과 액션을 공통 기준으로 사용
  - 각 센서가 유효한 구간에서만 해당 상태와 운동에 연결, 무정보 구간 정렬을 강요하지 않음
- **핵심 기여** — 센싱 시스템, 문제 정식화, 실물 비교 결과
  - 접촉 전 근접 센싱과 접촉 후 촉각 센싱을 결합한 손끝 센싱 시스템, 실물 파지 실험에서 상보성 확인
  - 단계별로 유효 구간이 다른 센서의 표현 학습 문제 정식화와 PROPRA 제안
  - 실물 과제에서 비전 단독 정책과 이미지 앵커 사전학습 대비 평균 성공률 향상, 정책 실행 기록에서도 접촉 전 정보 보존
- **가치** — 단계 의존 센서를 하나의 감각운동 기준에 묶는 사전학습 경로 제시

### (c) 시사점

- 단순 센서 추가가 비전 단독보다 나쁠 수 있음을 측정
- 손끝 센서를 서로 정렬하지 않고 감각운동 기준에 각각 묶는 사전학습 — 손끝 단위 센서 결합 설계 참고
- 센서 추가가 항상 이득이 아님을 비교로 확인 — 연결 방식 대비 비용의 근거 자료
- 앵커가 고유수용감각과 액션이라 센서별 인코더 교체 가능성 — 센서 헤드 교체 설계 참고

### (d) 먼저 확인할 점

- 코드 저장소 서술 없음, 프로젝트 페이지만 확인
- 초록에 성공률 수치 없음 — 과제 수와 시행 횟수 본문 확인 필요
- 근접·촉각 겸용 손끝 하드웨어 전제 — 다른 손에서의 재현 여부 별도 확인 필요

## 🥉 논문 3

**Tactile-JEPA: Topology-Aware Self-Supervised Representation Learning for Distributed Tactile Sensors**
[arXiv:2609.24385](https://arxiv.org/abs/2609.24385) · Elizaveta Kovtun, Matvey Konovalov, Andrey Sakhovskiy, Semen Budennyy · arXiv preprint · source: citation-graph · 코드 공개

**점수 9/15** · R3 · N2 · M2 · Real0 · Repro2 — 초록 "Code is available at https://github.com/E-Kovtun/tactile"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 센서 연결 그래프 위 마스킹으로 촉각 JEPA 사전학습
- **문제** — 촉각 인코더가 원시 잡음 신호로 처음부터 학습돼 표현력이 제한됨
  - VLA는 사전학습 백본의 비전·언어 표현을 물려받지만 촉각에는 대응물이 없음
- **기존 한계** — 촉각 자기지도 학습이 비전 기반 촉각 센서에 집중, 분산 전자 피부는 거의 다뤄지지 않음
  - 전자 피부 출력을 이미지처럼 다루는 방식은 센서 표면의 공간 구조를 반영하지 못함
  - 센서 요소가 희소하고 불규칙하게 배치돼 시각 자기지도 방법의 직접 재사용이 비효율적
- **핵심 방법** — I-JEPA 방식으로 가려진 센서 요소의 임베딩을 보이는 요소로부터 예측
  - 마스크를 픽셀 격자가 아닌 센서 연결 그래프 위에서 샘플링
  - 국소 마스크와 전역 마스크 두 척도를 사용해 지역 접촉 세부와 표면 전체 상태를 함께 포착
- **차별점** — 마스크 샘플링 공간을 센서 연결 그래프로 바꾸고 두 척도를 혼합
  - 그래프 마스크가 이미지형 블록 마스크보다 낫고, 척도가 국소성을 조절해 국소 또는 전역 마스크가 특정 하류 과제에 유리
- **핵심 기여** — 방법과 비교 결과와 코드
  - 자기장·압저항 센서, 여러 로봇 형태, 단일·쌍 센서 구성의 세 데이터셋에서 기존 최고 대비 힘 추정 오차 6.3%, 인핸드 방향 오차 20.8% 감소
  - 힘·자세 추정, 물체·동작 분류, 촉각 조건 정책 학습에 걸친 일관된 향상
  - 마스크 형태와 척도에 대한 ablation
  - 코드 저장소 공개
- **가치** — 촉각 이득이 인코더 사전학습 품질에 크게 좌우됨을 보이고 전자 피부용 사전학습 기준점 제공

### (c) 시사점

- 토폴로지 인식 촉각 토큰 사전학습의 공개 기준점
- 센서 배치 그래프를 표현에 반영 — 손가락·손바닥에 분산된 센서 토큰 구성에 쓸 사전학습 후보
- 코드 공개 — 바로 재현 가능, 도입 비용 낮음
- 자기장·압저항 등 센서 종류와 로봇 형태에 걸친 적용 — 센서 교체 대응 설계 참고

### (d) 먼저 확인할 점

- 실물 로봇 결과 없음, 기존 데이터셋 평가 중심
- 정책 학습 이득의 수치는 초록에 없음 — 본문 확인 필요
- 비전 기반 촉각 센서에 적용되는지는 서술 범위 밖 — 별도 확인 필요
