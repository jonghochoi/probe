**VisTacAlign: Co-Training Dexterous Policies on Tactile Human and Robot Demonstrations**
[arXiv:2609.30959](https://arxiv.org/abs/2609.30959) · Julien Poffet, Matthew Strong, Ankush Dhawan, Baiyu Shi, Shalika Neelaveni 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 11/15** · R3 · N2 · M2 · Real3 · Repro1 — abstract "Project page: https://vis-tac-align.github.io"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 핵심 기여
- 사람 시연의 손·시야·촉각을 로봇 신호 공간에 맞춘 공동학습
- **손 동작** — 장갑 추적 동작을 17자유도 촉각 로봇 손으로 리타게팅, 일회성 손끝 보정 적용
- **시각** — 양안 영상에서 사람 손을 지우고 로봇 손 메시를 합성한 뒤 스테레오 파운데이션 모델을 재실행, 사람 포인트클라우드가 로봇 쪽과 같은 스테레오 오류·가시성을 갖도록 구성
- **촉각** — 정전용량 촉각 장갑을 로봇 손끝 센서의 신호 공간에 정렬, 손가락별 힘 표현 하나로 통일
- 디퓨전 트랜스포머(diffusion transformer)가 포인트클라우드·고유수용감각·손가락별 촉각 토큰을 함께 소비
- 레고 조립·딸기 따기·전동 드릴 작동 3개 실물 과제에서 사람 시연 추가 시 로봇 단독 정책 대비 향상, 어블레이션에서 촉각 입력과 시각 정렬 모두 필요

### (c) 시사점
- 사람 시연을 손가락별 힘 표현 단위로 로봇 데이터와 합치는 경로 확인
- 센서 물리가 달라도 신호 공간 정렬로 한 토큰 형식에 수렴 — 센서 교체에 강한 표현 설계 참고 가능
- 포인트클라우드와 손가락별 촉각 토큰을 한 모델이 소비하는 구조 — 기하 융합과 접촉 융합 결합 사례

### (d) 먼저 확인할 점
- 코드 저장소 서술 없음, 프로젝트 페이지만 확인
- 개선 폭 수치는 초록에 없음 — 본문 확인 필요
- 정렬 대상이 17자유도 촉각 로봇 손과 정전용량 장갑 조합 — 다른 센서 조합 이식 시 정렬 보정 재수행 필요
- 프레임마다 스테레오 파운데이션 모델을 다시 돌리는 합성 단계 — 데이터 준비 비용 요소

## 🥈 논문 2

**Self-Supervised Anchoring of Fingertip Sensing to Proprioception and Proactive Actions for Robot Imitation Learning**
[arXiv:2609.29822](https://arxiv.org/abs/2609.29822) · Tomohiro Motoda, Masaki Murooka, Keisuke Shirai, Hanbit Oh, Ryoichi Nakajo 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M2 · Real2 · Repro1 — arXiv comment "Project page is available at https://tomohiromotoda.github.io/nia.propra/"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 손끝 센서를 고유수용감각·액션에 독립 정렬하는 사전학습
- 압력 촉각 센서와 반사형 근접 센서, 사전학습 센서 인코더를 모방 학습에 결합
- 근접은 접촉 전, 촉각은 접촉 후에 유효한 단계 의존 신호로 구분
- 센서를 단순 추가하면 성능이 일관되게 오르지 않고 비전 단독 정책보다 낮아질 수도 있음을 측정
- PROPRA 사전학습이 손끝 센서별 이력을 고유수용감각·액션 구간에 각각 정렬, 센서-손가락 귀속을 정책 입력까지 유지
- 실물 과제에서 평균 성공률이 비전 단독 정책과 이미지 앵커링 사전학습 베이스라인을 모두 상회, 표현 분석에서 접촉 전 상태 정보 보존 확인

### (c) 시사점
- 센서를 더하면 오히려 손해일 수 있다는 측정과 그 해법
- 앵커를 영상이 아닌 고유수용감각·액션에 두는 설계 — 센서-손가락 귀속을 보존하는 사전학습 방식 참고 가능
- 센서별 독립 정렬 구조 — 센서 추가·교체 시 재학습 범위 축소 가능

### (d) 먼저 확인할 점
- 코드 저장소 서술 없음, 프로젝트 페이지만 확인
- 성공률 수치와 과제 수는 초록에 없음 — 본문 확인 필요
- 센서가 압력 촉각과 근접 2종 한정 — 비전 기반 촉각 센서(Deform Map 등) 이식 여부 별도 확인 필요

## 🥉 논문 3

**VT-Bridge: Bridging Pretrained Foundation VLAs to VTLAs via Lightweight Residual Adaptation**
[arXiv:2609.22606](https://arxiv.org/abs/2609.22606) · Yansong Wu, Tuo Yang, Rongping Zhao, Lingyun Chen, Xiao Chen 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R2 · N2 · M2 · Real3 · Repro1 — P4 2026-10-01 판정 유지, abstract "The project page is available at https://hoxnocha.github.io/vt-bridge-web/"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 사전학습 VLA에 촉각을 잔차 어댑터로 얹는 경량 경로
- 백본 구조 수정 없이 0.98M 파라미터 어댑터와 백본별 가중치로 로봇 실행 주파수에서 액션 보정
- 과제당 비주오택타일 시연 최대 50개로 VLA 미세조정과 어댑터 학습
- π0, π0.5, SmolVLA 3개 백본과 4개 접촉 집약 과제에서 일관된 효과
- 과제 완료율이 VLA 미세조정 단독 11.7%에서 62.9%로 상승

### (c) 시사점
- 촉각 융합을 구조 변경 없이 얹는 저비용 선택지 확보
- 소량 데이터로 촉각 이점 확인 — 도입 비용 낮음
- 융합 위치가 액션 출력단 — 입력 단계 융합과의 성능 차이 비교 가치

### (d) 먼저 확인할 점
- 코드 저장소 서술 없음, 프로젝트 페이지만 확인
- 잔차 보정은 액션 단계 결합 — 손가락별 접촉 귀속 보존 여부는 초록상 서술 없음, 본문 확인 필요
- 비교 대상과 어블레이션 상세는 초록에 없음 — 본문 확인 필요
