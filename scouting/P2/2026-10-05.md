## 🥇 논문 1

**Uni-VLaT: Whole-Body Tactile Adaptation of VLA Policies for Humanoid Loco-Manipulation**
[arXiv:2609.35450](https://arxiv.org/abs/2609.35450) · Zihao Wang, Shutong Liu, Siqi Zheng, Liu Cao, Ruoqu Chen 외 · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — P3 2026-10-01 판정 유지

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 전신 촉각을 사전학습 VLA에 붙이는 예측 보조 학습
- **문제** — 휴머노이드 이동 조작에서 접촉 상태를 비전과 고유수용감각만으로 파악하기 어려움
  - 접촉 부위가 가려지면 비전으로 접촉을 구분하기 어렵고, 촉각 없이는 자세 오차나 하중 변화가 과도하거나 부족한 접촉으로 이어짐
  - 전신 분포 촉각을 사전학습 VLA가 제어에 쓰도록 만드는 방법이 핵심 과제
- **기존 한계** — 촉각을 입력 스트림으로 덧붙이는 방식과 전용 아키텍처 의존 방식
  - 촉각 특징을 단순 결합하면 접촉과 신체 반응, 장면 변화의 연결이 보장되지 않음
  - TACT, WT-UMI, HTD 등 전신 촉각 선행 연구는 전용 정책·계획 구조에 의존해 사전학습 일반 정책의 의미·액션 사전지식을 활용하는 방법이 불분명
  - 예측 지도를 쓰는 선행 연구는 미래 촉각·힘 신호 중심이며 신체 상태·시각과 함께 접촉이 변하는 과정은 다루지 않음
- **핵심 방법** — 촉각을 물리적 앵커로 삼아 촉각 중심 멀티모달 맥락을 만들고 미래 표현을 예측
  - 사전학습 정책 내부에서 시각·언어·고유수용감각·액션 표현과 상호작용한 뒤의 촉각 특징이 촉각 앵커 멀티모달 맥락을 구성
  - 이 맥락에서 세 예측기가 미래 촉각·고유수용감각·시각 표현을 각 잠재 공간에서 추정
  - 모달리티별 표현을 하나의 구분 없는 표현으로 합치지 않고 촉각이 서로 보완하는 관측을 잇도록 설계
- **차별점** — 촉각 입력만 추가하지 않고 촉각 맥락에서 세 모달리티의 미래를 함께 예측
  - 사전학습 VLA를 처음부터 재학습하지 않고 기존 의미·시각·액션 사전지식 위에 촉각을 접지
- **핵심 기여** — 세 가지
  - 촉각 앵커 멀티모달 학습 — 보조 예측 지도로 미래 촉각·고유수용감각·시각 표현 예측
  - 사전학습 VLA의 촉각 적응 전략
  - Unitree G1 실물 5개 과제 평가 — 두 사전학습 VLA 백본과 처음부터 학습 정책 비교, 촉각·예측 구성요소 ablation 포함
  - 실물 5과제 평균 성공률 75%, 촉각 없는 베이스라인 대비 43점, 예측 지도 없는 촉각 입력 베이스라인 대비 7점 우위
  - 두 백본 모두 Table Sweeping 30점 향상, Back-Tap Walking 85–90점 향상
- **가치** — 사전학습 VLA를 전신 물리 상호작용으로 확장하는 촉각 적응 경로 제시

### (c) 시사점

- 촉각 잠재 상태에 예측 지도를 거는 퓨전 설계의 정량 근거
  - 예측 지도 없는 촉각 입력 대비 7점 우위로 결합 방식 자체의 이득 분리 확인
  - 촉각 특징을 사전학습 정책 내부에서 다른 모달리티와 상호작용시킨 뒤 예측에 쓰는 구성 — 접촉 상태 토큰 설계 참고 가능
- 단순 결합이 아닌 상호작용 후 맥락에서 예측하는 구성이 직접 멀티모달 예측 대비 우위
  - 구성별 평균 성공률 80% 대 60%, 사전 단계 촉각만 쓴 구성 55%
- 센서 교체 관점 — 손가락 단위가 아닌 몸 전신 배열 센서라 손 단위 귀속 구조로의 직접 이식은 아님

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음, arXiv comment는 쪽수·그림 수만 기재
- 전신 몸통 촉각 대상이며 손가락 단위 접촉 귀속은 아님 — 다지 손 접촉 토큰으로의 이식 별도 확인 필요
- 과제 5종 규모, Back-Tap Walking 같은 촉각 지시형 과제는 촉각 입력 유무만으로 향상 — 지속 접촉 조절 과제에서의 이득이 핵심 검증 대상
- 저자 인정 한계 — 배열 센서의 잡음·장착 편차 민감, 전신 촉각 시뮬레이션 부족

## 🥈 논문 2

**CableVLA: Simulation-Privileged Global-Local Representation Learning for Cable Routing**
[arXiv:2609.25606](https://arxiv.org/abs/2609.25606) · Zhifei Teng, Bo Feng, Xiang Zou, Jinpeng Xiao, Min Li 외 · arXiv preprint · source: keyword-sweep · 코드 미공개

**점수 7/15** · R2 · N2 · M2 · Real1 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음 (arXiv comment 비어 있음 — API 제한, 초록 기준)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 케이블 위상과 국소 촉각을 시뮬레이션 특권으로 학습
- **문제** — 케이블 배선은 전역 케이블 위상과 변하는 국소 접촉을 함께 다뤄야 하는 과제
  - 잡기·당기기·놓기가 케이블 형상과 장력 분포를 바꿔 이후 동작의 조건이 달라짐
  - 가림 때문에 케이블 구간과 공간 관계가 가려지고, 외부 카메라는 케이블-손가락 접촉면을 잘 보지 못함
  - 하중 전달과 미끄러짐 전이는 시간에 따른 촉각 해석이 필요
- **기존 한계** — VLA를 케이블 과제에 적용한 선행 연구는 위상·촉각 표현 부재
  - DLO-Lab, WireCraft는 시뮬레이션 벤치마크에서 VLA 베이스라인만 평가
  - DLORoute는 VLM 계획과 배선 스킬을 조합
  - 실물 데이터 수집은 비용이 크고 희귀 구성·접촉 전이의 커버리지가 낮음
- **핵심 방법** — 시뮬레이션의 특권 신호로 배포 시 센서 이력만으로 계산되는 표현을 지도
  - TopoHead — 현재·미래 위상 예측과 교사-학생 증류로 특권 시간 교사의 노드 수준 물리 정보를 RGB 전용 학생에게 전달, 인과적 시각 맥락으로 액션 전문가를 조건화
  - TacSense — 프레임 가지와 택셀 가지가 저항 배열 촉각 이력에서 전체 영역 시간 변화와 택셀 국소 동역학을 학습, 시뮬레이션 유래 물리·이벤트 지도 사용
  - 접촉 게이트 힘-촉각 잔차 — 손목 렌치 특징과 촉각 표현이 동결된 위상 조건 부모 정책의 출력을 다음 8개 팔·그리퍼 액션 수준에서 보정
- **차별점** — 전역 위상은 액션 생성을 조건화하고 국소 접촉은 동결 정책 위 잔차로 분리
  - 시뮬레이터 상태 없이 배포 시 인과적 센서 관측만으로 두 표현 계산
- **핵심 기여** — 세 가지
  - CableVLA — 위상 조건 액션 생성과 접촉 게이트 힘-촉각 액션 보정을 결합한 시뮬레이션 특권 전역-국소 VLA 프레임워크
  - TopoHead — 현재·미래 예측과 교사-학생 증류로 특권 물리 정보를 시각 맥락에 이전하는 시간 위상 인코더
  - TacSense — 시뮬레이션 유래 물리·이벤트 지도로 전체 영역·택셀 국소 접촉 동역학을 학습하는 이중 가지 촉각 인코더
  - MuJoCo 핵심 평가 345회, π0.5 시각 베이스라인 62.6%에서 84.9%로 향상
  - 미끄러짐 전이 인식에서 유사 파라미터 CNN-LSTM 베이스라인 우위, 동결 인코더 프로브에서도 유지
- **가치** — 실물 수집 없이 시뮬레이션 특권 지도로 배포 가능한 위상·촉각 표현을 만드는 경로 제시

### (c) 시사점

- 학습된 촉각 표현을 접촉 게이트로 정책 위에 얹는 구조 사례
  - 두 가지 촉각 가지와 손목 렌치를 합친 잔차가 동결 정책의 액션을 보정
  - 시뮬레이션 접촉 이벤트 지도를 배포 가능한 촉각 표현으로 증류하는 방식 — 센서 교체 시 지도 재사용 가능성
- 위상 헤드가 시각 맥락에 주입되는 구성 — 시각 표현에 구조 정보를 앵커링하는 참고 사례
- 센서 구조 면에서 저항 배열 촉각과 손목 렌치 중심, 손가락별 귀속 구조는 아님

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음, arXiv comment 필드 비어 있음
- 주 평가는 MuJoCo, 초록의 실물 비교는 제로샷 전이 검토 수준으로 수치 미제시
- 케이블 배선 단일 과제군 — 다지 손 조작으로의 일반화 별도 확인 필요
- 그리퍼 형태와 손가락 수는 초록상 서술 없음 — 다지 손 적용성 별도 확인 필요
