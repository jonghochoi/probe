**FINGR: Learning Dexterous Hand Control for Real-World Rubik's Cube Solving**

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 지단 상대 기하와 미래 토큰으로 큐브 턴 99.0%
- **문제** — 한 손으로 루빅스 큐브 레이어를 연속해서 돌리는 접촉 집약적 협응
  - 손가락마다 역할이 다름 — 일부는 큐브를 지지, 일부는 레이어를 밀고 접촉을 풀고 복귀
  - 공간 구조 — 움직이는 레이어와 지지면이 손가락 기준 어디에 있느냐가 가용 동작을 결정
  - 시간 구조 — 한 번의 턴 안에서 접촉이 로딩, 밀기, 해제, 복귀로 바뀜
- **기존 한계** — 큐브를 전역으로, 손가락을 따로 인코딩하면 둘의 관계를 정책이 스스로 추론해야 함
  - 행동 모방만으로는 관측 인코더가 접촉과 운동의 전개를 명시적으로 학습하지 못함
  - 비교 대상인 베이스 플로 정책은 전역 점집합 인코딩을 사용
- **핵심 방법** — 큐브 점을 5개 지단 기준 좌표로 옮겨 손가락별 기하 특징을 만들고, 미래 토큰으로 접촉 전개를 감독한 뒤 플로 정책에 조건화
  - 손가락 상대 기하 — 지단 원점 기준 큐브 점 인코더와 대칭 집계, 점 순서와 큐비 인덱싱에 불변이며 결과를 해당 손가락 상태 토큰에 직접 더함
  - 미래 토큰 — 3개 시간 척도, 관측 토큰과 트랜스포머 인코더에서 상호작용하며 접촉력 변화·타깃 레이어 진행·손가락 관절 변위를 예측
  - 배포 시 — 미래 예측은 학습 보조 감독, 인코딩된 토큰이 관절 행동 청크 생성을 직접 조건화
  - 하드웨어 — 7관절 팔과 다지 손, 엄지·중지가 큐브를 유지하고 검지·약지·소지가 학습된 동작 수행
- **차별점** — 손가락별 기하 특징을 해당 손가락의 상태 토큰에 직접 더해 귀속을 유지하고, 미래 감독을 같은 관측 인코더에 공유
- **핵심 기여** — 실물 큐브 풀이 시스템, 지단 정렬 기하 인코딩, 다중 시간 척도 미래 토큰
  - 연속 레이어 턴 기반 실물 큐브 풀이 시스템
  - 실물 레이어 턴 방법당 300회 — 국소 기하로 79.7%에서 92.7%, 미래 토큰 추가로 99.0%
  - 비교 베이스라인 ACT, Diffusion Policy, 베이스 플로 정책
  - 무작위 스크램블 2×2×2 큐브 10개 전부 풀이, 픽업·재파지·배치·복귀 포함 평균 약 137초
- **가치** — 손가락마다 역할이 다른 연속 접촉 과제에서 관측 표현의 구조가 성패를 가른다는 실물 정량 증거

### (c) 시사점

- 손가락별 기하 귀속의 실물 정량 기준점
  - 지단 상대 기하를 손가락 상태 토큰에 더하는 방식은 손가락 귀속 보존의 가벼운 구현 사례
  - 국소 기하 단독 13.0%p 상승, 미래 토큰 추가 6.3%p 상승으로 두 요소의 기여가 분리됨
  - 접촉력 변화 예측은 촉각 토큰 구성 시 보조 감독 헤드 후보

### (d) 먼저 확인할 점

- 단일 손, 마커 부착 2×2×2 큐브, 마커 기반 재구성 — 비마커 관절 물체와 다른 손으로 일반화는 저자도 미검증으로 명시
- 큐브 점은 마커 재구성 입력이라 카메라 기반 다중 뷰 융합과는 다른 문제
- 10회 풀이 규모 — 저자가 더 큰 스크램블 집합 필요를 언급
- 코드는 미공개, 프로젝트 웹사이트만 확인되며 설정은 부록 A 기준

[arXiv:2609.30959](https://arxiv.org/abs/2609.30959) · Julien Poffet, Matthew Strong, Ankush Dhawan, Baiyu Shi, Shalika Neelaveni, Yujia Yuan 외 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 9/15** · R3 · N2 · M2 · Real1 · Repro1 — 초록 "Project page: https://vis-tac-align.github.io"

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ)

### (b) 논문 요지

- 인간 촉각 글러브를 로봇 지단 센서 신호 공간에 정렬
- **문제** — 인간 시연으로 다지 손 정책을 공동 학습하려면 정책이 소비하는 모든 모달리티의 인간-로봇 격차를 닫아야 함
  - 텔레오퍼레이션은 규모 확장 비용이 크고 조작자가 평소보다 훨씬 느리게 움직임
  - 인간 시연도 손 추적과 리타게팅이 정확해야 하고 시각과 촉각을 데이터 효율적으로 담아야 함
- **기존 한계** — 기존 리타게팅 알고리즘이 지단에서 취약, 시각과 촉각 정렬은 따로 해결해야 함
  - 정밀 깊이 센서도 수 센티미터 오차가 정책 롤아웃 전체로 전파
  - 인간 손이 비치는 영상은 그대로 로봇 학습에 쓸 수 없음
- **핵심 방법** — 리타게팅, 시각, 촉각 세 정렬을 거친 인간 시연을 로봇 시연과 함께 3D·촉각 확산 트랜스포머로 학습
  - 리타게팅 — Apple Vision Pro를 의사 정답으로 Rokoko 글러브 지단을 보정, VIVE 트래커로 손목 자세를 로봇 말단 프레임에 보정
  - 시각 — 두 스테레오 뷰에서 인간 손을 지우고 로봇 기록 픽셀로 칠한 로봇 손 메시를 합성, Fast-FoundationStereo를 다시 돌려 인간 포인트 클라우드에도 로봇과 같은 스테레오 오차와 가시성을 반영
  - 촉각 — 60 Hz 용량형 촉각 글러브를 ORCA 손 지단 taxel의 신호 공간에 정렬해 손가락별 해석 가능한 힘 표현 생성
  - 정책 — 포인트 클라우드, 고유수용감각, 손가락별 촉각 토큰을 확산 트랜스포머가 소비하며 이진·연속 촉각 신호 사용
- **차별점** — 정렬을 학습된 잠재 공간이 아닌 로봇 센서 신호 공간에서 수행해 정책이 해석 가능한 값을 소비
  - 포인트 클라우드를 말단 프레임으로 표현하고 인간 손을 로봇 손 포인트로 대체
- **핵심 기여** — 지단 보정 리타게팅, 시각 정렬 파이프라인, 촉각 정렬, 3D·촉각 확산 트랜스포머
  - 정밀 힘이 필요한 실물 3개 과제 — 레고 조립, 크기가 다른 딸기 따기, 전동 드릴 작동과 들기
  - 정렬된 인간 시연을 기존 로봇 데이터에 더하면 로봇 단독 정책보다 향상
  - ablation — 촉각 입력과 시각 정렬이 모두 필요
  - 초록은 성공률 수치를 제시하지 않음
- **가치** — 값싼 인간 시연을 시각과 촉각 양쪽에서 로봇 데이터와 같은 공간으로 끌어와 힘 정밀 과제 학습에 투입하는 경로

### (c) 시사점

- 인간 촉각 데이터를 로봇 토큰 공간으로 흡수하는 경로
  - 손가락별 촉각 토큰과 3D 포인트 입력 구성이 기본 구조와 일치하는 공개 사례
  - 센서 신호 공간 정렬은 교체 가능한 센서 헤드에 인간 글러브 소스를 편입하는 근거
  - 시각 정렬 ablation이 인간 영상 합성 단계의 필요성을 뒷받침

### (d) 먼저 확인할 점

- 촉각 맵은 과제별로 비페어 힘 샘플에서 적합 — 과제 접촉을 담은 짧은 로봇 기록이 여전히 필요
- 지단을 단일 수직력으로 축약해 taxel 배치와 전단이 사라짐, 저자도 인핸드 조작과 미끄러짐에 중요할 가능성 언급
- 과제는 단기이고 대체로 준정적
- 학습된 잠재 공간 정렬과 직접 비교 없음, 신호 공간 선택의 근거는 해석 가능성
- 초록에 성공률 수치 없음, 본문 표 확인 필요

## 🥉 논문 3

**TacDyn-WAM: Learning Implicit Tactile Dynamics in a Heterogeneous Visuo-Tactile World Action Model**
[arXiv:2610.00638](https://arxiv.org/abs/2610.00638) · Enyi Wang, Mingxin Wang, Quan Shi, Hetian Guo, Hongyu Wang, Xi Wang 외 · arXiv preprint · source: citation-graph · 코드 미공개

**점수 9/15** · R2 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 촉각 픽셀 복원 대신 암묵 촉각 동역학을 예측
- **문제** — 접촉 집약 조작에서 카메라가 접촉 상태, 국소 기하, 상호작용 힘을 다 가리지 못하는데 월드 액션 모델의 예측은 시각 중심
  - 촉각을 넣은 VTLA 모델은 현재 촉각 상태만 이해하고 전개를 예측하지 못해 촉각 피드백에 반응적
- **기존 한계** — 기존 촉각 월드 액션 모델은 비디오 생성 파이프라인을 재사용해 미래 촉각 이미지를 반복 디노이징으로 복원
  - 추론이 느리고 예측이 픽셀 복원에 묶임
  - 시연 분포를 벗어나면 카메라 뷰는 거의 같아도 접촉 위치와 힘의 작은 변화가 촉각 이미지를 크게 바꿈
  - N0-VTLA — 동결 DINOv2 특징 공간에서 단일 시점 순변화만 예측, 정적 자연 이미지로 학습한 공간이라 촉각 프레임 간 진화에 최적화되지 않음
  - 단일 순변화는 눌렀다 비슷한 상태로 돌아오는 접촉의 중간 사건을 가림
- **핵심 방법** — 시각과 촉각 전문가가 각자의 목표 공간에서 미래를 예측하고 결합 어텐션으로 상호작용, 액션 전문가가 둘을 사용
  - TacRep — 촉각 클립의 마스크 시공간 예측으로 학습하고 관계 구조 증류로 정규화한 동역학 인지 목표 공간
  - 암묵 촉각 동역학 전문가(ITDE) — 한 번의 순전파로 여러 시점의 미래 표현과 그 변화량을 예측, 디노이징 불필요
  - 읽기 전용 촉각 이해 메모리가 현재 촉각 상태를 제공
  - 단계적 학습으로 사전학습된 전문가에 촉각 모듈을 통합
- **차별점** — 미래 촉각 관측을 복원하지 않고 TacRep 공간에서 다중 시점 표현과 변화를 예측, 시각과 촉각 전문가의 파라미터와 목표 공간을 분리
- **핵심 기여** — 이종 시각-촉각 월드 액션 모델, TacRep, 시뮬레이션과 실물 결과
  - UniVTAC 평균 성공률 81.5%, 제공된 시연만 사용하며 대규모 시각-촉각 사전학습 모델 N0-VTLA·N0-TWAM과 경쟁적
  - N0-TWAM은 비디오 생성 방식이며 파라미터 약 2배
  - ablation — 두 촉각 경로와 TacRep가 픽셀 복원·정적 대안보다 우수
  - 실물 5개 과제 평균 71.0%, 촉각 정책 FTP-1보다 16%p 높고 실물 궤적 약 6,000개 사전학습 시 85.0%
- **가치** — 촉각 월드 모델이 무엇을 예측해야 하는지에 암묵 동역학 표현과 단일 순전파라는 답을 제시

### (c) 시사점

- 촉각을 별도 전문가 경로로 융합하는 비대칭 구조 사례
  - 시각 전문가와 촉각 전문가가 결합 어텐션으로 만나는 구조는 단순 이어붙이기를 넘는 융합 계열
  - TacRep는 촉각 이미지의 동역학 인지 표현 후보, 비전 기반 촉각 센서와 입력 형태가 같음

### (d) 먼저 확인할 점

- TacRep와 ITDE는 단일 종류의 시각-촉각 센서용, 힘·taxel 배열 등 비이미지 모달리티 일반화는 저자도 후속 과제로 명시
- 서론과 초록 기준 손가락별 토큰 구성 언급 없음, 촉각을 센서 클립 단위로 처리
- 81.5%는 UniVTAC 벤치 결과, 실물 71.0%와 85.0%는 사전학습 유무가 갈리므로 구분 필요
- 코드·프로젝트 페이지 신호 없음
