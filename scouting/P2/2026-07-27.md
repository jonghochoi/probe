## 🥇 논문 1 — 우선순위 ★★★

**Imagining the Sense of Touch: Touch-Informed Manipulation via Imagined Tactile Representations**
[arXiv:2607.01684](https://arxiv.org/abs/2607.01684) · Zhiyuan Zhang, Adeesh Desai, Jyun-Chi Hu, Yosuke Saka, Quan Khanh Luu 외 · source: citation-graph (ViTacFormer)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여

- 촉각 센서가 취약·고비용·유지보수 부담이 커 실제 배치를 제약한다는 문제를 겨냥, "배치 시점에 촉각 센서 없이도 촉각 지식을 활용할 수 있는가"를 정면으로 제기
- TacImag — 시각+고유수용성 관측으로부터 촉각 관측을 예측하는 "촉각 상상(tactile imagination)" 프레임워크, 짝지어진 비주오택타일 시연 데이터로 학습 후 테스트 시점에는 시각 관측만으로 촉각-정보 조작 수행
- 상상된 힘장(force field)과 상상된 촉각 이미지를 비교 — 접촉-민감 과제엔 힘장 상상이, 텍스처-민감 과제엔 촉각 이미지 상상이 더 크게 기여한다는 과제-표현 정합성 발견
- 촉각 상상이 단순히 결측 촉각 측정치를 복원하는 것이 아니라, 미묘한 시각적 상호작용 신호를 정책이 활용하기 쉬운 형태로 변환하는 "접촉-인지 지도 신호" 역할을 한다고 재해석
- 시뮬레이션 6개 + 실물 4개 과제에서 검증 — 실물 실험에서 상상된 힘장이 접촉-민감 과제 평균 44.4%, 상상된 촉각 이미지가 텍스처-민감 과제 평균 23.3% 성능 개선

### (c) 시사점

- 촉각 하드웨어 의존을 시각-기반 상상으로 대체할 수 있다는 실증 — 센서 스왑·유지보수 부담을 우회하는 대안 경로 확보
- 힘 중심 신호와 텍스처 중심 신호가 서로 다른 촉각 표현 형태로 더 잘 전달된다는 발견 — 촉각 신호를 정책에 주입할 때 단일 표현으로 통일하기보다 과제 성격에 맞춰 표현 형태를 선택할 근거 제공
- 촉각 예측을 "결측치 복원"이 아닌 "지도 신호 변환"으로 재해석한 관점 — 기존 실 센서 융합 설계와 병행 가능한 저비용 보완 경로로 검토 가치

### (d) 먼저 확인할 점

- 짝지어진 비주오택타일 시연 데이터로 학습해야 하므로, 학습 단계에서는 촉각 센서가 여전히 필요 — 완전한 센서-프리 파이프라인은 아님
- 코드·데이터 공개 여부 초록 미기재 — 재현 비용 사전 파악 필요
- 과제-표현 정합성(힘장 vs 촉각 이미지)이 본 실험 셋업에 국한된 경험적 발견인지, 다른 접촉 유형·핸드 구조로 일반화되는지 별도 검증 필요

## 🥈 논문 2 — 우선순위 ★★

**FM-VLA: Force-based Memory for Vision-Language-Action Models in Contact-Rich Manipulation**
[arXiv:2607.18231](https://arxiv.org/abs/2607.18231) · Ruicheng Li, Qixiu Li, Ruichun Ma, Yu Deng, Lin Luo 외 · source: citation-graph (ForceFlow)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여

- 기존 메모리-증강 VLA가 과거 이미지 프레임 샘플링에 의존해 계산 비용이 크고, 미세한 동작 반복처럼 시각적으로 모호한 시간적 사건(예: 버튼을 여러 번 살짝 누름)에 근본적 한계가 있다는 문제 지적
- FM-VLA — 힘 히스토리를 VAE로 압축한 "힘 메모리 토큰"을 액션-전문가 모듈의 추가 조건화 토큰으로 투입, 비-마르코프적 접촉-집약 조작에 시간적 컨텍스트 추론을 부여
- 힘 시계열 복원으로 사전학습된 VAE를 통해 힘 히스토리를 컴팩트 latent로 인코딩 — 원시 힘 신호를 그대로 붙이는 방식보다 가벼운 조건화 경로
- 숨은 블록 찾기·버튼 누르기·특정 횟수만큼 그릇 닦기 등 메모리-의존 과제 3종에서 검증, 경량 힘 메모리로 80% 이상 성공률과 최소한의 추론 오버헤드로 baseline 대비 유의한 개선

### (c) 시사점

- 힘 신호를 "현재 관측"이 아니라 "누적된 접촉 이벤트 히스토리"로 취급해 정책에 투입하는 설계 — 순간 융합만으로는 풀리지 않는 시간적 모호성 과제에 대한 구체적 해법 경로 제공
- VAE 기반 압축 토큰이 원시 신호 투입보다 추론 오버헤드가 낮다는 결과 — 힘 히스토리를 저비용으로 정책에 결합하는 실용적 참조 패턴
- 시각적으로 구분 불가능한 반복 동작을 힘 메모리로 구분한다는 사례 — 비전-편중 관측 설계의 사각지대를 힘 모달리티가 보완할 수 있음을 구체적 과제로 실증

### (d) 먼저 확인할 점

- 3개 검증 과제가 실물 로봇인지 시뮬레이션인지 초록에 명시되지 않음 — 본문에서 실물 검증 여부 확인 필요
- 코드 공개 여부 초록 미기재, 프로젝트 페이지만 존재 — 재현 비용 사전 파악 필요
- 메모리-의존 과제 3종에 특화된 평가로, 시간적 모호성이 없는 일반 접촉-집약 과제에도 이득이 유지되는지 별도 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Asynchronous Multimodal Diffusion Policy Composition via Latency-Aware Guidance Fusion**
[arXiv:2607.17257](https://arxiv.org/abs/2607.17257) · Zihao He, Hongjie Fang, Shirun Tang, Cewu Lu, Haoshu Fang · source: keyword-sweep (force+multimodal+manipulation)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여

- 여러 모달리티를 추가한 멀티모달 디퓨전 정책이 모달리티별 센싱 속도·추론 지연이 서로 다르다는 사실을 간과, 기존엔 동기 퓨전 또는 수동 설계한 다중-주파수 아키텍처에 의존해 고주파 피드백을 늦추거나 새 모달리티 조합으로의 확장성이 떨어진다는 문제 제기
- LAG-Fusion — 지연시간을 인지하는 안내(guidance) 융합 프레임워크, 모달리티별 정책이 각자의 고유 추론 속도로 동작하면서 준비될 때마다 디노이징 안내를 기여하도록 허용
- 상대적 액션 표현 하에서 디퓨전 변수를 정렬하는 "참조 프레임 재기준(rebasing)" 규칙을 도출 — 지연된 안내를 융합 전에 정합시켜 비동기 합성을 일관되게 만드는 핵심 메커니즘
- 저주파 비전 정책과 고주파 힘 정책을 합성하는 접촉-집약 조작에 적용, 이종 지연시간 조건에서 동기 퓨전 및 전용 설계된 force-aware baseline 대비 정책 반응성·과제 성능 개선 확인

### (c) 시사점

- 비전·힘처럼 샘플링·추론 속도가 다른 모달리티를 하나의 정책으로 합성할 때, 동기화를 가정하지 않는 별도 정렬 규칙이 필요하다는 것을 구체적으로 실증
- "재기준" 아이디어는 특정 센서 조합에 종속되지 않는 일반 메커니즘으로 서술 — 새 모달리티를 추가할 때마다 아키텍처를 재설계할 필요를 줄이는 확장 경로로 검토 가치
- 동기 퓨전 대비 고주파 피드백 지연을 줄인다는 결과 — 실시간성이 중요한 접촉 반응 과제에서 퓨전 설계의 병목을 짚어낸 사례

### (d) 먼저 확인할 점

- 실험이 실물 로봇인지 시뮬레이션인지 초록에 명시되지 않음 — 본문 확인 필요
- 검증 범위가 "저주파 비전 + 고주파 힘" 2-모달리티 합성 1개 셋업에 한정 — 3개 이상 모달리티·다른 지연 조합으로의 확장성 별도 확인 필요
- 코드·프로젝트 페이지 공개 여부 초록 미기재 — 재현 비용 사전 파악 필요

## 🌱 논문 4 — 인접 분야 픽

**Wake up for Touch! Mask-isolated Tactile Alignment Learning in MLLMs**
[arXiv:2607.00302](https://arxiv.org/abs/2607.00302) · Yoonhyung Park, Minji Kim, Sungwon Moon, Jiyoung Lee · adjacent field: MLLM 파라미터-효율 지속학습 (parameter-efficient continual learning) → P2 D3AG · source: citation-graph (ViTacFormer)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여

- 컴팩트 멀티모달 LLM에 촉각이라는 새 모달리티를 편입시키려 할 때, 제한된 파라미터 예산이 "새 감각 습득"과 "기존 비전-언어 추론 보존" 사이의 제로섬 트레이드오프를 강제한다는 문제 규명
- Splash — 사전학습 파라미터별 중요도를 정량화해 파라미터 공간을 휴지(dormant)·핵심(critical) 부분공간으로 분할하는 마스크-분리 촉각 정합 학습 프레임워크
- 동결된 핵심 부분공간이 기존 시각-언어 지식을 지키는 고정 앵커 역할을 하고, 분리된 휴지 부분공간만 갱신해 촉각 정합을 내부화 — 선택적·비파괴적 확장으로 치명적 망각 방지
- SSVTP·TVL·TacQuad 등 비주오택타일 벤치마크에서 LLM 부분의 추가 추론 오버헤드 없이 촉각 추론 최고 성능 달성, 기존 범용 능력도 보존됨을 확인

### (c) 시사점

- 새 감각 모달리티를 편입할 때 "무엇을 갱신하고 무엇을 동결할지"를 파라미터 중요도로 사전 분리하는 방식 — 다른 촉각 센서로 교체하거나 새 모달리티를 추가할 때 기존 능력을 깨지 않는 설계 원칙으로 참조 가능
- 추가 추론 오버헤드 없이 새 모달리티 추론을 내부화했다는 결과 — 모달리티 확장이 항상 추론 비용 증가를 수반하지 않을 수 있음을 시사
- 비파괴적 모달리티 확장이라는 목표 자체가, 센서 헤드를 교체해도 공통 토큰 포맷과 기존 능력을 유지해야 한다는 요구와 원리적으로 맞닿아 있음

### (d) 먼저 확인할 점

- MLLM 레벨의 촉각-언어 정합이 중심이라, 다지 손 손가락별 접촉 귀속이나 조작 정책으로의 직접 연결은 다루지 않음 — 조작 정책 성능으로의 전이는 별도 검증 필요
- 파라미터 중요도 분할이 특정 백본 크기·아키텍처에 종속적인 결과인지, 다른 규모의 모델로 일반화되는지 본문 확인 필요
- 코드·모델 공개 여부 초록 미기재 — 재현 비용 확인 필요

- Reproducibility 2 — 예측기 구조 상세 기술, 시각-전용 baseline 대비 정량 비교(44.4%/23.3%) 제시, 코드·데이터 공개 여부는 미기재
- Methodology 3 — 시뮬레이션 6개 + 실물 4개 과제, 힘장 상상 vs 촉각 이미지 상상 비교 ablation, 과제-표현 정합성 분석까지 수행
- Sim2Real 3 — 실물 조작 과제 직접 검증, 정량 개선폭(44.4%/23.3%) 명시

**FM-VLA (12/15)**
- Relevance 3 — 힘 히스토리를 압축 메모리 토큰으로 액션-전문가에 조건화 투입, D2DV 비-concat 이종 퓨전을 시간축으로 확장
- Novelty 3 — 시각적으로 모호한 반복 접촉 과제에 힘 기반 메모리로 대응하는 문제 정의·해법 모두 신규
- Reproducibility 2 — VAE 프리트레인 구조·조건화 방식 상세 기술, baseline 대비 80%+ 성공률 정량 제시, 프로젝트 페이지 존재하나 코드 공개 여부 미기재
- Methodology 2 — 메모리-의존 과제 3종으로 특정 가설(시간적 모호성)을 타겟 검증하나 광범위 ablation은 초록에 미제시
- Sim2Real 2 — 과제 서술이 실물 지향적이나 초록에 실물/시뮬 구분 명시 없음, 본문 확인 필요

**Asynchronous Multimodal Diffusion Policy Composition / LAG-Fusion (12/15)**
- Relevance 3 — 비전 저주파·힘 고주파 이종 모달의 비동기 융합이라는 D2DV "비-concat 퓨전"의 미해결 축(모달별 상이한 지연)을 정면으로 다룸
- Novelty 3 — 비동기 디퓨전 변수를 정렬하는 참조 프레임 재기준 규칙은 기존 동기 퓨전·수동 다중-주파수 설계 대비 신규
- Reproducibility 2 — 재기준 규칙 유도 과정 상세 기술, 동기 퓨전·force-aware baseline 대비 정량 비교 수행, 코드 공개 여부 미기재
- Methodology 2 — 이종 지연시간 조건에서 개선 확인하나 비전+힘 2-모달리티 합성 1개 셋업에 범위 제한
- Sim2Real 2 — 접촉-집약 조작 실험 서술되나 초록에 실물/시뮬 구분 명시 없음, 본문 확인 필요
