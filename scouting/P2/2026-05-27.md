## 🥉 논문 1 — 우선순위 ★

**InvariantCloud: A Globally Invariant, Uniquely Indexed Point Cloud Framework for Robust 6-DoF Tactile Object Pose Estimation**
[arXiv:2605.25216](https://arxiv.org/abs/2605.25216) · Pengfei Ye, Yuxiang Ma, Yi Zhou, Wei Chen, Wenzhen Dong · source: keyword-sweep (`cat:cs.RO AND tactile`)

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D11](https://img.shields.io/badge/D11-d97706.svg)](#ref-D11) [![D9](https://img.shields.io/badge/D9-d97706.svg)](#ref-D9)

### (b) 핵심 기여

- **InvariantCloud** — 마커 배열 내장형 비주얼 촉각 센서에서 마커 군집(marker constellations)의 전역 불변성(global invariance)을 활용하는 6-DoF 접촉 포즈 추정 프레임워크
- **드리프트·요 회전 억제** — 기존 접근의 누적 드리프트(cumulative drift)와 요(yaw, Z축) 회전 추정 오류를 1회 등록(one-shot)으로 억제
- **신규성** — 기존 마커 기반 포즈 추정(GelSight 계열)은 국소 패치 추적 의존 → 요 회전 실패·장기 시퀀스 드리프트 누적, 본 논문은 유일 인덱스 점군(uniquely indexed point cloud)으로 1회 등록만에 6-DoF 전체를 드리프트 없이 추정
- **결과** — 장기(long-sequence) 조작 태스크 실제 로봇 검증, 재배치(re-localization) 반복 정확도에서 기존 벤치마크 대비 우월 보고

### (c) 시사점

- **촉각 특징 풍부도 질문** — 현재 촉각 인코더의 contact-binary/slip-binary 보조 출력만으로 조작에 충분한지, 6-DoF 접촉 포즈 수준의 기하학적 정보가 추가로 필요한지를 직접 제기
- **접촉 귀속 보강 가능성** — 손가락별 접촉 기하학(접촉 포즈)을 손가락 토큰에 더하면 크로스핑거 접촉 귀속(contact attribution) 개선 여지
- **이식성 제약** — 비전 기반 촉각 센서 한정 결과 → 변형 이미징 센서로의 적용 가능성은 별도 확인 대상

### (d) 먼저 확인할 점

- **센서 전제** — 마커 군집 내장 비주얼 촉각 센서(GelSight·DIGIT 계열) 가정, 이산 마커 배열이 없는 변형 이미징 센서와 구조 상이
- **이식 불가 구간** — marker constellation invariance → point cloud registration 방법론을 이산 마커 없는 변형 이미징 센서에 직접 이식 불가, 상응하는 전역 불변 특징 추출 가능 여부를 시뮬레이션 소규모 실험으로 우선 확인
- **표현 성격** — 6-DoF 포즈는 기하학적 등록(geometric registration) 최적화이지 학습된 인코더가 아님, 학습된 표현 요건 충족하려면 포즈 추정 결과를 손가락 토큰 입력 피처로 재가공하는 추가 설계 필요

## 🌱 논문 2 — 인접 분야 픽

**PointACT: Vision-Language-Action Models with Multi-Scale Point-Action Interaction**
[arXiv:2605.21414](https://arxiv.org/abs/2605.21414) · Shizhe Chen, Paul Pacaud, Cordelia Schmid (INRIA) · adjacent field: 3D 공간 표현 기반 VLA 정책

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-9467bd.svg)](#ref-P2) / [![D12](https://img.shields.io/badge/D12-d97706.svg)](#ref-D12)

### (b) 핵심 기여

- **PointACT** — VLA 정책의 액션 디코딩에 계층적 3D 점군(3D point cloud) 표현을 통합하는 모델
- **병목 윈도우 자기주의** — bottleneck window self-attention으로 액션 토큰이 로컬 기하학 세부와 전역 장면 구조 모두에 조밀하게 어텐션, 전체 점군 dense attention 대비 연산 비용 절감
- **신규성** — 기존 VLA(ViTacFormer, XL-VLA)는 2D 비전 피처만 정책 입력으로 사용, 본 논문은 사전 학습 2D 의미 표현 + 계층적 3D 기하학의 긴밀한 결합(tight coupling)이 정밀·견고한 제어에 필수임을 체계적 절제로 입증
- **결과** — RLBench 10-Tasks에서 최신 사전 학습 VLA 대비 성공률 10% 향상 보고

### (c) 시사점

- **3D 사전 융합 경로** — 멀티카메라 2D 피처를 직접 융합하는 대신 3D 점군으로 먼저 통합한 뒤 계층적 어텐션을 적용하는 경로가 공간적 접촉 단서(contact cues)를 더 잘 보존할 가능성
- **선결 조건** — 손가락 접촉 단서의 공간 해상도가 3D 점군 리프팅(depth estimation 오차) 이후에도 보존되는지 확인이 우선

### (d) 먼저 확인할 점

- **시뮬레이션 한정** — 평가가 LIBERO·RLBench 시뮬레이션 전용, 실제 로봇 조작 실증 없음
- **폐색 구간 리프팅 품질** — 점군이 외부 뎁스 카메라(wrist/overhead)로 생성 → 손가락 접촉 영역처럼 폐색 많은 구간의 3D 리프팅 품질이 최대 미지수
- **핵심 요건 시험 지점** — "손가락별 접촉 단서 보존" 요건이 뎁스 오차·폐색이 가장 심한 구간에서 시험받음

### Anti-topics

- **경계 명확화 제안** — "기하학적 비학습 표현(geometric non-learned representation)"이 반복적으로 경계선 사례로 등장(지난 주 TacO, 이번 주 InvariantCloud). 기존 문구 "Tactile sensing hardware design without a learned representation / encoder"의 "hardware design" 범위를 "hardware design 또는 순수 기하학적 최적화 방법(기계적 보정, ICP 등)"으로 명확화 제안
- **단서** — InvariantCloud처럼 D11 특징 형태 결정에 직접 영향을 주는 경우는 ★ 등급 채택이 타당
