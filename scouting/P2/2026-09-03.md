## 🥇 논문 1 — 우선순위 ★★★

**ChainSplat: A Physics-Inspired Screw-Theoretic Model for Learning Deformable Linear Object Dynamics from Multi-View RGB Videos**
[arXiv:2608.28570](https://arxiv.org/abs/2608.28570) · Seungyeon Kim, Noémie Jaquier · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D8EJ](https://img.shields.io/badge/D8EJ-d97706.svg)](#ref-D8EJ) [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 핵심 기여
- 케이블·로프·호스 등 변형선형물체(DLO)의 3D 기하·외형·운동학·동역학을 다중뷰 RGB 영상만으로 동시 학습하는 물리 기반 프레임워크 ChainSplat 제안
- DLO를 회전 관절로 연결된 강체 링크의 개방 체인 구조로 모델링해 나사이론(screw theory) 기반 해석적·저차원 상태 표현 확보
- Gaussian Splatting과 결합해 임의 상태에서의 고품질 RGB 렌더링과 동역학·기하 복원을 동시 달성

### (c) 시사점
- 깊이 센서·다단계 파이프라인 없이 RGB만으로 동역학까지 포함한 압축 상태 표현을 얻는 경로 — 센서 구성 단순화 여지
- 실시간 상태·힘 추정과 모델 기반 궤적 최적화까지 직접 검증 — 조작 제어 루프에 즉시 연결 가능한 실용성
- 저차원 관절 구성 기반 표현이 고차원 상태 표현 대비 연산 비용을 낮추는 사례로 참고 가능

### (d) 먼저 확인할 점
- 변형선형물체(케이블류)에 특화된 구조 — 강체·비정형 일반 물체로의 일반화 여부 별도 확인 필요
- 다중뷰 동시 촬영 조건 전제 — 카메라 수·배치가 제한된 환경에서의 성능 저하 가능성 확인 필요
- 공개 링크가 프로젝트 사이트 형태로만 제시 — 실제 저장소 구조·설치 난이도 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**$\mathcal{N}_0$-Foundation: Towards the Age of Tactile Intelligence**
[arXiv:2608.29601](https://arxiv.org/abs/2608.29601) · NeoteAI Team, Fudan TEAI Team · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여
- 촉각 하드웨어·대규모 멀티모달 데이터·촉각 표현학습·표준화 평가를 하나로 묶은 촉각 임바디드 조작 프레임워크 제안
- 6개 임바디먼트·450개 태스크·30000시간 이상 규모의 동기화 비전-촉각 시연 데이터셋 NeoData 구축, 5000시간 오픈소스 서브셋 OpenNeoData 별도 공개
- 서로 다른 촉각 센서 설계 간에 전이 가능한 표현을 학습하는 NeoForce 제안, 실물(NeoReal)·시뮬레이션(NeoSim) 양쪽을 포괄하는 표준화 벤치마크로 검증

### (c) 시사점
- 정책이 센서 고유 외형이 아닌 물리적 접촉 상태 자체로부터 이득을 얻음을 실증 — 센서 교체 시 표현 재학습 부담을 낮추는 근거
- 대규모 이종 촉각 데이터 확보·공개 전략의 참고 사례 — 자체 데이터 구축 없이도 사전학습 표현 활용 가능성
- 실물·시뮬레이션 양쪽 표준 벤치마크 확보 — 향후 촉각 융합 설계안 비교 시 공통 기준점으로 활용 가능

### (d) 먼저 확인할 점
- 코드·모델 저장소 링크는 초록상 명시되지 않음, 데이터셋 공개 서술만 확인 — 재현 가능성 별도 확인 필요
- 대규모 데이터·연산 자원을 전제로 한 사전학습 — 소규모 팀 재현 비용 별도 확인 필요
- 손가락 단위 귀속 여부는 초록상 불명확 — 전체 촉각 신호 기준인지 별도 확인 필요

## 🥈 논문 3 — 우선순위 ★★

**Facet-0: A Robotic Foundation Model for Contact-Rich Precise Manipulation**
[arXiv:2609.01596](https://arxiv.org/abs/2609.01596) · Haoyuan Deng, Haichao Liu, Wenkai Guo, Yuan Ling, Zaijia Yang, Yuanjiang Xue 외 · arXiv preprint · source: citation-graph (ForceFlow) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV)

### (b) 핵심 기여
- 손목 wrench(힘·토크) 이력을 비전-언어 의미·기구학적 상태와 정렬해 플로우 매칭으로 액션 청크와 예상 wrench 프로파일을 동시 생성하는 Facet-0 제안
- 배포 롤아웃으로 유사한 태스크 진행 상황에서도 접촉 결과가 다른 동작을 구분하는 분포형 Action-Wrench Critic을 강화학습 후처리로 학습
- 부품별 동역학 차이에 대응하는 경량 bounded actor로 고정 표현 위에서 온-로봇 적응 수행, 예측용 wrench 헤드는 비-커맨드 방식으로 접촉 결합 유지

### (c) 시사점
- 힘 정보를 액션 생성과 가치 평가 양쪽에 동시 결합하는 설계 — 접촉 결과 민감 태스크에서 정책 개선 방향을 힘 신호로 직접 조준 가능
- 서브밀리미터 정밀 조립 태스크에서 최강 베이스라인 대비 5배 이상 성공률 확보 — 정밀 접촉 태스크에서 힘 융합의 효과 규모 확인
- 고정 표현 재사용과 경량 액터로 부품별 적응 — 신규 부품 대응 시 전체 재학습 없이 확장 가능한 경로 시사

### (d) 먼저 확인할 점
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
- 1000시간 규모 힘-동기화 전용 데이터(ManuFacet-1K) 구축 비용·특수 하드웨어 의존도 별도 확인 필요
- 조립 3개 임바디먼트·서브밀리미터 특화 태스크 한정 검증 — 더 넓은 다지 조작 태스크로의 일반화 여부 미확인

## 🥈 논문 4 — 우선순위 ★★

**Blind Dexterity: Whole-Body Humanoid Manipulation via Pure Proprioception**
[arXiv:2608.29487](https://arxiv.org/abs/2608.29487) · Aditya Bhatt, Oleg Kaidanov, Puze Liu, Jan Peters · arXiv preprint · source: keyword-sweep · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D2DV](https://img.shields.io/badge/D2DV-d97706.svg)](#ref-D2DV) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 핵심 기여
- 카메라·마커·힘-토크·촉각 센서 일체 없이 온보드 고유수용감각만으로 Unitree G1 휴모노이드의 전신 조작 스킬을 학습
- 컴플라이언트 접촉 하에서 관절 인코더 값이 시간에 따라 변화하는 양상 자체를 전신 촉각 채널로 재해석하는 관점 제시
- 정책과 분리 학습된 태스크별 상태 추정기로 유의미한 접촉 이후 물체 상태(자세 등) 디코딩 오차가 빠르게 감소함을 실증

### (c) 시사점
- 추가 센서 없이도 컴플라이언트 액추에이션만으로 접촉 인지형 전신 조작이 가능함을 실물로 확인 — 센서 최소화 설계의 하한선을 보여주는 참고 사례
- 관절 인코더 신호가 예상보다 풍부한 접촉 정보를 담고 있음을 시사 — 저비용 하드웨어에서도 접촉 인지 성능 확보 여지
- 보행·공 트래핑·가방 들기·스케이트보드 탑승 등 질적으로 다른 네 과제에서 공통 신호원으로 검증 — 범용성 근거 확보

### (d) 먼저 확인할 점
- 전신 보행형 컴플라이언트 접촉 중심 검증 — 다지 손의 미세 접촉·슬립 판별처럼 세밀한 촉각 정보가 필요한 과제로의 일반화 여부는 별도 확인 필요
- 순수 고유수용감각 신호의 정보량이 물체 형상·질감 등 시각·촉각 고유 정보를 대체하지 못하는 한계 상황 별도 식별 필요
- 코드 저장소 공개 서술 없음, 프로젝트 페이지만 확인
