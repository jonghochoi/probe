## 🥈 논문 1 — 우선순위 ★★

**ViTaR: Visuo-Tactile Residual Adaptation for Foundation VLA Manipulation**
[arXiv:2608.15816](https://arxiv.org/abs/2608.15816) · Yi Wang, Renjun Wu, Jinyan Liu, Xuesong Li · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D10](https://img.shields.io/badge/D10-d97706.svg)](#ref-D10)

### (b) 핵심 기여
- 촉각 신호를 액션을 직접 생성하는 입력이 아니라 고정된 VLA 위에 유계(bounded) 보정만 얹는 "실행 조정자"로 재정의
- Effect-Guided Modeling으로 국소적 보정의 필요·방향을 판단, Residual Action Modulation으로 실시간 시각-촉각 관측 기반 연속 보정 강도 산출
- 사전학습 VLA 내부 구조 수정이나 근-실패 조건 온라인 강화학습 없이 촉각 적응 달성

### (c) 시사점
- 백본을 고정한 채 촉각 적응 계층만 얹는 구조 — 사전학습 시각-의미 prior를 훼손하지 않고 접촉 반응성 확보 가능
- UniVTAC 벤치마크(접촉 집약 태스크 7종) + 실물 로봇 검증 모두 확보 — 실환경 전이 가능성의 초기 근거
- 촉각 전용 설계 베이스라인 대비 우위 — 순수 촉각 특화 아키텍처보다 프리트레인 prior 보존이 유리할 수 있음을 시사

### (d) 먼저 확인할 점
- 코드·체크포인트 공개 여부·시점 미확인 — 초록·코멘트 모두 공개 서술 없음
- 접촉 판단이 흔들리는 상황(다중 접촉점, 연성 물체 등)에서 보정 강도 산출의 강건성 별도 검증 필요
- 손가락 단위 접촉 귀속이 아닌 전체 촉각 신호 기반 조정 — 세밀한 손끝 단위 제어로의 확장 여부 확인 필요

## 📊 점수 요약

**ViTaR (11/15)**
- Relevance 3 — 촉각 피드백을 VLA 정책의 실행 조정자로 결합하는 이종 모달 퓨전 메커니즘, 접촉 집약 조작이 핵심 대상
- Novelty 2 — 촉각을 액션 생성이 아닌 유계 보정 신호로 재정의하는 2단계(Effect-Guided Modeling + Residual Action Modulation) 구조, 기존 VLA 내부 수정·온라인 RL 방식과 차별화
- Reproducibility 0 — 초록·코멘트 모두 코드·프로젝트 페이지·공개 예정 서술 없음
- Methodology 3 — UniVTAC 벤치마크 접촉 집약 태스크 7종, 고정 VLA 베이스 대비 30.6%p 개선, 촉각 전용 베이스라인과 비교
- Sim2Real 3 — 실물 로봇 실험으로 실센서 노이즈·동역학 전이 확인
