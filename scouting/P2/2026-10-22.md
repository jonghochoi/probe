## 🥇 논문 1

**Relational Spatial Alignment for Vision-Language-Action Models**
[arXiv:2610.24705](https://arxiv.org/abs/2610.24705) · Chaoran Zhu, Hengyi Wang, Chenglin Cui 외 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB)

### (b) 논문 요지

- 점별 특징 정렬 대신 쌍별 관계 정렬로 3D 지식 이식
- **문제** — VLA에 3D 공간 인식을 넣으면서 원래 표현력을 잃지 않는 방법
  - 3D 기반모델과 VLA 표현을 직접 맞추는 방식이 진짜 3D 이해로 이어지는지 불명확
  - 정렬 후 VLA 특징 공간의 수치적 랭크가 크게 붕괴하고 일반화가 떨어진다는 관찰
- **기존 한계** — 두 갈래의 기존 접근을 모두 지적
  - 깊이 맵·포인트 클라우드를 추가 입력으로 쓰는 명시적 3D VLA — 사전 스캔 환경이나 고품질 센서 관측에 의존, 센서 노이즈·반사면·가림에 취약
  - 3D 기반모델 특징을 증류하는 암묵적 방식(Spatial Forcing 등) — 직접 특징 정렬이 사실상 저랭크 정규화로 작동해 표현 용량 손실
- **핵심 방법** — 절대 특징 대신 특징 간 상대 유사도를 정렬하는 RIGID(Rotation-Invariant Geometry Distillation)
  - 정렬 목표가 잠재 공간의 임의 직교 변환에 불변임을 이론으로 제시, 특징 붕괴 방지의 근거
  - 공간 어텐션 분포 위의 Optimal Transport 문제로 기하 지식 전이를 정식화
  - 교사는 VGGT, 단일 시점과 교차 시점 정렬을 함께 사용
- **차별점** — 점별 동등성 강제 대신 쌍별 관계 정렬
  - VLA가 자기 특징 좌표계를 유지한 채 3D 지식을 유사도 구조에 담음
  - 직접 특징 증류, Gram 행렬 목표와 맞댄 구성요소 분석 수행
- **핵심 기여** — 랭크 붕괴 분석, 정렬 방법, 시뮬레이션·실물 검증
  - LIBERO와 LIBERO-Plus에서 Spatial Forcing 대비 교란 조건 전반의 강건성 우위 보고
  - LIBERO-Plus Spatial 스위트 2,402 에피소드 제로샷 비교에서 직접 특징 78.2%, Gram 행렬 83.9%, RIGID 86.6%, 카메라 교란은 Gram 68.6%에 RIGID 90.4%
  - 교사 VGGT 12번째 층의 어텐션 목표가 시험한 층 중 최고
  - Franka 팔 장난감 주방 6개 과제, 과제당 10회 시행에서 π0와 Spatial Forcing 대비 최고 평균 성공률
  - 새 공간 추론 벤치마크와 프로빙 실험 제시
- **가치** — 3D 인식 주입과 표현 용량 보존 사이의 상충을 풀 수 있다는 경로 제시

### (c) 시사점

- 기하 증류 인코더 선택 시 정렬 방식이 변수가 된다는 신호
- eVGGT류 점별 증류 기준점에 대한 직접적 반증 후보
  - 우리 증류 설정에서도 랭크 붕괴가 나타나는지 점검할 근거
- 도입 비용 낮음 — 추론 때 추가 모듈 없이 학습 손실만 교체
- 시각 인코더 쪽 기하 사전지식 이식에 한정, 촉각·고유수용 융합과는 별개 축

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 신호 없음, 재현은 논문 서술에 의존
- 교사 VGGT의 편향과 한계를 저자도 인정, 로봇 미세조정 데이터 규모가 작아 전이 다양성 제약
- 실물 평가가 장난감 주방 6개 과제 10회 시행, 과제별 편차가 커 평균 우위의 신뢰 구간 불명
  - 가장 어려운 두 과제는 세 모델 모두 어려움
- 다지 손·촉각 설정 검증 없음, 평행 그리퍼 VLA 기준 결과

## 🥈 논문 2

**FINGR: Learning Dexterous Hand Control for Real-World Rubik's Cube Solving**
[arXiv:2609.33973](https://arxiv.org/abs/2609.33973) · Yutong Liang, Quanquan Peng, Matthew Kim 외 · arXiv preprint · source: citation-graph

**점수 10/15** · R2 · N3 · M3 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9WZ](https://img.shields.io/badge/D9WZ-d97706.svg)](#ref-D9WZ)

### (b) 논문 요지

- 손가락 기준 상대 기하와 미래 토큰으로 큐브 풀이 99.0%
- **문제** — 단일 다지 손으로 큐브 층을 연속 회전하는 접촉 집약적 협응
  - 일부 손가락은 큐브를 지지하고 다른 손가락은 층을 밀고 해제하고 복귀해야 함
  - 한 번의 밀기 성공이 아니라 다음 동작을 지탱하는 손-큐브 배치가 필요
- **기존 한계** — 관측 표현이 공간·시간 구조를 정책에 맡김
  - 큐브를 전역으로, 손가락을 따로 인코딩하면 둘의 상대 관계를 정책이 스스로 추론해야 함
  - 행동 모방만으로는 접촉과 움직임이 어떻게 변할지를 인코더가 배우지 못함
- **핵심 방법** — 두 구성요소를 플로우 정책에 결합
  - 큐브 점을 다섯 손가락 끝 기준 원점으로 옮기고, 공유 점 인코더와 대칭 집계로 손가락별 기하 특징 생성, 각 손가락 상태 토큰에 직접 더함
  - 세 시간 규모의 학습형 미래 토큰이 관측 토큰과 트랜스포머 인코더에서 상호작용, 접촉력 변화·층 회전 진행도·손가락 관절 변위를 예측
  - 미래 예측은 학습 때만 보조 지도, 배포 때는 인코딩된 토큰이 행동 생성을 조건화
  - 7관절 팔과 다지 손, 이산 솔버와 테이블 보조 재파지를 결합한 전체 시스템
- **차별점** — 큐브 점 순서와 큐비 인덱싱에 의존하지 않는 손가락 끝 기준 점 집합 인코딩
  - 점 순서에 불변이면서 상대 방향과 거리 정보 보존
- **핵심 기여** — 실물 큐브 풀이 시스템과 두 구성요소의 ablation
  - 실물 손 300회 층 회전 시도에서 성공률 99.0%, 기본 플로우 정책 79.7%, ACT 77.7%, Diffusion Policy 78.7%
  - 손가락 기준 기하만으로 92.7%, 미래 토큰 예측 추가로 99.0%
  - 개선 대부분은 타임아웃 감소, 300회 중 3회 대 기본 정책 59회
  - 섞인 2×2×2 큐브 10개를 전체 시스템 평균 약 137초에 풀이
- **가치** — 연속 접촉 전환을 요구하는 다지 조작에서 손가락별 상대 기하가 관측 표현의 유효한 단위임을 실물로 제시

### (c) 시사점

- 손가락 정체성을 관측 인코딩에 넣는 방식의 실물 근거 확보
- 손가락별 상대 좌표 특징을 상태 토큰에 더하는 단순한 결합
  - 행동 쪽 집계가 아닌 관측 쪽 손가락 귀속이라 기존 추적 논문과 보완적
- 미래 접촉력 예측 보조 지도를 쓰는 점은 촉각 토큰 설계에도 참고 가능
- 공개 기준점은 없음, 방식의 이식 비용은 낮은 편

### (d) 먼저 확인할 점

- 손 1종, 마커 부착 2×2×2 큐브, 마커 기반 재구성에 한정
  - 저자도 마커 없는 관절 물체와 다른 손으로의 확장을 미검증으로 명시
- 최종 풀이는 10개 스크램블 시연, 동작 범위 특성화에는 더 큰 표본 필요
- 점 집합 입력이 전제, 이미지·촉각 중심 관측으로 바꿀 때 같은 이득이 나올지 불명
- 손가락 기준 기하와 다른 손가락 귀속 방식을 맞댄 비교는 없음
- 코드 공개 신호 없음, 프로젝트 웹사이트만 존재

## 🥉 논문 3

**Spark-0: Scaling Spatially Aligned Tactile Pretraining for Robot Dexterous Manipulation**
[arXiv:2610.22342](https://arxiv.org/abs/2610.22342) · Tianxing Chen, Wenwei Lin, Chuqiao Lyu 외 · arXiv preprint · source: keyword-sweep

**점수 9/15** · R2 · N3 · M2 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P2](https://img.shields.io/badge/P2-e2f5d5.svg)](#ref-P2) / [![D9NB](https://img.shields.io/badge/D9NB-d97706.svg)](#ref-D9NB) [![D3AG](https://img.shields.io/badge/D3AG-d97706.svg)](#ref-D3AG)

### (b) 논문 요지

- 촉각을 시각 토큰의 학습 전용 지도로 쓰는 사전학습
- **문제** — 대규모 시각 사전학습만으로는 힘·컴플라이언스·초기 미끄러짐이 영상에서 보이지 않는 접촉 집약적 다지 조작이 어려움
- **기존 한계** — 대규모 시각 사전학습이 접촉 집약적 조작에서 힘·컴플라이언스·초기 미끄러짐을 놓침
  - 특정 선행 방법을 지목한 서술은 초록에 없음
- **핵심 방법** — 시각-촉각-언어-행동(VTLA) 모델, 촉각을 두 경로로 사용
  - 사전학습 때 촉각 장갑에서 얻은 이미지 공간 접촉 지도와 고정된 3D 기하 교사 특징이 시각 토큰을 지도, 두 목표는 추론 때 제거
  - 별도 촉각 경로가 영역별 힘 이력과 3D 택셀 상태를 인코딩해 액션 전문가를 조건화
  - 체크포인트 하나로 시각 전용과 촉각 조건 배포를 모두 지원
- **차별점** — 접촉 지도를 학습 전용 지도 신호로 쓰고 추론 때 제거
  - 촉각을 정책 입력이면서 동시에 확장 가능한 지도로 사용
- **핵심 기여** — 데이터셋, 벤치마크, 모델
  - HumanTouch — 전손 촉각 인간 조작 1,000시간 데이터셋, 에고센트릭 영상·로봇·시뮬레이션 데이터와 함께 사전학습
  - SparkArena — 시각 전용 시뮬레이션 과제와 촉각 조건 실물 과제를 한 다지 로봇에서 묶은 벤치마크
  - SparkArena 두 트랙 모두 최고 평균 성공률, Ego Humanoid Manipulation Benchmark 종합 8개 지표 전부 1위
  - 같은 데이터·연산으로 촉각을 버린 시각 전용 사전학습 대비 HumanTouch 촉각을 유지하면 Ego Humanoid 시각 전용 성공률 52.5%에서 71.7%, 촉각을 배포에도 쓰는 SparkArena-Real에서 44.0%에서 52.0%
- **가치** — 촉각 데이터가 입력을 넘어 시각 사전학습의 확장 가능한 지도원이 될 수 있다는 근거

### (c) 시사점

- 촉각을 추론 비용 없이 시각 인코더에 심는 경로 제시
  - 촉각 센서 없는 배포 환경에서도 이득을 유지하는 구조
- 기하 인식 시각 인코더 설계에 촉각 접촉 지도를 더하는 구성 참고
- 영역별 힘 이력과 3D 택셀 인코딩은 촉각 토큰 설계의 비교 기준
- 도입 비용은 촉각 장갑 데이터 확보에 좌우

### (d) 먼저 확인할 점

- HTML 원문 없음 — 요지는 초록 기준
- 촉각 지도와 3D 기하 교사 지도를 따로 떼어 본 ablation이 초록에 없어 이득의 출처 불명
- SparkArena-Real 개선은 44.0%에서 52.0%로 폭이 작고 시행 수 확인 필요
- 촉각 장갑 데이터가 특정 장갑과 로봇 손 형상에 묶인 정도 확인 필요
- 코드 공개 신호 없음, 웹사이트만 존재
