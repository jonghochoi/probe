## 🥇 논문 1

**Multi-View Latent Action Pretraining for Cross-Embodiment Robot Learning from Videos**
[arXiv:2610.27794](https://arxiv.org/abs/2610.27794) · Oliver Hausdörfer 외 5명 · arXiv preprint · source: citation-graph

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — arXiv comment는 프로젝트 페이지뿐, 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- 멀티뷰 영상으로 잠재 행동의 6D 복원력 향상
- **문제** — 액션 없는 영상에서 지도 신호를 뽑는 잠재 행동 모델(LAM)이 단일 시점이라 6D 로봇 행동을 모호하게만 복원
  - 시점 평면 밖 움직임은 결정되지 않고 장면 일부는 가려짐
  - 하위 정책 성공률이 잠재 행동의 실제 로봇 행동 예측력에 좌우됨
- **기존 한계** — 기존 개선책이 단일 시점의 깊이 모호성을 풀지 못함
  - 행동 접지(CLAM 계열) — 행동이 달린 데이터 일부만 접지에 쓸 수 있음
  - 시각 전처리(LAOF) — 단일 시점 입력을 전처리할 뿐 시점 정보를 늘리지 않음
  - 대규모 단일 시점 사전학습(LAPA) — 로봇 궤적 97만 개로 사전학습해도 깊이 방향 행동이 복원되지 않음
  - 대상 로봇 영상만 쓰거나 임베디먼트·과제·외관이 섞인 대규모 공개 데이터를 써서 교차 임베디먼트 전이의 기여를 분리하기 어려움
- **핵심 방법** — 동기화된 다중 카메라 영상을 하나의 잠재 행동으로 압축하는 LAM과 이를 소비하는 계층형 정책
  - LAM — 시점 간 패치 교차 어텐션으로 깊이와 가림을 해소한 뒤 잠재 행동으로 압축
  - 다중 시점은 LAM 사전학습에만 사용, 정책 학습은 외부 카메라 하나와 손목 카메라만 사용
  - 정책 — 동결 VLM 백본 둘레에서 잠재 전문가와 액션 전문가를 순차 플로우 매칭으로 결합
  - 잠재 계획을 먼저 예측하고 이에 조건해 액션 청크를 예측, 소량 행동 라벨 데이터와 대량 영상 전용 데이터를 함께 학습
- **차별점** — 두 시점을 하나의 잠재로 함께 인코딩해 깊이를 해소
  - 비교 대상 MVP-LAM은 시점을 따로 인코딩하고 교차 시점 재구성 손실로만 연결, 같은 두 시점 사전학습이지만 크게 뒤처짐
  - 잠재 계획이 행동과의 결합 노이즈 제거 목표가 아닌 명시적 조건 인터페이스로 행동에 연결
- **핵심 기여** — 방법, 교차 임베디먼트 분석, 실물 검증
  - 행동 전용 대비 정책 성공률 시뮬레이션 +13.5%(LIBERO, LIBERO-Plus, MimicGen), 실물 +20%
  - 같은 영역 멀티뷰 영상으로 실제 행동 복원성 17% 향상, 단일 시점 LAM 대비 정책 성공률 +7.3%
  - 소량 이중 시점 데이터가 약 100배 많은 단일 시점 사전학습(LAPA 초기화)을 능가
  - 교차 임베디먼트 하나로 기술 전이가 가능하고 두 번째 시점 추가가 최대 4개 임베디먼트 추가보다 우수
  - 실물 TRLC-DK1에서 850회 시행, 사람 손 시연 영상 사용, 이중 시점이 단일 시점 대비 평균 +25%(46% 대 21%)
  - 사람 영상만으로 새 과제 기술 전이 시연
- **가치** — 영상 기반 사전학습에서 단일 시점 데이터 확대보다 보정된 다중 시점 확보가 저렴한 지렛대임을 제시

### (c) 시사점

- 영상 사전학습에서 데이터 양보다 시점 수가 효과적이라는 측정
- **데이터 구성** — 영상과 로봇 데이터가 상보적이라는 결과, 임베디먼트 추가보다 시점 추가가 이득이라는 비교가 구성 질문에 새 축을 더함
- **백본 구성** — VLM을 동결하고 전문가만 학습하는 구성과 같은 방향의 실물 사례
- **도입 비용** — 다중 시점은 LAM 사전학습에만 필요하고 정책 입력은 카메라 둘, 배포 시 추가 비용 없음

### (d) 먼저 확인할 점

- 코드 저장소나 공개 약속 없음, 프로젝트 페이지만 제공
- 보정된 동기 다중 시점 영상이 전제, 단일 시점 에고센트릭 영상에는 그대로 적용되지 않음
- 사람 영상만 쓴 실물 일반화의 성공률은 약 20%, 저자도 실용성 한계로 인정
- 영상 이득은 과제 의존적이며 정밀 병목과 그리퍼 중심 과제에서는 감소
- 실물 실패 중 잡기 실패가 54%, 영상은 주로 상위 계획 오류만 줄임(52%에서 23%)

## 🥈 논문 2

**Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs**
[arXiv:2611.05249](https://arxiv.org/abs/2611.05249) · Asher James Hancock 외 8명 · arXiv preprint · source: keyword-sweep

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- VLM 그래디언트 차단은 기본값 아닌 조건부 선택
- **문제** — VLM과 플로우 매칭 액션 전문가를 묶은 VLA에서 연속 액션 손실이 전문가만 학습시킬지 VLM까지 갱신할지의 결정
  - 결합은 백본이 제어에 필요한 정보를 보존하도록 가르칠 수 있으나 무작위 초기화 전문가의 그래디언트가 사전학습 시각·언어 특징을 훼손할 우려
- **기존 한계** — 두 갈래의 보고가 서로 반대이면서 레시피 차이로 원인을 가리지 못함
  - Knowledge Insulation — FAST 액션 토큰과 비전·언어 목표로 VLM을 지도하며 차단 학습의 이점을 보고, FAST 없는 차단은 평가하지 않음
  - Wall-OSS-0.5 — 이산 액션과 멀티모달 목표를 유지하고도 결합 학습에서 더 높은 액션 성능을 보고
  - 두 시스템은 레시피·초기화·데이터·최적화가 달라 액션 토큰 지도와 그래디언트 흐름의 기여를 분리하지 못함
- **핵심 방법** — 액션 토큰 지도와 전문가-VLM 그래디언트 흐름을 교차한 네 조건 비교
  - 주행 모델 — Qwen3-VL-2B 백본과 같은 폭의 비인과 플로우 매칭 전문가, 전문가가 VLM 레이어별 키-값에 어텐션
  - 차단은 stop-gradient, 결합은 그래디언트 통과, 액션 토큰은 평가 때 디코딩하지 않는 학습 보조 신호
  - 동시 학습과, 한 구성요소를 먼저 학습하는 단계 학습 두 스케줄에서 평가
  - 조작 확장 — π0.5 재구현(PaliGemma-3B)과 MolmoAct2
- **차별점** — 두 요인을 독립 변수로 교차하고 데이터·아키텍처·최적화·의미 공동학습은 스케줄별로 고정
- **핵심 기여** — 차단의 이점이 액션 토큰 지도 여부에 달렸다는 분리 결과
  - 개루프 주행 — 액션 토큰 지도가 있으면 두 라우팅이 거의 구분되지 않고, 없으면 결합이 궤적 예측 오차를 약 25% 감소
  - 폐루프 주행 동시 학습 — 결합이 경로 진행을 액션 토큰 지도 있을 때 약 17%, 없을 때 40% 증가
  - 조작(PolaRiS 3환경, 조건·환경당 50회, 시뮬레이션) — π0.5 재구현은 FAST 없음 10.3%에서 32.9%, FAST 있음 19.5%에서 30.7%
  - MolmoAct2는 FAST 없음 14.5%에서 36.5%, FAST 있음 22.0%에서 24.3%
- **가치** — VLA 학습 레시피에서 VLM 차단을 기본값으로 두지 말고 액션 토큰 지도·스케줄과 함께 고르라는 근거

### (c) 시사점

- 동결 계열 기본값의 전제를 직접 비교로 시험한 결과
- **적응 범위** — 차단이 경쟁력을 갖는 조건은 VLM이 액션 토큰으로 지도되는 경우에 한정
- **보존 수단** — 비전·언어 공동학습이 이미 있으면 차단의 추가 보호가 불분명하다는 지적
- **표현 선택** — 연속 플로우 매칭 헤드는 유지한 채 이산 액션 토큰을 보조 지도로 두는 구성의 비교 자료

### (d) 먼저 확인할 점

- **저자 명시 한계** — 주행 모델 1종과 조작 모델 2종, 폐루프 평가는 전부 시뮬레이션이고 실물 로봇 검증 없음
  - 조건당 학습 1회라 학습 시드 변동은 측정되지 않음
  - 메커니즘은 규명하지 않은 경험적 연구
- 주행에서 결합 단계 학습이 경로 진행은 비슷하거나 높아도 과실 충돌률이 더 높게 관찰됨
- 차단 쪽에 일관된 주행 근거 품질 이점은 없었으나 VLM 능력 보존 일반을 입증한 것은 아님
- 코드 저장소나 공개 약속 없음

## 🌱 논문 3 — 인접 분야 픽

**SLA: Scaling Spatial-Language-Action Model via Continual Pre-training**
[arXiv:2611.08373](https://arxiv.org/abs/2611.08373) · Fuhao Li 외 9명 · adjacent field: spatial-geometric fusion representation · 코드 공개

**점수 12/15** · R2 · N2 · M3 · Real3 · Repro2 — arXiv comment "Github: https://github.com/OpenHelix-Team/Spatial-Forcing/tree/master/SLA"

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 3D 인식 모델 정렬을 연속 사전학습으로 확장
- **문제** — VLA 기반 모델이 2D 이미지-텍스트로 사전학습된 VLM의 시각 표현을 물려받아 3D 정밀 조작의 신뢰성에 한계
  - 공간 지도는 과제별 적응 단계에서만 도입되어 전이 가능한 기반 능력이 되지 못함
- **기존 한계** — 사후학습 단계의 3D 도입 방식은 확장성이 낮음
  - 깊이맵·포인트클라우드를 VLM 백본이나 액션 헤드에 넣는 방식 — 센서 데이터가 노이즈·결손을 가지고, 센서 종류·위치·보정이 제각각이며, 대규모 로봇 데이터 일부는 깊이가 없음
  - Spatial Forcing — 깊이 없이 암묵적 3D 표현을 정렬하지만 사후학습에 머물러 공간 능력이 과제별 부가물
- **핵심 방법** — π0.5에서 초기화해 행동 예측과 시각 임베딩 정렬을 함께 최적화
  - 중간 시각 임베딩을 동결된 3D 인식 모델(OmniVGGT)의 표현과 정렬
  - 특징 의존 게이트로 여러 VLA 레이어의 임베딩을 적응적으로 집계
  - 교사가 일부만 있는 깊이와 카메라 보정을 RGB와 함께 활용
  - 확률적 상태 드롭아웃으로 시연 궤적 과적합 완화
  - 이종 공개 로봇 데이터셋을 끝점 표현과 좌표 규약으로 통합한 코퍼스 사용
  - 연속 사전학습 뒤 사후학습에서도 정렬 유지
- **차별점** — 정렬을 사후학습이 아니라 연속 사전학습으로 확장하면서 아키텍처와 액션 헤드는 그대로 둠
  - 교사·투영기·게이트는 학습에만 쓰여 사전학습 VLA 가중치를 그대로 재사용하고 추론 구조 유지
- **핵심 기여** — 벤치마크와 실물 결과
  - LIBERO-Plus 전체 87.4%
  - RoboTwin 2.0 Clean2Random 72.3%, 두 설정 평균 79.2%
  - RoboCasa-Panda 하위 시연 과제당 50개로 68.4%, 비교 정책은 과제당 300–3,000개
  - RoboDojo-Real 세 임베디먼트 단일 정책 33.9%, π0.5는 12.8%
  - 실물 8개 조건(Piper·Franka) 평균 83.8%, π0.5 대비 24.0%p, 모든 조건에서 비교 방법 중 최고
  - 두 학습 단계 모두에 정렬을 적용한 구성이 모든 데이터 비율에서 단일 단계보다 우수
- **가치** — 공간 이해를 과제별 부가물이 아닌 기반 모델의 전이 가능한 능력으로 키우는 경로 제시

### (c) 시사점

- 보조 정렬 지도를 사전학습 단계에 거는 레시피의 실물 검증
- **단계 구성** — 사전학습과 사후학습 양쪽에 같은 지도를 유지하는 쪽이 한쪽만 쓰는 것보다 낫다는 통제 실험
- **도입 비용** — 추론 구조 변경이 없고 교사·정렬 모듈은 학습 전용, 배포 쪽 부담 없음
- **공개 기준점** — 사전학습 π0.5에서 이어 학습하는 공개 코드 기준점 확보

### (d) 먼저 확인할 점

- 인접 분야(공간 표현) 논문이라 우리 쪽 코퍼스 구성에 대한 직접 근거는 아님
- 실물 비교는 π0.5·Spatial Forcing 등 같은 계열과의 결과이고 조건당 50회 수준
- 두 단계 정렬 이점은 데이터 비율 실험에 한정된 근거
- 3D 교사 모델을 돌리는 학습 비용은 본문에서 확인 필요
- 저장소는 Spatial Forcing 저장소의 하위 경로
