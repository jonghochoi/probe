## 🥇 논문 1 — 우선순위 ★★★

**HiFi-UMI: Learning Deployable Manipulation Policies from High-Fidelity UMI Data Alone**
[arXiv:2607.25895](https://arxiv.org/abs/2607.25895) · source: citation-graph (π0 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 헤드마운트 오프라인 스테레오-관성 SLAM, 마이크로초 단위 GPIO 트리거, 손당 200도 광각 카메라 2대로 구성된 로봇-프리 UMI 데이터 수집 시스템 HiFi-UMI 제시 — 외부 트래킹 장비 없이 3mm 워크스페이스 단위 엔드이펙터 정확도 달성
- 로봇 실측 데이터 비중을 줄이는 기존 접근 대신, 로봇-프리 데이터 자체의 충실도를 높여 실로봇 앵커 데이터를 아예 제거하는 "zero-robot post-training" 실증
- VLA·World-Action-Model 계열 3개 서로 다른 백본(StarVLA-QwenPI, OpenPI-pi_0.5, LingBot-VA)에 HiFi-UMI 데이터만으로 post-training 수행 — 실물 로봇에서 teleoperation 기준선과 대등한 성능 재현
- 마이크로초 동기화, 초광각 시야, 시뮬레이션 재생으로 검증된 2,000시간 규모 HiFi-UMI-2K 데이터셋 오픈소스 공개

### (c) 시사점
- 실로봇 데이터 비중을 낮추고 고충실도 로봇-프리 데이터로 대체하는 경로의 실현 가능성 시사 — 데이터 수집 비용 구조 재검토 여지
- 사전학습 시간(4,000시간)을 늘렸을 때 미확인 과제 액션 오차 41% 감소, 특정 백본 성공률 18.1%p 향상 등 데이터 규모-성능 관계에 대한 정량 근거 확보
- 백본 아키텍처(VLA·WAM 계열 무관)에 걸쳐 재현되는 결과 — 특정 아키텍처에 종속되지 않는 범용 데이터 개선 레버로 검토 가능

### (d) 먼저 확인할 점
- 3mm 정확도가 저자 자체 제작 헤드마운트 SLAM 리그에 의존 — 표준 UMI 장비 대비 재현 난이도 및 장비 접근성 확인 필요
- 검증 과제가 정밀 삽입 등 소수 과제 중심 — 더 넓은 과제 분포·조작 스킬에서 zero-robot post-training 일반화 여부 미검증
- 3개 백본 중 1개는 오히려 소폭 하락(-2.5%p, -0.6%p) — 전 백본 일관 이득은 아니며 백본별 데이터 활용 방식 차이 존재 가능

## 🥈 논문 2 — 우선순위 ★★

** $`π\mathbf{R}^2`$: Reactive Real-time Flow Policies**
[arXiv:2607.26055](https://arxiv.org/abs/2607.26055) · source: citation-graph (π0 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 핵심 기여
- 대형 사전학습 backbone과 표현력 있는 멀티모달 정책을 그대로 유지하면서 실시간 반응성을 확보하는 $`π\mathbf{R}^2`$ 제시 — 액션 청크의 open-loop 실행이 초래하는 지연·경직성 문제 해결
- diffusion forcing의 위치별 노이즈 스케줄을 기반으로, 매 틱 갱신되는 고유수용감각 fast channel과 비동기 갱신되는 시각-언어 slow channel로 조건화를 분리
- 진행 중인 액션을 인페인팅 조건으로 취급하고 호출당 1-스텝 디노이징만 수행하는 latency-adaptive flow 스케줄 도입 — 하나의 학습된 모델이 다양한 하드웨어 지연에 적응
- 기존 아키텍처에 최소한의 수정만으로 사전학습된 정책(GR00T-N1.7)에서 파인튜닝 가능 — 실물 xArm6+XHand 플랫폼에서 기존 정책 대비 약 4배 빠른 재계획(~25Hz) 달성

### (c) 시사점
- 백본을 새로 학습하지 않고 인터페이스 수준의 경량 수정만으로 반응성·실시간성을 확보 — 사전학습 자산을 보존한 채 배포단 적응 비용을 최소화하는 사례
- 시뮬레이션 대비 실물에서 개선폭이 더 큼(최대 +23% vs +30%) — 실배포 조건에서 지연-정확도 트레이드오프 해소 효과가 두드러짐
- 액션 표현(flow) 설계가 파인튜닝 용이성과 반응성에 직결 — 백본을 고정한 상태에서도 액션 헤드 쪽 설계 여지가 크다는 근거

### (d) 먼저 확인할 점
- 검증 플랫폼이 xArm6+XHand 단일 조합 — 자유도가 더 높은 다지 핸드에서도 fast/slow 채널 분리 효과가 유지되는지 미확인
- 4배 속도 향상 수치가 A5000 GPU 기준 — 온보드·저전력 추론 환경에서 동일 이득 재현 여부 별도 확인 필요
- 베이스 정책(GR00T-N1.7) 자체의 성능 상한에 종속 — 베이스 정책이 애초에 실패하는 과제에서는 반응성 향상만으로 보완 불가

## 🥉 논문 3 — 우선순위 ★

**Patch Policy: Efficient Embodied Control via Dense Visual Representations**
[arXiv:2607.18236](https://arxiv.org/abs/2607.18236) · source: citation-graph (π0.5 인용) / keyword sweep 중복 확인

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 사전학습된 Vision Transformer의 dense patch token을 전체 VLM 없이 직접 소비하는 최소 아키텍처 확장 Patch Policy 제시
- block-causal attention mask로 표준 정책의 시간적 인과성을 유지하면서도 관측당 다수의 patch token에 대한 attention을 허용
- 시뮬레이션 4종 + 실물 3종 환경 스위트에서 global-pooled 표현 사용 정책 대비 40% 상대 개선, 파인튜닝된 OpenVLA-OFT 대비 파라미터의 약 0.7%만으로 18% 상회

### (c) 시사점
- 수십억 파라미터 VLM 전체를 갖추지 않고도 대규모 시각 사전학습의 이득(dense feature)을 정책에 반영할 수 있는 경량 backbone 대안으로 검토 가치
- 고빈도 반응 제어에 필요한 학습·추론 효율을 유지하면서 시각 표현 품질을 개선하는 경로 제시
- 지속적으로 발전하는 시각 표현학습 성과를 정책 쪽에 낮은 비용으로 흡수할 수 있는 파이프라인 성격 — backbone 교체 비용을 낮추는 방향성

### (d) 먼저 확인할 점
- 초록 기준으로는 언어 조건화·과제 다양성 범위가 불명확 — VLM의 언어 이해 능력 없이 복잡한 지시를 수행할 수 있는지 확인 필요
- 프로젝트 페이지에 영상 공개만 확인됨 — 코드·체크포인트 공개 여부는 네트워크 정책상 실접근 미검증
- 실물 검증 스위트가 3종으로 제한적 — 더 다양한 조작 과제·임베디먼트에서 40% 개선폭이 일반화되는지 확인 필요
