## 🥇 논문 1 — 우선순위 ★★★

**Contrastive Conceptor Activation Steering (COAST): Unlocking Vision-Language-Action Models through Hidden States**
[arXiv:2605.17144](https://arxiv.org/abs/2605.17144) · Miranda Muqing Miao, Subin Kim, Brandon Yang, Lyle Ungar · 2026-05-16 · source: keyword-sweep (frozen VLM / action expert)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **개입 방식** — VLA 잠재 벡터를 성공 서브스페이스로 유도하는 "개념기(conceptor)" 기반 액션 사이드 개입, 추론 시점에 backbone 파라미터를 전혀 건드리지 않는 zero-cost 구현
- **아키텍처 횡단 검증** — 실험 대상에 flow-matching VLA(π0 계열), autoregressive VLA, Diffusion Policy 모두 포함
- **핵심 발견** — 현재 VLA는 이미 task-relevant knowledge를 잠재 표현에 보유, bottleneck은 액션 전문가의 디코딩이라는 관찰
- **진정으로 새로운 점**
  - 5~10개 성공·실패 rollout에서 task-specific 서브스페이스 추출, 추론 시점에 VLA 잠재 벡터를 그 서브스페이스로 soft-project하는 학습 없는 추론시점 개입(training-free inference-time steering)
  - 기존 사전학습 보존 연구가 fine-tuning 단계에 개입한 반면, COAST는 배포된 frozen backbone에 전혀 손대지 않고 실시간 개입
  - 실패 모드가 task 간 공유 구조를 지님(failure representations share substantial structure across tasks)이라는 기하학적 관찰

### (c) 시사점

- **동결 백본 충분성 직접 증거** — VLM 사전학습에서 비롯된 perceptual prior가 충분히 보존되어 있음이 실험으로 드러남
- **저비용 진단 도구** — 성공·실패 rollout 5개만 수집해도 동작하는 조기 진단 메트릭
- **개입 절차 가능성**
  - in-hand rotation 태스크에서 성공·실패 trajectory를 수집해 conceptor 학습
  - 개입 후 성공률이 +20pp 이상 개선되면 backbone이 이미 task-relevant 표현을 충분히 보유한다는 신호
  - 개입 후에도 성공률이 낮으면 backbone 표현 불충분 신호

### (d) 먼저 확인할 점

- **Rollout 수 의존성** — conceptor 품질은 성공·실패 rollout 수에 민감, 학습 초반 성공 예시가 희소하면 잘못된 서브스페이스 추출 위험, 최소 샘플 수는 ablation으로 사전 검증 필요
- **Multi-phase 조작** — 논문이 보고한 "stationarity-executability gap"(특정 residual threshold와 성공률 간 비단조 관계), in-hand rotation처럼 접촉 시점이 중요한 태스크는 phase 단위로 분리한 conceptor 필요 가능
- **잠재 레이어 선택** — 손/몸 split-head 구조에서 어느 잠재 레이어에 steering을 적용할지 결정 필요

## 🥈 논문 2 — 우선순위 ★★

**From Abstraction to Instantiation: Learning Behavioral Representation for Vision-Language-Action Model**
[arXiv:2605.22671](https://arxiv.org/abs/2605.22671) · Bing Hu, Zaijing Li, Rui Shao, Junda Chen, April Hua Liu · 2026-05-21 · source: citation-graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **구조** — VLM backbone에 Mamba 기반 Visuomotor Behavior Encoder(VBE)를 추가, Phase-conditioned Behavior Decoder(PBD)로 행동 표현을 액션으로 디코딩
- **역할 분리** — VLM을 지각·의미 처리에 전담시키고 시간적 통합은 VBE가 담당, VLM을 semantic role에 유지하는 연속 액션 헤드의 확장
- **문제 진단** — 기존 VLA는 분포 이동 하에서 shallow correlation 의존으로 성능 저하
- **진정으로 새로운 점**
  - 행동 표현을 action-centric latent variable(기존 LAM 방식)이 아닌 장기 궤적 전체를 통합한 통일 행동 표현(unified behavioral representation)으로 구성
  - Causal Mamba 아키텍처(VBE)가 장기 시간 의존성 포착, PBD가 실행 진행 상황(phase)에 맞춰 실시간 인스턴스화
  - 실환경에서 OpenVLA-OFT 대비 50% 시연 데이터만으로 동등 성능 달성한 데이터 효율성

### (c) 시사점

- **아키텍처 대안 기록** — 연속 액션 헤드 검토 시 VBE→PBD 캐스케이드 구조를 대안으로 보관
- **데이터 효율 검증 경로** — VBE 유사 구조(causal temporal encoder)를 손/몸 전문가 입력 측에 추가하는 ablation 설계 가능
- **비교 지표** — 새로운 물체 배치(cross-object generalization)에서 행동 일관성 및 성공률
- **운용 단계** — 학습 아키텍처 변경을 수반하므로 진단 목적 ablation으로만 운용

### (d) 먼저 확인할 점

- **Mamba 시간 인과성** — VBE의 causal Mamba는 고밀도 uniform sampling 가정에 최적화, 원격조작 데모는 속도 변동이 크고 희소한 접촉 이벤트가 표현에 묻힐 우려
- **Phase 경계 정의** — PBD의 phase conditioning은 task-level 진행 단계 사전 정의 전제, in-hand rotation처럼 접촉·이동·릴리즈 경계가 모호한 태스크에서 phase 레이블 없이 학습 가능한지 검증 필요

## 🥉 논문 3 — 우선순위 ★

**RoVLA: Multi-Consistency Constraints for Robust Vision-Language-Action Models**
[arXiv:2605.19678](https://arxiv.org/abs/2605.19678) · Jingzhou Luo, Yifan Wen, Yongjie Bai, Xinshuai Song, Yang Liu · 2026-05-19 · source: keyword-sweep (VLA generalization + backbone)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **방식** — backbone 파라미터를 건드리지 않고 학습 시 3가지 consistency 손실(IC·EC·OC)을 추가, VLM이 사전학습에서 습득한 의미·언어 결합을 보존
- **삽입 위치** — 세 consistency 손실은 VLM 동결 + 전문가 학습 단계에서 추가 학습 목표로 삽입 가능
- **보존 메커니즘**
  - IC(Instructional Consistency) — 동의어 표현에서도 stable grounding 유지
  - OC(Observational Consistency) — 시각 교란에 대한 과적합 억제
- **진정으로 새로운 점**
  - 단일 end-to-end 정책 내에 세 가지 보완적 invariance(instruction semantics·trajectory evolution·observation perturbation)를 동시에 강제하는 멀티 일관성 제약(multi-consistency constraint) 훈련
  - 기존 robustness 연구가 더 많은 데이터나 post-training에 의존한 반면, 정책 자체에 불변성을 내재화
  - LIBERO-Plus, RoboTwin 2.0, 실환경 조작에서 기준 모델 대비 일관된 향상

### (c) 시사점

- **보조 손실 도입 가능** — 학습 구성에 IC + OC 보조 손실을 도입하는 실험 계획 가능
- **동결 유지 근거 강화** — VLM 동결 상태에서도 언어 grounding이 다양한 표현에 견고하다면 완전 동결 유지 근거 강화
- **단계적 도입** — 증강 데이터 생성(파라프레이즈·시각 교란) 추가 비용 발생, IC 먼저 OC 이후로 단계적 도입

### (d) 먼저 확인할 점

- **증강 비용** — IC 손실은 지시 파라프레이즈 생성, OC는 관측 교란 샘플링 요구, 데모 수집 파이프라인에 온라인 증강 삽입 시 배치당 연산량 증가, 실질 throughput 저하 수준 선행 측정 필요
- **태스크 다양성 전제** — 논문 실험 태스크(LIBERO-Plus, RoboTwin 2.0)는 테이블탑 pick-and-place 위주, in-hand rotation처럼 접촉 집약적·세밀한 손가락 제어가 필요한 경우 IC·OC 증강 전략이 같은 방식으로 작동할지 검증 필요

## 🌱 논문 4 — 인접 분야 픽

**Octopus: History-Free Gradient Orthogonalization for Continual Learning in Multimodal Large Language Models**
[arXiv:2605.14938](https://arxiv.org/abs/2605.14938) · Yuehao Liu, Shanyan Guan, Weijia Zhang, Xuanming Shang · 2026-05-14 · adjacent field: continual learning for MLLMs · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **프레임워크** — 태스크 적응 → 정규화 2단계 진행 구조와 직접 대응
- **HiFGO** — History-Free Gradient Orthogonalization, 이전 태스크 데이터 재생(replay) 없이 gradient 레벨에서 직교성 강제
- **진정으로 새로운 점**
  - 과거 태스크 데이터를 저장·재생하지 않고도 gradient 레벨 직교성을 달성하는 History-Free 접근
  - 기존 replay 기반 방법의 개인정보·저장 비용 문제를 회피하면서 catastrophic forgetting 억제
  - MLLM(multimodal LLM) 대상 시험으로 VLA 맥락과 가장 유사한 연구 중 하나

### (c) 시사점

- **prior 보호 도구** — LoRA 학습 루프에 HiFGO 삽입, π 사전학습 gradient 방향을 "이전 태스크" proxy로 취급해 직교화 적용 시 사전학습 prior를 명시적으로 보호 가능

### (d) 먼저 확인할 점

- **벤치마크 격차** — Octopus 검증 벤치마크(UCIT)는 비로봇 MLLM 분류 태스크, VLA의 연속 액션 출력에서 gradient 직교화가 같은 방식으로 작동하는지 확인 필요
- **proxy 근사** — "이전 태스크" proxy를 π 사전학습 파라미터에서 어떻게 근사할지 확인 필요
