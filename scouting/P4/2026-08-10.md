## 🥇 논문 1 — 우선순위 ★★★

**JoyAI-RA 0.5: Scaling Robot Manipulation Learning via Dual Action Alignment**
[arXiv:2608.05674](https://arxiv.org/abs/2608.05674) · JoyAI-RA Team (Joy Future Academy, JD) · 2026-08-06 · source: citation-graph (Being-H0.5·π0·π0.5·GR00T N1·Qwen-VLA 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 로봇 시연 데이터 희소성 문제를, 에고센트릭 인간 비디오·시뮬레이션·실물 로봇 데이터를 함께 흡수하는 Vision-Language-World-Action(VLWA) 프레임워크로 해결
- Implicit 정렬(시각 전이에서 latent action 추론, 라벨 없는 데이터도 world model 학습에 활용) + Explicit 정렬(통합 물리 액션 공간, 카메라-프레임 상대 엔드이펙터 액션)의 이중 정렬로 이종 데이터를 하나의 학습 루프에 통합
- 사전학습 → world-action 사전학습 → 타깃 로봇 사후학습의 3단계 구성, world model은 동결한 채 VLM·액션 전문가만 학습
- 20,000시간 이상 규모의 자체 에고센트릭 데이터셋(EgoLive) 구축, 10/25/50/100% 중첩 서브셋으로 사전학습 데이터량만 단독 변수로 통제한 스케일링 실험 수행
- 실물 AgiBot 벤치마크에서 기존 과제·미보유 변형 과제 모두 강한 성능, 에고 데이터량 증가에 따라 성능이 최대 규모에서도 포화 없이 지속 개선

### (c) 시사점
- 에고센트릭 데이터가 사전학습 단계 스케일에서 실제로 이득을 주는지에 대한 통제된(단일 변수) 실증 근거 확보 — 지난주 다뤄진 합성 리타게팅 데이터 실증과는 다른 각도(원본 에고 비디오 자체의 스케일링)에서 같은 질문 보강
- 이종 데이터(라벨 있는 로봇·라벨 없는 인간 비디오·시뮬레이션)를 하나의 정렬 프레임워크로 통합하는 구체적 메커니즘 확보 — 데이터 확장 시 임베디먼트·라벨 이질성 문제의 실전 해법
- 사전학습 단계에서 world model을 동결하고 VLM·액션 전문가만 학습하는 구성이 대규모 에고 데이터 흡수에도 안정적으로 작동함을 확인

### (d) 먼저 확인할 점
- 자체 구축 EgoLive·AgiBot 벤치마크 모두 비공개 자산 — 원문에서 다양성 통계·태스크 정의 세부 확인 필요
- 산업 랩(JD) 테크리포트 형식으로 동료 심사 여부 불명, 재현 시 프로젝트 페이지 외 코드·체크포인트 공개 여부 확인 필요
- 스케일링 곡선이 8개 다운스트림 과제(PnP-Easy/PnP-Hard)에 한정 — 더 넓은 과제 분포·조작 난이도에서도 동일 추세가 유지되는지 원문 확인 필요

**SiMDex: Mining Similar Egocentric Videos for Cross-Embodiment Dexterous Manipulation**
[arXiv:2608.04196](https://arxiv.org/abs/2608.04196) · Nie Lin, Takehiko Ohkawa, Sijin Chen 외 10인 · 2026-08-04 · source: citation-graph (π0·π0.5 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 약 3,200만 개 에고센트릭 인간 샘플 풀에서 실제로 다지 조작에 도움이 되는 데이터가 무엇인지 규명하기 위해, 데이터 선별 문제를 추천 시스템 문제로 재정식화
- 로봇 시연 하나당 recall-ranking-re-ranking 3단계 파이프라인으로 과제 관련 서브셋을 추출하는 SiMDex 제안, VLA 아키텍처·학습 절차 변경 없이 임바디먼트-비특정 액션 공간에서 동작
- 무작위 샘플링 동일 규모 기준선 대비, 전체 풀의 5% 미만인 약 149만 개 마이닝 샘플만으로 실물 다지 조작 과제 전체 성공률을 47.7%에서 61.1%로 향상
- 무분별한 데이터 혼합보다 선별적 큐레이션이 우월함을 정량적으로 실증

### (c) 시사점
- 에고센트릭 데이터를 얼마나, 어떻게 섞을지에 대한 열린 질문에 "양보다 관련성"이라는 구체적 축을 정량 근거와 함께 제시
- 대규모 인간 비디오 풀 확보 이후의 병목이 데이터 총량이 아니라 선별 파이프라인에 있음을 시사 — 데이터 확보 전략과 별개로 선별 인프라 투자 가치 확인
- VLA 아키텍처 변경이 필요 없는 플러그인 방식이라 기존 파이프라인에 도입 비용이 낮음

### (d) 먼저 확인할 점
- 원문에서 로봇 시연 데이터가 산업용 조립(assembly) 단일 시나리오에 한정된다고 명시 — 조작 카테고리 다양성 확대 시 마이닝 파이프라인 재현성 확인 필요
- 3,200만 규모 에고센트릭 풀 자체의 출처·라이선스·이 확보 가능 여부 원문 확인 필요
- 추천 파이프라인(recall-ranking-re-ranking) 학습에 필요한 초기 시드 로봇 시연 규모·비용 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- VLA 모델이 사전학습된 VLM으로부터 물려받은 의미적 표현이 로봇 시연 파인튜닝 과정에서 실제로 얼마나 붕괴하는지, 거울 뉴런 이론에서 착안한 프로빙으로 체계적으로 진단
- 파인튜닝 진행에 따라 의미 구조가 점진적으로 소실되며, 이 소실 정도가 과제 성공률·OOD 일반화 성능과 동기화됨을 정량적으로 확인(π0 백본의 LIBERO-Goal 중간층 특징에서 t-SNE로 시각적 확인)

- 실물 양팔 로봇(AgileX Cobot Magic V2) 4개 과제 계열 + 5개 OOD 축(언어·위치·물체·시각·과제 조합)에서 π0 기준선 대비 ID +18.7%p, OOD +21.5%p 개선, ACT·Diffusion Policy와도 비교

### (c) 시사점
- 사전학습된 프라이어가 파인튜닝 중 "무엇이, 왜" 소실되는지를 진단 가능한 형태로 제시 — 보존 기법 설계 이전에 진단 도구로도 활용 가치
- π0 계열 백본에서 직접 검증된 사례라 이 정책 스택에 이식 시 아키텍처 변경 이질감이 적음
- 추론 시점 오버헤드 없이(학습 시에만 개입) 적용 가능한 보존 기법 후보

### (d) 먼저 확인할 점
- 실물 검증이 특정 양팔 플랫폼(AgileX Cobot Magic V2) 단일 하드웨어에 한정 — 다른 임바디먼트에서 정렬 레이어·정렬 목표 선정이 동일하게 유효한지 확인 필요
- 공유/사적 채널 분해와 대조 정렬 목표가 학습 비용(추가 forward pass, 대조 손실 계산)에 미치는 영향 원문 수치 확인 필요
- 최근 다뤄진 유사 프라이어 보존 기법(증류 기반)과의 상대적 우위·적용 상황별 트레이드오프는 원문에서 직접 비교되지 않음 — 자체 비교 필요
