**Riemann-1.0: An Embodied World Action Model for Physical AI**
[arXiv:2608.27033](https://arxiv.org/abs/2608.27033) · Haofeng Sun, Jiangbo Pei, Fei Kang, Zexiang Liu, Yaokun Li 외 11인 · 2026-08-27 · arXiv preprint · source: citation-graph (Being-H0.5·GR00T N1·Qwen-VLA 인용) · 코드 미공개

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 기존 World-Action-Model이 공동 생성·비디오 우선 예측·분리형 모델링 중 한 패러다임에 묶여 있다는 문제의식에서, 시각 관측·로봇 상태·임바디먼트별 액션을 하나의 인과적 자기회귀 시퀀스로 통합하는 **Riemann-1.0** 제안
- 로봇 액션과 월드 전이를 하나의 인과적 상태 전이로 표현, 실행 가능한 로봇 정책과 다중 임바디먼트 비주얼 월드 시뮬레이터 두 역할을 단일 모델로 동시 수행
- 에고센트릭 인간 비디오·핸드헬드 그리퍼 시연·이종 로봇 궤적을 하나의 월드-액션 모델링 목적함수 아래 순차적으로 통합하는 점진적 임바디드 사전학습 프레임워크 구축, 200,000시간 이상의 상호작용 데이터로 학습
- RoboTwin2.0·LIBERO·장기 구성형 벤치마크 RoboCasa-365에서 기존 최고 성능 대비 최대 8.4%p 앞서고, 실물 장기 조작 과제에서도 성공률 85.0%·진행성공률 94.4%로 최강 오픈소스 기준선 대비 성공률 15%p 초과 달성

### (c) 시사점
- 에고센트릭 인간 비디오·핸드헬드 시연·로봇 궤적을 순차적으로 접지하는 대규모 점진적 사전학습 설계가, 실물 성능까지 이어지는 정량 스케일링 근거로 참고 가능
- 로봇 정책과 월드 시뮬레이터를 분리하지 않고 단일 모델로 통합하는 구조가, 시뮬레이션·실물 양쪽에서 동시에 최상위 성능을 낸 구체적 사례로 참고 가능
- 시뮬레이션 벤치마크 3종과 실물 장기 조작 과제 모두에서 일관된 우위를 보여, 시뮬레이션 개선이 실물로 이어지지 않는 흔한 괴리를 피한 사례로 활용 가능

### (d) 먼저 확인할 점
- 코드·데이터·체크포인트 공개 여부가 초록·arXiv comment 모두에 명시되지 않아 재현 경로 확인 필요
- 16인 규모 연구팀과 200,000시간 이상의 상호작용 데이터가 전제, 이 규모의 코퍼스를 이 팀 밖에서 확보 가능한지 확인 필요
- 기존 세 WAM 패러다임(공동 생성·비디오 우선·분리형) 대비 구체적으로 어떤 조건에서 통합 모델이 우위를 보이는지 원문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**WLA³: World Latent Action Modeling for Semantics, Dynamics, and Kinematics**
[arXiv:2609.15870](https://arxiv.org/abs/2609.15870) · Peidong Liu, Zhiyuan Xiang, Mingyang Li, Wenhao Li, Jiale Zhang 외 2인 · 2026-09-14 · arXiv preprint · source: citation-graph (Being-H0.5 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 핵심 기여
- 이종 데이터로 제너럴리스트 정책을 스케일링하는 데 통일된 저잡음 액션 지도 신호가 부족하다는 문제 제기, 에고센트릭 비디오는 풍부하나 고품질 손-액션 라벨이 달린 비중은 작다는 데이터 제약 지적
- 관측된 월드 전이 자체를 데이터 소스 전반에 걸친 공통 액션 관련 지도 신호로 활용하는 **World Latent Action Model(WLAM)** 제안, 동기화된 카메라 시점과 임바디먼트 상태 변화를 압축된 로컬 잠재 액션과 전이 특징으로 인코딩
- 이 표현을 물리 동역학 모델링(잠재 액션)·VLM 직접 지도(세그먼트 수준 의미 특징)·로봇 제어 공동 예측(액션 전문가) 세 용도로 재사용하는 **WLA³** 프레임워크 구성, 인간 비디오가 확장 가능한 전이 지도를, 로봇 궤적이 실행 가능한 네이티브 제어 근거를 각각 제공
- LARYBench에서 32차원 잠재 액션 평균 분류 정확도 67.89%, 실물 로봇 6개 과제 평균 성공률 81.9%로 π0.5의 66.2% 상회, 제너럴리스트 정책 중간학습 데이터 규모 확대에 따라 성능이 함께 개선되고 인간 비디오가 인간-로봇 전이를 지지함을 확인

### (c) 시사점
- 손-액션 라벨이 부족한 에고센트릭 비디오도 월드 전이 관측만으로 액션 관련 지도 신호를 뽑아낼 수 있다는 구체적 방법 확보, 에고센트릭 비디오 활용도를 라벨링 비용과 분리하는 참고 사례
- 하나의 잠재 표현을 물리 동역학·VLM 의미 지도·로봇 제어 세 갈래로 동시에 재사용하는 설계가, 액션 표현 선택 논의에 구체적 대안으로 참고 가능
- π0.5 대비 15.7%p 앞서는 실물 6개 과제 성공률이, 유사 파이프라인 도입 시 기대할 수 있는 개선폭의 구체적 기준점으로 참고 가능

### (d) 먼저 확인할 점
- 코드 저장소 URL 없이 프로젝트 페이지만 공개돼, 공개 범위(모델·데이터·학습 코드)와 실제 접근 가능 여부 원문·페이지 확인 필요(네트워크 정책상 페이지 직접 접근 미검증)
- 7인 소규모 연구팀 결과로, π0.5 외 다른 백본·임바디먼트에서도 동일 우위가 유지되는지 확인 필요
- 월드 전이 기반 잠재 액션 학습 자체는 기존에도 다뤄진 프레이밍이라, 이번 제안이 기존 유사 기법 대비 정량적으로 어느 만큼 앞서는지 ablation 상세 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**What Makes an Efficient VLA? Navigating Action-Head Design, Scaling, and Latency**
[arXiv:2609.13984](https://arxiv.org/abs/2609.13984) · Luoyang Sun, Guoyang Xia, Fengfa Li, Lei Ren, Xinyu Cui 외 7인 · 2026-09-12 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 사전학습된 비전 인코더·언어 백본·액션 헤드로 구성된 VLA에서 각 구성요소의 상대적 기여가 지연시간을 통제한 조건에서 규명된 적 없다는 문제 제기, 백본 계열(SigLIP2·Qwen2.5)과 학습 파이프라인을 고정한 채 액션 헤드 설계·모듈 규모를 온디바이스 지연시간과 함께 통제 비교
- 액션 헤드 성능이 디코더 아키텍처·손실함수·추론 예산이 아니라 초기화 방식에 좌우됨을 규명, 언어 백본의 마지막 트랜스포머 레이어를 헤드로 복사하는 초기화가 지연시간 비용 없이 모든 모듈 규모에서 유효한 단일 최대 레버임을 확인
- 헤드가 정렬된 이후에야 모듈 용량 확장이 성능으로 이어지고, 현재 π 계열 VLA가 이미 쓰는 규모 근처에서는 추가 확장의 수익이 급격히 줄어듬을 확인
- 이 발견들을 반영한 경량 모델 **EffVLA** 구성, 표준 LIBERO에서 최강 오픈소스 VLA와 동등한 성능, LIBERO-Plus 교란 축 대부분에서 더 낮은 지연시간으로 우위, 동일 레시피로 실물 SO-ARM101 로봇에 전이

### (c) 시사점
- 액션 헤드 성능을 좌우하는 핵심 레버가 아키텍처·손실함수가 아니라 백본과의 초기화 정합이라는 결과가, 적응 단계 설계에서 무엇을 바꿔야 실제로 이득이 나는지 구체적 우선순위 제공
- 헤드 용량 확장이 정렬 이후에만 의미가 있고 현재 규모 근처에서 수익이 급감한다는 결과가, 무작정 모듈을 키우기보다 정렬 여부를 먼저 점검해야 한다는 저비용 점검 순서로 참고 가능
- 지연시간을 통제 변수로 명시한 비교 설계 자체가, 유사한 아키텍처 선택 실험을 설계할 때 재현 가능한 참고 틀로 활용 가능

### (d) 먼저 확인할 점
- 코드·모델 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 실물 SO-ARM101 전이가 "레시피 변경 없이" 이뤄졌다고만 기술, 구체적 정량 성공률이 초록에 제시되지 않아 원문 확인 필요
- SigLIP2·Qwen2.5 두 백본 계열에 한정된 결과로, 다른 계보(π0/PaliGemma 등)에서도 동일한 초기화 레버가 지배적인지 확인 필요
