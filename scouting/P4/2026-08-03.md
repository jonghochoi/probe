**Xiaomi-Robotics-U0: Unified Embodied Synthesis with World Foundation Model**
[arXiv:2607.11643](https://arxiv.org/abs/2607.11643) · Xinghang Li, Jun Guo, Qiwei Li 외 21인 · 2026-07-13 · source: citation-graph (π0.5 인용)

### (b) 핵심 기여
- 380억 파라미터 규모 멀티모달 자기회귀 모델로, 임베디드 장면 생성을 텍스트-이미지 생성·이미지 편집의 자연스러운 확장으로 취급하는 통합 프레임워크 Xiaomi-Robotics-U0 제시
- 텍스트-이미지 생성, 이미지 편집, embodied scene 생성, embodied transfer(세밀 편집), embodied video 생성을 하나의 목적함수로 공동 최적화 — 대규모 사전학습에서 획득한 시각 지식을 그대로 유지
- 멀티뷰 일관성과 상호작용 동역학을 보존하면서 구조적으로 제어 가능한 embodied transfer 최초 지원, 다중 로봇 임바디먼트에 걸친 고품질 멀티뷰 장면 생성 최초 시연
- GPT-Image-2.0 대비 embodied scene 생성·전이의 인간 평가 우위 확보, World Arena embodied video 생성 부문 1위
- 자체 생성 데이터를 π0.5 사후학습에 투입 시 도전적 실물 조작 과제의 OOD 성공률을 36.9%에서 63.2%로 향상 — 세계 파운데이션 모델이 embodied 세계모델이자 확장 가능한 데이터 엔진으로 동시에 기능함을 실증

### (c) 시사점
- 사전학습된 세계모델의 시각 지식을 그대로 보존하면서 로봇 도메인으로 확장하는 경로 — 별도 임베디드 전용 백본 구축 없이 데이터 증강 레버 확보 가능성 시사
- 동일 계열 핀 논문 정책(π0.5)의 실물 성능을 직접 끌어올린 사례 — 정책 자체의 아키텍처 변경 없이도 데이터 구성 축만으로 큰 개선폭을 낼 수 있음을 재확인
- 코드·체크포인트 공개로 이 파이프라인에 이식 검증 가능한 후보 확보

### (d) 먼저 확인할 점
- 380억 파라미터 규모 세계모델 자체의 학습·추론 비용이 상당 — 이 인프라에서 실질적으로 감당 가능한 규모인지 확인 필요
- π0.5 개선폭이 보고된 특정 challenging task 세트에 한정 — 더 넓은 과제 분포에서 동일 개선폭이 재현되는지 원문 확인 필요
- 생성 데이터의 물리적 정합성(접촉·마찰 등) 검증 방식과 실패 모드 원문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**WALA: Learning Executable Latent Actions from Action-Labeled Demonstrations and Action-Free Videos**
[arXiv:2607.11397](https://arxiv.org/abs/2607.11397) · Jiahao Liu, Zhongpu Xia, Shuai Tian 외 13인 · 2026-07-13 · source: citation-graph (π0·GR00T N1 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 핵심 기여
- 액션-라벨 로봇 시연과 액션 라벨이 없는 비디오를 함께 사용해 실행 가능한 latent action을 학습하는 WALA 프레임워크 제시
- 현재 관측과 성긴 미래 관측 간 변화를 모델링하되, 픽셀 대신 DINOv3 특징 공간과 깊이(depth) 델타를 예측 대상으로 삼아 과제 관련 의미·기하 구조를 보존하면서 외형 민감도를 낮춤
- 사전학습된 인코더는 안정적인 latent action target을, 디코더는 학습 가능한 latent world model 역할을 수행 — 로봇 액션 예측·latent action target 매칭·미래 동역학 예측 세 신호로 공동 지도학습
- 액션-라벨 시연은 실행 가능한 제어 지도신호를, 액션-프리 비디오는 로봇 액션 라벨 없이 동역학 지도신호를 제공하도록 역할 분리
- RoboTwin에서 강한 성능, RoboCasa에서 평균 성공률 75.2%로 신규 최고 성능 갱신, 실물 조작 과제에서도 정책 성능·일반화 개선 확인

### (c) 시사점
- 액션 라벨이 없는 대규모 비디오를 사전학습 신호로 흡수하는 구체적 메커니즘 확보 — 로봇 시연 데이터 확장의 병목 완화 경로로 검토 가치
- latent action을 통일된 액션 표현으로 사용하는 설계가 서로 다른 데이터 소스(라벨/비라벨)를 동일 학습 루프에 통합하는 실용적 해법으로 기능
- 의미·기하 특징 공간에서 예측 목표를 설정하는 방식이 픽셀 재구성 대비 더 안정적인 사전학습 신호를 제공한다는 근거 확보

### (d) 먼저 확인할 점
- 실물 조작 과제 결과의 정량 수치가 초록에는 구체적으로 명시되지 않음 — 원문에서 실물 성공률 세부 확인 필요
- latent action 사전학습에 필요한 비디오 규모·다양성 요구치가 이 확보 가능 데이터 규모와 맞는지 확인 필요
- DINOv3 특징·깊이 예측 파이프라인의 계산 비용이 기존 픽셀 기반 방식 대비 어느 정도인지 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Understanding and Mitigating the Video-Action Generalization Gap via Temporal Ratio**
[arXiv:2607.08127](https://arxiv.org/abs/2607.08127) · U. Mishra, Yongxin Chen, Danfei Xu 외 3인 · 2026-07-09 · source: citation-graph (π0·GR00T N1 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL)

### (b) 핵심 기여
- 생성형 비디오 파운데이션 모델이 가진 구성적(compositional) 사전 지식이 로봇 액션 데이터로 파인튜닝된 이후 소실되는 "video-action generalization gap" 현상을 정의하고 체계적으로 분석
- world-action model·video-action model 설계공간을 폭넓게 평가했으나 표준 설계 선택만으로는 이 격차를 설명하는 뚜렷한 패턴이 없음을 확인
- 액션 헤드가 현재 프레임 대비 미래 latent rollout에 얼마나 의존하는지를 측정하는 attention 기반 지표 Temporal Ratio(TR) 제안 — TR이 구성적 일반화 능력의 예측 변수로 기능하며, 과제 단계(계획/정밀 조작)에 따라 자연스럽게 변동함을 규명
- TR이 포착하는 특성을 활용해 정책이 미래 rollout에 의존하는 시점에 맞춰 구성적 비디오 조건화 신호를 동적으로 증폭하는 추론 시점(inference-time) adaptive guidance 기법 제안
- LIBERO 벤치마크와 실물 과제 평가에서 OOD-ID 구성적 일반화 격차 완화 확인

### (c) 시사점
- 사전학습된 생성적 prior가 다운스트림 파인튜닝으로 소실되는 문제를, 추가 학습 없이 추론 시점 개입만으로 완화할 수 있다는 대안 경로 제시
- 학습 단계의 보존 손실과는 다른 층위 — 배포 이후 추론 파이프라인에서 저비용으로 적용 가능한 보완 레버로 검토 가치
- 사전학습 prior 소실 여부를 사후적으로 진단하는 지표(TR)를 자체 평가 파이프라인에 참고 지표로 도입할 여지

### (d) 먼저 확인할 점
- 분석 대상이 world-action model·video-action model 계열로, 표준 VLM 백본 기반 정책에 동일 진단·개입이 유효한지 원문에서 재확인 필요
- 실물 과제 정량 수치가 초록에 구체적으로 명시되지 않음 — 원문에서 실물 성공률 세부 확인 필요
- TR 측정과 adaptive guidance 적용에 필요한 추가 추론 비용(레이턴시) 원문 확인 필요
