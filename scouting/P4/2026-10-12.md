### (b) 논문 요지

- VLA 적응 비용의 영역별 쏠림을 실측해 LoRA 랭크 배분
- **문제** — 배포 환경마다 반복되는 VLA 적응을 수십 개 시연의 저데이터로 감당해야 하는 비용
  - 외관·물체 형상·지시 문구 변화에 VLA 성능 저하, 현장마다 적응 반복
  - 전체 미세조정은 수십 개 시연으로 수십억 파라미터 갱신 — 저자 실물 실험에서 선택적 적응보다 보류 장면 성공률 낮음
- **기존 한계** — 지배적 전략인 균일 PEFT가 모든 네트워크 영역에 같은 조정이 필요하다고 암묵 가정
  - 균일 LoRA(전 층 고정 전역 랭크) — 시각 인코더·언어 백본·교차 모달 투영기·액션 헤드가 기능적으로 다른데도 같은 용량 배분, 무관한 영역 과잉·관련 영역 과소 배분
  - 비전 모델의 선택적 적응 선례, VLA 미세조정 중 비균일 LoRA 배분(LoRA-SP), 미세조정 후 표현 추적 — 미세조정 전에 소수 비라벨 관측으로 영역별 적응 수요를 측정한 사례 없음
- **핵심 방법** — 관측·진단·배분·적응 4단계 파이프라인
  - 관측 — 대상 환경의 비라벨 관측 10장 수집
  - 진단 — 미세조정 없이 영역별 적응 비용 추정, 캐시한 소스 기준 대비 CKA 점수(1단계)와 기준 없는 그래디언트·MC Dropout 신호(2단계)를 Fréchet 게이트와 결합 점수로 통합
  - 배분 — 추정치를 파라미터 예산 아래 가변 랭크 LoRA 어댑터로 변환, 잘 보정된 영역은 동결
  - 적응 — 표준 LoRA 미세조정으로 배분된 어댑터 학습
- **차별점** — 미세조정 시작 전에 적응 수요 분포를 측정하고 그 측정을 용량 배분으로 직접 변환
  - 동시 연구는 미세조정 중에 배분하거나 미세조정 후에 표현을 추적하는 사후 접근
- **핵심 기여** — 적응 스펙트럼 실측, 사전 진단 배분 알고리즘, 음성 결과를 포함한 실물 실험
  - 적응 스펙트럼 — OpenVLA-OFT·π0·SmolVLA·DTP·Octo(93M–7B) 5종, 5가지 통제 이동에서 외관 이동은 시각 인코더, 지시 이동은 언어 백본, 새 물체 이동은 시각 인코더와 액션 헤드에 비용 집중, 지배 영역이 5개 아키텍처 공통
  - 진단 정확도 — 배포별 영역 순위 중앙값 Spearman 0.91
  - 시뮬레이션 — LIBERO·CALVIN에서 시험한 모든 예산에서 균일 LoRA와 같거나 우위
  - 실물 xArm-7(OpenVLA-OFT) 지시 문구 이동 — 학습 파라미터 0.04%로 21/30, 전체 미세조정 22/30
  - 실물 보류 장면 5조건(재학습 없음) — 11–23/30, 가장 강한 PEFT 기준선 8–18/30(같거나 큰 예산), 전체 미세조정 2–11/30
  - 비교 기준선 11종(균일 LoRA·DoRA·AdaLoRA·LoRA-SP·Surgical 등), 5개 아키텍처·5 시드·6개 실물 이동
- **가치** — VLA 적응 비용이 미세조정 전에 측정 가능할 만큼 구조화돼 있다는 근거
  - 균일 어댑터 대신 진단 기반 용량 배분으로 더 적은 파라미터의 적응 경로 제시

### (c) 시사점

- VLM 동결 전제를 이동 유형별로 점검할 근거
- **적응 범위 판단 근거** — 외관·지시 문구 이동은 비용이 시각 인코더·언어 백본에 몰림, 액션 쪽만 학습하는 범위로는 못 덮는 이동 유형 존재 가능
  - 새 물체 이동은 시각 인코더와 액션 헤드에 함께 분포 — 액션 쪽 학습만으로는 부분 대응
- **현재 계보에 바로 대입 가능** — π0이 측정 대상 5종에 포함
- **도입 비용 낮음** — 비라벨 관측 10장, 7B 기준 진단 약 90초, 미세조정 불필요
- **범위 확장 시점의 측정 도구 후보** — 잘 보정된 영역은 동결하는 배분 결과가 백본 보존 방향과 일치, 확장 여부를 진단 점수로 판단 가능

### (d) 먼저 확인할 점

- **실물 범위** — 실물 평가는 OpenVLA-OFT 하나, xArm-7 평행 그리퍼 하나, π0 실물 결과 없음
- **적응 단계 데이터** — '비라벨'은 진단에만 해당, 적응에는 약 20개 라벨 시연 필요(저자 명시)
- **음성 결과** — 목표를 가리는 실물 공간 이동에서 중요도 신호가 퍼져 배분 전략 간 차이 없음, 제안 배분 16/30 대 AdaLoRA 19/30(유의하지 않음)
- **비교 프로토콜** — 전체 미세조정 대비 우위는 공통 10 에폭 체크포인트 기준, 따로 조기 종료한 전체 미세조정보다 우월함은 미입증(저자 명시)
- **코드 없음** — 저장소·공개 약속 없음, 진단 재구현 필요
- **이전 비용** — 몸통·손을 나눈 액션 전문가 구조에선 영역 분할(시각 인코더·언어 백본·투영기·액션 헤드) 재정의 필요

**점수 11/15** · R3 · N3 · M2 · Real3 · Repro0 — 초록·본문에 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 에고-로봇 공동 사전학습 3방식을 같은 조건에서 실물 비교
- **문제** — 에고센트릭 인간 상호작용 데이터를 체화 기반 모델 사전학습에 효과적으로 넣는 방법이 불분명
  - 로봇 시연은 수집 비용·하드웨어 제약·과제·환경·물체 다양성 한계로 체화 기반 모델 확장의 병목
  - 에고 영상은 실행 가능한 행동 라벨이 없고, 추정한 손 동작이 로봇 명령과 형태·기구학·좌표계·외관에서 차이
- **기존 한계** — 행동 리타깃팅·임바디먼트 정렬·잠재 행동·월드 모델 목적함수 등 기존 연결 방식이 각각 고립적으로 연구됨
  - 다수가 대규모 사전학습이 아닌 후학습 단계에서만 작동
- **핵심 방법** — VLA·WAM 두 아키텍처에서 세 가지 공동 학습 패러다임을 같은 데이터·연산 조건으로 사전학습해 비교
  - Atom-DH — 지각·언어·행동 표현은 공유하고 최종 행동 투영만 에고·로봇 헤드로 분리한 공동 학습
  - Atom-CL — 에고 사전학습 → 과제 정렬 인간·로봇 시연(공통 엔드이펙터 상대 자세 표현)으로 정렬 학습 → 로봇 사전학습의 3단계 커리큘럼, 각 단계가 앞 단계 체크포인트에서 시작
  - Atom-WAM — Fast-WAM 초기화 후 에고·로봇 영상-행동 공동 모델링
  - VLA 두 방식은 π0.5 구조를 쓰되 π0.5 정책 체크포인트가 아닌 PaliGemma VLM 가중치에서 초기화
  - 코퍼스 — 로봇 약 1,560시간(AgiBot World Beta·DROID·RoboCOIN·RoboMIND·자체 Piper 양팔), 에고 EgoVerse 약 1,079.5시간, 정렬 데이터 약 20시간
- **차별점** — 단일 메커니즘에 고정하지 않고 도메인 분리·명시 정렬·영상 예측 통합 세 경로를 통제 조건에서 나란히 비교
  - 정렬 전용 변환은 소량 정렬 데이터에만 적용, 전체 코퍼스 재처리 불필요
- **핵심 기여** — 코퍼스, 세 패러다임 구현, 통제 비교, 경험 원칙
  - 큐레이션 코퍼스와 확장형 처리·품질 관리 파이프라인 — 초록·§3.1은 약 2,659시간(334,054 에피소드), 서론은 3,033시간으로 표기
  - 실물 양팔 플랫폼 7개 과제, 과제당 ID 10회·OOD 10회(체크포인트당 140회) — Atom-CL이 ID 64.29%·종합 53.57%로 VLA 기준선 대비 +21.43·+20.71%p
  - OOD — VLA 기준선 22.86% 대비 Atom-DH 41.43%, Atom-CL 42.86%
  - Atom-WAM은 WAM 기준선보다 하락, 종합 28.57% → 20.71%
  - 원칙 — 데이터 규모 × 정렬 품질 → 능력 향상, 에고 데이터의 가치는 정렬·활용 방식에 좌우
- **가치** — 에고 데이터를 사전학습에 넣는 방식 선택에 대한 통제 비교 근거와 실무 지침
  - 에고 데이터 규모 확대만으로는 부족하고 정렬 품질이 함께 필요하다는 결론

### (c) 시사점

- 에고 → 정렬 → 로봇 순서가 가장 일관된 이득
- **사전학습 데이터 구성 판단 근거** — 에고 데이터를 섞기만 한 방식보다 정렬 단계를 거친 점진 이전이 ID·종합 최고, 에고 중심 구성의 효과가 정렬 방식에 달렸다는 조건부 근거
- **단계 순서 설계 참고** — 에고 → 소량 정렬 → 로봇 커리큘럼의 실물 측정치 확보
- **가까운 출발 조건** — PaliGemma VLM 가중치와 π0.5 구조에서 시작, 현재 계보와 같은 계열
- **정렬 데이터 비용 낮음** — 약 20시간 정렬 데이터만 공통 엔드이펙터 표현으로 변환
- **영상 예측 경로 반례** — 영상-행동 공동 모델링은 기준선보다 하락, 영상 목적함수를 사전학습 신호로 쓰는 안의 경고

### (d) 먼저 확인할 점

- **실물 표본 규모** — 단일 양팔 플랫폼, 과제·조건당 10회 시행
- **코퍼스 규모 표기 불일치** — 2,659시간(초록·§3.1) 대 3,033시간(서론)
- **규모 한계** — 자원 제약으로 사전학습 코퍼스 규모 제한, 단일 방식 최적화보다 방식 비교에 초점(저자 명시)
- **적응 효율 축 부재** — 모든 방식이 같은 7개 과제 데이터로 후학습 후 평가, 후학습 데이터량을 바꾼 비교는 실험 구성에 없음
- **코드 없음** — 저장소·공개 약속 없음
- **이전 비용** — 정렬 단계가 인간 손 자세를 단일 엔드이펙터로 취급, 손가락 관절 정렬 없음 — 다지 손 행동 공간에선 정렬 표현 재설계 필요

- **기존 한계** — 연속 사전학습을 대규모 행동 적합으로만 다루는 단순 방식의 세 가지 실패 모드
  - 전체 종단 갱신 — 웹 규모보다 좁은 로봇 궤적이 범용 시각-언어 특징을 잠식
  - 단일 액션 헤드 지도 — 백본이 그 헤드의 디코딩 기하에 과특화, 다른 헤드로의 전이 제한
  - 임바디먼트별 출력 공간 — 그리퍼 개폐처럼 물리적으로 비슷한 행동을 분리된 헤드로 표현해 교차 임바디먼트 공유 약화
- **핵심 방법** — 사전학습된 VLM(Qwen3-VL-4B)에서 출발해 공개 다중 임바디먼트 로봇 데이터(DROID·InternA1·RoboCoin·MolmoAct)로 백본을 연속 사전학습
  - VLM 사전 보존 — 시각 인코더와 LLM 하위 절반 층 동결, 캡션·그라운딩 데이터 혼합
  - 다중 헤드 연속 행동 공동 지도 — OFT·PI·GR00T 헤드를 함께 붙여 단일 헤드 과특화 방지
  - 부분 통일 교차 임바디먼트 행동 배치 — 비활성 차원 마스킹, 주기 관절용 wrap-aware 손실
  - 미세조정 시 사전학습 헤드·캡션 스트림을 버리고 새로 초기화한 과제별 액션 헤드를 붙여 전체 모델 학습
- **차별점** — VLM을 시각-언어 사전학습에서 물려받는 고정 부품이 아닌 VLA의 1차 설계 변수로 취급
  - 비교마다 백본 가중치만 바꾸고 액션 헤드·하류 데이터·옵티마이저·미세조정 예산을 고정, 7.6–21.4pt 향상을 백본에 귀속
- **핵심 기여** — 시뮬레이션·실물·미경험 임바디먼트 전이 전반의 하류 성능 향상
  - 시뮬레이션 — LIBERO-Plus 82.6%(같은 백본 계열 Qwen3VL-OFT 75.0%), VLA-Arena 54.8%, RoboTwin 2.0 92.5%, ABot-M0·LingBot-VLA 등 산업 VLA 상회
  - RoboDojo — 점수 10.66, 성공률 7.60%로 성공률 기준 6위, 명시적 WAM 항목 전부 상회
  - 미경험 휴머노이드 RoboCasa-GR1 — 하류 궤적 20%로 49.5%, 전체 데이터 GR00T-N1.6 47.6% 상회
  - 실물 Franka Research 3 — 단일 팔 단기 ID 평균 92.5%(사전학습 없는 Qwen3VL-4B-OFT 77.5%), 양팔 협응 72.0%(44.0%), 과제당 10회
  - 얕은 층 보호 절제(부록 C) — 전체 갱신 LIBERO-Plus 78.9%, 시각 인코더만 동결 81.3%, 시각 인코더와 LLM 하위 절반 동결 82.6%
  - 공개 데이터와 16 GPU 학습 설정만으로 달성
- **가치** — 데이터 확장과 별개인 독립 축으로서 연속 사전학습 설계의 효과 제시
  - 고정 자원 예산에서 백본 설계만으로 산업 시스템과 경쟁 가능한 성능

### (c) 시사점

- 백본만 바꿔 7.6–21.4pt — 계보 선택이 1차 변수
- **계보 선택 근거** — 액션 헤드·데이터·예산을 고정하고 백본만 바꾼 측정, 초기 가중치 × 추가 사전학습 코퍼스 조합이 하류 성능을 가르는 단위라는 관점의 직접 근거
- **추가 사전학습 중 보존 수단** — 시각 인코더·하위 층 동결과 캡션 혼합을 절제로 측정, 보존을 배포 적응이 아닌 사전학습 단계에서 거는 선택지
- **적은 데이터 적응 근거** — 미경험 휴머노이드에서 하류 데이터 20%로 전체 데이터 기준선 상회
- **공개 기준점 확보** — 모델·학습 파이프라인 공개, 16 GPU 설정으로 재현 가능한 출발점
- **헤드 교체와 맞물림** — PI 헤드 포함 다중 헤드로 학습 후 새 헤드를 붙이는 프로토콜, 플로우 매칭 액션 전문가를 새로 붙이는 구성과 호환

### (d) 먼저 확인할 점

- **실물 비교 기준선 하나** — 실물은 사전학습 없는 Qwen3VL-4B-OFT와만 비교, 과제당 10회
- **백본 계열 차이** — Qwen3-VL-4B 기반, PaliGemma 계보에서의 효과는 미측정
- **절제는 부록** — 얕은 층 보호·캡션 혼합·헤드 다양성 절제가 부록 C–F에 위치
- **공개 표기 차이** — arXiv comment는 공개 완료, 본문 §4는 학습 스크립트·체크포인트 공개 예정으로 표기
- **이전 비용** — 하류 미세조정에서 전체 모델을 풀어 학습, VLM 전체 동결로 적응하는 설정에서의 이득은 별도 확인 대상

## 🌱 논문 4 — 인접 분야 픽

**A Deafening Silence: Catastrophic Forgetting Lives in the Output Embeddings of Tokens the Data Never Speaks**
[arXiv:2610.09835](https://arxiv.org/abs/2610.09835) · Jonghyun Han, Younghoon Song, Jongyoul Park · adjacent field: 연속 학습·파국적 망각(LLM)

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — 초록·본문에 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- LLM 망각은 드문 토큰의 출력 임베딩에 집중
- **문제** — 원 사전학습 데이터 없이 연속 사전학습·미세조정할 때 파국적 망각이 어디서 왜 생기는지
  - 리플레이는 원 데이터를 섞어야 하지만 그 데이터는 대개 접근 불가
- **기존 한계** — 완화 연구와 위치 규명 연구 양쪽의 공백
  - 데이터 프리 방어(파라미터 선택, 저랭크 어댑터, 직교 부분공간 투영) — 전체 파라미터 표류를 무차별 제약해 가소성을 희생하고 보존 확보
  - 위치 규명 연구 — 초기 어텐션·하위 층·FFN 등 서로 다른 위치 보고, 주로 가중치 변위 같은 상관 지표에 의존
  - 저랭크 출력 모드에 망각이 집중한다는 이론은 있으나 그 모드를 담은 텐서는 미규명
- **핵심 방법** — 학습 중 파라미터 그룹을 사전학습 값으로 고정해 각 그룹의 인과적 망각 기여를 분리
  - 위치·2차 모멘트 대역·코퍼스를 바꿔 원인 위치를 노출이 적은 토큰의 출력 임베딩으로 특정
  - 기제 — 부재 토큰이 받는 지속적 단방향 softmax 그래디언트를 Adam의 2차 모멘트 정규화가 전체 크기 갱신으로 증폭
  - 개입 — 출력 투영에만 Adam ε를 높이는 한 줄 옵티마이저 조정
- **차별점** — 상관 지표가 아닌 학습 중 동결로 망각 위치를 인과적으로 특정하고 그 텐서만 겨냥
  - 전체 표류를 묶는 기존 데이터 프리 방어와 달리 목표 학습 손실 없이 보존
- **핵심 기여** — 인과적 위치 규명, 기제 해명, 출력 한정 ε, 경계 조건
  - 위치 — 5개 안정 설정에서 망각의 31–51%가 드문 토큰 출력 임베딩, 같은 대역의 본체는 10% 미만
  - 위치는 학습 방식이 아닌 코퍼스 어휘 결핍이 결정, 토큰 수만으로 재학습 전 위험 순위 추정
  - 출력 한정 ε — 160M–12B, 4개 모델 계열, 8개 설정 중 안정적인 7개에서 망각 39.4–67.9% 제거, 목표 학습 저하·원 데이터·모델별 튜닝 불필요
  - 리플레이와 가산 이상 결합(Qwen·한국어 79.8%), released-head LoRA의 23배 망각 급증 방지
  - 경계 — 표류한 행의 사후 편집은 망각의 5% 미만 회복, 개입은 학습 중이어야 함
  - 3 시드 평균 보고, 질량을 맞춘 대조군 포함
- **가치** — 원 데이터 없이 옵티마이저 설정 하나로 망각을 줄이는 1차 방어 수단 제시

### (c) 시사점

- 보존 수단을 망각 위치 진단 뒤 좁게 거는 사례
- **보존 전략의 다른 축** — 전체 파라미터를 묶는 대신 망각이 몰린 텐서만 겨냥, 어댑터·백본 동결식 보존과 다른 선택지
- **출력 층 점검 가설** — 동결 백본 위 새 출력 층을 학습할 때도 같은 Adam 증폭 기제가 작동하는지 점검 가치
- **도입 비용 낮음** — 옵티마이저 ε 한 줄 변경, 추가 데이터·연산 없음
- **사전 위험 진단 아이디어** — 새 코퍼스의 어휘 결핍으로 재학습 전 망각 위험 순위 예측, 추가 사전학습 코퍼스 점검에 대응시킬 여지

### (d) 먼저 확인할 점

- **로봇 실험 없음** — LLM 언어 코퍼스 결과뿐, VLA나 연속 행동 출력에서의 재현 미검증
- **기제의 전제** — 좌표별 적응 옵티마이저에만 해당, Muon 등은 범위 밖(저자 명시)
- **효과 불균일** — Pythia-410M 한국어에서 6개 시드 중 2개는 회복 미미하고 목표 학습 손실
- **분포 내 미세조정** — 망각이 본체로 이동하면 본체 ε 억제가 측정한 두 조건 중 한 곳에서 학습 비용 발생
- **코드 없음** — 저장소·공개 약속 없음
- **이전 비용** — 연속 플로우 매칭 행동 헤드에는 어휘 softmax가 없어 '부재 토큰' 기제의 직접 대응물 없음, VLM 언어 출력 층 보존 쪽이 적용 후보
