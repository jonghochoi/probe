### (b) 논문 요지

- 모션 잠재를 액션으로 삼아 인간 93.2% 데이터로 사전학습
- **문제** — 휴머노이드는 전신 협응이 필요한 큰 액션 공간과 부족한 시연 데이터 탓에 지시 추종 범용 정책이 없음
  - 다리·몸통·팔·손가락이 함께 움직여야 해서 관절 명령을 직접 예측하면 협응과 지시 해석을 한 번에 학습해야 함
  - 기존 휴머노이드 범용 정책은 과제마다 원격조종 시연으로 파인튜닝해야 배포 가능
- **기존 한계** — 인간 모션 데이터를 쓰는 기존 방식이 로봇 시연을 요구하거나 리타깃팅 결과에 의존
  - 로봇이 사람을 따라 하게 하며 기록하는 방식은 시연마다 로봇 필요
  - 인간 모션을 로봇으로 리타깃팅해 지도 신호로 쓰는 방식도 존재
  - 기존 휴머노이드 범용 정책은 과제별 로봇 시연 파인튜닝에 의존
- **핵심 방법** — 정책이 관절 명령 대신 몸통·손 모션 잠재를 예측하고 사전학습된 컨트롤러가 관절 명령으로 변환
  - 몸통 — 기존 잠재 모션 컨트롤러(SONIC)의 인간·로봇 공유 잠재 공간 사용
  - 손 — 같은 구조로 따로 사전학습한 손 인코더·컨트롤러가 손가락 명령 생성
  - 정책 입력은 에고센트릭 이미지, 지시문, 고유수용감각이며 인코더와 컨트롤러는 정책 학습 중 동결
- **차별점** — 인간 녹화를 정책의 액션 공간에서 바로 라벨링
  - 인간 인코더가 모션을 잠재 타깃으로 바꾸므로 시연마다 로봇이 같은 동작을 수행할 필요 없음
- **핵심 기여** — 학습 코퍼스 구성, 실물 제로샷 결과, 백본 일반성
  - 훈련 시연 풀 1.406억 프레임 중 93.2%가 인간 데이터, 변환 결과 781시간
  - Unitree G1 실물에서 과제별 파인튜닝 없이 이동 100% 성공, GR00T N1.7 16.7%와 Ψ0 0% 대비
  - 같은 조건에서 조작 88.6% 성공, 노트북 닫기·코트 걸기·의자 회전 과제
  - 같은 방식을 VLA 백본 2종과 월드-액션 모델 백본 1종에서 검증
  - 인간 시연만으로 학습한 정책이 실물 이동을 제로샷 수행
- **가치** — 로봇 시연 없이 인간 녹화를 휴머노이드 범용 정책 사전학습 자원으로 쓰는 경로 제시

### (c) 시사점

- 인간 비중 93.2% 코퍼스로 실로봇 제로샷을 보고한 극단 사례
- 사전학습 코퍼스의 인간 대 로봇 비율이 실로봇 제로샷 성능과 함께 보고되는 보기 드문 수치
- 액션 공간을 관절 공간에서 모션 잠재 공간으로 옮겨 인간 데이터를 라벨 변환만으로 편입하는 설계
- 저자 한계 서술상 조작은 로봇 단독 학습이 더 높아 인간 데이터의 이득이 행동별로 갈림

### (d) 먼저 확인할 점

- **저자 명시 한계** — 평가가 Unitree G1 한 대에서 13개 과제, 과제당 5회 시행
- **인간 데이터의 이득 범위** — 인간 후 혼합 학습은 이동을 개선하지만 조작은 로봇 단독 학습이 더 높음
- **손 제어** — 손 디코더가 접촉력 피드백 없이 손가락 위치 명령만 생성, 잡기와 유지에서 어려움 잔존
- **외부 모듈 의존** — 수행 가능한 동작이 사전학습된 몸통·손 모듈의 표현 범위에 묶임
- **코드 신호** — 공개 예정 문장만 있고 저장소 URL 없음

## 🥈 논문 2

**What Matters for Latent Actions in Robot Learning**
[arXiv:2608.19613](https://arxiv.org/abs/2608.19613) · Xizhou Bu, Qingda Hu, Lei Zhou 외 13인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 9/15** · R3 · N2 · M2 · Real1 · Repro1 — arXiv comment "Project page: https://carldegio.github.io/latent_action.github.io"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- 잠재 액션 설계 41종을 한 틀에서 비교한 실증 연구
- **문제** — 잠재 액션 모델(LAM)의 어떤 설계가 하류 조작 성능을 좌우하는지 불명
  - 로봇 액션 데이터는 웹 규모 영상·이미지-텍스트 대비 수 자릿수 부족
  - 라벨 없는 영상에서 액션 대리 표현을 뽑는 LAM 연구가 파편화
- **기존 한계** — 설계 선택이 각기 따로 제안되고 일관되지 않은 설정에서 평가됨
  - 연속 프레임에서 잠재 액션을 학습하는 방식, 정규화 방식, 물리 액션 예측에 통합하는 방식이 논문마다 다름
  - 잠재 액션 품질의 대리 지표는 사전학습 단계에서 MLP 프로브의 예측 오차를 쓰는 것이 관행이나 하류 성능 예측력은 미검증
  - 하류 성능 측정은 3단계 학습 파이프라인 전체가 필요해 반복 개발 비용이 큼
- **핵심 방법** — 대표 LAM을 공통 오토인코딩 틀로 통일하고 3개 축에서 41개 설계 선택을 체계적으로 비교
  - 축 1 — 잠재 액션 모델링 패러다임
  - 축 2 — 학습 목표와 정규화
  - 축 3 — 잠재 액션 통합 전략, 5종 평가
  - LIBERO, LIBERO-Plus, RoboTwin2.0에서 평가하고 Franka Panda 실물로 추가 검증
- **차별점** — 설계 선택을 한 틀에서 동일 조건으로 분리 비교하고 대리 지표의 신뢰도까지 검증
  - 대리 지표 4종과 하류 조작 성능의 상관을 분석
- **핵심 기여** — 설계 지침 5개 묶음
  - 원래 LAPO가 원시 데이터 직접 학습에서 여전히 강한 베이스라인, 사전학습 시각 인코더의 특징 차분만으로도 경쟁력 있는 잠재 액션 확보
  - 정규화 방식은 하이퍼파라미터를 맞추면 하류 성능이 비슷, 통합 전략 5종 평가로 지침 도출
  - 잠재 액션 차원 32가 평가 벤치마크 평균 최고
  - FDM 재구성 지표가 프로브 지표보다 하류 성공률을 더 잘 반영하나 거친 모델 선별용이며 최고 모델 식별에는 불충분
  - 잠재 액션으로 VLM 백본을 파인튜닝하면 하류 정책 초기화가 강해지고 OXE 데이터로 2단계 코퍼스를 늘리면 성능 향상
  - 실물 Franka Panda 4과제에서 원래 OpenVLA-OFT 64.75%(259/400)가 파인튜닝 백본 적용 시 79.25%(317/400)
- **가치** — 잠재 액션 설계의 기준점과 VLM 백본 초기화 효과에 대한 통제된 증거 제공

### (c) 시사점

- VLM 백본을 잠재 액션으로 먼저 파인튜닝하면 하류 초기화가 강해진다는 통제 증거
- 사전학습 단계 하나를 추가해 같은 하류 학습에서 더 빨리 수렴, 실물에서 10k 스텝 85.0%가 40k 스텝 기준선 76.25%를 상회
- 라벨 없는 영상으로 백본을 먼저 적응시키는 중간 단계의 효과 크기 가늠 가능
- 백본이 OpenVLA 계열이라 PaliGemma 계열 계보에 그대로 대응하지는 않음

### (d) 먼저 확인할 점

- **실물 범위** — 단일 7자유도 Franka Panda 팔과 4과제에 한정
- **백본 범위** — 파인튜닝 백본 효과의 실물 검증이 OpenVLA-OFT 하나
- **저자 명시 한계** — 휴머노이드·사족보행·다지 손 등 다른 플랫폼으로의 일반화는 미검증
- **대리 지표** — 최고 모델 식별에는 불충분하다고 저자가 직접 밝힘
- **코드 신호** — 프로젝트 페이지만 있고 저장소 URL 없음

## 🥉 논문 3

**Juno: Taming Predictive Latents for Vision-Language-Action Models**
[arXiv:2610.09940](https://arxiv.org/abs/2610.09940) · Yuchen Zhu, Chenyi Xu, Yulin Zhang, Gang Xu, Wentao Zhu · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 9/15** · R2 · N2 · M2 · Real2 · Repro1 — arXiv comment "Project Page: https://juno-policy.github.io/"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- 하나의 JEPA로 사전학습·정책 학습·배포 적응을 잇는 틀
- **문제** — 예측형 잠재가 VLA에 도움이 된다는 점은 확인됐으나 사전학습, 정책 학습, 배포 세 단계 모두에서 쓸모 있게 만드는 방법이 불명
  - 사전학습 — 인터넷 영상 표현은 시각적으로 강하나 임바디먼트별 제어 가능 동작과 어긋남
  - 정책 학습 — 예측 목표가 시각-언어 경로에 붙어 예측 그래디언트가 제어와 간섭하고, 미래에 정렬된 상태가 액션으로 디코딩 가능하다는 보장이 없음
  - 배포 — 큰 분포 이동에서 동결 교사 자체가 보정 불량이 되고 실패 롤아웃은 정책 목표로 쓸 수 없음
- **기존 한계** — 예측 목표를 공유 시각-언어 경로에 얹는 기존 방식은 제어와 간섭
  - 배포 적응 방법들은 신뢰할 수 있는 동결 교사를 가정
- **핵심 방법** — 액션 조건 JEPA 하나를 제어 정렬 표현 백본, 예측 교사, 적응형 동역학 모델 세 역할에 사용
  - 사전학습 — 정책 학습과 같은 임바디먼트 매칭 궤적에서 픽셀부터 학습하고, 동적 CLS 손실로 모션 가중 패치 동역학을 전역 토큰에 전달
  - 정책 학습 — 현재 프레임 JEPA 패치를 VLA 시각 토큰에 융합하고, 별도 변환 파라미터의 분리된 추론 분기가 동결 교사의 미래 잠재 상태를 증류해 플로우 매칭 액션 디코더를 조건화
  - 배포 — 실패 롤아웃을 포함한 모든 전이로 월드 모델을 적응시키고 교사를 동결한 뒤 검증된 실행으로 LoRA 어댑터와 액션 헤드를 재정렬
- **차별점** — 실패한 행동은 나쁜 정책 목표이지만 그 결과는 유효한 동역학 감독이라는 비대칭을 활용
  - 정책 갱신 전에 월드 모델 쪽을 먼저 적응시켜 교사 오차와 정책 오차의 혼동 방지
- **핵심 기여** — 세 단계별 기여와 시뮬레이션·실물 결과
  - 임바디먼트·제어 분포에 맞춘 교사가 사전학습 규모만큼 중요할 수 있다는 주장
  - SimplerEnv에서 가장 강한 베이스라인 Qwen3GR00T 평균 성공률 60.9%를 68.5%로, 테스트 시 적응으로 72.7%까지 상승
  - 실물 로봇에서 배경·높이·물체 변화 아래 70–75% 성공 유지, 기본 정책은 0%로 붕괴
- **가치** — 예측형 잠재를 사전학습부터 배포까지 하나의 모델로 일관되게 운용하는 설계 제시

### (c) 시사점

- 단계마다 적응 범위를 다르게 두는 구성의 사례
- 사전학습은 JEPA 전체, 정책 학습은 동결 교사 증류, 배포는 LoRA와 액션 헤드로 범위를 좁혀 가는 단계 구성
- 실패 롤아웃까지 쓰는 배포 적응이 재정렬 범위를 LoRA와 액션 헤드로 제한해 앞 단계 사전학습 결과 보존
- VLM 계보 선택과는 별개로 시각 표현 백본을 교체하는 축의 증거

### (d) 먼저 확인할 점

- **통제 범위** — 사전학습 JEPA가 정책 학습과 같은 임바디먼트 매칭 궤적으로 학습되어 대규모 코퍼스 구성 질문의 증거는 아님
- **실물 수치** — 70–75%의 시행 수와 평가 과제 수 확인 필요
- **적응 한정** — 배포 적응 수치는 SimplerEnv와 실물 설정에 한정
