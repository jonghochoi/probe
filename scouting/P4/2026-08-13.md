## 🥇 논문 1 — 우선순위 ★★★

**Wh0: Generative World Models as Scalable Sources of Egocentric Human Hand Manipulation Data**
[arXiv:2606.22136](https://arxiv.org/abs/2606.22136) · Yangtao Chen, Zixuan Chen, Peiyang Wang, Yong-Lu Li, Jing Huo, Jieqi Shi, Yang Gao · 2026-06-20 · source: citation-graph (Being-H0.5 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여
- 다지 조작 학습이 스케일-정합성 트레이드오프에 갇혀 있음을 지적 — 텔레오퍼레이션은 정합적이나 고비용, 시뮬레이션은 확장적이나 Sim2Real 갭, 실제 에고센트릭 비디오는 확장적이나 로봇 배포와 불일치
- 생성형 비디오 world model을 언어·물체·장면 조건으로 구동해 5만 에피소드 규모의 에고센트릭 인간-물체 상호작용 비디오(WM-H)를 합성하는 Wh0 프레임워크 제안
- 합성 비디오를 손 동작 재구성과 시각 편집을 통해 로봇 학습 가능한 지도 신호로 변환, 소량의 실제 로봇 데이터와 함께 co-training해 사전학습된 VLA 모델을 다지 조작 배포로 적응
- 18개 실물 다지 조작 과제에서, 로봇 데이터만으로 사후학습한 모델 대비 미보유 과제 제로샷 성공률을 8.3%에서 38.9%로 개선
- Ablation으로 확장 가능한 생성과 장면/임바디먼트 정합성이 성능 향상의 핵심 동인임을 확인

### (c) 시사점
- 에고센트릭 데이터를 실제로 수집하지 않고도 생성형 world model로 대량 합성해 조작 데이터 부족을 완화하는 구체적 경로 확보
- 텔레오퍼레이션(정합·고비용) vs 실제 에고 비디오(확장·불정합) 트레이드오프를 생성형 합성으로 우회하는 실증 사례 — 데이터 확보 전략의 제3의 축
- 소량의 실제 로봇 데이터와 결합한 co-training만으로 적응 효과가 나타나, 배포 단계 데이터 효율성 개선에도 직결

### (d) 먼저 확인할 점
- 합성 비디오의 물리적 타당성(접촉·힘 상호작용 등)이 실제 에고 비디오 대비 얼마나 정확한지 원문 확인 필요
- 18개 과제가 특정 실험실 환경·물체 세트에 한정될 가능성 — 더 넓은 물체·장면 분포에서도 동일 이득이 유지되는지 확인 필요
- world model 자체의 사전학습 비용(생성 품질 확보에 필요한 데이터·연산량)이 원문에 정량화되어 있는지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**TEMPO: Semantic-Action Decoupled RL Post-Training for Vision-Language-Action Models**
[arXiv:2608.07314](https://arxiv.org/abs/2608.07314) · Ziheng Liu, Quantao Yang · 2026-08-07 · source: keyword-sweep

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여
- 지도 미세조정(SFT)의 분포 불일치 문제와, 강화학습(RL) 후학습이 모델 전 구성요소를 동일한 업데이트 전략으로 다루는 한계를 지적
- 사전학습된 시각-언어 백본을 동결해 일반 의미 표현을 보존하고, 의미 투영층과 저수준 액션 전문가 두 구성요소에만 별도 RL 최적화 루프를 부여하는 TEMPO 제안
- 의미 투영층은 느리게(잠재 액션 안정성 유지), 액션 전문가는 빠르게(온라인 상호작용 피드백 신속 반영) 업데이트하는 이중 시간축 전략으로 분리
- CALVIN 벤치마크와 실물 조작 과제에서, 사전학습된 최신 VLA 모델 및 단일 업데이트 전략 RL 기준선 대비 일관된 성능 우위, 실물 2개 과제에서 평가 보상 유지
- 코드 저장소를 익명 리뷰 페이지(anonymous.4open.science)로 공개

### (c) 시사점
- 백본 동결 + 구성요소별 차등 적응이라는 자사 기본 전략을 SFT가 아닌 RL 후학습 맥락으로 확장한 사례 — 별도 축의 보강 근거
- 느린-빠른 이중 시간축 분리가 의미 표현 붕괴를 방지하면서도 온라인 학습 효율을 유지하는 구체적 메커니즘 제시
- 실물 로봇에서 평가 보상 기반 검증까지 확보해, 시뮬레이션 벤치마크에 그치지 않는 근거 수준

### (d) 먼저 확인할 점
- 코드 공개가 익명 리뷰 페이지 형태로, 정식 게재 후 지속 접근 가능 여부 불명 — 재현 전 공식 저장소 전환 확인 필요
- 실물 검증이 2개 과제로 제한적 — 과제 다양성 확대 시 이중 시간축 업데이트 비율이 그대로 유효한지 확인 필요
- 저자 2인의 소규모 연구로 동료 심사·대규모 벤치마크 비교(π0/π0.5/GR00T N1 등과의 직접 비교)가 원문에 있는지 확인 필요

## 🥉 논문 3 — 우선순위 ★

**LA4VLA: Learning to Act without Seeing via Language-Action Pretraining**
[arXiv:2606.27295](https://arxiv.org/abs/2606.27295) · Tao Lin, Yuxin Du, Yiran Mao 외 13인 · 2026-06-25 · source: citation-graph (π0 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여
- 밀도 높은 시각-액션 지도 신호가 상대적으로 희소한 언어-액션 신호를 압도해, 정책이 언어 조건화 대신 시각적 지름길에 의존하게 되는 문제를 지적
- 기존 시연 궤적을 원자적 액션 구간으로 분해하고 각 구간에 저수준 액션 서술을 결합해, 시각 관측 없이 언어-액션 사전만으로 학습하는 LA4VLA 제안 — 추가 로봇 데이터 수집 없이 기존 시연에서 3.3만 에피소드(LA-33K) 생성
- 경량 1B 파라미터 VLA 모델(LA4VLA-1B)로 LA 단독 사전학습·순차적 LA→VLA 사전학습·혼합 LA-VLA 사전학습 세 가지 패러다임을 비교
- 혼합 LA-VLA 사전학습이 사전학습 미적용 기준선 대비 시뮬레이션 17.8%p, 실물 45.0%p 성공률 개선으로 가장 우수
- GitHub 코드 공개(MINT-SJTU/LA4VLA)

### (c) 시사점
- 추가 로봇 데이터 수집 없이 기존 시연을 재가공해 사전학습 신호를 확보하는 저비용 레시피 축 확보
- 사전학습 단계에서 무엇을, 어떤 순서로 넣을지에 대한 통제된 3-way 비교 — 레시피 설계 시 참고할 정량적 근거
- 실물 성능 개선폭(45.0%p)이 시뮬레이션(17.8%p)보다 커, 시각 지름길 의존 완화가 실배포 환경에서 더 크게 작동할 가능성 시사

### (d) 먼저 확인할 점
- LA-33K가 기존 시연 궤적의 재라벨링에 의존 — 원본 시연 품질·다양성이 낮으면 언어-액션 사전 품질도 제한될 가능성, 원문에서 데이터 품질 관리 절차 확인 필요
- 경량 1B 모델 기준 실험이라 대형 백본(π0/π0.5 등)에서도 동일 이득이 재현되는지 확인 필요
- 원자적 액션 구간 분해·서술 생성 파이프라인의 자동화 수준(수작업 여부)과 새 임바디먼트 적용 비용 원문 확인 필요

- **관찰** — TEMPO는 현재 v1 기본 전략(백본 동결 + 어댑터형 프라이어 보존)이 SFT뿐 아니라 RL 후학습 맥락에서도 유효하다는 독립적 보강 근거 — 다만 저자 2인의 소규모 연구·실물 검증 2과제로 근거 강도는 제한적, 트리거 임계치 미달
- **대상** — D21 (단계적 사전학습·적응 레시피)
- **관찰** — LA4VLA는 "무엇을 사전학습에 넣을지"의 순서·조합(언어-액션 사전 vs 로봇 사전학습)에 대한 통제 비교 근거 제공 — 현재 커리큘럼 논의(ego→robot 순서, 아직 미결)와는 다른 축(언어-액션 vs 시각-액션)이라 별개 근거로 축적 필요, 트리거 임계치 미달

### Anti-topics
- **후보 제안** — 이번 회차 키워드 스윕에서 VLA 대상 적대적 공격/방어류 논문(예: 물리적 패치 공격, 확산 기반 무제약 공격) 2편이 관련성 낮음으로 조기 배제 — "적대적 강건성/공격-방어 논문(사전학습 구성·계보 레버 없음)"을 명시적 anti-topic으로 추가하는 안을 제안, 다음 회차 재관측 시 확정 검토 권고
