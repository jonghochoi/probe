- 잠재 액션 학습을 사전학습 레시피에 넣을지 여부와 그 방식(파인튜닝 vs 동결)을 결정할 때 참고할 구체적 실증 지표 확보

### (b) 핵심 기여
- 가장 강력한 로봇 파운데이션 모델일수록 비공개 데이터로 학습돼 폐쇄 가중치로 남는 경향 지적, LLM 커뮤니티를 뒤따라 등장한 관리형 지도 미세조정(SFT) API 접근 방식은 가중치·그래디언트·학습 내부 정보 없이 학습 데이터만 제출해 튜닝된 정책을 받는 구조로, 강화학습 등 폐쇄 루프 개선을 원천적으로 배제한다는 한계 지적
- Gemini Robotics On-Device(GROD)를 실물 휴머노이드에 적용해 관리형 API 적응 체제의 유효성을 검증하는 최초의 실증 연구 중 하나 수행
- API를 통한 직접 SFT가 동일 시연으로 학습한 대표적 오픈 웨이트 VLA를 크게 앞서지만, 민첩하고 접촉이 집약적인 과제의 배포 수준 숙련도에는 못 미침을 확인
- 배포 시점 보상 피드백을 API 호환 지도 데이터로 변환해, 가중치·그래디언트·우도·손실 접근 없이도 폐쇄 루프 정책 개선을 가능케 하는 **CLIFT(Closed-Loop Iterative Fine-Tuning)** 제안
- 두 차례의 플라이휠 사이클만으로 GROD를 "모델 박스를 열지 않고도" 거의 완벽한 성공률로 끌어올림을 실물 휴머노이드로 확인

### (c) 시사점
- 가중치에 전혀 접근할 수 없는 완전 폐쇄 모델에서도, 배포 데이터를 지도 신호로 재가공하는 것만으로 폐쇄 루프 개선이 가능함을 실물 로봇으로 입증 — 프라이어를 건드리지 않는 적응 전략의 극단적 사례
- API 기반 관리형 파인튜닝이라는, 자체 가중치 보유 없이도 강력한 파운데이션 모델을 적응시키는 대안 경로의 실효성과 한계(순수 모방으로 도달 가능한 수준의 상한)를 동시에 확인
- SFT 단독 → 폐쇄 루프 플라이휠이라는 2단계 적응 레시피가, 가중치 접근이 전혀 없는 극단적 제약 조건에서도 유효함을 확인

### (d) 먼저 확인할 점
- Gemini Robotics On-Device 자체가 완전 폐쇄 API-only 모델로, 이 가 동일 방식을 재현하려면 대상 모델 제공사가 관리형 SFT API를 제공해야 한다는 전제 조건 확인 필요
- 두 차례 플라이휠 사이클의 구체적 반복 횟수·소요 시간·비용이 원문에 정량화되어 있는지 확인 필요
- 오픈 웨이트 VLA 기준선 대비 비교는 있으나 원문에 별도 ablation이 있는지, 폐쇄 루프 개선 폭 중 보상 피드백 품질이 기여하는 비중이 분리돼 있는지 확인 필요

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL)

### (b) 핵심 기여
- 사전학습된 VLA를 여러 스킬에 순차 적응시키면 이전 스킬이 쓰던 표현·속도 매핑이 흔들려 치명적 망각이 발생, 아키텍처 기반 접근은 스킬을 격리해 망각을 줄이지만 추론 시 자원 소모가 커지고, 최근 서브스페이스 제약 기법은 모델 전체에 단일 제약을 부과하는 한계 지적
- VLA 내부 구성요소를 분석해 VLM은 광범위한 의미 표현을 유지해 용량 고갈에 취약하고, 액션 헤드는 국소적 속도 패턴을 정제해 교란에 특히 민감하다는 두 가지 VLA 특유의 문제 규명
- VLM과 액션 헤드에 서로 다른 서브스페이스 제약을 별도로 부과해, 재사용 가능한 의미 용량은 보존하면서 국소 속도 패턴은 별도로 보호하는 **OrthoSkillVLA** 제안
- 최종 속도 디코더(출력층)에는 특징 공간 친화도에 따라 학습 없는 라우터가 스킬별 컴팩트 전문가를 선택하는 경량 전문가 혼합 디코더 도입
- 시뮬레이션·실물 평가 및 ablation을 통해, 데모 재생 없이도 이전 스킬을 더 잘 보존하면서 새 스킬을 습득함을 확인

### (c) 시사점
- 백본을 균일하게 다루는 대신 VLM과 액션 헤드를 서로 다른 민감도의 구성요소로 구분해 별도 보존 전략을 적용하는 세분화된 접근 확보
- 데모 재생(replay) 없이 순차 스킬 학습이 가능해, 배포 후 스킬을 늘려갈 때 이전 데이터 재저장·재학습 부담을 줄이는 경로로 참고 가능
- 학습 없는 라우터로 스킬별 전문가를 선택하는 구조라 추론 시 추가 학습 비용 없이 확장 가능

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- "확장적 실물 평가"의 구체적 과제 수·성공률 수치가 초록에 제시되지 않아 원문에서 정량 규모 확인 필요
- 서브스페이스 제약을 몇 개까지 누적할 수 있는지(스킬 수 증가에 따른 확장 한계) 원문 확인 필요

## 🥉 논문 6 — 우선순위 ★★

**Vid2WAM: Distilling Video Diffusion Priors into World Action Models**
[arXiv:2608.08558](https://arxiv.org/abs/2608.08558) · Chenhao Qiu, Ruixiang Wang, Runyi Zhao, Sixu Lin, Songen Gu 외 5인 · 2026-08-09 · arXiv preprint · source: carry-forward 재검토(2026-08-17 최초 관측, 4축 게이트 재확인) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- World Action Model(WAM)의 확장성·일반화가 비용이 큰 전문가 시연 의존에 제약된다는 문제 지적, 미래 예측에 필요한 지도 신호가 반드시 목표 과제의 전문가 궤적에서 나와야 하는지 질문
- 대형 비디오 파운데이션 모델의 시각적 diffusion prior를 컴팩트한 WAM 학생 모델로 오프라인 증류하는 **Vid2WAM** 제안
- 과제 조건부 미래 롤아웃으로 학생의 미래 예측 분기를 직접 지도하고, 역동역학 모델로 임바디먼트별 의사-액션을 복원해 액션 학습에 활용하는 두 경로 병행
- 공유 액션 백본 주변에 소스별 보정을 학습하는 소스-인지 잔차 액션 적응으로, 잡음 섞인 의사-액션의 간섭을 완화하며 합성·실제 지도 신호를 통합
- 추론 시에는 비디오 교사·역동역학 모델을 모두 버리고 WAM 학생만 남겨 저지연 배포, 시뮬레이션·실물 실험에서 신규 과제 일반화와 데이터 효율성 개선 확인

### (c) 시사점
- 대형 비디오 파운데이션 모델을 사전학습 prior로 재사용해 목표 과제의 전문가 시연 의존도를 낮추는 경로 확보, 전문가 데이터 확보 비용이 큰 과제에 참고 가능
- 합성 지도 신호와 실제 지도 신호를 하나의 액션 백본에서 소스별로 분리 보정하는 구조가, 서로 다른 출처의 데이터를 함께 사전학습에 섞을 때의 간섭 완화 사례로 참고 가능
- 추론 시점에는 경량 학생 모델만 남아 저지연 요구와 양립 가능한 배포 형태 확보

### (d) 먼저 확인할 점
- 핵심 프레이밍이 World Action Model 축에 가까워, VLM 백본 계보·조성 레버로의 직접 적용 가능성은 원문에서 별도 확인 필요
- 코드·데이터 공개는 프로젝트 웹사이트만 확인되고(네트워크 정책상 실접근 미검증), 실제 공개 시점·범위 확인 필요
- 부록에 기재된 실물 로봇 실험이 시뮬레이션 결과만큼 상세한 정량 수치를 제공하는지 원문 확인 필요
