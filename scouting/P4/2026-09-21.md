## 🥇 논문 1 — 우선순위 ★★

**Not All Layers Need Tuning: Diagnosing and Directing Adaptation in Vision-Language-Action Models**
[arXiv:2609.18084](https://arxiv.org/abs/2609.18084) · Shahram Najam Syed, Arthur Jakobsson, Prayuj Sachdev, Jeffrey Ichnowski · 2026-09-16 · arXiv preprint · source: citation-graph (π0 인용) · 코드 미공개

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- 새 배포 환경에 맞춰 VLA를 파인튜닝할 때 모든 네트워크 영역에 동일 용량의 어댑터를 적용하는 관행에 문제 제기, OpenVLA-OFT·π0·SmolVLA·DTP·Octo 등 9,300만–70억 파라미터 규모의 아키텍처가 서로 다른 5개 VLA에서 이 가정을 직접 검증
- 영역별 적응 비용을 영역 고립 파인튜닝 하의 정규화된 파라미터 변위로 측정, 외형 변화는 비전 인코더에, 지시문 변화는 언어 백본에, 신규 물체 변화는 비전 인코더와 액션 헤드에 비용이 집중되는 적응 스펙트럼을 5개 아키텍처 전원에서 공통 확인
- 파인튜닝 없이 라벨 없는 목표 관측 10개만으로 영역별 비용을 미리 추정하는 진단, 이를 파라미터 예산 하의 가변 랭크 LoRA 어댑터로 변환하는 할당, 정합도가 높은 영역은 동결하는 관측-진단-할당-적응 파이프라인 제안
- 진단이 배포별 영역 순위를 스피어만 상관계수 중앙값 0.91로 예측, LIBERO·CALVIN 전 예산 구간에서 균일 LoRA와 동등 이상, 실물 xArm-7에서 지시문 문구 변화 조건에 전체 파인튜닝 대비 0.04% 파라미터만으로 대등한 성능 달성

### (c) 시사점
- 적응 범위를 균일하게 적용하지 않고 영역별 비용을 파인튜닝 전에 미리 진단해 예산을 배분하는 구체적 방법론 확보, 백본 동결 후 어느 영역을 얼마나 열지 결정하는 데 재현 가능한 절차로 참고 가능
- π0를 포함한 5개 아키텍처 전원에서 일관된 적응 스펙트럼이 관측돼, 백본 계보를 바꾸더라도 재사용 가능성이 높은 진단 신호로 참고 가능
- 라벨 없는 목표 관측 10개만으로 사전 진단이 가능하다는 결과가, 배포 전 저비용 사전 점검 절차의 구체적 하한선으로 참고 가능

### (d) 먼저 확인할 점
- 코드·모델 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 4인 소규모 연구팀 결과로, 검증된 5개 아키텍처 밖의 계보에서도 동일 적응 스펙트럼이 유지되는지 확인 필요
- 실물 평가가 xArm-7 단일 플랫폼·held-out 5개 장면에 한정, 더 넓은 임바디먼트·과제 범위에서의 일반화는 원문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**UMI-Bridge: Action-Anchored Latent Alignment across Human and Robot Manipulation Data**
[arXiv:2609.18232](https://arxiv.org/abs/2609.18232) · Haiyi Liu, Jingming Ma, Ke Rui, Yuteng Wei, Yuan Ma 외 10인 · 2026-09-16 · arXiv preprint · source: citation-graph (π0 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL)

### (b) 핵심 기여
- 로봇 실측 시연 부족 문제에, 에고센트릭 비디오와 핸드헬드 UMI 시연 등 로봇 없이 수집한 인간 조작 데이터를 활용하되, 시점·임바디먼트·액션 지도 신호 차이로 픽셀 유사도가 아닌 모션 등가성 기준 정렬이 어렵다는 문제 제기
- UMI를 인간 비디오와 로봇 데이터 사이 중간 도메인으로 삼아, 엔드이펙터 모션과 그리퍼 거동에 잠재 표현을 고정하는 **UMI-Bridge** 제안, 동기화된 헤드-리스트 관측과 페어링된 에고-UMI 클립으로 시점·도메인 간 정렬 지지
- 로봇 시연 없이 인간 조작 데이터만으로 듀얼뷰 잠재 액션 모델(LAM)을 학습한 뒤, 손목 교사와 동역학 모델을 동결해 UMI·로봇 데이터 상의 VLA 사후학습을 정칙화하는 2단계 구조 구성, 공유 손목 인터페이스로 정책의 표준 추론 아키텍처를 그대로 유지
- 실물 로봇 3개 과제에서 평균 성공률 91.7%로 동일 UMI·로봇 데이터 조건의 Naive Co-training(73.3%) 상회, 데이터 효율 과제 2종에서 로봇 시연 25%만으로 전체 데이터 Robot-only 기준선 상회, UMI 시연만으로 학습한 별도 과제 2종에서도 85%·90% 성공률 달성

### (c) 시사점
- 로봇 시연 없이 인간 비디오·UMI 데이터만으로 학습한 동결 모듈을 하위 VLA 학습의 정칙화 신호로 쓰는 2단계 구조가, 프라이어 보존 전략에 사람 비디오 유래 대안을 구체적으로 제공
- 동일 데이터 조건에서 단순 co-training 대비 큰 폭의 성공률 격차가, 인간 비디오·로봇 데이터를 그냥 섞기보다 액션 등가성 기준 정렬을 별도로 설계할 가치가 있다는 정량 근거로 참고 가능
- 로봇 시연 25%만으로 전체 데이터 기준선을 넘어선 결과가, 에고센트릭·UMI 데이터 확충이 실측 로봇 데이터 수집 비용을 상쇄하는 구체적 비율로 참고 가능

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 15인 규모 연구팀 결과로, π0 계열 밖 다른 백본·계보에서도 동일 정칙화 구조가 유지되는지 확인 필요
- 성능 비교 기준선이 Naive Co-training과 Robot-only 두 가지에 한정, 더 정교한 기존 인간-로봇 정렬 기법 대비 우위는 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**Improving Imitation Learning Efficiency for Manipulation through Geometric Prior Pretraining**
[arXiv:2609.12721](https://arxiv.org/abs/2609.12721) · Shogo Iwakata, Tomohiro Motoda, Ryosuke Yamada, Koshi Makihara, Ryoichi Nakajo 외 6인 · 2026-09-11 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 핵심 기여
- 새 조작 과제에 정책을 적용할 때마다 새 시연 수집·재학습이 필요해 표본 효율이 실무적 관건이라는 문제의식에서, 과제별 데이터 수집 이전에 거의 무비용으로 제공 가능한 유용한 프라이어가 무엇인지 질문
- 평면·물체·손만 존재하는 장면으로 궤적을 자동 생성하는 기하학적 시각 사전학습 데이터셋 구성, 텍스처·배경을 모두 제거해 손-물체 간 기하학적 관계만 노출, 손을 큐브로 표현해 특정 로봇 형태에 종속되지 않도록 설계
- ACT 정책을 시뮬레이션 로봇 3종 × 과제 5개씩과 실물 로봇 과제 3종에서 평가, 다수의 로봇-과제 조합에서 처음부터 학습 대비 기하학적 프라이어로부터 파인튜닝한 쪽이 학습 초기 단계에 더 높은 성공률 달성
- 매우 단순화된 기하학적 장면만으로도 과제 데이터가 제한적일 때 로봇 간·실물 전이가 가능한 유용한 초기화를 제공함을 확인

### (c) 시사점
- 대규모 로봇 데이터셋 수집 없이도 거의 무비용의 합성 기하 데이터만으로 파인튜닝 초기 표본 효율을 끌어올리는 저비용 대안 확보, 사전학습 구성 논의에 에고센트릭·혼합 데이터와는 다른 축의 참고 사례로 활용 가능
- 손을 큐브로 추상화해 특정 로봇 형태에 종속되지 않는 설계가, 여러 임바디먼트에 걸쳐 재사용 가능한 사전학습 자산을 저비용으로 구축하는 구체적 방법으로 참고 가능
- 사전학습 후 소수 시연 파인튜닝이라는 2단계 구조 자체가, 단계적 사전학습·적응 레시피 논의에 극단적으로 저비용인 사전학습 단계의 하한 사례로 참고 가능

### (d) 먼저 확인할 점
- 코드·데이터셋 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- "다수의 로봇-과제 조합"이라고만 기술, 전체 조합 중 개선이 관측되지 않은 비율과 그 원인이 초록에 제시되지 않아 원문 확인 필요
- 대규모 실측 로봇 데이터셋 사전학습과의 직접 정량 비교 없이 처음부터 학습(scratch) 대비 우위만 보고, 상대적 경쟁력은 원문 확인 필요
