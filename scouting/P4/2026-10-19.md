**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — 초록 "We will release our code, models, and data to support further research."

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 500시간 전신 인간 데이터와 3단계 학습으로 휴머노이드 정책 구축
- **문제** — 휴머노이드 이동 조작 정책이 요구하는 전신 협응과 손-물체 상호작용 시연을 대규모로 확보하기 어려움
  - 전신 원격조작 시연은 로봇 시간과 인력이 많이 들어 과제·환경 단위로 확장하기 어려움
- **기존 한계** — 에고센트릭 인간 영상 기반 지도는 전신 협응을 담지 못함
  - 영상에서 손목·손 궤적을 복원해 행동 지도로 쓰는 방식 — 접근, 자세 조정, 잡은 채 운반 같은 몸통과 손-물체 상호작용의 시간 협응을 보존하지 못함
  - 전신 원격조작 — 비용 때문에 다양성 확보에 한계
- **핵심 방법** — 몸통·손 모션이 동기화된 인간 데이터로 3단계 학습, 인간·로봇 차이는 도메인별 인터페이스가 흡수
  - 데이터 — 경량 웨어러블로 에고센트릭 영상과 몸통 모션을 기록하고 손 모션은 영상에서 복원한 HumanVerse-500
  - Stage I — 다양한 에고센트릭 데이터셋에서 손 모션 중심 상호작용 사전학습
  - Stage II — HumanVerse-500으로 몸통·손 모션을 맞추는 전신 모션 중간학습
  - Stage III — 하위 과제와 로봇 기종에 맞춘 로봇 후학습
  - 단계 간 전이는 인간·로봇 공유 표현 공간이 맡고, 상태·행동 차이는 도메인별 인터페이스가 처리
- **차별점** — 손목·손 궤적에 그친 에고센트릭 사전학습 위에 몸통 모션을 동기화한 전신 중간학습 단계를 추가
  - 로봇 원격조작이 아니라 웨어러블로 수집한 전신 인간 데이터가 전신 지도 공급원
- **핵심 기여** — 데이터셋, 3단계 정책, 규모와 단계 효과를 측정한 실험
  - HumanVerse-500 — 개방 환경 500시간, 에고센트릭 영상·몸통 모션·손 모션 동기화
  - 실물 4과제(과제·정책당 초기 배치 10개) 평균 성공률 62.5%, 가중 진행도 80.4%, 최강 외부 기준선 대비 각각 22.5%p, 25.8%p 우위
  - 시뮬레이션 SIMPLE 전체 성공률 90.0%, StarVLA 대비 3.9%p, Ψ0 대비 4.4%p 우위
  - 단계 절제(실물 성공률/진행도) — 전체 62.5%/80.4%, Stage I 제거 50.0%/75.9%, Stage II 제거 22.5%/59.9%, 둘 다 제거 15.0%/54.0%
  - Stage II 데이터 비율 0%에서 100%로 늘리면 실물 진행도가 59.9%에서 80.4%로 단조 증가
  - 로봇 시연에 없는 물체에서 인간 시연으로 유도한 정책의 진행도 55.8%, 최강 기준선 π0.5 46.5%, 로봇 단독 변형 제로샷 48.4%
  - 검증 손실이 5%에서 100% 데이터로 대표 홀드아웃 35.5%, clean 홀드아웃 40.6% 감소
- **가치** — 로봇 없이 수집한 전신 인간 데이터가 휴머노이드 이동 조작의 확장 가능한 지도 자원임을 단계별 측정으로 제시

### (c) 시사점

- 전신 인간 중간학습이 에고 손 사전학습보다 실물 기여가 큼
- **단계 순서의 실물 측정** — 단계 절제에서 Stage II 제거 시 성공률 하락 40.0%p, Stage I 제거 시 12.5%p
  - 에고센트릭 사전학습, 인간 모션 중간학습, 로봇 후학습으로 이어지는 단계 레시피의 각 단계 기여를 분리한 자료
- **데이터 조성 비교 재료** — 에고센트릭 손 데이터와 전신 인간 데이터를 단계별로 나눠 얻는 이득을 측정, 에고 중심 대 혼합 질문에 쓸 수 있는 실물 근거
  - 직전 회차 VioLA(2610.12435)의 조작 과제 로봇 단독 우위와 방향이 다른 결과
- **규모 신호** — 데이터 비율에 따른 진행도 단조 증가는 인간 데이터를 더 모으는 쪽에 유리한 근거
- **도입 비용** — 전신 모션을 기록하는 웨어러블 수집 체계와 몸통 제어 인터페이스가 선행 조건

### (d) 먼저 확인할 점

- **평가 범위** — 로봇은 G1 한 기종, 풀사이즈 휴머노이드 전이는 저자도 미검증
- **인간-로봇 정렬** — 체형·시점·가능 동작 차이로 정렬이 불완전하다고 저자 명시
- **규모 곡선의 한계** — 검증 손실 선형 적합이 단일 시드라 시드 간 재현성과 외삽은 저자도 보증하지 않음
- **표본 크기** — 실물 과제당 시행 10회, 과제별 격차는 작은 횟수에 민감
- **시뮬레이션 비교 조건** — 공개 SIMPLE 리더보드 항목은 각자의 원 프로토콜을 유지, 직접 평가한 쪽은 StarVLA와 자체 모델
- **코드 공개 예정** — 저장소 URL 없음

### (b) 논문 요지

  - WAM은 영상 생성 사전지식을 상속하고 구현 경험으로 실행 가능한 제어 신호로 바꿈
- **기존 한계** — 기존 시스템은 모놀리식

  - 결합 탓에 요인별 기여를 통제해 비교하기 어려움
- **핵심 방법** — 공개 연구 스택 OpenWAM이 WAM 사전학습을 통제 실험 프로그램으로 전환

  - OpenWAM-Study — 무엇을 상속할지, 세계 학습과 행동 학습이 어떻게 상호작용할지, 시너지가 어떻게 확장되는지 세 질문을 통제 실험으로 검토
  - OpenWAM-α — 도출한 원리를 조합해 에고센트릭 인간·로봇 데이터 약 6,400시간으로 사전학습한 공개 WAM
- **차별점** — 한 모델을 제시하는 대신 모듈 위에서 요인을 하나씩 바꿔 원리를 증류
- **핵심 기여** — 세 원리와 공개 스택, 사전학습 모델
  - 상속 — 상류 지식은 충분히 강한 생성 백본과 압축적이고 정보가 풍부한 잠재 공간을 통해 전이
  - 상호작용 — 세계-행동 시너지에는 전용 행동 용량, 세계에서 행동으로 가는 명시적 정보 흐름, 동기화된 공동 노이즈 제거가 필요
  - 규모 — 구현 사전학습은 주로 도메인 밖 일반화를 개선, 에고센트릭과 로봇 데이터의 1단계 공동학습이 세계 커버리지와 행동 접지를 통합

  - 인프라, 평가 프로토콜, 사전학습 모델, 데이터 레시피 공개
- **가치** — WAM 사전학습의 설계 선택을 같은 틀에서 비교할 수 있는 공개 기준점 제공

[arXiv:2609.34199](https://arxiv.org/abs/2609.34199) · Chuan Qin, Shaoting Zhu, Siyuan Luo, Siqiao Huang 외 3인 · arXiv preprint · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, arXiv comment는 프로젝트 페이지 주소(`https://wb-wam.github.io`)뿐

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 몸통·루트·손 주석을 한 액션 공간으로 묶은 사전학습
- **문제** — 휴머노이드 이동 조작 정책에 필요한 전신 액션 커버리지가 기존 로봇 사전학습에 부족
  - 인간형 몸통, 루트, 다지 손의 협응된 동작을 직접 지도하는 데이터와 행동 인터페이스 부족
  - 영상, 몸통, 손 주석이 모두 갖춰진 학습 시퀀스를 요구할 수 없다는 점이 핵심 난점
- **기존 한계** — 기존 로봇 사전학습은 단일 팔, 양팔, 바퀴형 이동 시스템 중심
  - 데이터와 행동 인터페이스가 몸통·루트·손 모션을 직접 지도하지 못함
  - 에고센트릭 조작 기록은 몸통 모션이 없고 모션 컬렉션은 영상이 없는 상보적 구조
- **핵심 방법** — Fast-WAM 위에서 생성형 영상 사전학습에 명시적 전신 액션 지도를 편입
  - 액션 표현 — 몸통 관절 참조, 루트 모션, 관절식 손 상태를 하나의 72차원 물리 공간에 배치, 주석이 있는 좌표만 채움
  - Stage I — 약 1,900시간(초록 기준 1,880.2시간) 부분 주석 영상·모션으로 영상과 액션을 함께 학습
  - Stage II — 리타깃팅한 PICO 시연으로 에고센트릭 관측과 공유 액션 공간을 짝지어 전문화
  - Stage III — 과제별 시연과 순기구학(FK) 보조 지도로 로봇 과제에 적응
  - 배포 — 몸통·루트 참조는 SONIC이 실행하고 손 참조는 관절 명령으로 직접 전달
- **차별점** — 불완전한 주석 소스를 버리지 않고 한 액션 공간에서 함께 학습
  - 과제에 맞춘 인간 모션을 로봇 적응 직전 중간 지도로 삽입
- **핵심 기여** — 전신 사전학습 레시피, 데이터셋, 시뮬레이션과 실물 결과
  - WB-Datasets — PICO 시연 22시간과 8개 과제의 로봇 에피소드 1,011개
  - 시뮬레이션 HumanoidArena 평균 성공률 81.9%, 7개 과제 모두 보고된 최강 기준선 상회
  - 실물 5개 과제 평균 성공률 84.0%, 최강 평가 기준선 80.0% 상회, 이동이 필요한 3개 과제는 76.7% 대 71.7%
  - 과제 정합 PICO 중간학습 후 로봇 시연 30개로 평균 성공률 73.8%, 시연 100개 직접 적응 65.0%보다 높아 로봇 시연 70% 절감
  - 같은 시연 30개 예산의 직접 적응은 48.8%
  - 언어 조건 조작과 시각 일반화 연구 부가
- **가치** — 불완전 주석의 인간 모션을 전신 사전학습 자원으로 쓰는 경로와 로봇 시연 절감 효과 제시

### (c) 시사점

- 과제 정합 인간 모션 중간학습이 로봇 시연 필요량을 줄임
- **단계 레시피 근거** — 사전학습 이후 중간학습 단계를 넣고 안 넣은 비교가 같은 시연 30개 예산에서 73.8% 대 48.8%
  - 로봇 시연 100개 직접 적응 65.0%를 상회
- **조성 단서** — 부분 주석 이종 데이터를 한 액션 공간에서 함께 쓰는 방식은 에고 중심 코퍼스에 로봇 데이터를 섞는 설계의 구체 사례
- **전신 사전학습의 공개 상태** — 프로젝트 페이지만 있어 같은 조건으로 따라 하기 어려움
- **중복 논점** — 같은 회차의 General Humanoid Loco-Manipulation Model(2610.00438)과 전신 인간 데이터 중간학습이라는 같은 질문에 다른 모델 계열로 답함

### (d) 먼저 확인할 점

- **평가 범위** — 로봇 한 기종과 과제별 정책에 한정, 미학습 과제 전이는 저자가 향후 과제로 명시
- **중간학습 비교 범위** — 73.8% 대 65.0%는 PICO 시연이 정렬된 4개 과제 한정
- **실물 시행 수** — 과제당 20회 평가, 과제별 격차는 작은 횟수에 민감
- **시뮬레이션 기준선** — HumanoidArena 비교는 보고된 과제별 최고 기준선과의 비교
- **코드 없음** — 프로젝트 페이지만 있고 저장소 URL이나 공개 약속 없음
