**Hierarchical Skill Retrieval for Data-Efficient Adaptation of Vision-Language-Action Models**

### (b) 핵심 기여
- 대규모 로봇 데이터셋으로 사전학습된 VLA가 소량의 과제별 시연으로 적응할 때 성능이 저하되는 문제 지적, 기존 검색(retrieval) 기반 적응 기법은 시각 유사도·상태-액션 표현·과제 수준 언어 매칭에 의존해 장기 조작 과제 특유의 계층적 구조를 놓친다는 한계 규명
- 목표 과제를 후보 스킬 시퀀스로 분해하고 의미적 타당성과 사전 데이터셋 기반 스킬 신뢰도로 각 분해안을 평가하는 계층적 스킬 검색(**HSR**) 제안
- 서브태스크 수준 언어 검색과 행동-특징 재순위화를 결합한 하이브리드 검색으로, 목표 과제와 의미적으로 관련되면서도 호환 가능한 시연 식별
- 일반 스킬 습득과 과제별 적응을 분리하는 2단계 사전학습-파인튜닝 파이프라인으로 정책 적응
- LIBERO 벤치마크 및 다수 실물 로봇 조작 과제에서, 최강 기준선 대비 평균 성공률 각각 10.3%p·21.3%p 개선

### (c) 시사점
- 사전학습 코퍼스 자체를 재구성하는 대신, 적응 시점에 사전학습 데이터를 스킬 단위로 재검색해 재사용하는 제3의 축 확보 — 코퍼스 조성이나 파인튜닝 방식 어느 쪽도 바꾸지 않고 데이터 활용 효율을 높이는 경로
- 장기 조작 과제를 스킬 단위로 분해해 재사용하는 접근이 실물 로봇에서 더 큰 개선폭(21.3%p, 시뮬레이션은 10.3%p)을 보여, 실배포 환경에서 특히 유효할 가능성 시사
- 코드·영상 공개로 재현 가능성 확보, 이 파이프라인에 검색 모듈만 추가하는 형태로 도입 비용이 낮을 가능성

### (d) 먼저 확인할 점
- 4인 소규모 연구팀 결과로 대형 산업 랩 벤치마크와의 직접 비교가 원문에 있는지 확인 필요
- 스킬 분해·검색 파이프라인이 사전 데이터셋의 스킬 다양성에 의존, 이 코퍼스가 충분히 다양한 스킬을 포함하는지 확인 필요
- "코드 이용 가능"이 GitHub 저장소인지 프로젝트 페이지 경유 배포인지 원문에서 직접 확인 필요(초록은 프로젝트 페이지 URL만 명시)

## 🥈 논문 2 — 우선순위 ★★

**On the Efficiency of LoRA Fine-Tuning for Vision-Language-Action Models in Industrial Robotic Manipulation**
[arXiv:2607.10172](https://arxiv.org/abs/2607.10172) · Finn Ferchau, Daniel Pommer, Cristian Axenie · 2026-07-11 · ICANN 2026 · source: carry-forward 재검토(원 관측 2026-08-03 🚫, 게이트-일관성 정정으로 승격) · 코드 미공개

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- 10억 파라미터급 VLA 모델을 산업 하드웨어에 배포하려면 임바디먼트 격차를 메우는 파인튜닝이 필요하나, 완전 파인튜닝(FFT)은 데이터센터급 GPU를 요구한다는 문제 지적
- 플로우매칭 VLA인 π0를 대상으로 UR5e 로봇팔 기반 4개 정밀 조립 과제에서 LoRA 랭크(r=8–256)·할당 전략·컴포넌트별 동결 조합을 체계적으로 스윕하는 실증 연구 수행
- 특정 LoRA 구성 대비 FFT의 통계적으로 유의한 우위가 없음을 확인, 성능이 r=32에서 포화되고 VLM 백본과 액션 전문가 전반에 균일하게 LoRA를 배분하는 것으로 충분함을 규명
- VLM을 동결하거나 시각 인코더만 LoRA로 제한하면 성능이 유의하게 저하됨을 확인, 임바디먼트 적응에는 의미·시각 양쪽의 가소성이 모두 필요함을 시사
- r=32 LoRA + 시각 인코더 완전 파인튜닝 조합이 성능 손실 없이 정적 최대 VRAM을 36.2GiB에서 10.8GiB로 절감함을 확인

### (c) 시사점
- 현재 기본 전략인 백본 완전 동결 방침에 대해, VLM을 동결하면 성능이 유의하게 저하된다는 반대 방향 실증 근거 확보 — 지난 회차 관측된 반대증거에 이은 두 번째 독립 사례
- 완전 파인튜닝과 통계적으로 다르지 않은 성능을 훨씬 적은 GPU 메모리로 달성하는 구체적 LoRA 구성(r=32, VLM+비전 인코더 균일 배분)을 확인, 적응 범위 결정 시 참고할 정량 기준점 확보
- ICANN 2026 정식 게재로 동료 심사를 거친 근거

### (d) 먼저 확인할 점
- π0 단일 백본·UR5e 단일 임바디먼트·4개 조립 과제로 실험 범위가 제한, 다른 백본·임바디먼트·과제 유형에서도 동일 결론이 유지되는지 확인 필요
- 저자 3인 소규모 연구로, 대형 산업 랩의 대규모 벤치마크와 결과가 일치하는지 확인 필요
- 코드·설정 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요

- 네이티브 VLM 백본에 VQA·서브태스크 예측을 계속 유지시키는 설계가, 완전 동결도 완전 파인튜닝도 아닌 제3의 적응 범위 선택지로 참고 가능

- 분포 변화 환경에서도 테스트-시점 연산 배분의 이득이 유지됨을 확인, 배포 후 분포 변화 대응 레버로 참고 가능

### (d) 먼저 확인할 점
- 정확도·성공률 개선폭이 구체적 수치로 초록에 제시되지 않아, 원문에서 기준선 대비 정량 개선폭 확인 필요

- 테스트-시점 연산 배분에 따른 추론 지연시간 증가가 실시간 제어 요구와 양립 가능한 수준인지 원문 확인 필요
