## 🥇 논문 1 — 우선순위 ★★★

**Flatness Preserves Instruction Following in Vision-Language-Action Models**
[arXiv:2606.23641](https://arxiv.org/abs/2606.23641) · Haochen Zhang, Yonatan Bisk · 2026-06-22 · source: keyword-sweep (VLM finetuning forgetting robot)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **진단 — "지시 맹목(instruction blindness)" 규명** — 제한된 로봇 데이터로 파인튜닝 시 VLM 언어 지시 표현이 침식되어 정책이 시각 지름길로만 행동하는 실패 모드 최초 명명·정량화
- **메커니즘 가설** — 소량 데이터 SFT가 파라미터 공간의 희소 점에만 그래디언트를 적용 → 고곡률(high-curvature) 날카로운 손실 지형(sharp loss landscape) 형성 → VLM 표현 불안정
- **평탄화 최적화(flatness-preserving optimization)** — SAM(Sharpness-Aware Minimization)을 VLA 파인튜닝에 직접 적용; 동일 데이터·아키텍처 수정 없음·재학습 없이 손실 지형 평탄화
- **결과** — 시뮬레이션 + 실환경 복수 벤치마크에서 언어 지시 추종 성능 **60% 이상** 향상; 기존 가이드 기법(language guidance)과 보완적으로 결합 가능
- **프로젝트 페이지 공개** — 결과 재현 기반 확보

### (c) 시사점

- **D20 보존 원칙의 메커니즘 근거 확보** — "전체 VLM 동결"이 단순 연산 절약 이상의 이유임을 손실 지형 관점에서 설명; 동결이 불가능한 partial-finetune 시나리오에서 SAM이 보존 전략 대안
- **보존 전략 실행 비용 최소화** — 추가 데이터·아키텍처 변경 없이 옵티마이저 교체만으로 적용 가능; Stage 3 보수적 적응 단계에 ConSFT 중요도 가중치와 독립적으로 병행 도입 검토 가능
- **"지시 맹목" 지표를 Stage 2/3 진입 체크포인트로 활용 가능** — 언어 지시 추종 성능 추적이 VLM prior 보존 상태의 프록시 지표로 사용 가능; 평탄화 최적화 적용 여부 결정 트리거 확보
- **기존 Does VLA Know the Basics (2606.19297, 6/19 보고)와 독립 경로 수렴** — 지식 보존 측정(Act2Answer) vs. 손실 지형 평탄화 보존이 동일 문제의 두 독립 각도에서 정합

### (d) 먼저 확인할 점

- **SAM 계산 비용 평가** — SAM은 forward-backward 2회 계산 필요; Stage 3 배포 적응 단계에서 학습 비용 증가 폭 및 수렴 속도 저하 수준 사전 측정 필요
- **평탄화 선택성(selective sharpness)의 레이어 분포** — 논문이 언급하는 "selective sharpness" 분석이 어느 레이어 집중인지 확인; attention vs. FFN 레이어 평탄화 효과 차이 검토
- **인핸드 다지 조작 적용 범위** — 검증 벤치마크가 탁상 조작(LIBERO 계열) 위주인지 여부 확인; 손가락 세밀 접촉 태스크에서 instruction blindness 발현 패턴 동일 여부 미확인
- **보수적 SFT와 결합 효과 측정** — ConSFT 중요도 가중치 + SAM 병행 시 상호 보완 vs. 간섭 여부 정량 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**LaST-HD: Learning Latent Physical Reasoning from Scalable Human Data for Robot Manipulation**
[arXiv:2606.23685](https://arxiv.org/abs/2606.23685) · Jiaming Liu, Yinxi Wang, Chenyang Gu, Siyuan Qian · 2026-06-22 · source: keyword-sweep (human video pretraining manipulation)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **전제 전환** — 기존 인간-로봇 데이터 전이가 기구학적(kinematic) 재타겟팅에 집중했다면, 이 논문은 "물리 역학(physical dynamics) 정렬"이 전이의 핵심이라는 가설 제시
- **LaST-HD 패러다임** — reasoning-before-acting VLA를 인간-손 데이터로 확장하는 새로운 사전학습 방법론
  - **보조 액션-조건 세계 모델(auxiliary action-conditioned world model)** 을 비쌍(unpaired) 인간 손 데이터로 학습 — 로봇 레이블 불필요
  - 인간-손 시연과 로봇 시연을 **공유 잠재 추론 공간(shared latent reasoning space)** 에서 정렬
  - 기구학 패턴 모방 대신 물리 역학 레벨 일치를 추구
- **확장성 확보** — 비쌍 인간 손 데이터(레이블 없는 에고센트릭 영상 포함) 활용 가능 → 사전학습 코퍼스 규모를 로봇 시연 의존 없이 비선형 확장 가능
- **VLA 추론 사이클 통합** — "추론 후 행동(reasoning-before-acting)" 구조가 잠재 물리 추론 정보를 액션 예측에 통합

### (c) 시사점

- **D22 에고센트릭 코퍼스 활용의 새 경로** — 기구학 재타겟팅 없이 물리 역학 잠재 표현만으로 전이 가능하다면, 3D 손 포즈 복원 품질 요구 없이 일반 에고센트릭 비디오를 사전학습 데이터로 활용 가능; 이전 보고(Dexterous Point Policy, DO AS I DO)의 "3D 손 포즈 필수" 전제에 대한 대안 경로 제시
- **비쌍 데이터 → 코퍼스 병목 해소** — 로봇 레이블 없이 인간 손 에고센트릭 영상만으로 세계 모델 사전학습 가능 → D22 코퍼스 확장 단가 대폭 절감 잠재력; 실제 다지 로봇 데모 수집 없이 Stage 1 코퍼스 선행 확장 경로
- **인핸드 조작 특화 잠재력** — 손-물체 접촉의 물리 역학 정렬은 거친 그립(grasp)보다 정밀 인핸드 조작에서 더 큰 개선 여지; VLA prior 표현 품질 향상 경로로서 핀 논문 Being-H0.5와 직교하는 차별점
- **D21 Stage 1 보조 목표 후보** — 잠재 물리 추론 정렬을 Stage 1 추가 사전학습의 보조 학습 목표로 도입 시 인간 비디오 활용률 극대화 가능

### (d) 먼저 확인할 점

- **비쌍 세계 모델 학습의 정렬 품질 확인** — 비쌍 인간 데이터로 학습한 세계 모델이 로봇 물리 역학을 얼마나 충실히 포착하는지; 도메인 갭(domain gap) 수준 측정 필요
- **다운스트림 조작 성공률 수치 미확인** — 초록에 정량 성공률 미명시; 기준선(kinematic 재타겟팅 대비) 성능 향상 폭 및 벤치마크 범위 본문 확인 필요
- **코드·데이터 공개 여부 미확인** — 비쌍 인간 데이터 전처리 파이프라인 및 세계 모델 학습 코드 공개 여부 확인 필요; 재현을 위한 인간 손 데이터셋 명세 필요
- **인핸드 다지 조작 테스트 범위** — 검증 범위가 기초 조작(탁상 그립) 위주인지, 정밀 인핸드 접촉 태스크를 포함하는지 확인

## 🥉 논문 3 — 우선순위 ★

**RECALL: Recovery Experience Collection for Active Lifelong Learning in Vision-Language-Action Models**
[arXiv:2606.23617](https://arxiv.org/abs/2606.23617) · Ulas Berk Karli, Tesca Fitzgerald · 2026-06-22 · source: keyword-sweep (VLA continual learning)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **능동적 연속 학습 패러다임 제안** — VLA의 소극적 모방 학습(passive IL: 실패 태스크에서 추가 데모 수집) 대신, 불확실성 기반 능동 수집(uncertainty-guided recovery data collection)으로 데이터 효율 향상
- **핵심 발견** — 능동 수집 복구 데이터만으로 파인튜닝 시 **재앙적 망각(catastrophic forgetting)** 발생 확인; 새 행동 습득(plasticity)과 기존 행동 유지(retention) 간 트레이드오프 정량화
- **연속 학습 기법 비교** — 리플레이 기반 데이터 혼합(replay-based data mixing) vs. 탄성 가중치 통합(EWC, Elastic Weight Consolidation) 실험적 비교; 트레이드오프 특성 확인
- **자동회귀 VLA에서의 활성 연속 학습 기준점** — 불확실성 기반 복구 데모가 수동 수집 대비 적응 효율 향상 확인; 대규모 로봇 정책에 새 데이터 통합 시 미해결 과제 식별

### (c) 시사점

- **재앙적 망각이 Stage 3 적응의 구조적 위험 확인** — 능동 수집된 특화 데이터로만 파인튜닝하면 이전 역량 소실; Stage 3 배포 적응 시 기존 행동 분포 유지 전략(리플레이·EWC) 병행 필수 확인
- **리플레이 기반 데이터 혼합의 상대적 유효성** — EWC 대비 리플레이 혼합이 VLA 규모에서 더 실용적인지 여부; 혼합 비율 선택 기준(Stage 3 적응 데이터 예산 내에서)을 이 논문의 실험 데이터로 근사 가능
- **불확실성 기반 수집 → 수집 단가 절감 경로** — 전체 태스크 재수집 없이 불확실성 높은 상태만 집중 수집; Stage 3 배포 적응 데이터 예산 절감 경로; ConSFT 중요도 가중치와 상보적

### (d) 먼저 확인할 점

- **불확실성 측정 방법의 VLA 적용 신뢰성** — 어떤 불확실성 지표(엔트로피·dropout MC·앙상블)를 자동회귀 VLA에 적용하는지 확인; 대형 VLA에서 불확실성 추정 계산 비용 측정 필요
- **망각 발생 시점과 규모** — 복구 데이터 몇 단계(episode/iteration) 후 이전 역량 저하가 임계치에 도달하는지; 조기 종료 기준 확인 필요
- **VLA 규모 및 테스트 태스크 범위 미확인** — 사용된 VLA 모델(π0.5 계열 등) 및 조작 태스크 종류(탁상 단순 조작 위주 가능성) 확인; 인핸드 다지 조작 포함 여부 미확인

  - 단, 프로젝트 페이지에서 인핸드 조작 태스크 커버리지 확인 후 핀 승격 결정 권고

- **대상** — [arXiv:2606.23685](https://arxiv.org/abs/2606.23685) LaST-HD
- **제안** — [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) 비쌍 에고센트릭 데이터 → 잠재 물리 역학 정렬 경로 확립; DO AS I DO(2606.19333, 6/19 보고)의 3D 재타겟팅 방식과 독립적인 두 번째 "레이블-없는 인간 데이터 활용" 논문; D22 open ablation 실험 설계에 두 경로 비교 변수 추가 가능

  - 발동 조건: D19 동결 기본값에서 partial-LoRA 전환 검토 시, 언어 지시 추종 성능 평가 후 SAM 병행 적용 여부 결정

- **제안**: RECALL(2606.23617) 근거 — D20 v1(action-side adapter + conservative SFT) 설명에 "망각 검출 시 리플레이 기반 데이터 혼합이 EWC보다 실용적" 노트 추가 제안; Stage 3 적응 데이터 혼합 비율 설정의 경험적 근거
  - 트레이드오프: 리플레이 데이터 보존 및 혼합 비율 튜닝 비용 발생

- **대상**: [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) (Pretraining data composition)
