## 🥇 논문 1 — 우선순위 ★★★

**RotVLA: Rotational Latent Action for Vision-Language-Action Model**
[arXiv:2605.13403](https://arxiv.org/abs/2605.13403) · Qiwei Li, Xicheng Gong, Xinghang Li, Peiyan Li, Quanyun Zhou, Hangjun Ye, Jiahuan Zhou, Yadong Mu · 2026-05-13 · source: VLA-Adapter Citation-Graph + π0 Citation-Graph

### (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4), [D19](#ref-D19), [D22](#ref-D22), [D23](#ref-D23). VLM 백본을 동결한 채 플로우 매칭 액션 헤드만 학습하는 구조(D19 v1 + D23 v1)를 크로스 구현체 로봇 데이터 + 인간 에고센트릭 비디오 1,700+ 시간으로 사전학습합니다(D22). D22 v1의 "π 사전 지식만 활용" 기본값을 대체할 수 있는, 실제 로봇까지 검증된 데이터 레시피를 제시하는 이번 회차 최우선 논문입니다.

### (b) 진정으로 새로운 점

기존 잠재 액션 모델(LAMs)은 이산 양자화에 의존해 평범한 프레임 재구성과 물리적 구조 부재라는 두 가지 한계를 가졌습니다. RotVLA는 잠재 액션을 **SO(n) 리 군(Lie group) 원소**로 모델링해 이 한계를 극복하며 합성 가능성과 부드러운 보간을 구조적으로 보장합니다. 삼중 프레임 학습 목적 함수가 퇴화 없이 의미 있는 시간 역학을 학습하도록 강제합니다. 결과: 1.7B 파라미터, LIBERO 98.2%, RoboTwin2.0 클린/랜덤화 89.6% / 88.5%, 실제 로봇 조작에서 기존 VLA 모델 대비 일관적 우위. 핵심 주장: 잠재 액션의 기하학적 구조가 VLM 의미 공간과 분리되어 백본 교란을 최소화합니다.

### (c) 의사결정 함의

[D23](#ref-D23) v1(연속 플로우 매칭 헤드) 방향성을 유지하되, 잠재 액션 공간에 SO(n) 구조를 도입하는 소규모 에블레이션을 [CP1](#ref-CP1) 이전에 추가합니다. 구체 적용: (1) 플로우 매칭 노이즈 δ를 `SO(3)` 지수 맵 형태 `δ = exp_SO(3)(z)` 로 재정의, (2) 삼중 프레임 보조 손실 추가 `L_total = L_flow + β * L_triplet`, β = 0.1 초기값 스윕. [D22](#ref-D22) 구체 적용: RotVLA 데이터 구성(크로스 구현체 로봇 데모 + 인간 에고센트릭 비디오 비율)을 D22 [CP3](#ref-CP3) 진입 조건 평가의 기준 레퍼런스로 추가 — 공개 데이터셋 목록·비율을 확인한 뒤 π 사전 지식 대비 성능 격차를 측정합니다.

### (d) 먼저 검증해야 할 실패 모드

(1) SO(n) 구조는 관절 공간이 리 군 기하학을 따를 때 유효합니다. 인핸드 다지 조작처럼 손가락이 비독립적으로 커플링되는 환경에서는 SO(n) 분해가 자연스럽지 않으며, 이 경우 삼중 프레임 학습이 수렴하지 못할 수 있습니다. (2) 1,700+ 시간 사전학습 데이터의 구체적 출처와 라이선스가 초록에 명시되지 않아 D22 평가 전 공개 여부를 별도 확인합니다. (3) 코드가 공개된 것으로 확인되지 않아 삼중 프레임 학습 구현 세부 사항을 직접 재현해 검증합니다.

## 🥈 논문 2 — 우선순위 ★★

**ALAM: Algebraically Consistent Latent Action Model for Vision-Language-Action Models**
[arXiv:2605.10819](https://arxiv.org/abs/2605.10819) · Mark Tang, Haoyun Liu, Xinyuan Chang, Chang Jie Wu, Dongjie Huo, Yandan Yang, Bing Liu, Zhejia Cai, Feng Xiong, Mu Xu, Jiacheng Luo, De Ma, Zhiheng Ma, Gang Pan · 2026-05-11 · source: Keyword Sweep (arXiv VLA + backbone/pretraining)

### (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4), [D19](#ref-D19), [D22](#ref-D22), [D23](#ref-D23). 액션 레이블 없는 일반 비디오로부터 잠재 액션 사전 지식을 추출해 VLA 사전학습에 활용하는 D22 방향을 제안하며, 사전학습된 인코더를 완전 동결(D19 v1)하고 잠재 전이 시퀀스를 로봇 액션과 공동 플로우 매칭 목적 함수로 학습합니다(D23). D22 v1의 "π 사전 지식만 활용" 기본값을 수학적으로 검증된 비디오 보조 학습으로 교체하는 구체적 레시피입니다.

### (b) 진정으로 새로운 점

기존 잠재 액션 모델들은 재구성 목적 함수만으로 학습해 정책 생성에 부적합한 비구조적 코드를 생성했습니다. ALAM은 **대수적 일관성 제약** 두 가지를 더합니다: ① 합성 일관성 `z(t1→t3) = z(t1→t2) ⊕ z(t2→t3)`, ② 역방향 일관성 `z(t1→t2) ⊕ z(t2→t1) = 0`. 이 제약이 잠재 전이 공간에 국소 가산성 구조를 부여합니다. 하류 VLA 학습에서 인코더를 동결하고 잠재 전이 시퀀스를 공동 플로우 매칭 보조 타겟으로 사용한 결과: MetaWorld MT50 47.9% → 85.0%, LIBERO 94.1% → 98.1%, 합성·역방향 오류 25–85배 감소, 실제 로봇 조작 일관적 개선.

### (c) 의사결정 함의

[D22](#ref-D22) 구체 적용: [D21](#ref-D21) Stage 2 학습 중 에고 비디오 잠재 전이를 보조 타겟으로 추가합니다. 손실 항: `L_total = L_flow + λ_comp * L_composition + λ_rev * L_reversal`, 초기값 λ = 0.1, 스윕 범위 0.05–0.2. [D19](#ref-D19) 구체 적용: π0 비전 인코더를 동결 상태로 유지하면서 ALAM 스타일 잠재 전이 감독으로 훈련 — D19 v1(완전 동결)과 완전히 호환됩니다. [D23](#ref-D23) 구체 적용: ALAM의 공동 플로우 매칭 헤드(잠재 전이 + 로봇 액션 동시 디노이징)를 [CP1](#ref-CP1) 이후 Stage 3 진입 조건 체크리스트에 "비디오 보조 손실 에블레이션" 항목으로 추가합니다.

### (d) 먼저 검증해야 할 실패 모드

(1) MetaWorld MT50의 47.9%→85.0% 향상은 시뮬레이션 기반이며 실제 로봇 결과는 정량 수치 없이 "일관적 개선"으로만 기술되어 있어, 접촉 집약적 인핸드 조작에서의 정량 검증을 별도 수행합니다. (2) 대수적 제약(합성·역방향 일관성)이 다지 손가락의 비선형 강체 접촉 동역학 환경에서도 유효한지 미검증이며, 국소 가산성 가정이 접촉 집약적 과제에서 파괴될 수 있습니다. (3) 비디오 소스의 도메인 구성(실내·야외·에고센트릭 비율)이 D22 평가에 영향을 미치므로 구성 상세를 확인합니다.

## 🥉 논문 3 — 우선순위 ★

**Action with Visual Primitives**
[arXiv:2605.22183](https://arxiv.org/abs/2605.22183) · Weilong Guo, Yuchen Wang, Renping Zhou, Yunfeng Zhang, Rui Fang, Yue Meng, Wenda Xu, Yuan He, Gao Huang · 2026-05-21 · source: Keyword Sweep (arXiv VLA + backbone/pretraining)

### (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4), [D19](#ref-D19), [D20](#ref-D20), [D23](#ref-D23). "VLM이 모터 액션을 직접 예측하면 이미 VLM에 내재된 인지·지각 역량을 액션 전문가가 재학습해야 한다"는 비효율을 실험으로 검증하며, D19 v1(완전 동결)과 D20 v1(액션 측 어댑터)의 합리성을 새로운 관점에서 지지합니다. VLM 출력 인터페이스를 구체적으로 재정의하는 AVP 프레임워크를 제시합니다.

### (b) 진정으로 새로운 점

기존 VLA의 단일 포워드 패스(instruction → visual observation → action) 구조 대신 **시각 원시 인터페이스**를 도입합니다: VLM은 다음 단계 목표를 추론해 시각 원시 토큰 — 엔드 이펙터 다음 단계 키프레임 — 으로 출력하고, 이 조건을 받아 플로우 매칭 액션 전문가가 모터 액션을 생성합니다. "액션 전문가가 VLM의 인지 역량을 재학습해야 하는 부담"을 인터페이스 차원에서 제거합니다. 실제 로봇 일반 픽-앤-플레이스 과제에서 π0.5 대비 성공률 27.61% 향상, 데이터 효율·공간 합성 일반화·객체 전이에서도 일관적 개선.

### (c) 의사결정 함의

[D19](#ref-D19)와 [D23](#ref-D23) v1의 방향성을 확인하는 동시에 인터페이스 수준의 구체적 구현 경로를 제시합니다. 구체 적용: (1) π0 VLM 레이어 출력 위에 선형 프로브를 추가해 "시각 원시 토큰 예측" 보조 헤드 구현, 손실 `L_total = L_flow + α * L_visual_primitive`, α = 0.05 초기값; (2) [D20](#ref-D20) 어댑터 설계 시 split-head를 "시각 원시 예측 헤드"와 "플로우 매칭 액션 헤드"로 명시 분리하는 방향을 [CP1](#ref-CP1) 체크리스트 후보로 추가; (3) 모니터링 지표: "시각 원시 예측 정확도(다음 키프레임 위치 오차)" 를 D21 Stage 3 진입 조건 대시보드에 포함.

### (d) 먼저 검증해야 할 실패 모드

(1) "일반 픽-앤-플레이스" 범위의 실제 로봇 실험은 인핸드 다지 조작처럼 접촉 집약적·고차원 액션이 필요한 과제에서의 검증이 없으며, 시각 원시 토큰이 복잡한 접촉 동역학을 충분히 표현하는지 확인이 필요합니다. (2) 분포 외 객체나 새로운 작업 구성에서 VLM이 잘못된 시각 원시를 생성할 경우 액션 전문가가 올바른 액션을 출력하지 못할 수 있습니다 — VLM의 시각 추론 역량이 새로운 병목이 될 수 있습니다. (3) 코드 및 모델 공개 여부가 초록에 명시되지 않아 재현성을 직접 확인합니다.

## 💡 컨텍스트 제안

### Tracked literature

**추가/교체 제안 2건:**

1. **RotVLA** [arXiv:2605.13403](https://arxiv.org/abs/2605.13403) 추가 검토 — D22/D23 핀 논문 후보. SO(n) 잠재 액션 + 크로스 구현체 비디오 사전학습의 실제 로봇 정량 결과가 논문에 보완되면 현재 Multi-Embodiment Data [arXiv:2506.19121](https://arxiv.org/abs/2506.19121) 의 보완 항목으로 §6.1에 추가 제안.
2. **ALAM** [arXiv:2605.10819](https://arxiv.org/abs/2605.10819) 추가 검토 — D22 핀 논문 후보. 대수적 일관성 잠재 액션은 비디오 사전학습의 수학적 토대로 현 핀 목록에 없는 관점. 실제 로봇 정량 결과 보완 후 Multi-Embodiment Data와 함께 §6.1 D22 슬롯에 추가 제안.

### Decision Log

- **[D22](#ref-D22)** (다중 구현체 사전학습 데이터): 이번 회차 RotVLA(1,700+ 시간 크로스 구현체 + 인간 비디오)와 ALAM(액션 레이블 없는 비디오)이 동시에 비디오 기반 사전학습의 유효성을 실제 로봇 수준에서 검증했습니다. 이번 스카우트에서 "π 사전 지식만 활용" 기본값을 향한 경쟁 압력이 두 회차 연속 강해진 것을 확인했습니다. [CP3](#ref-CP3) 이전에 소규모 비디오 보조 사전학습 에블레이션(D21 Stage 2 중 ALAM 스타일 보조 손실 추가 실험)을 D22 액션 아이템으로 조기 추가합니다.
- **[D23](#ref-D23)** (액션 표현 × VLM 보존): RotVLA(SO(n) 잠재 액션), ALAM(대수적 일관성), AVP(시각 원시 인터페이스) 세 논문이 모두 "VLM을 의미 역할에 유지하고 액션 전문가가 제어를 담당"하는 D23 v1 방향성을 지지합니다. D23 v1을 유지하되, AVP의 "시각 원시 토큰 인터페이스"를 [CP1](#ref-CP1) 이전 소규모 인터페이스 에블레이션 항목으로 추가합니다.

## 🔄 직전 리포트 대비 종합

- **직전 P4 리포트** (2026-05-21): UAM(아키텍처 분리 보존), ConSFT(Stage 3 SFT 목적 함수), VLA-GSE(스펙트럼 PEFT), AT-VLA(적응적 촉각 주입). 이번 회차 채택 논문(RotVLA·ALAM·AVP)과 중복 없음.
- **연속 트렌드**: 직전 리포트에서 UAM이 "아키텍처 분리로 VLM 보존"을 제안했다면, 이번 회차에서는 ALAM과 RotVLA가 "비디오 잠재 액션 사전학습으로 VLM 동결 상태에서 성능 향상"이라는 구체적 데이터 레시피를 제공합니다. 이번 스카우트에서 VLM 보존 방법이 "동결 처방"에서 "동결 + 비디오 보조 학습"으로 진화하는 흐름을 2주 연속 확인했습니다.
- **D22 신호 강화**: 비디오 기반 사전학습(ALAM, RotVLA)이 동시 등장 — D22 액션 아이템("다중 구현체 데이터셋 목록업") 실행을 가속할 근거가 충분히 누적되었습니다.
- **D23 v1 재확인**: 세 채택 논문 모두 플로우 매칭 + VLM 의미 역할 분리를 지지합니다. D23 v1(연속 플로우 매칭 헤드) 결정은 현재 증거 기반으로 유지합니다.
- **Anti-topic 필터 상태**: 이번 회차 Anti-topic 기준 제외 논문 5건(SkiP·AttenA+·StableVLA·PAIR-VLA·기타 효율화 논문 다수). 키워드 스윕 노이즈 수준은 직전 회차와 유사합니다.
- **월간 트렌드 (2026년 5월)**: 비디오 사전학습 + VLM 동결 조합이 5월 VLA 논문의 핵심 흐름으로 부상했습니다. ConSFT·UAM(5-21 리포트) → RotVLA·ALAM·AVP(이번 리포트)로 이어지는 연속성을 확인했으며, D22 진입 가속 논의를 5월 말 기준으로 시작합니다.
