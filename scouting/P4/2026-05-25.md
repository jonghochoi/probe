## 🥇 논문 1 — 우선순위 ★★★

**RotVLA: Rotational Latent Action for Vision-Language-Action Model**
[arXiv:2605.13403](https://arxiv.org/abs/2605.13403) · Qiwei Li, Xicheng Gong, Xinghang Li, Peiyan Li, Quanyun Zhou, Hangjun Ye, Jiahuan Zhou, Yadong Mu · 2026-05-13 · source: citation-graph

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **위치** — VLM 백본을 동결한 채 플로우 매칭 액션 헤드만 학습하는 구조를 크로스 구현체 로봇 데이터 + 인간 에고센트릭 비디오 1,700+ 시간으로 사전학습, 실제 로봇까지 검증된 데이터 레시피 제시
- **SO(n) 잠재 액션** — 기존 잠재 액션 모델(LAMs)의 이산 양자화 한계(평범한 프레임 재구성, 물리적 구조 부재) 극복, 잠재 액션을 SO(n) 리 군(Lie group) 원소로 모델링해 합성 가능성·부드러운 보간을 구조적으로 보장
  - 삼중 프레임 학습 목적 함수가 퇴화 없이 의미 있는 시간 역학 학습을 강제
  - 잠재 액션의 기하학적 구조가 VLM 의미 공간과 분리되어 백본 교란 최소화
- **결과** — 1.7B 파라미터, LIBERO 98.2%, RoboTwin2.0 클린/랜덤화 89.6% / 88.5%, 실제 로봇 조작에서 기존 VLA 모델 대비 일관적 우위

### (c) 시사점

- **데이터 레시피 대안** — π 사전학습 prior에만 의존하던 기본값을 크로스 구현체 비디오 사전학습 레시피로 대체할 후보
- **백본 교란 최소화** — 잠재 액션 공간에 SO(n) 구조를 도입해 연속 플로우 매칭 헤드 방향을 유지한 채 백본 보존 강화 가능

### (d) 먼저 확인할 점

- **다지 커플링 미검증** — SO(n) 구조는 관절 공간이 리 군 기하학을 따를 때 유효, 손가락이 비독립적으로 커플링되는 인핸드 다지 조작에서는 SO(n) 분해가 부자연스러워 삼중 프레임 학습 수렴 실패 가능
- **데이터 출처 불명** — 1,700+ 시간 사전학습 데이터의 구체적 출처·라이선스가 초록 미명시, 공개 여부 별도 확인 필요
- **재현성** — 코드 공개 미확인, 삼중 프레임 학습 구현 세부 직접 재현 필요

## 🥈 논문 2 — 우선순위 ★★

**ALAM: Algebraically Consistent Latent Action Model for Vision-Language-Action Models**
[arXiv:2605.10819](https://arxiv.org/abs/2605.10819) · Mark Tang, Haoyun Liu, Xinyuan Chang, Chang Jie Wu, Dongjie Huo, Yandan Yang, Bing Liu, Zhejia Cai, Feng Xiong, Mu Xu, Jiacheng Luo, De Ma, Zhiheng Ma, Gang Pan · 2026-05-11 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **위치** — 액션 레이블 없는 일반 비디오로부터 잠재 액션 사전 지식을 추출해 VLA 사전학습에 활용, 사전학습 인코더를 완전 동결하고 잠재 전이 시퀀스를 로봇 액션과 공동 플로우 매칭 목적 함수로 학습
- **대수적 일관성 제약** — 기존 잠재 액션 모델은 재구성 목적 함수만으로 학습해 정책 생성에 부적합한 비구조적 코드 생성, ALAM은 두 제약 추가
  - 합성 일관성 `z(t1→t3) = z(t1→t2) ⊕ z(t2→t3)`
  - 역방향 일관성 `z(t1→t2) ⊕ z(t2→t1) = 0`
  - 두 제약이 잠재 전이 공간에 국소 가산성 구조 부여
- **결과** — MetaWorld MT50 47.9% → 85.0%, LIBERO 94.1% → 98.1%, 합성·역방향 오류 25–85배 감소, 실제 로봇 조작 일관적 개선

### (c) 시사점

- **비디오 보조 학습 레시피** — π 사전 지식만 활용하던 기본값을 수학적으로 검증된 비디오 보조 학습으로 교체하는 구체 레시피
- **동결 호환** — 비전 인코더를 동결 상태로 유지하면서 잠재 전이 감독으로 훈련 가능, 완전 동결 방향과 호환

### (d) 먼저 확인할 점

- **실 로봇 정량 부재** — MetaWorld MT50 47.9%→85.0% 향상은 시뮬레이션 기반, 실제 로봇 결과는 정량 수치 없이 "일관적 개선"으로만 기술, 접촉 집약적 인핸드 조작 정량 검증 별도 필요
- **가산성 가정 위험** — 대수적 제약(합성·역방향 일관성)이 다지 손가락 비선형 강체 접촉 동역학에서 유효한지 미검증, 국소 가산성 가정이 접촉 집약적 과제에서 파괴 가능
- **도메인 구성 확인** — 비디오 소스의 도메인 구성(실내·야외·에고센트릭 비율) 상세 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Action with Visual Primitives**
[arXiv:2605.22183](https://arxiv.org/abs/2605.22183) · Weilong Guo, Yuchen Wang, Renping Zhou, Yunfeng Zhang, Rui Fang, Yue Meng, Wenda Xu, Yuan He, Gao Huang · 2026-05-21 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **위치** — "VLM이 모터 액션을 직접 예측하면 이미 VLM에 내재된 인지·지각 역량을 액션 전문가가 재학습해야 한다"는 비효율을 실험 검증, VLM 출력 인터페이스를 재정의하는 AVP 프레임워크 제시
- **시각 원시 인터페이스** — 기존 VLA의 단일 포워드 패스(instruction → visual observation → action) 대신 시각 원시 인터페이스 도입
  - VLM은 다음 단계 목표를 추론해 시각 원시 토큰(엔드 이펙터 다음 단계 키프레임)으로 출력, 이 조건을 받아 플로우 매칭 액션 전문가가 모터 액션 생성
  - 액션 전문가가 VLM 인지 역량을 재학습해야 하는 부담을 인터페이스 차원에서 제거
- **결과** — 실제 로봇 일반 픽-앤-플레이스 과제에서 π0.5 대비 성공률 27.61% 향상, 데이터 효율·공간 합성 일반화·객체 전이에서도 일관적 개선

### (c) 시사점

- **인터페이스 분리 경로** — 동결 + 액션 측 어댑터 방향을 확인하는 동시에 split-head를 "시각 원시 예측 헤드"와 "플로우 매칭 액션 헤드"로 명시 분리하는 인터페이스 구현 경로 제시
- **모니터링 지표 후보** — 시각 원시 예측 정확도(다음 키프레임 위치 오차)를 진행 지표로 활용 가능

### (d) 먼저 확인할 점

- **다지 미검증** — "일반 픽-앤-플레이스" 범위의 실제 로봇 실험은 인핸드 다지 조작처럼 접촉 집약적·고차원 액션 과제 검증 부재, 시각 원시 토큰이 복잡한 접촉 동역학을 충분히 표현하는지 확인 필요
- **VLM 추론 병목** — 분포 외 객체나 새로운 작업 구성에서 VLM이 잘못된 시각 원시를 생성하면 액션 전문가가 올바른 액션을 출력하지 못할 수 있음, VLM 시각 추론 역량이 새로운 병목 가능
- **재현성** — 코드 및 모델 공개 여부 초록 미명시, 재현성 직접 확인 필요
