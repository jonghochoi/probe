## 🥇 논문 1

**IronMind: Scaling Humanoid Dexterous Manipulation via Camera-Space Ego-Centric Pretraining**
[arXiv:2609.39403](https://arxiv.org/abs/2609.39403) · Huimin Pan, Yufan Ren, Kunpeng Song 외 16인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N3 · M2 · Real3 · Repro1 — arXiv comment "https://xpeng-robotics.github.io/ironmind/"

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 핵심 기여

- 카메라 공간 액션으로 에고센트릭 영상을 사전학습에 직접 편입
- **임바디먼트 격차 해소** — 몸통 기구학 없는 에고 영상을 리타게팅 없이 쓰기 위해 영상의 기준 좌표계인 카메라 공간을 액션 표현으로 채택, 로봇·인간 액션 차원을 의미 단위로 정렬
- **데이터 규모 곡선** — 사전학습 예산 250–10,000시간에서 검증 손실이 대략 로그 선형 감소
- **실로봇 OOD 결과** — 미지 물체·어포던스·추론 지시 6개 과제에서 10,000시간 모델 성공률 55.0%, 5,000시간 이하 예산은 최대 11.7%, 사전학습 없음은 5.0%
- **표현 대조** — 같은 예산에서 카메라 공간 액션이 토르소 프레임 기준선을 상회

### (c) 시사점

- 사전학습 예산을 변수로 둔 실로봇 OOD 곡선 확보
- **조성 질문의 규모 증거** — 에고센트릭 비중이 큰 코퍼스에서 사전학습 규모가 사후학습 성공률을 가르는 정량 자료, 혼합 대 에고 중심 비교의 에고 쪽 기준점
- **도입 비용** — 에고 영상을 리타게팅 없이 쓰는 경로로 수집 계획과 정합, 액션 표현 선택이 데이터 활용 범위를 좌우
- **임계 구간** — 5,000시간 이하와 10,000시간 사이의 급격한 성능 차이가 필요 사전학습 규모의 하한 추정 근거

### (d) 먼저 확인할 점

- 프로젝트 페이지만 명시, 저장소·체크포인트·데이터 확보 경로 확인 필요
- 사전학습 구성에서 인간 에고 데이터와 로봇 데이터의 비율을 바꾼 조성 비교는 초록에 부재, 규모 효과와 조성 효과 분리 불가
- 시드 반복과 한계 서술 부재, 6개 과제 55.0%의 분산 확인 필요
- 휴머노이드 플랫폼 결과로, 손 단독 플랫폼 이전 가능성 별도 확인 필요

### (b) 핵심 기여

- 에고 데이터, 전신 인간 500시간, 하류 적응의 3단계 사전학습
- **신규 코퍼스** — 에고센트릭 영상과 몸통·손 모션을 동기화한 인간 전신 조작 500시간 데이터셋 HumanVerse-500 구축
- **단계 구성** — 다양한 에고센트릭 데이터로 상호작용 학습, HumanVerse-500으로 몸통·손 협응 학습, 하류 과제·임바디먼트 적응
- **공유 표현** — 인간·로봇 상태·액션 차이는 도메인별 인터페이스가 흡수
- **평가** — SIMPLE과 실물 휴머노이드 로코조작 4개 과제에서 최고 성능, 스케일링·일반화·단계별 기여 분석 동반

### (c) 시사점

- 단계 레시피를 변수로 다룬 단계별 기여 분석 자료
- **레시피 기준점** — 에고 데이터 → 전신 인간 데이터 → 하류 적응 순서가 사전학습 단계 설계의 구체적 사례
- **데이터 확보** — 코드·모델·데이터 공개 예정으로 인간 전신 코퍼스 확보 시 직접 활용 가능
- **조성 질문** — 에고 중심 코퍼스 쪽 증거를 휴머노이드 전신으로 확장

### (d) 먼저 확인할 점

- 공개는 예정 단계, 데이터셋·체크포인트 실제 공개 여부 확인 필요
- 실물 평가가 4개 과제이고 초록에 성공률 수치 부재, 원문 표 확인 필요
- 단계 제거 ablation의 범위와 혼합 코퍼스 대조군 유무 확인 필요
- 전신 로코조작 중심으로, 손 조작 단독 과제 이전은 별도 확인 필요

- **세계 표현** — 현재 상태(시각-언어 문맥과 3D 기하), 전이(3D 모션), 미래 상태(미래 의미)로 상호작용을 분해
- **사전학습 코퍼스** — 에고센트릭 인간 조작, UMI, 실로봇, 시뮬레이션 데이터 혼합, 기하·3D 모션·미래 의미는 사전학습 시각 모델의 잠재 감독

- **결과** — 시뮬레이션 RoboDojo-Sim 평균 점수 27.10으로 비교 월드-액션 모델 중 최고, 소량 하류 데이터 파인튜닝 후 실로봇 다수 과제 성능 보고

- 혼합 코퍼스 사전학습 사례의 공개 기준점 확보
- **혼합 측 증거** — 인간·UMI·로봇·시뮬레이션을 섞은 조성의 대규모 사례, 에고 중심 대 혼합 질문의 혼합 쪽 자료
- **재현 경로** — 코드 저장소 명시로 사전학습 설정 확인 가능
- **적응 효율** — 소량 하류 데이터 파인튜닝 결과가 사전학습 이득의 간접 지표

### (d) 먼저 확인할 점

- 코퍼스 구성 비율을 바꾼 조성 비교는 초록에서 불명확, 혼합의 순효과 분리 불가
- 실로봇 결과는 과제 수·성공률 수치가 초록에 부재, 원문 확인 필요
- 체크포인트와 데이터 공개 여부는 코드 저장소에서 별도 확인 필요
- 3D 기하·모션 감독이 외부 시각 모델에 의존, 감독 모델 교체 시 이득 유지 여부 미확인
