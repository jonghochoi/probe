## 🥇 논문 1

**IronMind: Scaling Humanoid Dexterous Manipulation via Camera-Space Ego-Centric Pretraining**
[arXiv:2609.39403](https://arxiv.org/abs/2609.39403) · Huimin Pan 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 12/15** · R3 · N3 · M2 · Real3 · Repro1 — arXiv comment "https://xpeng-robotics.github.io/ironmind/"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- 에고센트릭 영상을 카메라 공간 액션으로 사전학습
- **문제** — 에고센트릭 인간 영상을 휴머노이드 다지 조작 사전학습에 쓰려면 두 간극을 넘어야 함
  - 임바디먼트 간극 — 사람 손과 로봇 엔드이펙터의 기구학·관절 수 차이, 저가 에고센트릭 녹화에는 몸통 기구학 정보 부재
  - 품질 간극 — 손 자세 추적 노이즈, 약하게 정렬된 텍스트 주석, 조작 없는 구간 포함
- **기존 한계** — 사람 몸을 로봇 관절 공간으로 옮기는 리타깃팅이 관측되지 않은 몸통 기구학 가정을 요구
  - 강체 척추 모델 같은 가정이 라벨 노이즈를 유발
  - 로봇 시연 수집은 느리고 비싸며 웹 규모 조작 코퍼스 부재
- **핵심 방법** — 카메라 공간 액션 표현과 다단계 큐레이션, 이중 전문가 VLA
  - 사람과 보정된 로봇 궤적을 같은 카메라 공간 표현으로 쓰고 임바디먼트 간 액션 차원을 의미 기준으로 정렬
  - 큐레이션 — 규칙 기반 필터링, 원자 과제 재주석, 프레임별 품질 가중
  - 비전-언어 전문가와 플로우 매칭(flow matching) 액션 전문가를 공유 어텐션으로 잇는 Mixture-of-Transformers
  - 선택 요소로 동결 비디오 생성 모델의 미래 프레임 예측을 월드 프라이어로 사용, 사전학습 후 예측 모듈 제거
- **차별점** — 몸 리타깃팅을 우회하고 에고센트릭 영상의 고유 좌표계에서 인간·로봇 액션을 통일
- **핵심 기여** — 사전학습 레시피, 아키텍처, 평가 스위트, 실물 검증 네 가지
  - 인간 에고센트릭 영상과 이종 로봇 데이터 합계 1만 시간 이상 코퍼스, 예산 250–10,000시간에서 검증 손실이 로그-선형 감소
  - 실물 휴머노이드 6개 OOD 과제(미지 물체·어포던스·추론 프롬프트), 10,000시간 모델 성공률 55.0%
  - 5,000시간 이하 모든 예산은 최대 11.7%, 사전학습 없음 5.0%
  - 같은 예산에서 카메라 공간 표현 55.0%, 몸통 프레임 기준선 26.7%
  - 열린 루프 지표, 정책 인 더 루프 롤아웃, 실물 평가를 묶은 평가 스위트
- **가치** — 대규모 에고센트릭 인간 데이터 사전학습의 예산 대비 실물 성과 곡선을 공개 근거로 제시

### (c) 시사점

- 코퍼스 규모 레버의 실물 증거 확보
- 사전학습 예산을 250–10,000시간으로 바꿔 사후학습 OOD 실물 성공률을 측정한 점이 코퍼스 조성 판단의 직접 근거
- 카메라 공간 액션 표현이 몸통 프레임 대비 우위를 보여 액션 표현 선택에 참고 가능
- 단계적 사전학습 뒤 사후학습 구도가 현행 단계 레시피와 맞닿음
- 추적 중인 Being-H0.5 에고센트릭 코퍼스 대비 예산 곡선이 새 정보

### (d) 먼저 확인할 점

- 코드·체크포인트 미공개, 프로젝트 페이지만 확인됨
- 스케일링 연구는 아키텍처 하나와 데이터 혼합 하나, 실물 평가는 로봇 1종·6과제·과제당 10회 시행
- 카메라 외부 파라미터 보정과 실로봇 사후학습이 여전히 필요, 로봇 의존성이 제거되지 않음
- InternVLA-A1.5 외 기준선(DreamZero 등) 비교는 미수행
- 코퍼스가 가정·주방·작업장에 집중, 장기 과제와 접촉 집약적 과제는 미검증

## 🥈 논문 2

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 10/15** · R3 · N2 · M2 · Real2 · Repro1 — 초록 "We will release our code, models, and data"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 에고센트릭 전신 인간 데이터로 3단계 사전학습
- **문제** — 휴머노이드 전신 이동 조작은 몸 움직임과 손-물체 상호작용의 시간적 협응을 담은 지도가 필요
  - 전신 텔레오퍼레이션 시연은 로봇 시간과 인력이 많이 들어 과제·환경 확장이 어려움
- **기존 한계** — 에고센트릭 영상에서 복원한 손목·손 궤적만으로는 전신 협응을 담지 못함
  - 접근, 자세 조정, 파지 유지 같은 이동 조작 행동의 협응이 빠짐
- **핵심 방법** — 3단계 학습의 전신 VLA(λ0)
  - 1단계 — 다양한 에고센트릭 데이터셋에서 상호작용 학습
  - 2단계 — HumanVerse-500으로 몸과 손 동작 협응 학습
  - 3단계 — 하류 과제와 로봇 임바디먼트에 적응
  - 공유 표현 공간으로 단계 간 전이를 잇고 도메인별 인터페이스가 인간·로봇의 상태·액션 차이를 처리
- **차별점** — 손 궤적에 그치지 않고 몸·손 모션을 동기화한 전신 감독을 중간 단계로 삽입
- **핵심 기여** — 데이터셋, 정책, 스케일링 분석
  - HumanVerse-500 — 개방 환경 인간 이동 조작 500시간, 에고센트릭 영상과 몸·손 모션 동기화, 경량 웨어러블 수집
  - SIMPLE과 실물 이동 조작 4과제에서 가장 강한 기준선 대비 각각 3.9, 22.5%p 향상
  - 인간 데이터 규모를 늘리면 검증 손실 감소와 실물 과제 진행도 향상
  - 단계 ablation에서 두 인간 데이터 단계 중 전신 미드트레이닝이 실물 성공에 더 크게 기여
  - 인간 시연이 로봇 미경험 물체의 진행도를 개선
- **가치** — 전신 인간 데이터를 휴머노이드 이동 조작의 확장 가능한 감독원으로 쓰는 근거 제시

### (c) 시사점

- 단계 순서가 있는 사전학습 레시피의 실측 사례
- 에고센트릭 → 전신 협응 → 하류 적응 순서에서 단계별 기여를 ablation으로 분리해 단계 설계 판단에 참고
- 에고센트릭 코퍼스에 전신 모션 구성을 더하는 선택지의 효과 근거
- 500시간 코퍼스와 코드·모델·데이터 공개 약속으로 재현 경로 기대

### (d) 먼저 확인할 점

- 코드·모델·데이터는 공개 예정 단계
- 초록과 서론의 향상폭은 최강 기준선 대비 %p, 기준선 구성은 본문 확인 필요
- 실물 평가는 4과제, 손가락 수준 다지 조작 비중은 불명
- 인접 연구가 이미 추적 중이라 신규성은 단계 순서와 500시간 코퍼스에 한정

## 🥉 논문 3

**OrthoSkillVLA: Continual Skill Learning via Gradient-Informed Skill Subspace Adaptation**
[arXiv:2608.19589](https://arxiv.org/abs/2608.19589) · Jiaqi Wang 외 · PRCV 2026 (accepted) · source: citation-graph · 코드 미공개

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- VLA 컴포넌트별 부분공간으로 순차 기술 학습 시 망각 억제
- **문제** — 사전학습 VLA에 기술을 순차 적응하면 이전 기술의 표현과 속도장 매핑이 흐트러져 파국적 망각 발생
- **기존 한계** — 두 계열 모두 VLA 배포에 걸림돌
  - 아키텍처 기반 접근은 기술 격리로 유지력을 얻지만 기술마다 구조가 커져 추론 부담 증가
  - 부분공간 제약(그래디언트 투영) 방식은 모델 전체에 균일한 제약을 부과
- **핵심 방법** — 모듈 인지형 직교 적응과 특징 인지형 MoE 디코더
  - 그래디언트 누적으로 기술 특징 부분공간을 추정하고 이전에 점유된 방향의 직교 여공간에 새 기술을 주입
  - VLM과 ActionHead에 서로 다른 부분공간 예산 배정
  - 최종 속도 디코더는 직교 미세조정에서 제외하고 기술마다 소형 전문가를 할당, 학습 없는 투영 기반 라우터가 특징 공간 친화도로 전문가 선택
- **차별점** — 네트워크 전체 균일 제약 대신 VLM과 ActionHead의 역할 차이에 맞춘 컴포넌트별 제약
  - VLM은 재사용 가능한 의미 표현이라 용량 소진에 취약, ActionHead는 국소 속도 패턴이라 섭동에 민감하다는 분석에 근거
- **핵심 기여** — 분석, 방법, 검증 세 가지
  - VLA 특유의 두 과제 규명 — 모듈 간 표현 이질성, 출력단 표현력 병목
  - 모듈별 부분공간 예산과 학습 없는 라우팅 MoE 디코더
  - 시뮬레이션·실물 평가에서 부분공간 제약 기준선 대비 이전 기술 유지와 최종 성공률 개선
  - 시연 재생 없이 동작
- **가치** — 구조 성장 없이 사전학습 VLA의 기술을 누적하는 경로 제시

### (c) 시사점

- 어댑터 측 보존 레버의 컴포넌트별 설계 근거
- VLM과 ActionHead의 민감도 차이를 분석으로 보여 동결 범위 결정 시 비교 기준으로 활용 가능
- 재생 없는 순차 적응이라 이전 과제 데이터 보관 부담 없음
- 추적 중인 ContinualVLA 대비 컴포넌트별 분리 제약이 신규

### (d) 먼저 확인할 점

- 코드·프로젝트 페이지 신호 없음, 재현 경로 불명
- 초록에 실물 평가 수치가 없어 정량 규모는 본문 확인 필요
- 기술 수가 늘 때 부분공간 용량 소진과 MoE 전문가 증가에 따른 추론 비용 확인 필요
- 비교 대상이 부분공간 제약 기준선 중심
