### (b) 논문 요지

- 에고센트릭 영상 사전학습 규모를 250–10,000시간으로 변화
- **문제** — 다지 조작을 하는 범용 휴머노이드 정책의 데이터 부족
  - 실물 다지 시연은 수집이 느리고 비싸며, 로봇 조작에는 웹 규모 코퍼스가 없음
  - 에고센트릭 인간 영상은 저비용 대안이나 두 가지 간극이 있음
  - 구현체 간극 — 사람 손과 로봇 말단장치의 기구학·관절 수 차이
  - 품질 간극 — 손 추정 노이즈, 약하게 정렬된 텍스트, 조작 없는 구간 포함
- **기존 한계** — 인간 영상을 로봇 관절 공간으로 옮기는 리타깃팅의 라벨 노이즈
  - 에고센트릭 영상에는 착용자의 전신 자세가 없어 척추 강체 모델 같은 가정이 필요하고, 이 가정이 라벨 노이즈로 이어짐
  - 비교 기준은 몸통 좌표계 액션 표현 (torso-frame baseline)
- **핵심 방법** — 카메라 공간 액션 표현과 멀티스테이지 큐레이션을 결합한 VLA 사전학습
  - 인간과 보정된 로봇 궤적을 같은 카메라 공간 표현으로 쓰고 구현체 간 액션 차원을 의미적으로 정렬
  - 큐레이션은 규칙 기반 필터링, 원자 과제 재주석, 프레임별 품질 가중치의 3단
  - 구조는 비전·언어 전문가와 플로우 매칭 액션 전문가를 분리한 Mixture-of-Transformers, 공유 어텐션으로 연결
  - 선택 요소로 동결 비디오 생성 모델 기반 미래 프레임 예측을 월드 프라이어로 사전학습에 사용, 사전학습 후 보조 모듈은 제거하고 학습된 쿼리 토큰만 유지
- **차별점** — 몸통 리타깃팅을 생략하고 카메라 공간을 인간·로봇 공통 인터페이스로 사용
  - 같은 사전학습 예산에서 카메라 공간 표현 55.0%, 몸통 좌표계 기준 26.7%
- **핵심 기여** — 사전학습 레시피, 아키텍처, 평가 스위트, 실물 검증의 네 가지
  - 인간 에고센트릭 영상과 이종 로봇 데이터 총 10,000시간 이상을 처리하는 카메라 공간 레시피, 검증 손실은 데이터 예산에 대해 약 로그 선형 감소
  - 월드 프라이어를 선택적으로 넣는 이중 전문가 VLA 구조
  - 카메라 공간 오픈루프 지표, 미공개 장면 정책 롤아웃, 실물 평가를 묶은 평가 스위트
  - 실물 휴머노이드의 미공개 물체·어포던스·추론 지시 6개 과제에서 10,000시간 모델 성공률 55.0%, 5,000시간 이하 예산은 평균 최대 11.7%, 사전학습 없음 5.0%
- **가치** — 에고센트릭 중심 코퍼스의 규모 곡선을 실물 성공률로 연결한 공개 기준점

### (c) 시사점

- 에고센트릭 코퍼스 규모가 실물 일반화를 좌우한다는 직접 곡선
- 사전학습 예산을 직접 변수로 두고 포스트트레이닝 후 실물 성공률을 측정한 사례, 에고센트릭 중심 대 혼합 조성 질문의 규모 축 자료
- 5,000시간까지 평균 11.7% 이하였다가 10,000시간에서 55.0%로 도약, 에고센트릭 중심 조성에서 필요한 최소 규모 판단 근거
- 월드 프라이어를 사전학습에만 쓰고 추론에서 제거하는 구성, 단계별 레시피에서 사전학습 단계 보조 지도의 도입 비용 참고
- 카메라 공간 표현의 우위는 액션 표현과 사전학습 호환성 논의의 보강 자료

### (d) 먼저 확인할 점

- 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음, 코퍼스·체크포인트 확보 경로 확인 필요
- 규모 연구는 아키텍처 1종과 데이터 혼합 1종, 실물 평가는 구현체 1종·6개 OOD 과제·과제당 10회 시행으로 한정
- 비교 대상이 InternVLA-A1.5 위주, 그 밖의 모델과의 비교는 저자도 미수행으로 명시
- 에고센트릭 중심 대 혼합 코퍼스의 직접 분리 ablation은 아님, 규모 변화와 조성 변화의 구분 확인 필요
- 카메라 외부 파라미터 보정과 실물 로봇 포스트트레이닝이 여전히 필요, 구현체 의존이 완전히 사라지지 않음

### (b) 논문 요지

- VLM과 액션 헤드에 서로 다른 부분공간 예산을 둔 연속 기술 학습
- **문제** — 사전학습 VLA에 기술을 순차 추가할 때 이전 기술의 표현과 속도장 매핑이 흐트러지는 망각
  - 서로 크게 다른 행동 패턴을 맞추는 갱신이 기존 표현을 간섭해 속도장 예측이 왜곡됨
  - 평생 기술 습득을 요구하는 VLA 배포의 확장성을 저해
- **기존 한계** — 기존 접근 두 갈래의 한계
  - 아키텍처 기반 격리 — 기술이 쌓일수록 구성요소와 추가 연산이 늘어 실시간 제어에 불리
  - 부분공간 제약(그래디언트 투영) 기반 — 네트워크 전체에 균일한 제약을 걸어 VLA 구성요소의 역할 차이를 반영하지 못함
  - 직접 이식 시 두 가지 VLA 특유의 문제 — 모듈 간 표현 이질성, 최종 속도 디코더의 출력단 표현력 병목
- **핵심 방법** — 누적 그래디언트로 기술 특징 부분공간을 추정하고 이전 기술이 점유한 방향의 직교 여집합에 새 기술을 주입
  - VLM과 액션 헤드에 별도 부분공간 예산을 배정, VLM은 의미적 가소성 유지와 액션 헤드는 정밀한 속도 패턴 보호를 담당
  - 최종 속도 디코더는 직교 미세조정에서 제외하고 기술마다 소형 전문가를 할당하는 경량 MoE 디코더로 대체
  - 학습 없는 투영 기반 라우터가 그래디언트 기반 기술 기저와의 특징 공간 유사도로 전문가 선택
- **차별점** — 전체 균일 제약 대신 모듈별 예산 배분
  - VLM은 용량 소진에 취약하고 액션 헤드는 작은 섭동에 민감하다는 분석에 근거
  - 읽기 층인 디코더는 동결하면 표현력 병목, 갱신하면 기존 매핑 덮어쓰기 위험이라는 딜레마를 전문가 추가로 해소
- **핵심 기여** — 분석, 방법, 검증의 세 가지
  - VLA의 모듈 단위 표현 이질성과 출력단 표현력 병목 두 문제의 실증 규명
  - 모듈 수준 부분공간 예산 전략과 학습 없는 라우팅의 특징 인지 MoE 디코더
  - 시뮬레이션과 실물 환경에서 부분공간 제약 기준선 대비 이전 기술 유지와 최종 성공률 개선, ablation 포함
- **가치** — 구조 성장 없이 사전학습 프라이어 안에서 용량 위치별 보존 규칙을 정하는 방법

### (c) 시사점

- 백본 안에서 어디에 갱신 용량을 허용할지 모듈별로 나누는 보존 설계의 사례
- VLM 의미 용량과 액션 헤드 속도 패턴의 보호 강도가 다르다는 분석, 백본 동결 기본값과 액션 측 어댑터 구성을 점검할 근거
- 출력층 갱신이 기존 매핑을 덮어쓴다는 지적, 액션 측 어댑터 설계의 출력단 처리 참고

- **문제** — 영어 위주로 학습·평가된 로봇 파운데이션 모델에 다른 언어를 싸게 추가할 수 있는지
  - 그리스어 로봇 시연 데이터셋이 없고, 새로 수집하려면 수개월의 텔레오퍼레이션 필요
  - 저자들의 핵심 주장은 병목이 데이터나 모델이 아니라 측정 도구라는 점
- **기존 한계** — 기존 벤치마크의 언어 무시 현상
  - 장면마다 학습된 목표가 하나인 스위트에서는 VLA가 언어를 대체로 무시한다는 선행 연구가 있고, 저자들도 재현
  - 단일 목표 스위트 성공률 정상 그리스어 84.6%와 일부러 틀린 지시 82.6%
  - 색 히스토그램 지표는 노이즈에 점수를 주고 학습 손실은 그리스어 성공을 예측하지 못함
- **핵심 방법** — 기계 번역 지시만으로 아키텍처 변경 없이 그리스어를 추가하고 대조군으로 전이를 측정
  - 그리스어를 따를 수 없음이 보장된 동일 정책을 학습해 구성상 보장된 널 기준으로 사용
  - 90개 과제 스위트에서 팔마다 3시드로 반복
  - 다국어 텍스트 타워 유무, 이중 언어 시연 샘플링, 월드 모델 웜스타트, 텍스트 타워 해동 조건을 비교
- **차별점** — 가정하지 않고 구성으로 보장한 널 대조군
  - 두 번째 정책을 학습해야 하는 비용을 감수하고 섭동 기반 통제를 보완
- **핵심 기여** — 결과를 계층별로 정리하고 철회한 결론까지 함께 보고
  - 영어 중심 텍스트 타워는 SFT로 그리스어를 배우지 못했고, 다국어 타워로 바꾸면 일관된 그리스어 조건 장면을 생성
  - 월드 모델 웜스타트는 영어 79.2%(기본 96.4%)와 그리스어 13.6%(기본 48.6%)로 양쪽 모두 저하, 단 팔당 1회 실행
  - 이중 언어 시연 샘플링으로 10개 목표에서 그리스어 48.6%, 90개 과제 3시드 평균 27.4%
  - 이중 언어 정책의 마진은 매 시드에서 틀린 지시 대조군 대비 6.7–7.1점, 그리스어 단독은 최대 2.7점
  - 번역자 표현 과적합은 과제당 7개 표현 학습으로 약 절반 감소
  - 시드 불안정은 10개 목표에서 31.6점이었다가 90개 과제에서 2.4점으로 축소
- **가치** — 저자원 언어 로봇 정책 현지화에서 지표 신뢰 확보 절차 제시

### (c) 시사점

- 텍스트 타워 해동이 성능을 낮춘다는 3시드 측정
- 월드 모델 웜스타트의 부정적 전이가 단일 실행 결과라 확정 근거는 아니나, 단계 레시피에서 중간 단계 삽입 시 프라이어가 침식될 수 있다는 경고
- 널을 구성으로 보장하는 대조군 설계는 프라이어 보유 측정 전반에 이식 가능한 평가 절차
- 사전학습 선택 변수를 바꾼 연구가 아니라 프라이어 보유·적응 범위를 재는 증거 풀로 분류

### (d) 먼저 확인할 점

- 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음, 재현 경로 확인 필요
