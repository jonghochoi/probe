### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 하위과제 밀집 주석 데이터셋과 단일 VLA 미드트레이닝
- **문제** — 장시간 양손 조작 정책을 학습할 장기 양손 데이터와, 하위과제 경계를 학습 내내 밀집하게 표시하는 언어 지도의 부재
  - 사람처럼 과제를 진행 중인 하위과제 열로 쪼개 따라가는 능력이 정책에 필요하다는 전제
- **기존 한계** — 데이터셋과 모델 양쪽에서 하위과제 지도가 비어 있음
  - 단일 팔 데이터셋 — 수십만 궤적 규모이나 지시 하나가 붙은 짧은 pick-and-place 에피소드 위주
  - 기존 양손 데이터셋 — 가장 큰 것도 기록 시간의 일부에만 하위과제 라벨, 다양성을 집계로만 보고해 접촉 집약적 롱테일 기술 커버 여부가 가려짐
  - 기존 주석 파이프라인 — 영상 전체에 포괄 라벨을 달거나 실행 중 하위과제를 즉석 생성, 학습 내내 단계별 안내를 주지 않음
  - 플랫 VLA — 지시와 이미지를 곧바로 액션으로 매핑해 수 분짜리 과제의 진행 추적 수단 없음
  - 계층형 대안 — 계획과 실행을 서로 다른 두 모델로 분리
- **핵심 방법** — 사전학습 VLA 백본을 확장한 단일 end-to-end 정책 FineART-VLA
  - System-2 — 다음 하위과제를 언어로 예측
  - System-1 — 예측한 하위과제에 맞춰 연속 액션 실행
  - 계층적 추론과 knowledge insulation으로 두 역할을 한 모델 안에서 연결
- **차별점** — 하위과제를 별도 플래너의 출력이 아니라 학습 내내 지속되는 감독으로 쓰고, 계획과 실행을 한 정책에 유지
- **핵심 기여** — 데이터셋, 모델, 미드트레이닝 효과 3축
  - FineART 데이터셋 — 40,543 에피소드, 1,718시간, 151개 과제, 하위과제 라벨 533,913개로 에피소드당 약 13개, 전 에피소드에 주석
  - 하위과제 학습이 없는 동일 조건 정책 대비 공간 판별 과제 성공률 32.0%에서 100.0%, 사람 보정이 필요한 장기 과제 16.0%에서 76.0%
  - ALOHA 미드트레이닝 후 다른 로봇 YAM에서 원자 과제 5개 미세조정만으로 미학습 다단계 과제 달성, 아침 준비 28.0%, 도구 정리 12.0%, 방해물 속 케이블 넣기 60.0%
  - 새 로봇 최소 미세조정에서 미드트레이닝 없는 베이스라인이 필요로 하는 데이터의 10분의 1만 필요
  - 데이터셋, 모델 가중치, 학습 코드 공개
- **가치** — 하위과제 주석을 갖춘 대규모 공개 양손 코퍼스와 학습 레시피를 공통 기준점으로 제공, 긴 과제 지도를 정책 안으로 들이는 경로 제시

### (c) 시사점

- 미드트레이닝이 새 로봇 적응 데이터를 10분의 1로 절감
- 사전학습과 배포 적응 사이에 끼운 미드트레이닝 단계의 효과를 새 로봇 적응 데이터량으로 직접 측정한 사례
- 바꾼 변수가 인간 영상이 아니라 로봇 시연의 하위과제 주석 조성이므로, 에고센트릭 중심 대 혼합 조성 질문의 직접 근거는 아님
- 데이터셋과 가중치가 공개돼 단계형 레시피를 같은 조건에서 재현하고 비교할 공개 기준점 확보

### (d) 먼저 확인할 점

- 데이터셋이 단일 로봇 플랫폼 기반이고 정책 학습이 약 10% 에폭에 그친 점이 저자 명시 한계
- 10분의 1 데이터 비교에서 베이스라인의 구성과 미세조정 조건은 초록에 없어 원문 확인 필요
- 장기 과제 76.0%는 사람의 단계별 하위과제 안내가 붙은 조건
- 교차 임바디먼트 전이를 일으킨 미세조정 과제가 무엇인지 저자도 분리하지 못했다는 명시
- arXiv comment가 LeRobot 통합을 예고하는 형태로, 공개 시점과 위치는 원문 확인 필요

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 에고센트릭 사전학습 예산을 250–10,000시간으로 스케일
- **문제** — 휴머노이드 다지 조작 범용 정책이 데이터 가용성에 막힘
  - 실로봇 다지 조작 시연은 수집이 느리고 비싸며 웹 규모 조작 코퍼스가 없음
  - 에고센트릭 영상을 쓰려면 두 격차를 넘어야 함
  - 임바디먼트 격차 — 인간 손과 로봇 end-effector의 구조·관절 수 차이
  - 품질 격차 — 손 추적 노이즈, 약하게 정렬된 텍스트, 조작 없는 구간
- **기존 한계** — 인간 영상을 로봇 공간으로 옮기는 방식과 미정제 영상 사용 양쪽을 지적
  - 인간-로봇 몸체 리타깃팅 — 저가 에고센트릭 녹화에는 몸통 기구학이 없어 척추 강체 모델 같은 가정이 필요하고, 이 가정이 라벨 노이즈로 이어짐
  - 미정제 영상 — 추적 노이즈와 비조작 구간이 데이터 효율을 낮춤
- **핵심 방법** — 카메라 공간 액션 표현을 인간과 로봇의 공통 인터페이스로 둔 사전학습
  - 인간 궤적은 SLAM 카메라 움직임과 카메라 기준 손 움직임, 로봇 궤적은 보정을 거쳐 같은 표현으로 기술하고 액션 차원을 의미 기준으로 정렬
  - 규칙 기반 필터링, 원자 과제 재주석, 프레임별 품질 가중을 거는 다단계 정제 파이프라인
  - 비전-언어 전문가와 플로우 매칭 액션 전문가를 공유 어텐션으로 잇는 듀얼 전문가 Mixture-of-Transformers
  - 동결 비디오 생성 모델로 미래 프레임을 예측하는 월드 프라이어 감독을 선택적으로 추가, 사전학습 뒤 예측 모듈은 제거하고 학습된 쿼리 토큰만 유지
- **차별점** — 인간-로봇 몸체 리타깃팅을 하지 않고 에고센트릭 영상의 원래 기준 공간인 카메라 공간에서 인간과 로봇을 묶음
- **핵심 기여** — 레시피, 아키텍처, 평가 스위트, 로봇 검증 4축
  - 인간 에고센트릭 영상과 이종 로봇 데이터 합계 10,000시간 이상 사전학습 레시피, 검증 손실이 데이터 예산에 로그 선형으로 감소
  - 선택적 월드 프라이어를 붙인 듀얼 전문가 아키텍처
  - 카메라 공간 개루프 지표, 미관측 장면의 정책 인더루프 롤아웃, 실로봇 평가를 묶은 평가 스위트
  - 실제 휴머노이드의 미관측 물체·어포던스·추론 지시 6개 과제에서 10,000시간 모델 55.0%, 5,000시간 이하 예산은 모두 최대 11.7%, 사전학습 없음 5.0%
  - 같은 사전학습 예산에서 카메라 공간 표현 55.0%, 몸통 프레임 베이스라인 26.7%
- **가치** — 에고센트릭 인간 영상 중심 사전학습이 예산에 따라 실물 OOD 성능을 끌어올린다는 스케일링 근거와 리타깃팅 없는 공통 액션 표현 제시

### (c) 시사점

- 에고센트릭 우선 코퍼스의 규모-OOD 곡선을 실물로 실증
- 예산을 250–10,000시간으로 바꿔 사후학습 OOD 실물 성능을 측정한 사례, 5,000시간 이하 최대 11.7%에서 10,000시간 55.0%로 도약해 사전학습 규모가 직접 레버라는 정량 근거
- 같은 예산에서 카메라 공간 표현이 몸통 프레임을 앞선 비교가 액션 표현 선택이 사전학습 효율을 좌우한다는 직접 측정
- 에고센트릭 인간 영상 비중이 큰 코퍼스 구성의 스케일 참고점

### (d) 먼저 확인할 점

- 프로젝트 페이지만 명시, 저장소와 체크포인트 URL 미기재로 확보 경로 확인 필요
- 인간 영상과 로봇 데이터를 합산한 예산 증가 실험으로, 에고센트릭 단독 대 혼합 조성을 분리한 결과인지 원문 확인 필요
- 실물 평가가 휴머노이드 1종의 6개 과제로 요약되어 과제당 시행 수는 원문 확인 필요
- 55.0%의 절대 수준이 아직 낮아 실사용 기준점으로 쓰기 전 과제별 분포 확인 필요

## 🥉 논문 3

**Towards a General Humanoid Loco-Manipulation Model via Egocentric Whole-Body Human Data Pretraining**
[arXiv:2610.00438](https://arxiv.org/abs/2610.00438) · Chongyang Xu, Zhao Wu, Jin Chen, Yiming Jiang 외 8인 · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 9/15** · R3 · N2 · M2 · Real1 · Repro1 — abstract "We will release our code, models, and data to support further research."

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 전신 인간 데이터 500시간으로 3단계 사전학습
- **문제** — 휴머노이드 전신 로코-매니퓰레이션 정책에 몸 움직임과 손-물체 상호작용의 시간적 협응을 담은 시연이 필요
  - 접근, 자세 조정, 잡은 채 이동이 이어지는 과제 특성
- **기존 한계** — 두 수집 경로 모두 전신 협응 지도를 충분히 주지 못함
  - 전신 텔레오퍼레이션 — 로봇 시간과 인력이 많이 들어 과제와 환경 전반으로 확장하기 어려움
  - 에고센트릭 영상에서 손목·손 궤적을 복원하는 방식 — 손 움직임만 얻어 전신 협응을 담지 못함
- **핵심 방법** — 전신 인간 데이터셋 HumanVerse-500과 3단계 학습의 정책 λ0
  - 1단계 — 다양한 에고센트릭 데이터셋으로 손 움직임 상호작용 학습
  - 2단계 — HumanVerse-500으로 몸과 손 움직임의 협응을 학습하는 전신 미드트레이닝
  - 3단계 — 하위 과제와 로봇 임바디먼트에 맞춘 로봇 후학습
  - 단계 간 공유 표현 공간으로 전이하고 인간과 로봇의 상태·액션 차이는 도메인별 인터페이스가 처리
- **차별점** — 손 궤적 위주 지도에서 벗어나 에고센트릭 영상, 몸 움직임, 손 움직임을 동기화한 전신 지도를 미드트레이닝 단계로 편입
- **핵심 기여** — 데이터셋, 정책, 스케일링과 단계 ablation
  - HumanVerse-500 — 경량 웨어러블로 에고센트릭 영상과 몸 움직임을 동기화해 수집한 500시간의 개방 환경 인간 로코-매니퓰레이션 데이터
  - SIMPLE과 실물 로코-매니퓰레이션 4개 과제에서 가장 강한 평가 베이스라인 대비 성공률 3.9, 22.5 퍼센트포인트 향상
  - 2단계 데이터를 5%에서 100%까지 늘린 중첩 부분집합 비교에서 최소 검증 손실이 representative 35.5%, clean 40.6% 감소, 로그 피팅 R²는 0.9868과 0.9901
  - 인간 데이터 두 단계 중 전신 미드트레이닝이 실물 성공에 더 크게 기여, 인간 시연은 로봇이 못 본 물체의 진행도를 개선
- **가치** — 전신 협응이 담긴 인간 데이터가 휴머노이드 전신 정책의 확장 가능한 감독원임을 규모와 단계별 기여로 제시

### (c) 시사점

- 전신 미드트레이닝의 실물 기여를 단계별로 분리
- 인간 데이터 사용 단계를 나눠 어느 단계가 실물 성공을 더 올리는지 ablation한 사례, 단계형 레시피의 단계별 기여를 읽는 정량 자료
- 에고센트릭 데이터셋 사전학습과 전신 데이터 미드트레이닝의 순서가 곧 에고센트릭 중심 코퍼스의 커리큘럼 설계 참고점
- 인간 시연이 로봇 미관측 물체 일반화에 기여한다는 결과가 조성 질문의 보조 근거

### (d) 먼저 확인할 점

- 코드와 모델, 데이터는 공개 약속 단계, 저장소나 프로젝트 페이지 URL 미기재

- 실물 4개 과제의 과제별 성공률과 시행 수는 초록에 없어 원문 확인 필요
