## 🥇 논문 1 — 우선순위 ★★★

**π0: A Vision-Language-Action Flow Model for General Robot Control**
[arXiv:2410.24164](https://arxiv.org/abs/2410.24164) · Physical Intelligence (Kevin Black, Danny Driess, Karl Pertsch 외) · source: 소스(P4 §5 핀, lineage)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D19b](https://img.shields.io/badge/D19b-d97706.svg)](#ref-D19b) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **구조** — PaliGemma-2B 백본을 동결한 채 별도 flow-matching action expert만 학습, freeze + action expert 격리의 정본
- **lineage 정의** — PaliGemma-2B × π0 mix 가중치(openpi)의 정의 논문
- **연속 헤드 원형** — 연속 flow-matching head 선택의 원형, 조건 특징에 stop-gradient를 씌우면 VLM이 embodied 학습에서 분리된다고 정리
- **보존 전략 계승** — action-side adapter(= split heads) 보존 전략이 π0의 expert 패턴을 그대로 계승
- **진정으로 새로운 점** — 핀 논문 중 유일하게 백본 동결 + 액션 전문가 + flow matching 전체를 한 논문에 묶어 정의, 다른 핀(VLM2VLA·VLA-Adapter)이 π0 대비 *어디를 바꿨나*로 정의되는 반면 π0는 그 기준선 자체

### (c) 시사점

- **분석 강력 권고** — 핀 lineage·연속 헤드·보존 전략의 공통 출처인데도 `analysis/` deep-dive 부재
- **deep-dive 산출 기대값**
  - VLM freeze + 전문가 학습 단계의 flow-matching expert 구조를 `vendor/lerobot` 좌표로 매핑 → 구현 진입점 확보
  - conditioning 경로(cross-attention vs prefix)와 stop-gradient 적용 지점 확정 → freeze 무결성 검증의 측정 대상 레이어 결정
  - 50-step chunk · flow-matching 손실 $`L_{\text{FM}}`$ 의 하이퍼파라미터를 기본값으로 고정

### (d) 먼저 확인할 점

- **lineage 분포 한계** — π0는 양팔·그리퍼 중심 데이터(OXE + π in-house)로 학습된 lineage
- **다지 정보 충분성** — 다지 조작(in-hand rotation) 분포에서 동결 백본 특징 $`h`$ 안에 손가락 제어 정보가 충분한지 미검증, 부족하면 LoRA 이동 trigger 조기 발동 우려

## 🥈 논문 2 — 우선순위 ★★

**VLA-Adapter: An Effective Paradigm for Tiny-Scale Vision-Language-Action Model**
[arXiv:2509.09372](https://arxiv.org/abs/2509.09372) · source: 소스(P4 §7 Competitor)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19b](https://img.shields.io/badge/D19b-d97706.svg)](#ref-D19b) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **구조** — action-side adapter의 대표, Prismatic-VLM + Qwen2.5-0.5B(0.5B 초소형 백본)에 Bridge Attention 어댑터만 붙여 LIBERO + CALVIN으로 학습
- **lineage 반례** — "백본 규모를 키워도 이득이 제한적"이라는 보고는 규모 우선론의 직접 반례
- **진정으로 새로운 점**
  - "성능을 가르는 본질은 사전학습 백본"이라는 대전제의 반례 트랙
  - 0.5B 백본 + 어댑터만으로 경쟁력, robot-data 사전학습 없이 벤치마크만으로 학습
  - split-heads-as-adapter 가설과 같은 평면(어댑터로 제어 능력 주입)에 있되 백본을 키우지 않는 극단 선택

### (c) 시사점

- **분석 강력 권고** — 별도 가설 트랙으로 다룰 반례로 명시되었으나 deep-dive 부재
- **deep-dive 산출 기대값**
  - Bridge Attention의 어댑터-백본 결합 방식을 split-head 보존 전략과 인터페이스 레벨에서 대조 → 어댑터가 백본의 어느 레이어 hidden을 읽는지 좌표화
  - "백본 규모 무관" 주장을 lineage 2-pair 비교 실험의 대조 가설로 등록

### (d) 먼저 확인할 점

- **시뮬레이션 편중** — 검증이 LIBERO + CALVIN 시뮬레이션 중심
- **반례 성립 범위** — 0.5B 백본의 의미 prior 빈약함이 다지·접촉 집약적 태스크 일반화에서 드러나는지(반례가 우리 스코프에서도 성립하는지) 먼저 확인 필요

## 🥉 논문 3 — 우선순위 ★

**VLM2VLA: Actions as Language — Scaling VLA Models via Natural-Language Action Representation**
[arXiv:2509.22195](https://arxiv.org/abs/2509.22195) · Hancock et al. · source: 소스(P4 §5/§7 핀)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **구조** — LoRA-only, Gemma-3-12B-IT의 모든 linear module에 LoRA만 걸어 backbone을 최소 수정
- **원인 제거** — 저수준 행동을 자연어로 표현해 사전학습 분포와의 불일치를 데이터 레벨에서 먼저 해소, NL-style action의 출처
- **진정으로 새로운 점**
  - forgetting을 "분포 불일치"로 진단하고 그 갭 자체를 데이터로 제거(action을 NL로 정합)한 뒤 LoRA만으로 학습
  - 보존을 사후 방어(정규화·replay)가 아니라 상류 원인 제거로 푸는 유일한 핀 논문
  - VQA 보존 + 다국어 instruction following zero-shot 일반화를 800회 이상 실세계 실험으로 입증

### (c) 시사점

- **분석 권고** — LoRA 이동 또는 NL-action 이동 시 유일한 레퍼런스 경로인데 deep-dive 부재
- **deep-dive 산출 기대값**
  - LoRA 적용 범위(all linear modules) · rank를 다음 단계 진입 시 기본 후보값으로 고정
  - NL-action 정합 파이프라인(Gemini-2.5 변환) 비용을 NL-action 전환 트리거의 사전 점검 항목으로 등록
  - VQA 보존 측정 프로토콜을 고정 probe와 정렬

### (d) 먼저 확인할 점

- **NL 토큰화 병목** — NL-action은 행동 표현을 자연어 정합에 묶음, 손가락 관절 궤적처럼 자연어로 손실 없이 토큰화하기 어려운 다지 제어에서 표현력 병목 발생 여부
- **freeze 누수** — language head 경로 누수로 freeze가 깨지지 않는지 먼저 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**LoRA: Low-Rank Adaptation of Large Language Models**
[arXiv:2106.09685](https://arxiv.org/abs/2106.09685) · Hu et al. · adjacent field: PEFT(parameter-efficient fine-tuning) · source: 소스(taxonomy §2.2 B①)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **수학적 토대** — LoRA/adapter PEFT 옵션의 수학적 토대, 부분공간 제약 계열의 정본
- **단계적 활용** — LoRA / top-layer 제한적 fine-tuning 단계에서 직접 사용하는 기법
- **진정으로 새로운 점**
  - $`W = W_0 + BA`$ ($`r \ll \min(d,k)`$)로 갱신을 저차원 부분공간에 가두어, 백본을 동결한 채 "멀리 갈 수 있는 방향 자체"를 제한
  - P4 맥락에서는 *보존 전략*이라기보다 LoRA 이동 시 쓰는 도구의 원전

### (c) 시사점

- **분석 보류 / 낮음** — 기법 자체는 taxonomy에 이미 정리되어 별도 deep-dive 한계효용 낮음
- **인용 용도** — LoRA 단계 진입 시 rank · 적용 모듈을 "작은 값부터"(measurement-first) 스윕하는 기준 문헌으로 인용

### (d) 먼저 확인할 점

- **rank 트레이드오프** — rank가 너무 낮으면 새 행동 특징 학습이 질식, 너무 높으면 forgetting 경로가 넓게 열림
- **미지수** — VLA에서의 rank↔KL 곡선은 우리가 직접 측정해야 할 미지수
