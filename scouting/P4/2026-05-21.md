## 🥇 논문 1 — 우선순위 ★★★

**UAM: A Dual-Stream Perspective on Forgetting in VLA Training**
[arXiv:2605.15735](https://arxiv.org/abs/2605.15735) · Jianke Zhang, Yuanfei Luo, Yucheng Hu, Xiaoyu Chen, Yanjiang Guo, Ziyang Liu, Hongbing Xu, Tian Lan, Jianyu Chen · 2026-05-15 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **현상 정량화** — VLM을 액션 데이터로 미세조정하면 멀티모달 역량이 체계적으로 침식되는 "구현 세금(embodiment tax)" 정량화
- **구조적 진단** — 단일 인코더가 언어-의미 표현과 제어 관련 시각 특징을 동시에 떠안는 구조가 침식의 병목
- **병렬 Dorsal Expert** — 생물학적 등측 경로(dorsal pathway)에서 영감, 사전 훈련된 생성 모델로 초기화 후 시각 동역학 예측 목적 함수로 학습하는 병렬 분기 추가
- **결과** — 파라미터 동결·그래디언트 차단·보조 VL 공동학습 없는 end-to-end 훈련만으로 VLM 멀티모달 역량 95% 이상 보존, OOD 조작 과제(미학습 객체·새로운 객체-목표 조합·언어 변형)에서 베이스라인 최고 성공률 달성
- **핵심 주장** — "보존은 동결이 아닌 아키텍처 분리에서 창발"

### (c) 시사점

- **동결 전제 재검토 여지** — 동결이라는 처방을 아키텍처 분리로 대체할 가능성 제시
- **저비용 비교 경로** — Dorsal Expert 분기 추가 vs. 완전 동결을 소규모 에블레이션으로 우선 비교 가능
- **모니터링 지표 후보** — VQA/GQA 계열 멀티모달 벤치마크 점수로 VLM 침식 여부 측정

### (d) 먼저 확인할 점

- **초기화 모델 불명** — Dorsal Expert 초기화에 쓸 "사전 훈련된 생성 모델"을 논문이 구체 명시하지 않음, 임의 초기화 대체 시 성능 유지 여부 선확인 필요
- **검증 환경 불명** — 초록이 OOD 실험의 실제 로봇/시뮬레이션 여부 미명시, Sim2Real 보수적 평가, 실제 로봇 검증 독립 요구
- **고차원 적용 미검증** — 인핸드 다지 조작 고차원 액션 공간에서 Dorsal Expert가 시각 동역학을 올바르게 분리하는지 미검증

## 🥈 논문 2 — 우선순위 ★★

**Preserving Foundational Capabilities in Flow-Matching VLAs through Conservative SFT**
[arXiv:2605.08879](https://arxiv.org/abs/2605.08879) · Tianyi Zhang, Shaopeng Zhai, Haoran Zhang, Fuxian Huang, Qi Zhang · 2026-05-09 · source: citation-graph + keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **대상** — 플로우 매칭 VLA(플로우 매칭) 계열 π0·π0.5·GR00T-N1.6-3B를 직접 대상으로 사전학습 역량 침식 문제 취급
- **ConSFT (Conservative Supervised Fine-Tuning)** — 모델 신뢰도(confidence)에 따라 학습 신호를 동적 스케일링, 저신뢰도 샘플의 과도한 그래디언트 억제
  - RL의 trust-region 클리핑(PPO 유사)에서 영감, 단 참조 네트워크·사전 데이터·구조적 overhead 불필요
- **결과** — vanilla SFT 대비 역량 보존에서 평균 20%p 이상 절대 성능 향상, 사전 데이터가 필요한 Experience Replay와 동등 보존 효과, 실제 로봇 배치에서 공간적 과적합(spatial overfitting) 억제 확인

### (c) 시사점

- **목적 함수 후보** — 단계적 학습 후반 진입 시 미세조정 목적 함수를 교체할 구체 후보 확보
- **모니터링 지표 후보** — LIBERO / RoboTwin 평가에서 멀티모달 VQA 점수 병행 추적으로 역량 보존 측정
- **에블레이션 항목** — 후반 단계 진입 직후 ConSFT vs. vanilla SFT 비교, 공간적 과적합 여부 대조

### (d) 먼저 확인할 점

- **보정 의존** — 신뢰도 스케일링이 π0 플로우 매칭 모델의 신뢰도 보정(calibration)에 의존, 보정이 어긋나면 잘못된 위치에서 그래디언트 억제 가능
- **고난도 과제 미검증** — LIBERO·RoboTwin 위주, 접촉 집약적 인핸드 조작 등 고난도 과제 효과 미검증
- **재현성** — 코드 미공개로 신뢰도 임계 구현의 재현성 직접 확인 필요

## 🥉 논문 3 — 우선순위 ★

**VLA-GSE: Boosting Parameter-Efficient Fine-Tuning in VLA with Generalized and Specialized Experts**
[arXiv:2605.06175](https://arxiv.org/abs/2605.06175) · Yuhua Jiang, J. Lu, X. Qin, Xiaoyu Chen, Kaixin Wang, Feifei Gao, Li Zhao · 2026-05-07 · source: citation-graph

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **위치** — LoRA/어댑터 PEFT(파라미터 효율적 미세조정, PEFT)의 구체적 구현 방법론, 코드 공개로 즉시 에블레이션 가능
- **스펙트럼 분해(spectral decomposition)** — 동결된 백본을 분해해 선두 특이 성분(leading singular components)은 공유 일반화 전문가(Generalized Expert)에, 직교 잔차 성분(disjoint residual)은 라우팅 특화 전문가(Specialized Expert)에 할당
  - 표준 LoRA의 랜덤 초기화와 달리 백본의 실제 가중치 구조를 활용해 학습 가능 파라미터 배치
- **결과** — 훈련 가능 파라미터 2.51%만으로 LIBERO-Plus 제로샷 성공률 81.2% 달성, LoRA 수준 VLM 역량 보존, 실제 로봇 분포 이동(distribution shift)에서도 성능 개선, GitHub 코드 공개

### (c) 시사점

- **초기화 기본값 후보** — PEFT 진입 시 표준 LoRA 초기화 대신 SVD 기반 스펙트럼 초기화를 기본값으로 채택할 후보
- **파라미터 예산** — 학습 가능 파라미터 2.51% 수준으로 보존-효율 양립 가능성
- **정량화 경로** — 훈련 후 VQA 계열 멀티모달 점수로 LoRA 비교군 대비 VLM 역량 보존 정량화

### (d) 먼저 확인할 점

- **백본 미검증** — π0 백본(PaliGemma 계열) 직접 테스트 없음, OpenVLA/LLaVA 기반 평가, 플로우 매칭 아키텍처에서 스펙트럼 초기화 효과 동일 여부 확인 필요
- **전처리 비용** — SVD 분해는 대규모 Transformer 레이어에서 전처리 계산 비용 발생, 훈련 전 시간 예산 확인 필요
- **라우팅 혼선** — 라우팅 기반 Specialized Expert가 접촉 집약적 인핸드 조작처럼 강한 특화 신호에서 공유 전문가와 혼선 가능

**AT-VLA: Adaptive Tactile Injection for Enhanced Feedback Reaction in Vision-Language-Action Models**
[arXiv:2605.07308](https://arxiv.org/abs/2605.07308) · Xiaoqi Li, Muhe Cai, Jiadong Xu, Juan Zhu, Hongwei Fan, Yankun Shen, Guangrui Ren, Hao Dong · 2026-05-08 · adjacent field: P2 (구조적 촉각 입력-모달리티 결합) × P3 (이중 스트림 System0/System1)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **검증 대상** — "미세조정 단계에서 새 모달리티를 도입하면 사전학습 역량이 훼손될 수 있다"는 명제를 독립 실험으로 검증, P2(촉각 입력 구조화)·P3(이중 스트림 System0/System1)와 직접 교차
- **적응적 촉각 주입(Adaptive Tactile Injection)** — 촉각 신호가 액션 생성에 유의미하게 기여하는 시점·위치만 동적으로 결정해 주입
  - "항상-켜짐" 주입이 사전학습 표현을 교란함을 확인, 적응적 타이밍으로 방지
- **이중 스트림** — 느린 VLM 시각-언어 스트림(저주파 인식 추론) + 빠른 촉각 제어 스트림(0.04초 응답, 고주파 물리 상호작용) 분리, 실제 로봇 접촉 집약적 조작에서 유효성 확인

### (c) 시사점

- **late-fusion 합리성 뒷받침** — 늦은 촉각/구조화 입력 융합으로 백본은 사전 훈련 모달리티만 처리한다는 방향을 실험적으로 지지
- **게이팅 참조** — 촉각 모달리티 도입 시 적응적 게이팅 메커니즘을 임계값 설계 참조로 활용 가능
- **금지 방향** — 항상-켜짐 촉각 주입은 VLM 침식 유발이므로 명시적 금지 방향 후보

### (d) 먼저 확인할 점

- **임계값 재튜닝** — 적응적 주입 임계값이 과제별로 달라질 수 있어 새 배포마다 재튜닝 필요 가능
- **하드웨어 요구** — 빠른 촉각 스트림(0.04초)은 전용 하드웨어 요구, 현재 센서 인터페이스와 호환성 사전 확인 필요
- **다지 확장 미검증** — 다지 조작처럼 다중 손가락 동시 촉각 피드백 환경에서 확장 가능성 미검증
