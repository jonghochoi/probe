### (b) 핵심 기여

- **Xiaomi-Robotics-U0** — 380억 파라미터 규모 멀티모달 오토리그레시브 모델, 텍스트-이미지 생성·이미지 편집·임바디드 장면 생성·임바디드 전이·임바디드 비디오 생성을 하나의 통합 목적함수로 공동 최적화
- **파운데이션 월드모델 계보 확장** — 기존 로봇 데이터로 파운데이션 모델을 어댑테이션할 때 대규모 사전학습으로 얻은 시각 생성 지식이 훼손되는 문제를 겨냥, 임바디드 생성을 "파운데이션 이미지/비디오 생성의 확장"으로 재정식화해 사전학습 지식 보존과 임바디드 특화를 동시에 달성
- **Catastrophic forgetting 회피 레시피** — T2I·이미지 편집 태스크를 임바디드 적응 전 과정에서 지속적으로 co-training에 포함시켜 일반 시각 생성 능력의 망각을 구조적으로 차단, 별도 벤치마크(Table 4)로 일반 이미지 생성·로컬 편집 성능이 어댑테이션 후에도 유지됨을 확인
- **스케일러블 데이터 엔진 검증** — 임바디드 장면 생성 파이프라인으로 클린 실물 데모(태스크당 약 40시간) 대비 동일 규모의 스타일 변환 증강 데이터(배경·조명·텍스처 변주, 로봇 상태·액션 라벨은 보존)를 생성, 이를 π0.5 정책 파인튜닝에 co-training 데이터로 투입해 도전적 실물 조작 과제에서 OOD 성공률을 36.9%에서 63.2%로 향상
- **검증 범위** — 실물 태블탑 조작 3과제(이어폰 정리·수건 개기·상자 포장) 마일스톤 기반 평가, GPT-Image-2.0 대비 인간 평가 임바디드 장면 생성·전이 우위, World Arena 임바디드 비디오 생성 1위

### (c) 시사점

- 사전학습된 파운데이션 시각 생성 모델의 지식을 로봇 도메인 적응 중에도 보존하는 구체적 co-training 레시피 확보 — 백본 동결이 아닌 "지속적 다중 태스크 리허설"이라는 별도 보존 채널의 실증 사례
- 동일 파운데이션 가중치가 (i) 데이터 증강 엔진, (ii) 임바디드 장면/전이 생성기로 동시에 재사용 가능함을 실증 — 사전학습 투자 대비 활용 폭 확장 참고 사례
- 핀 논문(π0.5) 정책의 실물 OOD 성공률을 직접적·정량적으로 끌어올린 사례로, 파운데이션 월드모델을 로봇 정책 사전학습의 보조 데이터 소스로 쓰는 접근의 구체적 효과 확보

### (d) 먼저 확인할 점

- **의미론적-기하학적 잠재 액션 모델** — 현재 관측과 미래 관측 간 변화를, 원본 픽셀이 아니라 DINOv3 특징 공간과 깊이(depth) 공간의 델타로 예측하도록 사전학습, 외형 디테일에 덜 민감하면서 과제 관련 의미·기하 구조는 보존
- **단계적 학습 구조** — 사전학습된 인코더가 안정적 잠재 액션 타깃을 제공하고 디코더는 학습 가능한 잠재 월드모델로 기능, 정책 학습 단계에서 로봇 액션 예측·잠재 액션 타깃 매칭·미래 동역학 예측을 공동 지도학습
- **핵심 실험 — 에고센트릭 인간 비디오의 실물 전이 효과 정량화** — 로봇 데모 없이 빵을 집어 접시에 놓는 신규 과제에 대해 관련 장면의 액션-프리 에고센트릭 인간 비디오 400개를 추가한 결과, 실물 로봇 제로샷 성공률이 10회 중 3회에서 9회로 향상
- **검증 범위** — RoboTwin·RoboCasa(75.2% 평균 성공률로 신규 SOTA) 시뮬레이션 벤치마크와 다과제 실물 로봇 조작 실험(데이터 예산별 비교)

### (c) 시사점

- 사전학습 목표를 원본 픽셀 재구성 대신 의미·기하 특징 공간의 델타로 바꾸는 설계가, 액션 라벨 없는 다양한 비디오 소스를 활용 가능하게 만드는 실용적 경로로 확인
- 액션 라벨 데이터와 액션-프리 비디오를 하나의 잠재 액션 학습 목표로 통합하는 구체적 학습 레시피 사례 확보 — 단계적 사전학습·정책 학습 설계 시 직접 참고 가능

### (d) 먼저 확인할 점

- 핵심 zero-shot 전이 실험이 10회 시행 기준(3/10→9/10)으로, 통계적 유의성 판단에는 시행 규모가 제한적
- 프로젝트 페이지(`liujiahao2077.github.io/WALA.github.io`)가 확인되나, 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 코드·데이터 실접근은 미검증
- 다지 손 조작 언급 없이 표준 그리퍼 플랫폼 중심 검증 — 손재주 조작 태스크로의 이전 여부는 미검증

## 🥉 논문 3 — 우선순위 ★

**SPACE: Enabling Learning from Cross-Robot Data Toward Generalist Policies**
[arXiv:2606.24049](https://arxiv.org/abs/2606.24049) · Haeone Lee, Byeongguk Jeon, Suchae Jeong, Jian Kim, Kimin Lee · 2026-06-23 · source: citation-graph (GR00T N1 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **문제 정의** — 서로 다른 로봇(embodiment 간, 심지어 동일 embodiment의 하드웨어 유닛 간)은 동일 동작을 위해 다른 제어 커맨드가 필요, 이 불일치가 여러 로봇에 걸친 데이터로 정책을 학습·배포하는 것을 방해
- **SPACE 프레임워크** — Cartesian 상태 델타(엔드이펙터의 기하학적 변위)를 로봇에 무관한 범용 액션 표현으로 채택, State Prediction 정책이 이를 예측하면 Action Adapter가 로봇별 제어 커맨드로 변환
- **경량 캘리브레이션** — Action Adapter는 무작위 스크립트 정책으로 수집한 1분 미만 분량의 캘리브레이션 궤적(10개, 길이 50)만으로 선형회귀 기반 적합, 로봇 접근 시 이후 튜닝 없이 즉시 적용 가능
- **검증 범위** — 실물 Franka Research 3(DROID 플랫폼) + UR5 크로스-embodiment co-training(π0.5 정책을 베이스로 파인튜닝), 동일 embodiment 내 하드웨어 유닛 간(DROID 여러 유닛) 학습, 제어 주파수·페이로드·컨트롤러 게인 변화에 대한 배포 시점 강건성까지 확인

### (c) 시사점

- 서로 다른 로봇의 데이터를 하나의 사전학습·co-training 코퍼스로 묶을 때 액션 표현의 이질성이 걸림돌이 된다는 점과, 이를 낮은 비용으로 해소하는 구체적 어댑터 설계를 실물로 확보 — 크로스-embodiment 코퍼스 구성 시 직접 참고 가능한 실용적 해법
- 핀 논문(π0.5) 정책을 그대로 베이스로 사용해 검증한 사례로, 기존 계보에 대한 낮은 통합 비용 확인
- 액션 표현 선택이 사전학습 데이터의 재사용 범위(embodiment 수·하드웨어 유닛 수)를 실질적으로 좌우한다는 정량 근거 — 액션 표현과 사전학습 코퍼스 구성을 함께 설계해야 한다는 논리를 실물로 뒷받침

### (d) 먼저 확인할 점

- 검증이 그리퍼 기반 양팔·단일팔 조작(Franka·UR5)에 집중 — 다지 손 조작 플랫폼으로의 확장 여부는 미검증
- 에고센트릭 인간 데이터가 아닌 로봇 간(텔레오퍼레이션) 데이터 중심 검증 — 사람 비디오 코퍼스로의 확장 가능성은 별도 확인 필요
- 프로젝트 페이지(`haeone.site/space-website`)가 확인되나, 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 코드 실접근은 미검증
