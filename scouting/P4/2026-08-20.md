## 🥇 논문 1 — 우선순위 ★★

**G0.5: One Autoregressive Stream for Robot Reasoning and Action**
[arXiv:2608.11739](https://arxiv.org/abs/2608.11739) · Yicheng Liu, Zibin Dong, Baijun Ye, Tianyuan Yuan, Tao Jiang 외 22인 · 2026-08-12 · arXiv preprint · source: citation-graph (π0·π0.5·GR00T N1·Being-H0.5·Xiaomi-Robotics-0·Qwen-VLA 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여
- 기존 VLA 레시피는 사전학습된 VLM에 별도 학습된 플로우매칭 액션 전문가를 결합해, VLM을 맥락 인코더로만 쓰고 의사결정자 역할을 하지 못하게 만드는 한계를 지적
- 단일 트랜스포머 디코더가 추론 토큰과 액션 토큰을 하나의 목적함수 아래 함께 생성하는 사전학습 자기회귀 VLA **G0.5** 제안
- 이종 로봇 액션을 공유 어휘로 매핑하는 학습 가능한 임바디먼트 간 액션 토크나이저, 과제 분해·물체 접지·액션 힌트를 액션 토큰과 교차 삽입하는 네이티브 사고연쇄 스트림, 시각 인코더로 수 초 규모 이력을 주입하는 시각 메모리 모듈 세 요소로 대규모화 가능성 확보
- 로봇 데이터셋과 VQA 샘플을 함께 사전학습, 실물 로봇 사후학습(R1lite/R1pro)·BEHAVIOR Challenge·DROID 제로샷 전이·LIBERO·RoboTwin 2.0·SimplerEnv-Bridge 등 7개 독립 평가 체계에서 π0.5·GR00T-N1.7 등 최신 모델 대비 우위(R1lite/R1pro 76.7% vs 53.3%/24.4%)
- 추론과 액션이 가중치를 공유해 사전학습된 VLM의 능력이 물리적 행동으로 직접 전이, 추가 학습 없이 프롬프트만으로 액션 세분도·과제 시간범위·분포 밖 장면 대응 조정 가능

### (c) 시사점
- VLM을 맥락 인코더로 남기는 분리형 백본+플로우매칭 전문가 구조 대신, 추론·액션을 한 스트림에 통합하는 대안 계보를 실물 로봇 다중 벤치마크로 검증한 사례 확보
- 프롬프트만으로 액션 세분도·시간범위·OOD 대응을 조정 가능해, 배포 후 재학습 없는 거동 제어 축 별도 확보
- 7개 독립 평가 체계 전반에서 일관된 우위, 백본 계보 선택 논의에 폭넓은 비교 근거 축적

### (d) 먼저 확인할 점
- 코드·체크포인트·데이터 공개 여부가 원문에 명시되지 않아 재현 가능성 자체 확인 필요
- 27인 규모 대형 연구팀·산업 규모 사전학습 자원 투입이 전제, 자사 규모에서 동일 구조가 동일 이득을 내는지 확인 필요
- 자기회귀 방식 특유의 추론 지연시간(디코딩 스텝 수)이 원문에 정량화되어 있는지, 실시간 제어 요구와 양립 가능한지 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Pre-training Visual Dexterity in Simulation**
[arXiv:2608.15917](https://arxiv.org/abs/2608.15917) · Sarthak Kamat, Adam Rashid, Satvik Sharma, Aseem Doriwala, Chelsea Finn 외 2인 · 2026-08-16 · arXiv preprint · source: citation-graph (π0 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여
- 대규모 사전학습이 로봇 정책 파인튜닝을 데이터 효율적으로 만들었으나, 이 흐름이 대부분 평행 조 그리퍼 데이터셋·임바디먼트에 국한돼 다지 손은 상대적으로 데이터 기근 상태임을 지적
- 실제 텔레오퍼레이션은 스케일 비용이 크고, 인간 손 비디오는 오프-임바디먼트라 손실이 큰 자세 추정·리타게팅이 필요하다는 두 경로의 한계에 정면 대응
- VR 헤드셋 안에서 인간이 가상 물체를 조작해 온-임바디먼트 궤적을 로봇 없이 수집하는 시뮬레이션 사전학습 프레임워크 **SPD** 제안, 5명의 오퍼레이터가 1주일간 75시간 규모 다중 과제 다지 조작 데이터 수집
- 시퀀스 모델링 목적함수로 인과 트랜스포머를 사전학습한 뒤, 56자유도 양팔 다지 조작 실물 셋업에서 1–2시간 규모 실제 시연만으로 파인튜닝
- 스크래치 학습 행동복제 정책 대비 우위 확인, 이력 조건화·짧은 액션 청크가 반응적 제어에 기여함을 ablation으로 확인

### (c) 시사점
- 에고센트릭 인간 비디오나 실제 텔레오퍼레이션 없이도, VR 시뮬레이션에서 온-임바디먼트 궤적을 수집해 사전학습 데이터로 쓰는 제3의 경로 확보
- 다지 손 특유의 데이터 기근 문제에 직접 대응하는 사전학습 데이터 소스로, 손재주 조작 중심 전략과 정합
- 실제 로봇 파인튜닝에 필요한 시연이 1–2시간 규모로 소량, 배포 단계 데이터 효율성 개선과도 직결

### (d) 먼저 확인할 점
- 5명 오퍼레이터·75시간 규모로 데이터 규모 자체가 크지 않아, 더 큰 스케일에서도 이득이 유지되는지 확인 필요
- 비교 기준선이 스크래치 행동복제 단일 기준선에 그쳐, 다른 사전학습 접근(에고 비디오·실제 텔레오퍼레이션) 대비 상대적 우위는 원문에서 직접 비교되지 않음
- VR 조작과 실제 물리적 접촉·힘 상호작용 간 격차가 실물 전이 성능에 미치는 영향 정량화 필요

## 🥉 논문 3 — 우선순위 ★★

**ViTaR: Visuo-Tactile Residual Adaptation for Foundation VLA Manipulation**
[arXiv:2608.15816](https://arxiv.org/abs/2608.15816) · Yi Wang, Renjun Wu, Jinyan Liu, Xuesong Li · 2026-08-16 · arXiv preprint · source: keyword-sweep · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여
- VLA 정책이 광범위한 시각-의미 프라이어를 인코딩하지만 국소 접촉 이벤트를 인지하지 못해, 접촉 성립·상실·불안정화 상황에서도 동일한 액션을 내는 접촉 집약적 조작의 사각지대를 지적
- 기존 대응은 VLA 내부를 수정(프라이어 소실 위험)하거나 실패 직전 접촉 조건에서 온라인 강화학습을 요구, 둘 다 촉각에 액션 생성에 대한 무제한적 영향력을 부여해 일반화를 지탱하는 프라이어와 충돌
- 촉각 피드백을 액션을 생성하는 입력이 아니라, 동결된 VLA 위에서 유계 잔차 보정을 선택·조정하는 실행 조정자로 재정의하는 **ViTaR** 제안
- Effect-Guided Modeling(결과 기반 선호 증거로 보정 필요 여부·종류 판단)과 Residual Action Modulation(실시간 비주오택타일 관측으로 연속 스케일 잔차 산출) 2단계로 적응 분해
- UniVTAC 벤치마크(접촉 집약적 7개 과제)에서 동결 VLA 기준선 대비 평균 성공률 30.6%p 개선(61.3%), 전용 촉각 기준선도 상회, 실물 로봇 실험으로 실제 센서 노이즈·동역학 전이 확인

### (c) 시사점
- 동결 백본 위 유계 잔차 보정 구조가 촉각이라는 새로운 감각 모달리티로도 그대로 확장됨을 확인, 프라이어 보존 전략의 적용 범위를 넓히는 근거
- 접촉 집약적 조작에서 프라이어 붕괴 없이 국소 반응성을 확보하는 구체적 메커니즘 제시
- 백본을 건드리지 않는 플러그인 구조라 기존 파이프라인 도입 비용이 낮음

### (d) 먼저 확인할 점
- 코드·프로젝트 페이지 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 실물 로봇 실험이 정성적 "전이 확인" 수준으로 기술, 정량 성공률이 벤치마크만큼 상세히 보고되는지 원문 확인 필요
- 저자 4인의 소규모 연구로, 다른 임바디먼트·촉각 센서 종류에 대한 일반화 여부 확인 필요

**BridgeVLA++: A Data-Efficient, Generalizable, and Memory-Augmented Vision-Language-Action Framework for 3D Manipulation**
[arXiv:2608.05042](https://arxiv.org/abs/2608.05042) · Peiyan Li, Yuze Zhu, Yixiang Chen, Qisen Ma, Yuan Xu 외 8인 · 2026-08-05 · arXiv preprint · source: citation-graph (π0·π0.5 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision

### (b) 핵심 기여
- 기존 3D VLA 방법들이 데이터 소모적이고 분포 변화에 대한 일반화가 제한적이며 과거 관측에 대한 명시적 메모리가 없다는 한계를 지적
- 전작 BridgeVLA는 3D 액션 학습 중 사전학습 VLM의 입력-출력 정합을 보존(포인트 클라우드를 다중 시점 이미지로 투영, 중간 히트맵 예측 후 액션 생성)해 데이터 효율성과 일반화를 확보한 프레임워크

- 공간 조작 과제에서 강한 성능과 강건한 일반화, 메모리 의존적 조작 벤치마크 2종에서 최고 성능 달성
- 양팔 조작 설정에서도 효과적으로 동작, 추가 실물 로봇 플랫폼에서도 검증해 과제·환경·로봇 플랫폼 전반의 확장성 입증

### (c) 시사점
- 사전학습된 VLM의 입력-출력 정합을 보존하는 접근이 메모리 확장과 같은 추가 기능을 얹어도 그대로 유지됨을 확인, 프라이어 보존 전략에 확장성 근거 추가
- 메모리 의존적 장기 조작 과제로 능력을 확장하면서도 데이터 효율성을 희생하지 않는 구체적 사례
- 여러 로봇 플랫폼에서 검증돼, 특정 하드웨어에 국한되지 않는 이식 가능성 확인

### (d) 먼저 확인할 점
- IEEE TPAMI 투고 중으로 동료 심사 결과 및 최종본 반영 여부 확인 필요
- 코드 저장소 링크 없이 프로젝트 웹사이트만 명시, 실제 공개 범위(체크포인트·데이터 포함 여부) 확인 필요
- 메모리 아키텍처 추가에 따른 추론 시점 연산·메모리 오버헤드가 원문에 정량화되어 있는지 확인 필요

- Sim2Real 3 — 56자유도 양팔 다지 조작 실물 셋업에서 1–2시간 규모 실제 시연 파인튜닝 결과 직접 보고

**ViTaR (9/15)**
- Relevance 3 — 동결 VLA 위 유계 잔차 보정이라는 자사 v1 프라이어 보존 전략을 촉각 모달리티로 그대로 확장한 사례
- Novelty 2 — 촉각 피드백을 액션 생성 입력이 아닌 실행 조정자로 재정의하는 2단계(Effect-Guided Modeling·Residual Action Modulation) 프레이밍 신규, 동결 백본+잔차 어댑터 패턴 자체는 반복 관측 축
- Reproducibility 0 — 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음
- Methodology 2 — UniVTAC 벤치마크(접촉 집약적 7개 과제) 정량 평가, 동결 VLA 기준선·전용 촉각 기준선 비교(실물 실험 세부 ablation은 제한적)
- Sim2Real 2 — 실물 로봇 실험으로 실제 센서 노이즈·동역학 전이 확인(정량 성공률은 벤치마크만큼 상세히 보고되지 않음)

**BridgeVLA++ (11/15)**
- Relevance 2 — 사전학습 VLM 입력-출력 정합 보존이라는 전작 BridgeVLA의 프라이어 보존 메커니즘을 메모리 확장 맥락에서 유지, 핵심 프레이밍은 메모리·일반화 축
- Novelty 2 — 지속적 공간 맥락·시간적 상호작용 이력을 다루는 통합 시공간 메모리 아키텍처는 신규, 기반 프라이어 보존 메커니즘 자체는 전작에서 이미 확립
- Reproducibility 1 — 초록 "Project website: https://bridgevla-plus.github.io/."
- Methodology 3 — 공간 조작·메모리 의존적 벤치마크 2종 정량 평가, 양팔 조작 설정 포함
- Sim2Real 3 — 양팔 조작 설정 및 추가 실물 로봇 플랫폼에서 검증 직접 보고
