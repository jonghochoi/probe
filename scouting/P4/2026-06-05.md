## 🥇 논문 1 — 우선순위 ★★★

**Can VLA Models Learn from Real-World Data Continually without Forgetting?**
[arXiv:2605.26820](https://arxiv.org/abs/2605.26820) · Jiarun Zhu, Yijun Hong, Xiaoquan Sun, Zetian Xu, Mingqi Yuan · 2026-05-26 · source: Keyword Sweep (쿼리 3, catastrophic forgetting + VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **공백** — VLA 연속 학습(continual learning) 기존 연구는 모두 좁은 시뮬레이션 환경에 한정
- **실환경 데이터셋** — 실환경 4개 순차 조작 태스크(강체 집기, 접촉 집약적 누르기, 변형체 접기)로 구성된 최초의 실환경 VLA 연속 학습 데이터셋 구축
- **망각 실증** — VLA 모델이 이질적 실환경 데모로부터 연속 학습할 때 심각한 catastrophic forgetting 발생함을 실증
- **신규성** — 실환경 heterogeneous 데모에서의 망각 측정, experience replay(ER) 구현 요인(버퍼 크기, 샘플링 비율, 재생 빈도)의 성공 영향을 체계적으로 분석한 첫 사례

### (c) 시사점

- **사전학습 prior 보존 필요성 실증** — 동결 백본 학습 후 두 번째 태스크 학습 시 첫 태스크 성공률 하락을 실환경에서 처음으로 정량화
- **연속 학습 진입 진단 근거** — 망각율 임계(20%p)와 ER 구현 요인이 우리 스택에서 보존 전략 발동 시점을 정량 설계하는 기준점 제공
- **경량 검증 가능** — 인핸드 회전 태스크와 임의 2번째 태스크 조합으로 2주 이내 forgetting 측정 루틴 실행 가능

### (d) 먼저 확인할 점

- **태스크 분포 차이** — 4개 태스크(강체 집기, 누르기, 접기)는 인핸드 다지 조작과 다른 difficulty distribution
- **학습 순서 의존** — 학습 순서(curriculum order)가 결과를 크게 좌우, 인핸드 회전처럼 접촉 집약적 다단계 태스크의 선/후 배치별 forgetting rate 차이 미측정
- **확인** — 인핸드 회전 태스크를 첫 번째 또는 마지막 순서로 배치했을 때 ER 효과가 동등한지 LIBERO에서 먼저 검증

## 🥈 논문 2 — 우선순위 ★★

**PHASER: Phase-Aware and Semantic Experience Replay for Vision-Language-Action Models**
[arXiv:2606.03598](https://arxiv.org/abs/2606.03598) · Ziyang Chen, Shaoguang Wang, Weiyu Guo, Qianyi Cai · 2026-06-02 · source: Keyword Sweep (쿼리 3, catastrophic forgetting + VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **질문 전환** — 논문 1이 "ER이 필요하다"는 사실과 구현 요인을 측정했다면, PHASER는 "어떤 ER이 더 잘 작동하는가"에 답함
- **문제 진단** — 기존 naive uniform ER이 조작 단계(phase)별 중요도를 무시해 접촉 집약적 중간 phase를 과소표집
- **두 보완책 결합**
  - **Phase-Aware replay** — 조작 시퀀스를 접근(approach)·접촉(contact)·완료(completion) 3단계로 분할, 단계별 버퍼를 독립 유지
  - **Semantic replay** — VLM 임베딩 공간에서 현재 태스크와 의미적으로 먼 기존 경험을 우선 재생해 망각 선제 방어
- **신규성** — VLM 백본을 전혀 건드리지 않고 replay 전략만으로 forgetting을 방어하는 첫 체계적 제안

### (c) 시사점

- **보존 전략 발동 시 첫 후보** — phase-aware + semantic replay 조합이 naive ER 대비 인핸드 회전 forgetting rate를 충분히 줄이면 경량 적응 슬롯의 공식 전략으로 채택 가능
- **동결 원칙과 호환** — frozen backbone 위 액션 전문가 파라미터만 업데이트, 플로우 매칭 헤드 파라미터만 재생 대상 → 완전 동결 원칙과 무충돌

### (d) 먼저 확인할 점

- **phase 분류 방식 불명** — phase 분류(접근·접촉·완료)가 자동화인지 수동 레이블링 요구인지 확인 필요
- **연속 접촉 우려** — 인핸드 다지 조작처럼 phase 경계가 불명확한 연속 접촉 태스크에서 phase 분할 모호 → 버퍼가 한 phase에 치우칠 우려
- **확인** — LIBERO에서 phase 자동 분할 정확도 먼저 측정, 분류 오류율 > 20%이면 semantic replay 단독 fallback 실행

## 🥉 논문 3 — 우선순위 ★

**X-DiffVLA: X-Embodied Diffusion Action Heads for Vision-Language-Action Models**
[arXiv:2605.25044](https://arxiv.org/abs/2605.25044) · Boyu Li, Chaoyi Xu, Haoqi Yuan, Xinrun Xu, Börje F. Karlsson · 2026-05-24 · source: Keyword Sweep (쿼리 6, multi-embodiment + cross-embodiment)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **공백** — 기존 크로스-구현체 VLA(Being-H0.5, GR00T N1)는 구현체별 특화 fine-tuning을 여전히 요구
- **X-DiffVLA** — Morphological Tree Diffusion(MTD)과 Embodiment Forcing(EF)을 결합해 단일 diffusion action head로 그리퍼부터 다지 손(dexterous hands)까지 동일 가중치로 커버
  - **MTD** — 구현체의 kinematic 트리 구조를 diffusion 잠재 공간에 명시적 반영, 이종 end-effector 간 행동 상관관계 보존
  - **EF** — classifier-free guidance 방식으로 구현체별 미세 구조를 명시적 레이블 없이 학습
- **결과** — RoboCasa +15.3%, Isaac Gym +12.5% 개선 및 실환경 검증 보고

### (c) 시사점

- **다중 구현체 데이터 메타 확장** — RoboCasa·Isaac Gym 데이터셋의 그리퍼 대 다지 손 비율, DOF 분포를 데이터 카탈로그에 세분화 기록 가능
- **액션 헤드 대안 후보** — 연속 플로우 매칭 헤드와 MTD head를 다지 손 zero-shot 크로스-구현체 전이 성공률로 병렬 비교 가능
- **백본 계보 후보** — VLM 백본 정체가 공개되면 백본 계보 2-쌍 비교 후보로 편입 가능

### (d) 먼저 확인할 점

- **트리 사전 정의 의존** — Morphological Tree는 구현체의 kinematic 트리가 사전 정의되어야 함
- **동적 DOF 우려** — 인핸드 다지 손처럼 접촉 중 DOF 배열이 동적으로 변하면(손가락 단계별 접힘) 고정 트리가 실행 중 손 구성을 올바르게 표현 못할 우려
- **확인** — MTD가 손가락 개폐 순서가 다양한 인핸드 회전 태스크에서 쓰는 kinematic 트리를 확인, 트리 고정 vs 동적 재구성 두 설정을 LIBERO에서 비교

## 🌱 논문 4 — 크로스폴리네이션

**Unified Video-Action Joint Denoising for Dexterous Action and Data Generation**
[arXiv:2606.03868](https://arxiv.org/abs/2606.03868) · Dingrui Wang, YuAn Wang, Jinkun Liu, Yue Zhang, Mattia Piccinini · 2026-06-02 · adjacent field: 비디오 생성 모델 → 다지 손 조작 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **착안점** — 기존 World Action Model(WAM)들이 비디오 기반 VLM 사전학습 prior를 단일 관측-조건 정책 분포로 좁혀온 것과 달리, video-action 결합 분포 자체를 단일 denoising 아키텍처로 모델링
- **동시 생성** — 언어 + 초기 이미지 + 초기 손 상태를 조건으로 미래 비디오와 bimanual MANO 궤적을 동시 생성
- **데이터 엔진 전환** — 이미지 조건 없이는 동일 아키텍처가 text-conditioned 비디오-액션 쌍 롤아웃을 생성해 데이터 엔진으로 전환
- **신규성** — 다지 손(MANO) 궤적 생성에 특화된 첫 통합 비디오-액션 denoising 모델

### (c) 시사점

- **합성 다지 손 궤적 생성 경로** — 실환경 로봇 데모 수집 비용이 높을 때 데이터 엔진 모드로 text-conditioned bimanual MANO 궤적을 생성해 다중 구현체 데이터 보강 가능
- **동결 원칙 조건** — 생성 데이터로 VLM 백본을 재훈련하지 않는 조건이 명시되어야 완전 동결 원칙과 무충돌

### (d) 먼저 확인할 점

- **실환경 검증 불명** — 초록에 "action, video, text-only generation evaluations"만 언급, 실환경 로봇 검증 미명시 → 시뮬레이션 또는 합성 데이터 평가에 그칠 가능성
- **물리 제약 충족 우려** — 생성된 MANO 궤적이 실제 로봇 손 관절 제약(토크 한계, 마찰 모델) 만족 여부 확인 필요
- **확인** — 코드 공개 여부 확인 후 생성 궤적을 IsaacGym에서 kinematic replay로 실행 가능성 측정
