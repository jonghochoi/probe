## 🥇 논문 1 — 우선순위 ★★★

**LA4VLA: Learning to Act without Seeing via Language-Action Pretraining**
[arXiv:2606.27295](https://arxiv.org/abs/2606.27295) · Tao Lin, Yuxin Du, Yiran Mao 외 13인 · source: citation-graph (Qwen-VLA 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여
- 표준 VLA 사전학습(시각 관측+언어 지시를 동시에 액션으로 매핑)이 시각 단서에 정책을 편중시켜, 언어가 액션을 어떻게 제약하는지에 대한 학습 신호를 희석시키는 문제 지적
- 시연 궤적을 원자적 액션 세그먼트로 분해 후 저수준 언어 설명과 짝지어 시각 없이 "언어-액션" 쌍만으로 사전학습하는 LA4VLA 프레임워크 제안 — 기존 시연에서 추가 로봇 데이터 수집 없이 LA-33K(3.3만 에피소드) 구축
- 경량 1B 파라미터 LA4VLA-1B 모델로 LA-only 사전학습 / 순차적 LA→VLA 사전학습 / LA-VLA 혼합 사전학습 세 패러다임 비교
- 시뮬레이션·실물 로봇 전반에서 LA 사전학습이 VLA-only 대비 일관 우위, 혼합 방식이 추가 이득 — no-pretraining 대비 최대 시뮬레이션 +17.8%p, 실물 +45.0%p 성공률 개선
- 시각 교란 상황에서도 이득 유지, 서로 다른 VLA 아키텍처 간 전이 확인

### (c) 시사점
- 사전학습 단계에서 "언어가 액션을 어떻게 제약하는가"를 시각 신호와 분리해 학습시키는 방식이 유효 — 표준 공동 학습이 놓치는 축을 노출
- 기존 시연 데이터만으로 추가 로봇 데이터 수집 없이 새로운 중간 사전학습 데이터 계층 구축 가능 — 데이터 확보 비용 낮음
- 실물 로봇에서 시각 교란 강건성 개선까지 보고 — 배치 환경 변동성 대응에 참고 가치

### (d) 먼저 확인할 점
- 원자적 액션 세그먼트 분해와 저수준 언어 설명 라벨링 파이프라인의 자동화 정도, 자사 시연 포맷에 그대로 적용 가능한지 불명확
- 세 패러다임(단독/순차/혼합) 비교가 자체 벤치마크·아키텍처 조합에 한정 — 다른 백본 조합에서 이득 재현 여부 미검증
- 저장소는 논문 헤더 프로젝트 페이지(GitHub)로만 확인 — 학습 스크립트·체크포인트·LA-33K 데이터 실제 공개 여부는 코드 내용 미검토
