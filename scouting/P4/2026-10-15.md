## 🥇 논문 1

**Beyond Data Scaling: Representation-Centric Continued Pre-training for Vision-Language-Action Models**
[arXiv:2608.27550](https://arxiv.org/abs/2608.27550) · Senqiao Yang, Chengyao Wang, Yuxin Chen, Zixuan Wang 외 12인 · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — arXiv comment "All models and training pipelines are publicly available at https://starvla.github.io/VLAct"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- VLM 사전지식을 지키는 로봇 계속 사전학습 레시피
- **문제** — 로봇 궤적은 웹 말뭉치와 달리 확장이 어려워, 고정된 데이터 예산에서 계속 사전학습이 전이 가능한 표현을 만들어야 함
  - 로봇 궤적은 장면·물체·embodiment 공간의 일부만 듬성하게 덮음
  - 질문은 "고정 데이터 예산에서 궤적 너머로 일반화하는 표현을 어떻게 학습하는가"
- **기존 한계** — 단순 계속 사전학습이 행동 적합에 그친다는 지적
  - 전체 백본 업데이트 — 좁은 로봇 데이터가 VLM의 시각·언어 특징을 훼손
  - 단일 행동 헤드 지도 — 백본이 그 헤드의 디코딩 기하에 과특화, 같은 헤드에서만 이득이 나고 다른 연속 헤드(PI, GR00T)와 짝지으면 성능 저하(사전 실험)
  - embodiment별 고립 출력 공간 — 그리퍼 개폐처럼 물리적으로 비슷한 행동도 공유되지 않음
- **핵심 방법** — 계속 사전학습 때만 쓰는 세 구성요소로 백본 표현을 빚고, 다운스트림은 임의의 행동 헤드를 붙여 미세조정
  - VLM 사전지식 보존 — 얕은 층 보호와 캡션 데이터 혼합
  - 다중 헤드 연속 행동 공동 지도 — 단일 헤드 과특화 방지
  - 부분 통합 교차 embodiment 행동 레이아웃과 주기 관절용 wrap-aware 손실
- **차별점** — 행동 예측 정확도가 아니라 백본이 어떤 표현을 갖는지를 설계 대상으로 삼음
  - 모든 비교에서 바뀌는 것은 VLM 백본 가중치뿐, 행동 헤드·다운스트림 데이터·옵티마이저·미세조정 예산은 동일
- **핵심 기여** — 공개 데이터와 16-GPU 학습으로 만든 백본과 그 성능
  - 시뮬레이션 — LIBERO-Plus 82.6%, VLA-Arena 54.8%, RoboTwin 2.0 92.5%
  - RoboDojo — 점수 10.66, 성공률 7.60%로 성공률 6위, 명시된 WAM 항목 전부를 능가
  - 미관측 휴머노이드 RoboCasa-GR1 — 다운스트림 궤적 20%만으로 전체 데이터 GR00T-N1.6 상회
  - 백본 교체만으로 7.6–21.4점 이득
  - 사전학습 데이터는 DROID, InternA1, RoboCoin, MolmoAct, 학습 스크립트·체크포인트 공개 예고
  - 부록 ablation — 전체 백본 갱신 78.9% 대비 시각 인코더와 LLM 하위 절반 동결 82.6%
- **가치** — 로봇 데이터 확장과 별개로 VLM 백본을 VLA의 1차 설계 변수로 다룰 근거 제시

### (c) 시사점

- 동결 대 부분 동결을 계속 사전학습 단계에서 직접 비교한 공개 기준점
- 부분 동결(얕은 층 보호)이 전체 갱신보다 높다는 측정(LIBERO-Plus 78.9% 대비 82.6%)은 동결 기본값의 근거를 보강하되, 완전 동결이 아닌 하위 층 동결이라는 차이 존재
- 캡션 혼합 보존과 다중 헤드 공동 지도는 행동 측 어댑터 방식과 병행 검토 가능한 보존 수단
- 연속 헤드를 여럿 섞는 설계는 플로우 매칭 단일 헤드 가정을 시험할 수 있는 대조군
- 코드와 체크포인트가 공개되어 도입 비용 낮음

### (d) 먼저 확인할 점

- 실물 비교 대상이 사전학습 없는 Qwen3VL-4B-OFT 하나뿐이고, 과제당 10회 시행
- 반복 시드·분산과 한계 서술이 본문에 없음
- 부록 동결 ablation의 수치는 LIBERO-Plus 설정이며 다른 벤치마크 일반화는 미확인
- RoboDojo에서 Memory 계열이 뚜렷한 약점으로 남음
- 기반이 Qwen3-VL-4B라 PaliGemma 계열 계보에 그대로 옮겨지는지 별도 확인 필요

## 🥈 논문 2

**AtomEgo: Exploring Ego-Robot Integration for Embodied Foundation Model Pretraining**
[arXiv:2609.21461](https://arxiv.org/abs/2609.21461) · Di Wu, Dongchen Zheng, Junhe Sheng, Zhongxing Wei 외 7인 · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — 본문 머리말 "https://github.com/Agentic-Intelligence-Lab/Atom-0"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 에고센트릭 데이터 투입 방식 세 가지를 통제 비교한 연구
- **문제** — 로봇 시연의 규모·다양성 한계를 에고센트릭 인간 데이터로 메우려 하나, 사전학습에 넣는 효과적 방법이 불분명
  - 대부분의 에고센트릭 영상은 실행 가능한 행동 라벨이 없고, 추정한 손 동작은 로봇 명령과 형태·기구학·좌표계·외형이 다름
- **기존 한계** — 격차를 메우는 기법(행동 리타깃팅, embodiment 정렬, 잠재 행동·월드 모델 목적)이 따로따로 연구됨
  - 상당수가 대규모 사전학습이 아닌 사후학습 단계에서 동작
- **핵심 방법** — VLA와 WAM 두 구조에서 세 사전학습 패러다임을 같은 데이터·연산 조건으로 비교
  - Atom-DH — 도메인별 행동 헤드를 둔 공동 학습
  - Atom-CL — embodiment 정렬을 거치는 에고→로봇 점진 전이
  - Atom-WAM — 영상·행동 결합 모델링
- **차별점** — 하나의 메커니즘에 거는 대신 세 경로를 한 틀에서 맞대어 "단순 분리로 충분한가, 명시적 정렬이나 통합 목적이 필요한가"를 검증
- **핵심 기여** — 코퍼스, 비교 결과, 원칙 하나
  - 에고–로봇 코퍼스 구축(초록 약 2,659시간, 서론 3,033시간) 및 처리·품질 관리 파이프라인
  - 실물 7개 과제, 체크포인트당 ID 10회와 OOD 10회, 총 140회 — VLA 기준선 ID 42.86%에서 Atom-CL 64.29%, 종합 53.57%(+20.71점), Atom-DH 종합 43.57%
  - OOD — 기준선 22.86%에서 Atom-DH 41.43%, Atom-CL 42.86%
  - Atom-WAM은 WAM 기준선보다 낮음 — 종합 28.57%에서 20.71%
  - 원칙 "Data Scale × Alignment Quality → Capability Gain"
- **가치** — 에고센트릭 데이터의 가치가 규모가 아니라 정렬·활용 방식에 달렸다는 통제된 근거 제시

### (c) 시사점

- 에고 데이터를 섞는 것만으로는 부족하고 정렬 단계가 필요하다는 직접 비교 결과
- 도메인별 헤드만 분리한 공동 학습의 ID 이득은 42.86%에서 45.71%로 미미, 이득은 OOD에 집중
- 에고→로봇 점진 전이가 공동 학습보다 높아 순서 있는 커리큘럼 검토의 근거
- 에고 중심 코퍼스를 가정하는 구성에 정렬 단계를 함께 설계해야 한다는 경고
- 저장소가 공개되어 재현 비용 낮음

### (d) 먼저 확인할 점

- 저자 스스로 코퍼스 규모 제한과 단일 경로 알고리즘 최적화 부재를 한계로 서술
- 실물 평가가 시행 10회 단위라 점수 차이의 분산 해석에 한계
- 반복 시드 보고가 본문에 없음
- 코퍼스 시간이 초록(약 2,659시간)과 서론(3,033시간)에서 다름
- 부록에서 최적수송 정렬 정규화기를 끄는 쪽이 높아(종합 +8.57점) 정렬 구성요소별 효과는 단정 어려움
- WAM 경로가 기준선보다 낮은 원인은 본문에서 정렬 부족으로만 해석

## 🥉 논문 3

**ZETA: A Controlled Study of Zero-Shot Cross-Embodiment VLA Transfer for Tabletop Manipulation**
[arXiv:2609.02546](https://arxiv.org/abs/2609.02546) · Mi Yan, Wenhao Zhang, Zhiqi Zhang, Yu Peng 외 13인 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- 교차 embodiment 제로샷 전이를 네 요인으로 분해한 통제 연구
- **문제** — 새 로봇 하드웨어마다 과제 데이터를 다시 모으지 않으려면 제로샷 교차 embodiment 전이가 필요하나, 체계적 이해가 부족
- **기존 한계** — 평가 설정이 불일치하고 변수가 뒤섞임
  - "제로샷"이 두 가지 다른 프로토콜을 가리킴 — 목표 embodiment가 학습 전체에 없는 경우와, 사전학습에만 포함된 경우
  - 기존 평가는 embodiment 변화를 과제·환경·카메라·데이터량·프로토콜 차이와 묶어 실패 원인을 귀속하기 어려움
- **핵심 방법** — 정지형 탁상 조작과 2지 그리퍼로 범위를 고정하고 목표 embodiment 노출을 실험 변수로 삼음
  - 엄격한 제로샷과 사전학습 노출 제로샷을 구분 정의
  - 외형·그리퍼·팔·전체 embodiment 변화로 나눈 통제 시뮬레이션 벤치마크와 실물 검증
  - 연구 질문 4개 — 상태–행동 표현, 소스 embodiment 다양성, 보조 공동 학습 목적, 목표 embodiment 노출
- **차별점** — 백본·다운스트림 소스 데이터·평가 설정을 맞추고 요인 하나씩만 바꿔 효과를 분리
- **핵심 기여** — 프로토콜 정리, 벤치마크, 요인별 정량 결과, 실무 권고
  - 로컬 EEF 중심 상태–행동 표현이 엄격 전이를 평균 약 15점 개선
  - 640K 궤적 예산에서 소스 512종이 단일 소스보다 약 18점 높음
  - 보조 공동 학습으로 평균 진행도 75.7%에서 77.7–82.3%
  - 사전학습에 목표 embodiment 데이터 5%만 넣어도 평균 진행도 +13.4점
  - 실물 검증 — 7개 테스트 embodiment에서 2개 과제, 쌍당 10회, EEF 표현 89.9% 대 다른 표현 56.0–61.6%
  - 시뮬레이션 모델당 6,300회 롤아웃
- **가치** — 제로샷 전이 보고 시 목표 embodiment 노출을 따로 밝혀야 한다는 평가 기준과 설계 지침 제공

### (c) 시사점

- 소스 다양성과 목표 노출이 전이를 크게 좌우한다는 근거
- 상태–행동 표현 선택이 전이를 15점 가까이 바꾼다는 측정은 행동 표현 결정의 참고 수치
- 목표 embodiment를 사전학습에 소량 포함하는 전략의 비용 대비 효과 확인
- 보고 시 엄격 전이와 노출 전이를 분리하는 평가 틀을 차용 가능

### (d) 먼저 확인할 점

- 저자가 밝힌 범위 한계 — 정지형 탁상 조작, 2지 그리퍼, 단기 과제
- 다지 손, 이동 베이스는 범위 밖이라 다지 조작 전이는 직접 근거 없음
- 소스 다양성 결론은 절차적으로 생성한 Franka 계열 소스 풀 안에서의 비교
- 코드 저장소나 공개 약속이 확인되지 않음
