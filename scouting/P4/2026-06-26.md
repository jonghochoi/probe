## 🥇 논문 1 — 우선순위 ★★★

**Learning Action Priors for Cross-embodiment Robot Manipulation**
[arXiv:2606.26095](https://arxiv.org/abs/2606.26095) · Dong Jing, Tianqi Zhang, Jiaqi Liu, Jinman Zhao, Zelong Sun et al. · 2026-06-24 · source: keyword-sweep (VLM pretraining adaptation VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **기존 VLA 설계의 구조적 공백 규명** — VLM 백본에 액션 모듈을 부착 후 공동 최적화하는 표준 구조에서, 액션 모듈이 물리 동작을 처음부터 학습해야 하는 이중 부담(시간적 동작 다이나믹스 발견 + 크로스모달 정렬) 최초 명명·정량화
- **2단계 액션 prior 사전학습 프레임워크**:
  - **Stage 1** — 시각·언어 토큰을 전혀 처리하지 않고, 플로우 매칭(flow-matching) 기반 경량 인코더-디코더를 **비조건부 액션 궤적**만으로 학습 → 크로스-구현체 시간적 동작 구조 습득
  - **Stage 2** — 디코더 재사용 + 초기 잠재 증류(early-stage latent distillation)로 습득된 prior를 VLA 학습에 전이; 종단간 정책 정제는 계속 허용
- **역사 압축기(history compressor)** — 학습된 인코더가 상태-액션 이력을 단일 시간 맥락 토큰으로 압축 → 무시 가능한 계산 비용으로 이력 인식 모델링 달성
- **스케일링 수혜 실험** — Stage 1 액션 데이터 규모 확대 → 다운스트림 VLA 성능 직접 향상; 데이터 확장으로 일반화 action prior 확보 가능
- **검증 범위** — 시뮬레이션 + 실환경 13개 크로스-구현체 태스크에서 수렴 속도 향상, 성공률 향상, 소량 데이터 실환경 태스크 성능 현저한 개선

### (c) 시사점

- **D21 Stage 0→1 사이에 "액션 prior 사전학습" 단계 삽입 근거 확보** — VLM 독립적으로 액션 모듈을 먼저 사전학습하는 새로운 단계; 기존 Stage 0(계보 선택) 이후 Stage 1 추가 사전학습 진입 전에 낮은 비용으로 적용 가능
- **D19 동결 기본값과 구조적 호환** — VLM 백본을 동결한 채 액션 전문가(action expert)만 훈련하는 기본값이 Stage 2에서 그대로 유지됨; 동결 전략의 데이터 효율성을 action prior로 보강 가능
- **D23 플로우 매칭 헤드의 독립 사전학습 가능성 실증** — 플로우 매칭 인코더-디코더를 VLM 없이 액션 궤적만으로 사전학습 가능함을 확인; 플로우 매칭 헤드의 초기화 전략 개선 경로 제공
- **소량 실환경 데이터 환경에서 직접 이득** — 인하우스 데모 수집 비용이 높은 다지 조작 환경에 즉시 적용 가능; 데모 수집 병목 완화에 액션 prior 스케일링이 보완 경로

### (d) 먼저 확인할 점

- **Stage 1 액션 데이터 소스 명세** — "비조건부 액션 궤적" 데이터셋 종류(OXE·인하우스·시뮬레이션 생성) 및 규모 확인; 어떤 코퍼스가 Stage 1 prior 품질에 가장 기여하는지 ablation 확인 필요
- **Stage 1 vs Stage 2 데이터 예산 비율** — 어느 비율에서 Stage 1 확장이 실질적 다운스트림 개선을 가져오는지; 액션 prior 학습 비용 대비 성능 수익 곡선 확인 필요
- **인핸드 다지 조작 태스크 포함 여부** — 13개 태스크 중 다지 손 세밀 조작 포함 여부 확인; 플로우 매칭 prior가 고자유도 손 관절 궤적에서도 유효한지 미확인
- **코드·체크포인트 공개 여부** — Stage 1 사전학습 체크포인트 재사용 가능성; 공개 여부에 따라 도입 비용이 크게 달라짐

## 🥈 논문 2 — 우선순위 ★★

**Supervise What Survives: Geometry-Guided VLA Adaptation from Synthetic Robot Videos**
[arXiv:2606.24448](https://arxiv.org/abs/2606.24448) · Danze Chen, Yanzhe Chen, Qiming Huang, Zhijun Cao, Chen Gao · 2026-06-23 · source: keyword-sweep (catastrophic forgetting VLA backbone finetuning)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **"비대칭 보존 원칙(Asymmetric Preservation Principle)" 규명** — 비디오 생성 과정에서 기하학(공간 궤적: "어디(where)")은 보존되나 제어 신호(모터 명령: "어떻게(how)")는 소실됨; 합성 비디오에서 의사-액션(pseudo-action)을 복원하는 기존 접근의 추상화 불일치 최초 정식화
- **GRA (Geometry-guided Representation Alignment)** — 비대칭 보존 원칙에 따른 새로운 적응 방법론:
  - 소스 인간 비디오에서 포즈 추정 → 재타겟팅 → 시뮬레이션 → 보정 투영 4단계로 미래 2D 엔드이펙터 웨이포인트 추출
  - 보조 2D 헤드를 통해 VLA 비전 백본에 공간 앵커 주입
  - 제어(action head)는 실제 시연 데이터에서만 학습
- **공간 표현 앵커(spatial representation anchor)** — 파인튜닝 중 웨이포인트 손실이 지속되어 백본의 기하 표현 손실 방지
- **결과** — 실환경 태스크에서 동일 데이터 예산 조건의 의사-액션 기준선 대비 성능 향상; 더 많은 실환경 시연으로 학습한 정책과의 격차 축소

### (c) 시사점

- **D22 합성/인간 비디오 활용 설계 원칙 확립** — 생성 비디오를 코퍼스 소스로 활용 시 "기하 앵커 전용" 방식이 "의사-액션 복원" 방식보다 안전; D22 코퍼스 데이터 소스별 레이블링 전략 명확화에 직접 적용 가능
- **D20 보조 경로 제시** — 공간 표현 앵커가 파인튜닝 중 백본 기하 표현을 보존하는 소프트 사이드채널; 완전 동결 외에 추가적인 표현 보존 메커니즘 확인
- **인간 비디오 활용 파이프라인 단순화** — 2D 엔드이펙터 웨이포인트 추출(3D 재타겟팅 불필요)은 DO AS I DO(2606.19333, 6/19 보고)의 단안 3D 재타겟팅 대비 계산 비용 절감 잠재; D22 코퍼스 확장 파이프라인 후보 추가
- **의사-액션 대비 동일 예산 우위** — 소량 실환경 시연 + 합성 비디오 기하 앵커 조합이 합성 비디오 단독 의사-액션 학습 대비 비용 효율적

### (d) 먼저 확인할 점

- **4단계 웨이포인트 추출 파이프라인 복잡도** — 포즈 추정→재타겟팅→시뮬레이션→보정 투영의 오류 전파 가능성; 에고센트릭 영상 대규모 적용 시 처리 속도 확인 필요
- **2D 웨이포인트의 인핸드 조작 적용 범위** — 2D 웨이포인트가 손가락 단위 세밀 접촉 기하를 충분히 포착하는지 미확인; 3D 정보 부재가 다지 조작에서 앵커 품질 저하 우려
- **실환경 태스크 종류** — 검증된 실환경 태스크가 그리퍼 탁상 조작 위주인지 확인; 다지 손 조작 포함 여부 미확인
- **소스 인간 비디오 요구 사항** — 에고센트릭 vs 3인칭, 특정 카메라 보정 요건 존재 여부 확인; 범용 에고센트릭 영상 적용 가능성 측정 필요

## 🥉 논문 3 — 우선순위 ★

**FORCE: Efficient VLA Reinforcement Fine-Tuning via Value-Calibrated Warm-up and Self-Distillation**
[arXiv:2606.26006](https://arxiv.org/abs/2606.26006) · Shuyi Zhang, Yunfan Lou, Hongyang Cheng, Yichen Guo et al. · 2026-06-24 · source: keyword-sweep (VLM pretraining adaptation VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **VLA RL 파인튜닝의 두 핵심 병목 규명**:
  - (1) 불안정한 Q-함수로 인한 **재앙적 초기 망각(catastrophic initial unlearning)** — RL 탐색 초기에 이미 학습된 사전학습 정책 지식이 빠르게 소실
  - (2) 저품질 탐색 데이터로 인한 비효율 정책 업데이트 — 인간 개입에 과도하게 의존
- **FORCE 3단계 프레임워크**:
  - **Value-Calibrated Warm-up** — Q-함수 안정화를 위한 사전 준비 단계
  - **Self-Distillation** — VLA 사전학습 정책을 교사로 활용, RL 탐색 중 학습된 prior 보존
  - **RL Fine-tuning** — 안정화된 Q-함수 + self-distillation 정규화 하에 정책 최적화
- **샘플 효율성 향상** — 기존 VLA RL 파인튜닝 방법 대비 샘플 효율성 개선; 인간 개입 의존도 감소

### (c) 시사점

- **D20 prior 보존의 RL 환경 확장** — Self-distillation이 RL 탐색 중에도 사전학습 지식 유지; ConSFT(중요도 가중치 보수적 SFT) 기반 기본 보존 전략에서 RL 파인튜닝 환경으로 보존 원칙 확장
- **D21 Stage 3 RL 경로 설계 참조** — Stage 3(conservative deploy adaptation)에서 RL 사후 학습이 필요해질 경우, Q-함수 안정화→self-distillation→RL 3단계가 구체 프레임워크 제공
- **6/24 Flatness 보고와 독립 수렴** — Flatness(SAM 기반 손실 지형 평탄화)가 감독 파인튜닝(SFT) 중 prior 보존이라면, FORCE는 RL 파인튜닝 중 prior 보존; 두 경로가 D20 영역의 독립 채널에서 동일 문제 공략

### (d) 먼저 확인할 점

- **사전학습 구성 레버 부재** — RL 파인튜닝 단계만 다루고 사전학습 데이터 구성·계보 선택 레버 없음; 사전학습 upstream 변수에 영향 없음
- **실환경 검증 범위** — RL 파인튜닝 검증이 시뮬레이션 위주인지, 실환경 포함인지 확인 필요; 다지 조작 포함 여부 미확인
- **Self-distillation 계산 비용** — 교사·학생 동시 forward 필요; Stage 3 배포 적응 단계 학습 시간 증가 폭 측정 필요
- **Q-함수 불안정성과 사전학습 품질의 연관성** — 더 나은 사전학습 prior(D21 Stage 1–2)가 Value-Calibrated Warm-up 필요성을 줄이는지 ablation 확인 가능 여부
