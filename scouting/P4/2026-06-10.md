## 🥇 논문 1 — 우선순위 ★★★

**Q-VGM: Q-Guided Value-Gradient Matching for Flow-Matching VLA Policies**
[arXiv:2606.08015](https://arxiv.org/abs/2606.08015) · Ziqian Wang, Jiayu Sun, Xingjian Mao, Minqian Wang, Yao Mu · 2026-06-06 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **문제 진단** — 플로우 매칭 VLA 파인튜닝에 Q-함수 기반 RL을 적용할 때 기존 두 경로의 병목 규명
  - 디노이징 체인 전체 역전파: VLA 규모에서 수치 불안정(numerically unstable)
  - 정책 그래디언트 방법: 반복 디노이징 하 tractable 액션 가능도(action likelihood) 不在
- **VGG-Flow** — 벨류 그래디언트를 전체 ODE 체인이 아닌 **디노이징 타임 벨류-그래디언트 필드**로 변환
  - 액션 가능도 계산·디노이징 체인 역전파 모두 불필요
  - 고정된 리플레이 버퍼(replay buffer) 기반 오프-폴리시(off-policy) 운용 → 추가 전문가 지도 없이 자기 생성 롤아웃으로 개선
- **크리틱 설계** — Cal-QL 앙상블 + 컴팩트 RLT 특징 + 레이어별 액션 주입(per-layer action injection)
- **출발점** — few-shot SFT **π0.5** VLA → 우리 계보(PaliGemma × π0.5 mix)에 직접 연결
- **결과** — LIBERO 75.0%→92.5%, RoboTwin 2.0 76.4%→87.2%; **실환경 두 테이블탑 태스크 40.0%→67.5%** (동일 백본·동일 크리틱 기준선 전원 상회)

### (c) 시사점

- **D23 오프-폴리시 사후 학습 경로 추가** — 플로우 매칭 헤드(flow-matching head)를 동결 VLM 백본 유지 상태에서 RL로 개선하는 구체 절차 확보; 직전 보고서 FlowPRO(온라인 개입-롤백 수집)와 상이한 **오프-폴리시 경로**
  - FlowPRO → 온라인 조작자 개입 필요, Q-VGM → 고정 리플레이 버퍼로 수집 부담 없음
- **Stage 2.5 슬롯 5번째 후보** — LP-DS → IDM → PHASER → FlowPRO 순서에 Q-VGM 추가; 오프-폴리시 특성상 태스크별 온라인 수집 대체 가능
- **π0.5 계보 직접 호환** — 출발점이 π0.5이므로 D19 v1 동결 원칙과 무충돌, 별도 계보 변환 없이 적용

### (d) 먼저 확인할 점

- **크리틱 학습 비용** — Cal-QL 앙상블 + RLT 특징 학습에 추가 연산 및 리플레이 버퍼 관리 비용 발생; 실환경 데이터 수집량 대비 크리틱 수렴 조건 먼저 정량화 필요
- **실환경 태스크 범위** — "두 테이블탑 태스크"만 보고; 인핸드 회전처럼 접촉 집약적(contact-rich) 다단계 태스크에서 Q-함수 수렴 여부 미확인
- **확인** — 코드 공개 여부 확인 후, LIBERO 단일 태스크에서 크리틱 수렴 에피소드 수를 FlowPRO 개입 에피소드 수와 먼저 비교

## 🥈 논문 2 — 우선순위 ★★

**Robotic Policy Adaptation via Weight-Space Meta-Learning**
[arXiv:2606.07217](https://arxiv.org/abs/2606.07217) · Christian Bianchi, Siamak Yousefi, Alessio Sampieri, Andrea Roberti, Luca Rigazio, Fabio Galasso, Luca Franco · 2026-06-05 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **전환 질문** — "파인튜닝 없이 새 태스크에 적응할 수 있는가?"
- **WIZARD** — 동결된 VLA 정책을 위한 웨이트-공간 메타 학습(weight-space meta-learning) 프레임워크
  - 언어 지시 + 짧은 데모 비디오만 입력 → **단일 순전파**(single forward pass)로 태스크별 LoRA 파라미터 생성
  - 태스크별 액션 레이블·테스트 타임 최적화 불필요
  - 메타 학습 중 태스크 증거를 전문가 LoRA 업데이트로 직접 매핑, 웨이트 공간에서 태스크 간 관계 학습
- **신규성** — 기존 LoRA 파인튜닝 접근이 태스크별 액션 데이터 + 그래디언트 업데이트를 필요로 하는 것과 달리, WIZARD는 하이퍼네트워크(hyper-network)가 LoRA 가중치를 직접 생성해 태스크별 파인튜닝 완전 생략
- **결과** — LIBERO에서 미보인 데이터셋 컬렉션 대비 최대 ~2×, 미보인 태스크 대비 최대 ~14× 향상; **Franka Emika Panda 실환경에서 real-domain adapted 기준선 대비 일관 개선**

### (c) 시사점

- **D19 동결 유지 + 태스크 특화 신규 경로** — 동결 VLA(D19 v1) 위에서 LoRA 가중치를 생성해 태스크별 특화를 달성하는 메타 학습 경로 등장; 전통적 LoRA 파인튜닝(D19 deferred 진입 조건 미충족 시) 발동 전 시도 가능한 비침습 적응 옵션
- **데이터 수집 요구 최소화** — 짧은 데모 비디오 + 언어만으로 적응; Stage 3 진입 전 실환경 시연 데이터 요구량을 대폭 낮출 가능성
- **D21 Stage 3 진입 트리거 완화 가능성** — WIZARD 방식으로 충분한 성공률을 달성하면 전통 파인튜닝 트리거 발동 시점 지연 근거

### (d) 먼저 확인할 점

- **메타 학습 분포 의존** — 메타 학습 데이터셋 태스크 분포가 WIZARD 성능 상한 결정; LIBERO 태스크 분포와 인핸드 다지 조작(dexterous manipulation) 분포 차이 사전 정량화 필요
- **하이퍼네트워크 생성 정밀도** — 생성된 LoRA가 태스크별 SFT LoRA와 얼마나 유사한지 측정; 접촉 집약적 정밀 제어 태스크에서 생성 오차 누적 우려
- **확인** — LIBERO-90 내 접촉 집약적 태스크(뚜껑 열기·서랍 밀기)에서 WIZARD 생성 LoRA 성공률을 task-specific SFT LoRA와 먼저 비교

## 🥉 논문 3 — 우선순위 ★

**ELAN4D: Embodiment-Centric 4D Supervision for Vision-Language-Action Models via Plug-and-Play Adaptation**
[arXiv:2605.30484](https://arxiv.org/abs/2605.30484) · Zeyuan He, Bowen Yang, Zhirui Fang, Keru Zhou, Lei Jiang, Jingjing Qian, Fan Mo, Junchi Yan, Philip Torr, Xiu Li, Li Jiang, Jialin Yu · 2026-05-28 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **문제 진단** — 기존 VLA 정책이 현재 관찰에서 반응적으로 액션을 회귀하되 미래 역동학(future dynamics)을 모델링하지 않아 OOD 교란에 취약
- **ELAN4D** — 구현체 중심 4D 인식 학습(embodiment-centric 4D-aware training) 프레임워크
  - 고유 감각(proprioceptive) 상태 → 순방향 기구학(FK)만으로 로봇 키포인트(조인트·엔드이펙터) 3D 변위 트랙 도출 → 외부 트래커·재구성 불필요, 전처리 비용 무시
  - **플러그-앤-플레이 보조 브랜치**: 경량 트랙 디코더가 4D 신호를 액션 전문가에만 주입
  - **그래디언트 격리(gradient isolation)로 사전학습 VLM 백본 완전 보존** → 추론 시 트랙 디코더 제거, 기저 정책 인터페이스 무변경
- **결과** — LIBERO, LIBERO-Plus, RoboTwin 2.0, **실환경 조작 태스크**에서 강력한 기준선 대비 일관 개선; OOD(카메라·배경·레이아웃 교란) 시나리오에서 대폭 향상

### (c) 시사점

- **그래디언트 격리 = D20 외부 구현 사례** — 4D 신호를 액션 전문가에만 주입하고 VLM 백본에서 그래디언트를 차단하는 설계가 D19(a) 동결 원칙·D20 보존 전략을 동시에 외부에서 실증
  - D20 prior-preservation 방식이 실환경 OOD 강건성 향상과 연결되는 정량 근거 추가
- **Stage 2 보조 손실 후보** — Stage 2(VLM-freeze + 액션 전문가 학습) 단계에서 ELAN4D 4D 보조 손실 추가 시 실환경 카메라·배경 교란 강건성 향상 가능
- **추론 비용 무증가** — 트랙 디코더 추론 시 제거 → 배포 파이프라인 무변경; 학습 단계 비용만 소폭 증가

### (d) 먼저 확인할 점

- **FK 가정의 고차원 한계** — 고유 감각 FK로 3D 트랙 도출; 손가락이 많은 다지 손(dexterous hand) 구현체에서 관절 수 증가로 계산 비용·FK 근사 오차 누적 우려
- **보조 신호 품질 의존** — 3D 트랙 품질이 FK 모델 정확도에 직접 의존; 실환경 마찰·탄성 변형 하에서 FK와 실제 위치 괴리 측정 필요
- **확인** — 인핸드 5지 로봇 손 환경에서 FK 도출 3D 트랙과 비전 기반 손가락 위치 추정 결과 비교; 오차율 > 15%이면 보조 신호 대안 필요

### (d) 먼저 확인할 점

- **로봇 조작 특화 미측정** — 평가가 주로 생성·이해 벤치마크 기준; 로봇 조작 파인튜닝 후 성공률 미공개
- **스케일·비용 장벽** — NVIDIA 규모 학습 인프라 필요; 경량 경로(PaliGemma-2B × π0 lineage)와 파인튜닝 비용 비교 전 직접 대입 불가
