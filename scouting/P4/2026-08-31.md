## 🥈 논문 1 — 우선순위 ★★

**$N_0$-VTLA: Scaling Vision-Tactile-Language-Action Model with Latent Tactile Tokens**
[arXiv:2607.23782](https://arxiv.org/abs/2607.23782) · NeoteAI Team, Fudan TEAI Team · 2026-07-26 · arXiv preprint · source: citation-graph (π0 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여
- 기존 시각 기반 백본에 촉각을 통합하는 시각-촉각-언어-액션(VTLA) 파운데이션 모델 **N0-VTLA** 제안
- 비주오-촉각 사전학습 → 단계적 촉각 경로 통합 → 어드밴티지 조건부 오프라인 정책 개선의 3단계 학습 리시피 구성
- 사전학습 단계에서 자체 구축한 대규모 비주오-촉각 로봇 데이터셋 NeoData로 광범위한 접촉 프라이어 학습, 촉각 데이터를 대규모로 사전학습한 최초의 VTLA 모델로 소개
- 사후학습 단계에서 예측적 촉각 경로를 추가, 사전학습에서 축적한 접촉 패턴을 다운스트림 촉각 중심 조작에 필요한 미세 동작 조정으로 증류
- 고정된 배포 데이터 코퍼스에서 상대적 진행도·궤적-이벤트 비교를 이진 어드밴티지 라벨로 변환하는 오프라인 강화학습 기법 **ALTER**로 변형 물체 조작 등 접촉 집약적 스킬의 과제별 학습 추가 개선
- 실물 로봇 NeoReal 9개 과제 전원 승리, 20개 과제 시뮬레이션 스위트에서 평균 63.8% 성공(최강 기준선 44.0% 대비 큰 격차), ALTER 적용 시 장기 실물 로봇 과제 3종에서 75–95% 성공률 달성

### (c) 시사점
- 기존 시각 기반 백본에 촉각이라는 새 모달리티를 얹는 구체적 3단계 리시피 확보, 사전학습 단계 자체를 확장하는 설계에 참고 가능
- 사전학습에서 축적한 접촉 프라이어를 사후학습에서 예측적 경로로 증류하는 구조가, 별도 촉각 전용 모델 없이 촉각 중심 조작 성능을 끌어올리는 경로로 참고 가능
- 배포 데이터만으로 이진 어드밴티지 라벨을 구성해 추가 학습하는 오프라인 강화학습 기법이, 별도 라벨링 비용 없이 배포 후 성능을 개선하는 실증 사례로 참고 가능

### (d) 먼저 확인할 점
- 저자가 팀 단위(NeoteAI Team, Fudan TEAI Team)로만 표기돼 개별 연구자 수·동료 심사 여부 확인 필요
- 코드·NeoData 데이터셋 자체의 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- "기존 시각 기반 백본"이 구체적으로 어떤 계보(초기 가중치)인지 원문 확인 필요, 자사 백본과의 호환성 판단에 필요
