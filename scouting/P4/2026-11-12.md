## 🥇 논문 1

**Open-HumanWAM: An Open Recipe for Scaling Human and Robot Experience for Embodied Foundation Models**
[arXiv:2611.06817](https://arxiv.org/abs/2611.06817) · Juncheng Ma 외 34명 · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 13/15** · R3 · N2 · M2 · Real3 · Repro3 — arXiv comment "GitHub: https://github.com/DAGroup-PKU/HumanNet/tree/Open-HumanWAM"

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 에고센트릭 5만 시간 사전학습의 완전 공개 레시피
- **문제** — 에고센트릭 영상 사전학습이 데이터 규모에 따라 로봇 성능을 일관되게 올리는 레시피가 아직 연구 단계
  - 텔레오퍼레이션 수집은 비싸고, 손동작과 언어가 달린 에고센트릭 영상은 다양한 상호작용 기록을 제공
- **기존 한계** — 선행 연구는 에고센트릭 규모의 가치를 보였으나 다양성과 하류 적응에 필요한 로봇 지도량의 분석이 남음
  - EgoScale — 대규모 인간 모션 사전학습이 손재주 로봇 조작을 개선
  - Being-H0.8 — 에고센트릭 사전학습을 시각·촉각 월드 모델링으로 확장
  - HumanScale — 사후학습 뒤 실물 로봇 궤적 검증 액션 손실이 사전학습 시간에 로그선형으로 감소
  - Dyna-2 — 100만 시간까지 확장해 제로샷 로봇 액션 예측의 스케일링 법칙 보고
- **핵심 방법** — 하나의 월드–액션 모델(WAM) 틀에서 순수 에고센트릭 사전학습 규모를 100–50,000시간으로 바꾸며 공통 사후학습으로 비교
  - 정제한 데이터와 통합 액션 표현(양손 액션 공간, 카메라 프레임·손목 축·그리퍼 정렬)
  - 폐루프 시뮬레이션으로 하류 로봇 성공률을 통제된 조건에서 재현 가능하게 비교
  - HumanWAM-Goal — 시각 목표 조건을 더한 모델로 인간·로봇 혼합 사전학습을 학습
- **차별점** — 순수 에고센트릭 단독 사전학습을 규모별로 체계적으로 분석하고 데이터·파이프라인·체크포인트까지 전부 공개
  - 시간 수뿐 아니라 과제·장면 범위를 함께 넓히면 고정 범위에서 시간만 늘릴 때보다 곡선이 가파름
- **핵심 기여** — 스케일링 분석, 혼합 사전학습 결과, 전체 공개
  - 사전학습 시간과 분포 밖 성공률 사이의 경험적 로그선형 법칙
  - HumanWAM-Vanilla — 5만 시간 에고센트릭만으로 사전학습, 사후학습 뒤 RoboTwin 2.0 Clean2Clean 92.08%, Clean2Random 68.88%, RoboDojo 평균 성공률 14.17%와 진행 점수 19.00
  - 실물 네 과제에서 천·조명 변화 아래 평균 성공률이 에고센트릭 사전학습 없음 2.5%에서 67.5%로 상승
  - 로봇 14.6k 시간에 인간 45.9k 시간을 더하면 실물 20개 과제 평균 제로샷 성공률이 20.0%에서 30.5%로 상승
  - HumanWAM-Goal — 사후학습 뒤 RoboTwin 2.0 Clean2Clean 92.70%, Clean2Random 84.60%, 평균 88.65%
  - 시각 목표만 바꿔 파라미터 갱신 없이 동작을 바꾸는 임베디드 인컨텍스트 학습 관찰
  - Open-HumanWAM-50K 코퍼스, 큐레이션·사전학습 파이프라인, 사전·사후학습 체크포인트, 추론 코드, 시뮬레이션 평가 도구 공개
- **가치** — 에고센트릭 사전학습 규모 연구를 다른 팀이 재현하고 이어 갈 수 있는 공개 기준점 제공

### (c) 시사점

- 에고센트릭 단독과 인간·로봇 혼합을 한 틀에서 나란히 본 실물 근거
- **데이터 구성** — 순수 에고센트릭 5만 시간 모델과 혼합 모델이 같은 사후학습 벤치마크에서 갈리는 수치를 제공
  - Clean2Random 68.88%(에고센트릭 단독) 대 84.60%(혼합)
- **단계 구성** — 사전학습 규모, 사후학습 적응, 영샷 평가를 한 틀에서 묶은 레시피
- **공개 기준점** — 코퍼스와 체크포인트가 있어 우리 쪽 코퍼스 구성 실험의 비교 기준으로 직접 사용 가능

### (d) 먼저 확인할 점

- 에고센트릭 단독 모델과 혼합 모델이 시각 목표 조건 등 구조도 달라 데이터 구성 효과만 분리한 비교는 아님
- 시드 반복과 한계 진술은 본문 검색에서 확인되지 않음
- 로그선형 법칙은 두 어텐션 구성에서 관찰된 경험적 관계이며 범위 밖 외삽은 근거 없음
- 주요 수치는 RoboTwin 2.0과 RoboDojo 시뮬레이션이고 실물은 20개 과제 과제당 10회 시행

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 영상·UMI·로봇 4.7만 시간 코퍼스로 WAM 지도 설계를 통제 비교
- **문제** — 영상 사전학습의 언어–영상 정렬을 유지하면서 액션 학습으로 언어–영상–액션 정렬을 확장하는 방법이 불분명
  - 액션 학습을 도입하면 사전학습된 정렬이 손상될 수 있음
  - 경험 종류와 지도 형태가 제어 일반화에 하는 역할이 정리돼 있지 않음
- **기존 한계** — 기존 WAM 연구는 아키텍처와 학습 메커니즘에 집중
  - 영상 사전학습 방법은 언어–영상 정렬을 이미 확립된 기반으로 취급
  - 데이터와 지도 설계에 대한 원칙적 지침이 부족
- **핵심 방법** — 약 47,000시간 다원 데이터 풀을 만들고 세 층위로 체계적으로 연구
  - 풀 구성 — 일반 영상 약 11,000시간, 에고센트릭 영상 약 11,000시간, 자체 UMI 시연 약 15,000시간, 로봇 시연 약 10,000시간
  - 언어–영상 층위 — 언어 주석 품질이 사전학습된 시각 능력에 주는 영향
  - 언어–영상–액션 층위 — UMI와 로봇 시연의 액션 지도가 액션 예측과 제어를 돕는 방식
  - 공동 학습 층위 — 데이터 레시피와 모델 아키텍처
- **차별점** — 모델 구조가 아니라 어떤 경험을 어떤 지도로 섞는지를 변수로 두고 효과를 측정
  - 언어–영상 지도, 언어–영상–액션 지도, 둘의 병용을 나눠 비교
- **핵심 기여** — 데이터·지도 레시피와 결과, 공개 약속
  - 고정 학습 예산에서 에고센트릭 영상과 UMI 시연을 섞으면 제어 일반화가 개선
  - 상세한 조작 설명과 환경 단서가 언어–영상 정렬을 유지해 제어 일반화를 높임
  - RoboTwin Clean 시연만으로 사후학습해 Easy(Clean-to-Clean) 88.10%, Hard(Clean-to-Random) 61.56%
  - 실물 세 과제 Hard 설정 성공률 40.00%, 가장 강한 비교 모델 OpenWAM 23.33%
  - 데이터, 코드, 모델 가중치 공개 약속
- **가치** — 데이터 수집·조직과 지도 설계, 공동 학습에 대한 경험적 지침 제공

### (c) 시사점

- 에고센트릭 영상과 UMI 시연의 혼합이 제어 일반화를 높인다는 통제 측정
- **데이터 구성** — 영상, 에고센트릭, UMI, 로봇 시연의 비율과 조합을 바꿔 본 사례로 구성 질문에 직접 근거

- **도입 비용** — 로봇 데이터가 적은 단계에 UMI류 휴대형 시연을 보태는 선택지를 시사

### (d) 먼저 확인할 점

## 🥉 논문 3

**Latent RL Priors for Data-Efficient Dexterous Manipulation**
[arXiv:2611.08458](https://arxiv.org/abs/2611.08458) · Yixiao Wang 외 5명 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 9/15** · R2 · N3 · M3 · Real0 · Repro1 — §Ethics "We plan to publicly release the training and evaluation code and datasets."

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 동결한 RL 액션 디코더에 시각 인터페이스만 학습
- **문제** — 소량 시각 시연으로 손재주 조작을 학습하려면 지각 접지와 정밀 행동 생성을 함께 익혀야 함
  - 시뮬레이션 RL은 풍부한 제어 행동을 익히지만 물체·목표 상태 같은 특권 정보에 의존해 배포 시 그대로 쓸 수 없음
- **기존 한계** — 사전학습 VLA는 시각·언어·로봇 데이터의 전이 가능한 사전 지식을 주지만, RL로 얻은 제어 지식을 재사용하는 경로는 따로 필요
  - 특권 정보에 기댄 RL 정책의 제어 능력을 시각 관측과 잇는 인터페이스가 필요
- **핵심 방법** — 두 단계 틀
  - 특권 사전학습 — 절차적 자세 정렬로 학습한 RL 교사의 대규모 롤아웃을 고유수용감각 기록과 잠재 과제 맥락을 조건으로 하는 플로우 매칭 액션 디코더로 증류
  - 시각 적응 — 디코더를 동결하고 이미지를 잠재 맥락으로 옮기는 시각 인터페이스만 행동 지도로 학습
  - 특권 라벨, 잠재 목표, 사전학습·적응 데이터 간 짝지은 궤적 모두 불필요
  - 단일 팔 디코더를 여러 팔이 공유하고 팔별 시각 맥락을 학습해 양팔 조작으로 확장
- **차별점** — 사전학습된 상태 인코더를 거쳐 시각 예측을 라우팅하는 명시적 전이 대신 시각에서 잠재 맥락으로 직접 조건화
  - 직접 조건화가 적응 성능과 학습 안정성을 모두 개선
- **핵심 기여** — 프레임워크, 시연 효율 근거, 행동·표현 분석
  - 시뮬레이션 세 과제에서 소량 데이터 조건의 π0.5와 GR00T N1.7 전체 파라미터 미세조정을 능가
  - 문 들어올리기와 양팔 조립에서 각각 10배, 5배 적은 시연으로 전체 데이터 기준선을 상회
  - 시연에 없던 질량 변화에 대한 강건성
  - 디코더 표현에서 접촉력 정보의 선형 접근성이 처음부터 학습한 경우보다 높음
  - 3개 학습 시드의 평균과 표준편차 보고
- **가치** — 대규모 시뮬레이션 RL 제어 지식을 시각 시연 소량으로 옮기는 경로를 제시

### (c) 시사점

- 사전학습 쪽 디코더를 동결하고 인터페이스만 학습하는 구성의 소량 시연 근거
- **백본 구성** — 사전학습 부분을 얼리고 앞단만 적응시키는 설계가 전체 미세조정 기준선을 이김
  - 비교 기준이 VLA 계열 서로 다른 모델의 전체 미세조정이라 같은 계통 안의 적응 범위 비교는 아님
- **사전학습 신호** — 인간 영상이나 로봇 시연이 아닌 시뮬레이션 RL 롤아웃을 사전학습 자원으로 쓰는 새 축
- **적응 비용** — 적응 단계가 시각 인터페이스 학습에 한정돼 학습 안정성이 높음

### (d) 먼저 확인할 점

- 모든 평가가 시뮬레이션이고 물리 로봇 성능은 미검증, 같은 팔–손 시스템 하나만 사용
- 유능한 특권 교사와 대량 시뮬레이션 경험이 전제라 전체 데이터·연산 효율이 아닌 시각 시연 효율만 개선
- 동결 사전 지식이 교사의 실패 모드를 물려받고 다른 제어가 필요한 과제의 적응을 제한할 수 있음
- 질량 강건성과 힘 판독은 해석을 뒷받침하나 시연 효율 향상의 인과 기제를 분리하지는 않음
- 시뮬레이션 세 과제로 한정, 형태가 다른 로봇으로의 전이는 입증되지 않음
