## 🥇 논문 1

**OrthoSkillVLA: Continual Skill Learning via Gradient-Informed Skill Subspace Adaptation**
[arXiv:2608.19589](https://arxiv.org/abs/2608.19589) · Jiaqi Wang, Zhou Fang, Qiongfeng Shi, Yi Zhou · PRCV 2026 · source: citation-graph · 코드 공개

**점수 14/15** · R3 · N2 · M3 · Real3 · Repro3 — 표제부 "https://github.com/Jiaqi-Wangx/OrthoSkillVLA" · §0.A.2 "The accompanying code repository provides access to both the common starting checkpoint and the LeRobot-formatted datasets" · Appendix 0.B "the control command for the Inspire dexterous hand is 6-dimensional"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- VLA 모듈별 부분공간 예산으로 순차 스킬 망각 억제
- **문제** — 사전학습 VLA가 스킬을 순차로 익힐 때 새 갱신이 기존 스킬 표현을 간섭해 속도장(velocity field) 예측이 왜곡되고 성능 급락
  - 다과제 적응에는 강하지만 지속적 스킬 습득에는 약함
  - 평생 스킬 습득이 안 되면 VLA의 확장 배포가 막힘
- **기존 한계** — 구조 분리 방법은 스킬마다 구조가 커지고, 부분공간 제약 방법은 VLA 구성요소의 역할 차이를 무시
  - 구조 기반 방법 — 스킬별 계산 경로 분리로 보존하지만 스킬이 쌓일수록 구조·보조 연산이 늘어 실시간 제어에 불리
  - 그래디언트 투영 기반 부분공간 방법 — 구조는 고정이지만 네트워크 전체에 균일 제약을 걸어 VLM·ActionHead·최종 속도 디코더의 역할 차이를 반영하지 못함
  - 균일 제약의 상충 — ActionHead에 필요한 엄격한 제약은 VLM의 적응 용량을 빠르게 소진, VLM 가소성을 지키는 느슨한 제약은 ActionHead의 국소 속도 패턴 보호에 실패
  - 최종 속도 디코더 — 갱신하면 기존 속도 매핑을 덮어쓰고, 동결하면 직교 부분공간에 묶인 앞단 어댑터가 부담을 떠안는 출력단 병목
- **핵심 방법** — 누적 그래디언트로 스킬 특징 부분공간을 추정하고, 기존 방향의 직교 여공간에 새 스킬을 저랭크 적응으로 주입하는 재생 없는 지속학습
  - 모듈 인지 예산 — VLM과 ActionHead에 별도 부분공간 예산을 배정해 의미 가소성과 속도 패턴 보존을 함께 확보
  - Feature-Aware MoE 속도 디코더 — 최종 디코더는 직교 미세조정에서 빼고 스킬마다 소형 전문가 할당
  - 학습 없는 투영 기반 라우터 — 그래디언트 기반 스킬 기저와의 특징 공간 친화도로 전문가 선택
- **차별점** — 직교 제약을 모델 전체에 한 기준으로 거는 대신 모듈 역할별로 다르게 걸고, 출력단만 스킬별 전문가로 분리
  - 가장 강한 비교 대상 KeepLoRA는 VLM과 ActionHead에 같은 에너지 임계값을 공유
- **핵심 기여** — VLA 특유의 두 문제 제시, 모듈별 예산과 MoE 디코더, 시뮬레이션·실물 검증
  - 진단 — 모듈 수준 표현 이질성과 출력단 표현력 병목을 실험으로 제시
  - 시뮬레이션 — LIBERO-100을 OpenClose·Turn·PickPlace 3스킬로 재구성한 스킬 증분 프로토콜, 3개 순서 평균에서 KeepLoRA 대비 NBT 0.46→0.13, Final SR 56.61%→83.50%
  - 비교 대상 — SeqLoRA·IncLoRA·EWC·OLoRA·KeepLoRA, 모두 X-VLA 기반 동일 시작 체크포인트
  - 실물 — 7-DoF xArm + 6-DoF Inspire 손, Flip·Pick·Push·Press 4스킬 순차 학습 후 평균 최종 성공률 86.25%, KeepLoRA보다 15.0% 높음 (스킬당 시연 50개, 20회 시행)
  - 공개 저장소에 공통 시작 체크포인트와 LeRobot 형식 데이터 제공
- **가치** — 시연 재생 없이 사전학습 VLA에 스킬을 순차 추가하는 경로, VLA 구성요소마다 보존 요구가 다르다는 진단

### (c) 시사점

- VLM과 액션 측 보존 요구가 다르다는 실측 근거
- **VLM 동결과 전체 갱신 사이의 중간 선택지** — VLM에도 직교 부분공간 안의 저랭크 갱신을 허용하되 예산을 액션 측과 분리
- **출력단 병목 진단** — 최종 디코더를 묶어 두면 앞단 어댑터가 부담을 떠안는다는 관찰, 액션 측 어댑터 설계에 바로 참고 가능
- **재생 데이터 불필요** — 사전학습 데이터 접근 없이 쓸 수 있는 보존 수단
- **도입 비용 낮음** — 코드·시작 체크포인트·데이터 공개, 다지 손 실물 설정까지 공개

### (d) 먼저 확인할 점

- 시뮬레이션 수치는 저자들이 재구성한 스킬 증분 프로토콜 기준 — 표준 LIBERO 프로토콜 결과와 직접 비교 불가
- 출발 계보는 X-VLA, LIBERO는 도메인 파라미터만 웜업 — 다른 계보의 플로우 매칭 VLA에서 같은 예산 분리가 통하는지는 원문에 없음
- 실물은 단일 플랫폼 4스킬, 실물 비교 대상은 KeepLoRA 하나
- 스킬마다 소형 전문가가 추가됨 — 구조 증가를 비판한 서론과 달리 디코더는 스킬 수에 비례해 커짐, 스킬 수가 늘 때의 라우팅 정확도 확인 필요

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 고정 데이터 예산 아래 표현 중심 VLA 계속 사전학습
- **문제** — 로봇 궤적은 웹에서 긁어 올 수 없고 물리 상호작용 공간을 듬성하게만 덮어, 데이터 규모만으로 일반화 백본을 만들기 어려움
  - 장면·물체·목표·체화·접촉 동역학에 걸친 조합적·연속적 공간이라 대규모 데이터셋도 부분적·불균등 커버리지
  - 질문 — 고정 로봇 데이터 예산에서 계속 사전학습(continued pre-training)이 어떻게 전이 가능한 시각-액션 표현을 만드는가
- **기존 한계** — 계속 사전학습을 대규모 액션 적합으로만 다루는 단순 레시피의 세 실패 모드
  - 전체 end-to-end 갱신 — 웹 규모 코퍼스보다 훨씬 좁은 로봇 궤적이 범용 비전-언어 특징을 침식
  - 단일 액션 헤드 감독 — 백본이 그 헤드의 디코딩 기하에 과특화, 파일럿에서 OFT 헤드로 사전학습한 백본이 PI·GR00T 헤드와 결합 시 성능 저조
  - 이산 FAST 토큰 감독 — 미세한 시간·진폭 정보 손실
  - 체화별 출력 공간 분리 — 그리퍼 개폐처럼 물리적으로 같은 액션을 로봇별 헤드로 갈라 교차 체화 공유를 약화
- **핵심 방법** — 사전학습된 VLM에서 시작해 다중 체화 로봇 궤적으로 계속 사전학습한 백본 VLAct, 세 구성요소
  - VLM 사전 보존 — 비전 인코더·얕은 LLM 층 동결 + 캡션 데이터 혼합
  - 다중 헤드 연속 액션 공동 감독 — OFT·PI·GR00T 헤드를 함께 붙여 백본을 학습
  - 부분 통합 교차 체화 액션 레이아웃 — 비활성 차원 마스킹, 주기 관절용 wrap-aware 손실
  - 다운스트림 — 사전학습 헤드·캡션 스트림을 버리고 새로 초기화한 과제별 헤드를 붙여 파인튜닝
  - 기반 VLM은 Qwen3-VL-4B, 사전학습 데이터는 DROID·InternA1·RoboCoin·MolmoAct 공개 데이터
- **차별점** — 백본 가중치만 바꾸고 액션 헤드·초기화·다운스트림 데이터·옵티마이저·예산을 모두 고정한 비교
  - 7.6–21.4점 이득을 백본 단독 효과로 귀속
- **핵심 기여** — 표현 중심 계속 사전학습 레시피와 그 백본, 시뮬레이션·실물·미지 체화 검증
  - 시뮬레이션 — LIBERO-Plus 82.6%, VLA-Arena 54.8%, RoboTwin 2.0 92.5%
  - RoboDojo — 점수 10.66, 성공률 7.60%로 성공률 기준 6위, 명시적 WAM 항목 전원 상회
  - 미지 체화 — 사전학습에 없던 휴머노이드 RoboCasa-GR1에서 다운스트림 데이터 20%만으로 전체 데이터 GR00T-N1.6 상회
  - 실물 Franka Research 3 — 단일팔 단기 ID 평균 92.5% 대 사전학습 없는 Qwen3VL-4B-OFT 77.5%, 양팔 협응 72.0% 대 44.0% (과제당 10회)
  - 공개 데이터와 16 GPU 학습 설정만 사용
- **가치** — VLM 백본을 상속 부품이 아닌 VLA의 1차 설계 변수로 다루는 근거, 제한된 자원에서 사전학습 설계로 성능을 끌어올리는 경로

### (c) 시사점

- 계보 선택이 다운스트림을 가른다는 통제 증거
- **계보 단위의 직접 측정** — 같은 VLM에서 계속 사전학습 레시피만 바꾸고 헤드·데이터·예산을 고정한 비교, 초기 가중치 × 추가 사전학습 코퍼스 조합을 하나의 변수로 다루는 근거
- **사전학습 단계의 보존 수단** — 얕은 층 동결·캡션 혼합으로 VLM 사전을 지킴, 배포 단계 보존보다 한 단계 앞의 레버
- **단일 헤드 사전학습 경고** — 플로우 매칭 헤드 하나로만 사전학습하면 백본이 그 헤드에 과특화될 위험, 다중 헤드 공동 감독이 대안
- **공개 기준점 확보** — 공개 데이터·16 GPU 규모라 백본 교체 실험 비용 낮음

### (d) 먼저 확인할 점

- 계보가 Qwen3-VL-4B — PaliGemma 계열에 같은 레시피를 적용한 결과는 원문에 없음
- arXiv comment는 공개를 말하지만 §4 본문은 "We will release the training scripts and model checkpoints" — 실제 공개 범위 확인 필요
- 실물 비교 대상은 사전학습 없는 Qwen3VL-4B-OFT 하나, 과제당 10회
- RoboDojo에서 저자 스스로 Memory 계열 과제를 명확한 한계로 지적
- 다운스트림은 새 헤드를 붙인 파인튜닝 — 백본을 고정한 채 액션 측만 적응할 때의 이득은 따로 측정되지 않음

[arXiv:2609.21461](https://arxiv.org/abs/2609.21461) · Di Wu, Dongchen Zheng, Junhe Sheng 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 14/15** · R3 · N3 · M3 · Real3 · Repro2 — 초록 "https://github.com/Agentic-Intelligence-Lab/Atom-0"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 에고-로봇 공동 사전학습 세 패러다임 통제 비교
- **문제** — 로봇 시연은 수집 비용이 크고 하드웨어에 묶여 과제·환경·물체 다양성이 제한, 데이터가 체화 파운데이션 모델 확장의 병목
  - 에고센트릭 인간 상호작용 영상은 규모를 주지만 실행 가능한 액션 라벨이 없음
  - 추정한 손 동작은 형태·기구학·좌표계·외관에서 로봇 명령과 다름
- **기존 한계** — 액션 리타깃팅·체화 정렬·잠재 액션·월드 모델 목표 등 연결 수단이 각각 고립적으로 연구됨
  - 다수가 대규모 사전학습이 아닌 사후학습 단계에서만 다뤄짐
- **핵심 방법** — VLA와 WAM 두 아키텍처에서 에고 데이터 통합 패러다임 셋을 같은 데이터·연산 조건으로 사전학습해 비교
  - Atom-DH — 도메인별 액션 헤드를 둔 공동학습
  - Atom-CL — 인간 손과 로봇 엔드이펙터를 공통 엔드이펙터 표현으로 맞춘 점진적 에고→로봇 전이
  - Atom-WAM — Fast-WAM 초기화 위 비디오-액션 공동 모델링
  - VLA 두 패러다임은 π0.5 구조, 사전학습된 π0.5 체크포인트가 아닌 PaliGemma VLM 가중치에서 초기화
  - 코퍼스 — 로봇 약 1,560시간(AgiBot World Beta·DROID·RoboCOIN·RoboMIND·자체 Piper), EgoVerse 에고 약 1,079.5시간, 같은 과제의 인간·로봇 정렬 데이터 약 20시간, 합계 약 2,659시간
- **차별점** — 한 가지 메커니즘에 걸지 않고 도메인 분리·명시적 체화 정렬·통합 시각 예측 목표를 한 틀에서 맞비교
- **핵심 기여** — 정제 코퍼스·처리 파이프라인, 세 패러다임 구현, 통제 비교와 경험칙
  - 실물 양팔 7과제, ID·OOD 각 10회(총 140회) — Atom-CL ID 64.29%·종합 53.57%, 로봇 데이터만 사전학습한 VLA 기준선 대비 +21.43·+20.71%p
  - 단순 혼합의 한계 — Atom-DH 종합 43.57%, ID는 42.86%→45.71%로 소폭 개선
  - OOD — VLA 기준선 22.86% 대비 Atom-DH 41.43%, Atom-CL 42.86%
  - WAM 역전 — Atom-WAM이 Fast-WAM 기준선보다 하락, 종합 28.57%→20.71%
  - 경험칙 "Data Scale × Alignment Quality → Capability Gain"
- **가치** — 에고 데이터의 가치가 규모만이 아니라 정렬 품질과 통합 방식에 달려 있다는 통제 증거, 에고-로봇 사전학습 설계 지침

### (c) 시사점

- 에고 단순 혼합은 이득 미미, 정렬이 이득을 만듦
- **열린 코퍼스 구성 질문에 통제 수치** — 같은 데이터·연산에서 혼합 방식만 바꾼 실물 비교
- **정렬이 선행 조건** — 에고 비중을 늘리기 전에 공통 엔드이펙터 표현과 인간·로봇 쌍 정렬 데이터 확보가 먼저
- **에고→로봇 순서의 첫 실물 근거** — 점진적 전이가 세 패러다임 중 최선
- **OOD 이득** — 에고 데이터의 효과가 분포 이동 아래에서 크게 나타남, 소량 배포 데이터 적응에서 기대할 효과의 방향
- **가까운 조건** — PaliGemma 초기화 + π0.5 구조라 우리 계보와 비교가 쉬움

### (d) 먼저 확인할 점

- 코퍼스 규모 표기 불일치 — 초록·§3.1은 약 2,659시간, 서론은 3,033시간

## 🌱 논문 4 — 인접 분야 픽

**A Deafening Silence: Catastrophic Forgetting Lives in the Output Embeddings of Tokens the Data Never Speaks**
[arXiv:2610.09835](https://arxiv.org/abs/2610.09835) · Jonghyun Han, Younghoon Song, Jongyoul Park · adjacent field: 지속 학습·파국적 망각 (LLM 계속 사전학습)

**점수 8/15** · R2 · N3 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- LLM 망각을 희귀 토큰 출력 임베딩에 국소화
- **문제** — 계속 사전학습·파인튜닝이 파운데이션 모델에 파국적 망각을 일으키고, 대표 완화책인 재생(replay)은 대개 접근할 수 없는 원 사전학습 데이터가 필요
  - 데이터 없는 조건에서 망각이 어디서 왜 생기는지 인과적으로 특정하고 그 자리만 막는 것이 목표
- **기존 한계** — 데이터 없는 방어는 무차별 제약, 국소화 연구는 서로 엇갈림
  - 파라미터 선택·저랭크 어댑터·직교 부분공간 투영 — 전체 파라미터 드리프트를 무차별 제약해 보존 대가로 가소성 희생
  - 국소화 연구 — 초기 어텐션·하위층·FFN 등 서로 다른 위치를 보고, 가중치 변위 같은 상관 지표에 의존
  - 저랭크 출력 모드에 망각이 몰린다는 이론은 있으나 그 모드를 담은 텐서는 미특정
- **핵심 방법** — 학습 중 파라미터 그룹을 하나씩 사전학습 값에 동결해 그룹별 망각의 인과 몫을 측정
  - 위치·Adam 2차 모멘트(√v̂) 대역·코퍼스를 바꿔가며 망각 위치를 특정
  - 메커니즘 — 새 코퍼스에 없는 토큰의 출력 임베딩이 한쪽 방향 softmax 그래디언트를 지속적으로 받고, Adam의 √v̂ 정규화가 이를 전체 크기 갱신으로 증폭
  - 개입 — 출력 투영에만 Adam ε를 높임
- **차별점** — 전체 드리프트를 제약하는 대신 망각이 사는 텐서 하나만 겨냥, 원 데이터와 모델별 튜닝 불필요
- **핵심 기여** — 인과 국소화, 메커니즘, 출력 한정 ε 개입, 경계 조건
  - 국소화 — 5개 안정 설정에서 망각의 31–51%가 희귀 토큰 출력 임베딩에 집중, 같은 대역의 몸통은 10% 미만
  - 위치를 정하는 것은 학습 방식이 아니라 코퍼스의 어휘 결핍, 토큰 수만으로 재학습 전 위험 순위 산정
  - 출력 한정 ε — 160M–12B, 4개 모델 계열, 8개 설정 중 안정 7개에서 망각 39.4–67.9% 제거, 목표 학습 저하 없음
  - 재생과 가산 이상으로 결합 — Qwen/한국어 79.8%, released-head LoRA의 23배 망각 급증 방지
  - 경계 — 드리프트한 행의 사후 편집은 망각의 5% 미만만 회복, 개입은 학습 중이어야 함
- **가치** — 원 데이터 없이 옵티마이저 설정 한 줄로 망각을 줄이는 경로, 망각 위치에 대한 엇갈린 보고를 어휘 결핍이라는 한 변수로 통합

### (c) 시사점

- 로봇 데이터가 VLM 어휘를 굶길 때의 망각 위치
- **같은 구조의 조건** — 로봇 궤적 계속 사전학습은 언어 어휘 대부분이 등장하지 않는 코퍼스, 논문이 말하는 어휘 결핍 상황과 같은 구조
- **VLM을 갱신하는 경우의 첫 점검 대상** — 출력 임베딩 드리프트, 재생 데이터 없이 적용 가능한 저비용 보존 수단 후보
- **코퍼스 구성 단계의 사전 진단** — 토큰 수 기반 위험 순위로 추가 사전학습 전에 망각 위험을 가늠하는 도구 후보

### (d) 먼저 확인할 점

- 실험은 전부 LLM 언어 도메인 주입(한국어·수학·코드) — VLA·로봇 데이터 결과 없음
- VLA는 언어 출력 헤드 대신 액션 헤드로 출력 — 출력 임베딩 국소화가 VLA에서 그대로 성립하는지 미검증, VLM을 동결하면 해당 없음
- 저자 한계 — 재학습 전 진단은 순위만 예측, 분포 내 튜닝에서 몸통으로 옮겨간 망각의 방어는 예비 단계, Pythia-410M 한국어 6시드 중 2시드는 회복 미미
- Adam 계열 좌표별 적응 옵티마이저 전제 — Muon 등은 범위 밖
- 코드 공개 언급 없음
