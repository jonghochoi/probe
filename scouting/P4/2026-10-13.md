### (b) 논문 요지

- **문제** — 휴머노이드 범용 정책이 전신 협응과 시연 부족이라는 두 장애로 새 지시를 바로 따르지 못함
  - 전신 협응 — 다리·몸통·팔·손가락이 함께 움직여야 해, 관절 명령을 예측하는 정책은 협응과 지시 해석을 동시에 학습해야 함
  - 시연 부족 — 휴머노이드 원격조작은 로봇과 조작자가 모두 필요해 다과제·다환경 기록 비용 큼
- **기존 한계** — 인간 기록은 로봇 관절 명령이 아닌 인간 모션이라 그대로 지도 신호가 되지 못함
  - 기존 휴머노이드 범용 정책 — 대상 과제마다 추가 로봇 시연으로 미세조정, 새 과제 배포마다 데이터 수집 반복
  - 로봇이 사람을 따라 하며 함께 녹화하는 방식 — 시연마다 다시 로봇 필요
  - 인간 모션을 로봇에 리타깃팅해 정책을 지도하는 방식 — 원문은 대안 경로로 언급
- **핵심 방법** — 범용 정책은 관절 명령 대신 몸통·손 모션 잠재 청크를 예측하고, 동결한 사전학습 제어기가 이를 관절 명령으로 실행
  - 입력 — 에고센트릭 영상, 언어 지시, 고유수용감각
  - 몸통 — SONIC의 인코더·제어기, 인간 모션과 로봇 모션을 같은 잠재 공간에 사상
  - 손 — 같은 구조로 따로 사전학습한 손 인코더-디코더, 인간·로봇 손 모션을 공유 64좌표 공간으로 사상
  - 학습 목표 — 동결 인코더가 인간·로봇 시연을 잠재 목표로 변환, 범용 정책 학습 중 인코더·제어기 전부 동결

- **핵심 기여** — 모션 잠재 행동 공간 정책, 인간 위주 학습 데이터, 실물 제로샷 결과와 지도·백본 비교

### (c) 시사점

- **도입 전제** — 인간·로봇 모션을 공유 잠재로 사상하는 사전학습 몸통·손 모듈이 먼저 필요

  - 같은 미세조정이 집고 놓기 과제의 놓기 행동을 완전히 망각(0%)
- **핵심 방법** — 동결한 기반 정책을 대상 로봇에서 사전학습 과제군 지시로 롤아웃하고, 그 예측 행동을 목표로 전문가 데이터와 함께 학습
  - 자기 시연 수집 — 기반 정책의 조건부 플로우 분포에서 행동 청크를 샘플링해 실행하며 관측-행동 쌍 기록
  - 결합 목적 — 전문가 지도 손실에 가중치 λ의 자기 지도 손실을 더함, 1:1 혼합 균등 샘플링
  - 같은 초기 장면에서 서로 다른 지시로 수집해 정책이 지시를 계속 참조하도록 유도
  - 바람직하지 않은 자기 시연은 증류 전 수동 필터링
- **차별점** — 원 사전학습 데이터 없이 대상 하드웨어·장면·지시에서 생성한 리허설이라 도메인 간극 없음
  - 과제를 끝내지 못한 롤아웃도 행동이 지시와 의미적으로 상관된다는 관찰에 근거해 지도 신호로 사용
- **핵심 기여** — 자기 시연 결합 미세조정, 실물·시뮬레이션 결과, 새 RoboTwin 벤치마크
  - 사전학습 행동 증류 — 집기 전문가 데이터와 자기 지도 놓기 데이터 결합 시 놓기 행동 0%→55%, 놓기 전문가 시연 없음

  - 지시 수행 지표에서 자기 시연이 전문가 시연을 다시 수집한 오라클과 동등
  - 보류 스킬 망각 방지 — 학습에 없는 밀기 스킬 60%, 전 과제 전문가 시연 오라클 5%

- **가치** — 원 데이터 없이 범용 정책의 사전 능력을 대상 로봇으로 옮기는 데이터 측 보존 경로 제시

### (b) 논문 요지

- 민감한 층에만 LoRA를 거는 층 선택 적응
- **문제** — 파라미터 효율 미세조정(PEFT)으로 LLM을 특화 과제에 맞추면 사전학습으로 얻은 일반 능력이 저하되는 망각
  - 모델 규모가 커질수록 전체 미세조정의 연산·메모리 비용 증가, LoRA가 대안으로 널리 쓰임
- **기존 한계** — 기존 완화책은 학습 데이터나 제약에 의존, 어디에 적응할지는 미탐구
  - 데이터 리플레이 — 일반 도메인 예시를 섞음, 원 사전학습 코퍼스에 접근할 수 없으면 제한
  - 정규화(EWC·L2-SP) — 파라미터 변화를 제약, 목표 과제 향상을 제한할 수 있음
  - 표준 LoRA — 모든 Transformer 층에 같은 적응 구성 적용
- **핵심 방법** — 층별 목표 과제 민감도를 순전파만으로 추정해 민감한 층에만 LoRA 배치
  - 층별 경험적 Fisher 점수로 목표 과제 민감도 측정
  - 대리 지표 — 층 입력-출력 코사인 유사도, 목표 과제 보정 입력 100개에 한 번의 순전파, 응답 라벨·역전파 불필요
  - LS-LoRA — 유사도 0.85 미만 층에만 어댑터 학습, 선택 층은 학습 내내 고정, 사전학습 가중치 전부 동결
- **차별점** — 데이터·제약 대신 적응 위치 선택으로 망각 완화, 추가 정규화 손실 없음
- **핵심 기여** — 민감도 분석, 순전파 대리 지표, LS-LoRA와 LLM 실험
  - 입력-출력 유사도와 Fisher 점수 사이 모델·과제 전반의 일관된 음의 순위 상관
  - 수학 추론 — Llama-3.2-1B·3B, Llama-3-8B, Mistral-7B 4종 모두 수학·상식 평균 최고, 전 층 LoRA 대비 수학 0.4–1.1점·상식 6.0–14.3점 향상
  - Llama-3.2-3B — 기준 모델 대비 상식 정확도 하락을 15.3점에서 1.0점으로 축소, 수학 65.8%→66.9%, 상식에서 L2-SP-LoRA·EWC-LoRA보다 5.6·7.2점 높음
  - 코드 생성 — 4종 모두 pass@k 평균·상식 평균 최고, 전 층 LoRA 대비 상식 1.2–6.2점 향상
  - 무작위 층 선택 대비(Llama-3.2-1B) — 수학 52.2% 대 51.4%, 상식 31.8% 대 27.1%, 4종 모두 우위
  - 효율 — 최대 GPU 메모리 4.2–14.4%, 학습 시간 10.0–29.6% 절감
  - DoRA·PiSSA에도 적용 가능성 제시
- **가치** — 적응 위치를 미세조정 효율과 능력 보존의 실용적 설계 변수로 제시

### (c) 시사점
