**Scaling Dexterous Manipulation via Action Representation Pretraining**
[arXiv:2610.34453](https://arxiv.org/abs/2610.34453) · Yanjinghao Xu 외 · arXiv preprint · source: citation-graph

**점수 12/15** · R3 · N3 · M3 · Real3 · Repro0 — arXiv comment "Project page: https://arpg-project.github.io/" (프로젝트 페이지만)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 인간 조작 데이터로 액션 표현만 따로 사전학습
- **문제** — 복잡한 다지 조작의 액션 생성이 로봇 시연 규모에 묶여 있음
  - 로봇 시연 하나로 액션 표현과 과제 조건부 액션 분포를 함께 배워야 함
  - 질문은 로봇 시연과 생성 백본을 함께 키우지 않고도 액션 표현 사전학습만으로 성능이 오르는가
- **기존 한계** — 주류 정책은 로봇 시연으로 액션 생성을 끝에서 끝까지 학습
  - 개선 폭이 로봇 시연 규모와 하위 모델 용량 양쪽에 제약됨
  - 사전학습 시각 인코더는 모션·상호작용 의미는 담지만 액션 복원용 표현 공간은 아님
  - 액션만으로 하는 자기지도 학습은 표현을 처음부터 배워야 해 시각 사전학습 구조와 장면 맥락을 못 씀
- **핵심 방법** — 액션 표현 사전학습과 과제 조건부 생성을 분리하고, 사전학습된 표현 공간 안에서 생성
  - 시각-액션 이중 타워 — 동결한 V-JEPA 2.1이 시각 표현을 뽑고 액션 Transformer가 궤적을 인코딩, 시그모이드 손실로 두 표현을 정렬
  - 사전학습 후 액션 타워를 동결해 표현 인코더로 쓰고, 로봇 시연으로 연속 액션 복원 디코더를 학습
  - 생성 단계 — 미래 액션 청크를 동결 인코더로 사상한 목표를 DiT 백본(약 130M 파라미터)이 플로우 매칭으로 생성하고 디코더가 실행 액션으로 복원
- **차별점** — 액션 표현이 정책 학습 중 내부에서 생기는 부산물이 아니라 독립적으로 사전학습·확장하는 대상
  - 인코더가 특정 로봇의 액션 세부에 생성 목표로 맞춰지지 않아 대규모 에고센트릭 인간 데이터로 확장 가능
- **핵심 기여** — 액션 표현 사전학습을 하위 정책의 독립 확장 축으로 제시하고 수치로 뒷받침
  - DexJoCo 시뮬레이션 다중 과제 공동 학습에서 π0.5 대비 양손 다지 조작 평균 성공률 10.1%에서 44.7%, 전체 평균은 단일 과제 61.3%, 다중 과제 57.8%
  - 인간 사전학습 데이터 10시간 40.9%에서 500시간 57.8%, 3,000시간은 추가 이득 없음, 로봇 8.8시간만 쓴 인코더는 42.7%
  - 액션 표현 학습 방식만 바꾼 비교에서 Action-MAE·Action-iBOT이 Raw Action보다 낫고 시각 정렬이 최고
  - 실물 양손 3개 과제(망치 전달, 커피콩 붓기, 캐비닛 꺼내기) 모두 π0.5보다 전체 과제 성공률 높음
- **가치** — 액션 공간 사전학습이라는 새 확장 방향과, 시간보다 행동 범위가 효율을 좌우한다는 관찰

### (c) 시사점

- 액션 표현 인코더를 인간 데이터로 따로 키우는 경로의 첫 정량 근거
- **표현 선택** — 연속 플로우 매칭 생성 위에 사전학습 표현 공간을 얹은 구조, 원시 액션 대비 이득을 같은 조건에서 측정한 공개 기준점
- **데이터 조성** — 인간 데이터 500시간과 3,000시간이 같은 성능, 늘릴 것은 시간이 아니라 과제 범위라는 신호
- **로봇 데이터 대비** — 로봇 8.8시간 인코더가 인간 100시간보다 낮은 결과, 인간 데이터 쪽 우위의 한 근거
- **도입 비용** — 생성 백본 약 130M이라 적응 단계 비용은 낮은 편

### (d) 먼저 확인할 점

- **저자 명시 한계** — 다지 조작에서만 검증, 그리퍼 등 다른 로봇으로의 이전은 미검증
  - 개방 환경의 의미 이해와 과제 일반화는 체계적으로 평가하지 않았고 사전학습 데이터·연산 규모도 제한적
- 인코더 크기와 사전학습 연산을 키워도 하위 성능이 일관되게 오르지 않음, 저자는 풀링 후 정렬 목표와 토큰 단위 생성 사이 불일치를 추정
- 코드·체크포인트 공개 약속이 없어 재현 경로가 프로젝트 페이지뿐
- 비교 π0.5 수치는 DexJoCo 원 논문 보고값 인용, 이전 가능성은 자체 사전학습 코퍼스(EgoDex·EgoVerse 중심) 구성에 의존

### (b) 논문 요지

- 에고센트릭 사전학습 후 휴머노이드 적응의 3단계 VLA
- **문제** — 휴머노이드용 범용 VLA는 전신 협응 제어와 다양한 전신 시연이 필요한데 실물 수집 비용이 큼
  - 팔 움직임이 몸통·하체와 협응하며 균형을 유지해야 해 매니퓰레이터용 VLA를 그대로 옮기기 어려움
  - 에고센트릭 인간 시연은 보완 자원이지만 시각적 몸체 차이와 로봇 고유수용감각 부재로 직접 쓰기 어려움
- **기존 한계** — 기존 휴머노이드 이동 조작은 상위 정책과 강화학습(RL) 기반 제어기를 결합한 계층 구조
  - 이 구조는 상위 정책이 전신 실행으로 이어지는 액션 인터페이스를 따로 요구
  - 에고센트릭 데이터를 쓰는 학습 파이프라인은 시각 차이와 고유수용감각 부재를 풀지 않은 채 남겨 둠
- **핵심 방법** — 기존 VLA 구조 3종이 사전학습된 전신 제어기용 잠재 모션 토큰과 손 제어 신호를 예측
  - 3단계 — 에고센트릭 사전학습, 휴머노이드 적응, 다운스트림 미세조정 순
  - 사전학습 중 시뮬레이션 재생으로 의사 고유수용감각 상태를 구성
  - 미세조정 중 에고센트릭 영상의 팔 영역을 재렌더링해 로봇 팔 외관으로 교체
- **차별점** — 에고센트릭 데이터를 사전학습과 미세조정 양쪽에서 휴머노이드용으로 가공
  - 사전학습 단계는 상태 입력을, 미세조정 단계는 시각 외관을 보정
- **핵심 기여** — 2,000시간 이상의 에고센트릭·로봇 코퍼스와 3단계 학습 레시피
  - 시뮬레이션 HumanoidArena 평균 성공률 HuGe-GR00T 66.67%, HuGe-Pi 65.00%, 가장 강한 기준선 π0.5보다 12.86%p, 11.19%p 높음
  - 학습 전략 비교(동결·LoRA·전체) — 전체 미세조정이 세 변형 모두 최고로 LoRA를 19.29–38.81%p 상회
  - 시각 적응이 특징 분포 거리(FD)를 Wan2.2 기준 2.0311에서 1.3499로 낮춤
  - 실물 Unitree G1 콜라 집어 놓기 — 로봇 시연 110개만 43.3%(13/30), 원본 에고센트릭 400개 추가 60.0%(18/30), 시각 적응본 66.7%(20/30)
- **가치** — 불완전한 에고센트릭 인간 경험을 휴머노이드 정책 학습 자원으로 쓰는 단계별 레시피 제시

### (c) 시사점

- 에고센트릭 데이터 추가와 시각 보정이 고정된 로봇 시연 예산에서 성공률을 올린 실물 측정
- **적응 범위** — 동결·LoRA·전체를 같은 조건에서 비교해 전체 미세조정이 앞선 결과, 동결 기본값을 점검할 반례 자료
- **단계 구성** — 에고센트릭, 로봇 적응, 과제 미세조정 순의 3단계 레시피 참고 사례
- **데이터 조성** — 에고센트릭 사전학습 규모가 커질수록 두 변형이 오르는 규모 곡선

### (d) 먼저 확인할 점

**EXE: Egocentric Cross-Embodiment Pretraining via Factorized Latent Actions for VLA Models**
[arXiv:2610.33685](https://arxiv.org/abs/2610.33685) · Qingyuan Cai, Bo Zhang, Yongzhen Huang, Jianyu Chen · arXiv preprint · source: citation-graph

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 액션을 공유 위치 부분공간과 로봇별 부분공간으로 분해
- **문제** — 에고센트릭 인간 영상은 풍부하지만 몸체 차이 때문에 로봇 정책에 쓸 액션 표현을 뽑기 어려움
  - 인간 손(MANO 손가락 관절)과 로봇 말단 장치(그리퍼·다지 손)는 동작 기본형은 같고 기구학이 다름
  - 질문은 액션의 어느 부분을 공유할지와 공유 액션을 몸체 사이에 어떻게 정렬할지
- **기존 한계** — 기존의 두 접근은 각각 한계가 있다고 저자가 주장
  - UniT — 액션 전체를 하나의 공유 코드북에 넣어 공유 코드가 몸체별 기하를 흡수하고 과제 의미를 가림
  - LAPA — 프레임 전이에서 잠재 액션을 배워 배경·조명 같은 무관 정보가 얽힘, CLAP이 시각 잡음을 인코딩한다고 지적
  - GR-1, GR-2, HPT — 시각 특징만 쓰고 인간 손동작의 액션 정보는 옮기지 않음
- **핵심 방법** — 특징 그룹 라우팅 액션 토크나이저와 이중 정렬, 3단계 파이프라인
  - 토크나이저 — 액션을 공유 위치 부분공간(손목·말단 3차원 위치)과 몸체별 운동학 부분공간(손가락 관절·그리퍼)으로 나눠 공유는 공동 코드북, 몸체별은 도메인 전용 코드북으로 양자화
  - 정렬 — 대조 학습이 공간 궤적이 비슷한 도메인 간 샘플을 당기고, 동결 언어 임베딩 기반 관계 증류가 의미는 같고 궤적이 다른 쌍을 맞춤
  - 파이프라인 — 토크나이저 학습, 에고센트릭 영상·로봇 데이터로 VLM 공동 학습(공유 토큰 지도), 다운스트림 미세조정
- **차별점** — 액션 전체를 한 코드북으로 합치지 않고 공유할 차원만 골라 코드북을 공유
  - 의미가 같은 액션을 궤적 유사성이 아닌 언어 신호로도 정렬
- **핵심 기여** — 그리퍼와 다지 손 양쪽에 적용되는 에고센트릭 사전학습 레시피
  - RoboTwin 2.0 평균 성공률 76.2%(쉬움 75.6%, 어려움 76.8%), X-VLA 72.9%보다 높고 사전학습 없는 EXEbase보다 높음
  - RoboCasa GR1 56.6%, EXEbase 52.0%, StarVLA-GR00T 공식 결과 47.8%
  - 에고센트릭 대 로봇 혼합비 1:1이 76.2%로 최고, 2:1 74.3%, 3:1 75.5%
  - 인간 데이터 출처 VITRA-1M·EgoDex·EgoLive 모두 EXEbase 대비 향상, EgoLive 최고
  - 실물 AgileX Piper 쓰레기 쓸기 — 학습 분포 내 EXEbase 60%에서 EXE 80%, 미학습 물체 방해 시 10%에서 30%(각 10회 시행)
- **가치** — 로봇 종류에 상관없이 쓰는 에고센트릭 영상 사전학습의 일반 레시피 제시

### (c) 시사점

- 에고센트릭 대 로봇 데이터 혼합비를 직접 바꿔 본 측정, 1:1이 최고라는 공개 기준점
- **데이터 조성** — 인간 비중을 너무 낮추면 사전학습 지식이 깎인다는 저자 해석, 에고 중심 가설과 방향 일치
- **다지 손 이전** — 그리퍼에서 학습한 공유 어휘가 다지 손 환경 RoboCasa GR1에서도 이득
- **단계 구성** — 토크나이저, 공동 학습, 미세조정으로 이어지는 3단계 구성의 참고 사례

### (d) 먼저 확인할 점

- 혼합비 비교는 RoboTwin 2.0 한 벤치마크 3개 지점이라 차이가 1–2%p 수준
- 저자 명시 한계 문장과 반복 시드는 확인되지 않음
- 실물은 단일 과제이고 시행이 군당 10회라 표본이 작음
- Stage 2에서 대규모 교차 몸체 로봇 데이터를 의도적으로 제외, 혼합 코퍼스 대비 이득은 이 논문으로 확인 불가
- 코드 저장소나 공개 약속 없음
