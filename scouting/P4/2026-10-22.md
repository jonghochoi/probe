## 🥇 논문 1

**LAPT-Scale: Scaling Embodied Policies with Latent Action Pre-Training on Human Videos**
[arXiv:2610.13732](https://arxiv.org/abs/2610.13732) · Zhiyuan Xiang, Peidong Liu, Mingyang Li, Jiawei Li 외 3인 · CoRL 2026 · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — arXiv comment "Accepted at CoRL 2026; 24 pages including appendix"에 코드 저장소·공개 약속 없음, 초록·본문도 동일

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 연속 잠재 행동으로 인간 영상을 VLA 사전학습 지도로 전환
- **문제** — 에고센트릭 인간 영상은 규모가 크지만 로봇 행동 라벨이 없음
  - 인간 동작을 로봇 제어 공간에 바로 대응시킬 수 없음
  - 로봇 상호작용 데이터는 수집 비용이 높아 확장이 막힘
- **기존 한계** — 영상에서 행동 지도를 뽑는 두 계열 모두 지도 품질이 부족하다는 주장
  - VITRA 같은 명시적 동작 추정 — 추정 오차가 노이즈 주석이 되고 영상을 더 넣어도 정책이 개선되지 않을 수 있음
  - 기존 잠재 행동 모델(LAM) — 이산 코드북(VQ)이 에고센트릭 조작의 연속적 변화를 과압축
  - 픽셀 복원(MSE) 신호는 정적 영역이 지배해 작은 손-물체 상호작용에 약한 신호
- **핵심 방법** — 잠재 행동 모델과 3단계 VLA 정책 학습의 두 구성요소
  - LAPT-Scale-LAM — 프레임 간 시각 변화를 설명하는 연속 잠재 행동을 학습해 인간 영상의 지도로 사용
  - 정렬 신호 — 지각적 정렬(접촉 충실도), 자기지도 특징 기반 의미 정렬(손-물체 구조), 광학 흐름 정렬(관측된 동역학)
  - LAPT-Scale-Policy — 인간 영상 잠재 행동 사전학습, 대상 로봇 데이터 임베디먼트 정렬, 과제별 후학습의 3단계
- **차별점** — 이산 LAM 대신 연속 잠재 공간을 쓰고 복원 손실 너머의 정렬 신호를 더함
  - 명시적 손 궤적 라벨 없이 잠재 행동만으로 사전학습 지도 구성
- **핵심 기여** — LAM, 3단계 프레임워크, 실물 규모 실험
  - LAM은 에고센트릭 영상 23.3K시간으로 학습, 정제한 5.1K시간 부분집합에 주석
  - 자체 수집 로봇 데이터 250시간으로 정렬, RoboTwin 2.0 Easy/Hard 90.0%/89.3%로 최강 기준선을 근소하게 상회, RoboCasa-GR1 평균 64.8% (시뮬레이션)
  - 실물 3과제 평균 85.0%, π0.5와 JoyAI-RA 상회
  - 로봇 데이터 고정, 주석 인간 영상만 1K시간에서 5K시간으로 늘리면 실물 성공률 63.3%에서 85.0%로 상승 (1K 63.3%, 3K 80.0%, 5K 85.0%)
  - 같은 규모 비교에서 손 동작 주석은 3K시간까지 오르다 5K시간에서 55.0%로 하락, DreamDojo LAM은 5K시간 76.7%
  - Stage 1 제거 대조와 같은 연산량의 Stage 2 연장 대조 모두 전체 모델에 미달
  - 정렬 항 제거 절제에서 광학 흐름 제거가 RoboTwin Hard에서 가장 큰 11.5점 하락
  - 더 어려운 실물 4과제에서 위치·조명·배경 변화 아래 70.0–75.0% 유지
- **가치** — 로봇 라벨 없는 인간 영상이 주석 품질이 받쳐지면 영상량에 따라 정책 성능으로 이어질 수 있다는 규모 증거 제시

### (c) 시사점

- 사전학습 인간 영상량이 실물 성공률로 이어짐을 단계별로 분리 측정
- **단계 레시피 근거** — 인간 영상 사전학습 단계를 제거하거나 같은 연산량으로 후속 단계를 늘린 대조가 모두 전체 모델에 미달
  - 에고센트릭 사전학습 이후 로봇 정렬, 과제 후학습으로 이어지는 단계 구성의 각 단계 기여를 가르는 자료
- **데이터 조성 단서** — 주석 방식에 따라 영상량의 효과가 갈림
  - 손 동작 주석은 5K시간에서 하락, 잠재 행동 주석은 단조 상승
  - 에고센트릭 영상을 더 모으는 쪽의 이득은 주석 품질에 달렸다는 신호
- **도입 비용** — 23.3K시간 영상 처리와 자체 로봇 데이터 250시간이 선행 조건
  - 비교 가능한 공개 산출물이 없어 같은 조건 재현은 어려움

### (d) 먼저 확인할 점

- **평가 범위** — 저자 명시: 실물 연구는 7과제와 대상 플랫폼 1종, 조건당 20회 시행
  - 시행 수가 작아 성공률 정밀도 제한, 배치 견고성 주장에는 더 넓은 검증 필요
- **임베디먼트 정렬 의존** — 잠재 행동이 로봇 자유도와 일치한다는 보장이 없어 대상 로봇 데이터 정렬이 계속 필요
- **실패 조건** — 조작 신호가 약한 영상, 큰 임베디먼트 차이, 심한 가림, 카메라 움직임이 지배하는 변화에서 실패 가능
- **시뮬레이션 우위 폭** — RoboTwin 우위는 저자도 근소하다고 서술
- **코드 없음** — 저장소 URL이나 공개 약속 없음

### (b) 논문 요지

- 에고센트릭 인간 데이터 사전학습에 2분 미세조정과 행동 조향을 결합
- **문제** — 새 환경에서 새 과제를 인간 시연 5개와 5분 안에 배우는 로봇 정책
  - 로봇 학습 레시피가 요구하는 대규모 로봇 시연을 줄이는 것이 목표
- **기존 한계** — 시연 수와 적응 시간 양쪽에서 기존 접근이 부족하다는 주장
  - 원격조작 행동 복제 — 과제별로 수백에서 수천 개 시연 필요
  - 대규모 사전학습 후 일부 파라미터 미세조정 — 큰 모델은 여전히 며칠 소요
  - 보정된 환경에서 3D 주석(손 자세, 물체 점)을 얻는 인간 데이터 — 일반 가정용 로봇에는 과한 가정
  - 인터넷 규모 에고센트릭 영상 — 3D 손 자세 같은 주석이 없어 배포성 제한
- **핵심 방법** — 사전학습과 두 가지 적응 기법의 결합
  - 사전학습 — 스마트 글라스(Aria Gen 2)로 기록한 일상 상호작용 100시간 에고센트릭 데이터로 4억 파라미터 확산 트랜스포머 학습
  - 적응 — 새 과제 인간 시연 5개로 2분(2000 스텝) LoRA 미세조정
  - 행동 조향 — 역확산 샘플링 중 배포 환경 관측과 가장 가까운 시연으로 행동을 조향
  - 임베디먼트 전이를 위한 데이터 처리 파이프라인 포함
- **차별점** — 미세조정과 행동 조향을 함께 쓰고, 학습과 적응 모두 인간 데이터만 사용
- **핵심 기여** — 적응 레시피, 인간 데이터 전용 시스템, 통합 배포
  - 12개 과제, 12개 새 환경(실험실부터 새 가정 주방까지)에서 성공률 71%
  - 실험실 과제 비교 — 미세조정 2k 스텝 단독은 전부 실패, 조향 단독은 23%, 150k 스텝 미세조정은 비슷한 성공률이나 하루 학습 필요
  - 사전학습과 LoRA 미세조정의 연산량·데이터량을 바꾸면 성공률이 오르는 곡선을 표준편차와 함께 보고
  - 인코더·디코더 구조 절제와 조향 궤적 선택 전략 비교 포함
  - 열린 지식 내비게이션과 VLM 오케스트레이터를 연결해 단일 언어 명령으로 배포
  - 데이터셋, 모델 가중치, 코드, 영상 공개 예정
- **가치** — 로봇 시연 없이 인간 영상만으로 새 환경 적응을 수 분 단위로 줄이는 경로 제시

### (c) 시사점

- 사전학습 단계와 적응 단계가 각각 무엇을 사는지 예산 변화로 측정
- **단계 레시피 근거** — 미세조정만, 조향만, 둘의 결합을 같은 과제에서 비교해 적응 단계의 기여를 분리
  - 짧은 LoRA 적응 단독은 실패, 조향이 더해져야 성공한다는 결과
- **적응 범위 단서** — 대규모 사전학습 위에 LoRA 미세조정만 얹은 적응이 5분 예산에서 작동한 사례
  - 백본 동결 대 부분 적응 선택에 참고할 비용 곡선
- **도입 비용** — 사전학습 연산과 100시간 스마트 글라스 데이터 수집 체계가 선행 조건
  - 코드와 가중치는 공개 예정

### (d) 먼저 확인할 점

- **접촉 정보 부재** — 저자 명시: 인간 영상에 접촉 정보가 없고 행동을 시각으로만 주석해 저수준 행동이 원시적, 다지 능력 제한
- **리타깃팅 의존** — 인간 행동 예측이 맞아도 기구학 리타깃팅 오류로 로봇이 실패 가능
- **객체 일반화 범위** — 필요한 행동이 시연과 크게 다르지 않을 때만 새 객체에 견고
- **비교 범위** — 71%는 12개 과제 평균, 과제별 편차와 조향 시연 선택 전략 비교 수치는 본문 확인 필요
- **공개 예정** — 저장소 URL 없이 프로젝트 사이트 약속뿐

## 🥉 논문 3

**Train Together or Merge Later? Unifying VLA Experts via a Shared Action Interface**
[arXiv:2609.33125](https://arxiv.org/abs/2609.33125) · Zhizhen Zhang, Yuxia Fu, Zijian Wang, Helen Huang 외 1인 · arXiv preprint · source: citation-graph

**점수 8/15** · R3 · N2 · M2 · Real1 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- 행동 인터페이스를 고정한 LoRA 전문가를 문맥 기반 희소 병합
- **문제** — 공동학습 다과제 VLA는 과제별 독립 학습 성능에 못 미칠 수 있음
  - 독립 학습 전문가는 성능이 좋지만 정책이 분리됨
  - 공동 후학습 없이 과제별 이득을 하나의 다과제 정책에 유지하는 방법이 필요
- **기존 한계** — 모델 병합을 VLA에 그대로 쓰기 어렵다는 주장
  - 병합은 비전·언어 모델에서 성과를 냈지만 VLA에서는 개별 전문가가 강해도 병합 후 능력이 살아남는다는 보장이 없음
  - 정적 병합 — 하나의 파라미터 집합으로 모든 과제를 처리해 현재 과제와 무관한 업데이트가 실행에 간섭
  - 입력 기반 전문가 선택 — 목표나 물체가 겹치는 과제는 문맥이 비슷해 잘못된 전문가를 고르거나 충돌하는 업데이트를 합칠 위험
- **핵심 방법** — PolicyWeave의 두 구성요소
  - 병합 호환 후학습 — 모든 전문가가 기반 정책의 행동 인터페이스(행동 정규화 통계, 행동 인코더·디코더)를 유지하고 행동 모델 은닉층의 LoRA 업데이트로만 적응
  - 문맥 기반 희소 병합 — 초기 시각-언어 문맥에 대한 각 전문가 LoRA 업데이트의 응답으로 순위를 매기고, 층 하나씩 제거했을 때의 순위 안정성으로 전문가 집합을 결정해 현재 과제용 희소 가중 병합을 고정
  - 학습된 라우터와 보정용 궤적 없음
- **차별점** — 전문가끼리 호환되지 않는 원인을 행동 인터페이스 변경에서 찾아 후학습 단계에서 막음
  - 후학습 중 인터페이스 변경이 은닉층 변화로 보상되고, 병합이 이 보상을 깨뜨린다는 설명
- **핵심 기여** — 병합 호환성 진단과 방법, 평가
