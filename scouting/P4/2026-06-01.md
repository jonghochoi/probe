**Qwen-VLA: Unifying Vision-Language-Action Modeling across Tasks, Environments, and Robot Embodiments**
[arXiv:2605.30280](https://arxiv.org/abs/2605.30280) · Qiuyue Wang, Mingsheng Li, Jian Guan, Jinhui Ye et al. (Alibaba/QwenLM) · 2026-05-28 · source: Keyword Sweep (쿼리 1) + Citation-Graph (π0.5 인용)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) 핵심. [D19b](#ref-D19b)(새 백본 계보 후보), [D22](#ref-D22)(다중 구현체 공동 사전학습 레시피), [D23](#ref-D23)(iii)(DiT 액션 디코더)를 동시에 건드립니다.

### ✨ (b) 진정으로 새로운 점

기존 핀 논문들이 단일 VLM 계보(PaliGemma, Eagle-2, Molmo 등)를 개별 구현체에 특화 미세조정하는 구조였다면, Qwen-VLA는 **Qwen2.5-VL 백본 + DiT 액션 디코더**를 결합하고 로봇 조작 궤적·인간 에고센트릭 데모·합성 시뮬레이션 데이터·시각-언어 내비게이션·보조 VL 데이터를 단일 공동 사전학습 스텝에서 훈련합니다. 구현체별 차이는 textual embodiment-aware prompt conditioning으로만 처리해 동일 가중치로 ALOHA·WidowX·RoboTwin을 모두 커버합니다. 실환경 ALOHA OOD 성공률 76.9%, zero-shot DOMINO 동적 조작 26.6%는 D19b 2-쌍 비교 실험의 직접 대조 기준을 제공합니다.

### ⚙️ (c) 의사결정 함의

**[D19b](#ref-D19b)** 2-쌍 비교 실험 후보 목록에 `Qwen2.5-VL × Qwen-VLA mix`를 추가해야 합니다. 현재 D19b v1은 `PaliGemma-2B × π0 mix`이며, "계보 귀속 실패가 실환경 롤아웃에서 진단될 경우 2-쌍 비교" 트리거를 기다리고 있습니다. Qwen-VLA는 동일 조건(LIBERO 97.9%)에서 v1 계보와 직접 비교 가능한 수치를 공개했으므로 다음 실환경 실험에서 **v1 PaliGemma × π0 vs. Qwen2.5-VL × Qwen-VLA mix** 구성으로 2-쌍 실험을 설계할 준비가 됩니다. D22의 다중 구현체 공동 사전학습(Stage 0½) 레시피 설계 시, Qwen-VLA의 데이터 믹스(로봇 조작 + 에고센트릭 + 합성 + 내비게이션)를 기준 배합 비율로 참조해야 합니다. D23(iii) DiT 액션 디코더는 우리 v1 플로우 매칭 헤드와 유사한 역할 분리 구조를 취해, VLM이 의미 역할에 머무는 설계를 공유합니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

Qwen2.5-VL은 범용 VL 이해를 위해 사전학습된 모델이며, 이들의 로봇 궤적 데이터(DROID + MolmoAct + 자체 수집)는 비공개 가능성이 높습니다. 우리가 동일 계보를 채택할 경우 **공개 데이터만으로 동등한 로봇-도메인 표현을 확보할 수 있는지** 먼저 검증해야 합니다. 가장 빠른 확인 방법은 HuggingFace `QwenLM/Qwen-VLA` 저장소에서 공개 체크포인트·데이터 목록을 확인하고 LIBERO 벤치마크 단독 재현 실험을 돌려 v1 π0 대비 성능 격차를 측정하는 것입니다.

## 🥈 논문 2 — 우선순위 ★★

**BORA: Bridging Offline Reinforcement Learning and Online Residual Adaptation for Real-World Dexterous VLA Models**
[arXiv:2605.30226](https://arxiv.org/abs/2605.30226) · Zhongxi Chen, Yifan Han, Yanming Shao, Huanming Liu · 2026-05-28 · source: Citation-Graph (Being-H0.5 인용)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) D19(a) + D20 + D21 교차. [D19](#ref-D19)(a) 온라인 단계에서 VLA 기저 완전 동결, [D20](#ref-D20)(오프라인 크리틱이 동결 VLM 인식 토큰을 활용하는 prior-preserving 가치 추정), [D21](#ref-D21)(오프라인 → 온라인 단계적 레시피).

### ✨ (b) 진정으로 새로운 점

BORA의 핵심은 오프라인 크리틱이 **VLM 인식 토큰(cognition tokens) + 액션 청크**를 입력으로 받아 행동-조건부 가치 추정(action-conditioned value guidance)을 수행한다는 점입니다. 기존 VLA RL 사후학습이 시각 관찰만으로 가치를 추정했던 것과 달리, 동결된 VLM 표현을 직접 가치 신호로 재활용합니다. 온라인 단계에서는 VLA 기저를 동결한 채 경량 HiL chunk-wise 잔차 어댑터(residual adapter)만 최적화하며 5개 실환경 손재주 조작 태스크에서 평균 성공률 +33% p, 미보인 객체 일반화 +43% p를 달성합니다.

### ⚙️ (c) 의사결정 함의

[D21](#ref-D21) Stage 3/4 진입 트리거 조건("Stage 2 인-분포 플래토 + 일반화 손실")이 발동될 경우의 구체적 레시피를 제시합니다. LoRA를 먼저 풀기 전에, **오프라인 크리틱 구축(VLM 인식 토큰 기반) → 온라인 잔차 어댑터 미세조정** 순서를 삽입하면 백본 보존 상태에서 RL 이득을 확보할 수 있습니다. D20 action-side adapter v1이 지금은 D4/D7 split heads로 구현되어 있지만, RL 사후학습 단계로 진입할 때는 BORA의 chunk-wise 잔차 어댑터 설계를 우선 참조해야 합니다. 구체적으로는 `offline_critic_input = concat(vlm_cognition_tokens, action_chunk)` 구조를 채택하고, 개입 보상(intervention-driven reward) 신호를 HiL로 수집하는 파이프라인을 D21 Stage 3 진입 시 표준 절차로 채택하는 방안을 검토하십시오.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

오프라인 크리틱의 품질이 오프라인 시연 데이터셋 분포에 직접 의존합니다. 초기 데모가 불균일하거나 부족할 경우 VLM 인식 토큰이 가치 추정에 충분히 정보적이지 않을 수 있습니다. 가장 빠른 확인은 VLA-Trace([arXiv:2605.30117](https://arxiv.org/abs/2605.30117))에서 제안한 CKA(Centered Kernel Alignment) 체크포인트 드리프트 메트릭으로, 오프라인 크리틱 학습 전후 VLM 표현이 얼마나 이동했는지 측정하는 것입니다. 드리프트가 크다면 백본 보존이 실질적으로 훼손된 것으로 판단해 D19(d) LoRA 전환 트리거를 앞당겨야 합니다.

## 🥉 논문 3 — 우선순위 ★

**Turning Video Models into Generalist Robot Policies**
[arXiv:2605.27817](https://arxiv.org/abs/2605.27817) · Sizhe Lester Li, Evan Kim, Xingjian Bai, Tong Zhao, Tao Pang, Max Simchowitz, Vincent Sitzmann (MIT CSAIL) · 2026-05-27 · source: Citation-Graph (π0.5 인용)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) [D19](#ref-D19)(a) 극단 사례 실증 + [D19b](#ref-D19b) 계보 확장 + [D21](#ref-D21) 단계적 레시피 참조. VLM이 아닌 비디오 생성 모델을 동결 백본으로 사용하는 접근이지만, "동결 백본 + 구현체별 모듈" 패턴을 16-DoF Allegro 손 조작에서 검증합니다.

### ✨ (b) 진정으로 새로운 점

비디오 플래너(video world model)를 구현체에 관계없이 완전히 동결하고, Jacobian 기반 역동역학 모델(IDM)만 구현체별로 훈련합니다(VERA: Video-to-Embodied Robot Action Model). 동일 비디오 플래너 가중치로 Panda 팔 zero-shot 조작과 16-DoF Allegro 손 정육면체 재배향을 모두 수행합니다. IDM은 자기 탐색(self-play) 데이터만으로 훈련 가능해 레이블이 필요 없습니다. 이 결과는 D19(a) "전체 동결 + 구현체별 전문가"라는 v1 설계가 극도로 고차원 손 제어에서도 zero-shot 이전이 가능함을 외부 실험으로 지지합니다.

### ⚙️ (c) 의사결정 함의

[D19b](#ref-D19b) 백본 계보 후보 목록에 "비디오 생성 모델(video world model)" 카테고리를 별도 행으로 추가하는 방안을 검토해야 합니다. 현재 D19b 후보들은 모두 VLM(PaliGemma, Eagle-2, Molmo, Qwen2.5-VL 등)이지만, VERA는 같은 동결 백본 + 구현체별 전문가 아키텍처에서 비디오 모델이 VLM을 대체할 수 있음을 보입니다. D21의 Stage 2 액션 전문가 학습 시, 우리 파이프라인에 Jacobian 기반 IDM을 보조 손실 항으로 추가해 구현체별 제어 정확도를 높이는 실험을 D21 Stage 2 설계 옵션으로 기록해 두십시오.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

IDM이 로봇 Jacobian을 직접 활용하는 설계이므로, 손가락 링크가 많고 접촉 역학이 복잡한 다지 손 조작에서는 Jacobian 근사 오차가 누적될 수 있습니다. 또한 self-play 데이터 수집 자체가 실환경 하드웨어를 요구하므로, 시뮬레이션에서 사전 훈련한 IDM이 실환경 마찰·질량 불확실성에 얼마나 민감한지 확인해야 합니다. 가장 빠른 확인은 VERA 공식 사이트(https://vera.csail.mit.edu)의 공개 코드로 Allegro 손 시뮬레이션 재현 실험을 돌리는 것입니다.

**VLA-Trace: Diagnosing Vision-Language-Action Models through Representation and Behavior Tracing**
[arXiv:2605.30117](https://arxiv.org/abs/2605.30117) · Haoyuan Shi, Xiancong Ren, Yingji Zhang, Qinfan Zhang · 2026-05-28 · adjacent field: 해석 가능성 / 메커니즘 분석 · source: Citation-Graph (GR00T N1 인용 + π0.5 인용)

### ✨ (b) 진정으로 새로운 점

π0.5와 OpenVLA를 대상으로 CKA(Centered Kernel Alignment) 체크포인트 드리프트 + 어텐션 녹아웃 + 롤아웃 행동 프로브를 결합한 **VLA 표현 진단 파이프라인**을 제시합니다. 핵심 발견: (1) 두 모델은 VLA 미세조정 중 서로 다른 모달리티별 적응 동역학을 보이며, (2) 레이어별 멀티모달 라우팅 전략이 완전히 다르고, (3) 두 모델 모두 시각적 궤적 생성은 우수하지만 세밀한 의미 추종에는 한계가 있습니다. 미래 방향으로 **"representation-preserving adaptation"** 을 명시합니다.

### ⚙️ (c) 의사결정 함의

[D19](#ref-D19)(d) LoRA 진입 트리거 기준에 정량적 측정치를 추가할 수 있습니다. 구체적으로, Stage 2(동결 + 액션 전문가 학습) 후 VLM 레이어별 CKA 드리프트 점수가 기준선 대비 **일정 임계값 이상** 상승하면 "백본 표현 불충분 + 적응 압력 존재"로 판단해 D19(d) LoRA 트리거 조건을 발동하는 방식입니다. 임계값 자체는 실험으로 교정해야 하지만 VLA-Trace의 오픈소스 CKA 구현체를 우리 학습 루프에 모니터링 훅으로 통합하는 작업은 D19 결정이 활성화되는 즉시 수행 가능합니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

진단 도구 자체가 새로운 학습 방법을 제안하지는 않으며, CKA 측정의 계산 비용이 체크포인트 수와 레이어 수에 비례해 증가합니다. CKA가 표현 드리프트를 잘 반영하는 지표인지 여부는 π0.5·OpenVLA 외 다른 VLA 아키텍처에서 아직 검증되지 않았습니다. 우리 스택(PaliGemma 기반)에서 동일 메트릭이 유의미한 신호를 주는지 확인하려면 Stage 2 학습 중 매 N 스텝마다 CKA를 계산하는 파일럿 실험이 필요합니다.
