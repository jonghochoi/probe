- **공동 사전학습 배합 참조** — 로봇 조작 + 에고센트릭 + 합성 + 내비게이션 데이터 믹스가 다중 구현체 사전학습 배합의 기준점 제공
- **VLM 역할 분리 공유** — DiT 액션 디코더가 우리 플로우 매칭 헤드와 유사하게 VLM을 의미 역할에 머물게 하는 설계 공유

### (d) 먼저 확인할 점

- **데이터 비공개 우려** — Qwen2.5-VL은 범용 VL 이해용 사전학습 모델, 로봇 궤적 데이터(DROID + MolmoAct + 자체 수집)는 비공개 가능성 높음

### (b) 핵심 기여

- **동결 표현을 가치 신호로 재활용** — 오프라인 크리틱이 VLM 인식 토큰(cognition tokens) + 액션 청크를 입력으로 받아 행동-조건부 가치 추정(action-conditioned value guidance) 수행
  - 기존 VLA RL 사후학습은 시각 관찰만으로 가치 추정, BORA는 동결 VLM 표현을 직접 활용
- **경량 온라인 적응** — 온라인 단계에서 VLA 기저 동결, HiL chunk-wise 잔차 어댑터(residual adapter)만 최적화
- **수치** — 5개 실환경 손재주 조작 태스크에서 평균 성공률 +33% p, 미보인 객체 일반화 +43% p

### (c) 시사점

- **RL 사후학습 진입 레시피** — 인-분포 플래토 + 일반화 손실 발생 시, LoRA를 풀기 전 오프라인 크리틱 구축 → 온라인 잔차 어댑터 미세조정 순서로 백본 보존 상태에서 RL 이득 확보 가능
- **어댑터 설계 참조** — RL 사후학습 단계 진입 시 chunk-wise 잔차 어댑터 구조 우선 참조 후보
- **수집 파이프라인** — VLM 인식 토큰 + 액션 청크 결합 입력과 개입 보상(intervention-driven reward) HiL 수집을 표준 절차 후보로 검토

### (d) 먼저 확인할 점

- **데모 분포 의존** — 오프라인 크리틱 품질이 오프라인 시연 데이터셋 분포에 직접 의존, 초기 데모 불균일·부족 시 VLM 인식 토큰의 가치 추정 정보량 부족 우려
- **드리프트 측정 확인** — VLA-Trace([arXiv:2605.30117](https://arxiv.org/abs/2605.30117))의 CKA(Centered Kernel Alignment) 체크포인트 드리프트로 오프라인 크리틱 학습 전후 VLM 표현 이동량 측정
- **보존 훼손 판단** — 드리프트가 크면 백본 보존 실질 훼손으로 보고 LoRA 전환 트리거 조기 발동 필요

## 🥉 논문 3 — 우선순위 ★

**Turning Video Models into Generalist Robot Policies**
[arXiv:2605.27817](https://arxiv.org/abs/2605.27817) · Sizhe Lester Li, Evan Kim, Xingjian Bai, Tong Zhao, Tao Pang, Max Simchowitz, Vincent Sitzmann (MIT CSAIL) · 2026-05-27 · source: Citation-Graph (π0.5 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D19b](https://img.shields.io/badge/D19b-d97706.svg)](#ref-D19b) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **동결 비디오 모델 + 구현체별 모듈** — 비디오 플래너(video world model)를 구현체에 무관하게 완전 동결, Jacobian 기반 역동역학 모델(IDM)만 구현체별 훈련 (VERA: Video-to-Embodied Robot Action Model)
  - 동일 비디오 플래너 가중치로 Panda 팔 zero-shot 조작 + 16-DoF Allegro 손 정육면체 재배향 모두 수행
  - IDM은 자기 탐색(self-play) 데이터만으로 훈련 가능, 레이블 불필요
- **진정한 신규성** — "완전 동결 백본 + 구현체별 전문가" 패턴이 극도로 고차원인 손 제어에서도 zero-shot 이전 가능함을 외부 실험으로 지지

### (c) 시사점

- **백본 계보 카테고리 확장** — 비디오 생성 모델이 동결 백본 + 구현체별 전문가 아키텍처에서 VLM을 대체할 수 있음, 백본 후보 목록에 video world model 카테고리 추가 검토
- **보조 손실 옵션** — 액션 전문가 학습 시 Jacobian 기반 IDM을 보조 손실 항으로 추가해 구현체별 제어 정확도를 높이는 실험 옵션 기록

### (d) 먼저 확인할 점

- **Jacobian 근사 오차** — IDM이 로봇 Jacobian을 직접 활용, 손가락 링크가 많고 접촉 역학이 복잡한 다지 손 조작에서 근사 오차 누적 우려
- **self-play 하드웨어 요구** — 데이터 수집 자체가 실환경 하드웨어 요구, 시뮬레이션 사전 훈련 IDM이 실환경 마찰·질량 불확실성에 얼마나 민감한지 확인 필요
- **확인 경로** — VERA 공식 사이트(https://vera.csail.mit.edu) 공개 코드로 Allegro 손 시뮬레이션 재현
