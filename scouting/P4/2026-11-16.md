## 🥇 논문 1

**LeWAM: Latent evolving World Action Model**
[arXiv:2609.27455](https://arxiv.org/abs/2609.27455) · Xueji Fang, Boqiang Duan, Hua Wu 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R3 · N2 · M2 · Real3 · Repro2 — arXiv comment "https://github.com/XuejiFang/LeWAM"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-c7edee.svg)](#ref-P4) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS) [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB)

### (b) 논문 요지

- I-JEPA 임베딩 공간에서 행동과 미래를 함께 예측하는 WAM
- **문제** — 영상 확산 모델(VDM) 기반 WAM에서 시각 표현이 행동 생성의 병목이 되는 점
  - VDM 기반 WAM은 VAE로 압축한 잠재를 대형 영상 확산 백본에 통과시켜야 쓸 만한 특징을 얻으므로 성능과 학습 비용이 영상 생성 사전학습에 묶임
  - 배포 때는 미래 영상을 만들지 않고 현재 관측에서 행동을 바로 내는 WAM이 늘어, 학습 때만 쓰는 시각 표현의 적합성이 더 중요해짐
- **기존 한계** — 시각 표현이 행동 생성에 미치는 영향을 같은 조건에서 가른 연구 부재
  - 기존 인코더 비교는 대상 표현 수가 적거나 VLA 특징에 덧붙이는 방식으로만 평가
  - 기존 잠재 월드 모델은 예측 임베딩을 목표 조건 계획에 쓰고 행동 생성에는 직접 쓰지 않음
  - VLA와 VDM 기반 WAM은 서로 다른 시각 경로(VLM 특징, VAE 잠재)를 써 직접 비교 불가
  - 재구성·자기지도·비전-언어 정렬·영상 예측 등 서로 다른 목적으로 사전학습한 동결 인코더를 같은 행동 예측기에 넣어 맞댄 연구 없음
- **핵심 방법** — 동결 I-JEPA 임베딩에 행동 생성과 미래 임베딩 예측을 한 예측기로 학습하고 선호 기반 정제 단계를 덧붙이는 구성
  - 현재 임베딩, 노이즈 낀 행동과 시연 행동 토큰, 미래 임베딩 질의를 한 토큰열로 묶고 구조화 어텐션 마스크로 정보 누출 차단
  - AdaFuse — 동결 인코더의 층별 표현을 특징 차원마다 적응적으로 결합
  - DemoDPO — 시연으로 동결 기준 정책이 낸 행동 후보 사이의 선호를 만들어 추가 환경 상호작용 없이 오프라인 정제
  - 추론 때는 시연 행동과 미래 질의를 빼고 현재 관측과 과제 맥락만으로 행동 생성
- **차별점** — 영상 확산 백본 없이 JEPA 임베딩 공간에서 행동 생성과 환경 진화 예측을 함께 수행
  - 정책 학습 틀과 학습 절차를 고정한 채 인코더만 바꿔 표현의 기여를 분리
- **핵심 기여** — 표현 비교 분석, LeWAM 구조, DemoDPO
  - 통제 비교(과제 ID 조건) — Wan2.2 VAE 10.81%로 최하위, 대형 인코더 중 V-JEPA2-Large 최고, ImageNet-22K만 쓴 I-JEPA-Huge가 V-JEPA2-Huge보다 우수
  - 깊이·분할 프로브에서도 I-JEPA-Huge가 개별 인코더 중 최고, Wan2.2 VAE 최저
  - 미래 임베딩 직접 예측 87.02%, 플로우 매칭 방식 86.21%, 행동 단독 86.17%
  - AdaFuse 단독 86.17%에서 86.88%, 미래 예측까지 더하면 90.69%
  - DemoDPO 적용 시 RoboTwin 2.0 50개 과제 평균 92.28%(clean 93.14%, randomized 91.42%), 학습 가능 파라미터 0.4B, 로봇 사전학습 없음
  - AgileX 듀얼 Piper 실물 3개 과제(과제당 50회) 과제 진행도가 DemoDPO로 81.1%, 58.3%, 50.7%에서 84.9%, 60.7%, 53.0%로 상승
- **가치** — 대형 영상 생성 사전학습 없이 WAM을 구성할 수 있다는 근거와 표현 선택 지침

### (c) 시사점

- 예측 임베딩이 VAE 잠재보다 행동 생성에 유리하다는 통제 비교 수치 확보
- 같은 예측기에서 인코더만 바꾼 수치라 잠재 공간 예측 선택의 근거로 쓸 수 있음
- 미래 임베딩 예측을 학습 때만 쓰고 추론은 행동만 내는 구조라 배포 비용 부담 낮음
- 코드가 공개돼 있어 JEPA 보조 예측 구성을 자체 정책에 붙여 보는 비용 낮음
- 직접 회귀가 플로우 매칭보다 높게 나온 차이는 작아 예측 방식 선택의 근거로는 약함

### (d) 먼저 확인할 점

- RoboTwin 2.0 결과가 최상위 VLA·WAM과 비슷한 수준이라는 서술이어서 우위 주장은 아님
- 반복 시드와 분산이 본문에 없어 0.5–1점대 차이의 유의성 미확인
- 실물 지표가 성공률이 아니라 마일스톤 기반 과제 진행도이고 DemoDPO 이득도 2–4점 규모
- 실물 평가는 AgileX 한 플랫폼의 3개 과제에 한정
- 코드는 보충 자료로 제공되고 실물 데이터셋은 공개 예정 단계
- 표현 비교가 과제 ID 조건에서 이루어져 언어 조건 설정에서도 같은 순위인지 미확인

## 🥈 논문 2

**Devol-ONE: One Autoregressive Mixture of Transformers to Unify Vision-Language-Action and Latent World Modeling**
[arXiv:2609.32193](https://arxiv.org/abs/2609.32193) · Hongyi Cai, Yi Herng Ong, Tingshiuan C. Wu 외 · arXiv preprint · source: citation-graph

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-c7edee.svg)](#ref-P4) / [![D8XB](https://img.shields.io/badge/D8XB-d97706.svg)](#ref-D8XB) [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 비전-언어, V-JEPA 동역학, 행동을 한 자기회귀 MoT로 통합
- **문제** — 정책이 과제 추론, 미래 상태 예측, 행동 생성을 한 구조 안에서 함께 할 수 있는지가 질문
  - VLA는 장면을 한 번 인코딩해 곧바로 제어로 사상할 뿐 행동에 따른 환경 변화를 모델링하지 않음
  - WAM은 미래 영상 생성의 추론 비용이 크고 명시적 텍스트 추론이 없음
- **기존 한계** — 기존 WAM 설계는 예측과 정책 학습이 구조적으로 분리
  - 계단식 설계는 미래 프레임이나 하위 목표를 만든 뒤 별도 역동역학·목표 조건 모듈로 행동 복원
  - 결합 설계는 한 백본에서 미래 영상 토큰과 행동 토큰을 함께 디노이징하지만 픽셀 공간 생성의 추론 비용을 짐
  - VLA-JEPA는 목표 잠재를 실제 미래 프레임에서 만들어 학습 때만 쓸 수 있고, 추론 때는 모델 자신의 잠재 예측에 의존해 학습-추론 불일치(노출 편향과 유사) 발생
- **핵심 방법** — 파라미터가 분리된 세 흐름을 층마다 잇는 MoT
  - VL 흐름 — 과제 관련 의미 특징 제공
  - 동역학 흐름 — V-JEPA 사전학습 백본으로 초기화해 언어 지시 아래 미래 잠재 상태를 자기회귀로 예측
  - 행동 전문가 — 확산 방식으로 연속 행동 청크 디노이징
  - Layerwise Joint MoT Block — 모든 트랜스포머 층에서 행동 전문가가 의미 특징과 예측 동역학을 함께 참조
  - ALRT — 예측기와 행동 전문가를 모델이 스스로 만든 K단계 잠재 롤아웃에 노출해 학습
- **차별점** — 예측 출력만 넘기는 연결 대신 층 단위 공동 어텐션으로 예측과 행동 생성을 같은 계산에 묶음
  - 마지막 층 특징만 행동 전문가에 넣는 방식과 구분됨을 직접 비교로 확인
- **핵심 기여** — 통합 구조, 롤아웃 학습, 분포 변화와 실물 검증
  - LIBERO 평균 98.4%, Long 스위트 97.0%(Fast-WAM 95.2%, VLA-JEPA 95.8%, OpenVLA-OFT 94.5%)
  - 미세조정 없는 LIBERO-Plus 제로샷 71.4%
  - RoboTwin 2.0 34개 과제 평균 clean 61.1%, randomized 63.7%
  - 행동 전문가 조건 ablation — VL 단독 96.0%, JEPA 단독 96.9%, 마지막 층 결합 97.0%, 층별 공동 어텐션 98.4%(Long 97.0% 대 92.1%)
  - 예측 길이 4, 6, 8프레임에서 평균 96.8%, 97.5%, 98.4%
  - Flexiv 단일 팔·양팔 실물 과제(과제당 20회) 평균 성공률이 π0.5, π0 포함 모든 기준선보다 높음
- **가치** — 픽셀 영상 생성 없이 잠재 동역학 예측을 정책 내부 계산에 묶는 통합 구성의 근거

### (c) 시사점

- 통합 구조와 마지막 층 결합 구조를 같은 조건에서 직접 대조한 수치 확보
- 마지막 층 결합은 저자가 GR00T류 구성과 같다고 설명한 방식이며 Long 스위트에서 격차가 큼
- 의미 흐름과 동역학 흐름이 서로 보완적이라는 ablation 수치가 구성 결정의 근거
- 픽셀 WAM 대비 분포 변화 강건성을 같은 벤치마크에서 비교한 점이 참고 기준

### (d) 먼저 확인할 점

- 코드 저장소와 공개 약속이 없어 재현 경로 없음
- RoboTwin 2.0 34개 과제 평균 61.1%(clean), 63.7%(randomized)로 LIBERO 점수에 비해 낮아 과제 구성과 기준선 대비 위치 확인 필요
- 부록에 정밀 배치나 세밀한 추론이 필요한 과제에서 실패가 몰린다는 한계 서술
- ALRT 단독 ablation 수치는 본문 ablation에서 확인되지 않음
- 실물 결과는 Flexiv 플랫폼 계열에 한정
- LIBERO 점수가 포화 구간이라 98.4%와 기준선 간 차이가 구조 효과인지 설정 효과인지 분리 필요

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음, 초록 "Additional videos are available on our website: jointmdf.github.io" 프로젝트 페이지뿐

### (a) 관련 Pillar / Decision

### (b) 논문 요지

- 관측 인코더를 확산 백본과 끝단 학습하는 시각-촉각 WAM
- **문제** — 나사 조이기, 너트 결합처럼 접촉이 지배하는 과제에서 행동의 결과(접촉 형성, 힘 전파)를 예측하는 모델이 필요
  - 시각만으로는 접촉 단서, 힘 피드백, 고유수용감각을 충분히 못 잡음
- **기존 한계** — 기존 WAM의 두 가지 한계 지적
  - 대부분 시각 관측 중심이라 촉각과 힘 정보가 거의 탐색되지 않음
  - 픽셀 재구성이나 자기지도 시각 목적으로 사전학습한 동결 인코더에 의존해 표현이 로봇 제어와 정렬된다는 보장 없음
  - 촉각은 범용 사전학습 인코더가 더 드묾
  - 단순 끝단 미세조정은 인코더와 확산 백본이 함께 적응해 디노이징은 쉽지만 제어에는 덜 유용한 잠재로 붕괴
- **핵심 방법** — 인코더를 확산 기반 WAM과 함께 학습하는 다중 과제 구성
  - 기존 Multimodal Diffusion Forcing(MDF) 위에서 정책 학습, 행동-관측 공동 예측, 순동역학, 역동역학 목적을 혼합
  - 선택적 그래디언트 역전파 — 각 모달리티 자체 디노이징 손실의 그래디언트를 막고 교차 모달 예측 신호로 잠재 공간 학습
  - 정책, 월드-행동, 순동역학, 역동역학 구조화 질의 사용
- **차별점** — 동결 잠재 공간에서 동역학을 모델링하지 않고 인코더 자체를 WAM 목적으로 미세조정
  - 붕괴를 막는 장치로 선택적 그래디언트 흐름 도입
- **핵심 기여** — 구조화 질의와 선택적 그래디언트 흐름의 효과, 시뮬레이션과 실물 결과
  - 시뮬레이션 5개 과제(방법당 150회) 평균 86.9%, 적응한 MDF 68.4%, 선택적 학습만 추가 시 71.5%
  - 모든 인코더에 전체 그래디언트를 흘리는 방식 64.1%, SIGReg 정규화 추가 58.1%
  - 동결 ViT 58.7%, 동결 Sparsh 58.9%, UWM 74.2%
  - 정책 단독 학습 78.9%, 촉각 입력 Diffusion Policy 68.7%
  - Franka Research 3와 GelSight mini 실물 2개 과제(과제·정책 조합당 20회) — 볼트 조이기 80%(16/20)로 UWM 50%, 동결 ViT 30%, 너트 결합 40%(8/20)로 UWM 25%, 동결 ViT 15%
- **가치** — 촉각처럼 사전학습 인코더가 드문 모달리티에서 제어에 맞는 표현을 WAM 안에서 얻는 경로 제시

### (c) 시사점

- 동결 인코더 대비 공동 학습 표현의 이득을 시뮬레이션과 실물에서 함께 확인한 수치

- 픽셀 수준 예측이 제어에 불필요한 재구성 부담을 준다는 해석을 뒷받침하는 UWM 대비 수치
- 촉각 센서가 있는 플랫폼이 전제이고 공개 산출물 없음

### (d) 먼저 확인할 점

- 실물 평가가 Franka 한 플랫폼의 2개 과제로 한정되고 너트 결합 성공률 40%로 절대 수준 낮음
