## 🥇 논문 1 — 우선순위 ★★★

**Does VLA Even Know the Basics? Measuring Commonsense and World Knowledge Retention in Vision-Language-Action Models**
[arXiv:2606.19297](https://arxiv.org/abs/2606.19297) · Nikita Kachaev, Andrey Moskalenko, Matvey Skripkin, Nikita Kurlaev, Daria Pugacheva · 2026-06-17 · source: Keyword Sweep (catastrophic forgetting + VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **공백 규명** — VLM → VLA 파인튜닝 후 상식·사실 지식이 얼마나 보존되는지가 체계적으로 측정된 바 없었음; 기존 평가는 조작 성공률만 측정하여 지식 손실과 저수준 제어 실패를 혼동
- **Act2Answer 프로토콜** — VLM 지식 벤치마크를 VLA 평가 형식으로 변환하는 경량 프로토콜
  - 각 질문 → 단일 탁상 에피소드로 변환: 로봇이 물체 배치 액션(action-through-answering)으로 답변
  - 지식 실패와 저수준 제어 실패를 분리 측정; 제어 오차 없이 지식 보존량만 격리 추적 가능
- **핵심 발견** — 표준 VLA 파인튜닝(로보틱스 데이터로 전체 파인튜닝) 후 상식·사실 지식 심각하게 저하; 로보틱스 데이터 파인튜닝이 VLM 사전지식을 침식한다는 정량 근거 제공
- **실험 범위** — 실제 탁상 환경에서 VLA 에이전트를 통한 지식 측정; 제어된 단일 액션 에피소드

### (c) 시사점

- **"완전 VLM 동결" 원칙의 외부 정량 근거 확보** — 파인튜닝이 VLM 내 상식·사실 지식을 침식한다는 실험적 증거; 동결 전략이 단순한 GPU 절약 이상의 이유임을 직접 뒷받침
- **Stage 2/3 진입 전 사전지식 체크리스트 후보** — Act2Answer를 동결-→-부분파인튜닝 전환 검토 시 "VLM prior 보존 상태 확인" 기준으로 채택 가능; 동결 vs LoRA 전환 시 지식 보존량 비교 지표
- **D20 보존 전략의 정량 평가 도구** — 보존 전략별(완전 동결·conservative SFT·LoRA) 지식 손실 분포 측정에 Act2Answer 적용 가능; 보존 전략 선택의 객관적 비교 기준 확보

### (d) 먼저 확인할 점

- **지식 손실 → 조작 성공률 연결 미명시** — Act2Answer가 측정하는 상식·사실 지식 손실이 실제 로봇 조작 성공률 저하로 직접 이어지는지 인과 연결 데이터 초록 수준 불확인
- **프로토콜 범위의 편향성** — 물체 배치 액션으로 변환 가능한 질문 유형에 국한; 암묵적 절차 지식(procedural knowledge) 또는 공간 추론 지식이 과소 측정될 가능성
- **확인** — 파인튜닝 방법별(전체 FT vs 동결 vs LoRA) 지식 보존 점수 비교 데이터를 초록 이후 본문에서 확인; LIBERO·RoboTwin에서 동일 정책의 Act2Answer 점수와 조작 성공률 상관 측정

## 🥈 논문 2 — 우선순위 ★★

**Motion-Focused Latent Action Enables Cross-Embodiment VLA Training from Human EgoVideos**
[arXiv:2606.18955](https://arxiv.org/abs/2606.18955) · Runze Xu, Yiluo Zhang, Jian Wang, Yu Wang, Jincheng Yu · 2026-06-17 · source: Keyword Sweep (pretraining data + egocentric)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **전제 전환** — 기존 VLA 사전학습은 액션 레이블이 있는 로봇 궤적에 의존; 이 논문은 레이블 없는 인간 에고센트릭 비디오에서 VLA 사전학습용 액션 prior를 직접 추출하는 방법 제안
- **Hybrid Disentangled VQ-VAE** — 동작 다이나믹스와 환경 배경을 분리하는 핵심 아키텍처
  - **동작 집중 잠재 액션(motion-focused latent action)** 추출: 배경 변화에 독립적인 행동 표현 확보
  - 크로스-구현체 학습 가능: 인간 손 동작과 로봇 엔드이펙터 동작을 잠재 공간에서 공통 표현으로 정렬
- **레이블-없는 대규모 활용** — 에고센트릭 인간 비디오의 다양한 환경적 편차를 사전학습 코퍼스로 직접 활용; 로봇 데모 수집 없이 다양성 확장 가능
- **크로스-구현체 사전학습** — 인간→로봇 구현체 도메인 전이를 잠재 공간 정렬로 해소

### (c) 시사점

- **레이블-없는 에고센트릭 영상의 D22 활용 경로** — D22 열린 변수("에고센트릭 중심 코퍼스")의 수집 범위를 레이블 없는 인터넷 규모 에고센트릭 영상으로 확장하는 구체 방법론; 로봇 데모 병목 없이 코퍼스 규모 비선형 확장 가능
- **D21 Stage 1 코퍼스 구성 다변화** — Stage 1(추가 사전학습)에서 레이블 없는 에고센트릭 영상 + 잠재 액션 추출을 추가 데이터 소스로 도입하면 로봇 데모 대비 수집 단가 대폭 절감
- **이전 보고의 3D 키포인트 접근과 보완 관계** — 직전 Dexterous Point Policy(2606.10614, 06-17 보고)가 "3D 키포인트로 인간-로봇 정렬" 접근이라면, 이 논문은 "잠재 공간 디컨탱글먼트로 정렬"; 두 경로가 D22 코퍼스 활용의 서로 다른 가설

### (d) 먼저 확인할 점

- **잠재 액션의 다운스트림 기여 정량화 필요** — 잠재 액션 prior를 주입한 VLA의 성공률 향상 폭(vs. 레이블 없는 인간 영상 미사용 기준선) 미확인; 초록 수준에서 벤치마크 수치 미명시
- **다지 손 동작 분리 적합성** — Hybrid VQ-VAE의 동작/배경 분리가 손가락 세밀 동작(핀치·그립 전환)을 충분히 포착하는지 미검증; 복잡한 다지 조작에서 배경과 손 동작이 상관될 때 분리 품질 저하 우려
- **확인** — 에고센트릭 영상 대규모 전처리 시 VQ-VAE 추론 속도 측정; LIBERO에서 잠재 액션 사전학습 유무에 따른 성공률 비교; 인핸드 접촉 집약적 태스크에서 잠재 액션 표현력 시각화

**Qwen-RobotManip Technical Report: Alignment Unlocks Scale for Robotic Manipulation Foundation Models**
[arXiv:2606.17846](https://arxiv.org/abs/2606.17846) · Haoqi Yuan, Zhixuan Liang, Anzhe Chen, Ye Wang, Haoyang Li · 2026-06-16 · source: Keyword Sweep (pretraining data + egocentric)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **핵심 가설** — 언어·멀티모달 파운데이션 모델이 이질적 데이터 정렬(alignment) 후 스케일 확장으로 강력한 일반화를 달성한 것처럼, 로봇 조작 데이터도 동일한 레시피 적용 가능
- **Qwen-RobotManip** — Qwen-VL 위에 구축된 VLA 파운데이션 모델
  - 로봇 조작 데이터의 이질성 (분산 수집·낮은 다양성·높은 수집 비용) 을 통일 공식으로 정렬
  - 정렬 우선(alignment-first) 후 스케일 확장(scale-after) 레시피
  - 크로스-구현체 이질적 데이터를 통합 표현으로 매핑하는 정렬 기법 포함
- **Qwen 계보 스케일링 실험** — Qwen-VLA(2605.30280, 현재 핀 논문) 이후 동일 팀의 로봇 조작 특화 확장; 텍스트→행동 사전학습 + 이질적 데이터 정렬의 결합 효과 정량 제시

### (c) 시사점

- **D19 Qwen 계보 비교 데이터 확보** — Qwen-RobotManip이 공개 벤치마크(LIBERO·RoboTwin 2.0 등)에서 달성하는 성능은 π0 계보(PaliGemma × π0 mix)와 Qwen 계보(Qwen-VL × 이질 데이터 정렬) 간 비교 기준점
- **D21 "정렬 우선" 원칙 검토 근거** — 이질적 로봇 데이터를 스케일 이전에 먼저 정렬해야 한다는 Qwen-RobotManip의 주장은 D21 Stage 1 코퍼스 구성에서 "혼합 전 정렬 전처리" 단계 추가 검토 근거
- **D22 이질 데이터 정렬 방법론 참조** — 이질적 구현체·동작 공간의 통일 공식화 방법이 D22 에고센트릭-중심 코퍼스와 로봇 데이터의 혼합 실험 설계에 선행 정보

### (d) 먼저 확인할 점

- **기술 보고서 특성상 독립 재현 부재** — 내부 평가 기준 위주일 가능성; LIBERO·RoboTwin 2.0 등 공개 기준선 직접 비교 수치가 본문에 포함되는지 확인 필요
- **"데이터 정렬" 기법 구체성 미확인** — 어떤 정렬 기법(재레이블링·임베딩 정규화·공동 코딩)을 사용하는지 초록에 미명시; 방법론의 재현 가능성 본문 확인 필요
- **인핸드 다지 조작 평가 범위 불명** — 기술 보고서 평가가 그리퍼 기반 탁상 조작 집중 가능성; 손가락 세밀 제어 태스크에서 Qwen 계보 적합성 미확인

## 🌱 논문 4 — 인접 분야 픽

**DO AS I DO: Dexterous Manipulation Data from Everyday Human Videos**
[arXiv:2606.19333](https://arxiv.org/abs/2606.19333) · Bhawna Paliwal, Haritheja Etukuru, William Liang, Pieter Abbeel, Nur Muhammad Mahi Shafiullah · 2026-06-17 · adjacent field: 단안 RGB 3D 손 복원 + 구현체 재타겟팅 — 인간 비디오 → 다지 로봇 손 데이터 변환 파이프라인 · source: Keyword Sweep (pretraining data + egocentric)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **데이터 병목 직접 해소** — 다지 로봇 손 조작 학습의 최대 병목(대규모 로봇 시연 수집 비용)을 인터넷 규모 인간 비디오로 대체하는 알고리즘 제안
- **DO AS I DO** — 단안 RGB 인간 비디오만으로 다지 로봇 손 궤적을 복원·재타겟팅
  - 손-물체 상호작용 기하 복원 (monocular RGB → 3D hand-object geometry)
  - 인간 손 → 다지 로봇 손 구조 재타겟팅 (구현체 격차 해소)
  - depth 센서·마커·보정 장비 불필요 — 순수 RGB 단일 카메라 기반
- **Abbeel 그룹** (Berkeley) — 실환경 다지 로봇 플랫폼 검증 가능성 높음
- **규모 확장 경로** — 스마트폰·웹캠으로 촬영된 일상 인간 비디오가 잠재적 다지 조작 데이터 소스로 전환

### (c) 시사점

- **D22 에고센트릭 코퍼스 데이터 파이프라인 후보** — 단안 RGB 인간 비디오 → 다지 손 시연 변환 파이프라인이 확립되면 D22 에고센트릭 코퍼스 구성 시 로봇 시연 수집 없이 다지 조작 데이터 규모 확장 가능; 수집 단가 기존 원격조작 대비 극적 절감 예상
- **depth-free 3D 손 포즈 복원 가능성** — 직전 Dexterous Point Policy(06-17 보고)가 "3D 키포인트 파이프라인"을 요구했다면, DO AS I DO는 depth 없이도 3D 복원이 가능함을 시사; D22 코퍼스 수집 조건을 "RGB 카메라 한 대"로 낮출 수 있는 근거
- **인핸드 다지 조작 데이터 수집 전략 전환점** — 다지 손 원격조작(며칠~주 단위 수집)을 대체하는 저비용 데이터 생성 경로; D22 open ablation 실험에서 "로봇 데모" vs "인간 비디오 파이프라인" 비교 실험 설계 가능

### (d) 먼저 확인할 점

- **단안 RGB 복원 정밀도 한계** — 단안 깊이 불확실성이 3D 손 자세 오차로 이어지며, 다지 로봇 제어에서 관절별 위치 오차 허용 범위(~mm급) 충족 여부 미확인
- **물체 포즈 의존도** — 손-물체 상호작용 복원이 물체 형상·포즈 추정 정확도에 의존; 반사 표면·투명 물체·비구조 형태에서 복원 실패 가능
