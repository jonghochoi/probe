## 🥇 논문 1 — 우선순위 ★★★

**Generalizable VLA Finetuning via Representation Anchoring and Language-Action Alignment (Anchor-Align)**
[arXiv:2607.13429](https://arxiv.org/abs/2607.13429) · Dwip Dalal, Shivansh Patel, Chahit Jain 외 7인 · source: citation-graph (π0 인용)

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여
- BC(behavior cloning) 파인튜닝이 사전학습 VLM 표현을 점진적으로 덮어써 시각·의미 일반화를 훼손하는 문제 지적
- 웹 이미지-텍스트 co-training 만으로는 문제 미해결 — 언어 손실과 액션 손실이 서로 다른 관측에 적용돼 언어-액션 불일치 발생을 실증적으로 노출, 표준 조작 벤치마크는 이를 드러내지 못함
- **Vision-Language Anchoring**(고정 VLM 사본에서 레이어별 표현 증류) + **Language-Action Alignment**(액션 타겟을 이산 모션-방향 라벨로 변환해 언어·액션 공동 학습) 두 목적함수 결합 제안
- 실물 xArm7 로봇에서 서로 다른 두 VLA 아키텍처 모두 성공률 대폭 개선 (28%→54%, 37%→60%), LIBERO-PRO / LIBERO-Plus / CALVIN 시뮬레이션에서도 OOD·지각 강건성·장기 제어 일관 개선

### (c) 시사점
- 사전학습 표현 보존과 액션 학습이 근본적으로 상충하지 않음을 실물 로봇으로 실증 — 보존 손실 추가만으로 둘 다 개선 가능성 시사
- 표준 벤치마크가 놓치는 언어-액션 불일치를 드러내는 평가 축 제시 — 내부 평가 설계 참고 가능
- 저장소 공개(GitHub 링크 arXiv 페이지에서 확인)로 두 손실함수 조합의 직접 이식·검증 가능

### (d) 먼저 확인할 점
- 결과가 xArm7 기반 두 아키텍처에 국한 — 다른 하드웨어·백본 조합에서 재현 여부 미검증
- Language-Action Alignment 이 요구하는 이산 모션-방향 라벨링이 연속 액션 표현과 어떻게 결합되는지 원문에서 불명확
- 저장소 완성도(학습 스크립트·체크포인트 포함 여부)는 arXiv 링크로 존재만 확인 — 코드 내용 자체는 미검토
