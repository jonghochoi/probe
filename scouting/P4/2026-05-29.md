## 🥇 논문 1 — 우선순위 ★★★

**What Frozen VLAs Already Know About Success: A Probing Study of Value-Like Structure in Foundation Robot Policies**
[arXiv:2605.28527](https://arxiv.org/abs/2605.28527) · Jiachen Zhang, Junnan Nie, Junyi Lao, Wei Cheng, Chenghao Liu, Jiaxin Jiang, Songfang Huang · 2026-05-27 · source: citation-graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **핵심 가설 검증** — 동결된 VLA backbone이 미션 성공을 예측하는 정보를 이미 보유함을 실험으로 입증
  - 선형 프로브(linear probe)로 frozen OpenVLA, π0.5, DINOv2, CLIP 특징 벡터에서 Monte-Carlo 성공-목표값 복원
  - π0.5 프로브가 동일 태스크·동일 시간 단계 비교에서 약 92% 쌍별 순위 정확도(pairwise ordering accuracy) 달성
- **진정한 신규성** — VLA 모방 학습 목적함수는 보상·성공 여부를 요구하지 않음에도 frozen backbone 잠재 표현에 성공 예측 정보가 자연 형성된다는 직접 인과 검증
  - 기존 COAST([arXiv:2605.17144](https://arxiv.org/abs/2605.17144), 직전 리포트)는 '조향을 위해 표현을 이용한다'는 관점, 본 논문은 '그 표현에 무엇이 내재해 있는가'를 체계적으로 해부
  - 태스크·시간 단계 단축키(shortcut) 제거한 동일 조건 비교 설계(same-task, same-timestep matched comparison)
  - 추론시점 선택자(test-time selector)로 push-plate 태스크 성공률 26.7% → 44.3% 개선하는 행동 검증

### (c) 시사점

- **동결 유지 근거 강화** — 동결 backbone에 풍부한 성공-예측 구조가 내재함을 확인, prior 보존의 이유가 단순 망각 방지가 아닌 내재 구조 보호임을 구체화
- **저비용 진단 도구 확보** — 성공·실패 trajectory 소량 + 선형 회귀로 backbone 표현 충분성을 점검하는 체크포인트 운용 가능

### (d) 먼저 확인할 점

- **분포 의존성** — 프로브가 LIBERO-Goal 시뮬레이션 데이터로 학습·검증됨
  - 실제 로봇 인핸드 조작처럼 접촉 집약적 도메인에서는 성공-예측 신호가 훨씬 약할 수 있음, 실물 환경에서 동일 프로브 재학습해 정확도 비교 필요
- **모델 특이성** — 선형 프로브 성능이 π0.5 특징에서 가장 높음, PaliGemma 기반 체크포인트에서도 동일 수준이 나타나는지 확인 필요 (PaliGemma 특징 프로브는 CLIP/DINOv2 대비 성능 상이 가능)
- **최소 샘플 수** — 논문이 최소 데이터 요구량 미명시, 초기 단계 성공 예시가 희소하므로 5개 이하 성공 trajectory로도 신뢰 신호를 주는지 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Rethinking VLM Representation for VLA Initialization**
[arXiv:2605.25802](https://arxiv.org/abs/2605.25802) · Weifeng Lin, Siyuan Huang, Hao Li, Tingwei Chen, Ruichuan An, Xinyu Wei, Jianbo Liu, Hongsheng Li · 2026-05-25 · source: citation-graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D19b](https://img.shields.io/badge/D19b-d97706.svg)](#ref-D19b) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **초기화 비교** — VLM → VLA 초기화 방식으로 LoRA와 Full Finetune을 체계적으로 비교
  - "사전학습 표현을 과도하게 재형성하면 VLA 초기화가 약해진다(overly reshaping the pretrained representation can weaken VLA initialization)"는 결과 제시
  - "원래의 사전학습 VLM 표현이 액션 성능의 핵심 원천"이라는 발견 — 표현 품질이 VLA 성능 상한 결정
  - 단계적 LoRA 기반 학습(staged LoRA-based training)이 가장 강력한 VLA 초기화 제공
- **진정한 신규성** — 초기화 문제를 세 축(embodied VQA 능력 수준, 파라미터 업데이트 전략, 로봇 데이터 사전학습)의 통제된 팩토리얼 실험으로 분해
  - embodied VQA 적응이 항상 이득은 아니며(하류 병목 의존), 능력 도메인 이득이 단순 합산되지 않는 비선형 상호작용 보고
  - LoRA가 Full FT보다 VLA 초기화 품질에서 우월 — 주요 VLA 논문(OpenVLA 등)의 Full FT 권고와 정면 배치

### (c) 시사점

- **동결·LoRA 정당성** — 동결 또는 LoRA 제한이 계산 효율뿐 아니라 품질 측면에서도 타당함을 뒷받침
- **계보 선택 기준** — 사전학습 표현 품질이 VLA 성능 상한을 결정하므로 backbone 후보 평가 시 표현력을 우선 기준으로 삼을 근거
- **LoRA 레시피 참조** — LoRA 진입 시 rank·target module 설정의 출발점 제공

### (d) 먼저 확인할 점

- **평가 벤치마크 의존성** — 실험이 표준 VLA 벤치마크(구체 미공개, 주로 시뮬레이션 추정) 기반, 접촉 집약적 인핸드 조작처럼 시각-촉각 통합 태스크에서 LoRA 우월성 유지 여부 확인 필요
- **사전학습 corpus 의존성** — "원래 VLM 표현이 핵심"이라는 주장은 VLM 사전학습 품질에 이미 의존, 우리 backbone 계보가 분석 대상 VLM들과 표현 품질이 유사한지 먼저 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Can VLA Models Learn from Real-World Data Continually without Forgetting?**
[arXiv:2605.26820](https://arxiv.org/abs/2605.26820) · Jiarun Zhu, Yijun Hong, Xiaoquan Sun, Zetian Xu, Mingqi Yuan, Zhiyong Wang, Wenjun Zeng, Jiayu Chen · 2026-05-26 · source: keyword-sweep (VLM catastrophic forgetting)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **실물 환경 포게팅 실증** — VLA 모델이 실제 환경 데이터로 지속 학습(continual learning)할 때 심각한 카탈클로픽 포게팅(catastrophic forgetting)을 겪음을 보이는 최초의 실물 환경 연구
  - 경험 재생(experience replay)이 가장 안정적인 방어 수단임을 실물 환경 4개 연속 태스크에서 실증
- **진정한 신규성** — 기존 지속 학습 VLA 연구가 시뮬레이션에 국한된 반면, 실물 환경 4개 연속 조작 태스크(rigid-object pick-and-place, contact-rich pressing, deformable-object folding 포함) 전용 실물 데이터셋 구축 후 포게팅 직접 측정
  - 경험 재생 구현 세부(버퍼 크기, 재생 비율)가 성공 여부를 좌우한다는 실용적 발견 — 선행 연구 미수록

### (c) 시사점

- **트리거 발동 후 결과 자료** — 동결에서 벗어나는 순간 활성화되는 prior 보존 결정의 결과를 가장 현실적인 조건에서 제시
- **방어 레시피 참조** — 동결을 벗어나 파인튜닝하는 단계에서 경험 재생 버퍼 설정(버퍼 크기, 적응형 재생 스케줄)의 구체적 출발점 제공

### (d) 먼저 확인할 점

- **적용 경계** — 포게팅 분석이 VLM backbone 파라미터 변경을 수반하는 full FT 또는 LoRA 시나리오 기반, 완전 동결 상태에서는 포게팅이 차단되므로 직접 위험은 동결을 벗어날 때만 적용
- **태스크 순서 의존성** — 포게팅 정도가 학습 순서(curriculum)에 크게 의존, 단일 순서에서 찾은 경험 재생 설정이 다른 순서에서도 일반화되는지 확인 필요

## 🌱 논문 4 — 인접 분야 픽

**HumanEgo: Zero-Shot Robot Learning from Minutes of Human Egocentric Videos**
[arXiv:2605.24934](https://arxiv.org/abs/2605.24934) · Zhi Wang, Botao He, Kelin Yu, Seungjae Lee, Ruohan Gao, Furong Huang, Yiannis Aloimonos · 2026-05-24 · source: keyword-sweep (flow matching + robot) · adjacent field: 인간 중심 동작 인식 / 데이터 효율적 로봇 학습

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **데이터 효율 경로** — 인간 에고센트릭 비디오(human egocentric video) 30분으로 4개 실물 태스크에서 92.5% 평균 성공률 달성, Being-H0.5의 약 16,000시간 에고 비디오 대비 극단적으로 효율적
- **진정한 신규성** — 로봇 데이터 없이(robot-data-free) 인간 에고센트릭 비디오만으로 플로우 매칭 정책(flow matching policy)을 학습하는 end-to-end 프레임워크
  - 손-물체 상호작용(hand-object interaction)을 엔티티 수준 표현(entity-level representation)으로 추상화해 외관·기구학 격차(embodiment gap) 해소
  - 밀도 보조 목적함수(dense auxiliary objectives) 결합
  - 15분 비디오만으로 동등 시간의 로봇 원격조작 데이터 대비 41% 높은 성공률 보고

### (c) 시사점

- **인간 비디오 ROI 자료** — 인간 비디오 소스 유형별 ROI 분석에 핵심 데이터 포인트 제공 ("30분 에고 비디오 → 4 real-world task, 92.5% SR")
- **파일럿 우선 전략** — 대규모 에고 비디오 수집 전에 소규모(30분급) 파일럿으로 효용을 먼저 검증할 근거
- **플로우 매칭 한계 탐색** — 플로우 매칭 헤드의 데이터 효율성 경계(boundary condition) 탐색에 참고 가능

### (d) 먼저 확인할 점

- **태스크 다양성 한계** — 보고된 4개 태스크가 단순 배치·집기 류에 치우칠 경우, 인핸드 조작처럼 정밀한 손가락 제어가 필요한 태스크로의 일반화가 보장되지 않음
- **엔티티 표현 추출 비용** — 손-물체 상호작용의 엔티티 수준 추상화가 별도 모델(pose estimator, segmenter)을 요구해 파이프라인 복잡도 증가, 인프라 비용을 먼저 파악 필요
