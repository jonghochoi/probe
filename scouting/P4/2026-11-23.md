## 🥇 논문 1

**Dexterous Tactile World Model**
[arXiv:2609.34286](https://arxiv.org/abs/2609.34286) · Ziyao Zeng, Xiatao Sun, Hao Wang 외 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 9/15** · R3 · N2 · M3 · Real0 · Repro1 — §Sx2 "We will release code, per-model configurations, split lists and per-clip scores"

### (a) 관련 Pillar / 질문

[![P4](https://img.shields.io/badge/P4-c7edee.svg)](#ref-P4) / [![D9KS](https://img.shields.io/badge/D9KS-d97706.svg)](#ref-D9KS)

### (b) 논문 요지

- 장갑 촉각을 손 위치에 얹어 영상 세계 모델의 미래 예측을 개선
- **문제** — 접촉이 결과를 가르는 조작에서 영상만으로 학습한 세계 모델이 접촉을 정확히 예측하지 못함
  - 손이 접촉 부위를 가리고, 닿기와 세게 누르기가 영상에서 거의 같아 보임
  - 생성 영상에서 손가락이 사라지거나 물체와 뭉개지고 손이 실제보다 덜 움직임
- **기존 한계** — 촉각을 쓰는 기존 세계 모델은 로봇 환경에서 평가되고 촉각 표현이 이미지 위치와 정렬되지 않음
  - 세 편은 손가락·그리퍼 센서가 달린 로봇 궤적으로 학습
  - TouchWorld는 같은 사람 코퍼스를 쓰지만 로봇 손에 적응해 정책에 하위 목표를 공급하는 시스템의 일부
  - 네 편 모두 촉각을 전역 특징, 추가 토큰, 별도 촉각 이미지로 표현해 접촉이 일어나는 영상 영역과 맞물리지 않음
- **핵심 방법** — 사전학습 영상 확산 트랜스포머에 각 손의 촉각 신호를 손 위치의 영상 토큰에 잔차로 더함
  - **촉각 배치** — 렌더링한 손 골격으로 손 위치를 계산하고 가우시안 풋프린트로 주변 토큰에 퍼뜨림
  - **0 초기화 투영** — 초기에는 사전학습 모델이 그대로이고 경로는 학습으로 형성
  - **인과 마스크** — 관측 프레임에만 촉각을 주고 예측 프레임이 뒤 프레임을 보지 못하게 막음
  - 13프레임을 관측해 다음 36프레임을 한 번에 예측하며 백본·오토인코더·텍스트 인코더는 동결
- **차별점** — 촉각을 글로벌 특징이 아니라 접촉이 일어난 영상 위치에 정렬해 주입
  - 미래 손 자세·행동·촉각 없이 과거 관측만으로 사람의 조작을 예측하는 단독 세계 모델
- **핵심 기여** — 촉각 조건화 세계 모델과 촉각의 어떤 정보가 효과를 내는지에 대한 분석
  - 구조·파라미터·학습을 맞춘 영상 전용 모델 대비 손 움직임 과소추정 23%에서 9%, 손 영역 지각 오차 7.4% 감소(모델당 3회 학습)
  - 예측 후반 구간의 개선이 첫 구간보다 약 4.1배 큼
  - 기존 시각-촉각 세계 모델 세 편을 같은 장갑 데이터로 맞춰 비교해 지각 오차 1.8–14.7% 낮음
  - 촉각을 이진 접촉 상태(위치별 또는 손별)로 바꾸면 오차가 늘어 힘의 크기와 위치가 모두 기여
  - 힘이 줄거나 늘어나는 손은 유지되는 손보다 0.5초 안에 놓을 가능성이 1.8–2.5배
  - 추론 때 촉각이 없어도 촉각으로 학습한 모델의 예측이 개선
- **가치** — 접촉 신호가 미래 예측에 주는 이득을 같은 조건의 대조로 분리해 보여 줌

### (c) 시사점

- 촉각의 크기와 위치가 이진 접촉보다 예측에 낫다는 대조 수치 확보
- 영상 전용 모델과 구조를 맞춘 비교라 촉각 경로의 순효과가 읽힘
- 추론 때 촉각이 없어도 이득이 남아 촉각 센서 없는 배포 경로의 참고점
- 사람 장갑 데이터 기반이라 로봇 손 촉각 센서 구성에는 그대로 대응하지 않음
- 코드 공개는 약속 단계라 당장 재현 비용을 낮추지 못함

### (d) 먼저 확인할 점

- 사람의 조작을 예측하는 모델이라 로봇 플래너나 정책에 바로 넣을 수 없고 로봇 구현 확장은 후속 과제
- 실물 로봇 결과 없음, 평가는 사람 장갑 코퍼스의 미래 프레임 예측 지표에 한정
- 코드 저장소 없이 프로젝트 페이지만 확인되고 공개는 약속 문구
- 행동을 입력으로 받지 않아 행동에 따른 결과를 묻는 용도에는 해당하지 않음
- 영상 예측 오차 개선이 하위 정책 성능으로 이어지는지는 논문에 없음

## 🥈 논문 2

**World Models Dream of Success: Diagnosing and Repairing Failure Insensitivity in Robot World Models**
[arXiv:2610.09134](https://arxiv.org/abs/2610.09134) · Jiuyi Xu, Xiao Hu, Meida Chen 외 · arXiv preprint · source: citation-graph · 코드 공개

**점수 12/15** · R2 · N3 · M3 · Real2 · Repro2 — 초록 "Code is available at https://github.com/jiuyixu25/CureWM"

### (a) 관련 Pillar / 질문

[![P4](https://img.shields.io/badge/P4-c7edee.svg)](#ref-P4) / [![D3FQ](https://img.shields.io/badge/D3FQ-d97706.svg)](#ref-D3FQ) [![D6FM](https://img.shields.io/badge/D6FM-d97706.svg)](#ref-D6FM)

### (b) 논문 요지

- 공개 세계 모델이 실패에 둔감함을 재고 검증된 반사실 실패로 고침
- **문제** — 정책 평가·계획·합성 데이터에 쓰는 세계 모델이 성공과 실패 행동을 구분하지 못함
  - 실패하는 행동에 높은 성공 값이나 성공처럼 보이는 미래를 내면 의사결정이 어긋남
- **기존 한계** — 실패 진단은 있으나 어떤 데이터가 공개 체크포인트를 고치는지는 남은 과제
  - MiraBench는 행동 조건 예측의 낙관 편향을 찾았지만 어떤 학습 데이터가 고치는지는 다루지 않음
  - 실패 궤적을 단순히 더하면 성공과 실패 행동 모두의 예측 성공률이 내려가 낙관만 줄고 구분은 나아지지 않을 수 있음
  - 병행 연구 FACT는 실패한 정책 롤아웃과 행동 조건화를 세계 행동 모델에 넣지만 공개 체크포인트를 구조와 목적 함수 변경 없이 고치는 문제는 다루지 않음
- **핵심 방법** — 성공 시연에서 대안 행동을 만들고 실행으로 결과를 검증해 미세조정
  - **반사실 구성** — 성공 시연을 심각도 격자로 교란하되 개입 전 행동은 유지해 같은 시작 맥락의 행동 대조를 만듦
  - **실행 검증** — 시뮬레이션이나 실물에서 재생해 결과 라벨을 확정
  - **사후 학습** — 실패와 살아남은 성공 재생을 정상 시연과 함께 공개 모델에 미세조정하며 구조와 목적 함수는 그대로
- **차별점** — 새 구조나 목적 함수 없이 공개 체크포인트를 데이터만으로 고침
  - 새로 수집한 정책 실패 대신 같은 맥락에서 행동만 바꾼 반사실 실패를 사용
- **핵심 기여** — 진단, 복구 방법, 낙관 감소와 구분력을 함께 재는 평가
  - 두 구조 계열의 공개 체크포인트 네 개(Cosmos Policy, Ctrl-World 계열)에서 행동 변화에 둔감하고 검증된 실패에 성공처럼 예측함
  - LIBERO 반사실 실패 484건에서 낙관이 공식 데이터 미세조정 80%에서 독립 미세조정 네 모델 30–43%(평균 38%)로 감소
  - 실물 로봇 팔 두 번의 평가에서 잠재 거리 진단으로 성공처럼 판정된 실패 예측이 성공 시연만 쓴 90%에서 33%로 감소
  - 실패 수·성공 재생·학습 예산을 맞춘 조건에서 성공-실패 값 격차가 반사실 실패 0.124, 새로 수집한 정책 실패 0.014
  - 낙관 감소만으로는 복구를 입증하지 못하며 성공 행동의 오경보와 함께 재야 함
- **가치** — 세계 모델 기반 평가와 계획의 신뢰 전제인 실패 구분력을 데이터로 복구하는 경로 제시

### (c) 시사점

- 공개 세계 모델의 평가 환경 용도가 실패에 둔감하다는 측정 수치 확보
- 구조 변경 없이 검증된 반사실 데이터로 구분력을 올리는 저비용 복구 레시피
- 낙관 감소와 구분력을 분리해 재는 평가 틀이 평가용 세계 모델 점검에 재사용 가능
- 코드가 공개돼 있어 보유 체크포인트에 같은 진단을 적용해 보는 비용 낮음
- 평가 대상이 LIBERO와 팔 조작이라 다지 손 과제로의 확장은 근거 없음

### (d) 먼저 확인할 점

- 다지 손이 아니라 로봇 팔과 LIBERO 과제 중심이라 손가락 접촉 조작에는 직접 적용 불가
- 실물 결과가 로봇 팔 한 대의 두 평가이며 지표가 잠재 거리 진단이라 성공 판정 자체의 신뢰는 진단 정의에 의존
- 복구 효과 비교가 시험한 학습 예산에 한정되고 결론에서도 더 넓은 이전과 로봇 제어 개선은 열린 과제로 남김
- 반사실 실패 생성에 성공 시연과 실행 검증이 선행돼 데이터 수집 비용 발생
