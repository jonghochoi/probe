## 🥇 논문 1

**RAFT: Reasoning-Aligned Fine-Tuning Improves Robustness of VLA Post-Training**
[arXiv:2611.04368](https://arxiv.org/abs/2611.04368) · Shresth Grover 외 2명 · arXiv preprint · source: keyword-sweep

**점수 11/15** · R3 · N2 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 추론 주석 어댑터를 먼저 학습하고 동결한 뒤 액션 미세조정
- **문제** — 소량 시연으로 범용 VLA를 적응하면 명목 성공률은 오르지만 외관·물체·지시 변화에 대한 강건성이 떨어짐
  - 시연이 좁은 환경 몇 곳에서만 수집되어 시연에 없던 시각·의미 변화를 견디지 못함
  - 질문은 사전학습 VLM의 추론 능력을 저데이터 적응에 어떻게 쓰는가
- **기존 한계** — 적응 중 강건성이 깎인다는 점이 출발점이고 기존 대응은 파라미터 병합과 적응 중 정규화
  - RETAIN — 사전학습 가중치와 미세조정 가중치를 병합
  - DeLock — 시각 인코더 가중치 이동을 정규화하고 추론 시 대조 프롬프트 가이드를 적용
  - 저자는 이들을 대체가 아닌 보완 관계로 보며 기존 방법이 실패한다는 주장은 하지 않음
- **핵심 방법** — 두 단계 사후학습
  - 1단계 — 사전학습 파라미터를 고정한 채 언어·비전 모듈의 저랭크 어댑터를 과제 관련 추론 주석으로 학습
  - 2단계 — 어댑터를 동결하고 언어 모델·액션 전문가·투영층을 액션 시연으로 미세조정, 액션 그래디언트가 추론 어댑터를 직접 갱신하지 않음
- **차별점** — 추론 지도와 액션 학습을 단계로 분리하고 어댑터를 동결
  - 추론과 액션을 함께 학습하면 시뮬레이션 pick-and-place 평균 성공률 63.2%로 일반 미세조정 79.6%보다 낮음
  - 2단계에서 어댑터를 풀어 두면 74.0%로 역시 일반 미세조정 아래
- **핵심 기여** — 시뮬레이션 두 과제와 실물 두 플랫폼의 강건성 개선, 표현 분석
  - 실물 DROID — MolmoBot을 시연 50개로 적응, 분포 밖 시행 성공률 75.0%로 일반 미세조정 27.9%의 약 2.7배
  - 분포 밖 세부 — 새 물체 색 83% 대 33%, 방해물 75% 대 25%, 바뀐 탁상 65% 대 25%, 시연 환경은 63% 대 60%로 근접
  - 실물 양손 YAM — π0.5를 시연 100개로 적응한 다단계 과제에서 평균 70.0%, DeLock 36%, 일반 미세조정 35%, RETAIN 29%
  - 시뮬레이션 pick-and-place 최고 평균 성공률과 open-drawer 개선
  - 주석 영역에 더 많은 어텐션, 후반 층에서 물체 정체성에 대한 선형 프로브 정확도 상승
  - 더 넓은 추론 데이터 혼합이 시연 예산 전반에서 하위 성공률을 추가로 올림
- **가치** — 사전학습 VLA의 시연 적응에서 강건성 손실을 줄이는 단계 분리 처방 제시

### (c) 시사점

- 저데이터 적응에서 보존 수단으로 동결 어댑터를 둔 단계 분리의 실물 측정
- **보존 방식** — 병합·정규화 계열과 나란히 비교한 결과, 적응 단계 앞에 보존 구성요소를 두는 대안
- **단계 구성** — 적응 전에 보조 지도를 먼저 학습하는 순서 효과가 공동학습 대비 수치로 확인됨
- **도입 비용** — 저랭크 어댑터와 추론 주석 확보가 비용 항목

### (d) 먼저 확인할 점

- **저자 명시 한계** — 추론 주석 모달리티별로 성능이 갈리며 과제별 최적 모달리티 선택은 미해결
- 시연 환경에서는 63% 대 60%로 차이가 작고 이득은 분포 밖 조건에 집중
- 실물 시행 수와 평가 프로토콜은 부록에서 확인 필요
- 추론 주석 작성 부담이 과제마다 들며 주석 없는 과제로의 이전은 본문에 없음
- 코드 저장소나 공개 약속 없음

## 🥈 논문 2

**The Low-Rank Structure of VLA Reinforcement Learning**
[arXiv:2609.34599](https://arxiv.org/abs/2609.34599) · Minjae Oh 외 3명 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 8/15** · R3 · N2 · M2 · Real0 · Repro1 — §7 "We plan to publicly release the code used in our experiments, along with relevant artifacts such as our trained checkpoints, upon acceptance"

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- RL이 액션 전문가의 작은 모듈만 저랭크로 갱신
- **문제** — VLA에 RL을 적용했을 때 학습 신호가 파라미터 공간 어디에 어떤 형태로 저장되는지 불명확
  - 사전학습 후 소량 과제 데이터로 사후학습하는 흐름에서 RL이 정책을 어떻게 바꾸는지 이해가 부족
- **기존 한계** — LLM에서는 RL 사후학습의 파라미터 구조 규명이 LoRA 같은 효율 학습으로 이어졌으나 VLA는 미탐색
  - 플로우 기반 액션 전문가 구조가 달라 LLM 결과를 그대로 옮길 수 없음
  - 표준 LoRA 설정은 이 논문이 지목한 모듈을 포함하지 않음
- **핵심 방법** — π0.5와 GR00T N1.5/N1.6을 LIBERO·ManiSkill·MetaWorld·CALVIN에서 RL로 학습하고 갱신을 분석
  - 갱신 랭크와 위치 측정으로 변화가 집중된 모듈을 찾음
  - 모듈 교체 실험으로 해당 모듈이 RL 이득에서 차지하는 몫을 측정
  - 모듈 출력을 스케일·시프트·게이트로 분해하고 프로빙과 조향으로 시프트 벡터의 역할을 확인
- **차별점** — 갱신이 액션 전문가의 Timestep Module에 집중된다는 발견
  - 이미지·비디오 생성 모델의 RL에서는 같은 저랭크 구조가 관측되지 않아 액션 정책 특유의 현상으로 해석
  - 이산 디노이징 타임스텝 학습이 저랭크 갱신의 원인이라고 제시
- **핵심 기여** — 구조 규명과 이를 쓴 개선
  - 모듈 교체 실험에서 Timestep Module이 RL 성능 이득의 불균형적으로 큰 몫을 차지
  - Timestep Module에만 LoRA를 거는 구성이 표준 LoRA 구성보다 우수
  - 시프트 갱신 방향으로 과제 성공 예측 ROC-AUC 최대 99.6%
  - 시프트 갱신 간 유사도와 과제 간 전이 패턴의 Spearman 상관 0.794
  - 시프트 갱신 방향으로 조향하면 추가 RL 없이 RL 정책이 더 개선됨
- **가치** — RL 사후학습이 소수 모듈의 벡터 수준 변조로 상당 부분 설명된다는 근거, 더 효율적인 사후학습의 출발점

### (c) 시사점

- 적응 시 어느 파라미터를 열어야 하는지를 모듈 단위로 좁힌 측정
- **적응 범위** — 액션 전문가 안의 작은 모듈이 이득 대부분을 담는다는 관찰, 백본을 고정하고 액션 쪽만 학습하는 구성과 방향이 같음
- **어댑터 배치** — 표준 LoRA 대상에서 빠진 모듈을 넣는 것만으로 이득이 난다는 점은 어댑터 설계의 점검 항목
- **재사용** — 과제별 갱신 방향이 과제 관계를 반영해 이전 가능성 판단에 쓸 단서

### (d) 먼저 확인할 점

- **시뮬레이션 전용** — LIBERO·ManiSkill·MetaWorld·CALVIN 결과만 있고 실물 결과 없음
- 대상은 RL 사후학습이며 VLM 백본이나 사전학습 단계의 선택을 비교한 연구가 아님
- 저자 확인 사항으로 이산 타임스텝 BC도 비슷한 저랭크 구조를 보여, RL 고유 현상으로 읽을 범위가 좁음
- 시드 분산이나 한계 진술은 본문에서 확인되지 않음
- 코드와 체크포인트는 채택 시 공개 예정

## 🥉 논문 3

**Behavioral Steering of Vision-Language-Action Models in the Low-Parameter Regime**
[arXiv:2611.00522](https://arxiv.org/abs/2611.00522) · James Tcheng 외 1명 · NeurIPS 2026 RoboPAD Workshop · source: keyword-sweep

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL)

### (b) 논문 요지

- 256개 파라미터 어댑터로 VLA 실행 스타일 조향
- **문제** — 사전학습 능력을 유지하면서 VLA의 실행 스타일(속도·궤적·운반 높이)을 선호에 맞게 바꾸는 방법
  - 질문은 스타일 이득과 능력 유지가 학습 가능 파라미터 수에 따라 어떻게 변하는가
- **기존 한계** — 학습 없는 활성화 조향이 기존 접근
  - 방향이 목표 행동에 맞춰 최적화되지 않아 스타일 변화도 과제 성공도 보장되지 않음
  - 활성화 개입은 구조와 특징에 따라 치명적인 것부터 무시할 만한 것까지 편차가 큼
  - 저자 재현에서 활성화 기준선은 운반 높이를 일관되게 올리지 못하고 과제 성공을 해침
- **핵심 방법** — 동결한 OpenVLA-OFT 7B에 TinyLoRA 어댑터를 붙여 LIBERO-Goal에서 물체를 더 높이 나르도록 학습
  - 어댑터 규모 8–384 파라미터
  - 과제 성공 제약 아래 운반 높이 보상을 GRPO 또는 CMA-ES로 최적화
  - 학습된 갱신을 가중치 보간으로 재조정해 스타일과 유지의 절충 곡선을 추적
- **차별점** — 파라미터 수와 최적화기를 독립 변수로 두고 같은 보유 성공률에서 갱신을 비교
  - 프롬프트·활성화 개입 기준선과 학습 갱신을 같은 평가 스위트에서 대조
- **핵심 기여** — 소규모 어댑터 조향의 수치와 용량·최적화기 효과
  - 파라미터 256개로 학습 과제에서 운반 높이 120 mm 상승, 성공률 92%
  - 보류 과제에서 74 mm 상승, 성공률 80%
  - 갱신을 재조정하면 재학습 없이 스타일 이득과 유지의 절충을 조절
  - 어댑터 용량이 커질수록 같은 스타일 이득에서 더 많은 능력이 유지되는 경향
  - 낮은 파라미터 수에서는 CMA-ES가 경쟁력이 있고 용량이 커지면 GRPO의 절충이 낫다는 비교
- **가치** — 극소 차원 갱신으로 사전학습 VLA 행동을 조향할 수 있다는 근거와, 적응과 유지를 조절하는 실무 손잡이 제시

### (c) 시사점

- 적응 용량과 사전학습 능력 유지 사이의 절충을 파라미터 수 축으로 직접 잰 측정
- **적응 범위** — 백본을 고정한 채 수백 파라미터만 열어도 행동이 바뀐다는 하한 자료
- **보존 수단** — 갱신 크기를 사후에 줄여 유지를 되찾는 방법, 추가 학습 없이 쓰는 안전장치 후보
- **한계 인식** — 스타일 조향 과제의 결과라 목표 과제 적응 전반으로의 일반화는 별도 판단 필요

### (d) 먼저 확인할 점

- **저자 명시 한계** — LIBERO-Goal 시뮬레이션의 운반 높이 한 가지만 평가, 실물 검증 없음
  - 설정당 학습 시드 하나라 구간은 평가 변동만 반영
  - ES가 2.4–4.8배 많은 에피소드를 쓰고 대리 목적이 달라 ES 대 GRPO 차이 일부는 예산 차이일 수 있음
  - 스타일은 보류 그릇 과제로는 전이되지만 와인병과 다단계 과제로는 약하게 전이
- 플로우 매칭 정책으로의 확장은 미검증, 평가 대상은 OpenVLA-OFT 하나
- 워크숍 논문이며 코드 저장소나 공개 약속 없음
