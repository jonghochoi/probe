## 🥇 논문 1 — 우선순위 ★★★

**Dexterous Point Policy: Learning Point-based Dexterous Hand Policies from Human Videos**
[arXiv:2606.10614](https://arxiv.org/abs/2606.10614) · Beomjun Kim, Seong Hyeon Park, Seunghoon Sim, Seungjun Moon, Sanghyeok Lee · 2026-06-09 · source: Citation-Graph (GR00T N1 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **전제 전환** — 기존 VLA 기반 다지 조작 학습이 로봇 원격 조작 시연(robot demonstration)에 의존하는 것과 달리, 로봇 데이터 없이 순수 인간 비디오(human video)만으로 다지 손 정책 학습 달성
- **Dexterous Point Policy** — 3D 키포인트(3D keypoints)를 통합 관찰-액션 공간으로 사용하는 프레임워크
  - 원시 비디오에서 태스크 관련 물체·인간 손의 3D 키포인트 추출
  - 추출된 키포인트에 대해 자동회귀 트랜스포머(autoregressive transformer) 학습
  - **구현체 간 정렬 관찰** — 손목·지끝(fingertips) 키포인트 수준에서 인간과 로봇의 행동 패턴이 긴밀히 일치 → 직접 정책 전이 가능
- **성능** — 실환경 실제 로봇 태스크(픽앤플레이스·도구 사용 포함) 전반에서 성공률 **75.0%** 달성; 비교 기준선 최신 VLA **1.0%** 대비 극적 차이
- **일반화** — 미보인 다중 물체 환경·새로운 물체 카테고리에서도 강력한 일반화 확인

### (c) 시사점

- **D22 열린 질문에 실험적 답변 추가** — "로봇 데이터 없이 인간 비디오만으로 다지 조작이 가능한가?"라는 D22의 에고센트릭-중심 코퍼스 논거에 가장 강력한 실증 사례; 75% vs 1%라는 수치 차이는 3D 키포인트 중간 표현이 구현체 격차 해소에 효과적임을 직접 보여줌
- **에고센트릭 코퍼스 설계 기준점** — 손목·지끝 수준의 3D 포즈 일치라는 조건이 충족될 때 인간 비디오가 로봇 데이터를 대체할 수 있음을 정량화; D22 코퍼스 수집 전략에서 "3D 손 포즈 복원 가능한 에고센트릭 영상" 품질 기준 추가 근거 확보
- **데이터 수집 비용 근본 절감 경로** — 다지 손 원격 조작(며칠 소요)을 제거하는 접근; 인핸드 조작 확장의 가장 큰 병목(로봇 데이터 수집 비용) 직접 해소 방향

### (d) 먼저 확인할 점

- **VLM 백본 미사용** — Dexterous Point Policy는 3D 키포인트 특화 자동회귀 트랜스포머이며 VLM 백본을 사용하지 않음; VLM 사전학습 prior 보존·언어 일반화 능력 전이가 필요한 태스크에서 적용 한계 존재
- **VLA 기준선 성능 의문** — "최신 VLA 1.0%"라는 비교 기준선이 어떤 VLA인지 초록에 명시 없음; π0.5 계보 동등 기준선 대비 직접 비교 필요
- **3D 포즈 복원 파이프라인 비용** — 물체·손 3D 키포인트 추출이 MediaPipe 등 별도 파이프라인을 요구하는지 여부 확인 필요; 에고센트릭 영상 대규모 전처리 시 계산 비용 측정 선행 필요

## 🥈 논문 2 — 우선순위 ★★

**Encoder Winners Do Not Reliably Transfer Across VLA Backbone Scale: A Frozen-Backbone Grafting Diagnostic**
[arXiv:2606.14153](https://arxiv.org/abs/2606.14153) · Qingping Zeng, Fei She · 2026-06-12 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **공백 진단** — VLA 정책이 업스트림 VLM 릴리스에서 비전 인코더를 상속받지만, 작은 VLA 규모에서 검증된 인코더 선택이 큰 규모 백본에 전이되는지 불명확
- **동결-접목 진단법(frozen-backbone grafting diagnostic)** 제안 — 출시된 VLA의 비전 타워를 후보 인코더로 교체하되 언어 모델·액션 전문가를 동결; 고정 프로토콜(어댑티브 평균 풀링 + LayerNorm + 단일 선형 투영)로 표준화
- **핵심 발견**:
  - **SigLIP** — 소형 백본(SmolVLA-450M) 양대 LIBERO 스위트 모두에서 최우수
  - **DINOv2-small** — 대형 백본(π0.5-3.3B) 공간 스위트에서 리더; 물체 스위트는 시드 민감 접전
  - **규모 의존적 랭킹** — 소형 백본 우승자가 대형 백본 최상위 계층을 안정적으로 선택하지 못함; 12개 백본-스위트 비교 중 11개 시드 수준 셀에서 규모 의존적 랭킹 지지
  - **접목 래퍼 비중립성** — 래퍼 자체가 SmolVLA에서 +45–56% MSE, π0.5에서 -50–52% MSE → 결론은 고정 프로토콜 조건부
- **권장 사용** — 대규모 인코더 선정 전 타겟 백본 규모에서 사전 스크리닝 진단 방법으로 위치

### (c) 시사점

- **D19 계보 선택의 규모 검증 원칙 확립** — 소규모 실험 기반 인코더 선택이 대규모 VLA에서 그대로 유효하지 않음을 실험 정량화; π0.5 규모에서 직접 동결-접목 스크리닝 후 최종 계보 선정 권장
- **SigLIP vs DINOv2 이중 후보 전략** — 소형 아키텍처 실험은 SigLIP 우선, 대형(3B급) 아키텍처 실험은 DINOv2 계열 병행 스크리닝 전략 근거; 단일 소규모 결과로 대규모 계보를 고정하는 것의 위험 경고
- **비용 효율적 진단 경로 제시** — 40회 접목 실험(오프라인 MSE 지표)이 풀 스케일 파인튜닝 없이 인코더 후보 판별; D19 계보 스크리닝 시 이 방법론을 1차 필터로 채택 가능

### (d) 먼저 확인할 점

- **오프라인 메트릭 한계** — 오프라인 액션 MSE가 온라인 성공률과 일치하지 않을 수 있음; LIBERO 온라인 성공률 기준으로 동일 결론이 재현되는지 확인 필요
- **접목 래퍼 비중립성 보정** — 래퍼 자체가 백본마다 MSE를 반대 방향으로 이동시키므로 비교 가능한 조건 정규화 방법 추가 검토 필요
- **인핸드 다지 조작 미검증** — LIBERO 스위트(탁상 조작 집중)에서의 결론이 손가락 세밀 제어·접촉 집약적 태스크로 확장되는지 미확인; 해당 도메인 특화 평가 필요

## 🥉 논문 3 — 우선순위 ★

**DiPOD: Diffusion Policy Optimization without Drifting Apart**
[arXiv:2606.13795](https://arxiv.org/abs/2606.13795) · Haozhe Jiang, Haiwen Feng, Pieter Abbeel, Jiantao Jiao, Angjoo Kanazawa · 2026-06-11 · source: Citation-Graph (GR00T N1·π0 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **"이중 표류 현상(double-drift phenomenon)" 규명** — 확산/플로우 정책의 RL 사후 학습에서 기존 방법이 불안정한 원인 최초 이론화
  - 변분 서로게이트(variational surrogate)를 최적화하면 ELBO가 참 로그-가능도(true log-likelihood)에서 이탈
  - 이탈된 ELBO → 프록시 정책 그래디언트가 진짜 기대 수익 그래디언트와 정렬 불일치
- **DiPOD** — 자기-증류(self-distillation)와 정책 개선 그래디언트 업데이트를 교차 수행(interleaving)
  - 각 그래디언트 업데이트마다 온-폴리시 ELBO 정규화 항 추가 → 타이트 바운드(tight-bound) 동작 유지
  - 이전 방법 대비 "학습을 실질적으로 안정화하고 더 높은 보상 달성"
- **적용 범위** — 확산 언어 모델 사후 학습 + 연속 제어 확산 정책 모두에서 검증 (Berkeley·Abbeel 그룹)

### (c) 시사점

- **Stage 3 플로우 매칭 RL 안정화의 이론적 근거** — 기존에 누적된 플로우 매칭 헤드 RL 사후 학습 후보들(FlowPRO·Q-VGM·RLDT)이 공유하는 잠재적 불안정성 원인을 규명; Stage 3 보상 기반 적응 선택 시 DiPOD의 ELBO 정규화 원칙을 설계 기준으로 참고 가능
- **자기-증류 ↔ 보수적 적응 연결** — DiPOD의 자기-증류 정규화가 ConSFT의 중요도 가중치 기반 보수적 적응과 개념적으로 유사; "RL 사후 학습에서도 사전학습 정책 분포를 유지하는 항 추가"가 수렴 조건임을 독립 확인
- **플로우 매칭 헤드 특유의 이중 표류 점검** — SVGD 기반 RLDT·Q-VGM이 DiPOD가 규명한 이중 표류에 노출되는지 여부 기존 구현 검토 필요; 해당 경로 적용 전 서로게이트-참 가능도 이탈 측정 권장

### (d) 먼저 확인할 점

- **실환경 검증 미명시** — 초록의 "연속 제어 확산 정책" 실험 범위가 MuJoCo 수준인지 실환경 로봇인지 명시 없음; 실환경 인핸드 조작 결과 확인 필요
- **플로우 매칭 vs 확산 정책 적용 경계** — DiPOD는 DDPM 계열 확산 정책에 대해 유도됨; DDIM/ODE 기반 플로우 매칭 헤드에서 동일한 ELBO 이탈 현상이 동일한 방식으로 나타나는지 이론 확장 검토 필요
- **확인** — 코드 공개 여부 확인 후, π0.5 플로우 매칭 헤드 기반 LIBERO 태스크에서 Q-VGM 대비 DiPOD ELBO 이탈량 측정; 서로게이트 이탈 임계치 정량화

## 🌱 논문 4 — 인접 분야 픽

**GAM: Geometric Action Model**
[arXiv:2606.17046](https://arxiv.org/abs/2606.17046) · Jisang Han, Seonghu Jeon, Jaewoo Jung, René Zurbrügg, Honggyu An · 2026-06-15 · adjacent field: 기하학적 파운데이션 모델(GFM)을 VLM 대신 백본으로 사용하는 조작 정책 · source: Curated List (awesome-vla-wam)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **전제** — 현행 VLA·WAM은 2D 이미지 또는 2D 파생 잠재 공간에서 동작; 접촉 집약적 조작에 필요한 3D 기하 구조가 암묵적으로만 존재
- **GAM(Geometric Action Model)** — 사전학습된 기하학적 파운데이션 모델(GFM)을 지각·시간 예측·액션 디코딩의 단일 기반으로 재활용
  - GFM을 중간 레이어에서 분리: 얕은 레이어 → 관찰 인코더, 삽입된 인과적 미래 예측기(causal future predictor) → 언어·고유감각·액션 히스토리 조건부 미래 잠재 토큰 예측
  - 예측된 미래 토큰을 나머지 GFM 블록을 통해 전파·디코딩 → 단일 백본이 미래 기하 정보와 액션 모두 생성
  - **최소한의 아키텍처 수정**으로 언어 조건부 시간 세계 모델링 부여; GFM의 풍부한 기하 사전(geometric prior) 보존
- **결과** — 광범위한 시뮬레이션 + 실환경 조작 벤치마크에서 현행 파운데이션-모델 규모 기준선 대비 "더 정확하고, 더 견고하고, 더 빠르고, 더 가볍다" 보고

### (c) 시사점

- **VLM이 아닌 GFM 계보의 접촉 조작 강점** — VLM 사전지식(언어-시각 의미론)과 다른 유형의 사전(3D 기하 구조)이 접촉 집약적 조작에서 실질적 이점을 가질 수 있음을 실험 제시; D19 VLM 계보 가정에 대한 비교 관점 추가
- **기하 prior 기반 백본의 인핸드 조작 잠재력** — 손-물체 접촉이 본질적으로 3D 기하 문제인 인핸드 조작에서 GFM 계보의 구조적 이점 가설; 우리 계보 D19(PaliGemma × π0) 대비 손 접촉 특화 태스크 직접 비교 실험 가치 있음
- **단일 백본 다중 역할 설계 참조** — 인코더+예측기+디코더를 하나의 GFM 백본으로 통합하는 분리 설계가 파라미터 효율과 기하 일관성을 동시 달성; VLM 분리 헤드 설계 대비 구조적 대안으로 참조 가능

### (d) 먼저 확인할 점

- **언어 이해 역량 미확인** — GFM은 이미지-기하 사전학습 특화; 복잡한 언어 지시 이해·구성형 일반화(compositional generalization)에서 VLM 계보 대비 열위 가능성 초록 수준 불명
- **GFM 종류·공개 여부 미명시** — 사용된 기하 파운데이션 모델 구체 식별(DUSt3R·MASt3R 계열 등) 및 오픈소스 여부 확인 필요
- **확인** — 언어 OOD(미보인 언어 지시) 조건에서 GAM과 π0.5 기준선의 성공률 차이 비교; 인핸드 손가락 세밀 접촉 태스크에서 GFM 기하 표현의 실질적 기여 측정

## 🔄 직전 리포트 대비 종합

- **중복 없음** — 직전 보고서(2026-06-15) 채택 4편(APT·Cotraining·FRS·FTP-1)과 이번 채택 4편(Dexterous Point Policy·Encoder Winners·DiPOD·GAM) 전원 신규; 2606.13675(FRS)와 2606.13795(DiPOD)는 arXiv id 유사하나 별개 논문
