## 🥇 논문 1 — 우선순위 ★★★

**Wall-OSS-0.5 Technical Report**
[arXiv:2605.30877](https://arxiv.org/abs/2605.30877) · Ryan Yu, Pushi Zhang, St Liu, Brae Liu, Miracle Kang · 2026-05-29 · source: Citation-Graph (π0.5 인용 확장) + Keyword Sweep (쿼리 1)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) 핵심 명제를 직접 검증합니다. [D19](#ref-D19)(a) 완전 동결의 타당성 기반, [D19b](#ref-D19b) 오픈소스 계보 비교, [D20](#ref-D20) 사전학습 prior 가치 측정, [D21](#ref-D21) Stage 2 진입 전 기준선 설정에 관계합니다.

### ✨ (b) 진정으로 새로운 점

P4의 핵심 질문인 "VLA 사전학습 자체가 실행 가능한 로봇 행동을 산출하는가, 아니면 단순히 하류 정책 학습에 더 나은 초기화를 제공하는 데 그치는가?"를 오픈소스 4B VLA로 직접 검증합니다. 기존 모든 핀 논문(π0, π0.5, GR00T N1 등)은 태스크별 파인튜닝 후 성능만 보고해왔으며 사전학습 단계 자체의 로봇 제어 능력이 독립 측정된 사례가 없었습니다. Wall-OSS-0.5는 3B VLM 백본에 액션 생성 컴포넌트를 결합해 **파인튜닝 없는 사전학습 전용(pretrained-only) 실행 능력**이 측정 가능하도록 설계된 첫 오픈소스 모델입니다.

### ⚙️ (c) 의사결정 함의

[D21](#ref-D21) Stage 2(VLM 동결 + 액션 전문가 학습) 진입 전, Wall-OSS-0.5를 pretrained-only 기준선으로 삽입하는 평가 루틴을 설계합니다. 구체적 절차:

1. `eval.pretrain_baseline = "wall_oss_0.5"` 플래그를 Stage 1 완료 직후 활성화해 인핸드 회전 태스크에서 파인튜닝 없이 10회 롤아웃을 수행합니다.
2. pretrained-only 성공률 ≥ 20%: 사전학습 prior가 충분히 실행 가능한 표현을 보유 → [D19](#ref-D19)(a) 동결 유지 근거 추가 확보.
3. pretrained-only 성공률 < 5% (≈ 랜덤 기준): 사전학습 prior의 로봇-도메인 표현이 미약 → [D19b](#ref-D19b) 대안 계보 탐색 트리거 또는 Stage 0½([D22](#ref-D22)) 멀티-구현체 공동 사전학습 조기 진행 검토.
4. Wall-OSS-0.5의 3B VLM 계보(공개 체크포인트 확인 필요)가 [D19b](#ref-D19b) 2-쌍 비교 실험 후보에 추가될 수 있습니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

Wall-OSS-0.5의 액션 생성 컴포넌트 설계와 학습 데이터가 논문 초록에서 구체적으로 명시되지 않습니다. VLM 백본 계보(3B VLM의 사전학습 corpus)가 공개되지 않으면 D19b 비교 실험에 활용할 수 없습니다. 가장 빠른 확인: 공개 저장소에서 `model_card.md` 또는 `config.json`을 통해 백본 계보(init weights + further-pretrain corpus)를 확인하고 LIBERO나 표준 벤치마크에서 pretrained-only 결과를 독립 재현합니다.

## 🥈 논문 2 — 우선순위 ★★

**Lagrangian Perturbation Diffusion Steering: Latent Reinforcement Learning for Generative Policies**
[arXiv:2606.01151](https://arxiv.org/abs/2606.01151) · Hikmet Simsir, Ozgur S. Oguz · 2026-05-31 · source: Keyword Sweep (쿼리 6, flow matching+VLA)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) 핵심. [D19](#ref-D19)(a) 완전 동결 + [D20](#ref-D20) 액션 사이드 어댑터 + [D23](#ref-D23)(iii) 플로우 매칭 헤드 세 결정이 교차하는 지점에서 새로운 적응 메커니즘을 제시합니다.

### ✨ (b) 진정으로 새로운 점

동결된 플로우 매칭 생성 정책을 개선하기 위해, 디코딩 전 노이즈 공간(noise space)에 소형 perturbation δ를 학습하는 LP-DS(Lagrangian Perturbation Diffusion Steering)를 제안합니다. 플로우 매칭 디노이징 체인 시작점 x_T에 δ를 더한 뒤 동결 정책으로 디코딩하는 구조로, VLM 백본과 플로우 매칭 헤드 모두를 건드리지 않습니다. 핵심 차별점: BORA([arXiv:2605.30226](https://arxiv.org/abs/2605.30226), 직전 리포트)가 동결 VLM 위에 별도의 잔차 어댑터 네트워크를 훈련하는 데 비해, LP-DS는 **δ 벡터 하나만 최적화**하므로 파라미터 규모가 극단적으로 작습니다. Lagrangian trust-region 목적함수가 δ 크기를 제한해 사전학습 prior를 명시적으로 보호합니다.

### ⚙️ (c) 의사결정 함의

[D21](#ref-D21) Stage 3(LoRA/partial FT) 진입 트리거가 발동될 때, LoRA보다 먼저 시도할 **최경량 적응 실험**으로 LP-DS를 Stage 2.5 단계에 삽입합니다:

- `adaptation.lp_ds.enabled = True`, `adaptation.lp_ds.delta_rank = 32`, `adaptation.lp_ds.lagrangian_lambda = 0.1`을 초기 스윕 값으로 설정.
- 비교 지표: in-hand rotation 태스크에서 LP-DS 적용 전후 성공률 변화량이 [D20](#ref-D20) v1 split heads 대비 +15%p 이상이면 Stage 3 LoRA를 보류하고 LP-DS로 유지.
- [D23](#ref-D23)(iii)과의 정합성: LP-DS는 디코딩 시작점만 이동시키므로 플로우 매칭 ODE trajectory 자체는 사전학습 분포를 유지합니다 — D23(iii) 불변식을 해치지 않습니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

LP-DS의 δ는 단일 벡터(또는 저차원 파라미터)로 표현력이 제한적입니다. 인핸드 조작처럼 다단계(multi-phase) 접촉 시퀀스가 요구되는 태스크에서는, 단일 δ가 전 실행 구간을 대표하지 못해 성능 향상이 제한될 수 있습니다. 가장 빠른 확인: LIBERO 단순 집기 태스크(단일 phase)와 인핸드 회전(다중 phase) 태스크에서 각각 LP-DS를 적용해 phase 수가 많을수록 효과가 떨어지는지 비교합니다.

## 🥉 논문 3 — 우선순위 ★★

**Mitigating State Aliasing in Vision-Language-Action Models via Inverse Dynamics Learning**
[arXiv:2605.29577](https://arxiv.org/abs/2605.29577) · Kyujin Lee, In-Ho Kim, Jihwan Park, Yejun Ju, Minseok Joo · 2026-05-28 · source: Citation-Graph (π0.5 인용 확장) + Keyword Sweep (쿼리 1)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) [D19](#ref-D19)(a) 동결 유지의 잠재적 실패 조건을 실험적으로 규명합니다. [D20](#ref-D20) 대기 결정의 발동 가능성 측정 도구로도 활용 가능합니다.

### ✨ (b) 진정으로 새로운 점

동결 VLM 표현이 저수준 제어에 필요한 미세 시각 구별력이 부족해 **상태 별칭(state aliasing)** — 시각적으로 유사하지만 매우 다른 액션이 필요한 상태들이 VLM 임베딩에서 동일 위치에 집중되는 현상 — 이 발생함을 측정합니다. 기존 VLA 연구들이 이 문제를 미래 프레임 생성이나 추론 토큰으로 해결하려 한 것과 달리, 역동역학 모델(IDM: Inverse Dynamics Model)을 보조 모듈로 훈련해 (VLM_embed_t, VLM_embed_{t+1}) 쌍으로부터 중간 액션을 예측함으로써 VLM 백본 자체를 건드리지 않고 해결합니다.

### ⚙️ (c) 의사결정 함의

[D19](#ref-D19)(d) LoRA 전환 트리거에 **상태 별칭 진단 지표**를 추가합니다:

1. Stage 2 완료 직후, VLM 임베딩 공간에서 k-NN(k=5) 이웃 평균 액션 분산(mean pairwise action distance among k-NN neighbors)을 측정합니다: `eval.state_aliasing_knn_k = 5`, `eval.state_aliasing_threshold = 0.15`.
2. 상태 별칭율 > 15% 기준선: IDM 보조 모듈 추가 훈련(`adaptation.idm.enabled = True`, `adaptation.idm.hidden_dim = 256`)을 먼저 시도합니다. IDM이 상태 별칭을 해소하면 [D19](#ref-D19)(a) 동결 유지.
3. IDM 추가 후에도 별칭율 > 15% 지속: [D19](#ref-D19)(d) LoRA 전환 트리거 발동. IDM이 LoRA보다 먼저 시도되는 경량 단계로서 D21 Stage 2.5에 편입합니다(LP-DS와 동일 슬롯 — 둘 중 하나를 먼저 시도).
4. [D20](#ref-D20) 관점: IDM 훈련은 VLM 백본에서 이미 보존된 표현을 활용하는 액션 사이드 모듈이므로, D20 v1 action-side adapter 전략과 일관됩니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

IDM이 (embed_t, embed_{t+1}) 쌍을 입력으로 사용하므로, 다음 타임스텝 임베딩을 추론 시점에 미리 알 수 없습니다 — IDM은 학습 시점에만 완전히 동작하고 추론 시점에는 예측 임베딩을 대신 써야 합니다. 예측 임베딩의 오차가 IDM 출력에 전파되면 인핸드 조작처럼 연속 접촉 변화가 빠른 태스크에서 IDM 보조 효과가 줄어들 수 있습니다. 가장 빠른 확인: 학습 시 oracle(t+1) 임베딩을 쓸 때와 추론 시 예측 임베딩을 쓸 때의 성공률 차이를 LIBERO에서 먼저 측정합니다.

## 🌱 논문 4 — 크로스폴리네이션

**HARP-VLA: Human-Robot Aligned Representation Learning for Vision-Language-Action Model**
[arXiv:2605.31234](https://arxiv.org/abs/2605.31234) · Xiangpei Zhu, Puzhen Yuan, Yichen Liu, Jianyu Chen · 2026-05-29 · adjacent field: 인간-로봇 크로스-구현체 표현 정렬 · source: Citation-Graph (π0.5 인용 확장)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4) [D22](#ref-D22)(멀티-구현체 사전학습 데이터) 실행 단계 설계. 인간 비디오와 로봇 데모 공동 학습 시 발생하는 **시각 표현 불일치** 문제를 정렬 손실로 해소하는 접근입니다.

### ✨ (b) 진정으로 새로운 점

잠재 액션 모델(LAM) 기반의 기존 크로스-구현체 공동 학습이 액션 실행 격차만 해소하려 했던 것과 달리, HARP는 VLM이 인간 비디오와 로봇 영상을 처리할 때 생성하는 **시각 특징 분포 자체**가 불일치함에 주목합니다. MMD(Maximum Mean Discrepancy) 기반 정렬 손실 `L_align = MMD(h_robot, h_human)`을 도입해 VLM 백본이 두 도메인에서 일관된 표현을 생성하도록 유도합니다. 이로써 잠재 액션의 도메인 의존성이 감소해 인간 비디오에서 학습한 정보가 로봇 정책으로 전이됩니다.

### ⚙️ (c) 의사결정 함의

[D22](#ref-D22) Stage 0½ 멀티-구현체 공동 학습(D22 실행 트리거 발동 시) 레시피 설계에서, HARP의 MMD 정렬 손실을 정규화 항으로 추가합니다: `loss.harp_align_weight = 0.1`을 초기값으로 스윕. 단, D19(a) 완전 동결 기준과의 긴장 관계 주의: HARP 정렬 손실이 VLM 백본 파라미터를 업데이트하는 방향으로 작용한다면 D19(a) 위반입니다. 따라서 정렬 손실을 VLM 출력 특징에만 적용하고 역전파를 백본에 전파하지 않는 `stop_gradient` 변형을 먼저 실험합니다.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

MMD 정렬 손실은 배치 내 인간·로봇 비디오가 동시에 공급되어야 효과적입니다. 배치 구성에서 도메인 비율이 불균형하면 정렬이 한 쪽 도메인 분포를 지배해 VLM 표현이 왜곡될 수 있습니다. 또한 HARP의 실험이 인핸드 다지 조작이 아닌 일반 조작 태스크 중심인지 확인이 필요합니다.

## 💡 컨텍스트 제안

### 📌 Tracked literature

1. **Wall-OSS-0.5** [arXiv:2605.30877](https://arxiv.org/abs/2605.30877) — 파인튜닝 없는 사전학습 전용 VLA 실행 능력을 직접 측정하는 유일한 오픈소스 4B 모델로, P4의 핵심 명제("사전학습 prior는 보존할 가치가 있는가")에 직접 실험 근거를 제공합니다. 현재 8편 cap에서 RT-2([arXiv:2307.15818](https://arxiv.org/abs/2307.15818))와의 교체를 2분기 재조정 시 검토해 주십시오(RT-2는 web/robot co-FT 원점 역할이 Qwen-VLA로 이미 대체 가능한 상태). 대안으로 §7 경쟁·유사 모니터링 테이블에 별도 행으로 추가하는 방안도 가능합니다.

2. **LP-DS (Lagrangian Perturbation Diffusion Steering)** [arXiv:2606.01151](https://arxiv.org/abs/2606.01151) — 동결 플로우 매칭 정책의 노이즈 공간 perturbation이라는 신규 메커니즘으로, D20 v1 액션 사이드 어댑터 전략의 경량 구현 대안입니다. 핀 논문 추가보다는 D21 Stage 2.5 구현 옵션으로 Decision Log에 기록하는 것이 적합합니다.

### 📌 Decision Log

1. **D21** — Stage 2와 Stage 3 사이에 `Stage 2.5 (경량 액션 적응: LP-DS noise-space perturbation 또는 IDM 보조 모듈, 완전 동결 백본 유지)` 항목 추가를 제안합니다. 진입 조건: Stage 2 in-distribution 성공률 플래토 + 상태 별칭율 > 15%. LP-DS를 먼저, IDM을 두 번째, LoRA(Stage 3)를 세 번째 순서로 시도합니다. 이 순서는 백본 교란 최소화 원칙을 단계별로 적용하는 D20 v1 방향과 일관됩니다.

2. **D19 트리거 조건 구체화** — 상태 별칭(state aliasing) 측정을 D19(d) LoRA 전환 트리거의 정량 기준으로 추가해 주십시오: "Stage 2 완료 후 k-NN(k=5) 이웃 평균 액션 분산 > 15%, IDM 보조 후에도 해소 불가" 조건을 v1에 명시하면 트리거 발동 기준이 명확해집니다.

3. **D22** — HARP-VLA의 MMD 정렬 손실(L_align)을 Stage 0½ 공동 학습 레시피의 보조 정규화 항 후보로 D22 deferred 항목에 기록해 주십시오. 단 `stop_gradient` 변형(VLM 백본에 역전파 차단)을 조건으로 명시해야 D19(a) 동결 원칙과 충돌하지 않습니다.

- §7 경쟁 라인업 신규 대규모 릴리스 없음. PriorVLA·MolmoAct2 인용 축적이 느린 상태로 분화 가설(완전 동결 + split-heads-as-adapter + 플로우 매칭 헤드 조합의 최소 교란 우위)은 유지됩니다.

## 🔄 직전 리포트 대비 종합

- **직전 P4 보고서 (2026-06-01)**: Qwen-VLA([arXiv:2605.30280](https://arxiv.org/abs/2605.30280)), BORA([arXiv:2605.30226](https://arxiv.org/abs/2605.30226)), VERA([arXiv:2605.27817](https://arxiv.org/abs/2605.27817)), VLA-Trace([arXiv:2605.30117](https://arxiv.org/abs/2605.30117)). 이번 회차 채택 4편 모두 중복 없음.
- **연구 흐름 연속성**: 직전 리포트(2026-06-01)가 "동결 백본의 적용 범위를 넓힌다"(Qwen-VLA: 다중 구현체, BORA: RL 사후학습, VERA: 비디오 모델 백본)는 흐름이었다면, 이번 회차는 "동결 백본이 실제로 얼마나 유용한가를 측정하고 부족할 때 어떻게 최소 개입으로 보완하는가"로 초점이 이동합니다. Wall-OSS-0.5(측정), LP-DS(경량 noise-space 보완), State Aliasing(IDM 경량 보완) 세 논문이 이 질문에 각기 다른 각도로 답합니다.
- **D# 트리거 신호**: D19(d) LoRA 전환 트리거는 아직 발동되지 않았으나, 이번 회차에서 State Aliasing 논문이 "VLM 동결 표현이 불충분할 수 있는 구체적 메커니즘(상태 별칭)"과 그 측정 방법을 제시했습니다. D21 Stage 2.5 삽입 근거도 LP-DS와 IDM 두 경로가 구체화되었습니다.
- **Anti-topic 필터 건강도**: 이번 스캔에서 Anti-topic 범주 배제 논문 약 280건. "백본 보존 분석 없는 full-FT VLA", "인간형 로코모션/whole-body tracking 전용", "추론 최적화·양자화 집중 논문"이 대다수.
- **월간 트렌드 노트**: 2026년 6월 2주차(이번 회차)에는 동결 prior 가치 측정(Wall-OSS-0.5)과 경량 적응(LP-DS, IDM)이 동시에 부상합니다. 직전 5월 말 ~ 6월 초의 "동결 원칙 확장"(Qwen-VLA·VERA) 흐름에서 "동결 원칙의 한계 측정 + 경량 보완"으로 연구 프런티어가 이동하는 추세입니다. 6월 중에는 Wall-OSS-0.5의 공개 체크포인트 출시 여부와 LP-DS 코드 공개를 중점 모니터링 권고합니다.
