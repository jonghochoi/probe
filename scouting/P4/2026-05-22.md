[arXiv:2605.19282](https://arxiv.org/abs/2605.19282) · Chongyu Fan, Gaowen Liu, Mingyi Hong, Ramana Rao Kompella, Sijia Liu · 2026-05-19 · source: Keyword Sweep (HTTPS, 쿼리 2)

D21 Stage 3/4 진입 시 LoRA·어댑터 레이어의 옵티마이저 선택에 직접적인 근거를 제공하며, D19 v1(완전 동결) 이후 단계에서 어떤 옵티마이저가 VLM prior를 덜 훼손하는지를 실험으로 규명합니다.

### ✨ (b) 진정으로 새로운 점

기존 연구들은 옵티마이저를 "언제 바꾸는가"만 논의했습니다. 이 논문은 "왜 VLA 미세조정에서 Muon이 망가지는가"를 스펙트럼 관점에서 설명합니다. 해결책인 **Pion** 옵티마이저는 Promotion+Suppression 2단계 high-pass spectral 필터를 도입해 주요 특이값은 1로 유지하고 노이즈 tail은 0으로 억제합니다. π0.5 백본 + 실제 Franka Research 3 로봇에서 검증했으며, VLA-Adapter 아키텍처로 LIBERO Object 100% 성공률 달성 (Muon 97.0%, AdamW 32.2% 대비). per-head 모드로 사전학습 어텐션 헤드 이질성을 보존한다는 점도 D19 방향과 일치합니다.

### ⚙️ (c) 의사결정 함의

[D21](#ref-D21) Stage 3/4 진입 시 LoRA·어댑터 레이어의 기본 옵티마이저를 `AdamW` → `Pion`으로 교체합니다. 구체 적용: (1) `optimizer=Pion(high_pass_strength=β)` — β는 소규모 LIBERO 스윕(0.1–0.5)으로 결정, (2) per-head 모드 활성화: 어텐션 헤드별 독립 spectral 업데이트로 사전학습 헤드 이질성 보존, (3) 모니터링 지표: 액션 모듈 그래디언트 랭크 및 head/tail 특이값 비율을 학습 초기 단계에 기록해 tail 증폭 여부 조기 탐지. [CP1](#ref-CP1) 체크리스트 추가: "Stage 3 옵티마이저 선택 에블레이션 (Pion vs AdamW), VQA 벤치마크로 VLM 역량 보존 확인."

### ⚠️ (d) 먼저 검증해야 할 실패 모드

(1) 논문 실험은 VLA-Adapter(l₁-regression)·VLANeXt(flow-matching) 아키텍처 기준입니다. π0 split-head + flow-matching 아키텍처에서 Pion이 동일하게 작동하는지는 우리가 직접 검증해야 합니다. (2) `high_pass_strength` β를 과도하게 설정하면 주요 특이값이 억제되어 언어·시각 표현 모듈에 간섭이 생길 수 있습니다 — Stage 3 시작 직후 VQA/GQA 멀티모달 벤치마크로 VLM 역량 저하 여부를 측정해야 합니다. (3) per-head 모드가 추가 계산 비용 없다고 논문은 주장하지만, π0 PaliGemma 계열 대규모 백본에서의 실제 학습 처리량은 아직 미확인 항목입니다.

[arXiv:2605.10821](https://arxiv.org/abs/2605.10821) · Junjie Lu, Xinyao Qin, Yuhua Jiang, Kaixin Wang, Chuheng Zhang, Bin Liang · 2026-05-11 · source: Keyword Sweep (HTTPS, 쿼리 2)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4), [D19](#ref-D19), [D20](#ref-D20). 저자들은 "사전학습 VLA를 완전히 동결한 채 가벼운 노이즈 액터만 업데이트"하는 방식으로 D19 v1(완전 동결 + 액션 전문가)과 D20 v1(액션 측 어댑터)의 설계 방향을 실제 로봇에서 검증합니다. noise-space RL과 인간 교정 시연을 통합해 데이터 효율적 적응을 달성하는 UniSteer 프레임워크가 그 결과물입니다.

### ✨ (b) 진정으로 새로운 점

noise-space RL(사전학습 VLA 동결 + 노이즈 액터만 학습)의 탐색 비효율 문제를 해결하기 위해, 인간 교정 시연을 action-space → noise-space로 역변환(action-to-noise inversion)해 학습 신호를 제공합니다. 동일한 노이즈 액터가 RL 목적 함수와 인간 교정 지도 신호를 동시에 수신하므로 별도의 reference network나 모델 복사본이 불필요합니다. 4개의 실제 조작 과제에서 평균 66분 만에 성공률 20% → 90% 달성, noise-space RL 단독과 action-space HITL 베이스라인을 모두 능가합니다.

### ⚙️ (c) 의사결정 함의

[D19](#ref-D19) v1의 "완전 동결 + 액션 전문가" 패턴이 실 로봇 적응에서도 유효함을 독립 검증합니다. 파이프라인 적용: [D20](#ref-D20) v1의 액션 측 어댑터를 표준 SFT 대신 noise-actor 업데이트로 구현할 경우 `noise_actor_lr`과 `rl_exploration_coeff` 두 하이퍼파라미터만 조정하면 됩니다. [D21](#ref-D21) Stage 2 plateau 도달 시 Stage 3 전환 전에 UniSteer 적응 패턴(소규모 실 로봇 데이터 + 인간 교정 66분 내)을 먼저 시도하는 것을 권장합니다. [CP1](#ref-CP1) 체크리스트 추가: "Stage 3 진입 직전 noise-actor 경로(UniSteer) vs. LoRA SFT 비교 에블레이션."

### ⚠️ (d) 먼저 검증해야 할 실패 모드

(1) action-to-noise inversion이 π0 flow-matching 디코더에서 수치적으로 안정적인지 직접 확인이 필요합니다 — 역변환은 근사이므로 denoising trajectory가 길수록 오차 누적이 증가합니다. (2) 코드 미공개로 `rl_exploration_coeff` 등 하이퍼파라미터 구현 세부 사항을 직접 재현해야 합니다. (3) 4개 과제가 모두 그립-앤-플레이스 계열로 추정됩니다. 다지 인핸드 조작의 고차원 접촉 집약적 공간에서도 noise-space RL 효율이 유지될지는 추가 실험으로 검토할 열린 문제입니다.

## 🥉 논문 3 — 우선순위 ★

**RotVLA: Rotational Latent Action for Vision-Language-Action Model**
[arXiv:2605.13403](https://arxiv.org/abs/2605.13403) · Qiwei Li, Xicheng Gong, Xinghang Li, Peiyan Li, Quanyun Zhou, Hangjun Ye · 2026-05-13 · source: Keyword Sweep (multi-embodiment/cross-embodiment 스윕)

### 🎯 (a) 관련 Pillar / Decision (P# / D#)

[P4](#ref-P4), [D23](#ref-D23), [D22](#ref-D22). 저자들은 D23 v1(연속 플로우 매칭 헤드)의 방향과 정렬되는 연속 잠재 액션 표현을 행렬군(SO(n))을 이용해 제안합니다. D22(다중 구체화 사전학습 데이터) 관련으로는 이종(heterogeneous) 로봇 데이터셋과 인간 비디오를 단일 잠재 액션 공간으로 통합하는 새로운 방법을 내놓습니다. π prior 초기화를 다중 구체화로 확장하는 직접적 경로를 제시합니다.

### ✨ (b) 진정으로 새로운 점

기존 Latent Action Models(LAMs)의 이산 양자화 파이프라인 — 자명한 프레임 재구성 동작, 제한적 표현 용량, 물리적 의미 구조 부재 — 을 지적하고 잠재 액션을 SO(n) 원소(회전군)로 모델링합니다. SO(n) 위에서 작동하므로 잠재 액션이 연속적이고, 서로 합성할 수 있으며, 기하 구조가 실제 동작과 맞물립니다. VLM 백본 + 플로우 매칭 액션 헤드 + SO(n) 잠재 플래너를 위아래로 쌓은 구조로, 잠재 플래너가 고수준 지침을 내려보내고 플로우 매칭 헤드가 로봇 액션을 생성합니다. 1.7B 파라미터로 LIBERO 98.2% / RoboTwin2.0 89.6%(clean)/88.5%(randomized) 달성 + 실 로봇 조작 검증.

### ⚙️ (c) 의사결정 함의

[D23](#ref-D23) v1의 "연속 플로우 매칭 헤드"를 SO(n) 잠재 플래너 계층 추가로 확장하는 로드맵을 제시합니다. 구체 적용: (1) π0 action expert 위에 SO(n) 잠재 플래너를 상위 계층으로 추가 — 하이퍼파라미터 `latent_dim_n`(군의 차수)·`triplet_margin`(프레임 학습 정규화), (2) D22 v1의 "π prior만 의존"에서 벗어나 SO(n) 잠재 공간으로 이종 데이터셋 통합을 검토, (3) 모니터링 지표: LIBERO-Plus / RoboTwin2.0 성공률로 D23 v1 플로우 매칭 헤드 단독 대비 개선 여부 측정. [CP1](#ref-CP1) 이전 에블레이션 목록에 "D23 v1 vs RotVLA 잠재 플래너 추가 비교" 추가.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

(1) SO(n) 잠재 액션이 π0 백본(PaliGemma 계열)과 직접 호환되는지 검증되지 않았습니다 — RotVLA의 VLM 백본 계열을 논문 초록이 밝히지 않아 별도 확인이 필요합니다. (2) SO(n) 구조의 triplet 학습에서 잠재 공간이 다지 조작(15–22 DoF 고차원 공간)과 얼마나 정렬되는지는 미검증입니다. (3) 1,700+ 시간의 이종 데이터셋 사전학습이 현재 파이프라인의 π prior 초기화와 맞물릴지는 아직 열린 질문입니다.

ControlNet 아이디어를 내비게이션 기반 모델에 적용합니다: 사전학습된 백본의 완전한 사본을 학습 가능 분기로 추가하고 zero-initialized residual pathway로만 그래디언트를 흘려 기하학적 단서(깊이 정보)를 학습합니다. 원본 백본은 동결을 유지합니다. 사전학습 일반화를 유지하면서 in-domain 기하학을 습득하고, 미세조정 데이터셋 범위를 넘어서는 액션 예측 개선이 오프라인 분석에서 확인됩니다.

### ⚙️ (c) 의사결정 함의

[D20](#ref-D20) v1의 "액션 측 어댑터" 설계에 ControlNet 스타일 zero-init residual 적용을 검토합니다. 구체 적용: (1) π0 split-head action expert에 frozen backbone copy + zero-initialized residual branch 추가로 새로운 모달리티(촉각·깊이) 수용, (2) 하이퍼파라미터 `residual_init=zeros`·`depth_conditioning_scale`(0.5–1.0 범위 스윕), (3) 대조 실험: zero-init residual vs 랜덤 초기화 residual로 사전학습 prior 보존 차이 측정. [D21](#ref-D21) Stage 3 진입 조건 체크리스트에 "zero-init residual 어댑터 에블레이션" 추가.

### ⚠️ (d) 먼저 검증해야 할 실패 모드

(1) 실험이 내비게이션 도메인(장애물 회피·목표 도달)에 한정되어 있어 접촉 집약적 다지 조작에서 zero-init residual의 수렴 속도를 별도 검증해야 합니다. (2) 백본 사본을 추가하면 메모리 사용량이 약 2배로 증가합니다 — 현재 파이프라인 GPU 메모리 예산과의 호환성 확인이 필요합니다.
