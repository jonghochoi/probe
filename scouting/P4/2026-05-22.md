## 🥇 논문 1 — 우선순위 ★★★

**Rethinking Muon Beyond Pretraining: Spectral Failures and High-Pass Remedies for VLA and RLVR**
[arXiv:2605.19282](https://arxiv.org/abs/2605.19282) · Chongyu Fan, Gaowen Liu, Mingyi Hong, Ramana Rao Kompella, Sijia Liu · 2026-05-19 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **위치** — Muon 옵티마이저가 VLA 미세조정 단계에서 실패하는 구조적 메커니즘을 최초 실증
- **진단** — 액션 모듈 그래디언트가 본질적으로 저랭크(low-rank), Muon의 스펙트럼 균등화가 노이즈성 tail 방향을 증폭해 VLM 사전학습 표현 교란
- **Pion 옵티마이저** — Promotion+Suppression 2단계 high-pass spectral 필터 도입, 주요 특이값은 1로 유지하고 노이즈 tail은 0으로 억제
  - 기존 연구는 옵티마이저 교체 "시점"만 논의, 본 논문은 "왜 VLA 미세조정에서 Muon이 망가지는가"를 스펙트럼 관점에서 설명
  - per-head 모드로 사전학습 어텐션 헤드 이질성 보존
- **결과** — π0.5 백본 + 실제 Franka Research 3 로봇 검증, VLA-Adapter 아키텍처로 LIBERO Object 100% 성공률(Muon 97.0%, AdamW 32.2% 대비)

### (c) 시사점

- **옵티마이저 선택 근거** — 동결 이후 단계에서 어떤 옵티마이저가 VLM 사전학습 표현을 덜 훼손하는지 실험적 근거 확보
- **헤드 이질성 보존** — per-head spectral 업데이트로 사전학습 어텐션 헤드 구조 유지 가능
- **모니터링 지표 후보** — 액션 모듈 그래디언트 랭크 및 head/tail 특이값 비율로 tail 증폭 조기 탐지

### (d) 먼저 확인할 점

- **아키텍처 미일치** — 실험이 VLA-Adapter(l₁-regression)·VLANeXt(flow-matching) 기준, π0 split-head + flow-matching 구조에서 Pion 동일 작동 여부 직접 검증 필요
- **필터 강도 위험** — high-pass 강도를 과도 설정 시 주요 특이값이 억제되어 언어·시각 표현 모듈 간섭 가능, 멀티모달 벤치마크로 VLM 역량 저하 측정 필요
- **처리량 미확인** — per-head 모드가 추가 계산 비용 없다는 주장이나 PaliGemma 계열 대규모 백본에서 실제 학습 처리량 미확인

## 🥈 논문 2 — 우선순위 ★★

**Unified Noise Steering for Efficient Human-Guided VLA Adaptation**
[arXiv:2605.10821](https://arxiv.org/abs/2605.10821) · Junjie Lu, Xinyao Qin, Yuhua Jiang, Kaixin Wang, Chuheng Zhang, Bin Liang · 2026-05-11 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **위치** — 사전학습 VLA를 완전히 동결한 채 가벼운 노이즈 액터만 업데이트하는 방식을 실제 로봇에서 검증, UniSteer 프레임워크
- **action-to-noise inversion** — noise-space RL의 탐색 비효율 문제 해결을 위해 인간 교정 시연을 action-space → noise-space로 역변환해 학습 신호 제공
  - 동일 노이즈 액터가 RL 목적 함수와 인간 교정 지도 신호를 동시 수신, 별도 reference network나 모델 복사본 불필요
- **결과** — 4개 실제 조작 과제에서 평균 66분 만에 성공률 20% → 90% 달성, noise-space RL 단독과 action-space HITL 베이스라인 모두 능가

### (c) 시사점

- **동결 패턴 독립 검증** — "완전 동결 + 액션 전문가" 패턴이 실 로봇 적응에서도 유효함을 독립 검증
- **저비용 적응 경로** — 동결 백본 + 가벼운 액션 어댑터로 소규모 실 로봇 데이터 + 인간 교정 66분 내 적응 가능

### (d) 먼저 확인할 점

- **수치 안정성** — action-to-noise inversion이 flow-matching 디코더에서 수치적으로 안정적인지 직접 확인 필요, 역변환은 근사이므로 denoising trajectory가 길수록 오차 누적 증가
- **재현성** — 코드 미공개로 하이퍼파라미터 구현 세부 직접 재현 필요
- **다지 확장 미검증** — 4개 과제가 모두 그립-앤-플레이스 계열 추정, 다지 인핸드 조작 고차원 접촉 집약적 공간에서 noise-space RL 효율 유지 여부 추가 검토

## 🥉 논문 3 — 우선순위 ★

**RotVLA: Rotational Latent Action for Vision-Language-Action Model**
[arXiv:2605.13403](https://arxiv.org/abs/2605.13403) · Qiwei Li, Xicheng Gong, Xinghang Li, Peiyan Li, Quanyun Zhou, Hangjun Ye · 2026-05-13 · source: keyword-sweep

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **위치** — 연속 잠재 액션 표현을 행렬군(SO(n))으로 제안, 이종(heterogeneous) 로봇 데이터셋과 인간 비디오를 단일 잠재 액션 공간으로 통합
- **SO(n) 잠재 액션** — 기존 잠재 액션 모델(LAMs)의 이산 양자화 파이프라인(자명한 프레임 재구성, 제한적 표현 용량, 물리적 의미 구조 부재) 지적, 잠재 액션을 SO(n) 원소(회전군)로 모델링
  - SO(n) 위에서 작동 → 잠재 액션이 연속적·합성 가능, 기하 구조가 실제 동작과 맞물림
  - VLM 백본 + 플로우 매칭 액션 헤드 + SO(n) 잠재 플래너를 적층, 잠재 플래너가 고수준 지침을 내려보내고 플로우 매칭 헤드가 로봇 액션 생성
- **결과** — 1.7B 파라미터로 LIBERO 98.2% / RoboTwin2.0 89.6%(clean)/88.5%(randomized) 달성 + 실 로봇 조작 검증

### (c) 시사점

- **이종 데이터 통합 경로** — π 사전학습 prior에만 의존하지 않고 SO(n) 잠재 공간으로 이종 데이터셋 통합 가능성
- **표현 계층 확장** — 연속 플로우 매칭 헤드 위에 SO(n) 잠재 플래너 계층을 추가하는 로드맵 제시

### (d) 먼저 확인할 점

- **백본 호환성** — SO(n) 잠재 액션이 PaliGemma 계열과 직접 호환되는지 미검증, VLM 백본 계열을 초록이 밝히지 않아 별도 확인 필요
- **다지 정렬 미검증** — SO(n) triplet 학습에서 잠재 공간이 다지 조작(15–22 DoF 고차원 공간)과 얼마나 정렬되는지 미검증
- **사전학습 정합** — 1,700+ 시간 이종 데이터셋 사전학습이 π prior 초기화와 맞물릴지 열린 질문

## 🌱 논문 4 — 인접 분야 픽

**D-CLING: Prior-Preserving Depth-Conditioned Fine-Tuning for Navigation Foundation Models**
[arXiv:2605.19690](https://arxiv.org/abs/2605.19690) · Shintaro Nakaoka, Takayuki Kanai, Kazuhito Tanaka · 2026-05-19 · adjacent field: Navigation Foundation Models — P4 VLM 보존 × ControlNet 스타일 적응

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **위치** — 내비게이션 기반 모델(NFM)을 대상으로 사전학습 백본의 동결 사본을 zero-initialized residual pathway로만 학습시키는 ControlNet 스타일 적응, 액션 측 어댑터 패턴의 인접 도메인 독립 검증
- **ControlNet 스타일 적응** — 사전학습 백본의 완전한 사본을 학습 가능 분기로 추가하고 zero-initialized residual pathway로만 그래디언트를 흘려 기하학적 단서(깊이 정보) 학습, 원본 백본은 동결 유지
- **결과** — 사전학습 일반화를 유지하면서 in-domain 기하학 습득, 미세조정 데이터셋 범위를 넘어서는 액션 예측 개선이 오프라인 분석에서 확인

### (c) 시사점

- **zero-init residual 참조** — 액션 측 어댑터 설계에 ControlNet 스타일 zero-init residual을 새로운 모달리티(촉각·깊이) 수용 경로로 검토 가능
- **단계적 적응 정합** — 사전학습 정렬을 유지한 채 in-domain 적응을 더하는 방향이 staged 학습 철학과 직접 맞닿음

### (d) 먼저 확인할 점

- **조작 도메인 미검증** — 실험이 내비게이션 도메인(장애물 회피·목표 도달) 한정, 접촉 집약적 다지 조작에서 zero-init residual의 수렴 속도 별도 검증 필요
- **메모리 비용** — 백본 사본 추가로 메모리 사용량 약 2배 증가, GPU 메모리 예산 호환성 확인 필요
