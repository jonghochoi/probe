## 🥇 논문 1 — 우선순위 ★★★

**FlowPRO: Reward-Free Reinforced Fine-Tuning of Flow-Matching VLAs via Proximalized Preference Optimization**
[arXiv:2606.05468](https://arxiv.org/abs/2606.05468) · Yihao Wu, He Zhang, Junbo Tan, Xueqian Wang, Zhengyou Zhang · 2026-06-03 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **문제 진단** — 플로우 매칭 VLA의 사후 학습(post-training)에서 SFT·DAgger는 실패 신호를 간접적으로만 활용, 보상 기반 RL은 실환경 보상 설계 및 크리틱 학습 난이도 때문에 병목
- **RPRO 목적함수** — 플로우 매칭 액션 헤드에 특화한 선호 최적화(Robotic Flow-matching Proximalized Preference Optimization) 제안
  - 대조 목적함수(contrastive optimizer)에 명시적 근접 정규화 항(proximal regularizer) 추가 → Flow-DPO의 보상 해킹 실패 모드 제거
  - VLM 백본 전체 동결 상태에서 플로우 매칭 헤드만 최적화
- **데이터 수집 패러다임** — 원격 조작 개입-롤백(intervention-and-rollback) 방식으로 단일 조작자 개입에서 양성·음성 궤적 쌍 `(τ^w, τ^l)`을 자동 생성; Smooth Interpolation + 배치 혼합으로 희소 교정을 밀집 상태 단위 지도로 변환
- **결과** — 4개 장거리 양팔(bimanual) 실환경 태스크에서 4개 기준선 대비 최고 성공률 달성; 각 손실 구성 요소 기여 어블레이션 확인

### (c) 시사점

- **플로우 매칭 헤드 전용 사후 학습 레시피 확보** — Stage 2 이후 플로우 매칭 액션 헤드를 백본 완전 동결 상태에서 개선하는 구체 절차(RPRO + 개입-롤백 데이터 수집) 확보
- **보상 설계 부담 없는 RL 루프** — 별도 보상 함수 없이 조작자 개입만으로 선호 쌍 구성 → 실환경 데이터 수집 파이프라인에 통합 가능
- **Stage 2 → Stage 2.5 연결** — 직전 리포트(2026-06-05)에서 제안된 Stage 2.5 경량 적응 슬롯에 RPRO를 Phase-aware ER(PHASER)·LP-DS·IDM과 함께 추가 후보로 기록 가능

### (d) 먼저 확인할 점

- **데이터 분포 의존** — 선호 쌍 품질이 조작자 개입 시점의 기저 정책 성능에 직접 의존; 기저 정책이 충분히 나쁘면 양성 궤적도 낮은 품질
- **단일 플로우 헤드 가정** — 논문의 RPRO는 단일 플로우 매칭 헤드를 가정; 바디·핸드 전문가가 분리된 split-heads 아키텍처에서 각 헤드별 RPRO 적용 가능한지 미확인
- **확인** — LIBERO에서 RPRO와 단순 SFT의 단일 헤드 vs. split-head 성공률 차이를 먼저 비교해 아키텍처 의존성 확인

## 🥈 논문 2 — 우선순위 ★★

**DRIFT: A Residual Flow Adapter for Decoding Continuous Outputs in Vision-Language Models**
[arXiv:2606.05758](https://arxiv.org/abs/2606.05758) · Zhuoming Liu, Jinhong Lin, Kwan Man Cheng, Lin Zhang, Shayok Bagchi, Yin Li · 2026-06-04 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **공백** — 자기회귀 이산 토큰 기반 VLM은 텍스트 출력에 특화, 연속값(로봇 제어 액션, 시간 경계 등) 출력에 부적합
- **DRIFT 아키텍처** — 동결 VLM 위에 잔차 플로우(residual flow) 어댑터를 추가
  - **기저 예측기(base predictor)** — 동결 VLM이 조잡한 연속값 추정치 생성
  - **플로우 정제기(flow-based refinement)** — 기저 예측 주변의 잔차 분포만 학습, 전체 출력 분포 대신 국소 잔차 분포 모델링
  - 잔차 공식화(residual formulation)가 최적화 문제를 전역 분포 학습에서 강한 사전(prior) 주변의 국소 분포 학습으로 단순화
- **광범위한 검증** — 시각적 그라운딩(visual grounding) + 로봇 제어 두 도메인 × MLLMs, VLAs, WAMs 여러 아키텍처에서 일관된 성능 향상

### (c) 시사점

- **D19+D20+D23 조합의 실증 근거** — 동결 VLM + 플로우 매칭 잔차 어댑터가 여러 아키텍처에서 작동함을 실증; split-heads-as-adapter + 플로우 매칭 헤드 조합의 외부 지지 근거 추가
- **잔차 공식화 참조** — 우리 플로우 매칭 헤드 학습에서 목표 분포 직접 학습 대신 VLM 출력 대비 잔차 분포 학습으로 전환 시 수렴 안정성 향상 가능성
- **평가 벤치마크 확장** — 시각적 그라운딩·로봇 제어 동시 벤치마크 구성이 VLM 보존 품질 측정의 다차원 기준으로 활용 가능

### (d) 먼저 확인할 점

- **기저 예측기 품질 의존** — 잔차 플로우가 기저 예측기(동결 VLM)의 조잡한 추정에 의존; 기저 VLM이 전혀 로봇 제어를 학습한 적 없으면 잔차가 지역 분포가 아닌 전체 분포가 되어 이점 소멸
- **아키텍처 종속성** — MLLM / VLA / WAM 세 아키텍처에서 검증되었지만 구체 파라미터(잔차 헤드 크기, 플로우 단계 수) 보고가 초록에 없음
- **확인** — PaliGemma 기반 π0 설정에서 잔차 플로우 헤드 크기(파라미터 수)와 플로우 매칭 스텝 수를 LIBERO에서 그리드 서치로 먼저 정량화

## 🥉 논문 3 — 우선순위 ★

**ActiveMimic: Egocentric Video Pretraining with Active Perception**
[arXiv:2606.06194](https://arxiv.org/abs/2606.06194) · Xingyao Lin, Guojin Zhong, Tianyi Lu, Ziyi Ye, Yichen Zhu, Zuxuan Wu, Yu-Gang Jiang · 2026-06-04 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **공백 규명** — 에고센트릭 인간 비디오(egocentric human video)로 사전학습한 모델이 로봇 데이터 사전학습 모델 대비 일관되게 저성능인 이유를 처음으로 실험적으로 규명
- **핵심 원인 — 능동 지각 격차(active perception gap)** — 인간이 조작 중 지속적으로 시점을 재조정하는 카메라 움직임이 기존 파이프라인에서 노이즈로 처리
- **ActiveMimic 프레임워크**
  - 단일 착용형 RGB 카메라에서 동기화된 카메라 궤적 + 손목 궤적을 복원
  - 카메라 모션을 시점 액션(viewpoint action)으로 모델링
  - 능동 지각과 조작을 인-더-와일드 에고센트릭 비디오로 동시 학습 후 목표 로봇으로 적응
- **결과** — 실환경 다양한 능동 지각 요구 태스크에서 에고센트릭 비디오 사전학습 기준선을 일관 상회; 로봇 데이터 사전학습 SOTA 모델과 동등 성능

### (c) 시사점

- **에고 비디오 활용 조건 명확화** — D22 v1(π 사전학습 prior 의존, 추가 공동 학습 없음)에서 에고 비디오를 보강 데이터로 고려 시, 능동 지각 신호 복원 여부가 핵심 조건임을 정량적으로 규명
- **데이터 카탈로그 분류 기준** — `catalogs/dataset.md` 인간 비디오 항목에 "고정 카메라 에고 비디오 vs. 능동 카메라 에고 비디오" 분류 추가 근거
- **D22 발동 전 검증 루틴** — 에고 비디오 데이터 추가 실험 전, 카메라 움직임 포함 여부를 데이터 품질 메타 조건으로 기록해야 함

### (d) 먼저 확인할 점

- **카메라 모션 복원 비용** — 카메라 + 손목 궤적 동시 복원이 별도 pose estimator를 요구하는지, 단일 RGB 카메라만으로 완결되는지 초록에 명확하지 않음
- **태스크 유형 의존** — 실험이 "다양한 능동 지각 요구 태스크"로 기술; 정밀한 인핸드 접촉 시퀀스처럼 카메라 모션이 거의 없는 태스크에서도 이점이 유지되는지 미확인
- **확인** — 코드 공개 여부 확인 후, 고정 카메라 에고 비디오 대비 능동 카메라 에고 비디오의 성공률 차이를 단일 고정 카메라 환경에서 먼저 비교

## 🌱 논문 4 — 크로스폴리네이션

**Flow-based Policy Adaptation without Policy Updates**
[arXiv:2606.06461](https://arxiv.org/abs/2606.06461) · Luzhe Sun, Jingtian Ji, Haoran Chen, Jiawei Zhou, Matthew R. Walter · 2026-06-04 · adjacent field: 테스트 타임 플로우 기반 액션 보정 · source: Keyword Sweep (catastrophic forgetting VLA 스윕)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23)

### (b) 핵심 기여

- **착안점** — 사전학습 정책·기반 모델·인간 조작자의 액션이 비최적·노이즈·분포 이탈일 때, 정책 파라미터를 전혀 수정하지 않고 액션을 보정하는 테스트 타임 메커니즘
- **GLOVES** — 소규모 전문가 데모로 훈련된 플로우가 비전문가 액션을 전문가 액션 분포로 이동(transport); 역방향 플로우 평가(reverse flow evaluation)가 자연스러운 분포 내 점수(in-distribution score) 제공
  - **개입 게이트(intervention gate)** — 역방향 플로우 점수가 높은 액션(전문가 분포와 일치)은 통과, 이탈 액션만 보정 → 필요할 때만 개입
- **결과** — 제한된 전문가 지도로 다양한 태스크·환경에서 성공률 향상, 공개 코드 제공

### (c) 시사점

- **동결 정책 위 테스트 타임 보정 경로** — 플로우 매칭 헤드의 출력 액션을 파이프라인 말단에서 외부 보정 플로우로 교정하는 패턴은 D19 동결 원칙과 무충돌
- **선택적 개입 설계** — 역방향 플로우 점수를 이상 감지(anomaly detection) 메커니즘으로 활용, Stage 2 이후 "언제 보정이 필요한가"를 정량화하는 도구로 검토 가능

### (d) 먼저 확인할 점

- **전문가 데모 의존** — 소규모라도 태스크별 전문가 데모가 필요, 완전 zero-shot 적용 불가
- **플로우 보정 한계** — 플로우가 국소 액션 분포 이동으로 작동하므로 기저 정책이 완전히 잘못된 행동을 출력할 때 보정 범위를 초과할 우려
- **확인** — LIBERO에서 GLOVES 보정과 FlowPRO 미세조정의 성공률 변화량 비교, 데이터 요구량(전문가 데모 수) 대비 효과 측정

- **제안** — D23 v1(연속 플로우 매칭 헤드)의 핀 논문 후보; 8편 cap에서 다음 분기 재조정 시 VLM2VLA([arXiv:2509.22195](https://arxiv.org/abs/2509.22195))와의 교체 검토
  - 근거 — VLM2VLA는 §7 경쟁 모니터링에서 계속 추적 가능; FlowPRO는 D23 사후 학습 레시피의 첫 실증 논문으로 역할 명확

### Decision Log

- **D21 Stage 2.5 옵션 업데이트** — FlowPRO(2606.05468)를 Stage 2.5 슬롯에 추가
  - 직전 리포트(2026-06-05)에서 PHASER 추가 후 세 번째 옵션으로 기록 제안
  - 우선순위 순서 업데이트 제안: LP-DS → IDM → PHASER → FlowPRO(백본 교란 정도 오름차순, FlowPRO는 플로우 헤드만 건드리므로 백본 교란 없음 측면에서 PHASER와 동급이지만 선호 최적화 학습 비용이 더 높음)
- **D23 플로우 매칭 헤드 설계에 잔차 공식화 후보 추가** — DRIFT(2606.05758) 근거
  - 현재 D23 v1은 "연속 플로우 매칭 헤드"로 단순 명시; 잔차 플로우 공식화(base predictor + flow refinement)를 D23 구현 옵션으로 deferred 항목에 기재 제안
  - 조건 — PaliGemma 기저 예측기가 충분히 정보적인지(비어있는 연속 예측이 아닌 의미 있는 기저 추정치 제공 여부) Stage 2 완료 후 검증 필요
- **D22 데이터 카탈로그 갱신 조건** — ActiveMimic(2606.06194) 근거
  - `catalogs/dataset.md` 인간 비디오 섹션에 "능동 카메라 에고 비디오 (camera motion as viewpoint action)" 항목과 ActiveMimic 논문을 ROI 참조로 추가 제안
  - D22 v1("추가 공동 학습 없음") 조건을 변경하기 전 능동 지각 복원 가능 여부 확인 항목으로 기재
