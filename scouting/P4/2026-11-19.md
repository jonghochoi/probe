## 🥇 논문 1

**Lift, See, Act: Hierarchical Robot Policy Pretraining with 3D Foundation Models**
[arXiv:2611.20481](https://arxiv.org/abs/2611.20481) · Yiyuan Ge 외 4명 · NeurIPS 2026 · source: keyword-sweep · 코드 공개 예정

**점수 11/15** · R3 · N2 · M3 · Real2 · Repro1 — NeurIPS Paper Checklist "the paper states that the code will be released"

### (a) 관련 Pillar / 질문
[![P4](https://img.shields.io/badge/P4-d0e4f8.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 논문 요지

- 인간 영상에서 손 궤적뿐 아니라 3D 중간 표현까지 지도로 사용
- **문제** — 인간 영상에는 행동 관련 표현이 없어 로봇 정책 사전학습 신호로 쓰기 어려움
  - 조작 데이터 수집 비용 때문에 인간 영상이 사전학습 데이터의 핵심 원천
- **기존 한계** — 두 갈래의 기존 추출 방식이 각각 한 가지를 놓침
  - **2D 시각 프리미티브** — 접촉점, 접촉 히트맵, 객체 박스는 3D 조작 과정의 시간적 표현이 없음
  - **3D 손 궤적 추정** — 3D 파운데이션 모델이 낸 희소 궤적만 지도로 남기고 기하 표현과 깊이 맵 같은 조밀한 정보를 버림
- **핵심 방법** — 3단계 계층 사전학습 Lift, See, Act
  - **Lift** — 여러 3D 파운데이션 모델의 중간 표현에 정책 얕은 층의 특징을 정렬, 정렬 손실 가중치는 적응적으로 조정
  - **See** — 깊이 맵 복원 보조 과제로 3D 공간 구조를 학습하고, 손 영역 가우시안 히트맵으로 인코더 어텐션을 상호작용 부위로 유도
  - **Act** — 미래 3D 손 궤적을 예측해 로봇 행동의 대리 신호로 사용
- **차별점** — 궤적만 남기던 방식과 달리 추출 과정에서 나오는 조밀 표현과 깊이 맵까지 지도로 활용
  - 원문은 여러 3D 파운데이션 모델의 다층 정보를 계층적 사전학습에 쓴 첫 접근이라고 주장
- **핵심 기여** — 시뮬레이션과 실물 모두에서 기존 최고 방법 대비 우위 보고
  - 시뮬레이션 MetaWorld, DexArt, Adroit에서 하위 정책에 명시적 3D 관측 없이 DP3, KAN-We-Flow와 대등하거나 높은 성능
  - 밝기 40% 감소 시 7.5% 하락, 무작위 가림 방해 시 18.7% 하락, 비교 기준선은 더 크게 하락
  - 실물 Franka Research 3 평균 성공률 68.3%, 가장 강한 기준선 HRP 41.7%
  - 궤적 지도 품질 효과를 따로 보는 ablation 수록
- **가치** — 인간 영상 사전학습의 지도 신호를 희소 궤적에서 조밀한 3D 표현으로 넓히는 경로 제시

### (c) 시사점

- 손 궤적 위에 깊이와 어텐션 지도를 얹어 코퍼스에서 더 뽑는 방향
- **추출 신호** — 궤적 품질뿐 아니라 추출 과정의 중간 산출물을 버리지 않는 설계가 비교 대상
- **배포 비용** — 하위 정책 학습에 명시적 3D 관측이 필요 없어 센서 부담 없음
- **도입 비용** — 공개 3D 파운데이션 모델 출력에 의존하나 코드는 공개 예정 단계

### (d) 먼저 확인할 점

- 저자가 인간-로봇 신체 격차를 한계로만 언급하고 이를 측정하지 않음
- 코드 미공개, 공개 예정 문구만 부록 체크리스트에 존재
- 실물 평가가 Franka Research 3 한 대의 소수 과제에 한정
- 손재주 평가는 시뮬레이션 DexArt와 Adroit 수준

## 🥈 논문 2

**EgoX: Egocentric Cross-Embodiment Manipulation with Embodiment Dreaming**
[arXiv:2611.16728](https://arxiv.org/abs/2611.16728) · Yaru Niu 외 21명 · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문
[![P4](https://img.shields.io/badge/P4-d0e4f8.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D6JW](https://img.shields.io/badge/D6JW-d97706.svg)](#ref-D6JW) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 인간·로봇·시뮬 데모를 모달리티 구조로 묶은 교차 신체 사전학습
- **문제** — 형태, 센서, 제어 인터페이스가 달라 인간·실제 로봇·시뮬레이션 데모를 합쳐 학습하기 어려움
  - 신체·과제·장면마다 데이터를 모으고 따로 학습하면 비용이 크고 경험 재사용이 제한됨
- **기존 한계** — 원문은 특정 선행 방법을 지목하지 않음
  - 이종 데모는 형태, 시점, 고유수용감각, 행동 의미, 동역학이 달라 합친 경험을 쓸 만한 능력으로 바꾸기 어렵다는 점만 지적
- **핵심 방법** — 세 요소로 구성
  - **통합 표현** — 해부학적·기능적으로 대응하는 모달리티로 신호를 묶고 자세를 공통 에고센트릭 프레임으로 표현
  - **MED(Modular Embodiment Dreamer)** — 신체 안에서 관측 모달리티마다 토크나이저, 행동 모달리티마다 전문가를 두고 신체 간 공유 트랜스포머 트렁크로 연결
  - **embodiment dreaming** — EMA 복사본이 인코딩한 미래 관측 잠재를 학습 전용 전문가가 예측, 픽셀 복원과 배포 시 추가 계산 없음
- **차별점** — 의미가 대응하는 모달리티로 전이하되 센서와 제어 인터페이스는 신체별로 유지
- **핵심 기여** — 5개 과제와 6개 신체에서 체계적 전이 연구
  - 13개 과제-신체 쌍에서 사전학습이 평균 과제 진행도를 0.63에서 0.80으로 상승, 13쌍 중 12쌍에서 최고
  - 분포 밖 조건에서 0.53에서 0.77로 상승
  - 사전학습 혼합을 넓힐수록 전이 향상, 7개 설정에서 dreaming이 0.63에서 0.78로 상승하고 신체 간 잠재 기하를 더 비슷하게 만듦
  - 모달리티를 합친 거친 변형에서는 큰 성능 하락
  - 실물 로봇 5종과 시뮬레이션 휴머노이드 1종 포함
- **가치** — 이종 신체 데모를 한 사전학습 레시피로 모으는 구조와 그 효과를 여러 신체에서 측정한 근거 제공

### (c) 시사점

- 코퍼스 혼합 폭과 모달리티별 행동 전문가의 효과를 직접 측정
- **코퍼스 구성** — 인간, 실제 로봇, 시뮬레이션 혼합을 넓힐수록 전이가 좋아진다는 절제 결과
- **행동 전문가** — 행동 모달리티마다 전문가를 공유 트렁크에 두는 구조, 모든 데이터를 한데 섞는 GR00T N1 접근과 대비되는 설계
- **배포 비용** — dreaming 헤드는 학습 전용이라 추론 비용 증가 없음

### (d) 먼저 확인할 점

- 교차 신체 데모를 저자 팀이 직접 수집해 데이터 규모가 작고 공개 데이터셋 통합은 미검증
- 시뮬레이션은 휴머노이드 하나와 주방 과제 둘에 한정
- 새 신체 추가 시 모달리티 대응과 좌표 변환을 수작업으로 지정
- 신체별 같은 크기 미니배치 탓에 작은 데이터셋이 반복 사용되어 과적합 우려
- 실물과 시뮬레이션이 섞인 평균이라 실물만의 수치 분리 필요

## 🥉 논문 3

**PRISM: Primitive Routing via In-context Skill Mixing for Retentive VLA Adaptation**
[arXiv:2611.08917](https://arxiv.org/abs/2611.08917) · Jiachen Tao 외 4명 · NeurIPS 2026 · source: citation-graph

**점수 9/15** · R3 · N2 · M2 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / 질문
[![P4](https://img.shields.io/badge/P4-d0e4f8.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 논문 요지

- 스킬별 LoRA를 동결 보존하고 라우터로 조합하는 VLA 적응
- **문제** — VLA를 새 행동에 순차 미세조정하면 앞서 익힌 스킬이 손상되고, 장기 과제는 아는 스킬을 재조합하지 못한 채 처음부터 맞춰야 함
  - 저자가 두 요구를 스킬 유지와 장기 조합으로 정의
- **기존 한계** — 표준 적응은 과제를 하나의 공유 파라미터 갱신으로 흡수
  - 어느 파라미터가 어느 스킬인지 위치를 알 수 없어 이후 갱신이 앞선 행동의 방향을 간섭
  - 과제별 파라미터를 추가하는 방어는 재사용을 제한하고, 전역 제약은 습득이 느리면서 보호할 방향을 짚지 못함
  - 장기 궤적에서 언제 어느 스킬을 호출할지의 장치 없음
- **핵심 방법** — 세 요소를 결합
  - **프리미티브 뱅크** — 스킬 계열마다 액션 전문가 위 저랭크 어댑터를 하나씩 저장하고 복합 학습 때 스킬별 잔차를 추가
  - **라우터** — 청크마다 VLM 프리픽스를 읽어 뱅크 위 혼합 가중치를 출력, 지시문이 아닌 프리픽스 조건
  - **결정론적 라벨러** — 행동에서 파생한 청크별 라벨로 라우터를 지도, 학습 파라미터와 궤적별 사람 라벨 불필요
  - **학습** — 1단계 원자 스킬 30K 스텝, 2단계 복합 과제 20K 스텝, 2단계에서 프리미티브는 동결
- **차별점** — 스킬을 파라미터 수준 일급 객체로 두고 복합 학습 중 동결해 구성상 보존
  - 새 스킬 추가는 새 슬롯 추가이며 기존 프리미티브는 건드리지 않음
- **핵심 기여** — 구조적 발견, 프레임워크, 평가
  - 스킬별 저랭크 갱신이 재현 가능한 저차원 부분공간을 이루고, 복합 과제 LoRA는 프로베니우스 에너지의 약 56%를 이 공간에 두며 무작위 회전 대조는 거의 0%
  - 시뮬레이션 RoboCasa365에서 원자 성공 56.43%와 복합 20.00%, $\pi_{0.5}$-LoRA 두 단계 미세조정은 17.86%와 17.50%
  - 실물 AgileX PIPER에서 과제당 20회 시행, 복합 성공 55.0%로 모든 열에서 최고
  - 실물에서 $\pi_{0.5}$-LoRA 기준선은 복합 학습 중 원자 성공률 30–40점 하락, PRISM은 Cup→Table 65%→65%, Doll→Plate 80%→85%
- **가치** — 사전학습 VLA 위에서 습득한 스킬을 보존하면서 조합하는 파라미터 수준의 적응 구조 제시

### (c) 시사점

- 적응 중 사전학습으로 얻은 스킬을 파라미터 단위로 지키는 대안
- **적응 범위** — 하나의 공유 LoRA로 흡수하는 방식과 동결 어댑터 뱅크를 같은 조건에서 비교한 결과
- **보호 방식** — 행동 측 어댑터에 보수적 미세조정을 얹는 ConSFT와 달리 스킬별 어댑터를 동결해 보존
- **도입 비용** — 코드 문구 없음, 뱅크 규모 확장은 원문이 후속 과제로 남김

### (d) 먼저 확인할 점

- 사전 정의한 스킬 계열과 그리퍼 이벤트 기반 라벨 규칙에 의존, 이벤트 단서가 없는 과제는 다른 라벨러 필요
- 평가 범위가 시뮬레이션 프리미티브 3개와 복합 과제 4개, 실물 프리미티브 2개와 복합 과제 1개
- 원자 평가는 과제 지정 라우팅을 쓰고 복합 평가만 학습 라우터 사용
- 실물 평가는 초기 배치를 맞춘 조건이며 반복 시드 없음
- 코드 저장소나 공개 약속 없음
