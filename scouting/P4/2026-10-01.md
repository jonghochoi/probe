## 🥇 논문 1 — 우선순위 ★★

**WB-WAM: Heterogeneous Body-Hand Pre-training for Humanoid Loco-Manipulation**
[arXiv:2609.34199](https://arxiv.org/abs/2609.34199) · Chuan Qin, Shaoting Zhu, Siyuan Luo, Siqiao Huang 외 2인 · 2026-09-28 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 핵심 기여
- 기존 로봇 사전학습 데이터가 전신 모션 커버리지를 충분히 제공하지 못한다는 문제에서, 몸통·루트·손가락 주석을 하나의 공유 물리 액션 공간으로 통합해 생성형 비디오 사전학습에 액션 지도를 직접 편입
- 부분 주석 비디오·모션 데이터 1,880.2시간으로 비디오와 액션을 함께 학습, 이후 PICO 미드트레이닝과 순기구학 보조 지도를 거쳐 로봇 과제에 적응하는 단계적 구성
- 리타깃팅한 에고센트릭 인간 시연과 로봇 궤적을 함께 묶은 WB-Datasets로 인간 모션이 제한된 로봇 데이터를 보완, 시뮬레이션 HumanoidArena 81.9%, 실물 5개 과제 평균 성공률 84.0%
- 과제 정합형 PICO 미드트레이닝이 다운스트림 성능을 높이면서 실물 시연 필요량을 줄인다는 ablation 제시

### (c) 시사점
- 에고센트릭 인간 데이터와 로봇 궤적을 한 코퍼스로 묶고 미드트레이닝 단계를 끼웠을 때의 적응 비용 감소를 직접 측정한 사례, 에고센트릭 중심 대 혼합 조성 질문의 스케일 실증 자료로 활용 가능
- 미드트레이닝 단계 유무에 따른 실물 시연량 변화가, 사전학습과 배포 적응 사이 중간 단계 설계 논의의 정량 근거
- 공유 액션 공간으로 이종 주석을 통합하는 방식이, 몸통·손 분리 액션 전문가 구성과 같은 문제의 데이터 측 대응

### (d) 먼저 확인할 점
- 프로젝트 페이지만 명시, 저장소 URL 미기재로 코퍼스·체크포인트 확보 경로 확인 필요
- 인간 데이터 제거 조건과 혼합 비율 변화 ablation의 범위가 초록에 제시되지 않아, 조성 질문에 대한 직접 분리 결과인지 원문 확인 필요
- 휴머노이드 전신 과제 중심 결과로, 손 조작 단독 과제로의 이전 가능성은 별도 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Train Together or Merge Later? Unifying VLA Experts via a Shared Action Interface**
[arXiv:2609.33125](https://arxiv.org/abs/2609.33125) · Zhizhen Zhang, Yuxia Fu, Zijian Wang, Helen Huang 외 1인 · 2026-09-27 · arXiv preprint · source: citation-graph (GR00T N1 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 독립 학습한 과제별 전문가를 병합해도 성능이 유지되지 않는 원인을 과제별로 바뀐 액션 인터페이스, 즉 액션 정규화와 액션 인코더·디코더에서 규명
- 사후 학습 동안 모든 전문가가 공통 기반 정책의 액션 인터페이스를 유지하고 적응은 액션 모델 은닉층 LoRA 갱신으로 한정하는 **PolicyWeave** 제안, 초기 시각-언어 문맥으로 전문가별 LoRA 갱신을 점수화해 희소 가중 병합
- GR00T N1.5 기준 RoboCasa365 18개 과제에서 목표 과제 시연 10%만 사용, 액션 인터페이스 보존만으로 정적 병합 4종 평균 성공률이 17.0%에서 52.8%로 상승
- SFT 전문가 64.7%, 과제별 RL 후 74.1%로 공동 RL 60.7% 상회, LIBERO-10과 AgileX Piper 실물 팔에서도 평가

### (c) 시사점
- 액션 측 어댑터가 기반 정책의 인터페이스를 건드리지 않아야 한다는 조건이 병합 성공률을 좌우한다는 정량 근거, 백본 보존형 적응 설계의 구체적 체크포인트
- 액션 정규화 프레임 보존이 성능을 가른다는 결론이 기존 연속 과제 스트림 관측과 같은 방향으로 재확인
- LoRA 적응 범위를 액션 모델 은닉층으로 한정하는 구성이, 동결 백본 위 저비용 적응 레시피의 직접 참고 대상

### (d) 먼저 확인할 점
- 초록·arXiv comment 모두 코드·프로젝트 페이지 신호 없음, 재현 경로 확인 필요
- 실물 검증이 단일 팔 플랫폼 하나로 요약되어 규모·과제 수는 원문 확인 필요
- 병합 후 기반 정책의 원래 일반화 성능이 유지되는지 측정 여부가 초록에 없어 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**VT-Bridge: Bridging Pretrained Foundation VLAs to VTLAs via Lightweight Residual Adaptation**
[arXiv:2609.22606](https://arxiv.org/abs/2609.22606) · Yansong Wu, Tuo Yang, Rongping Zhao, Lingyun Chen 외 4인 · 2026-09-18 · arXiv preprint · source: citation-graph (π0 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 비전-촉각-언어-액션 모델을 처음부터 학습하면 대규모 촉각 데이터와 연산이 필요하다는 병목에서, 사전학습 VLA 구조를 바꾸지 않고 실행 주파수에서 액션을 보정하는 경량 잔차 어댑터 제안
- 동일한 잔차 어댑터 구조를 백본별 가중치로 재사용, 과제당 촉각 시연 최대 50건과 0.98M 파라미터 어댑터만으로 구성
- π0·π0.5·SmolVLA 세 백본, 접촉 집약적 과제 4종에서 과제 수준 VLA 파인튜닝 단독 평균 11.7%를 62.9%로 개선

### (c) 시사점
- 액션 측 어댑터만 추가하고 백본은 유지하는 구성이 새 모달리티 적응에서도 성립한다는 사례, 백본 보호형 적응 경로의 타당성 참고
- 세 계보에서 같은 어댑터 구조가 통한다는 결과로, 특정 백본에 묶이지 않는 어댑터 설계 가능성 시사
- 50건 미만 시연 수준의 데이터 요구량이 낮은 적응 비용의 기준점

### (d) 먼저 확인할 점
- 프로젝트 페이지만 명시, 저장소 URL 미기재로 재현 경로 확인 필요
- 백본도 함께 파인튜닝하는 구성이라 기존 VLA 능력 유지 여부는 초록에서 측정 근거 미확인, 원문 확인 필요
- 촉각 모달리티 추가 사례로 한정되어, 촉각 외 입력으로의 일반화는 별도 확인 필요
