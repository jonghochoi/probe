**Rho: A Foundation for Efficiently Adaptable VLA Models**
[arXiv:2609.38164](https://arxiv.org/abs/2609.38164) · Rho Team (Simran Bagaria, Daphne Chen, Dean Fortier 외 10인) · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — abstract "We release the base Rho model and the embodiment-specific checkpoints"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 임바디먼트 미드트레이닝으로 하류 적응 데이터를 절반으로 절감
- **문제** — 사전학습 VLA·WAM의 미지 과제 제로샷 성공률이 낮아 적응이 필수인데, 그 적응이 데이터 집약적
  - 적응 한 번에 "대상 로봇을 제어하는 법"과 "새 과제"를 함께 익혀야 하는 구조
- **기존 한계** — 사전학습이 다양한 과제·환경·임바디먼트를 넓고 얕게 섞어 노출할 뿐, 특정 로봇의 센싱·기구학·액션 공간·데이터 관례에 초점을 두지 않음
  - 사전학습만 거친 모델에 미지 과제를 직접 학습시키면 로봇 플랫폼 숙지까지 하류 적응이 떠안음
- **핵심 방법** — 임바디먼트 적응과 과제 적응을 분리하는 정규화 점진 적응(regularized progressive adaptation) 레시피
  - 백본 — Microsoft Phi 계열 VLM에서 증류한 백본을 물리 세계 이해용으로 적응시키고 플로우 매칭 액션 전문가와 결합
  - 사전학습 — 엔드이펙터 포즈 액션 공간에서 양팔 로봇 시연 중심의 다임바디먼트·다과제 혼합에 로봇 관련 웹 VQA를 더해 Rho-base 생성
  - 수평 미드트레이닝 — 대상 로봇 하나의 다양한 과제·동작·환경으로 Rho-YAM-Box, Rho-UR-AI-Trainer, Rho-FR3-Duo 생성
  - 수직 과제 적응 — 오프라인 파인튜닝 뒤 선택적 내부 잠재 정책이 관측을 플로우 초기 조건으로 매핑, 교정 상호작용으로 이 모듈만 학습
- **차별점** — 적응 단계를 임바디먼트 단위 미드트레이닝으로 앞당겨 과제 적응 부담을 모델 안으로 흡수
  - 온라인 적응은 잠재 정책만 학습하고 액션 생성기를 동결해 앞 단계에서 얻은 능력을 보존
- **핵심 기여** — 오픈 웨이트 모델군 공개와 단계별 효과 실증
  - Rho-base와 3개 임바디먼트 변형 체크포인트 공개, 5B 파라미터 규모
  - 시뮬레이션 RoboTwin·LIBERO·RoboEval과 실물 양팔 3종(YAM Box, UR AI Trainer, FR3 Duo)에서 레시피 평가
  - RoboTwin 2.0 듀얼 UR5e 미드트레이닝 45과제 후 보류 5과제 적응에서 미드트레이닝 모델이 25% 데이터로 기본 모델의 50% 데이터 성능에 도달, 12.5% 구간에서 약 30% 우위
  - 사전학습 레시피 ablation(15% 서브셋, LIBERO 20k 적응 단계)에서 로봇+VL 0.963, 로봇 단독 0.943, 사전학습 없음 0.924
  - 교정 피드백 15회 에피소드 수준의 온라인 적응으로 오프라인 분포 경계 상황 처리
  - 평가한 오픈 웨이트 베이스라인·과제·임바디먼트 전반에서 최강 성능 주장
- **가치** — 오픈 웨이트 출발점 위에서 사전학습, 미드트레이닝, 과제 적응의 상호작용을 데이터량으로 측정한 기준점

### (c) 시사점

- 미드트레이닝 단계의 적응 데이터 절감 실측 근거
- 중간 단계 하나가 하류 데이터 요구를 절반으로 줄이는 수치로, 단계형 레시피의 효과 크기 가늠 가능
- 사전학습 모델 계보 후보를 늘리는 오픈 웨이트 체크포인트, 백본이 Phi 계열이라 PaliGemma 계열과 직접 대응하지 않음
- 온라인 적응이 잠재 정책 하나만 학습하고 생성기를 동결하는 구조, 사전학습 prior를 건드리지 않는 적응 사례

### (d) 먼저 확인할 점

- **저자 명시 한계** — 평가가 유한한 벤치마크·3개 양팔 플랫폼에 한정, 최강 모델 주장도 보고된 베이스라인·예산·프로토콜 안으로 제한
- **절감 수치의 설정** — 절반 절감은 RoboTwin 2.0 듀얼 UR5e 시뮬레이션 5과제 설정, 실물에서의 같은 크기 여부는 본문 7.5절 확인 필요
- **언어 조향성** — 다양한 지시문 추종과 표현 민감도는 미평가
- **코드 신호** — arXiv comment 없음, 초록의 체크포인트 공개 문장만 근거라 저장소 URL과 가중치 위치 확인 필요
- **사전학습 코퍼스** — 양팔 로봇 시연 중심 혼합이라 에고센트릭 대 혼합 구성 질문의 증거는 아님

## 🥈 논문 2

**EgoLAP: Learning from Egocentric Human Data through Language-Action Reasoning**
[arXiv:2610.08726](https://arxiv.org/abs/2610.08726) · Lihan Zha, Shresth Grover, Tenny Yin 외 7인 · arXiv preprint · source: citation-graph · 코드 공개 예정

**점수 11/15** · R3 · N2 · M2 · Real3 · Repro1 — arXiv comment "Project website: https://ego-lap.github.io/"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE)

### (b) 논문 요지

- 언어 액션 사고사슬로 인간·로봇 궤적을 함께 사전학습
- **문제** — 에고센트릭 인간 영상은 규모와 행동 다양성이 크지만 임바디먼트 격차 탓에 원시 인간 궤적이 제어 지도 신호로 부적합
  - 형태·기구학·제어 차이가 인간 데이터에서 로봇 정책으로의 액션 수준 지식 전이를 제한
- **기존 한계** — 인간 데이터 활용 방식이 각각 확장성 또는 전이에서 막힘
  - 어포던스·손 포즈·이미지 트랙·잠재 플랜·시각 편집 같은 수작업 중간표현은 추출 파이프라인의 편향과 실패를 상속
  - 인간·로봇 대규모 공동학습 계열은 임바디먼트 특화 포즈 타깃이나 FAST·OAT 같은 비언어 액션 토큰을 써서 교차 임바디먼트 전이를 방해
  - 서브태스크·객체 박스·시각 트레이스 추론은 무슨 행동인지, 어디로 가는지만 지정하고 물리적 이유는 담지 못함
- **핵심 방법** — 인간·로봇이 낮은 수준 액션이 아니라 동작 의도를 공유한다는 전제로 언어 액션과 동작 수준 추론을 묶은 액션 사고사슬(action chain-of-thought)
  - 언어 액션 — 포즈·그리퍼 변화를 시간 추상화한 구조적 문장, 예를 들어 "move forward 3 cm, rotate clockwise 14 degrees, and close gripper"
  - 동작 수준 추론 — 접촉·기하·객체 어포던스와 다음 동작의 의도 효과를 잇는 국소적 물리 근거
  - 추론 시 경량 액션 전문가만 구동, 텍스트 타깃은 학습 보조 감독이며 자기회귀 생성 불필요
- **차별점** — 액션 표현을 VLM의 사전학습 의미 공간에 있는 언어로 두고 인간·로봇이 같은 언어 타깃을 공유
  - 다단계 증류나 추론 시 텍스트 생성이 필요한 기존 추론 방식과 달리 학습 시 감독으로만 사용
- **핵심 기여** — 액션 표현 비교와 추론 형식 비교에서의 실물·시뮬레이션 우위
  - 커스텀 양팔 YAM 실물 제로샷 5개 행동(과제당 10회, 복합 과제 12회)에서 평균 과제 진척도 80.1%, 대안 액션 표현 대비 2.3배
  - 동작 수준 추론이 실물 과제 진척도에 기여한 폭 44.7점, 복합 추론 형식(서브태스크·객체 박스·시각 트레이스) 상회
  - 14개 과제 1,400 에피소드 시뮬레이션 제로샷 평가에서 성공률 38.3%, 시뮬레이션 데이터로는 학습하지 않음
  - 교차 임바디먼트 스킬 검색에서 동작 수준 추론이 최대 25점 향상, 언어 액션과 추론 대상 강화학습 적응도 보고
- **가치** — 별도 추출 파이프라인 없이 인간 에고센트릭 데이터를 로봇 사전학습의 감독 자원으로 쓰는 표현 후보 제시

### (c) 시사점

- 인간 에고센트릭 데이터를 사전학습 감독으로 쓰는 새 액션 표현
- 액션 표현이 인간 데이터의 전이 효율을 좌우한다는 직접 비교 증거, 같은 모션 추론 아래 FAST·OAT 대비 우위
- 추론 시 비용이 늘지 않는 학습 시 감독 구조라 지연 증가 없이 채택 가능
- 에고센트릭 우선 코퍼스 구성을 검토할 때 어떤 중간 감독으로 쓸지의 선택지 하나

### (d) 먼저 확인할 점

- **저자 명시 한계** — 언어 액션이 고정 1초 창과 양자화된 이동·회전을 요약해 빠르고 접촉 집약적인 조작의 동역학·정밀도를 놓칠 수 있음
- **범위** — 평가가 양팔 탁상 과제에 한정
- **강화학습 설정** — 강화학습 적응은 시뮬레이션 한정이며 과제 보상이 아닌 동작 일치 대리 지표를 최적화
- **베이스라인** — 비교 대상 EgoFAST·EgoOAT는 저자 재구현이고 OAT 토크나이저도 자체 혼합 데이터로 재학습, 재구현 충실도 확인 필요
- **코퍼스 조성** — 주 비교 축이 액션 표현과 추론 형식이라 인간 단독 대 혼합 조성의 분리 증거는 부록 C.3 확인 필요
- **코드 신호** — 프로젝트 페이지만 있고 저장소 URL은 없음

## 🥉 논문 3

**V-JEPA Policy: Building Effective World-Action Models on Predictive Visual Latents**
[arXiv:2609.37250](https://arxiv.org/abs/2609.37250) · Yang Zhang, Jiangyuan Zhao, Chenyou Fan 외 4인 · arXiv preprint · source: citation-graph · 코드 공개

**점수 9/15** · R3 · N2 · M2 · Real0 · Repro2 — abstract "Our code is available at https://github.com/breez3young/VJEPA-Policy"

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 논문 요지

- 동결 V-JEPA 잠재 위에서 세계-액션 모델을 학습
- **문제** — 세계-액션 모델(WAM)이 시각 상태 변화 예측 능력을 얻으려고 사전학습 생성 모델 전체를 상속해야 하는지가 불명
- **기존 한계** — 대규모 사전학습 시각 생성 모델을 WAM 학습에 적응시키는 계열이 생성 백본 전체를 함께 상속
  - 비디오 생성 모델은 동작·장면 전개 prior를 주지만 지식이 생성 백본과 묶여 옴
  - 이미지 편집 모델은 지시 조건 시각 변환 prior를 주지만 마찬가지로 백본째 상속
- **핵심 방법** — 동결 V-JEPA 2.1 인코더의 예측형 잠재 공간 위에 WAM을 구성
  - 지시 조건 미래 잠재 예측기가 관측 잠재 토큰과 미래 위치 쿼리를 합쳐 한 번의 순전파로 미래 잠재 예측
  - 전문가 혼합 트랜스포머(MoT) 구조로 예측기와 플로우 매칭 액션 전문가가 어텐션 공유, 예측기의 계층별 context key-value가 액션 생성 조건화
  - 총 0.9B 파라미터 중 0.6B가 학습 대상, 두 모듈을 단일 하류 단계에서 처음부터 학습
  - 선택 단계 — DROID 영상-지시 쌍으로 예측기만 액션 라벨 없이 사전학습한 뒤 새 액션 전문가와 함께 이식
- **차별점** — 생성 모델 전체 대신 예측형 시각 잠재 공간만 가져옴
  - 같은 하류 프레임워크와 학습 예산에서 시각 기반만 바꿔 비교하는 통제 설계
- **핵심 기여** — 시뮬레이션 벤치마크 성능, 시각 기반 통제 비교, 예측기 사전학습 효과
  - LIBERO 97.25%, LIBERO-Plus 79.25%, RoboCasa-GR1 50.92%로 대표 WAM·VLA 베이스라인과 경쟁
  - 판별형·재구성형·비디오 이해형 시각 기반 대비 V-JEPA 잠재가 우위, 분포 이동에서 격차 확대
  - 같은 시연 위 하류 학습 컴퓨트 연장은 일반화 수익 체감
  - 예측기 사전학습으로 LIBERO-Plus 79.25%에서 91.50%, 연장 학습의 81.64% 상회
  - 실물 양팔 2개 다단계 과제 평균 45%에서 사전학습 후 80%
- **가치** — 액션 라벨 없는 일반 영상 지식을 예측 잠재 공간에 쌓아 WAM에 옮기는 경로 제시

### (c) 시사점

- 액션 라벨 없는 영상 사전학습이라는 새 계보 선택지
- 사전학습 대상이 예측기뿐이라 단계 구성에서 영상 단계와 액션 단계를 분리하는 설계 사례
- 같은 하류 틀에서 동결 시각 기반 4종을 맞비교한 증거, 백본 선택 근거로 재사용 가능
- VLM이 없는 구조라 VLM 계보 질문에 직접 답하지는 않음

### (d) 먼저 확인할 점

- **실물 증거** — 초록은 시뮬레이션 결과만 서술해 Real0, 본문은 TianJi Marvin 양팔 2과제 45%에서 80% 보고, 시행 수와 설정 확인 필요
- **코퍼스 조성** — 사전학습이 DROID 단일 코퍼스라 에고센트릭 대 혼합 질문의 증거는 아님
- **일반화 주장 범위** — 연장 학습이 81.64%에 그친다는 비교는 평가한 예산 안에서만 성립
- **벤치마크** — 핵심 수치가 LIBERO 계열과 RoboCasa-GR1 시뮬레이션이라 공개 벤치마크 비교 가능성만 보여 줌
