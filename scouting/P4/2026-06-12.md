## 🥇 논문 1 — 우선순위 ★★★

**FiberTune: Preserving Action-Fiber Visual Residuals in Vision-Language-Action Fine-Tuning**
[arXiv:2606.08653](https://arxiv.org/abs/2606.08653) · Haihao Lin, Xiangsheng Huang, Xiao Yang, Weibang Zhou, Yiqi Zhang · 2026-06-07 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **문제 정식화** — 액션 지도 파인튜닝(action-supervised fine-tuning)이 액션을 변화시키는 시각적 방향만을 제약하므로, 액션-등가 상태(action-equivalent states)에서 일관된 시각 구조가 붕괴하는 현상 최초 공식화
  - 명칭: "국소 액션 파이버를 따른 잔차 시각 붕괴(residual visual collapse along local action fibers)"
  - 기존 동결 전략이 왜 시각 표현을 보호하는지에 대한 첫 기계론적 설명
- **FiberTune** — 추론 비용 추가 없이 시각 잔차를 보존하는 학습 시간(training-time) 목적함수
  - **온라인 액션 탐침(online action probe)**: 액션 예측 방향을 추정 → 중간 시각 토큰 표현에서 해당 방향을 필터링
  - 탐침-필터링된 잔차를 동결 시각 교사(frozen visual teacher)에 정렬 + 유효 랭크(effective rank) 정규화
  - 추론 시 탐침 제거 → 기저 정책 인터페이스 무변경
- **범용 검증** — π0.5 및 OpenVLA-OFT 두 아키텍처에서 동일 학습 조건 하 6개 제어 시나리오 전원 개선
- **정량 결과** — CALVIN ABC-to-D SR(5) +10.7pp; 실환경 SO-101 픽-플레이스 72.7% → 78.1%

### (c) 시사점

- **보존 전략의 원리 설명 확보** — 파인튜닝 중 사전학습 VLM 시각 표현이 붕괴하는 구체 경로(액션-등가 방향 붕괴)가 규명됨; 단순 동결만으로는 부분적 방어이고, 적응 단계에서 시각 잔차를 명시 정렬해야 한다는 근거
- **Stage 2 보조 손실 후보** — Stage 2(VLM-freeze + 액션 전문가 학습)에서 FiberTune 정규화 항 추가 시, 부분 파인튜닝 또는 LoRA 전환 시 시각 표현 붕괴 방어 가능; 완전 동결보다 유연한 경로 확보
- **π0.5 계보 직접 호환** — 아키텍처(PaliGemma × π0.5)가 우리 계보 v1 선택과 동일, 별도 변환 없이 적용 가능

### (d) 먼저 확인할 점

- **탐침 정확도 의존** — 온라인 액션 탐침이 액션 예측 방향을 부정확하게 추정하면 잔차 필터링이 올바른 방향을 차단해 보존 효과 반전 우려; 접촉 집약적 다단계 조작에서 탐침 오차율 먼저 측정 필요
- **인핸드 다지 조작 미검증** — CALVIN + SO-101 픽-플레이스 위주 평가; 손가락 세밀 제어가 요구되는 인핸드 회전처럼 시각-액션 등가 상태 공간이 복잡한 태스크에서 파이버 방향 추정 효과 미확인
- **확인** — LIBERO-LONG에서 FiberTune 적용 전후 잔차 유효 랭크 변화를 인핸드 접촉 태스크와 픽-플레이스 태스크 간 비교; 탐침 분류 정확도 동시 측정

## 🥈 논문 2 — 우선순위 ★★

**Two Bridges, One Pathway: From VLMs to Generalizable VLAs with Embodied Trajectory-Coupled Data**
[arXiv:2606.08520](https://arxiv.org/abs/2606.08520) · Linqi Yin, Shiduo Zhang, Shenling Qiu, Chenxin Li, Zhaoyang Fu · 2026-06-07 · source: Keyword Sweep (catastrophic forgetting + VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **이중 간극(two-fold gap) 진단** — VLM → VLA 직접 파인튜닝 장벽을 독립 두 구성요소로 분리
  - *시각 분포 간극*: VLM은 인터넷 이미지 학습, VLA는 로봇 장면 인식 → 시각 컨텍스트 불일치
  - *목적함수 간극*: VLM은 언어 이해 목표, VLA는 모터 액션 예측 목표 → 두 간극 동시 해결 시 수렴 불안정
- **ETC 데이터(Embodied Trajectory-Coupled data)** — 로봇 장면·궤적에서 추출한 비전-언어 감독 신호; 액션 레이블 없이 로봇 시각 컨텍스트를 VLM 언어 이해 목표로 처리 → 두 간극 사이의 자연스러운 디딤돌
- **3단계 브리징 레시피**
  - *Distribution Bridging*: ETC 데이터로 VLM을 로봇 시각-언어 의미론에 적응
  - *Objective Bridging*: 획득한 표현을 유지하며 액션 예측으로 점진적 전환
  - *Retentive Adaptation*: 타깃 배포 도메인 특화 + 표현 보존
- **태스크 관련 OOD ETC 데이터** 혼합 시 추가 로봇 데모 없이 새로운 언어-시각 조건으로 일반화 달성
- **결과** — 시뮬레이션 + 실환경 실험에서 점진적 브리징 레시피가 VLM 일반화의 VLA 전이에 핵심임을 확인

### (c) 시사점

- **사전학습 → 적응 경계 사이 중간 단계 근거** — 현행 Stage 1(추가 사전학습) → Stage 2(VLM-freeze + 액션 전문가) 전환 시 ETC 브리징 단계를 삽입하면 Stage 2 진입 초기 상태 품질 향상 가능; "Stage 1.5" 개념 실험 근거 확보
- **비액션 로봇 데이터의 활용 경로** — ETC 데이터(로봇 장면 + 언어 감독, 액션 레이블 없음)는 수집 비용이 낮음; 에고센트릭 비액션 영상에 VLM 자동 캡셔닝을 붙여 ETC 형식으로 변환 가능 → 사전학습 코퍼스 구성 실험에 저비용 데이터 포인트 추가
- **계보 독립성** — ETC 데이터 생성 파이프라인이 특정 VLM 백본에 의존하지 않음; π계보 외 다른 계보 비교 시에도 동일 논리 적용 가능

### (d) 먼저 확인할 점

- **ETC 생성 파이프라인 비용** — 로봇 장면에 비전-언어 감독을 붙이는 구체 방법(VLM 자동 캡셔닝 vs 수동 레이블링) 미명시; 캡션 품질 저하 시 Distribution Bridging 효과 감소 우려
- **태스크 일반화 범위** — "태스크 관련 OOD ETC 데이터"의 구체 범위 미명시; 인핸드 세밀 접촉 조작처럼 인터넷 이미지 분포와 크게 다른 태스크에서 ETC 브리징 효과 미검증
- **확인** — 코드·데이터 파이프라인 공개 여부 확인; LIBERO 단일 태스크에서 ETC 브리징 단계 유무에 따른 Stage 2 수렴 에피소드 수와 최종 성공률 비교

## 🥉 논문 3 — 우선순위 ★

**Reinforcement Learning for Flow-Matching Policies with Density Transport**
[arXiv:2606.08602](https://arxiv.org/abs/2606.08602) · Boshu Lei, Kostas Daniilidis, Antonio Loquercio · 2026-06-07 · source: Citation-Graph (π0.5 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **핵심 인식** — RL 기반 정책 개선을 "고보상 영역으로의 액션 밀도 전이(action density transport)"로 해석; 플로우 매칭의 전이 공식(transport formulation)과 수학적으로 정렬
- **RLDT(RL with Density Transport)** — 최대 엔트로피 RL 목적함수로부터 SVGD(Stein Variational Gradient Descent)로 전이 필드 구성 → 사전학습 플로우 매칭 정책을 해당 필드에 정렬
  - 기존 두 한계 동시 극복: Q함수 근사 편향(Q-VGM 방식) 없음 + 다모달 모델링 용량 희생(증류 기반 방식) 없음
  - 중간 디노이징 스텝에서 기대-타깃 추정(expected-target estimation)으로 시간축 역전파 없이 파라미터 업데이트
- **세 번째 독립 경로** — FlowPRO(선호 최적화)·Q-VGM(가치 그래디언트) 대비 보상 함수 명시 가능 환경에서 직접 RL 최적화 경로
- **결과** — 밀집·희소 보상, 상태 기반·비전 기반 장거리 로봇 조작 과제에서 경쟁 기준선 대비 보상 품질·수렴 속도 우위; 프로젝트 페이지 공개

### (c) 시사점

- **세 번째 플로우 매칭 헤드 사후 학습 경로** — 보상 신호를 명시 설계할 수 있는 과제에서 FlowPRO(개입-롤백 데이터 수집 필요)·Q-VGM(오프폴리시 리플레이 버퍼 관리 필요) 대비 더 직접적인 RL 루프 가능; Stage 2 이후 실환경 피드백 신호를 보상으로 변환할 수 있는 태스크에서 우선 시도 후보
- **다모달 액션 분포 유지** — SVGD 기반 전이 필드가 플로우 매칭 다모달 용량을 유지하며 RL 개선; 다지 손의 복잡 파지(핀치·파워 그립 등 멀티모드)처럼 다모달 액션이 필요한 태스크에서 유리

### (d) 먼저 확인할 점

- **VLM 백본 동결 여부 불명** — 초록에 VLM 백본 보존 전략 미명시; RLDT가 전체 정책 파인튜닝 시 사전학습 VLM 표현 손상 우려 — 코드 확인 후 백본 동결 여부 필수 점검
- **보상 함수 설계 부담** — FlowPRO 대비 명시적 보상 함수가 필요, 실환경 보상 수집 파이프라인 추가 구축 필요; 인핸드 접촉 성공 판정처럼 희소 이진 신호로도 수렴하는지 미검증
- **확인** — 프로젝트 페이지(rpfey.github.io/rldt) 코드 공개 여부 확인 후 VLM 백본 동결 여부 점검; LIBERO에서 FlowPRO 대비 동일 보상 정의 하 수렴 에피소드 수 비교

## 🌱 논문 4 — 인접 분야 픽

**Bridging the Morphology Gap: Adapting VLA Models to Dexterous Manipulation via Intent-Conditioned Fine-Tuning**
[arXiv:2606.12109](https://arxiv.org/abs/2606.12109) · Chuanke Pang, Junyi Huang, Zhijun Zhao, Yaobing Wang, Kun Xu · 2026-06-10 · adjacent field: 형태 간극(morphology gap) 브리징 — 그리퍼 VLA → 다지 손 적응 · source: Keyword Sweep (catastrophic forgetting + VLA)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **형태 간극 규명** — 저DoF 그리퍼 기반 VLA를 고DoF 다지 손에 직접 엔드-투-엔드 파인튜닝하면 공간 추론 능력의 파국적 망각과 액션 다양체 붕괴(action manifold collapse)가 발생함을 실험적으로 규명
- **InDex 프레임워크** — 교차-형태 의미 상속(cross-morphology semantic inheritance) 기반 2단계 분리 학습 아키텍처
  - **Stage 1** — 파라미터 효율 정렬: VLA 백본이 연속 팔 궤적 + 스칼라 파지 의도(grasp intent) 예측 학습; 기존 1-DoF 그리퍼 출력을 파지 의도 프록시로 재활용 → 그리퍼 사전 지식 폐기 없음
  - **Stage 2** — 공간 백본 동결 후 의도-조건 디노이징 확산 헤드(intent-conditioned denoising diffusion head)가 다지 관절 아티큘레이션 생성; 원본 VLA prior 공간 일반화 보존
- **결과** — 다단계 접촉 집약적 다지 조작 시뮬레이션 벤치마크에서 최소 데모 데이터로 단일체 기준선 대비 일관 우위; 원본 VLA 공간 일반화 보존 확인
- **한계** — 시뮬레이션 전용 검증 (실환경 다지 손 실험 없음)

### (c) 시사점

- **π0 계보 VLA → 다지 손 전환의 최초 실험 전례** — 그리퍼 기반 VLA 사전학습 prior를 버리지 않고 다지 손으로 계승하는 2단계 분리 전략; "직접 파인튜닝 = 공간 추론 붕괴"라는 구체적 실패 조건을 정량화해 어떤 적응 경로가 위험한지 명시
- **파지 의도를 브리지로 삼는 설계** — 기존 그리퍼 출력(스칼라 개폐)을 폐기 대신 파지 의도 프록시로 전환하는 아이디어는 π0 계보를 인핸드 다지 손으로 이식할 때 사전학습 지식 폐기량을 최소화하는 저렴한 접근

### (d) 먼저 확인할 점

- **시뮬레이션 전용 한계** — 실환경 다지 손 검증 없음; 시뮬레이션 접촉 모델과 실제 마찰·탄성·센서 노이즈 간 차이로 2단계 분리 효과가 감소할 우려
- **파지 의도 스칼라 표현력 제한** — 스칼라 파지 의도가 복잡한 다단계 그립 전략(핀치·후크·파워 그립 연속 전환) 전반을 대표하는지 미검증; 벡터 또는 페이즈 레이블로 확장 필요 여부 불명
