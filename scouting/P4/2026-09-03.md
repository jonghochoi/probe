## 🥇 논문 1 — 우선순위 ★★

**Beyond Data Scaling: Representation-Centric Continued Pre-training for Vision-Language-Action Models**
[arXiv:2608.27550](https://arxiv.org/abs/2608.27550) · Senqiao Yang, Chengyao Wang, Yuxin Chen, Zixuan Wang, Longxiang Tang 외 11인 · 2026-08-27 · arXiv preprint · source: citation-graph (π0·GR00T N1·Xiaomi-Robotics-0 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 핵심 기여
- 로봇 궤적 데이터가 웹 규모 이미지-텍스트 데이터만큼 확장되기 어려워, 고정된 로봇 데이터 예산 아래에서는 계속 사전학습이 액션을 단순히 맞추는 대신 전이 가능한 시각-액션 지식을 만들어내야 한다는 문제의식 제시
- 과제별 파인튜닝 이전에 광범위하고 이종적인 다중 임바디먼트 로봇 데이터로 VLM 백본을 계속 사전학습하는 **VLAct** 제안
- VLM 프라이어 보존, 다중 헤드 연속 액션 공동지도, 부분 통합 임바디먼트 간 액션 레이아웃 세 메커니즘으로 광범위한 VLM 프라이어를 지키면서도 임바디먼트 간 공유 액션 의미를 확보, 파인튜닝 단계에서는 과제별 액션 헤드 허용
- LIBERO-Plus·RoboTwin 2.0에서 ABot-M0·LingBot-VLA 등 산업 VLA 시스템 대비 우위(성공률 82.6%·92.5%), RoboDojo에서 명시적 World-Action-Model 계열 전부를 상회
- 미보유 휴머노이드 임바디먼트(RoboCasa-GR1)에서 다운스트림 궤적 20%만으로 전체 데이터를 쓴 GR00T-N1.6 기준선을 상회, 16-GPU 규모의 완전 오픈소스 데이터·모델로 재현 가능한 컴퓨팅 예산 제시

### (c) 시사점
- 데이터 규모 확장이 아니라 계속 사전학습이 만드는 표현 품질 자체가 별도의 독립적인 개선 축이라는 근거 확보, 백본 계보·적응 범위 논의에 "무엇을 계속 사전학습할 것인가"라는 구체적 설계 변수 추가
- VLM 프라이어 보존 메커니즘을 명시적으로 설계에 포함하고도 다중 임바디먼트 전이에서 우위를 보여, 프라이어 보존과 임바디먼트 간 공유 액션 학습이 상충하지 않음을 확인
- 16-GPU 규모로 재현 가능한 컴퓨팅 예산을 명시, 소규모 연구팀이 검증 가능한 계속 사전학습 실험 설계의 참고 사례 확보

### (d) 먼저 확인할 점
- "공개돼 있다"는 문구가 초록·arXiv comment에 있으나 GitHub 등 저장소 URL은 명시되지 않아, 프로젝트 페이지 경유 공개 범위(모델·코드·설정) 실제 확인 필요(네트워크 정책상 페이지 직접 접근 미검증)
- RoboDojo·RoboCasa-GR1 등 초록에 인용된 벤치마크가 시뮬레이션 기준으로 보여, 실물 로봇 정량 성공률이 원문 본문에 별도로 보고되는지 확인 필요
- VLM 프라이어 보존·다중 헤드 공동지도·액션 레이아웃 통합 세 메커니즘 각각의 개별 기여도가 ablation으로 분리되는지 원문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**World Tokens: Enhancing Embodied Policies with Training-Time World Modeling**
[arXiv:2608.09730](https://arxiv.org/abs/2608.09730) · Qu Tang, Benhui Zhuang, Bo Yuan, Xue Yu, Longteng Guo, Junlan Feng · 2026-08-10 · arXiv preprint · source: citation-graph (GR00T N1 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP) [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 핵심 기여
- World-Action-Model이 사전학습된 비디오 월드모델을 활용해 물리적 장면 변화를 포착하지만, 미래 생성 분기나 대형 비디오 백본을 제어 루프에 남기면 추론 비용이 크게 늘어나는 문제 지적
- VLM 특징을 고정된 개수의 월드 토큰으로 변환하는 **World Adapter**를 도입, 이 토큰이 학습 중 공동 파인튜닝되는 미래-비디오 디노이저를 조건화하는 동시에 액션 전문가의 유일한 시각-언어 맥락으로도 기능하는 아키텍처 제안
- 미래-비디오 디노이징의 그래디언트가 액션 예측에 쓰이는 표현을 직접 형성하도록 공유 조건화 구조를 설계, 배타적 라우팅으로 정책이 이 표현을 우회하지 못하게 강제
- 배포 시에는 월드모델 분기를 완전히 제거해 VLM·World Adapter·액션 전문가만 남기고 온라인 비디오모델 추론 없이 동작
- 2B 백본과 별도의 임바디드 액션 사전학습 없이도 LIBERO에서 경쟁력 있는 성능, SIMPLER에서 최고 평균 성능 달성, 실물 R1 Pro 로봇에서 동일 조건 액션 전용 기준선 대비 성공률 상당폭 개선, VLA 수준 지연시간으로 액션 청크 생성

### (c) 시사점
- 학습 시점에만 월드모델링을 반영하고 배포 시 완전히 제거하는 구조가, D3WV의 단계적 레시피 축에 "별도 대규모 사전학습 단계 없이" 월드모델 신호를 얻는 경량 대안으로 참고 가능
- 2B 규모 백본·임바디드 액션 사전학습 부재라는 조건에서도 경쟁력을 보여, 백본 계보·적응 범위 선택에서 대규모 추가 사전학습이 항상 필수는 아닐 수 있다는 대조 근거 확보
- 배포 시 온라인 비디오모델 추론이 전혀 없어, 월드모델 활용과 실시간 제어 요구가 상충하지 않는 구체적 설계 사례 확보

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 실물 R1 Pro 결과가 "상당폭 개선"으로만 기술, 구체적 성공률 수치가 원문 본문에 보고되는지 확인 필요
- 6인 소규모 연구팀 결과로, 2B보다 큰 백본이나 다른 임바디먼트에서도 "추가 사전학습 불필요"라는 결론이 유지되는지 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**CometVLA: Co-Training on an Embodied Data Pyramid towards Physical Understanding**
[arXiv:2608.30289](https://arxiv.org/abs/2608.30289) · Hanwen Wan, Dafeng Chi, Linbo Zhai, Tianao Shen, Yuzheng Zhuang 외 4인 · 2026-08-31 · arXiv preprint · source: citation-graph (π0 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 기존 물리 VQA 데이터가 로봇 액션 도메인과 정렬되지 않은 탈체화 데이터라, 향상된 VLM 물리 이해가 실제로 다운스트림 액션 생성에 도움이 되는지 불분명하다는 문제 지적, 에고센트릭 비디오는 보조 사전학습 용도로만 쓰이는 관행도 함께 지적
- 로봇 액션 데이터·임바디먼트와 엄격히 정렬된 임바디드 물리 VQA 코퍼스·벤치마크 **CometData/CometBench** 구축
- 과제 무관 동작 규칙성만 분리하는 컴팩트한 학습 가능 병목인 **Global Action Prior(GAP) 토큰**을 도입, 사전학습된 VLM 백본을 훼손하지 않으면서 액션 헤드가 물리 상식을 소비하도록 설계
- 텔레오퍼레이션·시뮬레이션·에고센트릭 궤적·VQA 네 계층으로 구성된 "임바디드 데이터 피라미드" 전체를 공동학습하는 **CometVLA** 제안
- 실물 조작 과제와 RoboTwin 시뮬레이션에서 강력한 VLA 기준선 대비 일관된 우위, CometBench에서의 VLM 성능이 높을수록 VLA 성공률도 높아지는 상관관계 확인해 물리 이해 사전학습이 실제로 다운스트림에 기여함을 실증

### (c) 시사점
- 물리 VQA·시뮬레이션·에고센트릭 비디오·텔레오퍼레이션을 하나의 조성 축(피라미드)으로 놓고 계층별 정렬을 설계 변수로 다룬 구체적 사례 확보, 에고센트릭-혼합 조성 논의에 "정렬 여부"라는 새로운 축 추가
- GAP 토큰이라는 컴팩트 병목으로 백본을 훼손하지 않으면서 물리 상식을 액션 헤드에 전달하는 구조가, 프라이어 보존과 보조 사전학습 신호 도입을 동시에 만족하는 설계로 참고 가능
- VLM 물리 이해도와 다운스트림 성공률의 상관관계를 직접 측정, 사전학습 단계에서 저비용으로 다운스트림 성능을 예측할 프록시 지표 후보 확보

### (d) 먼저 확인할 점
- 코드·CometData·CometBench 공개 여부가 초록·arXiv comment 모두에 명시되지 않아 재현 경로 확인 필요
- 실물 조작 과제의 구체적 과제 수·정량 성공률이 초록에 제시되지 않아 원문 확인 필요
- "임바디드 데이터 피라미드" 네 계층의 실제 혼합 비율과 각 계층의 개별 기여도가 ablation으로 분리되는지 원문 확인 필요
