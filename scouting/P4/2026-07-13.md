## 🥇 논문 1 — 우선순위 ★★★

**Native Video-Action Pretraining for Generalizable Robot Control (LingBot-VA 2.0)**
[arXiv:2607.08639](https://arxiv.org/abs/2607.08639) · Qihang Zhang, Lin Li, Luyao Zhang, Shuai Yang, Yiming Luo et al. · 2026-07-09 · source: citation-graph (π0.5 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **LingBot-VA 2.0** — 디지털 콘텐츠 생성용 비디오 생성 모델을 로봇 제어에 그대로 전용하는 접근을 지양, 임베디먼트 전용으로 처음부터 설계된 비디오-액션 파운데이션 모델 제시
- **인과적 사전학습 패러다임** — 시간적 동역학의 엄격한 인과성에 착안, 양방향 아키텍처를 사후 개조할 때 흔히 발생하는 catastrophic forgetting을 원천 회피하기 위해 처음부터(from scratch) 인과적 구조로 학습
- **의미론적 시각-액션 토크나이저** — 기존 재구성 중심 VAE 대신 시각 표현을 의미와 액션 모두에 정렬시키는 토크나이저 도입, 후속 정책 학습의 지시 이행·액션 정밀도 개선
- **데이터 레시피 명세** — 일반 이미지/비디오 → 로봇 데이터(AgiBot·RoboMind·OXE/DROID 등 재가공) → 에고센트릭 인간 데이터(수천 시간, 6.54만 에피소드, 5대 테이블탑 환경, 손 6-DoF 포즈+22 손가락 관절 각도를 그리퍼 액션 공간으로 변환) 순의 단계적 구성을 구체 수치로 공개
- **검증** — 실물 4개 과제(과일 분류·펜 수거·서랍 정리·접시 전달)에서 단일 제너럴리스트 정책으로 π0.5 및 전작 LingBot-VA 대비 성공률·과제 진행도 모두 우위 확인

### (c) 시사점

- 비디오 생성 모델을 로봇 제어용으로 전용하는 대신 처음부터 인과적 구조로 사전학습하는 설계가 forgetting 문제를 구조적으로 회피하는 대안 계보로 실증 — 계보 후보 비교 시 "VLM+어댑터"와 다른 축의 참고 사례 확보
- 에고센트릭 인간 데이터의 손 포즈를 로봇 그리퍼 액션 공간으로 변환하는 구체적 파이프라인과 규모(수천 시간·6.54만 에피소드) 확보 — 코퍼스 구성 설계 시 직접 참고 가능한 실증 수치
- 동일 체크포인트로 다중 과제를 커버하는 멀티태스크 제너럴리스트 정책이 파인튜닝 없이도 π0.5 대비 우위를 보여 사전학습 단계 투자의 상대적 가치를 재확인

### (d) 먼저 확인할 점

- 실물 검증 4개 과제 전원 자체 인하우스 벤치마크 기준 — LIBERO 등 외부 표준 벤치마크 교차 검증 여부 확인 필요
- 다지 손(dexterous hand) 조작 언급 없이 그리퍼·양팔 플랫폼 중심 검증 — 손재주 조작 태스크로의 이전 여부는 미검증
- 웹사이트 링크는 명시됐으나 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 코드·체크포인트 실접근은 미검증
- Mixture-of-Experts 백본 규모의 실제 학습 컴퓨트 비용이 상세 기술되지 않아 자체 재현 시 비용 추정 별도 필요

## 🥈 논문 2 — 우선순위 ★★

**Human-Centric Transferable Tactile Pre-Training for Dexterous Robotic Manipulation (TTP)**
[arXiv:2607.01067](https://arxiv.org/abs/2607.01067) · Chi Zhang, Penglin Cai, Ziheng Xi, Haoqi Yuan, Hao Luo et al. · 2026-07-01 · source: citation-graph (Being-H0.5 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D20](https://img.shields.io/badge/D20-d97706.svg)](#ref-D20)

### (b) 핵심 기여

- **H-Tac 데이터셋** — 160시간 규모 에고센트릭 인간 촉각-액션 데이터셋, 300개 이상 과제·13.5만 에피소드 규모로 기존 촉각 데이터셋 대비 대폭 확장
- **Transferable Tactile Pre-Training(TTP)** — 인간 데이터 기반 촉각 사전학습 시스템, 사전학습·사후학습 전 단계에 걸쳐 통일된 촉각·액션 공간(핀 논문 Being-H0.5의 200차원 액션 공간을 그대로 계승)을 사용해 인간→로봇 전이 시 사전 지식 보존
- **촉각 전문가(tactile expert)** — 미래 촉각 예측을 담당하는 별도 전문가 모듈로 접촉 동역학과 정밀 물리적 상호작용을 명시적으로 모델링
- **검증 범위** — Franka·Realman 양팔, Inspire 6-DoF 다지 손·DexBotic 12-DoF 다지 손·시각촉각 그리퍼 등 다양한 임베디먼트에 걸친 9개 실물 과제(정밀 박피·꽃병 닦기·부서지기 쉬운 물체 집기·가림 상황 플러그 삽입 등)에서 ID/OOD 성능 및 스케일링 어블레이션까지 확인

### (c) 시사점

- 촉각 모달리티에서도 "에고센트릭 인간 데이터 사전학습 → 통일 액션 공간 기반 로봇 전이"라는 동일한 P4 논리가 그대로 성립함을 실증 — 시각 중심 계보 논의를 촉각까지 확장할 근거 확보
- 핀 논문(Being-H0.5)의 200차원 통일 액션 공간을 그대로 재사용해 검증한 사례로, 해당 액션 공간 설계의 확장성에 대한 독립적 방증 확보
- 다지 손 중심의 정밀·접촉 집약적 조작 과제로 검증 범위를 구성해 손재주 조작이라는 우리 지향점과 직접 맞닿음

### (d) 먼저 확인할 점

- 프로젝트 페이지(`beingbeyond.github.io/TTP`)에 데이터셋 공개 의사가 명시되나, 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 실접근은 미검증
- 촉각 센서 하드웨어가 과제별로 상이(압저항식·시각촉각식 등)해 센서 이종성이 성능에 미치는 영향에 대한 정량 분석은 제한적
- 9개 과제 전원 저자 자체 실험실 플랫폼 기준 — 외부 재현 시 촉각 센서·다지 손 하드웨어 차이에 따른 변동 가능성 확인 필요

## 🥉 논문 3 — 우선순위 ★

**Learning Transferable Dynamics Priors from Action to World Modeling (A2World)**
[arXiv:2606.29501](https://arxiv.org/abs/2606.29501) · Ze Huang, Jiahui Zhang, Hairuo Liu, Chenxi Zhang, Ran Cheng, Li Zhang · 2026-06-28 · source: citation-graph (GR00T N1 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **A2World** — 대규모 로봇 조작 데이터에 실제 액션 주석을 결합해 사전학습한 멀티뷰 인터랙티브 확산 world model, 액션이 시각 장면을 어떻게 변화시키는지 예측하도록 학습해 외형 수준 비디오 생성을 넘어서는 재사용 가능한 상호작용 동역학을 포착
- **이중 활용 검증** — 동일 사전학습 가중치로부터 (i) 과제·장면 특화 실물 시뮬레이터(A2World-sim, 실로봇 롤아웃을 world model 롤아웃으로 대체)와 (ii) 비디오-액션 공동 예측 정책(A2World-policy)을 각각 파생해 검증
- **사전학습 목적 비교 어블레이션** — 동일 하류 조건에서 C-init(사전학습 world model 직접 초기화)·T-pre(텍스트 조건 world model 사전학습)·A-pre(액션-투-비디오 사전학습, 본 논문 방식)·P-pre(정책 특화 텍스트-비디오-액션 사전학습)을 통제 비교, A-pre가 C-init·T-pre를 상회하며 정책 특화 P-pre에 근접하는 성능 확인
- **검증 범위** — LIBERO 4-suite 98.6% 성공률(π0.5·OpenVLA-OFT 등 강력 베이스라인 상회), LIBERO-Plus OOD 세팅, 실물 로봇 5개 과제에서 π0.5·LingBot-VA 대비 우위 확인

### (c) 시사점

- 사전학습 목적(어떤 신호로 백본을 초기화할지)에 대한 통제된 정량 비교 데이터 확보 — 액션-조건 world model 사전학습이 텍스트 조건 사전학습보다 하류 정책 성능에 유리하다는 구체 근거
- world model 학습이 시뮬레이터 대체 용도와 정책 사전학습 용도로 동시에 재사용 가능함을 보여, 사전학습 투자 대비 활용 폭을 넓히는 설계 참고 사례로 활용 가능
- P5(world model) 영역과의 교차 검증 사례로, 사전학습 신호 선택이라는 P4 논의에 P5 관점의 정량 근거를 보태는 결과

### (d) 먼저 확인할 점

- 주 검증 축이 LIBERO 계열 시뮬레이션 벤치마크에 집중, 실물 검증은 5개 과제로 상대적으로 제한적
- 다지 손 조작 관련 언급 없음 — 손재주 조작 태스크로의 일반화 여부는 미검증
- GitHub 링크가 본문에 명시되나 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 코드 실접근은 미검증
- Fudan University 등 학계 랩 단독 프로젝트로 대규모 로봇 데이터 확보 경로(자체 수집 vs 공개 데이터셋 활용 비율)가 상세히 기술되지 않음

### Decision Log
- **D22 보강 근거** — LingBot-VA 2.0([arXiv:2607.08639](https://arxiv.org/abs/2607.08639)) — 에고센트릭 인간 데이터를 손 포즈→그리퍼 액션 공간으로 변환하는 구체 파이프라인 + 규모(수천 시간·6.54만 에피소드) 실증치, TTP([arXiv:2607.01067](https://arxiv.org/abs/2607.01067)) — 촉각 모달리티에서도 동일 논리(에고센트릭 인간 데이터 사전학습)가 성립함을 보이는 방증
- **D20 보강 근거** — TTP([arXiv:2607.01067](https://arxiv.org/abs/2607.01067)) — 통일 액션·촉각 공간을 통한 인간→로봇 전이 시 사전 지식 보존 사례, 프리트레인-포스트트레인 전이 설계 시 참고
- **D19/D21 참고 근거** — A2World([arXiv:2606.29501](https://arxiv.org/abs/2606.29501)) — 사전학습 목적(텍스트 조건 vs 액션 조건 vs 정책 특화) 통제 비교 수치, 계보/레시피 설계 선택 시 정량 참고점으로 활용 가능
- **재현성 공백 관측(반복)** — 이번 사이클도 relevance·novelty·methodology 강한 후보 다수(Learning Action Priors, Supervise What Survives/GRA, Present but Not Remembered 등)가 코드·프로젝트 페이지 부재로 reproducibility 게이트 미통과 — 누적 관측 패턴, 공개 시점 재확인 트리거 후보로 계속 추적 권고

### Anti-topics
- 이번 실행 특이사항 없음 — 배포-시점 전용 프레임워크(Harness VLA, Look Before You Leap 등 frozen VLA를 파인튜닝 없이 조작·평가하는 계열)는 기존 anti-topic 규칙("pretraining-composition/lineage 레버 없는 배포-시점 전용")으로 정상 필터링
