## 🥇 논문 1 — 우선순위 ★★

**The Gaussian Is Enough: Flow-Matching Priors Do Not Help When Fine-Tuning Large Behavior Models**
[arXiv:2609.27070](https://arxiv.org/abs/2609.27070) · Chen Xu, Rishi Shah, Hadas Kress-Gazit, Haruki Nishimura, Masha Itkina · 2026-09-22 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D1WE](https://img.shields.io/badge/D1WE-d97706.svg)](#ref-D1WE) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 처음부터 학습할 때는 표준 가우시안 대신 목표에 더 가까운 비가우시안 프라이어를 쓰면 성능이 크게 개선된다는 기존 결과에서, 이 이득이 대규모 사전학습 행동 모델(LBM 1.0·π0.5·GR00T N1.5) 파인튜닝에도 이어지는지 검증
- 시뮬레이션 두 플랫폼·40개 이상 과제에 걸쳐 세 LBM 전체로 10만 건 이상 롤아웃, 양팔 조작 과제 5종에서 실물 하드웨어 롤아웃 1,250건을 수행해 파인튜닝 데이터 비율을 아우르는 정량 비교 실시
- 목표에 더 가까운 비가우시안 프라이어가 매우 낮은 파인튜닝 데이터 비율을 제외하면 표준 가우시안과 통계적으로 구분되지 않거나 오히려 낮은 성능을 보임을 확인, 학습률 ablation으로 인코더 학습이 프라이어 선택보다 파인튜닝 성능을 압도적으로 좌우함을 규명

### (c) 시사점
- 프라이어 선택이 사전학습 단계에서 효과적이어도 파인튜닝 단계에서는 무의미해질 수 있다는 반증으로, 연속 플로우 매칭 헤드의 이득이 어느 학습 단계에서 실제로 발생하는지 구분해 재평가할 근거 확보
- 파인튜닝 성능을 좌우하는 지배적 요인이 인코더 학습이라는 규명이, 백본 동결·부분 적응 결정에서 어느 구성요소를 열지 판단할 저비용 우선순위로 참고 가능
- π0.5·GR00T N1.5 등 추적 계보와 인접한 세 LBM 전체에서 일관되게 관측된 결과로, 유사 계보 밖에서도 재현 가능성이 높은 결론으로 참고 가능

### (d) 먼저 확인할 점
- 코드·모델 공개 여부가 프로젝트 페이지로만 명시, 저장소 URL 미기재로 재현 경로 확인 필요

- "매우 낮은 파인튜닝 데이터 비율"에서는 예외 가능성을 언급하나 구체적 임계치·수치가 초록에 제시되지 않아 원문 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Think Like a World Model, Act Like a VLA: Distilling World-Model Representations into Compact Robot Policies**
[arXiv:2609.24682](https://arxiv.org/abs/2609.24682) · T. Dao, Sankalp Yamsani, Jaden Park, Joohyung Kim, Yong Jae Lee · 2026-09-21 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 공개 예정

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV)

### (b) 핵심 기여
- VLA가 세계 반응을 반영하는 목적함수 없이 관측을 행동으로 매핑해 강건성이 데이터 커버리지에만 의존한다는 문제에서, 월드 모델이 가진 접지된 물리 표현은 미래를 굴려야만 얻어진다는 통념에 반례 제기
- 동결된 월드 모델을 학습 프레임에 대해 한 번만 실행·캐싱해 학생이 그 캐시에 합의하도록 만드는 특징-정합 항 하나만 통상 VLA 학습에 추가, 교사 로딩 없이 배포 정책은 무증류 베이스라인과 동일하게 32ms·1.86GB로 실행
- 0.8B 학생 모델이 LIBERO 97.9%, RoboCasa-GR1 휴머노이드 조작 48.2%에서 50.5%로 개선, 단일팔·양팔 실물 플랫폼 모두로 동일 목적함수 이전 확인, 학생 규모·백본·정합 레이어·교사를 바꿔도 이득이 유지됨을 ablation으로 검증

### (c) 시사점
- 월드 모델의 생성 기계장치를 버리고 접지된 특징만 상속하는 설계가, 추론 지연·비용 증가 없이 사전학습 신호를 보강하는 구체적 축으로 참고 가능
- 학생 규모·백본·교사를 바꿔도 이득이 유지된다는 결과가, 특정 조합에 국한되지 않는 광범위한 표현적 prior라는 근거로 단계적 레시피에 안전하게 편입할 수 있는 신호로 참고 가능
- 배포 정책이 무증류 베이스라인과 동일한 지연시간·메모리로 실행된다는 결과가, 도입 비용이 순수 학습 단계에 한정된다는 구체적 근거로 참고 가능

### (d) 먼저 확인할 점
- 코드·가중치 공개 여부가 프로젝트 페이지로만 명시, 저장소 URL 미기재로 재현 경로 확인 필요
- 5인 소규모 연구팀 결과로, 검증된 교사 월드 모델 밖의 다른 월드 모델에서도 동일 정합 효과가 유지되는지 확인 필요
- 실물 검증이 단일팔·양팔 두 플랫폼에 한정, 더 넓은 임바디먼트·과제에서의 일반화는 원문 확인 필요

## 🥉 논문 3 — 우선순위 ★★

**Skel-WAM: A Hand-Skeleton-Conditioned World Action Model for Human-to-Robot Manipulation Transfer**
[arXiv:2609.21514](https://arxiv.org/abs/2609.21514) · Ze-Tao Cai, Ya-Ping Li, Yi-Qun Wang, Xinyu Zhan, Yu-Yin Yang 외 6인 · 2026-09-18 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 로봇 시연 수집 비용이 크고 과제 변형 커버리지가 제한적이라는 문제에, 저비용 인간 비디오로 보완하되 시각 외형·액션 공간의 임바디먼트 격차를 어떻게 메울지 질문
- 공통 손-스켈레톤 모션 인터페이스로 인간·로봇 모션을 정렬하는 **Skel-WAM** 제안, 장면에 모션을 접지하는 스켈레톤 오버레이와 손 기구학을 인코딩하는 2.5-D 키포인트를 결합, 비디오·키포인트 전문가가 Mixture-of-Transformers로 시각·스켈레톤 동역학을 공동 학습하고 별도의 로봇 학습 액션 전문가가 실행 가능 제어로 매핑
- 이 분리 구조로 인간 비디오에 로봇 액션 라벨 없이도 공유 동역학을 직접 지도, 실물 양팔 과제 4종·시뮬레이션 과제 7종에서 평균 성공률 79.86%·63.29%로 최강 기준선을 각각 22.22%p·8.28%p 상회, 인간-로봇 공동학습이 로봇 학습 데이터에 없는 과제 변형의 실물 성공률을 38.89%에서 86.11%로 두 배 이상 개선

### (c) 시사점
- 손-스켈레톤이라는 공통 인터페이스로 인간 비디오와 로봇 데이터를 직접 정렬해 공유 동역학을 지도하는 구체적 방법 확보, 에고센트릭-혼합 조성 개방형 질문에 로봇 액션 라벨 없는 인간 비디오 활용 경로로 참고 가능
- 로봇 학습 데이터에 없는 과제 변형에서 인간-로봇 공동학습이 성공률을 두 배 이상 끌어올린 결과가, 커버리지 확장 목적의 인간 비디오 도입 가치를 정량으로 뒷받침
- 비디오·키포인트 전문가와 로봇 액션 전문가를 분리해 인간 비디오에 로봇 액션 라벨이 불필요하도록 설계한 구조가, 저비용 데이터 확충과 실행 가능성을 동시에 만족하는 구체적 사례로 참고 가능

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 11인 규모 연구팀 결과로, 검증된 양팔 임바디먼트·과제 범위 밖에서도 동일 스켈레톤 인터페이스가 유지되는지 확인 필요
- 최강 기준선의 구체적 정체와 손-스켈레톤 추정 오차가 실물 성공률에 미치는 민감도가 초록에 제시되지 않아 원문 확인 필요
