## 🥇 논문 1 — 우선순위 ★★★

**Egocentric Human Video vs. Robot Teleoperation Data for Embodied Foundation Model Pretraining**
[arXiv:2606.20521](https://arxiv.org/abs/2606.20521) · 저자 미확인 (Semantic Scholar 미인덱싱; 2026-06-18 게재) · source: curated-list (awesome-vla-wam)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- 에고센트릭 인간 동영상 vs. 로봇 원격조종 데이터를 사전학습 코퍼스로 직접 비교한 최초 통제 ablation 실험 제시
- 필터링된 에고센트릭 데이터 → 실물 로봇 액션 예측 검증 손실 24% 감소 (동일 규모 원격조종 데이터 대비)
- 동분포(in-distribution) 태스크 성공률 52.5% 상승, 분포 외(OOD) 태스크 90% 상승 확인
- "에고센트릭 사전학습 → 소량 레이블 로봇 데이터 적응" 패러다임의 정량 기준점 공개 확립

### (c) 시사점

- 에고센트릭 우선 코퍼스의 성능 우위 수치화 — 동일 예산 사전학습에서 원격조종 대비 일관된 격차 확인
- 사내 에고센트릭 수집 계획(P0 D24)과 방향 일치 — 수집 우선순위 결정의 사후 정당화 근거 확보
- 사전학습 코퍼스 구성이 백본 초기 가중치 선택만큼 성능에 영향을 준다는 증거 추가
- Stage 1 코퍼스 설계 방향 구체화에 즉시 활용 가능

### (d) 먼저 확인할 점

- 에고센트릭 클립 필터링 기준 명세 확인 — 어떤 클립이 제외되는지 재현에 필요
- 사용된 에고센트릭 데이터셋 종류(Ego4D / EPIC-Kitchens 등) 및 총 시간 규모 확인
- 비교 조건 통제 확인 — 에고센트릭 vs. 원격조종 데이터를 "동일 분량"으로 맞춘 설계인지 검토
- 실험 태스크 다양성 — 특정 조작 유형(그립 위주 등)에 편중된 결과인지 평가 필요

## 🥈 논문 2 — 우선순위 ★★

**Finetuning Vision-Language-Action Models Requires Fewer Layers Than You Think**
[arXiv:2606.20246](https://arxiv.org/abs/2606.20246) · 저자 미확인 (Semantic Scholar 미인덱싱; 2026-06-18 게재) · source: keyword-sweep (VLA backbone/adaptation)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- π0 및 GR00T-N1.5의 계층별 표현 중복성 최초 체계 분석 — CKA 유사도로 "twin layers" 쌍 식별
- 레이어 최대 50% 제거 시 파인튜닝 성능 유지 또는 향상 달성
- 학습 시간 40–50% 단축, 추론 속도 30% 향상
- 검증 범위: 4 embodiments, 실물 10개 태스크, LIBERO / RoboCasa / SimplerEnv 3 벤치마크 포함
- 구조 프루닝을 통한 VLA 적응 범위 재정의 — 실제로 필요한 레이어 집합 실증

### (c) 시사점

- 적응 범위 기본값 재검토 신호 — "전체 VLM 동결 + 액션 전문가만" 방식이 최적이 아닐 수 있음; 선별 레이어 파인튜닝이 효율 우위 가능성
- Stage 2–3 학습 비용 절감 가능성 — 불필요 레이어 제거 시 동일 데이터 예산 대비 성능 회수율 향상
- 실물 배포 실용성 향상 — 추론 속도 30% 절감은 실시간 제어에서 유의미
- 레이어 중요도 프로파일링을 Stage 0 lineage 선택 이후 선행 분석 단계로 추가 검토 가능

### (d) 먼저 확인할 점

- 제거 가능 레이어의 유형 분포 확인 — attention vs. FFN vs. cross-attention 어느 쪽이 주로 twin인지
- π0 계열 외 다른 계통(Qwen-VLA, Xiaomi-Robotics-0)에서 동일 twin-layer 패턴 재현 여부
- OOD 일반화 성능 — 50% 레이어 제거 시 미지 태스크에서 성능 하락 여부
- 핸드-센트릭 조작 커버리지 — 실물 10개 태스크 중 손 조작 비율 및 난이도 평가 필요
