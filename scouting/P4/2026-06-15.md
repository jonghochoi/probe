## 🥇 논문 1 — 우선순위 ★★★

**APT: Action Expert Pretraining Improves Instruction Generalization of Vision-Language-Action Policies**
[arXiv:2606.12366](https://arxiv.org/abs/2606.12366) · Kechun Xu, Zhenjie Zhu, An-Jen Chen, Rong Xiong, Yue Wang · 2026-06-10 · source: Citation-Graph (π0.5·GR00T N1 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **진단 — 구조적 불균형 문제** — VLA 학습 데이터에서 언어가 시각·액션 콘텐츠 대비 현저히 부족 → 연속 액션 전문가는 랜덤 초기화에서 불균형 데이터로 학습 → 잡음 그래디언트가 VLM을 오염시키고 언어 역량 활용 불가
- **베이지안 정책 분해** — 정책을 "언어-비의존 비전-액션(VA) prior × 언어 조건부 VLA likelihood"로 인수분해; 액션 전문가 사전학습을 이 prior 추정 단계로 재해석
- **APT 2단계 레시피**:
  - **Stage 1** — 동결 VLM에서 비전-액션 쌍만으로 액션 전문가를 VA prior로 사전학습; 언어 불균형 완전 우회
  - **Stage 2** — 게이트 퓨전(gated fusion) 메커니즘으로 VLM 특징에 언어 토큰 주입; 학습된 비주오모터 prior 유지
- **아키텍처 범용성** — π 계열(PaliGemma 기반)과 GR00T 계열(Eagle2 기반) 모두 동일 APT 방법 적용 가능
- **결과** — 미보인 언어 지시(OOD language instructions) 및 구성형 태스크(compositional tasks)에서 일관된 성능 향상 확인; 프로젝트 페이지 공개

### (c) 시사점

- **Stage 0→1 사이 "VA prior 사전학습" 선행 단계 개념 확보** — 현행 Stage 1(추가 사전학습)이 언어-비의존 VA prior 확립을 포함하는지 검토 필요; APT 논리에 따르면 추가 사전학습 이전에 액션 전문가를 VA prior로 별도 사전학습하면 Stage 2 VLM 오염 위험 대폭 감소
- **π 계보 직접 호환** — π 아키텍처(PaliGemma × 액션 전문가)가 APT 검증 플랫폼; Stage 1에서 VLM 동결 유지 → D19 v1 동결 원칙과 무충돌
- **OOD 언어 일반화 지표 추가 근거** — 미보인 언어 지시 성공률을 Stage 2 진입 품질 기준으로 채택 가능; 현재 평가 지표 보완 검토

### (d) 먼저 확인할 점

- **실환경 검증 미명시** — 초록에 실환경 로봇 실험 명시 없음; 프로젝트 페이지(https://xukechun.github.io/papers/APT/) 먼저 확인하여 실환경 결과 여부 파악 필요
- **VA prior 학습 데이터 의존** — Stage 1 비전-액션 쌍이 충분히 다양하지 않으면 VA prior 일반화 범위 제한; 인핸드 다지 조작 같은 고차원 액션 공간에서 prior 표현력 확인 필요
- **확인** — π 기반 LIBERO 기준선에서 Stage 1(VA prior만) 단독 성공률과 Stage 1+2 결합 성공률 비교; 코드 공개 여부 프로젝트 페이지 확인

## 🥈 논문 2 — 우선순위 ★★

**What Matters When Cotraining Robot Manipulation Policies on Everyday Human Videos?**
[arXiv:2606.06627](https://arxiv.org/abs/2606.06627) · R. Li, Aditya Prakash, Andrew Wen, Saurabh Gupta, Yilun Du · 2026-06-04 · source: Keyword Sweep (cotraining + robot 스윕) + Citation-Graph (π0 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **질문 설정** — 정제된 시연 데이터(curated demonstrations)가 아닌 일상적 인터넷 영상(everyday internet video)을 로봇 조작 정책 공동학습(cotraining)에 활용할 때 어떤 요인이 실제 전이를 가능하게 하는가 최초 체계적 조사
- **신규 데이터셋** — 532편·28시간, 삼각측량 손 레이블(triangulated hand labels) 포함 자연스러운 동작의 고품질 인간 비디오 구축
- **주요 발견**:
  - **손 포즈 품질이 전이에 영향** — 정밀 손 레이블이 있어도 모션 갭(motion gap, 인간 손 vs. 로봇 엔드이펙터 동작 패턴 차이)이 잔존하면 전이 제한
  - **모션 갭은 구현체 특화(embodiment-specific specialization)로만 해소** — 비전 네트워크 + 정책 네트워크가 각 구현체에 특화될 때만 갭 극복; 파라미터 완전 공유 시 전이 한계
  - **공동학습 레시피 효과** — 위 조건 충족 시 로봇 데이터 부족 구간(low-robot-data regime)에서 실제 로봇 6개 조작 태스크 전반 절대 성공률 **+29.7%** 향상

### (c) 시사점

- **D22 열린 변수 조기 정량화** — "에고센트릭-중심 vs. 모든 것을 혼합한 덤프" 비교 실험에서, 일상 인터넷 영상이 공동학습에 포함될 수 있는 조건(구현체 특화 분기)과 그 기여 크기(+29.7%)를 최초 정량화 — D22 open ablation 설계 기준점 확보
- **에고 영상 vs. 정제 시연 경계 조건 명확화** — 어느 조건에서 인터넷 영상이 정제 시연을 보완할 수 있는지 실험 기반 조건 제시; "데이터 카탈로그 인간 비디오 항목 분류"를 '손 레이블 품질 × 모션 갭 수준 × 구현체 특화 여부'로 세분화 근거
- **저비용 데이터 수집 경로** — 삼각측량 손 레이블이 단일 RGB 카메라 기반 재구성으로 가능하다면 D22 에고센트릭 코퍼스 확장 저비용 경로 확보

### (d) 먼저 확인할 점

- **구현체 특화 레이어 범위 미명시** — "비전 + 정책 네트워크 특화"가 어느 레이어를 얼마나 분리하는지 상세 설명 없음; 특화 범위와 성능 트레이드오프 확인 필요
- **π 계보 적용 가능성** — PaliGemma VLM + 액션 전문가 조합에서 "비전 네트워크"와 "정책 네트워크"의 구현체 특화 분리 방법 미명시; π0.5 아키텍처 직접 적용 경로 확인 필요
- **확인** — 데이터셋·코드 공개 여부 확인; LIBERO 단일 태스크에서 삼각측량 손 레이블 인간 영상 vs. 원시 인터넷 영상 공동학습 후 성공률 차이 먼저 비교

## 🥉 논문 3 — 우선순위 ★

**Improving Robotic Generalist Policies via Flow Reversal Steering**
[arXiv:2606.13675](https://arxiv.org/abs/2606.13675) · Andy Tang, William Chen, Andrew Wagenmaker, Chelsea Finn, Sergey Levine · 2026-06-11 · source: Citation-Graph (π0.5·π0 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D23](https://img.shields.io/badge/D23-d97706.svg)](#ref-D23) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21)

### (b) 핵심 기여

- **핵심 관찰** — 사전학습된 플로우 매칭 제너럴리스트 정책이 **풍부한 행동 prior를 잠재 노이즈 공간에 인코딩**; 직접 명령이 실패해도 prior를 적절히 활성화하면 원하는 행동 모드 유발 가능
- **Flow Reversal Steering (FRS)**:
  - 열등하지만 "그럴듯한(reasonable)" 액션을 플로우 역방향으로 통과시켜 잠재 노이즈 추출
  - 추출된 노이즈를 인근 제너럴리스트 행동 모드로 매핑 → pretrained prior 활용
- **세 가지 응용**:
  - **Zero-Shot Control** — 인간 또는 VLM의 거친 의미론적 지도를 좋은 로봇 액션으로 변환
  - **행동 복제 증류** — FRS 출력을 보조 정책이 직접 예측하도록 학습 (1분 미만 훈련에서 최대 **절대 +95%** 성공률 향상)
  - **RL 부트스트래핑** — 표준 RL이 실패하는 태스크에서 의미론적 지식으로 RL 탐색 가이드
- **실환경 검증** — 시뮬레이션 + 실환경 조작 설정 모두 평가

### (c) 시사점

- **사전학습 prior 투자 정당성 강화** — 제너럴리스트 사전학습이 풍부한 잠재 행동 prior를 구축함을 실험적으로 입증; 사전학습 단계 투자가 클수록 FRS 같은 테스트-타임 조종의 효과 증대 → Stage 0→1 사전학습 단계 투자 근거 추가
- **플로우 매칭 헤드의 구조적 이점** — 연속 잠재 공간이 역방향 순회 및 노이즈 추출을 가능하게 함; 이산 토큰 헤드 대비 독점 이점 확인
- **Stage 2 이후 경량 슬롯 후보** — 1분 미만 행동 복제 증류로 Stage 2 이후 신속한 태스크 특화; 보수적 적응(Stage 3)의 보완 또는 선행 경로

### (d) 먼저 확인할 점

- **"그럴듯한" 초기 액션 전제** — FRS 역방향 순회는 입력 액션이 최소한의 품질을 갖춰야 함; 완전 랜덤 액션에서는 유의미한 잠재 노이즈 추출 불가
- **사전학습 행동 분포 범위 의존** — FRS는 사전학습 정책이 대상 태스크와 유사한 행동 모드를 보유할 때만 작동; 인핸드 세밀 접촉처럼 사전학습 데이터 희귀 행동에서는 효과 제한
- **확인** — π0.5 기반 정책에서 인핸드 다지 조작 태스크의 FRS 잠재 노이즈 공간에 유의미한 행동 모드 집중화 여부 먼저 시각화; 사전학습 분포 외 태스크에서 FRS 실패 조건 정량화

## 🌱 논문 4 — 인접 분야 픽

**FTP-1: A Generalist Foundation Tactile Policy Across Tactile Sensors for Contact-Rich Manipulation**
[arXiv:2606.13102](https://arxiv.org/abs/2606.13102) · Chengbo Yuan, Zicheng Zhang, Mingjie Zhou et al. · 2026-06-11 · adjacent field: 촉각 도메인 이종 센서 간 제너럴리스트 사전학습 패러다임 · source: Citation-Graph (π0.5·GR00T N1 인용 확장)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d62728.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19)

### (b) 핵심 기여

- **공백** — 기존 촉각 기반 정책은 특정 촉각 센서 하드웨어에 고정; 이종 센서 간 지식 전이 불가
- **FTP-1** — 이종 촉각 센서 간 사전학습으로 전이 가능한 촉각 조작 역량을 획득하는 최초의 제너럴리스트 기반 촉각 정책
  - **교차-센서 사전학습(cross-sensor pretraining)** — 서로 다른 촉각 센서 간 표현 정렬 → 새로운 센서 설정에 데이터 효율적 적응 가능
  - 접촉 집약적(contact-rich) 조작 태스크 전반 검증

### (c) 시사점

- **이종 입력 제너럴리스트 사전학습 패러다임의 촉각 재현** — GR00T N1의 크로스-구현체 사전학습 논리(이종 로봇 데이터 → 공통 prior → 적응 효율)가 이종 촉각 센서 도메인에서도 재현됨; "사전학습 다양성 → 적응 효율" 패턴의 모달리티 독립성 확인
- **장기 촉각 데이터 통합 시 선행 참조** — D22 코퍼스에 촉각 데이터를 장기 추가할 경우, 이종 센서 간 표현 정렬 기법이 선행 요구사항임을 시사

### (d) 먼저 확인할 점

- **VLM 백본과 촉각 사전학습 통합 경로 미명시** — FTP-1은 촉각 전용 정책; 공유 VLM 백본 위에 촉각 모달리티를 통합하는 방법 미탐색
- **초록 기준 태스크·데이터 규모 미명시** — 구체적 태스크 수·훈련 데이터 규모 확인 필요

  - Reproducibility 2 — 데이터셋·6개 태스크 공개 프로토콜 기술; 코드 공개 미확인
  - Sim2Real 3 — 실제 로봇 6개 조작 태스크 직접 측정; +29.7% 절대 향상 보고

- **FRS (11/12)**
  - Relevance 2 — D23(플로우 매칭 헤드 잠재 prior 활용) + D21(사전학습 prior 투자 정당화); 사전학습 레시피 자체는 아님
  - Novelty 3 — 플로우 역방향 순회로 잠재 노이즈 추출 후 행동 모드 조종 최초 제안; RL 부트스트래핑 응용 신규

### Decision Log

- **D21 Stage 1 내부 세분화 검토** — APT 근거([arXiv:2606.12366](https://arxiv.org/abs/2606.12366))
  - 현행 Stage 1(추가 사전학습) 내부에 "VA prior 사전학습(언어-비의존, VLM 동결) → 언어 주입 공동학습" 순서 삽입 실험 제안
  - 발동 조건: Stage 2 진입 후 OOD 언어 지시 성공률 < 40%이면 Stage 1 세분화 적용

- **D22 공동학습 조건 명세 추가** — Cotraining 논문 근거([arXiv:2606.06627](https://arxiv.org/abs/2606.06627))
  - D22 v1(에고센트릭-중심 코퍼스)에 "일상 영상 포함 시 유효 조건 명세" 추가 제안: (a) 손 포즈 품질(삼각측량급 이상) × (b) 구현체 특화 분기 여부가 전이 효율 상한 결정; 두 조건 충족 시 +29.7%p 기준점
  - D22 open ablation 실험 설계 시 "인터넷 영상 + 구현체 특화 분기 레이어 조합" 독립 변수로 추가 권고

- **D23 Stage 2 이후 FRS 경량 증류 경로 추가** — FRS 근거([arXiv:2606.13675](https://arxiv.org/abs/2606.13675))
  - Stage 2 완료 후 신속 태스크 특화 슬롯에 FRS 행동 복제 증류(1분 미만)를 D21 deferred 후보로 추가 제안
  - 트레이드오프: "그럴듯한" 초기 액션 확보 필요; 사전학습 행동 분포 내 태스크 한정 적용
