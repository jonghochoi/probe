**From Foundation to Application: Improving VLA Models in Practice (LingBot-VLA 2.0)**
[arXiv:2607.06403](https://arxiv.org/abs/2607.06403) · Wei Wu, Fangjing Wang, Fan Lu, He Sun, Shi Liu et al. · 2026-07-07 · source: citation-graph (π0·π0.5·GR00T N1·Being-H0.5·Xiaomi-Robotics-0·Qwen-VLA 전체 인용)

### (a) 관련 Pillar / Decision

[![P4](https://img.shields.io/badge/P4-d5def5.svg)](#ref-P4) / [![D19](https://img.shields.io/badge/D19-d97706.svg)](#ref-D19) [![D21](https://img.shields.io/badge/D21-d97706.svg)](#ref-D21) [![D22](https://img.shields.io/badge/D22-d97706.svg)](#ref-D22)

### (b) 핵심 기여

- **LingBot-VLA 2.0** — 전작 LingBot-VLA를 세 기능 영역(과제·구현체 일반화, 확장 액션 공간, 예측적 동역학 모델링)에서 개선한 후속 리포트
- **대규모 사전학습 코퍼스 재구축** — 데이터 처리 파이프라인 전면 개편, 총 6만 시간 사전학습 데이터 확보 — 로봇 궤적 5만 시간(20개 로봇 구성) + 에고센트릭 인간 비디오 1만 시간 혼합
- **확장 액션 공간** — 듀얼암 하드웨어 외 머리·허리·모바일 베이스·다지 손 자유도까지 지원, 실제 복합 과제 대응력 확대
- **예측적 동역학 모델링** — 미래 예측을 프록시 태스크로 재정식화, 비디오 표현 모델(의미 사전지식) + 깊이 추정 모델(기하 단서)을 결합해 시간적 추론 보강
- **검증 범위** — GM-100 벤치마크 제너럴리스트 세팅 전 영역 개선 확인, 두 로봇 플랫폼에 걸친 실물 cross-embodiment 장기 수평 모바일 조작 능력 입증

### (c) 시사점

- 로봇 궤적과 에고센트릭 인간 비디오를 5:1 비율로 혼합한 대규모 사전학습 코퍼스 실증 사례 확보 — 코퍼스 구성 비율 설계 시 직접 참고 가능한 구체 수치
- 20개 로봇 구성에 걸친 사전학습 데이터 확장이 실물 cross-embodiment 장기 수평 조작 능력으로 이어짐 확인 — 계보 확장 시 이종 embodiment 수 스케일링 효과의 참고 사례
- 프리트레인 단계에 예측적 동역학(미래 예측 프록시 태스크)을 통합하는 방식이 별도 world model 학습 없이 시간적 추론 개선에 기여 — 사전학습 레시피 확장안으로 검토 가치
- 공개 저장소·체크포인트 링크가 명시돼 실접근 후보로 확인(다만 이번 실행에서는 네트워크 정책상 해당 도메인 접근이 차단돼 저장소 실접근은 미검증)

### (d) 먼저 확인할 점

- 다지 손 자유도 지원은 언급되나 다지 조작 태스크 자체의 성공률·세부 성능이 리포트에 기술되지 않음 — 손재주 조작 특화 벤치마크 결과 별도 확인 필요
- 에고센트릭 인간 비디오 1만 시간의 수집 출처·품질 관리 기준이 상세히 기술되지 않음 — 자체 코퍼스 대체 가능성 판단 전 데이터 원천 검증 필요
- GitHub·HuggingFace 링크는 확인됐으나 네트워크 정책상 이번 확인에서 해당 도메인 접근이 차단돼 저장소 실접근·체크포인트 실사용 가능 여부 미검증
- 정량 개선폭이 자체 GM-100 벤치마크에 한정 — LIBERO 등 외부 표준 벤치마크 교차 검증 여부 확인 필요
