## 🥇 논문 1 — 우선순위 ★★★

**OpenWAM: An Open, Modular Exploration Towards Systematic World-Action Model Pretraining**
[arXiv:2609.07398](https://arxiv.org/abs/2609.07398) · Yuran Wang, Siqiao Huang, Mingleyang Li, Chenhao Zhang, Jiaqi Liang 외 19인 · 2026-09-07 · arXiv preprint · source: keyword-sweep · 코드 공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D3WV](https://img.shields.io/badge/D3WV-d97706.svg)](#ref-D3WV) [![D9QJ](https://img.shields.io/badge/D9QJ-d97706.svg)](#ref-D9QJ)

### (b) 핵심 기여
- 기존 World-Action-Model이 생성 백본·시각 표현·아키텍처·정보 흐름·추론 절차·학습 데이터를 강결합해, 어떤 설계 선택이 실제로 성능에 기여하는지 불분명하다는 문제 지적
- WAM 설계 공간을 조합 가능한 모듈로 분해해 통합 학습·추론·배포·평가 인프라를 갖춘 개방형 연구 스택 **OpenWAM** 제안
- "무엇을 상속할 것인가" · "월드·액션 학습이 어떻게 상호작용하는가" · "이 시너지가 어떻게 스케일링되는가" 세 질문을 통제 실험으로 검증
- 충분히 강력한 생성 백본과 컴팩트한 정보압축 잠재공간을 통해 상류 지식이 전이됨, 전용 액션 용량과 명시적 월드-액션 정보 흐름 및 동기화된 공동 디노이징이 시너지에 필요함, 에고센트릭·로봇 데이터를 한 단계로 공동학습할 때 분포 밖 일반화가 가장 크게 개선됨의 세 원칙 도출
- 도출한 원칙을 조합해 에고센트릭 인간·로봇 데이터 약 6,400시간으로 사전학습한 **OpenWAM-α** 구축, 8개 시뮬레이션 벤치마크와 실물 로봇 실험(단일팔·양팔·다지 손 임바디먼트) 전반에서 시뮬레이션 최상위 성능을 실물까지 유지, 인프라·평가 프로토콜·사전학습 모델·데이터 레시피 전체 공개

### (c) 시사점
- 백본 계보와 데이터 구성 두 축을 하나의 통제 실험 프레임 안에서 동시에 분리 측정한 사례 확보, 향후 유사 실증 설계의 방법론적 참고 청사진
- 에고센트릭·로봇 데이터를 한 단계로 공동학습하는 편이 분포 밖 일반화에 가장 크게 기여한다는 정량 근거, 조성 논의에 참고할 실증 결과로 활용 가능
- 인프라부터 데이터 레시피까지 전체 스택이 공개돼, 동일 조건에서 직접 재현·확장 실험을 시작할 수 있는 낮은 진입 장벽 확보

### (d) 먼저 확인할 점
- 24인 규모 대형 연구팀 결과로, 6,400시간 규모 에고센트릭·로봇 데이터를 이 팀 밖에서 동일하게 확보 가능한지 확인 필요
- 세 원칙이 도출된 통제 실험이 구체적으로 어떤 임바디먼트·태스크 범위에서 수행됐는지, 결론이 다른 도메인에도 일반화되는지 원문 확인 필요
- "무엇을 상속할 것인가" 원칙이 구체적으로 어떤 후보 생성 백본들을 비교했는지 원문에서 세부 확인 필요

## 🥈 논문 2 — 우선순위 ★★

**Continual Field-Adaptive Models (CFAMs) for Post-Deployment Physical AI**
[arXiv:2609.04552](https://arxiv.org/abs/2609.04552) · Amarjot Singh, Tanmay R. Pancholi, Jainam Kothari, Shrirang Mahajan, Ketan Bansal 외 5인 · 2026-09-03 · arXiv preprint · source: citation-graph (π0·GR00T N1 인용) · 코드 미공개

### (a) 관련 Pillar / Decision
[![P4](https://img.shields.io/badge/P4-e0d5f5.svg)](#ref-P4) / [![D5ZL](https://img.shields.io/badge/D5ZL-d97706.svg)](#ref-D5ZL) [![D3RP](https://img.shields.io/badge/D3RP-d97706.svg)](#ref-D3RP)

### (b) 핵심 기여
- 위험 현장에 투입돼 인간 대신 도구를 다루는 무인 상호작용 자율성이 미션 크리티컬 영역에서 아직 부재한 역량이라는 문제 제기, 이런 영역은 훈련 데이터가 희소하고 온보드 연산만 가능하나 배포된 시스템이 기존 역량을 지우지 않으면서 새로움에 대응해야 한다는 요구 제시
- 실험실에서 효율적으로 학습하고 배포 후에도 자율적·그래디언트 프리 온디바이스 업데이트로 계속 학습하는 **연속 현장-적응 모델**(CFAM) 제안
- 동결된 느린 학습 요소(감지·추론·행동 세 코텍스로 구성)와 빠른 학습 요소인 Capsule Field로 구성된 상보적 학습 아키텍처 설계, 스킬 설치는 실험실에서 소량 시연으로 이뤄지고 현장에서는 연속적으로 이뤄짐
- 조작기·사족보행·휴머노이드·쿼드로터·오프로드 차량 5개 임바디먼트에 걸쳐 평가, 동일한 자체 다중 임바디먼트 데이터셋으로 π0·CogACT·SpatialVLA를 기준선으로 실물 플랫폼 비교 수행
- 전체 사전학습 데이터의 40%(궤적 수 기준 2.5배 적은 데이터)만으로 표준 정책과 동일한 운용 수준 도달, 검증된 분포-근접-이탈 사례의 자율 포착으로 행동 성공률 13.9%p 개선, 순차 시뮬레이션에서 후방 전이가 LoRA의 -11.4%p 대비 -0.5%p로 기존 역량 보존 폭이 크게 우수

### (c) 시사점
- 동결 요소와 빠른 학습 요소를 분리하는 구조가, 배포 후 지속 학습과 기존 역량 보존을 동시에 만족하는 구체적 아키텍처 사례로 참고 가능
- π0를 포함한 기존 파운데이션 정책 대비 후방 전이(기존 역량 보존)를 직접 정량 비교한 근거 확보, 적응 시점의 보존 전략 설계에 참고할 구체적 기준점
- 목표 데이터 40%만으로 표준 정책과 동일한 성능에 도달한다는 결과가, 배포 데이터 수집 비용을 줄이는 경로로 참고 가능

### (d) 먼저 확인할 점
- 코드·데이터 공개 여부가 원문에 명시되지 않아 재현 경로 확인 필요
- 5개 임바디먼트 결과가 자체 구축한 인하우스 데이터셋 기준, 공개 벤치마크나 제3자 데이터에서도 동일 결론이 유지되는지 확인 필요
- 그래디언트 프리 온디바이스 업데이트의 구체적 계산·메모리 요구사항이 실제 온보드 하드웨어 제약과 양립 가능한 수준인지 원문 확인 필요
