# PROBE 리디자인 결정 기록

조율실(`design/playground/`)에서 확정한 설정과, 옵션으로는 남지 않는 결정을
한곳에 적는다. 조율실의 기본값(`playground.html`의 `DEFAULT`)이 이 문서와
같은 상태가 "내 설정 15차"다. 실제 사이트(`site/`)로 옮길 때는 이 문서를
기준으로 삼는다.

- 완료: 공통 테마, 첫 화면, 분석 목록, 신규 탐색, 비교 (15차 기준)

- 남음: 논문 상세, 연구 축 페이지

## 3. 분석 목록 (`index.html`)

### 3-1. 옵션으로 정한 것

| 항목 | 결정 |
|---|---|
| 가장 최근 카드 | 없음. 가장 최근 논문은 목록 첫 줄 |
| 추천 카드 | 없음 (데스크톱·휴대폰 모두) |
| 서재·연구 축 거르기 자리 | 목록 위 가로 줄 |
| 연구 축 줄 이름 칸 | 왼쪽에 옅은 주색 칸 + 연구 축 아이콘(겹친 층). 글자 없음 |
| 목록 · 한 줄 요약 | 보이기 |
| 목록 · 결과 줄 | 숨기기 |
| 목록 · arXiv 번호 열 | 보이기 |
| 목록 · 연구 축 칩 | 보이기 |
| 링크 | 아이콘만. 데스크톱은 제목 바로 뒤, 휴대폰은 연구 축 칩 옆 |
| 분량·용어 | 표시하지 않음 (그 칸은 휴대폰에서 링크 아이콘 자리) |
| 한 쪽에 몇 편 | 10 · 20 · 30, 기본 10 |

### 3-2. 옵션 밖에서 정한 것

- **연구 축 줄**
  - "연구 축" 제목 글자와 서재 항목은 뺀다.
  - 오른쪽 끝에 "91편 · 최근 날짜"를 둔다 (데스크톱).
  - 항목의 숫자는 이름과 같은 글자 기준선에 맞추고, 색 점만 가운데 정렬한다.
  - 테두리는 글자색 24%, 그림자는 얇게 한 겹만 둔다. 넓게 번지는 그림자는 배경과 섞여 경계가 흐려진다.
  - 휴대폰에서는 옆으로 밀고, 오른쪽 끝에 "더 있음" 그라데이션을 두며, 끝에 닿으면 지운다. 이름 칸은 밀어도 왼쪽에 고정된다.
  - 누른 항목은 주색 바탕에 흰 글자, 색 점에 흰 테두리.
- **쪽 이동 줄**
  - [이전 1 2 … 10 다음] 오른쪽 끝에 [≡ 10 ˅] 하나만 둔다.
  - 누르면 위로 10편 / 20편 / 30편 메뉴가 열린다. 바깥을 누르거나 Esc를 누르면 닫힌다.
  - "1–10 / 91편" 표시와 구분선은 두지 않는다.
  - 휴대폰에서도 한 줄 (320px까지 확인).
  - 현재 쪽은 2px 밑줄.
- **추천 카드를 실험하며 버린 것**
  - 여러 카드 스타일, 링크·새로고침·결과 수치, "추천" 이름 칸 시안 모두 버렸다.
  - 남는 교훈: 카드 오른쪽에 아이콘 칸을 따로 두면, 휴대폰에서 제목이 좁은 칸에 갇힌다.

### 3-3. 확인할 것

- **결정(D#) 공개 범위.** "제목 + 현재 선택 한 구절"은 `context/P*.md`의 문구를
  사이트에 싣는다. `site/CLAUDE.md`의 불변식("`context/`는 툴팁의 `D#` 제목
  너머로 공개되지 않는다")과 부딪친다. 옮기기 전에 불변식을 고칠지,
  "제목만"으로 갈지 정해야 한다. 조율실의 연구 축 페이지 문구는 비공개 시안에만 있다.

## 4. 신규 탐색 (`scout-new.html`)

페이지는 제목 띠 → 날짜 줄 → 추천 카드 → 후보 표 순서다. 묶음 제목은 없다
(분석 목록처럼). 카드와 표 모양이 둘을 가르고, 순위는 칩이 말한다.

### 4-1. 옵션으로 정한 것

| 항목 | 결정 |
|---|---|
| 묶음 제목 | 없음 (분석 목록처럼) |
| 연구 축 줄 | 빼기 — 탐색은 이미 연구 축별로 고른 결과 |
| 회차 고르기 자리 | 날짜 줄 (연구 축 줄 자리) |
| 날짜 줄 표시 | 날짜 + 편수 (`11.12 15`) |
| 회차 머리 | 없음 (날짜 줄이 회차를 보여 줌) |
| 추천 카드 글 | 모두 — 영어 원제목, 한 줄 요약, 평가 태그 |
| 추천 카드의 '1위' | 보이기 |
| 순위 표시 모양 | 칩 안에 `P2 · 2위` (카드와 표 공통, '추가'·'인접'도 같은 모양) |
| 평가 태그 | 카드에만 |
| 추천 카드 줄 나누기 | 줄을 고르게 — 5편이면 3 + 2, 짧은 줄의 카드는 넓어져 채움. 태블릿 두 칸, 휴대폰 한 칸 |
| 후보 목록 모양 | 분석 목록과 같은 표 — 열 제목 띠(arXiv · 논문 · 한 줄 · 연구 축), 제목 아래 한 줄 요약 |
| 논문 세부 내용 | 옆에서 열리는 서랍 (휴대폰은 아래에서 올라오는 시트) |
| 목록에만 오른 논문 · 근접 후보 | 보이지 않음 |

### 4-2. 옵션 밖에서 정한 것

- **날짜 줄**
  - 분석 목록의 연구 축 줄과 같은 카드다. 위치·폭·높이가 픽셀까지 같다
    (페이지 여백을 분석 목록과 같게: 데스크톱 위 1.5rem, 휴대폰 1.1rem .9rem).
  - 왼쪽 옅은 주색 칸의 달력 아이콘이 달력 버튼이다. 오른쪽 "달력" 버튼은 없다.
  - 달력은 아이콘 아래, 날짜 줄 왼쪽 끝에서 펼쳐진다. 휴대폰도 같은 팝업이며
    페이지가 아래로 이동하지 않는다. 바깥을 누르면 닫힌다.
  - 고른 회차는 주색 바탕에 흰 글자. 휴대폰에서는 옆으로 밀고, 고른 날짜가
    자동으로 화면 안에 들어온다.
- **추천 카드**
  - 윗줄: 연구 축 칩(순위 포함) 왼쪽, arXiv 번호 오른쪽. 번호는 arXiv로 연결된다.
  - 제목이나 카드 아무 곳을 누르면 세부 내용이 열린다.
  - 평가 태그 줄은 모든 카드의 아래쪽 같은 높이에 붙는다. 휴대폰에서는 태그를 뺀다.
- **후보 표**
  - 줄 어디를 눌러도 세부 내용, arXiv 번호는 arXiv로.
  - 마우스를 올리면 분석 목록처럼 왼쪽에 주색 선.
  - 휴대폰에서는 번호 / 제목 / 요약 / 칩이 세로로 쌓인다.
- **세부 내용**
  - 지금 사이트의 회차 페이지(`s/<날짜>/index.html`)가 이미 싣는 내용을 그대로
    보인다 — 논문 요지(문제의식 · 접근 · 성과), 연구 축별 시사점, 먼저 확인할 점.
  - 위쪽 머리: 연구 축·순위, arXiv 링크, 이름, 영어 원제목, 한 줄 요약, 평가 태그.
  - 닫기: ×, 바깥 누르기, Esc. 서랍은 내비 위에 뜬다.
  - 휴대폰에서는 지금 사이트처럼 시사점·확인할 점이 요지보다 먼저 온다.
- 학회 일정은 표시하지 않는다 (첫 화면에만).

## 5. 비교 (`cmp-new.html`)

분석 목록·신규 탐색과 같은 결: 제목 띠 → 연구 축 줄 → 카드. 묶음 제목은 없다.

| 항목 | 결정 |
|---|---|
| 연구 축 줄 | 두기 — 분석 목록과 같은 줄, 오른쪽 끝에 "9편 · 최근 날짜". 축을 누르면 그 축의 비교만 |
| 목록 모양 | 탐색 추천처럼 카드, 줄을 고르게 (9편이면 3 + 3 + 3) |
| 표의 둘째 줄 | 갈래 — 논문마다 입장 (표 모양으로 바꿀 때 쓰는 값) |

카드 하나는 위에서부터 이렇다.
- 윗줄: 연구 축 칩, 오른쪽에 작성 날짜.
- 질문 (제목 서체).
- `공통` 한 줄 — 둘 또는 셋이 같은 자리.
- 구분선 아래, 논문마다 한 줄: 이름과 그 논문의 입장.
- 카드를 누르면 그 비교 페이지로 간다.

## 6. 서재 (`shelf-new.html`) — 진행 중

- 위 줄 카드 하나에 아이콘 하나로 즐겨찾기·책갈피·메모를 묶는 시안은 어색해서 버렸다.
  종류마다 아이콘을 따로 두는 시안을 비교 중이다.
- 목록은 분석 목록과 같은 표다. 즐겨찾기는 저장일 / arXiv / 제목·한 줄 / 연구 축,
  책갈피는 둘째 줄에 책갈피 자리, 메모는 둘째 줄에 메모 앞 두 줄과 초안·게시됨.
- 내보내기·가져오기는 텍스트 버튼 대신 ⋯ 메뉴.
- 조율실은 예시 데이터를 보여 준다. 실제 저장소에는 쓰지 않는다.

## 7. 사이트로 옮길 때 고칠 코드

조율실은 빌드된 페이지 위에 CSS를 입히고 DOM을 옮기는 방식이라, 그대로
옮길 수 없는 부분이 있다.

1. **한 쪽 개수.** `filter.js`는 개수 버튼(`[data-size]`)에서 선택지를 읽는다.
   빌드가 10 / 20 / 30을 찍고, 쪽 이동 줄 끝의 메뉴로 옮긴다. `.pgstat`은 내지 않는다.
2. **가장 최근 카드 제거.** 카드를 빼면 그 논문의 목록 줄이 첫 쪽에 남아야 한다.
   조율실에서는 카드만 숨기다가 가장 최근 논문이 목록에서 사라진 적이 있다.
3. **제목 뒤 링크 아이콘.** 지금 `.row-main`은 제목과 한 줄 요약을 감싼 링크
   하나라 그 안에 링크를 넣을 수 없다. 제목을 링크로 만들고 `::after`로 클릭
   영역을 칸 전체로 넓힌 뒤, 아이콘을 그 위(`z-index`)에 둔다.
4. **연구 축 줄이 상단 띠 위로.** 상단 띠(`.mast::before`)가 제목 아래로 약
   58px 더 내려온다. 줄 카드에 `position: relative; z-index: 1`이 없으면 띠가
   카드 위쪽을 물들인다.
5. **현재 쪽 밑줄.** 안쪽 그림자(`inset box-shadow`) 대신 배경 그라데이션으로
   그린다. 일부 브라우저에서 가장자리에 세로 선이 남는다.
6. **고운돋움.** 조율실은 Google Fonts에서 받는다. 사이트는
   `site/builder/fonts.py`가 서체를 코퍼스 글자로 잘라 직접 싣는다. 같은 방식으로
   넣어야 한다.
7. **휴대폰 가로 밀기 힌트.** `mask-image`를 쓰면 카드 테두리까지 지워진다.
   끝에 붙는 `::after` 그라데이션으로 그린다.
8. **내비 현재 메뉴 밑줄.** 쪽 번호와 같은 까닭으로, 안쪽 그림자 대신 배경
   그라데이션으로 그린다.
9. **탐색 세부 내용.** 조율실은 회차 페이지를 불러와 `.sc-item`의 `.sc-body`를
   꺼내 쓴다. 사이트에서는 빌드가 새 탐색 페이지에 같은 내용을 직접 싣거나,
   회차 페이지로 보낸다. 표시 규칙은 `builder/scouting.py`가 이미 지키는
   공개 범위를 그대로 따른다.
10. **날짜 줄 카드가 넘치지 않게.** 달력 팝업을 보이려고 카드의 `overflow`를
    풀면, 카드가 내용 폭만큼 넓어져 휴대폰 페이지가 옆으로 밀린다. 카드와 그
    부모에 `min-width: 0`을 준다.
